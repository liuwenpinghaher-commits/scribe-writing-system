# 诡秘之主 · 拆文提示

规则真源配套：`docs/plans/2026-08-25-lotm-full-cards-loop.md`。  
密度样板：优先 `章卡/89.md`；若尚未落盘，段结构与成色对齐 `docs/worlds/乱世铜炉-拆文/章卡/89.md`（学结构，不搬铜炉故事）。

铁律：只根据原文；没写到写「正文未写到」；必须按索引只读该章；打开书压缩场面、有标点；禁整章糊进打开书；书证≥3 条带 `L` 行号。

## 第 1 轮 · 厚卡（`pass=chapters`，每章一张）

**责任：** 打开书，这一章是谁的日子、发生哪一件、读完地/人/日子/规矩变成什么样。把这一章里以后写书会翻的骨头留下。

```text
你只做索引里序号 = {seq} 的那一章。先读索引文件，找到这一行的标题和起止行。再用 read_file 的 offset/limit 只读这一章。不要读全书。不要把整章原文贴进卡里。

若索引这一行标了「空壳」：仍必须写这张卡。【打开书】写「正文几乎没有」；其余段写没有或正文未写到；turned=false；书证可写「本节行距过短，无句可引」。这算合格卡。

若目标卡已经存在，且任务未要求 force：先读旧卡。只有标题、下面没有写出谁/哪一件/世界怎么变，或书证没有带 L 行号的，视为不合格，必须重写。合格才跳过。

先问自己：打开书，这一章是谁的日子、发生哪一件、读完世界怎么变。问不清就再读，不要开始写。

按下面的段写到指定路径。每段只问一件事。没有就写没有或正文未写到。

【打开书】谁的夜或白日。发生哪一件事。读完地、人、日子变成什么样。这一章是谁的眼睛在看，还是说书的人站在外头评。

【这场戏有没有翻】开头这人站在哪一边，章末有没有翻到另一边。翻的是处境（安危、脸面、在不在路上、信不信、还欠着什么），不是气氛变热闹。没翻就写没翻——有热闹不等于有戏。

【日子】人在过什么日子。用这件事说。以正文为准，不要拿词去套。

【这一章落在哪一天】过年、节气、时辰、隔了多久。写不出就写正文未写到，不要编天数。

【人】出场的人各自要什么、做了什么。起哄、劝酒、报信、收钱、害怕、看热闹都算办事。谁只站着当家具，写明。若有人第一次出场：读者是靠他做了什么认识他的。能点名的人名都写下。

【地与走】在哪。换了地方，读者怎么看出他到的。没换就写没换地方。宅子、酒庄、狱里头换了哪一间，也算走。地名必须来自本章正文。

【这一章新讲明的规矩】术、官、钱、庙、禁忌、物件怎么用。原样记下。没有就写没有。

【钱与人情】谁因为银子、面子、酒桌、酬金、官差改了决定。没有就写没有。

【话】若有一段对上劲的对话：嘴里说什么，心里要什么，哪一句把局面推了一步。没有就写没有。

【热怎么变冷】笑闹/酒/日常切到怕/怪/凶/空，切在哪一个动作上。没有就写没有。

【怎么起、怎么收】第一段把人放进什么里。最后一段停在什么没做完的事上。章题是事变还是评点。

【叙述怎么插手】说书评点在人做事之后还是之前。学的是插在动作后的那一句，不是学半文不白。谁嘴里不能知道的，说书的人有没有评出来。有没有倒叙、插叙、预先把后头的事说了。没有就写没有。

【这一章放了什么】当时像闲笔、以后可能要响的东西。它在当场必须还在办自己的事，不能干等。没有就写没有。不要猜以后会怎样。

【这一章收了什么】以前露过的事，这一章真的发生了。没有就写没有。不要把「又提到一次」当成收了。

【谁比谁多知道】读者、说书、场上某个人，谁比谁多知道一点；这一点改了局面才写。没有就写没有。

【留给下一章的日子】读完，谁的日子改成什么样了。没有改就写没有。

【这一章回不去的事】谁死了、账改了、年没过成、路断了。没有就写没有。

【这一章人怎么叫人】新出现的称谓、口头禅。没有就写没有。

【可搬走的一条作法】只一条，带一句不超过四十字的书证和行号。写「以后写别的书可以怎么做」，不要写「把这本情节搬过去」。

【专名原样记下、下一本换自己的名】这一章出现的人名、地名、物件名、规矩名、点过名的妖鬼生灵，列出来供以后汇总。学的是结构，不要把这些名原样搬进下一本。

【书证】若干条，每条 L行号 + 短句。不要引用网站广告行。

ok=true 仅当文件已写（或合格跳过），且你用工具按索引起止行读过这一章。path=写入路径。title=章题原文。turned=这场戏有没有翻。place=主要地点；本章没写地点则空字符串。
```

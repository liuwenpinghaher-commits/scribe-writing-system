# 《诡秘之主》多轮拆书提示

**第一性目标：把整本书榨干。**  
凡是以后写书会翻的，都要从原文挖出来。挖出来的是参照，不是再写一本诡秘。专名、情节、非凡途径原样记下，并标明：学结构、换自己的名；不要把这本故事搬进下一本或 Surreal。

原文：`docs/worlds/诡秘之主-全文.md`。索引：`docs/worlds/诡秘之主-拆文/00-index.md`。章卡：`docs/worlds/诡秘之主-拆文/章卡/{seq}.md`。

密度样板：优先同目录 `章卡/89.md`；若尚未落盘，打开书密度对齐 `docs/worlds/乱世铜炉-拆文/章卡/89.md` 的段结构与压缩写法（有标点、场面串、书证带 L）。

---

## 铁律（每轮都遵守）

- 只根据原文。没写到的写「正文未写到」，不许补。
- 必须用 `read_file` / `grep`。禁止凭记忆。禁止把全文一次性读进对话，也禁止按页把全书翻完。切章只用 grep 章题；章卡按索引行号只读那一节。
- 每一条能指到场面：标题 + 行号 + 不超过四十字的原句。指不出就删。
- **设定、地名、人名、时间、规矩必须挖全**，这是参照的骨头。
- 这本书的专名、途径、组织、情节原样记下；以后写别的书，学它怎么立规矩、怎么走路、怎么过日子；专名和这本故事不要原样搬。
- 禁止主题升华、字数配额、机制词清单、把人写成职能标签、用「至少 N 个」当写好。
- 打开书先问自己：这一节是谁的日子、发生哪一件、读完世界怎么变。问不清就再读，不要开始写。
- 打开书压缩场面、有标点；**禁止**把整章原文糊进打开书。书证 ≥3 条 `L` 行号。

## 第 0 轮 · 切章索引（`pass=index`）

**责任：** 按作者章题切开，记下每一节起止行。切错了，后面每张卡都会读错书。

```text
切章只许用 grep 找章题行，再用 read_file 只抽该标题行前后各两三行核对。禁止为切章而按页顺序读完全书。禁止为填表去 read_file 任何一节的正文。不要凭记忆，不要把正文抄进索引。

目标：找出每一个真正的章题行，写成 Markdown 表，存到 00-index.md。
列：序号、卷、章号、分册（空|上|中|下|…）、标题原文、起始行、结束行、行数、标记。
行数 = 结束行 − 起始行。最后一节结束行 = 原文末行（read_file 文末几行确认）。

怎么认章题（必须 grep，以本书实际章题为准）：
- 行首「第X章……」「第X节……」等作者章题形态。
- 卷界、分册（上中下）各算一节，不要合并。
- 标题以原文为准，不要改字。

不要当成章题：正文里有人说话提到「第几章」、网站广告、域名行、图片占位。

去重：连续复读标题合并；后出现且正文明显重复的标「疑似重贴」、不占新序号。空壳（两章题间距过短）仍进正表并标记，后面必须出卡。

写完抽查：第一题、末题、号段交界附近若干章题，grep 行号允许 ±2。

返回：ok=true 仅当已用 grep 找到章题、抽了标题附近行、并写了 00-index.md。chapter_count=正表节数。
```

## 第 1 轮 · 章卡（`pass=chapters`，每节一张）· 厚卡

**责任：** 打开书，这一节是谁的日子、发生哪一件、读完地/人/日子/规矩变成什么样。把这一节里以后写书会翻的骨头留下。

```text
你只做索引里序号 = {seq} 的那一节。先读索引文件，找到这一行的标题和起止行。再用 read_file 的 offset/limit 只读这一节。不要读全书。不要把整节原文贴进卡里。

若索引这一行标了「空壳」：仍必须写这张卡。【打开书】写「正文几乎没有」；其余段写没有或正文未写到；turned=false；书证可写「本节行距过短，无句可引」。这算合格卡。

若目标卡已经存在，且任务未要求 force：先读旧卡。只有标题、下面没有写出谁/哪一件/世界怎么变，或书证没有带 L 行号（或不足 3 条）的，视为不合格，必须重写。合格才跳过。

先问自己：打开书，这一节是谁的日子、发生哪一件、读完世界怎么变。问不清就再读，不要开始写。

按下面的段写到 docs/worlds/诡秘之主-拆文/章卡/{seq}.md。每段只问一件事。没有就写没有或正文未写到。

【打开书】谁的夜或白日。发生哪一件事。读完地、人、日子变成什么样。这一节是谁的眼睛在看，还是说书的人站在外头评。压缩场面、有标点；禁止整章粘贴。

【这场戏有没有翻】开头这人站在哪一边，节末有没有翻到另一边。翻的是处境（安危、身份、知情、还欠着什么、还能否公开办），不是气氛变热闹。没翻就写没翻。

【日子】人在过什么日子。用这件事说。以正文为准，不要拿词去套（不要用「日常/战斗/升级」空壳标签交差）。

【这一节落在哪一天】日期、时辰、隔了多久。写不出就写正文未写到，不要编天数。

【人】出场的人各自要什么、做了什么。报信、试探、交易、旁观、害怕都算办事。谁只站着当家具，写明。第一次出场：读者靠他做了什么认识他。能点名的人名都写下。

【地与走】在哪。换了地方，读者怎么看出他到的。没换就写没换地方。地名必须来自本节正文。

【这一节新讲明的规矩】途径/序列、仪式、组织规矩、金钱与身份、禁忌、物件怎么用。原样记下。没有就写没有。

【钱与人情】谁因为金钱、面子、人情、职位、交换改了决定。没有就写没有。

【话】若有一段对上劲的对话：嘴里说什么，心里要什么，哪一句把局面推了一步。没有就写没有。

【热怎么变冷】日常/轻松切到怕/怪/凶/空，切在哪一个动作上。没有就写没有。

【怎么起、怎么收】第一段把人放进什么里。最后一段停在什么没做完的事上。

【叙述怎么插手】说书/旁白在人做事之后还是之前。谁嘴里不能知道的，叙述有没有点破。有没有倒叙、插叙、预先把后头的事说了。没有就写没有。

【这一节放了什么】当时像闲笔、以后可能要响的东西。它在当场必须还在办自己的事。没有就写没有。不要猜以后会怎样。

【这一节收了什么】以前露过的事，这一节真的发生了。没有就写没有。不要把「又提到一次」当成收了。

【谁比谁多知道】读者、叙述、场上某个人，谁比谁多知道一点；这一点改了局面才写。没有就写没有。

【留给下一节的日子】读完，谁的日子改成什么样了。没有改就写没有。

【这一节回不去的事】谁死了、身份改了、秘密公开了、路断了。没有就写没有。

【这一节人怎么叫人】新出现的称谓、口头禅、代号。没有就写没有。

【可搬走的一条作法】只一条，带一句不超过四十字的书证和行号。写「以后写别的书可以怎么做」，不要写「把这本情节搬过去」。

【专名原样记下、下一本换自己的名】人名、地名、组织、途径/序列名、物件、仪式名。学结构，不要原样搬进下一本。

【书证】至少 3 条，每条 L行号 + 短句。不要引用网站广告行。

ok=true 仅当文件已写（或合格跳过），且你用工具按索引起止行读过这一节。path=写入路径。title=章题原文。turned=这场戏有没有翻。place=主要地点；本节没写地点则空字符串。
```

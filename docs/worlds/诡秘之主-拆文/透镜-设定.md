# 世界靠什么规矩转

规矩原样记下。禁止拿途径总表冒充本节。

---

规矩原样记下。**禁止拿途径总表冒充本节**——那是设定表，不是规矩。规矩的意思是：它在某一场戏里让某个人不得不改主意、不得不付钱、不得不认栽。下面每一条都尽量挂着那一场。

### 世俗这一层：警察、法律、报纸

**警察是十五六年前才有的东西。** 制服黑底白格，徽章软帽，肩章三颗银制六角星高于两颗、高于三个 V。他小时候还叫治安官。命案要见报，报纸一便士——工业化造纸和印刷之后的价，蒸汽列车往外地分发。凶案的官方说法可以由值夜者改写：韦尔奇案对外是「入室抢劫杀人，值钱的都没了」。

**济贫法能把人从街上赶走。** 「这是《济贫法》的规定！」——全书最后一部里仍然在用这句话赶睡在街上的人。世俗的法在这本书里从头到尾没变软过。

- 第二百一十三章 再看一眼 L18854：「这是《济贫法》的规定！」

**热武器半管制。** 全类武器使用证极难拿，狩猎证容易，限猎枪且有数量。这条直接卡住主角能不能光明正大带枪。

### 钱：三层货币，周薪定体面

**货币三层，写得很死。** 苏勒来源于古代银币，一苏勒等于十二铜便士，有一和五两种面值；顶端是金镑，纸币但以黄金作保障并直接挂钩，一金镑等于二十苏勒，有一、五、十三种面值。

- 第四章 占卜 L248：一苏勒等于十二铜便士，有一和五两种面值。
- 第四章 占卜 L249：一金镑等于二十苏勒，有一、五、十这三种面值。

**周薪不是收入，是身份。** 合同每周 3 镑。妹妹嫌花钱，他只能上大道理：既然拿 3 镑的周薪，就要有匹配 3 镑周薪的体面。同一章立刻给了参照系：事务律师克里斯也接近 3 镑周薪，订婚超过四年、还在攒钱、打算再等至少一年才进教堂。**同一个数字同时是他的阔气和别人的窘迫**——这是这本书写钱最狠的一手。

- 第二十三章 副手武器 L2170：五年合同，每周3镑。
- 第二十四章 节俭持家 L2188：既然拿3镑的周薪，就要有匹配3镑周薪的体面。
- 第二十四章 节俭持家 L2202：他们订婚超过四年了……直到今天还在攒钱

**房子只能租，买不起是算出来的。** 公司不出售房产；旁例是地契十五年三百镑、买断八百五十。他自己心算：周薪三镑加班森一镑十苏勒，吃好一周近两镑，一年攒约三十五镑，八百五十镑要二十几年。租金从十三苏勒加五便士家具、四周押金，谈到十二苏勒、三便士、押金两镑，一式两份加公证。同一栋两居租给三口人是五苏勒六便士。

**物价是随手报的，不是设定表。** 公共马车超过四公里四便士；黑麦啤酒 1 便士、恩马特 2、南威尔 4；香煎肉鱼六到八便士，黑胡椒牛肉五便士，姜啤一便士，一磅奶油一苏勒三便士；一顿大约一苏勒六便士；报纸一便士；银行兑换收千分之五。《谷物法案》废除后黑麦从 11 便士降到 9——法案在这本书里是靠面包价出场的。

### 官方这一层：值夜者、教会、门

**入职先签的是保密，不是薪水。** 违反不走王国法庭，由黑夜女神教会仲裁庭处理，像军人上军事法庭；五年合同；没有印章就按指纹；对外叫黑荆棘安保公司。裁判所、仲裁庭、处刑机关里非凡者依旧存在——这是主角刚穿越时最怕的一句。

- 第六章 非凡者 L513：在仲裁庭，在裁判所，在处刑机关，非凡者依旧存在

**查尼斯门不能随意进。** 黑铁对开，七枚圣徽，队长值守时不能离开。这扇门全书没有被写成说明书，一直只作为「有人必须守着」的位置存在。

**对普通人严格保密是有理由的，理由由招他的人说出来。** 文职可以先听秘密再决定要不要当非凡者；想当也未必能当，各大教会同样严格；队员和文职绝大部分来自教会内部。他被邀请的三条理由摆在桌面：活下来说明有优点比如幸运；他在历史系常碰第四纪文献有泄密风险；他已经沾上事件了。

**圣堂考查决定能不能拿到下一瓶。** 功勋才能申请配方和材料；超过 50 岁不能再服药，即使消化了也不行。晋升在这本书里是**审批**，不是打怪。

### 魔药与序列：名字就是钥匙

**魔药的关键不在拿到手。** 罗塞尔日记原话：魔药的关键不是掌握，是消化；不是挖掘，是扮演；魔药的名称也不仅仅是核心象征，还是具体意象，更是消化的钥匙。全书所有晋升的规矩都从这一句长出来。选错途径不能回头。

- 第二十一章 他乡遇故知 L1946：魔药的关键不是掌握，是消化！不是挖掘，是扮演！

**材料是会枯竭的。** 北大陆超凡物种逐渐消亡，没有它们就没有更多魔药，非凡者越来越少；巨龙、巨人、精灵变成书上的记载，海族不再靠近海岸。这一条让「变强」在世界层面是有限资源，不是无限刷。

**低序列配方是能写出来的，也真的写了。** 观众序列 9：八十毫升纯水、五滴秋水仙精华、十三克牛齿芍药粉末、七瓣精灵花、一对成年曼哈尔鱼眼睛、三十五毫升羊角黑鱼血。分量宁愿少不要多。这里学的是**把神秘写成配料单和克数**，不是学这张单子。不要补途径全表。

### 扮演法与失控：全书唯一那条注意事项

**注意事项只有一条。** 白银城通识课讲得非常清楚：扮演法的注意事项只有一条——记住，你只是在扮演。教会执事的描述基本一致。全书最关键的规矩，正文只肯给这一句。

- 第一百五十八章 有备无患 L14149：「扮演法」的注意事项只有一条，「记住，你只是在扮演」。
- 第一百六十八章 “小丑”魔药 L14954：这是白银城总结出来的唯一注意事项

**代价是人会被抽空。** 到不死者末章，他要靠把情绪完全抽离、以冷漠旁观的姿态注视一切才能不被戏剧里的情感影响；紧接着场上同时站着有疼痛的克莱恩、傲慢的克莱恩、冷酷的克莱恩、温柔的克莱恩，还有周明瑞、夏洛克·莫里亚蒂、格尔曼·斯帕罗、道恩·唐泰斯。扮演到最后，人被扮成了好几个。**这才是这本书的收费方式**。

- 第二百一十四章 一个恩赐，或者，一个诅咒 L80392：将情绪完全抽离了出来，以冷漠旁观的姿态注视着一切
- 第二百一十四章 一个恩赐，或者，一个诅咒 L80398：这有疼痛的克莱恩，这有傲慢的克莱恩，这有冷酷的克莱恩

**失控的门槛是灵性和材料里的残留。** 超凡材料的灵性残留是配药关键，也是失控根源之一。刚晋升开灵视会眉心抽、头痛、敏感、少许幻觉、易被别人情绪影响，要反复练习、节制、及时结束；退出有一套动作，他给自己设的开关是敲眉心两下——一下易混，三下浪费。

### 仪式与祈求：向谁求，代价是什么

**向外祈求只能找正统神灵。** 低序列者本身还不够强大，能做的几乎所有仪式魔法都是向外祈求，所以只能考虑女神、风暴之主等正统神灵，绝对不要试图沟通未知的、难以预料的存在，哪怕有人信奉祂们，哪怕记载的承诺充满诱惑。尝试过一次就会滑向深渊，努力只能延缓。

- 第五十一章 接地气的仪式魔法 L4676：绝对，绝对不要试图沟通未知的、难以预料的存在

**格言就是防失控的绳。** 窥秘人的格言：为所欲为，但勿伤害。严格遵守并敬畏，失控风险最低；反过来也成立。占卜家没有对应格言——正文明说没有，这个缺口后来一直空着。

- 第五十一章 接地气的仪式魔法 L4662：难道邓恩没有告诉你窥秘人的格言吗？为所欲为，但勿伤害！

**普通人做仪式要挑日子，非凡者靠灵性。** 普通人要占星选日期时间；非凡者尤其擅长者，蓬勃的灵性和强大的星灵体才是关键，没把握时再选合适的日期提高成功率。日期在这里第一次跟「实力」挂钩。

### 物件：当场干什么，后来另有没有用

封印物按危险分级，编号写死（0-08、2-049、3-0782……）。神奇物品有灵性之墙可以隔断。收尸人的小壶能压恶臭反胃；铜哨能让死灵改换归属；符咒是一次性的、有配额；配额用尽要等下个月恢复。物件在这本书里的规矩是：**当场必须有用，后来还能再用一次，但每用一次都留下账**。不要把它们列成道具栏。

### 势力与行当

七大教会（黑夜、风暴、蒸汽与机械、大地母神、战神、知识与智慧、诡秘）、值夜者与特殊行动部、军情九处、机械之心、心理炼金会、极光会、密修会、摩斯苦修会、魔女教派、收尸人、塔罗会、海盗团与各家船。俱乐部也是行当：填资料、初次五年费五镑、之后每年一镑，免费会议室占卜房工具咖啡茶，成本价午餐晚餐酒和教材材料。

信仰按地方分：鲁恩多信仰；弗萨克只服从战神；费内波特唯大地母神。风暴、黑夜、蒸汽三大教会千百年磨合，相对克制。这几句一出，地图就有了政治。

### 有没有一个人独有的便宜

有，而且是全书最大的一处：**源堡**。晋升古代学者后，他对源堡有了初步掌控——无论是谁，是否掌握了正确的仪式和相应的咒文，要想进入灰雾之上，都必须得到他的允许。主角的金手指在这本书里最终被写成**一道门禁**，不是一件武器。

- 第一章 欺诈 L97041：要想进入灰雾之上，都必须得到他的允许！

# 话与知情

对话何时在办事。谁嘴里不能知道什么。

---

**对话何时在办事。** 「你杀了我吧」连说三轮，把报价挡回去。门不敢敲的那句是心里话，没说出口，一样办事。梅丽莎「不用害怕」把孩子从姑姑身后送到祭台前。出诊里「你对未来有什么期望」把半神按在墙后说话。婚礼上「我愿意」把这一户的日子落到旁人身上。督察「又要见报了」把东区死人推进晚报。

**谁嘴里不能知道什么。** 对奥黛丽不说地球。塔罗桌上互不知马甲。孩子只看见可怕又挥手的东西。阿蒙比克莱恩多知道仪式必失败。出诊里他用童话问她：如果父亲母亲哥哥都是空想出来的。她听见的是希望破灭，不是地球。墙后不能把真话说完。

**读者比场上人多知道什么。** 触手是谁；6 月 28 日等着被倒推；单片眼镜以后会变味。婚礼角落空着的位置，梅丽莎扭头看见没人，读者知道谁坐过。不要提前在场上人嘴里说破。

**说书的人站在哪。** 独白插在动作后。上课出现在身份设计、尊名原理——可搬停顿，不要搬课。看见左轮才愣住；看见空座位才酸；看见触手才停几秒。评点不要抢在看见前面。人还在搏斗时不要先上课。

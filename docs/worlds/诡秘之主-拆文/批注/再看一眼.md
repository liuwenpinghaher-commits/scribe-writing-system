# 再看一眼

克莱恩这一日。墓园到广场。学：要走，先看见门，伸手又缩回。

---

## 段间

### 地还在过

> 他发现自己正站在水仙花街，对面是自己和哥哥、妹妹共同的家。

批：本能地回来。联排还在。家没有先变成废墟。

### 手为什么停

> “我这要是过去敲门，梅丽莎恐怕会当场晕过去吧……”

批：能扶，不能认。想象里妹妹晕、哥哥掉头发。门始终没被这个哥哥敲开。

### 告别交给别人办

> 只见他满是红黄白等各色油彩的脸上，嘴角高高翘起，固定着一个快乐的笑容

批：热切在别人的笑脸上。自己的告别交给小丑办。油彩笑是假告别，缩回的手是真回不去。

### 票

> 克莱恩想了想，买了下午两点的那班，二等座。

批：翻的是这户日子他还过不过得成，不是去首都热闹。济贫法还在赶人，世俗这一层没因为他要走就变软。

## 因文

1. 一行本事：他不敢认亲，买了去首都的票。
2. 为什么不能一行：一行是离开。要写的是花由别人递。
3. 文活在哪：缩回的手；固定的笑；二等座。
4. 删了会怎样：只剩去贝克兰德。
5. 下一本偷伸手又缩回。不要自己上去认。

# 出诊

东区两居室。学：半神去看病，先让人进别人的命案和一堵墙。

---

## 段间

### 别人的房间

> 贝克兰德，东区，一个两居室的房间。

批：开门不是升级。地方是租客的命案。警察跟着房东进去。

### 掩嘴

> 里面弥漫着强烈的血腥味！

批：房东不敢多留。督察戴白手套。热在例行出警，冷切在血味。

### 桌上的牌

> 以及一叠散开的塔罗牌。

批：经济状况一般的神秘学爱好者——这是警察的判断。灰雾那一层的物件落在东区橱柜旁边。三层撞在同一间屋里。

### 床上的人

裂痕细而深，像铁丝勒进骨头。翻的不是主角功力，是旁人的日子把官方按到现场。家人是奢望如果要出口，落在现场，不要落在独白课上。

## 因文

1. 一行本事：半神去看一桩东区命案。
2. 为什么不能一行：一行是查案。要写的是墙后问诊，人先塌在别人的床上。
3. 文活在哪：两居室；白手套；散开的塔罗牌。
4. 删了会怎样：只剩非凡者现场。
5. 下一本偷先让人进别人的命案。不要剖心。

# 这一晚

文德尔这一夜。学：换卷不写主角，先让人进自己的被窝。

---

## 段间

### 门窗洞开

> 深夜，哐当哐当的门窗洞开声让文德尔从沉睡中惊醒

批：几天没睡好。地方先变，人后醒。不要从愚者眼睛写这场。

### 这是哪

> 究竟发生了什么事情？乌托邦遭遇了特大风暴？

批：他还当自己在乌托邦。判断靠闭馆时间：就算早起，也来不及在王国博物馆闭馆前赶到贝克兰德。城换了，日历不给。

### 旁人的床

翻的是人还在不在乌托邦。名片、被窝、别人的城。前传那个人不在这场日晒屋里——这场也一样，克莱恩不在文德尔的被窝里。

## 因文

1. 一行本事：乌托邦没了，他醒在贝克兰德。
2. 为什么不能一行：一行是换地图。要写的是自己的被窝先在，判断后到。
3. 文活在哪：门窗洞开；闭馆来不及。
4. 删了会怎样：只剩设定崩塌。
5. 下一本偷换城不写主角。一张判断告诉他日子不是了。

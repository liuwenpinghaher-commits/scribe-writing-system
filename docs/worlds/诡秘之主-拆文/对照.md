# 对照：远近、假破真、办事

已有的戏，点名给下一本偷。不要新理论。专名原样。换自己的名。

不要学：开篇必须一个强钩子、三章交代主线、努力三次失败、黄金三章、途径表开书。诡秘先立请假的夜，周明瑞这个名后文几乎丢掉。

---

## 一、距离：近了才共情，远了只旁观

近：绯红跟进周明瑞的痛和镜子。读者跟他一起看见洞。痛！手枪？左轮？

远：牺牲者大段解释如何瞒亚当。门先生停滞在那里，评点先上课。人还在搏斗。

不从自己眼里看：这一晚文德尔从沉睡里起来；文末阿兹克和姑姑。前传那个人不在这场日晒屋里。

下一本：要人共情，把眼睛交给当场那个人。换卷可以先让旁人进被窝。

## 二、假 → 破 → 真

再看一眼：油彩笑是假告别，缩回的手是真回不去。我这要是过去敲门——没敲。

欺诈：源堡仪式是假希望，看绝望才是真。你以为我不知道刚才的仪式最终无法成功吗？

光：丰饶覆盖是假单纯的活路，有代价才是真账。战争就这样结束了——亲眼看见才肯信。

希望之地：下车是假翻身，街上还没租到房才是真日子。6 点 39 分，没有晚点多少。不要把换城写成翻。

下一本：要落一个真意，先给反面，再破功。

## 三、办事，不剖心

嘴上要变强、要回家、要 3 镑体面；真正缺的是门还进不进得去。看见谁办了哪一件，日子怎么变。不要鉴定式人设。

班森借债点灯是办事。梅丽莎不坐公共马车是办事。邓恩把心脏塞进骨灰盒是办事。你杀了我吧是办事。不用害怕去和他打个招呼是办事。

下一本：用办事说。开篇先立还在过的日子。

## 四、不要学的几处

归来记大段三层身份，敲门才办事。牺牲者大段解释瞒亚当。希望之地换地没翻。开合之间一千多章未抽，不要当成世界很大。部总结当正文——不要。设定讲解腔——不要。途径总表冒充规矩——不要。

# 三层怎么互相要账

禁止途径等级表。细账和书证见参照本第三节。

1. 过日子的城向谁要账：济贫法赶人；东区见报；周薪房租；公共马车她不坐。梅丽莎为了省钱自己走。雾霾死人进报纸。

2. 教会和官方向谁要账：查尼斯门必须有人看守；五年契约；圣赛琳娜的骨灰。危急关头邓恩把心脏塞进骨灰盒。军情九处只知道莫妮卡没有姓。

3. 灰雾聚会向谁要账：出诊墙后的人塌了，正义还在，缺了世界这场会少问诊不会少晚会。她请求愚者做交易的见证。塔罗会不是城。

4. 三层撞上：雾霾死人进报纸，晚会还在过。东区两居室里散开一叠塔罗牌。魔药落到还能不能当人：扮演把人按住，失控把老尼尔收成糜烂血肉，丰饶把将死之人按在原地。

5. 落到日子：还能不能当人、还能不能开门、城还欢不欢呼。回不去了。你杀了我吧。触手停了好几秒。

# 人都有谁

点过名的人。第一面靠当场办的那一件。

---

点过名的人。每个写：名、第一次在哪一章、读者靠哪个动作认识他、正文最后还在不在。只站着的写明是家具。没点过名的不要编。名录文末自己写了「这一轮没挖全」的名单，这里不假装写过。

### 打开书那一夜

- 第一章 绯红 L36：手枪？左轮？周明瑞整个人都愣住了

### 只站着的、只在嘴里的

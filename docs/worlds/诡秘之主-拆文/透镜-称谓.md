# 人怎么称呼、口头禅是什么

叫法一改，关系就翻。

---

谁叫谁什么。口头禅是哪一句。一开口就能听出是他。叫法一改，关系就翻。堆「先生、阁下、女士」交差的，不算。

**马甲随场合。** 家里是克莱恩；贝克兰德侦探是夏洛克；海上是格尔曼·斯帕罗；阔气门牌是道恩·唐泰斯。灰雾上是愚者。学的是**换地方换称呼，同一张桌子上的人互不知马甲**。报假名是当场办事，不是人设标签。

- 第二章 萨默尔太太 L19014：「夏洛克·莫里亚蒂，你可以直接叫我夏洛克。」
- 第一章 新的身份 L42824：根据克莱恩的意思，他叫做格尔曼·斯帕罗。
- 第二百五十章 终点 L63677：「道恩·唐泰斯。」

**塔罗桌上的代号。** 愚者、正义、倒吊人，后来世界、太阳、月亮、隐者。代号是保密，也是关系：她叫愚者先生，他不叫她奥黛丽。第一场她请求见证，他选倒吊人。

**卷毛狒狒。** 这一户的尺。班森先用，克莱恩接。后文家里人仍能用，说明还是这一户。不敢敲门时他替班森想的那句也带着卷毛狒狒。

**尊名。** 三句：不属于这个时代的愚者；灰雾之上的神秘主宰；执掌好运的黄黑之王。第四句是他用来防自动回应的：「贝克兰德魔术和戏剧表演的保护者。」阿蒙把门开到一半问出来。孩子乱码也能点烛——文末她不会古赫密斯语，仪式仍成。

**赞美女神 / 阁下 / 先生。** 世俗礼节和宗教仪轨分开。胸前点四下勾绯红之月。牧师回以同样的动作。这一轮没把每部的称谓表抽全，细节见厚卡「人怎么叫人」。

**一开口只能是他。** 早期克莱恩是请假和吐槽；阿蒙是正眼镜再报价；梅丽莎文末是「不用害怕」；邓恩是忘了刚才说什么。找不到专属那一句的，写正文未写到，不要编口头禅给人戴上。

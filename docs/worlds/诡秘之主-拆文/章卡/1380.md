# 1380 倒吊人 第二十八章 权柄

## 打开书
知识与智慧之神教会总部那座白色高塔内。被困在地底卢卡·布鲁斯特完成祈祷后将注意力放回封印加强这件事情本身。他想研究下究竟是怎么一个情况看能否破解出其中蕴藏奥秘以此发明一些秘术。一层一层下行间一件封印物一件封印物检查中卢卡突然愣住停下脚步。……南大陆一座属于黑夜女神教堂旁边。……我刚才想做什么？……黄金梦想号最近又来到苏尼亚海停在有电报某个港口达尼兹想盛情邀请他们来拜亚姆做客见识一下神使大人体面。如果可以他希望黄金梦想号能以拜亚姆为母港这样一来他随时可以回到船上参加冒险寻找宝藏同时还能有选择听一听船长讲课。……比我预想得速度快就算以后失业我也能去电报局找一份薪水不错工作。达尼兹有点骄傲又有点忧患意识想道。……我最后究竟发了什么？达尼兹忍不住低语一句。他最后似乎大概可能在电报里嘲讽大副二副铁皮水桶他们然后热情洋溢向船长做告白。完蛋了完蛋了……我怎么会把心里话说出去……达尼兹脸色一点点变白怀疑自己刚才被魔药控制写内容竟然没经过大脑。……星界之中被黑夜女神隐秘掉存在和事物有一定先后顺序突破限制回到现实。……另外黑夜女神也略带迷茫停在半空似乎还没想好接下来该做什么不过祂本能是先做好自我防护。被厚棱镜似光斑限制在各自神国内风暴之主永恒烈阳知识与智慧之神同样出现一定变化反击激烈程度明显降低给人一种开始自我怀疑不确定眼前是否为敌人感觉。灯神丢下特伦索斯特黄铜书直接回归那盏许愿神灯内。祂既像拼到极限不得不缩回封印之中又似乎想起什么下意识做出躲避。……要有光！星界之中光芒随之变亮刺入阿蒙真身分身原初魔女隐匿贤者等存在眼中。……这些门同时打开又同时关闭让黑夜女神等存在都无法把握到阿蒙真身究竟是从哪里离开。这是利用一个漏洞将阿蒙真身远离等于阿蒙们远离。……这位空想家脚下那片包容着所有颜色所有可能大海刹那消散仿佛回归地底。……祂和真实造物主融合只是刚刚开始还未结束刚才提升至半个旧日尝试其实相当勉强和冒险——这会让祂们接下来进度不得不放缓许多。……风暴之主永恒烈阳知识与智慧之神先是粉碎神国外面厚重光斑然后就安静下来和之前一样继续堵着世界屏障裂缝。漂浮于古老宫殿上方黑夜女神收起漆黑棺椁黄昏巨剑鸟型黄金饰品和四条手臂将目光投向下方。……他刚抬起脑袋望向黑夜女神蒙着薄薄黑纱脸孔身外就浮现出一件漆黑斗篷斗篷下方一根又一根滑腻邪异触手延伸出来。成为愚者后他体内福生玄黄天尊毫无疑问又更进一步复苏了。……诡秘之主没有任何办法杀死即使祂意志会被时间一点点消磨祂精神也将永存随时可能夺取克莱恩身体彻底复活。若非刚杀一次诡秘之主意志让此时苏醒祂比克莱恩预想得弱一点克莱恩都怀疑自己未必能撑得过去只能眼睁睁看着身体崩溃自己变成另外一个存在。当然他还能请黑夜女神帮忙给自己一滴永暗之河河水但这绝不是长久办法只能拖延一段时间他终究要面对。靠着自身意识和锚克莱恩平衡起体内天尊意志。……飘于上方黑夜女神轻轻颔首道：你现在最需要是稳定。……克莱恩侧头看眼还有点迷茫安提哥努斯念头一转拿走许愿神灯和0-02这两件物品返回源堡。……源堡内部克莱恩坐至愚者那个位置专心致志稳定起自身精神状态。和之前一样初步稳定前他没法寻求心理医生治疗除非去拜访空想家亚当但那很可能会疯得更加厉害。……它叫愚弄！它不仅包容历史时间命运变化和隐秘部分权柄还是心灵领域里盲目痴愚象征——这最简单应用就是降低敌人智商。……源堡被谁入侵了！而直到对方入侵成功克莱恩才获得提示！……这位错误先生眼中染着少许幽黑笑容显得有点疯狂。……惊喜吗？克莱恩想要调动源堡驱除对方却发现阿蒙不知什么时候也拥有源堡掌控权！……我放开对体内诡秘之主意志压制。祂是源堡主人等于我也是源堡主人当然可以进来。这很冒险即使是我之前都不敢尝试但既然你成长到现在这个程度我只好冒险了。这很刺激效果还不错。……祂主动让诡秘之主部分复活让自己陷入半疯状态。

## 这场戏有没有翻
翻了。开头凡界「愚弄」后遗（忘事／达尼兹电报告白）；神们迷茫；亚当要有光掩护阿蒙用「真身远＝众远」Bug撤；半旧日收；克莱恩愚者触手稳天尊；女神叮稳定；回源堡得愚弄权；章末阿蒙放天尊半疯共掌源堡「惊喜吗」。翻的是权柄＝愚弄落地＋源堡遭闯。

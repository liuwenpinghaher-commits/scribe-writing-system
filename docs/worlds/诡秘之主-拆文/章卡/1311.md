# 1311 倒吊人 第四十六章 全自动许愿机

## 打开书
间海郡利蒙市。贾斯敏将围巾包裹在脸上走出公寓大门。她听说一年一度利蒙狂欢节已经开始想去市政广场那边看一看。去年这个时候因为战争缘故狂欢节没有举行让贾斯敏很是失望而之后她遭遇人生中最大创伤一直躲在家里不敢也不想外出。……小姐你知道这台机器是做什么吗？……它叫全自动许愿机。那年轻男子笑着介绍道这是我发明可以自动化地实现操纵者愿望对了忘记自我介绍了我叫梅林·赫尔墨斯一位流浪魔术师。全自动许愿机……贾斯敏发现自己每个单词都能听懂却没办法将它们组合在一起。你可以试试作为第一位体验者免费。化身梅林·赫尔墨斯克莱恩含笑说道。……比如你可以许一个让自己变回原本样子愿望。……不试一试你又怎么知道愿望不会实现呢？又不需要你付出什么。克莱恩看着她背影语速不快不慢说道。……真的？她嗓音生涩问道。……我可以退出十米远而你需要做事情就是转一下那台机器上扳手。不用你摘掉帽子和围巾。……好。等到梅林·赫尔墨斯退出一段距离贾斯敏才靠近那台机器小心翼翼探掌握住门扉上扳手。……转动之前记得许下你愿望。不远处克莱恩提醒一句。……我想变回被火烧伤前样子。……下一秒钟那台全自动许愿机门扉打开伸出来一根普普通通原木色手杖触碰贾斯敏额头一下。……等到那原木色手杖缩回全自动许愿机内部这枚镶嵌红宝石金戒指也跟着消失了。齿轮转动声音里贾斯敏看见机器门扉缓缓合拢。……祝贺你愿望实现了。克莱恩走回来轻轻鼓掌如同一位见证者。……您是神吗？我只是一个喜欢创造奇迹魔术师。克莱恩微笑指指旁边机器你最该感谢是它全自动许愿机。……对不需要别人帮忙可以自行运转全自动许愿机。你可以理解成瓦斯计费器只要投入硬币就能像获得煤气一样实现愿望。具体步骤很简单投入1便士许下你愿望然后转动扳手。记住只能实现三个愿望。……如果哪天我不幸死去变成封印物希望是类似全自动许愿机东西。……它我是说这台全自动许愿机会一直在这里吗？贾斯敏犹豫着开口问道。不会。它可能会在这里待三天也可能没那么久或许太阳升起时候它就会消失。但它不会永远不见或许有一天你又会在街道拐角地方看见它。……谢谢您全自动许愿机先生。……谢谢您赫尔墨斯先生。……可以实现三个愿望？对但之后不再免费需要投入硬币。克莱恩一点也不介意地回答道。

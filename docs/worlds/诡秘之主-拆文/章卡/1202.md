# 1202 逐光者 第五十三章 收获

## 打开书
灰雾之上古老宫殿内。一道道深红星光蹿起形成几道身影。星星伦纳德随意扫一眼目光突然凝固停在斑驳长桌上摆放那个银黑色首饰盒处。如果他没有记错这应该就是之前私下聚会里世界克莱恩·莫雷蒂特意强调0级封印物旧日之盒。秘之圣者布提斯真执掌着这件0级封印物？而且有拿出来使用？隐者女士和正义小姐最终还成功了？伦纳德瞳孔略微放大险些不敢相信自己眼睛。作为正统官方非凡者黑夜教会红手套队长他对0级封印物有清晰概念知道这些东西随随便便就能毁灭一个城市让人突然暴毙难以反抗面对它们不仅不能接触就连了解都尽量不要去做。伦纳德原本以为真遭遇0级封印物后隐者女士和正义小姐她们会按照预案脱离战场另外再想办法救出魔术师小姐谁知她们竟然成功了而且还把旧日之盒这0级封印物抢回来了！隐者女士神秘再现强大到这种程度？她说背叛之宴真可以让封印物反叛？或者说愚者先生提供一定帮助？伦纳德无声嘀咕间瞄青铜长桌最下方世界克莱恩·莫雷蒂一眼发现这位前同事相当平静。克莱恩环顾一圈嘶哑笑：祝贺各位这次狩猎很成功。所有战利品都在这里。说话间他抬起右手将许多神秘学知识凝成一团淡白光华并附带桃花源烂柯棋局等源自东方少量传说故事想让隐者女士试一试它们是否属于神秘有无真实源头。女士这是你报酬。世界克莱恩让那团淡白光华飞向隐者嘉德丽雅然后指指桌面摆放旧日之盒秘法师非凡特性旅者行囊布提斯眼珠九条星之虫大量宝石和材料道另外你有优先挑选权利。经过猎杀秘之圣者布提斯这场半神层次战斗隐者嘉德丽雅真正有圣者气质和自信先行接过那团淡白光华闭上眼睛消化起里面蕴藏神秘学知识。在第二纪古神们相信最初那位造物主有遗留一些事物那或许是祂身体一部分衍化出来国度也或许是祂制造东西……这些事物蕴藏源质共有九个分别是混沌海源堡永暗之河知识荒野暗影世界母巢失序之国灾祸之城光之钥……远古太阳神来自一个叫做切尔诺贝利地方……偷盗者途径序列0叫做错误……罗塞尔大帝那些童话也许源自曾经发生过事情…………这些神秘学知识回荡之中隐者嘉德丽雅忍不住睁开眼睛望向世界格尔曼·斯帕罗。这里面有太多让她震惊让她颠覆认知让她打开新世界大门东西！我以前完全想不出愚者先生来历现在隐约能把握到一点了……嘉德丽雅脑海念头一闪有某个猜测。她旋即控制住自己不愿深想也不敢深想。她害怕自己会得出某个惊悚足以让她接近失控答案：这里就是那九大源质之一愚者先生目的是搜集所有源质尝试恢复……抬起右手推推鼻梁沉重眼镜隐者嘉德丽雅强迫自己将注意力转移到那几个小故事上决定返回现实世界彻底消化完魔药就尝试据此创造魔法利用神秘再现汲取力量。当然她也相信不会每个都成功相信那几个故事之中肯定有部分是纯粹虚构毕竟这属世界先生附赠礼物不保证一定有效而且当初罗塞尔大帝给神秘女王讲那么多童话故事和远古传说里真正能衍化出魔法也只是很小一部分。用几秒钟时间定定神嘉德丽雅将目光投向斑驳长桌中央准备挑选自己战利品。毫无疑问最吸引人眼球是那个编号为0-61旧日之盒那镶嵌着不少宝石银黑色首饰盒完全遮掩住其他物品光芒。嘉德丽雅对0级封印物不算太陌生因为神秘女王贝尔纳黛那里就有不止一件也正因为如此这位女王创立要素黎明才能与第四纪初期就诞生古老组织摩斯苦修会抗衡。——天使与圣者位阶差距不是强大梦幻童话魔法能够弥补。要想成为真正大人物晋升序列2或者拥有0级封印物必然得有其一嘉德丽雅对旧日之盒不是没有渴望但想到世界格尔曼·斯帕罗从愚者先生那里得到提示想到可怕负面效果极端危险第三层和没法控制大部分非凡能力她又一阵恐惧。虽然她有短暂幸运但到目前为止是缺乏封印旧日之盒能力。经过一番激烈思想挣扎隐者嘉德丽雅指指那枚梦幻晶石：我要秘法师非凡特性。这如果能找到合适高序列工匠可以变成相当不错负面效果勉强可以承受封印物而神秘女王贝尔纳黛就有这样资源只是未必能请托成功。最终产品哪怕只有一个传送也足够了但很明显秘法师不会只掌握传送……即使负面效果无法承受也能请女王粉碎多次尝试或者卖给魔术师小姐……嗯她说过她老师会给她准备材料……嘉德丽雅随即对世界点头表示自己确认刚才选择。选秘法师非凡特性？听到隐者女士回答克莱恩脑海内莫名就浮现出一幕场景：穿紫纹黑袍戴深色兜帽女士依靠闪现留下密密麻麻分身然后她们同时划燃一根火柴。……卖火柴小女孩变成无数个卖火柴女巫……这简直是恐怖版童话故事……世界克莱恩遏制住嘴角微微抽动嗯一声：好这是你权利。他旋即将目光投向魔术师小姐：该你挑选了。我我什么都没做……魔术师佛尔思有些心虚说。克莱恩呵一声：你圆满完成诱饵工作。……佛尔思不知自己该以什么表情来应对但有听见星星先生疑似笑一声。缓慢吸口气她将目光投向青铜长桌上战利品们。坦白讲她有点想选旧日之盒因为这是她老师家族被抢走物品。她并不想自己用打算直接归还给老师。但考虑到自己真只是做次诱饵佛尔思觉得自己没那个资格拿这种层次物品。0级封印物有多么稀有珍贵和危险她已借助星星先生介绍有深刻印象知道旧日之盒价值绝非圣者非凡特性可以比拟。想到这是在世界格尔曼·斯帕罗注视下挑选魔术师佛尔思最终放弃冲动指着那对眼珠：就它们吧。她想将这对眼珠带到自己老师面前告诉他布提斯死了所有仇恨都结束了。而除这方面价值布提斯眼珠还能制作成强力诅咒物或者做诅咒媒介使用也算相当不错物品。克莱恩轻轻颔首没有规劝什么只是指着宝石材料和星之虫平静：你还付出月亮纸人可以再挑点东西做补偿。好。佛尔思条件反射般就答应下来。因为学徒途径不少符咒和仪式需要宝石做材料而这些东西平时还能欣赏佛尔思拿其中一部分宝石等待聚会后通过赐予仪式得到。克莱恩随之移动视线对审判小姐：该你了。审判休同样知道自己没做太大贡献也清楚自己没能力抵御旧日之盒负面效果所以看都没看0-61一眼指着黑色口袋：我选旅者行囊。这样一来她就能随身携带些重武器关键时刻说不定还能拖出一门火炮。至于隐藏空间隔一段时间就得加固问题她也考虑过反正前期还能用一年左右之后可以从隐者女士那里租赁封印物来维持而且到那个时候佛尔思说不定都成为秘法师了。世界克莱恩点头又望向星星伦纳德：到你了。伦纳德也不客气扫一眼连点几下：三条星之虫二十颗宝石那部分材料。这让我有一种给官方势力交保护费感觉……克莱恩吐槽诗人同学一句转而对正义小姐：任务很成功我很满意虽然你已经拿到报酬但也可以再挑选一点。正义奥黛丽能解读得出世界先生这句话诚意未做推选一条星之虫和三分之一灵性材料。至此作为任务委托者世界格尔曼·斯帕罗收获是五条星之虫0级封印物旧日之盒三分之一灵性材料和近三十颗高品质宝石。他笑笑看向魔术师佛尔思：记得将这件事情告诉你老师就说这是我善意而我想和他做一笔交易。

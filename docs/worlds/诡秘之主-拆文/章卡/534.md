# 534 旅行家 第五十三章 善为人师

## 打开书
无法忍受这种场面达尼兹决定做点什么。咳两声对冰山中将道：「船长格尔曼先生有些问题想请教你？」呼…克悄然舒口气。再对峙下去他就要崩人设了。艾德雯娜动作很轻微点下头看着克道：「斯帕罗先生你接受过教育吗？」这什么问题？表情不变淡漠回应：「大学毕业。」啊？达尼兹愕然望向格尔曼不敢相信这疯狂冒险家赏金猎人居然念过大学而且还毕业了！完全没办法将大学这知识殿堂与格尔曼联系在一起！除非是猎人大学杀手学院…或者只存在于疯子精神病人臆想里大学…忍不住腹诽两句。艾德雯娜不见异常继续问：「掌握了哪些语言？」…忍住皱眉冲动道：「巨人语精灵语巨龙语古赫密斯语赫密斯语古弗萨克语鲁恩语…」艾德雯娜嗯一声：「对神秘学其他领域有了解吗？」恍恍惚惚间似乎回到上辈子小学入学那会因为年龄差点被老师考了一系列问题什么掌握多少个汉字什么学会四则运算没有什么认识英文字母吗什么能背多少首唐诗…冷静…你现在是格尔曼…再次面无表情道：「精通。」艾德雯娜思考两秒语速不快不慢解释：「我必须结合你知识水平来考虑如何回答问题方便你较为轻松理解。」这…简直惊到只觉面前美丽女士完全不像兼职海盗冒险家根本就是一个表情冰冷但态度和蔼循循善诱教师。想了想每天跑大地母神教堂吸血鬼又平静下来。这是我正式认识第一位海盗将军果然有特色…暗自感慨一句开口说：「第一个问题大海上非凡生物出没地点？非常见那些。」没直接问美人鱼消息免得被冰山中将窥见自己真实目的从而带来不必要意外。艾德雯娜想了想随手擦掉黑板上降灵仪式连画带写：「从苏尼亚岛出发往这里航行1200海里会深入人类未正式探索过海域。在那里活跃着一个娜迦部落它们一直致力于寻找传闻里封印着强大魔怪海底城那是它们信仰对象…」一条条讲着部分是她自身追寻宝藏途中发现部分源于交换来知识与传闻。用了好一阵子才大致讲完但让克沮丧是除了加尔加斯群岛东侧海域其余地方都没有美人鱼传说。迅速调整心情转而说：「第二个问题你是否知道去除非凡特性内精神污染办法？」没掩饰自己知晓非凡特性之事。艾德雯娜第一次出现眸光闪动似乎重新认识了格尔曼。摇摇头：「不知道。但我曾经有过一个设想借助外在强大力量将被污染非凡特性彻底粉碎还原成最微小光点这样一来无论污染还是诅咒都将因为失去载体发散出去或迅速或缓慢消失而被粉碎非凡特性将基于本身某种特质一点点聚合再次成形。可惜能办到这种事情只有诸神如果你得到了哪位神灵眷顾可以尝试着取悦祂奉献足够祭品祈求回应。」非凡特性聚合定律…心里补完艾德雯娜刻意没提东西。与此同时不得不感慨这位冰山中将黄金梦想号船长神秘学知识极其渊博不比看过许多罗塞尔日记经历过诸多事情了解不少秘闻自己差。传闻冰山中将能复制或者说模拟对手在她面前使用过非凡能力…这和艾辛格斯坦顿先生2-081戒指很相似…思绪刚一发散就被自己强行拉回来仿佛在考虑什么问题般点点头：「我认同这个假设。」「很遗憾没有实践过只能是设想。」少有使用表达情绪单词。一直旁听达尼兹此时已一脸呆滞完全跟不上节奏。他们在说什么？他们在讨论什么？为什么我每个单词都认识组合起来就不明白是什么意思了…非凡特性是什么？粉碎是什么情况？聚合又代表什么？左看右看两只眼睛写满茫然。这时克抛出思考过第三个问题：「哪里有古老怨灵？」只提这种怪物因为对应材料明显也能用在死灵领域不会暴露本身序列秘密。艾德雯娜看达尼兹一眼道：「我会帮你留意。如果你想参加拜亚姆非凡者聚会他知道一些可以带你去。」不错嘛和聪明人说话就是轻松…补充问：「你知道哪里有能利用非凡材料或特性制作神奇物品人？」「在聚会里遇到过但他之后再没有出现。」坦然回答「我掌握了相应知识可以模拟尝试但不保证成功率。」呵呵…那我还是先等一等…不再纠结这话题转而问：「你对死神钥匙知道多少？」「不了解。」手中忽然具现出一把铁黑色钥匙它足有七弦琴那么大形制古老光泽暗沉。这位海盗将军半抱半托着这沉船遗物道：「如果你是说这把钥匙我可以肯定告诉你它属于巨人。」瞄眼达尼兹：「你水手长告诉我它也可能属于巨龙或魔狼。」「这是最早猜测我最近找到了些历史文献结合船上其他物品初步有了确定答案。」一点也不烦躁充满耐心但表情依旧冷淡。达尼兹终于找回梦境主人存在感好奇问：「船长真是巨人？」「嗯。」给出肯定答复「那批文献显示第四纪时依然有许多巨人活跃部分改信战神部分散落于各地成为人类狩猎目标。其中一个部落打造船只试图出海寻找失落巨人王庭从此再没有回来我们发现沉船和里面部分物品与他们遗留在原本定居点古物极为相似所以我们有足够理由相信那把钥匙属于巨人并且很可能指向着它们一族在大灾变前就失落王庭。」巨人王庭？小太阳说就在距离他们白银城不远地方…没有开口安静听完冰山中将描述。不得不说白银之城和神弃之地是我知识领域完胜其他非凡者东西…嗯就连七位正神目前都找不到那里难以弄清楚具体情况这一点上我比祂们强…半得意半自嘲想了想沉声开口：「如果我付出足够代价你是否愿意卖掉这把钥匙？」「当然除非我另外得到了巨人王庭线索。」依旧不快不慢语速。很好要是哪一天塔罗会组织起巨人王庭探索团我会购买这把钥匙…本想说最后一个问题忽然记起之前遇到那四个冒险家。借助梦境符咒力量具现出有青灰色眼眸穿男性衬衫女士以及她三位同伴：「你认识他们吗？」艾德雯娜看一眼几乎没有回想过程说：「拉蒂西亚·多瑞拉一位考古学家兼冒险家。传闻她是摩斯苦修会或者要素黎明成员。」摩斯苦修会…信仰隐匿贤者那个古老组织…果然不是为了金钱目的肯定是废弃神庙内某样东西…随口问：「你对要素黎明有什么了解？」这神秘组织和心理炼金会类似诞生也就一两百年糅合神秘学各个流派要素有一套属于自己理论成员都擅长施法掌握着诸多古老巫术。艾德雯娜抿下嘴唇道：「他们一直在对抗摩斯苦修会。传闻是罗塞尔大帝长女贝尔纳黛·古斯塔夫建立。」要素黎明首领是贝尔纳黛？查拉图预言挺准嘛这真算是超凡世界大人物了…内心有些恍然有些唏嘘。忍住叹息冲动望向冰山中将平淡开口：「最后一个问题。」等美丽女士和烈焰将注意力全部投过来一点点咧开嘴角：「有没有兴趣合作？」「什么合作？」反问。脸上笑容越来越盛几有疯狂味道：「狩猎血之上将。」

## 这场戏有没有翻
翻了。入学考式问答；章末狩猎合作。翻的是善为人师讲完再甩猎将军，不是只打听美人鱼。

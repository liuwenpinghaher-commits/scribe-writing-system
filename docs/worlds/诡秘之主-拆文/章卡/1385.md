# 1385 倒吊人 第三十三章 狭路

## 打开书
听到阿蒙那句你疯了克莱恩头部微仰哈哈笑道：我只是遵照你们安排放弃而已只不过比你想象更彻底一点。说话间他覆盖着冰冷诡异面具额头处一道虚幻烙印凸显出来。那是一座沾染着些许青黑奇异光门。……对我来说与其你成为诡秘之主不如让过去那位复活。精神状态稳定下来想明白阿蒙这次突袭关键后克莱恩就着那种放弃心理初步解除对体内诡秘之主意志压制让祂更进一步复活了。正因为如此他才能于关键时刻更多地掌控住源堡借取来错误力量规避掉阿蒙制造空间坍塌。……你能在被源堡污染出现疯狂征兆后立刻就恢复过来反向利用源堡制造出盲目痴愚效果你能在放开对体内诡秘之主意志压制后不进入半疯状态是因为有外在力量在帮助你。你应该有一个非常关键分身甚至就像帕列斯那样自降位格本体沉睡在亚当那里由祂这位空想家亲自维护着你精神状态而只要诡秘之主意志复苏没超过亚当能承受极限那里没失去控制你就不会疯掉。所以你最严重隐患是必须时刻保持自己与那个身体联系正常一旦被干扰你状态就会出问题而这种联系在源堡分割下其实很脆弱。你故意展现出半疯情况除诱导我往这方面寻找机会踩中你预设陷阱也是在隐藏这一点不让我围绕那种联系展开战斗。当然除这个还有不少问题毕竟你还没有真正准备好。如果被我提早发现这些哪怕我只是掌握唯一性天使之王也有办法击败你。……你确实又强大又狡猾又可怕无愧于欺诈之神这个称号如果不是我早就考虑过被你逼到绝境且没有别办法时该怎么做我刚才肯定会犹豫而只要稍有犹豫现在就已经死去。那样一来阿蒙将完全掌控住源堡以此阻止克莱恩从历史迷雾中回归让他没法复活。……你体内诡秘之主快真正苏醒了。……你也可以来比拼这一点。我们接下来战斗很简单就是比谁体内诡秘之主意志苏醒更多比谁对源堡掌控更深百分之五十百分之七十百分之九十一直到百分之百然后砰我们就炸开了祂就回来了。怎么样要来赌一赌吗看谁先撑不下去？这很刺激很有趣很符合你喜好就像是弗萨克流行轮盘赌两人一把左轮里面一颗子弹轮流对着自己太阳穴扣动扳机谁先放弃就等同让对方获胜而要是都不放弃一直坚持到最后那将没有一个赢家祂才是。……你虽然一直以追求刺激敢于冒险著称但你大部分时候都达成目的不仅没有损失什么反倒收获颇丰而小部分时候你也只是失去一些分身损失点物品从来没有真正遭受过严重创伤或陷入绝境。你每一次行动几乎都是精心谋划产物哪怕失败也有退出通道。这是否说明你比我想象更重视自己生命你确实喜欢刺激寻求愉悦但为了它们不计代价只是你包装出来形象真正欺诈之神怎么可能拿自己做赌注？当然这只是我个人猜测也许是错误总之要来赌一把吗？阿蒙抚抚水晶磨成单片眼镜像梅迪奇那样啧一声：你疯得真厉害。……在别人看来这确实很疯狂。但对我来说只是一个选择。比起你我更愿意相信过去那位诡秘之主祂是真正旧日俯视着宇宙将绝大部分生灵都视作虫豸这反倒会让祂远离现实。而且我应该还有时间请灯神做见证请那位诡秘之主承诺一些事情对祂来说很简单很没价值事情。……我失去不会太多只有自我而已。总有些事情高于其他。……克莱恩随即环顾一圈在漂浮于虚空中一块块荒野碎片里找到许愿神灯和特伦索斯特黄铜书。……你看我没有遭受处罚这说明我没有撒谎说都是真话。其实特伦索斯特黄铜书制定规则早在恒星降临神国破碎时就开始失效阿蒙们后来都敢于尝试多人窃取了但克莱恩主要目的不是以此证明什么而是展现出自己坚定决心或者说疯狂。……听起来很有意思。是吗那就开始吧。克莱恩毫不迟疑回应道眼眸愈发幽暗。……这一刻阿蒙变得更像诡秘之主了。但祂不是在和克莱恩比拼体内诡秘之主苏醒程度而是在伪装自己以此欺骗过源堡制造相应Bug创造出脱离机会。错误权柄在同层次间要想生效往往得有不同先决条件：一是媒介和目标有足够相似性；二是两者存在一定联系；三是某些事和物有逻辑矛盾；四是部分规则确实存在不完善地方；五是不直接影响目标以创造神国形式构筑充满错误环境……在这方面愚弄限制更少可一旦满足条件错误更难以防范和阻止。……此时阿蒙外形像诡秘之主气息像诡秘之主能力像诡秘之主精神烙印也像诡秘之主那配合错误权柄当然会让源堡在某个刹那误以为祂是诡秘之主。霍然间克莱恩残破愚者神国彻底崩塌那座恢弘古老宫殿和里面斑驳长桌浮现出来。本来位于源堡下方灰白雾气腾起来笼罩住这片空间。……源堡力量在这一秒自我矛盾似乎不知道该听从哪位诡秘之主命令。阿蒙身影当即消失利用门权柄直奔源堡之外。……愚者位置上克莱恩嘴角微勾坐在那里眉心和身周奇异光门愈发明显宛若实质。……你也可以跟着让诡秘之主意志进一步苏醒啊但这和死亡不同绝对会波及亚当那里那具身体。概念化阿蒙迅速又有实体祂依靠门权柄脱离刚才那种状态。祂嘴角带着笑意没去回应克莱恩抓住这个机会就要应用错误权柄里以假代真用提前准备好位于外界一个分身取代自己对调双方位置。这和占卜家领域本体秘偶位置互换类似但这个层次更高原理不同不会被绝大部分情况干扰。……祂发现自己错误权柄被强行压制了。……盲目痴愚效果！下一秒他将自己和星空中某个概念嫁接在一起并利用愚弄权柄影响起对应那片环境。……一片无法想象异常炽烈光海奔涌而出粉碎祂单片眼镜淹没祂身体。

## 这场戏有没有翻
翻了。开头克莱恩更彻底放天尊借错力；拆阿蒙＝亚当维稳分身联脆弱；邀轮盘赌％天尊；阿蒙假疯逃＝像诡秘欺源堡；克莱恩痴愚压错＋嫁星空概念；章末炽烈光海吞阿蒙。翻的是狭路＝赌命逼／光海打。

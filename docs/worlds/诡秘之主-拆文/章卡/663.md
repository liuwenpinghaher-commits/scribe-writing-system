# 663 旅行家 第一百八十二章 争分夺秒

## 打开书
美人鱼？克莱恩心中一喜涌现久违的激动。离开贝克兰德近四月经历不少事情后终于抵达这次旅行的目的地满足了晋升序列5秘偶大师需要的最后一个条件！心里因等待产生的焦躁烦乱在进入这片海域后一直不断增长，未来号上种种看似荒诞可笑细想却异常惊悚的事情和神战遗迹内黑夜正午梦境三种状态分别蕴藏的危险与未知更让他始终紧绷精神煎熬度过每一小时每一分钟。现在这些情绪这些压力终于有了宣泄释放的机会！呼……缓慢吐了口气直接返回船舱进入自己房间。没有慌乱没有忘形按照预定流程拿出阿兹克铜哨威尔·昂赛汀纸鹤用它们干扰可能存在的神秘女王窥视。将古老怨灵残余灵性、六翼石像鬼眼珠、龙纹树树皮、装苏尼亚金色泉泉水的金属瓶从行李箱取出展开于书桌后进入盥洗室反锁房门熟练布置祈求赐予仪式。弄好没急着去灰雾响应又额外布置了个仪式：自己召唤自己。逆走四步低诵咒文来到灰雾响应召唤借此以灵体状态来到现实将火种手套带回那片神秘空间。做完前置来到愚者位置具现纸笔快速写占卜语句：前方唱歌的是美人鱼。取下黄水晶吊坠用占卜确认：未来号前方唱歌的正是美人鱼！平复心情招手让铁制卷烟盒从杂物堆飞出落到青铜长桌。啪打开盖子看见没有瞳孔的全黑之眼依旧安静躺在里面极致疯狂和危险隐约可感却宛若沉眠。静静凝视两秒拿起火种手套缓慢戴于右掌。不再犹豫向前伸出右掌张开五指。眼前画面霍然浮上各种各样光团灰白铜绿深红和黑沉构成这片神秘空间主基调。全黑之眼内蒸腾的张牙舞爪般铁黑光芒正缠绕着剩余所有颜色。无需灵性直觉仅凭对事物了解也能清楚认识到代表真实造物主精神污染的就是这铁黑色光芒！高度戒备中五指合拢抓住目标随即拧动腕部。铁黑色光芒一下被抽离融入火种手套耳畔顿时又响起虚幻邪恶可怕似曾相识难以名状的嘶吼。摧毁思绪磨灭精神带来脑袋即将炸裂的痛苦但很快被灰雾力量压制彻底平静。没能力多想依循预定方案和演练过多次的动作左掌抓住火种手套将它褪下来丢到宏伟宫殿石质地砖上。紧接着有些麻木抓住不再有问题的全黑之眼快速回应祈求赐予仪式将这秘偶大师遗留的非凡特性通过虚幻大门传递去盥洗室祭坛。不敢有任何耽搁只是瞄了眼已染上铁黑色五指扭曲掌心撕裂充满邪异感的火种手套就用灵性包裹自身模拟急速下坠返回现实。如果让蠕动的饥饿全程目睹火种手套的遭遇和结果不知道它会有什么感想……睁开眼睛抓起祭台内全黑之眼直奔外面房间。停于书桌前从侧方拿出原本属于未来号厨房的钢铁奶锅将80毫升苏尼亚金色泉泉水倒进去。淡金液体缓缓荡漾清澈透明让人下意识感觉嘴巴发干想痛快喝上一杯解除渴意。龙纹树树皮六翼石像鬼眼珠古老怨灵残余灵性一一放进锅里激起不同反应最终药水基剂颜色变成暗金但看起来轻飘飘没有一点重量。到了这个关键节点反而变得异常平静沉稳拿起那无瞳黑眼将它沉入基剂。已经可以确认真实造物主的精神污染没法穿透灰雾重归全黑之眼内！而这是能够预见的。全黑之眼瞬间被暗金液体淹没水面随即冒起一个又一个气泡。每一个气泡破裂药剂就黑上一分十来秒后所有变化全部终止。奶锅内魔药成形呈全黑色里面似乎有无数条肉眼看不太清楚的细小虫子在飞快游动。掏出金币用占卜快速确认。得到成功启示后舒了口气将秘偶大师魔药倒入提前准备好的金属瓶塞进衣兜。没有急也没有乱按预定流程飞快处理盥洗室祭坛拿回铜哨和纸鹤。直到这个时候才脚步略快离开船舱来到甲板。此时未来号上象征符号魔法标识和奇异花纹已层次分明亮起组成璀璨星之海洋将美人鱼歌声做了最大程度削弱。——传闻美人鱼歌声会让人类失去理智变得痴狂从而跳下所在船只成为美人鱼们的食物。下意识抬头望向船长室对应窗户。星之上将站在那里周身缭绕点点星芒回看的目光颇为复杂。这是想起梦中说过的话和展现的态度了？腹诽一句表情淡漠：我要一条小船。已经准备好了。嘉德丽雅不见意外指了指船舷。格尔曼雇佣未来号时就已经提过目的是寻找美人鱼！很快离开未来号离开璀璨星海保护踏足小船置身大洋。歌声飘渺传来似乎直接钻入灵体让他浑身发麻难以遏制想听到更多。这对他程度还远远不够而且灵性直觉告诉他必须再靠近一点让歌声更清晰一点才能满足仪式需求。风暴！掏出枚白锡符咒召唤来一阵可控制大风推动小船往前。不知过了多久美人鱼歌声突然变大清楚就仿佛正在耳边浅吟低唱每一个音符都能敲动灵体每一段旋律都让人沉醉向往。恍惚一下险些跳进海里游向美妙歌声来源。竭力控制自己发现前方不远处有许多礁石一道道身影正坐于边缘曼声轻唱。这些生物长着人类脑袋眉眼清纯里透着几分艳丽胸口高高鼓起但又被暗红色鳞片覆盖下半身是硕大鱼尾很有节律地拍打礁石。不同美人鱼有不同长相和不同鱼尾鳞色对人类来说有种异样美感。放开对小船控制抬起右手就要探入衣兜取出魔药。就在这时一条条美人鱼察觉他的临近纷纷望过来。然后这些又被称为海妖的生物一个个惊慌失措停止歌唱噗通噗通跃入水里。不要走啊……右手无力虚抓两下。不是说好用歌声吸引人类当食物吗？怎么人类来了你们反而跑了？我也不是什么坏人我就来听个歌而已……心里充满了我草的情绪。很快发现歌声并没有完全停止在这片礁石较远位置还有几条美人鱼背对这边在风浪背景下未发现同伴逃离依旧大胆歌唱。精神一振略作思考拿出另一张符咒。这是海神领域让水下生物对使用者亲近的符咒！风暴！咒文声里青蓝色火焰包裹白锡薄片让它凭空消失。见剩余美人鱼虽然察觉自己但不再胆怯逃跑当即拿出装秘偶大师魔药的金属瓶拧开盖子。抓紧时间以防意外！咕噜略显苦涩的魔药带着陈腐感觉涌入嘴巴沿着食道直奔胃袋。霍然间发现自己变得异常僵硬就像回到廷根回到被封印物2-049那奇异木偶操纵时的状态。试图活动关节里面却仿佛灌满铅水。同时感觉一条条细小虫子钻进每一个细胞钻进灵体。思绪开始变缓脑海内映照自身状态的能力也逐渐失效。美人鱼歌声悠扬传来挑动那种渴望积蓄狂热和痴迷让他保持住最后的情绪并借助这种引诱一点点摆脱僵化迟缓。眼前迅速浮现淡漠灰白雾气耳畔响起虚幻霍纳奇斯……弗雷格拉……和他晋升占卜家小丑魔术师时相比这呓语明显变得断断续续似乎正被什么干扰着排除着。与成为无面人时不同呓语明显强了不少能间断性突破灰雾与现实糅合力量的阻隔了……我的思考能力恢复了！心中一喜尝试抬起手臂。关节艰涩仍在但已越来越弱！看见自己现在样子：肤色黄褐就像缠着陈旧绷带活埋了多年的人偶；一颗颗肉芽藏于皮肤之下蠕动着分离着融合着。当即于脑海勾勒无数光球用冥想平复。美人鱼歌声依旧回荡让关节和肌肉出现抽动缓慢退去僵硬。不知过了多久睁开双眼身体已彻底正常。吸了口气无声感慨：终于……终于序列5了！终于是秘偶大师了！

## 这场戏有没有翻
翻了。开头确认歌声是美人鱼；灰雾上把污染偷进火种炼成药；靠近时海妖见他反而逃；亲和符留住几条当场喝下。翻的是猎食者见格尔曼逃跑，争分夺秒不是慌是演练过的检查单。

吐气回舱。火种抽污。奶锅炼药。要小船。海妖跳水。咕噜僵硬。终于序列5。

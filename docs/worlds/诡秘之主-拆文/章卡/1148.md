# 1148 红祭司 第二百零三章 逃

## 打开书
台下奥黛丽等见炸如大型魔术，几秒后尖叫混乱卫兵奔高台；内阁上院或躲或跟查。她微怔不够真实：世界重点关注＝愚者注视，愚者迄今目的未败——神灵意志。其他市政广场梅丽莎班森闻爆演讲戛止，安静后躁动交头，未知恐慌占心。……1号遗迹内乔治神智模糊，体内极端疯狂意识火山喷，改身扭周围。隐约巨黑王座己坐戴冠俯视现实统万民与众神平等。伸手抓未来，无数诅咒与不知来处攻击落身再也触及。「不……」虚化规则手停半空意识撕裂身完全异变。已崩血肉团的特莉丝无数粗长蛇发簇拥覆盖秩序阴影。轰隆！外界山林骤内塌扬尘如浓霾。轰隆！巨深坑连通塔索克河引奔流。轰隆隆！高空阴暗无尽恐怖风暴笼罩。更远山峰：圣洁白袍不老魔女卡特琳娜与兜帽苍白红天使恶灵凝望。两秒卡特琳娜轻叹：找回她因原初说她有强烈自毁倾向。红天使表情略扭：我知道是谁干扰我的回应了。她想答案难肯定沉默。祂缓吐：黑夜。补：要不然早就找到特莉丝奇克。转离。……另一遗迹陵塌大片血克莱恩闪欣喜不得不转自身：仪式败未成黑皇帝目的达成，下步逃走！陵毁影响中蕾妮特按约不留抢先入灵界逃深——借过去力将尽。秀美隐秘天使达维持极限衍奇异世界后自然消。半垮遗迹他独对神孽臂、赫密斯、罗塞尔影、威廉影、光天使影及不知指哪雷声，任一可轻松置死。再召天使影非两三下可成。身虚化欲躲史隙——灰白雾突冒漩涡，无数透明蠕虫构成伸透明滑腻触手。查拉图！本体出现！一直在史隙等他！入隙行动不可逆，眼睁被漩涡吸向中心！欲响指燃千纸鹤——无火苗；查拉图试探后位格压制诡秘权柄使他不能再控火。直觉：传送终点诡异连向蠕虫漩涡。无法脱来不及召足分量帮手。占卜家不做无准备表演。漩涡缓转迎主动拜访，触手不可挡缠来——只缠住深色封皮古书，表面鲜血未褪。《格罗塞尔游记》！最危一秒主动弄破指血流游记面嗖入书中世界暂脱致命陷阱。入书立刻抓史隙出短暂拥有过的秘偶赫温·兰比斯——此处可召真史投影属源堡，书中向愚者祈不受阻；不行则召书中史正义奥黛丽。需观众途中高序列带入集体潜意识海入奇迹之城利维希德入诚实大厅。越快越好不知查拉图序列1多久掌握游记密会否强降书中。争分夺秒！温和正装暗红领结赫温略僵拉他入光影重叠集体潜意识海。操纵师力数秒抵奇迹之城诚实大厅门。解除偶维持狂风推奔跑入门。穿艳丽壁画内心声回荡大厅：此处召0-08成功率应较高；用它在左壁画尽头描绘书写可影响现实；安排让查拉图失误找安全逃离；不，让阿蒙分身加入混战牵扯较易实现；难怪女神把阿蒙钓来贝克兰德；右壁画代表书中世界可用0-08再绘临时门出去……飞奔不停虚抓。五次十次二十次再借过去己力后右手陡沉拖出黯淡古典羽笔0-08！抵半截巨柱——时光沧桑空想之龙安格尔威德宝座。绕柱至壁画尽头提笔欲落——此前未敢实验恐惊阿蒙哥哥暴露阻黑皇帝图谋；此刻可全心编织所需发展。突然即将书写的0-08消失，未达维持极限就消失！怎么回事……惊讶。诚实大厅未放大此句周围极静。灵感转：沧桑石柱不知何时成上百米高十字架。前方模糊巨大人影屹立背负一切怜悯注众灵。大厅多排黑靠背座椅仅一祈祷者：闭眼第一排中央简朴白袍淡金须遮下半脸，双手交握胸前银十字，神情和煦平静。亚当。黄昏隐士会会长天使之王亚当。竟完全不知祂何时到。亚当抬头清澈如孩童眼眸，缓站平和问：乔治三世陨落，鲁恩遭受重创，因蒂斯不再旁观决定趁机发动进攻，这场大战开始真正席卷世界。这样的结局，你接受吗？

## 这场戏有没有翻
翻了。开头广场还当魔术、他以为目的达成只需逃；章末逃进书中世界提笔欲写，亚当已坐在诚实大厅问他接不接受世界大战。翻的是「逃出去」收成逃进另一双眼睛里，不是查拉图触手厉不厉。

# 1315 倒吊人 第五十章 陌生的城市

## 打开书
再一点点积累下去用不了多久就能回应月城祈求治好他们畸形创造一个不小奇迹了……另外也初步总结出奇迹师扮演守则这么按部就班下去消化只是时间问题今年年内说不定就能成功……克莱恩将目光从窗外收回……这让他看起来更像一个流浪魔术师了。如果他愿意他甚至能利用生命手杖或嫁接能力赋予这手偶一定活着特性。逗小孩同时克莱恩思绪发散开来考虑起晋升仪式所需秘偶城市该建在哪里：秘偶城市想在灵界诞生对应区域需要足够互动这就意味着放在神弃之地是不行……放在南北大陆或海上殖民地需要足够小心在仪式接近成功前绝对不能暴露这是一个秘偶城市否则必然会受到查拉图阿蒙等敌人干扰破坏乃至袭击……嗯必须给秘偶城市出现一个足够理由并在与来往商旅周围人类互动里不出现一点异常让每个秘偶都是一个活生生人……这意味着秘偶城市会高度复杂需要分化出许许多多灵之虫来做处理这也就潜藏失控风险……是夫妻就得像夫妻……我还只是个孩子……这就是一个大型真人秀或者说高级版过过家必须能骗过观众那种……沐浴在黄昏光芒内巨人王庭顶端那扇打开大门沉重而缓慢合拢了。……这……克莱恩眸光微沉隐约猜到这场景意味着真实造物主即将重新封锁神弃之地。……真实造物主抓到阿蒙了？还是已经放弃了？祂重新封锁神弃之地是不想别人再进去？这会不会太小气了？克莱恩在心里咕哝几句一时有点失望。……有什么事吗？这个时候你应该在散步？作为一名资深观众奥黛丽立刻就察觉到不对。……奥黛丽小姐我是心理炼金会会长埃里克·德雷克我希望见你一面讨论你成为心理炼金会评议团委员事情我就在附近公园内。……奥黛丽有个怪家伙找你我我记不清他长什么样子了他他直接将想说的话放入我心灵岛屿内！……我认为你不应该去这很危险。……如果不去会更受怀疑那样一来危险同样不可避免甚至会波及这栋房屋内其他人。而且这也是一个机会就像倒吊人先生说那样既然末日终将来临那所有不带来灾难努力和尝试都是有意义……我会保护好自己。……那你可以带着我吗？就像之前那样在他们眼里我只是一条狗。苏茜鼓起勇气说道。不不用我很快就会回来相信我我会得到神灵庇佑。奥黛丽浅笑回应道。安抚好苏茜她利用心理学隐身能力像正常出门一样一步步离开豪华别墅。……不属于这个时代愚者……坐在愚者位置那道身影自然查看起新成形祈祷光点发现那位信徒非常陌生。和正义小姐家环境一致……疑似受到侵入心灵岛屿虚拟人格引导……正义小姐通过这种方式规避监控祈求庇佑……几秒后克莱恩进入源堡……正义小姐越来越有高序列观众风范了……克莱恩暗赞一声将目光投向代表正义那颗深红星辰。……请进。一道低沉男声从里面传出来。……德尔劳先生？您不是已经死去了吗？奥黛丽认识眼前这位先生恰当地表现出自己诧异。对一名观众来说死亡只代表一个身份终结在别戏剧里我依旧活着。坐在黑色轮椅上老派绅士微笑回应道除前王室医学顾问贝克兰德医学院前任校长这个身份我还是大海上黑座之王巴洛斯·霍普金斯……那我该怎么称呼您？……你可以称呼我会长先生也可以继续叫我德尔劳先生。……坐吧我们先去一个地方然后再讨论你成为心理炼金会评议团委员事情。……这是一名狼人。

## 这场戏有没有翻
翻了。开头秘偶城规划；王庭门合；苏茜传会长约；愚者庇佑；章末德尔劳「死而活」载入见狼人。翻的是陌生城市＝心城入口。

## 日子
火车／手偶。王庭合门。公园约。马车狼人。

## 这一章落在哪一天
离利蒙后；奥黛丽受邀日。

## 人
- 克莱恩：规划秘偶城；应庇佑。
- 奥黛丽：赴约。
- 苏茜：传话。
- 德尔劳／会长：死而复现身。

## 地与走
途中思 → 源堡应 → 别墅出 → 公园马车 → 心城入口。

## 这一章新讲明的规矩
- 秘偶城需互动；不可神弃；须骗过真人秀级。
- 观众：死亡＝身份终结仍可他戏活。
- 虚拟人格可塞心灵岛屿传话。

## 钱与人情
末日努力有意义。不带狗。神灵庇佑。

## 话
「我还只是个孩子……」「死亡只代表一个身份的终结」「我会得到神灵庇佑的。」局面是赴心城。

## 热怎么变冷
秘偶秀还热。冷切在王庭合。赴约还热。冷切在死者坐轮椅。门关还热。冷切在狼人。

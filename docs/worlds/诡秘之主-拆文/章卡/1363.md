# 1363 倒吊人 第十一章 行动派

## 打开书
打开心智体之门后克莱恩依旧谨慎将愚者相关记忆提取出来聚在一起嫁接到灰雾之上。接着他看见金发柔顺披下浅白丝巾缠眼奥黛丽沿具现出来古老石梯从集体潜意识大海内一步步登上自己心灵岛屿。略有犹豫后克莱恩不再让自己那部分意识高踞灵性天空处放弃相应掌控任由它们回归并融合。——如果不这样在接下来心理治疗中他会保持绝对理性无法被各种记忆感动失去增强人性可能。这意味着奥黛丽治疗在一开始就注定失败。依靠灵性直觉抵达那座更像梦境世界心灵岛屿后奥黛丽停下来微张开双臂。……这是她唤醒格尔曼·斯帕罗人性相关记忆方式属于共情效果非凡化。一幅幅或值得珍视或蕴藏深切感触画面在奥黛丽意识内相继闪过她脚下代表克莱恩心灵岛屿表面一点点萤火虫般光芒穿透泥土浮上来。……一个小孩迈着短腿接过一个雪糕；一个学生以教科书为遮掩偷偷摸摸看着小说和漫画；一个少年坐在家里电脑桌前入神玩着游戏忽然他听到钥匙插入锁孔轻轻拧动声音他猛地跳起来强制关掉电脑冲回房间……一个青年和他同伴一起推着扭捏朋友……一个还有点稚气年轻人偷偷看向楼下……一个肚子已经有点微凸职员放假回到家中……一个颇有点书卷气男子和哥哥妹妹搬完家后看着彼此脸上污迹和尘埃哈哈大笑……克莱恩坐在露台小圆桌旁一手拿着摘掉礼帽一手悬在半空似乎想往脸上凑。……克莱恩闭上眼睛神情既柔和又感伤。他心灵岛屿内奥黛丽仿佛化身为情绪漩涡吸聚起属于同类记忆。……下一秒这神秘人深黑长袍下蹿出一条又一条滑腻虚幻触手。此时此刻奥黛丽意识虽然看不到听不见但她灵性直觉让她有强烈危险预感有种污染组成大海即将淹没自己幻觉。……奥黛丽正要全力安抚自己并削弱前方污染漂浮于岛屿上那些萤火虫般光点已急速聚拢照亮灰白雾气淡化奇异光门周围深黑让长满神秘古怪花纹触手们缩回去。这也就是克莱恩要在精神初步稳定可以勉强压制天尊复苏意志后才来接受心理治疗原因。这让奥黛丽感知到危险减弱忙给自己做个精神分析然后立刻安抚起那片污染做真正意义上催眠。一遍一遍又一遍奥黛丽不知花费多长时间终于取得初步预想中效果。——这次治疗很困难所以她没有用虚拟人格直接上本身心智体。感知到治疗结束克莱恩抬手抹抹脸庞让嫁接到灰雾之上愚者记忆回归本体。隔好几秒奥黛丽取下眼睛和鼻子处缠着浅白丝巾解除自我催眠。她看着对面世界先生半是自语半是感叹般道：这就是神性带来精神问题吗？……克莱恩轻轻颔首道：对每一位天使都有区别只在于是比较严重还是非常严重。……我认为或许没有这么悲观就像每个人类生命源泉都来自外在事物：空气面包肉类水等等等等。我们吸收它们同时也会吸收它们附带不好于是会积累种种问题出现生病等情况但这不表示我们就要完全对抗它们将它们视作绝对意义上外来事物一旦吸收总会有部分属于我们。……超凡者获取非凡特性就如同人类享用食物？然后平和心态不要抱有太过排斥想法既对抗也合作既压制也融合？大概是这样。奥黛丽刚说完又自嘲般笑笑不过这似乎也有不好寓意人类终会死亡超凡者……这一周内再来两次差不多就可以在正常状态下保持住精神稳定了嗯正常状态。还有其他时候可以去怀念或者向往地方走一走。克莱恩点点头直接开口道：对于暴怒提议你有什么想法？奥黛丽脸上笑容缓慢消失表情逐渐严肃起来：你有什么建议？克莱恩放下茶杯平缓说道：严格来讲你带来危险分为两类：一类是你主动或被动卷入某些事情将强大敌人引到自己身边波及家人亲属朋友和无辜者另一类是你本身存在让某些势力选择对你最重视人手下以此威胁你。对于后面一类除非你已经死亡否则永远也规避不了……如果你放弃目前在神秘学世界所有身份从此只做愚者先生信徒和奥黛丽·霍尔小姐不再主动参与涉及超凡或者不稳定因素任何事情可以规避掉绝大部分第一类风险……所以完全不用分割一个身份出来。奥黛丽沉默好一阵微不可见咬下嘴唇开口问道：如果要分割一个身份呢？只要你让那个身份也信仰愚者先生那就和我刚才说没有太大区别唯一不同在于你从此得远离亲人朋友以另外身份生活和行动。克莱恩嗓音略沉带着点凝重说道另外你放心让赫密斯帮你分割身份吗？奥黛丽被这个问题打乱内心情绪眼眸微动道：可是分割身份应该是序列3织梦人非凡能力。……克莱恩嘴角微翘突然问道：你可以靠那张傲慢面具直接进入伊甸园？……我没法支付等价报酬而且……不等她说完克莱恩神情冷峻说道：一方面亚当背离愚者先生差点杀死我另一方面末日将近愚者先生预言到一些情况到时候祂可能再次沉睡作为祂眷者我也无法幸免你需要付出报酬就是等到出现这样变化按照愚者先生遗留吩咐做一些危险事情努力唤醒祂。没给正义小姐消化这段话语机会克莱恩伸出右手往前方虚空里抓几下抓出一张灰白色冰冷虚幻人格面具。他依靠位格和奥黛丽对本身信任强行从历史孔隙里召唤来傲慢面具投影。……给我一根头发。克莱恩平静说道。奥黛丽没有多想拔掉一根金发递给格尔曼·斯帕罗。克莱恩接过这根头发将它缠到人格面具眼部孔洞里。……这个过程中他调动源堡欺诈起规则。……那张傲慢面具毫无阻碍戴到克莱恩脸上他眼前旋即出现一个个做人类打扮直立行走动物。他直接进入伊甸园。望着城市中央那座镶嵌颅骨黑色教堂克莱恩微勾嘴角抽出星之杖将丝绸礼帽戴到头顶。

## 这场戏有没有翻
翻了。开头嫁接愚者记忆入治；前世／廷根萤火共情；天尊触手被人性光压；食物比喻融合；克莱恩劝勿分身；章末金丝缠傲面欺诈入伊甸园。翻的是行动派＝治毕即打伊甸园。

- 金丝＋源堡欺诈＝他可用傲面。

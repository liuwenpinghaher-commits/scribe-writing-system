# 1199 逐光者 第五十章 随机性

## 打开书
又过一阵塌陷树林半空突然撕裂出现一扇虚幻而神秘大门。大门无声敞开走出位黑发金眼礼服笔挺成熟儒雅英俊男士。他还未来得及审视现场就听见砰音爆声感受到有狂暴飓风吹来看见侧前方多了位气势惊人中年男子。那中年男子有较为明显大耳垂头发深蓝圆粗眼眸内似乎藏着数不清闪电。他是风暴教会枢机主教贝克兰德教区大主教深蓝主祭雷达尔·瓦伦丁。这位穿着绣风暴符号黑色长袍神职人员左右看一眼将目光投向那位金眼男子嗓音如同雷鸣问：赛尔特这里发生什么事情？被称为赛尔特金眼男子摇头：我也刚到。他话音刚落另外一边虚空中有山峰一样近乎透明灵体浮出将一道人影放在半空。那人影穿着黑底红纹大主教长袍眼神深邃没留胡须正是黑夜教会贝克兰德教区负责人安东尼·史蒂文森。那巨大灵体完成自己任务后立刻缩小投入圣者安东尼口中与此同时某个黑色长发遮住脸孔下半身透明飘忽灵于安东尼身后凸显出来托住他肩膀让他没往下坠落。下一秒钟汹涌气流从贝克兰德城区奔来推着一道人影高速靠近这片区域。很快这人影停下来是个身穿白色牧师袍头戴神职人员软帽面容慈祥温和老者。这老者背后喷出气流随之消失闪烁着金属光芒黑沉管口缩回他身体内部。这是蒸汽与机械之神教会贝克兰德教区大主教神前会议成员霍拉米克·海顿。他奇怪静止于半空环顾一圈：这里战斗虽然不算太激烈但可以肯定属于圣者层次。还有这残余污染气息简直简直……说话间四位半神同时低头望向坍塌树林中央。那里插着一张塔罗牌牌面描绘着一个杵拐杖提玻璃灯老者。隐者牌！雷达尔·瓦伦丁赛尔特安东尼和霍拉米克顿时陷入沉默短暂竟无人开口。……灰雾之上古老宫殿内克莱恩正皱眉看着面前旧日之盒。这0级封印物一被献祭上来整个源堡就发生异动如同被烧到沸点开水。磅礴力量蒸汽一样自行激发汇聚成洪流将旧日之盒完全淹没层层包裹死死束缚。此时此刻那镶嵌着宝石银黑色三层首饰盒似乎成为琥珀内小虫根本没有动弹余地。之前源堡应激而发都是我窥视真神或天使之王遭遇伤害时……这还是它第一次因外来物品出现类似变化……克莱恩忍不住抬起右手擦擦并不存在汗水。坦白讲他有点后怕觉得自己在初步掌握源堡后有点飘了。在以前他根本不敢让0级封印物进入这里而这次因为不涉及唯一性自身又相比过去有本质提升所以才有尝试想法。还好控制住了……以后得告诉隐者女士他们不能捡到什么都献祭给我我又不是收破烂……克莱恩咕哝两句开始检视旧日之盒。他记得魔术师小姐还在这封印物里面所以打算尽快弄清楚旧日之盒情况免得因拖延害死诱饵。这件封印物层次很高魔镜阿罗德斯了解相当有限还是得我自己来啊……目前看来只要不尝试占卜第三层有什么不试图寻找力量源头危险是可以承受甚至没有……克莱恩依循自己灵性直觉初步做出判断。紧接着他具现纸笔开始占卜。不知过多久他终于睁开眼睛无声自语：第一层可以将内部空间与目标区域对换位置并玩具化缩小化相应场景……这是它勉强可以被利用一个能力……被玩具化生灵必须在24小时内释放否则会永久转化连灵体都得不到安眠……释放很简单只要指定一片区域小到近乎没有生物区域与内部空间进行对换就可以了……这个能力覆盖范围有极限顶多一个像贝克兰德这么大城市……我为什么要用这个举例……第二层记录着不同场景有深渊有星空有各种各样地方可以让持有者和一定范围内生灵直接转移到目标区域……这个的问题是有随机性小部分时候可以自行指定放出相应地点绝大部分时候选择地点会发生变化最终抵达目的地难以预料……至于什么时候指定有效什么时候出现异变没法知道……而且这似乎是好运无法影响或者说序列0以下好运无法影响……这意味着没办法用旧日之盒这个非凡能力将白银城直接从神弃之地转移出去哎如果可以我奇迹师仪式就很简单了……呃等会试一试玩具化行不行……第三层很危险很危险很危险重要话说三遍我就不冒险窥探了不这应该叫作死窥探……旧日之盒负面效果很简单就是持有者会随机性消失暴毙或者异变如果没持有者周围区域生灵将按照距离远近个体大小相继遭遇这种可怕事情最大范围和第一层类同……这些0级封印物都是一句话不对就毁灭城市杀掉几十上百万甚至更多人可怕家伙啊难怪需要按最高标准封印不窥探不打听不描述……消失者去哪里似乎与第二层场景有关……秘之圣者之所以敢于拿着这封印物行动是因为他有命运天使乌洛琉斯祝福可以将负面效果随机性降到最低但就算这样他也不敢持有太久因为祝福会被消磨……看来他最后没能提前恢复清醒找到机会传送离开也和运气变差有关……大组织受重视圣者真难杀啊……隐者女士也算经验丰富头脑清醒没有盲目接触而是制造无形仆役去拿并且最短时间内就将这0级封印物献祭给我……理论上来说我可以召唤历史孔隙中投影来拿这物品反正死了消失了异变了都没关系但这无法保证使用时间除非预先得到威尔·昂赛汀祝福……封印办法是放入灵界这还不够得是灵界里被扭曲隐藏起来一片空间然后定期往里面灌普通水让旧日之盒每天闲着没事玩弄微生物……那么多生灵可以支撑很长一段时间了……掌握这个思路封印办法还有不少……大致弄清楚旧日之盒具体情况后克莱恩看着这0级封印物只觉它第三层似乎不再有那种沉重无法打开感觉。隐约间他相信自己只要伸手解除源堡力量封锁就能轻松打开旧日之盒第三层。……好强诱惑力……克莱恩拔回目光将手一挥让旧日之盒飞向角落里杂物堆。管它是不是0级封印物先去那里清醒一下！作为一件可怕0级封印物得有编号才有位格可惜我不知道七大教会0级封印物排到多少号了应该不会超过50吧？嗯旧日之盒暂时就叫0-61以后视具体情况再调整……如果隐者女士没法创造好封印环境可以把0-61放在灰雾之上等有需要了再申请当然必须提前向威尔祈求祝福……也不知道我这个执掌好运黄黑之王得到什么阶段才能名副其实？奇迹师有一部分诡秘侍者应该也有一部分……克莱恩自娱自乐想一阵后拿起秘之圣者布提斯遗留非凡特性。这外形如同晶石里面无数光芒折射衍化出一道又一道虚幻而璀璨门。克莱恩凝视几秒突然将这非凡特性扔向半空。源堡力量又一次沸腾在克莱恩操纵下形成实质般半透明波浪狠狠拍到那颗晶石上。晶石瞬间破碎分裂为数不清细小光点一股股漆黑气体从中冒出在源堡内扭曲着飞快消融淡化不见。那些细小光点在非凡特性聚合定律作用下逐渐靠拢用近一分钟时间重组为刚才那颗瑰丽梦幻晶石落回克莱恩掌心。它里面污染被清除。——在源堡内克莱恩就等于一位序列2天使只不过很多时候空有力量无法使用对应层次非凡能力必须有正确辅助之物帮忙。放好秘法师非凡特性后克莱恩又将目光投向布提斯残余那两颗眼珠。

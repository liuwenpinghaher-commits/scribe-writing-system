# 1325 倒吊人 第六十章 成功的“弥撒”

## 打开书
对于向愚者先生祷告之事巴德尔举双手双脚赞同一点也没有催促波恩意思。他自己每天早上醒来时和晚上入睡前都会做超过一分钟祈祷感谢愚者先生带来纯净阳光美味食物和不再有压抑绝望生活。……这个时候波恩已找张椅子坐下虔诚向愚者先生祷告：支配灵界伟大主宰不属于这个时代愚者我渴望得到您庇佑渴望您能实现我摆脱畸形愿望……非常自卑辛和鲁斯等人隐约猜到愚者先生打算满足类似愿望祷告之时身体竟微微颤抖难以控制。……灰雾之上古老宫殿内坐在青铜长桌最上首愚者克莱恩看见色泽不同一点点纯净光辉相继亮起在自己眼前形成一条缓缓转动浩荡银河。那祈祷声音完全重叠在一起回荡于源堡内部荡起阵阵涟漪。克莱恩闭目感应几秒颇为感叹抬起右手屈起中指轻敲斑驳长桌边缘一下。……她瞬间闭上眼睛弯下腰背将额头贴至地面难以遏制赞美起愚者先生。……当！……赞美愚者先生！他们同时喃喃自语将右掌按在左胸。拜亚姆城内波恩和巴德尔泪流满面调整自己位置朝向菲利普斯街朝向那座属于愚者先生教堂虔诚而感激聆听着来自天国神圣钟声。灰雾之上愚者克莱恩却是颇有点惊愕和茫然。……他旋即将目光投向菲利普斯街16号愚者教堂。……克莱恩险些爆出粗口。此时此刻他目光都难以掩饰呆滞不少不太明白为什么时天使阿蒙会突然出现而且还很认真敲响自己教堂大钟。对于阿蒙和查拉图可能到来克莱恩其实有一定心理准备因为白银城和月城人数量实在太多无法隐蔽融入外界社会。……也就是说白银城和月城必然会被各大教会和隐秘组织知晓这种情况下不管是公开还是私下传教都不会影响到事情发展所以克莱恩默许白银城广泛宣扬愚者信仰尝试为自己晋升序列1准备更多锚。……在这里于源堡内具备天使之王位格和层次克莱恩能充分发挥主场优势而白银城也有着0级封印物完全可以对抗阿蒙拿下查拉图。……可是阿蒙现在行为让克莱恩相当迷惑不明白这位欺诈之神究竟想达到什么目的。……菲利普斯街16号愚者教堂内。轮值这里大主教白银城六人议事团长老戴里克·伯格同样愕然望向高处彩绘玻璃。……戴里克一边利用无暗者非凡能力审视周围环境一边飞快思考敲钟是否有神秘学上象征意义。排除一个个可能后他突然记起白银城编撰愚者圣典。……那是用来描述时天使阿蒙与愚者先生关系确定祂实质地位。……对于那段语句戴里克其实持反对态度因为他知道渎神者阿蒙不是愚者先生眷者双方关系甚至谈不上和睦处在敌对状态。可是他之前撒那些谎让白银城六人议事团其他成员相信时天使阿蒙是受愚者先生指派为神弃之地人们洒下最初光芒存在正是因为祂寄生戴里克才有后来种种变化直至希望降临。戴里克想要解释但又不好意思解释那会扯出太多谎言让他在六人议事团其余长老在白银城民众面前失去形象如同正义小姐曾经说过那样社会性死亡。最终他选择拖延想着圣典是要先给愚者先生看如果描述有什么不妥祂肯定会降下神谕给出修改意见。谁知道愚者先生什么都没表示默许圣典内容。……他忙低下脑袋开始祷告将这件事情汇报给愚者先生。……灰雾之上源堡内部。克莱恩还没来得及清除阿蒙对方就陡然透明化成光芒消失在钟楼上。这家伙想做什么？如果祂爹是大帝而非远古太阳神那我可以合理怀疑祂在给我送钟……克莱恩一边检查白银城和月城人体内是否有潜伏阿蒙一边毫无思路分析着阿蒙目的。就在他打算用占卜方法寻求线索时太阳戴里克完成祷告。……圣典圣典？克莱恩嘴角微动从杂物堆里召唤来白银城献祭给自己圣典。……缓慢吸口气克莱恩伸出右手一页页翻动起面前经文。克莱恩越翻越快越翻越快终于他看到最后一页。克莱恩猛地合拢愚者圣典将它丢回杂物堆内。月城这场奇迹后嗯魔药已消化得差不多了秘偶城市得登上历史舞台了……克莱恩面无表情审视下自身状况微不可见点点头。自从他初步掌控住源堡在这里也能获得来自现实反馈了。

## 这场戏有没有翻
翻了。开头银河许愿去畸成功；天国钟响；阿蒙认真敲愚者教堂钟；圣典默许致社死拖延；章末翻圣典丢回＋秘偶城上台。翻的是成功弥撒＝神迹成＋阿蒙送钟谜＋消化够晋。

# 1233 逐光者 第八十四章 “降临”的投影

## 打开书
灼眼纯白射线直接穿透玻璃窗落到巫王卡拉曼身上。它随即爆发出强烈光芒消融着所有不死阴暗和邪恶。卡拉曼身影腾得燃起发白火焰就如同凑近烧红煤炭纸人。那确实是一张纸人仿佛由绯红月光凝成纸人。巫王替身之术月亮纸人！纸人化成灰烬间那位古老巫王出现在教堂尖顶处将冰冷目光投向钟楼附近埃姆林·怀特。就在这时卡拉曼鲜红如血眼眸内映照出身穿黑色宫廷长裙头戴小巧软帽莎伦身影躯体一下僵硬似乎失去自我控制能力。埃姆林见状没有犹豫就像演练过千百次一样将纯白之视对准对面巫王左胸准备激发太阳领域无暗之枪。只要这攻击能命中卡拉曼心脏这位巫王就没法靠月光化消解也难以通过人造吸血鬼超强恢复能力自愈。当然这肯定会给附身于卡拉曼莎伦造成较为严重伤害但如果能因此快速解决目标她愿意付出相应代价。在之前沟通里埃姆林和莎伦马里奇已经讨论过类似几个方案取得一致。这也是莎伦不通过影响巫王卡拉曼衣物束缚住他原因比起怨魂附身这对能月光化对手来说更加容易化解至于卡拉曼是否会因裸奔而羞耻魔镜答案是不会。类似种种前提下他们最终选择让埃姆林·怀特突袭目标以此消耗他月亮纸人给莎伦附身创造机会。眼见埃姆林手中透明玻璃球又一次积攒起光辉延伸出一支纯净到极点炽白到极点长枪僵立在教堂尖顶处卡拉曼突然有变化。他额头正中快速裂开一道缝隙里面仿佛镶嵌着一轮血红满月。潮水一样月光涌出来让身体虚幻头发淡金眼眸浅蓝莎伦身影不受控制从卡拉曼身上漂浮出少许。卡拉曼僵硬迟缓动作勉强恢复正常在满月光辉里他化成一团血色分裂出无数光之碎片。他身影飞快于教堂另一处尖顶重组背后紧贴着身穿黑色宫廷长裙莎伦虚影而埃姆林制造无暗之枪穿过卡拉曼原本所在位置飞向远方于半空膨胀成一轮微缩太阳。整座港口城市骤然被照亮。与此同时卡拉曼右边肩膀出现明显蠕动有事物撕裂黑袍钻出来。这是一个做工精致男性人偶它只有巴掌大小身穿暗红镶金纹礼服眼睛不知被谁挖掉只剩下两个黑洞。这人偶坐在卡拉曼肩头双手抬起十指连按仿佛在弹奏无形乐器。莎伦身影顿时被弹离卡拉曼背后似乎受到严重排斥。埃姆林则感觉衣物一下变紧牢牢束缚住自己。他领结同样活过来要将他勒死在半空。那个人偶是玫瑰学派给予卡拉曼1级封印物叫做无瞳将军是异种途径一位序列4半神因某个意外暴毙后形成物品。它有活着特性可以根据拥有者想法附身有灵事物唤醒无灵物品但平时必须由持有者用自身血肉喂养否则它会逐渐长出眼睛。而这封印物一旦完好就会化身为疯狂追杀原本主人恶灵并憎恶所有人类。埃姆林听见自己骨头发出不堪重负声音时灼烧着他灵魂纯白之视绽放明澈光芒将周围区域变成没有阴影没有邪恶无暗国度。无瞳将军对他衣物影响随之中断。但这个时候卡拉曼已是含糊不清念出某个单词带着残忍笑意前探双手凭空拉伸出一扇虚幻朦胧铭刻着诸多神秘符号门。这是召唤之门！月亮途径序列3叫做召唤大师！原本只有巫王层次卡拉曼在额头那血红满月照耀下竟直接完成召唤！不过他整体气质也因此发生一定变化理性褪去不少疯狂更加明显。虚幻吱嘎声里召唤之门敞开一道缝隙。缝隙中两只人类手掌探出来皮肤毫无光泽缺乏质感如同最劣质布偶。……凡尔特克城外原本打算追随复活尸体进攻鲁恩军队防线玫瑰学派信徒和附庸们疯狂自相残杀着没有一点理智可言。原本是普通人他们有弯下腰背长出灰黑色狼毛嘴角咧开不断滴下黏稠唾液有皮肤染上黑色坚硬如同钢铁有失去心脏倒在地上却又一点事情都没有爬起来有身体透明虚化仿佛变成一个个幽影……神孽斯厄阿只是气息降临就污染周围生灵让他们或崩溃惨死或异变成狼人活尸等超凡生物。——作为序列1高位存在祂是能直接赐予信徒们力量只是有时间限制只是这种方式未必是那些反抗军希望。战场另外一侧超过两千米外鲁恩工事后那一个个士兵虽然什么都没看见什么都未听闻皮肤表面依旧冒出一个又一个透明水泡脑海里回荡尽是宣泄各种情绪各种欲望想法。用不了多久他们就会一个接一个疯掉变成没有理智可言野兽而整个阵地乃至凡尔特克城内都找不出多少还能保持清醒人类。突然之间他们听见吟诵。那是由一道又一道圣洁空灵声音组成吟诵。这吟诵来自城内黑夜教堂就仿佛有多个唱诗班在赞美女神。士兵们市民们军官们相继沉睡过去就在工事后战壕内街道旁。他们梦见一片宁静黑暗梦见一朵朵月亮花一丛丛夜香草身心都极为宁和不再受到邪恶侵蚀。凡尔特克城黑夜教堂里值夜者高级执事女神之眼伊丽娅努力维持着这笼罩全城梦境无力再插手外面半神级战斗。克莱恩和蕾妮特·缇尼科尔则同时感觉到周围灵性在异变似乎化成一重又一重屏障试图将他们束缚在原地限制他们行动。而那位巫王胸腹间血红软泥处斯厄阿手臂完全探出后一团覆盖黑色粘稠液体蠕动肉块跟随钻出构成这位神孽身躯。祂就像是一株被浇上石油巨大树木伸展枝丫由凸起一个又一个奇怪事物诸多手臂担当。树干之上粘稠黑色液体表面一个又一个布满血丝黑白眼珠到处滚动着让目睹者理智瞬间被清空变成一只只兔子一头头山羊一条条肥猪。那几十上百条手臂飞快延伸往外有封锁高空有钻入大地有从四面八方合围有直接抓向克莱恩和蕾妮特·缇尼科尔。与此同时神孽斯厄阿发出直刺灵体嘶吼让两个目标同时颤抖出现一定僵直让半空绯红月光变得更加浓厚让一副场景在红色幕布上呈现出来。那幕场景核心是一个缠绕着发黄绷带木乃伊它被数不清棕褐色树枝刺穿悬吊于半空。它肚子高高鼓着时而有某个位置凸起又瘪下仿佛正孕育新生命。这木乃伊嘴巴张合着不停惨叫着克莱恩虽然听不到实质声音但身体与灵魂内依旧有一种痛苦在共鸣在让他一点点负担起木乃伊遭遇。被缚之神！神孽斯厄阿刚才那声嘶吼是由一个个古赫密斯语单词以超出人类想象方式重叠组成本质是在向被缚之神祈祷然后祂成功得到回应！——欲望母树还无法将太多力量渗透入现实若想向祂祈祷获得天使层面反馈必须有一个大型祭礼当然欲望母树直接施加影响和祂通过被缚之神给予注视也是存在一定区别和本质差距。被缚之神原本并不是真神只是容纳异种途径唯一性和两份序列1非凡特性天使之王在生下神孽斯厄阿后祂甚至还失去一份序列1非凡特性等到被欲望母树完全侵蚀则同样遭受隔离命运。所以无论欲望母树本质如何绕这么一圈后能对现实造成影响也有限但不管怎么样这次针对蕾妮特·缇尼科尔陷阱足够豪华！随着被缚之神投影出现整片大地都染上暗红颜色克莱恩顿觉与灵界联系被切断无法再用传送离开。他身影瞬间于一丛丛火焰里跳跃趁着蕾妮特·缇尼科尔对抗神孽斯厄阿机会将手探入虚空于不同位置分别抓一下。最终克莱恩拖出一个镶嵌着各种宝石银黑首饰盒然后毫不犹豫打开它第二层。旧日之盒！这0级封印物第二层能将范围内生灵整体转移到它记录某个场景中！

## 这场戏有没有翻
翻了。开头还在纯白射线打中纸人；西拜朗卡拉曼血红满月＋无瞳将军＋召唤之门探手；凡尔特克伊丽娅全城沉睡后被缚之神投影落地、克莱恩开旧日之盒。翻的是降临从气息变投影＋0级开盒，不是无暗之枪亮不亮。

## 热怎么变冷
无暗之枪将发还热。冷切在血红满月。无暗国度还热。冷切在召唤门手掌。全城沉睡还热。冷切在被缚之神幕布。开盒——热留给下章随机。

## 怎么起、怎么收

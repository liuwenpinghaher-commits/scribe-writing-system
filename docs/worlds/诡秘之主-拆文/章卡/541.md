# 541 旅行家 第六十章 戒严的拜亚姆

## 打开书
眼见格尔曼穿上外套戴好帽子提起手杖达尼兹才想起自己似乎被遗忘。咳一声在两道目光注视下道：「我我需要跟去吗？」最好是不要…谁知道会发生什么事情！之前只是临停班西港却遭遇相当诡异事件昨晚带着格尔曼去拜访反抗军联络人结果惹出海神诅咒今天再跟着这疯子去排查拉蒂西亚那几个考古学家谁知道又会发生什么事情！低头瞄眼还绑着夹板左臂只觉短短几天时间内自己遇到事情就胜过以往几个月甚至半年。「你可以留在这里但等下会有人来排查。」艾尔兰呵呵笑一声。有人来排查？然后大海盗烈焰落网变成金镑？眉头一皱干笑道：「除了拿悬赏能从军方手里赚钱机会不多我非常乐意试一试。唯一问题是你们得等待几分钟我做些伪装船长先生我不希望引起不必要误会从而让你为难。」如果不做伪装我这大海盗跑去和军方教会一起行动只会被当场摁倒抓捕归案…想象一下自己被直接按翻遭膝盖抵背只能像鲶鱼一样挣扎场景。艾尔兰回想几秒从衣物内侧口袋掏出个铁黑色面具扔过去：「戴上它就行了其余事情我会解释。」嗯没必要浪费时间做用处不大伪装…心里评价一句。没有说话拧动把手走出房门。艾尔兰紧随其后边戴铁面具边取外套达尼兹匆匆忙忙追赶。来到多有积水不见路人街上按按帽子道：「怎么找？」艾尔兰笑笑道：「分区域排查。我非凡职业拥有一些特性只要见过真人照片或素描就能牢牢记住目标样子获得超凡层面上额外感应嗯我还能察觉不正常因素把握到不明显痕迹这两者结合起来就可以相当有效进行排查了。」仲裁人途径序列8治安官…若有所思点头边走边问：「有他们物品吗？」——昨晚达尼兹贴布告上有附送拉蒂西亚肖像画这是用仪式魔法自己向自己祈祷完成。「没有。」摇摇头「尚未掌握他们之前行踪能确认情况是他们昨天下午3点左右才从西弥姆岛返回而两点之后没有客轮离港今早因为天气原因也是只进不出。」也就是说拉蒂西亚等人还没能坐船离开…明白意思。达尼兹忽然嗤笑一声：「这什么也不能说明或许他们昨天下午就已经离开拜亚姆前往岛上其他城市。」蓝山岛是罗思德群岛第一大岛面积很大森林和矿产资源丰富所以岛上还有许多城市它们围绕肥沃土地和储量惊人矿藏建立。为了这些财富鲁恩王国先是贿赂土著王公继而武力强迫最后直接成立总督府以较为高效方式开拓了连通各个城市宽阔大道并完成几条重要铁路——这是以组建相应铁路公司在贝克兰德证券交易所卖出股份募集资金形式推进。当然这些大工程伴随是诸多本地人死亡险恶施工环境超限度工作近乎奴隶待遇相当微薄薪水让马路路基和铁道枕木下埋葬一具又一具尸体。直到今天大量本地人仍然仇视铁路认为它吞噬大量人命带来数不清苦难是邪神恶魔象征。艾尔兰侧头看达尼兹一眼道：「如果他们从陆地离开那就不需要担心什么。」「为什么？」不解反问。很简单那些道路穿过丛林直接受到反抗军威胁而反抗军绝大多数都属于海神信徒所以导致卡维图瓦行将崩解拉蒂西亚等人怎么敢晚上通过这些区域？如果他们敢只能说明一个问题他们并没有认识到自身在西弥姆岛海神遗迹内做事情会导致何等严重结局这也就否定摩斯苦修会或者要素黎明另有图谋猜测…控制住摇头冲动跟着拐入另一条街道。艾尔兰也未解释什么直接拿出一张布告递给格尔曼：「主要目标就是上面这个女人。」上面这个女人是我画…瞄一眼丢给达尼兹。就这时听见侧面房屋内传出一阵激烈打斗声。「找到了？」达尼兹问出想问问题。「应该不是。」摇下头「根据安排发现主要目标后第一反应是放出红色烟花只要出现这种情况所有人都要向那个地方靠拢如果遭遇是其他通缉犯且属于本身无法对付类型则放橙色烟花周围几个小组会赶去支援若只是一般海盗罪犯自行处理。我们等等看也许是来不及放烟花…」说话间临街房屋三层玻璃喀嚓一声破碎一个巨熊般壮汉跳下来速度极快宛若猎豹奔向远方。这时巨大阴影笼罩他哒哒哒声音从高空传来。那壮汉身体几乎被机枪子弹撕裂没有反抗之力倒在街上鲜血汩汩流出染红一地如果不是居民们被禁止出门必然会有此起彼伏尖叫响起。不知什么时候漂浮过来飞空艇没有停顿移开转向别位置。「…戈尔塔特。」达尼兹辨认出死者是谁。见格尔曼侧头望来强行笑道：「这是个海盗团首领弗萨克人赏金950镑。」弗萨克人…果然都是蛮子吗…竟然就这样在戒严街道上奔跑完全不知道防备头顶袭击…也是这些海盗刚醉生梦死一晚根本不知道连飞空艇都出动了…他要是规划下逃跑路线未必躲不开空中机枪扫射…收回视线目送深蓝涂装空中怪物飞过屋顶。达尼兹看见那位海盗下场分外庆幸自己跟出来。艾尔兰见这边警报解除不再停留领着两人转向自身将负责区域。快步行走五六分钟后看见前方路口堆起街垒架起枪支摆好火炮一位位红衣服鲁恩士兵沉默守在那里。街垒另一侧二三十具尸体凌乱倒在地上形成冲锋过来队形。他们衣着破烂脸庞干瘦皆是本地人种。更远一点地方好几个年纪不大土著小孩躲在墙角安静畏缩望着这边望着幽深铁沉枪口眼珠乌黑脸庞肮脏。克等人沉默几秒绕过这地方。……贝克兰德乔伍德区。佛尔思端起桌上陶瓷水杯感受到些许滚烫。凝聚精神安静等待起变化。热水温度飞快降低液体表面凝出薄薄冰层杯子边缘则有白霜浮现。「我是戏法大师了…」欣喜闭闭眼睛。收到食灵者胃袋没有耽搁当即调配魔药完成晋升获得不少威力较低类法术能力。其中最喜欢造雾刮风闪光冰冻电击和让人脚下打滑摔倒术。直到这一刻才觉得自己算是完整非凡者不再只会穿墙开门不再必须依靠仪式魔法。……临近中午艾尔兰在克和达尼兹辅助下完成大部分排查工作。「先啃条面包喝点水再继续。」摘下船形帽嘴唇发干说。正要点头忽然看见不远处有一朵橙色烟花腾上半空绽放开来。艾尔兰几乎没有犹豫当即戴上帽子奔跑往那个方向：「我先过去支援。」「橙色表示有无法对付别通缉犯…会是谁呢？」颇感兴趣自语。改用高抬腿姿势前行务求战斗结束才抵达然后看见格尔曼扔下自己紧随公正艾尔兰而去。瞄眼半空飞来深蓝怪物干笑两声猛地加快脚步。两分多钟后抵达目标所在地看见一栋有临街草坪房屋外倒着三四位军方人员他们皆脸色发青身体颤动似乎被丢进了结冰湖水里。越往那个方向走越有种遭遇寒灾来到极地感觉。很快发现房屋外面沟渠里堆满厚厚白雪。就这时房屋内突然传出一阵女性笑声时高时低时疯狂时诡异：「哈哈哈…咯咯咯…哈哈哈…咯咯咯…」达尼兹忍不住停下脚步用右手摸下起了层疙瘩脖子。哐当一声窗户打开飞出一具焦黑人体。重重落在地上就像遭遇火灾。仅瞄一眼就依靠灵性直觉辨认出这是跟随拉蒂西亚三位男性冒险家之一。

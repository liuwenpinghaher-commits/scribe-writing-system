# 1239 逐光者 第九十章 “潮水”

## 打开书
清晨时分霍尔伯爵在最习惯那个时间点醒来于自家花园内和草坪上做次散步。等他看完心爱几匹纯血马回到别墅三楼更换好外出衣物他夫人凯特琳也已起床正在吩咐贴身女仆将刚想到安排传达下去。该用早餐。霍尔伯爵立在衣帽架旁笑着对自己夫人说一句。就在这时他听到外面传来一阵喧哗而且越来越近没有平息。微不可见皱下眉头霍尔伯爵侧头看自己贴身男仆一眼。无需这位大贵族开口那贴身男仆立刻走到窗边拉开剩下那层薄纱帘布。刷一声后更多光芒照入卧室一片澄净。那贴身男仆随即将目光投向窗外左右扫几眼表情突然变得凝重。他回过头来瞄眼还在和女仆说话伯爵夫人快步走至霍尔伯爵身旁压低嗓音：游行！很多人在游行！游行？霍尔伯爵对这个名词一点也不陌生作为鲁恩大贵族康斯顿煤钢联合体第二大股东他见过不少次工人聚集游行要求提升周薪规定最高劳动时间而最近这一两个月里贝克兰德也因种种问题爆发过几次游行抗议但都很快就被平息下去没能造成什么影响。目光在贴身男仆脸上来回移动几秒霍尔伯爵眼睛微眯敏锐察觉到今天游行可能和自己想象得不太一样。他不动声色前行来到窗边。一眼望去霍尔伯爵眸光突然凝固。借助身在三楼优势他看见远处路上黑压压都是人他们聚集在一起往着这个方向涌来就如同要笼罩贝克兰德巨大乌云。面包！我们要面包！几千几万甚至更多人呐喊汇聚在一起逐渐变得响亮和清晰听得霍尔伯爵头皮微微发麻。在纪念日广场参与大弥撒等活动时他不是没见过这么多人没听过一声声叠加起来话语但那个时候他勉强算是处在人群中是属于这个整体一部分而今天他是那汹涌潮水目标之一。霍尔伯爵忍不住看眼那游行队伍后方发现根本没有尽头不过有着丰富事务经验他能根据观察到一些细节作出判断。他能看见位于游行队伍两侧警察和士兵非常少与大量人群相比就如同海潮激起一朵朵浪花极其渺小。霍尔伯爵相信针对皇后区游行肯定会得到最强有力控制不会没有大量士兵和警察被派过来现在状况只能说明一个问题：参与游行人实在太多！以至于士兵和警察们被分散得太开！超过十万人游行？或许还不止……因为食物短缺产生游行随时可能转化成暴乱和抢夺……现在看起来还很有秩序……是因为有许多组织者和领导者？该死军情九处和各大教会就没发现一点迹象吗？这种规模游行怎么可能一夜就组织起来？就算贝克兰德已经变成火药桶要想把它点燃也得划不少根火柴！霍尔伯爵脑海内闪过一个又一个念头表情越来越凝重。面包！我们要面包！那呼喊声越来越整齐越来越巨大就仿佛城市里出现海啸。此时霍尔伯爵府邸内男仆女佣们都察觉到动静纷纷来到窗边望向大门之外。他们脸色旋即变得苍白就像遇到决堤洪水而自身躲避不开。面包！我们要面包！数不清声音交汇在一起黑压压人头带来极强压迫感。霍尔伯爵猛地惊醒下意识就要找人拍电报给王室让他们组织军队过来镇压。可他做更进一步观察时候发现游行队伍里不少人穿着军服身体残疾。面包！我们要面包！维持秩序士兵们一边戒备一边同情看着游行队伍枪口都指向天空。那些人里面有他们过去战友有他们父母妻儿有他们朋友邻居以及大量活生生和他们一样只想不饿死人们这让他们如何不心生怜悯充满同情？这样情绪最初或许只是在五六个士兵和警察心里产生但很快就蔓延到几乎所有人身上。换做以往在军官手枪监督下他们肯定会麻木接受一切命令而现在不少人心里想都是：哪个婊子养敢让我开枪我就开枪干死他！面包！我们要面包！一声声呼喊里大量人群聚集带来冲击中霍尔伯爵脸色变白一点。他忍不住收回目光看向房屋外面聚集卫队和保镖看向身边负责保护自己家族黑夜教会非凡者们发现两者反应各不相同。卫队和保镖们充满畏惧藏在里面被他雇佣来一些非凡者表情已变得相当严肃而黑夜教会保护者们目光里多有同情和怜悯情绪。对教会来说我这里或许相当于一千个信徒而外面有几万十几万甚至更多……霍尔伯爵瞬间产生这么个明悟对自己之前准备做事情会带来怎样后果有清晰认知：哪怕武装到牙齿仅靠数量不多卫队也根本没法对抗那么多游行者一旦爆发冲突黑夜教会非凡者根本指望不上自己一家能够在雇佣来保镖下逃出皇后区就算女神眷顾！第一次霍尔伯爵体会到人多力量体会到那么多人汇聚起来恐怖。念头电转间他当即转头吩咐贴身男仆：拍电报给首相拍电报给其他贵族说我愿意带头捐出绝大部分粮食！请他们一定要保持冷静！随着电波飞逝和交换居住在皇后区贵族们都知道霍尔伯爵态度。现任尼根公爵表情凝重看眼窗外沉默一阵吐口气对身旁男性秘书：保护好府邸放弃强硬姿态跟着霍尔伯爵做。还有先拿那批囤积粮食商人做表率！等到上流社会初步达成一致有应对方案霍尔伯爵一颗心终于落回原本位置有余力前往餐厅和家人会合。通过餐厅之门时他下意识扫一眼里面情况。妻子立于窗边忧虑望着外面；长子不断地来回踱步显得很是愤怒和焦躁；女儿站在妻子身旁极为安静看着游行队伍潮水一样前移。……迷雾海未来号。嘉德丽雅踏着星光凝成璀璨长桥回到甲板上。船长你这次一定要管管弗兰克！水手长妮娜率先冲过来高声喊。嘉德丽雅忧郁悲伤心情一下被打破微皱眉头：他又做了什么？妮娜一脸愤怒：他问我会不会生孩子他想要研究生命是怎么孕育灵魂是怎么产生！……你打了他吗？嘉德丽雅默然一秒。打！妮娜一点也没掩饰。嘉德丽雅随即将目光望向不远处弗兰克无视他鼻青脸肿状态：你还是先研究鱼类繁衍吧。好吧。弗兰克挠下头听从船长命令。嘉德丽雅随即对船舱阴影里长出来脸色苍白无血者希斯·道尔点头：没事。希斯·道尔明显放松下来：是船长。被船员们这么一闹嘉德丽雅终于回到现实世界趁他们不注意揉揉额角飞进船长室。接着她用魔法封闭这里拿出那个在0级封印物里也排名前列许愿神灯。做完准备嘉德丽雅坐至书桌后低下脑袋用巨人语诵念起愚者先生尊名向祂汇报神秘女王事情。正提着马灯在北方城邦遗迹周围区域勘察地形克莱恩略微侧头倾听几秒然后按照流程进入灰雾之上。他旋即坐至斑驳长桌最上方属于愚者那张高背椅将灵性蔓延向代表隐者那颗深红星辰。神秘女王有那座原始岛屿初步线索打算离开安全航道做大范围长期搜寻……那座原始岛屿是罗塞尔大帝偶然发现上面很可能藏着他九座秘密陵寝之一……这是目前唯一没被发现没被摧毁那个是大帝复活归来希望所在……不过那座原始岛屿生灵似乎在崇拜源自星空未知力量仅仅了解就会被污染星空……得提醒隐者女士一句让她写信告诫神秘女王……许愿神灯……许愿神灯？原来这件0级封印物在神秘女王手里……它是由奇迹师非凡特性和来历神秘特性结合而成连真神都无法粉碎……克莱恩刚听完0-05事情立刻就调整视角将那盏水壶状金色神灯影像放大。突然那许愿神灯壶口灯芯自行燃起来！

## 这场戏有没有翻
翻了。开头霍尔伯爵还在早餐散步；潮水要面包逼他带头捐粮；女儿安静看潮；章末嘉德丽雅汇报0-05时灯芯自燃。翻的是贵族从镇压念头翻到捐粮冷静、灯已醒，不是游行声响。

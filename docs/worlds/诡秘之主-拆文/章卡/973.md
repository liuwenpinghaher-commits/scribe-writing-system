# 973 红祭司 第二十八章 心灵世界

## 打开书
赫温端骨瓷茶杯，看坐姿端正的奥黛丽：不用拘束，两年前还讨论伯曼道德哲学与孔西索实用主义。她：难以把您和评议团委员联系一起——合理推测，他尚未自报。他跷腿：心理炼金会偏学术非事务，委员当大学教授。若不知他幕后操纵卡隆自杀，表面只是渊博和蔼风趣学者；有戒心则不信。她注意力不钉一点、思绪发散，防催眠。精神恍惚：七道净光、密密身影弥漫高处——灵性天空，灵界心灵映射。下方幽邃大海，每滴水液如光影、意识烙印。近处几座岛，一座属她。露出海面=能察觉意识；淹没=深层次。岛上先见孤独灰蒙，遮潜意识深黑轮廓与集体潜意识海洋。灰蒙潮退，石阶现；赫温闪现蹿升——全白密发、三件套蓝灰裤暗红领结——气质阴鸷无笑，审视潜层。几步从集体潜意识入她意识岛，未允许未敲门的沉默访客。登岛后部分皮肤灰白鳞、金竖瞳。她明悟：心灵世界=灵性天空+集体潜意识海+个人意识岛。愚者天使祝福触发警戒，分离最本质自我，半空操纵岛屿对抗读心。兰比斯真可恶，闯入别人的家！现实回：面对大学教授也很拘谨。岛内咕哝：他至少序列4半神，天然敬畏。沙发上他笑：听希尔伯特说你几个月从心理医生晋催眠师，好奇怎么办到；伊思兰特的勇于应用不够，要细节。岛上他无表情倾听回荡声。她装组织语言：勇于应用——规划里早有心理医生，有能力就帮身边人。岛屿忠实地不好意思。某天体内哗啦破碎入血，隐约虚幻星辰，笃定能成催眠师——潜意识暗示？故意让岛上自己吐舌，证尴尬=真话。他点头：有天赋，自己摸索扮演法。她内外诧异。他：按魔药名扮演总结守则，消化减负面；序列6前不提倡成员用此加速，故不教。为何？会变得不像自己，被残留影响同化；前三序列慢适应让自我更鲜明，利于后抗扮演问题——只对观众途径有意见。她想起太阳“记住你只是在扮演”，觉更恰当；要多注意自我加强。请他细讲。他：有资格申请序列5梦境行者配方，前先给任务——公平也锻炼；成序列5将领导两三小组，判断影响成员未来乃至生命。第一个任务简单长期，每次反馈算贡献。叹：新党保守党隔阂撕裂；留意霍尔伯爵对议案态度转达我——不会损害，只想弥补裂痕。无逻辑支撑的承诺；岛上他按额角，她竟深信。半空她旋即清醒，发现不对。

## 这场戏有没有翻
翻了。开头还在骨瓷茶与教授比喻里拘谨；章末已在心灵世界看穿闯入读心，又几乎被“弥补裂痕”暗示按住，半空自我才醒。翻的是表面学术谈话收到读心与政治任务，不是岛屿奇观。

## 这一章新讲明的规矩
- 心灵世界：灵性天空、集体潜意识海洋、个人意识岛屿。
- 可借集体潜意识隐秘侵入心智；天使祝福可分离本质自我对抗读心。
- 扮演法：按魔药名扮演、总结守则；消化减负面。
- 心理炼金会序列6前不提倡扮演加速（防不像自己、被同化）；前三序列慢适应自我。
- 观众序列5=梦境行者；晋升前派任务；序列5领导两三研讨小组。
- 任务：留意霍尔伯爵态度转达——他声称弥补裂痕。

# 1308 倒吊人 第四十三章 上门辅导

## 打开书
黎明号绕着那座原始岛屿航行三圈后终于向着被暴风雨笼罩远方驶去。贝尔纳黛缓慢收回视线将目光放在漂浮于空中贤者额饰上。作为一名预言大师她清晰看见晋升契机明白自己已完成相应仪式阻止一场涉及高层次力量灾难。但代价却是亲手封印自己父亲思念一百多年追寻一百多年父亲。这真是一个绝妙讽刺啊……贝尔纳黛看着那钻石镶嵌成竖眼微不可闻叹息一声。……她不再犹豫不再自责不再产生种种负面情绪坚定抬起右手于虚空中勾勒出一个又一个闪烁星辉古老单词召唤出那个上半身人下半身风灵界生物从它那里拿回贤者魔药部分辅助材料。……没过多久贝尔纳黛借助苍白的死亡粉碎贤者额饰调配好那瓶可以让她晋升序列2魔药。……随着贤者魔药入口贝尔纳黛身体以肉眼可见速度变得虚幻。……整条黎明号乃至周围狂风暴雨闪电海水波浪都随之失去实感仿佛还原成最底层最本真各种各样信息。……这又称信息生物。贝尔纳黛依靠贤者额饰曾经多次化身信息洪流……此时她竭力维持着自身意识存在并与阻止一场高层次灾难产生灵界信息建立起某种联系。……这个过程中灰雾之上克莱恩借助特殊标记过祈祷光点轻敲下斑驳长桌边缘利用奇迹师在某种程度内改变某些事情某些行为概率能力赐予贝尔纳黛一定好运。……此时她渐渐能感觉到星之上将嘉德丽雅牵挂感觉到要素黎明成员和属于自己船员水手们日常做着祈祷。……这是来自隐匿贤者干扰！作为这个世界知识和信息某种化身作为窥秘人途径近似序列0隐匿贤者能对同途径低于自身序列者施加一定影响。没给贝尔纳黛使用苍白面具机会克莱恩披着幕布轻轻扬起来。……这一刻她真正成为祂成为窥秘人途径序列2天使是神秘世界可以被尊称为隐秘存在大人物了。……女士我是橘光希拉里昂。……某位伟大存在让我将有关旧日外神和星空知识告知你……灵界之上伟大主宰。……祂还有另外一个尊称：愚者先生。……某片海域中行于安全航道内未来号上。……嘉德丽雅翻身坐起披上斗篷尝试着向愚者先生祷告希望这位伟大存在能给自己一点提示或者庇佑一下女王。……神秘女王贝尔纳黛从灵界中走出回到黎明号上让这条船只逐渐远离隐约可见无名岛屿。嘉德丽雅顿时松口气诚恳感谢起愚者先生。……你在做什么？……之前构想遇到挫折暂时进行不下去我拜托妮娜从海底给我弄些泥土研究里面蕴藏微生物。……克莱恩具现出一个盒子把四张亵渎之牌都放进里面做了层层封印后立刻回到现实世界直奔最近那座黑夜教堂。他打算将亵渎之牌隐患用祷告形式告知黑夜女神提醒祂注意相关问题不要让大地母神莉莉丝得到母亲牌或者月亮牌。

## 这场戏有没有翻
翻了。开头讽封父；饮药成信息生物；幕布挡隐匿贤者成序2；橘光上门授旧日知；章末克莱恩奔教堂告牌。翻的是上门辅导＝愚者派橘光＋自去告神。

## 日子
绕岛三圈。饮药虚化。橘光上门。未来号梦醒。黑夜教堂。

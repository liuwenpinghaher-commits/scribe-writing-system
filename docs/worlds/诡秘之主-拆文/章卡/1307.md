# 1307 倒吊人 第四十二章 再见

## 打开书
灰雾之上克莱恩瞳孔瞬间放大下意识就低头看向身前斑驳长桌。那里反扣着四张背面花纹不太一样亵渎之牌。这一刻他有点后怕又有点庆幸感觉自己是蒙着眼睛在深渊边缘徘徊几圈却始终没有掉下去。如果他致力于搜集亵渎之牌凑齐二十二张或者得到母亲牌以他喜欢容纳不同纸牌获得对应位格和特质习惯现在说不定已经被那位堕落母神侵蚀不知道在孕育什么东西了。……万物皆有神性……最初还活着活在每个人体内！……你刚才说那些话语哪些该相信哪些该提防？你自己考虑。呵这不就是你们占卜家说话风格吗？……制造苍白的死亡那张面具时我察觉到一件事情：第四纪那位死神可能还没有彻底陨落而且留下复活伏笔不止一个其中部分或许与那条永暗之河有关呵呵死神肯定不是那么容易死去……果然只有选择占卜家学徒或者偷盗者途径穿越者才能进入源堡。我猜测出这个因素时候已经太迟太迟。我不知道你是否想成为旧日也不清楚这是否需要仪式只能告诉你这肯定比成神危险危险不知多少倍或许那位将我们保存起来依次投放到现实存在就在那里等着你。我唯一可以给你建议是在你尝试这么做之前和许愿神灯里面灯神交流一下。……好。……要是你真能成为旧日可以考虑救一救我只有旧日才能对抗旧日嘛。……如果连成为旧日你都没办法让我彻底摆脱原始月亮污染那你记得抹去我毁掉这座陵寝扶持出一位新黑皇帝让我永远都不再有可能复活……我会不会忘记。……当然在此之前你要多抢救我几次。……我妻子早就已经过世……我的长女贝尔纳黛你已经见过是不是很美丽？……我不知道该以什么样立场向你提出一个请求毕竟我从未帮助过你也和你没什么交情只是来自同一个时代同一个地方有几分老乡情谊。……你日记给了我很大帮助……能不能不提日记？罗塞尔轻咳一声道……我请求是帮我照看一下贝尔纳黛在她需要时候提供一定帮助。……我会帮你照看她。……嘶这话怎么听有点别扭？……对了还没问你姓名至于我你应该很清楚黄涛。周明瑞。克莱恩坦然回答道。结婚了吗？有孩子吗？几岁了？……没有。……你和我同辈贝尔纳黛该叫你周叔叔。……来到这个时代后我最开始是将这一切当成游戏……而你……我能感觉得出你孤独从骨子里透出来孤独。……如果我们都还活在原本那个年代就好了我会每天准时去上班……几个大男人一起坐到街边吃点串喝点酒吹一吹牛……再见吧朋友。希望真能有再见一天。……罗塞尔·古斯塔夫回归永恒沉眠。

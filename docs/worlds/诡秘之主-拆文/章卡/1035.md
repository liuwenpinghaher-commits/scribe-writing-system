# 1035 红祭司 第九十章 “预想”的发展

## 打开书
日记续：第二亵渎石板多远古太阳神晚年窥见之秘；门几乎肯定——太阳神陨，亵渎石板生。第一块谁制？多出何知？门：回现实才讲清。罗塞尔问时代潮流谁定——门笑十余秒：小心观众。通识者竟忘观众成神仪式，只记得序列0空想家；问门——你刚才不是说过了？仪式=让时代发展符合自己预想，关键节点潮流中晋神。比「时代是造物主一部分」更直；高位者稍不符预定即被引导或摧毁。门曾与所罗门查拉图图铎等第四纪姓氏共观完整第二石板。克莱恩如直面神话：亚当自四纪备；乔治秘密或即其预想浪潮；深查雾霾极危，女神难神降；眷者已承诺难逃，有所得必有失；至少先弄清国王秘密。收日记：「你们开始吧。」正义举手问十字意义——可等价。愚者：古代太阳神遗物；层次对应无暗者，清污染析多余特性助退圈。魔术师惊宫廷侍卫长怎持此物。正义悟世界曾问摆脱神秘。月亮侧目太阳。太阳惊喜宿命感应，请换取——付足代价即可。倒吊人问租赁数时——可。星星想阳炎与灵巫，暂不需。魔术师悔未记录能力，慰可租。无人要，克莱恩示意开交易。内心：安德森或需，让达尼兹问。正义提需求：梦境捕手心脏、心灵幻影结晶或成年心灵巨龙完整大脑。

# 1232 逐光者 第八十三章 两处

## 打开书
自从战争深入鲁恩士兵们见过不科学不自然现象已经太多多到他们都有些麻木可这种支离破碎尸体纷纷爬起来场景依旧震撼他们让他们一阵惊悚一阵迷茫有种自身也无法幸免终将成为活尸感觉。当然他们能在见识过那么多不科学不自然现象后还保持士气没出现崩溃也是有原因。就在他们心生极大恐惧时一阵阵吟诵声从后方传过来：他们赤身裸体无衣无食在寒冷中毫无遮掩。……黑夜没有放弃他们给予他们眷顾。神圣怜悯祈祷声回荡于整条防线让每个士兵恐惧飞快消散身心都变得宁静。然后部分士兵听从命令搬出布满银色花纹炮弹调整炮口瞄准黑压压涌来残缺尸体。轰隆！轰隆！轰隆！火光不断闪现间一枚枚炮弹落在战场不同地方爆炸开来散发出浓郁黑暗。那些残缺尸体或直接被摧毁或无力倒下纷纷回归长眠。反抗军后方那位穿黑袍戴兜帽神秘人见状将双臂抬起来仿佛要拥抱高空绯红之月。就在这个时候他身体突然虚化染上淡红变成一道朦胧月光。这月光瞬间破碎化成一片片红鳞消散在原地。月光化！这是药师途径序列5深红学者就具备非凡能力对一位序列4巫王来说几乎已经成为本能。而这巫王刚才所在位置一道人影飞快勾勒出来。这是一个巨大布娃娃它头发金黄眼睛鲜红身穿铭刻有无数神秘花纹缠绕邪异藤蔓黑色哥特式长裙皮肤没有人类该具备那种光泽。蕾妮特·缇尼科尔！祂用星之杖召唤出是完好状态时自己。当然克莱恩借给这位信使小姐是真正星之杖提前从灰雾之上带到现实世界星之杖。——如果不是这样就等于克莱恩历史孔隙影像召唤出星之杖投影然后星之杖投影再召唤出过去巅峰状态蕾妮特·缇尼科尔这所有负担都将加于魔术师佛尔思身上让她灵性很快就被抽干。而将星之杖本体暂时交给蕾妮特·缇尼科尔使用可以有效规避这方面问题消耗灵性都由这位古代邪物本身承担。同时蕾妮特·缇尼科尔也许是最不害怕星之杖负面效果存在之一。作为节制派代表作为一名木偶一个布娃娃祂是完全可以让脑海内不浮现任何画面而转化为隐秘状态后星之杖也很难再影响到祂历史孔隙影像。刚才完好状态蕾妮特·缇尼科尔试图隐蔽靠近直接附体控制住玫瑰学派这位巫王让战斗瞬间结束可对方竟然提前察知到危险借助月光照耀抢先一步脱离怨魂附身。笼罩着大地绯红清辉中一片片红鳞于远处飞快重组凝聚成穿黑袍戴兜帽玫瑰学派巫王他紧闭双眼不敢直视对面那个古代邪物。与此同时战场另外一边有道人影急速勾勒而出正是穿黑色风衣戴半高礼帽格尔曼·斯帕罗他左掌套着透明手套右手抬起啪地打个响指。一丛丛赤红火光随之在战场各处腾起就像在预告一场盛大表演。那巫王刚完成重组就探出左手刷地撕破胸腹间衣物而这个时候蕾妮特·缇尼科尔鲜红眼眸内已映出他身影。如果不出意外玫瑰学派这位巫王将在下一秒钟变成一只兔子或者一头山羊失去绝大部分特质和非凡能力但是他身体只是腾起一阵微光未发生任何变化。他胸腹位置裸露出来那里镶嵌着一个细长棕黄色木偶。这木偶似乎是从巫王体内长出来与内脏连接在一起眼睛和嘴巴都如同弯月体表种植着晒干花朵和枯草在月光中透着说不出诡异。霍然之间这木偶染上鲜红颜色仿佛被血液浸透。它随即出现明显软化变成一摊通往巫王五脏六腑烂泥。这烂泥之中一条手臂伸出来。它表面流淌着漆黑黏答液体凸起一个又一个奇怪事物有骷髅脑袋有带刺舌头有立体眼睛。神孽斯厄阿！这位玫瑰学派首领序列1存在借助提前布置隔空降临过来！那邪恶气息瞬间让周围玫瑰学派成员和附庸们或直接暴毙或出现异变或疯狂攻击起自己人除那位巫王无一幸免。……西拜朗一处港口城市。已成为这里最高统治者巫王卡拉曼立在原本属于黑夜教会教堂顶层俯视着灯火稀疏城市。不远处一栋房屋内埃姆林·怀特看坐在椅子上宛若人偶莎伦一眼拿出镶嵌着多枚红宝石青铜盒子。那盒子内装是一个眼珠状玻璃球是埃姆林从血族内部申请来太阳领域1级封印物叫做纯白之视。在对付异种途径半神和巫王上它有非常好效果在某些方面甚至称得上克制。当然它不会因为埃姆林和莎伦是自己这边非凡者就产生怜悯情绪变得仁慈。看见莎伦轻轻颔首表示没有问题后埃姆林身体骤然虚化在照入房间月光中分解成一片片鲜艳妖异红鳞。附近教堂顶层头发蓬松黑白相间卡拉曼来回踱几步对这座城市值夜者和代罚者带着鲁恩移民提前撤离并拿走所有封印物事情抱以冷笑：如果只有非凡者逃脱不是不可能但带着那么多普通人还怎么隐藏转移？我无需派人追踪封锁周围可以停靠船只取得食物地方就能让他们自行崩溃……无声自语中这位第五纪初期就活跃于南大陆甚至被人怀疑早已因年迈死去巫王将目光投向窗外凝视起高空那轮绯红月亮。之前那次红月变白异常现象让卡拉曼感受到原始月亮愤怒一直都有些忐忑和不安。他是在研究自然互动法密契仪式等神秘学知识时一步步成为原始月亮信徒。正常来说巫王活到一千岁是较为轻松但之后必然会出现身体状况下滑无可逆转老迈灵体衰败和腐朽所以一千两百岁往往是巫王和血族伯爵自然极限要想继续活下去只能依靠各种各样办法来延续比如封印自身沉眠于古堡深处棺材内。卡拉曼能年近一千四百岁还精力充沛不需要减少行动是因为得到过原始月亮馈赠。这同时也是他消失那么多年原因。后来他获得原始月亮启示加入玫瑰学派。在这方面卡拉曼一直都有点疑惑他有时相信欲望母树和原始月亮是一体是同一位伟大存在不同面有时又感觉欲望母树和原始月亮不仅截然不同彼此间甚至还有深深矛盾。这就导致他们这些后来加入玫瑰学派原始月亮信徒始终得不到足够重视除获赠一些物品都被安排在非关键位置。就在卡拉曼专注感受红月试图获得启示时洒落于教堂钟楼绯红月光中一片片鲜红纯净光之鳞片浮现聚集在一起变成穿礼服打领结埃姆林·怀特。这位血族背后弥漫出浓郁黑气形成一对虚幻蝙蝠翅膀。——埃姆林早就服食过相应魔药消除自身气味和灵性波动让自己能隐蔽靠近目标。当然那是位半神同途径序列4半神他就算做好充分准备也不敢离得太近否则很容易就被发现。望眼巫王卡拉曼所在房间窗户审视一秒玻璃上投影埃姆林·怀特打开镶嵌有红宝石青铜盒子用戴着黑色天鹅绒手套左手拿起那颗纯白之视。他表情顿时扭曲一下体会到完全暴露于炽烈阳光中痛苦。强忍着这种感受埃姆林将那眼球状透明玻璃球凑到右眼位置。前方所有建筑突兀消失在他视线内只留下一道道或阴冷绯红或堕落邪恶身影。其中有道人影就如同巨大黑色漩涡疯狂吞噬着周围光线让自身都变得扭曲。这正是埃姆林目标古老巫王卡拉曼。一点光芒随即亮起凝聚成灼热刺眼射线从纯白之视上蹿出直奔玻璃窗后面身影。

## 这场戏有没有翻
翻了。开头还在尸潮被黑夜炮火压下；凡尔特克侧信使＋克莱恩刚出手就迎神孽降临；西拜朗侧埃姆林开纯白之视。翻的是两处同开、诱饵成真，不是月光化炫技。

# 1218 逐光者 第六十九章 换一个目标

## 打开书
未被战争阴云笼罩迷雾海上未来号在一条条船只簇拥中缓慢往着狂暴海方向航行。最近没什么事情只是等待摩斯苦修会回应请求星之上将嘉德丽雅漫步于甲板上享受着照穿淡薄雾气阳光。目光一扫间她看见弗兰克·李。这位未来号大副星星海盗团二号人物穿着厚帆布做成淡蓝长裤和一件没系上面两个扣子白色衬衣露出浓密棕色胸毛就如同化成了人形巨熊。他立于船头眺望着远方不知在思考什么事情整个人显得颇为低落。嘉德丽雅脚步不由自主放慢一点转身就要进入船舱。船长！弗兰克发现她满脸期待望过来似乎在等待这位星之上将解答疑难。嘉德丽雅身形一下顿住推推鼻梁沉重眼镜状似闲聊：你在困惑什么？弗兰克思索下该怎么表达自己问题认真：我在重新审视我这么多年来发明和创造。……有什么感想？嘉德丽雅配合问。弗兰克点头苦恼：有太多需要反省地方。其中最关键一点是我创造那些事物还欠缺一样最重要东西。嘉德丽雅一阵疑惑又不想追问但最终她还是抱着要对未来号所有船员负责任想法斟酌开口：是什么？弗兰克表情瞬间变得肃穆：它们都缺少灵魂！小麦葡萄和蘑菇没有灵魂是好事……嘉德丽雅下意识就这么劝一句接着才道：这不是你现在能触及领域你只是一个序列5德鲁伊。弗兰克听得眼睛一亮脱口：我明白了！嘉德丽雅脸庞微不可见皱一下：你明白什么？弗兰克一扫刚才低落：我明白问题在哪里那就是我想要创造已经超过德鲁伊能力极限。所以船长我不做德鲁伊了我要成为古典炼金师！这是耕种者途径序列4是半神起点。星之上将嘉德丽雅表情凝固好几秒钟然后才摆出船长和半神姿态轻轻颔首：有一个目标是好事但你要认清楚它艰难。言下之意就是不要抱什么期待也不要把这个目标当真。得到鼓励弗兰克·李当即重重点头：我会努力！为不让弗兰克·李乱来嘉德丽雅决定将这件事情进度掌控在自己手中：我也会帮助你。到时候即使有收获也能告诉弗兰克·李很遗憾。弗兰克非常高兴发自内心感谢船长接着：我也会写信给格尔曼·斯帕罗请他提供一些帮助。他是我好朋友！弗兰克不知道是他最近大半年写几封信都走相当复杂流程：交给信使——信使给佛尔思——佛尔思在塔罗聚会上转交或请愚者先生帮忙。嘉德丽雅又推推厚厚眼镜没再多说什么转身进入舱房。回到船长室她还没来得及思考刚才那件事情就看见摆放着黄铜六分仪书桌上多一封信。嘉德丽雅心中一喜顾不得使用非凡能力快步走过去拿起那封信将它拆开来。这来自贝尔纳黛她简单寒暄几句后直接写：最近如果有空闲可以秘密来一次拉夏。拉夏是迷雾海上一座相当隐蔽岛屿藏着神秘女王行宫——那叫做翡翠城。嘉德丽雅将这句话反复看几遍嘴角不自觉就勾起来。……贝克兰德西区奥德拉家别墅内。埃姆林·怀特又一次见到卡西米·奥德拉这中年绅士模样血族男爵。尼拜斯大人怎么说？埃姆林控制下自己心情努力让自己显得不是那么迫不及待。卡西米看着埃姆林鲜红眼睛：他只是让我告诉你整个血族都没有多余伯爵非凡特性只能等待现存伯爵们有谁因年迈或意外去世留下遗产。血族相比人类有着漫长生命哪怕没有爵位普通成员也能活三百岁左右这种情况下他们可以一点点做积累将每一个层次都占满不让太多非凡特性空余出来。所以无论是普通成员晋升男爵还是男爵成为子爵都不是那么容易要么等待现存者逝去要么从外部获取要么立下足够功劳得到珍贵赐予。而和前两阶相比子爵变成伯爵是更加困难事情因为血族伯爵已经是半神轻松就能活一千年以上那些子爵得一代又一代才有希望等到一位伯爵过世。正因为如此只要有一份伯爵特性空出来立刻就会被分配下去而不是放入仓库。如果说男爵和子爵特性或多或少还有部分以非凡材料封印物形式存在于血族宝库中只是数量不多每一份赐予都必须非常严格那伯爵特性真是没一点空余。这个回答在埃姆林预料之中他看着卡西米男爵轻轻颔首：也就是说只要有哪位伯爵过世就会轮到我？不。卡西米摇头：虽然你已经积攒不少功勋但顺位还没到第一。我排在第几位？埃姆林先是微皱眉头旋即就舒展开来不让自己表现那么明显。卡西米咳一声清清喉咙：第十二位。……这等到末日来临都未必轮得上……始祖既然给了我拯救族群重任为什么不把这些事情安排好？我深红学者魔药都消化好几个月了……难道这又是一个考验？埃姆林腹诽两句沉默几秒若有所思问：如果我从其他地方拿到伯爵特性族内是否会帮我准备仪式？卡西米吐口气：当然！埃姆林不再逗留离开奥德拉家别墅乘坐马车返回自己住处。自从费内波特向鲁恩宣战他就再也没有去过丰收教堂只是听星星说那里门被砸坏东西被抢走不少成为流浪汉居住点。至于乌特拉夫斯基神父半个月在查尼斯门后一间牢房内半个月在圣赛缪尔教堂上层一个房间里旁边就是贝克兰德大主教如此反复不断循环。——这是担心长久待在查尼斯门后会让乌特拉夫斯基神父遭受不可逆转无法治疗侵蚀而局势如此紧张情况下黑夜教会希望留一个缓冲点将来也好借此表达善意开启谈判。埃姆林虽然不是黑夜信徒甚至有些讨厌教堂但每个月都会固定去圣赛缪尔教堂两次探望乌特拉夫斯基神父。去哪里获得伯爵特性呢……感觉自己已经落后未必能承担起拯救族群责任埃姆林一边望着萧条大街一边认真思考每一个可能。他很快有一些想法：隐者女士提过极光会幽暗圣者放牧一个巫王这对应伯爵特性如果能像诱杀秘之圣者一样狩猎这位牧羊人途径半神那问题就解决了……可是有前面那次教训幽暗圣者不应该再轻易踏入陷阱……也有直接引来天使之王可能……这是塔罗会上大家讨论过事情得出结论是最近一年绕着极光会走尽量不要再招惹。除幽暗圣者处有序列4巫王特性埃姆林·怀特能想到只剩下一个地方：玫瑰学派！不管是生命学派人造吸血鬼还是南大陆原本就存在原始月亮崇拜者现在都属于玫瑰学派了。当然肯定也有部分家伙追求自由目前没加入任何一个组织但要么序列不高要么没足够情报流出。一想到玫瑰学派埃姆林瞬间就记起一个人：马里奇！马里奇代表是玫瑰学派节制派系这是反抗欲望母树势力。他们似乎也想从玫瑰学派那里得到一些东西或许可以找他们合作……埃姆林幅度很小点头。……月城一部分居民略显焦急聚集在入口处不时将目光投向东方。他们是大祭司率领那些人亲属同时也是月城绝大部分人代表。终于一点点火光浮现大祭司尼姆带着鲁斯等人由远及近回到月城。一个男子迎上去将目光投向自己姐姐发现她脸上还残留着些许泪痕。这位不是畸形者月城居民感受到弟弟注视难以遏制心中悸动张开嘴巴未语泪先流。神神来拯救我们了……她哭起来哭得很伤心哭得很肆意。

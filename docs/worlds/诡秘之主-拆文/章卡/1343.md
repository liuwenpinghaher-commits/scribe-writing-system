# 1343 倒吊人 第七十八章 人性

## 打开书
见秘偶城镇没什么异常克莱恩又开始思索起正义小姐遭遇：针对艾瑞霍格这条心灵巨龙行动不是亚当安排而是赫密斯主导？否则亚当不可能不神降艾瑞霍格也不可能那么容易就逃掉必然要借助第二个奇迹之城才有一定希望。如果是赫密斯主导整件事情发展倒是符合逻辑……赫密斯根本没想过抓住或击杀艾瑞霍格只是希望从这条古老心灵巨龙处知道一些信息当艾瑞霍格说出亚当不一定就是亚当时行动自然就结束了。嗯这么看来赫密斯对亚当真实状态早就有一定怀疑只是碍于自己身份限制没法让艾瑞霍格主动出现才辗转利用正义小姐。亚当不一定就是亚当艾瑞霍格不一定就是艾瑞霍格……这句话真很有意思观众途径高层次比占卜家还要神秘啊当初空想之龙安格尔威德明明已占据序列0位置身边却还有个同途径序列1儿子噩梦之龙阿勒苏霍德……若亚当真不是亚当那祂会是谁？……正义小姐遇上艾瑞霍格赫密斯与那位军情九处人员回乌托邦上庭作证几乎同时发生。单独来看两边都没有什么问题可同时这个单词让克莱恩有些警惕。他对恰好巧合同时差不多都非常敏感这是过去种种经历在他心灵内留下印记。……紧接着他开始影响乌托邦打算通过各种安排让目前在城内外乡人暂时离开。……这两天好好休息上庭还要等一段时间。拜尔斯将文德尔送到鸢尾花旅馆门口。……我现在已经有困意。……他身上那一条条虚黑细密灵体之线同时脱落向着上方飘起。一张剪裁精致纸人落下与那些灵体之线连接在一起飞快变成另一个拜尔斯。……下一秒罗塞尔·古斯塔夫历史投影伪造一段一切正常信息让它沿着与纸人连接灵体之线传向市政广场圣阿里安娜教堂传向教堂地底。……神孽斯厄阿历史投影！……祂没有任何耽搁右手一探利用非凡特性聚合定律将拜尔斯体内那条灵之虫吸出去。……无声无息间灵之虫融入丑陋人偶人偶一阵扭曲蠕动着长出眼睛鼻子和耳朵变得像是克莱恩·莫雷蒂。……整个乌托邦内所有秘偶灵体之线同时断掉无法再连接本体。……他没有犹豫念头一转就要回归源堡以天使之王位格和实力对抗已露出水面和还未露出水面敌人们。……就在这个时候他上浮意识碰到无形深暗屏障难以穿透过去进入源堡。……他能不用仪式一念回到源堡事情知道高位存在并不多！……此地禁止漫游！此地禁止传送！……克莱恩没被情绪主导见一时无法回归源堡当即改变策略纵身跃向历史迷雾。……克莱恩虽然无法回归源堡但能够影响值守灰雾之上灵之虫们让它们摄来幕布提供帮助。……这个时候乌托邦内不少死亡很久秘偶在失去灵体之线维持情况下或血肉急速腐烂或残肢纷纷掉落或被本身非凡特性影响出现种种异变化身为不同形态超越想象恐怖怪物。……这对他来说是一个可以信赖安全屋因为必须古代学者加史前人类才有资格进入。克莱恩没有犹豫习惯性环顾一圈后就在层层叠叠都市废墟上开始向黑夜女神祈祷。……亚当给了我人性。

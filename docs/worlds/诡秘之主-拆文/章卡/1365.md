# 1365 倒吊人 第十三章 布置

## 打开书
收回视线克莱恩将目光投向鲍利·德尔劳体内析出那部分非凡特性。它由一缕缕淡薄雾气组成仿佛一团不够真实来自梦境灰白大脑。……他认为伊甸园最为安全所以将本体放在这里于外界活动都是不同身份？谁知道本该作为防御屏障赫密斯背弃这里如果有一位真正天使看着伊甸园充分发挥这座心灵城市特殊我也没办法这么容易就欺诈规则成功侵入……克莱恩边在心里自语边随意许个愿望……啪！他打响指实现自己愿望。接着他摄起那团织梦人非凡特性和可以作为辅助材料事物摘下脸上傲慢面具一步脱离伊甸园。……从此之后伊甸园传说将出现于许许多多梦境里最终被某些艺术家描绘出来编成故事广为流传。而所有故事结局都必然趋于一致那就是伊甸园被毁灭了。回到霍尔家族庄园露台上克莱恩看着对面已调整好心理状态正义小姐将织梦人非凡特性相应材料和自己从第二块亵渎石板上看到魔药配方递过去。抢在奥黛丽开口前他嗓音低沉说道：正式晋升前你都可以反悔。奥黛丽接过世界先生馈赠默然点头表示自己会认真考虑。……消除掉痕迹隐秘线索后克莱恩巧妙利用嫁接能力和源堡特殊回到贝克兰德出现在轮休审判休面前。……有有什么事情吗？她谨慎没有称呼对方世界先生也未喊出格尔曼·斯帕罗这个名字。克莱恩轻轻颔首道：愚者先生让我来问你是否希望获得序列4律令法师魔药配方非凡特性和辅助材料？……那么代价是什么？克莱恩赞许点下头：末日将要来临许多变化开始发生愚者先生因此预见到一些事情。到了那个时候祂很有可能再次沉睡而作为祂眷者祂左手我也无法幸免。你需要付出代价就是在那样情况真出现时按照愚者先生遗留神谕做某些可能危险也可能轻松可能复杂也可能简单可能漫长也可能短暂尝试以唤醒愚者先生。身为一名天使之王级占卜家身为本源堡主人克莱恩很早前就能做某种程度预言最近更是看见些模糊画面有一定灵感于是思路不算太清晰但绝对有意识做起各种布置。现在我才是真正神棍……他心里吐槽自己一句。抢在审判休开口前他又补充道：你可以选择拒绝你不是唯一选择。休相信世界先生不会在这种事情上说反话没立刻回答认真考虑起这件事情。……不管是愚者先生告知还是我利用职务之便刻意搜集各种预言都明确或含糊指出末日将至……只剩十六年了……休下意识侧身看眼二楼。……十六年后洛正是壮年……佛尔思或许已经有序列3……而我却帮不上什么忙……休缓慢收回目光表情沉凝静默一阵。然后她看着世界格尔曼·斯帕罗郑重点下头：好。你随时可以布置仪式向愚者先生许愿祂会满足你愿望。克莱恩没有啰嗦简单交代一句。……文德尔似乎又去乌托邦但奇怪是他当晚回来了并未上庭作证。这让他又疑惑又担忧。告诉他不用再担心这件事情了乌托邦所有人都被一场天灾埋葬了。克莱恩说完转身走入灵界。……克莱恩静静看着那些摆放骨灰盒柜子许久没有移开眼睛。过一阵他缓步来到无人树荫下拿出冒险家口琴历史投影凑至嘴边吹一下。……没等信使小姐开口克莱恩主动问道：各大教会准备围剿玫瑰学派并打算联合你们。有什么需要我提供帮助吗？他从星星伦纳德和月亮埃姆林处知晓这件事情。……暂时……不……需要……等……锁定……目标……之后……再说……意思是有欲望母树原始月亮等外神和被缚之神这天使之王干扰占卜预言提供庇佑玫瑰学派半神们不是那么好找到……如果有直接关联物品做媒介我可以锁定对应目标。到时候利用源堡力量来刺穿遮掩。好！蕾妮特·缇尼科尔四个长相明艳脑袋同时上下摇晃。克莱恩没有其他事情见状准备让信使小姐回去。他本打算以开玩笑口吻问一句这次召唤要收费吗灵感突然一动整个人沉默下来。隔几秒他抬手从源堡内部取出一枚金币。这是已经浸染源堡气息有些神异五枚金币之一。这次邮费。克莱恩笑着将手中金币递过去。这次……不……蕾妮特·缇尼科尔提着两个金发红眼脑袋说完之后剩余两个却没有补齐话语。……下一秒未曾开口两个金发红眼脑袋之一扬起咬住克莱恩指尖那枚金币。好了。克莱恩收回手微笑说道。……莎伦小姐和马里奇还在贝克兰德吗？在……信使小姐将自己学生现在地址告知克莱恩。……就这样克莱恩加入他们行列玩一手又一手牌有输有赢。……玩大概两个小时后克莱恩站起身来正式对莎伦小姐和马里奇行一礼。……灵界深处藏着卡尔德隆城稀薄雾气外已接受完三次治疗克莱恩出现在此地。

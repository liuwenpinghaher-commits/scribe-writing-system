# 1357 倒吊人 第五章 对话

## 打开书
黑夜女神投影语气平和说道：对于祂或者祂们我们无法战胜和阻止只能对抗和压制。也许某些时候只是一个微小疏忽或程度很轻松懈我们就会变成祂……克莱恩默默替黑夜女神补两句。……我降生之时您是否做一定干扰？黑夜女神那仿佛快融入周围环境投影微微点头道：我利用安提哥努斯唯一性间接影响源堡将伴随你降生非凡特性对应地点篡改到神弃之地。……安提哥努斯唯一性可以间接影响源堡？黑夜女神投影嗓音轻柔如同夜曲回答道：祂已经失控疯狂。这也就意味着祂自我认知再无法压制体内诡秘之主意志两种精神缝合在一起体现出最原始最本能也最血腥最疯狂一面。而那位诡秘之主是源堡前主人现在安提哥努斯自然可以通过这个身份间接影响源堡。……为什么您和罗塞尔降生时没有非凡特性伴随？……这也就是我为什么说诡秘之主不知出什么意外对很多安排失去控制。在连续失败两次后源堡才出现一定变化。这对你来说也是一件好事。随着末日来临诡秘之主残余意志是在消散最终只会有精神存留试图苏醒。如果你出生于第四纪在成为诡秘侍者那一刻你就已经变成祂。……安提哥努斯当初是怎么容纳愚者唯一性？黑夜女神梦境投影没做隐瞒嗓音柔和回应道：祂请亚当和阿蒙帮忙。祂们当时都支持亚利斯塔·图铎。……利用命运木马能力？克莱恩根据威尔·昂赛汀说辞和自己思考敏锐直指核心。黑夜女神投影仿佛夜晚星空静静安抚着周围：祂们抓一位所罗门帝国半神由亚当做深层次催眠和相应记忆移植让对方认为自己就是安提哥努斯。然后阿蒙在安提哥努斯配合前提下窃取走祂身份和命运安提哥努斯则利用篡改权柄将阿蒙手中身份命运与实验对象组合在一起。那个所罗门帝国半神开始以安提哥努斯状态生活并在一段时间后主动尝试容纳愚者唯一性。祂毫无疑问失控了而这个时候真正安提哥努斯解除篡改让自己身份和命运回到阿蒙手中阿蒙则结束偷窃将它们还给原本主人。……这样一来就等于安提哥努斯容纳唯一性失败变成怪物和安提哥努斯活得很好没出任何问题这两种完全不同命运同时存在于现实世界所以命运在某种程度上被愚弄了……这样不会存在什么问题吗？有很大风险。黑夜女神梦境投影平静回应道命运并不好承受。如果不能在目标将要失控那极短暂时间内收回命运事情将毫无疑问失败：早一秒收回仪式不会有任何效果；晚一秒收回安提哥努斯将背负上失控疯狂命运不可避免地走向同样……也是承接命运自然要承接命运带来麻烦……克莱恩在心里咕哝两句开始思考自己该怎么模仿安提哥努斯家族先祖那个仪式。——在正常仪式很难完成而事情又很紧迫前提下用简易版仪式容纳愚者唯一性似乎是当前最优选择。……他打算请黑夜女神帮忙压制住安提哥努斯家族先祖然后利用源堡窃取走对方身份命运和自我认知。这样一来他体内就同时存在自己意识天尊意志安提哥努斯家族先祖自我认知和来源于新白银城新月城罗思德群岛锚而他也将于某种程度上成为安提哥努斯承接下对方失控疯狂命运。……等到仪式结束克莱恩解除偷盗恢复原本身份和命运之后将不再受疯狂影响直接成为半个愚者。……这时黑夜女神梦境投影似乎猜到他想法：如果你想窃取安提哥努斯命运最好让祂进入暂时永眠状态。我可以尝试帮你但我需要媒介才能有足够把握这是一位容纳愚者唯一性天使。什么媒介？克莱恩仿佛在思考般问道。黑夜女神梦境投影语含些许笑意说道：永暗之河河水。……只是河水？黑夜女神梦境投影轻轻颔首道：你现在也没办法取走整条永暗之河你到卡尔德隆深处就明白了。有事情等你回来再问。……于你而言那里有不同寻常危险你最好等精神状态稳定下来再去。好的。……等你醒来举行一个祈求赐予仪式我会给你一件用来取永暗之河河水物品。……亚当是远古太阳神一部分是祂其中一个身份。黑夜女神梦境投影未出现明显情绪波动轻柔舒缓说道：祂已经去神弃之地见到真实造物主。……不管接下来会发生什么这都需要一段较长时间你暂时不用关注。

# 1344 倒吊人 第七十九章 又见面了

## 打开书
克莱恩一下转过身体看向那道既熟悉又陌生的人影。他预想过乌托邦遭遇袭击种种情况但绝对没有料到会出现这样场景。如果是阿蒙寄生格尔曼·斯帕罗这个秘偶以克莱恩现在位格和源堡之上灵之虫们全天候监控肯定能第一时间发现问题而若是查拉图将灵体之线转接也只能短暂瞒住他……要想防备这种情况只能定期断掉灵体之线让秘偶进入死亡状态那样一来不管原本有没有人性最终都将不复存在。可惜克莱恩之前根本没有听说过这种手段只是单纯防备着虚拟人格对秘偶们入侵。这或许就是空想家威能可以给每一个虚构出来不够真实生命独特人性。……源堡内灵之虫们接收到他意志放弃这个秘偶灵体之线并拿起星之杖准备给克莱恩致命一击自己杀死自己。……尸骨教堂亚当尸骨教堂空想家神国！……无数银白闪电从源堡落下穿透历史迷雾劈在这座教堂上却无法撼动它分毫。与此同时古老宫殿内坐在愚者位置上那道身影突然往旁边倒下崩溃成一团透明蠕虫组成漩涡。……第一纪之前旧日都市中戴着半高丝绸礼帽穿着黑色风衣格尔曼·斯帕罗抬头望向源堡表情变得颇为复杂。他本质是一具尸体在灵体之线被放弃后自然没法再维持自身存在。……对一个由诸多灵之虫组成真正神话生物而言胸口伤势根本谈不上致命那古老染血十字木桩主要作用是封印非凡能力。……此时他没做尝试是害怕从不敢做变成不想做。我没想到你会直接插手这件事情你想对付我完全不需要等到今天。克莱恩看看被胸口鲜血染红衬衣认真说出自己疑惑。……在此之前你能在很多地方发挥不小作用。……阿蒙来偷尸骨教堂时我和祂达成一项交易祂帮我拿到第一块亵渎石板我帮祂抓住你。……亚当一方面不想在成神时被真实造物主等存在阻挠另一方面又想得到第一块亵渎石板于是一边用给予无暗十字等办法推动克莱恩去巨人王庭……一边通过祂兄弟阿蒙……而想抓住即将初步掌控源堡克莱恩肯定由空想家安排最为妥当。……我同样没想到查拉图会和你合作祂不怕变成阿蒙食物吗？……于祂而言你成为旧日就意味着祂必然陨落可如果是阿蒙成为旧日祂只要表现出自己忠诚依旧可以保留现在位格和层次诡秘之主总是需要诡秘侍者。……所以祂选择和我合作……在这点上祂很有决断。解释这么多不像你风格。克莱恩先是随口回应一句接着才皱眉问道成为旧日不需要相应途径所有序列1非凡特性？……对于相邻途径只需要唯一性和一份序列1非凡特性强行占据更多反而容易导致失控所以查拉图效忠阿蒙之后是有机会成为天使之王……占卜家秘偶分身和偷盗者时之虫分身在这方面有本质区别前者涉及灵体之线后者只靠自己。……这和第一块亵渎石板很像但没有那种异常古老感觉。……第二块亵渎石板？克莱恩略显诧异开口问道。……不用着急阿蒙要等到完成仪式成为序列0才会来窃取走你命运否则祂没办法承受住源堡主人身份而在此之前让你继续待在我神国是最好选择。亚当就像在宽慰一位忏悔信徒。……混沌海＋空想家唯一性＋太阳唯一性＋暴君唯一性＋白塔唯一性＋倒吊人唯一性＋……源堡＋愚者唯一性＋错误唯一性＋门唯一性＋……看到这里克莱恩侧头望向空想家亚当颇为疑惑问道：你为什么要给我看这些？……坦白讲如果另外一边不是阿蒙我更愿意帮你成为灵界支配者。我们有太多相似之处从某种意义上来说还是见过一面老朋友。……我们又见面了诡秘。

# 494 旅行家 第十三章 宝藏的传说

## 打开书
甲板之上烤架下面额外垫层石棉防止煤炭火星被风刮出灼烧船面。肥胖厨师系围裙戴罗塞尔发明白色高帽不停用细密毛刷将混杂罗勒小茴香海盐胡椒粉柠檬汁等秘制调料涂抹白嫩长条鱼肉上并时常翻转保证两侧均匀受热。鱼人肚子肉多有油脂一滴滴落下让铁网下面盛放煤炭发出嗞嗞声往上蹿出火苗。诱人奇香逐渐弥漫克吸一口又一口。面前已摆好圆桌椅子上面放着瓶造型别致酒颜色金红晃动间似有些微粘稠感。「苏尼亚血酒由金色泉周围区域特产甜木汁酿造就像混杂血液稀薄蜂蜜它口感甜润但非常容易喝醉如果你看上哪位女士想请她喝酒可以考虑这种它会让对方不知不觉喝多哈哈前提是你得有足以承受它酒量。」察觉审视艾尔兰半开玩笑介绍。不愧曾经水手长自带荤笑话素养…坐下保持冷峻：「一名合格冒险家不会沉迷于酒精。」旁边克里维斯点头：「只有回到家里冒险家才允许自己喝酒。」「那真是遗憾啊。」转而望正好奇打量苏尼亚血酒堂娜丹顿姐弟笑一声：「这不是未成年孩子该体验东西。」「我喝过真的很好喝！」堂娜当即反驳：「只是只是后来不知不觉就睡着了睡了整整一个下午…」「我记得你那次喝了两杯！」小绅士丹顿艳羡说。艾尔兰没满足渴求吩咐船员给姐弟俩各一杯甜冰茶并随口解释：「这条船上有不少南方人。」丹顿收回失望目光看向已被取走有价值材料鱼人略显天真：「其实其实它并不是那么可怕它就是一条比较大特别丑有四肢的鱼！」堂娜瞥弟弟一眼：「祝贺你你终于认识到了它的本质。」随即眼巴巴望克里维斯和艾尔兰：「叔叔叔叔海上有很多这样怪物吗？」鱼人并没有超越想象非凡能力在普通人看来它就略等于海上猛兽略等于传说魔怪生物原型。艾尔兰呵呵笑：「不在主航道及周围海域类似怪物很少出现早就被清剿得差不多了能遇到一只鱼人见识到这种生物是你们足够走运。你想想如果经常能猎杀到价值200镑甚至更高怪物那我肯定不会做客船船长我会组织属于自己捕猎船追逐这些金镑！」说得非常有道理！暗暗喝彩。根据刚才观察鱼人身上非凡材料应该是它鱼鳔那蔚蓝如水光芒让人就像看见宝石。克里维斯端起水手刚送来红茶先闻闻味道然后才抿一口：「只有偏离主航道深入经常笼罩迷雾或风暴大洋才有不低机会遇到这样怪物但那非常危险。除了会攀爬有鳞片鱼人那些海域里传说还有上半身是人类下半身是巨蟒娜迦它们长着六条手臂动作非常敏捷。」艾尔兰接过话题：「还有吐出汁液能腐蚀干净许多人巨大章鱼有轻轻一顶就掀翻掉一条船恐怖海怪有歌声让人沉醉再也不愿意离开美人鱼有能制造闪电蓝色巨龙有扇翅可以掀起飓风大鸟呵呵这些我都没有见过都是海上传说没人知道真假。」美人鱼…表情未有变化。「很有趣。」堂娜一脸神往赞叹。丹顿左看右看见克没有发言遂好奇问：「叔叔你也是冒险家你之前见过这样怪物吗？」愣一下微翘嘴角：「见过一次当时我们有五个人意外遇上了一只一只鱼人经过激烈搏斗终于解决了它。」这是廷根真实经历也是第一次直面失控官方非凡者。当时他和老尼尔应恶龙酒吧老板斯维因请求帮忙清除一位异变水手。想到这事有些缅怀有些唏嘘脸上硬装出来冷峻锐利不由柔和许多。「五个人？」反问同时堂娜动作很隐蔽数了数刚才参与战斗人员。1，2，3…发现之前击杀鱼人只有三位动手。不等克回答艾尔兰略显诧异开口：「意外遇上？」「是的。」坦然回答。「有人伤亡吗？」追问一句。摇头：「一些轻伤。」「意外遇上只用五个人就解决一只鱼人…你们很厉害。」克里维斯给出评价。伙伴塞西尔也用点头表明惊叹。刚才战斗简短迅捷鱼人似乎不堪一击但她和克里维斯都很清楚如果没有预先准备诱饵没有胡椒粒致幻效果和后续疲惫没有薄荷膏对鱼人致命威胁没有借来两杆步枪在场不知要死多少人才能杀得掉一只鱼人。「确实很厉害。」艾尔兰若有所思看了克一眼。那可是四位序列9一位序列8组成队伍…半笑半叹：「当时我还非常年轻甚至没经历过什么战斗只是纯粹辅助。」「叔叔你现在也很年轻！」堂娜用力点脑袋。这句话我爱听…敏锐发现艾尔兰因自己刚才话语放松不少。这时几位船员端来陶瓷大盘上面放着炸至金黄鱼肉洒着点缀颜色罗勒叶勾人香味扑鼻而来。艾尔兰端起倒苏尼亚血酒杯子发表祝酒词：「一个美好夜晚风暴与我们同在！」「美好的夜晚！」堂娜丹顿欢呼一声各自喝口甜冰茶。克选择用红茶杯子与对方碰一下。叉起一块来自鱼人肋部肉只觉紧致结实没什么脂肪但吸收植物油后太干缺点被弥补于咀嚼中散发出回味无穷弹性和肉香。果然比眼下脸颊肉差一点但也足够好了胜过贝克和普利兹吃过所有鱼…满足赞叹。艾尔兰放下刀叉喝口苏尼亚血酒就着刚才话题叹息：「在海上最危险不是怪物而是那些海盗。他们驾驭着船只想到哪里就到哪里谁也无法提前做出防备。」「船长叔叔我们会遇见海盗吗？」丹顿吞下油炸鱼肉有些担忧问。艾尔兰笑：「去罗思德群岛航道是全世界最安全每隔两三天就有殖民岛屿可以停靠沿途还经常有皇家海军和风暴教会船只巡逻。即使有哪伙海盗流窜到这里也不会做太过分事情在见识过我们火炮后他们最多勒索一些赔偿。」见两个未成年孩子安心下来又补充：「但从罗思德群岛南下或者继续往东我们就得依靠主的庇佑了。许多海盗活跃这些区域与海军教会船只捉迷藏如果运气不错我们会非常顺利抵达南大陆抵达每一个地方但要是不够走运就会遭遇相当强大海盗这包括那七位海盗将军甚至四王舰队。不过你们也不用太担心自从纳斯特成为五海之王制定一些通行于海上规则后大部分海盗也就洗劫你们钱财不会做出太过分事情。这里面我们最害怕遇到是黑色郁金香号船长地狱上将路德维尔他会让手下杀掉船上所有人将这些无辜者丢入地狱其次是血之上将塞尼奥尔他喜爱鲜血纵容属下做一切恶行许多少女遭他们蹂躏后还被卖到不同岛屿…」堂娜听得打寒颤下意识转移话题：「我听说我听说海上有很多宝藏！」「是有宝藏传说但绝大部分是假的。」艾尔兰看克里维斯一眼：「故事最多名气最大有六个排在第一位是死神的钥匙传闻第四纪末尾掀起苍白灾难死神被七神击杀却没有当场陨落试图返回南大陆祂掀起狂暴风浪制造无法逾越障碍彻底隔断南北大陆航道这就是狂暴海来源传说但是祂最终没有回到南大陆消失在了那片海洋里。」说到这里有些向往叹息：「据说在狂暴海某个隐秘地方死神遗留宝藏正等待着持有特定钥匙人找到并打开可那把钥匙长什么样子会出现在哪里没人知道。排在第二位是不老泉就在苏尼亚海深处传闻四王之一不死之王阿加里图就喝过不老泉泉水。」

## 这场戏有没有翻
翻了。烤鱼开席；章末死神钥匙／不老泉。翻的是宝藏传说落地＋海盗比怪可怕，不是再猎。

## 话
「合格的冒险家不会沉迷于酒精。」「风暴与我们同在！」「绝大部分是假的。」「死神的钥匙」局面是从血酒收到冷峻；从五人鱼人收到放松；从海盗收到寒颤；从宝藏收到钥匙泉。

## 热怎么变冷
奇香还热。冷切不沉迷。怪谱还热。冷切美人鱼无变。五人还热。冷切辅助年轻。海盗还热——宝藏冷切向往。

# 1237 逐光者 第八十八章 推测

## 打开书
处理好这次收获将净化过巫王非凡特性赐予埃姆林·怀特后克莱恩没急着离开源堡简单复盘一下今天战斗。其中他关注重点是神孽斯厄阿各方面表现以此评估一位天使究竟有多么强大。如果正面遭遇不留余力那我很可能连召唤出一位天使投影机会都没有除非能一次就成功……当然我目标乌黯魔狼是序列2奇迹师而神孽斯厄阿已经有序列1双方差距应该还是不小……不过乌黯魔狼和我同属占卜家途径对我这较低序列者存在全方位压制……只能庆幸祂还没有完成仪式晋升序列1否则完全看不到赢希望……序列1……思绪电转间克莱恩眸光突有收缩整个人一下坐直。他刚才灵感一动想到一个可能：乌黯魔狼科塔尔会不会已经晋升成为序列1诡秘侍者祂制造秘偶城市只是在误导可能追踪者比如说时天使阿蒙？不排除这种情况……嗯还有另外一种可能那就是乌黯魔狼科塔尔已完全掌握那块幕布有了准序列1实力……克莱恩越想越觉得接下来行动也许比自己预料得还要危险。乌黯魔狼能在神弃之地存活那么多年连阿蒙这位狡诈之神都无法成功捕获说明祂无论实力还是智慧都达到相当高水准！针对祂狩猎计划还得再多做些准备……克莱恩微皱眉头缓慢吐口气。……贝克兰德西区奥德拉家别墅内。埃姆林坐在会客厅皮制沙发处将右脚跷起搁到左边大腿上耐心等待着卡西米男爵前来。没过多久那位中年绅士模样血族男爵进入会客厅扫埃姆林一眼：怀特子爵为什么深夜来访？埃姆林笑：这不正是一天开始吗？你看窗外红月多么美丽。卡西米很想回这个年轻血族一句说你在丰收教堂时候一直都保持着早上七点起床夜里十一点前入睡良好作息习惯但犹豫一下还是忍住冲动转而：你究竟有什么事情？埃姆林抬手拍拍礼服拉下领结一点点起身微抬下巴：告诉尼拜斯大人说他可以准备一场伯爵受封仪式。……卡西米本能问：你在说什么？话音刚落他突然醒悟过来联想起埃姆林之前申请：你你拿到伯爵不巫王非凡特性了？埃姆林享受着这一刻种种感觉微笑回应：难道你以为我借纯白之视只是在开玩笑？他边说边拿出那个镶嵌着多枚红宝石青铜盒子将它打开展示下里面那个眼珠状玻璃球表示自己没有弄丢即将归还。卡西米眸光闪烁几下：玫瑰学派节制系还保持着这么强实力？那他们为什么要和你合作？贝克兰德血族高层也就是卡西米祖父尼拜斯·奥德拉侯爵对埃姆林之前申请并不是太看好有心等待他和玫瑰学派节制系合作失败不得不向自己等半神求援。埃姆林看他一眼含笑：秘密。这是他从格尔曼·斯帕罗那里学来口吻觉得很酷很符合自己喜好。同时这也是之前塔罗会自由交流里倒吊人反复告诉过他关键点：只有保持神秘才能让血族高层产生一定畏惧不敢找借口或者凭身份拿走那份巫王特性。不等卡西米回应埃姆林扔下装着纯白之视青铜盒子边系上礼服扣子边越过这位男爵走向会客厅门口。快出去时候埃姆林停一下没有回头腰背挺得笔直目视前方：下次记得称呼我伯爵阁下。有始祖眷顾月亮看重他对自己成为巫王充满信心。卡西米脸庞肌肉抽动一下但始终保持沉默等到埃姆林离开他才难以控制扭曲表情。作为罗塞尔时期就存在血族他比埃姆林年长不知多少岁但直到现在都还只是一个男爵仅仅比没有爵位那些好一点而埃姆林这已成为贝克兰德血族圈子笑话年青一代却眼见就要跨越神与凡物界限成为序列4巫王血族伯爵。这让卡西米如何不失态如何不嫉妒如何不震惊。花好几分钟控制住情绪他一路进入地下区域通过好几扇秘门来到尼拜斯沉睡那处灰色大厅：祖父埃姆林行动成功。那黑铁打造般沉重棺柩内短暂竟没有声音传出隔三四秒尼拜斯才开口：他背后势力超乎想象……这位血族侯爵嗓音沉厚苍老带着些许低哑回荡在大厅内部。祖父埃姆林是依靠纯白之视才最终获得成功他所得到物品理应分族内一份。卡西米不太甘心有点期待说。尼拜斯声音变大一点：愚蠢！能在玫瑰学派放纵系明显有准备情况下猎杀一位巫王是任何人任何势力都能办到吗？玫瑰学派节制系经过这么多年折损还能残余多少实力？最多也就是一位状态不好天使或者一件0级封印物加两到三位半神这加起来都限制不住一个神孽斯厄阿而玫瑰学派还有别天使别0级封印物为数不少半神以及被缚之神投影欲望母树眷顾。埃姆林这次行动能成功你可以算一算至少还得出动多少位天使加0级封印物这是可以和我们媲美势力！以后不要再刻意调查埃姆林还有哪些同伙！这么吼几句后尼拜斯咳嗽两声显得有些吃力。卡西米脸色一阵青一阵白好不容易才平复下来：那……真给他准备仪式？不然呢？尼拜斯反问一句接着叹口气：或许在埃姆林为血族未来展开冒险后始祖真开始眷顾他…………迷雾海拉夏岛。在安全航道上离开未来号利用童话魔法抵达这座隐秘岛屿星之上将嘉德丽雅来到一座山峰前对着什么都没有崖壁念出一段巨人语咒文：芝麻开门！那崖壁上顿时出现一条道路似真实似虚幻不知通向哪里。嘉德丽雅利用本身在预言上特长简单评估下有无危险然后踏足那条道路深入崖壁。走着走着她眼前豁然开朗看见蓝宝石一样剔透大海看见一座纯粹由翡翠组成华丽城堡。这就是神秘女王贝尔纳黛翡翠城。嘉德丽雅对这里并不陌生轻松通过守门魔像询问和各种考验来到城堡内部观景效果最好那个半开放房间。那位身材高挑女王正立在栏杆后眺望着一层层涌来波浪。不知为什么嘉德丽雅内心暗藏激动兴奋和喜悦在这一刻突然平静下来产生一种踏实惬意自由自在感觉。以往航行于海上她偶尔会觉得孤单忧伤就像离开树木叶子只能任由风将自己吹向不同地方而现在她似乎已经落到地上就在那棵树旁边。她张张嘴却一时不知该说点什么最终只是推推鼻梁上架着沉重眼镜简单问候：下午好女王陛下。贝尔纳黛转过身体轻轻颔首：我将你召回翡翠城是有些物品有些事情要交给你。嘉德丽雅直觉反问：为什么是交给我？女王手下是有着要素黎明这个隐秘组织和一群海盗！贝尔纳黛没直接回答嘉德丽雅问题转而：我之前得到一条线索仓促离开贝克兰德。我记得这件事情。嘉德丽雅插话。贝尔纳黛又直又长眉毛轻微动一下：通过这条线索我从爱德华兹威廉珀利等人后裔处拼凑出一张不算完整海图这记录着我父亲当年在迷雾海内探索过部分地方。借助这张海图和本身预言能力我大概能猜到某片远离安全航道海域可能藏着他秘密打算乘坐黎明号去那里做一次漫长搜寻。我不确定什么时候能返回也许永远也无法返回所以必须提前将一些物品一些事情交给你。嘉德丽雅认真听完毫不犹豫就说：我和你一起去。那是我父亲这是属于我一个人事情。神秘女王贝尔纳黛缓慢摇头。嘉德丽雅沉默几秒：如果你没有返回我也会做这样事情。

## 这场戏有没有翻
翻了。开头克莱恩复盘天使强度后推测魔狼或已诡秘侍者／准序列1；中段埃姆林秘密口吻逼血族认伯爵仪式；章末嘉德丽雅接翡翠城托付却要同行被拒。翻的是猎狼风险上修＋血族权力结构让步＋女王远行线起，不是芝麻开门好玩。

# 447 无面人 第二百三十五章 阿蒙可能的来历

## 打开书
阿蒙…原以神弃白银渎神者为后裔升半神——或活两千年＋＝鼎盛成员！修陵假死？定格时间痕？掠命活四五纪？序1非不可能。人偶霍扯喉掉皮露复杂机械；漏风声：「搜地上尸；勿靠近。」松气。尸凝特性或结神物＋随身——洗地开销回本大投资高回报。跟无灯人偶向棺另壁。阿罗德斯讨好调亮：风化斑驳壁画毁；唯一较完整在顶延穹顶——巍峨山脉主峰巨十字架叠光神圣；前雄伟影山如宠物匍；四周双翼四翼六翼天使号角竖琴笛虔诚欢；山下十二翼二天使各抱婴谦登：左微卷黑发黑瞳＝阿蒙；右淡金金发金眸＝亚当。霍低念两名。迷雾浓：山顶真神？十字架亦真造物主用；远古太阳神后裔传闻≠纯太阳——或白银创造一切主全知全能？符苏醒剥夺巨人王空想龙权柄；远古太阳＝创造主掌太阳时间＋奥尔米尔安格尔威德权回归——超序0？初阿蒙继承时间；另后裔亚当继承何？真造物主何关系模仿或深联？不显疑惧阿罗德斯打量。霍按壁——壁画解体石屑色蒸！教会掩三四纪史？他教同？绕半圈：轮廓石门角。人偶关节嘎仍近推——门水光凝景：深蓝浪涌浓黑雾；嶙峋峰淌黏；后黑雾无尽底永坠。「深渊…」腐真神源？罗塞尔迷雾海偏航「我看见了深渊」——入口在迷雾海某？阿蒙仪后借通道入深渊＝世人以为逝；神弃是否深渊某处不定。偶回取时间？坟被挖表情精彩——莫名喜。人偶右腕扭左——齐腕折无骨破；腕嵌黑冷金属管＝左臂小口径神秘火炮！摩尔黑科技难量产。腕抵门齿轮灵爆发白昼亮——门变纯粉！阿蒙急返开不了好玩。探索终；景缩；虚幻古银镜浮；黑宝石微光；白词：「汇报完毕；时刻准备再效。」警惕颔：「很好；先离开。」「是，灵界之上的伟大存在。」景碎。自语：察觉灰雾？真投靠另有目的？慎观——它在机械之心勿想炮火三轮。憧憬明：整理完该让挑物！

## 这场戏有没有翻
翻了。开头阿蒙活古董猜；章末镜退＋可挑物。翻的是阿蒙亚当双婴壁画＋深渊门毁，不是棺里挖到人。

## 话
「阿蒙。」「亚当……」「深渊……」「灵界之上的伟大存在。」局面是从古董收到双婴；从毁壁收到深渊；从粉门收到挑物憧憬。

## 热怎么变冷
两千年还热。冷切在掩史毁壁。深渊还热。冷切在粉门好玩。伟大存在还热——炮火三轮冷慎。

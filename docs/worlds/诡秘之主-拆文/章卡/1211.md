# 1211 逐光者 第六十二章 传播光辉

## 打开书
刚才克莱恩思考办法时候脑海里自然就想到一幅画面：两座山峰间云海急剧沸腾向着左右分开露出一条幽暗看不到底部缝隙橘红色黄昏光芒填入其中形成实质道路。这是渎神者阿蒙进入巨人王庭梦境投影时制造场景。而就在克莱恩觉得自己对相应能力没有足够了解打算换一个方法时星之杖上镶嵌红绿蓝透明等宝石已绽放濛濛微光自行激发。凝固灰白雾气同样沸腾了只是不那么剧烈。它们倒卷着向两侧分开但前方依旧是无边无际灰白根本没有尽头。克莱恩在心里叹口气一边注意对思绪控制一边做起别尝试。三分钟里他至少进行十次努力有七次是自身愿意有三次属应激而发但都没能打开那无形屏障。……正常办法果然不行……克莱恩手腕一抖让已接近维持极限0-62历史投影消失在现实世界。他凝望着那片毫无声息灰白雾气几十秒没有一点动作就如同原地变成雕像。终于克莱恩闭闭眼睛收回视线提着那盏马灯向着不远处窥探这边人类走去。他不打算继续做盲目尝试因为这大概率不会成功他准备询问那些在附近坚守两三千年明显对这片灰白雾气有过探索古代遗民看能否从他们长久以来日积月累经验里找到灵感。按照克莱恩预计那些人类对自己靠近必然会做出较为过激反应已经准备好相应能力让他们能心平气和与自己对话可是当他就着两边灯笼昏黄光芒望过去时却发现那一个个或丑陋或畸形人类都嘴巴微张看着这边表情又迷茫又震惊仿佛短暂失去思考能力。克莱恩眉头微皱一下在深沉黑暗里步伐不快也不慢走到那批古代遗民面前停于大概两三米外。你们对这雾气有什么了解？克莱恩用巨人语低沉问。这种能撬动自然力量语言并不存在地区和地区之间差别只稍微有一点口音不同但也不会太多因为若是在原版基础上进行异化大概率就会在仪式魔法上失去效果。直到格尔曼·斯帕罗提出问题阿达尔似乎才回过神来他嘴唇翕动一阵答非所问：我们我们都没有让雾气出现过改变……刚才格尔曼·斯帕罗让雾气如水沸腾向着两侧分开画面真吓到他们有一种在目睹神迹感觉。月城两三千年一代又一代人努力都比不上对方拿着手杖一两百次心跳间尝试！这也就是他们在格尔曼·斯帕罗靠近时放弃抵抗主要原因。他们本能就认为自己再怎么规避都不会有任何效果。克莱恩沉默两秒继续问：你们有相应记载吗？阿达尔这次有点明白格尔曼·斯帕罗意思犹豫下缓慢点头：有……不过只有大祭司他们才会经常翻看。穿黑色风衣戴半高礼帽克莱恩想想突然探手从虚空里拿出一件物品。那是一个染满铜绿凸出好几根尖刺十字架。源于远古太阳神无暗十字历史孔隙影像！克莱恩拿着这十字架将它举高一点对准那群古代遗民。纯净明亮温暖光芒绽放而出驱散周围黑暗照在阿达尔和辛等人身上。他们战斗经验让他们条件反射般试图做出防御但源自本能舒适让他们动作只完成一半就纷纷停止。那种光明那种温暖绝不是火堆能够比拟！这让月城狩猎小队剩余成员们恍惚中想起古代典籍里和大祭司口中神灵散发无穷光明带来无穷温暖神灵。明净光芒照耀中一股股扭曲挣扎仿佛有自己生命力般虚幻黑气从阿达尔辛等人身上蒸腾而起飞快消散。月城狩猎小队成员们只觉身体有变轻松灵魂内压抑随之不见。净化完目标体内集聚污染和疾病后克莱恩手腕微抖让无暗十字消失在身前。紧接着他又往斜前方抓一下从虚无里拖出另一根手杖普普通通原木色手杖。这是曾经白银城封印物生命手杖！虽然克莱恩已经将它献祭给黑夜女神但只要古代学者曾经拥有过都只会换一个方式陪伴他。拿着生命手杖克莱恩上前几步用杖头杵一下月城狩猎小队领头者。刚才体验让阿达尔没有闪避他脸上肉瘤开始崩裂流脓淡化收缩消失到最后就连一点伤疤都未残留。阿达尔从队员们眼神里知道自己变化有些犹豫有点迟缓抬起右手摸摸自己脸庞从上到下从下到上连续几遍。这个过程中他发现自己状态前所未有好比刚成年时还好。克莱恩没有看他斜走一步又用生命手杖治疗起其余古代遗民。有了阿达尔这个榜样辛等人一边戒备和警惕一边接受杖头触碰然后在无法言喻感觉里获得新生。其中情绪本就容易激动两个畸形者已忍不住流下泪水。可惜啊不能治疗天生缺陷……精神方面疾病可以治有些疯狂倾向却治不了……克莱恩向后收回右手让生命手杖历史投影凭空消散。他走至原本位置转过身体望着那群古代遗民：我来到这里不是为毁灭是为传播我主光辉带来光明与温暖。回去告诉你们首领我在这里如果他愿意可以过来。他没试图问出这群古代遗民聚居点在哪里也没打算直接过去因为这会激发最强烈抗拒和警惕。所以将主导权交给对方是最合适处理办法。阿达尔和辛等人此时已被对面传教士格尔曼·斯帕罗不断凭空拿出各种神奇物品表现震撼心灵愈发觉得自身在走进神迹并且已经接受神光洗礼让身体状况恢复最佳甚至超越最佳。……好的。几秒后阿达尔开口做出回应。就在他们转过身体准备返回月城时黑暗深处一点点火光亮起飞快由远及近。为首者是位套着深棕兽皮老者他头发灰白杂乱垂下脸上是一道道真正沟壑。大祭司……看清楚对方模样后辛脱口喊。来者正是月城大祭司尼姆。尼姆身后跟着鲁斯等提前回城狩猎小队成员和好几位较高序列非凡者。尼姆对阿达尔和辛等人点头走至队伍前方看着那自称传教士格尔曼·斯帕罗男子双手交叉行一礼：尊贵客人我是月城大祭司尼姆。月城曾经是属于吸血鬼城市但那个文明在古老年代里已经被毁灭。之后我们接受伟大太阳神创造一切主命令迁移到这里看守这片灰白雾气并做相应尝试哪怕后来这片大地被诅咒主不再回应我们也未放弃。到今天已过去三千七百二十二年。

## 这场戏有没有翻
翻了。开头还在雾气被杖搅开仍无尽；章末无暗十字＋生命手杖传光辉、大祭司尼姆到场自报三千七百二十二年。翻的是硬闯变传教落地，不是手杖厉不厉。

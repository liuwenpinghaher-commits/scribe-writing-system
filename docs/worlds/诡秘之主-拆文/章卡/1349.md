# 1349 倒吊人 第八十四章 愿望

## 打开书
亚当转过脑袋看向克莱恩清澈浅色眼眸内映照出那张流下股股鲜红血液脸庞。他表情依旧没什么变化和煦中带着些许怜悯就仿佛神灵在注视世人。克莱恩微笑看着祂头部一寸寸裂开来。这样趋势随即蔓延到他身体让他坍塌成一摊血水。……在尸骨教堂内在空想家亚当神国中克莱恩就这样诡异死去。……那个疯狂蠕虫漩涡瞬间失去动静分解成一条又一条僵死灵之虫。下一秒这些灵之虫变得虚幻染上灰白仿佛融入历史迷雾中。……也就是几秒钟工夫灵之虫们重组为一道人影正是黑发褐瞳正装衬衣克莱恩·莫雷蒂。随着这位源堡主人回归被摧毁斑驳长桌和二十二张高背椅飞快复原洒满地都是杂物们再次堆在一起。克莱恩拿起那根镶嵌着多种宝石星之杖坐到属于愚者位置上。……克莱恩旋即对占据贝尔纳黛祈祷光点金色人影点点头道：我会履行我承诺。灯神笑一声道：看来你没有继承祂狡诈和无耻很好。话音刚落模糊扭曲金色身影急速退去不再投影于贝尔纳黛祈祷光点。做得不错。克莱恩一边分出一只灵之虫回应神秘女王祈祷一边低下脑袋向自己许愿道我希望我能恢复今晚前状态。他本体死去时只带走最核心那部分奇迹师非凡特性剩余都被亚当尸骨教堂隔绝无法回收。……许下这个愿望后克莱恩招来那块幕布披在身后并啪打个响指。杂物堆内之前从幕布里分离出来那些占卜家途径序列9至序列3非凡特性同时浮起化作一个个纯净光点钻入克莱恩身体。他状态瞬间就回到之前已接近消化完奇迹师魔药时候除没有肉体和遭遇袭击时毫无区别。……乌托邦内脸上覆盖白须戴着兜帽穿着黑袍查拉图立在圣阿里安娜教堂屋顶身旁围绕着罗塞尔·古斯塔夫威廉·奥古斯都和神孽斯厄阿历史投影耐心地等待着尸骨教堂大门打开格尔曼·斯帕罗自行走出。……就在这个时候僵立不动那部分乌托邦秘偶身上一根根虚幻细密灵体之线突然上浮急速飘向无穷高处。……此地不得封闭。下一秒威廉·奥古斯都历史投影抬起右手长剑庄严宣布道。……罗塞尔·古斯塔夫历史投影当即化作庞杂信息洪流涌向克莱恩剩余秘偶要干扰它们行动神孽斯厄阿历史孔隙影像则攻击起那幕布般阴影扩大相应空隙。查拉图随之将手一伸把面前虚空与自身提前定位过狂暴海另外一座岛屿连接在一起。……列奥德罗！如果在神弃之地因为有暴君神力残留所以仅凭这个名字克莱恩就能直接引动神灵力量可外界不是这样具体要不要惩戒喊出祂真名家伙由风暴之主自己决定。克莱恩让秘偶们同时念出这个尊名唯一作用就是让风暴之主将目光投向这里。而作为全知全能五途径之一风暴之主大概是最不希望看到亚当谋划得逞真神之一——如果阿蒙成为诡秘之主时空之王这位暴君将陷入非常危险处境……所以比起黑夜女神和大地母神风暴之主永恒烈阳和知识与智慧之神可能是更不希望看到亚当和阿蒙成功存在。如果之后还有机会克莱恩打算让秘偶们继续喊奥赛库斯和赫拉伯根！……他略有犹豫就准备去找现任首席韦特·希尔蒙提议使用神级封印物荣耀之证先将新白银城和附近森林内新月城保护起来然后再根据异变进展决定要不要向愚者先生祈祷。……地底封印失效了。……立刻动用荣耀之证！戴里克毫不犹豫说道。……戴里克想法很明确那就是使用荣耀之证压制另外那件神级封印物——大地的恩赐压制很快会对周围产生负面影响圣级封印物们。……枢机主教阁下地底大部分封印失效了！只有某些物品间利用效果克制达成平衡没有消失！……你们立刻以三人为单位组成一支支小队将短时间内不会造成太大危害以及有活着特性2级3级封印物带离地底避免发生连锁反应。……而随着时间推移等到封印失效异常过去代罚者们就能腾出手来处理这些物品。不过前提是那三件1级封印物没有失控。……这对他来说短时间内不会有太大危险毕竟他也是位半神最大问题在于剩余两件1级封印物毫无疑问会对拜亚姆造成相当严重破坏。……剩下交给我。他话语变成一道又一道电波组合成银白闪电飞向地底。

翻了。开头第三愿死于神国；源堡重组归；自愿恢复状态；喊列奥德罗拖亚当；并行封印失效戴里克／阿尔杰救城。翻的是愿望＝死而归源堡＋全线异变。

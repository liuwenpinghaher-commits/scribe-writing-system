# 1332 倒吊人 第六十七章 现身说法

## 打开书
霍然间文德尔背部肌肉完全紧绷起来呈现一种即将爆炸状态。他心中又惊又疑脑海内难以遏制闪过好几个猜测：乌托邦居民都是披着人皮怪物平时看起来很正常但只要遇到逻辑盲点就会表现出有异于普通人一面无视掉明显存在问题地方？或者那名站台工作人员已经发现我在撒谎只是不愿意对付我才故意装作没有看见放我离开？这又是为什么呢？嗯提着行李箱去站台盥洗室完全可以用害怕行李丢失这个理由解释可整个站台都是有遮挡根本不需要提前拿出雨伞而且雨早就停了……或许因为我真诚帮助翠西所以那名站台工作人员才刻意无视我问题放我离开？……我们昨晚……站台……乌托邦……王国……没有……请保密……他们在说王国境内根本没有乌托邦这个站而昨晚蒸汽列车状态是失踪！……这比参与战斗还让人疲惫。阿尔弗雷德对父亲霍尔伯爵抱怨一句。……先回房间休息一下等会到书房再聊。……贝克兰德最耀眼宝石呢？还有希伯特呢？奥黛丽去她基金会了下午才回来她一直抱怨你没法提供确定行程让她无从知道你究竟什么时候能抵达。希伯特现在是内阁秘书非常忙碌。……我更喜欢东拜朗随意。他照照镜子笑着对自己副官道。这样你更有贵族气质。他副官边说边将手里文件递过来将军这是军情九处给您。……军情九处？阿尔弗雷德若有所思破坏文件袋封口这么快就有乌托邦调查结果了？……这就是她背后故事吗？阿尔弗雷德无声自语一句。……请进。霍尔伯爵声音传出来。……已经是个男子汉了。没有人会对男子汉说这样话。阿尔弗雷德一点也不拘谨回应道。在我心里你还是那个有点叛逆少年。霍尔伯爵笑笑道你已经是序列5非凡者了？对我已经是一名真正骑士了。……你应该经历很多痛苦。据我所知无论魔药还是战争都会给人带来严重伤害从身体到心理。每个人一生都会有很多很多痛苦。阿尔弗雷德有些唏嘘说道。……比起离开贝克兰德时我现在状态反而更好只要掌握方法在我这个层次还不需要太担心疯狂冲击。……你妹妹也成为非凡者。嗯？阿尔弗雷德先是一惊旋即记起什么有点懊恼说道我以为她真只是单纯转变爱好。看来奥黛丽冒险有得到你帮助。霍尔伯爵略显恍然说道我希望你能找她谈谈告诉她序列魔药这条路有多么危险疯狂和痛苦让她就停留在当前层次。……我会去做。……阿尔弗雷德你有什么事情找我？换上居家衣物奥黛丽领着苏茜为兄长打开房门。……有些事情想提醒你。阿尔弗雷德步入书房随手拉张椅子坐下。……需要让苏茜出去吗？没必要我想它应该不会偷听我们对话。她。奥黛丽随口纠正一句。……听说你成为非凡者？嗯。奥黛丽坦然点头道。……你应该是观众途径非凡者吧？七彩蜥龙有类似方面能力。……你现在能做心理领域治疗吗？绝大多数非凡者包括我都需要这方面帮助。嗯忘告诉你我已经是仲裁人途径序列5惩戒骑士。……我是一名合格心理医生接受过专业训练这一点你可以向爸爸和妈妈求证。……奥黛丽有些事情我需要提醒你魔药带来不仅仅是力量。……每份魔药里都蕴藏着疯狂会导致失控……我曾经见过类似情况不止一次……它们发生在我敌人身上也发生在我朋友身上没有哪个群体可以豁免……阿尔弗雷德结合自己在东拜朗种种经历详细讲起魔药危害。这个过程中他发现不仅妹妹奥黛丽听得是专注而且金毛大狗苏茜也表现得非常安静。

## 这场戏有没有翻
翻了。开头文德尔悟人皮／列车失踪；切阿尔弗雷德归家收乌托邦卷；父嘱劝妹停阶；章末兄现身说法魔药疯苏茜静听。翻的是现身说法＝兄不知妹已半神级听众。

# 1226 逐光者 第七十七章 召唤仪式

## 打开书
大弥撒后克莱恩跟随刚就任愚者祭司尼姆进入那座黑塔。尼姆再没有丝毫保留将月城有多少半神多少1级封印物详细介绍一遍。三位半神……五件1级封印物……月城一点也不弱啊……不愧是能直接获得神谕看守边界势力……而且最初时候他们二十二条非凡途径相对齐全彼此能有效配合让部分仪式不需要外求不用受环境限制……嗯他们能在周围环境恶劣于白银城且没有0级封印物支撑情况下一直维持到现在确实也有过人之处……如果不是找不到合适食物他们至少还能在黑暗里坚守几百上千年……克莱恩听得一阵感慨。这时尼姆恭敬：神使大人所有封印物和非凡特性我们都愿意献祭给主不知道哪件更能取悦祂？这位大祭司刚才说过除他这位守夜人月城还有一位铁血骑士一位律令法师分别担任闪电祭司和黑夜祭司。至于五件1级封印物一件属于怪物途径似乎是部分厄运法师非凡特性糅合一点混乱行者特性一件来自异种途径木偶一件源于当初红天使梅迪奇赐予能让所有人力量集合在一起一件疑似诡法师特性衍变而成还有一件不知道对应哪条途径有非常强洞察能力却受到不知名污染相当危险。听到尼姆这句话克莱恩眼皮微跳笑着：以心侍主而非祭品。主包容整个世界不会在意这些事物。说到这里他顿一下：当然如果你们不介意可以带我去参观一下让我能增长见识。没有问题！尼姆毫不犹豫就做出回答。他原本以为格尔曼·斯帕罗会在参观中拿走一件1级封印物谁知这位神使大人真只是想了解具体情况没有索取好处意思他将每一件封印物都拿起看了看但最终还是放回去。等到参观结束克莱恩对三位半神祭司：离开这片诅咒之地机会还没有到来你们需要再坚守一段时间。而我将继续我旅程寻找别幸存者传播主光辉。是神使大人。尼姆等祭司一点也不为难回应。有那些蘑菇他们至少最近三代内不会有覆灭危机。安排好月城事情克莱恩穿着风衣戴着礼帽提着马灯走入外面深沉黑暗。他接下来要做什么其实很明确那就是：找到乌黯魔狼科塔尔狩猎这位愿望之神！我愿望是拿到奇迹师非凡特性和那块幕布不知道祂能不能帮我实现……走着走着克莱恩在心中调侃一句。见已脱离月城居民注视他从历史迷雾里拽出另一个自己。他本体随之进入孔隙让意识转移到投影身上。这投影又召唤出星之杖历史孔隙影像借助它非凡能力直接降临到脑海内勾勒那个地方：已彻底毁灭北方古城诺斯！顺利抵达目的地后投影飞快消失克莱恩本体回到月城外面荒野内。紧接着他也召唤出星之杖投影重复起之前流程瞬间返回诺斯遗迹。他刚才那个历史孔隙影像主要作用就是探路确保脑海内浮现场景与现实一致没有差别不会让星之杖产生随机性效果。这就是一位古代学者谨慎。……白银城安静黑沉训练场中央。背负两把直剑科林·伊利亚特立在旁边看着戴里克·伯格布置好仪式向愚者先生做出祈求请祂派一位圣灵降临提供帮助。这和正常召唤仪式不同相应咒文更为复杂：伟大愚者；您是灰雾之上主宰；您是执掌好运黄黑之王。我祈求您眷顾；祈求您注视；祈求隐秘与变化力量。我！我以伟大愚者名义召唤：洞察一切圣灵黄黑之王眷属梦境与心灵旅者。一句句巨人语回荡在祭坛内蜡烛顶端火光猛然膨胀交织成一道布满神秘花纹虚幻之门。虚幻之门缓缓打开一位穿着纯白长裙戴着银色面具女性走出来踏着虚空一步步踩到地面上。她发色酒红眼眸金黄既清澈又幽深仿佛能看穿每一个人心灵。这是正义奥黛丽她利用谎言修改自己身高和面具无法掩盖主要特征。她以灵体形式来到白银城来到神弃之地。其实这个召唤仪式本质并不复杂克莱恩提前把奥黛丽灵拉入灰雾之上等到召唤之门建立再帮她打开让她通过就搞定整件事情。也就是说洞察一切圣灵等描述并不重要换成沉睡公主金苹果拥有者水晶鞋上任主人一样可以让正义奥黛丽降临这只取决于克莱恩想让谁通过召唤之门毕竟仪式关键点是借愚者名义召唤借源堡力量沟通神弃之地。戴着银白面具奥黛丽悄然环顾一圈不着痕迹打量划过闪电天空隐藏着危险黑暗和不远处白银城首席科林·伊利亚特。她随即收回目光对小太阳点点头：可以开始了。说话间她忍不住在心里感慨起对方身高。虽然这在塔罗聚会时就能看出但真正在现实里遇到还是让奥黛丽一阵恍惚。她记得很清楚太阳比自己要小好几岁按照鲁恩标准目前肯定还未成年谁知竟然就有超过两米身高这让利用谎言面具刻意变高一些奥黛丽依旧只能仰望。戴里克不再犹豫放松起精神将目光投向祭台上摆放金黄色魔药。渐渐地他变得有些恍惚脑海内不由自主闪过一幕幕画面：那是躺在棺材内还活着父母；那是重重刺下银色直剑那是飞溅到脸上蒙住眼睛鲜血；那是一家人曾经温馨场景；那是黑暗中摇摇欲坠白银城；那是互相扶持做彼此盾牌队友；那是站在所有人前方挡住风雨长老们；那是一次又一次诅咒那是在黑暗里看到闪电希冀；那是两千多年来日复一日期盼那是一代又一代人对光明渴求。戴里克最强烈最不愿意舍弃情感很复杂包含对现实愤怒对过去怀念因处境而来痛苦历史沉淀出压抑以及拯救白银城渴望。正义奥黛丽一点点分离着这些情绪仿佛经历一遍白银城绝望和悲伤经历他们团结与牺牲。她金黄眼眸时而沉凝时而闪烁似乎抓住什么有所感怀却依旧迷茫。过一阵她看见背生十二道洁白翅膀光之天使这是愚者先生对太阳戴里克又一次回应。奥黛丽抓住机会将那些强烈感情附着到这天使虚影上让它们短暂不会消失不会回流不会与戴里克本体完全分离。可以了。她没有张开嘴巴让自己声音直接回荡在戴里克心中。此时戴里克眼眸变得异常冷漠似乎已不知道什么是高兴什么是悲伤什么是痛苦什么是压抑。他随即拿起面前金黄药剂将它灌入口中。这是通过粉碎无暗十字得到半神魔药。那件源自远古太阳神封印物至此不复存在当然对克莱恩来说只要曾经拥有就能天长地久。灼热狂暴液体滑过戴里克喉咙瞬间就充斥他全身占据他灵魂。一道又一道明亮阳光从他体内迸发而出洗去着他血肉内残余污染和灵魂中沉淀情感。戴里克身体越来越纯净越来越通透就如同由纯粹光辉组成圣灵。他自我意识他情绪念头都被净化着排斥着用不了多久就会只剩下赞美太阳本能。这个时候奥黛丽不再让剥离强烈情感依附于天使虚影引导着它们回流向小太阳。一幕幕场景重新浮现于戴里克脑海让他涌现出异常复杂情绪。他又一次体会到亲手杀死父母痛苦体会到白银城处境带来绝望体会到获得愚者先生眷顾后欣喜。这刻入他骨髓是他心灵世界基石非常坚固非常牢靠帮助他抵挡住魔药净化力量最后几轮冲刷。终于戴里克睁开眼睛一片纯白。他看见前方有一道光残留本能就伸出右手试图抓住。但是那道光很快黯淡平息。戴里克怔一下旋即握紧右手。一道道光辉随之腾起笼罩整个白银城。神话传说中正午在这一刻短暂降临。包括首席科林·伊利亚特在内每一个白银城居民都看得呆住这比以往任何一位半神晋升都让他们震撼。阳光。这是照亮全城阳光。……结束召唤奥黛丽回到灰雾之上。此时愚者先生已经不见古老宫殿内只有之前就在这里打算旁观仪式世界格尔曼·斯帕罗。你状态似乎不是太好？克莱恩主动问。奥黛丽坐下来笑：只是有一些徘徊犹豫和迷茫。这很正常在真正下定决心前每个人都会这样退缩和反悔者不计其数。克莱恩平和说。奥黛丽没直接回应这个话题转而浅笑：自从成为观众我总是在别人面前表现出他们最能接受一面照顾着他们最细腻情感这不是坏事但这样一来我就没法知道最真实自己在别人眼里是什么样子就无法揭开那华丽衣物看见下方藏着腐烂血肉无法弄清楚问题在哪里。我最近在尝试于一些细节上展露自己真正状态看周围人在当前局势下会是什么态度看他们是否还认为我是那个善良和蔼品行高洁小姐。说到这里她忽然沉默好几秒后才轻叹一声：鸿沟……

## 这场戏有没有翻
翻了。开头还在月城献祭参观；中段召唤正义助太阳晋升正午照城；章末正义叹鸿沟。翻的是神弃之地升半神接到贵族自认鸿沟，不是阳光厉不厉。

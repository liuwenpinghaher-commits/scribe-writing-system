# 1348 倒吊人 第八十三章 “门”

## 打开书
贝尔纳黛祈祷未获得回应后已拿着许愿神灯走到船长室窗边眺望起深蓝大海。她没有急躁没有试图使用自己预言能力耐心地等待着事情发展。过好几分钟她眼前突地浮现出一片灰白雾气。紧接着这雾气染上金色仿佛涂一层粘稠糖浆。贝尔纳黛当即低头看向手中许愿神灯只见壶口灯芯自行燃烧起来。灰雾之上古老宫殿内愚者座椅旁那个膨胀到人类头颅大小祈祷光点瞬间被一道扭曲而模糊淡金人影占据。这人影目光穿透祈祷光点穿透灰白雾气看向试图毁灭周围一切蠕虫漩涡。祂嗓音旋即回荡在源堡内部威严而恢弘：竟然失控了？灯神语气里带着明显嘲讽也没管疯狂灵之虫们是否能听懂。就在这个时候已然散架愚者座椅上方一座由无数光球组成奇异光门凸显出来。……这符号原本存在于愚者座椅背后由半个无瞳之眼和半个扭曲之线组成。下一秒钟代表愚者那个符号内传出克莱恩声音：灯神我想和你做一笔交易。……哈哈我说过你终究会答应。……我刚才就在想能成为源堡新主人怎么可能轻易就失控？这是我为最坏情况做准备。那个愚者符号内声音一点也没急躁。……你不怕我临时抬高价格吗？……这对我来说只是准备之一可于你而言也许是很多年内唯一机会。……我条件与上次一样只要你能解除封印放我出去我将带着属于我那部分回归星空把剩下都留给你并实现你三个愿望。当然从现在情况看你似乎需要我预支报酬。……我给出承诺是在本纪元1368年结束前将这盏许愿神灯送到星空至于之后你怎么脱困是你自己事情而我要求更简单只需要两个愿望。这就是我说交易是否答应由你决定。1368年是最初屏障消失年份是这个世界预言家们公认末日。……如果不解除封印我能完成愿望很有限一旦超过某个层次它将以非常扭曲方式实现。……我需要那两个愿望现在你就可以满足。……头脑因自身和外在两方面原因发热维尔杜没有浪费时间按照战争之神吩咐改造祭坛铭刻上正确象征符号魔法标识和奇异花纹。……伟大万门之门；无尽星空领路者；所有神秘世界钥匙。我祈求您回应祈求您降临到这个世界上……那对应诡法师秘法师和寄生者三个半神级怪物就仿佛被无形之手捏住只是略有挣扎就直接爆开化成一团团闪烁不同颜色光点血肉。……那根代表门先生蜡烛火焰猛然蹿升照亮整座血肉之门照亮那片黑暗。……那些光球飞快扬起竟组成一条巨大手臂穿过血肉之门都颇为困难手臂。这明显不属于人类手臂抵在祭坛之上用力往外挤出让整个血肉之门甚至整片森林整座岛屿都出现摇晃形同一场地震。……这个时候那只手臂终于挤过血肉之门开始尝试将后续部分拔出。……终于一道由纯粹光球组成巨大身影穿过血肉之门。下一秒那些光球开始坍缩和层叠似乎要进行可以产生质变重组周围森林内随之出现一道又一道来自于虚空幽暗缝隙。……海浪教堂内正因维尔杜传送离开没法监控而烦恼阿尔杰·威尔逊突然听见一扇又一扇门打开声音。……这……阿尔杰侧头望向似乎是异常源头城外森林内。……灰雾之上半坍塌古老宫殿内疯狂蠕虫漩涡本能袭击着淡金人影和愚者符号却都没能成功。近一分钟过去灯神忽然低笑道：你确实不是祂否则我已经扭曲你刚才承诺让祂布置封印自行解除。只有原主人被扭曲话语才能达到这个效果？你上次就是依靠这个办法认出我不是诡秘之主？克莱恩声音从愚者符号内传出。灯神呵一声道：对于祂我有至少十种办法鉴别。……你现在这种状态似乎维持不了太久好交易达成在我完成你两个愿望后本纪元1368年结束前你必须将许愿神灯送到星空。……如果你不能完成这个承诺即使你已经成为诡秘之主也会因此陨落并分裂。灯神告诫一句开口问道说出你两个愿望吧……第一个愿望：将贝尔纳黛·古斯塔夫之前许两个愿望计在我名下。这对你来说应该很简单。灯神当即笑道：果然你是想利用许到第三个愿望就会遭遇不好事情规则对抗现在困境不错这是基于我本身位格我将满足你让你痛苦地死去。……第二个愿望：让我乌托邦在灵界诞生对应区域。这不涉及序列提升也与较高层次非凡特性无关你肯定可以办到。灯神那淡金人影摇晃一下笑着说道：你愿望将被满足。……你在第四纪不尝试成神是因为没得到0-08？这是一个因素更重要是那个时候还有很多隐患没有解决。亚当目光和煦注视前方巨大十字架。克莱恩侧过脑袋看着这位空想家道：比如那个时候原初残留意志还很强……可他嘴角却微微翘起来。

## 这场戏有没有翻
翻了。开头灯神入源堡嘲失控；交易两愿（计贝尔纳黛愿＋乌托邦灵界区）；并行门先生挤出血肉之门；章末克莱恩嘴角翘。翻的是门＝双线同时：灯交易破局＋门将成神。

## 这一章新讲明的规矩
- 灯交易：1368前送灯星空；两愿即可（非三）；未解封则愿有限／扭曲。
- 愿1：贝尔纳黛两愿计克莱恩名＝触第三愿死规则。
- 愿2：乌托邦灵界区诞生（仪式效）。
- 原主扭曲话可解己封；非诡秘之主可鉴别。
- 门降临致满城门开声。

# 496 旅行家 第十五章 悬赏墙

## 打开书
激励一代代冒险家出海宝藏传说讲完——厨师也烤好鱼人肚子上肉。透出熟白颜色染些许焦黑布满褐色细小颗粒闪烁滋润油光。反复涂抹调料已渗透肉纹理呈现诱人视觉效果。「迪西烤鱼和你们经常吃不太一样。」艾尔兰指厨师放下白色瓷盘。堂娜手按刀叉跃跃欲试：「我最爱吃蜂蜜烤鱼！但这个也很诱人。」蜂蜜烤鱼…那得用多少蜂蜜啊…有机会试试味道应该不错…一下浮想联翩。有了厨师无需再亲自动手满怀期待看着一片片鱼肉被切割下来放入不同盘子推到自己面前。克在享用美食态度上非常严肃没急着对付鱼肉反倒先端起杯子喝口红茶用微酸液体清除口腔内残余味道。做完这一切叉片鱼肉塞入口中。瞬息感受到小茴香罗勒等香料略显刺激味道它们充分打开一个个味蕾。紧接着肉鲜美汁水海盐咸香微涩柠檬清爽酸甜同时爆发交织回荡口腔引诱出唾沫。牙齿嚼动被烤出油脂下鱼肉最后倔强一条条断开呈现肉质本身美好和隐约甘甜。吞下嘴里鱼肉回忆上辈子看美食节目挑选最契合刚才感觉评价语：「层次感分明非常棒！」「哈哈你语气和用词像一位美食家。」艾尔兰开句玩笑。堂娜晃手里叉子附和：「叔叔也许你应该在报纸上开个专栏点评不同餐厅不同美食。」咦我为什么一直没想到这创意…这是又能赚稿费又能品尝美食好工作啊！唯一问题肥胖人无法做灵活小丑…用催吐大法？那多浪费食物啊！认真考虑堂娜提议。「为了这个美好夜晚！」食物所剩无几时艾尔兰又倒点苏尼亚血酒脸色红润举杯。克等人心情同样不错附和：「为了这个美好夜晚。」相继喝掉杯子内剩余液体看着侍者收拾餐桌打扫甲板。冷冽寒风里又聊一阵聊到堂娜最感兴趣美人鱼。克里维斯告诉小姑娘在某些传说里美人鱼又叫海妖她们用歌声迷惑人类不是为好玩而是狩猎；除加尔加斯群岛通往苏尼亚海深处航路上可能遇到这种生物人类尚未探索充满各种危险海域里也有一定机会发现；但是这都源于某些海盗喝醉后吹嘘话语他们全部回避自己是怎么逃脱美人鱼歌声问题不是太值得相信。不管怎么样这至少指出一个可能方向…记下讨论话语。「堂娜丹顿该回去了你们明天还要早起陪你们父母共享早餐。」塞西尔看眼月亮位置。「好吧。」堂娜恋恋不舍站起。丹顿则慌忙问：「我我有机会做冒险家吗？」他心灵已被之前狩猎活动和刚才那些传说俘获。克里维斯走到旁边拍拍肩膀：「问这问题前你需要至少五年格斗训练和知识获取我想你父亲会给你请不错家庭教师的。」「嗯！」眼睛一亮用力点头。五年之后长大起来你大概率不会再想做随时葬身海底冒险家…克里维斯处理很老辣啊没直接拒绝反倒给希望让时间冲刷这就避免小孩子突如其来叛逆…不管怎么样掌握一门格斗术对谁来说都不会吃亏…双手插入衣兜赞赏想。返回船舱内部路上克里维斯将两张5镑钞票递给克：「你的酬劳。」他刚才已收到艾尔兰购买整只鱼人150镑。「我并没有做什么。」本能拒绝。克里维斯用淡蓝眼眸扫他一下低沉：「你解放了塞西尔看好了孩子们。」看好了孩子们？有些想笑但最终接过那两张钞票在胸口画三角形：「你比我想象得慷慨谢谢。」他不再推辞是忽然想明白一个问题——如果自己不收那10镑在克里维斯这种资深冒险家眼里就是对价钱不满意试图获得更多随时可能袭击他们——自称冒险家人里贪财疯子绝不在少数！见格尔曼揣好钞票克里维斯收回目光表情平淡说一句：「这是海上的规矩。」不再多说跟在塞西尔堂娜等人身后进入船舱。如果我每一单委托每一个任务都是这种难度都能有这种收获我早就靠私家侦探这职业发财了…自嘲一笑侧头望眼高空红月。它依旧安静温柔照耀黑夜。「海上传说不同怪物…我终于找到了点冒险家感觉。」转身走至船舷边缘沐浴绯红轻纱欣赏起越远越黑波浪心情逐渐沉淀从贝克大雾霾后阴郁里一点点走出来。凛冽又潮湿风拍在脸上广袤而无垠大洋映入眼帘让心胸慢慢开阔。这瞬间有了吟唱诗歌冲动可张开嘴巴后发现自己根本记不起相应现代诗句。总不能来一句大海啊你全是水…大帝通识者序列真非常适合做类似事情有空得翻翻他诗集免得像个文盲…边腹诽边望红月和海洋叹息：「真是一个美好夜晚。」……经过一场意外迷路探索小队回到白银城。看着缝隙里长满荒草城墙戴里克竟有些恍惚仿佛自己已离开很多年。斜后方猎魔者科林眼神突然迷茫抬手按下右侧太阳穴。其余队员则充满发自内心喜悦和放松。艰难探索后能有一个终点一个家园在等待他们是他们心里最美好事情。科林目光恢复正常微侧脑袋看向斜前方。……贝克兰德怀特家。经过反复思考充满自信埃姆林来到父母面前开口问：「如果如果我想深入研究我们血族历史我该找谁？」直接问白银城事情很可能会暴露我问题我虽然不害怕很坦然但为了始祖为了拯救整个血族我只能选择隐瞒…我一直对血族历史感兴趣搜集不少资料爸爸妈妈很清楚这点不会有任何怀疑…这借口非常完美！心里自我夸赞。他父亲和他有五六分相似戴副金丝边眼镜显得很专业。这位真切拿到医学博士学位绅士放下手里厚厚《解剖学》推下眼镜：「在贝克兰德没有谁比尼拜斯大人知道更多。」…我要是敢去找尼拜斯大人早就去了…想到愚者描述背负秘密背负误解救主姿态表情严肃追问：「除了尼拜斯大人呢？他沉睡在地底不方便频繁被打扰。」父亲拉下厚棉睡衣领子想了想：「威曼迪他总认为自己是一个历史学家。」暗中松口气露笑容：「我希望去拜访他。」……呜！汽笛鸣响白玛瑙号驶入达米尔港。它将在这殖民岛屿补充淡水和食物于第二天早上再次起航。狩猎鱼人后克度过了两天可说悠闲也可说无聊生活对海上景色彻底乏味决定今晚去港口酒吧探一探希望能获得更多美人鱼情报找到扮演灵感。如果遇到哪个满手血腥海盗上岸我也不会吝啬教训蠕动饥饿内还有一个个灵等待被释放…将所有神奇物品戴身上额头出汗离开船舱下至港口。这过程遇到堂娜和克里维斯等人他们似乎要去港口餐厅品尝达米尔最出名腌肉。堂娜丹顿趁父母不注意向刚认识不久冒险家叔叔打个招呼似乎很好奇他打算去哪里。回以微笑扯拢领口按照路牌提示找到最近一家酒吧。「飞鱼与酒…」看眼招牌发现酒吧门外贴满各种各样悬赏令。这里面有属五海之王80万镑也有普通海贼头目上百镑从高到低层层叠叠形成独特风景。「都是钱啊…」驻足原地看了好一阵子。收回视线推门进入酒吧发现里面反常安静没有这种场合必备喧闹。发生了什么事情？环视一圈看到穿暗红外套艾尔兰船长坐在吧台看到两个壮汉对峙于中央。

# 341 无面人 第一百二十九章 “老油条”阿尔杰

## 打开书
愚者心答：有多远躲多远——默以观。阿尔杰：信息太少；不知庙内除堕落＝真实造物主像还有何，难分析。佛尔思津津有味；正义期待描述。戴里克：壁画恶灵已被两长老清；壁画末日＋堕落救信徒＋血腥祭；角有巨人语衍文破解＝「救赎蔷薇」（作者代号或组织）；首席判≥千年（白银以闪电频疏为日夜、无四季，天数难把握）。佛尔思：无日无月无四季城＝童话／大麻小说；想写又怕教会上门。正义放飞冒险又自检危。克莱恩：极光＜三百年非彼建；真实信仰或四／五纪早有，教派覆灭后死灰＝极光会？戴里克：废墟恶怪初清，任务探地下——注意何？阿尔杰几乎不犹豫：「绝对不要去！」邪神庙毁仍诡险；他长老或可冒高风险，但带队＝牧羊人洛薇雅而真实＝该途顶端神——绝不能去。愚者扶额：老油条故意少付代价套全庙况欺小孩。太阳：任务必须接。阿尔杰：无必须；巡逻故意让怪弄伤（参旧例）。正义读「这样也行？」——无巡逻。阿尔杰：弄到近失控；连两日灵干涸→幻听失控征，不续压一周好转；白银有治故估时出发前两三天开始。太阳愣：失控前兆控圆塔地底药／仪式／物治轻则服药。老实孩被老油条毒——技巧常恐真失控。太阳犹不欺长老——阿尔杰：他长老知堕落掌牧羊人途？「不知。」洛薇雅或害白银？「是。」「你唯一知却难提醒——死庙则无人揭；你假失控非自私为救城；荣誉vs城谁重？」咬牙：「明白了！谢谢。」正义魔术师欲掩面。愚者叹好忽悠——世界请单独问太阳：白银有去除非凡特性邪神精污法？「未遇邪神；仅有失控者精污分离。」资格≥巡逻队长序列7甚探队序列6。「望你尽早有资格。」

## 这场戏有没有翻
翻了。开头还在等稳妥建议；章末老实太阳被忽悠成「为救城假失控」，世界另套到去污线索门槛。翻的是建议还能否只劝别去，不是救赎蔷薇。

# 1166 逐光者 第十七章 群星归位时

## 打开书
切尔诺贝利！听阿蒙话语第一反应错愕。靠近青黑独眼巨人过程中预想很多展开怎么都没料到听见这样一个名称。就像古代油画里出现水冷机枪科研论文里出现小说桥段充满违和让人不敢相信。下一秒联想到远古太阳神用自己肋骨造出暗天使萨斯列尔却给长子取名亚当的滑稽事情本能认为此时遭遇就是类似情况忍不住想笑。意识到实力近乎Bug总是一脸恶劣笑的天使之王阿蒙用相对严肃庄重姿态说出的是这么一个名称时想笑冲动愈发难遏制也不想遏制。最好笑得阿蒙恼羞成怒直接把我弄死……阿蒙会变成今天这幅样子远古太阳神教育绝对要负很大一部分责任！嘴角咧开准备毫不留情宣泄内心笑意。这时又一道银白闪电划破天际照亮幽邃沟壑让他再看见底部灰白连绵厚重建筑。这是与当前与第四纪第三纪乃至第二纪风格都截然不同的建筑。噗通！心脏急速收缩一下又扩张笑容刚有绽放就凝固脸上。噗通噗通！听见自己心跳脑海骤然冒出一个又一个关于当前世界常识：一年十二个月三百六十五天有闰年……每天二十四小时每小时六十分每分钟六十秒……证实是星球……天空中有且只有一个太阳和一个月亮……噗通噗通噗通！本能阻止想下去但内心深处还是冒出声音：会不会从来没有穿越这种事情我其实一直都在地球上只是被悬吊在灰雾之上那扇光门太久太久真正地不属于这个时代……随这想法成型许许多多没引起注意的细节火山一样喷薄：苏尼亚海最东面进神战遗迹前深海古井四周有腐朽坍塌钢铁建筑似人类留下……南北大陆整体地形很像南北美洲只不过两者靠近那很大一块不知被什么力量直接抹去形成航道复杂曲折狂暴海……苏尼亚岛如同北方大岛整体漂移往南形成……间海仿佛五大湖扩张连通版像遭遇巨大陨石袭击……北大陆山脉河流多有改变但整体形状还勉强可辨……这样一来精灵故乡西大陆神弃所在东大陆就与切尔诺贝利对应上了……海上宝藏传说有失落文明叫纽因斯沉在迷雾海某处……巨人王父母是人类血族精灵源头也疑似人类……之前两个疑问源堡为何从地球抓取穿越者为何那些人全部属我所在那个时代也都能得到解释了……短短两三秒脑海仿佛一个又一个惊雷连续炸响嘴唇轻微颤动似竭力遏制某个答案成形。可是这世界月亮是绯红色星空情况也与地球有点不一样……不是天文学爱好者记不太清但大帝服食通识者途魔药星空真要完全相同他早就发现了……反对意见如坚固锚让暴风雨中船只不被吹离港口。可下一秒记起两句话。一句是上辈子网上看过一则恐怖预言：当群星归位之时混沌将从地底升起伟大的最初将会苏醒。另一句：小心月亮！这……那预言不是胡编乱造的？群星归位于是和之前有了区别？近乎无视眼前阿蒙连身体都轻轻颤抖。用很大力气才在心里发一声叹息：也许我从未离开故乡却永远也不可能回家了……刚产生这样认知与明悟眼前无声无息出现那片灰白雾气。这一次直接站在对应衰败森林对应第一纪末尾第二纪初期那个历史片段内。与以往不同前方无边灰雾不再空旷雾气深处很远很远地方亮起一个又一个破碎光斑。它们就像灯塔照亮历史道路牵引他往前奔跑不断追溯穿越几千上万年甚至更多时光。然后看见染些许青黑灿烂光门看见悬吊光门之上一个又一个透明蚕茧看见穿T恤休闲裤的自己。无形风吹过光门之下灰白雾气一层层翻开露出一座座城市。之内竖立高高摩天楼停各种各样汽车凝固来来往往行人。这些城市一座压着一座布满灰白尘埃许多建筑已倒塌刺出折断钢筋汽车有的凹陷有的崩坏有的摊成铁饼行人们目无生气如一尊尊蜡像……看到这一幕停下来深深凝视。已无比清楚：这个世界就是地球！他的古代学者魔药在这一刻彻底消化了。霍然间意识回现实发现自己与源堡联系进一步加强。嗡声里周围因塔罗会成员祈祷产生共鸣变得愈发强烈。之前就已能借助它们隐约感应灰雾之上源堡看见愚者那张座椅的他似乎与扭曲着想要成形那道深红人影终于建立起某种联系。瞬间有一个明悟：这一刻自己无需诵念咒文无需逆走四步只要一个意念灵体就能进入源堡与那道人影合二为一。这毫无疑问是脱困最好机会！顾不得感叹这世界是地球抱着阿蒙肯定想不到会有这种变化心思当即转动念头跃向源堡。就这时眼眸映出戴尖顶软帽单片穿古典魔法师长袍阿蒙嘴角微翘带着说不尽愉悦。脑海突然炸了所有思绪都被来自阿蒙疯狂呓语占据：你说的很对我不想窃走你命运在成为源堡新主人同时背上沉重负担……你说的很对这是一场从开始就在进行的欺诈……但是这欺诈核心是让你以为我一路给你希望又摧毁它是为击垮你意志自己答应成为我眷者……如果不是我进入神弃时特意更换服装如果不是我几次不小心表现出利用错误能力你能那么肯定我本体已经抵达吗？难道一个欺诈之神会不明白当时改变形象会透露出很多问题？你以为早就进入过切尔诺贝利的我会不明白这个名称代表什么？我在神弃之地一千多年就是在寻觅最古老那段历史超越第一纪那段历史。这段旅程真实目的是给你一些时间给你一些历史知识帮你消化完古代学者魔药让你放松这方面戒备然后在你与源堡联系进一步加深尝试引动源堡时抓住这个机会利用漏洞直接盗走源堡。命运归你源堡归我。……这来自天使之王恐怖呓语不仅蕴藏阿蒙轻笑声还摧残精神不比门先生嘶吼差。皮肤表面随之凸显一条条灵之虫痕迹处在失控边缘。而体内一条十二环节时之虫钻出来化成身穿黑魔法师长袍头戴同款尖顶软帽与水晶单片的阿蒙虚影。祂是浅层次寄生在他体内的阿蒙目的不是监控思维也不是关键时刻通过深层次寄生掌控局面而是把握住当前这样机会！阿蒙最开始就采用深层次寄生主要目的就是为了在一位圣者没察觉情况下再浅层次寄生一条时之虫！这阿蒙虚影回过头来看眼被呓语干扰无法转动念头的他露出与本体一模一样笑容：嘴角微微翘起带着说不尽愉悦。旋即转身借助那无形联系跃向灰白雾气之上源堡。这与祂之前寄生戴里克体内试图通过对应太阳深红星辰潜入灰雾之上情况类同。但这一次再没谁于源堡内做出净化关闭大门隔绝阿蒙。这是一场精彩的表演。这就是欺诈之神。

## 这场戏有没有翻
翻了。开头还想笑切尔诺贝利违和；章末魔药消化跃源堡却被浅层时之虫抢先。翻的是故乡真相收成盗堡陷阱，不是蜡像城市厉不厉。

# 516 旅行家 第三十五章 慷慨之城

## 打开书
贝克兰德乔伍德区。当前眼深红光芒消退佛尔思又看见熟悉书桌和摊开记录灵感笔记本。对她来说这样体验虽然已没有任何新奇之处但依然让她发自内心敬畏。这是不属于人类力量哪怕半神半人也不行！食灵者胃袋过两天就能拿到我学徒魔药也已消化完毕…终于要成为戏法大师了不知道会获得什么样非凡能力…依靠自己完成晋升老师肯定会更加重视我之后除了魔药配方肯定也将或多或少提供一些非凡材料…期待啊我甚至还不知道对应序列6和序列5叫什么只清楚序列7是占星人等成为戏法大师就立刻写信给老师…觉得自己离摆脱满月诅咒又近一步。就这时听见一阵急促脚步声由近及远最后化成大门哐当。「休又出去了真是忙碌啊。」无声感叹「如果不是她要偿还欠格莱林特子爵400镑我们现在应该在迪西海湾度假。」经过很长一段时间努力得益于实力提升后某些以前无法完成委托变得简单加上时不时能从黄金面具男那里得到些报酬不菲小任务休已经将自己存款从110镑提升到320镑距还清债务只剩80镑。其实我可以先帮她垫上这80镑可惜虽然她个子不高但自尊心还是很强…收回思绪考虑起世界先生委托事情。作为一名医生一位作家她对无线电甚至整个机械领域事情都了解不多平时看报纸也没有留意相关内容根本不清楚该去哪里买对方想要收报机。「百货商店？似乎没有…啊对阿维勒是写科学幻想小说的在这方面应该知道不少。」迅速找到请教对象。但立刻又有了新难题那就是直接去拜访还是写信询问？瞄眼铺着厚软毛毯安乐椅闻下弥漫于房间内咖啡与烟草香味感受一阵缓慢蠕动温暖出门动力一点点瓦解。「我和他并不熟悉不应该贸然拜访。」嘟囔着坐下摊开信纸。……白银城伯格家。戴里克睁开眼睛从假装睡眠里醒来。按照原本计划现在就该举行献祭仪式送出食灵者胃袋但倒吊人话语提醒了他让他决定再谨慎一点多观察一下。额…先把倒吊人先生要材料集齐一次性完成献祭…沉默几秒别上飓风之斧直奔尖塔。先在功勋兑换点查查目前有物品资料没急着完成交易打算等天空闪电减少后去地下交易市场再看一看。上到三楼直奔图书馆神话传说和古代典籍区域充满饥饿感寻找起未学过有价值知识。忽然看到一本封皮坚硬发黄书籍：《巨人王庭黑岩之书手抄集》直接从巨人王庭流传下来记载？不知道有没有天使之王相关内容…伸手抽出那本书发现它由一张张褐色怪物皮纸装订而成。这个时候图书馆上层穿亚麻色衬衣披棕色外套科林·伊利亚特正静静屹立注视着下方。他缺乏打理花白头发被窗口吹入风轻轻拂动浅蓝色眼眸深邃而内敛。……1月12日周三下午5点40分。天空昏暗云层如卷深蓝波浪高高低低起起伏伏。白玛瑙号在这暴风雨快来临场景里时上时下仿佛一位巨人手掌里玩具。「这就是大海不管多么强大力量在它面前都显得渺小。」达尼兹立在窗口欣赏着外面场景「幸运的是我们快抵达慷慨之城了。」从班西港离开后白玛瑙号航行一直颇为顺利在风帮助下速度稳定在15节因此仅比预定时间晚一点抵达提亚纳港将比正常早半天完成全部旅途。也就是说原定13日上午到达慷慨之城白玛瑙号将于12日傍晚抵港。听到达尼兹感慨克只是抬头瞄他一眼就收回视线继续自己沉思。越是扮演格尔曼这个角色越是在某些时候必须强撑着做出符合人设行为他就越是深刻认识到自己是什么样一个人在面对不同场景时他真正想做选择和格尔曼并不一样。比如正常他此时会回应达尼兹和对方闲聊海上天气和那些恐怖暴风雨带来灾难但格尔曼不会必然冷漠对待内敛不语。「类似反差越多我越能认清自己。」由衷在心里叹息一声。这是之前以私家侦探夏洛克身份活动时没有体验因为那个时候不需要伪装性格做自己就行。我感觉我魔药消化了一点…不过格尔曼也有和我本身相同地方至少选择下船进入班西港救人时我自己和这个身份是完全重叠没有区别…当然也可以说是为了自己在一定程度上添加了人设斯文和疯狂之下是一颗善良勇敢怜悯重感情心呵呵自夸要不得如果早知道班西是宾西我我多半就怂了…也不一定至少当时占卜出危险在可以承受范围内…半是总结半是自嘲想着。这让他愈发明白一个问题虽然扮演纯粹虚构人也能帮助消化魔药但要想加快速度提高进度确实需要顶替一个原本就存在身份获得对方人际关系肯定感受相应喜怒哀乐情感沉浸但不沉迷。成为任何人但最终回归自己？并从相应人员那里收获反馈？望着淡黄色地毯脑海思绪纷呈。见格尔曼没有回应达尼兹无奈摊下手觉得自己憋得慌。除了会让我做些仆人做事情这疯狂家伙其他方面都很好只有一点不爱说话有交流障碍这样下去我一定会因此疯掉…还好还好总算要到拜亚姆了总算能解脱了！觉得自己迟早会在对方类似沉默里养成自己和自己说话习惯。过一阵看见格尔曼抬头微笑开口：「你可以讲一讲拜亚姆有哪些属于海盗联络点了。」…狗屎！你还是不要说话比较好！表情一下扭曲。呜！傍晚6点15分暴风雨来临前白玛瑙号顺利进港抵达罗思德群岛首府慷慨之城拜亚姆。这里又被称为香料群岛有着各种各样奇异香料以这方面种植园为经济支柱。其中拜亚姆所在蓝山岛占据群岛一半以上土地面积有金银铜煤铁等矿藏森林覆盖率高水果品种多土地异常肥沃正因为如此第一批殖民者将他们建立在海边城市命名为慷慨之城认为这是神灵许诺流淌着奶和蜜酒宝藏之地。克提上达尼兹收拾好行李箱离开312房间进入通往甲板过道。没有意外遇到堂娜一家和克里维斯等人。之前被吓唬后两姐弟到现在都还有些害怕克半躲在父母和保镖身后不敢说话像是蔫掉气球。轻轻点头算是与他们打招呼。就这时乌尔迪犹豫一秒上前半步道：「斯帕罗先生你会在拜亚姆停留吗？如果我想雇佣不请你帮忙该怎么联系你？」果然是有冒险精神商人即使害怕也要结交有非凡能力人…想了想道：「这里有什么报纸？」「群岛主要流行苏尼亚早报和新闻报。」乌尔迪不需要回想就能给出答案。「你在苏尼亚早报上连续刊登三天求购达米尔特制腌肉广告并留下地址我会去找你如果三天之后我还没有出现就说明我又出海了。」相当谨慎给出单向联络方式。「好。」乌尔迪吐口气露出笑容。克里维斯等人又一次表示感谢有序离开船舱。眼见舷梯在望堂娜忽然放缓脚步往后缩到克旁边仰起脸蛋咬下嘴唇道：「斯帕罗叔叔既然既然那样力量必定带来危险和疯狂你你为什么要选择？」这问题她想了好久终于鼓起勇气发问。克怔一下本能勾勒出一抹笑容：「为了梦想。」接着嗓音变低吐出两个单词：「以及守护。」守护…堂娜略显茫然念着这单词加快脚步追上父母。目送布兰奇一家离开白玛瑙号后克收回视线对旁边达尼兹道：「你自由了。」啊？达尼兹一时还有点不适应。

## 这场戏有没有翻
翻了。多线切到港；章末你自由了。翻的是「梦想以及守护」答堂娜，不是冷漠走人。

## 话
「你可以讲一讲拜亚姆有哪些属于海盗的联络点了。」「为了梦想。」「以及，守护。」「你自由了。」局面是从安乐椅收到写信；从黑岩书收到科林注视；从沉默收到联络点；从吓唬答收到守护；从放人收到啊。

## 热怎么变冷
戏法大师期待还热。冷切写信。暴风雨还热。冷切认清自己。守护还热。冷切你自由了。

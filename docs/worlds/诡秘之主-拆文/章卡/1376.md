# 1376 倒吊人 第二十四章 疯狂的呓语

## 打开书
数不清大小不一魔女们带来万物坍缩般毁灭让整个霍纳奇斯山脉主峰往着巨大石球方向发展。这使得那座古老宫殿破败外墙飞快垮塌让大厅中央克莱恩连同他分身和秘偶一起暴露在星界之中。眼见那一条条蟒蛇般黑色触手快要奔涌入宫殿一轮绯红月亮在这末日一样场景中升起来。沐浴着月华大厅外围瞬间长出一丛丛小麦一朵朵鲜花一个个蘑菇一株株树木它们彼此纠缠一层又一层叠加将属于安提哥努斯宫殿密封于内。……它们扬起来不断地拍打着这源于自然屏障让后者一层又一层石化崩裂或直接坍塌。……执掌着月亮途径唯一性地母神挡住原初魔女奇克。这个时候一道无法被绝大部分非凡者看见光芒从高处直直落下撞到以植物为根基自然屏障上。……隐匿贤者！……它们有的记录人类面对超凡物种时无力和悲惨有的以史诗般笔触再现人类以自身为实验体尝试融合非凡材料以此获得力量拯救族群场景……当初那位工匠之神并没有很好地消化掉序列1文明启蒙者这份魔药就因种种缘由晋升序列0并且保持住理智和清醒但这也让祂不得不分出更多精神去对抗失控和疯狂趋向在七位正神里要比其他存在都差上一些。……等到罗塞尔以蒸汽之子和教会成员身份掀起工业革命带来各种各样思潮工匠之神才抓住机会改名蒸汽与机械之神分享文明启蒙进展消化掉相应魔药。而作为相近途径真神在隐匿贤者选择与克莱恩为敌后祂最终站在其余正神这边。庞杂到恐怖信息洪流撞入那一幅幅虚幻画卷中迅速膨胀开来试图撑裂牢笼。可是几千上万年文明是那样厚重和广博以亿来计算一代又一代人类遗留历史是如此浩瀚和恢弘用来承载隐匿贤者信息洪流完全足够。隐匿贤者努力冲破蒸汽与机械之神限制时被一层层植物密封安提哥努斯大厅内克莱恩延伸出一根根滑腻奇异触手拿到那张代表愚者唯一性半透明面具将它凑向自己脸孔。……错误先生阿蒙分身们！祂们不知是利用原初魔女还是隐匿贤者入侵开后门钻漏洞悄无声息抵达目标附近。看眼刚戴上半透明面具开始容纳愚者唯一性克莱恩这些阿蒙同时露出笑容张开嘴巴吐出一个个正常人无法听懂单词。……你忽略原初魔女……对祂来说只恢复到序列1梅迪奇根本构不成威胁……祂现在最希望就是立刻有一位诡秘之主诞生打开西大陆封印让祂有机会找到灾祸之城……很显然比起你我是更好选择你太弱小了……呵呵是不是还在等待欲望母树或者堕落母神给予帮助？没用的我将第一块亵渎石板放到迷雾海放到深渊入口放到那座原始岛屿不远处。加上门相关权柄带来封印增强和半个星界之主对世界屏障掌控无论哪位外神短时间内都没法将力量渗透入现实……而没有外神施加影响宇宙暗面和被缚之神目前并不想干涉神战祂们更宁愿抓住这个机会尝试摆脱束缚。祂们同样也希望尽快诞生一位诡秘之主帮助祂们摆脱困境……如果不是引动祂们会同时引发祂们体内外神污染我现在就可以做出承诺和祂们达成一致让祂们共同对付你……反正于祂而言这不会浪费什么时间一方面祂分身足够多每条时之虫说一个单词就足以组成许多话语另一方面祂将信息强行糅合在一起一个词语就能代表很多。如果是在平时对于最多序列1层次呓语克莱恩完全可以凭借自身位格强行压制不受什么影响但此时此刻他正在容纳愚者唯一性精神平衡微妙而脆弱。……而且在克莱恩精神刺痛自我认知混乱同时他体内陷入永眠状态安提哥努斯精神烙印和福生玄黄天尊意志都出现苏醒征兆。——永眠在某种意义上来说就是一种极致封印容纳门唯一性阿蒙们毫无疑问可以让封印减弱甚至失效！另外克莱恩刚戴到脸上那张半透明面具——愚者唯一性内部有着更加强烈福生玄黄天尊意志它也在逐渐摆脱永眠影响与克莱恩体内同类产生一定共振。……并且这一切似乎无法逆转除非还能有永暗之河河水让安提哥努斯精神烙印和更加强大福生玄黄天尊意志继续永眠。但这个时候就算还有永暗之河河水黑夜女神也无法分心因为祂正全力压制双途径真神阿蒙。从这个角度来看阿蒙们其实是故意牺牲真身以此拖住黑夜女神为分身们破坏克莱恩仪式创造机会。……0-02特伦索斯特黄铜书！这件封印物在半空舒展开身姿一边沐浴着淡金光芒一边让空白页上突兀出现一条规则和之前不断重复那些条文截然不同规则：此地禁言！阿蒙分身们嘴巴不断张合却再也无法发出声音。……此地禁止互相攻击！啪特伦索斯特黄铜书掉在地上摊开于克莱恩脚边。它在许愿神灯照耀下竟然初步摆脱之前循环制定出有利于克莱恩规则。……特伦索斯特黄铜书上那些新条文之前一段话语逐渐成形：以下规则无效……不能攻击不等于不能偷盗不能送礼！

## 这场戏有没有翻
翻了。开头母神月植封宫挡奇克；蒸汽文明画卷挡隐匿；克莱恩戴面；阿蒙分身呓语破永眠＋解母树指望；灯照0-02出禁言／禁互攻；阿蒙写「以下无效」＋偷盗≠攻击。翻的是疯狂呓语＝戴面危＋灯书暂救。

# 1206 逐光者 第五十七章 多里安的决断

## 打开书
贝克兰德乔伍德区希望路22号帽子戏法旅店。肩膀宽阔胳膊粗壮多里安·格雷·亚伯拉罕不自觉地在房间里来回踱步等待着学生佛尔思拜访。再是坦然再是做好心理准备在真正需要面对答案最后关头他还是免不了有点紧张和忐忑。不知过多久房间门口响起笃笃笃敲击声。多里安侧耳倾听几秒间隔节奏然后深深吸口气走至门边拧动把手向后一拉。门外正是褐发微卷穿深色长裙戴有色玻璃眼镜佛尔思。多里安习惯性看佛尔思身后确认无人注意这边才让开位置任由学生通过。与此同时他瞄眼佛尔思双手发现自家学生并没有提行李箱。多里安随即收回视线走到房间中央找个位置坐下然后指指对面沙发：坐吧。佛尔思颇有点拘谨提提裙子坐下来并顺势问候：上午好老师。多里安没直接步入正题思索一下：你们真杀死布提斯？嗯。佛尔思从衣物暗袋内拿出一个精致修长卷烟盒将它打开向多里安展示里面事物。那是两颗瞳色深黑眼珠凝固着难以言喻惊恐似乎在死前看到什么极端可怕东西。多里安本来做好心理准备像上次一样收到一个血污碎片拼凑起来让人做噩梦恐怖脑袋谁知学生竟没有提行李只是拿出女士卷烟盒。这让他以为里面是能证明布提斯身份遗物但事实又一次出乎预料：这依旧是布提斯尸骸但比路易斯·维恩那次残留更少！只剩一对眼珠了……占星人灵性直觉让多里安相信那眼珠确实属于布提斯。见老师陷入沉默没有开口佛尔思下意识解释：他身体已完全崩溃消散只有这对眼珠还算完好。她顿顿又道：这眼珠里有残留布提斯死前惊恐情绪和来自旧日之盒污染是很强诅咒物所以我没直接寄给您那会让经手邮差们遭遇不好事情甚至不知不觉死去。旧日之盒污染……多里安有所恍然点头叹息着笑：他最终是死于旧日之盒吗？这真是宿命啊……当初布提斯反叛引来极光会人抢走第一件物品就是旧日之盒。佛尔思有在分配战利品私下聚会里听隐者女士和正义小姐讲述大致经过明白自己错过战斗有多么华丽和惊险此时想：算是吧……不过他在被旧日之盒污染前已经开始失控。多里安不觉意外对自己学生：收起来吧这是属于你战利品。等到佛尔思合拢卷烟盒将它放回暗袋多里安前倾身体交握双手抵下鼻子：布提斯是我见过最有学徒天赋人之一谁知最后变成这个样子……说到这里多里安长长叹口气似乎在缅怀什么忏悔什么。佛尔思并不太了解当初那些事情细节不敢贸然开口只能保持沉默等待老师自己从情绪里走出。过十来秒多里安直起身体转而问：你是怎么消化掉记录官魔药？这不仅仅是在关心学生也是在积累经验为家族其他成员教导学生提供一些参考。佛尔思表情顿时变得有些复杂仿佛回忆起什么不想回忆事情：主要是有人提供帮助一方面让我记录了许多或奇特或高层次能力一方面带着我在几个月内去多个地方记录不同民俗和美景……多里安一阵默然点头：这不是好模仿……他随即问：格尔曼·斯帕罗？嗯。佛尔思做出肯定回应。多里安又沉默下来隔几秒才道：他想做什么样交易？或者说他想得到什么？佛尔思打起精神颇有点不好意思：他想要旅法师魔药配方并且用旧日之盒换你们手中两件0级封印物之一。这个价格绝对厚道佛尔思原本以为世界先生是要用承诺直接换取旅法师魔药配方和0级封印物没想到还附加旧日之盒。当然让亚伯拉罕家族摆脱诅咒这个承诺对多里安来说肯定值那么多但承诺永远只是承诺未必能实现。多里安对格尔曼·斯帕罗索要0级封印物并不感觉意外早有一定心理准备反倒认为这条件优越到超乎想象毕竟到今天亚伯拉罕家族还能让一位半神觊觎东西并不多了。他微微皱起眉头：他要旅法师魔药配方做什么？不知道。佛尔思坦然回答。多里安站起来开始踱步。突然他停止下来望向佛尔思：我需要与他见一面谈一谈才能下定决心。好。佛尔思一点也不为难答应下来。多里安暗自松口气准备送学生离开然后快速取出药剂服食。——他约这个时间点见面就是算着自己诅咒即将爆发真有什么意外敌人肯定来不及通他灵。可佛尔思起身后却没有走向门口她立在原地向前方虚空中抓一下。她手臂猛然一沉飞快后拉拖出一道穿黑色风衣戴丝绸礼帽身影。这身影黑发棕瞳轮廓深刻线条冷硬正是格尔曼·斯帕罗。格尔曼·斯帕罗眼珠微动迅速摆脱呆滞变得与真人无异。老师他来了。佛尔思郑重介绍：他就是格尔曼·斯帕罗。这番操作看得多里安嘴巴微张忘合拢短暂竟没做回应。——虽然他出身古老家族掌握许多隐秘但碍于本身只有序列7许多事情即使看到描述也无法真正想象。克莱恩意识转移过来后将手伸入衣物内侧拿出一块金壳怀表。啪他按开怀表看一眼不带一点感情对多里安：你有三分钟时间。……和传闻一模一样冷峻高傲疯狂……多里安没敢耽搁时间直截了当：给我一个相信你承诺理由。克莱恩合拢怀表边将它放回衣物内侧边开口：其实我已经掌握让门先生回归仪式。多里安眼睛一亮就要脱口询问却听见格尔曼·斯帕罗平静补充：但我不打算这么做。为什么？多里安和佛尔思都一脸疑惑只不过一个敢问一个不敢问。克莱恩看眼窗外：你知道源自星空污染吗？除开真神和天使论起对星空了解亚伯拉罕家族绝对排名第一克莱恩相信他们必然有留下一些暗示和隐晦记载。多里安郑重点头：知道。我怀疑门先生有被星空污染。克莱恩简单解释：至于我承诺它现在就有实现办法只是你们未必愿意而且那并没有彻底解决诅咒。什么办法？多里安忍耐住澎湃激动心情追问。克莱恩表情一下变得严肃：你和你家族成员们都改信我主那样一来圆月和血月时你们将得到庇佑不再被诅咒困扰。彻底消化完古代学者魔药后克莱恩已无需通过将人拉入灰雾之上来规避门先生呓语可以直接利用天使之拥解决目前唯一需要烦恼是亚伯拉罕家族人可能比较多忙不过来或者灵性不够。……你主是哪位？多里安沉默一下开口问。克莱恩压制住羞耻之心庄严：伟大愚者先生。愚者……你们是安提哥努斯家族人？多里安霍然有些联想。克莱恩摇头否定对方猜测。多里安再次沉默但考虑到只有三分钟时间忙又问：信仰了那位就能让我们免受诅咒困扰？作为古老家族成员他很清楚信仰一位未知存在有多么危险害怕解决门先生呓语又背负上别诅咒。克莱恩坦然：这只是暂时性解决我会给你们找到更好办法。多里安点头抓紧时间：我会试着信仰你们主并将旅法师魔药配方给你如果这真能暂时解决诅咒我们再完成0级封印物交易。他打算以自己做实验体看那个办法是否有效并且不准备告诉其他家族成员让他们等待格尔曼·斯帕罗口中更好办法直到等不下去。好。克莱恩从衣服口袋内拿出纸笔刷刷写下愚者尊名。而多里安也开始用水晶球辅助回忆记录下旅法师魔药配方。交换之后克莱恩直接就将目光投向辅助材料和仪式部分：辅助材料：星之虫一条时之虫一条灵体之虫一条。晋升仪式：在这个星球外九个地方留下传说。

## 这场戏有没有翻
翻了。开头还在旅店踱步等学生；章末三分钟谈判定案：先信愚者换配方，暂缓0级交易，旅法师仪式＝星球外九传说。翻的是决断落地成半成交，不是怀表厉不厉。

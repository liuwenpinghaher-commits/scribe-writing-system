# 1210 逐光者 第六十一章 想象不出

## 打开书
马车在路上缓缓行驶奥黛丽视线不自觉又投向窗外。不少行人站在路边盯着拉车马匹眼中仿佛冒着绿光成功领取到食品幸运儿遮遮掩掩穿过街道奔向自家所在地方。一队队穿黑白格制服警察巡逻于街上腰间别着左轮手里提着短棒震慑着一个个想冒险家伙。最近我们都不敢独自上街了……奥黛丽旁边贴身女仆安妮小声嘀咕。奥黛丽轻轻颔首未做回应。过一阵马车来到佩斯菲尔街停在圣赛缪尔教堂门前广场边缘。那里成群白鸽已不知去向一片空荡。鲁恩慈善助学基金和之后成立鲁恩济贫基金鲁恩医疗慈善基金都从佩斯菲尔街22号搬迁到教堂内部几个小房间因为原本所在建筑在前段时间空袭里倒塌。对这三个基金会工作人员而言那是一段惊险回忆若不是各自因不同缘由提前离开佩斯菲尔街22号早就成为遇难者。走下马车通过大门奥黛丽看见一位黑发褐瞳脸型偏瘦少女迎过来。不等对方开口她主动：梅丽莎还有食品可以发放吗？梅丽莎表情沉凝摇头：就连我们救济那些伤残士兵都领不到足额食品了……奥黛丽碧绿眼眸黯淡一下没表现出自身无奈和软弱微微点头：我会想办法。……来自白银城……来自被诅咒之地外……格尔曼·斯帕罗话语回荡于阿达尔辛和鲁斯等月城狩猎小队成员耳中让他们恍然如梦久久无法回神。就在阿达尔逐渐找回理智斟酌着想说点什么时候天生没有鼻子辛已激动发出一连串问题：白银城在哪里？是什么样子？离这里有多远？诅咒之地外面还有多少正常人？克莱恩扫她一眼用不含感情声音回答：白银城在这片被诅咒大地另外一边他们发现一种可以正常食用植物叫做黑面草这让他们维持住族群稳定能有效探索黑暗深处寻求离开办法。他们最近又找到一些蘑菇这些蘑菇能以怪物血肉为养分结出各种不含毒素和疯狂果实。白银城进一步摆脱疯狂等到新生代长成就算年迈也不会那么容易失控了……这些话语听得阿达尔和辛他们怅然若失仿佛自身坚持不再有任何意义。格尔曼·斯帕罗描述白银城生活就是他们能够想象最美好场景而别人简简单单就拥有。他们新生儿里有畸形者？辛用梦呓般口吻问。克莱恩摇头：几乎没有。他们父母会在身体状态下滑不年老后自己走入黑暗深处吗？阿达尔下意识跟着追问。穿黑风衣戴礼帽提马灯克莱恩回答：不会。因为他们背负着弑亲诅咒一条生命如果不能在血脉亲人手里终结将异变成可怕恶灵或者怪物。月城狩猎小队队员们终于找回一点真实感内心就像慢慢升温湖水逐渐冒出一个又一个气泡。这些气泡脆弱空洞一戳就破里面实际上什么都没有但却闪烁着某种叫做希望和光明东西。两只眼睛近乎挤一起鲁斯忍不住重复辛后面那个问题：诅咒之地外面还有多少正常人？克莱恩目光略显复杂看着他们：基本是正常人不用时刻担心怪物袭击不用害怕置身黑暗不用在年老后变得疯狂不用背负各种诅咒每天起床都能看见阳光每天食物都足够正常每晚都有红月升起……但是这一切现在都在遭受着破坏……克莱恩默默于心里补一句。这一次阿达尔辛和鲁斯等人都有些茫然因为格尔曼·斯帕罗描述画面他们似乎能想象又似乎不能想象就如同他们阅读残留不多古代典籍时可以领会到一定精神却难以真正理解某些内容一样。什么是太阳什么是红月他们根本没有概念。不过每天都是正常食物不用背负各种诅咒不用总是担心怪物袭击不用害怕置身黑暗不用在年老后疯狂是他们日夜渴望美好。这个世界还有这样地方？这就是古代典籍里记载天国吗？这片大地真被诅咒了吗？月城狩猎小队成员们又一次陷入沉默。他们之中有人张张嘴却不知道该问点什么有人想要带格尔曼·斯帕罗回月城将这个消息告知大祭司告知所有人却又害怕引去危险。这个过程里他们始终没有放弃戒备放弃警惕。对于他们这种态度克莱恩一点也不觉得意外反倒认为这是能延续到现在神弃之地文明该有表现。他提着马灯向左侧迈步试图绕过这些或围兽皮或穿奇怪材质衣物人类继续往东。无论这些人有什么样故事是否值得顺手帮一下他都打算等一会再调查再倾听再考虑因为他灵性直觉告诉他目的地已经不远传说中西大陆就在前面两三小时路程处。克莱恩刚一迈步阿达尔等人立刻弯下腰背做好防御和攻击准备但他们没能等到格尔曼·斯帕罗靠近看着他向左行十几米折而前行。眼见这位穿奇怪黑色衣物戴奇怪黑色帽子提奇怪透明灯笼年轻男子渐行渐远昏黄光芒越来越小脸上长不少肉瘤阿达尔表情变幻几下高声喊：你究竟是什么人？克莱恩没有转身提着散发出昏黄光芒马灯边往黑暗深处走去边正常开口：一个传教士。传播我主光辉人。阿达尔和辛等人互相看一眼表情里透露出都是困惑。他们犹豫好一阵就在那昏黄火光几乎只剩一点时全部本能迈步跟在克莱恩身后。他们不敢靠近又不想脱离就这样背负着之前狩猎来食物似监控似防备似追随沉默迈步而克莱恩走得不快不慢保持着大致速度没去等待也没尝试甩掉。就这样两边都极为安静在稀疏闪电下行走着不知什么时候鲁斯和另一位狩猎小队成员脱离队伍拿着兽皮灯笼和收获食物转个向无声消失在看不到边际黑暗中。时间一分一秒流逝克莱恩终于停下脚步。借助划过天空闪电他看见几百米外凝固着一片灰白雾气。这雾气连接着大地一直蔓延到高空仿佛没有顶部。同时雾气向两侧延伸着漫无边际。克莱恩专注看好久哪怕中间有黑暗隔断也一直缓慢仰头往上在第二道闪电平息后才收回视线。这雾气之后或者之中就是消失西大陆？克莱恩心情凝重想着呼吸都忍不住放慢一些。他提着马灯继续前行一直到那昏黄光芒都能照出凝固雾气。无需做别尝试克莱恩占卜家直觉就告诉他那片灰白雾气是无形屏障不是常规方法能够通过。他想想伸出右手向斜前方黑暗里抓一下又一下。连续四五下后克莱恩从空气内拖出一根镶嵌着多种宝石黑色手杖。这是星之杖被克莱恩用旧日之盒交换来编为0-62恐怖封印物！当然克莱恩目前只是召唤出星之杖历史孔隙影像。这样一来即使他脑海内有不需要画面呈现即将有相应效果激发时他也能通过解除对历史孔隙影像维持及时中止危险。对一名古代学者来说这是日常使用0级封印物最好办法只是时效有限目前不能超过三分钟而且效果和原版有一定差距——用秘偶持握星之杖是无法规避负面影响因为秘偶需要操纵有操纵就大概率有画面传递。当然如果进行有准备战斗克莱恩不会这么做因为那将占据他宝贵三个召唤名额之一而且星之杖虽然目前已属于他但只是强迫属于处在封印状态再加上这0级封印物本身位格相当高克莱恩没法一次就召唤成功往往得三到六次不等在激烈战斗里这需要足够机会不是那么容易。正因为如此做有准备表演时他会提前催眠自己在特殊状态下使用星之杖把召唤历史孔隙影像机会留给信使小姐阿兹克先生阿里安娜女士威尔·昂赛汀等熟悉天使。拿着那镶嵌各种宝石黑色手杖克莱恩脑海里自然浮现出一幕虚幻之门缓慢打开场景。手杖上宝石随之闪过微光灰白雾气表面飞快勾勒出一扇不够真实大门。这大门无声敞开后面依旧是灰雾。开门不行……克莱恩对这个结果不算意外但依旧有点失望。他想想准备换个方法。可是就在他想时候星之杖随着画面呈现自行激发了。

## 这场戏有没有翻
翻了。开头还在奥黛丽战时粮荒问梅丽莎；章末月城人想象不出阳光红月、自认传教士、抵灰白雾、0-62开门失败自行激发。翻的是「想象不出」与「门打不开」双落，不是星之杖厉不厉。

# 398 无面人 第一百八十六章 被污染者

## 打开书
戴里克看染血头皮忆诱菇；杜姆＝人指——胃痉挛酸液涌喉。忍呕公鸭嗓唱：「神啊，求您的国度降临…」歌颂者力——不适平灵性充勇气力敏升。达克愈非人连问三遍「你身上是什么东西」！衣撑条凸如毒蛇；血淋淋肉条穿黑衣带体毛粗皮——血色软毛刺猬！肉条奔涌。戴拧腰飓风斧砍断数条；夜无闪电；更多肉条缠斧死不放。眼亮纯净光如小太阳；另手虚握嘴鼻祈——焰明净光柱落焦肉条；惨叫断裂跳有生。肉条失控灵性融仪咒自然力→淡红波浪投入烛火膨胀→虚幻神秘门！烛上早绘愚隐秘符——简步完整献祭！喀嚓椅碎达克扑渴求炽热无惧。灰雾克响应——门缝后深沉黑暗透明影；高处七色净光；上灰雾古殿。阴角影蹿覆达克——肉条被漆黑黏液裹如袋中猫；影延向戴厉呼「停止！你要做什么！」监本旁观至不可收拾；见门缝震慑邪神感——边通知边强断献祭。戴早选远离端；影须先控达克（异不可留背）。趁机铁盒扔门缝——哐当合消失。戴记倒吊嘱扭曲脸狰狞迎影；覆前剧咳捂嘴倒地。影裹成两黑蚕蛹。黏液缩回影；戴昏手落十二环虫；达克成血肉团蠕嘶将攻。监再裹怪达克；见指头头皮吸气；影潮通知首席；审视虫：「阿蒙分身死了？」猜：阿蒙与污达克幕后死敌不惜分身；训场观察／举报皆阿蒙尝试；幕后派达克控戴——头皮指道具。认同首席忧：末日或更大灾连续诡异。切圆塔：影原原本本述。科林颔：「戴／阿蒙确预谋——符烛／邪物／倒水祷／献祭送物。」两问：符指阿蒙本体或背后神？为何弃分身暴露探索异常——死敌？安静四十二年何为？或预言特遇探索寄宿破帷幕图——四十二年等此刻？影恍：「于德尔失控因预言时近急换自由寄体！」科林：只盯戴异常未想时间点。影请立刻控探索全员＋洛薇雅或污！科林皱：达克出门前洛薇雅已来——疑队员被污建议暗监必要时值守哈维克倒立陵寝（前首席入陵门永闭）。影愕：「洛薇雅早提？」「无问题就好…」科林：「已派人控队员；亦勿忽他可能。让艾芙洛来——我与她一起审问戴里克·伯格。」

## 这场戏有没有翻
翻了。开头撕面后战斗；章末铁盒入门毁证、十二环虫落地、首席按「阿蒙死敌」误读、洛薇雅反先举报、将审戴。翻的是计划成功能嫁祸，不是审问结果。

白银伯格家夜；圆塔首席室。

无镑；监误读成阿蒙牺牲分身。

## 话
「你身上的是什么东西！」×3「停止！你要做什么！」「阿蒙藏在戴里克体内的分身死了？」局面是从刺猬肉条收到门缝毁证；从虫落地收到首席误读。

## 热怎么变冷
歌颂光柱还热。冷切在门合盒消。阿蒙死敌猜还热。冷切在洛薇雅早举报。

第一段头皮回忆。最后段艾芙洛来审戴。章题：被污染者——达克怪＋误读。

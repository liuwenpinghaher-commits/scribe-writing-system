# 1316 倒吊人 第五十一章 “傲慢”

## 打开书
这是什么地方？奥黛丽神情没太大变化问道就像在询问今晚舞会地点。自称心理炼金会会长鲍利·德尔劳同样将目光投向窗外微笑说道：这是每个人心中城市。有人地方就有它。……也就是说可以从人类社会任何一个角落进入这里？对。……这里一切都有着相应心理学象征他们叫做兽欲。……那一个个行人里除狼人还有直立行走熊有神情慵懒猫有脸部是一只斑斓蜘蛛怪人……马车行驶于黯淡夜色下穿行在这一位位行人和各种各样哥特式建筑间很快就抵达城市最中央一座教堂。……请坐。……奥黛丽小姐我有些事情想问你。请讲。……我想知道你是怎么晋升序列4操纵师你魔药配方和非凡特性是从哪里得到？来自一场交易。有位委托者希望得到观众途径半神帮忙预付操纵师魔药配方和非凡特性。……竟然有这种事情？条件宽厚就像是一位父亲在找借口给自己女儿礼物。能告诉我你具体提供什么帮助吗？围杀另外一位半神。在这件事情里精神方面控制相当关键。……成功了？结果很明显。……我只是其中一个参与者。……你知道那位委托者操纵师魔药配方和非凡特性来自哪里吗？他并没有直接说明这个问题。……他？你能告诉我他是谁吗？……这涉及我和他约定我想信守承诺应该是一个全世界都认同道德标准而在神秘学里这更是牵涉很多。……如果因为这个问题隐瞒你们无法真正相信我我愿意接受。我可以只做一名普通成员用自己贡献换取我能换取心理学研究资料。……每个人都有自己秘密这很正常我需要评估是你秘密是否会影响到整个心理炼金会安全运转。……那你可以告诉我你是怎么认识这样一位委托者吗？我记得我曾经向你们报备过在加入心理炼金会前我已经在神秘学圈子里接触一些人认识几位非凡者。……还有一个问题你最后一次见到赫温·兰比斯是什么时候？……我需要当面再确认一次。……我最后一次见到赫温·兰比斯委员是在格莱林特子爵府邸内……那天之后我再也没有见过他。……这不仅没让奥黛丽感到轻松反而愈发警惕甚至不敢去想愚者先生和世界格尔曼·斯帕罗相关任何事情。她只确信一点：只要自己有暴露危险愚者先生肯定会提供庇佑。……和之前回答一致。……我无法用神秘学办法追溯出你体内那份非凡特性来源这说明那位提供者背后有着超乎想象存在。……我不能强迫你不与别非凡者合作交易……我只希望你承诺一点不向任何人透露心理炼金会有关事情……我承诺不将心理炼金会相关事情告诉不具备对应权限生灵。……由于这张限制之网出自奥黛丽本身灵性哪怕她成为天使也将无力清除……从现在开始你就是心理炼金会评议团委员了。你可以选择一张人格面具作为自己代号。……剩下两张人格面具一张是暴怒一张是傲慢。德尔劳介绍道它们来源于第三纪那位造物主圣典。……我选傲慢。……这也是当初赫温·兰比斯选择。

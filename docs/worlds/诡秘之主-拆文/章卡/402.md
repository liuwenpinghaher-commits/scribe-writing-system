# 402 无面人 第一百九十章 私家侦探的宿命

## 打开书
死了？威尔死且似已久？假？克惊疑——威尔自带特殊或缠水银之蛇序1；占卜游／「运气变差」害艾伦久；千纸鹤定星灵灌启；灰雾难窥行踪——怎莫名死于梦前？亲人？忍恶审视腐尸——周围泥撕碎塔罗牌；灵直觉大概率真威尔。震惊费解——回头雾上确认假死？又：与我何干？早决不深掺防水银蛇缠或甚0-08。猛回神：「报警！」守墓人迭声跑如有活尸追——普通人不慎露背易被铲拍（卷宗同伙坑）。扶艾伦：「已死无惧。」「就是死了才怕。」礼服沾泥心疼值钱。笑：「向神祈祷有用。」艾伦绯红月祷女神缓。克画三角圣徽无声：「蒸汽与机械…一点也不虔诚的信徒…」疑被雷劈——雷属风暴不属蒸汽轻松。二十余分警局录口：克坦然私探不知；艾伦详梦挖因。警初不信转圈后改态无嫌签字可离——值夜出面；先教堂好处。出门见入梦值夜灰风衣蓝眸扫过装高级督察；克推镜戴帽装普通侦探离。马车上艾伦：「事止？」「若真威尔应不再困。另觉古怪？」无。「值得庆贺！」——案或死路卷宗暂结防红手套奇想。艾伦疑口供何信？克装傻律师保释。艾伦勾嘴：「进警局经验丰富？」克深沉：「这是每一位私家侦探的宿命。」切同刻佛黑裙网纱入格林墓园安丽萨墓。一小时前格莱林特愿借400无息——唯一要求：今晚陪A先生聚会护安全；急皇冠水母毒液结晶完药师。独角飞马角奥黛丽宝库出抵债；附条确认尼根巨龙标本是否千面狩猎者／光点。不急求愚成交——太迅休疑。空闲西区墓园谢安丽萨：知守恒后明学徒主材＝其特性继承。初冬温室素雅贵花谢罗塞尔。碑前放花「谢谢」闭眼忆。苍老声：「又善良又好心。」劳伦斯亚伯亦持淡雅花！「非善良——安丽萨给失母温馨。」眼润。劳叹重视情谊。闲聊告辞——劳剧咳发软倒地似窒息。医佛急救稳；劳擦唾笑：「送我回旅馆？」搀起；眼失焦半悲半嘲：「我的生命也许已经走到尽头了…」

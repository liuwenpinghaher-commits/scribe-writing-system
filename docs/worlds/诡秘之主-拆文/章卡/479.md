# 479 无面人 第二百六十七章 诚实的回报

## 打开书
石柱断折大厅——残骸祭坛周围一群黑风衣丝绸礼帽值夜者；为首黑夜女神教会贝克教区大主教圣者安东尼·史蒂文森。「被人破坏了？」低语未再停——直接来内侧石门前。浓郁黑暗浮现石门无声敞开；圣安东尼领部分值夜者入往深处。沿途无一名守卫任何有价值事物——仿佛被强力清扫一遍。终于最深房间——除墙壁石柱依然什么也没有；克出来时幽蓝光门早已消失。几位值夜者手中马灯突失光；黑夜笼罩房间。等恢复——四周墙壁不知何时消融不见；后方未有暗门地道；要么厚实泥土石块要么来时走廊。圣安东尼沉默十几秒开口：「尝试占卜。搜索附近。」……阿嚏！克穿行无道路峭壁树林——悲哀发现自己似乎真病了。A非凡能力残余＋冬日浑身湿透——可耻地感冒了。不敢停留搜集枯枝点火烘衣晾钞票——怕被教会非凡找到。哪怕已在机械之心经斯坦顿·艾辛格背书获半官方身份；事涉原初魔女苏醒真造降临两件最高等级案——必接受严格调查：轮流机械之心代罚者值夜者品尝红茶主动或被动复述全部过程。两大隐患：一值夜者内有熟人；大侦探夏洛克·莫里亚蒂长相与殉职克莱恩·莫雷蒂有不小区别靠照片几乎无法分辨；真面对面仍没什么信心；二相近途径缘故黑夜教会对死神有关人与物不太友好——上溯四纪末苍白年代死神陨落七神围攻下；夏洛克关键召唤帮手却是强大死神后裔——怎么都洗不掉。刚才位格极高强者也许赶着处理因斯与0-08没空理友方小角色；但不能大意该跑还得跑！有机会可写信机械之心阐述不得不暂离贝克第二原因；以后说不定还能合作；须先暗中观察机械之心是否对死神后裔抱强烈敌意…不知阿兹克先生现在怎样…呵呵也许官方通告里夏洛克死于陨石天降算没辜负这身份姓名…忍发烧寒冷交替想尽快找小镇进入人群。只有人类社会无面人能力才能发挥极致。与A合作那女人额应是魔女去了东区…从仪情况看那边恐怕大规模死亡不知…占卜家灵性直觉忽然心头沉甸甸。就这时眼前所有颜色变浓郁像被神灵泼洒油彩。感觉一闪而逝——发现己已远离原位置；见肤色古铜五官柔和阿兹克出现旁边。「阿兹克先生您没受伤吗？」难遏制松口气。「有。」坦然旋即笑：「但对不死者而言这不是什么大问题。」放下心转问：「因斯和0-08呢？」「因斯还活着仍执掌那件0级封印物。」边走边说。努力跟上忍不住叹：「真是可惜啊。」「不用在意他受了不轻伤。」郑重：「更关键我们知道了他在和王室秘密合作不用担心之后找不到他；这样一来你可以专心提升自己；我也能先试着去已回想起来几个地方唤醒更多记忆。呵呵你运气不错我一直暗中观察军情九处和王室人想以此确定因斯行踪；这里面红蔷薇庄园是重点所以我总在那附近徘徊否则没那么快赶来救你。」说起这事顿时有些尴尬：「阿兹克先生您不疑惑我为什么没死的问题吗？」「我也常常进了棺材又苏醒这是我之前回想起来的事情。」毫不在意笑：「而在我残缺记忆里类似事情在别人身上虽然罕见但也不是没有先例。」常常进棺材又苏醒…常常？突然发现担忧问题在真正大佬眼中都算不上事情。不愧死神途径不死者…额先生之前说曾在这序列停留很久言下之意早晋升…想了想有些忧虑问：「因斯会不会发现我就是克莱恩·莫雷蒂？」怕对方报复班森梅丽莎。「他应该没有最多认为我们早就认识或者你干脆就是我的…用警方说法是我的线人。」回想：「但那件0级封印物可能会察觉不过你不用担心。」「为什么？」追问。阿兹克不知记起什么神色忽然古怪似乎又想笑又感觉惊悚：「那件0级封印物会一直尝试写死自己的主人这应该是它的本质不会改变；所以这种关键时刻能让因斯吃大亏的信息我不认为它会主动透露除非涉及绕不过去没法解释的地方。」见说得如此笃定有理有据吐口气感冒都仿佛好一点。阿兹克见状补一句：「你近期最好远离贝克；因斯可能会用那件0级封印物报复你依靠你的假名。只要不在贝克就没有问题；那件0级封印物影响范围不会超过一座大都市。」和我猜测一样有范围限制…否则因斯完全可躲南陆某小镇悠闲安排所有目标命运根本不用担心被人找到…斟酌问：「短暂回贝克待一天或半天没有问题吧？在变换身份容貌前提下。」说完揉脸瞬间变回廷根时样子。阿兹克眉毛微动点头：「问题不大。」回首望已看不见远处一眼：「我似乎被黑夜教会强大存在盯上了；你最好不要跟我身边以免遭受波及；呵呵他们对死神有关非凡特性很感兴趣。」「嗯我准备出海一边消化魔药一边寻找美人鱼这是我晋升需要条件。」阐述计划。阿兹克侧过脑袋：「美人鱼？变成了死灵的美人鱼可以吗？我至少能找到四条。」「应该不可以吧…」伸手抹额。直觉告诉肯定不行；打算之后还是灰雾上占卜确认。阿兹克没再提死灵美人鱼转而：「有什么事情通过信使联系。」信使…突然心虚惭愧：「它它在我和A战斗里阵亡了它救了我一命。」阿兹克看一眼摇头笑：「不用在意只要不是被天使级强者杀掉或者用特殊办法只要冥界还存在它都能在那里缓慢重生。而在此之前类似信使有有额我也数不清有多少。」看起来那么强那么巨大信使有一个军团？张嘴说不出话。羞愧消散不少好奇问：「冥界也就是地狱究竟在哪里？」「灵界准确描述是它是远古死神在灵界内开辟出来的特殊地方。」无隐瞒。远古死神？应是不死鸟始祖格蕾嘉莉这位古神…原来冥界从属灵界难怪神秘学基本架构现实－灵界－星界不包含冥界和深渊…正要询问有关——忽然记起一事连忙：「阿兹克先生我获得一张罗塞尔大帝制作的亵渎之牌里面包含高序列秘密我认为它能帮助你唤醒更多事情不过你得等待一阵它藏在贝克。」没提悬赏怕泄露塔罗会灰雾正义小姐秘密；只能委婉感谢帮助付出。阿兹克略感诧异望一眼最终什么也没说轻轻颔首：「等你取回让信使带给我我研究之后就立刻还给你或者你直接抄录相应内容给我。」顿了顿似乎也想起什么——从衣兜拿出一只轻薄仿佛人皮制成手套递给克：「有关记忆我已唤醒不再需要它；呵呵它是那个海盗中将遗物我有做一些封印让它平时不会饥饿；但每使用一次就必须用一个人类血肉和灵魂喂饱它否则它将吞噬你。」…蠕动的饥饿？源于某位牧羊人死后遗留？当即回想起那只手套代表什么。

# 518 旅行家 第三十七章 命名

## 打开书
金黄液体冰冰凉凉让奥黛丽就像在享用美味冰淇淋随即又喝了口香槟有细小气泡不断腾起无声炸裂带来微麻刺激。听力忽然蔓延开来连走廊尽头两位女仆在遗憾没机会去东切斯特郡霍尔家族城堡和庄园交谈都能听到。这一刻觉得自己溶解成虚幻气体并飞快往外膨胀占据满整栋房屋与每个人心灵意识组成海洋交叠在一起。视线也发生变化看到一切都异常光滑成为另类镜子照出她现在模样。纯美精致大气灵动等单词描述美貌下她裸露于外皮肤在缓慢长出一枚枚金色鳞片碧绿眸子收缩染上淡金色泽仿佛被竖起来。看到这样自己突地生出发自内心恐惧不想也不愿意变成非人怪物！嗡一声脑海开始模糊体表似乎有什么东西在缓慢疼痛地钻出。这时听见金毛大狗苏茜柔和声音：「不要害怕冷静下来。不要害怕冷静下来。」找回思绪竭力让自己进入观众状态。起伏情绪飞快平复下来灵似乎抽离出身体观众一样俯视着自己。看见体表金色鳞片在明显消退看见绿宝石般眼睛变得正常。没过多久重新掌握身体并明白心理医生都有哪些非凡能力以及如何使用。刚才刚才真的好危险…后怕抬手只见肌肤白嫩细腻哪还有刚才异状。经过这件事情真正理解愚者先生偶尔提点倒吊人先生总是强调失控危险有多么可怕深切认识到超凡之路艰难。即使有扮演法也没可能彻底排除掉隐患！有次聚会里世界先生说过非凡者是时刻对抗着危险和疯狂可怜虫…我之前只能从字面意义上理解现在终于感受到这句话背后重量…奥黛丽不要气馁不要害怕爸爸妈妈哥哥还等着你保护有了这次经验以后就不会再被自己吓到不会那么容易濒临失控！加油！握握拳头给自己鼓劲。平静两秒走到苏茜面前半蹲下来抱住这只金毛大狗边梳理对方毛发边用脑袋抵着狗侧脸在那种温暖里喃喃自语：「谢谢谢谢…」苏茜蹭两下认真说：「奥黛丽这就是心理医生感受吗？我很喜欢。」…忽然有些哭笑不得旋即抿下嘴承诺：「苏茜我们以后互相治疗嗯心理问题！」「好的汪！」苏茜开心回应。直到这时候才真正恢复有心情审视自己获得提升：「我身体好像变得更健康了虽然没有明显肌肉但力量和速度都比以前强了不少…我视力又有提升连藏在黑暗里物品也能清楚看到…我嗅觉能分辨更多细微气味了从而把握住目标最真实情绪和想法…我终于有真正意义上非凡能力了唔一个是震慑可以对单个目标也可以对一个范围内群体让他们就像面对巨龙瞬间惊慌出现混乱；一个是狂乱引爆目标情绪或心理状态让他陷入狂乱之中遭受精神层面强烈伤害某些时候甚至会让目标直接失控；一个是心理暗示通过特定动作特定语言特定媒介暗示目标让他不知不觉就遵循我安排或者强烈发自内心地不想违背某个承诺；一个是安抚也叫精神分析可以让处于失控边缘非凡者找回理智摆脱危险景况这有一定失败概率序列越高越容易成功也可以让因各种缘由心理不稳定患者平静下来能够沟通；一个是真正读心通过烛火纯露等媒介让目标处于半催眠状态直接与他心智体交流就像希尔伯特·阿鲁卡尔德先生对我做那样如果没有愚者先生天使提供保护我没办法在那种情况下撒谎唔…以后我得提防类似技巧不能被目标欺骗应该还有不少办法可以达到那种效果…有了安抚和读心再加上一定心理学知识我就能扮演真正心理医生了可以开诊所那种！」心情迅速好转终于有了自己已成长起来是合格非凡者感觉。我是中序列非凡者了！果然有质变！站起来提起裙摆脚步轻快绕一圈。很快发现一个问题那就是心理医生依旧缺乏直接攻击能力。还好我有它…停在实验桌前打开一个很普通棕色盒子。盒子里面摆了张银色面具只能遮住上半张脸那种正是倒吊人卖给她那件神奇物品。将它拿起放在掌中观察几秒。然后蔓延出灵性像在灰雾之上那样给予对方一定想法。看见银色面具开始内卷化成一只中间镂空花纹精致略显巨大耳饰。「可能变成项链会更好。」低语一句。接着充满收获感尝试起这件神奇物品各方面能力对微调容貌这点最为满意。「可惜除了操纵火焰它也没有更多更直接攻击能力或许我得再准备一把手枪有非凡效果那种…」略感遗憾想着。迅速收敛心绪对着手上神奇物品尾音上扬说：「从今天开始你名字就是谎言最美丽的谎言~」……慷慨之城拜亚姆码头区酸柠檬街48号蔚蓝之风旅馆。外面雨水如注暴风肆掠豪华套房内却壁炉温暖环境安雅。克坐在椅子上沉默看着烈焰自己处理左臂严重骨折。等对方用撕成一条条旧衣服绑好手臂才直截了当开口：「什么宝藏？」根据达尼兹说法正是因为某个宝藏血之上将塞尼奥尔才想对付冰山中将艾德雯娜。哗啦啦风雨声透窗传来达尼兹喝口桌上烈朗齐又愤怒又苦涩笑：「那帮脑子被活尸啃了家伙！我们在上一次探险里找到一艘沉船虽然没收获太有价值东西但却发现一把不像人类使用巨大黑铁钥匙。你能想象吗？沉在海底那么多年它竟然没有生锈。」「能。」言简意赅回应。在超凡与神秘交织世界里什么事情不可能？死而复生都有更别提其他！达尼兹一下被噎住缓了七八秒才知道怎么往下说：「我们内部或许出了叛徒这消息被传扬出去无数海盗相信这是死神钥匙是可以打开那个死神遗留宝藏钥匙。我原本以为这问题很快就能澄清愉快申请休假结果事情变得更加复杂连血之上将都加入那些疯狂海盗行列我都有点怀疑那或许就是死神钥匙一把可以让人成为真神钥匙。」「愚蠢。」冷静给出评价。无论在占卜领域还是与神灵打交道上面都称得上经验丰富所以对死神钥匙有着属于自己解读并且很有信心。认为钥匙是一个启示一种象征打开死神宝库大概率不是钥匙形状东西而是某种特性某种血脉甚至是特定某几个人及他们后裔。达尼兹怔两秒油然感叹：「你话和船长之前评价完全一致就连表情都很像。她怀疑那把钥匙属于更古老年代不属于人类。在大灾变前这世界上还活跃着巨人巨龙精灵魔狼等生物那把钥匙形制隐约指向它们之一。」魔狼…忽然想到之前总在晋升时回荡于自己耳畔呓语里面弗雷格拉指就是古神毁灭魔狼。涉及第二纪元宝藏？按捺住好奇转而平静说：「将血之上将做过事情全部写出来包括钢铁麦维提和他手下。」记得血之上将和他海盗团是大洋上最臭名昭著群体可以说满手血腥罪恶深重。「我怎么可能记得住？他们又不是船长那样美女！」摊手说「我只能列最主要事迹以及我印象深刻一些细节嘶你想做什么？」一点一点露出笑容让达尼兹胆战心惊笑容。低沉开口：「如果合适我想狩猎他们。」

# 410 无面人 第一百九十八章 纷至沓来

## 打开书
确阿兹克非同名。谁找？灵教团复活死神？因斯幕后？后者不太——有0-08何必黑帮赏金；除非悬赏本＝0-08安排：因斯被阿兹克盯无把握胜→借0-08让阿与某势冲突间接除敌！或灵教团接复仇歧裂。嘱科勒打听发布者＋价——合适顺便留意。私探≈赏金猎人差形式。教套话应急。科勒谢「又拥美好生活」——克内：仅基本生活。怔：来贝克兰德首听朋友名；首可能握因斯行踪！三月余主消化——与高序因斯差难补；0-08不寒而栗勿近查。黑荆棘皮鞋幕跃脑海；吐气出咖。切希尔斯顿陈旧屋：艾辛格·斯坦顿邀讨论杀人案；曾拒融资忙——对方愿等智慧火花。占卜宜访日＝谈后今午敲定。门铃退候。助手瘦削金边镜：「斯坦顿起居等；咖或茶？」「红茶少柠檬。」「临时仆今休——自过去。」不对：提前定怎恰仆全休？掏铜便士——门因敲裂缝；封印解浓烈血腥！安乐椅倒暗红血；书落封面《西维拉斯地区的恶魔传说》！烈风拉门哐——壁炉炭尽；家具倒碎战迹；血焦痕无尸无残肢！退欲脱——被锁定！冰冷无情注视；应对错即致命！宜访？启示误读？冷静。哒助手托盘锡壶两白釉杯来——见状愣；望克恐惧顿词：「你，杀了，斯坦顿，先生…」每词脸肉掉血淋；刷四分五裂如一直碎尸缝合。壶杯落地红茶浸。克不动仍被注——等行动扑咬颈。僵持大门开黑白格警冲入见碎尸枪指克。枪口下放松——后脑注视消失！举手无奈：「见律师前什么也不说。」切希萨克局拷水管再见于尔根。「陪同审讯。」叹：「悲剧——本该想晚饭非板脸警官。」幸极光／玫瑰关注未携非凡；左轮魔术瞒搜身。原原本本述信邀讨论案。警官：「回家取信望仍在。怎识斯坦顿？」「连环杀人案…」愣——曾疑恶魔犬背后主人现场冷哼；斯坦顿遇害前看恶魔传说！蛰伏报复？斯坦顿＝警方记录主线索领赏人！

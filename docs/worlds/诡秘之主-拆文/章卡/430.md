# 430 无面人 第二百一十八章 病急不能乱投医

## 打开书
埃吓打量：「比想富有。」本以为至少一周筹2450。「攒很久。」叹。埃：「侦探这么赚？」「方便行动身份；无大悬赏一年两三百。」「实际何？走私军火偷富豪金库？序7下很快攒两千多不多；多游违法边缘。」吸血鬼谈违法？向往快钱？笑：「接较危任务；不惧死可试。」埃闭嘴半晌：「傍晚来；带你去卖家。」从心吸血鬼。克觉不保险——卖家见财起意／无材劫杀？埃可信介绍未必；本拟雾占——更好法：「不，你自己去。预付1000；两材带丰收堂确认再付尾；卖家应受——显高贵血族信用。」捧抬颏：「交易方式无问题。」嘿：「怕那边不讲信用？堂内安心？」「当然；两米二肌肉母神眷者旁谁都有安全感。」指乌特。「能对付他也不在意两三千。」埃脸暗哼：「不担心我私吞1000？」「为何担心？你每天回此易找；活吸血鬼拆卖不止1000。」痛处恼：「血族！明白？勿用『只』！」轻笑等平静。「按你方式。」递上午信封＋厚千镑：「晚8点此见。」埃数确认；偷瞧乌特压嗓：「听过邪神愚者？」邪你…表情常：「多人找愚信徒；你也想入行列索悬赏？」叹：「否；考虑否向邪神／邪灵求解除心理暗示；尊名传出转赫密斯／古赫密斯或应…了解？危害多大？强制改观点？」病急乱投医…复杂：「愚很神秘；除已知无详神职／祷仪。疑惑：何不求血族始祖古神莉莉丝？仪正确祭品恰当应解暗示。」埃后靠直视数秒深沉：「大灾变前始祖已少回应；仅特殊事项——不含解心理暗示。」白银传说莉莉丝权柄被收／陨——偶应者谁？原始月？故意：「还有原始月；地下非凡仪式多借祂。」（巫王等）埃唇翕无声惧。久凝重：「疑原始月＝邪神／高位恶魔假扮；求者多渐改残忍疯满繁衍欲；剩以血族主大概率当场失控真怪。曾厉害血族危求→变只知交配生殖肉块；与牛羊马鼠植物石头生奇异后裔各开新怪种；幸速清。」原始月如此危？秘书未提；巫王或被蚀？幸祷己…七神外隐秘不值得信——我除外。叹。埃苦笑：「若愚负面不大求亦可虑。」唯一影响付酬…拍肩画三角：「向不清隐秘求极危；不如七神挑喜；不影响日常不弃人偶。」「若实无他法…」忽发现比想平静。克挤廊出；望雾空思：重心攒钱寻材。太阳再稳——去污染抵酬；娜迦发委倒吊；人皮幽影靠己；埃／智慧之眼月余无讯换渠——玫瑰学派或松勇敢者酒吧傍晚转联络莎伦马里奇。先东区黑棕榈一居换工装。切格林墓园：佛黑纱帽伴多里安扫劳伦斯安丽萨墓献花。思全在食灵者胃袋——学徒已消化；得胃袋即戏法；无线索；太阳因事前不敢仪不敢邀猎。为摆脱满月咒向愚求眷寻材；透露新书出版将收保底稿酬证购买力——不惧愚知现实身份。停劳伦斯墓；遗照「他是个好老师」；多里安沉默久叹：「真讽刺…」「为何？」康斯顿公学教师故此铭。「与你无关；家族事。」自嘲放花。直起目视前突开口：「佛尔思，你想成为非凡者吗？我信里描述的那种。」

## 这场戏有没有翻
翻了。开头成交方式定堂内交割；章末病急乱投医愚／原始月险、佛墓园被邀成非凡。翻的是投医劝退与亚伯招揽并章，不是契约生物细则。

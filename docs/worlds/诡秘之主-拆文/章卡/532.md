# 532 旅行家 第五十一章 4200镑先生

## 打开书
「旅馆内有危险。」低念占卜语句进入冥想状态往上弹出金币。当！微弱但清亮声音回荡于安静房间内金币翻滚着落下掉在掌心。这一次是数字朝上表示否定。没有危险…皱眉审视起四周从衣帽架上外套内掏出瓶有驱除虫豸效果精油。在身边洒一圈快速逆走四步进入灰雾之上做确认性占卜。也就是十来秒工夫得到启示依然是没有危险。回到现实世界摇摇头放回金币和瓶子穿上外套裤子与皮靴坐到床沿背倚靠枕谨慎对待。依然记得自己占卜家守则尤其占卜不是万能这条约所以即使答案都是很安全也不敢放松继续睡觉。这不是说不相信灰雾屏蔽干扰能力而是认为存在太多可能性自己占卜语句未必准确未必囊括从而导致解读错误。对刚才事情已有一定猜测那就是之前餐厅内冒险家四人组在西弥姆岛原始丛林里确实找到被废弃被遗忘古老神庙收获财富或者文物但也惊动相应苟延残喘邪灵被恶念或诅咒缠上。时间一分一秒过去忽然感觉到某种微妙灵性波动从附近房间内往外扩散飞快融入周围黑暗里。那潜藏让他有些许察觉暗流随之消失夜宁静彻底归来。果然…确实具备非凡能力…这就解决了？再等等反正还有一两个小时就天亮了…真出什么问题这里也是有教堂和代罚者小队…半闭眼睛做起冥想。……拜亚姆香树叶酒吧。打定主意要愚弄监控者达尼兹端着烈朗齐醉醺醺看着拳击台上几位女郎跳热辣性感舞蹈。「狗屎！这么久都没有少一件衣服！」和别酒鬼一起大声嚷嚷。然后他们也不管有没有回应彼此哈哈大笑碰个杯子灌上口烈酒。「看报纸了吗？」一个深夜还在酒吧鬼混男子打了个悠长嗝对身边同伴道。「你脑子被驴啃了吗？你认为你认为我能看得懂那些扭来扭去字母？风暴在上我只对这种扭来扭去感兴趣！哈哈哈！」同伴抬起酒杯指着跳舞女郎们为自认为幽默回答大笑不已。先前说话男子啪一声拍下他后脑勺：「钢铁死了！被烈焰弄死了！」附近达尼兹先是一愣旋即坐直微微侧头。清清喉咙灌口烈酒显得若无其事但暗中却往那边挪挪想听听别人怎么评价这件事情。带他入行那位冒险家兼海盗曾经说过如果没有烈酒女人和吹牛那海上人生将毫无意义。「钢铁？什么钢铁？我和你讲我年轻时候曾经战胜过一根钢管！」另外酒鬼插嘴。「你究竟对钢管做了什么？我是不是该说一声哟你可真细啊！」最先说话男人露出我懂笑容。没等待回答自顾自说：「钢铁麦维提死了血之上将二副死了！」最后半句话是低吼出来吓得旁边一个已经站不稳家伙滑到桌底惊恐呓语：「不是我不是我做的…」狗屎！酒吧总是这么混乱！你们快点进入主题啊我正等着你们赞美烈焰大人！伪装过达尼兹恨不得把手里酒杯扔到那帮人头上。「报纸上说是海军和教会联手做的钢铁死了血色荆棘死了冷静斯考尔也死了约翰·史密斯那帮恶棍也被抓起来了！」一位还算清醒酒鬼挤过来加入这话题。「不不不真相不是这样！」最先提及这话题男子笑着摇头「我有朋友在报社他告诉我他们有确切消息但无法刊载上去。海军和教会只是被利用对象真正凶手是烈焰和一位神秘老练强大冒险家赏金猎人。」「不可能！烈焰绝对赢不了钢铁就算是偷袭他也干不掉钢铁！」附近好几位酒客同时给出类似观点。「重点是那位强大冒险家我怀疑这是位接近海盗将军层次冒险家！」主导话题男人强调「不知道达尼兹从哪里认识了这么一个家伙呵他也做出贡献据说血色荆棘就是他干掉！你们难道没有注意？烈焰悬赏令变了赏金提到了4200镑！」「对！」「真的？」「烈焰不简单啊！」「真是一个凶猛海盗不大海盗！」「大海盗？我上次和他喝酒时候真没看出来！」呸！你这个婊子养的我什么时候和你喝过酒？我完全不认识你！一声声惊叹里达尼兹美滋滋想着：4200镑了！那帮家伙要是知道肯定羡慕地晚上起来擦甲板哈哈哈我现在可以说是黄金梦想号最强水手长了！这一刻恨不得飞回船上和铁皮水桶这些家伙喝酒吹牛好好讲一讲班西港惊悚事件讲一讲自己如何战胜堕落主教如何从钢铁等人埋伏里机智逃脱如何设置陷阱将敌人一把清空再也没办法玩这人生牌局。可惜为了船长还得继续做格尔曼这疯子仆役…唉我已经是4200镑大海盗了啊！叹口气让自己继续麻痹于酒精。……随着风暴教堂钟声响起天边升起橘黄色太阳周围依然安静得只能听到水声。没有等到异常松口气又脱去衣物回到被窝补两个多小时眠。灵性已算得上强大在预定8点半醒来慢悠悠洗漱换衣到一楼买了条有煮熟栗子面包和一杯咕噜树树汁边吃边走向码头。因为来时候已经买了9点回程客轮卡着时间准备登船。就这时看见那位青灰色眼眸女士以及她团队三个男性冒险家。他们正在售票点购买船票。快开船了9点这班他们肯定已经赶不上了…他们不知道从废弃神庙里拿了什么东西昨晚竟引来类似邪灵存在乘坐客轮时候可别出现意外啊…用身体挡住那几位冒险家视线掏出金币做了次占卜。获得启示是后面那班客轮没有危险。犹豫两秒看眼在售票点附近等待10点客轮那些乘客们手指无声一搓点燃掌中船票。什么事情都没发生一样返回售票点花费4苏勒买了10点那班客轮票。接着前往码头盥洗室进入灰雾之上再就担心问题快速占卜。想得很清楚若结果显示有很大隐患那不会冒险登船而是想办法阻止开船有必要时隐蔽地破坏掉船只不让无辜者因此死亡。如果和刚才占卜启示一致就正常乘坐只是预防下意外。最终答案是没有问题。松口气直接回到现实世界将鱼人鳔位置调整到最便于拿出地方。真要出意外茫茫大海之上这件非凡材料将相当重要。——非凡材料也能初步简单地应用就像被真实造物主污染过全黑之眼一样。……10点整。格尔曼模样提起行李箱跟在那群冒险家身后登上客轮。沿途之上看似在假寐或者阅读船上过期报纸和杂志实则一直有留意那位青灰色眼睛女士和她同伴。这样警惕一直延续到拜亚姆港口中间没有任何意外发生。他们将所有问题解决掉了？他们究竟得到了什么？停到路旁边从报童手中买最新报纸边用眼角余光目送那四位冒险家远去直至他们消失不见。呼…决定不再想这件事情只要没危害到大环境并不关心那些人究竟做了什么只是稍微有点好奇。提高行李箱边翻阅报纸边往酸柠檬街走去就像一位普通路人。突然嘿一声低笑自语：「达尼兹悬赏金额升到4200镑了…」再这样下去有点怀疑自己会不会忍不住将这家伙上交给总督府。漫步回到蔚蓝之风旅馆还未掏出钥匙就听见里面有一浪高过一浪呼噜声。他没逃？略感诧异但又不是太意外。之前在阴影斗篷上动了点手脚只要达尼兹离开就能利用占卜手段一路跟踪对方找到冰山中将。虽然胆小但还算谨慎…开门入内看着一下惊醒达尼兹一点点咧开嘴角：「祝贺你4200镑先生。」瞬间清醒到极点想干笑回应却笑不出来。这一刻觉得自己可能会有生命危险。

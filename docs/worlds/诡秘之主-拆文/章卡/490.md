# 490 旅行家 第九章 调查报告里的夏洛克·莫里亚蒂

## 打开书
伦纳德？有那么一瞬间克还以为自己看错了。但光芒造成模糊并不严重熟悉对方迅速就肯定之前判断。也就是呼吸一次时间伦纳德消失光芒散开河谷恢复隆冬季节安静梦中所见画面随之破碎。睁开眼睛将得自兰尔乌斯那枚徽章放到青铜长桌表面。「真的伦纳德还是无面人伪装的伦纳德？」略作思索抛了枚金币。灵性借助这媒介告诉他那就是廷根市值夜者小队队友伦纳德·米切尔！「他是女神教会为那个聚会派出调查员还是背着值夜者冒险寻找机会复仇者？」疑惑自语难以做出准确判断。而在根本没有前置信息情况下占卜无法给予启示。沉默几秒自嘲一笑在胸口画绯红之月：「祝他好运愿女神庇佑他。」不再纠结这问题准备更了解那个聚会详情后再决定将来要不要参与要不要匿名提醒伦纳德·米切尔。……贝克兰德蒸汽教堂地下区域一间密室里。伊康瑟摘下帽子按了按蓬松却不柔软头发坐到左侧第一个位置。随即从衣物内侧特制口袋拿出阿罗德斯这面古老银镜摆放于面前。他的右侧对面斜向有一位位机械之心执事和队长他们都是被神前会议成员贝克大主教霍拉米克·海顿召集来开会。这位穿白色牧师袍大主教此时则仿佛一位普通老者正安详坐最上首。见人员到齐环顾一圈温和：「从伊康瑟开始按照顺序讲一讲这几天调查情况。」伊康瑟·伯纳德扒拉头发边翻动厚厚文件边语言简洁汇报：「大主教阁下我们负责是夏洛克·莫里亚蒂部分经过详细调查和对应非凡手段辅助我们确认他是被动卷入这件事情在此之前没有任何证据表明他已经知晓埃德萨克王子问题。他和死去塔利姆·杜蒙特是朋友间接完成过王子给予一些委托但那并没有什么问题最多就是虚报了一些费用。」讲到这里突然有些心虚因为夏洛克同时也是机械之心线人他在这边报销开支很可能也存在一定程度夸大。不管怎么样他线人工作都卓有成效非常出色足以抵消很多问题而且他成为我们线人并不久涉及金钱最多那次还属分成…缓慢吐气继续：「我们结论是他属于无辜者背后没有任何隐藏图谋他曾经敏锐察觉红蔷薇庄园危险但那属于推理错误结果正确典型他害怕是王室倾轧为此他一直消极怠工没做实质性深入性调查这一点他是对我们报备过的。可惜是他依然没能避开这次事件但他也足够幸运他提到那位死神后裔就在红蔷薇庄园附近监控及时将他从陨石砸落绝境里解救出来现场痕迹表明这是一次非常恐怖袭击大概率与0-08有关。」克在信里有提及因斯与0-08存在至于他是否认识那位前大主教和0级封印物问题无人关心因为他当时和阿兹克在一起完全可能是从对方口中得知这也是所有人下意识间判断。而在0级和1级封印物上七大正统教会一直在互相通报粗略情况编号共享不存在重复。「…不过我们并没有掌握全部情况还有三件事情无法确认第一2-111显示夏洛克逃入那片树林后没急于远离反倒留在原地不知在向谁祈祷第二他和阿兹克什么时候认识问题第三他怎么从那个地下遗迹逃出来问题以他实力应该办不到而这个过程中他甚至还破坏了极光会降临仪式。」最后总结。2-111指阿罗德斯这面魔镜。霍拉米克静静听完自言自语般笑：「虚报费用…」旋即清喉咙：「不管怎么样夏洛克·莫里亚蒂都是贝克兰德英雄。如果没有他及时阻止如果他在那一刻感到害怕选择逃走我们之中大多数人都活不到现在。而且他也表现出对神信仰对我们友善只要他没有太大问题一些小缺点小秘密我们都可以当做不知道。」「主教阁下这正是我们想法。」松口气：「我猜测他在树林内祈祷包括吹铜哨仪式都是联络阿兹克方法但效果不一样速度不一样那样危急处境下他能做唯一事情只有自救这一点我们是从事情后续进程推断出来的。」「除了自救也可以写遗书。」另一位机械之心执事调侃一句旋即汇报自己负责环节：「…我们还是没能找到夏洛克描述那个地下遗迹即使借助2-111也不行而王室高序列强者当天行踪我们暂时无法掌握。」「…可以确认黑夜教会最早收到情报这来源于霍尔伯爵一个特殊渠道具体情况不详。」「…极光会在贝克势力被我们和值夜者代罚者联手清除了绝大部分但我怀疑他们还有隐藏力量…」「…事件发生时夏洛克提到特莉丝正前往贝克可在此之后就没人见过她了根据夏洛克说法她是关键人物并被改名为特莉丝奇克。」「…无法弄清楚黑夜教会是用什么方式抓获绝望魔女和管家芬克尔的占卜结果告诉我他们还活着但已不自由。」……一位位执事和队长相继汇报自身调查结果霍拉米克半闭眼睛似乎在思考什么。房间安静十几秒后睁开眼睛语速不快不慢：「全力寻找特莉丝奇克如果她还活着。将占卜无法得到有效启示问题汇总起来交给我教会有圣者擅长这方面事情虽然不一定比2-111有效。对王室高序列强者监控和调查可以放到牌桌之上不需要太担心他们一直知道我们在做这些事情这同样也是一个警告。对地下遗迹排查继续并通报给黑夜和风暴教会。伊康瑟你向2-111提问询问夏洛克是怎么逃出遗迹以及什么时候认识阿兹克的。」看了看大主教又望同僚们一咬牙齿：「是大主教阁下。」悲哀认为自己传说即将从负责几支机械之心小队扩散至整个贝克蒸汽教会非凡者。熟练流程后开口：「尊敬的阿罗德斯我的问题是夏洛克·莫里亚蒂什么时候认识阿兹克·艾格斯的？」两侧仿佛长了眼睛银镜之上忽有水光浮动迅速形成一幅画面：夏洛克站在一个房间内看着一只腹部腐烂老鼠爬墙钻洞身后则是老科勒和廉价旅馆老板。「他是在完成阿兹克悬赏任务时与对方认识的那个任务由军情九处颁布来源于巧合般冲突。」解读画面内容。说完选择对等回答然后屏住呼吸等待阿罗德斯给出刺穿灵魂问题。没有意外看见鲜红单词：「你知道全力讨好一个人却被他丢弃在原地心情吗？」这这个问题不够犀利啊不像阿罗德斯平时风格…突然觉得镜面鲜血单词缺乏往常惊悚感不够血淋显得有气无力。顾不得去想为什么当即开口回答：「知道！」「祝贺你答对了。」银镜表面出现新单词颜色泛白。……1月5日上午9点。脖子缠灰色围巾克提着皮箱和手杖抵达玫瑰码头。白玛瑙号停泊那里相对人类而言异常庞大据说能搭乘数百位船客。有着属这个时代浓郁特色烟囱与风帆并立两侧船舷各有12门火炮及相应炮位——这是防备海盗和同行必须。在船长艾尔兰·卡格安排下被挑选出精壮水手和船员在舷梯口一字排开有的甚至还故意露出合法左轮步枪和佩刀。这让陆续登船客人多了不少安全感对接下来长达九天旅程不再畏惧。克立下方抬头望一眼于起伏蔚蓝海水里走上悬梯。旅行开始了…迈步间默默感叹一句。

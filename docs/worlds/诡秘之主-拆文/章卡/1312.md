# 1312 倒吊人 第四十七章 第三个愿望

## 打开书
贾斯敏听得一阵激动但还是有点不放心：这需要付出什么样代价？在她看来之前免费尝试不需要付出代价不表示之后许愿也是这样。克莱恩正正头顶高高礼帽微笑说道：你付出便士就是代价实现愿望后需要承受相应变化也是代价。……我我可以先回家一趟吗？贾斯敏又懊恼又不好意思问道。当然这是你自由但我不保证全自动许愿机会始终在这里等你。克莱恩用魔术师口吻笑道有时候它很任性。贾斯敏嗯两声道句谢转过身体往着市政广场相反方向小跑而去。……咦贾斯敏？……晚上好汉米尔太太好久没见到你了你是要去参加狂欢节吗？未戴围巾贾斯敏发自内心笑道。……自从你们搬走就没有见过了听说你在之前轰炸里受了伤？嗯但已经好了。贾斯敏重重点头道。……朱莉现在怎么样了？……她被她被弗萨克人欺负因此死去了……可怜朱莉。贾斯敏悲痛而诚恳在胸口顺时针点四下画出繁星。……——她害怕去得太迟全自动许愿机已消失不见。……真的全自动不需要他在旁边？贾斯敏疑惑低语一句。她没去浪费时间掏出1便士铜币将它投入全自动许愿机内部。我希望我父母身体恢复健康希望家庭变得富裕。贾斯敏小声说出自己愿望并闭上眼睛等待奇迹发生。下一秒她听见叮当声音就像有硬币从全自动许愿机内滚出来。这个愿望无法实现？呃一个愿望里不能包含太多内容？我刚才许其实等于两个愿望……有烧伤被治好经验在前贾斯敏并没有怀疑全自动许愿机出问题。……我希望我父母身体恢复健康。这一次她听见全自动许愿机内响起轻轻敲击声：笃。……不过这次梦想完全可能变成真因为她面前就有一台可以创造奇迹非常神奇全自动许愿机。……我希望变得非常非常非常美丽。……她话音刚落全自动许愿机门扉又一次打开一张银白色面具被推出来盖在贾斯敏脸上。……这这就是神迹吗……贾斯敏由衷难以遏制发出一声赞叹。她沉迷欣赏着自己好不容易才抽回目光向全自动许愿机行一礼。……小姐你可以坐这里。……谢谢你。……这是位绅士应该做。……这一刻贾斯敏觉得自己就像在荒野里行走。

## 这场戏有没有翻
翻了。开头问代价；二愿父母健康；三愿非常非常非常美丽戴面具；章末绅士让座却荒野感。翻的是第三愿＝神迹起怖。

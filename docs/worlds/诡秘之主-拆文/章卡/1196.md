# 1196 逐光者 第四十七章 心灵风暴

## 打开书
那把似乎在无法追溯古老年代里曾经出现过染血长枪吸收这个房间内所有存在感一下就刺到秘之圣者布提斯身上。褐发坚硬布提斯身影陡然虚化变成一扇对开深黑大门。与此同时他出现在门后方与那把可怕长枪处在两个不同世界遥遥相望。下一个刹那染着暗红血液长枪刺破那扇深黑大门贯入布提斯所在空间。布提斯身影不断后退不断幻化变成一扇又一扇虚拟之门它们有的由两具弯曲石人组成有的门缝旁存在拳头大小孔洞有的镶嵌着银钉有的布满神秘花纹一重接一重一重连一重层层叠叠数之不尽。无声无息间朗基努斯之枪不断刺破这些虚幻之门竟没有丝毫停顿没让秘之圣者寻觅到脱离机会。不到一秒这散发出强烈毁灭意味染血长枪粉碎了数不清虚幻之门在气息明显下降后终于真正刺到目标胸前。布提斯身体瞬间裂出无数缝隙就仿佛摔到地面陶瓷物品。喀嚓一声这秘之圣者变得漆黑崩解成碎片散落一地。这不像是他本体倒如同他影子。这是他从真实造物主座下某位序列3圣者那里记录下阴影替身之术。当然若没有那层层叠叠门削弱朗基努斯之枪布提斯觉得自己很有可能连影子带本体一起破碎。惊险躲过这一击后布提斯强忍着脑袋眩晕和嘉德丽雅不完整神话生物形态带来冲击让眼眸内凝聚出一条没有鳞片银白巨蛇。这巨蛇是如此之大占满布提斯双眼表面有密密麻麻花纹和标识构成一个又一个神秘转轮。它首尾相接和无数虚幻河流交汇一起衍化为一个模糊不够真实缓缓转动巨大圆轮而圆轮四周有各种各样象征符号代表不同未来。霍然之间地面还未消失漆黑碎片一个接一个飞起重组为布提斯。那把染着暗红血液朗基努斯之枪从一扇又一扇飞快成形虚幻大门内急速倒退直至回归扭曲黑团身前。让人产生强烈恐惧之情气息潮水一样退去离开房间。到处都是裂缝和眼珠黑团蠕动着复原变回戴深色兜帽穿紫纹黑袍女子。所有一切都回到丑小鸭魔法使用前。命运之重启！这是秘之圣者之前颠覆亚伯拉罕家族得到奖赏之一从命运天使乌洛琉斯处记录序列1非凡能力。当然这肯定和原版有极大差距只能重启三秒内现实只能重启这么一个打通房间甚至无法影响整个公寓一楼。重启刚一结束早有准备般幽暗圣者克斯玛立刻采取行动。被他放牧源自血族伯爵扭曲黑影张开双臂做出拥抱红月姿态。嘉德丽雅身周黑暗一下涌动瞬间形成一条又一条虚幻但坚实漆黑锁链将她牢牢束缚在原地。而布满地面墙壁和天花板血肉疯涌着聚集一起变成一个覆盖黑色全身盔甲手提深沉巨剑极有压迫感骑士。这黑骑士面甲空隙处两团深红光芒微微闪烁瞬间锁定南瓜马车旁戴兜帽那位女性。嘉德丽雅脚下影子突然活过来抓住她脚踝水流般上淹将她死死缠住。黑骑士统御阴影！然后那快抵住天花板仿佛来自神话传说巨型骑士一个迈步就冲到离目标不算远地方劈出手中又长又宽又深沉大剑。另外一边秘之圣者眼眸中有银白色虚幻书册飞快翻动定格在其中一页。布提斯随之伸出自己左手隔着二三十米距离抓向南瓜马车抓向那穿紫纹黑袍神秘女子。他手臂骤然变长表面漆黑黏糊似乎流淌着邪异液体。这些液体之中长出苍白骷髅脑袋长出血管明显眼珠长出带着尖牙舌头长出各种各样奇形怪状东西让极端邪恶极端疯狂感觉飞速弥漫。房间内地面瞬间干裂原本还活着几只蟑螂僵硬倒毙。这是来自神孽斯厄阿某种状态攻击！当初拜亚姆城外秘之圣者被火种手套吸引过来后似乎只是旁观一阵拾取物品就直接离去但实际上他当时在拼命记录高位存在能力或状态。失败多次后由于时常有命运眷顾他最终得到自己想要当然那次交手里他只来得及记录这么一个。在这邪异漆黑手臂之下嘉德丽雅意识沾染些许疯狂短暂竟无法做出有效应对。再加上黑暗枷锁和自身影子束缚她只能僵立在原地眼睁睁看着幽暗圣者巨剑斩来看着秘之圣者左手抓向自己。就在这个时候不再有血肉墙壁分隔内外房间里突然刮起一阵无形风。这风刚一出现就变得狂暴席卷向秘之圣者和幽暗圣者心灵。操纵师心灵风暴。面对这夹带庞杂念头精神影响布提斯不仅没有惊讶和慌乱而且还勾勒嘴角露出些许笑意。作为重启开关他自然记得乘坐南瓜马车半神还有一个同层次帮手就藏在失修公寓外面某个地方。他之所以依旧将重点放在明面上敌人处就是为了引出潜伏着那个半神！在命运之重启和神孽状态两者间歇里布提斯有悄然给自己做一个催眠让自己遭遇心智剥夺或信息洪流冲刷时能自然分化出绝大部分星之虫承担留下少量操纵身体锁定隐身敌人。——之前龙威震慑和无法发现目标现实让布提斯确信潜藏是一位观众途径半神。思绪瘫痪堵塞之中几条细小支路飞快运转帮助布提斯初步找到袭击源头。可这个时候绝大部分星之虫内回荡念头却不像他认为那样是毫无意义信息洪流。他脑海里仿佛有道声音在一秒内说了几千上万句话：德莱尔森林一座废弃古堡底部有一扇对开青铜大门它封印着地底污染越是高序列靠近越容易受到影响……星空非常危险有未知存在注视……暗天使疑似远古太阳神分离负面人格…………什么？布提斯愣一下只觉这些念头又危险又让人忍不住想更进一步了解。就是这么一愣他本已找到敌人又一次消失脱离他注意范围而那抓向南瓜马车和女性半神神孽手掌也出现迟缓。同样幽暗圣者也受到心灵风暴影响动作僵硬一秒。等到他们恢复过来嘉德丽雅已张开嘴巴吐出一粒豌豆。这豌豆瞬间生长化成一根根青绿粗大藤蔓将嘉德丽雅托向门外让她借此摆脱黑暗枷锁找回一定行动自由。等到幽暗圣者深沉巨剑和秘之圣者漆黑手臂分别落到她身上却只是粉碎影子没能伤到这位神秘学家。此时嘉德丽雅是皇帝的新衣是根本不存在东西自然也就不会被创伤！下一秒钟这位穿紫纹黑袍戴深色兜帽女士身体骤然变得透明化成一堆泡沫。这些泡沫飞快散开相继破碎什么都没留下而那青绿藤蔓一直长到半空燃起熊熊火焰照亮周围街区。一切又恢复安静刚才短暂而激烈半神层次战斗似乎根本没有发生过。秘之圣者和幽暗圣者彼此对视一眼对这样变化并不觉得意外。很明显在突袭未能成功后敌方两位半神开始处于下风再也无法达成目的而这里又是贝克兰德拖得越久越是危险于是他们抓住机会逃离现场。另外他们为了干扰追踪还故意制造出极大动静以吸引贝克兰德官方势力。至于那本莱曼诺旅行笔记和那个序列7或者序列6学徒途径非凡者都是可以舍弃诱饵。微微点下头后秘之圣者从黑袍暗袋拿出一个水晶球让它冉冉生辉飞快破碎融入虚空。他这是在防止神秘学领域追踪。他确实不敢继续停留打算直接传送离开返回极光会总部然后拷问诱饵弄清楚真相决定之后该怎么做。一秒后布提斯身影飞快透明消失不见幽暗圣者则进入阴影急速远去沿途不断地消除着痕迹。

## 这场戏有没有翻
翻了。开头还在朗基努斯刺中；章末命运重启翻盘后心灵风暴＋皇帝新衣撤离，布提斯带走饵自以为赢。翻的是「杀到」变「饵被劫走」，不是枪厉不厉。

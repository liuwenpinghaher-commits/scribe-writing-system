# 1294 倒吊人 第二十九章 战争前线的后遗症

## 打开书
不要救我……不要救我……身在源堡且容纳着愚者牌克莱恩已有天使之王位格不会再受门先生嘶喊直接污染但那话语里内容却让他头皮微麻瞳孔放大难以遏制心中骤然涌起惊恐之意。他原本以为门先生一直在呼救可现在听到却是：不要救我！……帮助我……帮助我……接着他解除对万能钥匙和深红月冕历史孔隙影像维持让灰雾之上这片空间彻底回归平静。……门先生确实是半疯了但疯部分不是竭力呐喊时祂而是状似冷静可以理智和人交流祂……后者还能在某种程度上影响前者扭曲祂呼喊内容？清醒时门先生竟然喊是不要救我……对一个被放逐被封印一千多年天使之王来说这绝对不是正常该有反应除非祂认为回到现实祂会带来祂自身都不愿意看见灾难……一位彻底失控天使之王？结合门先生和大帝交流时一直诱导他去外神占据月亮来看这件事情还有另外可能：被放逐门先生没有最初造物主遗留屏障保护遭遇某位甚至某几位外神侵蚀失去绝大部分理智状态只比被缚之神好一点……学徒途径在序列3就能漫游星空门先生尊名里还包含着无尽星空领路者这个称谓……这是否说明这位天使之王在被放逐前就有可能接触过外神受过一定影响？嗯魔术师小姐最后看见深红大地金字塔式建筑不同位置星空又代表着什么？这不像是在当前星系内也和黑皇帝需要陵寝不太一样……影响门先生某位外神老巢或者说门先生成为旅……难怪当初黄光威尼坦预言诅咒解除之日才是亚伯拉罕们真正灾难开端……门先生一直呼救导致亚伯拉罕家族没法再出一位半神或许是某种意义上保护……虽然这会让亚伯拉罕家族失去地位和大部分珍贵事……他打算让魔术师佛尔思在告知她老师时只说部分真话：一是强调门先生已经半疯非常危险即使与祂对话交流也存在极大风险；二是不说较容易达到第二个解除诅咒仪式只讲献祭占卜家偷盗者和学徒半神各一位那个。……这能有效消除亚伯拉罕们心病阻止他们帮助门先生脱困让他们更多更快开始信仰愚者。……同时告知仪式本身也能增强亚伯拉罕家族对魔术师佛尔思信任。……不说现存秘法师还有多少位问题能成为诡法师半神肯定一个比一个难抓且大部分集中在密修会对付他们就是在挑衅查拉图即使亚伯拉罕家族本身还有半神可以短时间内动用0级封印物也没法……还有之后用世界格尔曼·斯帕罗口吻提醒魔术师小姐一句让她提防亚伯拉罕家族极端分子……克莱恩想了想开始回应魔术师佛尔思之前祷告。……毁坏很严重啊……下了列车出了站台后克莱恩站在高处眺望一眼这座纯粹工业都市。……这里死亡人数绝对以十万计……克莱恩暗自叹口气提着行李箱沿阶梯走下蒸汽列车站真正进入康斯顿城。前往旅馆途中他继续自己奇迹师扮演随机挑选位三十岁出头壮年男子。我是一位流浪魔术师我最擅长魔术是满足每个人提出愿望你想要试一试吗？曾经薄脸皮克莱恩此刻已能非常自然搭讪他人。……你能让我父亲母亲两个兄弟和一个孩子复活吗？……我之前路过马里斯河时听见水中有很多人在哭喊我没敢去看风一样跑回城内……这算什么我在风信花街9号看到更加可怕东西！那里窗户上贴着一张脸！非常苍白脸！我家后面好几个路人失踪血迹一直拖到最近废墟里但警察们没有找到尸体……真是可怕啊愿女神庇佑我们！风暴在上让这些鬼魂和怪物远离我们吧。对了市政厅有贴出公告说是发现类似事情立刻向警察局报案。看来之前那场绞肉机式战争让许多尸体来不及被安魂变成鬼怪呼很多时候有逝者未必还有尸体能保留……嗯这里面肯定也不乏因精神崩溃或身体残缺失控非凡者……还有那些未按正常流程服食魔药人……就在这个时候克莱恩看见前方十字路口走过一队戴着红手套穿着黑风衣值夜者但他一个也不认识。果然宁静教堂派更有机动性红手套小队来帮忙……呃附近出了什么异常？克莱恩微不可见点头循着灵性直觉将目光投向一堆废墟后某栋公寓式建筑。那里四楼一个凸肚窗后有一张高度腐烂脸孔正贴着玻璃注视外面淡黄带黑液体一滴又一滴沿窗户下滑。

## 这场戏有没有翻
翻了。开头不要救我定性半疯结构；策略性转告；康斯顿鬼怪后遗；章末腐脸贴窗。翻的是战争前线后遗症＝外神侵蚀猜＋城市未安魂。

## 这一章新讲明的规矩
- 清醒喊不要救；疯喊帮助我；清醒可扭疯喊。
- 或外神蚀／失控天使之王；诅咒或保护。
- 转告策略：只提难仪＋半疯险；防极端。
- 战尸未安魂→鬼；红手套机动清。

## 热怎么变冷
不要救还热。冷切在帮助我交错。策略还热。冷切在毁坏十万。复活问还热。冷切在腐脸滴液。

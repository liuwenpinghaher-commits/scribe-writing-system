# 414 无面人 第二百零二章 戒指

## 打开书
对联手克反应不大：「恶魔行前预知危甚至来源；难找拖。」艾颔：「非无解。」卡斯问。艾：正面战见预知优缺——提前长；谋划危害付诸则有预感（须切实危害）。克内心：不同恶魔强弱异或仅十几二十分——未出口。缺：只知来源不知细节＝可利用。卡斯不信陷阱；克点头（内：灰雾可欺但不可人前露）。艾笑：非凡不可思议。坦白诚意——己＝阅读者途序7守知者／侦探；此境坦诚更要。序7逃欲望使徒？有强物！卡斯：「守知者克预知？」否——有戒指源失控序6阅读者：辨识看清记住模拟见过非凡；越强失败越高。「教会格言：全知意味着全能。」耳熟——艾出示碎钻簇拥碧绿人眼宝戒指！见之眩晕脑力耗——封印物2-081！艾＝智慧之眼老先生？愕望——轮廓吻合细节异；伪装强或借2-081。浮想：若轮坦白我默拿太阳胸针？「好哇原来是你小子」！卡斯：「拟何对抗预知？」艾狐笑：「恶魔对危险的预知能力。」啊？解四步：①谋危害方案付诸（正做）；②使徒察危知来源我／此；③恶魔本能先扼杀报复身变再虑远；④拟预知者察使徒威胁定位其所在。神操作！后续逃来不及？艾：现必藏周围；远程情绪有距；刚导斯失控。逃追踪后等到现在＝与值夜机械心军方商——各派两三队分区代号；使徒早料正常。一定位即通知封锁层层围。「怎几秒通知？否则逃；或已远。」艾：完美无；或等某封印启用；使徒或离贝克可返。出示巴掌金物似小电报机＋喇叭：「声五公里同响；负：启用后五公里声全入耳久——可拟能力减弱。」卡斯皱：「有官方何需我等？」艾慎戴2-081诚：「不提前惊——距我等最近区力量空白；目标在此须三人拖延。」克略思答应；卡斯：「为己也会合作不必多解。」「解释＝谋划部分；协议＝行动始…」半闭眼；碧绿宝幽蓝近黑光。忽站凝指上方：「他就在这里，就在楼上！」克卡斯起——响指火柴跃二楼／随奔门。未想败后仍留明斯克15！或讨论时楼上冷注？卡斯眼通红右拳啪打艾背心！悟：未逃因还有布置——卡斯心埋种未催化！仅三非凡之一！前骚动＝松警惕关键催化！最大目标仍艾！狡猾！克响指空气弹射卡斯喊「小心！」艾经验前扑——卡斯无视弹臂血花；连拳带人撞艾后背脊椎！喀嚓骨断声！

# 428 无面人 第二百一十六章 各方

## 打开书
夜煤气灯照湿地；马车溅水。贝克中部距苏尼亚海数十公里常小雨；七月均高28冬低约2少破零——潮湿阴凉穿透衣血；北弗萨克人亦难受。克未燃壁炉立凸肚窗后望安宁静谧——身心灵异常轻松。凑材调药即可晋序6无面人。「魔术师彻消化…使徒亲手终结…极光寻愚死路打转…除阿兹克被追与材料暂无困扰」呵气窗凝白雾。冒险堵截因惧另布置摆脱追踪→关键意见者或被记事后泄愤；冷血少为伴仇但险死可泄愤。检讨：隐士会或接应；逃则不知情报按序5防；或借深渊牌＋会助晋高序——后怕；正义补刀不可或缺。沙发思下：机械心赏金→千面垂体血可买；娜迦发钱够可倒吊帮；人皮幽影特性＋金镑仍不够。自嘲：本非特爱钱廷根怂梅消费请女仆；隐秘安全第一；为复仇须升须买材只能便士苏勒攒。肩缩阴冷魔术师颤——决洗澡钻被窝床读；三四小时睡勿燃壁炉。切蒸汽堂地下：伊翻口供喝咖；取阿罗德斯。卡尔森好奇：问数学未解／悖论会正确答？「大多拒；恶意或闪电／诅咒。活封印高智非差分机；勿钻漏洞。」卡尔森坦然愿代问——伊苦笑：「该知皆知不怕；偶问深奥你身难承惩。」握拳抚镜三：「指使欲望使徒刺尼根是谁／何势力？」久才水光：日落平原田地淡金余晖。「黄昏？生命终点？死神教／末日疯？」窥秘人斟；卡尔森附后者。镜问伊：「最喜欢什么颜色的内裤？」脸涨红顶冒烟艰难：「红色。」室静众人望角。虚脱抓发拟二问——卡尔森不忍代试。问：「欲望使徒合作者有哪些？」水光：出色身材女背影；极模糊男勉强判男装。「果然还有合作者＝出卖情报者；有处理…」选问题！血红：「你每天都靠手来解决？」耳烫小声「是…」切圣赛缪尔底：戴莉扔塔罗案资料索前。「比想少。」「只是索引。」伦：「何不深查接触杰森者对比前两案？或藏塔罗组织线索。」索笑：「尼根＝风暴虔诚信徒政坛利益；代罚必疯寻真凶我等勿掺易矛盾；查他塔罗案或新线索；奔波＝红手套职责。」伦明。脑老头啧：「值夜错过；那人身上有黑皇帝味道——真正黑皇帝味道！」切圣风：神之歌者银眸扫：「将离贝克枢机会议决。任务唯一查尼根刺案。申报有权动1级封印；须弄清谁针对我等！」锚形青黑纹身中年领拳击胸遵命。切霍尔别墅：奥压嗓问苏茜爸讨论何——晚归凝重派狗旁听。「尼根被刺。」「啊？」怔——权势公爵真死？体成人世界残酷冰冷。「谁？」「序5恶魔；已被灭口——侠盗黑皇帝。」再愕：怎愚眷者？上次助阻刺！矛盾！嘱再听；反锁祷愚：「眷者有在现场？」「是。他在寻找指使欲望使徒的那个组织。」果然非安排；阻齐亦为幕后？「何组织得您关注？」平常：「黄昏隐士会。」

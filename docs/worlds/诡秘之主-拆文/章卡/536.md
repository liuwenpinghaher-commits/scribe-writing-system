# 536 旅行家 第五十五章 灵感太高

## 打开书
立在门后是个赤裸着上身男子胳膊上纹着条青蓝色狰狞海蛇脸颊两侧胸前腹部有红色油彩涂抹出短条纹每三个为一组。真有异域风味啊…但不怕太显眼出门就被警察堵住吗？你们可是隐秘活动反抗军啊！刚要收回视线却被对方粗杂眉毛冷血动物似眼睛弄得险些皱眉。杀过很多人…凭借灵性直觉做出粗略判断。坦白讲因为上辈子身份和认知对殖民统治反抗者最初是抱有很大同情毫无鲁恩人自觉但听说对方和海神信徒几乎重叠后心里更多却变成戒备和排斥。这不是说歧视本地信仰而是据他了解所有殖民岛屿传统信仰都停留在原始祭祀阶段崇尚血食崇尚活祭处在相当蒙昧状态。另外以大帝体会和自己经验这世界超凡本质是有疯狂和扭曲要素还处于原始祭祀环节神灵基本不可能对抗这种趋向风格可想而知…没有说话跟在达尼兹侧后走进房间。「埃德蒙顿谁来了？」一道醇和嗓音从靠窗位置传来。纹身男子边关门边说：「他们做了伪装。」这个时候已将房间内情况尽收眼底有了初步掌握。这里客厅不大放了一个橱柜一张桌子和几把椅子就已显得局促。右侧有两扇门通往疑似卧室地方左边是用柜子隔出来厨房至于盥洗室毫无疑问是没有上楼时候就发现每一层楼梯拐角处有个公共盥洗室许久没清洗过味道弥漫出来催促着行人尽快上楼入屋。正前方有扇窗户两根竹竿往外支出晾晒着不少衣物。卧室门口和客厅内或站或坐着四五男子都是肤色较深黑发微卷本地人种他们套着深蓝色塔拉巴衫于裸露在外皮肤上涂抹着或多或少红色油彩至于海蛇纹身因为被衣物挡住无法看出有没有。他们有腰别左轮有端着托把棕红猎枪有甚至背负有灰白色钢铁背包拿着粗长高压蒸汽步枪对入门达尼兹和克形成半包围态势。刚才问话人是个坐在铁轮椅上男子四十来岁膝铺毛毯身着夹克。剃了个光头脸颊两侧留着发青胡须深棕色眼眸情绪内敛似无波动。瞄眼访客缓缓露出笑容：「烈焰。」达尼兹愣一下强行笑道：「卡拉特你眼力真不错。」狗屎！我化妆改扮技术真那么差？不愿接受心里怒吼一句。卡拉特没理睬烈焰一点也不真诚赞美转而呵呵笑道：「听说你杀了钢铁和血色荆棘？」「要不然他们怎么会死？」毫不犹豫反问。卡拉特眯下眼睛目光慢慢移到顶着张毫无特色脸孔克身上。很清楚仅凭烈焰别说钢铁就连血色荆棘都很难杀掉对方能够成功传闻是获得一位强大冒险家老练赏金猎人帮助。是他旁边这位吗？注视着克眼睛没发现紧张担忧警惕等情绪那双眸子就如同深邃海洋。很可能是…至少比烈焰强！对埃德蒙顿等人使了个眼色暗中提高戒备。「你们来做什么？」没再纠缠刚才话题。达尼兹下意识望克一眼在看见肯定颔首后回答：「看看你们有什么好东西。」卡拉特指着桌子道：「都在上面。」那里摆放着不少造型奇特东西包括骨头制成口哨简单粗糙风笛颜色铁黑叶片沾着鲜血石头…不等审视卡拉特拍下手掌道：「我有个任务。如果你们能完成它可以自由从这里挑选一件物品不需要付出任何代价。」笑一声补充：「按照你们这些外乡人定义它们不属于神奇物品但都有些超自然力量只是会缓慢嗯不算太慢减弱直至消失。」「什么任务？」平静问半点没掩饰达尼兹只是个随从事实。卡拉特将手伸入膝盖上毛毯内拿出一叠白色纸张：「找到他们下落。如果能直接抓住你们将获得更多。」抬起双臂开始展示一张张栩栩如生肖像画其中有位眼眸青灰身着男性衬衫女士。拉蒂西亚…一眼就认出反抗军想找人是谁。那是昨晚遇见今早同船女性考古学家冒险家疑似摩斯苦修会或要素黎明成员。达尼兹仔细看两秒隐约觉得眼熟。忽然回想起在哪里见过：身旁格尔曼在自己梦里展示过！他下午才询问船长晚上就遇上相关事件了…这搜集情报能力太强大了吧？忍着冲动没去看旁边疯狂冒险家害怕被卡拉特和埃德蒙顿他们发现异常。在这方面还是很有经验。信仰海神反抗军在寻找拉蒂西亚…海神信仰遍及罗思德群岛包括西弥姆…昨晚有蛇出现…海神形象是巨大海蛇…将两件事情重叠在一起很快有初步判断：考古学家拉蒂西亚等人在西弥姆岛原始丛林内被遗忘神庙中拿到一件涉及海神重要物品于是有了昨晚试探和反抗军寻找！想了想敷衍回答：「我会留意的。」我不会乱掺和这种与邪灵有关事情当然如果有必要我会举报…心里默默补两句。卡拉特点点头道：「你们先看看有什么想要。」走过去正要边挑选边询问心中忽有感应下意识就望向那堆物品右侧。那里有一把细长骨头打造成短剑比小臂略长通体乳白有几个暗红色深沉斑纹。能触动我灵感…伸出右手试图拿起那把前端尖锐骨剑仔细检查一下。手指刚碰到那把骨剑脑海内就突然回荡起一声声绝望而痛苦喊叫鼻端隐约浮现出一股股浓郁血腥恶臭眼前则仿佛看见一道道扭曲腐烂被黏液包裹虚幻身影。额头一阵疼痛如被针刺下意识就缩回手指。有点邪异啊…不是简单物品…有过更强烈体验表情只出现细微变化。忍住开灵视冲动害怕看见不该看见东西。注意到这一幕卡拉特和埃德蒙顿对视一眼含笑出声：「这把骨剑能吸干敌人血液还算不错想要它吗？」有点主动…微皱眉头旋即舒展然后沉声说：「不这里没有我想要。」如果卡拉特不问是打算买下那把骨剑弄到灰雾上研究但对方主动推销行为一下让他有些警惕于是理智放弃原本计划。卡拉特交握起双手道：「它并不昂贵。或者再看看其他？」「不需要。」瞳孔突缩直接转过身体走向门口。达尼兹迟疑一下赶紧跟上。臂有海蛇纹身埃德蒙顿沉默看着似乎随时会伸手阻止但最终还是没采取任何行动。那是干掉钢铁血色荆棘等人强大冒险家！出房间不发一言蹬蹬下楼达尼兹快步追赶莫名心惊。分辨形势没有询问只是跟随。两人很快回到广场再次聚集起来或跪拜或匍匐人群重又散开躲避。但与之前不同有个男子依旧伏跪于原地没有动弹。目不斜视直接经过完全不停顿。达尼兹下意识看一眼发现那男人脸庞干得就像风化已久岩石。啪！那男人脸颊有块肉突然脱落带着片有胡须皮肤摔在地面色泽发灰。他整个人似乎失去所有水分。达尼兹吓一跳再也不敢乱看只觉事情不知什么时候已变得奇异且危险。两人穿过街巷出这片城区登上辆出租马车。车夫是明显本地土著四十来岁笑呵呵很是讨喜。可沿途之上他一句话也没有说安静得让达尼兹心头如在打鼓。抿着嘴唇同样沉默。出租马车很快来到码头区因为要改变装扮达尼兹让它停在远离酸柠檬街地方。下马车没付车资没有停留直接大步离开看得达尼兹一愣一愣。丢两苏勒给车夫慌忙追赶格尔曼。追几步无意识回头望一眼只见那车夫满脸狂热和虔诚跪下来伏至地面边流泪边亲吻克刚才踩过地方。

## 这场戏有没有翻
翻了。任务肖像；章末车夫吻地。翻的是灵感触骨剑拒买＋广场干尸，不是接任务发财。

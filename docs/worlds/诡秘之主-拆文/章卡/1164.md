# 1164 逐光者 第十五章 豪华阵容

## 打开书
阿蒙说话时祂背后巨大漩涡内一根根布满神秘花纹透明触手已延伸过来缠绕住祂不同灵体之线。瞬息之间这些虚幻细密黑线被毫无阻碍提起。于是一只只形态奇特怪物被悬吊半空如同等待风干火腿。阿蒙身边那些灵体之线都是祂不知什么时候偷来的！查拉图展开攻击同时祂另外滑腻触手不断伸入虚空试图往回拖拉出某些事物。也就是这样两三下工夫一道人影飞快勾勒出来。留栗色微卷长发蓝眼睛高鼻梁薄嘴唇有两撇打理得很漂亮小胡须穿着锈金线暗红外套——正是因蒂斯曾经皇帝罗塞尔·古斯塔夫。这位知识皇帝刚踏入现实世界就居高临下望向巨大化阿蒙眼眸内瞬间凝聚一个又一个复杂虚幻符号。祂一点不担心阿蒙偷走自己攻击因为准备的是极其大量没什么作用的庞杂知识无论强行灌输还是阿蒙自行拿走都可达成撑爆对方脑海目的。就在罗塞尔投影彻底成形时查拉图透明触手又拖出一道身影。面容年轻长发却已半白往后扬起浮半空黑夜里一半藏匿一半明显。这是克莱恩不认识的天使外形男性眼眸幽黑含沧桑五官还算不错脸颊却长出一撮撮粗黑短毛给人既苍老又青春既理智又疯狂矛盾感受。旋即化成一团蠕动合抱小虫延伸出与查拉图投影相似透明滑腻触手。很显然也是位占卜家途天使。此时他甚至有点不敢直视半空情况但灵感一动已察觉某种熟悉。被查拉图召唤第二位天使是：古神之子安提哥努斯家族最初那位先祖！这是祂还没成为半个愚者时的历史孔隙投影。很显然查拉图在这段时间做了充足准备。随着安提哥努斯展完整神话生物形态周围环境再变黑暗更浓郁如同有自己生命一样涌向巨大化穿古典黑袍戴尖顶软帽单片的阿蒙。这片黑暗笼罩地方所有怪物瞬间变成秘偶。安提哥努斯似将记忆中古神神国移部分到现实以此将阿蒙和他分隔。这同样是一种奇迹。奇迹降临时查拉图透明触手从史雾拖出第三道投影。穿黑色全身盔甲骑士——第四纪所罗门帝国一位半神并未在历史上留太显赫名声。但是祂有另一重身份：战争之红军团一员这个军团首领是天使之王梅迪奇。在这军团内每个成员都能和红天使梅迪奇心灵相通形如一个整体。也就是说梅迪奇能集聚他们力量也能将自己力量传递给他们。——古代学者能力无法涉及唯一性哪怕通过序列提升得到质变也一样但占卜家们毫无疑问都会寻打擦边球办法试图绕过限制在一定程度内得到唯一性相关帮助。他是通过召唤只有一点力量的女神神降容器完成这点查拉图则是召唤战争之红军团内强者。这一刻那个投影就等于部分的梅迪奇！穿黑全身盔甲骑士踏足战场呆滞扫一眼立刻笑出声：哟小乌鸦被我烧掉的毛长好没有？因为自己召唤的史影又召唤了三个天使级史影他的维持压力瞬间激增怀疑自己连十秒都未必支撑得到。若非有这种变化他多半会觉得找到无限提升战斗能力办法——每次召两大天使加一个自己然后属自己投影再召两大天使加一个自己如此延续子子孙孙无穷匮也。这时阿里安娜身体淡化转入隐秘状态接着陡然于巨大化阿蒙身后出现劈出手中布满奇异花纹骨制长剑。趁阿蒙被五大天使投影围攻机会他连续将怪物转秘偶让它们对准自己张口发出砰声。一枚枚空气炮弹呼啸轰向自己。同时手一伸轻松从空气拿出一枚已激发即将起效阳炎符咒。他就不信这多重攻击下自己还能活着。砰砰砰声里突然听到一声滴答。整个世界似静止瞬间然后又恢正常。旋即看见幽黑天空破开大洞一束纯粹灼热阳光照进来点燃一枚黄金制成符咒。那正是阳炎符咒它变成巨大光球缭绕无数火焰火球。但是攻击目标却不是他——它出现了错误包裹住那个战争之红军团半神。另外一边罗塞尔灌注海量知识安提哥努斯创造奇迹阿里安娜挥出毁灭长剑查拉图延伸一根根透明触手都错误地指向同一目标——穿黑全身盔甲的梅迪奇下属。这位某种程度有梅迪奇部分意志的投影先是脑海炸开就连本能反应都似失去接着被一重重攻击命中迅速消散半空。戴尖顶软帽穿古典魔法师长袍阿蒙不知何时已恢人类大小落到战场底部。抬右手正了正水晶雕单片一抹光随之亮起。背后那古老斑驳完整时钟虚影又一次呈现最长秒针以超正常速度飞快转小半圈。这花费时间实际还不到一秒但整个荒芜平原上所有事物都似失去十几二十秒。安提哥努斯史影消失罗塞尔投影跟随散去接着是查拉图和阿里安娜史影。祂们能维持时间就这样被偷走了。正要做第三轮自杀的他看到这一幕竟有点不敢相信眼睛。对渎神者阿蒙能解决五大天使投影有所预料毕竟投影终究只是投影比本体差不少但绝没想到对方能如此轻描淡写让自己连自杀机会都未真正创造出来。用出底牌却换来这样一个结果难免有点意志消沉心生绝望。阿蒙推单片窃走距离一步来到面前看着笑：如果都是本体那确实会比较麻烦。但来自历史孔隙中的影像有着非常大的缺陷而抓住问题正是我擅长的事情。看着这位笑容不变神情间多有愉悦感完全不觉得刚才处境困难的时天使一颗心缓缓下坠如落深渊。脑海里灵感有所触动飞快闪过一幕幕：进入神弃后阿蒙变幻衣物将符合当前时代审美深色夹克呢制长裤黑礼帽换成古典魔法师长袍与尖顶软帽；在那之后祂提议进行一场逃与阻拦游戏；祂表现得极有自信一点不担心出现纰漏……思绪电转嗓子有些发干声音颇低哑：你是本体……进入神弃之地后你的本体就和分身会合了？真切怀疑眼前这位就是阿蒙本体真正渎神者完整天使之王！戴单片阿蒙嘴角一点点翘起：这很有趣不是吗？你知道这个真相后的表情就是我玩这场游戏想要看到的。祂明确承认自己就是本体天生容纳偷盗者途唯一性的本体是神灵之下第一档。这就意味除非有真神降临否则再怎么努力挣扎都不可能从阿蒙手上逃脱而这里是神弃之地唯一还活跃神灵是真实造物主祂对源堡兴趣不是太强。这一刻虽然有怀疑过旁边阿蒙已替换为本体但真正确定时多次历经希望产生又破灭的他还是体会到什么叫极致绝望——要不是塔罗会涉及正义小姐伦纳德他们要不是他知道阿蒙最擅长欺诈他都想开口认输表示愿意成为对方眷者。打不过就成为对方一员不是很正常吗……自我吐槽间忽然灵光一闪回忆起阿蒙之前说过一些话语。这……陡地眼睛一亮彻底平静下来看着阿蒙悠闲活动下身体含笑：你杀了我吧。

## 这场戏有没有翻
翻了。开头五大天使豪华围攻还像有戏；章末时间被偷、确认本体、他反而说你杀了我吧。翻的是豪华阵容收成极致绝望后的冷静反击口，不是小乌鸦笑话厉不厉。

## 话
「哟，小乌鸦，被我烧掉的毛长好没有？」「如果都是本体，那确实会比较麻烦。」「你，是本体……」「这很有趣，不是吗？」「你杀了我吧。」局面是豪华收成错误；绝望收成求死口令。

## 热怎么变冷
五天使围攻还热。冷切在滴答与阳炎打错人。偷时清场还热。冷切在连自杀机会都无。认本体还热。冷切在极致绝望。你杀了我吧还热。冷切在眼睛一亮彻底平静——章在开口停。

## 怎么起、怎么收
第一段触手缠灵体之线起。最后一段含笑：你杀了我吧。章题豪华阵容——召得起也守不住。

## 叙述怎么插手
风干火腿喻偷线。子子孙孙无穷匮也玩笑。进入神弃换装回忆链。打不过就入伙吐槽。灵光一闪截断绝望。

## 谁比谁多知道
阿蒙一直知自己是本体；他刚确认。读者跟他过绝望到灵光。投影不知攻击被改向。

## 留给下一章的日子

# 1372 倒吊人 第二十章 面对

## 打开书
克莱恩制造这个分身是以当前状态为蓝本而非道恩·唐泰斯夏洛克·莫里亚蒂梅林·赫尔墨斯免得出现认知上障碍。在遭遇亚当带来异变后他对类似方面更加小心了。瞄眼分身克莱恩念头一动让它脸部变得一片空白。这分身旋即探出右手调动源堡力量向本体抓一下。……他完全不抵抗放开身心情况下分身借助源堡位格和力量都还得花费这么多时间失败这么多次才最终成功实战价值可想而知。……当然他精神状态也出现一定波动因为失去查拉图残留精神牵扯后天尊复苏意志更强烈侵蚀起他心智。这在克莱恩预料之中所以他一点也没有慌乱凭借早已稳定下来自我认知还算坚韧意志和数量足够充分锚逐渐抵御住来自天尊意志污染找到新平衡。与此同时当那份克莱恩还未消化诡秘侍者非凡特性基本进入分身体内后它没有五官空白脸庞突然出现扭曲长出双幽黑无光眼睛和若隐若现白色长须。……不过它没有办法承受这份诡秘侍者非凡特性带来疯狂身体迅速往崩溃方向发展爬出一条又一条透明扭曲蠕虫延伸出一根又一根滑腻邪异触手。……到了这一步他已做好所有准备本体处在消化完魔药可以容纳愚者唯一性状态中并附带一个序列1秘偶。……对于众神之争我能做只有现在这些之后唯有尽力而为……嗯我对前面流程是不是想太乐观了因为有女神帮助有永暗之河河水做辅助所以根本不需要担心安提哥努斯家族那位先祖会造成什么意外？一番审视后克莱恩认为自己还是不够谨慎存在那么一点傲慢和大意。……完成这件事情后克莱恩站起来从历史迷雾内拿出蠕动饥饿将它戴至左手。这是为可能存在小范围战斗做准备那种场景下闪现比嫁接更快捷更方便。理下衣领克莱恩缓慢环顾一圈让目光落在那扇沾染着青黑奇异光门上落在悬吊于那里被一个个透明蚕茧包裹人类身上。一一扫过中他视线定格在那三个破裂透明蚕茧处。……紧接着他直接传送到霍纳奇斯山脉峰顶看见那个笼罩着迷雾破败不堪杂草丛生古老宫殿。……克莱恩将这里和星界嫁接到一起。……而和克莱恩上次送特伦索斯特黄铜书过来时不同里面一片幽黑让人既看不见悬吊于大厅众多尸体也发现不了盘踞于巨大石椅上透明蠕虫团。不需要猜测克莱恩利用天使之王层次占卜家直觉确定这是黑夜女神用永暗之河河水让安提哥努斯家族那位先祖进入永眠状态后带来变化。……生活于这张黑白旧照片内人们普遍高大看似正常地学习劳作休息着。……因为他直接看见那些亡者身上灵体之线。他们即将死去刹那灵体之线飘向峰顶被未知存在掌控了。……夜之国是属于黑夜途径那位天之母亲但在峰顶有一个供安提哥努斯家族先祖使用秘偶城镇。于是夜之国居民们恭敬又畏惧黑夜信仰着那位天之母亲同时他们相信死亡不是终点相信死去亲人会在黑夜里庇佑自己。确实死亡不是终点亡者之城就在他们旁边就在峰顶走路就能走到而死者们会以秘偶形式在那里继续自己生活。……进入永眠状态后安提哥努斯家族这位先祖终于短暂摆脱失控和疯狂变回以前样子？克莱恩立于大厅中央注视着此行目标油然喟叹一声。……阔别上千年梦境。

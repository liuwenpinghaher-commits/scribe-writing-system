# 117 小丑 第一百一十八章 八月

## 打开书
时间平稳流逝，廷根送走夏天的尾巴，来到八月中旬，气温稳定二十六七摄氏度。哗啦。浴缸内猛然站起迈步而出滴滴水珠。赤身裸体立在那里低头望腹部稍一用力块块肌肉线条清晰勾勒。这段时日坚持训练的成果，整个人也显得精神了许多。就在今天格斗老师高文开始教导基础拳击步法和发力技巧。啪啪啪光光的脚板踩盥洗室地上时而前滑时而急退时而右闪伴随挥拳和格挡。呼停下来欣喜吐气拿毛巾擦拭。接触达斯特之后的两周多仿佛摆脱了巧合离开总是碰到超凡事件的怪圈，生活变得平稳按部就班领薪水深入研究神秘学练习射击和格斗移植开发新的菜式与班森梅丽莎一件一件积攒体面的餐具和摆设向邓恩伦纳德请教过去的非凡案件到俱乐部帮人占卜并严格遵循本身总结出来的守则。心灵变得安定如果不是夜深人静还会思念地球如果不是红烟囱还没有查清楚如果不是厄运布偶传递的图案偶尔会出现于梦境里他都要开始习惯并眷念现在的生活了。此期间塔罗会召集了三次并未得到新的罗塞尔日记但据正义介绍她新认识了两位非凡者正在自然地接触她们等到进入相应圈子应该就能交易到更多日记。倒吊人也表示自身已经返回陆地正在处理一些事务只要空闲下来立刻着手寻找。另外正义感觉新认识的两位非凡者都是值得发展的对象比如各有不错的明面身份掩护各有一定不类同的资源渠道各有各的坚持和特点不是那种会随意出卖机密的人唯一的问题是都只有序列9不太适合塔罗会这种高端严格的隐秘组织。高端的组织？感觉更像传销。当时愚者只想掩面长叹对正义自我感觉良好竟找不到语言应对只能答应让她对那两位做进一步观察。当然正义也不是最开始那位天真烂漫的少女了谨慎地没提两位姓名和特点害怕倒吊人据此查到本身。正义说清晰感受到魔药消化迹象也许再有三四周就能完成观众的扮演读心者的配方得提上日程。擦干净身体边穿贴身衣物边想前天塔罗会上的事情。近二十天只约达斯特见过一面本着欲速不达只聊对方状态问心理炼金会一些无关紧要的事情。正义消化速度让他不得不提前琢磨怎么从达斯特那里得到序列8读心者配方。一颗一颗扣好衬衣纽扣又拿起另一块干毛巾包住头部吸收短发水分。和正义相比消化占卜家只快不慢到这周冥想和灵视状态时已经没再出现听见不该听见声音看见不该看见场景。反过毛巾又擦头发抬头望门口无声自语：总结的占卜家守则确实有效下周下周应该就能彻底消化掉魔药了小丑配方里的霍纳奇斯灰山羊独角结晶和人脸玫瑰还不知道去哪里弄也许可以学戴莉提交特别申请但那样肯定会被上层关注现在只想猥琐发育极光会在警察部门发展的信徒也被找到了但还是不知道Z先生是谁。亨利说这周结束前能完成红烟囱委托私房钱恢复到7镑出头不用担心怎么支付尾款。他之前给的部分房屋和住客资料暂时看不出问题又没空一个个排查。也许可以先看哪栋有红烟囱的房屋最近更换了住客。嗯这是个思路。静坐二三十秒穿上灰黑色长裤戴好领结扣稳枪袋将换下来的骑士练习服丢入洗衣筐开门走出盥洗室刚结束周三下午格斗训练没多久还在高文家里。您好莫雷蒂先生。高文的杂活女仆刚好路过忙躬身行礼。微微点头指着凌乱湿漉的盥洗室麻烦你清理一下。这是我的职责衣物会由浆洗女工处理她六点过来。浆洗女工不包吃住给的报酬也很低所以不会只受雇于一家往往承揽附近好些居住者的衣物或者每天匆匆忙忙赶场洗完一家立刻去另外一家或者全部搜集至家里一起处理依次送回只有这样她们才能勉强生存。没再多言来到客厅向坐在摇椅上的主人告辞。两鬓发白的高文没什么生气地颔首双腿之上铺着条浅褐色毛毯手里拿着份阿霍瓦晚报。知道眼前这位沐浴西斜阳光的男士其实刚五十出头但暮气沉沉得仿佛已八九十岁。平时格斗训练高文也保持沉默只在该指点时开口绝对不多说不闲聊克莱恩则由于每天累得要死要活缺乏主动攀谈欲望所以双方关系到现在依旧冷淡。看高文老师的演示力量还相当惊人步伐也足够敏捷打我三个估计都不成问题他有警察厅给的薪水在廷根郊区乡村还买了片土地可以收取固定地租雇佣着一位厨师一位杂活女仆一个浆洗女工在地球上的大吃货国有这样身家的五六十岁先生早满世界旅游去了。将视线收回暗自摇头来到衣帽架取半高丝绸礼帽和黑色薄风衣。穿戴齐整拿上手杖走出房屋沿着两侧长有杂草的石板道路靠近大门。就在这个时候看见铁栅栏外停着一辆双轮马车站着一个熟悉的男士。伦纳德？疑惑望着头发肆意凌乱的值夜者队友低声自语。身穿白衬衣黑长裤和无扣皮靴手里正旋转着自己的帽子看见克莱恩出来含笑：惊喜吗？只有惊没有喜。无视不正经盯着假诗人的绿眸：有什么事情？将帽子戴上：队长让你配合我和弗莱我们路上再详细说。好的跟着进入马车车厢。等到两边风景后掠伦纳德拿起旁边公文袋丢向对面。稳稳接住取出文件仔细翻阅。8月11日晚上11点西区济贫院内破产的索尔斯企图纵火制造惨案但最终只烧死了自己。8月11日晚上10点码头工人齐德跳入塔索克河结束了贫穷的生命。8月11日晚上8点铁十字街下街以糊制火柴盒为生的劳维斯太太突发疾病死亡。看到前面两件一阵疑惑认为类似死亡事件实在太普通太常见不仅不该引起值夜者重视就连警察部门也得避免警力浪费。可往下看去渐渐皱起眉头。翻了两页猛然抬首望向伦纳德：这未免太多了吧？当正常的死亡事件多到让人惊骇的程度时就很难称得上正常了。难得正经地点头：过去两周内的死亡事件是正常值的五倍。廷根市警察总局统计数据的时候发现了这个问题赶紧将事情移交给了我们移交给了代罚者和机械之心。虽然这些死亡事件初步核实都没有问题但队长认为我们必须重新查一遍而这就可能需要占卜或者仪式魔法的辅助了。恍然：我明白了。打了个响指：我你和弗莱一组他在铁十字街下街等我们西迦洛耀和老尼尔一组调查北区的相应事件队长留在安保公司内应对意外。郑重点头忽然想起一件事情连忙问：我能先回一趟家留一张纸条吗。得告诉哥哥和妹妹自己今晚有事不在家用餐。笑了起来没有问题刚好顺路。这才定下心再次翻阅那些死亡事件试图从不同的死法不同的名字不同的时间点里找到关联。看着看着油然想道：这就是我成为值夜者后的第一次集体任务？

# 1278 倒吊人 第十三章 迫切感

## 打开书
末日……虽然正义奥黛丽早就从知识教会那位半神口中知道关于末日预言但对此一直缺乏实感总觉得那是用来欺骗民众宣传。哪怕她已经历一场个人异常渺小战争也不认为这个世界距离末日只剩十几年。这一点迹象都没有！不过现在说出末日预言是愚者先生眷者一直都值得信赖敢于打天使主意世界先生而且语气是那样笃定似乎他已经真切看见十几年后将要发生事情。这让奥黛丽本能就选择相信内心骤然一沉既紧张又慌乱。除这些她还感觉自己迷茫一下消退不少——还有十几年就要末日了就算溺水人都会挣扎一下更何况一位状态完好序列4半神。末日……作为风暴教会枢机主教倒吊人阿尔杰最近看过不少末日预言但那些无从证实东西哪里比得上世界格尔曼·斯帕罗异常郑重提醒两者带来冲击根本不在一个层次上。与此同时他还敏锐注意到一个细节那就是世界说神灵都会毁灭。阿尔杰第一反应是格尔曼·斯帕罗对愚者先生不敬因为愚者先生也是一位神灵。但他迅速就否定这个想法毕竟世界格尔曼·斯帕罗是愚者先生眷者是最虔诚信徒塔罗会其余成员或许还有一定可能在言语间不小心亵渎到愚者先生世界格尔曼·斯帕罗那是绝无可能。基于格尔曼·斯帕罗不会对愚者先生不敬和他说了神灵也会毁灭这两个前提倒吊人阿尔杰很快得出另外结论：在世界格尔曼·斯帕罗心中愚者先生位格是高于真神！这……阿尔杰从不怀疑世界格尔曼·斯帕罗见识毕竟这是一位经常和天使打交道强者。……以命运之蛇血液晋升半神对应序列3叫做预言大师隐者嘉德丽雅偶然也会梦到末日来临般画面加上神秘女王贝尔纳黛时不时提醒她并没有因世界先生刚才话语产生诧异和震惊情绪只是有种扬起灰尘终于落到地面感觉。对于未来这位神秘学家同样迷茫除提升自己不知道该往哪个方向用力。末日……审判休和魔术师佛尔思隔着隐者女士对视一眼感应到对方心中掀起惊涛骇浪。……因为说话那个人是世界格尔曼·斯帕罗所以两位女士都未怀疑末日预言真假一时又惶恐又沉重。最开始时太阳戴里克难以遏制产生一定沮丧因为白银城刚离开末日般神弃之地来到光明世界结果用不了多久又要迎接新末日。很快他调整心态选择相信愚者先生。……虽然我是末日时血族救世主但也没想过末日会这么快降临……我才只是一位伯爵……月亮埃姆林忍不住微皱起眉头就像是才上几天课学生突然要迎接考试一样。……星星伦纳德从老头帕列斯·索罗亚斯德口中听过末日预言事情虽然不知道为什么会有这样发展但早就有一定心理准备此时最先回过神来开口问道：为什么末日会突然降临？现在一点迹象都没有……克莱恩操纵假人世界回应道：只是你们没有发现迹象而已。难道你们以为神战会毫无缘由爆发？见塔罗会众位成员都被震住陷入思考世界格尔曼·斯帕罗又补充一句：具体原因你们暂时没有资格知道那仅仅只是了解都会带来难以抵御污染只有天使及以上存在才有可能抗衡。这和知识教会那位半神说差不多……也接近星空污染……我好像遗忘什么事情……世界先生似乎已经了解原委……他不害怕被污染？他他已经是天使？是祂？正义奥黛丽脑海内闪过一个又一个念头敏锐察觉到世界格尔曼·斯帕罗可能已完成……紧接着倒吊人阿尔杰隐者嘉德丽雅等塔罗会成员都解读出那个事实知道世界格尔曼·斯帕罗已经站到现实世界顶端成为行于地上天使。他们有猜测这与格尔曼·斯帕罗之前谋划对付一位神话生物有关有相信这是愚者先生进一步复苏对眷者带来好处。……当然对于世界格尔曼·斯帕罗晋升至序列2这件事情他们都不是太意外早就变得麻木。克莱恩操纵世界让他环顾一圈道：你们接下来可以好好想一想之后打算做什么准备怎么做。审判休和魔术师佛尔思等塔罗会成员微微点头表示自己知道了。……你打算去哪里？两人同时开口道接着又同时沉默。……糟糕忘记今天下午有课了！这少年边喃喃自语边冲向楼梯口完全无视两位女士存在。……我准备回军情九处努力做事。我打算去老师那里一趟。佛尔思也回答刚才问题。紧接着这位旅行家身影飞快透明消失在原地。……然后她从暗袋里拿出纸笔写个留言条打算告诉老师自己已消化完旅行家魔药。……把烛台擦一擦。……我是在取悦母神。埃姆林咕哝一句走到后面房间换上大地教会褐色教士袍开始劳动。不知过了多久门口突然进来一堆人。埃姆林下意识望去看见卡西米·奥德拉男爵看见曾经来丰收教堂工作过欧内斯·博雅尔子爵看见一张张熟悉面孔。埃姆林嘴角不知不觉就翘起来。

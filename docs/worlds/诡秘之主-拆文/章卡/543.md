# 543 旅行家 第六十二章 专家级

## 打开书
克刚理清思绪艾尔兰就追上两人微笑说：「找到目标了排查结束了我先送你们回旅馆等两天再把报酬带过来还有今天最好不要外出。」维持人设只轻轻点下头没开口回应。返回蔚蓝之风旅馆途中达尼兹明显有疑惑或感叹想表达但碍于旁边军方人员艾尔兰存在只能转移话题饶有兴致讨论今天会有哪些海盗在这场全城排查里落网。对他来说那些家伙只要不属于黄金梦想号就不算朋友根本不值得同情。进入旅馆房间目送艾尔兰离去后边关门边啧啧说：「天灾之书…古精灵遗迹…这真是件有趣事情不过精灵怎么弄得和恶魔一样？只是拿了他们书随意翻翻那个女人就疯了失控了！」你心目中精灵是什么形象？活跃于山林海中擅长烹饪喜欢自然生物？呵按照小太阳说法大灾变前八位古神都非常暴虐非常残忍非常邪恶这里面就包括精灵王而信仰祂并以祂为王精灵们大概率不会好到哪里去具体可以参考极光会成员…黑暗纪元存留下来那些超凡种族基本不会和正常人概念里好联系在一起…心里回答两句。当然并不排除古神陨落后巨龙巨人精灵血族等生物逐渐摆脱负面影响最终变得较为正常可能但这只会局限于中下层不包含那些半神级强者而留下天灾之书上位精灵显然是后者。念头一转忽然察觉一件事情：达尼兹懂精灵文！他认出羊皮古籍名称是天灾之书！冰山中将对船员教育竟然到这种程度不仅仅普及古弗萨克语还教导能撬动自然力量精灵语…说不定巨人语古赫密斯语也在黄金梦想号课程里…真是一伙有知识有梦想海盗不过船长女士你是不是太偏科了达尼兹在很多方面表现得并不及格…也是主职为宝藏猎人海盗最重要就是掌握古语言…未理睬感叹将视线投向窗外。此时天空依旧有些阴沉似乎随时会降下暴雨让人不由自主感觉到压抑。微不可见颔首略感放松想着：「找到拉蒂西亚知道西弥姆岛上古精灵遗迹风暴教会和王国军方应该很快就能借助那遗迹与卡维图瓦藏身处联系找到这个越来越疯狂海神或者利用那遗迹加速它崩溃。这样一来除了最狂热最虔诚海神信徒会死亡其他人基本不会受到什么伤害…」原本还想用灵界定位方法在海神陨落后官方非凡者找到它藏身处前潜入那里顺走宝藏但这个计划还未开始就似乎因天灾之书出现濒临失败。呼…也没什么只存在于想象里从未属于自己物品没有也就没有了…我甚至不知道能收获什么…这件事情这样解决是最好…收回观察天气目光心情平静而放松仅略有些不可避免失落。这一天他和达尼兹遵从艾尔兰建议没再外出只在旅馆内活动。而拜亚姆城中时不时响起零零星星枪炮声爆炸声直到天黑才完全平息。……第二天清晨准时起床发现半空层云叠压天色依旧阴暗。这说明风暴教会枢机主教代罚者高级执事亚恩·考特曼和海神卡维图瓦对抗还在进行。感受下肚子疼痛准备拿份报纸去盥洗室。可看了看正叼着白面包躺在安乐椅上悠闲阅读报纸达尼兹又放弃这打算。坐马桶时候看报纸不符合格尔曼人设！虽然这会很无聊但扮演不能放松…唉又找到一个真正自我和伪装身份在行为选择上不同…默默做着总结走进盥洗室。褪掉裤子坐到马桶上近乎发呆看着前方浅白色墙壁似乎想从上面读出文字来。就这时灵感突有触发。忙叩动牙齿开启灵视。两根粗壮高大白骨出现于面前正是信使双腿。信使站在那里脑袋穿出天花板但眼窝内漆黑火焰依旧能看到。微低脑袋俯视着坐在马桶上克。抬头仰望愣两秒脑袋里转过全是莫名其妙想法：我是该像女士们一样匆忙遮掩下体还是坦坦荡荡无所畏惧…在他做出决定之前信使丢下封信刷地崩解成白骨暴雨般落下消失于地板。呆愣接住阿兹克先生回信好一会儿才反应过来。这个信使越来越不礼貌了！没看到我在上厕所吗？都不知道先敲门或者从门下面缝隙里塞进来啊！好气又好笑暗骂。仔细想了想又觉得从门底缝隙塞信有些为难信使身高近四米庞然大物得趴下来才可以够到那个位置。那画面想一想还是挺搞笑…嗯下次写信时候多一段内容让阿兹克先生好好教育下信使让它懂得礼貌…展开信纸阅读起阿兹克回复：「…根据我能回忆起来知识我可以提供两个办法第一个办法必须有足够前提条件那就是你或者别人独属物品在海神卡维图瓦那里这就可以借助占卜轻松定位…另一个前提是你可以进入灵界这方面我有足够技巧以下列出常用三种…第二个办法是利用密契仪式向红光艾尔·莫瑞亚祈求祂表征着权力与意志某种程度上掌握着与灵界生物灵界地点相关知识…」原来七道净光之一红光叫艾尔·莫瑞亚…密契仪式原理是调整自身状态放开身心让自己与祈求目标一点点契合最终部分重叠收获对应知识而这种契合和重叠是相对我收获知识同时本身秘密也对祈求目标开放了…我可没法信任红光…我有太多秘密…第一反应就排除第二种方法。至于第一种也缺乏成功可能并没有独属物品在海神藏身处。「除非能借助反抗军送点东西给卡维图瓦或者找到海神信徒曾经献祭过物品原本主人而且必须是专属…送点东西给卡维图瓦…」想着想着忽然有了主意。一下精神反复推敲几遍认为这有一定成功概率。蹲完厕所清洗过双手当即逆走四步来到灰雾之上就自己想要做尝试进行占卜得到有一定危险但只要处理得当就可以承受启示。做完这一切回到客厅走至安乐椅旁。达尼兹刷地坐起干笑开口：「有什么事情？」「你知道海神对应祈祷词吗？」语气没有起伏问。摊下手忽然嘶一声。「狗屎…」低骂伤臂一句转而笑道「知道我见过好几次反抗军举行仪式额…具体是大海与灵界眷者罗思德群岛保护者海底生物支配者海啸与暴风掌控者伟大卡维图瓦对了有效果两次是用精灵语念。」大海与灵界眷者…姿态摆得很低嘛…和我尊名有本质不同…也是我是仿造七位真神编…轻轻点头道：「你知道哪里有没人仓库废弃房屋吗？」「当然！每个大海盗都掌握了一些。」毫不犹豫回应。当即转身走向衣帽架：「带我去。」去做什么？虽然疑惑却不敢询问。……码头区一座肮脏破旧仓库内。达尼兹看着格尔曼拿出三根蜡烛和多个金属瓶子终于按捺不住好奇开口问：「你你想做什么？」没有回头非常平静回答：「献祭。」「向谁献祭？」饶有兴趣追问。布置好祭台拿出一个铁制卷烟盒语气平淡说：「卡维图瓦。」他想定位办法就是直接给海神卡维图瓦送东西！只要卡维图瓦收下他就能借助占卜等手段找到对方藏身处！至于卡维图瓦会不会收问题他当然有考虑过认为这存在一定可能性因为卡维图瓦现在状态是濒临死亡非常疯狂基本不会有理智仅靠本能行动而它对灰雾气息也许有强烈渴求。所以准备献祭一个经常放在灰雾上铁制卷烟盒试一下卡维图瓦会不会收如果不收也不会有什么损失就当没这回事情。向海神卡维图瓦献祭？这个瞬间达尼兹觉得自己脑袋有些不够用完全无法理解格尔曼想法。「你疯了吗？它怎么可能接受你献祭？就算接受了又有什么意义？它都快死了！而且这很危险！」脱口问。旋即心里补一句：不格尔曼没有疯因为他一直都是疯…瞥他一眼简单说：「在这方面我是专家。」献祭仪式领域我是专家级！对此并不谦虚。

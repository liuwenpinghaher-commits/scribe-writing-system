# 158 小丑 第一百五十九章 “赐予”与“献祭”

## 打开书
黄褐色羊皮纸上略显扭曲张牙舞爪的中文。8月2日这潭水比想象还深历史真是任人打扮的小姑娘。8月5日见识高序列强者简直可怕某方面已质变像神灵难怪一直用半神半人来描述我觉得称呼神话生物可能更加恰当。8月6日奇怪为什么七大教会对待魔药会有那样诡异的态度中低序列不仅给晋升者主要材料还慷慨分享配方演示配制如果有仪式也详细讲解高序列只提供成品魔药。这完全不符合逻辑中低序列材料相对容易制作较简单不是该保密配方直接调制给目标吗到了高序列主要材料难以获得不是该分享配方让有希望者主动去找吗这里面肯定隐藏着我还不知道的秘密。8月9日这两天让我感觉不是太好我亲手开启的工业革命亲手铸就的蒸汽与机械时代将成为邪神降生的温床。什么意思邪神降生的温床克莱恩微皱眉头食指轻缓敲击古老长桌边缘。愚者先生遇到难题了能让他为难的事情肯定涉及很高的层次奥黛丽从肢体语言里解读。只靠这么单纯两句话要占卜出实质不可能我又不是预言家直接占卜邪神降生的温床感觉在作大死邪神未必有永恒烈阳那么恐怖但能力也许更诡异说不定顺藤摸瓜就找到了我也没办法占卜这样尝试有多大危险一旦涉及神灵占卜有没有危险本身都会带来危险。先记住多观察。教会安排确实诡异也许等通灵者不该死灵导师戴莉成为大主教或高级执事进入核心能获得一定暗示。罗塞尔说得真让人有点向往高序列强者的风采。停止轻敲望了望正义倒吊人太阳你们可以自由交流了。倒吊人当即开口愚者先生正义小姐我新获得了一份情报飓风中将齐林格斯潜入贝克兰德是为了完成一件困难的任务或许会在那里停留很长一段时间并且制造骇人听闻的惨案另外这件事情涉及一件非常重要的物品能帮助齐林格斯很快成为高序列强者的物品。很快成为高序列强者他就不怕失控吗奥黛丽抓住重点摆出观众姿态。齐林格斯才是序列6的风眷者距离序列4还隔着一个序列5。所以那件物品才非常重要当然这都是我的推测情报是齐林格斯认为一旦完成委托拿到那件物品他很快就能与五海之王纳斯特等人并称让海盗里的四王变成五王让七位海盗将军减少至六位。普通人或许不清楚作为非凡者我们应该都知道四王要么直接是高序列强者要么在超凡船只和神奇物品配合下拥有高序列的战力齐林格斯要想获得承认必然也要有接近的水准所以我才那样推测。我只知道五海之王纳斯特是序列4不清楚他的魔药名称克莱恩安静听着没有轻易表态。太阳完全弄不懂倒吊人描述的事件根本不知道谁是谁依旧听得很专注只觉世界在眼前呈现出一扇新的大门。海盗他们生活的地方有书本上宣称的海洋那和白银之城周围环境有很大区别他们似乎从来不担心诅咒不担心黑暗之物的侵袭真是让人非常好奇愚者先生叮嘱过不要随意询问别人的秘密那是不礼貌的行为沉默地想来回审视倒吊人和正义。你的推测很合理当然那也可能是一件能媲美高序列强者的神奇物品正义浅笑。倒吊人望了眼高踞灰雾里的愚者斟酌后看着正义强调我刚才的描述有两个重点一是齐林格斯会在贝克兰德待很长一段时间二是涉及一件非常重要也可能非常神奇的物品。所以愚者先生您不心动吗您有充裕的时间让您的眷者到贝克兰德阿尔杰默默内心补了一句但不敢直接说只能委婉点一下。倒吊人先生你不必反复强调我听得懂但是我的实力不支持我掺和而且我也没办法擅自离开廷根后靠住椅背颇为无奈。不说眷者我倒是能找到两个较为强力的非凡者帮忙一个是已经晋升序列6的戴莉但我不可能向她说明所有情况顶多提一句线报飓风中将潜入贝克兰德那样一来戴莉很可能会直接调动值夜者的力量让事情变得非常混乱非常麻烦到了最后如果你们依旧没能找到帮手可以这么试一下避免惨案另外一个是阿兹克先生但我不可能向他透露愚者的身份要想请他掺和缺乏足够且正当的理由。平缓开口我知道了。见愚者依旧没有表态不重视齐林格斯的事情阿尔杰暗叹一声收敛失落开始与正义交流这一周的调查结果。总之我们初步锁定了齐林格斯的大致活动范围即将开始更进一步的寻找奥黛丽带着一种我在做大事做正经事的心态我们需要更多的情报重点是齐林格斯的爱好与习惯。他非常喜欢吃鱼尤其是海洋里的鱼切片生吃他爱喝烈酒看不起香槟和红葡萄酒等一旦上岸总是会找女人发泄强壮的身体让单独的一个女人无法满足他习惯用冷兵器排斥热武器很难长时间脱离水隔几天就要游一次泳或者潜一次水。奥黛丽一一记住在脑海里勾勒并丰满那个叫做齐林格斯的角色。希望能够成功合作愉快。合作愉快阿尔杰只能强迫自己相信在贝克兰德很有能量的正义小姐。他们交流之中克莱恩看似认真倾听实则思绪发散想到如果太阳希望得到材料该怎么给付。神秘学已经能够勉强及格习惯性往仪式魔法领域寻找这属于前面成功累积出来的路径依赖。之前翻值夜者内部资料看到过女神赐予信徒圣物的记载不少涉及邪神和恶魔的祭祀仪式里也有物品降临的描述这是不是意味着我能在回应祈求的时候赐予对方物品以此完成材料的给付。之前的尝试里我暂时只能回应包含图像和声音的意念但这不意味着永远只能这样等我晋升序列8并稳定下来或许会有新的变化。另外还有一个关键点我是否能将真实的材料或者物品带入灰雾之上对那些涉及邪神和恶魔的祭祀仪式往往包含了献祭环节我是否可以考虑自己献祭事物给自己这样一来也许真可以将现实的材料和物品带入灰雾之上如果尝试能够成功我就可以直接从正义太阳和倒吊人那里得到物品与材料然后自己赐予自己。献祭属于较为高级的仪式我暂时还接触不到目前最重要的事情还是尽快提升自己。收回思绪继续用高深的姿态听着三位成员交流从齐林格斯一直讨论到某些怪物的特点。差不多之后他微笑今天就到这里吧。遵从您的意愿太阳戴里克和正义倒吊人同时起身。切断联系之后克莱恩也飞快坠入灰雾离开那片神秘空间。回到卧室解除掉灵性之墙拉开凸肚窗的帘布让外面的阳光照射进来。这一周有两件重要的事情一是接受考查晋升序列8二是制作出阳炎符咒它的威能甚至会超过序列7序列6望着外面的街道充满期待明天明天应该就能收到阿兹克先生弄出来的灵异事件的报告了。

## 这场戏有没有翻
翻了。开头还在读日记皱眉敲桌；自由交流把齐林格斯说成贝克兰德长期惨案加一件能让四王变五王的物；愚者只回我知道了；章末独处才把章题落到赐予献祭两条还碰不到的仪式上。翻的是聚会公开的情报和私下的通道设想不是已经献祭成功。蒸汽温床没有答案。

## 这一章新讲明的规矩
- 高序列某方面质变像神灵，罗塞尔愿称神话生物；教会口头半神半人。
- 七教会魔药：中低序列给主材料、分享配方、演示配制、有仪式就讲；高序列只给成品。罗塞尔认为这反着逻辑。
- 蒸汽与机械时代或成邪神降生温床——日记问句，当场无解。
- 涉及神灵：占卜危不危险本身会带来危险；单纯两句占不出实质；他不是预言家。
- 海盗四王：本人高序列或船＋神奇物品顶高序列战力；将军七变六是齐林格斯的自我预期。
- 愚者叮嘱过：不要随意询问别人的秘密，不礼貌——太阳守着。
- 回应祈求目前只能图像和声音；晋升序列8稳定后或有变化——猜想未试。
- 女神赐圣物、邪神恶魔祭祀有物品降临：他想用来赐予材料。献祭或能把现实物带上灰雾，再自己赐给自己。献祭是较高级仪式暂时接触不到。
- 灵性之墙解除后才拉开帘。

## 怎么起、怎么收

## 叙述怎么插手
作大死／顺藤摸瓜是他不敢占。四王战力是阿尔杰讲给非凡者听的常识。海洋与诅咒是太阳对照白银。路径依赖是叙述点他为什么往仪式上想。高深的姿态是他装的。

## 可搬走的一条作法
以后写别的书：让日记先把神的问题问到不敢占卜，再把聚会公开情报压成一句我知道了；章题那两样办法只在人散了才敢想，并且当场写明还碰不到。书证 L14207：「我是否可以考虑自己『献祭』事物给自己？」

# 527 旅行家 第四十六章 放牧

## 打开书
清晨时分天色微亮墙角巷内多是安静不动幽暗。借助达尼兹斗篷克融入阴影里快速穿行游走只觉四周灰黑透明现实抽离模糊所有声音都仿佛从星空深处传来空荡而悠远。最大程度远离香树大道后辨别位置从阴影里长出浮现于一条布满残砖碎石无人巷子内。双手一抖将孔雀蓝飞毯裹住钢铁甩出去扔到面前务求在对方灵体开始消散前能完成放牧！丢掉飞毯上前一步伸出左掌微张五指居高临下对准尚有余温尸体。蠕动饥饿随之露出原本样子薄薄仿佛人皮制成。掌心位置裂开两只眼睛瞳孔鲜红仿佛血染。呜！巷子内突然刮起一阵寒意浸入骨髓微风它在钢铁尸体上打旋扭曲着形成一道近乎透明人类身影隐约能看出厚厚嘴唇和钢珠般卷发。麦维提灵体表情异常痛苦竭力抗拒蠕动饥饿吸引而灰白和黑绿交杂一点点光芒如同涌动银河迅速从血肉之躯里飞出融入那透明身影。「不！」发出无声惨叫试图求饶已来之不及只能绝望钻入人皮手套里面被固定在空白那根手指上并张扬出非凡特性与所处环境发生一定关联。这种关联就决定了放牧钢铁灵魂时能使用他哪些能力或许一个或许两个不超过三个。具体内容在固定下来前不受克控制纯粹随机。蠕动饥饿迅速覆盖满苍白最终又变回之前伪装样子：一只普普通通黑色手套。闭目感应几秒有些放松又有些喟叹吐口气。这一次运气不算差但也不算太好。成功获得钢铁三种非凡能力但其中没有他最想要不怕枪击不怕火烧不怕一定当量炸弹体如钢铁和顽强生命力。一是活尸力量能让我做出狂暴攻击弥补以前敏捷型格斗风格缺陷二是对冰掌握虽然无法像魔女途径一样凝聚冰枪制造暴风雪做最直接攻击但可以冰封四周地面降低空气温度有效影响对手行动如果出现身体接触甚至还能冻住敌人僵硬他血肉完美搭配格斗能力三是操纵活尸呵呵以后我也不怕人不够组不起牌局了…略作思考弯腰检查起钢铁随身物品。很快翻找出26镑11苏勒8便士现金以及一堆看似正常实则奇怪东西比如蜡烛夹子带刺皮鞭等等等等。考虑到钢铁大概率是玫瑰学派成员且属于放纵欲望那一系隐约明白什么呸一声收起现金。狼人有超强自愈力活尸有钢铁般身躯确实不需要带治疗类药剂或物品…和达尼兹判断一致麦维提没有神奇物品…也是神奇物品数量稀少许多又有明显缺陷和负面效果不是谁都想拥有谁都能拥有之前怨魂活尸狼人组合也才两件神奇物品深红月冕和生物毒素瓶…点点头从衣兜里取出一张叠好纸。展开这张表面发黄纸将它放在钢铁身上盖住对方脸孔。这是一张悬赏令上面印着麦维提肖像画和对应悬赏金额：「6000镑！」站直身体退后一步踩住那张孔雀蓝飞毯抽出一个纸人。啪！小臂一甩手腕抖动将纸人扔出去化成火屑洋洋洒洒飞落。紧接着又变成阴影与物品一起消失在这条巷子内。过了两三分钟科尔多瓦才带着部分代罚者队员匆匆赶到正好看见一阵凉风将悬赏令吹起露出钢铁血肉溶解眼睛圆睁脸孔。哗啦啦悬赏令掉在旁边依旧正面朝上。……失去目标踪迹科尔多瓦等人带着钢铁尸体沉默返回之前发生战斗区域。看眼检查现场队员身为执事科尔多瓦收敛情绪沉声问：「太阳信徒？」这对他对本教区来说是最为重要问题。负责寻找线索用超自然手段还原真相代罚者队员并不是风暴途径非凡者而是阅读者对应序列7守知者也就是侦探没急着回答走过来蹲下去检查起麦维提尸身。过一阵抬头说：「不是太阳信徒借助应该是神奇物品力量。」「理由？」皱眉问。那位代罚者队员道：「这里有来源于血肉深处邪恶感其中一具尸体就是这样被吞噬只留下本身特异和物品如果是太阳信徒即使是依靠物品也不会做类似事情对他们来说真实造物主领域东西都是污秽必须立刻被净化或封印不该也不能借用。」科尔多瓦想几秒认同这判断转而问：「极光会人？」「不真正蔷薇主教或牧羊人不会这么粗糙他们肯定会将尸体包裹在自己体内等离开后再做处理没理由当场肢解既浪费时间又留下一堆还算有价值东西。这么急着吞噬很像是神奇物品负面作用。」守知者冷静说。「同时拥有太阳和秘祈人领域神奇物品？或者类似牧羊人能力那种？贝格你判断是哪个？」身为执事有权限了解牧羊人和他们特殊能力而那位守知者知道是基于他在队伍里定位其余代罚者则不明白他们在说什么。守知者贝格站起来：「都有可能。」「有怀疑对象吗？」沉声问。贝格摇摇头：「暂时没有目标。但可以确认一点血色荆棘是烈焰杀另外那位是他帮手一个相当可怕强者不比海盗将军们差。」「一个可怕强者…」表情凝重低语一句旋即眼睛一亮道「会不会是艾德雯娜？她能模拟自身见过一些非凡能力！」守知者沉吟下道：「不排除这可能但情报显示她几天前还在苏尼亚岛附近除非除非她能模拟出相应能力借助灵界穿梭过来。」科尔多瓦来回踱几步环顾一圈道：「处理现场不要惊动附近居民。我会将任务报告提交上去希望能得到更多更有效情报。」这涉及一个战力至少等于序列5强者让他只能克制住暴躁心情做出最理智决定。……老奎因房屋内沉重石门封锁地下室中。坐在矮床上安静望着桌上烛火阿尔杰眼前忽然一花看见弥漫灰雾以及灰雾深处端坐高背椅俯视着一切愚者。一道模糊人影置身下方双手交握抵于脸前用虔

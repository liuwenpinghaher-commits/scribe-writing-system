# 476 无面人 第二百六十四章 愚者千虑

## 打开书
先映眼：环绕层叠光辉祭台＋台内高瘦人影。取兜帽露漂亮妖异宛女性脸；左胸肩腹大腿四位覆蠕动粘稠恶心血肉。四周光层充虚透影洋溢麻木绝望痛苦压抑。台外四祈祷影已倒——皮干瘪紧包骨如风化多年尸。大厅上方辉芒穿虚空来顺石柱地板空气飞投入台。克刚出躲——A已睁眼望其所在。瞳染血冷漠蕴极致疯狂。换别非凡恐下意识移目不敢对；克直面过永恒烈阳见渎神阿蒙未惧；冷静扣扳机铭纹银猎魔子弹激射奔台。A下意识想抬手终停——漠看银弹钻光层。无声满纹猎魔在层叠辉内融化消失被难数清不甘怨念负面吞没；彻底分解无痕。眼眸缩砰砰连扣余弹全射——淡金净化黄铜金芒驱邪首尾相接贯光层。同样分解消失未涟漪。A嘶哑笑：「没用小爬虫；仪已正式开始；以你力无法打破中断；即使序5亦办不到！但你幸运将活见证我主降临融入祂身躯。」不再理闭眼——对方确只渺小虫。「牧羊人」半举双手敞怀古赫密斯高喊：「创造一切的主；阴影帷幕后主宰；所有生灵堕落自性。您虔诚信徒祈求您降临；我愿奉献身躯让它作容器承担您伟大意志！」祈祷顶突光从未知降笼罩。四周不甘怨念负面潮内卷涌入A体。砰砰砰！克连响指操纵火竭攻台——仍不可抗光层内分解熄灭消融无效果。怎么办？他奇物皆灰雾上；取出须仪至少一两分；无保护肉身危…理智停尝试站思绪电转。太阳胸针生物毒素瓶全黑之眼黑皇帝牌皆似难破屏障！只能等正义及时援？或眼睁睁看真造降临？精神紧念头飞过滤身物掌沁冷汗。突然想到某样！来不及虑后果手伸衣兜抓充满金属质感物。蹬蹬蹬前跨几步用力甩——攥物扔出台。黄铜辉闪入层叠光层。形制古朴钥匙。「万能钥匙」。光层内黄铜万能开始分解融化。外壳不见——内蕴诅咒直接现；连接未知「门」先生。……切皇后区霍尔伯爵豪宅。奥黛丽立落地窗忧望远。天边雾渐浓淡黄染铁黑慢慢往己方渲染。「有些不对劲。」金毛苏茜蹲旁眺望本常见雾霾。希望来得及阻…不清雾代表何；默心里向女神愚者祈勿让原初魔女降临。忽然窗外枝摇玻璃轻振。「风来了…」莫名喜悦。切乔伍德圣风大教堂。外突浮肉眼可见恐怖风暴——向东鼓荡难想飓风。呜！沉积雾吹散浓黄铁黑飞快淡。呜！干枯枝落粉尘泥土扬随雾远。呜！行人帽离头身摇须扶树墙。码头水手如回港口见台风。东区工厂烟气淡健民轻微不适缓解。轰隆雷电跳炸。很快平息哗啦雨洗地。「风暴教会这次反应很快嘛…也有我等提前行动准备不太充分原因…呵呵中产富翁无相应保护在大雾里和平民毫无区别都待宰羔羊…」绝望坐出租马车悠然听雨敲玻璃。哪怕及时破——估雾霾直接死20000以上；后续还有蔓延瘟。魔药消化差不多只顺带收获…大量人口失踪痕迹将被抹去指向极光真造；没谁猜王室真想做…该离带走特莉丝…心情不错。行踪隐事前处理短时不惧贝克半神堵；等找到痕已远离！准备离马车——眼前一花见人影。对面年轻女披兜帽古典长袍眼发皆黑面容秀美但呆滞。……扔万能钥后克又握阿兹克铜哨屏息等结果。若构想未实现屏障仍未破——用铜哨看能否得信使助。再不行进灰雾搬黑皇帝等试每可能拼最后一秒！此时下午无绯红更无明澈满月——对万能内诅咒缺够信心；只望屏障消解威胁让它本能反应如反向沟通门先生传求救声。一两秒——见万能分解最微光粒＋一片虚幻扭曲绯红。绯红快速变淡竭力挣扎猛爆！刹那失听力——见光层内怨念不甘无数影齐仰头惨叫。飞快变染黑绿长第二脑颅第三眼或第五腿…交汇洪流涌入A体。A霍睁眼淡漠血色下不敢信惊愕。紧接着祭台四周光层扭曲坍塌。轰隆！巨爆从台中央外扩掀恐怖风浪。喀嚓！近四粗大石柱瞬折——远克只来得及翻滚被冲击波拍飞。砰！撞墙一下扁平化薄纸。薄纸迅速后续风浪撕碎洒四周。本人浮现角落借墙对抗爆风浪。「万能钥匙」破坏效果超想象！强行消融诅咒确本能反应将门先生呐喊传递；至少天使级被放逐者声音污染仪需不甘怨念麻木绝望——祭台失平衡走向自我毁灭！风浪稍平克冲出确认。半空虚影压抑感已消；祭台只剩些许残骸。A身前倾跪倒塌石柱旁少臂少半脸诸多内脏；仅剩那眼充满刻骨恨。但伤口很快蠕动血肉覆。瞧一眼毫不犹豫拔腿跑。对他：破坏真造降临＝终极目标；此时不走序6难道留与牧羊人A共进晚餐迎新年？

## 这场戏有没有翻
翻了。开头瞄准开打；章末破坏后跑。翻的是万能钥污染仪，不是子弹打穿。

# 531 旅行家 第五十章 “洋”大人

## 打开书
转入两条主街道之一换了张脸孔克直奔绿色邮筒而去从衣兜里取出一封早就准备好信。这是他模仿警察局公文格式写死亡通知单寄送对象是西弥姆港口小镇警长内容是本地居民温特在拜亚姆突发疾病身亡消息。在决定做这次扮演时已经制定好相应方案务求事情能顺利进行不偏离轨道且不对女孩蕊妮造成难弥补伤害。计划是利用沉眠符咒将真实扮演伪装成一场梦境这样一来女孩蕊妮若是对温特没有爱情直接拒绝表白事后听说对方死讯时也不会有什么愧疚心理顶多感觉害怕而这可以通过去教会祈祷和告解有效安抚。如果女孩蕊妮同样喜欢温特回应告白梦境这理由则有助于脱身之后死讯通知则能斩断蕊妮期待不对她将来生活产生较为恶劣影响。「可就算这样还是有点残忍无论哪种女性面对喜欢男孩在死后托梦表白这种事情都肯定悲痛欲绝很长一段时间无法释怀。嗯…如果什么也不做等温特死讯正常传回来蕊妮必然也会异常难过只是不一定那么严重但是她心里那个结或许将永远无法解开会一辈子纠结于当初温特外出冒险是为了追逐两人未来还是单纯不喜欢自己…事情这样收尾未尝不好等她缓解伤痛就会带着那份曾经被人真挚爱过温柔对待未来生活。唉不管怎么样为了扮演强行涉足别人生活让无辜者受到一定影响即使有完成心愿做借口也不是真正善良事情真像罗塞尔说那样非凡途径越往后走越是有一种扭曲和邪异感觉扮演法未必不是催化剂…我只能尽力将这种影响压到最低…」投递完信吐口气顶着张毫无特色本地人脸孔向小镇唯一那家旅馆走去。途中总结下刚才经验那就是真实伪装成另一个人并收获反馈应该是无面人守则主要条款仅次于你可以伪装成任何人但只能是自己。换做某些无面人或许会为了这次扮演封锁温特死讯答应蕊妮表白用一到两年时间和对方恋爱结婚生子然后不受这身份各种关系束缚牢记自己是谁冷酷离开…这过程里如果一直没有暴露魔药差不多也就消化完毕了…但我真做不到啊！根本过不了自己这一关只能打打擦边球…一阵唏嘘莫名畏惧。摇摇头无声自嘲：「非凡者必须时刻对抗不仅是危险和疯狂还有源于自己各种各样恶念以及稍不留神就会沉沦堕落引力…就算这样到了最后说不定同样会被深渊污染成为自己发誓要清除那种怪物唉…」收敛心思踏入旅馆对柜台后老板道：「一个普通房间。」身材瘦削老板抬头看一眼道：「有效身份证明文件。」我这刚捏脸怎么会有？讪讪笑道：「忘记携带了。」「那你无法住宿这是我们小镇规定。」老板重新埋下脑袋计算今天收支。掏出张1苏勒纸币若无其事推过去。老板顿时瞪大眼睛：「不不收起它！我可不想被警长关起来！出去出去你这个没有身份证明肮脏家伙。」略显愕然被赶出旅馆无法相信万能金钱在刚才失去作用。沉吟几秒转入一条无人巷子变回五官深刻格尔曼。重回旅馆轻敲下柜台桌面用带着贝克兰德腔调鲁恩语道：「一个房间。」老板抬头一看当即放下手中物品边站起身边点头笑道：「好的好的。您需要能看见海房间还是比较安静？」改用蹩脚带着浓浓香料味鲁恩语再没有提身份证明事情。这真是一个现实世界…腹诽一句礼貌回应：「安静。」「是是好的。」老板连声回应。然后喊来侍者看守柜台自己拿上钥匙领着往二楼走：「先生您需要住几天？每晚是1苏勒5便士。」「今晚。」有些受不了这种热情言语简洁回答。在蔚蓝之风旅馆和达尼兹住豪华套房一晚是5苏勒。毫无疑问老板挑选那个房间干净而整洁港口旅馆常见潮湿情况也基本没有环顾一圈满意点头：「非常棒。」「这是我荣幸。」老板谄媚中带着明显畏惧。放下行李休息一阵起身重回底楼准备解决晚餐问题。整个一楼除柜台凌乱摆放着多张桌子表面都略显油腻角落位置壁炉熊熊燃烧散发出光与热。罗思德群岛偏南方冬日最低也就10度左右但对当地人而言这依旧是需要烤火寒冷天气。随意找个位置坐下点了份本地特色烤肉和香叶蘑菇汤主食则是土豆面包。等待过程里悄然扫遍餐厅内食客目光本能落到一位女士身上。这位女士有一头简单扎起黑发和一双极有特点青灰色眼眸长相属于耐看那种越瞧越有味道。明显不是本地人种却穿着男士衬衣配茶色厚夹克手边放着顶中间凹陷圆边帽。这是大海上较为常见冒险家打扮同一桌三位男士也是如此且有明显日晒雨淋特征。从不掩饰自己有欣赏美丽女士心态但对方引起注意却非源于容貌。大海上有着强烈歧视女性氛围能在冒险家海盗团里混出一定地位女人要么很有心机手腕要么实力很强要么两者兼备是必须小心和提防对象！他们皮靴上有较为新鲜泥点…刚才丛林内回来？呵呵真是冒险家啊…根据一些蛛丝马迹做出初步判断。如果这四位冒险家是从拜亚姆乘船过来即使之前有踩中污水碰到淤泥痕迹也应该早就变干而小镇内部道路因为这两天没有下雨还算整洁只是有些灰尘排除掉这两种可能就只剩下对方从郊外丛林里探索归来这一个解释。之前就听说过许多冒险家会深入殖民岛屿上原始森林内寻找被废弃被遗忘异教神庙或祭坛那些地方往往有古代供奉黄金和珠宝只是后来因种种缘由被埋葬在无人问津无人知晓地方各个岛屿酒吧内都不缺乏谁谁谁在丛林冒险里满载而归一夜暴富传说。那些地方说不定有邪灵徘徊…还不如狩猎海盗至少提前能获得相应资料…收回目光专心等待食物。七大教会将殖民地原始信仰里各种神灵归类为邪灵但克认为里面应该有一部分属于自然灵。过一阵特色烤肉端上来它们被切成许多小块串在木签上表面涂抹有棕红色酱料香味浓郁色泽诱人。和上辈子烤串有点像…在鲁恩都是一大块肉一大块肉烤烤完才由厨师分割…这里方式更加入味…拿起根木签咬块肉下来只觉肉汁微溢咸香之中带着微甜。是我喜欢类型！满意点点头。这一餐吃得相当满意甚至还品尝当地咕噜树树汁这是一种特色饮料就像加了糖和奶柠檬水。回到房间因为昨晚狩猎一夜未睡早早洗漱完毕熄壁炉钻入被窝。而睡得太早必然会有一个问题那就是半夜被尿憋醒。美梦中断睁开眼睛一点点积累掀开被窝勇气。半夜西弥姆有八九摄氏度样子就体感而言已算寒冷。静静躺一阵伸出手臂又默默缩回来。思考几秒再次探手拿起床头柜子上太阳胸针。虽然这只提供精神上炎夏实质并没有提供热量但至少可以欺骗自己现在不冷。挪出被窝直奔房间内盥洗室。眯起眼睛舒缓起下腹压力。一切完毕拉好裤子准备洗手灵感突有触发。微皱眉头抬眼望向盥洗室通风口。忽然一条黑而滑腻东西掉下来挂在那里。这是一条吐着芯子毒蛇！吓一跳张开嘴巴发出声音：「砰！」那条毒蛇惨遭命中变成两截。发生了什么事情？凝望几秒见再无动静遂走出盥洗室从衣物口袋里掏出枚金币。

# 1320 倒吊人 第五十五章 特殊的六条途径

## 打开书
愚者克莱恩缓慢环顾一圈没像大家期待那样解释反倒收起叹息笑着提出一个问题：你们认为二十二条非凡途径源头在哪里？这是神秘学最核心三个问题之一从来没有公认答案。……隐者嘉德丽雅斟酌一下回答道：世界本质是知识知识本质是数……七大教会都认为非凡特性来源于最初那位造物主……星星伦纳德简单描述道……生命学派认为世界分为三层……非凡特性就是绝对理性世界某些事物在物质世界灵魂世界投影……月亮埃姆林回看星星一眼道：作为第二纪主宰之一我们血族相信非凡特性确实源自最初那位造物主……倒吊人阿尔杰微微点头道：非凡特性起源虽然有很多种解释但大部分都指向最初创造者……也就是说非凡特性源自最初造物主是比较一致认知？正义奥黛丽若有所思问道。差不多是这样。……就在这时愚者克莱恩略带叹息说道：并不全部。……并不全部……愚者先生意思是非凡特性确实源自最初那位造物主但并非全部其中有少量属于特例？这就是耕种者和月亮途径存在特殊原因？倒吊人阿尔杰瞬间想到很多一下把握到问题实质。……尊敬愚者先生您意思似乎是绝大多数非凡特性都源于最初那位造物主而耕种者和月亮这两条途径例外那它们来自哪里？愚者克莱恩相当简洁说道：星空。……不止这两条。……尊敬愚者先生还有哪些来自星空？……囚犯罪犯律师仲裁人。前两条源于欲望母树后两条加失序之国都来自混沌之子。……仲裁人……魔术师佛尔思愕然转头看审判休一眼。……尊敬愚者先生我平时没感觉到有什么异常也从未得到过神启嗯来自您之外。……愚者克莱恩笑笑道：仲裁人和律师相对较好。……耕种者和月亮途径特殊来自星空感知到神启很有可能是一种污染？……大概是这样。……我已掌握耕种者和月亮两条途径高序列魔药名称……月亮途径序列3叫召唤大师序列2叫创生者序列1叫美神；耕种者途径序列3叫抬棺人序列2叫荒芜主母序列1叫自然行者。我比较不解是美神和荒芜主母这两个魔药名称都有一定性别指向你们有什么看法？……我记得刺客途径序列7叫做女巫服用这份魔药刺客最后都变成女巫。……我分享一些事情。他语速不快不慢说出流浪魔术师梅林·赫尔墨斯康斯顿城一夜重建全自动许愿机等事情。说话同时他毫不掩饰瞥世界克莱恩一眼。克莱恩嘴角微动让世界格尔曼·斯帕罗目视前方道：我最近就会离开间海东岸。……咦这都是世界先生做？……以满足愿望为乐……这就是世界格尔曼·斯帕罗扮演吗？……从前段时间开始愚者先生让大家在祈祷时以许愿方式提出要求并给予满足。……即将离开间海东岸？那我调查就更轻松了……这时世界格尔曼·斯帕罗环顾一圈道：你们对黑座之王巴洛斯·霍普金斯有什么了解？

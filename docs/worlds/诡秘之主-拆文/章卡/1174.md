# 1174 逐光者 第二十五章 思路很重要

## 打开书
为难阿蒙？帕列斯嘿一声：这能有什么好处？没有就算了。伦纳德一时语塞隔几秒：至少能让你心情好。帕列斯呵呵：你不提这个话题我心情会更好。不等伦纳德回应这位偷盗者途序列1天使嗓音略显苍老叹气：你那位前同事不是有欺瞒符咒吗？也许可以从这上面想想办法。清除贝克兰德阿蒙分身后帕列斯有将制作欺瞒寄生剥夺衰老四种符咒神性符号和魔法标识经由伦纳德转交克莱恩克莱恩利用这些知识和分得时之虫弄出欺瞒子弹寄生子弹剥夺子弹各一枚后来对付丘纳斯·科尔格时用掉了但伦纳德并不知道。伦纳德若有所思压嗓问：老头你意思是借助欺瞒符咒误导阿蒙让他错判地点无法影响克莱恩逃走？脑海帕列斯没好气：在一位偷盗者途天使之王面前用欺瞒符咒你觉得有可能成功吗？不太可能……干笑两声厚颜追问：那你的意思是？帕列斯声音忽然精神一点：欺诈返回后只能在原本身体所在地方的规则！欺诈规则这也行？颇感震惊反问。帕列斯自嘲一笑叹息：比起欺诈阿蒙还是欺诈规则容易不少毕竟这个世界底层是疯狂和混乱的。这话听得伦纳德短暂难以成言一方面见识不够完全不知规则规律也能欺诈另外一方面则是没想到在老头心中阿蒙比自然规律世界规则更加可怕。过近十秒才重新开口：采用这种办法成功可能有多高？很低很低。帕列斯嗤笑：只是阿蒙分身蕴含一条时之虫制成欺瞒符咒能欺诈到这种规律概率很低很低所以我建议还是那个让他请求愚者帮助不要浪费时间了和阿蒙对峙拖得越久越危险。伦纳德沉思一阵认同点头：我明白了我也会建议他这么做。当然不会忘记提一提老头给这可能性不高办法。明白就好真是的打扰一位老人家读书看报……帕列斯嘟囔中声音逐渐变低消失脑海。平斯特街7号放茶几上报纸忽然飞起来自行展开于沙发前。……用欺瞒符咒欺诈只能在原本身体周围区域复活规则？灰雾之上古老宫殿内他用自己话语重构一遍帕列斯建议。话音刚落已回想起那盏亮了很久皮制灯笼：阿蒙欺诈自然规律让蜡烛处神奇状态不需要燃料也能发光一周。眼睛一下发亮低语：这个思路真的只有偷盗者途天使才能第一时间想到……未必不可行啊！和帕列斯相同也觉得比起对付阿蒙还是对付自然规律简单省心不少。看见希望后立刻分析具体可行性：虽然已用掉那枚欺瞒子弹但我可从历史孔隙里将它召唤出来反正效果结束前我肯定已重组身体成功复活……自然规律真的可怜不仅惨遭欺诈就连用来欺诈它物品都是虚假的……唯一问题是那枚子弹可能真没法欺诈到神秘学规律当初对付丘纳斯都显得有点勉强……思绪纷呈缓慢环顾一圈逐渐有了灵感。那就是利用源堡！在初步掌握源堡后已能在这里调动起序列2天使层次力量。而之前接触许多事情都说明源堡大概率跨越占卜家学徒偷盗者三条途径能对相应非凡者产生聚合效应并且明确引来阿蒙觊觎。也就是说怀疑源堡同时有这三条途径力量只不过本身是占卜家平时能撬动绝大部分都集中这领域。借助欺瞒子弹这媒介我也许可以撬动源堡另外力量……既然占卜家领域我已能使用一些奇迹方面能力那偷盗者途力量有天使层次威能是非常合理推断唯一问题是必须有足够层次媒介……这样一来就不用担心欺诈不了那个规则了……想着想着思绪豁然开朗认真制定详细计划。将那种神秘学规律作为目标试图策划一场骗局：为了降低难度最好有额外准备不能凭空欺诈除非我是阿蒙本体……嗯将一管我本身血液赐予小太阳构造一个超出范围虚假复活点。然后以欺瞒子弹为触发推动源堡内部蕴含相应天使层次力量误导那种规则让它将虚假复活点视为真正复活点把真正复活点当成虚假复活点……细节一点点勾勒想法最终成型后立刻借助自己与死亡点之间神秘学联系依靠真实视野观察具体情况。看见灰黄色雾气淡了不少藏着切尔诺贝利幽邃沟壑与之前相比没有一点变化。戴尖顶软帽和单片阿蒙不知从哪里偷来一块石头将它安放在他逝去地方自己则坐于上面耐心地玩着一只人皮手套。祂时而屈起那只人皮手套指头时而将它舒展似乎能就这样过一百年。一两千米外灰黄雾气深处某个地方三个穿黑色古典魔法师长袍阿蒙蹲在一块石头旁认真玩着不知从哪里偷来扑克牌时不时推一下单片。这片荒芜旷野别地方阿蒙们或单独或组团或悠闲散步或沉思书写或彼此讨论着各种各样问题。在黑暗危险神弃这是多么和谐一幅画面如果不是那些年轻男子都穿古典黑袍戴尖顶软帽和单片有着同样黑头发黑眼珠宽额头瘦脸庞那就更好了。就在他想更进一步观察时坐石头上那个阿蒙忽然抬头推水晶雕单片隔空望向了他。荒芜旷野上所有阿蒙跟着抬头望向历史迷雾最高处。旋即收回视线切断联系。……白银城戴里克来到圆塔顶部见到首席科林。首席阁下我已经得到了祝福许诺。相当坦荡直接说。头发花白脸有陈旧伤痕科林明显松口气缓慢点头：这样就好这样就好。少见地把一句话重复一遍。作为一名优秀猎魔者作为白银城首席他一直都很有耐心从不做不必要冒险所以在那位愚者突然没有反馈情况下并未立刻倒向真实造物主决定再耐心等待一个月。对已经在深暗时代等待两千多年白银城来说一个月时间完全等得起。不等戴里克回答猎魔者科林离开窗户旁语气平静：你先回去我要开始准备晋升仪式了。戴里克看首席一眼真诚：您一定能成功！不再停留立刻离开圆塔返回自己家中。重新布置好仪式将自己狩猎到六种强大生物遗骸摆放到正确位置后科林开始调配魔药。等到这些事情都已完成这位白银城首席闭闭眼睛低下脑袋用巨人语诵：不属于这个时代愚者灰雾之上神秘主宰执掌好运黄黑之王……灰雾之上他看见一圈圈光芒荡开听见略显虚幻祈祷声。当即招来一张纸人调动源堡力量与它结合将它丢入祈祷光圈内并顺手标记那位白银城首席。与此同时借助这祈祷光圈观察起整个圆塔整座白银城状况确认首席附近小太阳附近都没有阿蒙寄生体存在。必须抓住这个机会！当即具现世界格尔曼·斯帕罗让他摆出祈祷姿势。这时科林看见了光。神圣明澈光芒里一位背生十二对虚幻羽翼圣洁天使骤然降临在洁白羽毛飞舞飘落中用光之翼层层包裹住这位猎魔者。这是来自愚者先生祝福。

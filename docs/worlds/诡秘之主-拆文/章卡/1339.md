# 1339 倒吊人 第七十四章 游记

## 打开书
这个叫乌托邦小城和我曾游历过那些并没有本质上区别无论民俗人种还是建筑风格都标准地属于鲁恩。……说回乌托邦这里最特殊一点是气候多变常有暴风雨以至于大部分人都有雨伞都有涂抹多宁斯曼树树汁雨衣。……这里没有气象学家……乌托邦几公里外有一个深水港口但他们人手不足无法很好地经营只能维持很小规模。他们也没有本地报纸毕竟这只是一个几千人小城市报童们主要贩卖塔索克报迪西镜报和海风报……我喜欢这里第二个原因是乌托邦很多人都开朗乐观对生活充满热情。当我写下这段话时候旅馆外刚好有一支乐队经过。这不是职业乐队而是纯粹由业余爱好者组成团体……某些休息日他们会走上街头从市政广场出发绕城一周回到广场附近圣阿里安娜教堂他们称这为音乐巡游。……提到婚礼我对乌托邦最不能理解一点是它只有黑夜女神教堂要知道在王国绝大部分地方哪怕是一个小镇上也会有至少两个教堂一个属于黑夜女神一个信奉风暴之主。……其中最让我欣赏是当牧师宣布婚姻成立时新郎和新娘会互相向对方鞠躬没有谁高谁低问题……我喜欢乌托邦最重要那个原因是这里食物非常美味……而这里所有美食里最值得赞赏就是他们甜点……在这里我要郑重推荐一款饮料乌托邦气泡冰茶……每天傍晚我都会去市政广场散步……我在市政广场认识一位画家他叫安德森长相英俊画技精湛可惜是个哑巴……我另外还认识一位作家他叫阿勒苏相当奇怪名字他说他正在创作一部长篇小说并请我品鉴开头。对于他小说我不做评论我只是对小说开头部分就出现几个熟悉名字感觉奇怪。这包括安德森温蒂嗯这是我最爱那个面包房老板……当一位作家想不出人物名字时候拿身边认识人做参考是一件非常合理事情。我很赞同。……限于篇幅这次分享就到这里结束爱你们夏绿蒂。……她是一位作家原本并不算有名只能靠写些三流爱情小说维持生活——改信黑夜女神后她父亲几乎和她断绝往来。……这是位警察曾经因为翠西杀人案证人问题到鸢尾花旅馆询问过莫妮卡。……这是她改信黑夜女神后遇到最有神职人员气质牧师……而对阿尔弗雷德来说最大问题是怎么控制自己不表现出太过异于常人地方否则一位惩戒骑士参与狩猎话别人根本没有机会。他知道妹妹是非凡者但他同样清楚观众途径序列7不会有什么实质正面战斗能力。……这是哪里？一身猎装奥黛丽随口问一句。……找人问一问。……勋爵附近有个叫赫德拉克村庄……

## 这场戏有没有翻
翻了。开头夏绿蒂游记铺乌托邦日常／单神信仰／气泡茶／作家互借名；切莫妮卡线；猎狐近赫德拉克。翻的是游记＝秘偶城拟真课＋巨龙村撞命运。

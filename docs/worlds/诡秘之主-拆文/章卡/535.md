# 535 旅行家 第五十四章 本地信仰

## 打开书
什么？狩猎血之上将？达尼兹差点抬起右手掏一掏耳朵。第一时间反应就是自己听错了。可格尔曼暗藏疯狂笑容自家船长微微动眉异常都在提醒他刚才话语是真实！这…格尔曼这疯子还真敢想！这可是七大海盗将军之一绝非钢铁这种角色能比！瞳孔一缩内心近乎在呐喊。不提血之上将塞尼奥尔本身强大仅是他手下那些大海盗知名海盗就足以让人望而生畏——大副三副和各船船长每一个人都是可以分出来独立领导一个大型海盗团！钢铁带来拜亚姆组合在血之海盗团还有不少！当初飓风中将在贝克兰德像条野狗般无声无息逝去主要就是因为他不在自己海盗团内而血之上将不同很少离开自己旗舰很少脱离手下簇拥。即使回到塞尼奥尔本身实力那也是极为可怕他神秘诡异是大海之上仅次于四王几位强者之一哪怕船长也不敢说一定比他厉害…疯子胆大简直超乎想象不他根本就不知道害怕！一位海盗将军死亡与更替绝对是轰动五海事情！心里转过一个又一个想法最终却奇异平静下来。这是因为他想到格尔曼本身就是七将军级强者而且背后可能还有个隐秘恐怖组织。冰山中将默然几秒道：「你知道玫瑰学派吗？」我不仅知道还杀过他们人抢过他们神奇物品…等等我为什么要把自己描述成一个坏蛋…收敛住笑容不动声色道：「我狩猎过他们成员。」艾德雯娜又沉默下来旁边达尼兹再次有了他们在说什么玫瑰学派是什么东西我在哪里这是谁梦境等念头。短暂安静后冰山中将说：「和黄昏中将海盗团爆发大战后塞尼奥尔舰队就失去踪迹目前没人知道他们在哪里必须耐心等待。」这是答应下来了？再次露出笑容：「我并不缺乏这个。该怎么联络你们？」艾德雯娜侧头看向达尼兹：「他知道怎么联络。」我？降灵仪式？等一下船长你意思是我这段时间得跟着格尔曼这疯子？不！谁也不知道这家伙什么时候会发疯！打个激灵慌忙开口：「船长我已经离开黄金梦想号太久了缺了太多课程！我迫不及待想要返回！」努力让自己眼神显得真诚并填满对知识渴求：「我认为可以换一个人比如铁皮比如水桶…」话音未落艾德雯娜突然抬起右手按下耳朵。微微侧头没什么表情说：「你在说什么？我听不到了。罗塞尔托梦术接近极限了…」这位海盗中将裙摆微动向后退一步身影飞快变淡化成碎光。后续话语卡在喉咙里右手伸伸试图抓住什么却又无力落下。「罗塞尔托梦术」？大帝在神秘学知识里存在感也很强啊…冰山中将全名是艾德雯娜·爱德华兹…爱德华兹…这不是大帝天启四骑士之一姓吗？后裔？可是冰山中将语气显示她和大帝长女贝尔纳黛并不熟悉互相间甚至可能不认识…看眼表情完全垮掉达尼兹低笑一声：「也许有一天我将称呼你万镑先生。」…吓得一下挺直腰背然后看见格尔曼身影直接消失在自己梦境里。如果我只有序列7却顶着七八千镑悬赏金那无论走到哪里都会成为别人针对目标…停留在梦中越想越是头疼。……傍晚时分达尼兹看着一身土著打扮格尔曼道：「我们今天要拜访是本地势力也许可以在那里找到些好东西呵呵他们对非凡材料粮食武器都有不小需求。」说至这里上下打量格尔曼几眼难得找到心理优势笑道：「他们那片区域全是本地人连混血都少穿着打扮稍微有点异常就会被发现。你阔脚裤配棕色夹克还好里面不能是衬衣真正本地人穿都是塔拉巴衫和海魂衫类似但颜色全蓝或全白他们不戴鸭舌帽戴头巾或者什么都不戴。还有你这种明显鲁恩人长相在那里会遭遇非常严重排斥和敌视就像一只混进羊群恶狼完全无法掩饰自身存在…」话音未落就看见格尔曼侧过头来望自己一眼那深刻五官飞快柔和偏白肤色瞬间染上古铜仅仅一个动作时间整个人已变成毫无疑问没有特色土著。「…」一下哑然好几秒后才若无其事干笑：「我也是这样必须做好伪装。」你伪装？呵…取下鸭舌帽坐到椅子上：「什么本地势力？」竟然收购非凡材料粮食武器？「咳简单来说就是咳反抗军。」突然不确定格尔曼和鲁恩官方有没有某种程度上联系。内心怔一秒：「反抗军？」尴尬笑道：「就是喊着独立啊本地人管理本地事务那帮人他们大本营在丛林深处在大海之上和许多海盗冒险家有合作当然背后支持他们主要是弗萨克人因蒂斯人经常有战神永恒烈阳传教士偷偷摸摸往这边跑。」拜亚姆不是太平静啊…离开王国来到海上才真正体会到什么叫国际局势这不是看报纸知晓东拜朗发生战争能够比拟。轻轻颔首没有反对去拜访那股本地势力。出蔚蓝之风旅馆在涂黑脸孔达尼兹引领下穿街过巷一路往东南而去。离开慷慨之城最早期范围后进入一片建筑风格迥异地带这里有木桩支起底层放空房屋有从鲁恩式小楼演变来三四层并排建筑。它们分隔出道路狭窄肮脏两侧有大量地摊贩卖着各种各样石头制成头饰耳饰手饰其中以鲜艳红色和斑斓彩色数量最多。「真是一群审美奇怪家伙喜欢特别鲜艳颜色就和丛林里毒蛇一样。」小声嘀咕一句。你们因蒂斯人也好不到哪里去崇尚金色崇尚奢华感和精致感暴发户味道溢于言表…腹诽道。越过一位位肤色较深瘦削干瘪土著穿过一条条头顶有晾晒衣物巷子眼前忽地豁然开朗呈现出一个不算太大广场。广场之上一群本地人围着中央水池或跪拜或匍匐或喃喃自语或小声歌唱表情虔诚却麻木。一察觉有人靠近他们霍然起身慌乱奔进四周巷子。周围所有房屋二三楼和四楼窗户一扇扇哐当关闭广场变得颇为安静但灵感告诉他有许多人在窗后在巷子拐角处在阴暗角落里注视着突然闯入这片天地陌生人。达尼兹低下头压着嗓音道：「不用在意这是他们自我保护。」「嗯？」表示疑惑。呵呵笑一声：「被彻底殖民前罗思德群岛土著一直信仰海神卡维图瓦认为这常以巨大海蛇形象出现神灵守护着这里所有岛屿避免它们被地震和海啸吞没。现在明面上已经取缔这种信仰风暴教会也一直在打击异教徒就连黑夜教会和蒸汽教会都无法在这里拓展势力只有不多几个教堂。但实际上嘛这种几百上千年信仰哪有那么容易消除拜亚姆蓝山岛罗思德海域依旧有不少海神信徒即使一两个月就有批人被抓捕处以各种极刑也无法在短时间内扭转这种情况那些反抗军主要支柱就是海神信徒。我看啊至少还得有一百年打击海神信仰才会彻底消失当然前提是没有其他因素干扰。」海神卡维图瓦…形象是巨大海蛇…若有所思听着跟随达尼兹进了右前侧一栋四层房屋沿狭窄楼梯一路走至顶层。咚咚咚！敲响左手边房门。「谁？」里面有人低沉问。轻笑回应：「送来美酒和烤肉朋友。」「在哪里？」里面人问出奇怪问题。退后一步道：「在海上。」吱呀房门缓慢打开看见一只赤裸胳膊。那胳膊上纹着条青蓝色狰狞海蛇。

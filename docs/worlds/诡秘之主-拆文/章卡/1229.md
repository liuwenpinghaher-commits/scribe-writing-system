# 1229 逐光者 第八十章 再会

## 打开书
因为本身有过经验克莱恩将自己放到乌黯魔狼位置上来思考：平时肯定会关闭对祈祷自动响应以免被敌人借助反馈建立联系锁定位置；在这个前提下面对突然出现陌生祈祷毫无疑问会依靠相应光点观察一下对面究竟是谁掌握更多情报为将来可能发生事情做些准备；如果诵念尊名者是类似阿蒙比较熟悉强大存在当即掐灭那个祈祷光点是最好选择但对面若是陌生人在这种自身绝对安全处境之下做长期监控了解具体情况审视是否有反击必要是每一个有理智生物大概率会做事情至少克莱恩自己会这么做。这件事情本质就是非神话生物被高位存在标记随时可能莫名其妙地极为凄惨地死去对祈祷者来说这堪比自杀甚至更为可怕于乌黯魔狼而言却是只有好处没有坏处。最开始多疑乌黯魔狼肯定会怀疑有阴谋不敢贸然建立联系隔空影响克莱恩但随着时间推移观察深入确认对方真只是一个不到天使位阶带点源堡气息弱者且没有做足准备后祂必然会寻找机会在克莱恩最没有防备时候通过标记祈祷光点远程袭击。这和克莱恩之前总结自身优势——我很弱是吻合。这个方案唯一问题在于主动权完全在乌黯魔狼手里克莱恩一切都被监控着没法提前做准备一旦对方真尝试施加影响他将毫无还手之力没有幸免道理。呼这么做就是成功钓出猎物但猎人因此死了……没有任何意义……但不把自己放到这么被动位置也确实钓不出占卜家途径天使钓不出这么多疑魔狼……这是无法用秘偶或他人代替……如果能把握住乌黯魔狼因为多疑不敢贸然隔空袭击暂时只会选择监控和观察这段时间就好了……克莱恩脑海念头飞快转动从一个个不可能里寻找着也许存在机会。对此他最终只能在心中暗叹一声为自己不是观众途径天使而惋惜。据他猜测观众途径天使或多或少都会有一些别人对你越了解你也就愈发了解他非凡特质当乌黯魔狼通过祈祷光点密切监控仔细观察一位观众途径天使时祂位置毫无疑问会自然合理地暴露给对方。可惜我不是……而且观众途径序列2未必可以我只能肯定序列1有这方面特质……从历史迷雾里召唤0-08？不行不提没了格罗塞尔游记还能不能召唤那支笔问题就算成功弄出投影笔是笔我是我乌黯魔狼对我情况了解不会让0-08反向尝试掌握还有一次只能用那么短短两分钟来不及感应什么……这倒是可以作为计划辅助提前写下想要发展让乌黯魔狼选择变得合理消除掉不确定因素……克莱恩考虑很多但始终没能找到合适诱捕办法。除遗憾自身不是观众途径序列1天使他还能联想到是星空：仅仅因为了解就会被污染星空！如果我有星空本质那乌黯魔狼通过祈祷光点对我实施监控后将因了解遭受污染被我锁定位置但星空本质高过天使层面我怎么会有……我总觉得忘记一些事情……克莱恩让世界格尔曼·斯帕罗微不可见摇头环顾一圈：不需要现在就讨论出答案可以在回去后以合适方式与合适人交流一下。他重点看看星星伦纳德和隐者嘉德丽雅希望他们能从帕列斯·索罗亚斯德和神秘女王贝尔纳黛等经验更加丰富存在处得到建议。至于他自己将借助历史孔隙影像回到贝克兰德咨询一下信使小姐威尔·昂赛汀和苦修士阿里安娜。这就是做出重大决定前广泛征求天使或准天使们意见……克莱恩在心里吐槽自己这种行为一句。星星伦纳德和隐者嘉德丽雅闻言同时点头：好。……回到现实世界后正在圣赛缪尔教堂地底休息伦纳德压低嗓音将克莱恩问题捡重点描述一遍末了：老头你有什么建议？这是想拿遗留在神弃之地那份奇迹师非凡特性啊……帕列斯·索罗亚斯德先是恍然旋即呵呵一笑：告诉你前同事这件事情他没法自己解决我建议也只有一个那就是向那位愚者祈求帮助！伦纳德深知老头性格忙追问：真只有这么一个建议？帕列斯·索罗亚斯德哼一声：那是连阿蒙都没能抓住神话生物只有靠愚者帮忙。伦纳德这才点头叹口气：看来只能这样…………两天后月亮埃姆林和马里奇约定见面时间前两分钟。魔术师佛尔思窝在壁炉旁安乐椅上侧耳听听二楼动静将目光投向好友休：战争再这么发展下去贝克兰德肯定将遭遇更多袭击真不把你母亲和弟弟疏散到周围乡村？休淡黄短发不对称分开梳得整整齐齐她整个人与去年相比显得更为严肃更有裁决者气质就如同率领一支骑士团高位骑士。她颇有点犹豫：周围乡村能承载人口已经达到极限而且我现在还能从军情九处拿到足够食物。说到这里她顿一下：如果战火真烧到贝克兰德你就带着他们旅行去因蒂斯费内波特……似乎只能这样……佛尔思正要说一说前几天去因蒂斯采购食物事情突然听见闹钟叮铃铃响起。她打个激灵猛地坐直伸出戴着一条红色细绳右手往虚空中抓一下。她胳膊随即一沉拖出戴丝绸礼帽穿黑色风衣未戴眼镜格尔曼·斯帕罗。这冷峻冒险家眼珠一转获得意识减少对魔术师小姐灵性消耗。他边轻轻颔首边让左掌戴着手套飞快变得透明。没到一秒格尔曼·斯帕罗就传送离开消失在佛尔思和休租住房屋内。……佛尔思一阵呆愣好一会儿才嘴角微动侧头对休：我觉得我就是一个工具…………天色已黑街边煤气路灯却未亮起只有绯红月亮照耀着整座城市。克莱恩来到约定地方左右看一眼目光在异常冷清街道墙上烧灼痕迹和不远处坍塌房屋处分别停留几秒。仅就他

# 1259 逐光者 第一百一十章 全知

## 打开书
无需谁来开口介绍在场四位半神都明确认知到一个事实：沉睡于铁黑色宝座上与巨人身高相仿那名男子就是神之左手天国副君暗天使萨斯利尔！其中洛薇雅还清晰感受到来自绝对高位者那种压迫就如同向真实造物主祈祷获得回应时一样那是能让思绪混乱灵魂坠落身体颤栗气息。突然之间她听见一阵笑声有些迷茫有些错愕侧头望向旁边。克莱恩腰背微弯哈哈笑道：祂还在睡我们是该直接叫醒祂还是等祂自己醒来？如果选择叫醒祂该怎么打招呼？嗨暗天使殿下？救赎蔷薇首领？这两个问题听起来荒诞狂妄但却让科林和戴里克摆脱环境影响陷入沉思。刚才他们本能也考虑起第一个问题这相当重要关系到接下来该怎么做。暂时不要惊醒祂尝试着靠近寻找线索搜集情报。这也是我想法。克莱恩用左手随意打了个响指就要迈步走向那铁黑色宝座。这个时候他心里颇为庆幸庆幸自己已经解决影子让灵恢复完整要不然完全限制不住虚拟人格——他在模拟怎么打招呼时差点脱口而出嗨小萨。我用放牧魂灵试一试。……果然还是得靠我。我一向都比较胆小。扔完半盒火柴克莱恩半转身体回过头来笑着解释一句。克莱恩低下头来看见蠕动饥饿恢复人皮手套状态掌心位置裂开一道夸张缝隙里面是两排虚幻白森森牙齿。蠕动饥饿堕落了！啧。克莱恩发出明显感慨声顺势瞄了眼右手提着星之杖确认这本身没有活着特性0级封印物并未出现异变。他随即抬起右手将星之杖另外一端塞入蠕动饥饿口中。蠕动饥饿啃咬几下受到位格压制终于恢复平静。……属于阅读者途径全知力量？源堡气息……源堡……科林似乎记起什么有了一定恍然。必须具备源质才有可能得到回应或靠近萨斯利尔？所以倒吊人明明有了洛薇雅这个白银城半神信徒还要强迫我进入宫殿见一见暗天使？克莱恩好不容易才控制住虚拟人格本能开口。你命运和阿曼妮西斯列奥德罗亚当阿蒙赫拉伯根奥赛库斯梅迪奇乌洛琉斯有交集还有祂……对于黄铜色眼睛说出这一个个真名科林戴里克洛薇雅并不陌生知道第一个是黑夜女神后面是八大天使之王中七个而且不乏当前序列0真神这让他们听得点怔住不敢相信格尔曼·斯帕罗会与这么多超越序列1高位存在有命运交集。加上前面沉睡暗天使世界先生和八大天使之王都有了交集真是厉害啊……戴里克由衷在心里赞叹一句。克莱恩没心情去调侃自己神际交往学带着明显笑容反问一句：祂？克莱恩认为这个祂指应该是真实造物主毕竟自己身上到现在为止都还有对方遗留侵蚀力量。祂是另一个我……真实造物主真是远古太阳神另外一面从神尸上诞生那一面充满仇恨带着怨毒执掌堕落那一面？克莱恩逐渐将那个坐在远古太阳神胸腹裂口之中吞食着肠子阴森漆黑婴儿与真实造物主划上等号并且初步确认现在与自己对话是暗天使萨斯利尔遗……你们为什么要组建救赎蔷薇刺杀远古太阳神？覆盖在墙壁石柱和地砖上阴影帘幕晃动一下沉睡暗天使依旧没有醒来。太阳神只是我最初尊名你现在应该称呼我创造一切主全知全能神或者尊称我上帝。看得出来你一直在往那个方向靠。克莱恩终于笑出声音然后感觉到后怕因为他在嘲讽天国副君神之左手天使之王中天使之王以及祂本体。所以你为什么要背叛自己要和黑夜女神祂们建立救赎蔷薇刺杀自己？原初在我体内苏醒了……虽然科林戴里克和洛薇雅都不是太理解暗天使萨斯利尔这句话含义但依旧被话语里自带阴森畏惧瘆人感影响产生阴冷刺骨身心颤栗幻觉。原初在我体内苏醒了……这句话层层回荡许久没有平息。

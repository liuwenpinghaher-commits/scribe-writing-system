# 1334 倒吊人 第六十九章 “我”

## 打开书
我坐在警察局椅子上看着对面两个穿黑白格制服男人嘴巴交替张合仿佛在说着什么。左边那个一脸冷漠似乎已见过太多不幸右边那位还有点青涩目光里透着些许怜悯。我并不觉得痛苦也没后悔自己刺下那一刀在那一刻我甚至觉得自己得到解脱那喷到我身上温热鲜血就如同神灵给予救赎。我只后悔年轻时候为什么要那样狂热追逐金钱为此牺牲尊严身体和自由。……看这些拜金女郎她们出卖自己灵魂！……翠西小姐你有在听我们说话吗？一道声音拉回我思绪来自那位有点青涩警察先生。……翠西小姐接下来你就要准备上庭了我们会给你安排一位律师。很抱歉没有留下那位证人只有口供这对你相当不利。没关系。我平静对他说道。……等待上庭这段时间里能帮我从图书馆借几本书吗？嗯社会思潮与教育现象……我坐在斑驳长桌最下方听见审判小姐在讲述乌托邦事情。……这是一个仪式。不出预料我看见审判小姐目光出现一定凝固感觉到倒吊人先生正义小姐都望过来带着点揣测意味。他们肯定会怀疑这是世界格尔曼·斯帕罗序列1仪式而他们早就利用塔罗会内部交流知道有序列0真神情况下不可能存在序列1。可惜没有谁提出问题他们或许已经联想到天使之王们也或许认为乌托邦涉及仪式主要是帮助愚者先生更进一步复苏。……翠西小姐你父母居住在哪里？他们已经过世了……那位灵魂已不属于这里美丽女郎嗓音有些飘忽回答道。……你还有别亲属吗？没有……翠西小姐你有在听我们说话吗？……我后靠住椅背听着月亮埃姆林这个家伙描述他梦境。经过那位乌特拉夫斯基神父鉴定这个梦境并非源于大地母神神启。这就不得不让人将怀疑目光投向月亮投向那位堕落母神然后遭遇污染……我差点被自己想法逗乐。作为资深占卜家解梦大师我没有谦虚坦然说出自己认知：三个可能一是这梦境在诱导你去探寻什么追逐什么并在某种程度上干扰你命运二是这梦境希望你去深入解读它理解它然后借此一点点难以察觉侵蚀你三是你自己为美神之事太过忧虑于是梦到最害怕场景。第三个可能不用讲前面两种可能应对方法都一样不去想不去探究无必要不离开贝克兰德。……一起凶杀案？我浏览下手中案件资料用尾音变化表达出疑问你们应该去请一位大律师。……乌托邦只是个小城没有大律师得去别地方请。而且这个案子是以防卫过当起诉刑期很短涉案金额也不到400镑可以先放在治安法庭审理等判定防卫过当不成立再移交刑事法庭。很懂嘛是想转行做律师？不过正常来说以防卫过当起诉凶杀案也得交给刑事法庭呵呵这就是小城好处很多事情不是那么严格……我想了想嗯一声：那我试一试做无罪辩护。另外请你们尽快安排时间让我见一见那位翠西小姐。……班西？维尔杜想去班西？我坐在斑驳长桌最下方看着向愚者先生汇报倒吊人对事情发展有些疑惑。沉迷神秘学想借此救出门先生维尔杜确实有一定理由探寻班西废港而且他也在拜亚姆住差不多半年接触到班西资料实属正常……主要问题在于倒吊人之前监控没有提供相应征兆让维尔杜这个行为显得有点突兀……这件事情……继续监控。……他本体一直躺在圣阿里安娜教堂地底意识时而上升至源堡内部时而沉入体内。秘偶分身们经历种种画面不断在他脑海中闪现如同一场大量碎片组成梦境。

## 这场戏有没有翻
翻了。开头翠西「我」独白；切世界「我」判乌托邦＝仪式；解埃姆林梦三可能；入城当律师见翠西；章末班西继续监控＋本体躺堂底看碎片梦。翻的是「我」叠＝秘偶翠西／世界律师／克莱恩本体。

## 这一章新讲明的规矩

- 维尔杜赴班西突兀→继续监控。
- 本体堂底；分身碎片如梦。

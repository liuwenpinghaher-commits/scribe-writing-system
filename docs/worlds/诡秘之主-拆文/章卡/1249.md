# 1249 逐光者 第一百章 门后

## 打开书
因为有白银城上次探索打底所以克莱恩知道哪些地方有什么危险该怎么避开没用多久就沿那条小路经衰败森林荒芜隧道古代电梯抵达看守者们居住地方。又等待一阵等到灰雾之上那块幕布一分为二分离出诡秘侍者非凡特性克莱恩才探手拖出过去自己。——他不清楚别神国是否会隔离历史迷雾但至少失去主人没谁维持巨人王庭未对他尝试产生阻碍。可惜这件事情涉及层次太高占卜得不到结果要不然我会更安心一点……克莱恩摇头无声自语一句。他没急着跃入历史迷雾内先行从怀里拿出两件物品交给自己投影。其中一件是深黑色木盒里面装是巨人守护者格罗塞尔骨灰。克莱恩从未忘记自己承诺。他原本是想等小太阳第二次探索巨人王庭时把格罗塞尔骨灰交给对方请他帮忙安葬但各种事情牵扯下克莱恩自己竟直接来到神弃之地进入巨人王庭。至于苦修士斯诺曼骨灰克莱恩打算离开神弃之地时将它洒入那片泛着金黄海洋——那里荡漾是远古太阳神神血。给出骨灰盒和那把来自冰山中将黑铁钥匙后克莱恩按照惯例跃入迷雾狂奔到第一纪之前光之碎片中让意识自然转移到召唤出那个投影身上。这个投影并未拿着星之杖只是戴着蠕动饥饿因为从这里到巨人王居住宫殿还有不短距离中间存在许多巨型魔像阻拦克莱恩不敢保证自己一定能在五分钟内抵达目的地。紧接着他让左掌戴着手套变得透明整个人一下消失在原地。下一秒钟克莱恩夹着巨型黑铁钥匙身影出现在守卫居所外面并未传送太远。嗯在巨人王庭内部绝大部分力量都明显衰退……只有被神国承认守卫才能发挥相对正常水准？呃类似传送非凡能力还受到额外压制我只能在一个较小范围内闪现……这么看来我哪怕召唤出星之杖也没法通过脑海内勾勒相应场景直接降临到巨人王宫殿外面……不愧是曾经古神神国……克莱恩认真审视着环境带来影响。做好初步判断他转身走回守卫居所内部打开右手拿着木盒表情肃穆将格罗塞尔骨灰撒到每一个角落。根据他在格罗塞尔梦境里看见画面这处守卫居所是那位巨人长期生活和居住地方是他印象最深刻也最眷念家。可以想象古老年代里那段时间格罗塞尔等不知多少代后有理智巨人看守者在这里休息打闹交流传闻讨论音乐琢磨好玩游戏方式不用担心食物也不必忧虑疾病愉快过着每一天……随着克莱恩手部抖动那些粉尘挥洒飘落于墙上面地面床边桌椅和石柱旁。窗外橘红光芒永恒不变照耀着让这一切显得安宁。当克莱恩洒落最后一点骨灰时黄昏突然浓郁少许让不同位置粉尘融入橘红成为神国一部分。克莱恩闭闭眼睛似乎感受到格罗塞尔喜悦。一个被迫远离故乡三千多年游子终于回到日夜思念地方。那黄昏光芒随之柔和让克莱恩感觉自己不再受到那么大排斥。咦……相当于在一定程度上被承认成为被部分接纳守卫。克莱恩蔓延出灵性确认起变化。他不再停留利用蠕动饥饿和白银城探索小队上次探明道路不断闪现时而绕行时而拖出无暗十字相对没遇到什么困难就通过那个密谋大厅来到巨人王居所旁看见左侧是一排巨大石柱组成扶栏扶栏之外是弥漫橘红云气和轻轻涌动深蓝大海。深吸口气克莱恩退回刚才出来大厅探手拖出曾经属于自己还未被阿蒙寄生过秘偶恩尤尼。哪怕是用历史投影他也不想自己去开门！看眼略显呆滞恩尤尼克莱恩将夹在腋下巨型黑铁钥匙交给对方操纵他离开大厅沿着石柱拼成扶栏一路走到巨人王庭内部最高最恢弘那座建筑前。那里黄昏光芒宛若实质覆盖在宫殿表面带来强烈衰败感就像世间一切都行将落幕。宫殿两侧一边为尖塔一边为圆塔正门以灰蓝为底布满对称神秘符号整体高度远远超过十米。而门缝左侧三四米高地方有一个漆黑孔洞相当于成年人拳头大小。恩尤尼凝望几秒抬起那七弦琴般黑铁钥匙将它凑向前方那个幽深孔洞。它们是如此契合竟没留下一点缝隙。随着那把巨型黑铁钥匙没入幽深孔洞附近大厅内克莱恩屏住呼吸时刻准备着解除自身存在。笃一声秘偶恩尤尼手中黑铁钥匙触碰到底部。它突然变得柔软仿佛与孔洞融为一体并绽放出一道又一道灰蓝光芒。对开大门上各种符号标识和花纹跟着亮起凸显出来。这所有光辉迅速交织在一起沉重往内按压让灰蓝色宫殿正门缓缓打开。门缝越来越大恩尤尼眼中突然映照出一片汹涌漆黑黏稠虚幻海洋。不好……克莱恩心中一动脑海里涌现出强烈危险预感。没有任何犹豫他意识回归本体切断与自身历史孔隙影像联系。下一秒他眼前突暗左边脑袋一阵剧痛就像被人用烧红铁钎插进去不断搅动。与此同时他耳畔回荡起无法分辨呓语那仿佛来自比古老更古老年代。克莱恩表情瞬间扭曲起来显得异常狰狞。他还能勉强维持理智但已没有余力让自己停留于历史碎片内。无声无息间克莱恩落回巨人王庭看守者住处念头一动就要进入灰雾之上。——打算做这么危险事情前他毫无疑问又找理由和借口安排塔罗会各位成员祈祷以唤醒源堡自主召唤能力让自己可以在危急时刻不用逆走四步诵念咒文就能回归灰雾之上。可是克莱恩灵体刚看见那片灰白雾气听见熟悉嘶吼声就感觉到源堡排斥它不知接受谁命令竟阻拦起克莱恩进入。这……克莱恩惊愕之中发现一道黑影越过自己直奔源堡！这不是阿蒙而是一道和他本身气息完全一致阴影！下意识间克莱恩反向影响起源堡给出拒绝意念。然后他成功那道阴影同样被阻隔在灰白雾气中。紧接着他和那道阴影同时坠回现实世界。灵体回归肉身后克莱恩难忍痛苦弯下腰背如同蜷缩虾类生物。啪他头顶半高丝绸礼帽落到地上。过好几秒克莱恩终于缓回来慢慢直起身体将目光投向一面橘色宝石磨成玻璃窗。那窗户上模糊映照出他现在样子：以鼻梁为界右脸和平常一样左脸有数不清事物在爬进爬出。克莱恩眼睛顿时微微眯起。他忙做个深呼吸平复下状态找回小丑控制能力。他脑海中随之勾勒出他清晰模样：穿着黑色风衣乌发棕瞳棱角分明格尔曼·斯帕罗右脸如常左侧已变得半透明由一条条扭曲蠕虫合抱而成。头部往下他脖子也处在类似状态被衣物遮掩身体同样如此。失控边缘……嘶需要对抗强烈疯狂趋向……这这是为什么？克莱恩忽然心有所感本能低下脑袋望向脚边。那里空空荡荡缺失本该存在影子：橘红黄昏光芒从窗外映入没能在克莱恩旁边制造出一点阴影。哈哈我明白。克莱恩弓下背发出难以遏制笑声。他怀疑巨人王宫殿内涌出海水不仅淹没自己秘偶和历史投影而且还借助后者切割下自己影子导致他灵失去完整性无法再彻底压制失控倾向。而那个影子略等于几分之一个他同样能影响源堡于是就出现两边谁都到不了灰雾之上状况。只要清除掉那个影子问题就能解决……克莱恩右侧额角抽动间直起腰背。就在这时外面照入橘红光芒染上金色变得颇为灿烂这让整个巨人王庭仿佛从黄昏倒退回正午。克莱恩心中一动将目光投向窗外脑海里隐约浮现出一幅画面：巨人王庭最高最恢弘那座建筑物前秘偶恩尤尼立在那里面朝着打开大门。大门内一片幽暗完全看不清有什么事物存在。突然恩尤尼转过身体俯视起下方。他脸上覆盖着一层阴影头发变得深黑披到肩头微微卷着。他背后张开一对又一对虚黑羽翼。附近大厅内一道纯粹阴影下半身贴着石砖上半身笔直挺立游出来。

## 这场戏有没有翻
翻了。开头安葬格罗塞尔得接纳；秘偶开门见黑海；切影失控拦源堡；章末正午金光恩尤尼生羽、影子游出。翻的是开殿从探路翻成失影失控，不是骨灰温情。

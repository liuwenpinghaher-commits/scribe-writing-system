# 1220 逐光者 第七十一章 留言

## 打开书
如果乌黯魔狼真在准备诡秘侍者仪式那祂行踪就不是完全无迹可寻……克莱恩缓慢点头心中已有些模糊想法但还无法真正梳理成形。他本能就想借助被那块幕布浸染泥土直接占卜这件物品下落从而锁定乌黯魔狼目前藏身之处但考虑到对方是天使这种方式大概率会惊扰到祂让祂有所警觉做出规避克莱恩又理智放弃这个想法返回现实世界苦苦思索整件事情规划。第二天闪电频率逐渐变高时又有一批月城居民在一位叫做杜克祭司率领下来到格尔曼·斯帕罗篝火旁听他传教享用蘑菇等待净化。在一位位月城居民接受洗礼泪流满面后克莱恩环顾一圈状似不经意问：太阳神让你们守在这里注意是否有人从雾气里走出？是的。被治好浑身浮肿病症杜克知道大祭司已对眼前神使提过这件事情相当坦然回答。克莱恩轻轻颔首顺着这个话题又问一句：如果真发现有人从雾气里走出你们会怎么做？杜克没有犹豫直截了当：立刻诵念伟大太阳神尊名将这件事情……禀报祂……说着说着他语气变得非常低落到最后甚至已无法成言因为那位太阳神造物主在两千多年前就没再给予回应哪怕月城一次次举行最完整仪式反复诵念尊名也没得到一点反馈。除了这个呢？克莱恩敏锐追问。这既是灵性直觉启示也是某种程度上推理结果——很明显远古太阳神白银城造物主不会不考虑到一个问题一个可能那就是灰白雾气内走出来那个人非常小心非常谨慎不喜欢被注视不喜欢被监控发现月城巡逻小队后倾向于用自身非凡能力影响他们心灵让他们遗忘掉见过他事情不记得要诵念尊名。面对这种情况远古太阳神应该有做一定安排。当然这也不是绝对如果阿蒙祂父亲能精准预见到从灰白雾气内走出那个人是新手那就完全没必要在神谕里说得太多。不过考虑到这位远古太阳神白银城造物主连自己从灰白雾气哪个地方出来都预言错误了克莱恩对上面那种可能持怀疑态度。杜克想犹豫下：迎接那个人告诉他一个单词。克莱恩顿时精神一振表面却不动声色问：什么单词？杜克嘴唇动几下似乎在模拟发音然后他用一种古怪腔调：切尔诺贝利。……克莱恩脑海凝固一秒旋即发出无声叹息。……鲁恩王国东切斯特郡一片林地里。附近村庄农夫们汇聚到这里采摘着那些长满树根长满朽木长满灌木丛奇特蘑菇。按照王国法律这片林地和它内部生长一切都应该属于它主人奥黛丽·霍尔小姐但战争延绵粮食征收高昂税费让农夫们已顾不得触犯法律那是活下来才需要考虑事情而且参与人一多胆子自然就会变大。他们组成小队很有效率做着采摘并将或布满金星或有脂肪花纹蘑菇们分成两个部分小部分自留食用大部分预备卖给等待在林地外粮食商人换取金镑购买盐布料等必须物品。这些农夫并没有做得太过分除蘑菇只拿走一部分结在树上果实给林地看守者们留下足以上交收获。也就是两三个小时工夫农夫们卖掉大量蘑菇和果实揣好金镑背着口粮满脸笑容返回各自村庄。对他们来说今天发生一切都是自身想做并且也达到预定目的。那留着络腮胡粮食商人同样高兴因为这些是意料之外收获在目前局势下又能为他赚很大一笔钱。他带着工人将大量蘑菇和果实搬到城外加工点做相应处理然后全部放入仓库。作为一个做事细致商人他在打发走工人后又检查一遍仓库直至确认无误才亲自关门上锁。就在这时他看见地上多一叠厚厚现金全是10镑面额。我什么时候掉这么多钱？这位粮食商人庆幸弯下腰背将那叠钞票捡起来。点数之中他突然记起这些钱来历：它们是自己卖掉刚才那些蘑菇粉蘑菇干和果脯收益！真是丰厚啊！这位络腮胡商人满足感慨一声转头离开仓库。仓库内部穿着浅蓝长裙奥黛丽解除心理学隐身拿出一个黑色口袋。这是她从审判休那里租赁来旅者行囊。接着金发简单挽着奥黛丽轻松将一袋袋粮食倒入黑色口袋内。做完这一切她又拿出一本外壳坚硬铜绿色笔记翻到记录有传送一页。这是来自魔术师佛尔思莱曼诺旅行笔记。而之前发生事情都是奥黛丽暗中操纵。她先是将隐者女士提供快速繁殖蘑菇给予林地内一只只动物借助它们帮忙全部种到合适地方接着成片影响周围村庄农夫增强他们内心渴望让他们能战胜对律法恐惧而那个粮食商人和他雇工刚好路过发现这件事情。这种对人心操纵让人沉迷就如同万灵主宰但奥黛丽却没露出一点笑容反倒轻轻叹口气：还是不够啊……还差很多很多……她拿到蘑菇不是小太阳说能吸食怪物血肉成长繁衍类型需要环境给予足够养分才能快速生长所以这片林地短期内没法再种第二次蘑菇否则很有可能变成荒漠。凝望着那一条条空瘪下来布袋奥黛丽碧绿眼眸闪烁一下难以遏制想：大量粮食集中在教会王室军方政府贵族和大商人那里……弗萨克因蒂斯费内波特那里也有但只靠旅者行囊不知要搬多少次才够……操纵贵族大商人军方人很危险一不小心就会被发现……如果不是局势恶化到这种程度我也许永远不会知道有人会有那样一面……环境和处境不同每个人戴上人格面具就不同我以后得注意这点……思绪电转间缺乏处理类似事情经验奥黛丽打算这两天请教一下世界先生看他有什么样建议。由于世界格尔曼·斯帕罗长期独自行走于无人神弃之地周围是黑暗绝望环境奥黛丽建议他定期找自己做心理咨询这不一定真要治疗什么随意说说话也能有效缓解那种压抑孤独和苦闷。格尔曼·斯帕罗遵从医嘱而奥黛丽从聊天里知道这位强大冒险家除找自己做心理咨询也会时不时在灰雾之上与星星先生闲话情绪状态保持得相当不错。有决断奥黛丽当即就要激发旅行能力返回贝克兰德。可转念之间她又有少许沮丧。因为她知道哪怕自己筹集到大量粮食也只能让贝克兰德居民们安稳一段时间战争如果不结束局面还会恶化。战争……奥黛丽闭闭眼睛完全不知道自己能怎么阻止。她听隐者女士说过这次战争本质很可能是神战而神战前奏都很一致那就是花费一定时间和力量动摇对手锚。想了想奥黛丽抿嘴唇决定先从自己能做到事情做起。随着那页笔记发出濛濛光辉她身影飞快透明消失不见。……静静燃烧篝火旁送走月城来客克莱恩忍不住想起渎神者阿蒙曾经说过一些话语。祂说切尔诺贝利内部埋藏着祂想探寻历史有许多事情线索。远古太阳神也专门强调切尔诺贝利……思绪纷呈间克莱恩突然有去探索切尔诺贝利冲动。这也不算是冲动是他一直以来都想做事情只是碍于阿蒙才没敢付诸实践。我一路往东走大半年没谁能想到我会现在突然降临切尔诺贝利……阿蒙拿到最后一份时之虫非凡特性正在准备仪式本体不可能还窝在切尔诺贝利……嗯祂是一个很有耐心天使之王也许有分身一直等在切尔诺贝利……克莱恩分析下当前情况决定让历史孔隙里影像去试一试。反正他本体是绝对不会直接前往！下定决心后克莱恩先去灰雾之上做次占卜然后回到现实世界探手一抓拖出五分钟前自己。这历史投影随着本体消失获得意识接着他连抓几下拿出那根镶嵌着诸多宝石黑色手杖。星之杖！克莱恩要利用星之杖能力直接瞬移到切尔诺贝利！

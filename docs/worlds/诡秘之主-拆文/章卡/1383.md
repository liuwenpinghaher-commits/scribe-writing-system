# 1383 倒吊人 第三十一章 概念化

## 打开书
听到阿蒙话语克莱恩内心骤然一沉。在此之前他是不担心阿蒙策反灯神因为这是一名顶级诈骗师祂所做任何承诺都没法让人相信而灯神是遭遇过前任诡秘之主属于类似事情受害神肯定会以最防备态度来应对错误先生。这就是缺乏信用导致结果。有时候撒谎欺诈耍赖确实能让短期收益变高但从长远来看还是诚实守信能得到更多。可现在特伦索斯特黄铜书刚制定此地禁止诈骗规则。……同时克莱恩和灯神都没有发现对方在这件事情上有利用漏洞。……灯神甚至能依靠自身位格和特质在一定程度上扭曲这句话让我可以承诺变成我承诺让阿蒙没法再反悔一反悔就会遭受旧日层面规则伤害。这让克莱恩忍不住怀疑此地禁止诈骗条文究竟是阿蒙悄然引导特伦索斯特黄铜书制定还是灯神有意为之让所有可能成为诡秘之主存在都承诺送祂回星空。于灯神而言这样一笔交易稳赚不赔因为克莱恩本身就欠祂一个承诺。换做别场景克莱恩还有时间和灯神好好沟通重建信任但此时阿蒙威胁已近在眼前不会让他有机会去解决这方面问题。若是选择继续相信灯神克莱恩则等于将自己生命放到这位外神手中任由对方操纵——接下来战斗里灯神只要通过特伦索斯特黄铜书制定一些看起来没问题实际却偏向阿蒙规则本就处于极大劣势克莱恩将迅速败亡没法再逆转局面。……愚者！一圈圈无形波纹从他体内荡出刹那就笼罩灯神笼罩特伦索斯特黄铜书笼罩整片荒野笼罩阿蒙。盲目痴愚权柄！……特伦索斯特黄铜书写新条文速度明显放缓像是要用一刻钟甚至几个小时才能想到接下来该制定什么规则；灯神模糊而扭曲淡金身影一阵摇晃猛然缩回那盏水壶般金色神灯内不知是在逃避什么还是纯属本能反应。抓住这个机会克莱恩一边尝试脱离源堡一边准备着将自己与某件事物嫁接在一起。他意识刚有下沉那块水晶磨成单片眼镜就出现在源堡边缘挡住他道路。即使短暂出现智商降低阿蒙似乎也记得阻止克莱恩离开源堡。……我将这件事情写进我本能里这是对抗盲目痴愚效果好办法。……克莱恩没有沮丧立刻完成早就预备好嫁接。……处于永昼效果中荒野上一轮带着毁灭气息和沉重感觉橘红太阳从天而降落下来。……下一秒周围虚空都围绕着那轮真实太阳收缩起来万事万物或分崩离析或直接气化只剩下许愿神灯和特伦索斯特黄铜书还在火焰里苦苦支撑未受损害。……他将自己和那颗恒星嫁接在一起。当然他嫁接只是恒星概念而非实体要不然以愚者显著低于大部分序列0防御以他相对脆弱身体直接就会被真正恒星吞没当场死亡。愚者属于非常极端化神灵有能力毁掉一颗恒星却没办法直面对方优点和缺陷同样明显。另外正常来说概念这种东西是没办法直接影响周围环境伤害敌人不是说写下大质量大引力高温高热聚变这些词语就可以制造类似效果但克莱恩这位愚者先生执掌着愚弄权柄。……这既是强烈变化也是一种愚弄。阿蒙戴尖顶软帽穿古典黑袍身体在恒星近距离照耀下已是被彻底点燃开始气化。就在这个时候他身影扭曲一下瞬间染上璀璨星光变得极为虚幻仿佛化成一道星门。这一刻阿蒙不再像是实体生物更接近漫游星界通道钥匙门等象征集合体。这是旅法师借助星界前往不同星球不同世界能力——祂们可以让自己转化为象征符号从而有效利用星界。到序列0门这个阶段类似能力质变为概念化。阿蒙将自己变成概念生物规避掉恒星带来伤害。……祂灵体之线被克莱恩抓住。克莱恩利用那颗恒星带来混乱解除掉自己与相关概念组合悄然嫁接双方所在地点来到阿蒙身后。本来没有这种概念上重组恒星对周围环境带来影响将立刻中止但克莱恩愚弄时间让前两秒效果滞留到现在以此瞒过阿蒙。如果可以克莱恩现在最希望做是加深对阿蒙灵体之线掌控将祂变成自己秘偶但他很清楚在当前情况下这么做成功概率极低：一方面阿蒙可以承受伤害将灵体之线窃取回去另一方面祂或许能够利用双方间借助灵体之线建立起来联系卡一个Bug反向影响克莱恩……他抓住阿蒙灵体之线主要目的是给对方带来一定思绪滞涩。这是愚弄权柄在秘偶化阶段表现而以克莱恩现在状态他当然更愿意选择这种较低层次但能产生效果手段这对他负担较小不会像直接动用愚弄权柄一样严重影响到精神稳定。此时此刻他敌人除阿蒙还有体内福生玄黄天尊。当然阿蒙也是这样祂半疯之后若是不再做压制天尊已经在祂体内复活。……一是趁这个机会脱离源堡但他不清楚阿蒙本能是否还在运作还在阻止自己逃走；二是召唤历史孔隙中影像但这没有太大用处……他要趁机将阿蒙与源堡与那扇沾染着青黑光门嫁接在一起。当阿蒙与源堡完成重组祂体内天尊意志将明显增强精神混乱会显著加剧。……对一位以欺诈见长错误先生来说这将是致命影响。当然这种嫁接克莱恩只会维持一秒钟超过这个限度他面对或许就不是阿蒙而是福生玄黄天尊了。到时候对方肯定会直接笑纳源堡这份大礼以源质加两份唯一性相应序列1非凡特性位格吊打单途径序列0愚者。原本克莱恩可以依靠愚弄权柄来达到降低阿蒙智商效果但一是他现在状态没法长时间使用这种层次力量二是阿蒙作为双途径真神众多权柄执掌者盲目痴愚效果在祂身上能维持时间本来就相当有限所以克莱恩不得不冒险采用这种嫁接。而疯狂会长伴阿蒙直到祂找到新平衡或见到最好那位心理医生。……源堡。

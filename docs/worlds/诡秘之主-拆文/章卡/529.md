# 529 旅行家 第四十八章 文献资料

## 打开书
青铜长桌侧方梦魇呈现出来。这是一个外表年龄三十来岁男子黑发蓝眼脸颊瘦长鼻翼两侧有较明显沟痕嘴边和下巴长满不算茂密胡须。随着那能直观感受到痛苦与扭曲缓和他以手按胸庄重行一礼。与之前那位无面人相比这梦魇被释放后明显没那么浑噩和脆弱也不知道是因为黑夜途径对灵提升要强于占卜家途径还是由于他被放牧时间较短。克暗叹一声以通灵方式直接问：「你为什么会死在齐林格斯手上？」那梦魇嘴角微勾露出苦笑：「我是值夜者里面红手套正追查一批来源于拜朗皇室陵墓古老文献它们疑似与陨落死神有关。我发现其中一部分可能落到了某位富豪手中于是带领两位同伴登上了他乘坐那艘船不幸正要展开调查我们遇到了齐林格斯船队袭击。」「你同伴呢？」下意识问一句。梦魇略显痛苦说：「我们本来有机会离开甚至凭借熟练配合击杀齐林格斯但但我们船沉了只能改坐救生艇所有人所有人都死了不殉职了！」愿女神庇佑你们…心里默默画了个绯红之月。这让他更加深刻认识到海上战斗与陆地上有极大不同环境因素至关重要。不是水手途径序列者会非常吃亏！如果不是那张飞毯面积大不便于携带且速度很慢容易成为靶子肯定会选择留下它给达尼兹现金。还好我有鱼人鳔可以找工匠制作水底潜行类神奇物品…可惜工匠非常难找绝大部分都在蒸汽教会野生不多否则流通神奇物品不会稀少到现在这种程度实在不行还是得请倒吊人先生帮忙…看着面前因公殉职梦魇轻轻后靠道：「你叫什么名字？有什么未完成心愿？」那梦魇身影已在缓慢消散闻言笑道：「我叫戴维·雷蒙我在一场黑魔法事件里失去父母妻子和兄弟姐妹只剩下一个女儿她叫妮露出生于1330年是个很可爱女孩我很遗憾为了追查那场黑魔法事件真相我加入值夜者后来更是成为红手套一直没有好好地长久地陪伴她让她在失去母亲同时也近乎失去父亲。呵呵我相信教会肯定会将那份抚恤金一分不少给她并在暗中给予一定帮助我不担心她生活我只希望能看到她在女神见证下进入婚姻殿堂拥有属于自己家庭不再孤单。」「今年是1350年她也许已经有了结婚对象。」半是感慨半是叹息说。「时间过得真快啊…」戴维梦呓般回应「告诉她所有凶手都已经被惩戒我是因为意外才身亡不需要再仇恨谁告诉她爸爸爱她爸爸很抱歉…」身影越来越透明行将消失。闭下眼睛道：「她住在哪里？那个收藏了死神文献富翁叫什么名字？」「我们住在迪西郡康纳特市那是一个美丽海滨城市附近盛产橡胶如果她没有搬家那就还住在红梧桐街67号…那个富翁叫吉米·内克他应该也落到齐林格斯手上…」话音未落身影已完全散去只在手套表面留下一颗幽黑深邃宝石状胶质物。静静看着这一幕过好几秒才抬起右手在胸口顺时针点四下并低沉开口：「如果有机会我会去看看你女儿看看她现在过得怎么样。」巨人居所般宫殿下灰雾漫无边际没有起伏亘古不变。收起戴维非凡特性揉揉额角将注意力转回至死神文献事情：「死神途径和黑夜途径可以在高序列互换教会派人追查相应文献下落没有任何值得奇怪地方…吉米·内克不知道死没死得打听一下…如果他已经在那场惨案里过世且东西落在齐林格斯手上那就得从海盗方面查起…齐林格斯船队现在已经归属于疾病中将特雷茜…」因为涉及死神也许能帮助到阿兹克先生决定顺手查一查有什么困难就直接写信通知大佬。理清思绪后迅速返回现实世界并利用仪式将蠕动饥饿又带出来。做完这一切见时间已经不早放弃补眠打算决定总结下昨晚行动经验和教训。对克而言最大教训就是高估代罚者们耐心。原本希望即使前面有一定意外代罚者也能克制住自己等待真正主角真正目标钢铁登场。那个时候他们肯定会使用多人入梦封印物将掺和进来野生非凡者全部控制住而本质特殊能察觉入梦并强行挣脱我就可以从容对付钢铁和他帮手完成秒杀这个成就并带走一到两具尸体…结果刚有意外那群暴躁老哥就全部冲出来甚至没留下防范意外预备队顶多也就是让封印物持有者待在外围并配有一两位保护者…越想越是哭笑不得。如果不是钢铁那伙海盗比较谨慎分出至少两位非凡者和所有傀儡活尸去阻挡后续可能追来代罚者大概率会面对二打五这种情况那样一来将选择放弃直接进行战略转移。而最让满意一点是自己针对性准备做得相当好。这是魔术师职业习惯！因为早就从莎伦小姐和马里奇那里知道异种途径前面五个序列特点很清楚有过疯子阶段钢铁能利用非理性因素对抗干扰思绪影响精神非凡能力在这方面有很强抗性所以放弃心理医生龙威和狂乱放弃明显不如代罚者封印物强力梦魇只针对性使用审讯者精神刺穿和光之祭司净化能力。——精神刺穿非干扰思绪影响精神非凡能力而是直接攻击灵体手段本质上来讲其他是作用于心智体它目标是精神体两者有显著区别。「那一套连招只要有一个环节没能产生预想作用钢铁就能缓过来让我无法完成速杀而以当时环境这也就意味着失败嗯…我也针对性利用这途径纵欲派系容易被情绪掌控特点相信他们一旦精神受创大概率会发疯一样反扑不考虑其他…其实对付活尸最稳妥打法就是布置好火柴或达尼兹利用火焰跳跃和神圣之光放麦维提风筝让他想战斗抓不住对手想跑又逃不掉一个火球过去我就能追上来可惜太浪费时间环境不允许…」叹息一声掏出怀表啪地按开看下时间。见已接近上午9点拧动房门把手走出卧室。这个时候达尼兹正躺在安乐椅上睡得整个房间都是蒸汽机在运转般呼噜声。他也算警觉克刚一出来就睁开眼睛翻身坐起。「…你要外出？」看见格尔曼取下衣帽架上礼帽。「嗯。」维持人设没解释自己要尝试扮演帮人表白。那我呢？钢铁和他手下已基本全部完蛋我不用再那么担心了…即使报纸不刊登这条新闻我也可以自己宣扬出去有闲着没事海盗和冒险家以此做吹牛材料使事情扩散到海上提醒船长那群狗屎除了喝酒和吹牛什么都不会但就算这样也有点用处…想了想隐含畏惧问：「斯帕罗先生我我可以离开了吗？」一点点露出笑容：「你一直是自由的。」对啊…我这次又没被他抓住只是寻求帮忙…我一直是自由的！先是一愣旋即惊喜。就这时听见格尔曼轻飘飘来一句：「但是它到现在为止。」啊？什么？一脸茫然。用了足足三秒钟才明白过来真正意思：那就是自己又被对方抓了！「为什么？」又愤怒又憋屈问。戴上礼帽低沉说：「我想见你们船长。」眼睛一下圆睁猛地站起脱口喊：「你想做什么？」这家伙有点激动啊…平静回答：「有些事情问她。」

## 这场戏有没有翻
翻了。梦魇遗愿；章末又抓达尼兹。翻的是死神文献钩＋「但是它到现在为止」，不是真放人。

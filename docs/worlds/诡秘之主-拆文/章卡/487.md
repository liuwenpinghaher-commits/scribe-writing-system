# 487 旅行家 第六章 生活费

## 打开书
预定神奇物品？倒吊怔一秒才反应过来正义小姐在说什么。思维局限顿时被打开感觉这事有了被利用空间：从某种意义世界委托非凡特性已经算卖出去物品有确定终点…我完全可简化流程让事情变得更轻松更有利于我也就是说我没必要再卖给工匠应该选择委托制作方式这样一来我不用担心特性是否卖得出去既能拿到世界给抽成还可从正义那里收获更多利润需要付出前期成本只有委托加工费当然必须考虑工匠不遵守承诺风险…一个个想法浮现迅速权衡利弊做出决定。「没有问题我会处理这件事情的。」望向正义只觉对方散发让人无法直视金色光芒。即使加入风暴教会飘荡海上多年也没在别地方见过这样人。大海商挥霍者不少豪富者更多但没有一个真正不在乎钱。「正义小姐财政状况好转到这种程度了？」愚者克也吓一跳。有那么一瞬间想出声催促对方让她尽快支付欠自己眷者2000镑但考虑早就答应推迟到二三月份偿还又只能不发一言保持不动免得破坏愚者形象。至少无面人非凡特性钱很快能拿到速度只取决于倒吊联络某位工匠方式和工匠制作神奇物品快慢…可惜暂时只能靠倒吊联络工匠否则可直接把特性卖正义不用支付抽成…心情变得有些复杂。敲定一笔大生意后倒吊无声松口气觉得财政状况在缓慢好转。想了几秒询问：「女士们先生们你们谁有让分布在一条船上所有人同时沉睡办法或物品？」阿尔杰之所以到今天还没去那原始岛屿猎杀蓝影隼是因为还没想到怎么不引人怀疑离开幽蓝复仇者号离开那十来名属教会水手船员。让一条船人全部陷入沉睡？克最先想到生物毒素瓶但效果根本无法控制场面恐怕不会好看。紧接着又记起蠕动饥饿里那个梦魇灵魂让人沉睡拖人入梦属这非凡职业专长。但问题在于梦魇根本没法让那么多人同时进入梦境能影响极限不超过十人要满足倒吊要求至少得相应途径序列5甚至可能得半神半人层次强者…打消想法没让世界开口。同时正义魔术师太阳或摇头或以没有作答。月亮回想：「我可以帮你问一问也许我们血族内部有类似效果神奇物品。」总是说我们血族…以后可更多地从这方面入手说服…倒吊把握到一些事微笑点头：「麻烦你了。」见交易部分接近尾声克忙让世界提最新需求：「各位帮我留意古老怨灵残余灵性和六翼石像鬼眼睛。」除此之外辅助材料不是太难购买认为没必要通过塔罗会。「好的。」太阳第一个回应然后不好意思补充：「世界先生您想要去除非凡特性内精神污染办法还需要等待一段时间我应该很快就能晋升序列7。」说着又看旁边：「倒吊人先生我一回到白银城就整理周围区域常见怪物清单。」欠别人每一样东西答应而未完成每一个承诺都牢牢记在心上觉得睡觉都不够安稳。「没问题。」阴沉世界不甚在意说。克确实也不是太急无面人守则都还没总结完善魔药消化更是才开个头后续还得好几个月。所以规划是不直奔加尔加斯群岛以冒险者旅行者姿态活跃于沿途各个殖民岛屿时不时变化身份体验生活以提炼无面人守则。这过程里将更详细打听美人鱼事——知道女神教会豢养有这种灵性生物掌握占卜家途径高序列魔药配方后总担心加尔加斯群岛那里有针对每一位寻求晋升无面人陷阱。也就是说得花费两三个月甚至更多时间在苏尼亚海上旅行冒险这间隔长得足以让太阳拿到魔药配方搜集齐相应材料晋升为序列7太阳神官。随着交易部分完结塔罗会成员进入自由交流时间。正义没有辜负倒吊期待当先站起虚提裙摆对青铜长桌最上首行礼：「尊敬的愚者先生我想知道贝克大雾霾事件背后隐藏真相这纯粹是那些邪教徒为了让原初魔女苏醒和真造降临导致的吗？埃德萨克王子为什么要选择与他们合作？根据您订立等价交换原则我需要付出什么才能获得相应情报？」我要是知道现在事情已经彻底解决了…经验丰富克维持悠闲坐姿轻笑：「不需要。问题的根源还未被发现但已有足够线索希望三大教会的人不要太愚蠢。」问题根源还未被发现？事情还没彻底解决？愚者让眷者给教会和军方留了一定线索？奥黛丽听得颇震惊但又觉得这在自己之前忧虑担心里并没有太过意外。「谢谢您的解答。」真心诚意再行礼。贝克还有危险？魔术师顿时有点不安。等到正义坐下克操纵世界呵呵笑：「倒吊人先生我发现你说的那个巴伦了。」「涉及殖民岛屿多起奴隶逃脱案的巴伦？」不太相信反问。「是的棕红色皮肤南大陆人种贝克兰德口音左边第三颗牙齿是假牙。」世界嘶哑回答。「…应该是他。」回忆两秒：「他在哪里？目前是什么身份？还有世界先生你想直接拿100镑现金还是等价物品？」这是风暴教会任务购买线索可报销行为所以倒吊毫无压力。当然是钱！正为生活费发愁愚者克操纵世界：「100镑现金。巴伦在贝克兰德有人看见他和一位效忠于王室的军情九处人员碰头具体是谁我不知道因为对方戴着面具。」「效忠于王室的军情九处人员…」咀嚼这段话语忽然想到正义刚才问题：埃德萨克王子为什么要与极光会魔女教派合作？这同样指向王室…两件案子是否可合并？事情背后真相涉及奴隶们失踪？阿尔杰觉得自己隐约看到些关键点。「你真是一位渠道众多消息灵通的人那100镑现金将在明天支付。」表面沉静感谢一句。「嘿。」世界笑一声转而望太阳：「小家伙知道古赫密斯语吗？」戴里克没做隐瞒老实回答：「我听说过赫密斯语但白银城没有掌握这方面知识。」在第二纪时候没有赫密斯语和古赫密斯语区分直到第四纪不知什么年代才对古赫密斯语有相应简化使它更便于日常应用教导传播但不再具备那么强烈那么直接仪式效果也就是说小太阳口中赫密斯语等于古赫密斯语…白银城历史里果然有赫密斯这个人…暗自点头：「很可惜本来想请你帮个忙。」这时正义从他们对话里想起一件事来源于心理炼金会。本打算直接交流可看了看新晋成员月亮先生又觉得不是太了解对方只好小幅度举手：「尊敬的愚者先生我有事情向您汇报。」克轻轻颔首隔绝其他人感知能力。「什么事情？」语气平淡问。奥黛丽如实：「我从心理炼金会得到一些消息其中最重要是他们的建立源于挖掘出赫密斯的遗迹也就是创造古赫密斯语那位赫密斯大师。」赫密斯遗迹？这位老先生一两百年前还活着啊…是他故意引导心理炼金会发现遗物还是已经在罗塞尔事件里陨落？一阵心惊斟酌微笑提醒：「赫密斯是黄昏隐士会的成员。」没提赫密斯可能还活着因为无法确定。赫密斯是黄昏隐士会成员？心理炼金会很可能与这神秘组织有牵扯？奥黛丽悚然一惊旋即舒口气。幸亏我背后有塔罗会有愚者先生否则根本无从知晓无法防备…又一次感激赞美愚者。这时克本想宽慰正义两句让她不要太痛苦太忧虑于贝克大雾霾事件成熟不表示得放弃一定好心情和脸上笑容这不会影响对事情重视程度反倒能帮助自己坚持更久但考虑之后为维持愚者形象只好放弃这来自前小丑忠告。旋即取消对其他成员屏蔽等待接近尾声交流结束等待这次塔罗聚会结束。

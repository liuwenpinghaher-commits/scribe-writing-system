# 475 无面人 第二百六十三章 秸秆们

## 打开书
因斯消失处光尽染最浓黑暗。暗中吟诗安宁催眠——漆黑水面无数苍白臂上抓亦缓不再疯如获救赎。黑夜里人影走出＝刚被拖灵界因斯。失软帽左肩衣破撕血肉淡黄脓泡咕噜；眼不淡充满痛承难想折磨。0-08续写：「有人憾有人幸；因斯身有邪神脐带来自梅高欧丝腹婴来自真造；用脐带摆脱未知禁锢强返现实；彻底失那奇物；短时承邪神子嗣无法降生怨恨。实力如百货换季商品只剩原本55%；嗯数很精确。」切东区深街。老科勒抱纸袋火腿急返租寓。警惕四望惧饿眼狼光扑抢新年馈赠。乡下见过狼；贝克兰德再体会。太贵大只能合伙锯份——新年每顿两片三片不至少五片；切炖土豆甚至不放盐…望红白肉喉蠕吞唾。走着雾浓——远教堂钟楼被淡黄铁黑吞；行人超十步只模糊影。被世界遗忘感抬掌捂口鼻。「雾怎么难闻？」加快。一步两步三步脸烫额烧。胸紧喉不适呼吸难。「病了？该死还想美好新年；积蓄送诊所医院…不睡一觉盖被就好！」脑袋烫迷糊。荷荷听自喘——双手软纸袋重落。蹲拾却摔；按袋努力往怀里收。浓痰堵喉抗争风箱声。扑通！模糊视几步外亦人倒喘；年近五十鬓白。忽然明悟知将死。想起妻儿突染瘟快死；住院同房当晚笑聊清晨停尸房；流浪汉友一冬消失桥洞僵硬；不错工人时邻居突死头疼抽搐掉钢水骨痛浮肿无声倒工厂一批又一批。想起酒吧醉鬼：「我们这样的人，就像地里的秸秆，风一吹来，就会倒下，甚至没有风，自己也可能倒下」…风来了…抱紧火腿摸兜舍不得皱烟。不解健体突染病；浓雾非未历。想不明生活刚正轨收莫里亚蒂预付报酬买火腿迎新年正期待——为何突倒。掏出皱烟臂无力抬撞地。尽最后力想喊积攒话语——弱词徘徊嘴边无法传。听自己遗言。听自己问：「为什么？」切东区边缘公寓。丽芙挂完浆洗衣等晾。外雾浓判断不准时。「总之还早；浆洗全完…」表情沉。太早完≠休息＝开工不足收入不足。吸气转身对擦手望邻房单词册大女儿弗莱娅：「快新年大多雇主离贝克度假；不能再这样；得找新工作。」往门走：「节日有钱人宴会仆人不一定够或雇临厨清洗女工；我去问；你待家到时接黛西；我等需收入；那些婊子养小偷强盗人口贩子也需收入迎新年。」东区未入工厂妇女存活：手艺或泼辣其一。弗莱娅轻快：「好。」心思飘小桌单词册。丽芙刚拉门——踉跄跌。咳咳脸涨红关节酸痛。弗莱娅慌蹲：「妈妈你怎么了？」「没有咳我没问题。」呼吸渐难。「不你病了！立刻带医院！」「太贵了太贵咳去慈善医院我能等没什么大问题。」弗莱娅泪视线模糊。忽感肺烧身软倒连带丽芙摔。「弗莱娅你怎么了咳你也病？钱在柜子挡墙壁破洞；快去医院找好的医生！」弗莱娅想说发不出声；目光斜上见邻房门——卧室高低床小桌单词册。突抽搐。丽芙咳戛止。东区边缘公立初等：雾不算浓已不少学生咳。当值老师训：「快去教堂！旁教堂！」黛西惊起跟人潮奔。忽心悸失重要恐慌…妈妈…弗莱娅…猛扭逆潮冲家。被老师抓强拖教堂。竭力挣扎撕心裂肺：「妈妈！弗莱娅！」「妈妈！弗莱娅！」东区码头工厂：老迈隐疾如砍伐树木雾中相继倒；接触者染瘟飞快死；健壮成年孩子轻微不适。眼中淡黄铁黑交杂雾气如降临死神。1349最后一周周二贝克兰德大雾霾。切大厅墙角克紧贴石壁不让A发现。很快闷哼血肉糜烂味。「为主降临献出生命吧。」扑通扑通人影沉倒；强灵性波动回荡。献祭四侍者？刚想——耳畔虚幻层叠哭；喊妈妈剧咳痛苦呻。半神秘学专家似见一道道不甘怨念化虚透影前仆后继入仪；工厂码头东区沉积多年麻木绝望痛苦愤恨压抑情绪潮涌。正式开始？闭眼背贴墙右手猛握又松。此时最好：趁A专注溜出逃远。右松又紧紧又松连续多次。七八秒后睁眼嘴角浮夸上翘。伸手握左轮猛转身冲出。黑双排扣长礼服抬右手瞄准祭坛。

# 520 旅行家 第三十九章 大胆假设

## 打开书
在大洋上海盗们有三个标志性共通爱好那就是烈酒女人和赌博阿尔杰仅是掏出银色怀表按开看一眼就明白自己首先该去哪里打听消息。此时11点过一刻妓院和酒吧都还没有开门唯有赌场肯定已经聚集起一帮想轻轻松松就发财变富家伙。阿尔杰对拜亚姆这座港口城市熟悉胜过家乡小镇几乎没有辨别方向停顿流畅七拐八绕来到一间开在僻静巷子内没挂招牌赌场外面。据他所知这金币赌场主人是个背景深厚黑帮首领与总督府那位大人物有着无法说清但又隐约存在联系是许多海盗脱手赃物购买所需首选。正因为如此这里常有海盗出没他们也许上午才把劫掠物品换成厚厚金镑晚上就已输得一塌糊涂被赶出去。拉拉拉棕色厚外套按按大陆流传过来鸭舌帽推开半掩房门在一位位保镖注视下进入赌场。——鲁恩王国内部赌场是不被允许事物只能以一个个房间形式附属于酒吧但在王国广袤海外殖民地上它不仅合法还是支柱性产业其中罗思德群岛拜亚姆和东拜朗阿勒瑟在这方面最为出名贝克兰德和间海沿岸不少富翁会专门前往豪赌一把。环顾一圈看到各种各样纸牌玩法以及从骰子衍生出来转盘式赌博。由于时间尚早赌客们并不多很快就将他们浏览一遍。突然眼睛一亮敏锐辨认出某个化妆改扮后家伙原本是谁。摘掉帽子走到一张玩德州扑克桌子前拍下目标肩膀伏低腰背凑至对方耳畔压着嗓音道：「烈焰。」达尼兹正用右手打开底牌一角被这一拍一喊吓得差点跳起来直接给后面家伙一团火焰。被钢铁麦维提袭击后他就明白自己不应该以真正面目出来打听消息那会被一位位贪婪海盗盯上。虽然大部分海盗实力不强不被放在眼里但他同样不愿意暴露行藏让狩猎钢铁麦维提计划出现波折。可让他没想到精心改扮在出门1小时后就被人揭穿。精神高度紧绷快速侧头用眼角余光瞄眼打招呼是谁。等看见那标志性海草般深蓝色头发稍微松口气转而观察牌友们是否有听见对方话语。那一位位赌客都在认真研究底牌或丢或盖完全没注意这边发生什么事情。「你怎么来了？」状似随意问。他和阿尔杰在之前那场海盗大会上见过知道对方有一条幽灵船和十来个水手是个实力不错但没什么名气家伙。而据冰山中将判断这样一个不大也不算强海盗团能保留住一条古代幽灵船说明背后有大势力支持他们或许是风暴教会人也或许与哪位海盗王哪个隐秘组织有关平时伪装成普通海盗为真正效忠者搜集目标情报方便定点清除某些时候则代替幕后势力做一些他们不方便做事情比如灭口比如抢劫某样特殊物品。类似海盗团并不少没谁会专门去管这样事情。阿尔杰将旁边椅子拉过来顺势坐下微侧脑袋低声问：「听说你们船长得到了死神钥匙？」达尼兹嗤之以鼻笑一声：「我原本以为你还拥有自己脑子结果让我失望。这种东西怎么可能这么容易得到？如果你们想要且出够价钱我们肯定会卖！怎么样？要不要考虑下这桩交易？」阿尔杰随口说：「也许它有着别秘密也许有人想对付你们船长。」「谁知道呢？狗屎！」被新一轮底牌气到大声骂一句。旋即又压着嗓音道：「那玩意不像是人类造物可能属于巨人或者恶魔。」「造物？你们船长还在坚持教导你们文字？」有些好笑问。传闻冰山中将是一位对知识有着严苛态度女士她不能忍受手下是一帮文盲所以黄金梦想号上每天都有通识和阅读课程并强制船员轮流参加。达尼兹露出一副不想回顾表情：「这比和人战斗困难多了！正因为这样我们总是招募不到足够船员每次停靠港口补给都会有人辞职…」没再继续这话题望着发牌手自顾自说：「帮我留意下钢铁行踪。」钢铁麦维提？血之上将二副？低头看看烈焰被夹板略微撑起左臂有所恍然反问：「被他袭击了？为了那把钥匙？」「他脑子已经被他活尸吃掉了！」强调道。「你想报复他？」从对方口吻和要求推测。「嘿嘿。」笑而不语状似专心看起新底牌。阿尔杰回想下道：「你们船长上一次露面是在七天前在苏尼亚岛附近这是某份电报证实事情黄金梦想号没那么快抵达拜亚姆。你有新帮手了？如果仅靠你自己即使钢铁只有一个人你也不是他对手而你知道他从来都被簇拥着。」对于阿尔杰问题达尼兹回应是扔出一个筹码：「跟注！」「是谁？」先假设达尼兹态度是默认抱着问一问又不会损失什么心态开口。达尼兹盯着公共牌简单回答：「你不认识。」我不认识？有实力对付钢铁麦维提人不管是海盗还是冒险家在大洋上都该有些名气…除非隶属于某个隐秘组织或者是初次出海当然也可能是达尼兹不想回答怕暴露秘密这概率最大…隶属于某个组织初次出海有实力对付钢铁麦维提…眼皮微抬有了个大胆猜测。轻敲着桌缘闲聊天气般问：「在班西港玩得愉快吗？」他在玩这个单词上发了重音。达尼兹愕然侧头脱口问：「你怎么知道的？」他相信以风暴教会风格不可能自爆丑闻而白玛瑙号乘客们昨晚才抵达真实见证过程人员又都签了保密协议消息哪有那么快传播出去？阿尔杰笑了笑没有回答。这一刻深刻明白罗塞尔大帝那句话价值：大胆假设小心求证！达尼兹收起这把赢筹码嘟囔着说：「也不是什么大事那里有一些古老习俗在复苏导致了一位风暴主教堕落。」果然…低笑一声道：「我会帮你留意钢铁行踪的。但我该怎么联络你？」「嗯…香树大道15号是一栋没人居住房屋你把消息写在纸上扔进去就行了。」犹豫着回答。阿尔杰点下头边站起边拍拍烈焰肩膀：「不要忘记报酬。」转过身体走向门口。目送这位幽灵船船长离去达尼兹不由咕哝：「这家伙还不错。不过我也得离开这里了。」不敢完全相信阿尔杰怕过个几分钟对方就领着钢铁麦维提那群人杀过来。出了金币赌场穿着本地阔脚裤阿尔杰慢悠悠走向大街进入一家百货商店找到相应柜台微笑掏出一把黄铜色便士道：「给我一副塔罗牌。」等待过程中悠然想到一个问题：这个时候愚者先生眷者在做什么？……老约翰餐厅内。克看着侍者将装烤鱼盘子摆到自己面前上面缠绕着稻草似东西铺着他认识不认识各种香料。那浓烈味道钻入鼻端极大地丰沛了他唾液分泌量。不愧是香料群岛…正要拿起刀叉却看见侍者将两根树枝状东西放至餐盘上。筷子？有些惊到。然后迅速锁定嫌疑犯：罗塞尔·古斯塔夫！「吃烤梳刺鱼时得用这种餐具据说是罗塞尔大帝从精灵习俗里得到灵感。」侍者介绍。精灵习俗？果然是一个爱好烹饪和美食种族…或者说纯属罗塞尔找借口…颇为了解某人性格猜测着。上午去了拜亚姆几家教会医院想为某些濒死者提供临终关怀帮他们完成心愿顺便深入扮演结果始终没找到适合目标。这不是说医院里没人死去而是都有家属或陪伴在旁或已见证死亡再去假扮没有伪装可能只有吓人效果。等下去冒险家聚集酒吧转一转那里有许多外乡人为了追逐财富来到海上随时会像无人问津野狗一样死在哪个阴暗角落里而家人却永远得不到消息…收敛心思专注起美食。

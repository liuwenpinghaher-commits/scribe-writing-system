# 429 无面人 第二百一十七章 新的一天

## 打开书
奥：「黄昏隐士会…何组织？倒吊讲势力常识从未提…」愕迷；灰雾淡愚影消。眸转猜：比极光生命学派更秘更不为人知——见闻丰与风暴密倒吊亦不知；谋划直指王国大贵族全世界最权势小撮之一；或超凡最深观察者真操纵者影响南北——难怪愚关注。上次倒吊请眷助成功非酬丰——愚本针对隐士会！与塔罗一样神秘。激动淡化尼根冲击。「知隐士会非凡不多我即其一；塔罗正针对！」起至全身镜；微抬颏美丽弧。望碧眼少女平静——首因兴趣外要素迫切提序：「严护下非凡尼根都刺；何况普通人爸。宝库有非凡＋女神额外护仍不放心——尼根卫不差。加油尽快序7／6；藏暗做爸妈哥最后防线！」切罗思德慷慨之城：幽蓝复仇者再泊；阿尔杰换风暴花纹长袍至海浪教堂——石柱拱券高穹顶双钟楼。殖民初无堂→征服仍神秘大片无因死；教堂建后渐少。门口透过窄窗光审阴暗神秘＋温暖烛。入厅拳击胸：「风暴与你同在！」主教同应递电报：「枢机命令；看完再祷。」「何？」「尼根被刺；所有代罚教士留意黑皇帝相关＋塔罗仪式全部。」「黑皇帝？」充分诧——已知愚眷。主教：刺者为序5恶魔；逃亡被黑皇帝杀；同齐林格斯下场。外在同本质同——杀齐亦愚另一眷；真要尼根死＝愚？否上次会提醒齐小心正义…愚注幕后真凶／组织？谁让愚如此重视？电报：专查小队代罚精英。申加入？终决低调原规划。切新一天：克自然醒洗漱下楼；开信报箱报纸——夹厚信封！捏油墨清香；直觉不菲现金。拆点：1000镑！机械心赏金隐秘给予？信报箱？偷了？欣喜埋怨。有钱＋无暗护→可找埃完成交易！早餐后大衣帽杖报出门。见房东斯塔琳指挥女仆装箱马车。「上午好。」矜持回；精神似复。「去哪？」「新年玛丽提前给卢克假；迪西海湾迎新年…名城小镇去过；此次费内波特塞维亚。」「羡慕。」「你新年？」「回间海冬不同味。」（实大概率本地；补斯图亚特弹孔）「望迪西遇你。」切丰收堂：埃见夏洛克笑理发昂首压嗓：「有杰森情报；血族识他。」克递报头版：「昨天尊贵尼根公爵被刺；真正恶魔肆掠大地。」详述凶手银行家帕特里克·杰森当场击毙；极光会宣称负责。早餐险喷奶——初觉A疯抢承担；细想官方掩饰。隐士会若罗塞尔组织应敌视极光憎真造？埃茫反复报：「情报没用？」「理论是；官方仍查主使——若指此尚可卖。」己不想再掺。「没有…只识爱好。」好笑：「平时不看报？」「为何看报？我很忙。」忙教堂清洁／人偶／骗血——新时代吸血鬼；小丑压笑。认真：「已筹够两种材金镑。何时给我材料？」

翻了。开头奥知隐士会立志提序；章末1000到账找埃成交、报载极光背锅。翻的是新的一天钱材落地，不是病急乱投医讨价。

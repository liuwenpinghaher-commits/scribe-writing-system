# 1290 倒吊人 第二十五章 两个仪式

## 打开书
灰雾之上古老宫殿内克莱恩身影浮现出来。此时属于愚者那张高背椅上正坐着一个被灰白雾气笼罩人。随着克莱恩回到源堡这个人瞬间崩解化成一条条透明扭曲灵之虫飞到克莱恩身上钻进去。还好0-02限制只是不能泄密不能回归我和这部分值守源堡灵之虫并没有断掉联系要不然它们已经失控成怪物了……克莱恩暗自感慨一句坐至属于愚者位置拿起之前就献祭上来那……因为这亵渎之牌已经开启所以无需他额外再寻找咒语只用灌注灵性就能看到对应变化产生。愚者牌飞快变成一册微缩虚幻书籍随着克莱恩意念引导不断往后翻动直至最后两页：序列1：诡秘侍者。这是侍奉诡秘天使初步掌握相应领域权柄可以唤起物品原本存在灵体之线可以将许多实体事物或抽象概念组合在一起……魔药配方如下：主材料：一份诡秘侍者非凡特性；辅助材料：九种灵界特产；晋升仪式：建立一个纯粹由秘偶组成城镇并为每一个秘偶设计自身命运轨迹让它们通过彼此互动演绎一副足够真实生活画卷于灵界诞生对应区域。……序列0：愚者。这是真正神灵从某种意义上来说祂就是对应权柄化身……祂擅长以各种方式愚弄万物展现种种不可思议神迹……魔药配方如下：主材料：愚者唯一性自身之外剩余两份诡秘侍者非凡特性；辅助材料：掌控至少四分之一个历史迷雾；晋升仪式：愚弄一次时间历史或者命运。……比起诡秘侍者晋升仪式愚者实在是太过抽象了……怎么才能算愚弄时间历史或者命运？又怎么鉴定有没有成功？掌握至少四分之一个历史迷雾对我来说还算简单一方面我了解古代隐秘足够多点亮历史碎片不少另一方面我是可以通过源堡直接对历史迷雾施加影响……先不考虑成为愚者问题目前重心是诡秘侍者路得一步一步走呃当然某些幸运儿可以直接飞……九种灵界特产很容易找到无论是让信使小姐帮忙还是请教七光这都不是问题……那个晋升仪式和查拉图安提哥努斯家族先祖周围状况贴近且吻合七光说和灵界有密切联系话语可以初步判断确实是真……想到这里克莱恩取下左腕缠绕黄水晶吊坠用占卜方式确认诡秘侍者魔药配方真实性。这不是他不相信罗塞尔大帝而是那位老乡在制作亵渎之牌前应该就已经被门先生影响去了月亮之上遭受堕落母神污染和侵蚀并被扭曲相应记忆。正因为如此最后阶段罗塞尔在亵渎之牌里于关键地方埋一些陷阱是完全有可能发生事情。……说到原始月亮本体那位最强大旧日堕落母神从祂称号看大帝会不会已经不知不觉被玷污……在月亮之上也许生活着贝尔纳黛未曾见过许多弟弟和妹妹当然不一定有性别区分……诡秘侍者仪式需要秘偶可以从神弃之地获取那里怪物非常多也是一个优点而且我之前也积攒不少。克莱恩思绪发散间转头望眼古老宫殿另外一侧让杂物堆旁边区域灰白雾气一下消散。……可这样一座秘偶城市该怎么产生对应灵界信息？灵界是过去现在和未来诸多信息集合体但不直接包含这种虚假事物……通过别人认知来产生？每个生灵行为话语都会以抽象形式反映到灵界成为占卜源泉当他们某些行为某些话语某些强烈意念都明确构筑出一座秘偶城市后那这座城市灵界投影就会出现真实……这其中包含互动涉及灵界深层次奥秘啊……克莱恩若有所思关闭愚者牌将它拿在手里把玩。因为已经达到天使层次他对亵渎之牌制作有一定认知……又思考一阵克莱恩试探着将那张愚者牌容纳到体内。……源堡附带整片空间轻轻摇晃起来似乎要臣服于这位难以具体描述神灵脚下。位格又稍微提高一点其他没有太实质变化毕竟我已经是源堡主人了呵这就像是多了件能彰显气质时装一样……克莱恩摇摇头自嘲两句。与此同时他身上爬出一条又一条透明扭曲灵之虫于旁边重组为和他一模一样身影。分化出时刻能响应祈祷自己后克莱恩回到现实世界漫步于贝尔丹城以愿望方式治疗人们遭受创伤并从他们口里知晓战争其中一面。……狗屎！达尼兹听到船员回报后忍不住骂一声他们竟然把鲸油给吃掉了？你们怎么不阻止？路过加尔加斯群岛时候达尼兹和船员们购买一批还未炼制鲸油准备带回拜亚姆用高价卖掉谁知道竟被白银城半巨人们偷吃一部分。……他们根本听不懂我们在说什么我们也听不懂他们在说什么只有个子最矮那个可以交流但并不是随时都能找到他他总是去太阳能照到地方冥想每次都会更换位置。……这就是文盲下场。你们要是能像我一样掌握古弗萨克语巨人语精灵语等多种语言就不会有那样事情发生了。当然语言天赋这种事情和智商有关你们也不用太勉强。……神使大人他们吃掉是您买那部分鲸油。……狗屎！达尼兹反应比思绪更快冲向船舱。等到船只重归平静慷慨之城拜亚姆已近在白银城探路者小队眼前。戴里克领着利亚瓦尔和坎蒂丝等人来到甲板上眺望向这次旅行目的地。……他目光一扫间突然看见海边灯塔上立着位男子他身穿绣风暴符号长袍头发深蓝近黑如同绞成一团海草脸庞线条粗犷而深刻。视线交汇中戴里克一下变得平静不再忐忑。

- 诡秘侍者：秘偶城镇＋命运轨迹互动→灵界区域；九灵界特产。

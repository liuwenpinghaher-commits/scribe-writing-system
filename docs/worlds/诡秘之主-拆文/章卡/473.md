# 473 无面人 第二百六十一章 埃德萨克的“故事”

## 打开书
日晒屋埃阴沉择人欲噬望无所谓特莉丝：「为何又逃？」特望窗外轻笑：「见流星雨？感地颤？」背博物瓷摔厚毯；芬克尔侍旁。「非太罕见。」「迟钝。坦白：我是魔女！」表情未变望管：「门口守；勿入。」冷瞥特出。门关吐气：「特莉丝奇克；你喜特莉丝。知你魔女；帮购材人未成——那些我供！不介意王妃女巫／魔女；甚至看过通缉！」愣戏谑：「知很多…清我曾男真名特里斯？」「…什么？」圆睁偏头。特疯笑俯仰：「听没错！曾男！下面比你长粗！女巫药强制改性别！恶心？鸡皮？」泄积压前两步。埃本能退喉蠕：「不…真女人无问题可确认！从识你即真女；过去不想知！当未发生！喜爱现在的你！」怔擦泪：「可怜人。相遇非巧；甚至你喜欢…」反胃顿：「…上我亦在人安排；不觉太快？信一见钟情不信魔力如此；如三流言情主角一面痴迷忘曾目标太疯！」眼神直张嘴无语。身晃——从漫长梦醒。「你确我喜类型…但我反应真太夸张…」特翘嘴嗤：「可怜；连喜欢被安排如牵线木偶。你可牺牲对象；我＝王室魔女教合作人质兼骗伪装。带魔女教重物严密监管随时毁丢宝＝合作诚意；一旦暴露三大教／军方另派知——故事简：埃贪恋美色偷养魔女自知罪重吞枪自尽；问题全掩。」「不！」扭曲：「合何事？」「随时可弃人质怎知？」自嘲。埋头低颤笑。抬头勾：「怎处置？剥光丢床？应已心理障；现不介给温暖；两可怜互慰不丢人。」阴圆脸默近一分。突闭眼指另边：「离开。从那扇门。」愕：「放我？」「嗯。」转窗缓：「阻芬克尔；他追捕看你实力运气。」迷茫几秒快奔暗门。回望：「你呢？」不侧凝窗外觅旧影笑：「我？活在这美好故事里迎最后结尾无论好坏。」吸气入暗门。切圣赛缪尔安静房：夜教十三大主教之一贝克教区负圣者安东尼·史蒂文森拿霍尔紧急电报。无杂须深邃眼极干净黑红袍不晦——直面颤栗惧统灵／暗深未知注。特莉丝奇克…原初魔女…轻拍纸起。周光突消昏暗吞——全堂祷众瞬感夜降。复常现地底查尼斯门前。死灵导师戴莉值守。沉吩：「备流程；我要唤醒封印物。」用0-17确认处理特莉丝奇克——唯一保圣堂外0级；仅两高层知在贝克教区。「是。」闭眼浮资料：编号17；危0极密不可打听外传描述窥探；保密教宗A组＋贝克大主教（调离用1-29清忆）；封1-29＋1-80；描述：非物＝活天使；秀美黑发黑睛疑年轻女实龄无法估；无典籍羽外表近常人；无思考失全灵智；近者人物彻消——卜确认仍活在无法找；试1825法全败；影响无规律扩缩已＞70研究者消；警告无法被利用；附录苍白年代出现缺年日地；曾醒五次…切克传假因斯消息卜助胜万能钥扰奔启出口。地毯搜尸将发现争分。无面须配毁尸物…过关卡巡逻至指向出口——讶无守卫仅沉重对开石门孤！占误导？守外？角脱甲轻便。至门摸左壁角。金币确认——古朴黄铜万能钥抵墙轻扭。水波穿壁未走正门！穹顶自然光＝出口。慎不动适光：脚斑驳灰石板；前粗大柱。大厅中央围疑祭台跪四兜帽影。清柔低缓女声入耳：「A先生，你准备好了吗？」

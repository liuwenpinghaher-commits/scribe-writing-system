# 1345 倒吊人 第八十章 “空想家”的特殊

## 打开书
诡秘……克莱恩上次听到这个称呼是从降临真实造物主意识处再上一次则是历史中远古太阳神白银城造物主。而在某种意义上这两位是可以画等号：真实造物主等于收回萨斯利尔人格后远古太阳神恶灵。……当然他也不是那么冷静一定程度惊讶错愕和难以置信还是在所难免只是因为心灵古龙艾瑞霍格那句亚当不一定就是亚当让他猜测多种可能有相应心理准备。又见面了诡秘……亚当等于远古太阳神？或者远古太阳神复活后手？祂知道这一点却依旧想要复活祂父亲所以被梅迪奇称为偏执狂？克莱恩脑海内闪过一个又一个念头对之前某件事情有全新理解：……克莱恩最初以为这是空想家足够特殊可以凭借唯一性创造出一堆貌似真实信徒做锚不需要额外再搜集信仰而现在看来这或许只是原因之一。……你是远古太阳神？……你不觉得八大天使之王里我是最为特殊那个吗？在看过第二块亵渎石板关于旧日内容后你应该能清晰认知到这点。……与全知全能相关五位天使之王里你是唯一有唯一性。……暗天使萨斯利尔……空想天使亚当是观众途径唯一性加一份或者两份序列1非凡特性。……空想家属于全知全能五途径之一相应唯一性是远古太阳神成为旧日基石之一……克莱恩最开始还以为是远古太阳神察觉原初复苏所以故意通过生孩子办法将五大唯一性之一分离出去主动降低本身位格以此对抗那种侵蚀和污染。……身穿简朴白袍留着浓密金须亚当一步步走到克莱恩旁边转过身体望着那块亵渎石板道：空想家有一个很特殊地方。正常序列0由唯一性加三份序列1非凡特性组成缺失任何一个都不能称为真神只能算天使之王而空想家可以在成为序列0后分离两份序列1非凡特性出来以空想出相应特性代替。空想出事物足够真实可以在唯一性加一份序列1非凡特性框架下完美发挥作用让空想家位格不降力量不减。分离出来两份真实序列1非凡特性可以与自己某个身份或者空想出来某个生灵结合让祂们成为作家自由行动在必要时候通过某种方式或某些媒介转变为本体。而对全知全能者来说可以创造一份介于真实与虚幻之间唯一性来维持自身状态只要不超过必要限度。这就是空想之龙安格尔威德和祂孩子噩梦之龙阿勒苏霍德关系？……一旦它们相遇0-08这支源于噩梦之龙阿勒苏霍德羽毛笔就会苏醒成为降低位格空想之龙安格尔威德……有这样基础祂才有机会和亚当竞争空想家位置彻底复活。……空想之龙和噩梦之龙关系？是。……你是在成为空想家时觉醒？不是。亚当目视前方神情温和回答道在我陨落真实诞生时。……没有哪位存在怀疑吗？……除真实确定知道可能只有黑夜会在某种程度上怀疑。亚当嗓音不疾不徐说道我将自己伪装成一个偏执狂一个想要父亲在自己体内苏醒偏执狂……那梅迪奇……克莱恩突然有点同情红天使。……这是必要牺牲。你以为祂为什么能在成为恶灵后存活那么多年而没被发现？……你打算让我就这么等着？你也可以选择离开这座尸骨教堂但查拉图就在门口等你以你现在状态只能成为祂秘偶。亚当没有什么情绪波动说道。……迷雾海内黎明号无声航行于起伏不定蔚蓝波浪中。……这是封印物0-05许愿神灯。……不属于这个时代愚者；灰雾之上神秘主宰；执掌好运黄黑之王……

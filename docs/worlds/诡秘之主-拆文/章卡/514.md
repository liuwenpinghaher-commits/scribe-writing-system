# 514 旅行家 第三十三章 各有收获

## 打开书
坦白讲虽然倒吊人已预料正义小姐不会还价且那件神奇物品价值确实在5500镑水准线上下但依然对这样行为产生强烈不适感有种自己辛辛苦苦打通环节好不容易大赚一笔结果还没有别人零花钱多幻灭感。世界那里能分到675镑工匠制作费只有600镑我能纯赚400镑…这次交易里总计进账1075镑可惜世界不是一个简单人物他出手非凡特性和魔药配方众多参与事件不少能打听到相当重要消息不值得为了几百镑和他产生矛盾否则我能将他非凡特性价格压到4000镑以下…略感遗憾想着。在愚者欣喜于即将有3825镑入账时太阳看着对面女士诚恳说：「魔术师小姐你食灵者胃袋已经准备好。」「非常好！」佛尔思彻底松口气「我会将300镑现金支付给倒吊人先生。」倒吊人闻言也是精神一振忙向青铜长桌最上首愚者先生提出具现魔药配方申请。几秒之后他在面前黄褐色羊皮纸上书写好太阳神官配方：「序列7太阳神官主材料：黎明雄鸡红冠一朵光辉契灵树果实一枚辅助材料：黎明雄鸡血100毫升太阳精油10滴金手柑粉末8克凝固熔浆5克。」克虽然没有刻意去窥探这份魔药配方但依靠他才能具现出来内容依旧映入脑海只要他愿意用梦境占卜法回想立刻就能获得相应知识。这让他不得不无声感叹一句：果然做平台最赚钱！太阳期待接过那张羊皮纸半是放松半是激动浏览一遍。接着具现出白银城周围区域怪物清单让倒吊人挑选配平差价非凡材料。倒吊人不慌不忙仔仔细细看一遍准确把握到白银城周围区域状况然后挑了三种明确知晓买家和价格材料。得到之后两天内应该就能脱手大概可以拿1000镑样子算上魔术师小姐那里300镑和之前1075镑龙眼海雕眼珠钱总算凑够了…阿尔杰一阵疲惫侧头对佛尔思道：「魔术师小姐可以准备龙眼海雕眼珠交易了。」倒吊人身上现在只有十几镑就连预支给工匠制作费用都是靠广泛人脉借来但完成这一系列交易后现金资产将达到2375镑足够支付主材料所需要2000镑。魔术师想到上周在倒吊人先生那里吃亏略感委屈回应：「好的。」对她来说这笔交易最终能赚多少只取决于老师多里安愿意分她多少再没有额外收益。交易环节最后克操纵世界再次求购古老怨灵残余灵性和六翼石像鬼眼睛至于将鱼人鳔卖出或制作成神奇物品事情暂时不打算通过塔罗会希望能以此为引子拓展开自身在海上人脉和渠道。今天塔罗会后正义小姐心理医生魔药将凑够材料魔术师小姐戏法大师魔药同样如此…小太阳有了配方总算可以往序列7奋斗了距离提供我清除非凡特性内精神污染办法又近一步…倒吊人先生即将拿到风眷者主材料之一序列6只剩最后一道难题…只有埃姆林还没下定决心和找到办法短时间内看不到晋升希望…愚者环顾一圈轻笑一声道：「自由交流。」正义本来要习惯性发言但仔细想了想后又觉得这周没什么消息可以分享。除了参加一场又一场宴会上了两节心理课只有回东切斯特郡事情可以讲但这没有必要…轻抿嘴唇保持住沉默。魔术师正处于新年假期慵懒状态里脑袋还有些空白略感心虚提一句：「贝克兰德还处在之前那种高压状态里如果不是官方非凡者最近不要来冒险。」是吗？这段时间行为习惯良好月亮略感疑惑皱皱眉。三点一线状态吸血鬼无法体会所有非凡聚会全部停止痛苦。倒吊人点下头略作思考对太阳道：「不要大意。举行献祭仪式前最好确认这次率领探索小队首席不在白银城或者正忙碌于别事情。」「倒吊人先生您意思是首席有可能察觉到命运循环？」太阳惊愕反问。倒吊人郑重回应：「不排除这种可能。但我无法肯定毕竟我对你们白银城不够了解。」说到这里隐藏住笑容展现出凝重表情。太阳则有些懊恼说：「很多事情我也不清楚…」倒吊人暗叹一声排除掉失望情绪：「总之谨慎和小心才能让你活得更久。」「谢谢您提醒。」太阳诚恳开口。倒吊人收回目光转而笑道：「最近一段时间海上相对平静。」不这只是你认为的…克默默反驳一句操纵世界嘶哑道：「我正好听说了一件海上事情。」不等倒吊人询问先看向正义和魔术师两位小姐：「女士们能帮我买一台无线电收报机吗？」「我…可以试一试。」魔术师不甚在意答应下来。因为即将离开贝克兰德正义只能对此说一声抱歉。谈好这笔交易世界清清喉咙道：「那件事情与风暴教会有关。」与教会有关？我怎么没收到通报？不需要下达给我们这个层次人？倒吊人皱皱眉耐心等待世界讲述。世界本想用玩味眼神扫一下倒吊人但因为动作难度太高只能遗憾放弃沉哑着笑道：「班西港古老习俗复苏一部分居民变成邪教徒就连风暴教会主教也堕落了。我听说事情已经解决但死了不少人。」班西港…倒吊人回忆着那里情况主动为懵懂不解正义小姐等人解释：「那里拥有活祭传统目标是一个叫做天气之神邪灵。在海外在南大陆类似邪灵还有不少表面看起来已经被清除实际还以奇怪状态存活着许多人暴毙于那些地方呵呵不一定是因为疾病你们如果有类似旅行或冒险计划不要大意。」阿尔杰力图将班西港事情描述成一起偶然发生在理解范围内意外。突然听见一道略显低沉笑声。这笑声来自于斑驳长桌最上首！愚者先生…倒吊人猛然扭头。愚者先生！班西港事情不像表面那么简单！正义当即望向端坐高背椅上愚者先生。见一道道或疑惑或好奇或激动目光投来克悠然笑道带着点回忆口吻：「这让我想起了一位天使之王。」天使之王！班西港事情竟然涉及一位天使之王！奥黛丽一下睁大眼睛对愚者先生后续话语产生强烈期待。天使之王…魔术师暗自吸气表情有些发苦。我们塔罗会讨论为什么都是真实造物主降临原初魔女复苏天使之王再现这种事情？我才只有序列9啊！简直想仰望天空长叹一声。月亮则莫名激动找到始祖让自己向愚者先生祈祷又一个原因。果然这是一个为末日准备救主聚会我们都是被选中者将逐渐面对天使之王原初魔女真实造物主等邪恶存在！忽然有了股冲动想立刻答应下倒吊人提出交易但却被没钱事实无情击碎脑海里幻想。会是哪位天使之王？太阳少有参与进正义小姐等人话题。天使之王…班西港藏了什么秘密？倒吊人全神贯注等待答案。见愚者先生没有继续往下说意愿正义忍耐不住主动问：「尊敬愚者先生是哪位天使之王？」克靠着椅背轻笑一声道：「创立救赎蔷薇的梅迪奇祂血脉后裔居住在宾西。」救赎蔷薇！和真实造物主有关天使之王？奥黛丽没想到事情一层比一层严重下意识疑惑：「宾西？」「那是班西古称。」倒吊人双手虚握低沉回应。他已经无法想象这件事情背后究竟藏着什么真相只知道班西港变故也许并没有真正结束噬人危险还潜藏在暗处！对于救赎蔷薇了解不多仅仅清楚这个名词和真实造物主神庙命运天使乌洛琉斯有关无法确认具体代表什么。总之这件事情层次已经超乎想象！阿尔杰望向斑驳长桌最上首油然闪过愚者先生果然认识八大天使之王掌握不少秘密念头。就这时想到一件事情：上周这个时候正义小姐询问过剩余天使之王有哪些愚者先生回答是以后会接触到的。而仅仅一周过去就真的接触到一位新天使之王了！愚者先生早有预见！瞳孔一缩惊惧低下视线。

# 539 旅行家 第五十八章 压制

## 打开书
直到离开奥德拉家地下区域埃姆林还有些迷幻不敢相信这么轻松就拿到了7000镑奖励。那张汇票握在手里轻飘飘没什么重量但却让他体会到现实荒诞。倒吊人办法真管用…尼拜斯大人没有揭穿我惩罚我反而给了丰厚奖励而这仅仅是为了假装不知道鼓励我继续尝试以便暗中观察…血族心思也是这么复杂吗…一阵恍惚一阵感叹。很快收敛住发散想法将注意力移回那7000镑奖励上：「有了它我就能从倒吊人那里买下男爵遗物调配成魔药…我就快成为男爵了血族男爵埃姆林大人！」眼睛骤亮脚步都轻快不少。在血族内部如果没有长辈馈赠举行相应仪式出生在什么位阶就会固定于什么位阶几乎没可能靠自己靠时间提升。和埃姆林年龄相仿那些血族们除了运气极为不错家族先祖寿命接近极限不得不通过仪式赐予后辈力量绝大部分都还停留在成年这个概念里几十年内没有获得爵位可能。父亲和母亲活了那么多年到现在为止依然没有成为男爵甚至看不到什么希望！走出大门时忍不住看眼身旁卡西米。这位曾活跃于罗塞尔时期年长血族到现在为止也只不过是一位男爵…而我即将达到这位阶！总有一天我要成为尼拜斯大人那样血族侯爵！不公爵甚至亲王！只有这样才担负得起血族救主责任…嗯男爵遗物也就四千多镑还能剩不少钱可以再买几个人偶再为她们配些新衣服…不自觉挺直腰背走得愈发昂扬。……白银城伯格家。戴里克点亮蜡烛准备起献祭仪式。闪电频率多寡交替好几次后终于等到机会。非常确信首席此时此刻没法盯着自己因为他带着伤势初步愈合小男孩杰克和一支探索小队离开白银城寻找起对方从所谓海边来到那座毁灭城邦路线。没用多久布置好一切虔诚庄重低声诵念起愚者先生尊名。非常熟练有条不紊将魔术师小姐需要食灵者胃袋倒吊人先生指定非凡材料献祭给灰雾之上主宰。白银城坚实城墙上多有缝隙但填满黑硬泥土上面长着一丛丛细密杂草在风中轻轻晃动如同人类头发。忽然它们全部扬起似乎想抓摄什么但又毫无着力点落下来。……清晨时分海浪教堂。前来领取赏金阿尔杰从教区主教乔戈里口中听到一个颇为重要消息：摩斯苦修会拉蒂西亚以考古学家身份为掩饰进入西弥姆岛丛林深处她不知做了什么导致遭受重创躲藏多年海神卡维图瓦即将崩溃发疯一样寻找起延续本身存在机会。传闻这自称海神邪灵在很久以前罗思德群岛被发现后就遭两位枢机主教联合军方强者借助相应封印物品击败只能勉强逃脱隐藏起来…这样情况维持一百多年没有本质变化它怎么突然就快要崩溃无法维持本身存在了？微皱眉头想着最近有什么与以往不同事情发生。「摩斯苦修会故意制造局面？可之前一百多年里他们为什么不这样做？为了配合自身另外计划？」推测与疑惑交替间忽然察觉到一个重要因素。最近与过去一百多年最大最本质不同是：世界来到拜亚姆！愚者先生眷者来到罗思德群岛！他出现于哪里就表示哪个地方将有大事发生或酝酿？前有贝克兰德大雾霾中间是班西港异变现在是海神濒死挣扎和摩斯苦修会未知图谋…不更准确描述应该是哪个地方有大事酝酿或即将发生愚者先生眷者就会来到哪里！他们接受愚者先生安排追逐着那些隐秘组织邪神天使活动！思路一改豁然开朗觉得自己把握到真相。不是世界到哪里哪里就会出事而是哪里即将出事世界等眷者就会出现在哪里！这对愚者先生有什么好处？纯粹为了破坏敌对势力图谋还是这有利于祂解除封印透出更多力量？按捺住疑惑决定抓住这机会提交之前某个情报。右手握拳抵住左胸面露迟疑说：「乔戈里阁下我在追查钢铁残余势力过程中听说了一个消息。」「什么？」乔戈里本打算安排这位主教级船长到海上寻找反抗军踪迹却被对方强行打断一时有些烦躁。阿尔杰回忆着说：「有人在聊天里提到班西港说那里出了变故但梅迪奇家族后裔隐藏得很好没被发现。」班西港变故…乔戈里跨前一步追问：「他们还说了什么？」「他们说教会有主教在那里堕落其他就没有了乔戈里阁下梅迪奇家族是第四纪黑暗家族吗？」故意问。乔戈里脸色一沉：「这不是你应该知道的。我会立刻汇报给考特曼阁下。」这是指风暴教会枢机主教罗思德海域大主教代罚者高级执事群岛超凡世界真正统治者亚恩·考特曼。乔戈里想了想又问：「提到这件事情人是谁？长什么样子？」阿尔杰早有准备：「我不认识他们他们之后也没有再出现。我记得提及班西港和梅迪奇家族是个外表普通年轻男子他脸庞瘦削额头很宽黑眼睛黑头发戴着单片水晶眼镜。他似乎有注意到我在偷听但并未生气反而对我笑了笑。」描述正是渎神者阿蒙！要让枢机主教们认为梅迪奇家族与班西港秘密曝光源于天使之王间争斗。这真是一个非常适合作为理由对象…祂不会出来辩解什么即使辩解了也不会有谁相信…而对祂占卜明显不会有什么效果…如果用非凡手段确认我消息来源会因为涉及愚者先生出现强力被干扰迹象无法得到准确答案这从表现上看可以等效为阿蒙做…相当放心想着。乔戈里轻轻点头道：「你寻找下这些人并追查反抗军行踪。」「是乔戈里阁下！」一脸虔诚回应并握右拳击左胸。……高空乌云层叠天色昏暗到极点大雨磅礴而降滴答落地溅起阵阵白色水雾。拜亚姆港口蔚蓝海水缓慢但坚决上涨着货船客轮摇摇晃晃仿佛飘荡于半空树叶。雨水不停海平面逐渐逼近堤岸城市内多处积水环境异常压抑。一位位狂热而麻木本地人穿着塔拉巴衫披着破烂夹克一个接一个来到悬崖边缘或堤坝之上相继跳入海中。他们血肉和皮肤飞快失去着水分落进海里时已变成风化已久干尸。一群人哭喊着抱住一位走出基地海军士兵愤怒悲伤地用牙齿将他咬死咬出血肉模糊惨状大街之上处处混乱。哗啦！轰！堤岸崩塌不断高涨海水涌入拜亚姆城。克一下醒来脑海里回荡尽是刚才梦见画面。对一位占卜家来说这是非常明显启示！「卡维图瓦这个海神找不到存活下去办法彻底放弃完全疯狂要制造暴雨掀起海啸淹没整个罗思德群岛拉无数人为它殉葬？而与此同时它信众们也做出种种极端行为…我已经通知风暴教会他们应该来得及阻止…不就算我不通知出现这种情况他们也能察觉到问题所在从而做出应对…」翻身下床穿好衣物走出卧室。看见烈焰立在窗边眺望着外面。看见云层低压雨水连绵仿佛永无止境。出现征兆了？走到达尼兹旁边同样看起外面压抑天气耳畔隐约听到反常潮水声。静默之中半空忽然响起一道极有爆炸力雷声铅色云层飞快裂开掉落雨水失去后援码头方向一切恢复正常。高空晨曦洒落拜亚姆就仿佛沐浴在圣光里。达尼兹嘶一声自言自语般道：「亚恩·考特曼改变天气…」亚恩·考特曼…风暴教会那位枢机主教兼代罚者高级执事？他压制卡维图瓦力量？若有所思收回视线。达尼兹松口气道：「我刚才还挺担心呵呵害怕那个快崩溃海神制造灾难。但这里有亚恩·考特曼。」见格尔曼没有说话又自顾自补充：「如果在海上即使五海之王和神秘女王也赢不了他。船长说船长说他是序列3半神魔药名称是…是…海王！」

## 这场戏有没有翻
翻了。埃姆林昂扬；章末海王压制。翻的是阿蒙锅甩班西＋考特曼改天气，不是海啸成真。

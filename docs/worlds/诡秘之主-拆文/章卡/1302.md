# 1302 倒吊人 第三十七章 活化

## 打开书
已经死了……爱德华兹转过脑袋用那双浅蓝色眼眸望向贝尔纳黛无形仆役他目光不再冷漠和木然闪烁起奇异光芒充斥着不敢相信色彩。直到这一刻他才似乎认知到自己早已死去又活过来与需要提防威廉珀利和格林没有本质区别。这样变化只维持短短两秒钟时间爱德华兹脸庞突然扭曲起来本就青白皮肤飞快黯淡一寸又一寸撕裂。……不要不要靠近我……给自己脑袋一斧头后爱德华兹对着贝尔纳黛无形仆役艰涩低哑开口道。……沉默两秒贝尔纳黛让无形仆役对着爱德华兹背影道：你后裔们过得都还不错都有一定成就。……他目标方向似乎是那个亡者可以获得新生石柱坟场。……这位神秘女王没有惊讶和慌乱依循着预言大师本能和长久以来积累经验向前走出几步通过无形界限彻底离开那片原始森林进入黑皇帝陵寝所在空旷区域。这个过程中贝尔纳黛还让无形仆役回归灵界。……整片原始森林都活过来！……虽然是预言大师但贝尔纳黛还是没想到自己简简单单没直接点明一个问题会带来这种程度异变就仿佛那是一把钥匙打开连通深渊大门。……爱德华兹状况与威廉格林他们有着一定不同就像是这座原始岛屿上那种秩序漏洞或者说阴影……当他意识到自己早已死去时这个漏洞这片阴影就被秩序发现开始遭遇修补。而修补带来那种秩序增强导致整座岛屿都发生异变。我能感觉到这里面有一定程度黑皇帝力量是它影响爱德华兹让他新生后还保持着自身一部分意志而原始岛屿最初秩序来自哪里？咦……而且这心脏还在一点点长大！不需要再用窥秘能力去看腹部贝尔纳黛直接就感应到自己肚子里有了一个胎儿。它从葡萄干大小一直长到正常人类巴掌大并且还在一直长下去似乎用不了多久就会发育成熟撕开母亲腹部血淋淋钻出来。……大地母神……原始月亮……欲望母树……贝尔纳黛脑海内一下闪过三个神名。据她所知能造成这种异变神秘并不多绝大部分源自大地和月亮途径相关领域。——耕种者途径序列0就叫做母亲原始月亮可以让石头获得繁衍能力欲望母树则疑似掌握着月亮途径部分高序列非凡特性。……存活希望在陵寝内。……这些类同于亵渎石板上那种文字单词迅速交织成奇异符号开启一扇通往灵界深处般秘门。紧跟着秘门敞开狂风吹出化成一个上身人下身气流包裹着白布男子。贤者额饰。贝尔纳黛语气平和嗓音威严吩咐道。……这饰品核心是一只钻石镶嵌成竖眼它闪烁着纯净光芒给人异常神圣充满智慧感觉却又显得颇为冷漠没有温度。贝尔纳黛随即接过这饰品将它镶嵌到额头中央。这是件0级封印物贝尔纳黛平时根本不会随身携带因为负面效果实在太严重。不过此时此刻这贤者额饰有一个能力对贝尔纳黛相当重要她愿意为此承受所有偏邪异类魔法都不能使用且非凡特性会逐渐影响身体一点点融入后果。——如果不能在较短时间内取下那贤者额饰贝尔纳黛就等于被人将序列2魔药泼到身上一样到时候要么作为幸运儿成功晋升为贤者要么失控疯狂变成怪物而在没有辅助材料没举行相应……它略有正常婴儿一半大已长出五官和四肢皮肤皱巴巴流淌着粘稠脓液。随着它脱离母体尚未彻底成形它逐渐退化飞快消融于空气中。……与此同时贝尔纳黛化成信息洪流通过那扇沉重石门进入黑皇帝陵寝内部重组出原本身体。这个过程中她似乎看见一道黑色影子。

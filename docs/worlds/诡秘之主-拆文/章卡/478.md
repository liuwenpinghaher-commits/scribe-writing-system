# 478 无面人 第二百六十六章 莫名的微笑

## 打开书
郊外荒芜田地老管家芬克尔飞快奔逃。失帽梳理一丝不苟斑白发凌乱垂；衣表满泥泞。呼呼稍停喘气望后——来处空无人略安心。扭头准备改向——面前不知何时多一道人影。披兜帽古典长袍黑眼眸藏阴影面容呆滞无表情。芬克尔瞳缩当即张嘴试图念古赫密斯单词——愕然察觉鼻子在消失声音已不见。表情顿多几分绝望——整个人如虚空污迹被抹布擦干干净净再无丝毫残余。……阿嚏阿嚏咳咳！面对A即将发动致命攻击——克身染疾头痛脑热难操纵火跳跃。连空气弹都制造不出。对未知结果恐惧占心灵；小丑危险预感让「看见」己霍然分裂崩解最微光粒也许连复活不再有机会。刹那手探衣兜握一件。预先考虑过最危险情况应对！再怎么仓促魔术师亦有一定准备不会战斗慌乱无措。拿出阿兹克铜哨凑嘴边喷嚏咳嗽声里艰难吹一下！无任何前置动静——灵视见白骨喷泉涌出飞快勾勒眼窝漆黑火焰燃烧巨大信使。这时A面前书册亦停翻悠远声戛止。一阵绿蒙蒙光华涌出——近四米高白骨信使一下裂开裂无数纯粹光点。它身后让克只能原地打转力量率先崩溃；穿黑双排扣长礼服人影随即被笼罩变成黄沙铸就般雕像被风吹散。但散去是白色斑点如撕到极致纸屑。克身影浮现另外一侧半跪地控制不住大声咳。若非白骨信使先挡一下根本来不及短暂压制疾病用纸人替身！折腾后病更重几乎快失反抗能力。就这时致命一击未成功A突然也咳嗽起来比克还剧烈。痛苦匍匐嘴角涌血沫。咳咳咳！咳出一堆破碎内脏蠕动血肉——艰难张嘴试图舔入口中强行吃回去。怎么回事？一时懵。但不妨碍忍咳抬右手左轮瞄准A脑袋。这瞬间隐约明悟：A肉体伤可靠血肉魔法治疗维持；精神灵性冲击反噬却无法此方式弥补。本该切换另外非凡缓慢愈合灵体创伤——却被仇恨驱使强压制追赶；连续消耗动用超本身负荷非凡后情况恶化一下爆发。砰砰砰！射左轮内所有弹黄铜淡金银白流光飞越两人间不算长距。遗憾过程无法克制喷嚏咳嗽子弹未全部命中——只两发打A：一钻额一射躯干。滋！烧灼声——A脑袋仿佛无骨只烂肉组合；淡金弹深陷其中很快停顿未能致命只得绽阳光般金芒。抬下脖子破洞脑袋内血肉正疯狂蠕动。没死甚至没重创。曾经生命力顽强蔷薇主教！见此当机立断扭头跑不再尝试攻；A荷荷喘再低头舔舐咳出碎肉内脏。喷嚏咳嗽交错跑得东倒西歪时翻滚。终于逃到最边缘——超五十米崖壁。崖下略浑浊塔索克河奔涌不息宽阔但平静。无犹豫脚下用力跳出去。急速下坠感自由落体强失重。身体撕裂空气试图半空调整姿势变跳水标准动作。咳！阿嚏！疾病让团身翻滚三周半中途停；身体打开双掌调整亦未到位。啪叽摔水面摔成一张薄薄白纸。纸人迅速湿润半沉半浮。不远处水底克身影勾勒有所颤。衣物已浸湿；里剩余纸张皮夹内钞票同样。远离A后疾病得缓解…心有余悸。若非最后关头咳喷嚏平息不少甚至来不及纸人替身法摔内脏出血直接去世；当然那样死因觉能复活。双脚蹬水间嘴里造无形空心管子伸水面为自己带来新鲜空气。「魔术师」「水下呼吸」表演！嘴吸鼻呼不让浑浊气污染管道直接入水。同时悄向岸边游希望此方式避A后续追踪。可惜非城市无面人能力没法有效发挥否则一经脱离A肯定再找不到…游动本能闪。这一想——想到A先前用过控风非凡。一般属风暴之主途径…特点除风还有水尤擅水下活动…水下活动…牧羊人太全面太可怕！念头闪心脏几乎停跳。猛上游不再掩饰！刚浮出水面近岸——见A漂亮妖异脸孔上面长满鱼类鳞片裂出鳃口。鲜红长袍飘水面嘴角勾眼眸宛若实质仇恨。拼！只能拼！争取支撑到教会援军抵达或阿兹克先生脱困！疾病缓解毫不犹豫抬右手准备打响指。就这时两人同时望半空几乎本能反应。那里迅速勾勒一道有女性柔美感身影。戴兜帽穿深色长袍目光呆滞望向A。然后克见A似乎变成铅笔画被橡皮擦飞快抹掉毫无反抗力——只留下茫然里带不甘疯狂中藏绝望眼神铭刻现场唯一观众脑海。这…什么样位格！什么样实力！念头刚动——发现身影侧过脑袋望向自己。秀美脸庞无丝毫表情；黑眼眸幽暗深邃却缺乏灵性。心脏狂跳以为自己也会无声无息消失不知有无机会复活——那女子嘴角缓缓扯动向上勾起露出一个微笑。微笑？一阵愕然怀疑做梦。还没回过神身影瞬淡化消失原地；四周水流哗啦声寂静回荡。迷茫疑惑游到岸爬上环视——异常偏僻无道路无活人只有略浑浊河水永不改变流淌。这就结束了？A就这样死了？刚才女士是谁竟强到A连惨叫都来不及？还对我笑了笑…笑了笑…也许是祂？可三大教会除教宗层次哪还有天使行走地上；教宗层次显然不会在贝克…不敢信这就摆脱危险。沉沉心神终于找到几分真实感：「应该是教会派出强者及时赶到成功解救我。若我没提前通知正义小姐他们未必来得及；今天大概率死A手上还不知能不能复活…嗯也有我一直坚持将战斗拖延到现在因素。还算不错…」松口气咳两声开始寻找出路。……「放逐！」戴黄金面具男子指着阿兹克将其身影丢入虚空不知扔向哪里。旋即转身面对皱眉看自己因斯。「没时间了我们没法那么快解决他！必须尽快隐藏这里只能放逐！难道你想被教会人发现我们秘密？」恼怒沉声。因斯收疑惑点头转身来到停止书写0-08旁一把抓住。身影有些蹒跚双脚位置堆战斗里几乎撕裂裤子。……红蔷薇庄园埃德萨克王子坐落地窗边眼神异常空洞。「王子殿下请尽快。」旁声响。埃德萨克眼睛活过来吸口气拿起桌上左轮抵太阳穴——里面有一颗能泯灭灵体子弹。回过头眷念望眼外面高尔夫场地与正在散步马匹。砰！扣动扳机。

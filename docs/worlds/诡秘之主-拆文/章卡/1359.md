# 1359 倒吊人 第六章 选择

## 打开书
克莱恩又写了些对廷根印象后简单提一句自己已完成仪式成为序列1诡秘侍者并解决长久以来笼罩他心灵阴影之一——密修会首领查拉图。他并未详细描述自己困境只是认真探讨一下天使精神问题。收起钢笔折好纸张克莱恩探手从源堡内拿出阿兹克铜哨凑至嘴边吹一下。……不用这么畏惧我。克莱恩见状笑一声道我又不会对你做什么？……如果没有末日要维持廷根时生活且过得比较惬意能处理绝大多数案件最好有序列7。魔术师手段多样有准备情况下面对序列6和序列5都不会显得太弱而无面人和秘偶大师一个扮演时容易迷失一个晋升时容易失控相对来说都很……他不知道阿蒙会怎么对待这件封印物只是觉得对时天使来说这种层次物品不会有什么价值玩一段时间后就会丢弃到黑暗隐秘仓库里。不知道有没有机会拿回来。克莱恩刚闪过这么一个想法忽然有些心虚。因为就算他能将蠕动饥饿从阿蒙手中夺回也是扔进杂物堆中等待着赐给需要眷者或信徒。……这次又丢魔镜。亚当应该也看不上这么一面圣者层次镜子或许可以辗转拿回来……不阿罗德斯似乎是从混沌海里喷出来在某些事情上未必不能做个媒介……唉只希望亚当不要将它损坏等我想到办法将它拿回来……成为诡秘侍者更进一步掌握源堡后克莱恩已拥有一定隐秘权柄。……这是相当于神国雏形诡秘之境。……叹口气后克莱恩突然记起一事忙让值守源堡灵之虫们将自己晋升时定位某个灵界区域嫁接过来。……戴好礼帽站起身来克莱恩向前走一步直接进入对应乌托邦灵界区域。然后他解除嫁接通过这个灵界区域回到已成为废墟乌托邦。——这是利用嫁接和他本身自由进出灵界能力间接达成传送效果……一步踏入乌托邦废墟克莱恩环顾一圈发现倒塌房屋和焦黑尸体间闪烁着不同颜色光芒。……这对他来说或许已经没用但他还有众多信徒还有数量会逐渐增加眷者身为一位神灵总得储备一些非凡特性以便赐予。还好风暴之主没顺势把它们都卷走……克莱恩无声自语中忍不住感激列奥德罗一句。……太阳终于升起后饱受煎熬众人相继返回房间补充睡眠只留下阿尔弗雷德霍尔伯爵私人保镖黑夜教会派遣来执事和值夜者们调查昨晚事件缘由。……暴怒先生。这是之前追逐心灵巨龙艾瑞霍格心理炼金会暴怒先生疑似赫密斯某个身份存在。……而借助这个动作遮掩她手背闪过一片星辰般深红纹身。……很抱歉利用你。等到房门合拢那只巨型白兔主动开口道不过我也可能被谁利用了。……不用抱歉以后不再打扰就行了。……你曾经心愿是保护父母保护亲人但你不觉得你卷入太多麻烦给他们带来危险胜过你能提供帮助吗？……正常来说一位圣者确实能让家族和亲人获得更多安全但前提是他并没有牵涉到天使乃至神灵间争斗或者有一个足够强大组织可以依靠真正意义上依靠。见此情状巨型白兔缓缓说道我表达歉意礼品有两个你可以自由选择一个。……一个是真正成为心理炼金会傲慢小姐我们可以忽视掉你其他方面秘密默许你别行动只要你不将我们事情透露出去给心理炼金会带来危险当然这也有一定坏处你将承担一些事情或许会卷入不小麻烦中唯一不同在于你能获得很多……第二个呢？奥黛丽根本就没有从心理炼金会获得补偿想法。这个隐秘组织不再打扰她就是最好道歉。而且她非常怀疑暴怒先生说抱歉真实用意觉得这也许是另一次利用。……我可以帮助你分割一个身份出来让她留在亲人旁边提供一定保护和情感慰藉而你远离他们以另外身份活在这个世界上。这样一来你卷入麻烦就不会波及你想要保护人。在超凡世界里在某些时候某些情况下远离才是最好爱护。……你不需要立刻回答我也可以将两种方式综合一下。巨型白兔离开高脚凳站起来你知道怎么进入伊甸园。……而且一位枢机主教必然深受风暴之主重视阿尔杰背叛随时可能引来神罚……达尼兹越想越有点瑟瑟发抖害怕自己受到波及。……不要靠近被神厌弃人。……要不是格尔曼·斯帕罗以愚者先生侍者身份传递信息给我让我安置阿尔杰·威尔逊我早就把这失控炸弹绑好送回风暴教会了……达尼兹越是害怕越是忍不住在心里咕哝。……有什么收获？他压着嗓音问道。……神使大人风暴教会换一位枢机主教。原来那位呢？达尼兹略感愕然追问道。据说是调回总部了。那名情报主管说着自己从海浪教堂某些仆役处打听到消息。……他耳畔随即响起愚者先生话语：从今天起阿尔杰戴上面具担任海神教会教皇。

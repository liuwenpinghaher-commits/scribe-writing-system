# 1391 倒吊人 第三十九章 昨日不再

## 打开书
南大陆东拜朗某个黑夜教堂旁房间内伦纳德意识回归现实世界。他默然几秒端起面前已变凉不少咖啡轻轻抿一口。苦涩味道旋即充盈他口腔让他头脑逐渐清醒过来。老头今天究竟发生什么事情？终于伦纳德按捺不住主动开口问道。……错误陨落了。错误……伦纳德险些没反应过来老头说错误是哪位存在。……阿蒙？……嗯。帕列斯·索罗亚斯德嗓音比以往似乎又苍老一些准确来说是阿蒙主体陨落了。……这这怎么会一点迹象都没有？……祂应该是在源堡内陨落。源堡内？伦纳德吓一跳。他刚才参加聚会地方就在源堡内部！那里竟然刚爆发一场神战？阿蒙竟然侵入源堡？伦纳德思绪纷呈间表情逐渐凝重下来：老头愚者先生就是因此受伤不得不选择沉眠？祂要沉眠了？帕列斯·索罗亚斯德反问一句。……伦纳德嗯一声：祂今天临时召集我们就是为这件事情。……祂选择沉眠确实和之前神战和阿蒙潜入有关但不是因为受伤而是遭遇污染。污染？伦纳德颇为诧异脱口问道。到愚者先生这个层次还会遭遇本身很难驱除污染？……万物皆有神性依赖神性变强者永远都逃不过神性束缚。这一点你是这样我是这样愚者也是这样呵也许不该再称呼祂愚者了祂现在等于半个诡秘之主。诡秘之主……对于非凡特性内精神烙印问题伦纳德确实比同层次半神了解更深但在可能涉及更高层面可能因知道就带来污染知识上他还是有不少缺陷哪怕之前已经听老头提过诡秘之主这个名词还是不明白究竟代表什么。不过他目前也能根据愚者先生聚会时说辞和老头刚才话语确定愚者先生位格已经超越序列0实力足以击杀一位真神。……老头克莱恩为什么也会跟着沉眠？你有没有办法尽快唤醒他？……这种神灵层面事情我这个又老又弱天使怎么可能知道？至于唤醒就连愚者都没有更好办法何况我？……老头你有没有办法窃取别人才华？……才华这个词语定义模糊分类不清没法窃取。不过如果将它换成天赋那就有办法。……算了。伦纳德最终还是做不出窃取别人天赋来帮自己解决困难事情。……如果你不能接受这种方式那可以找一个拥有你想要那种天赋但非常穷困人做交易给他渴望金钱换取对应天赋。这有点像魔鬼……伦纳德中肯评价一句。……还有个更简单办法那就是花钱聘请有天赋人帮你解决相应困难。……老头你怎么不早说？伦纳德一下看到希望曙光。帕列斯·索罗亚斯德呵一声：这么简单你都没有想到？我以为你已经排除这个选项才来询问我。……你去哪里？帕列斯·索罗亚斯德略感诧异问道。……去附近书店买些诗集。自从晋升梦魇他就放弃过去买诗集让它们更多是作为装饰存在；等到成为灵巫他开始让搜集来能力合适部分灵阅读诗集以便在战斗中诵念制造非凡效果配合自己。……这是愚者吩咐？对宣扬相应传奇故事。伦纳德一边简单回答一边开门而出。……在写诗之外你还得多关注围剿玫瑰学派事情。……嗯。这一刻走向书店他仿佛又回到廷根回到还是午夜诗人时那段岁月。那个时候他也是这样走在热闹喧嚣街上预备着买一本鲁恩早期古典诗歌集和一本罗塞尔诗选。……对于愚者先生沉眠他感触和其余塔罗会成员稍微有一点不同。……所以埃姆林早就见惯和听多了沉眠这种事情知道它不等于过世不等于陨落认为如果找对办法愚者先生有不小概率醒来。……愚者先生沉眠了始祖神谕又经常受到干扰明显不能频繁提供帮助……果然到最后需要自己去面对去背负。这就是救世主宿命。说到救世主这个词语时埃姆林明显笑笑带上些许自嘲意味。……只能靠自己了。……该出发了。……好。……再等半天。……准备好了来找我。……通知身在贝克兰德所有血族过来有件事情需要讨论。是伯爵阁下。那些血族恭敬做出回应。……这就是救世主宿命啊……

## 这场戏有没有翻
翻了。开头帕列斯告阿蒙主体源堡陨／愚者污染半诡秘沉眠；伦买诗集唤廷根昨日；埃姆林「救世主宿命」自嘲组药司／血族会。翻的是昨日不再＝知神战后各自上路。

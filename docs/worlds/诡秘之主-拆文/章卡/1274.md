# 1274 倒吊人 第九章 新的旅程

## 打开书
博诺瓦·古斯塔夫……克莱恩目光从眼前年轻男子脸上滑过落到周围漂浮物品和那个金属零件拼成人偶上。人偶很有后现代风格……这里部分物理规律似乎有一定程度改变……克莱恩若有所思点头道：我想拿走那面魔镜。他非常坦然说出自己要求。博诺瓦没有表情变化仿佛只是一个人偶：你是黑夜眷者？目前算是吧。克莱恩笑了笑道。那你拿走吧。非常感谢。……接下来伊康瑟和那位机械之心成员所在车厢内却什么变化都没有发生。……不要开口。克莱恩对着镜子简单吩咐一句。是伟大至高主人。一个个淡银单词轻快从镜面深处浮出来。克莱恩旋即拿出纸笔以魔镜为垫准备写信。尊敬阿兹克先生：似乎已经有很长时间没有给你写信了因为我去了神弃之地做了一场奇妙旅行。那里生灵只有两种一种是活着智慧生物一种是怪物而那些智慧种族要么背负着诅咒要么已出现明显畸变比我之前想象更加悲惨。我尝试着帮助他们这不仅仅是在为仪式为锚为满足自己怜悯心理它本身就是意义……抛开那些苦难整个神弃之地状况与外界截然不同就像一幅幅以黑为主色调油画……让人惊奇是人造死神可以有限度影响这里不死生物我当时非常不解今天终于有猜测怀疑这与九大源质之一永暗之河有关……这让我想到灵界城市卡尔德隆想到您曾经提过黄金制成不死鸟饰品……传闻那位不死鸟始祖和第四纪死神都能在一定程度内利用永暗之河不知道您对此有什么了解？持续一年多战争终于结束黑夜女神取得最后胜利战神因此陨落我想以您层次和地位应该知道这意味着什么……不管怎么样久违和平降临人们逐渐回到平常生活里这是我喜欢画面但某些伤痛可能永远都无法抚平……不知道末日会不会准时降临也不知道您什么时候会醒来我只能盼望一切都往着好方向发展。最后再说一件微不足道小事我已经晋升序列2成为奇迹师这既是诅咒也是希望。祝安好您永远学生克莱恩·莫雷蒂。……这巨大信使从地下冒出时浑身骨头都在颤抖似乎察觉到灵界之上伟大主宰气息。……做完这件事情克莱恩将目光投向放在大腿上魔镜。伟大主人我们接下来去哪里？去哪里？克莱恩在心里复述一遍这个问题很想直接传送到霍纳奇斯山脉主峰进入现实与迷雾小镇间那座古老宫殿看有没有机会从安提哥努斯家族那半个愚者身旁拿走那张对自己来说最有用亵渎之牌。以他目前相当于大半个序列1实力这不是没可能完成任务——当初查拉图序列2时候都能从半个愚者处拿到诡秘侍者主材料。当然一切前提是黑夜女神保持着对安提哥努斯家族先祖压制和封印。于是事情又绕回来绕到和黑夜女神交易上。现在我已经是源堡主人可以分出一部分灵之虫留在灰雾之上时刻回应祈求这样一来除了精神状况有一定隐患其他方面都有不小好处嗯既可以随时支援本体又多一种复活手段……哪怕本体被彻底消灭依靠灰雾之上……就算去寻找永暗之河线索也要等到他满足众多愿望有真正奇迹师水准后。想到这里克莱恩拍了拍魔镜笑着说道：接下来我们一起去流浪吧。你有什么想去地方？特里尔不您想去哪里我就去哪里。阿罗德斯用文字谦卑回答道。……穿着圣洁白袍清灵秀美不老魔女卡特琳娜放下手中镜子侧头对旁边摇晃着安乐椅年轻男子道：战争结束她们终于决定将我召回总部。这一天我已经等待太久。坐在安乐椅上年轻男子啧一声道。他穿着黑底红纹长袍有一张线条柔和肤色偏棕略显苍白脸孔正是被红天使恶灵附身看门人。……你似乎一点也不急躁。当你和两个可恶家伙一起被关在地底一两千年都无法摆脱你就会知道一两年等待是非常轻松和惬意我一点也不着急。红天使恶灵呵呵笑道等这件事情结束如果你好奇我会让你体验一下当然我会记得给你扔两个男性同伴……说这段话时候红天使恶灵脸上没出现那两张嘴巴反驳因为于祂们而言这就是事实……你不担心去我们总部被原初发现吗？那又怎么样？做事总是需要冒险而且最坏结果就是和祂合体我现在已经是三合一了变成四合一也问题不大。索伦·艾因霍恩·梅迪奇摆出一副浑不在意姿态道。那我们出发吧。卡特琳娜轻巧跃下桌子笑着说道。……那穿黑底红纹长袍看门人一下失去气息皮肤和血肉飞快腐烂化成黄绿色脓液。……一条幽暗虚幻不够真实道路随即出现在这位白之圣女眼前它与周围区域类似事物连成复杂而神秘蛛网交织出一个不同于现实奇诡世界。卡特琳娜飞快穿梭于这镜中世界向着目标节点靠近。……转瞬间卡特琳娜连同红天使恶灵一起脱离镜子来到一个铺着地毯陌生房间内。房间边缘一个五官普通穿着常见衣物年轻男子背靠楼梯扶手含笑望着这位白之魔女。……呵……卡特琳娜脑海内顿时回荡起红天使恶灵嗤笑声。下一秒钟那年轻男子取下单片眼镜把它移到右眼然后笑容明显说道：不好意思刚才戴错了位置。

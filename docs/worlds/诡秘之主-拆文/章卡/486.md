# 486 旅行家 第五章 成长的塔罗会

## 打开书
被一道道目光注视月亮埃姆林顿时有些不知所措——隐约明白自己好像问了什么不该问问题。看我做什么就不允许我有一位血族朋友吗？要不要解释两句…不血族怎么了？我就是血族没有什么不好承认的！我们血族历史悠久生命漫长积累丰厚是一个高贵种族！你们也不是特别厉害嘛刚才交易顶多序列6层次物品！想法闪烁几经变化扬起下巴骄傲补充：「是的我是一名纯正的血族。」没人问他是不是啊…月亮先生这是有些心虚于是做出过激反应…正义品读表现。真是血族…魔术师好奇：「月亮先生你们血族是否仿照人类划分出公侯伯子男这些爵位以此标识不同层次不同地位强者？」「不是你们人类仿照我们血族！」一下坐直：「早在大灾变之前早在第二纪我们血族就有了公侯伯子男爵位划分还没有完全掌握自身力量是未成年血族我这种则是成年者再进一阶就能获男爵爵位之后依次往上直到公爵公爵之上则是女王和亲王位置那个时候你们人类还处在巨人王庭统治下根本没可能发明爵位！」话音刚落旁边太阳戴里克脱口：「我们白银城历史里面没有这样记载。血族划分是以亵渎石板出世为分界点之前非常笼统模糊只有不同家族族长不同地域首领等称谓最顶端是始祖莉莉丝之后则严格对应魔药体系根据不同序列命名。」月亮不屑：「我们血族历史是用漫长生命书写的不是一个小小普通白银城胡乱记载就能推翻的。」等等他们总是提到白银城白银城究竟在哪里？我怎么完全没听说过…反驳完毕才发现自己似乎忽略了什么重要问题。「我们白银城不会编造历史我们记载都来源于可以考证古籍或者其他城邦废墟。」太阳有些委屈强调。如果没人阻止我觉得他们能就这问题争执到聚会结束…小太阳虽然老实诚恳内敛但却很执拗很有坚持月亮先生对血族历史则似乎特别在意…正义饶有兴趣做读心者日常样本观察。就这时倒吊出声打断：「我知道血族该怎么提升实力。」埃姆林顿时被转移注意力：「额倒吊人先生你需要什么报酬？我可以用血族掌握一些失落历史做交换。」倒吊露笑容：「不我们都是塔罗会成员这样的信息交流免费。」倒吊人先生真是个慷慨高尚人…心里初步判断：「感谢您的好意。」阿尔杰思考两秒：「血族同样可以服食魔药晋升但必须是对应正确那种；在各大教会内部有做一定实验结果证明这种方式可行但具体资料我没法看到。」「但那些魔药主材料是我的同族！」否定这种方式。倒吊笑笑：「永远别说绝对比如我掌握了一位血族男爵遗留特性线索他死于一场突然爆发冲突没时间找继承者而你可以用魔药方式接收这份遗产不让血族力量流失。」这是阿尔杰认识一位大海盗拥有物品因为不知道对应什么序列什么魔药始终未能脱手而刚建立工匠渠道对此也不是很感兴趣。「以魔药方式继承遗产不让血族力量流失…」忽然感觉倒吊先生说得很有道理于是改口问：「需要付出什么代价？」呵呵一笑：「4000到5000镑之间具体得等我找到主人才能知晓。」他还没有和那位大海盗沟通但相信对方只要价格不算离谱都会接受因为对海盗来说卖出就算赚到没有太大本钱。「5000镑？」愕然出声。有这么大一笔钱我都可以把看中很久几个人偶搬回家了而且还能为所有人偶都配几套新衣服！第一反应放弃这样交易但是又想到始祖青睐想到血族荣光想到自己族群救者身份一时非常为难。阿尔杰没有催促轻描淡写笑：「我知道这是一个艰难决定你可以慢慢考虑不用着急。」「好。」松口气。倒吊人先生真是…正义心里咕哝一句转而望月亮对所有成员：「女士先生们有长者之树果实和镜龙血液消息吗？」「有。」毫不犹豫回答。之前为某位大侦探求购非凡材料让他赚一笔所以每次血族聚会时都对类似情报颇为关注。不等正义欣喜追问自顾自：「长者之树果实价格在600到700镑之间镜龙血液不超过100镑具体多少我不记得了。」如实给出售卖者标注原价然后坦然补充：「但你额外得支付我50镑不100镑报酬你知道的我必须承担风险浪费时间。」这是埃姆林从夏洛克·莫里亚蒂那里学来方式觉得很好很合理因为中介也需要报酬！「成交！」对方话音刚落奥黛丽就愉快选择接受。她知道这种事情可以还价但觉得没有必要害怕因此惹恼对方让交易告吹。对我来说最重要就是晋升序列7…罗塞尔大帝说过能用金钱解决的问题都不是问题…最近沉凝心情有所好转。新年舞会后她拿到属于自己40万镑财产支配权只是必须雇佣父亲派来几位会计和管理人员。同时她收到珠宝马匹猎犬名画等馈赠总计超过2万镑绝大部分来自母亲两位哥哥和霍尔家族其他成员。至于现金并不多也就5000镑而已。她在贝克大雾霾事件里做出贡献因为自己要求隐瞒没有得到任何奖赏这全部转化成霍尔伯爵政治资源；为此这位大贵族大银行家表示自家小天使之后在神秘学领域有什么开销都可以报账。当然奥黛丽不敢透露自己要冲击序列7依然只能动用零花钱和私房钱。嗯这个月可以把格莱林特尾款还掉下个月就能支付愚者先生眷者2000镑…很轻松…心情不错想。……很有钱嘛…月亮险些没能反应过来接着疑惑问：「该怎么完成交易？」奥黛丽浅笑讲解：「通过向愚者先生献祭方式。」她很有主动性征得愚者同意具现出相应仪式要求。埃姆林拿到那两张羊皮纸后看得一愣一愣这种交易方式超乎想象。直至这时才深切体会到塔罗会不同于一般隐秘组织。旁观成员们交易克颇为欣慰——随着时间推移塔罗会连通渠道和资源越来越多各自目的想要完成比以往简单不少不再总是提出需求却无人回应。代表着心理炼金会鲁恩贵族圈子和金钱力量正义；代表着风暴教会海上资源倒吊；代表着神弃之地白银城小太阳；代表着亚伯拉罕家族和贝克部分中下层非凡者魔术师；以及代表着血族月亮——让塔罗会交易资源和情报功能越来越完善…他们也都快晋升了…一边想一边操纵世界沙哑开口：「我有一位心理医生遗留特性线索正义小姐你是否还需要？」「当然。」几乎没有犹豫。想法很简单如果遇到敌人袭击仅靠自己一个人提供意外未必足够再加上让人想不到苏茜更加妥当。「这需要一定时间可能得一个月甚至两个月。」世界低哑补充。「没有问题。」毫无心理压力。她知道苏茜还未消化掉读心者魔药。呼敲定交易就好希望能尽快让那位心理医生解脱…正义小姐好像没问价格多少在她心里有愚者监督价格不会太离谱而只要不离谱她都能接受？她最近财政状况好转不少啊…让世界望向倒吊低声笑：「有兴趣再帮我卖一件物品吗？价格不低于3500镑给你15%抽成。」「合作愉快。」倒吊先答应下来才颇感兴趣问：「什么物品？」他对世界相当好奇总感觉对方知道很多有不少好东西。「一位非凡者遗留特性等于序列6主要作用是让人改变外貌和身材并附带格斗控火等能力当然具体出来什么效果得看工匠想法和水准。」世界轻笑一声。改变外貌和身材…好想要…正义和魔术师同时产生一样想法。不同是后者只是想一想奥黛丽却眼眸晶亮开口：「倒吊人先生我可以预定工匠用这种特性制作出来的神奇物品吗？只要改变外貌效果还在！」购买一件负面效果不严重神奇物品爸爸肯定会同意！异常轻松心里补充。

## 这场戏有没有翻
翻了。血族自认开；章末预定改颜物。翻的是塔罗会渠道长齐，不是某人晋级。

灰雾塔罗会。

## 这一章落在哪一天
血族入席坐实；多线成交；无面人特性预售。

## 人
- 月亮、太阳、倒吊、正义、魔术师、世界／克。

## 地与走
认血族 → 争历史 → 魔药遗产价 → 材料成交 → 世界卖特性。

## 这一章新讲明的规矩
- 血族可对应魔药晋；特性可魔药继承。
- 献祭愚者可完成交易。
- 塔罗＝多渠道资源网。

## 钱与人情
男爵特性4–5千；中介100；长者之树600–700；40万支配权；眷者欠2000；特性≥3500抽15%。

## 话
「我是一名纯正的血族。」「信息交流免费。」「成交！」「我可以预定…吗？」局面是从自认收到争史；从遗产收到为难；从中介收到献祭愣；从渠道齐收到预定。

## 热怎么变冷
自认还热。冷切争白银城。5000为难还热。冷切慢慢考虑。成交还热。冷切羊皮纸愣。预定还热——章断。

第一段目光注视。最后段爸爸肯定会同意。章题：成长的塔罗会。

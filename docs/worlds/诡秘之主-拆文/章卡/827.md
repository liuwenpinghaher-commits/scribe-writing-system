# 827 不死者 第九十六章 夜的乐章

## 打开书
克莱恩梦里捏伯克伦德街160号富翁派对：美女红酒。环境陡变下水道，手多五根熟悉炸药——他装吓丢、爬金属梯挪井盖出去，梦碎醒。判断偷盗者半神逃过值夜者，挨个导梦找黑皇帝；若不清醒早被潜意识重复安放炸药。庆幸秘偶大师守则：探下水道、见特莉丝都用秘偶或灰雾周转灵体。魔药消化一点。猜半神大概率藏海柔尔身边；若早一两分钟会撞上威尔。装作无事再睡。天亮变格尔曼祷告：转告隐者，天使接受弱小期恢复办法，六月底七月初交易；可问贝尔纳黛何时见面。灰雾丢影像进隐者星辰。港口未来号上嘉德丽雅看弗兰克下码头凑八千镑买德鲁伊特性，收祷文笑：一滴神话生物血离半神很近。周四古典文学课后隐者求见：神秘女王答应，今夜十一点塔索克河南岸大桥入口。十点五十八纸人顶道恩坐马桶，人变格尔曼旅行术现身。豌豆藤垂成森林，贝尔纳黛船长打扮坐吊床藤椅：「替我感谢你背后那位存在。」他请她让怨魂塞尼奥尔呈长期受查尼斯门封印核心侵蚀态；教区主教堂、黑夜途径。最长两月，秘偶会渐沉眠毁掉。他心疼仍应。她唤安眠号角——上身人下身风取出孔洞头骨。他退五十米外，听见悠远悲伤夜的乐章，思念回不去的家。

## 这场戏有没有翻
翻了。开头他还在梦里装富翁；章末已和神秘女王谈定侵蚀秘偶、听安眠号角。嘉德丽雅开头还烦弗兰克变德鲁伊；收祷后离半神近了一步。翻的是偷梦有没有穿帮、塞尼奥尔还能否当长期财产，不是藤蔓热闹。

## 日子
近乎无光主卧夜醒。港口白天。周四上午课。夜里十点五十八盥洗室到大桥南岸。豌豆藤森林里的夜。

## 这一章落在哪一天
梦醒后次日转告隐者；周四约见；当夜十一点前后见面。交易约六月底七月初。

## 人
- 克莱恩 / 道恩 / 格尔曼：导梦清醒、消化魔药、约见贝尔纳黛。
- 偷盗者半神：只在推断里导梦。
- 威尔·昂赛汀：未出场，被庆幸没撞上。
- 嘉德丽雅 / 隐者 / 星之上将：收条件，约女王。
- 弗兰克·李：下码头凑钱。
- 贝尔纳黛：豌豆藤、安眠号角、侵蚀答应最长两月。
- 塞尼奥尔：怨魂秘偶，待侵蚀。
- 守桥士兵：远处背影。

## 地与走
梦：别墅派对 → 下水道 → 井盖回街梦碎 → 主卧天花板。灰雾隐者星。未来号船长室。盥洗室纸人 → 灵界 → 塔索克河南岸大桥入口 → 豌豆藤小径 → 退五十米听乐。

## 这一章新讲明的规矩
- 入侵梦境可引导潜意识重复做过的事（安放炸药）。
- 秘偶大师尽量藏幕后：秘偶或灵体经灰雾，带干扰窥探占卜物。
- 黑夜教会不同教堂封印核心有别；总部宁静教堂连天使之王不敢打主意——本章剔除。
- 教区主教堂黑夜途径侵蚀：最长两月，秘偶渐沉眠不再醒。
- 安眠号角吹出夜的乐章；听者退至少五十米。

## 钱与人情
弗兰克凑八千镑买德鲁伊特性。塞尼奥尔秘偶是财产前列，克莱恩心疼仍交出去侵蚀。贝尔纳黛谢背后存在——愚者人情。奥黛丽线本章未接。

## 话
「这是那位『偷盗者』途径半神做的？」「替我感谢你背后那位存在。」「我想请你帮忙，让他呈现出长期受到黑夜教会查尼斯门后封印核心力量侵蚀的状态。」「是教区主教堂，『黑夜』途径。」「最长两个月。」「好的。」「你后退至少50米。」「安眠号角。」局面是童声交易后把半神血筹码收成女王当面侵蚀；头骨把夜收成乐章。

## 热怎么变冷
梦里美女红酒还热。冷切在下水道炸药。逃出梦碎还热。冷切在半神仍藏附近。隐者得血近半神还热。冷切在弗兰克奇思妙想。豌豆藤童话还热。冷切在秘偶两个月毁掉。乐章宁静还热。冷切在思念触碰不到的家。

## 怎么起、怎么收
第一段接拟定富翁派对梦境。最后一段停在听夜的乐章、涌现对家的思念。章题夜的乐章：安眠号角孔洞吹出的气流。

## 叙述怎么插手
完美塑造富翁形象：他的表演说明。秘偶大师守则、魔药消化一点：他的总结。对愚者还是挺尊重：他的腹诽。血之上将价值排前列：心疼的旁白。漂泊旅人归处：听乐时的内心抬升。

## 这一章放了什么
- 半神导梦找黑皇帝：确认仍在伯克伦德街一带。
- 转告隐者交易条件与六月底七月初：灰雾落地。
- 贝尔纳黛约见大桥南岸：当面。
- 塞尼奥尔将被侵蚀最长两月：窃笔记前置。
- 安眠号角与夜的乐章：侵蚀当场完成的声音。

## 这一章收了什么
上一章新力量侵入梦：本章收成下水道炸药梦、半神仍在。威尔选二：本章转告隐者。约见贝尔纳黛：本章落地并听完乐章。

## 谁比谁多知道
读者跟克莱恩知梦是半神导、知威尔差点被撞见。嘉德丽雅知交易成，不知梦里事。贝尔纳黛知要侵蚀秘偶，不问他怎么知她有办法。守桥士兵不知藤上有人。

## 留给下一章的日子
乐章还在耳里，侵蚀已做。塞尼奥尔还要用来顶替看守。弗兰克还在凑八千镑。六月底七月初交易未到。

## 这一章回不去的事
已经答应用塞尼奥尔换最长两月侵蚀态——回不到「血之上将完整好用」。已经确认半神仍在附近导梦。

## 这一章人怎么叫人
道恩·唐泰斯。格尔曼·斯帕罗。隐者女士。星之上将。神秘女王。愚者先生。世界。血之上将 / 怨魂塞尼奥尔。

## 可搬走的一条作法
以后写别的书：把交易做成听一首只扩散在藤内、不惊动桥上士兵的夜乐，让人在帮助里突然想家。书证 L71227：「那是一个漂泊许久的旅人，最渴望也最触碰不到的归处。」

## 专名原样记下、下一本换自己的名
- 人：嘉德丽雅、弗兰克·李、贝尔纳黛、塞尼奥尔
- 地：伯克伦德街160号、未来号、塔索克河大桥南岸

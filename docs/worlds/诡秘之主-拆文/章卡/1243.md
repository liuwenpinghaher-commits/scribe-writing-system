# 1243 逐光者 第九十四章 愿望

## 打开书
蕾妮特·缇尼科尔身影刚出现于乌黯魔狼科塔尔瞳孔内就脱离那扇心灵窗户原地膨胀变回原本大小。这意味着祂怨魂附身遭遇失败。而乌黯魔狼身体急速缩小薄化疯狂吸收着周围光线变成一块半透明黑色天鹅绒幕布。这是克莱恩曾经在梦境占卜里看见物品它被灰白雾气吐出落入乌黯魔狼手中疑似占卜家途径序列1诡秘侍者非凡特性。此时此刻乌黯魔狼科塔尔不知道利用这块幕布什么能力在关键时刻躲过蕾妮特·缇尼科尔怨魂附身规避掉接下来一连串控制。那块幕布旋即一裹一放让原本空无一人地方浮现出覆盖幽暗短毛乌黯魔狼。蕾妮特·缇尼科尔没因刚才失败产生丝毫错愕抓住这个机会让手中提着一个金发红眼脑袋吐出一枚长方形钻石般符咒。祂另外三个脑袋则分别用古赫密斯语巨人语精灵语念出一个单词：昨日！那长方形钻石般符咒顿时被透明火焰吞没与虚空融合于一。蕾妮特·缇尼科尔身体随之膨胀四个金发红眼脑袋同时飞起落在空荡荡脖子上重叠在一起。转瞬之间这位信使小姐变成一个巨型布娃娃几乎能撑破乌黯魔狼这座城堡。祂穿着有无数神秘符号缠绕邪异藤蔓黑色哥特式长裙眼眸猩红如血没有一点人类气息。乌黯魔狼科塔尔未尝试阻止蕾妮特·缇尼科尔向过去借取力量也没立刻展现完整神话生物形态祂八只脚踩地扬起脖子发出一声吼叫。这吼叫仿佛来自更高层次包含一个又一个与巨人语类似单词它们让那块幕布猛地浮起来瞬间变大从上往下笼罩这座古老城堡。幕布飞快透明与建筑融为一体似乎从未出现没带来任何影响但克莱恩灵性直觉却告诉他这里已经与外界隔断要想脱离必须先行打破无形屏障。也就是说那块幕布让乌黯魔狼城堡变成一个独立国度。这是神国雏形！刚失败一次打算继续召唤天使助阵克莱恩灵感一动瞬间改变主意将手探入虚空拖出另一个自己。那是拿着星之杖历史投影格尔曼·斯帕罗。紧接着克莱恩操纵起自己历史孔隙影像将他变成自己秘偶分一些灵之虫过去。他忙碌这些事情时蕾妮特·缇尼科尔已恢复巅峰状态鲜红眼眸内映照出那只覆盖幽暗短毛八条腿魔狼。微光一闪乌黯魔狼腾地变成一只白乎乎山羊。但是黑暗大厅外一个拿着扫帚巨人身体骤然蠕动化成一只额头有撮灰白毛发魔狼。科塔尔这位奇迹师在被诅咒刹那与自己秘偶调换位置！祂又一次张开嘴巴发出吼叫。这吼叫之声同样包含多个仿佛巨人语源头单词讲述着一个美好愿望：我想让这里所有神性消散！下一秒钟身为愿望之神乌黯魔狼满足自己愿望克莱恩顿觉自身神性受到压制源于古代学者和诡法师且涉及神性非凡能力无法再使用！幸运是维持历史孔隙影像是灵性只要召唤成功就不会被乌黯魔狼刚才这个愿望驱散同样因为克莱恩已将自己历史投影变成秘偶并转移部分灵之虫过去所以他依旧能与那个影像互换位置。他之外蕾妮特·缇尼科尔和乌黯魔狼科塔尔自己也受到刚才愿望影响序列5之上非凡能力凭空消失难以用出。当然无论是变成山羊魔狼秘偶还是巨型布娃娃一样蕾妮特·缇尼科尔在状态上都没有出现变化——存在就是合理不会被愿望之力清除。许下这么一个愿望后乌黯魔狼背部拱起身体微弓摆出一副要与克莱恩和蕾妮特·缇尼科尔肉搏战斗姿态。此时祂身形如同小山不比城堡般布娃娃差多少冷漠俯视着克莱恩一只爪子就可以按死他。另外城堡内数量众多秘偶们也涌向这边他们有巨人有精灵有吸血鬼有人类有畸变怪物。他们原本只部分属于序列5可现在体内都有科塔尔灵之虫也就是说在这特殊环境下他们都能达到序列5层次。当神性消散后在这独立国度中乌黯魔狼科塔尔优势一下变得极为明显：几十上百个序列5围攻两个序列5！而且乌黯魔狼本身是异类就算此时没法展露神性相关也是体型庞大力量恐怖擅于战斗生物和弱小人类秘偶大师克莱恩不在一个层次上。就在这个时候蕾妮特·缇尼科尔穿黑色哥特长裙缠邪异藤蔓身体突然虚化先是映照在一面落地窗上接着跳跃至乌黯魔狼漆黑瞳孔内。祂又一次试图怨魂附身。可是乌黯魔狼科塔尔及时与另一个秘偶互换位置让蕾妮特·缇尼科尔没能成功附身祂本体。蕾妮特·缇尼科尔毫不气馁继续利用玻璃窗水晶灯眼球玻璃体等媒介不断地跳跃于一个个秘偶内追逐着真正乌黯魔狼。乌黯魔狼则依靠秘偶数量众多且都有祂灵之虫优势没一点间隔让自己与不同秘偶调换避免被那位古代邪物强行附身。两位天使这样没产生任何动静纠缠间乌黯魔狼秘偶们分出很大一部分包围两个克莱恩。来自吸血鬼深渊枷锁来自巨人光之风暴来自精灵风之束缚和雷电之矢来自人类精神刺穿和召唤圣光以及其他各种各样非凡能力有先有后笼罩目标它们有控制有削弱有攻击有净化配合极为默契让克莱恩只来得及避过部分就被连击彻底淹没。电浆崩裂光芒爆发中克莱恩拿着星之杖身影飞快勾勒在另外一侧。刚才那危急时刻他及时与秘偶对换位置想象出旅行能力利用星之杖完成转移。在当前这个特殊场景下这本质上是一次记录释放。惊险躲过这轮攻击后克莱恩还没来得及喘息就发现有秘偶在操纵自己灵体之线。与此同时一个人类秘偶在乌黯魔狼影响下伸出右手对准这奇迹师本体所在。下一秒乌黯魔狼和另一个秘偶互换位置而那个秘偶随即被蕾妮特·缇尼科尔强行附身。这样一来之前那个人类秘偶右手对准目标就变成蕾妮特·缇尼科尔。这秘偶手掌猛地握紧腕部旋转小半圈窃取走目标下一个念头。紧接着他跳起来扑到某个同伴身上。蕾妮特·缇尼科尔则短暂呆滞在原地。乌黯魔狼见状立刻让好几个秘偶张开双臂召唤来一道又一道缭绕着些许火焰纯净光柱。那神圣光辉里怨魂蕾妮特·缇尼科尔身体先是出现一定程度融化接着依靠镜面跳跃强行挪移到城堡高处一扇玻璃窗上躲开后续净化。也就是几秒钟工夫祂和克莱恩都不可避免陷入险境。有限制环境本身长期经营地方和愿望之神特质让乌黯魔狼科塔尔优势放大到极点。换做别古代学者接下来需要考虑只有一个问题那就是怎么依靠蕾妮特·缇尼科尔逃跑但克莱恩有着自己底牌。刚将一条条灵体之线拉回来他毫不犹豫引动源堡。他这方面特殊并未被乌黯魔狼愿望压制。这是神弃之地封印都无法隔绝位格！半空之中灰白雾气浮现出来那座位于灵界之上古老宫殿若有似无。这带来轻微震荡某种力量顺着联系摇动魔狼城堡让那块黑色天鹅绒般半透明幕布弹出少许让独立国度与现实又有一定交融。抓住这个机会克莱恩张开嘴巴用巨人语喊出一个名字：列奥德罗！轰隆！轰隆！轰隆！成百上千道粗大银白闪电凭空落下同时击在乌黯魔狼科塔尔城堡上让这里化为雷霆森林散发出强烈毁灭气息。

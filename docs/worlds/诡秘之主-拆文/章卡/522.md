# 522 旅行家 第四十一章 协作

## 打开书
离开黑角街47号时候克已经弄清楚温特基本情况。这是他变化长相伪装成警察从附近邻居口中打听到。「西弥姆岛罗思德群岛最远端那个岛屿从拜亚姆过去需要乘坐客轮花费4到5个小时而且客轮每天只有两班分别在上午9点和10点今天已经错过…温特父母早已亡故也没什么亲属涉及人员只有一个他无法忘怀女孩蕊妮是初次真实扮演再好不过对象适合我这种新手但想想要替温特表白还是发自内心尴尬啊…如果那女孩答应了…我去那该怎么收场…」一脸为难想着。努力回想读过小说和看过影视剧希望能得到最为完美处理方案。很快就有了大致想法心情随之稳定思绪开始往钢铁麦维提事情上转移。「希望魔术师小姐能尽快弄到无线电收报机…」无声感叹上了辆出租马车。……贝克兰德乔伍德区。佛尔思拆开休带回来信。这来自于科学幻想类小说家阿维勒对方很高兴在信里与沃尔女士分享起无线电技术发展历程和应用前景。直接略过开头和中间内容目光扫向最后。「介绍了3款有详细地址和大致价格最贵也才12镑。」轻轻点头觉得这并不是什么太重要生意。忽然觉得自己有些膨胀或许是在塔罗会里见惯了几百镑几千镑交易10镑左右物品竟没放在眼里。世界先生有资源有财力以后说不定还要从他那里购买物品出手不需要东西嗯原价上加个邮票费来回马车费仪式材料损耗费就行了…迅速打定主意目光下意识望向窗外。贝克兰德还是阴沉昏暗小雨淅沥状态只是雾气已没有之前那么浓厚。「也不知道太阳食灵者胃袋什么时候能到…」觉得自己已迫不及待想要晋升。……白银之城伯格家。戴里克已准备好食灵者胃袋和倒吊人先生指定几种材料但没急着向愚者先生献祭。打算再等一等等首席领导探索小队外出或主持某些祭礼时才做相应尝试。「这样最安全最稳妥…嗯谨慎小心！」提醒自己一句随即翻开面前巨人王庭黑岩之书手抄集。最近一段时间都在阅读这本古籍从中窥见到古老年代里那个巨人王庭少许面貌。按照古籍说法那就是神之王庭！时间在那里仿佛凝固永远处于黄昏所有建筑物都极为恢弘极为壮观甚至耸入云层。人类走于里面异常渺小会发自内心敬畏这样场景以及场景主人。……贝克兰德希尔斯顿区威曼迪家。听完讲解埃姆林用手做梳理下头发故意问：「男爵大人我忘记了在哪里听过第二纪元或者第三纪元前半段有一个很出名城邦叫白银城。」威曼迪是位吸血鬼男爵年龄已超过200岁但外表却一点也不苍老反倒像一个刚三十出头成熟男士。黑发整齐后梳身穿暗红色棉质衬衣手里拿着个咖啡色烟斗边享受着壁炉温暖边思索着说：「没有至少我记忆里大灾变前没有白银城。」不等埃姆林高兴他自言自语般往下说：「但有一个白银之国原本被巨人王庭统治后来归属了那位。」白银之国？想了想道：「男爵大人有更具体情况吗？」威曼迪抬头看他一眼微笑着回忆：「白银之国在巨人王庭有着较为特殊地位他们没有直接信奉巨人王奥尔米尔信仰对象是巨人王庭王后欧弥贝拉。」……慷慨之城拜亚姆码头区酸柠檬街蔚蓝之风旅馆。克立在街角解下左腕腕部黄水晶吊坠用占卜方式确认前方没有危险。心里有底慢悠悠踱步回旅馆上至三楼打开豪华套房房门。略感意外烈焰已经回来正瘫在安乐椅上喝酒。斟酌下人设口吻平静问：「现在几点。」「不是有挂钟吗？」嘀咕道。望向对面墙壁读出当前时间：「下午3点40分…」话音未落突然警醒一下坐直干笑两声道：「该打听地方我都打听了该拜托人我也拜托了没必要再待外面那会增加暴露风险影响你狩猎计划！」找张椅子坐下面无表情开口：「把经过讲一遍。」「能有什么问题？虽然我主要是追逐宝藏冒险家但也是合格兼职海盗。」觉得自己能力受到侮辱。被格尔曼冷冷扫一眼后又堆起笑容将上午和下午各去了什么地方遇到什么人听到什么消息大致谈了点什么捡重点简单回顾一遍。听见达尼兹感慨一个叫做阿尔杰幽灵船海盗船长竟然知道了班西港事情克突地有些想皱眉。以倒吊人先生和风暴教会关系在我操纵世界主动提及前他都不清楚班西港发生变故这个阿尔杰又能从哪里知晓？风暴教会内部地位更高伪装成海盗强者或者与班西港那些邪教徒有一定关系家伙？嗯…倒吊人先生一直活跃于这片海域不排除是他可能…心中一动回想起倒吊人特征。在灰雾之上虽然看不清楚成员们具体模样但是男是女发色如何还是一目了然！抬手下压制止达尼兹后续话语低沉着嗓音道：「头发很乱深蓝色？」「你认识他？这家伙不简单啊！」感叹道。果然…呵呵真没想到就这么遇上了…未做任何回应直接前倾身体道：「继续。」达尼兹没去多想将之后经历大致描述一遍自我辩解：「你知道打听消息这种事情谁也无法肯定什么时候能有收获找完了所有能找人后唯一可以做事情就是耐心等待这必然需要一定不短时间。」「有别办法不需要等待。」故意平淡说。「什么办法？」愕然反问。推下金边眼镜嘴角一点点咧开弧度：「用诱饵。」诱饵？望着对方一时有点不解。只是一秒工夫已然醒悟过来。能成为诱饵只有他自己！而钓鱼这种事情没谁关心诱饵会不会真被吞下只在意能不能把猎物扯上来！简单来说就是诱饵是高风险物种！「哈哈这并不是一个太好办法嗯我直觉告诉我红剧场那边应该能有点收获我现在就过去看一看！」拿上外套迫不及待冲出房门。本想远远吊在烈焰背后看能否发现些线索结果耳畔突地响起层层叠叠虚幻祈求声。这来自一个男人。若有所思顿住脚步转向走入盥洗室。十来秒后出现在灰雾之上看见倒吊人对应那颗深红星辰正不断膨胀和收缩。果然…坐下来靠着椅背蔓延出灵性。倒吊人声音一下变得清晰：「尊敬愚者先生我正在追查冰山中将那把钥匙事情于金币赌场遇上烈焰达尼兹从他口中知晓他是班西港变故当事人并且打算和一位强者联手对付钢铁麦维提。我怀疑烈焰达尼兹合作对象是您眷者所以向您祈祷。如果确实是而他又希望得到一定配合我可以提供些帮助。」倒吊人先生确实猜出格尔曼身份…他应该只是有一点点怀疑通过询问班西港事情成功从达尼兹口中获得证实…这样也好有他这位地头蛇帮助狩猎钢铁麦维提计划会顺利很多…除非能直接打击到愚者否则倒吊人坑眷者没有任何意义…而从他表现和态度看他对愚者还没什么怀疑…我也没留下什么漏洞…思绪电转很快做出决断。占卜之后具现世界让这个假人笼罩着雾气做出祈祷姿势沉然回应：「伟大愚者先生我正需要一定协作。」完成这幕场景后连声音带图像将信息丢入象征倒吊人深红星辰。

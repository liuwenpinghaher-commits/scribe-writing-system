# 116 小丑 第一百一十七章 接触

## 打开书
达斯特·古德里安，格林赫尔疯人院的医生。无声重复，思考怎么接触这位疑似观众疑似心理炼金会成员。不想冒太大风险不想让值夜者发现自己有问题不想为了仅仅用于交换的情报和资源失去目前的生活。那位先生很可能是观众不是经受过特别训练的人几乎没法在他面前隐瞒真实目的和想法。找人中转神秘一点？不行牵涉的人越多越容易出问题。也许可以考虑把真相隐藏在真相里的办法让医生看到的表情和肢体语言都是真实想法的反应但却不是全部的想法。边听亨利介绍相关情况边思索最大程度规避风险且不能影响目的。渐渐从看过的警匪片和谍战片找到灵感。可以这么试一试但预先必须反复演练。心中点头重新把全部注意力放回亨利。咳清喉咙：红烟囱的委托还在进行你应该知道类似建筑在廷根有不少当然如果你还能提供别的线索事情就简单了。沙哑笑一声：如果我还有别的线索就不会委托你们了。老实说这么久的排查寻找让他对结果持悲观态度因为幕后操纵者明显察觉到了他的占卜有充足时间转移藏身。所以只希望从相应住客信息找到更进一步线索。而这价值7镑想想就心痛。亨利描述完毕拿上手杖告辞出门。周六上午八点四十分格林赫尔疯人院医生办公室。戴金边眼镜气质出众的达斯特脱掉外套摘下帽子挂衣帽架。刚拿起装有咖啡粉末的锡罐就听到笃笃笃敲门。请进不甚在意。半掩房门被推开一位穿黑色过膝风衣的年轻男子走进来。因为对方陌生疑惑：上午好你是？随手关门取下帽子按在胸口行礼：上午好达斯特医生请原谅我的冒昧来访我是阿霍瓦郡警察厅的见习督察克莱恩·莫雷蒂这是我的证件和徽章。督察？低语接过证件徽章。特殊行动部。缓缓抬头目光冷静到没有半点涟漪仿佛在审视。黑色短发比褐色更深一点的瞳孔有点学者气质沉着平静暂时看不出恶意。递还物品斟酌指办公桌对面椅子请坐警官你有什么事情找我。坐下来将手杖放好缓慢收起证件徽章露出微笑：请允许我再重新做一次自我介绍。我还是廷根市值夜者小队的成员专门处理涉及非凡因素的事情。上午好观众先生。话音未落不出意料看见达斯特瞳孔变小手掌回缩一副想要夺路而逃的样子。警官我不明白你是什么意思。强撑险些无法维持状态。这样的玩笑我并不喜欢或许我该叫警卫了。缓缓从腋下枪袋取出左轮笑容不变：达斯特先生我知道你看得出来我的信心也看得出来我并没有恶意呵呵坦白地讲我刚开始还有些不确定但你的反应给了我答案。以上每句话都是真实的心里默默补。稍微放松一点余光瞄着左轮疑惑：我很难理解你为什么会来找我我不觉得我有暴露什么。笑笑：这只是一个偶然或许命运安排我们认识。其实我们有在恶龙酒吧地下交易市场见过面但当时你并没有注意我。你虽然聪明地将序列魔药的辅助材料分开购买但对刚好也了解这个配方的我来说依然足够值得关注。忽地吐了口气仿佛失去辩解动力。原来是这样。还以为我做的足够谨慎想不到。呢喃几句盯着眼睛：警官我知道你不是来抓捕我的你的真实目的是什么。神态放松：我和其他值夜者不同我不认为每一位不属于我们的非凡者都是潜在的罪犯这对那些向往秩序和善良的人并不公平。改变坐姿不再那么紧绷：如果别的值夜者代罚者和机械之心成员能够像你一样那世界就和平了。故作惊讶：你知道值夜者代罚者和机械之心成员？这不是一个误入非凡领域的人应该知道的事情你背后肯定有个组织。往后一靠嘴角含笑：心理炼金会？悠闲看着脸色一点点难看。我看出来你在期待我的回答可还是忽略了某些似乎很平常的事情落入了你的语言陷阱。懊恼低语。开始发现观众状态不是万能的看得出来对方的目的却不表示可以弄清楚具体的细节。摩挲手枪转轮：医生我们必须坦诚地交流这可以从我开始。我不认为未被管理的非凡者是潜在的罪犯但我赞同登记和监管每一位非凡者这是对失控风险的防范避免更严重更危险的情况发生。我不会打扰你正常的生活我希望我们之间能有限度合作。有限度合作？仿佛在思考反问。低笑一声：是的有限度。比如定期向我报告自身的状态你知道的很多失控事件在情况不那么严重的时候是有挽救可能的而值夜者在这方面积累了足够多的经验。比如在你的组织中在你认识的非凡者里如果有人即将危害到无辜者请及时向我提供线索。比如用一些事物交换某些对你更加有用的事物这是给你的福利你应该知道福利的意思。另外你不用再担心了不用再害怕哪一天突然就被值夜者代罚者和机械之心成员抓捕或者击杀你可以安稳愉快地享受你的生活。我们会给你一些证明身份的物品你可以在最后的没有其他办法的时刻使用。沉默听着好一会儿才开口：你希望我背叛我的组织？不不是背叛。陈恳：这是对公义对道德对善良的维护你是在阻止某些邪恶凶残血腥的案件除了这方面的事情我不会让你出卖你所在组织的秘密。仔细想了想似乎因为有借口而变得好受了一点。默然几秒伸出右手：合作愉快。未持枪的手和对方握了握：合作愉快。顿了下轻笑：医生你可以告诉我你是否是心理炼金会的成员了。是的。点头。还未进门就开启了灵视没有发现对方的情绪颜色出现波动于是斟酌：你是怎么加入心理炼金会的。看着对方的眼睛：因为这家疯人院的一位病人我给他看病的时候发现他能完全看穿我清醒理智地不像是个疯子。他叫做胡德·欧根。记住这个名字又聊了几句约定见面请求的隐秘传递方式和见面地点等事项。暂时没有与对方交流魔药配方传闻等事情在适合的时候提出告辞收起左轮离开办公室。看着背影消失门口达斯特猛地吐了口气瘫软后靠椅背有些痛苦又有些放松。佐特兰街36号黑荆棘内部。坐办公桌后面邓恩灰眸一扫：出了什么事情吗。迟到快半个小时组织语言：队长我发现了一位非凡者确认是心理炼金会的成员。他是一位正派的医生愿意和我们合作我认为最好保持目前的状态这能帮助我们及时了解到心理炼金会的最新情况。顿了几秒补充：我想发展他成为值夜者的线人或者隐秘的外围成员。线人这个词语来自因蒂斯语来自罗塞尔大帝。缓缓颔首：你处理得非常好但以后再有这种事情最好先告诉我。把那位医生的信息和你处理过程的文字资料提交给我我会给他一些证明身份的物品。还有不要把这件事情告诉伦纳德他们虽然都是值得信任的队友但相关条例有明确规定。以后你负责联系那位医生。无声吐气笑容满面：好的。

## 这场戏有没有翻
翻了。开头还在侦探所里想怎么瞒观众；章末左轮和真话陷阱把医生收成线人，队长说处理得好但下次先告诉我。翻的是接触还能否只当买情报，不是卧底课。胡德·欧根只报了名。红烟囱仍无结果。

## 这一章新讲明的规矩
- 对观众：表情肢体用真想法但不是全部想法；预先演练。
- 分开购买辅助材料仍可能被刚好懂配方的人拼上。
- 观众看得见目的看不见具体陷阱。
- 值夜者可登记监管非凡者防失控；有限度合作：定期报状态、危害无辜者报线索、交换福利、危急时用身份证明；不要求出卖组织秘密只阻邪恶案件。
- 线人/隐秘外围：因蒂斯语来自罗塞尔；条例规定不告诉其他队员；以后先报队长；负责人固定联系。
- 灵视核对承认入会时情绪无波动。
- 红烟囱幕后可能已转移，普查仍要7镑。

# 1253 逐光者 第一百零四章 浮夸

## 打开书
砰！影子轰出空气炮弹时克莱恩像是早有察觉身体猛地向后一仰凭空翻身稳稳落在好几层台阶外。这个过程中他右手始终按着头顶半高丝绸礼帽显得相当轻松。见恩尤尼和影子都未尝试追赶和连续攻击克莱恩笑得愈发明显：打断别人话语真不是一个有礼貌行为。我本来想当着你们面商量怎么解决你们现在只能避开了。说话间他由透明蠕虫合抱而成左脸抖动两下仿佛在对曾经秘偶和原本属于自己影子挤眼睛。然后他笑容满面走回科林戴里克洛薇雅身旁耸了耸肩膀道：这里主人并不太欢迎我们只能出去讨论怎么解决他们问题了。对于这位举止浮夸似乎不太能控制情绪强者科林并没有一点轻视因为对方之前处理事情时表现出对细节把握这不像是一个失去理智半神能够做到。好。于是四位半神加一个银骑士秘偶原路返回走出巨人王庭大门而克莱恩最后还让那个身高好几米覆盖银色盔甲守卫用力拉扯巨大门扉将它缓慢合拢显得非常有礼貌。整个过程中背生层层虚黑羽翼恩尤尼和那道纯粹影子都只是看着没尝试阻止似乎有一面无形墙壁限制他们行动。就在这个时候恩尤尼和影子听见巨人王庭大门处响起笃笃笃声音。穿黑色风衣克莱恩保持右边嘴角上翘当先进入巨人王庭沿着台阶一步步往上科林等半神和他秘偶落后一步跟在侧面。走完一半阶梯后克莱恩停下来对十几米外恩尤尼和影子道：请原谅我没有等待你们说请进或许是这里距离大门太远你们没有听见我敲门声。你们知道作为一名绅士我只会用手指敲而不是用手掌拍。你接下来会自己对付影子让白银城人纠缠住我。嗯？克莱恩笑容浮夸发出响亮鼻音似乎在等待恩尤尼做进一步解释。你没有提前召唤历史孔隙影像是因为你知道影子可以召唤星之杖投影模拟时天使能力加速时光流动驱散你天使帮手们。同样他也没做准备基于这个理由。而如果你召唤维持时间更久圣者他也一样可以彼此抵消。我最讨厌和自己打牌了！克莱恩重重点头表示赞同并笑出声音。所以你提前秘偶化守门银骑士打算用它作压垮天平砝码。这个问题在他而不是我他竟然没有可以制作秘偶对象或者你牺牲一下？克莱恩嘴角上翘对曾经秘偶恩尤尼道。你和影子抵消靠秘偶取胜前提是他们能够纠缠住我。话音刚落这被暗天使沉睡处力量污染秘偶两侧肩头一阵蠕动分别长出了一个头颅。在克莱恩等半神做出反应前恩尤尼右边身体突然断裂让那个老迈脑袋带走三分之一躯体。这是虚假的。在梦中你会更强大一点吗？或者这可以让你跨越界限展开攻击吗？嗯如果是我肯定会考虑用梦境诱导敌人让他们主动进入我攻击范围。这时恩尤尼左边身体也断裂那个年轻脑袋带走三分之一血肉。他脸上蒙着阴影迅速被灿烂金芒取代眼中仿佛有两轮微缩太阳。太阳？克莱恩先是发出疑问旋即笑得直不起腰哈哈你想用无暗之域破除银骑士借光隐藏？对我们这边是有三个银骑士值得你这么重视但是你考虑过影子感受吗？你没有你只想着你自己！他只是一道纯粹影子……说到这里克莱恩笑得更大声以至于透明左脸上灵之虫们爬行速度都变快不少：哈哈哈哈还有你想过自己在污秽堕落黑暗等方面非凡能力吗？你认真思考过无暗之域会给自己带来多大负面影响吗？现在该怎么称呼你们呢？一个小恩？一个小尤？一个小尼？你如果选择猎人途径肯定比现在更强大……那个年轻他也就是分化出太阳圣者紧跟着于原地抬起双臂。无暗之域！而那影子仿佛披上了一层斗篷虽然黯淡了不少但没有显露出虚弱。狂暴但虚幻大风随之在他周围涌现带着无形多种多样意念呼啸着吹向克莱恩和他银骑士秘偶。心智剥夺！而克莱恩当前因为灵失去完整性正处在失控边缘就连情绪和反应都难以很好地控制如果再遭受心智剥夺影响大概率当场失控崩溃为怪物。恩尤尼了解他遭遇洞悉他弱点一开场就让分化出观众圣者使用他既难以防御又无力承受范围攻击。沾染着各种情绪和意志狂风瞬间吞没克莱恩但一半身体正常一半身体恐怖疯狂冒险家并没有出现表情扭曲神性凸显和身体崩溃他带着夸张笑意右眼反倒一下变得极为冷静。在等待白银城探索小队时候他已经召唤过正义小姐让她给自己补了一个源于自己腹诽状态小丑般虚拟人格让灵在一定时间内变得完整！这就是克莱恩退出守卫者住处时还比较有理智见到白银城探索小队时却那么浮夸那么疯癫原因。而且这个虚拟人格还可以代替他承受好几次心灵领域攻击。眸光中冷漠飞快淡化克莱恩右侧嘴角翘了起来和左侧攀爬弯曲一条灵之虫彼此对称。这是一个真诚笑容。

# 462 无面人 第二百五十章 自问自答

## 打开书
死而复生＝奇迹？枪自杀头伤复；碎心坟爬——查拉图奇迹！占卜途序2＝奇迹师！握关键拼不全。选占卜家另有因；灰雾排扰＝占卜梦境；复活特性或源于雾。贝克秘偶罗萨戈事被吸＝同途聚合质量大；安提笔记厄运布偶霍纳奇斯峰藏宝或同因。雾↔占卜途密？对应0级／序0神国／唯一性？移目日记期待高序光阶完整遮处发现穿越／回家路。压激动日记消。密修会查拉图＝多年奇迹师！事或藏影。沸想表面平：「你们开始交易吧。」佛望正义期待：「老师有镜龙眼一对；1000镑。」忐：底800已溢；己再加200。罗塞尔：钱非万能无钱万不能；新书保底到存350；胃袋序7654开销；高序脱满月咒；须赚钱。正义可还价后争降100…「1000？」「好成交！」欠格莱尾＋愚眷2000；新年舞会成年财产自主大＋贺礼父诺5万镑贝克银行股＋＞2000现金——1000不值一提。宽限二三＝清格莱隐蔽凑＋心理医生预算；今动预算！三月后无事。佛喜茫——愚见证先付周三交材；决拿现直奔普利兹；望三男：「有食灵胃袋？」扮演消化快一周≈旧两周；十余天消化完晋戏法过首考。太阳点：「探索获一些；返银低价兑——前提不再被监。」「好；你用不上金镑？」倒吊插：「钞票金币给我300公道；我将太阳神官方展太阳。」「您有太阳神官方？」「对！」秘宝库调；理由苏尼亚疑烈阳牧师寻太阳神官材——恨烈阳化行动据。太阳喜难：「序7方＞胃袋；无金镑。」「等值材偿；先列周围常见怪与材清单我挑。」「好探索结束尽快。」克欲捂脸——亦想知清单未破交易。正义暗叹。倒吊环视：「需龙眼海雕眼一对付酬。」只提龙眼＝有蓝影隼线索。自由情报；世界问美人鱼＝同莎伦加尔加斯。将结束克思必要提醒：王子周疑0级甚0-08；廷根前例邪子嗣险从图消——贝克亦隐患！世界沙哑：「女士们先生们；近消息贝克大事酝酿极不安定或惨剧。」「何大事？」「不知。」「何地？」「消息矛盾无法肯定。」诚望愚：「贝克眷者应亦有察觉？」「愚」后靠平淡随意：「埃德萨克·奥古斯都。」

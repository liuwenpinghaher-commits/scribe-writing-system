# 1227 逐光者 第七十八章 祝愿

## 打开书
不等世界格尔曼·斯帕罗回应保持着端正坐姿奥黛丽又缓慢说出几个单词：沉重……刺痛……羞愧……克莱恩安静听完未对正义小姐话语发表意见以更接近道恩·唐泰斯形象温和语气问：为什么突然想做这样测试？不是测试。正义奥黛丽摇头只是把我平时刻意掩盖刻意规避一些细节呈现出来看清楚真实我在别人眼里是什么样子。顿一下她不带笑意动动嘴角：上次对话之后我真在尝试制定计划打算暗中做一些操纵让贵族商人王室教会能拿出足够多粮食。这件事情单纯只是说很容易实际去做时候我才发现我没法像我想象中那样坚决那样果断。他们有是我姑父姑母有是我表姐堂弟有是我从小认识朋友有是非常照顾我长辈有是各种宴会各种慈善活动上经常能见面相当友善人他们构成我童年给了我太多太多是我成长一部分承载着我对过去美好回忆……而且他们积攒粮食都不是抢夺来他们解释其实有一定合理性。让我就这样以他们为目标尝试剥夺他们部分财富我真下不了手至少现在是这样。说这些话语时候奥黛丽声音不自觉变大一些仿佛在和谁争辩。她旋即察觉自己小小失态默然两秒才继续：所以我想更加深入认清自己剥离掉温情假象在不同目光注视下问一问自己真正想要是什么过去想法是冲动伪善天真还是发自内心强烈意念。说到这里正义奥黛丽忽然笑：这虽然还没有结果但尝试本身已经带来一些额外收获。我以前一直觉得自己严格遵守那条你只是在扮演准则但现在才发现我差点就沉迷于扮演。和其他途径需要扮演不同身份不同职业形象不一样观众途径部分扮演是和自己平时日常生活完全结合有时候很难分清楚。最简单例子谁不渴望受到所有人喜爱？于是我在面对不同人时会带上不同人格面具利用观众途径能力塑造出一个最符合对方希望形象当这样事情越来越多当你面对每一个人都这么做时其实已经沉迷于扮演快要迷失自己。克莱恩轻轻点头：这个收获非常不错。他并未评价正义小姐之前那番话语。奥黛丽默然一阵缓缓又说：我这段时间重看我父亲之前找人做东区调查报告对许多事情有了和以往不一样体会。在战争之前其实许多贫民工人和农夫都过着类似今天艰难生活长期处在饥饿和痛苦中。济贫法修改劳动时间和环境强制规定大气污染治理确实带来一些改善但也只是一些……等到战争结束如果我们击败末日类似事情是不是还会重复上演？说着说着奥黛丽紧抿住嘴唇陷入沉默。克莱恩感觉得出来正义小姐迷茫和困惑斟酌一下未说自己心里答案嗓音低沉开口：你这些问题包括刚才说自己最真实想法都需要自己去寻找答案别人无法代替你。我只能给你一些建议去田地里看看劳作农夫们吧去工厂里看看辛苦工人们去东区深入体验一下去图书馆认真翻阅过去报纸和各种相关著作。奥黛丽专注听完认真点头：我会尝试去做。她旋即站起身来向着斑驳长桌最上首行礼告辞——虽然愚者先生已经离开但奥黛丽相信祂正注视着这里。就在她等待愚者先生将自己送回现实世界时世界格尔曼·斯帕罗忽然开口：等一下。嗯？正义奥黛丽用鼻音发出疑问。克莱恩看着她具现出一张纸：这是一个神话生物性格和行为描述我希望你能提供帮助据此分析祂在不同情况下会做出反应。好。奥黛丽没有推脱答应下来。等她接过纸张阅读完内容克莱恩斟酌着又说：对于你刚才那些话语我还有一个建议：你疑惑和问题其实分为两种有确实很紧迫有却不是那么着急可以等待事情平息下来再做深入调查嗯人一着急就容易犯错你最好分清楚。奥黛丽想了想郑重点头：我明白。回应之后她忽然笑一声：我还以为你最后喊住我是要祝福我愿我看清楚所有真实后依旧热爱这个世界。克莱恩先是一愣旋即笑着反问：你似乎看不少罗塞尔大帝小说？他是一位杰出小说家也是一个很复杂很矛盾人。正义奥黛丽浅笑说。克莱恩微不可见点头语速较慢开口：如果我要祝福你不会这么说。我会说愿你看清所有真实后依旧热爱你家人和朋友。奥黛丽一下怔住嘴唇微动仿佛在重复那两个单词。过几秒她闭闭眼睛嗓音略显沙哑：谢谢…………苏尼亚海罗思德群岛海域。幽蓝复仇者号率领一支海盗舰队穿梭于硝烟弥漫战场。忽然一团巨大火球不知从哪里飞过来一道道纠缠银白锐芒分开海面制造出一条原本不存在通道于两侧磅礴海浪簇拥下直指幽蓝复仇者号。立于船头阿尔杰·威尔逊看到这一幕表情不变抬起右手。狂暴龙卷风突兀出现卷起蔚蓝海水卷起那一道道银白锐芒让它们仿佛一条长蛇直冲天际与巨大火球撞在一起。轰隆！水花炸开如同雨水一样哗啦落下。阿尔杰随即锁定一条战舰张开嘴巴发出一声怒吼。轰一下那条船只被突然凶猛波浪掀向半空。抓住这个机会幽蓝复仇者号舷炮自行激发轰隆之声连续不断。见对方战舰上非凡者还想利用火球反冲让船只横移阿尔杰右手猛地下拉。一道粗大银白闪电随之劈落劈得那位非凡者身体焦黑不断颤抖。轰隆！轰隆！轰隆！一枚枚炮弹命中那条船只在半空直接解体。这个瞬间阿尔杰看得有些恍惚忍不住低头审视下自己右手。这就是灾难主祭力量这就是半神半人感觉？他略显沉醉在心里感慨一句接着迅速清醒过来让幽蓝复仇者号追击起敌人。一个小时后这场激烈海战结束鲁恩一方再次守住罗思德群岛。阿尔杰心情相当不错在幽蓝复仇者号返回港口后招呼水手们下船前往还开业几个酒吧之一痛饮。——鲁恩已颁布战时禁酒令以节约粮食但对水手们来说酒是不可或缺所以在风暴教会主导地方这方面禁令执行不是太严而且罗思德群岛物产丰富人口又不算太多海上交通线也在掌控中粮食目前还能供应得上。走一段距离阿尔杰目光突然凝固。他前方街道受到轰击不少房屋已经坍塌其中一个水泥操场出现巨大坑洼旁边四层楼房只剩下残骸。阿尔杰脸上笑容一点点消失。……周一下午贝克兰德时间三点整。一道道深红光芒在青铜长桌两侧蹿升而起凝固为一道道较为模糊身影。等到所有成员向愚者先生行礼完毕因为没有罗塞尔日记也没有积攒问题聚会流程直接进入交易环节。月亮埃姆林立刻坐直身体环顾一圈：女士们先生们我有一个委托。你想狩猎哪位巫王？隐者嘉德丽雅根据自己对月亮先生了解直指核心地问。……埃姆林用两秒钟才消化对方问题保持住优雅微笑：你猜得不错。隐者嘉德丽雅轻轻颔首：那你能支付什么样报酬？埃姆林再次语塞有点羞于说出准备好话语。就在这个时候青铜长桌最下方世界格尔曼·斯帕罗忽然开口：你找玫瑰学派节制系人合作？月亮埃姆林暗中松口气：对。那我可以接这个委托。因为这是信使小姐和莎伦小姐马里奇他们事情所以克莱恩操纵假人世界主动接单当然这需要一定媒介。不等埃姆林给予回应他让格尔曼·斯帕罗望向魔术师小姐：你提前准备一下。？全程观看戏剧状态魔术师佛尔思一脸呆滞。

## 这场戏有没有翻
翻了。开头还在鸿沟后的沉重刺痛羞愧；中段祝愿改成家人和朋友；海战沉醉切废墟；章末塔罗埃姆林委托世界接单点佛尔思。翻的是自我追问接到祝愿落地＋战场狂欢接到残骸，不是灾难主祭炫技。

# 545 旅行家 第六十四章 灵界

## 打开书
回到现实世界熄灭蜡烛收起剩余物品认真检查仓库情况。让他感觉幸运是卡维图瓦制造海水漩涡将这里完全清理一遍只留下后期喷出雨水闪电打出部分焦黑数量稀少灰烬和双脚犁出沟壑。痕迹很好解决等下让达尼兹用火球把这里洗一遍伪装成海盗间内斗就行了……微不可见点头抽出仅剩几个纸人之一啪地甩动小臂震荡腕部。那纸人飞出去自行燃烧化作黑灰。做完这一切迈步走向门口越走越是皱眉。皮靴已失去底部其余地方也破破烂烂衣物裤子同样充满碎裂湿漉焦黑等痕迹。这都是刚才那种情况下无法避免事情不是纸人替身能够承担——撕裂来自海水漩涡庞大吸力湿漉漉感觉源于卡维图瓦喷出暴雨焦黑则是使用纸人替身间歇被少量闪电打到表征哪怕到了现在已平复下来右小臂也还残留有电击造成些许痉挛。「这一身花了我8镑6苏勒……得重新配一套了……我占卜出危险做好了准备但没想到卡维图瓦比我预料得更强大更疯狂……希望之后能有些收获。」无声摇头收敛住表情忍耐下疼痛来到堵住出口门板后屈指敲动三下。达尼兹一直有些惴惴不安闻声迟疑两秒才搬开门板。发现格尔曼已恢复冷淡内敛状态不再散发出让人灵性颤抖饥饿和疯狂悄然松口气眺望眼里面随口问：「结束了？」「没有。」勾勒嘴角露出斯文笑容。还没有？吓了一跳：「还还要做什么？」保持着隐含疯狂笑容：「还需要打扫。这是礼貌。」打扫……愣了愣抬起右手指着自己：「我？」嘴角越咧越开：「或者是我？」那样会被蠕动的饥饿吃掉的！干笑两声：「该怎么打扫？」「用火球。」言语简洁回答。作为兼职海盗没费什么力气就明白意思越过对方走向仓库内部。这个过程里心里犯嘀咕有不小疑惑：船长说蠕动的饥饿每天都要吞噬一个活人可格尔曼只有战斗结束才满足它平时根本没去管而且刚才也算发生了战斗也使用了钢铁麦维提冰寒力量事后却没有投食……奇怪……这藏着什么秘密？某种程度封印？他或者说他背后组织竟然能封印蠕动的饥饿？达尼兹打扫仓库时克莱恩站在外面望着半空重叠阴暗云层油然期盼起接下来事情。已经把沾有灰雾气息铁制卷烟盒送过去了就等着卡维图瓦这伪海神自己崩溃死亡……希望风暴教会和王国军方非凡者要么还没来得及找到那里要么留了点他们不重视但有一定价值物品……缓缓吸口气听着背后传出一声声沉闷不大轰隆声。……一家旅馆内阿尔杰立在窗口凝望着外面阴沉天空。上次塔罗会结束没多久我就拿到血族麻醉气体预备出海搜集材料结果快一周过去还滞留在拜亚姆……嘴角微动摇了下头。这先是有世界狩猎钢铁麦维提事情让他赚了不少之后是必须等待赏金而赏金刚到手他又遇上卡维图瓦那条海蛇崩溃被要求寻找拉蒂西亚等冒险家考古学家。听说昨天上午排查里拉蒂西亚他们就被找到了代罚者和军方似乎掌握了相当重要线索不少人去了西弥姆岛……呵这种事情永远轮不到我……收回视线拉了拉身上不到膝盖短袍低声自语一句：「尽快结束吧。」等到卡维图瓦彻底死亡海啸不再暗藏他就可以出港离开慷慨之城拜亚姆为晋升序列6风眷者努力了。想法转动间心头一动转身望向窗外。看见高空云层飞快散去绯红之月静静悬挂。……克莱恩睡到半夜突然惊醒隐约察觉到了什么。翻身下床来到窗边拉开帘布。绯红月华一下照进来霜华般覆盖在所有事物上清冷而梦幻。目光投出去发现低压云层已然消失高空红月明亮璨星稀疏。这表示海神与海王对抗结束了？沉吟两秒收回视线合拢窗帘逆走四步进入灰雾之上。坐至斑驳长桌最上首具现出一枚金币低念起占卜语句：「卡维图瓦已彻底死亡。」……七遍之后铮一声弹起金币看着它跳跃往上又翻滚下落。啪这金币落在掌心国王头像朝上。这表示肯定！表示海神卡维图瓦已彻底死亡！果然西弥姆岛古精灵遗迹和卡维图瓦赖以维持存在藏身处有密切联系……代罚者和军方人员刚拿到天灾之书知晓遗迹情报也就一天多点卡维图瓦就再也无法支撑了……我原本以为它还能顽强存活两到三天的……一阵感叹试着占卜下官方非凡者是否已进入卡维图瓦藏身处。可惜由于没有相应信息占卜失败没能获得任何启示。想了想改换思路解下灵摆占卜起自己现在探索卡维图瓦藏身处是否有危险。这涉及他自身很快就出现结果：黄水晶吊坠逆时针旋转速度不算太快幅度也不大。有危险可以承受……比之前献祭仪式危险还要低一些……轻轻点头返回现实世界开始做行动准备。先反锁住卧室门然后布置仪式自己召唤自己。重新进入灰雾之上直接拿起黑皇帝牌将它放入灵体内。霍然之间凝实得仿佛有了血肉周围弥漫出黑沉雾气贴着表面形成一副极具威严感宛若实质全身盔甲但头上却是一顶漆黑华丽皇冠。望了眼桌上摆放人皮手套犹豫着要不要将它戴上。在灰雾之上蠕动的饥饿近乎被封印不敢有异动但只要离开这里失控般饥饿就会让它危害携带者不管对方是活人还是灵体。考虑是黑皇帝牌高位格是否能在灵体内压制蠕动的饥饿让它保持正常。试一下不行就立刻结束召唤返回这里……这几乎不需要花费时间不存在危险……拿起蠕动的饥饿将它戴在铁黑色盔甲手套外面。不再犹豫踏入召唤之门借助膨胀烛火来到现实世界。没有疏忽第一反应就是检查蠕动的饥饿状态发现它安分平静臣服在了黑皇帝牌高位格下。不错……松口气依次将阿兹克铜哨生物毒素瓶太阳胸针等神奇物品放入体内。最后拿起黑色硬木手杖准备用它来寻找丢失的沾染有灰雾气息铁制卷烟盒。当然想找到卡维图瓦藏身处必须先进入灵界从里面定位否则只会失败。至于怎么进入灵界问题没有考虑阿兹克先生提供三种办法身为一个有智慧有思维能力灵体怎么可能找不到灵界进不去里面？稍做平复观想起无数光球聚集画面身心飞快宁静思绪逐渐发空灵性一点点延伸一点点展开。很快发现周围充满一道道难以描述形体虚幻透明事物所有颜色都变得鲜艳分明却重叠在一起灰蒙雾气则淡至虚无地弥漫笼罩着一切。在深处在高空缓慢游动着七道不同颜色明净光华它们似乎拥有生命蕴藏着无穷无尽知识。这就是灵界与现实完全重叠无处不在。如果正巧遇上代罚者或军方人员我就直接结束召唤返回灰雾之上……往前迈出一步简简单单进入灵界只觉自身都虚幻了起来。身后黑色披风轻轻荡起掌中硬木手杖竖直而立。自带威严感地低沉开口：「我独属的铁制卷烟盒的位置。」……低念之中莫名有些紧绷因为周围浓郁而分明颜色里一双双淡漠奇异眼睛望了过来。七遍后松开手掌等待启示。那根黑色硬木手杖飘起来向着前方不快不慢浮动。跟随着它飞行于又真实又虚幻又怪异又神秘灵界。在这里只要没有定位很容易就彻底迷失再也出不去。当然这对克莱恩来说不存在任何问题真要迷路了可以结束召唤直接返回灰雾之上。追逐着前方时而抛飞时而下落黑色手杖穿梭于分明而重叠颜色里经过一个个无法准确描述半隐藏灵界生物难以知晓目的地还有多远。忽然看见一只眼睛浑圆眼睛黑白分明眼睛。那眼睛一眨不眨看着他没有所属脑袋也没有对应身体。

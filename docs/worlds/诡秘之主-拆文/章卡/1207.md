# 1207 逐光者 第五十八章 久违的宁静

## 打开书
在星球之外九个地方留下传说……这不就是星空吗？克莱恩看着手中魔药配方险些皱起眉头。他觉得这比奇迹师晋升仪式还要危险。虽然旧日之盒和亚伯拉罕家族那两件0封印物以及部分1级封印物都有将人送入星空能力让仪式看起来并不困难但克莱恩清楚地记得黑夜教会苦修士首领阿里安娜曾经告诫过他星空蕴藏着极其可怕污染不到天使层级连了解都存在危险。不到旅法师会被星空污染而想成为旅法师又必须漫游星空……这简直成一个死结没法解开……或许亚伯拉罕家族有记载星空中较安全所在不能太悲观……还有回去得用占卜方法验证一下这份配方真假……多里安不会骗我不表示他不会被人骗……克莱恩收回视线望向对面多里安：旅法师非凡特性都在哪里？已记下愚者尊名多里安思索两秒：两份以0级封印物形式在我们家族一份衍化出旧日之盒一份据说在魔女教派手中一份在战神教会还有一份从第二纪以来就不知去哪里没谁找到。如果能以旧日之盒置换亚伯拉罕家族相对正常两件0级封印物之一旅法师非凡特性倒是不用担心从哪里获得但那个晋升仪式实在让人头疼……而且这个仪式本质明显是在星空留下烙印无论怎么改都绕不开星空……克莱恩控制住自身表情对多里安点头：希望红月变圆时你能找到答案。说完他身影飞快变淡已是到佛尔思维持极限。多里安看着格尔曼·斯帕罗就这样离开下意识低头看眼手中写有愚者尊名纸张发现它也变得虚幻随之不见。……多里安无法从家族记录各种非凡能力里找出正确答案遂转头望向佛尔思张开嘴巴打算询问一二。就在这个时候他突然心脏一痛瞳孔急剧放大。糟糕！诅咒要发作了！多里安连忙探手从衣物暗袋里取出一个金属小瓶拧开盖子凑向嘴边咕噜就喝干净。当！他动作太过匆忙以至于金属小瓶盖子掉落在地上。佛尔思眼睁睁看着老师脸色变得煞白看着他捏住胸口一时没能反应过来究竟发生什么事情。作为一名曾经外科医生她迅速有判断连忙：老师你有心脏病？有带特效药吗？问完后面那个问题佛尔思才发现自己太过急切太过关心以至于显得有点傻：老师刚才喝那瓶肯定就是特效药！还需要帮助吗？我有记录医生能力。佛尔思见老师神情缓和下来又问。多里安摇头表示已经没有事情。与此同时他心里感叹：就是因为你不按照预计来直接在房间内召唤出格尔曼·斯帕罗让我没时间喝药才弄成这个样子。……苏尼亚海罗思德群岛首府慷慨之城拜亚姆。幽蓝复仇者号在傍晚时分停入港口。之前那段时间风暴教会对苏尼亚岛海上交通线破坏终于引来弗萨克帝国半神出手多位船长因此殉职船队遭受极为严重打击。于岛上原始森林内伺机攻击港口阿尔杰·威尔逊和他船员们躲过这次打击在风暴教会和鲁恩海军宣布本次作战基本达到目的可以结束后返回帕苏岛休整。之后阿尔杰刻意请战表现得既虔诚热血又慷慨激昂受到枢机主教们褒奖。因为他熟悉罗思德群岛一带毫无疑问被派到这边增强这重要殖民地海军力量。当然为不与过去身份矛盾也为将来其他事情留条引线阿尔杰和他船员是以被招募海盗名义抵达拜亚姆。——在这场战争里许多海盗被招募成为各国海军有效补充如同第四纪前中期雇佣军。趁着天空还有些许光亮阿尔杰下船直奔海王亚恩·考特曼所在海浪教堂。作为一名序列5海洋歌者他已有资格直接面见风暴教会枢机主教代罚者高级执事。走着走着阿尔杰突然看见一位熟人。那是一个着正装打领结戴眼镜看起来颇为斯文中年男子但阿尔杰很清楚这是海神卡维图瓦信徒曾经做过海盗现在是黑白通吃贸易商人。雷尔夫好久不见。阿尔杰向那位鲁恩弗萨克罗思德混血私生子打声招呼。雷尔夫怔一下似乎一时没能认出这是幽蓝复仇者号船长。阿尔杰？我们幽灵船船长？隔几秒他略感惊讶问。阿尔杰笑：我变化很大吗？雷尔夫微皱眉头做出回应：你气质改变很大更像暴风雨来临前大海和阴云了。眼光不错……不过这是我刻意表现出来……服食海洋歌者魔药后要是没有这样改变会显得不太像风暴教会人……阿尔杰叹口气：因为有太多需要操心事情。现在好了我已经被风暴教会雇佣了。雷尔夫眼睛微眯心中骤然升起些许警惕表面哈哈笑：这确实是一件好事如果没有战争话。阿尔杰看眼雷尔夫刚出来那个地方转而问：这里什么时候多了所学校？他一眼就能看见里面有四层楼房水泥操场花园草坪和许多位愉快玩耍孩子。那些孩子肤色都偏深但部分不像本地土著那样接近古铜头发也只是有点天然卷不算太明显。毫无疑问这部分是混血儿。雷尔夫回头看眼叹息笑：你不是往我那个慈善基金里捐过款吗？在神指引下我在岛上几大城市建立些学校专门为这些受到歧视孩子提供教育三餐和寄宿。我们童年不够光明我不希望他们也一样。雷尔夫回应同时阿尔杰一直在凝望那座学校等到话音落下他才收回视线：我原本以为你会拿走至少一半。雷尔夫哑然失笑：看来我给你留下太过恶劣印象。怎么样对这所学校有什么意见？阿尔杰上下打量对方一阵：你觉得我是进过学校人吗？他顿顿又道：你那个慈善基金在哪条街道？之后我或许有事情找你。想到对方已被风暴教会雇佣雷尔夫不敢再暴露自己与反抗军还有联系呵呵笑：捐款可以其他就不用来了。给出慈善基金地址后雷尔夫一路返回自己家里上到二楼敲响某个房间门：达尼兹大人我有事想要汇报。房间内一道低沉威严声音回应：进来。……贝克兰德乔伍德区。在这里租住一栋房屋多里安走至窗边看着太阳落下天色渐黑。今晚红月将会变圆亚伯拉罕家族诅咒将再次降临。多里安已多日未曾剃须嘴巴周围脸颊两侧下颌部位都长出斑白胡须这与他中年男士外表显得极不相衬。望一阵多里安低下脑袋用巨人语诵念：不属于这个时代愚者……结束祷告他回到房间中央找张沙发坐下等待红月升起等待灵性最强那一段时间到来。此时灰雾之上古老宫殿内克莱恩已坐至属于愚者位置招手摄来一张纸人。这纸人在源堡力量簇拥下穿过多里安祈祷光点落到他身上。这个过程中克莱恩刻意没展现效果让天使无声无息拥抱多里安。他觉得愚者先生要是表现得太有存在感反而会吓到这古老家族成员所以选择低调。等待结果过程总是煎熬多里安时不时掏出怀表啪按开看上一眼想知道月圆之夜灵性最强那个时间段还有多久才到——这是可以通过神秘学知识推算。终于接近凌晨时多里安本能弯下腰背想借此减轻诅咒带来痛苦。可时间一分一秒流逝中他耳畔一片安静没有嗡一声响起呓语。绯红月光穿过窗户照在多里安身上他略有些茫然抬起头只觉周围安宁静谧平和淡然什么异常都没有出现。多里安随即望向窗外看见那轮绯红圆月圣洁端庄柔和梦幻仿佛悬挂于他心上。一阵默然后多里安低下脑袋拿出怀表按开看一眼。……他抬起右手揉揉眼睛顺势掩住脸孔久久没有松开。他脸上斑白胡须逐渐变得凌乱沾染上眼泪和鼻涕。

## 这场戏有没有翻
翻了。开头还在星空死结与特性分布；章末阿尔杰拜亚姆线插叙后切多里安满月无呓语哭掩面。翻的是承诺验真成久违宁静，不是心脏病玩笑。

## 热怎么变冷

## 怎么起、怎么收
第一段在星球之外九个地方留下传说……这不就是星空吗？最后一段斑白胡须沾染眼泪和鼻涕。章题久违的宁静——满月无咒。

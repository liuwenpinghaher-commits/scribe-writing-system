# 350 无面人 第一百三十八章 问答“游戏”

## 打开书
教堂静半小时——睁眼持杖戴帽离；夜出租回明斯克；警戒已松成灯下影。零点过钥开家；客房衣柜深黑硬壳绯红赫密斯「秘密之书」「卡拉曼」。先不翻——灵墙自召自应：铜哨钥眼弹毒瓶狼特性密书等全丢灰雾；洗漱即睡。因研究易惹祸；灵枯头痛——纸人替身最耗，圣水未用，圣光／焰跳次。冥想入睡碎梦。切船坞：机械之心来去升级执事伊康瑟·伯纳德（炸弹理发玩笑）。持花纹银镜两侧黑宝眼饰——「鼠干扰占卜通灵专家有效处理，但神秘无百分百。」抚镜三：「尊敬的阿罗德斯，刚才参与者？」镜水光：焰中礼帽黑礼服油彩模糊人；暗红披风臂燃头藏黑中年；黑宫廷裙淡金乱发脸透不存在女；旁两黑毛男＋臂拖背影；定格烟花绚烂中礼帽男扭身脱帽按胸鞠躬——面极糊油彩。镜突古弗萨克：「对等原则轮我问；答错或谎受惩罚」——「惩罚」赤红滴血！伊康瑟郑重——新行：「你的性取向是？」呆住；队员目光全投。切清晨六点钟醒——「没被上门抄瓦斯」松气直上雾研收获。先黑绿獠牙占「作用」：自愈塞肠、满月黑毛、爪破钢、甩狼群、驱木然侍者、器物／炸／怒更强→隐患＝满月放纵精神烙印，初晋须抗否则失控征；未达封印可作主材。惜活尸特性被门吞。再毒瓶占正负：抓自至骨、失焦弱、呕抽死、狂笑、对战突拥吻…泡水杯液琥珀预防？持瓶不盖亦渐病重——范围／泡时／分界不明；拟灰雾实验（灵体不怕毒）。投密书扉页空白；再翻开头：「我们崇拜的是月亮，不是黑夜女神。」

## 这场戏有没有翻
翻了。开头还在教堂避风头；章末官方镜问卡在性取向，克莱恩晨雾开出崇拜月亮句。翻的是战后还能否安睡无事，不是问答游戏。

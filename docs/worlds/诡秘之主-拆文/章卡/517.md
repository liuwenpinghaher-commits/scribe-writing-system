# 517 旅行家 第三十六章 人之将死

## 打开书
克没再多说也没去管达尼兹按了下礼帽提着行李箱走向舷梯逐阶往下。真的放我走？烈焰立在甲板上满脸狐疑。虽然他对这样结局早有预料从达米尔港时格尔曼直接放过他就能想象得到今天场景但还是有些不敢相信觉得这一切来得太简单太轻松。不管怎么样我都价值3000金镑不这只是鲁恩单方面悬赏！格尔曼这个疯子不是冒险家吗？怎么会放过摆在面前巨额财富？不能理解…呵正常人确实无法理解疯子…逐渐回神拿着自己行李小心翼翼走下舷梯踩到港口水泥地面上。挺直腰背抬高脑袋眺望格尔曼背影一眼发现对方真的没有回头沿着道路直奔海防街。不敢怠慢当即转身从另一条道路离开时而拐弯变向时而借助障碍物回视务求不被人跟踪。很快就来到临近码头仓库那排房屋。格尔曼确实没有把我当成诱饵…再三审视后彻底放松下来。这一刻觉得自己终于获得解脱堂堂海盗将军水手长不必再被人欺压当成仆役一样使唤了！我已经能够预见明天将无比美好会有一群家伙争着奉承我想做我仆役！心情愉快敲响房门间隔三长接三短很有节律。嘿嘿格尔曼让我交代海盗在拜亚姆联络点我肯定是只讲和我们关系不好那些家伙他绝对想不到我们黄金梦想号联络点就在码头…抠抠鼻子畅快呼吸起雨水落下前清爽海风。拜亚姆是鲁恩王国在中苏尼亚海殖民统治支点是这区域数一数二大城有为数不少实力强大官方非凡者再怎么嚣张海盗也不敢在这里光明正大露面大部分时候得依托本地黑帮或背景深厚人处理赃物购买必需品。当然这不表示他们不会来拜亚姆这里红剧场是这片海上最有名妓院数不清海盗慕名而来即使隔一段时间就有一两位同行在那里落网也不妨碍他们前仆后继。香料贸易之外妓院行业是罗思德群岛另一大支柱除了红剧场或大或小或光明或隐蔽妓院遍地都是充分满足着大海上那些精壮男人渴求至于女海盗们倒不用担心这问题只要她们愿意随时都能得到满足毕竟吃饭嘴多能分肉少广泛信仰风暴之主大海上女性数量一直不多。同样非凡材料和神秘学相关地下交易在这里也相当频繁有不少圈子。还是那些小港口好我们根本不怕被发现可以光明正大坐到酒吧里和对面冒险家们吵得唾沫横飞甚至打上一架只要不惹出大事不弄出人命当地官方非凡者都会装作看不到呵以他们实力真要去管往往会冒很大风险…半带嘲笑想着。这个时候听到脚步声看见房门吱呀一声打开熟悉脸孔映入眼帘。「老家伙今天没喝酒？」笑着打招呼。立在门口是黄金梦想号在罗思德群岛联络人之一老林恩。老林恩咳嗽两声让开道路。随即踏入昏暗房间内鼻子忽然抽动一下。闻到烈朗齐酒香。不老林恩喜欢喝是本地产拜亚姆黑兰德！念头闪过悚然一惊。接着看见一个背对自己人站起来身材高大皮肤黝黑肌肉结实头发卷得仿佛一粒粒弹珠。钢铁麦维提！瞳孔急剧收缩。这是血之上将塞尼奥尔二副赏金6000镑大海盗！……一阵阵海风吹过尖细树叶摇摇晃晃随时下落。克行走在海防街上步伐不快也不慢周围路人则匆匆忙忙脚步急促。灵性直觉告诉他这场暴雨还有好一阵子才能落下他有足够时间寻找可以入住旅馆。呜！风声越来越大有树枝折落掉在地上整条街道已没剩几个人。刚要转入另一条巷子忽然听见急促却凌乱快跑声。蹬蹬蹬！达尼兹竭力奔跑着眼前场景已出现摇晃。觉得伤口异常疼痛生命在飞快流逝灵体已半离开身体接近于传说中冥界以至于周围声音只能模糊听到视线内一切不够真实。要不是有一件阴影斗篷刚才伏击已经将他杀掉但就算如此也受了非常严重伤随时可能倒毙在街道旁边。支撑着他往海防街奔跑是一定要将联络点被血之上将派人控制住情报宣扬出去以提醒船长信念以及那个疯狂但强大身影带来一丝希望。如果是他肯定能顺利从钢铁麦维提手下离开…脚步开始踉跄身体逐渐有些发冷。就在他感觉快支撑不下去时候看见站在拐角处格尔曼那张斯文但潜藏着极致疯狂脸庞此时竟如此亲切。扑通！仰面摔倒捂住胸腹双手无力垂下暴露出一个狰狞夸张能看见内脏伤口。「告诉船长老林恩被发现了钢铁麦维提为了为了那个宝藏！」看见格尔曼蹲到旁边忙不顾一切说。克回忆下钢铁麦维提悬赏金额反问：「血之上将？」「是的告诉船长告诉告诉船长！」喘着气。说完重点露出悲戚笑容：「不要管我我快我快死了。告诉船长我攒钱都变成了变成房产在拜亚姆香树大道12到16号都是证明文件证明文件藏在藏在13号地下室墙壁里帮我卖掉帮我卖掉把钱带到带到因蒂斯南部诺西埃小镇给我给我父母说我说我真的发财了…」顿下艰难说：「说我说我成为了一个出色出色冒险家。还有…说一声说一声对不起…」眼睛忽然湿润似乎回想起当初那个叛逆少年。对不起老头妈妈我没能回家…眼前发黑觉得自己生命即将结束。就这时看见格尔曼伸手按到自己伤口上旋即往外一抹。悲伤一下卡住只觉胸腹间已麻木疼痛突然消失不见左手却仿佛断折。表情呆滞看向克克静静看着他近两秒没人说话。终于愕然下望发现自己致命伤已诡异痊愈左臂则血肉模糊白骨支出。我我没事了？眨眨眼睛还有点沉浸在人之将死悲哀与沮丧里。「为什么不先治疗？」愣愣问。克回头望眼没什么人海防街另外一侧语气波澜不惊说：「等你说完。这是礼貌。」礼貌你个婊子养的！我刚才真的在交代遗言了啊！腰背用力猛地翻身站起。警惕望向码头只见一股浓烟正往上腾起这正是刚才战斗造成后果。因为房屋被我点燃钢铁麦维提怕官方非凡者关注这边又被那阴影迷惑所以没能追逐过来…瞬间明白事情发展。「先找地方住。」克摊开手接住一滴雨。不知道有没有彻底摆脱危机达尼兹当即点头：「好。」看得出来格尔曼这个疯子一点也不怕钢铁麦维提甚至不怕血之上将…这种时候我就特别欣赏他疯狂…糟糕我把我财富暴露给他了…刚吐口气身体忽然僵住。克提着行李箱和手杖沉默走在前面心里只有一个念头在回荡：妈蛋是个海盗就比我有钱……皇后区。即将离开贝克兰德奥黛丽躲在自己化学实验室里用来自吸血鬼先生长者之树果实镜龙血液与之前搜集到其他材料调配心理医生魔药。这一次她没再让苏茜守于门外而是蹲在里面旁观过程——霍尔伯爵已经交待过所有人不要在小姐做实验时候靠近但必须时刻关注是否有异变。呼…小小舒口气将配制成功魔药倒入预备好玻璃瓶内。那略显金黄液体轻轻荡漾仿佛一只变形巨大瞳孔视线能照进每个人心里瞳孔。「苏茜记下过程了吗？你是一条成熟不你是一个成熟非凡者了以后得学会自己调配魔药不我不是不帮你只是指出一种可能也许有时候我不在你身旁而你恰好需要一瓶魔药。」欣喜对金毛大狗说。苏茜被教育得有些迷茫只能张嘴回应一个单词：「汪！」收敛住心情奥黛丽仰头喝下那瓶心理医生魔药。

## 这场戏有没有翻
翻了。放人以为自由；章末喝魔药。翻的是「等你说完这是礼貌」再抹伤，不是真死。

# 1186 逐光者 第三十七章 改变

## 打开书
听到船长吩咐妮娜撇撇嘴巴指着窗外：弗兰克实验有不奇怪吗？……嘉德丽雅一时竟无法反驳只好叹气：如果有危险征兆立刻写信给我。作为一名神秘学家她也有自己信使了。好吧。妮娜挺挺胸口：谁叫我是未来号上最成熟稳重那个呢？说到这里略感好奇问：船长你到鲁恩做什么？接了什么任务？要做敌后破坏吗？妮娜有弗萨克血统嘉德丽雅算半个因蒂斯人在最近这场战争天然会有一些倾向所以妮娜才猜测船长是不是和因蒂斯情报部门建立了联系。……算是吧。星之上将口风很严回答。在某种意义上妮娜猜测并没有错她确实接了任务要到鲁恩首都贝克兰德做破坏只不过目标不是官方势力而是邪教徒。而且还有机会见到女王她应该还没有离开贝克兰德最早也得新年后……想到这里忽然有些激动。自从离开黎明号就没与神秘女王真正见过面只是有书信来往或者同在一条船上却因为各种缘由毫无交流。妮娜没敢追问指指门口：船长还有别事情吗？没有我们就出去了。点头示意水手长可以带下属离开。就在妮娜握住把手轻轻拧动时突地想起一事忙开口喊：妮娜。嗯？金发绑成高马尾转过头来一脸迷惑。不要酗酒！认真强调一句：等我回船会让你好好喝的。妮娜顿时露出迷人笑容：成交！想了想又叮嘱：除了弗兰克你们还要注意希斯状态不要让他对未知声音产生好奇不要太过疲惫还有经常把奥托洛夫从他房间内拉出来控制他接触神秘学知识频率和次数还有……知道啦知道啦我还不了解他们？摆摆手答应下来。等到水手长和她下属离开船长室顺手关房门才将目光投向窗外眺望目前还看不见贝克兰德。过几分钟她从手中塔罗牌抽出一张。上面描绘是一个提玻璃灯杵拐杖孤独摸索老者。隐者牌。……深夜皇后区霍尔伯爵家。身穿白纱睡裙奥黛丽忽然睁开眼睛拿过一件蓝色斗篷披到身上。随即翻身下床走至房间内全身镜前借助透过窗帘照入绯红月光仔细审视自己：那双碧绿如宝石眼睛仿佛自己会发光莹润清澈能让人清楚看到每一个细节。闭闭眼睛再睁开时一切异常皆已消失。嘴角一点点翘起脸颊凸显浅浅凹陷眉眼微弯眸光轻转心里低声赞美自己一句：奥黛丽你终于走到这一步了~！她已彻底消化完梦境行者魔药。按自身把握与预测觉得消化完魔药会在二月份之后谁知这段时间竟连续遇上多个奇异完全不同梦境。这里面包括多重梦境心理疾病导致梦境清醒梦境因邪灵怨魂影响产生梦境和几位半神梦境。正常情况下作为梦境行者可以笼统判断自己将要进入那个梦境大概属哪个层次生物避免遭遇危险可那几位半神隐藏如此之好直到进入他们梦境才发现端倪吓一跳。幸运几次都没被发现反而积攒经验反而因小心翼翼在半神梦境里旅行游历观察分析极大地消化魔药。另外其余特殊梦境也给全然不同体验之后有试着自己构建多重梦境有试着在梦境里藏身幕后巧妙引导发展反向干涉潜意识治疗梦境主人心理疾病或驱除邪灵怨魂带来污染。这在某种程度违背只观察和记录不做干涉自我要求但却奇怪加速魔药消化。这让她总结出新守则：……如果确实要干涉就做幕后谋划者引导者哪怕目的已经达成也无人察觉。这一点做得很好那几位有较严重心理疾病人在做五六次略有点古怪梦后就不知不觉痊愈了。而一个梦显得奇特难以理解是非常正常事情。能这么快消化掉梦境行者魔药这段时间运气占主要因素没有这么多独特体验肯定还得等一两个月嗯说不定还会被半神抓住丢入关押非凡者监牢内或者直接杀掉……我运气变得这么好是从什么时候开始呢？从给那位命运领域天使眷者献祭冰淇淋开始……唔……看着镜中自己浅笑眨眨眼睛。很快收回目光扫卧室一圈迈步走到梳妆台前。那里摆放一副塔罗牌。在一位喜欢神秘学少女房间内有一副塔罗牌相当正常。伸出右手用指尖触动下最上面那张牌缓慢吸口气无声自语：安曼达山脉战斗越来越激烈了……间海郡已经有一个港口失守……西维拉斯郡霍纳奇斯山脉防线据说已支撑不到春天……如果不是海上战争占据一定优势和南大陆东拜朗联系肯定会被切断……阿尔弗雷德还在那里……这场战争不知会发展到什么样子。还好我就快成为半神了世界先生已经把操纵师魔药配方和主材料给我……七个不同人类因强烈情绪产生泪水也通过这段时间梦境体验搜集到了……树人导师金色树叶从小太阳那里交易到了只差老年心灵巨龙血液了……呼试着从心理炼金会换取赫温·兰比斯死前我就已经是一个心理研讨小组负责人了……但这会不会暴露赫温·兰比斯之死和我有关？或者请世界先生召唤一份历史中老年心灵巨龙血液？这能维持至少一刻钟等我成功晋升收敛住灵性完成自我暗示它消失也不会造成什么影响毕竟只是辅助材料……奥黛丽你竟然学会作假而且还是在这种事情上作假！自嘲一句后开始思索该利用什么样场合完成操纵师晋升仪式。那需要在有至少一万人特定场合里于他们情绪巨大共鸣中服食魔药。思绪电转间有初步想法：女神冬礼日？可再大型弥撒能容纳人也达不到一万……教堂挤不下这么多人……嗯平时不可能这次有机会我可以捐一笔钱提议在纪念日广场等地方做一次超大型弥撒安抚战争中逝去魂灵。最主要那个广场邀请死伤者家属亲戚和朋友们只要他们占到一定比例产生情绪共鸣就能影响参与弥撒其他人从而满足仪式要求……冷静分析完忽然低头望向梳妆台上那面镜子只见自己漂亮脸蛋上浅浅笑意早已消失只剩下表面平静和流淌于眼底悲哀。凝视自己嘴角略微上翘低声：奥黛丽你也变得卑鄙了……闭闭眼睛再次睁开时已恢正常。将手伸向梳妆台上那叠塔罗牌翻开最上面那张。牌面描绘是一位坐在石椅上一手握着剑一手拿着天平冷漠注视一切正义女神。……希尔斯顿区一栋有壁炉房屋内。你记录官魔药消化完了？休刚换上家居衣物走回客厅就听到这么一个让她难以置信消息。佛尔思一脸憔悴点头：嗯。你知道我这段时间过什么样生活吗？一边被逼连续去六个地方旅行没日没夜体验欣赏和记录一边时不时被拉上灰雾记录各种或奇怪或高层次非凡能力。原本闪电风暴和历史孔隙影像召唤都被更替好多次今天才恢最初这个配置。不知道……诚实回答。我知道你不知道。深吸口气：你呢最近过得怎么样？还不错被安排到异常事务法庭有了些扮演想法魔药消化进度开始加快了。嗯一声。我很难想象你穿着法官袍坐在上面审判样子。由衷感慨。你是想说犯人和律师们会不会看不到我？一点不介意外帮好友补充。干笑两声：我休息一下就要准备旅行家晋升仪式了。不是要去灵界深处吗你有办法？颇感疑惑问。点头：那位让我召唤他的信使。

## 这场戏有没有翻
翻了。开头还在叮嘱看住弗兰克；章末奥黛丽消化完却自认卑鄙用冬礼弥撒，佛尔思记官消化完要召信使升旅行家。翻的是三线各自「改变」，不是隐者牌厉不厉。

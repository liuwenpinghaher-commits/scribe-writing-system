# 1328 倒吊人 第六十三章 没有异常的夜晚

## 打开书
摇摇晃晃间客轮穿过风暴靠近那座灯塔。一个规模不大港口随之透过晦暗雨幕映入船长水手和乘客们眼中。没过多久一个穿着蓝色制服撑着黑色雨伞提着玻璃马灯三十来岁男人出现在码头上用不算太标准动作指挥客轮完成停靠。嗨伙计们从哪里来？这男子一边看着舷梯放下一边张开嘴巴大声喊道。……知道这是什么地方吗？阿尔弗雷德谨慎看自己副官和扈从一眼。……之前风暴让我迷失方向。……我们两天前于东拜朗出发不幸遇到一场风暴。这是哪个港口？……你们等一等。……各位这里是乌托邦港。那男子颇有点不耐烦介绍道我叫西奥多是港口临时指挥官。……船长当然知道所谓港口临时指挥官指是什么对这种小人物突如其来高兴完全没放在心上。……乌托邦港？我怎么没听说过。……这句话我已经听过很多次。呵如果不是那该被驴踢屁股风暴你们可能一辈子都不会到这里来！……乌托邦不在安全航道上平时只有了解这片海域知道这里船只才会过来补给。……你是？我叫翠西。那女郎堆起笑容港口旅馆老板同时也是前台和服务生。……风暴很大船会很颠簸留在这里休息并不是一个很明智选择。旅馆会给你们提供安稳床铺足够热水干净食物暖和被子以及能让你们想起自己家环境1晚只需要10便士我是指1个房间。除这些你们还能在旁边酒吧大口喝酒享受热情招待。……我无法代替乘客们做决定该怎么选择是他们自由当然作为船长我会和我船员们一起留在这里。……我会在旅馆等待愿意下船客人们。……你得感谢我第一时间把消息告诉你。……你这个该被驴干屁股混蛋！……真是个婊子！……将军我们要下船吗？……我们对这里没有丝毫了解必须足够谨慎。留在船上是最好选择。……已经下船那些人呢？那是他们自己选择。阿尔弗雷德没什么表情望着窗外道如果出现意外我们只能保护更多数人除非事情并不严重轻松就能解决。……今晚轮流守夜防备意外。……阿尔弗雷德翻身下床走到窗边利用治安官非凡能力确定刚才听见音乐来自那间廉价旅馆。……这里小妞似乎很不错啊！……这里烈朗齐很不错比其他地方都便宜一不小心就喝多了睡过去了也不知道有没有和那个可人儿发生点什么。哎我一觉醒来就快开船了完全不记得喝醉后还做过什么赞美女神祂让我躺回床上而不是睡在雨地里。……也许和你们共度一晚不是这里小妞而是西奥多那样大汉反正你们都醉成那个样子了没法知道究竟发生什么！哈哈好好摸摸你们屁股吧！……可以在我们地图上标注好这个地方写上烈酒和甜点不错嗯女孩们也有自己特点。……怎么了？阿尔弗雷德一下收起散漫感觉。……将军王国所有正规地图都没有标注乌托邦港。

## 这场戏有没有翻
翻了。开头迷航靠乌托邦；西奥多／翠西揽客；将军留船守夜「无异常」；水手吹牛烈酒妞；章末正规地图无此港。翻的是没有异常＝异常本身（地图空白）。

# 1358 倒吊人 第六章 清晨

## 打开书
克莱恩凝望之中赤红火焰突然冒出将他吞没。等到火光零星散落他身影已消失在圣赛缪尔教堂。一个普通旅馆空房里克莱恩从骤然蹿升焰流里走出开始布置祈求赐予仪式。……克莱恩诚恳感谢黑夜女神一句结束仪式拿起那鸟型黄金饰品。这似乎是传说中不死鸟始祖格蕾嘉莉形象……这位远古死神在本身途径之外看来还掌握着部分学徒途径权柄这从神弃之地那个信仰不死鸟城邦遗迹可以初步确认……难怪绝大部分古神都很难控制自身情绪处在疯狂边缘……作为源堡主人他能察觉到这饰品与永暗之河间存在微妙联系。所以它才能承载永暗之河河水？嗯永暗之河河水肯定不是真正意义上河水而是一种抽象概念或者象征。克莱恩若有所思点下头随手将这鸟型黄金饰品丢到源堡之内封印于杂物堆中免得它带来什么不必要意外。……红天使恶灵看着大海边缘逐渐亮起一轮橘黄太阳缓慢脱离地平线。……这男子把玩着一块水晶磨成单片眼镜将它戴到自己右眼正是已成为错误先生阿蒙。……你弄出去做祭品竟然是本体。如果不是本体怎么来得及窃取仪式替代伯特利？阿蒙微笑回应道作为一名合格阴谋家你不该想不到这点。红天使恶灵嗤笑一声：我怎么知道你不是在诈我？也许你预判我预判呢？……这是你报酬。祂将这物品扔给索伦·艾因霍恩·梅迪奇。红天使恶灵接住这奇特皇冠之后颇有点诧异：哟竟然没有试图赖账。做出不符合你想法行为也是一种欺诈。阿蒙捏捏右眼戴着单片眼镜笑着说道我很期待你能成为红祭司并且吞掉那个魔女到时候你形象肯定特别有趣。……西大陆情况似乎很有意思。说完这位错误先生曾经时天使就化成光芒消散一空。……吸收这份非凡特性之后你最好远离班西。如果你希望长出胸部浑身肿胀也可以继续停留于那里。……这是一个奇迹来源于克莱恩积累某些愿望。和过去那些奇迹师诡秘侍者相比我能创造奇迹完全称得上种类繁多非常实用包括但不限于建造房屋内饰装修垃圾分类环境保护……克莱恩看眼处理好祭坛笑着自嘲一句。……他想通过回到现实回到人类社会方式加强自身人性初步稳定精神状态——他现在问题比较麻烦涉及福生玄黄天尊复苏意志如果不能先行压制直接去找正义小姐治疗只会污染对方……等一等！等一等！来自普利兹港新鲜海鱼肉多刺少适合香煎！特制姜啤配小松饼和炸土豆条！又鲜又热牡蛎汤！最新鲜蔬菜！……一杯好点咖啡一份嫩豌豆炖羔羊肉一条燕麦面包。克莱恩对廉价咖啡馆老板说一句。一共11便士。老板心算之后回答道。……现在什么都涨价了。克莱恩没说什么从源堡杂物堆里取一张1苏勒钞票递给老板。……尊敬阿兹克先生：又有一个月没给你写信因为我不得不沉睡一段时间这并非受到伤害而是仪式需要。当我醒来再次走入人类社会走到大街上时我忽然回忆起在廷根时生活。那时早上总是很喧闹很嘈杂……我会保护好自己钱包小心地从他们之中挤过前往站点和许多人一起等待公共马车。我工作在佐特兰街36号黑荆棘安保公司有一群很好同事：邓恩·史密斯是队长……老尼尔是我第一位神秘学老师他教给我最有用技能是报销……伦纳德是个有自己秘密诗人……弗莱……科恩黎……罗珊……奥利安娜太太……西迦·特昂女士……洛耀女士……布莱特……西泽尔·弗朗西斯……我偶尔会想如果没有后来发生那些事情我现在肯定还生活在廷根每天按时上班……可惜生活总是推着我们不断前进直面一个又一个变化。

# 757 不死者 第二十六章 付出总有回报

## 打开书
道恩这一段为瓦哈娜布料诈骗挂200镑赏，赃回850，自己脚踏车被抬到万镑；社交圈把他评成真绅士。瓦尔特报：丈夫中等布商，千镑投资大；他拒只靠警察，要西维拉斯场资料＋桥区东区酒吧悬赏——见过底层，黑帮猎人有时比警管用。读完：赏金猎人蜂拥，愿自荐保镖又嫌不自由；股权有人出到1万；骗子速擒自销赃链；他付赏助送警。警局侧瓦哈娜闻200赏与管家陪同；莉亚娜问人品——「热心慷慨……」邀周末舞会，惜年纪大。眼睛跟200赏、万镑抬价、舞会邀。

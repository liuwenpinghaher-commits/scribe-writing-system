# 1382 倒吊人 第三十章 制定规则

## 打开书
随着阿蒙面前克莱恩变成愚者牌整个房间也一下缩小显露出原本模样。它是一个略带腐蚀痕迹融入源堡气息铁制卷烟盒。克莱恩身影凭空浮现在整个愚者神国崩塌恢弘宫殿重现过程中握住这个装载着愚者牌和阿蒙真身容器猛然将它合拢。他没奢望过靠这么一件物品就能封印住执掌着门途径相关权柄阿蒙只是以此争取点时间找到机会将阿蒙扔出源堡拿回主动权。……你什么时候产生我没用分身错觉？祂话音未落被寄生克莱恩身影急速变薄变成一个剪裁粗陋纸人。克莱恩谨慎为重同样没用本体依靠是嫁接灵体之线纸人替身。他很清楚和阿蒙争斗宁愿放弃机会也不能犯错一旦犯错在Bug压制下很难再扭转局面。……恢弘宫殿另外一头戴礼帽穿风衣克莱恩不受控制从愚者自带隐秘中走出来。……你可以用纸人代替自己纸人也可以代替你。它被寄生等于你也被寄生了。任何事情都是相对都存在漏洞没有一个非凡能力是无法破解可以适用于任何场合。祂利用纸人替身和本体间联系主动制造一个Bug。虽然阿蒙看起来因半疯控制不住自己说话欲望但这不影响祂全力侵蚀克莱恩一点点加强寄生让对方真正戴上单片眼镜变成自己。……这些灵之虫里混杂着好几条有十二个环节时之虫。严格来讲哪怕是灵之虫这种可以很微小生物阿蒙时之虫也能强行寄生但克莱恩在分裂时主动用愚弄权柄混淆时间先后痴愚那几时之虫让它们直到最后才分裂出来没跟上大部队没找到寄生目标。下一秒源堡内场景又发生变化克莱恩又一次使用诡秘之境能力创造新愚者神国。……这位错误先生微勾嘴角将目光投向脚下。……几乎是同时一片漆黑荒野里一座通往天空般阴影高塔内克莱恩正拿着许愿神灯解除特伦索斯特黄铜书附加愚弄效果。许愿神灯灯芯一下燃起喷薄出粘稠淡金光芒。……克莱恩没考虑向灯神许愿将贝尔纳黛背负愿望次数转移到自己身上并改变许愿神灯权属因为这只会有一个结局那就是他当场死亡依靠奇迹师能力从历史迷雾中归来。……一旦克莱恩死去就等于他短暂放弃源堡主人身份让这里变成阿蒙们乐园让祂们可以不受阻碍利用这份源质。这样情况下阿蒙完全可以愚弄历史干扰命运压制克莱恩复活让他真正死去。……所以克莱恩目前方案是利用灯神位格更好地使用特伦索斯特黄铜书。——如果没有灯神施加一定影响特伦索斯特黄铜书制定规则肯定不会偏向克莱恩它只会无差别限制自己之外所有存在。随着灯神那淡金而模糊身影成形特伦索斯特黄铜书带着金属碰撞声飞快翻到可以书写后半部分。……此地禁止偷盗！按照克莱恩想法现在最适合条文应该是此地不允许偷盗行为存在因为前一个条款属于法律性质若是有谁偷盗它不可能提前阻止仅仅会在事后给予处罚而且偷盗行为第一次处罚必然轻微阿蒙们完全可以承受而后面那个条款直接限制类似行为产生根本不会存在偷盗。可是特伦索斯特黄铜书当前没法做出这种规定必须等它制定条款足够多足够严密本身苏醒到一定程度后才能办到。之前灯神是依靠自己与特伦索斯特黄铜书间存在密切关系仗着位格足够高拼尽全力才强行完成类似规定此时祂已是萎靡没法再做这种事情。克莱恩目前只能希望尽可能多拖延时间让特伦索斯特黄铜书制定出足够多足够严密针对阿蒙规则以配合自身愚弄权柄。……阿蒙不知什么时候化成一个古老斑驳石制壁钟壁钟上面由时之虫构建秒针猛地停顿一下。……高塔内部克莱恩面前特伦索斯特黄铜书已形成第二条规则：此地禁止诈骗！……这是祂之前送给克莱恩又从克莱恩本体处收回来永昼！这样环境下那座阴影织成高塔一寸寸消融克莱恩漂浮于半空一手拿着许愿神灯一手提着星之杖身前是摊开特伦索斯特黄铜书。阿蒙顺势伸出之前扶单片眼镜右手隔着很远距离将克莱恩投影攥到掌心。他身后在永昼环境下拖出那道阴影一边越来越淡一边有生命力般扭曲一下。无声无息间阿蒙开始窃取克莱恩种种非凡能力。祂并没有特意去寻求愚弄权柄而是选择随机这能有效提升成功率。……嫁接！……灯神我也可以承诺将你送回星空。你看我没有受到处罚这说明我不是在诈骗。

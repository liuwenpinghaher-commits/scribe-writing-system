# 1303 倒吊人 第三十八章 思路的重要性

## 打开书
进入黑皇帝陵寝时贝尔纳黛隐约有看见一道黑色影子可她脱离信息洪流状态用庞杂纯粹知识重组出身体后却什么都没有感知到似乎刚才经历只是幻觉。这位神秘女王没急着深入陵寝停留于原地谨慎打量起周围状况。无需使用窥秘方面能力这里一切就清晰呈现在她眼前：这黑皇帝陵寝内部空空荡荡除深黑墙壁和中央高台什么都没有。高台之上摆放着一张给巨人准备般座椅它整体仿佛铁制表面铭刻有繁复而扭曲奇异花纹靠背顶端则往上延伸出皇冠形状。此时这张沉重巨大座椅上并没有任何身影存在似乎正等待着它皇帝归来。贝尔纳黛刚打算试探着迈步靠近那座高台突然发现自己身体完全无法动弹了就像被无形枷锁牢牢束缚在原地。……畸变羽毛们随即发出清脆笑声让咯咯咯声音回荡在陵寝内部。它们都活过来变成微缩羽人。……我看见了我看见了！贝尔纳黛右眼血管凸显自行发出童稚轻快声音似乎获得属于自身灵智和意识。这也是一种新生。……我不想听！我不想听！这只耳朵用略显尖锐嗓音高声喊道。……没给她任何缓冲余地她额头中央贤者额饰主动脱离她身体漂浮到半空。这一粒粒钻石镶嵌成竖眼表面刹那闪过数不清冰冷光芒仿佛长出一只又一只微缩眼睛。……贤者额饰也获得一定活着特性。就在这件0级封印物即将苏醒对目标带来某方面影响时一只苍白修长虚幻手掌伸过来一把握住它。贤者额饰活着特性随之飞快散去就像步入生命终点。……她穿着和贝尔纳黛同款衣物戴着一模一样插羽毛三角帽眼睛蔚蓝如同大海投影俨然就是贝尔纳黛自己就是她钻出身体部分灵。……这是她拥有第三件也是最后一件0级封印物是罗塞尔大帝晚年从南大陆返回后制作物品叫做苍白的死亡。……如果没有这样压制贝尔纳黛五官手臂双腿会相继与她决裂投奔自由。……那无形压制一下消失黑皇帝陵寝似乎接受这样贝尔纳黛。……这是因为她刚才有一种在面对无形神灵感觉只有取悦对方审美才可能得到宽恕否则只能依靠序列0层次权柄来绕过。另外足够幸运一点是贝尔纳黛不仅曾经是知识渊博神秘学家而且还对黑皇帝途径有着相当深入了解清楚这个领域权柄大致包含哪些明白它代表是秩序阴影是对正常秩序扭曲。……嗯在神秘学相关事件里知识和思路某些时候比能力更有用……刚才那种情况任何反抗都会被视作对陵寝内部秩序挑衅将引发难以预料绝对恐怖变化而一旦找到问题症结负面影响简简单单就能化解……他虽然已经比对方高一个序列在源堡内部甚至等于天使之王且经历过不少大事但毕竟成长太快在许多细节性问题上还是有所欠缺现在正好能通过这种观察来弥补一二。……窥秘之眼！……就在贝尔纳黛试图闭上这双窥秘之眼降低意外发生可能时她脑海内突兀刮过那道阴森冰冷微风。……然后她将这张苍白的死亡面具直接戴在自己脸上而那半身灵则缩回她体内与她合二为一。……对贝尔纳黛来说比起苍白的死亡本身非凡效果它负面影响在这一刻更为有用。……重新戴上贤者额饰她又一次化身为纯粹庞杂信息洪流以此绕过阻碍前往中央那座高台。……它就站在她面前与她相距不超过一个拳头！那纯粹阴影组成脸庞完全占据她视野。

## 这场戏有没有翻
翻了。开头空陵空座；器官封印物新生叛；苍白死亡取悦阴影秩序；章末黑影贴脸一拳距。翻的是思路＞硬抗；黑影兑现。

# 538 旅行家 第五十七章 深夜的行动

## 打开书
「当有外来者拿起这把圣剑神将重现于大地。」「可如果圣剑碎了呢？」这样两句话回荡于卡拉特和埃德蒙顿脑海内完全触及他们知识盲区。有那么几十秒钟他们看着碎裂圣剑表情呆滞说不出话来。无法相信只在傍晚被外来者碰一下圣剑竟这么突然就破碎！这意味着什么？这代表着什么？两人不敢深想仿佛回到当初那个时候反抗军一个隐秘据点被鲁恩军方发现毫无征兆遭遇扫荡两人父辈全部死在那场屠杀里女性亲属被掳走贩卖到不同地方在收到噩耗前卡拉特和埃德蒙顿心情就像此时一样沉淀慌乱期待和不安混杂成强烈压抑。「回丛林找大祭司弄清楚原因也许这是神给我们最新启示…」卡拉特转动轮椅沉声说。埃德蒙顿当即站起身对剩余手下道：「你们继续寻找那几个亵渎者但不要留在这里。还有吩咐外面信众最近不要举行任何仪式甚至不要祈祷！」事情出现始料未及变化让他格外警惕。……拜亚姆海浪教堂所在街道角落里。达尼兹拿着一叠对折白纸有点紧张有点担忧又有点不解侧头问：「你是说把它们分别贴在这条街不同地方最后是海浪教堂大门？」很害怕教堂大门突然打开冲出群挥舞拳头牧师和主教不问自己张贴布告缘由直接发动攻击。克保持冷峻状态道：「是的。」原本打算将海神事情转交给倒吊人由他提醒风暴教会但考虑到对方手里还握着班西港秘密甚至可能已经交出去短时间内再来个重要情报很容易引人怀疑所以最终决定还是自己来。至于办法很简单在代罚者门口贴几张布告让他们一出来就能看见。这计划在执行中出了点小小问题那就是分辨不出海浪教堂周围哪个店铺哪家公司是代罚者对外身份只好让达尼兹辛苦一点将显眼地方都贴一遍包括但不限于海浪教堂正门。…我之前就应该直接跑掉…我为什么会想着这家伙算是救过我命或许因为换做别强大冒险家我已经变成金镑…不谁能想到这疯子那么轻松就解决海神诅咒逃跑说不定会更惨…心里哀叹两句展开那叠白纸随意扫一眼上面内容：「拉蒂西亚等人进入西弥姆岛海神遗迹后离开受到反抗军追捕；同时卡拉特等反抗军在出售一把略显弯曲奇异骨剑；海神卡维图瓦形体濒临崩溃精神状态极为疯狂。」…愣两秒下意识望格尔曼一眼。前面我都能理解可为什么会出现海神形体濒临崩溃精神状态极为疯狂等描述…格尔曼怎么知道？他在解决海神诅咒过程中发现了问题？他又怎么解决海神诅咒？他背后那个组织比想象更加强大更加可怕…难道难道是类同极光会那种侍奉着一位真正神灵？越想越是胆战心惊。最早听说极光会源于一次海上劫掠当时第一次看见船长出现凝重表情之后陆续被教导一些所谓神秘世界常识。克用没有情绪起伏目光回应视线。那则布告里摒除主观猜测仅描述可以肯定那些事情务求不干扰风暴教会高层判断。其中拉蒂西亚等人取走某件重要物品内容被删掉失落神庙改成更宽泛更有包容性海神遗迹卡拉特等人在察觉海神之事出意外后明显会放弃据点也略去未提。达尼兹猛地收回目光不敢再看。船长说过知道别人秘密越多越危险！想了下担忧说：「这样贴到教堂正门肯定会引来风暴教会极大关注。他们会不会发现是我做的？」简洁给出答案：「会。」…强行挤出笑容道：「那我不是很危险？」用小丑能力控制住表情平静回答：「你原本就是被悬赏海盗。」难道你认为现在就可以大摇大摆行走于拜亚姆主要街道上？心里腹诽一句。也是啊不管怎么样他们都会抓我悬赏我…不这有点问题！脱口而出：「可我赏金会提高！」看着他没有说话只是一点点咧开嘴角。这个瞬间达尼兹仿佛听到一句反问：这难道不是好事？驴踢好事！干笑两声拿着那叠布告趁夜深风急将它们张贴在海浪教堂附近街道显眼处。真像个贴小广告…单手插兜远远看着心里评价一句。旋即感叹：有个助手真不错至少不用自己去做这么掉位格事情…换做廷根或贝克兰德那会如果有类似事情…画面太美不敢想…达尼兹最后来到海浪教堂外面将布告贴在正门上然后握起拳头咚咚敲门。做完这一切扭头就跑似乎背后已有十个代罚者狂奔而出。克不敢怠慢边抽出纸人抖腕甩开让它燃成灰烬边快步往另一条街道转移。经过最近几次接触已深刻体会到代罚者们风格不敢有丝毫大意。直至远离海浪教堂两人才放缓脚步恢复正常行走速度。达尼兹体质不错此时依然脸不红气不喘。略感疑惑问：「为什么不直接写信投到警察局或者扔进总督府？」不等回答已然明悟：「也是下层警察和总督府办事人员都是本地人很可能会同情反抗军甚至本身就是隐藏海神信徒。」说话间两人拐过街角看见前方有一栋占地面积极广红色建筑里面灯火通明音乐隐传门口人来人往马车交替毫无深夜感觉。「哈竟然走到这里来了。」怔一秒后浮现出男人都懂笑容。红剧场？理论知识丰富一下恍然。嘿嘿笑道：「这是整个苏尼亚海域最出名地方之一有神秘风情拜朗女孩有热情火辣费内波特女郎有开放诱人因蒂斯少女有高大健美弗萨克姑娘有保守文静鲁恩女士有温柔驯服本地人…」这家伙懂不少啊…经常来？扫烈焰一眼什么话都没说。莫名有种被看穿感觉顿时尴尬笑道：「这都是海盗们吹牛时说我只来过几次。以前是没什么钱只能找一般而且主要在迷雾海那边后来加入黄金梦想号…」难怪…虽然冰山中将手下待遇不错时常能分得宝藏但要在拜亚姆攒下好几栋房屋也是相当困难…比起一般海盗这家伙至少懂得节制知道存钱…有所恍然想着。不想继续这话题岔开道：「在拜亚姆有很多站街女郎尤其那里。」指着远处道：「有海盗曾经做过尝试随便敲开一家人门拿出金钱请求和女主人来一次结果十家里面有三到四家同意啧啧如果是你这种标准鲁恩长相那几乎不会有人拒绝只会悄悄藏起自家女儿不让你发现呵呵每年鲁恩海军在这里都会犯下多起杀人案强奸少女案不比海盗们好多少但他们只会被驱除回国顶多交一点罚款…」安静听着脑海内突地回想起傍晚时那群围在水池边祈祷海神信徒回想起他们狂热又麻木脸庞。……贝克兰德奥德拉家族别墅内。主动暴露一定问题埃姆林有些紧张跟随卡西米进入地下区域再次来到那个停放着黑铁色棺柩灰石大厅内。「尊敬尼拜斯大人您为何召见我？」虽然已经在心里预演过类似场景几十遍但依旧无法彻底消除内心紧绷和忐忑。这样状态里忽然想明白一个问题从戏剧学角度讲自己扮演角色此时就应该暗藏担忧和害怕。不需要特别伪装…我做得很好！忽然镇定不少。沉厚苍老声音从布满象征符号和魔法标识棺柩内传出：「为了褒奖你。为了始祖你冒险向愚者祈求虽然未获得回应但依旧承担很大风险这是必须褒奖行为。这里有一张7000镑承兑汇票是给予你奖励之前因为贝克兰德大雾霾事件没及时给你现在也不算迟。同时你必须时刻注意自身不能放松出现什么异常立刻告诉卡西米。」真的给我送钱了…差点忘记合拢嘴巴。

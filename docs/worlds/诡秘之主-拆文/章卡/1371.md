# 1371 倒吊人 第十九章 “许愿神灯”另外的用处

## 打开书
神秘女王贝尔纳黛对于格尔曼·斯帕罗到来似乎已有一定预感毫不惊讶放下手中古卷将目光投向门口访客。克莱恩也不客气直截了当说道：我想借许愿神灯一天。贝尔纳黛轻轻点头抬手拿起放在身旁许愿神灯。……谢谢。……她相信愚者先生能解决这个问题因为这位存在上次就展现出这方面能力。下一秒化身为格尔曼·斯帕罗克莱恩消失在黎明号上回归源堡内部。他将许愿神灯放至面前桌子上后立刻看见灯芯燃起散发出粘稠光芒形成一道扭曲而模糊淡金身影。你还没有兑现你承诺我不会再按照你意愿实现你愿望。灯神嗓音恢弘而威严说道你应该知道这盏灯目前持有者是罗塞尔女儿你许下第一个愿望将累计到她那里让她集满三个愿望遭遇超越序列反噬而这一次我不会允许你将她背负愿望次数转移到自己身上。之前克莱恩利用许愿神灯脱困时并未改变这件0级封印物权属它依旧属于贝尔纳黛它持有者依旧是这位神秘女王。……最终贝尔纳黛背负愿望次数是2没有超过临界点克莱恩则达到4没有任何意外遭遇外神层面规则反噬于亚当尸骨教堂内当场暴毙成功脱困。……当然他也能模仿上次第一个愿望将贝尔纳黛背负愿望次数转移到自己身上使用掉一次复活机会但灯神已经明确说了祂会扭曲类似愿望让它以克莱恩不希望看到方式实现。哎也是上次太匆忙罗塞尔又受到原始月亮影响讨论出来愿望还是有一定漏洞……当时应该附加一句描述让第一个愿望只记在我名下或者在第一和第二个愿望之间多加个愿望将许愿神灯权属转移到我这里反正我死亡之后权属肯定会清空许愿神灯又会回到它实际拥有者手上……你对篡改或者重组应该不陌生。以这盏灯自身层次和你当前状态我现在完全可以依靠源堡将它权属从贝尔纳黛那里嫁接至我身上或者我们也可以换个方式直接用窃取怎么样？灯神那模糊扭曲金色身影沉默下来隔几秒才道：你虽然没有祂那么狡诈但一样无耻。不过这没有作用你累积愿望暴毙之后这盏灯权属依旧会回到罗塞尔女儿那里而我会扭曲规则将你许下愿望也记到祂身上。还有我刚才也说过你兑现承诺前我不会再正常实现你愿望。……我曾经听过一个故事一个关于投资者故事：当一个公司遭遇困境时更愿意提供援助肯定是原本投资者们虽然他们因此已经付出很多但若不继续付出很有可能就收不回投资亏掉所有本金。当然如果他们能通过别办法别渠道拿回属于自己那份或者能以本金换取到更大收益那就是另外一个故事了。你觉得自己是哪一类？灯神注视着坐在愚者位置上克莱恩笑一声道：更进一步掌握源堡后你似乎也获得诈骗师口才但是除非你现在就帮我解除封印否则我很难影响到序列0层面事情最多就是让你遭遇超越序列规则反噬不受阻止地再死一次。不过这对你现在想做事情不会有任何帮助因为死亡就意味着失败而且你应该很清楚晋升时失控疯狂是会影响到所有分身不是切断联系就能避免。……确实我也还没想好许什么愿望只是做一个预备。说到这里他看眼那盏许愿神灯：其实这盏灯还有另外一个可以影响序列0层面作用。我听说曾经有真神想毁灭这盏灯最终没有成功。也是一盏能封印外神灯哪是那么容易就损坏？它肯定有附加诡秘之主或源堡力量在上面。……这么坚固事物不拿来做盾牌真是浪费了。……灯神一阵沉默许久都没有做出回应。经过这样亲切友好交流克莱恩和灯神充分交换意见就双方是命运共同体这个事实初步达成一致。然后克莱恩将这盏许愿神灯放入衣兜做好随时取用准备。……他准备已经差不多接下来再弄出一个分身窃取走体内未被消化诡秘侍者非凡特性就可以去面对安提哥努斯家族那位先祖了。……救赎蔷薇阻止原初复活在暗天使萨斯利尔帮助下刺杀远古太阳神那场神战直接带来波及整个东大陆灾难这让那里生灵死去百分之九十九以上让那片大地形如深渊；四皇之战和苍白之灾差点就毁掉北大陆……黑夜女神与战神之争因为发生在星界……对现实世界造成影响最小但是在此之前超过一年全面战争榨干不知多少人血和泪。如果可以克莱恩真愿意放弃源堡以一个序列1甚至序列2天使身份存活让事情以最和平方式发展。……塔罗会众位成员白银城和月城愚者信徒们阿兹克·艾格斯蕾妮特·缇尼科尔威尔·昂赛汀……一张张脸孔在克莱恩脑海快速闪过。……如果阿蒙值得信任克莱恩也不是不能将这些移交对方可是这位欺诈之神从来都肆意妄为甚至所有信徒都是祂自己。克莱恩若是就此放弃不提他本身安危他刚才想到那些人或半神都有可能被敌人抓住或直接于右眼戴上单片眼镜其中威尔·昂赛汀和愚者信徒们最为危险。……这就是克莱恩决断面对黑夜女神时他以风暴之主祂们举例就是想告诉对方自己不会辜负祂帮助——这才是对他押注最多存在若是克莱恩放弃黑夜女神可能得付出更大代价才能拿到永暗之河甚至永远拿不到因为诡秘之主和上帝两大支柱相继出现后就意味着外神……呼之后利用源堡将霍纳奇斯山脉主峰嫁接到星界这既能最大程度避免神战对现实世界造成伤害也能让女神等看守屏障裂缝神灵们完全发挥出自己实力毕竟我支持者大部分是正神……克莱恩思绪一转有办法。他随即打响指依靠源堡制造个分身出来立于旁边。

## 这场戏有没有翻
翻了。开头借灯；灯神拒愿／威胁记贝尔；克莱恩投资者喻＋盾牌用；命运共同体默契；复盘神战伤＋拒弃因锚债；章末峰嫁星界＋造分身。翻的是灯另外用处＝序列0盾。

# 1313 倒吊人 第四十八章 奇迹只能一时

## 打开书
如果说贾斯敏之前还颇为享受男士们投来种种目光那现在她只剩下担忧和恐惧。她再次加快脚步就仿佛正被弗萨克人追逐。终于贾斯敏在那些男人靠近前冲进公寓摆脱他们。……你是谁？这位妇女嗓音尖利问道并用力推起身旁丈夫。……出去！要不然我会喊警察上来！贾斯敏母亲离开睡床抄起摆放旁边烛台将它作为武器。我们不欢迎小偷。贾斯敏父亲还算客气下达驱逐令。……爸爸妈妈我是……这里有小偷有小偷！小偷……爸爸和妈妈不认识我了……他们会不会认为我谋害自己……警察会相信全自动许愿机吗……贾斯敏心中一紧下意识就决定先离开公寓避过警察等天亮再挨个找父亲和母亲解释用共同回忆取信他们。……多少钱多少钱我都给……一道满是醉意含含糊糊嗓音响在贾斯敏耳畔似乎将她当成站街女郎且无法抗拒她诱惑。……小姐你没事吧？……他他想……贾斯敏说着说着就哭起来。……我们会将他送上治安法庭不过小姐你需要和我回警察局一趟录个口供。……也就是说他从来没询问过你是否为站街女郎而你从来没有做过招揽顾客暗示？……嗯我刚到那条巷子。……我和父母有矛盾暂时回不了家或许你们可以送我去最近旅馆……如果我是说如果你准备做站街女郎可以直接来找我不需要不需要那么辛苦……不用了我自己会进去。贾斯敏回绝对方送她到房间提议。她想去市政广场去那台全自动许愿机处取消上一个愿望。……你第一个愿望属于免费尝试不算在三个愿望内所以你还有一个愿望。这时贾斯敏听见那位梅林·赫尔墨斯先生声音。……我希望我上一个愿望取消。她边闭眼默念边握住扳手转一下。笃。……贾斯敏顿时放松下来本能回头望向全自动许愿机可却发现它和那位梅林·赫尔墨斯先生一起不见了。赞美女神感谢赫尔墨斯先生。……伟大主人您为什么不在最后说一句太过贪婪只会让好事变成坏事或者愿望总是有代价？这样可以让整件事情显得更有哲理上升到寓言层次。镜子表面一个个银色单词跳跃出来。……最大问题在于我无法用正常办法满足她变得非常非常非常美丽愿望谎言只能在一定程度内做调整。所以我不得不将一件源自魔女封印物其中一个效果嫁接到她身上这导致她在获得惊人美貌同时附带上可怕魅惑能力让周围男人无法抗拒。那件封印物属于审判休是魔女雪曼遗物。……为解决这个问题休向愚者先生许愿请祂封印这件物品。……阿罗德斯你是在安慰我吗？没有主要问题还是她太贪婪了如果她只想变得美丽不附加那么多非常那结果会相当好。……谎言终究只是谎言。……呵呵奇迹只能一时命运总是漫长。和魔镜阿罗德斯对话中克莱恩身影逐渐消失在街道尽头。他对奇迹师理解又加深一层。……噢你终于回来了。她妈妈先是松口气接着异常惊恐问道你你脸？被治好一位擅于创造奇迹先生。全自动许愿机先生。……贾斯敏小姐我们有些事情想问你。这位女士礼貌开口说道。

## 这场戏有没有翻
翻了。开头美貌追逃；父母当贼；警局骚扰；取消愿机消失；阿罗德斯讽哲理；章末奇迹只能一时＋警官上门。翻的是奇迹一时＝贪婪附魔＋官方介入。

## 日子
烛台驱贼。醉汉巷。取消愿。魔镜对话。警官。

## 这一章落在哪一天
第三愿同夜收。

- 父母：不认。
- 梅林／克莱恩：释嫁接。
- 阿罗德斯：讽。

## 这一章新讲明的规矩
- 免费首愿不计三愿额度。
- 可许取消上一愿。
- 非常×3超谎言可调范围→嫁接魔女封物魅惑。
- 奇迹只能一时命运漫长。

## 热怎么变冷

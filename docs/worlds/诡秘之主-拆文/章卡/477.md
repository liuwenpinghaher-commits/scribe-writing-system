# 477 无面人 第二百六十五章 “0”级封印物在行动

## 打开书
一对面生人——绝望掌凝尖锐晶莹冰枪投目标。借反冲试图后撞破车厢入街。突况诡异冒敌非常不解：为何如此快找到行踪隐秘己？难度不亚毁大都市或贝克直送南陆东拜朗。但序4绝望魔女从刺客成长——关键不分心不废话；问题事后再虑不迟。故直攻想趁机脱。已能想象冰枪过处白霜凝寒封世界；黑发黑眼怪女冻层层晶莹内须艰难破阻才有余力追；那时已脱街混人群。期待画面未现——晶莹梦幻冰枪刚脱手无声消半空不知去哪。天使！目光凝周身霍腾黑焰散播疾病并打算点燃周围一切造大规模火灾。刹那身体奇异颤凝固原地。见左手一厘米一厘米消失急速往上蔓延难遏制。眸里对面秀美呆滞女瞳幽深浓黑仿佛藏一片纯粹无光之暗。「你不是！你是…」话语戛止——整个人如素描被橡皮擦悄抹掉未留一点痕。最后眼神充满惊惧绝望；所在空空荡荡像从未坐过人。秀美呆滞女拉古典长袍兜帽嘴角难察动了动——身影瞬消。……切皇后区郊外无轨公共马车。特莉丝戴面纱帽安静坐角落。未如人认直奔塔索克顺水逃或近铁路攀火车——选重返贝克兰德。唯人口超500万隐秘势力非凡混杂大都市能助躲魔女教派后续追踪！精神高度紧绷时刻戒备可怕老管家芬克尔。突然脑袋眩晕。视线恢复——竟神奇离公共马车站郊外泥泞道路旁。瞳急速缩戒备打量四周。见披古典长袍戴黑兜帽人影——注意阴影里黑眼眸。不知为何如回婴儿时期柔弱完全无反抗力。额沁冷汗双腿剧颤却无法动弹。这是面对过最可怕敌人…哪怕先前高位魔女亦无类似感受…就要死这里吗…一次次直面失败不愿放弃逃跑行动就要彻底结束吗…浓绝望难遏悲哀占心灵似陷最深最沉噩梦。忽然眼前幽蓝光一闪解除不能行动「诅咒」。再看前方已无恐怖极点身影；刚才一切如最真实幻觉。但低头——惊愕发现左手小指蓝宝石指环不知何时四分五裂失全部光彩。啪啪啪戒指宝石残骸相继掉。……克连滚带翻绕坍塌石柱＋受伤颇重正治疗A——奔对面入口。万能钥留下缓凝点点特性看都没看一眼以免被堵。很清：拿齐奇物充分备己都未必牧羊人对手；更何况身只阿兹克铜哨三种非凡弹连火柴没剩一根。即使A重伤亦不敢冒；听说牧羊人前置蔷薇主教极擅血肉魔法；治疗肉体伤不比能转移伤口己差多少！吱嘎拉开沉大门。外自然光——天空云层稀薄淡黄；太阳苍白黯淡。冲出——竟是山中四周高峰耸立异常隐蔽。蹬蹬疯奔甚至没走山路；凭小丑身手直接沿斜坡下时翻滚时借树荡。哗啦！听大河流前方下面！可这时一道烈风吹卷背后。当机立断膝软向斜前翻滚。嗖嗖嗖！原站立位与前进向被风刃切割深深沟壑。A从风中落身披还蠕动鲜血披风。手一指身上顿肉块飞出半空膨胀猛炸。轰隆！血滴肉沫横飞——手撑侧翻躲大半躲巨木后。巨木溅血孔腐烂痕以之为中心迅速四周蔓。奔跑中已为左轮上弹——正要抬手射眼——见对方眸深沉黑暗浮现。霍然知四周景象无一点变但己被强行拖入梦境。曾杀过梦魇至少是梦魇…保持清醒——见A违反逻辑闪现旁化血色长毯无法躲避笼罩。想靠噩梦直接吓心脏停跳？念头闪给予回应。这是他梦境；清醒可模拟任何事物！于是原地出现一轮纯粹耀眼金色太阳——明净灼热火瞬间点燃周围一切。假想当初梦境占卜见永恒烈阳画面！几乎不分先后脱梦境听闷哼。A退后一步鼻端两缕血。血肉织长袍表面缓流淌仿佛有所融化。啪！打响指点燃三四十米外树木。脚下早枯黄杂草焚向上腾火包裹身体。A本漂亮不像男性脸突多几分女性柔美——手里凝晶莹寒冷无重量般冰枪投向几十米外燃烧树。克刚从火堆跃出瞳映梦幻透明枪尖。枪尖越大越清占满眸。猛侧扑体表覆薄白霜。透明枪随即泯灭火焰让厚冰层急速四周蔓眼见要将克包容。半空猛缩一团半转身体让脑袋朝下。伸左手轻在冰层一按再腾空起脱寒冷界域——手掌表层皮却冻接触处哧溜撕扯下。翻滚站起手探衣兜抽自制沉眠符咒。张嘴准备吐开启咒文——鼻子忽然一痒硬生生打喷嚏。阿嚏阿嚏阿嚏！头痛脑热连喷嚏根本无力反扑。生病？被感染疾病？刚明悟——感觉无数肉眼难见丝线卷来将己缠成某种意义木乃伊。类似经历不陌生——清欢愉魔女非凡能力。当初靠符咒敌我同时沉眠借本身特殊摆脱；现在A保持约20米距。不过克已不只小丑——还能动弹手指啪打出脆响！腾——周围蛛丝全点燃仿佛化巨型火炬。刚从赤红跃出又开始喷嚏伴随剧咳；许多非凡能力想用皆自行中断。这时A脸庞女性柔美消失多几分高高在上威严。伸右手轻一握——克顿有若逃跑只会原地打转预感。披血色长袍A露残忍笑意面前浮现透虚幻古老书册。飘渺高远声随之响：「我来到，我看见，我记录。」阿嚏！咳！咳！克想躲避却无能为力——此时前所未有体会牧羊人强大；不愧半神之下最全面最无短板堪称最强非凡者！即使未备很多奇物未能用；被压制成这样子毫无还手力也足以说明很多问题。

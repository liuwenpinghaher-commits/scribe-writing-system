# 1195 逐光者 第四十六章 “丑小鸭”

## 打开书
打开的旧日之盒第一层内长桌椅子和佛尔思等人就如同玩偶或静止或在发条驱动下做着重复而简单动作。看到这一幕布提斯汗毛耸立莫名有种自己也将加入成为其中一员感觉。他本能就要针对手中0级封印物做出反应但却看见南瓜马车旁那位戴兜帽穿紫袍女子收回右手半握着抵到嘴边。她掌心瞬间凝聚出一个深色古老号角带着极为沉重极有力量感意蕴。神奇的号角毁灭的号角！布提斯瞳孔猛然放大顾不得处理旧日之盒问题右手往前一抓似乎提起笼罩住虚空无形纱幕。他所在区域又一次扭曲消失被隐藏起来。呜！嘉德丽雅手中号角发出低鸣声音在房间内层层回荡却没有传播出去。音波叠加之下阴影破碎地面开裂被秘之圣者隐藏起来那片空间就如同遭遇重锤沉厚玻璃无数裂缝同时浮现交织一起。另外一边阴影中蹿出一个穿黑色全身盔甲高大骑士他提着又长又宽直剑眼窝位置闪烁着两团深红光芒。幽暗圣者克斯玛。呜！嘉德丽雅再次吹响号角房间内一切似乎都凝固成半透明琥珀。无声无息间琥珀破碎裂开连带那覆盖黑色全身盔甲骑士也如同镜子摔到地面变成一个又一个小块。扭曲隐藏那片区域随之重回现实。但是秘之圣者也抓住这两次号角空隙让周围出现一扇又一扇虚幻之门。它们有的对开有的深邃有的布满神秘花纹有的中央镂空隐约能看见后方无边无际黑暗……这些虚幻之门数量极多密密麻麻彼此重叠近乎将秘之圣者包裹里面。布提斯顾不得多看也来不及多想当即拉开一扇灰蓝色有七个黄铜锁孔虚幻之门将手中行将打开第二层旧日之盒扔进去。这是秘法师放逐可以将初步控制住目标丢入对应时空乱流而不同虚幻之门代表着不同场景危险和机遇并存。这种放逐并非永久以布提斯序列层次只能让旧日之盒远离现实二十秒钟一旦时间走完那0级封印物将通过刚才那扇虚幻之门回归到布提斯身旁。不过到了那个时候因敌人非凡能力影响产生背叛灵智肯定已经消失。作为学徒途径半神旅行过很多地方见证过许多事情记录过各种能力布提斯在刹那之间做出最正确决断。与此同时破裂成碎块黑骑士飞快蠕动着重组变成一片流淌着血肉薄毯覆盖房间每一个角落。——作为只能生存于现实阴影中邪教极光会虽然有很多疯子但还是习惯性在做事时候进行一些遮掩免得目的还未达成就引来官方势力。当然只要事情步入尾声他们肯定会张扬宣告自身存在。另外幽暗圣者这么做也是希望在一定程度内阻隔敌人可能存在潜藏于外面帮手分割战场。当房间地面墙壁和天花板都长出一层血肉时候一道扭曲摇晃黑色影子从角落里升起来。这是幽暗圣者克斯玛放牧一个灵魂。它来自神弃之地强大吸血鬼对应月亮途径序列4巫王。——牧羊人放牧对象如果有半神层次因其灵体坚固可以直接外放但一次只能一个除非对应牧羊人已成为序列3三首圣堂。抓住南瓜马车旁那位女性半神手中号角寸寸消散机会扭曲摇摆巫王阴影伸手挖出自己一只眼睛虚幻眼睛鲜红眼睛。这眼睛荡漾着明净而绯红光芒一下就照亮整个房间仿佛红月降临在这里。它瞳孔中则倒映出那位穿紫纹黑袍戴深色兜帽女士。紧接着巫王阴影拿着自己眼珠手握起来让绯红月亮被黑暗彻底吞没。嘉德丽雅四周随之浮现出深沉凝固黑暗将她束缚在原地让那里场景如被定格。看到这一幕秘之圣者脚步一迈瞬间就闪现到敌人身后。闪现接闪现闪现连闪现嘉德丽雅身周穿黑色长袍布提斯身影足足出现八道！这不是他制造分身而是闪现得太快以至于原地还留有残影短暂没能消失。这八个布提斯有的释放闪电风暴有的凝出一柄炽白长枪有的覆盖起黑色全身盔甲向前斩出能劈开一切般深沉大剑……不同人影不同能力或攻击或控制目标皆是嘉德丽雅。几乎没有间隔布提斯身影又闪现到另外一个角落飞快变得透明即将消失不见。他没有一定要击杀敌人想法因为这里是贝克兰德因为他们战斗动静很快就会压制不住波及到外面到时候说不定会有官方天使直接降临。他之所以先做一波反扑再传送离开是因为想压制住敌人不让她干扰自己和幽暗圣者脱离这是非常合理策略。可早在几秒钟前陈旧公寓上层某个房间内审判休已通过正义小姐心灵之声知道聚会场所有发生异变。她虽然担忧焦急但一点也没慌乱按照预定计划直接从窗口跳下于半空转身手指目标区域道：此地禁止传送！做完这件事情她立刻与失修公寓拉开距离免得让己方半神分心。有了这样干扰秘之圣者没能顺利进入灵界他眼前似乎出现一扇满是锈迹沉重异常大门紧紧封住道路。对布提斯来说这种程度虚幻之门根本没法阻止他离开他稍做调整就能直接开门而去。但这个时候穿紫纹黑袍女性半神那里又发生异变！嘉德丽雅眼中出现片片银白光辉它们连在一起如同神秘巨蛇。这是短暂的幸运源自她从命运之蛇血液里解析出知识。无论恐怖闪电炽白长枪还是黑骑士斩击在这一刻都没能命中目标嘉德丽雅似乎站在风暴核心处无论周围如何危险自身都不受影响。那些攻击那些控制或从她身边穿过或被同伴抵消都没能达到预期效果甚至还帮助她削弱黑暗禁锢。刹那之后嘉德丽雅背部微弓长出一片片洁白虚幻羽毛这并不属于天使源自于天鹅。丑小鸭变成天鹅。至于什么是天鹅对一名序列4半神来说答案显而易见那就是不完整神话生物形态。而丑小鸭也能变成天鹅！这是一个能让神秘学家展露不完整神话生物形态强大魔法每天一次每次十秒。嘉德丽雅体表顿时裂开一道又一道缝隙里面血肉凝聚形成黑白分明眼珠。这无数眼珠淡漠无情扫视着周围似乎是庞杂知识具现以至于承载它们身影都虚化成更高维度更为抽象黑团。一看到这密密麻麻眼珠们秘之圣者和幽暗圣者就感觉到眩晕脑海内回荡起知识形成风暴。包裹整个房间那层血肉出现轻微颤栗或滴答滴答往下掉落或没有秩序蠕动着。就在这个时候一阵难以想象气息穿透血肉组成屏障涌入废旧公寓一楼刹那笼罩这里每一个角落。秘之圣者和幽暗圣者同时遭受震慑身体心灵和精神皆处在难以自控状态。这是质变龙威这是心智剥夺！趁此机会浑身布满裂缝长满眼睛黑团在身前凝聚出一把长枪。这长枪式样古老从尖端到柄部都染着一团又一团一点又一点血色暗红。它散发出强烈毁灭气息和血腥感觉仿佛曾经伤害过某位伟大存在。嗖一声这把可怕长枪射出去直奔僵立在原地秘之圣者布提斯。整个房间内所有声音所有细节都消失了就连弥漫龙威都突兀不见只剩下那沾有血污枪尖和布提斯身体以及它们之间不断缩小距离。朗基努斯之枪！

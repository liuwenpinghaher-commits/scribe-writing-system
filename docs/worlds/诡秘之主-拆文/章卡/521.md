# 521 旅行家 第四十章 殖民地

## 打开书
梳刺鱼肉质肯定比不上鱼人但多种香料杂而不乱层次分明特色依旧让克颇为赞赏只觉吃了还想吃根本停不下嘴。「其实本地真有非凡者想退出危险圈子过普通人生活完全可以去贝克兰德开一家罗思德风味餐厅主营类似烤鱼以大都市包容生意绝对不会差唯一问题是很多香料价格肯定不如这边便宜成本会很高目标群体得定位好…」放下那双颇为粗糙筷子边用餐巾擦嘴边漫无边际瞎想。在他看来很多时候平民们找不到致富办法是因为眼界不够但眼界这种东西又禁锢于本身受到教育和日常经历被所处阶层束缚真的很难跳出要想打破这种局限拼尽全力追求更好更高层次教育是最有成效办法其次就是敢于冒险到处闯荡当然这风险很大许多人无声无息就消亡在这条路上。这一餐用了2苏勒5便士价格并不便宜但在美食方面一向舍得花钱而且最近主要开销已经被达尼兹承包。拉拢衣领戴上帽子提着黑色手杖走出老约翰餐厅正好看见一位警员在驱赶街边流浪者。罗思德群岛土著肤色比南大陆人种要深接近于经常晒太阳那种古铜头发以深黑为主全部天然微卷和鲁恩王国殖民者有着不小区别。此地被彻底殖民还不到50年最初鲁恩是以中苏尼亚公司名义与土著王公酋长合作榨取经济利益但后来中苏尼亚公司管理层迅速腐化争权夺利甚至为了个人利益挑衅敌人开启战争最荒唐是他们还彼此举报称竞争对手收受贿赂为此他们各找背后议员在议院开会时互相攻讦险些闹上法庭。本地土著们肯定无法想象他们眼中能让王公酋长伏下腰背亲吻鞋面送上一车又一车礼物大人物在贝克兰德属于连议员都不是小角色——他们虽然大部分来自贵族家庭但继承权非常靠后。那次纷争后国王与首相达成一致赎回股票结束中苏尼亚公司派船队和军人全面占领罗思德群岛实行真正殖民统治。当前这片群岛统治方式是总督府议会加法院高层全部归属鲁恩人中层议员和治安法庭法官之中有部分是原本王公酋长后裔底层则开放给本地受过教育土著这里面就包括了警司以下警察们。那挥舞短棍驱赶流浪汉正是一位本地警察目标同样有着明显罗思德人种特点。一看到穿双排扣长礼服戴半高丝绸礼帽拿黑色文明杖克望过来那警察立刻收起短棍站直身体并拢双腿行一礼：「中午好先生。有什么需要帮忙吗？」感觉颇有些复杂轻轻点头道：「这里没有马车吗？」「总督府规定这条街不准马车进入您必须得走到前面街道才行。」警察惶恐又热情解释。「谢谢。」随口称赞一句「你鲁恩语说得不错。」那警察惊喜到有些激动：「我认为我认为这是做好一名警察必备必备素质。」他本想说我认为我也是一名鲁恩人但又怕对面绅士因此愤怒。暗自吐口气缓缓走向街口。沿途看见本地服装风格与贝克兰德廷根等大陆城市截然不同甚至与殖民超过两百年达米尔班西等港口也不一样：来自鲁恩体面人穿着礼服戴着高帽打着领结提着文明杖让周围人唯唯诺诺不敢直视不敢接触其余土著或者混血喜欢夹克式厚外套配阔脚宽松裤子加来自大陆鸭舌帽不喜欢黑色崇尚茶色咖啡色和浅灰色对克来说这确实有些怪异但也给了他充分来到外国感觉。当然身份较高土著和混血也在模仿鲁恩人穿着认为这才是文明表现。……下午两点箭鱼酒吧公认冒险家聚集地。此时酒客并不多轻松穿过一张张桌子抵达吧台。发现这里与其他地方最不同之处在于吧台侧面有三个被木架支撑着黑板其上贴着一张张白中泛黄布告内容五花八门千奇百怪有雇佣保镖有请求帮忙寻人有调查某座岛屿情况有高价悬赏某位海盗脑袋也有声称自己获得一张藏宝图想组个团队总之在鲁恩王国本土已经被私家侦探和安保公司瓜分掉事务在这里依旧属于冒险家。「一杯扎尔哈。」敲下吧台表面。这是一种本地产麦芽啤酒价格便宜风味不错深受冒险家们喜爱从烈焰口中得知。「3便士。」酒保随意瞄客人一眼并没有因为对方脸孔陌生就出现态度变化。拿到啤酒后就坐在吧台前高脚椅上一小口一小口抿着并安静旁听周围酒客们聊天从而寻找有价值目标。过了近一个小时酒吧客人变多终于听到了也许有用话题。精神一振愈发专注。离他不到3米那张桌子坐了四个人正在惋惜一位叫做温特男人：「我一直以为温特出海了没想到他一直在家里病得很重。」「唉如果我早两天去敲门他就不会死了你们不知道房间里有多可怕他尸体上都长出蘑菇一片一片白色的。」「狗屎！别讲了！没看到我在吃香肠吗？」「好的好的温特房间内到处都是虫子有飞蛾有苍蝇有蝴蝶有蜜蜂有蟑螂风暴在上我都不敢相信这是人类住地方后面来警察也吓到了！」……一句句对话传入耳朵微皱起眉头觉得温特死亡不太正常没死几天尸体就长满蘑菇房间内还飞着爬着各种各样昆虫。与超凡事件有关？这种程度异常警察肯定会上报给代罚者小队…听起来是三四天前事情该处理应该都处理完毕了…认真考虑起要不要去看一下至少那个叫做温特男子孤身一人在拜亚姆做冒险家也没哪个同伴想替他传递死讯。旁听许久初步掌握温特租住地方就在附近黑角街47号公寓。喝掉最后扎尔哈啤酒戴上帽子离开酒吧直奔那栋公寓而去。进了大门半闭上眼睛低声自语：「最近刚死过人房间。」一连七遍后利用手杖方便快捷来到来到温特之前居住房间外。它还没有重新被租出去里面异常已经被处理看起来没什么不对。收起用来开门便签纸反手锁住房门仔仔细细转一圈。确认过情况拿出纯露精油草药粉末和特制蜡烛等物品飞快在睡床前方布置起通灵仪式。虽然已经过了好几天只能获得最粗浅不连贯残余少许信息但认为有总比没有好。毫无疑问依然是在向自己祈祷接着进入灰雾之上做出响应给予通灵力量。蜡烛火焰忽有拔高于摇摇晃晃间染上幽蓝色泽。只觉一切都安静下来仿佛来到不属于现实领域。瞳孔被纯粹黑色占据就连眼白都被驱除。无需再用梦境占卜技巧已晋升无面人他在初步进入现实灰雾帮助下直接看见温特灵性残留不愿消散念头。那有三幅画面一是身材瘦高黑发微卷五官较为深刻温特来到一具被丢弃尸体前愕然看见上面有光泽闪动凝聚出一块充满生命气息青绿色宝石二是温特躺在床上双眼紧闭嘴巴微张皮肤表面长出各种各样蘑菇周围蟑螂飞蛾一堆又一堆而在他胸口有一条银制项链坠子正是之前那枚青绿色宝石三是一个容貌清秀眼睛水润亚麻色头发少女她正坐在海边周围环绕着温特不甘愿声音：「蕊妮我要死了我好后悔后悔从来没告诉过你我爱你我想让你嫁给我…」画面破碎通灵结束环顾一圈发现房屋还残留着晦暗和阴沉。这家伙真是倒霉…摇摇头叹息一声。已初步把握到温特死亡原因那就是乱捡东西：绝大部分非凡者并不知道非凡特性不灭和守恒定律根本没想到死去同类也能析出特性成为材料而这过程又相对缓慢容易被错过所以他们杀掉非凡者后往往都是搜刮一遍丢掉尸体便宜了温特这样路人或者海底野外生物。温特并不清楚那是非凡特性以为是神奇宝石于是弄成项链贴身存放结果慢慢地受到污染影响在痛苦中死去。

# 1292 倒吊人 第二十七章 恶魔油画

## 打开书
普利兹港某个正在重建仓库内。佛尔思时隔几天又一次见到自己老师多里安·格雷·亚伯拉罕。你准备好了吗？多里安沉声询问道。之前那次见面里他已经将学徒途径序列4秘法师仪式要求告诉佛尔思让她提前做好准备。差不多了……应该能满足要求了……佛尔思不是太有自信回答道。秘法师晋升仪式相对来说较为简单但这个简单是复杂反义词而非困难另外一头于佛尔思而言她更希望换成别。……差不多就行那个仪式对纯粹依靠自身序列5非凡者来说真是太困难适当寻求帮助是必不可少但一定要把握好程度不能超过相应界限否则仪式肯定会失败。他之前给佛尔思提供建议是只借一件1级封印物最好连圣者层次帮手都不要请。……我只打算向愚者先生许一个愿望提高服食魔药后晋升成功率愿望这更接近于在服食魔药时获得一个好运而不是在封印那个半神生物时得到庇佑。除这个就是利用老师您提到那幅画。那幅画不是0级封印物神之画卷而是属于亚伯拉罕家族一件1级封印物叫做恶魔油画。在第四纪在亚伯拉罕家族还有不少成员晋升序列4秘法师年代里他们制造那副油画用来封印相应半神层次生物。不过在遭受极光会袭击遗失不少资料后多里安·格雷也不太清楚恶魔油画究竟还封印着多少恐怖生物只肯定还有且不止一个。他原本打算是从恶魔油画里释放一个已彻底疯狂全凭本能行动半神层次生物作为学生仪式目标这比去对付有理智有智慧圣者轻松不知多少倍且完全符合仪式要求但他没想到佛尔思居然准备直接借……恶魔油画本身只有关押和封印效果并不具备主动影响目标能力换句话说就是你得自己把半神层次生物塞进恶魔油画里。……老师您说过自身记录能力不算是外在帮助。对。多里安·格雷给予非常确定答复。如果自身记录能力都算外在帮助那几乎没有一个旅行家可以获得晋升毕竟记录是学徒途径半神之前最核心能力一旦它被废除佛尔思几乎就只剩跑跑跑相关很难对敌人做什么。理论上是这样可你能记录半神层次能力最多也就四五种……多里安不是太放心说道。话音未落他想到那位愚者先生和祂眷者内心稍微安定一些。如果搭配得好不是没有成功可能那只是凭借本能疯狂生物。佛尔思既在说服老师也在说服自己。多里安微不可见点头没再多说什么当即召唤出自己契约生物喜爱音乐马尔莫斯拿回秘法师主材料辅助材料当场给学生调配一瓶秘法师魔药。要是没法完成封印不用强行服食即使魔药和玻璃瓶糅合变成封印物也能通过向愚者先生祈求将它还原成非凡特性。多里安依旧有点不放心叮嘱一句然后把魔药递给佛尔思。……嗯。佛尔思重重点头表示自己绝对不会担心魔药被浪费。她都已经提前做好预案那就是一旦放出来半神层次生物无法被封印自己立刻传送离开向愚者先生许愿请祂来解决。……这正是封印着不知多少个恐怖生物恶魔油画。如果你能成功晋升我只有一个要求。多里安拿着恶魔油画郑重对佛尔思说道那就是在满月夜晚听一听门先生究竟在说什么问一问祂那样做理由。亚伯拉罕家族成员到现在都还没法彻底接受自身遭遇诅咒来源于家族先祖觉得门先生可能不太清楚祂求救造成后果。……好。面对老师恳求佛尔思一点也没犹豫就答应下来。接着她拿过恶魔油画传送出普利兹港来到没有人类居住浩瀚沙漠内。……检查完周围场景和自身准备佛尔思将恶魔油画插入地面。她旋即交握起双手低头向愚者先生祈祷许下服食魔药后晋升成功率提高愿望。几乎没什么间隔她看见虚幻灰白雾气知道愚者先生已作出回应。拖延几秒佛尔思终于战胜自己拿出预先调配好草药粉末将它们洒向恶魔油画。……突然那个漩涡里探出一只青黑色多有腐烂痕迹手。……虽然恶魔油画内那个恐怖生物还未完全脱困但只是凭借神性对外界影响就让佛尔思失去大部分反抗之力等到它彻底脱离油画佛尔思甚至会因为直视它而失控。……幸运是她有一堆半神为她提供情报让她及时闭上眼睛没再去看恶魔油画否则后果不堪设想。——根据世界先生给予提示她知道那个恐怖生物完全脱离恶魔油画需要五秒钟。……这是佛尔思从隐者女士那里记录来童话魔法叫做：桃花的源头！抓住这个机会勉强找回身体控制权佛尔思从暗袋内拿出一枚罗塞尔象棋里皇后棋将它扔向桃花源头扔向那个贯穿流水山洞。这是她记录另一个童话魔法叫做：岁月的棋局！啪随着皇后棋落下那只正努力突破桃花源阻隔青黑色手掌一下从外探变成蠕动。佛尔思看都没去看效果用无形之手拿起插在沙堆里恶魔油画将它堵向那个山洞。……佛尔思心中一喜毫不犹豫再次念出咒文关闭恶魔油画外层封印。还好刚才那个半神生物已经被关得失控只剩疯狂没有智慧……也不知道等下服食魔药后会不会直接听见门先生呼喊……佛尔思精神依旧紧绷拿出那瓶秘法师魔药将它灌入口中。

## 这场戏有没有翻

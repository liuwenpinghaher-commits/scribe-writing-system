# 904 不死者 第一百七十三章 思维盲区

## 打开书
侦探片经验：围巾遮脸大衣掩身，非冬日狂暴海不寒——多半有问题。自认无关，回舱灰雾占卜：环境无大变较顺利，安睡到天明。离港时码头突现高鼻深眶浅蓝眼褐卷发男子，下巴微抬看不起人，锁定客轮。天骤暗如漆黑虚幻大门，海底飓风蔚蓝直冲，幽深闪电自愈裂口，阻隔船岸视线。克莱恩疑非自然：围巾客或半神或持1级封印物；不动海神权杖他自己也难引这级天象，或丢阿兹克铜哨让整片狂暴。自嘲承受超序列压力，仍信昨夜占卜。风暴息，甲板灵感触动：远处炽白火光成巨大火焰长枪落甲板不燃不穿，重组为码头男子。环视目瞪口呆旅客入舱。道恩松口气——不是找他。scarf客被摔出甲板，半脸鼻红须密唾液，三角眼恐惧后挪。男子因蒂斯语问谁让你带那东西这样打扮。答：不知，那人也这打扮，给东西+100镑让坐这船去南大陆自己返回。锐利目光再审，无改口。男子化火焰长枪投回哈尔曼。克莱恩判：假登船+操纵天象造「人在船上」证据，真身留港等敌追走；被追者或阴谋家魔术师一流；追者或猎人途径铁血骑士。傍晚另一港，不下船。舷梯人潮里：黑软帽暗金鬓角高挺鼻紧抿唇古典雕塑脸无皱——血液变冷，名字迸出：因斯·赞格威尔。幽暗一等舱，念头：大雾霾后首见踪迹；半神追的是他；诡计更深——伪装登船制造思维盲区让人排除本船；他从开始就在船上；天象或0-08；为何被因蒂斯猎人追。吹冒险家口琴，信使蕾妮特出现。写信：道恩·唐泰斯于狂暴海中程岛发现因斯·赞格威尔行踪→贝克兰德北区平斯特街7号信报箱。四头八眼齐望，咬信与金币。

## 这场戏有没有翻
翻了。开头当可疑旅客与己无关、占卜顺利可睡；章末认出因斯在船上、看穿思维盲区、信已发平斯特。翻的是这趟南大陆还能不能当普通富翁航程、仇人还在不在雾霾之后的消失里，不是火焰长枪帅。

## 日子
迪西烤鱼。哈尔曼离港风暴。火焰长枪重组。甲板上三角眼恐惧。傍晚另一港煤气灯。幽暗一等舱。信使四头。金币一枚。

## 这一章落在哪一天
哈尔曼停靠次日离港至傍晚下一港。大雾霾事件之后首次发现因斯踪迹。信当晚发出。

## 人
- 克莱恩/道恩·唐泰斯：占卜、观风暴、辨半神、认出因斯、写信。
- 围巾伪装客：收100镑与物品假扮登船，不知主使。
- 火焰半神（猎人/疑铁血骑士）：追至船，审完离去。
- 因斯·赞格威尔：真身混旅客下船；或用0-08搅天象。
- 蕾妮特·缇妮科尔：取信送平斯特街7号。

## 地与走
餐厅窗 → 舱房灰雾占卜 → 离港风暴窗后 → 甲板火焰降临 → 舱门摔人审讯 → 傍晚舷梯望因斯 → 一等舱召信使。

## 这一章新讲明的规矩
- 非冬日重围巾遮面=可疑；占卜顺利≠途中无半神戏。
- 狂暴海说变就变是常态，节点恰好变仍可疑。
- 引动该级天象≈半神或1级封印物；海神权杖同级参照；阿兹克铜哨或可搅整片海。
- 假登船+天象证据造思维盲区：让追踪者排除本船。
- 化身火焰长枪、傲慢、因蒂斯语≈猎人途径半神（铁血骑士可能）。
- 0-08可制造巧合天象（克莱恩推断）。

## 钱与人情
伪装费100镑。信+1金币给信使。旅客船资拼凑 vs 一等舱富翁——对照在下章更显。向伦纳德/平斯特报信=复仇情报人情。

## 话
「是谁让你带着那件东西，做这样打扮的？」「给了我100镑，让我坐这条船去南大陆，再自己返回！」局面是火焰审讯把围巾客收成道具；舷梯侧脸把顺利旅途收成因斯。

## 热怎么变冷
占卜顺利还热。冷切在码头锁定客轮的傲慢男子。风暴阻隔还热。冷切在半神级天象猜想。火焰出场帅还热。冷切在希望别船上开打。审讯收场还热。冷切在古典雕塑脸=因斯。

## 怎么起、怎么收
第一段接围巾遮脸多半有问题。最后一段停在蕾妮特咬住信纸和金币。章题思维盲区：排除本船的那层诡计。

## 叙述怎么插手
侦探片经验：他的比较。真是巧啊这应不是巧合：判断。承受太多本不属于这序列的压力：自嘲。目瞪口呆加引号：扮演反应。血液一点点变冷：身体先于名字。

## 这一章放了什么
- 假扮登船+天象的思维盲区拆解。
- 猎人半神与因斯追逐线。
- 因斯现身中程岛航线；0-08嫌疑。
- 情报发往平斯特街7号。

## 这一章收了什么
上一章窗边可疑客：本章收成诱饵道具。顺利占卜：本章未翻盘成翻船，却翻成仇人同船。普通富翁航程：本章结束。

## 谁比谁多知道
克莱恩认出因斯；半神与旅客不知舱里有道恩。伪装客不知自己是盲区零件。读者与克莱恩同步得名；平斯特尚未收到。因斯不知已被写信。

## 留给下一章的日子
信在路上。克莱恩仍在客轮一等舱。因斯已登码头拐角消失。半神已返港方向。

## 这一章回不去的事
已经确认因斯·赞格威尔出现在狂暴海中程岛航线。回不到「大雾霾后无线索」。已经把本船从「错误选项」翻成他藏过的地方。

## 这一章人怎么叫人
道恩·唐泰斯。因斯·赞格威尔。蕾妮特·缇妮科尔。因蒂斯语问话的半神。船长（未出场的责任想象）。

# 1360 倒吊人 第八章 联合行动

## 打开书
教皇……达尼兹吓一跳差点不敢相信自己听到神谕。如果不是这个吩咐直接来自愚者先生他肯定会脱口骂一句脏话。当然若对面是格尔曼·斯帕罗他也是能忍住。……神使大人还有什么问题？门外海神教会情报主管见圣达尼兹阁下表情变得颇为古怪一时有些害怕。……密切注意海浪教堂那边动静。是神使大人。那位情报主管暗自松口气赶紧行礼告辞。……愚者先生已降下神谕。……神说阿尔杰从今天起戴上面具担任海神教会教皇。愚者先生意志就是我意愿！阿尔杰难以掩饰露出一抹笑容弯腰行礼道。……愚者先生和风暴之主达成一定协议有某种默契自己叛逃行为不再被追究当然必须戴上面具使用假名不能让风暴教会丢脸；成为海神教会教皇是通往海神宝座关键一步。在阿尔杰看来这表示自己正式成为愚者先生下属以后无论是换取海神身份还是更进一步担任愚者教会首领都有不小机会……门先生回归现实世界而时天使阿蒙趁机窃取祂成神仪式晋升为序列0错误。几乎是同时愚者先生更进一步复苏通过源堡与占卜家学徒偷盗者这三条途径非凡者们建立微弱转瞬即逝联系。——身为偷盗者途径天使帕列斯·索罗亚斯德毫无疑问能感知到阿蒙成神体会到相应权柄变化并发现源堡与自身建立某种联系。老头阿蒙都已经晋升序列0了现在你对他来说应该没什么作用了你为什么还要寄生在我体内？伦纳德呼吸口清晨新鲜空气后压着嗓音半疑惑半关切问道。他脑海内帕列斯·索罗亚斯德呵一声：天真。是不是觉得自己已成为圣者掌握很多神秘学知识不再需要我教导了？你可以选择面对面教导我。伦纳德斟酌一下语气道。……坏处最明显一点是生命操纵于寄生者之手对方若是起歹意他根本阻止不了。这个问题曾经是伦纳德最担忧事情现在倒是不重要因为愚者先生复苏程度越来越高已能完全压制帕列斯·索罗亚斯德而且伦纳德也成为黑夜教会高级执事必然会受到黑夜女神注视……所以他觉得老头离开自己身体像长辈一样住到自己家中是更好相处方式等需要处理较危险事情时再让老头临时寄生回来。……你是不是还在想回家以后就解除寄生需要外出时再寄生？当我是你保镖啊？……如果你还没有彻底恢复想继续寄生我没意见。……接下来才是最危险一段时间为诡秘之主位置愚者和阿蒙必将有一战到时候非凡特性各种定律影响下我们这些同途径天使说不定会受到影响呵还是托庇于黑夜视线里安全。等诡秘之主诞生你求我寄生你我都瞧不上！……诡秘之主？这不是你能深入了解事情当然有我在倒是不用太担心。帕列斯·索罗亚斯德又是感叹又是自傲说道。伦纳德正想趁机询问忽然看见一位红手套队员拿着封电报跑过来。阁下圣堂电报。这位队员恭敬行礼道。……前往南大陆参与围剿玫瑰学派行动。……老头事情有些奇怪啊各大教会怎么突然要围剿玫瑰学派了？……另外他们有被缚之神欲望母树庇佑神灵们很难为行动提供精准指引。……这是在清除隐患为末日做准备。……母神让我们前往南大陆埋葬那些邪恶者。这位神眷者低沉开口道。……他昨晚梦见始祖梦见祂让自己和乌特拉夫斯基神父联合玫瑰学派节制系一起去南大陆对付信仰原始月亮那部分玫瑰学派成员。当然如果有机会信仰欲望母树敌人也不能放过。……他嗯一声竟颇有点沉稳回应乌特拉夫斯基神父：不用着急。我先联络玫瑰学派节制系成员。……再挑选一些自愿血族。……奥维尔……第兰……奥维尔……第兰……

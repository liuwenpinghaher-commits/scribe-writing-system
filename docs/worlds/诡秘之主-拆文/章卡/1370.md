# 1370 倒吊人 第十八章 谁是朋友谁是敌人

## 打开书
拜亚姆海神教会内部。举行完弥撒阿尔杰·威尔逊刚回到房间就看见窗户旁边浮现出一道身影。那是戴礼帽穿风衣格尔曼·斯帕罗。不等阿尔杰开口克莱恩前行两步庄严说道：我遵愚者先生命令而来。他习惯性扮演着诡秘侍者身份。……赞美愚者先生。克莱恩微微点头抬手从源堡杂物堆里取出一件物品。……作为水手途径序列4半神他无比确定眼前白骨权杖就是海神身份位格力量象征。他一边忍受着祈祷声带来少许眩晕一边将目光投向世界格尔曼·斯帕罗等待这位神灵侍者开口。克莱恩单手举起海神权杖神情肃穆说道：这是愚者先生恩赐和信任也是对你保护住大量信徒嘉奖。无论将来发生什么希望你能一直谨遵愚者先生吩咐竭尽全力完成祂给予任务。……他怀疑愚者先生之后会遭遇一些事情以至于出现损伤跌落低谷。……唯追随愚者先生！克莱恩见状暗自点下头然后才将对正义小姐和审判小姐说辞重复一遍。……你先适应这件封印物和海神日常等到消化完灾难主祭魔药再用它调配魔药这提前扮演能让晋升难度降低不少。其实克莱恩现在已经可以解除嫁接将指向自己和源堡海神概念转移给阿尔杰让他直接成为半个海神更好地适应这个身份更好地提前扮演。但考虑到接下来容纳愚者唯一性后需要足够锚来平衡天尊进一步复苏意志海神信徒们不可或缺克莱恩决定等自己状态真正稳定了再彻底转移海神相关。如今阿尔杰更接近于代掌权柄侍者帮助神灵聆听祈祷回应祈祷却不享有对应锚和身份——那根海神权杖主人依旧是克莱恩依旧指向他这是嫁接妙用。……这件封印物有哪些负面效果？愚者先生已经做一定封印海神权杖负面效果大幅度降低了。克莱恩简单说道它现在只会让持有者变得更暴躁一点让灵处于一定混乱中另外它每隔一个月会抽干周围生物血液一次你可以提前飞行去海上或无人岛屿。……完成额外准备后克莱恩坐到愚者那张座椅上具现出一张羊皮纸和一支暗红圆腹钢笔分析起前往霍纳奇斯山脉主峰面对安提哥努斯家族先祖可能发展：如果一切顺利进入容纳愚者唯一性最后阶段女神必然会解除隐秘因为只有这样才能让那片区域和现实交互才能让命运互通达到愚弄效果。从门先生成神仪式看容纳唯一性动静肯定也不会太小一旦没有隐秘此事必然会被其余神灵察觉而且关心此事存在们最近肯定都注视着霍纳奇斯山脉主峰那里一有什么变化祂们第一时间就能知道。这种情况下毫无疑问会有干扰有破坏有帮助有支持弄清楚谁是敌人谁是朋友很重要否则没法做有针对性准备。女神肯定是站在我这边……最不希望阿蒙成为诡秘之主是永恒烈阳风暴之主和知识与智慧之神一旦有谁试图破坏我容纳愚者唯一性仪式祂们毫无疑问会帮我直接提供援助。……这些真神之外不太常见序列0或接近序列0有意识存在里：深渊之主也就是宇宙暗面疑似被欲望母树侵蚀……祂们会怎么做只取决于欲望母树想法而对外神们来说推迟诡秘之主诞生应该是共识。……欲望母树最可能策略是默许甚至帮我容纳愚者唯一性让我和阿蒙间天平不再倾斜之后则一次次破坏我们聚合趋向和尝试将诡秘之主诞生拖延到末日降临时。……友方：黑夜女神风暴之主永恒烈阳知识与智慧之神；敌人：空想家亚当真实造物主错误先生阿蒙；中立里偏向我这边：大地母神宇宙暗面被缚之神；中立里偏向阿蒙：隐匿贤者；中立里态度模糊：原初魔女蒸汽与机械之神。……嗯先不管亚当和真实造物主融合到哪一步就按最坏状况算将祂们视作远古太阳神视作双途径序列0真神……女神有黄昏巨人和死神唯一性……即使还比不了远古太阳神也绝对可以拖住对方……阿蒙也按双途径序列0真神算风暴之主祂们三位里面至少得分出两位才有希望挡住祂……从表面情况看我这边还是占有一定优势……克莱恩看着纸上列出内容边专注思考边无声自语道。……原初魔女隐匿贤者蒸汽与机械之神都基于各自台面下交易或本身好恶选择帮助阿蒙。这样一来即使大地母神参战克莱恩这边也会处于劣势……而且这样抵消是一种理想型计算。实际场景中那种混乱局面下执掌错误阿蒙能玩出很多花样有可能一下就找到薄弱处直接绕过阻挡让克莱恩仪式失效当场失控。另外表面支持克莱恩某些神灵说不定会基于他现在无从知晓理由转而帮助阿蒙。……呵没想到还有薅欲望母树羊毛一天嗯我得为这最差局面再做些准备预防事情真往这个方向发展。克莱恩散去面前纸张和钢笔将目光投向某个被特殊标记祈祷光点。他身影随即消失在源堡内部出现在贝尔纳黛黎明号上。

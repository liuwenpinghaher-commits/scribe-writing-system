# 499 旅行家 第十八章 审问“白鲨”

## 打开书
扑通！酒保摔地上痛得蜷缩一团打滚。白鲨汉密尔顿重重哼一声什么话也没说扭头走向二楼踩得木制阶梯吱嘎作响。热闹看完酒鬼们纷纷散去艾尔兰船长等人不受影响返回上层继续打牌。克趁这机会跟着踏上楼梯。他回到飞鱼与酒不是为不存在危害对付白鲨纯粹想从这位与多股海盗势力有联系酒吧老板处了解更多情报毕竟他为新身份取名格尔曼隐藏意思就是要狩猎满手血腥海盗用他们灵肉和非凡特性替代蠕动饥饿内待释放者。达米尔港没有煤气资源二楼过道相当昏暗两侧墙壁镶嵌黄铜烛台上灯火摇曳黯淡如豆。边观察环境边伸手在脸上抹一下悄无声息变成一楼某位守卫。至于衣着装饰不同他用制造幻觉能力进行弥补。做好准备向着灵性直觉里白鲨汉密尔顿房间走去。最先路过打牌地方没引起任何人注意。来到扼守通道几名守卫前自觉停住脚步压低嗓音：「楼下又有点事情。」「风暴在上今晚究竟怎么了？」一名守卫感叹。「希望那些可人儿不要受到伤害。」另一名略有点担忧。他指依附酒吧妓女们。「她们没事。」越过守卫来到白鲨门前拘谨抬手敲动。「谁？」汉密尔顿警惕问。「老板是我楼下又出现情况了！」回忆刚才看热闹时获得称呼信息刻意沙哑嗓音。「该死！」怒吼一声：「进来说清楚发生了什么！」扭动把手走入。顺手关门时解除幻术脸部肌肉急速蠕动变回上一个身份——金发蓝眼五官普通新酒客。「你…」先是一愣旋即张大嘴巴试图高呼。同时手背浮现片片虚幻鱼鳞本就高大肥胖身体又膨胀一圈。突然心跳砰砰加快源于本能强烈恐惧扼住喉咙。这一刻觉得站门边陌生人就是一只饥饿许多天恶魔正用冰凉渴求目光来回审视自己血肉和灵魂。刹那之间陷入极度恐慌无法做出有效应对。克慢悠悠走到沙发位置坐下来礼貌笑：「现在可以平静交流了吧？」被恐怖怪物盯上感觉霍然消失一下变得轻松身体则如同被戳破气球干瘪许多。他不再鲁莽呼救额头见汗问：「你是谁？你想做什么？」「一个猎人。」随口回答：「听说你和多股海盗势力有联系我想知道相应情况。」「不我没有…」下意识否定。立刻又感受到那种疯狂到极致饥饿只觉对面男子眼睛都似乎染上一层暗红。克心里斟酌人设斯文笑：「你有两个选择。一是坦白回答二是被我杀死然后坦白回答。」杀人通灵？听说过类似传闻艰难吞咽唾液：「你为什么想知道这些情况？」露出笑容：「我是个猎人我追逐赏金。」忽然觉得对方彬彬有礼笑容里透着说不出疯狂意味忍不住脱口：「你你疯了吗？类似冒险家我见过不少但全都葬身海底！单独猎杀一名海盗并不困难但你能防备后续报复吗？酒吧内妓女看起来很普通顾客也许就是海盗线人！与你友善同伙随时会被收买背后给你一枪！海盗们还会提前搜集情报围堵你乘坐船只你能保护所有乘客吗？你能在一门门火炮轰击中在无法逃跑大海上活下来吗？」一口气宣泄完内心恐惧看见对面自称猎人男子又一次绽放斯文温和笑容：「都杀掉就不会有这些问题了。」…真正疯子…吸口气：「我和许多海盗是有联系但都是被动他们抢到现金珠宝货物需要售出需要换成烈酒食物淡水武器和女人安慰这都得通过我但我只能在这里等待他们不清楚他们船只究竟行驶哪里最近目标是什么。」「还有呢？」不动声色问。刚才回答主要吓唬白鲨至于海盗报复一点也不担心身为无面人要是这么容易就被找到那还不如找个地方自沉海底算了。还有…喉头蠕动下没立即做肯定或否定描述。紧闭嘴巴望戴半高丝绸礼帽绅士与对方平静内敛仿佛在酝酿疯狂眼睛对视起来。让人不安沉默像暴风雨来临前海面轻轻回荡碰撞发酵。终于移开视线烦躁将手撑在面前桌子上：「是的我还在替他们搜集消息如果有紧急情报我会利用他们给予电台提醒他们注意。」不敢冒险害怕对方拥有独特非凡能力可判断自己是否说真话是否说出全部事实。「电台？」博弈成功敏锐捕捉名词。「这是他们告诉我称呼和电报类似但不需要线。」转身走到灰白色保险柜前蹲下来。无线电报？海盗这么高科技了？隐约猜到对方所说电台是什么。曾经想过发明类似东西结果翻相应杂志才知道无线电报早就已经出现只不过在商用领域暂时还没有找到属自己位置——分隔南北大陆狂暴海常年电闪雷鸣磁场紊乱风暴肆掠只有少数几条航道可通行即使装备无线电报也近乎没有作用同样迷雾海苏尼亚海天气变化剧烈存在诸多影响电磁传播因素无线电报应用受到极大限制。难道出了可解决部分问题改进型？看着白鲨将保险柜前面地板撬开通过拧动装置让墙上出现一道秘门。秘门后是分为三格隐蔽柜子最上层放着些文件和票据中间有左轮新式半臂枪等武器下方则塞着复杂黑色机械。只是瞄一眼就通过上辈子印象和之前搜集资料判断出那机械造物属无线电台。「就是这东西他们称呼这是电台拍出消息最远可被罗思德群岛类似东西收到更远一点必须看天气靠运气平时平时也很麻烦很多限制。」不是太懂根据接受教导和使用经验模糊描述相应情况。比目前正商业化新型无线电台要厉害…也不知道是谁发明…安静听完直接问：「他们是谁？」让自己表现得像不懂科技赏金猎人。抹把额头冷汗：「自称为黎明号主人服务银币毒蛇奥德尔以及血之上将情报官老奎因他们是一起出现我无法确认他们是否在合作当然奥德尔一直都只是宣称。」黎明号主人那位神秘女王？收回视线手中不知什么时候多了枚金币。金币不断在指间滚动最后跃入半空落下去看得白鲨不明所以战战兢兢。低头瞄一眼缓缓站起。就这时突然问一句：「谁给你魔药？」「老老奎因…」犹豫下还是选择坦白回答。轻轻点头不再询问转身走向门口。哐当！木门打开又合拢穿黑色呢制大衣身影消失白鲨房间内。汉密尔顿屏住呼吸等待十几秒终于长长吁口气。快速擦掉脸上汗水将电台搬到桌上翻出密码本忙碌着向远方拍了封电报：「我被人盯上了！陌生家伙！」专心致志身旁克双手插兜静静看着将波段频谱和密码本内容全部收入眼底。刚才离去只是一场大型幻术表演对付白鲨这水手途径低序列者绰绰有余。至于之后是否能记住具体内容问题占卜家并不需要考虑一次梦境占卜就能全部回想起来。血之上将和他手下酷爱杀人喜欢鲜血热衷对女性施暴每次劫掠客船总会制造出惨案…这是公认事情而他们自身也很为此自豪总是不吝啬宣扬…狩猎目标冒险对象优先考虑他们…略作思考趁汉密尔顿收拾电台机会准备真正离开这房间。暂时不打算对付白鲨怕惊扰真正猎物反正这种身在陆地上有固定地盘且被自己拿住把柄家伙事后一封举报信就能轻松解决。无声脚步里房门缓缓裂开又静静合拢带入轻微凉风。

## 这场戏有没有翻
翻了。跟楼上开；章末幻术偷电报内容。翻的是审问＝电台＋血之上将线，不是当场杀白鲨。

## 话
「一是坦白地回答，二是被我杀死，然后，坦白地回答。」「都杀掉，就不会有这些问题了。」「我被人盯上了！」局面是从跟楼收到恐惧；从两选择收到被动销赃；从电台收到名单；从假走收到密码。

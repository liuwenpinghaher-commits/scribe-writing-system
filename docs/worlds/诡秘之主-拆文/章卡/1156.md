# 1156 逐光者 第七章 风度

## 打开书
克莱恩按灰白墙缓坐直微笑摇头：在填满我的胃之前，我的大脑抗拒工作。既真亦谎——成完整神话生物前圣者仍饥渴，序列3十天半月不补也可承，完整神话进食爱好非必须。意＝正式逃脱前须调状态至最好。一位魔术师的习惯。阿蒙笑评：我不负责提供食物但可自己想办法。看地面皮灯想几秒虚抓——前方现不高茶几＝道恩府邸物。昏黄光再召唤史隙精美盒：整套刀叉盘杯。选它因单独召不同餐具凑不成套——同时只能维持三影。不慌摆好餐具后礼貌侧头对尖顶软帽阿蒙点头，再召涂黑胡椒汁七分熟牛排落瓷盘冒热气，刀切显肌红蛋白残留面。叉一块入口质感真实口感美妙抚平胃焦灼。一刻钟内不仅不饥还能获真实补充。含笑介绍如好客主人非绑架可怜非凡者。阿蒙抵单片下缘微笑点头：我试过还不错。你状态调整很快啊真不考虑做我的眷者？又切一块边叉起边如友闲聊：你杀了我吧。此时较频闪电与无尽黑暗交替统治，光照不到处眼无情感注视，尖端暗红扭曲荒草随微风舞。半坍建筑内昏黄光为艺术茶几精致餐具镀温暖，煎牛香味若有似无，与几乎无间隔外界截然相反。他顶黑暗深处可怕怪物注视，在荒芜灰沉酝酿极大恐怖大地上优雅斯文享用美食。吃完招玫歌庄园冰酒一口喝。奶油浓汤香煎鳕鱼豌豆炖嫩羊肉焗土豆皮各葡萄酒依次召入肚。最早牛排超维持凭空消失胃袋被后续麻痹未察。茶几餐具有补召否则难维持到结束。尾声虚拿杯一球香草冰淇淋甜品匙挖融甜美。意犹未尽再召一球。连续五球不同口味。第六次探手侧面阿蒙忽笑：你的命运有了不正常变化已经足够幸运。这就是你的准备吗？右手顿半空瞳似放大。几乎同时深沉黑暗中灯光照不到处奇形怪状生物齐抽搐瞬成秘偶。一口气送一百条灵之虫望有幸运儿规避窃取。茶几后方黑呢大衣无帽人影换成浑身流脓恶心吸血鬼。艺术茶几精美餐具如摔地玻璃裂无数缝支离破碎飞快回归史隙以免影响后续召唤。下一秒一百偶连同不知藏哪本体齐探手虚抓用次数规避干扰——皆古代学者。源自诡法师能力占卜家质变源泉。每偶召唤成功概率独立。要召的是信使蕾妮特图铎遗迹恢复巅峰投影——契约符咒关系最易召天使影！阿蒙仍悠闲坐单片微光看一百零一克莱恩同时召。右手齐探又收皆未成功未拖出蕾妮特。阿蒙抬右手前抓臂微沉随意后拉——建筑外现巨如城堡阴沉繁复长裙藤蔓束缚布娃娃。古代邪物蕾妮特·缇尼科尔！盗走他召出的史影！红眸映一百偶——无声微光变头顶长角山羊白兔等。变形诅咒！本体早消从皮灯腾火光走出。看也许能称自己的各动物突又坐下呵呵：餐后散步能有效改善健康情况。半点不提逃脱如无事。阿蒙悠闲配合含笑点头：看过不少人类书写里确实有这观点。抬指外蕾妮特影：这就是你的信使？易确认不瞒嗯点头。可惜啊。上下打量啧啧摇头。感受胃内食物依次消失问：可惜什么？我应带你在贝克兰德多等几天就能等你信使送信然后祂将成为我的信使。推单片笑：偷走天使级信使很有挑战性也好玩不是吗？生活总需乐趣刺激期待。我也是这么想的。诚恳回应。可惜。又摇头：黑夜是必须小心的对象再停留不知会发生什么。解除对蕾妮特影维持让消。你对女神似乎很忌惮？伪装黑夜虔诚信徒口吻——实际仍是眷者。目光移皮灯昏黄：我无法从隐秘中窃取想知之事解读不出祂还会有何布置真正关键点在哪。对偷盗者天使之王足够忌惮理由。趁答诵女神尊名巨人语：您是比星空更崇高比永恒更久远的黑夜女神……刚念一句念头遗失若非先前有打算差点不知自己做了尝试。阿蒙转头笑：你是想试探我窃走你念头话语后是否内心重复一遍？只要成序列4寄生者就能控制偷来东西让合适时候呈现。这样啊。轻颔首：谢谢。同时飞快总结经验：契约隶属召信使最易成；从过去威尔召冰淇淋能与命运之蛇建微联得幸运恩眷每球一部分幸运——本拟以召冰淇淋遮掩秘密召命运之蛇；之后召唤须先干扰否则阿蒙直接窃走史影费力反送帮手……思绪间阿蒙指变形诅咒那堆动物露出略恶劣笑：你不是担心神弃没有合适食物吗？现在有了只要不解除诅咒它们就是真正的动物。……愣一下猛望山羊白兔。意念驱使动物视线同投向他。某种意义这都是克莱恩自己——灵之虫与怪物结合遭咒所变。

## 这场戏有没有翻
翻了。开头还用填胃挡正式开逃；章末大餐变第一次逃脱、信使影被盗、动物化的自己对视。翻的是「风度晚餐」收成失败后仍风度收场，不是牛排真不真。

## 热怎么变冷
牛排真实还热。冷切在你杀了我吧。五球冰淇淋还热。冷切在足够幸运／准备吗。百偶齐召还热。冷切在影被盗变形。忌惮女神还热。冷切在念头一句即丢。动物＝自己还热。冷切在合适食物笑。

## 怎么起、怎么收
第一段按墙坐直填胃大脑抗拒工作。最后一段山羊白兔视线投向他——都是自己。章题风度——逃败仍保持。

## 叙述怎么插手
圣者饥饿设定。三影餐具理由。荒原与晚宴对切描写。逃脱经验三条总结。动物即自己点题。

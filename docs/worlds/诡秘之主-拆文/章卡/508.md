# 508 旅行家 第二十七章 请求

## 打开书
「迪默多？他们还在餐厅里。」乌尔迪下意识回答。紧接着指向发霉脑袋被净化地方急声问：「刚才那是什么？」维持格尔曼人设克未做回答瞄眼达尼兹直接越过堂娜一家走到大门紧闭青柠檬餐厅前。烈焰提马灯因终于完成一个目标轻松不少挺直腰背看着乌尔迪等人嘿一声：「你们不需要去管这是什么记住它是会伤害你们怪物就行了。」如果不是格尔曼就在几米开外他甚至想宣称只有我烈焰达尼兹大人才能保护你们！克里维斯和塞西尔蒂格对视一眼主动上前宽慰雇主：「等返回白玛瑙号再问。」坦白讲他们三位保镖曾经都或长或短做过一段时间冒险家可对怪物认知依旧停留民俗传说和同行醉话这层次此时难免有些自己在做梦恍惚。但对他们而言既然见识过鱼人这种生物其他东西也就不是那么太难接受顶多比鱼人丑一点古怪一点特殊一点。这么一想内心稳定不少手中枪支似乎又找回力量。不过那道从天而降纯净光芒依然超出理解范围只觉长久以来形成世界观人生观价值观都出现动摇只能暂时不去考虑将种种情绪全部压到底。克停青柠檬餐厅门口抬起右手屈指敲动。咚咚咚！有节奏敲三下后里面无人应答一片安静。如果不是还有烛光从窗户和门缝里明晃晃透出甚至会以为这是一座废弃许久空屋。咚咚咚！又敲三下。餐厅之内沉默依旧所有人都仿佛在遵守大雾天气不回应敲击声习俗。收回右手拍拍双排扣长礼服下摆。突然身体后仰膝盖提起用力往前蹬出右脚。哐当一声餐厅大门猛地往后敞开固定铜锁钉子全部冒出来。身穿燕尾服脸蛋多肉近乎成圆老板福克斯还是站原本位置选择留宿女士和绅士们又纷纷打开房门静静站分界线上无声望着这边。「你想做什么？」福克斯没有发怒语气一如之前但手里已多了把左轮。开了灵视克转动脑袋环顾一圈未从在场人类身上发现邪异痕迹。视线落到餐厅老板身上目光沉凝下来看着对方眼睛：「迪默多一家呢？」福克斯与对方压抑着情绪仿佛在酝酿风暴深棕色眼眸对视两秒不自然扭过脑袋：「还有一桌外乡人在楼上。」「让他们下来。」冷漠吩咐。静默好几秒直至对方迅捷拔枪瞄准他脑袋。吸口气派位侍者前往二楼带着迪默多一家沿阶梯咚咚往下。「发生了什么事情？」迪默多是位不到三十男子这次是在和新婚妻子度假。垂下枪口平淡：「班西港发生了变故。你们是和我一起回船上还是留宿这里？」「变故？」咀嚼这单词同时看见外面乌尔迪在对自己重重点头。他知道对方是位很有钱进出口商人随身带三位保镖相信如果真有什么变故和对方待一起肯定更加安全所以答案不言而喻。至于班西港独特风俗那只是风俗而已！拉住新婚妻子手边走向门口边礼貌笑：「我们所有东西都在船上当然是和你们一起。」「谢谢。」他和他新婚妻子同时道谢越过克与外面布兰奇一家会合。收回左轮很有礼貌向老板福克斯微微鞠躬：「打扰了。」说完转过身体在餐厅外泄光明里走向克里维斯等人。哐当一声青柠檬餐厅大门再次合拢被风吹得有些摇晃。刚才其实有察觉到一些异常微妙气氛但既然灵视没有收获也不想去深究免得引爆班西港潜藏那个巨大危险。回到达尼兹旁边就着马灯光芒扫下人数。堂娜一家四口三个保镖迪默多夫妻以及几位仆人齐了…交换左轮和手杖位置抬起握枪右掌探入双排扣长礼服内摩挲下太阳胸针。暗金色光芒一闪无形力量飞快往外扩散波浪一样涌过在场所有人。这瞬间堂娜等人就像来到南方正沐浴温暖阳光驱散体内阴寒。他们不再那么紧张和担忧似乎找回属于自己勇气之前享用达米尔港特制腌肉残存些许黑色连同极为少量邪异感迅速消融。「太阳光环」能提高二十米范围内同伴勇气并净化他们体内邪异力量！借助胸针施展这种类法术能力受着灵性和精神控制可让太阳力量绕过不想帮助目标。「先去电报局。」重复一遍左手持杖右手握枪分辨好方向迈步前行。达尼兹则按示意走在斜侧方克里维斯塞西尔和蒂格非常专业接过另外两个方向警戒。超过15人队伍一旦遇到袭击很容易顾此失彼而且这里只有烈焰能真正称得上帮手…该怎么做呢？回想下之前遭遇怪物特点忽然将左轮塞回腋下枪袋并把手杖交于右掌。左手探入衣兜去掉铁制卷烟盒灵性之墙取出阿兹克铜哨将它握掌中时而抛起。相信那些只剩一个脑袋不死类怪物肯定会遗忘其他人「眼」里只剩这枚黄铜色古老哨子！这样一来我就不用担心来不及救援了这就是MT作用啊！感叹一声稍微加快步伐。就这时前方稀薄雾气里飞出三个长满霉斑干瘪脑袋它们利箭一样从不同方向冲往克完全无视其他鲜美血肉存在。三个！达尼兹瞳孔一缩有点担心格尔曼会手忙脚乱又有些期待对方展现真正实力。三个…不慌不忙抖动左掌将阿兹克铜哨扔向半空。那些拖着食道飞翔脑袋当即画个弧线奔向最主要目标。退后一步没有表情抬手捏下太阳胸针。霍然之间铜哨所在位置凭空产生一丛丛金色密集火焰神圣气息磅礴弥漫。「光明之火」！那三个皮包骨头般脑袋同时发出凄厉惨叫在金黄火光里化成一丛丛粉末。上前两步伸手接住阿兹克铜哨。…还能这样？又是一件神奇物品？达尼兹愣两秒只觉事情解决得太轻松。这时迪默多和他妻子也看清楚刚才袭击众人东西长什么样子一个吓得脸色发白一个惊慌失措问：「那那是什么？」堂娜当即转身认真点头：「等返回白玛瑙号再问。」说完竖起手指抵唇边模仿斯帕罗叔叔给出禁声意思。迪默多想到前方那个年轻人展现神圣气息艰难吞口唾沫拉拉妻子手警惕沉默下来仆人们见状只能顺从。队伍继续前行于只有单薄月光街道上两侧房屋内灯火都已熄灭凸肚窗后是看不清黑暗。堂娜总觉得里面有一双双眼睛在跟着自己等人移动但又碍于某些因素没谁露面。他们肯定都在害怕斯帕罗叔叔！拉紧弟弟手走在父母保护圈中。忽然侧方街口出现一道身影他披着黑色斗篷前倾身体露出还在冒鲜血脖子而脖子之上空空荡荡只有斗篷内衬映着月光。荷！那无头人影喉咙里发出野兽般低鸣蹬蹬蹬就冲向克踩得街道地面出现轻微摇晃。它所经过位置正好要与达尼兹碰上这位知名海盗暗骂一声挥动手臂从掌中甩出一团反复压缩过橘黄火球。轰隆！火球爆开炸得那无头之人向后连退几步。他身上衣物破烂皮肤飞快焦黑斗篷随之燃烧。但于早已失去生命怪物而言这不算什么太严重伤害。就在这刹那随着啪一声脆响黑色斗篷上赤焰猛然腾起如在盛放。穿着大衣克从火光里跃出借助坠落惯性和本身力量将双掌持握手杖直接插向无头人脖子。噗嗤！那手杖没入无头之人身体从它裆部伸出来。砰！背部肌肉一鼓硬生生将无头怪物插翻在地！趁此机会一边立对方背后继续紧握手杖一边将灵性灌注入太阳胸针内。刚才已用灵视判断过召唤圣光净化之斩和光明之火都无法短时间内解决这黑绿颜色浓郁怪物只能换一种办法。五秒四秒三秒无头之人竭力挣扎却像蛇一样半跪着被手杖牢牢钉在地上。两秒一秒！低沉开口吐出一个古赫密斯语单词：「太阳！」星星点点辉芒呈现化作水滴洒落往下淋在无头之人身上。嗞嗞嗞！黑绿气体冒出放开手杖侧移两步。稀疏雨水里无头之人连续抽搐最终平静下来融化成一摊血水。没有非凡特性…这说明不是真正敌人顶多算制造出来仆役…抽回手杖转身走向队伍。「好酷！」丹顿发出迟来赞叹声。堂娜眼眸也熠熠生辉。还是借助神奇物品力量…不过那个依靠火焰闪现说明真正实力真不好对付…烈焰收回视线觉得自己之前不盲目逃跑决定实在太明智。七八分钟后又清理两波怪物队伍抵达班西港电报局。克里维斯主动上前敲响大门。「谁？」里面传出一道平缓女声。「我们想找白玛瑙号船长艾尔兰先生。」隔门回答。安静夜里那女声不快不慢：「他和他大副去了隔壁教堂。」这里人说话有点奇怪啊或者只有类似夜晚是这样？抛枚金币确认对方没有撒谎。准备离去时电报局内那女声迟疑下：「你们可不可以帮我留意一个人。他是我同事今晚风起前出去再没有回来。他叫帕沃·考特。」

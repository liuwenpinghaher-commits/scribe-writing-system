# 484 旅行家 第三章 丰富的信息

## 打开书
赫密斯？这可是远古强者啊…克看得眉头微动。拥有扎实神秘学功底很清创造古赫密斯语那位老先生究竟活跃哪个年代。那可是巨人统治大地巨龙翱翔天空第二纪；从某种意义比战神大地母神还早出现人类历史；换句话说没加入塔罗会前小太阳不认识七神但多半听过赫密斯这名字；嗯等下找机会让世界确认…那位老先生亲身经历人类先民以自身试药一步步寻求非凡力量荆棘之路；以巨人语巨龙语为蓝本站一位位先驱者肩膀上开创性发明一整套属人类超凡语言；大概率看过第一块亵渎石板！竟活到罗塞尔大帝时期甚至可能活到现在！人类神秘学活化石啊！一阵感慨从另一方面体会黄昏隐士会可怕。就连赫密斯都是它成员！而其他隐秘组织甚至七神教会内部做祭祀仪式时使用却往往是古赫密斯语！黄昏隐士会真高端大气上档次…忍不住心里喟叹。最羡慕非黄昏隐士会竟有赫密斯这种与人类历史同在传奇人物——而是对方掌握第二块亵渎石板。这简直作弊！想到塔罗会只有二十二分之一亵渎之牌就有些唏嘘。目光焦点重回纸张继续读之前那则日记剩余：「我的天啊坐我旁边看起来普普通通平凡无奇老头子竟然是赫密斯他从黑暗第二纪元一直活到超凡衰退第五纪！这个组织加对了！我看到了我的光明未来不用三个感叹号不足以形容我此时心情！！！这帮大人物这些老不死聚一起就单纯信奉流传至今黄昏将近观点？不绝不是这样至少我就不是！他们之中肯定有人狂热相信那些理念纯粹想等待最初那位造物主苏醒想让历史进展按预计推进到那个节点呵呵按我理解多半不是苏醒而是复活。但这样人不会超过一半剩下都是各有目的家伙要么属我这种野心家要么潜伏二五仔；等一下我想到一个问题我答应那隐秘邀请后很快就参加聚会根本没经过审查虽然聚会召集者说为我加入各位成员出现分歧不得不投票表决靠超过三分之二同意数我才勉强得允许但这不是关键；关键是他们完全不在乎我是否信奉黄昏将近理念也不介意我抱有各种各样想法。他们是靠什么确认我不会危害到这个组织？难道这里有观众途径高序列强者达到天使阶高序列强者祂在不知不觉间就借我口头承诺种下隐秘心理暗示并有足够信心发现成员隐藏恶意？这真有可能但想想却让人有些不寒而栗。」「另外没得到允许情况下一旦对外界提及那个组织名称就立刻会被察觉他们甚至给我举几位被清除前成员做例子…哪怕写在纸上哪怕用新发明语言也不行！我想想我想想观众途径序列2是洞察者序列1是作家这里有谁符合相应特征？（注1）嗯我初步有了个怀疑对象那就是聚会召集者。对了还有观众途径序列0它的名称是：空想家！但我不认为这里有谁达到真神位阶否则根本没必要躲幕后当然他们可能有序列0层级神物比如某条途径唯一性也许就是它制造了这个连通大陆东西两岸真实梦境并拥有名称一被提及就做出反应能力。当时我没想那么多震惊之余又问了别的事比如对神灵描述里为什么会有权柄这个词语赫密斯老先生做出了精彩解答。」看到这里发现这页日记已到末尾。忙翻下一页但很快又倒退回来因为之后那则与前面根本连不上。解答呢？是在原本日记下一页还是因为太长懒得写或者没有记录于日记必要？躁狂想穿越过去掐住罗塞尔脖子让他把赫密斯回答告诉自己！当然表面无任何情绪波动也无多余肢体语言。原来观众途径序列0叫空想家这和空想之龙很对应嘛我还以为会是巨龙…空想家更贴近人类认知也就是说服食对应序列0魔药不会必然变成巨龙…序列1作家仅听魔药名称就觉得和0-08那支羽毛笔特点有些相似…黄昏隐士会召集成员方式是依靠一个连通大陆东西两岸真实梦境？日记开头神迹描述吓一跳还以为他们也有灰雾和灰雾之上神秘空间…平复情绪发现这页日记提供有效信息很多很重要。首先知赫密斯远古贤者至少活到一两百年前罗塞尔时期且是那神秘组织成员。其次从罗塞尔对组织名称不可言说描述出发基本确认那神秘组织＝黄昏隐士会。最后知观众途径序列0、1、2名称虽然一时半会用不到但真切丰富自身神秘学积累。说不定什么时候正义小姐就会提相关问题…她好奇心一直都很重…强迫自己忘记缺失解答翻到最后那页日记。阅读同时正义习惯性观察种种细节敏锐发现愚者先生盖在斑驳长桌上黑皇帝牌不见了！赐予了眷者提供相应帮助或者与哪位存在交换了物品？眼波微闪尝试猜原因。更倾向第一个想法因为如果没有愚者提供帮助祂眷者未必能破坏真造降临仪式。可惜爸爸没法看到记载详细经过卷宗否则我就能知道愚者眷者是谁了唔…他个子中等是位男性穿鲁恩最流行双排扣长礼服当时在红蔷薇庄园附近通过这些信息调查也许能锁定目标…但这有可能惹怒愚者祂可没让我揭穿祂眷者身份…奥黛丽不要多想不要好奇也许将来你们会遇到会认识…收回视线。这时克则因最后那页日记内容有些想笑：「三月十六日第一次参加这个世界这个国家贵族舞会。那些小姐和夫人们比我想象好很多在我看过小说里对类中世纪世界都有不洗澡靠香水掩盖恶心体味出门经常踩到屎用容易重金属中毒东西涂抹脸庞等描述。但这里不同她们很爱洗澡香水迷人皮肤白嫩腰部紧勒身材大部分都还不错。我克服紧张和德里洛塞子爵小女儿相谈甚欢聊到我祖上建立功勋聊到我家庄园和现在爵位然后她很礼貌提出要去吃点东西。我当时并没在意想着泡妞这事需要循序渐进可是我到楼下花园散步时候发现她正和富莱斯伯爵长子在没人书房内啪啪啪…日！他们也是第一次见面啊是我黄涛·罗塞尔长得不够帅还是我说话不幽默不风趣？真现实啊！还好那些夫人们对我都不错我感觉得出来她们隐藏热情嘿嘿。」罗塞尔最早还真不适应因蒂斯风格…根据历史记载古斯塔夫家族衰败好几代只剩男爵爵位田地资产也不多直到罗塞尔发迹…想不到大帝也有被抢走女人时候等等我记得罗塞尔有篇日记里提到他上了富莱斯伯爵夫人…厉害厉害…目光下移看剩余两则日记。它们都没什么价值属罗塞尔对庄园生活记载通篇想打猎怀念美食希望获超凡力量和好看女仆。略微后靠边让日记从手里消失边微笑：「你们可以开始了。」正义当即望斜对面太阳：「你摆脱那种循环了吗？」太阳戴里克先诚实点头接着向青铜长桌最上首行礼：「伟大的愚者先生万分感谢您的指导这让我从有救赎蔷薇文字壁画上找到命运天使这个关键点帮助首席破坏了命运循环。」什么命运天使…我什么都不知道…很懵愚者含笑回应：「不错。」

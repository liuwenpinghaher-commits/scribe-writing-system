# 1389 倒吊人 第三十七章 问答

## 打开书
对于自己任务是什么审判休一直都又期待又忐忑。期待是因为她已经选择接受愚者先生馈赠必然会付出相应代价早点知道是什么任务能够避免因未知产生猜测因猜测出现更加强烈恐惧情绪。忐忑则是由于她知道自己获得报酬实在太过丰厚相信最终任务不会简单必定充满危险。此刻听完愚者先生话语她在一颗心终于落回原本位置同时也悄悄松口气。调查红祭司途径三份序列1非凡特性和相应唯一性下落乃至确认原初魔女当前状态确实都很危险属于一不小心就会被什么污染以至于产生可怕异变任务但至少比抢夺唯一性和序列1非凡特性直面原初魔女要好太多。……是愚者先生。愚者克莱恩本打算看向另外一边考虑下又补充一句：小心班西。不等塔罗会众位成员展开联想克莱恩对星星伦纳德道：你任务和月亮类似在围剿玫瑰学派时从他们成员身上搜集欲望母树给予祝福气息和物品这同样很危险。他只叮嘱一句没像之前给月亮埃姆林任务时那样说太多。这是因为伦纳德身上寄生着一位偷盗者途径资深天使祂了解众多隐秘知道外神有多么危险不会任由伦纳德乱来。见伦纳德就要点头愚者克莱恩保持着刚才语气继续说道：在宣扬我名这件事情上你不需要做太多甚至可以不做。作为黑夜教会最有权势二十二位高层之一作为值夜者队伍不多高级执事之一伦纳德要是私下传播愚者信仰很容易出现问题被同事误会发生不必要冲突。但神奇是在克莱恩眼里月亮埃姆林这么做好像就不会被误解。对他周围人和血族来说他做什么都似乎不是太奇怪。也是……星星伦纳德已从之前迫不及待中恢复认识到现实残酷。……这个时候愚者克莱恩补充道：你可以偏向于传播世界事迹以诗歌创作形式。诗歌创作……星星伦纳德本能就皱起眉头竟没有立刻回应愚者先生。……除这些努力提高自身位阶为应对末日做准备。所有任务报酬是一个愿望。……星星伦纳德默然两秒缓慢吐口气道：是愚者先生。愚者克莱恩随即将目光投向一直等待正义小姐：除宣扬我名你任务有两个一是协助审判调查红祭司途径唯一性和序列1非凡特性下落确认原初魔女当前状态二是努力提升自己位阶。任务之一是让我提高序列……正义奥黛丽对这个任务略有些不解。……而且这对愚者先生没什么价值难道是要我治疗世界先生？奥黛丽心中刚闪过这么一个念头愚者克莱恩就补充道：你序列越高越有机会唤醒世界。在这方面你可以借助外部力量帮助赫密斯重新建立心理炼金会是选择之一但需要小心和提防。为此你必须付出一定代价。你也可以放弃之前收到报酬这只取决于你意志和想法。正义奥黛丽再无疑惑沉默一下郑重点头道：是愚者先生。愚者克莱恩目光落到倒吊人阿尔杰脸上：等一段时间你就知道你任务是什么了。……你可以带上海神权杖但在此期间所有海神信徒祈祷都将转移到太阳那里直接指向我。倒吊人阿尔杰虽然还无法准确猜到自己任务是什么但已经隐约有些预感。他略作沉吟就态度端正回应道：是愚者先生。……之后你们每月第一个周一下午依旧可以在这里聚会但不再有召集者。如果需要做私下隐秘小型讨论提前祈祷等待回应。说到这里愚者克莱恩闭闭眼睛道：这次聚会就到这里。……您意志就是我们意愿。……尊敬阿兹克先生：由于一些复杂原因我可能将沉睡很长一段时间很抱歉也许很久没法给您写信了……与此同时他放开一点来自源堡本身限制。……等白骨信使接过书信忙不迭离开源堡克莱恩抬手揉下额角。这倒不是天尊意志已摆脱永眠状态也非他清醒维持得很痛苦而是一种习惯。……斑驳长桌两侧正义奥黛丽倒吊人阿尔杰太阳戴里克魔术师佛尔思月亮埃姆林隐者嘉德丽雅星星伦纳德和审判休以他们加入塔罗会顺序相继又浮现出来。……等到灰白云气上那座奇异光门在望克莱恩招手摄来魔镜阿罗德斯。……他抬起脑袋望向光门上悬吊那一个个透明蚕茧望向蚕茧里面不同肤色同样现代人类。……那一个个蚕茧随之破裂里面人化作光点飞出源堡落向现实世界一些刚死之人。做完这件事情克莱恩低下脑袋看着掌中魔镜道：害怕吗？……不怕。……伟大主人您害怕吗？……怕。说完他迈开步伐拿着魔镜走向奇异光门中间青黑雾气穿透过去。……那一个个破裂蚕茧还在轻轻晃动。

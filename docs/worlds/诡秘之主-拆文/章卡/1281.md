# 1281 倒吊人 第十六章 罪名

## 打开书
哈哈怎么可能一眼就看出是不是外乡人？这该怎么分辨？罗伊强自镇定假装自己正在和同伴讨论黄纸内容。他以话语里潜藏意思宽慰菲尔和帕莎让他们不用紧张和慌乱毕竟除本地人拜尔斯剩下三位也都是鲁恩国民且不含南大陆血统单看五官轮廓是没有任何特殊性。可可是这是一起超凡事件……帕莎略有点结巴回应道。这无法用常理来判断！罗伊心中一凝看了看那些缓慢靠近没有任何表情市民忙低沉喊道：跑！……怎么办？断了一只手菲尔喘息着问道从公告内容看我们大概没法直接离开这座城市。我们需要摸清楚规律从规律中寻找办法。罗伊虽然也很慌乱但还是强迫自己冷静思考免得整支队伍情绪出现崩溃。……那块布告牌以前就有吗？有虽然我很少有机会到市政广场但之前被征入军队时是在那里集合有看见那块布告牌。布告牌应该没有问题也许那两张纸才是关键它们能让书写出来律令具备神秘学意义。帕莎说出自己猜测。……对。而且我怀疑那些律令必须公告出来才会有效果如果我们能找机会撕掉那两张纸相应限制或许就会消失。……试一试吧！如果一直被困住城里就算没被那些市民抓到也可能因各种各样缘由被律令处罚。……一行四人在还算老练猎人帕莎引导下绕大半圈从另外一条街道潜回市政广场。……破坏公告算不算一种违法行为？理论上是……帕莎怔一下道。……8破坏公物；……真有。拜尔斯脱口而出道。……破坏公物会遭遇什么处罚？……初犯是鞭笞。就在罗伊帕莎和拜尔斯思索答案时一道声音从他们后方传过来。……再犯是断手。累犯是什么我就不清楚了。你为什么会知道？罗伊一边警惕握住暗藏匕首一边皱眉问道。……我试过了那没有任何效果公告很快就会恢复。所以你遭遇鞭笞？帕莎有所恍然问道。嗯。那年轻男子神情轻松点头不过因为我同时还犯诈骗罪所以之后又遭受断手处罚。诈骗罪？拜尔斯有些难以理解问道。……简单来说就是我并没有亲自去破坏那张公告而是弄了个假人过去被鞭笞也是那个假人。……等到那只手掌覆盖上皮肤变得正常这几位非凡者才恢复过来又惊又疑又恐惧同时后退几步。……对了忘记自我介绍了我是一个流浪魔术师。刚才犯下诈骗罪和破坏公物罪正是克莱恩。……我最擅长魔术是满足别人愿望你们有愿望想要实现吗？……可以让我们离开贝尔丹吗？当然我会尽力去做这件事情但并不是现在。克莱恩给出承诺。……他愿望说完了你是什么？……让我手恢复。菲尔试探着说道。好。克莱恩将目光投向拜尔斯取出他手。……过来。克莱恩随即笑着对菲尔道。……扯下绑带。克莱恩继续吩咐道将断手安放在原本位置提醒你一句不要反了要不然等下得砍掉重来。……你愿望实现了。克莱恩后退两步笑着说道。谢谢……菲尔有些呆愣回应道。……你们愿望呢？我想知道我家人现在在哪里。……刚才那个问题答案是什么？……贝尔丹戈罗林墓园……的守墓小屋。……谢谢。……伟大主人我回答得足够善良吧？嗯。克莱恩微不可见点头将目光投向剩余那位女士。……我愿望是请您保护我们直到我们活着离开贝尔丹。……聪明。克莱恩笑着赞一句你愿望将得到实现。那我们要付出什么样代价？我是指观看魔术报酬。帕莎忙又问道。你们愿望本身就是代价。克莱恩简略回一句然后若有所思问道如果某些事物你们明确知道是假但主观上愿意利用它们那应该不算是诈骗对吧？肯定不算。这实际上是双方间一种游戏。有明确认知自愿行为肯定不属于诈骗。毫无疑问不是。……很好这就是正常民众认知。……女士究竟出了什么事情？……战神教会大牧首拉里昂出逃我正在追踪祂。……我来到贝尔丹后收到一份新情报。情报显示拉里昂出逃时带走一件封印物。0-02。

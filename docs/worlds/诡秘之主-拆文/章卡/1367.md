# 1367 倒吊人 第十五章 死亡烙印

## 打开书
茫然徘徊于永暗之河死神萨林格尔望向被灰白蚕茧包裹克莱恩。祂那双苍白火焰即将熄灭眼睛内瞬间映照出别于克莱恩胸前鸟型黄金饰品。下一秒低沉吼声从祂腐烂口中传出回荡在河流上空让整个卡尔德隆城出现明显摇晃。那条时而卷起时而下落时而深暗时而苍白支流随之高涨向着石制阶梯尽头向着克莱恩疯狂涌来。……灰白洪流一波又一波拍打起克莱恩身体却无法摧毁他身边蚕茧。死神萨林格尔腐烂身躯一步又一步走到支流边缘可怎么都脱离不了只能站在那里疯狂嘶吼。……这位死亡执政官似乎分裂成多个自己在永暗之河两侧苍白石柱间茫然徘徊。……那手掌穿透灰白蚕茧抓在他小腿上。……它攻击竟然可以无视源堡气息！……这水鬼是克莱恩·莫雷蒂！……在这四个水鬼拖拽下克莱恩身体渐渐脱离灰白蚕茧沉入洪流之中。……然后他毫不犹豫探出手掌调用源堡力量通过自己与历史投影间联系从后者身上窃取走一件物品。……那溺死在永暗洪水中身影随之消失。可以无视源堡气息说明那四道身影真是我……可我怎么会被困在永暗之河支流内永无止境徘徊？四道身影四道身影……克莱恩表情沉凝轻敲起斑驳长桌边缘在笃笃笃声音里有了灵感。与四和魂灵死亡对应事实是他已经死去四次复活四次。当然在成为诡秘侍者后四次复活机会又重置了。每死亡一次不管是否成功复活都会在永暗之河内留下印记？我死四次所以有四道身影徘徊于永暗之河两侧？克莱恩大致把握到其中关键随即在心里感叹道永暗之河不愧是源质不愧是死亡永眠终点尽头深暗等事物象征……这就是女神说于我而言有不同寻常……基于这个推断克莱恩对众多阿兹克身影和徘徊死神萨林格尔有了全新认知：……阿兹克先生在不死者阶段在后来追寻记忆历程中确实死过很多次只是每次都活过来。依照现在情况看不死者虽然不死但也有很大隐患等到死亡次数多了说不定哪一天本体就被吸引到永暗之河内成为永恒徘徊身影之一了……萨林格尔身影只有一道……这说明容纳了唯……而要想解决这方面隐患有两个办法一是补齐阿兹克灵魂让祂不再重复之前二是帮助黑夜女神成为旧日掌控住这条永暗之河。呵呵说不定这又是二合一选择：女神成为旧日也就没必要再利用阿兹克先生那一半灵魂。克莱恩收敛思绪将注意力放回这次目的上。他进入卡尔德隆深处不是要解决死神萨林格尔死亡烙印让祂再也没有复活希望而是取一些永暗之河河水。很显然漫出河流虚幻潮水不行这只是弥散气息而非河水本身。还有融合灰白雾气河水也不行不够纯粹应该达不到预想效果。这么看来只有趁支流变回深暗状态时才能取河水呵主干根本进不去那灰白雾气肯定又是坚固屏障。克莱恩根据自己分析迅速拟定一个计划。那就是先不靠近永暗之河不引来死神萨林格尔注视等到支流回落变得深暗再直接过去任由自身四个死亡烙印拖着历史投影沉往河底。在这个过程中历史投影抓住机会用鸟型黄金饰品取一些河水然后意识转移回源堡内依靠窃取能力和两者间紧密联系拿走鸟型黄金饰品。……他身周源堡气息逐渐浓郁化成一个薄薄蚕茧。没用多久克莱恩又抵达阶梯尽头看到那条流淌于虚无之中永暗之河看到它两侧苍白巨柱和徘徊于支流边缘无数模糊身影。……就是现在！克莱恩身影一闪窃取走距离出现在死神萨林格尔看不到角落。没有意外随着他身体浸入永暗之河河水一只只苍白手掌立刻穿透源堡气息抓住他双腿和双臂。……抢在彻底失去知觉前克莱恩脖子处钻出一条又一条透明扭曲蠕虫它们飞快爬到鸟型黄金饰品旁边簇拥着它将它抬起来准备汲取永暗之河河水。……那是一只被永暗之河支流完全淹没悬浮于水中巨鸟。这巨鸟体表覆盖着苍白火焰和神秘花纹织成羽毛但已被永暗之河消融很多裸露出部分漆黑腐烂留着淡黄脓液皮肤。……他意识立刻回到源堡内将鸟型黄金饰品窃取回来。……水中也有危险啊……不死鸟始祖格蕾嘉莉这位古神已完全沉入永暗之河……如果女神真正容纳死神途径唯一性萨林格尔若是不能趁机在祂体内复活应该也会像格蕾嘉莉一样沉入水中而格蕾嘉莉死亡烙印将因此进一步消融……克莱恩无声感慨几句将行动方案做相应修改。……等待一阵等到死神萨林格尔转过身体沉重缓慢往河边走去克莱恩猛然窃取走距离出现在对方眼前。……但是这片光芒笼罩住却不是克莱恩和鸟型黄金饰品而是死神萨林格尔。嫁接！抓住这短暂机会克莱恩历史投影内爬出灵之虫们将鸟型黄金饰品抬起来。……下个瞬间克莱恩意识回归源堡内抬手将饰品取回来。……对源堡主人来说这个任务确实不怎么难只要不鲁莽以本体进入完全可以依靠一次次失败来累积经验弄清楚情况。而若非永暗之河支流里同时存在两个死神一个徘徊一个沉底克莱恩也不至于失败两次。

## 这场戏有没有翻

- 己之死烙无视源堡气。

- 唯容纳唯一性者烙单道。
- 须深暗纯水；潮／融雾水不行。
- 嫁接可把「罩光」接到敌身。

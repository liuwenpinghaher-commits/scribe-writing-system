# 528 旅行家 第四十七章 默契

## 打开书
酸柠檬街48号蔚蓝之风旅馆外面。穿着厚夹克和阔脚裤烈焰绕路返回贴在墙角好久没有移动一步犹豫着要不要趁机逃跑不再面对格尔曼那个恐怖疯子。和班西港遭遇战不同这次他藏在较远处屋顶能将整个战斗区域尽数纳入眼底所以在辅助格尔曼并对抗血色荆棘同时终于看清楚那个疯狂冒险家战斗过程把握住对方表现出来非凡能力和特异之处。纸人替身火焰闪现精神冲击太阳领域神圣光芒搓动手指打出空气子弹彻底伪装成另外一个人能力以及变化了几次外形并吞噬掉斯考尔神奇手套数量超乎想象而且有几种还无法兼容这不是单纯序列加一两件神奇物品能够解释…还有那发自灵魂深处饥饿感也说明一些问题…飓风中将那只手套蠕动饥饿！船长特意提醒过我们那手套可以放牧多位非凡者灵魂从而使用他们能力…心里流淌过之前思考内容和最终判断：格尔曼是蠕动饥饿现在主人！并没有因为对方是依靠强力神奇物品才显得如此可怕就心存轻视反倒愈发敬畏。这一是大部分神奇物品能发挥多少取决于本身水准格尔曼要是没有一定实力和丰富超凡领域战斗经验就算拥有蠕动饥饿也没办法在十来秒内就解决掉钢铁加冷静斯考尔。二是他船长冰山中将从秘密渠道获知飓风中并没有死在风暴教会手上而是于逃跑途中被某位强者快速击杀。巅峰时期飓风中将有多么强大不缺乏了解明白一位可以轻松解决他强者究竟处在哪个位置那等于站在所有海盗顶端王者而且还是其中最强大最恐怖两位五海之王和神秘女王！虽然有突袭因素但也最多下调一些评价不会比不死之王差多少强过地狱上将和血之上将…蠕动饥饿现在归属于格尔曼说明要么他就是杀掉齐林格斯强者要么他背后还站着一位四王级大人物无论哪种可能都比原本想象预料更加可怕！身体紧绷实在不想去面对那流着疯狂血液冒险家。呼…吐口气觉得自己在这里犹豫太久必须尽快做出决断。格尔曼会占卜而且对这方面能力相当自信我阴影斗篷又在他手上逃跑不仅难以成功而且还会激怒他…阴影斗篷是少见神奇物品…一咬牙齿从墙角转出进入旅馆大门一路来到那间豪华套房外面。谨慎等待几秒观察下动静拿出钥匙打开房门。看见屋内一片昏暗煤气壁灯未被点燃清晨不算明亮阳光从窗口照入洒在面朝房门格尔曼身上。这位冒险家已换回原本打扮黑色呢制大衣配深色长裤手里拿着半高丝绸礼帽右脚抬起搁在左边大腿上。略微后靠面容因背对窗户显得阴暗模糊唯有那双深棕色眼眸异常清晰淡漠平静注视着门口。不自觉就低下脑袋干笑两声道：「按照你吩咐我绕到了几家报社所在地将烈焰击杀钢铁血色荆棘和斯考尔消息写在纸上扔了进去。当然在这条新闻内我拥有一位强大帮手他神秘未知是一个顶级冒险家是一位老练资深赏金猎人。」克轻轻颔首露出礼貌笑容：「很好。」松口气四下张望几眼看见那张孔雀蓝底色飞毯。愣几秒疑惑问：「钢铁和亨特利脑袋呢？」平缓开口：「没拿。」「没拿？」惊愕脱口「那我们赏金怎么办？」只要有钢铁和血色荆棘脑袋他就能通过一些有关系有背景人拿到相应悬赏虽然这会损失百分之十五到三十金钱但作为一名海盗不可能自己去领取只能采取这种方式——军方和教会用悬赏鼓励海盗们自相残杀不意味着他们会放过送上门来礼物。让他没想到眼里疯狂渴求着金钱格尔曼居然没取走钢铁和血色荆棘脑袋等于自动放弃悬赏。没有回答他指了指地上飞毯：「你是合作者你有两个选择。一是3000镑现金二是这个飞毯。给你5秒钟时间考虑超时视为放弃。」3000镑现金或者飞毯？这飞毯好像只有悬浮和飞行两种能力而且速度不算快用处不是太大…不对在海上对水手途径之外非凡者来说这类物品很珍贵至少不用担心船沉以后怎么办问题了…一时有点犹豫。然后听见格尔曼数道：「3，2…」！心头一惊慌忙开口：「飞毯！」点下头：「好。」知道对方很有信誉终于放松下来半是嘀咕半是抱怨问：「你怎么没数5和4？」说好是5秒！表情不变回答：「心里数了。」心里数了…深吸口气露出扭曲笑容。克慢慢站起手腕一抖扔出掌中礼帽让它稳稳挂在架子上然后走向卧室。……海浪教堂。以晨祈名义入内阿尔杰见到教区主教乔戈里将昨晚遭遇原原本本讲述一遍唯一做了修饰地方是把血族麻醉气体改成黑夜教会沉眠符咒。乔戈里赞赏点头：「为了信仰敢于深入敌窟承受生命威胁这样行为值得褒奖你是真正风暴侍者。昨晚我们抓捕了五位非凡者当场击杀了两位麦维提亨特利和斯考尔也因此身亡这三位海盗脑袋要么已不会再出现要么就在我们手上政府悬赏金将归属于我们。这总计超过1万镑你将获得大部分也就是6000镑。不要推辞主告诉我们为信仰而战者不可使其困顿。」「风暴在上！」一脸激动握拳捶击左胸。虽然他和世界没有约定怎么分战利品但相信两人对此是有一定默契比如各自狩猎海盗身上事物互不干涉悬赏金因为要通过教会洗白两人平分。至于因蒂斯弗萨克等国家和组织赏金没有奢望过因为每一次领取都需要交出目标完整尸体或脑袋所以只能挑选其中一家唯有背景深厚与各国各组织关系融洽人才能全部拿到。3000镑是属于世界…我一下少了3000镑必然会引起怀疑嗯得找机会买件神奇物品这种东西因为稀少往往都有溢价急需时候更是如此3000镑买报5000镑没人会怀疑…再把老奎因那里得到东西卖一卖这个账就平了…迅速就有后续处理办法。……知道将有3000镑入账克心情愉快坐在愚者那张高背椅上思考起一个严肃问题。那就是放牧钢铁后根据承诺他将释放蠕动饥饿内一个灵魂。他们非凡能力都很有作用在没找到替换前释放相当可惜嗯…而且我已经释放了那个无面人这次似乎没有必要…犹豫迟疑不舍情绪在心中发酵让他许久没有做出决定。过一阵往后一靠吐口气。「不能自己欺骗自己。」摇头失笑因下定决心一身轻松。将遵守承诺释放一个灵魂。之前无面人是因为他想获知相应情报才提前释放实质已经是等价交换。释放哪个呢？正义小姐买了心理医生材料买了5500镑神奇物品再有钱应该也出现资金紧张这个时候卖心理医生非凡特性不是太合适嗯她还差我眷者2000镑二三月份偿还…否决之前想法打算先释放那个梦魇。作为前值夜者对这个领域非凡者总是有些印象加成和感情偏向所以没其他因素情况下选择不难做出。平复下情绪拿起之前带入灰雾之上人皮手套闭目感应起那一个个扭曲虚幻灵魂。没有犹豫释放了梦魇。

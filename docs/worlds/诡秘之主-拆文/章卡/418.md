# 418 无面人 第二百零六章 心愿

## 打开书
博学者——名强；守知者／侦探偏知识推理附格斗器械；序6质变超凡战。占卜家节点＝序7魔术师。热咖不探密：「斯坦顿放松不紧？」艾拿烟斗「介意？」（贝克污染再二手烟…）「助思考？」「习惯早餐后。」叹：惧紧无助威胁——何不轻松大脑更活；助手太担心致致命灾。看卡斯：对手欲望使徒禁强情绪。轻笑：「并非无别法锁定。」何？自嘲喜安乐椅：「恶魔擅危预感不善占卜预知；查复仇目标必主动调查——怎知侦探贡献怎准锁定？打交道留痕＋机械心模糊影像＝线索。袭我须知住址作息有无官方护——观察打探交互＝痕迹。格言：凡走过，必留下痕迹。」罗塞尔…第二次听（上次廷根）。卡斯叹敬佩观察思维。艾：「各擅；格斗我败你；夏洛克亦想到——优秀侦探。」克惭愧挤笑：「你名副其实大侦探我差远。」「谦虚年轻人。」「从这些入手动用资源渠道。」克强笑——贝克渠道三分一来您！智慧之眼外仅马里奇莎伦／埃姆林乌特；机械心护排莎伦马里奇；埃半母神信徒可。卡斯无问题。奶油吐司咽：「提过封印开启——能对付使徒？」「是；围恶魔犬关键。代号1-42。」1级高度危险有限利用贝克仅存一二？「何物能力负？」艾：「夜教会机密不清；原不在贝克连环案急送。据说银全身盔甲染小片干暗红血；曾毁小城死超十万。」「诅咒盔甲？」凝摇：「或非；有称疯狂／嗜血盔甲；教会猜血或更古神灵。初无异常当古董贩藏；接触者相继死恐怖近分尸；后以之为心死亡外扩无需接触毁城。第五纪初值夜处理。」赞知识神知史多。卡斯忧危险？「夜教会有正确封印；能不接触尽量不。」餐后入曾战起居；卡斯先盥洗。克望背：「她似仲裁人途？」艾：「观察出色。」「王室军方古老贵族严持；卡斯有背景？」笑：「很显然。到此程度不主动提＝不方便。」目含笑言外：你不也？干笑坐。卡斯来续讨使徒——神色黯：「最危事件；不知能否活；若被杀望墓碑有句：她有一个伟大的母亲。」刚硬多温柔。艾同感最危敌；笑：「若我死你们活——愿否送遗物伦堡知识圣殿？」勿立Flag！竭力：「无问题希望永无此日。」艾好奇：「你呢？被杀有何心愿别人完成？」…复活我！叹：「望安葬风光不错墓地；尸最好完整；洒圣水鲜花…」核心：不要火葬！三人沉默——门铃叮。伊康瑟发倔挤帽缘乱；未带阿罗德斯。克想有机用魔镜看忠实仆人反应。伊立门未入语速极快：「有『欲望使徒』的线索了！」

## 这场戏有没有翻
翻了。开头轻松对使徒；章末墓碑心愿立Flag、门铃报有线索。翻的是心愿落地成行动钩，不是恶魔家族展开。

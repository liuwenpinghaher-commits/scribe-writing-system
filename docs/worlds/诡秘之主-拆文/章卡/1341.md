# 1341 倒吊人 第七十六章 同时

## 打开书
这一刻奥黛丽甚至怀疑命运安排并不是让自己前往赫德拉克村庄调查巨龙崇拜风俗而是让自己察觉到不对从而产生抵触在赫德拉克村庄周围区域使用虚拟人格能力悄然引导两个哥哥不知不觉改变想法被这条心灵巨龙发现奇迹之城利维希德……哪怕站在被安排一方奥黛丽也忍不住对此产生敬畏之情……要知道奥黛丽这位序列4操纵师在当时都觉得事情发展符合自己预期完全满足自己希望没一点警惕。……这里是许多心灵拼凑起来梦境迷宫即使设下陷阱那位亲自降临想找到这个房间也需要一段时间而我不会停留太久。……梦境迷宫……这是织梦人一种非凡能力或者说质变后能力？奥黛丽收敛住思绪沉稳问道：你想知道什么？……我叫艾瑞霍格目前仅存三条古龙之一。……你在哪里发现利维希德？一本叫做格罗塞尔游记书里传闻它是巨龙王安格尔威德亲手制作。……格罗塞尔……艾瑞霍格明显没听过这个名字重复一遍后追问道那是怎样一本书？……那本书里有一个近乎真实世界同时它能将符合条件或献上自身血液人吸入书内让他们生活在那个世界中。……那个书中世界有集体潜意识海洋吗？有。奥黛丽非常肯定给出答案我见到那个奇迹之城利维希德就在书中世界集体潜意识大海深处。……在那个利维希德你看见什么？一个布满巨柱城市一座座恢弘宫殿。另外我还进入巨龙王居所那里能让每个生灵内心声音直接回荡在周围我称呼它诚实大厅。诚实大厅尽头巨龙王神座后方有一扇古老神秘青铜大门它不知道封印着什么总之非常危险我根本不敢靠近。奥黛丽说是完完全全真话只是没提世界先生星星先生和自己那些猜测。……利维希德……这些石柱和宫殿以灰白为主落在岛屿般地基上与奥黛丽刚才描述奇迹之城利维希德一模一样。不这似乎就是奇迹之城利维希德。……灰雾之上古老宫殿内一道人影笼罩着灰白雾气坐在斑驳长桌最上首愚者位置静静注视着代表正义那颗深红星辰。……听说了吗？最近一个进入乌托邦人是一名车夫他送一位来自乌托邦商人去码头区时只是拐两条街道就发现周围变得陌生。有必要提醒一下贝克兰德所有车夫嗯最好将乌托邦与间谍画上等号方便他们理解。进出乌托邦方式真是让人恐惧啊。对有时候我甚至怀疑乌托邦入口能出现在任何一个地方。这肯定存在一定限制没有我们想象那么无所不能……要不然我只是去趟盥洗室就会发现自己到了乌托邦。从目前总结出来规律看这在理论上是成立。……除非有半神半人存在始终注视着我否则我很难避免返回乌托邦命运也许我洗完手后打开盥洗室门就会发现外面是乌托邦鸢尾花旅馆……不普通半神可能都无法阻止这种事情这简直不像是人类可以完成已经无比接近神灵……文德尔瞬间……我愿意上庭作证。我愿意上庭作证。……

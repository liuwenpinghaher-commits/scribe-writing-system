# 1275 倒吊人 第十章 流浪魔术师

## 打开书
看到眼前这一幕卡特琳娜身体不受控制向后退一步脑海内一片沉默。隔了两秒她嘴巴自行张开发出男性声音：哟小乌鸦。不等对面那年轻男子回应卡特琳娜自顾自笑道：只来几个分身啊会不会太瞧不起我了？难道你是邮差专程给我送非凡材料？说吧有什么事情想要合作？我并不是太痛恨你毕竟当初事情是那个偏执狂一手谋划主导者是亚利斯塔·图铎你只能算是从犯。……一听到你声音我就有点不想合作了这样吧你让索伦和艾因霍恩出来和我谈。啧啧这么多年了还像个孩子一样任性你还记得你还是个婴儿时候负责抱你是谁吗？烧掉你头发又是谁？红天使恶灵一点也不退让嘲讽道。……幼稚。见阿蒙真没有停留意愿红天使默然几秒在对方走出房间前操纵卡特琳娜身体嘿一声道：不要以为我不知道你想做什么但没关系既然在补完主事情上你和那个偏执狂想法并不一样那就有合作余地。阿蒙停住脚步半转过身体望向被红天使恶灵附身白之魔女卡特琳娜。……托比你这啤酒是不是加太多该死水了？一个戴着破旧鸭舌帽男子接过杯子喝一口忍不住开口抱怨一句。还记得之前禁酒令吗？奥利奇有酒给你喝就不错了！我听说禁酒令很快就会解除因为费内波特粮食很快就能送进来还有弗萨克和因蒂斯将赔偿大量粮食！我只能说但愿如此愿主庇佑。酒吧老板托比刚做出回应就听见大门打开声音。……一杯南威尔啤酒。那男子摆出好几枚铜便士。你是外乡人？是个魔术师？对最擅长魔术是让人们愿望得到满足。我听到什么？满足人们愿望！主啊这里有个冒充神灵家伙！那只是一个特别魔术。那你满足我一个愿望吧让这个吝啬老板请我喝杯啤酒。好。穿着黑色长袍年轻男子抬起右手在桌上轻敲一下。……托比你认识他？不认识。老板托比就像看傻瓜一样瞄奥利奇一眼。……奥利奇不太确定抬起杯子小心喝一口以试探托比是否让他付钱。你怎么办到？我说过一个特别魔术。那年轻男子悠然喝口南威尔啤酒。……我敢打赌你和托比之前肯定已经商量好你敲桌子动作是在说啤酒由你付钱。你可以另外再许个愿望。那位流浪魔术师毫不在意回应道。我和我兄弟家在之前一次轰炸里倒塌正在重建我愿望是它在我返回前就恢复原来样子。挽起袖子男人略显得意说道。……好了你愿望已经实现。……我没喝多少酒啊……托比那该死家伙往酒里掺那么多水！奥利奇嘟囔出声一副自己已醉出幻觉模样。真的真的……他不断喃喃自语就和疯一样。……我愿望实现那个魔术师那个魔术师……我魔术是实现你一个愿望。他侧头瞄眼不远处黑夜教堂道。……我愿望是让我爸爸叔叔和哥哥活过来我不想要他们抚恤金……我刚才是在开玩笑妈妈说过那样愿望就算神灵都无法实现……我只是想要想要爸爸再抱我一次……爸爸……小女孩猛然前扑投入那个温暖怀抱我好想你啊……转眼到周一灰雾之上古老宫殿内塔罗会成员们同时浮现整齐向愚者先生问好。……倒吊人目前已经是风暴教会枢机主教负责罗思德群岛教区；正义虽然暂时与心理炼金会失去联系但也有成为评议团委员资格了；太阳是白银城六人议事团长老；月亮是血族伯爵；星星是黑夜教会值夜者高级执事……除魔术师和审判还只有序列5塔罗会其余成员都已经是半神是神秘世界不同势力高层了。而魔术师得到亚伯拉罕家族支持有很大希望在年内晋升序列4秘法师。也就是说目前实力提升最困难是审判她只是军情九处中高层之一要想成为半神难度很大。笼罩着灰白雾气愚者克莱恩迅速收回目光在心里自嘲一笑……他随即对塔罗会众位成员轻轻颔首道：开始吧。

## 这场戏有没有翻
翻了。开头小乌鸦嘲合作余地；酒吧愿望魔术真；小女孩求抱父；章末塔罗会开。翻的是流浪魔术师＝小愿真满＋大愿心碎＝扮演起。

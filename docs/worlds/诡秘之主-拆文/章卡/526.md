# 526 旅行家 第四十五章 速战

## 打开书
刚从火焰里跃出左掌戴着金色手套克眼中就有两点光芒由小变大由暗变亮仿佛突然划破天际闪电。在用纸人替身吸引到钢铁一伙注意后就已然开启蠕动饥饿并切换至审讯者那个灵魂预备着使用精神刺穿这非凡能力。「啊！」钢铁陡然发出惨叫就像是被人用一把小刀插入头部正在搅动灰白色大脑疼痛感觉从他灵魂深处迸发瞬间占据满所有思绪。与此同时他超凡力量应激性爆发化作飓风卷向四周。半空顿时飘落起美丽梦幻雪花地面不断往外蔓延出透明晶莹冰层道路两旁树木一下挂上白棱接着飞快枯萎露出明显腐烂痕迹。徘徊不去怨念残灵相继被唤醒呜咽着啜泣着尖叫着让附近染上灰白而压抑颜色。自然从半空落下左掌手套绽放出太阳直射般灿烂光华。张开双臂后仰起身体仿佛在拥抱什么。脚跟刚刚踩到寒意袭人地面上方就落下一道纯净炽烈粗大光柱。这神圣辉芒笼罩钢铁照亮他黝黑皮肤结实肌肉如同粒粒钢珠卷发。光之祭司神圣之光！无声无息间麦维提表情愈发扭曲表层皮肤出现明显融化迹象。这一刻他就像是一截蜡烛被投入燃烧壁炉。比起只是被污染失控主教米勒身为活尸他在面对类似攻击时更被克制遭受伤害更为严重！飘零雪花随之停止地面冰层飞快溶解挂着根根白棱树木显露出本身棕色。这声势煊赫光柱毫无疑问引起血色荆棘和斯考尔注意前者脸色陡变手掌探向暗袋就要掏出施法材料以居高临下优势搭救钢铁。就这时他目光内突地跳出一只纯粹由火焰构成乌鸦。一只两只三只…数不清火鸦仿佛赤色星辰占据满亨特利视界它们从四面八方飞来扑腾着翅膀密密麻麻炽热高温。心头一颤眼神几乎凝固手掌当即改变方向抓出另一种材料。刷！往自身上方抛洒出一丛细小淡蓝粉末口中则用古赫密斯语低沉念道：「海浪！」那些粉末瞬间膨胀化作一道道深蓝色浪花向着周围席卷开来。它们与火鸦相遇发出滋滋滋声音制造大量白雾。之前爆炸火浪已稍有平息斯考尔透过残余赤红看见皮肤如蜡融化血肉寸寸消解钢铁看见侧对自己披着黑色斗篷陌生男子。没有惊慌就像一条失去这方面情绪冷血毒蛇平静抬臂猛然下压双掌。瞬息之间他看见那脸庞消瘦表情冷酷年轻男子身体变沉动作放缓似乎被折断用于飞翔翅膀而钢铁开始挣扎侧翻要躲避第二轮神圣之光。紧接着发现对方失去重量和厚度再一次变成薄薄纸人被无形力量压至地面浸入冰雪融化后泥泞。克从另一个位置凸显出来右手拇指和中指连续搓动边往前冲边打出三次响指。啪啪啪！身前太阳鸟形状暗金色胸针表面有光芒连续闪动为空气子弹附加上净化力量。砰砰砰！这三枚子弹连接紧凑速度极快相继命中动作还颇为迟缓钢铁打在他右胸穿透半融化皮肤和血肉制造出一个夸张狰狞伤口并有金色火焰向着四周扩散。嗖嗖嗖！斯考尔扔出一把又一把手术刀但却被克杂技般灵巧变向全部躲掉。这个时候钢铁已缓过来手掌一撑重新站起直奔敌人而去要发挥最擅长近身肉搏能力和身体奇异不怕击打特殊。脚下再有冰层凝结拳头已带上腐烂气息。然后他又一次看见克深棕色眼眸内有两道闪电如子弹般射出照进自己瞳孔。下意识仰头咬紧牙关鼻孔口中耳朵处全是往外沁出血液夹杂着之前融化皮肤。克打出空气子弹同时就已经改变放牧灵魂。依然是审讯者依然是精神穿刺！对付活尸这种体如钢铁非凡者灵体层面伤害更为有效！连续打击让钢铁在身体短暂僵硬同时失去理智枷锁脸上长出一根根黑色坚硬长毛牙齿和指甲在不断变长皮肤蠕动着想要聚合从黝黑淡化为苍白就像一头真正疯狂渴求着鲜血活尸！趁此机会已然欺近身体一矮从钢铁右侧擦肩掠过顺手将掌中紧握一个物品塞入自己制造出来那个狰狞伤口塞入对方体内。那是绑着几枚黄铜色普通子弹玻璃瓶里面装着提前准备好大量太阳圣水！噗！未做停留让斯考尔控制尝试又一次失败。脚跟一旋转到钢铁身后彼此背对着背。啪！抬起右手抢在钢铁掏出那个玻璃瓶前打出响指。砰！轻微爆炸声响起赤红火光腾跃粉碎了本就脆弱玻璃瓶大量太阳圣水顿时倾泻到钢铁体内。这位悬赏金额高达6000镑知名海盗一下僵硬在原地喉咙发出荷荷荷痛苦呻吟。扑通一下跪倒在地体内不断有黑绿色气体往外扩散消失于空中。看到这一幕斯考尔目光发沉当即掏出一枚黑铁色符咒低念出一个古赫密斯语单词：「尖啸！」那符咒霍然崩裂消失不见完成献祭。无形音浪海啸般荡开几乎不分先后钻入周围每一个人耳朵里。克脑海嗡一下鼻端凉飕飕有鲜血在沁出飞毯上血色荆棘更是凄惨脸庞扭曲身体抽搐倒下连惨叫都发不出来倒是远处屋顶上烈焰未受什么影响欣喜扔出一团反复压缩过炽白火球。那火球落在毫无反抗亨特利身上轰隆一声爆开。血肉猛地往外飞溅手指小腿脑袋等东西缠绕着烈焰落向下方飞毯随之失去控制缓缓沉降。斯考尔则趁这机会扭头就跑毫不犹豫。但是愕然发现那在10秒内就近乎解决钢铁恐怖男子没有一点耽搁回转身体追过来！怎么会？这是上将制作尖啸符咒！顾不得去考虑为什么拼尽全力狂奔往另一条街道。就这时脑袋突然被人重重敲一下撕裂般疼痛让他浑身痉挛。克眼中闪电光芒退去右手抬起又打出一个响指。砰！一枚空气子弹越过十来米距离准确钻入斯考尔后脑。没有钢铁那种非人类承受力眼前顿时一黑缓缓软倒。克几步赶上去探出左掌让欢欣雀跃蠕动饥饿开始享受大餐。我听过真实造物主声音承受过门先生呼救在这方面抵抗能力很强就连怨魂本身尖啸都可以快速缓过来何况只是一枚符咒…无声自语看着斯考尔身体变成血肉投入蠕动饥饿裂开那张嘴巴里。几秒时间后蠕动饥饿满意停止快步回到钢铁身旁。这位活尸惨遭净化虽未被打破脑袋但也失去生命。跨前几步拾起落在地上孔雀蓝飞毯用它裹住钢铁身躯并提起来。回头望眼混乱香树大道15号听了听活尸和傀儡失控动静感受到代罚者们正在往这边靠近拉拉斗篷帽子往那个方向微微鞠躬行一礼。啪！手指一搓周围碎纸全部被点燃腾起赤红焰柱。火光映照下身体虚化连带物品一起变成阴影消失在原地。至于正缓慢析出和凝聚斯考尔亨特利非凡特性没去看也没去管。贪婪会让人落入不必要危险之中现在收获已经足够！留下部分代罚者处理失控活尸傀儡被同伴击伤海盗和抓捕住非凡冒险家后科尔多瓦领着剩余人等飞快赶到这边可却只能看见洒了满地碎尸零落手术刀和枯萎行道树分辨出正缓缓退去太阳气息和来源于血肉深处邪恶感。

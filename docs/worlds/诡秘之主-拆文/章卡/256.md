# 256 无面人 第四十四章 “2-081”

## 打开书
铁面具挡住小丑没绷住的脸。药师自顾自：喜欢贝克兰德站街女郎，音乐厅戏剧场大街小巷，职业兼职女工女仆不同风味，西区偶尔破产贵族小姐。克莱恩赶紧问老师有没有意见。没有。教完草药一脚踢出门游历大陆，没告诉后续材料去哪找。精灵之泉髓质结晶务必告诉我，可先买再加价。能换药师配方吗？不行，只能教导学生。生命学派规矩？或对着隐秘存在立过誓。药师嘿一声：可以告诉你贝克兰德哪里弄到药师配方。克莱恩又问有没有治精神狂乱的药剂，演给保镖看，让她更信他是真实造物主的潜在疯子。镇静剂十苏勒一支，下次带四支，比医院有用，加了灵性材料。廷根地下医院货一到二苏勒，值夜者代罚者机械之心流出四到五。问智慧之眼能否再来。可以。留心贝克兰德早报，第五版恩斯特商行收购货物广告，即第二天晚上八点这里有聚会。敲门：报价四个数字，重、轻、间隔长、间隔短，后面无意义。不属于官方又没组织的非凡者：躲官方、抗失控与疯狂，太多同类死在这两件上；避开了还缺材料缺知识。神秘匮乏的时代。克莱恩有倒吊人的岛、太阳的白银城，不说。开口要神奇物品，不要太负面。智慧之眼有一些。要比自己强，不是提升格斗，最好有神奇能力。一件曾经的代号是2-081。表面疑惑，心里惊愕：查尼斯门后流出来的？七神教会搜集封印物，0最危险据说可毁国家甚至世界；0与1互相通报不重复，2与3各教会各自排序。克莱恩不懂通报家底，或是战略威慑。2-081出自知识与智慧之神教会：让你了解很多，辨识敌人非凡能力擅长与缺陷，有几率一定程度上模仿，对手越强失败越高，成功也与原版差很大。超限定时间脑袋高速运转会变成白痴。药师劝他总讲收藏迟早被抢。智慧之眼：怎么知道不是钓鱼执法，罗塞尔的词。6800镑买的，这等级四千到两万，有钱也买不到，不卖。那说这么多做什么。真正推荐：胸针，驱邪净化太阳领域部分法术，戴上永远南方炎热夏季；可变形状的帽子，水下至少半小时，水与风类法术，渴望水，行走大地越来越弱。一千五到三千五，翻倍也不一定买到，三十年才几件。克莱恩：考虑一下，而且我现在也没那么多钱。杀人案还没上街。

## 这场戏有没有翻
翻了。还想换配方培养帮手。翻的不是镇静剂贵，是2-081不卖、只拿来炫耀。收在没钱也问了价。胸针帽子记下，街上的阴风未起。

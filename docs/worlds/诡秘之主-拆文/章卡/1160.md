# 1160 逐光者 第十一章 倒数计时

## 打开书
做得不错……面对阿蒙表扬他努力挤笑礼貌：谢谢。坦白讲比起夸奖更希望听咒骂——至少意味距成功已近。当然怀疑就算真逃脱阿蒙也不会气急败坏，以恶作剧之神性格或一方面觉太有趣太刺激一方面又沮丧失望迫不及待进下一回合。能想到用门干扰我是很大进步。阿蒙一点不在意笑：可你不觉得开门时我会处相对警惕状态其实不那么容易被意外影响吗？他想了想认真答：最开始这么想后来又觉你应把握我这心理状态相信我不敢在你开门时行动，这时尝试一下或有奇效。在别人认为你不会这么做时真的去做也是策略。上辈子接触过类似思维层次博弈被绕得头都晕。如果我也想到这一层呢？阿蒙笑用指关节推单片底缘。同时还活着属他的那些秘偶相继从身从虚空拿出水晶雕单片戴右眼齐刷刷望向他。看得头皮隐发麻发现与偶联系瞬间中断。虽然有进步但失败总要承受一些惩罚。阿蒙笑转身走向教堂。随祂踏步那些偶一个接一个露笑僵硬倒下——灵魂一次次被撕裂额角血管肉眼可见鼓胀收缩。忍受痛苦立原地缓好阵才勉强平复。过程中一直在黑暗深处既没遭可怕怪袭击也没转隐秘。阿蒙不知何时将城邦内隐秘神力窃取？若尝试自我了断肯定连想法都被偷……还是准备不足对阿蒙把握不够没将祂之前窃取事物入考量……真没想到祂竟放出神战遗迹偷来的白昼……祂过去还窃取什么存体内根本无从了解没法针对性准备……单片是存储窃取事物的容器本身属阿蒙一部分？所以每次寄生都能拿出单片……揉额角重新走入教堂看光门前阿蒙状似随口问：为什么你有这么多单片眼镜平时放哪里？阿蒙抚右眼单片不甚在意笑：你为什么不问我为什么每个分身都有眼睛平时放哪里？……我明白了。恍然点头。阿蒙重新目光投向漩涡未平复光门闲聊般：我总觉得你这次行动实质是一次大型准备而非尝试。在刚才过程里你做了什么小动作？斟酌笑容不变：你猜。我确实有一定猜测你觉得我有没有猜中？捏单片上下缘饶有兴致反问。或许有也或许没有。根本不做明确回答配合走到旁边看祂再伸手按淡白光门。光门再荡涟漪愈剧烈愈夸张。十来秒涟漪渲染周围让光门膨胀足两倍。阿蒙看他一眼示意往前迈。本能回头环顾教堂四周。皮灯照亮区外畸变怪留下一些非凡特性正闪微光——生前并非全部非凡者，原普通人转怪后很大部分力量来自黑暗堕落不属于本身无特性可析。差点忘记。跟随看一圈阿蒙忽然摇头笑。话音刚落一团团非凡特性浮起自行投入祂体内与祂融合为一只剩少量留原地。主动转变成怪物的大部分是能进入城邦暗面的学徒途非凡者与家人。收回视线随口一句。就算相近途非凡特性这么直接吃掉也会出问题吧不是应只能跳相近途更高一阶吗还能向下兼容？看得有点怔问：这样不会累积疯狂吗？何止累积疯狂——怀疑自己这么做不小概率直接半疯。别人会。阿蒙笑：我不会。真是一个Bug啊……心里感叹。然后与光门距离消失。下意识忘掉残余死神途非凡特性与阿蒙一起进入异变光门。无尽深沉黑暗与蠕动线形光扭曲混杂急坠失重感。十来秒发现与阿蒙出现在一片广场上，皮灯昏黄仿佛被无形力量阻止只能照原本一半范围。高空闪电划过周围一下明亮。借闪电见广场四周竖残缺雕像：或双手绑背后或身缠荆棘玫瑰或形如木乃伊直观给人束缚感。这里最初是信仰异种王的城邦。阿蒙像合格导游介绍景点：他们很有趣平时节制安静像苦修士可一旦遇猎物或特定时刻就爆发嗜血残杀欲望——可想象满月之夜这里到处行走着狼人城市。看来异种最初理念也有节制……后来都被欲望母树带歪……借新一轮闪电又多看几眼思索问：异种王形象接近木乃伊？没有祂虽是丑陋扭曲男性却喜欢往身上缠荆棘缠带刺玫瑰。嗤笑一声。……趁机会问：你的信徒会供奉什么样神像？在神秘学里你的象征符号是时钟加时之虫？阿蒙抓下巴：理论上来说我的信徒都是我自己不需要那么麻烦去竖立神像。我的信徒都是我自己……还好现在有达尼兹这个眷者……忽然发现自己和阿蒙某些方面挺像。当然我说我的信徒是我自己属搞笑故事阿蒙说是惊悚小说风格差还挺大……心里自嘲。阿蒙边往前走边续：不过在我父亲那个年代不少人会跟着信仰我有的从时天使名称出发以时钟相关标志塑神像有的根据恶作剧之神称呼用覆盖神秘花纹乌鸦做形象也有将两者结合。说到这里侧头看他一眼勾嘴角：距离最终目的地不超过三天行程了。也就是说留给我时间只有三天了……险些倒抽凉气心理压力骤增有种神经快被压断感。还没判断出阿蒙玩这游戏真实目的是什么还没发现对方驱使自己做什么痕迹——意味无法把握关键找不到脱困真正机会。刚才阿蒙分身表现让明白不真正做好准备在祂面前或连十秒都撑不到。思绪电转沉默下来跟着走出布满毁灭痕迹广场。……街上行人稀少来去匆匆不少房屋布满火烧痕迹的普利兹港内挽栗色长发神秘女王贝尔纳黛将手中报纸放到桌上。那份塔索克报首页刊国王遇刺重磅消息宣称刺客来自弗萨克或因蒂斯。这不是阻止灾难也没有加剧灾难……表情略凝重自语。沉思一阵提起铺着桌布裹起来然后松手指任自行舒展。这次桌布内咖啡杯笔筒报纸等消失出现银制蜡烛等仪式相关物品。随即举行仪式召唤格尔曼·斯帕罗信使。作为合作者认为有必要询问对方情况看后续是否还有事需帮忙。仪式刚结束膨胀烛火里走出提四个金发红眼脑袋身穿阴沉繁复长裙脖子之上没有东西的蕾妮特·缇尼科尔。眼皮微不可见跳一下旋即拿起早备信与一枚金币递给信使。蕾妮特其中一个脑袋咬住信与金币其他脑袋打量神秘女王几秒。移回视线走入虚空可就在贝尔纳黛准备收桌布时这位信使小姐突然又出现。其中两个金发红眼脑袋依次开口：他……失踪了……

## 这场戏有没有翻
翻了。开头还在礼貌谢夸奖；章末异种王城邦导游结束于不超过三天，普利兹港信使回报失踪。翻的是游戏变成倒数计时，不是单片眼镜笑话厉不厉。

- 失败惩罚：断偶联系、偶戴单片僵倒撕魂。

- 单片≈分身之眼／窃取容器。
- 阿蒙可直接吃相近途特性不累积疯狂（别人会）。
- 异种王城：荆棘玫瑰束缚雕像；满月狼人式。
- 阿蒙信徒理论上都是自己；父亲年代有时钟／乌鸦神像。
- 距最终目的地≤三天。

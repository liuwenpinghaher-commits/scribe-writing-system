# 1190 逐光者 第四十一章 把握心理

## 打开书
友善？听到世界格尔曼·斯帕罗问题魔术师佛尔思差点怀疑自己耳朵。她脑海内瞬间浮现出那拼凑起来布满裂纹缝隙和血污X先生脑袋。就在佛尔思斟酌着想编一个好说辞时正义奥黛丽瞄身旁她一眼浅笑望向世界道：让亚伯拉罕家族感受到你友善重要不是你做了什么而是魔术师小姐在信中写了什么。对啊除非我直接出现于魔术师小姐她老师面前否则他对我了解只会局限于各种传闻和魔术师小姐告诉他那些事情……只要她讲故事够好就算与实际情况不符合也没任何关系……克莱恩一下醒悟自己之前思考相应问题时有点钻牛角尖了。啊？魔术师对正义话语有所明悟但又想不够透彻。正义看了看隐者星星等人后对佛尔思说：你需要将世界先生善意传达给你老师为此你可以编织一些故事而不是如实讲述。那我需要怎么说？魔术师主动请教。这并不是她不擅长编故事相反这正是她最拿手事情但问题在于写一本小说让人喜欢和写一个故事让人相信并不等同后者如果能得到一位资深心理学家建议毫无疑问会更加容易。正义在开口前就已经想好书信细节此时语速不快不慢回答：很显然你老师肯定已经注意到你飞速晋升事情并因为X先生之死和各种敏感问题对你参与非凡者圈子抱有一定疑虑和警惕。嗯。佛尔思微不可见点头认同。如果她老师多里安·格雷·亚伯拉罕是个粗心大意对各种迹象异常迟钝人根本活不到现在早就被极光会抓住或者死于其他对亚伯拉罕家族感兴趣势力手上了。正义继续：在这种情况下他依旧与你保持联络教导你知识给予你配方提供你材料说明他一方面认可你人格和品性另一方面也对你成为序列4半神对你从神秘又危险非凡者圈子得到重要情报抱有一定期待。我们要利用就是这种心理。奥黛丽本想用把握这个更加中性词汇来代替利用但略一停顿后还是选择直面自己直面事情本质。见魔术师摆出认真倾听姿态审判星星和隐者对自己接下来话语也颇为期待正义抿嘴唇道：你回去之后就可以写信告诉他说你已成为旅行家让他既对你成长欣喜又对这种夸张晋升速度惊疑然后解答他之前提出那个问题说求购星之虫先生有提及一件事情那就是亚伯拉罕家族血脉中古老诅咒似乎来自一位叫做门先生隐秘存在。这是你老师未曾告诉过你又绝对关心问题。毫无疑问他会对看起来知道你与亚伯拉罕家族有联系先生感觉恐惧想要躲避但是他必然也会渴望了解更多弄清楚折磨亚伯拉罕家族一代又一代人诅咒究竟隐藏什么秘密有没有解决办法。与此同时书信交流而非直接碰面会让他获得一定安全感他可能会转移住处更换身份采用更迂回方式收发信件但大概率不会断掉联系。保持住这种联系一步步透露更有价值内容唤醒你老师渴望并借此塑造世界先生形象让你老师能体会到某种善意。说到这里奥黛丽停下来又一次望向世界。她大概能看出来世界先生向亚伯拉罕家族表达善意是有求于对方但具体要求什么她不是预言大师也没读过格尔曼·斯帕罗心灵自然猜测不到也就没法再往下讲述。克莱恩点头对魔术师小姐嘶哑一笑：等建立起这种间接联系我可能会向你老师提出一个交易请求用解除诅咒承诺换取一些有价值事物。通过魔女特莉丝他其实已经掌握亚伯拉罕家族诅咒解决办法但他不打算以此交换旅法师魔药配方和0级封印物。这一方面是价值不等同相差太多会心生愧疚另一方面则是他并不想就这样将门先生这危险存在放回现实世界那是对他自己对所有无辜民众不负责任。他考虑另寻办法让亚伯拉罕家族诅咒在某种程度上消失也就是说它或许依旧存在但不会影响到亚伯拉罕们正常生活和一定范围内晋升了。这样啊……心灵领域中高层次非凡者真好厉害可以让人不知不觉就按照她安排去做相应事情……和刚认识时相比正义小姐就和完成蜕变一样令人畏惧和敬佩……魔术师看休一眼从对方眼神里似乎读出相同感慨。她思索一下鼓起勇气对世界道：要是我老师拒绝了您交易请求呢？以为我会杀人越货吗？克莱恩用中文心里吐槽一句呵一声：放心我不会对他不利不会采用强迫办法。呼……世界先生虽然可怕一点但还是很守承诺……魔术师缓慢点头：我等下就按照正义小姐建议给我老师写一封信。克莱恩轻轻颔首环顾一圈：你们可以讨论狩猎行动了。隐者嘉德丽雅接过主导权开口：这次行动最大问题是怎么找到那位秘之圣者布提斯？佛尔思顿时想起自己之前与布提斯偶遇事情抬下手：如果我能从我老师那里借来那件强大封印物那我可以携带它经常在贝克兰德闲逛通过非凡特性间聚合将布提斯吸引到附近。呃这也许还会吸引来别学徒途径半神或者密修会首领查拉图或者渎神者阿蒙……佛尔思越说声音越低觉得这办法实在太危险了。若查拉图和阿蒙真出现参与行动其他成员会怎么样她不知道但作为诱饵她毫无疑问跑不掉。隐者点头若有所思：如果只是学徒途径1级封印物非凡特性聚合定律对相近途径吸引力应该就不会那么强了范围将限定在学徒途径半神上而据我所知这并不多甚至可以说少他们绝大部分以特性封印物形式存在。突然不想成为序列4了……魔术师听得眼皮一跳。嘉德丽雅随即将目光投向世界：先不讨论有没有学徒途径1级封印物问题要想让秘之圣者和魔术师小姐偶遇前提是他也在贝克兰德且不那么谨慎经常外出。听到这里星星伦纳德从一位专业官方非凡者角度：这其实并不困难作为学徒途径半神布提斯绝对是极光会高层里负责处理意外支援不同地方那位他有足够机动性呵呵这是蒸汽列车和飞空艇发明后出现一个词汇。只要你们能在贝克兰德针对极光会制造一些事件他有大概率前来。说话间伦纳德看克莱恩一眼。据他所知格尔曼·斯帕罗引起那场拜亚姆城外混战里秘之圣者有出现过捡走一只手套。这是一个办法……正义等人纷纷点头。就在这时世界忽然开口：我提醒一句极光会是崇拜真神组织一旦你们对他们采取行动且暗含目的是狩猎他们高层真实造物主有可能预见到并给予一定警示。还能这样？奥黛丽眼眸微微睁大观察隐者星星等人发现他们也有同样错愕。这是他们之前完全没有考虑过事项。这不是他们不够聪明而是他们在此之前从未参与过这种涉及高层次存在事情或者说即使参与了也什么都不清楚。那该怎么办？魔术师忍不住问。克莱恩以启发口吻回答：用不直接针对极光会更加柔和办法钓出秘之圣者布提斯。

## 这场戏有没有翻
翻了。开头还在友善怎么让亚伯拉罕信；章末从书信心理设计转到钓布提斯且被真神预警卡死。翻的是人情信与猎杀线汇合，不是编故事厉不厉。

- 友善靠中间人故事不靠本人现身。

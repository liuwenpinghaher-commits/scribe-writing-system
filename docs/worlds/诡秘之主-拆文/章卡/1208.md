# 1208 逐光者 第五十九章 两个选择

## 打开书
房间之内绯红辉芒如水浸润每一个角落。多里安缓慢抬起脑袋看向凸肚窗外圆月久久没有移开眼睛似乎第一次欣赏到类似美景。呼……他吐口气站起身来进入盥洗室拧开水龙头捧一把冰冷刺骨自来水将它们狠狠拍在脸上。一番清洗后多里安用毛巾擦干脸庞回到客厅坐至沙发低下脑袋虔诚自语：赞美愚者先生！完成祷告他走入书房抽出纸笔给学生佛尔思写信：……请转告格尔曼·斯帕罗先生我已确认他承诺希望他能找到解决诅咒更好办法……我将召集家族其他成员商量是否用那两件0级封印物之一换取旧日之盒……在此我先介绍一下那两件0级封印物让格尔曼·斯帕罗先生能有充分时间考虑希望得到哪件：一件叫神之画卷它看起来是一副套在黄铜框架内普通油画但上面描绘内容会不定时变化。当它呈现出不同地点时持有者可以让目标周围区域改变让对应场景降临；当它呈现出不同人物时持有者可以让那些人物针对目标发起攻击每人一次；当它呈现抽象难以理解图像时会有不同效果在现实出现而我们弄清楚对应关系只占很少一部分；当它呈现一扇扇门时打开不同门会转移去不同地方事前无法预知目的地能用来放逐目标；当它呈现幽暗地底或者深邃星空时非常危险必须封印！如果这幅油画无人注视无人欣赏那它里面人物会活过来从油画里伸出手一点点进入现实世界封印时必须注意这点！曾经我家族有一个分支保管这神之画卷时出现错漏有足足一分钟无人欣赏它而那个时候它上面呈现是天使环绕神灵画面然后那位神灵活了从油画里走出来。我家族那个分支就此覆灭只残留几个精神失常成员那位神灵则不知道去哪里但未带走这幅油画。我们担心很久害怕那神灵会毁灭世界幸运是祂再未出现过也许已经被七神注意到做了处理。当然不排除这是那些精神失常者编出来故事但一夜之间大部分成员死亡小部分疯掉本身就意味着很多。另一件0级封印物叫星之杖它外形是一根黑色镶嵌宝石手杖。当持握着它时脑海里如果浮现相应场景且那真实存在依旧存在这根手杖会带着你直接抵达目的地但一定要注意一点勾勒画面必须绝对正确每一个细节都不能出错不能和原版存在差别否则你永远也不知道你将抵达目的地会是哪里；同样持握着星之杖时脑海里如果能浮现一些非凡能力或者人物这根手杖就会再现对应能力对应人后者能发动一次攻击要想达到这样效果对能力和人物有足够了解是前提否则你不知道会出现什么样异变曾经有人想用星之杖释放闪电风暴结果把自己变成一只青蛙直至找到解除诅咒办法才恢复；星之杖足够坚硬可以直接用来攻击被它抽打中人会随机性出现异变或遭遇各种奇怪效果之前我用星之杖击中一个极光会非凡者他左边身体被转移去门外右边还留在原地内脏哗啦掉落出来；星之杖本身会随机性转移如果不能正确封印它不知什么时候就会消失脱离掌控；持握着它时脑袋绝大部分时候必须放空因为一旦有画面浮现就有可能激发我前面描述那些效果；如没人持握星之杖周围会有各种异常发生好坏难以预料必须进行封印……阅后即焚……写好这封信多里安反复看几遍确认没有错误才将它塞入信封贴上邮票。此时灰雾之上古老宫殿内。克莱恩已通过祈祷光点全程看完多里安写信。我似乎忘记告诉他了可以通过愚者先生将相应情报转交给格尔曼·斯帕罗……这样也好这就当是塔罗会正式成员福利要是每个信徒都来这么一手不留一些灵之虫在源堡我根本忙不过来……嗯这也能有效维持愚者先生位格让亚伯拉罕家族成员们不敢轻视……克莱恩咕哝几句将注意力转回那两件0级封印物上。他再次确信0级封印物都是有严重负面效果东西不能作为常规物品使用。当然它们能力它们效果都极为强大极其可怕无愧于0级称号。相比较而言还是星之杖更适合我……可以提前让正义小姐催眠我让我潜意识浮现想法都以念头而不是画面形式存在必须有意识控制才能勾勒场景……不知道让白银城居民手持星之杖于脑海勾勒贝克兰德街道画面能不能直接脱离神弃之地……但事前没法给他们做催眠他们也没真正见过贝克兰德哪怕给他们还原相应场景他们也很难正确勾勒细节……总之很麻烦但可以试一试挑选不怕死志愿者……如果能交换到星之杖先不急着将它粉碎变成特性说不定什么时候就能派上用场毕竟那个晋升仪式未必能完成……有了星之杖对付乌黯魔狼从暗天使眼皮底下逃出神弃之地也算多点把握……克莱恩叹口气心中已是有决断。这时他又发现一个事实。那就是如果亚伯拉罕家族部分成员跟着多里安改信愚者先生那就算他把旧日之盒还给他们将来真要使用再借也不难。也就是说星之杖神之画卷和旧日之盒这三件0级封印物他得到一件所有权两件使用权。发展信徒还是很有作用嘛……到时候亚伯拉罕家族岂不是成塔罗会下属势力？不过多里安肯定不会那么快将愚者信仰传播出去除非某些成员已在失控边缘徘徊再也无法对抗下一次满月诅咒。克莱恩莫名感觉塔罗会势力在膨胀。他认真想想为自己将来可能一天24小时都得响应信徒生活感到悲哀。只有成为天使真正掌握源堡敢于放一些灵之虫在上面才能解决这个难题。实在不行就找阿罗德斯做人工智能客服……克莱恩揉揉额角离开灰雾之上返回神弃之地。……深夜罗思德群岛海域。一只庞大海怪飞快游到目标地点。这是阿尔杰向海神卡维图瓦祈求来帮手以海洋歌者层次他还无法驱使这种体型生物。其实他完全可以从拜亚姆游到这边但那样会太累无法对抗意外。几秒后海怪张开嘴巴阿尔杰游出来向一片绚烂珊瑚丛靠拢。绕过几个障碍后阿尔杰眼中突然浮现出一抹深蓝。透过这深蓝他看见一座珊瑚组成华丽宫殿。它明明是如此真实却没人能看到除非有特定媒介。阿尔杰凝望好一阵向前游动来到宫殿前方伸手推开大门。晃动水波至此停顿阿尔杰在风簇拥下穿过屏障落到地面。他环顾一圈发现两侧描绘着一幅幅壁画。这些壁画内容并不出奇以一条条船只一个个精灵脸孔人对抗风暴对抗巨浪为主。但是阿尔杰有注意到那些船只航行地方不是大海而是一片浓郁到化不开黑色。这让阿尔杰想到一个词语：深渊。这和传说里深渊有点像只是有点像而且也没有恶魔……它们似乎是从地底涌出来……这些壁画记录是精灵一族历史？但和相应神话不太吻合啊……世界说每一个精灵语单词都对应一位初始精灵……阿尔杰边思索边走向前方九层台阶。随着距离拉近他看见两张王座看见一根深蓝晶莹珊瑚。那珊瑚枝丫上一道道银白电蛇嗞嗞跳跃照亮周围。阿尔杰屏住呼吸放慢脚步一层层登上台阶来到王座前。他郑重伸出右手拿起那根珊瑚。哗啦声音随之响起宫殿外海水猛然晃荡而那珊瑚在一片深蓝包裹下逐渐虚化融入阿尔杰身体。一道又一道电光像花瓣一样绽放。

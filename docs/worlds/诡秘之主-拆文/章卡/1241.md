# 1241 逐光者 第九十二章 人类迷惑行为

## 打开书
……大帝偶然发现原始岛屿……岛上生物在崇拜来自星空未知力量……不到天使层次哪怕只是了解也会被星空污染……尽量不要向灯神许愿也不要带着它去那座原始岛屿……星之上将嘉德丽雅终于得到愚者先生回馈一边松口气一边更加担心起女王探寻之旅。她侧头看眼没什么反应许愿神灯忙将它收起来然后铺开信纸提起钢笔将刚刚才得到情报用自己语言描述一遍务求引起神秘女王贝尔纳黛重视。……贝克兰德一栋破旧公寓内。一个满脸络腮胡子男人坐在椅子上双手被反拷在身后。已靠着实力在军情九处成为中层休带着两名属下提着一把三棱刺立在这男子前面沉声：我们已有足够证人和证据证明你就是这次游行主要组织者之一你如果想减轻处罚就老实回答我问题。休还未开口时那络腮胡男子就感觉到极为强大压迫力等她说完则连精神都出现颤栗仿佛有一道又一道电流凝聚产生暗藏刺痛和麻痹随时可能爆发。络腮胡男子强忍着内心恐惧和虚弱：没有任何人指使我我只是在做我渴望做事情。你们难道还不清楚吗？整个贝克兰德已经变成火药桶即使只是一点火星都有可能引爆全城而像我这样忍耐不下去愿意冒险火星不知有多少！那些该死贵族商人囤积那么多粮食而东区已经有人饿死！你们想怎么处理我就怎么处理吧我从来不相信那些家伙承诺之前同意结束游行是因为大家都拿到不少食物。休正要再问点什么忽然侧过脑袋倾听起远方动静。轰隆隆声音不知从哪里传来低沉暗哑层层滚荡。弗萨克或者因蒂斯费内波特军队突破阻拦开始攻击贝克兰德防线？休表情一下变得凝重。……神弃之地克莱恩回到现实世界后立刻尝试着探手看能否从历史迷雾内拿出那盏许愿神灯。很快他确认这编号0-05封印物无法召唤。果然涉及唯一性或者说源质？总之灯神确实是被封印高层次存在位格至少是天使之王……完全没法利用……克莱恩吐口气将注意力转回狩猎乌黯魔狼科塔尔这件事情上。他这段时间已做不少准备也在灰雾之上推敲好整个计划。不过克莱恩没急于展开行动又花费不少时间检查漏洞补上不够完善地方。两三天后深沉黑暗死寂荒芜旷野中提前干扰占卜克莱恩戴着半高丝绸礼帽身穿黑色长款风衣提着一盏散发出昏黄光芒马灯表情沉凝探出右手往空气里抓一下。此时有一道闪电划过照亮整个世界。克莱恩随即拖出一道人影那是提着虚幻星之杖和马灯他自己。紧接着他本体进入历史迷雾狂奔到第一纪前藏匿于那层层叠叠旧日都市内部。他历史孔隙影像一下活过来脑海内浮现出这段时间勘察地形之一利用星之杖能力直接转移过去。——这与他本体所在相隔很远即使投影出问题也不会有谁能锁定他本体回归现实具体地点。环顾一圈将干涸河床怪物一样立于黑暗深处巨石等景象收入眼底后克莱恩不再维持星之杖历史投影右手一抖让它飞快淡化消失不见。做完这些事情克莱恩走至那块巨石旁放下马灯用巨人语低声诵念起一个尊名：与历史同在乌黯之主；无数奇迹化身；执掌愿望神祇……这是克莱恩从黑夜女神那里得到乌黯魔狼尊名虽然那位神话生物未必还在使用这个或许早就对它做一定改变但在神秘学上这毫无疑问还是会指向祂。……连绵起伏山脉深处一座古老城堡内。一个个巨人精灵人类吸血鬼分别担任着园丁厨师男仆女佣和守卫他们表情各不相同彼此遇到时还会低声交谈几句显得很有生气很有灵性。但他们回到自己房间后立刻就会变得呆滞眼眸不再转动身体往上飘起悬吊于天花板上。城堡深处只有窗外闪电才能照亮一个大厅内一道巨大身影静静趴在黑暗中。它如同一座小山通体覆盖着幽暗短毛漆黑瞳孔占据眼睛至少四分之三额头有一撮灰白毛发头部神似放大扭曲野狼。这正是愿望之神乌黯魔狼科塔尔。忽然这比普通巨人还夸张魔狼抬起脑袋每一根幽暗短毛都出现摇晃而城堡内所有仆役都同时跟着祂做出类似动作。科塔尔随即微动眼眸略侧头部似乎在倾听什么。下一秒钟祂张开嘴巴发出无声吼叫召唤出另一个自己。这条乌黯魔狼刚刚出现科塔尔本体就跃入灰白雾气中奔到第二纪某个历史光斑内。这是祂掌握一段隐秘历史。现实世界中乌黯魔狼历史孔隙影像用艰涩拗口语言许下一个愿望然后祂身影一闪直接就转移到北方城邦诺斯附近山峰上。做完相应准备这位愿望之神才让一根幽暗短毛脱落化成一条虚幻灵之虫并膨胀成相应祈祷光点。借助这光点科塔尔看见向自己祈祷究竟是谁：那是位戴古怪帽子穿古怪衣物年轻男子他立在一盏玻璃灯笼旁低声诵念着愿望之神尊名。嗯……乌黯魔狼漆黑巨大瞳孔一转看见那年轻男子身上蒙着一层灰白雾气雾气中藏着些看不清具体模样事物。作为占卜家途径序列2天使这神话生物能明确察觉到这雾气与历史迷雾相似能感应到雾中事物对自己有强烈吸引力。……源堡？科塔尔从魔狼之王弗雷格拉这位古神处听过一些事情瞬间就有一定猜测。在这个前提下祂对那位年轻人打算做什么有一个又一个想法：用源堡吸引我让我主动攻击他然后反向确定我位置？这是一个诱饵？确实他只是一个来自历史孔隙内影像本体不知躲在哪个碎片内埋伏者也不知藏在哪里……之前源堡明显异动我都控制住自己没试图寻找相应区域搜集遗留线索祂们为什么认为我这次会上当？只是单纯试一试不行再换别办法？或者这次祈祷里还暗含着什么不对？呵呵我活几千年经历那么多事情什么样情况没见过？现在最好处理办法就是不去管他也不做窥视记住他就可以。乌黯魔狼迅速有决定打算再观察一下就掐灭那个祈祷光点。就在这个时候祂看见那个年轻人又一次张开嘴巴：永恒烈阳啊；您是不灭之光；您是秩序化身。……乌黯魔狼有点看不明白这位年轻人想做什么。在这个被遗弃地方向别真神祈祷是无效！下一秒钟克莱恩又一次诵念出神灵尊名：创造一切主；阴影帷幕后主宰；所有生灵堕落自性。乌黯魔狼瞳孔略微放大一点因祈祷光点内那位人类行为产生一定迷惑。没等祂据此做出猜测克莱恩低念出第三个尊名：拨弄时光指针；遨游命运影子；欺诈与恶作剧化身……阿蒙……他在向阿蒙祈祷……乌黯魔狼已经不知道对方究竟想做什么本能觉得不对当即就要抹去对应祈祷光点。突然祂看见那年轻人抬起脑袋嘴角带上一点笑意。他随即拿出一片水晶磨成单片眼镜将它戴到自己右眼位置。仅仅只是一次祈祷克莱恩历史孔隙影像就变成渎神者阿蒙分身！几乎是同时乌黯魔狼感觉对方目光穿过祈祷光点望向自己然后穿过自己望向历史迷雾内本体。祂没有一点犹豫立刻就掐灭那个祈祷光点。而祂本体一边消融着那种注视一边解除对这个历史投影维持。历史迷雾内层层叠叠旧日都市中克莱恩猛然站起来脑海内浮现出一幕场景。而早在这场景成形前几秒他就切断本体与那个历史孔隙影像联系以免被阿蒙借此降临到自己身旁。他之前做那些莫名其妙事情主要是迷惑乌黯魔狼让祂在识破祈祷者不是本体后继续观察累积祂窥视源堡时间。最后向阿蒙祈祷则是借助这位欺诈之神可能降临和可能影响掩盖源堡对乌黯魔狼反向污染！若是阿蒙未做回应只是旁观克莱恩自己也准备有单片眼镜可以尝试着欺诈一下乌黯魔狼。

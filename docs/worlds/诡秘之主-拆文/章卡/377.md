# 377 无面人 第一百六十五章 表演开始

## 打开书
黑冠密甲穿门入：椅帽门厅→三层穹顶金厅水晶烛瓣吊灯→左厚门餐厅烤肉香浓。先外转半圈拉煤气管试黑皇帝力。占卜／小丑灵体：攻魂＋触冻；魔术师灵可用纸人空气弹／附体；黑皇加持力大携物多→怨灵尖啸（人耳不及声波伤精）＋冻增强。穿墙入餐厅；无情绪扫桌：赫凯蒂帕克切牛眼卡平——一触即收防灵感。仆气场遮掩飘清布局（客厅级大；壁炉管暖；十六煤气灯如昼；名家画）。贝里斯未在守地下——非凡苦差非简贩。靠日落油画拧开生物毒素瓶！挑晚餐人齐闭窗初冬见效快；灵体不怕毒无需预防剂。包容遮掩静赏壁灯——无色无味毒漫。赫吃龙骨鱼香槟畅想晚间征服倔少女；凯蒂精准解剖烤鸡均块；帕克红酒炖羔羊聊主座。卡平咽末牛眼邀甜点拉波瑞三样——「国家热爱甜点」点头。卡平抓脸痒→血痕肿半透淡黄→再挠裂脓喷。赫猛站警视。仆捧腹狂笑泪／晕／呕黄绿无一幸。凯蒂掀桌左轮软鞭；帕克恍惚觉撕肉卡平眉清目秀。赫喘不过：「屏息！帕克开门！凯蒂随我寻入侵！」幸仆先发症非凡未深；帕克最低最重。门开灵视见黑甲冠面具影如灵界王。赫指古赫「囚禁！」琥珀黏稠定；凯蒂淡金纹弹穿——纸人自燃灰！啪脆响十六灯＋壁炉火霍亮满红→全熄；唯路灯绯红月黯照。赫察毒不快敌未决前或真发；指门「禁闭！」灵难穿壁欲困死。凯蒂半空见黑影眼奇光未攻——脑嗡尖啸鼻血；赫略眩喘重；帕克金星虚浮。肩被拍阴冷僵骨——耳熟低沉「囚禁！」透壁困门边；克未附穿避赫术。赫眯甩：「释放！」

## 这场戏有没有翻
翻了。开头穿门试力；章末毒发宴乱、纸人替、灭灯尖啸、反囚帕克、赫释放。翻的是魔术师对秩序法令开打，不是关键环节收束。

## 话
「有点痒。」「屏住呼吸！」「囚禁！」「禁闭！」「释放！」局面是从甜点闲聊收成脓喷毒宴；从纸人灰收成灭灯尖啸反囚。

## 热怎么变冷
甜点还热。冷切在痒脓。狂笑还热。冷切在屏息令。囚禁还热。冷切在纸人灰。禁闭还热。冷切在反囚禁释放。

## 怎么起、怎么收
第一段穿门。最后一段「释放！」章题：表演开始——毒＋纸人。

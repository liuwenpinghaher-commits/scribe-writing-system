# 1373 倒吊人 第二十一章 命运木马

## 打开书
看着巨大石椅上半个愚者克莱恩脑海内闪过刚才经历那一幕幕与夜之国相关场景一时有些感触。对于安提哥努斯他了解并不多甚至好几次差点因对方霍纳奇斯……弗雷格拉……呓语失控所以此刻谈不上有什么同情只是有点感同身受：那始终徘徊于梦中毫无疑问是过去最美好记忆之一。就算天生属于超凡物种安提哥努斯似乎也深深眷念着曾经那个平静宁和封闭小国。……0-02特伦索斯特黄铜书。利用类似嫁接能力完成封印？嗯似乎还更进了一步不仅仅只是将开始部分直接连到收尾规则而且还愚弄特伦索斯特黄铜书灵智让它忽略掉被跳过中间部分未尝试做出改变一次又一次重复……克莱恩瞄眼0-02若有所思无声自语几句。这让他对愚者会具备什么能力有一定猜测。没去多想克莱恩让诡秘侍者秘偶将起点和终点嫁接在一起一步走至巨大石椅旁拾取起那本特伦索斯特黄铜书。……见那半个愚者依旧沉睡无法从永眠中摆脱克莱恩稍微松口气让秘偶拿着特伦索斯特黄铜书退至宫殿入口等待于那里。他之所以不让分身去拿这件0级封印物是因为担心与源质存在一定联系特伦索斯特黄铜书会在自己容纳愚者唯一性关键时刻展现被动负面影响让局势往不好方向急坠而去。……这也是克莱恩没带星之杖原因他不能将一颗定时炸弹放在身边。平时还好他可以依靠位格层次和能力强行压制星之杖但容纳愚者唯一性过程中他会非常脆弱没办法干涉周围人和事稍有一点意外就可能当场失控。而为应对源堡被封无法借用力量情况克莱恩又不得不带上可以提供传送能力封印物于是他选择蠕动饥饿。……他随即用右手抚摸下蠕动饥饿用开玩笑口吻低语道：不用担心你只是一个历史孔隙中影像。……下一秒克莱恩探出右手隔着不算远但也绝对称不上近距离将安提哥努斯身体包容于五指之间。他手指迅速合拢腕部一拧完成窃取。……虽然他已是天使之王中天使之王但偷盗方面能力都来自源堡目前只有序列1层次而安提哥努斯是被诡秘之主污染过容纳着唯一性天使之王两者还是存在明显差距。……对于这种情况他毫不紧张更没有半点失望因为这都是事前就能预料到反正只要窃取没有完成黑夜女神就不会解除隐秘让这里与现实命运互通也就不会存在外来干扰克莱恩有充足时间和安稳环境来尝试。……这是命运象征它还有许多不同形象比如缓缓转动分成多格轮盘和首尾相接巨蛇。这一刻命运更替时克莱恩看见是光之长河。……祂对父亲弗雷格拉从神们都没有太深刻印象记得最清楚是自己很厌恶愿望之神科塔尔哪怕这也是条魔狼；另外祂不喜欢亡灵之神萨林格尔觉得祂阴沉孤僻浑身上下都散发着腐烂恶心气息倒是厄运女神阿曼妮西斯兼具魔狼和人类审美性格温柔非常擅于安抚心灵不是那么令狼讨厌……魔狼见证自己父亲那位强大古神陨落看见古神鲜血洒满厄运女神阿曼妮西斯全身而那混乱场合里一份唯一性和一份序列1非凡特性受到牵引落入祂手中；……大灾变之后祂终于晋升为诡秘侍者将自己变成人类以安提哥努斯为姓离开霍纳奇斯山脉回归隐秘国度外现实世界；……祂容纳愚者唯一性后这种情况愈发严重了……我就是安提哥努斯我就是半个愚者！……错误先生阿蒙！……没意思。看到这一幕阿蒙笑着摇下头对此一点也不失望。祂只是想试一试克莱恩或者黑夜女神有没有修复这边一个Bug：敲钟之后祂在某种程度上已算是愚者时天使可以利用这个漏洞将对方部分锚直接窃取过来。……那水晶磨成眼镜上仿佛来自星空光芒骤然亮起。

# 978 红祭司 第三十三章 生活的乐趣

## 打开书
奥黛丽看盒中羽饰：南大陆民俗不像我们，但符合审美——半真心半客气，像赞遗迹却少买回家。克莱恩：南大陆内部差大，东西拜朗与高地河谷近乎不同；共同尊崇黄金有神奇力量。指羽：传闻佩戴获羽蛇即死神庇佑——暗示关键作用。序列6观众听出：关键可得所谓死神回应；操作属神秘学基础不必再讲。浅笑：真喜欢，合适场合插帽。与观众说话轻松。门外还有礼要送。「今天你是这里最受欢迎的人。」谢意委婉。内心烦恼：赫温·兰比斯要否现在告知世界？周一塔罗会再说，方便问倒吊人隐者如何防高序列暗示催眠——非每次能祷愚者得天使祝福；催眠可怕，不知不觉按吩咐做。疑上流社会多人曾被催眠。又悟：父母圣赛缪尔弥撒必贝克兰德大主教主持——半神；大主教有时家访——防类似？故赫温催眠未过分？目送道恩出门关门，无意识涂画：交织圈、冷酷眼、线条发散人脸——合格心理医生解读基本操作，灵性摩擦烧灰。克莱恩送完礼与理事闲聊，进兼职理事休息室写信：「尊敬的阿兹克先生……」南大陆已将亚当取0-08、与伦纳德戴莉复仇成功写成信吹铜哨——至今无回；亚当知其与阿兹克关系，分享不致激烈。此信不涉超凡：温柔详尽写慈善助学，末：有意义满足愉悦；醒来或可尝试，每次复活见曾助孩子——您不记得他们，他们记得您。铜哨白骨信使取走。携恩尤尼至圣赛缪尔教堂默祷一刻钟，奉献箱投80镑；找埃莱克特拉主教闲聊听布道——宗教社交回归。礼不当面给，瓦尔特私送主教家。下午茶：访艾伦医生家（理查德森上午已约）。见艾伦、夫人维尔玛·葛莱蒂斯、新生儿与几岁兄姐。遗憾没参加——停，等维尔玛笑答「威尔」。黄金护身符好运；艾伦接过垂入婴儿车：「威尔，喜欢吗？」胖婴儿抬臂啪打出去。场面尴尬，呵呵：小孩子都会有的反应。侍女三层托盘转话题。讲东西拜朗风俗，夫妇小孩追问。忽转向婴儿车，幻术里讲述不停：你似乎不喜欢我的礼物？威尔稚声：这种礼物有什么意义？不如直接送瓜达尔至少还能喝！笑摇头：乌珞琉斯被某位击伤，一时没法找你——不敢提亚当名号惧被察觉命运之蛇下落；阿蒙描述也暂弃防命运交汇。「某位」排除围攻与0级。威尔：就说你命运偏移长期是好事。正要解幻术，嘟囔：突然想喝瓜达尔最好加点冰。「这种饮料对小孩子不太好！」中断幻术拿冰淇淋勺逗：「威尔，想吃吗？」维尔玛：我们威尔不喜欢吃这个。话音落，克莱恩自己塞入口中。哇——婴儿车响亮哭声。

## 这场戏有没有翻
翻了。开头羽饰客套暗示庇佑；奥黛丽压下赫温不说。下半阿兹克家书与教堂回归后，艾伦家护身符被打飞，幻术情报换瓜达尔哭闹。翻的是「生活乐趣」底下藏命运之蛇对话，不是逗孩子热闹。

## 话
「传闻佩戴这种帽饰的人，会获得羽蛇，也就是『死神』的庇佑。」「今天你是这里最受欢迎的人。」「等您醒来，也许可以尝试着做类似的事情……」「威尔，喜欢吗？」「这种礼物有什么意义？你不如直接送我『瓜达尔』」「乌珞琉斯被某位击伤」「我就说嘛，你命运的偏移从长期看是好事。」局面是「某位」把天使情报收成可说出口；冰淇淋自吃把幻术收成哇的一声。

## 热怎么变冷
符合审美还热。冷切在赫温催眠思绪。慈善家书还热。冷切在护符被打飞。瓜达尔玩笑还热。冷切在不敢想亚当名字。

## 怎么起、怎么收
第一段民俗称赞。最后一段婴儿响亮哭声。章题生活的乐趣——乐子在哭声里。

# 1366 倒吊人 第十四章 支流

## 打开书
因为不清楚阿蒙现在究竟处于什么状态所以克莱恩没敢耽搁精神问题初步解决后立刻就来到卡尔德隆准备取永暗之河河水。而因为这涉及源质他只能在一定程度上占卜和预言模糊看见一些画面无法准确地做出判断。环顾一圈克莱恩抬手召唤出自己几分钟前历史孔隙影像让本体回归源堡。他意识随即转移到投影身上让它拥有实质存在感。接着克莱恩又往虚空中抓一下抽出星之杖历史投影。坦白讲在能通过源堡使用学徒途径序列0以下大部分非凡能力后克莱恩其实已不是那么需要星之杖这件0级封印物了——后者具备神奇他基本都能再现而且几乎没有负面效果。……在神秘世界里这绝对是有可能发生事情无论仲裁人途径规则限制还是某位外神带来一定程度内超凡失效都有可能达成类似效果。……作为一名占卜家途径天使之王做好各方面准备是一种本能！掂量下星之杖按按头顶礼帽克莱恩从源堡内拿出那个鸟型黄金饰品将它别到自己左胸位置口袋上。……克莱恩只是看一眼就让身周浮现出淡淡灰白雾气直接凭借源堡位格抵御住卡尔德隆将所有生灵转化为亡者规则。……之前上涨灰白洪水都退去了……戴礼帽穿风衣提手杖克莱恩若有所思点下头一步就迈入肉眼可以看见卡尔德隆深处。他这次利用是偷盗者途径非凡能力直接窃取走感知范围内距离以此避免和这座神秘城市内活跃各种危险怪物纠缠。这并非他害怕该害怕是那些怪物才对若非他不想浪费时间其实不介意趁机搜集一批秘偶填补乌托邦被毁灭造成损失。……卡尔德隆是亡灵城市地底最深处很有可能流淌着永暗之河而秘偶在本质上来说已经是亡者一旦接近地底就有可能出现异变。一步一步深入中克莱恩发现自己有点想多了：隐藏在这座奇异城市中各种怪物没有一个敢于出现源堡气息让它们求存本能战胜疯狂倾向和捕食习惯。……现在就和看黑白默片感觉一样要不是我能听见自己呼吸声和心跳声我都怀疑我是不是聋了……克莱恩轻咳一声用内心咕哝对抗着死亡寂静。……克莱恩凝望几秒没有犹豫提着星之杖通过敞开大门进入宫殿内部。……鸟型青铜雕像下石碑表面一个个源于亡者之语文字仿佛一只只不同形状非常简化鸟或一条条盘成不同模样蛇组成两句含义模糊话语：哪怕神灵也无法摆脱；哪怕死亡也会被拘禁。这是在警告所有来到卡尔德隆生灵不要沿这座阶梯往下？它直接通往永暗之河？克莱恩思绪一转认真解读起石碑上话语。在他看来这似乎是在说明哪怕序列0真神一旦靠近永暗之河也将沉沦在那里无法脱离而哪怕死亡本身也会被这份源质这条抽象河流拘禁虽然从此不会消逝但也无法解脱。这么看来和混沌海一样没有源质保护情况下即使只是接近永暗之河也会产生可怕异变……克莱恩收回目光整理下别在胸前口袋上鸟型黄金饰品绕过顶着青铜雕像石碑沿灰白阶梯一步一步下行。……不知下行多久后他身周源堡气息条件反射般膨胀变得极为浓郁仿佛一个灰白色蚕茧。……这和上次看见不太一样……克莱恩微皱起眉头。他之前到卡尔德隆狩猎灵界掠夺者时候引发一定变化让深坑底部涌上来大量灰白色虚幻潮水。……就在克莱恩念头电转时石制阶梯底部深暗潮水涌来地方淡薄灰白雾气弥漫往上与虚幻水液结合膨胀成更偏雾气灰白轻水。……若非周围有源堡气息保护克莱恩怀疑自己会被动无法抵御融入这片潮水。接下来那灰白色蚕茧在水流中起起伏伏随着潮落缓慢抵达阶梯尽头。……果然……克莱恩见状忍不住低语一句。对于这种雾气他一点也不陌生他曾经在班西废墟那扇门后见过在神弃之地最东面见过在源堡之下见过！而和其他地方不同那条永暗之河有部分水流穿透灰白雾气并与后者产生一定融合时而深暗时而苍白。……克莱恩认识祂祂是阿兹克先生父亲第四纪那位死神：冥皇萨林格尔。

## 这场戏有没有翻
翻了。开头史投＋鸟饰入城；窃距深潜；碑文警告；蚕茧抗潮至河；章末支流见冥皇萨林格尔。翻的是支流＝见死烙源。

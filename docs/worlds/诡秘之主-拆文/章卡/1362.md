# 1362 倒吊人 第十章 治疗方案

## 打开书
秋日阳光笼罩露台上奥黛丽戴着式样清新度假草帽坐在躺椅上悠闲翻看一本讲述时尚杂志。她身旁小圆桌上摆着一份份精致糕点和一杯家族庄园特产红茶。突然她抬起脑袋望向露台边缘只见穿黑色风衣戴丝绸礼帽格尔曼·斯帕罗一步步走过来。奥黛丽侧头看贴身女仆安妮一眼发现她和周围仆佣一样对奇异出现陌生人视而不见。同时奥黛丽也注意到周围似乎阴暗少许。……这个过程中她本打算相对严肃讨论心理炼金会和暴怒先生问题可转念一想又露出笑容用能感染他人情绪轻快口吻道：世界先生你是来寻求心理咨询还是处理暴怒问题？如果单纯是前者奥黛丽认为世界格尔曼·斯帕罗会让自己到灰雾之上见面这样更方便更快捷所以这位天使必然肩负着愚者先生交代需要在现实世界里完成任务。而同时她又敏锐感应到世界先生情绪相当复杂既满足高兴又低落悲伤。……都有。克莱恩拉过一张椅子坐到小圆桌旁。需要红茶还是咖啡？奥黛丽虽然没有主动去调查过世界先生情报但她和道恩·唐泰斯见过多次面……比如奥黛丽知道当道恩·唐泰斯是格尔曼·斯帕罗时他口味偏甜偏油带点微酸：喝咖啡喜欢加糖而不是牛奶；红茶里爱放柠檬片……红茶。克莱恩想想开口回应道。正义小姐轻松自然亲切态度让他放松不少觉得这样状态更有利于接下来安抚。……再来一杯红茶多加柠檬片。奥黛丽侧头对女仆安妮道。……奥黛丽没急着做心理治疗也没去询问世界先生情绪复杂原因她噙着笑意认真介绍起这片庄园特产借此和道恩·唐泰斯玫歌庄园做对比自然交代对方管家仆人们现在情况……克莱恩安静听着时不时提出一个问题就像在和朋友闲聊。……看着他吃一块奶油小蛋糕后奥黛丽碧眸微转笑着说道：对于天使来说食物似乎已经不是必需？对只是爱好。克莱恩简单回答一句后又补充道可以用来维持自身人性。维持自身人性……奥黛丽若有所思重复一遍这是为了对抗神性？你现在精神问题也属于这个类型？……克莱恩轻轻颔首道：对。你应该也有一定体会了每一个获得神性非凡者都必然会有这方面体会区别只是多和少。奥黛丽认真回想一下道：我偶尔会梦见一团光照亮整个世界光偶尔会听见无法描述难以理解声音看到一片模糊奇异似乎蕴藏许多矛盾概念虚幻大海这确定是幻觉但又那样真实。唔我偶尔还会梦到一个巨大十字架听见有谁在低声祈祷可怎么都分辨不清楚具体内容。第二个应该是来自混沌海这份源质和里面精神意志间接污染第三个似乎是空想家亚当开始对本途径非凡者施加影响……最初那位造物主创造万物也分裂成各种非凡特性这就是超凡源头。所以我们每个人体内都有神性都有最初那位造物主意志当非凡特性越聚越多祂就会一点点苏醒取代我们。……所以才要用人性对抗神性同时还要借助锚？对你梦见光听到无法描述声音看见虚幻大海就属于这类污染而那个巨大十字架和祈祷声应该是空想家亚当对本途径非凡者施加影响。克莱恩具体点明两种情况不同。奥黛丽下意识坐直身体环顾起四周显得有些害怕：……不用担心在我身边祂听不到。克莱恩解释一句。奥黛丽收回目光没有掩饰自己惊讶和愕然：你已经晋升序列1了？……克莱恩坦然回答道：算是天使之王了。……奥黛丽默然好几秒抿下嘴略带气恼笑着说道我刚才差点出现心理问题。克莱恩跟着笑笑：就我个人而言成为天使之王不一定是好事。嗯观众途径高序列者尤其要注意自己精神状态……观众途径非凡者不容易疯掉也最容易疯掉。奥黛丽警醒回应道：我明白了。……你精神状态不稳定出现心理问题是因为超出预计短时间内成为天使之王？对。克莱恩喝口红茶道我体内不属于自己意志已在很大程度上复苏目前只能勉强压制维持住初步精神稳定。奥黛丽一边听着格尔曼·斯帕罗描述一边利用自身非凡能力做着观察和分析。……我大致掌握你现在状况初步治疗方案分为两步：我先进入你心灵世界更多地唤醒你与人性有关记忆唔不包括会让你痛苦到想放弃那种接着在神性做出反应时通过安抚催眠等超凡能力减弱它带来污染和负面影响帮助你更好地压制住它。克莱恩沉默一下道：好。他决定利用梦境和心灵世界被别人进入时自己可以保持清醒特殊先将愚者有关记忆聚拢起来嫁接到灰雾之上灵之虫们那里。就在这时奥黛丽让女仆安妮拿来一根浅白色丝巾。……奥黛丽绑好丝巾后微微笑道：这是一个催眠封闭灵体感知催眠。这样一来我即使进入你心灵世界也看不到听不见被唤醒那些记忆当然我保留灵性直觉否则没法找到你意识岛屿也察觉不到神性变化。本来我直接催眠就可以了但你已经是天使之王担心被你意识影响所以用有象征意义仪式来完成催眠加强效果。……好开始吧。

# 342 无面人 第一百三十章 各自

## 打开书
塔罗自由聊：正义问海上奇闻；阿尔杰选述；佛尔思灵感海盗王俘女爱恨小说；太阳凭画作文字想象海。灵枯散会午觉。晚7:30佛尔思再入A先生聚会（瞒休）。直觉：A不再悠闲俯视——压抑控某物，山→吐芯毒蛇；幸未带休易逃。手链剩两石——教训深。旁观后扭笔迹求太阳神奇物／强力非凡武。未见烈阳信徒。黑板后回条：「光之环」戒指——光使者太阳侍从、免疫疾、召光束太阳法、净50米死灵；认可升不赞削；频用渐成烈阳信徒守教义。一次付9000镑可等筹！抢劫感；拆借亦难；见过钱加刺杀定金亦未及。装没事旁观十分无更便宜武器——盥洗诵愚者转世界。克莱恩表情扭曲：负太重勿成太阳信徒；改现金——450镑配方归你。接下看野蛮人女士线索否则智慧之眼胸针。佛尔思松气拟献祭；不还价（便宜千亦买不起且觉世界亦负不起）。因A变速离。散后A下地下室——膝弯滚阶；影赤红血肉融出无皮怪物人；喘平血肉回流；匍匐忏悔主降临被破。切白银戴里克绕桌难决：建议最好但队友脸＝背弃？求见首席告堕落＝牧羊途？愚者在彼眼亦邪神？雷闪斧光——忆父母死刺痛：「这次来不及…之后备好不被疑」咬牙练祈光人耗灵近干涸。切霍尔画室：母凯特琳传黛拉言——请伊思兰特家庭教师每周两次？「您拿主意。」笑邀母当模特。周二早报：明晚智慧之眼聚会——松气物品赶得上围杀；决克拉格休闲一天。

## 这场戏有没有翻
翻了。开头还在海上闲聊；章末各自：佛尔思撞9000镑光环、A先生血肉异变忏悔、太阳开假失控、奥黛丽家庭教师落定、克莱恩锁定明晚买物。翻的是「各自」还能否只当散会，不是光之环。

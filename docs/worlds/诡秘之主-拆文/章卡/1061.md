# 1061 红祭司 第一百一十六章 在线“授课”

## 打开书
克莱恩释疑：目标非半神，因某些影响才「活」至今——秘密在此。第四纪贵族属索罗亚斯德，或助伦纳德了解帕列斯；暂勿告知老头。要几滴血。周日近凌晨探。克莱恩教话术敷衍帕列斯。回现实，老头已问前同事何事。伦纳德用部分真话：怕书信泄密、涉那位；找到第三纪苦修士探历史。老头祝勿见不该见。伦纳德反问为何不好奇大灾变——克莱恩第二招：主动问人。帕列斯一眼拆穿：太主动掌握节奏=有藏。伦纳德僵，仍割血；奥黛丽亦催眠减痛取血。周日夜舞会后早睡，克莱恩自召世界位，确认结束可强脱游记。三瓶血+谎言面具。拉正义星星上雾。游记出自空想之龙安格尔威德，或空想或真实梦境。涂血入书：风雪佩索特城。伦纳德无伪装自窘；奥黛丽戴面具。第一目标：第三纪苦修士斯诺曼——最可能涉阿蒙兄弟；次莫贝特；巨人格罗塞尔与精灵夏塔丝靠后；最后入集体潜意识大海。

## 这一章新讲明的规矩
- 「活」带引号：非半神却跨纪存，因特殊影响。
- 探梦需血液。
- 话术：部分真话；与其被问不如主动问——仍可能被天使拆穿。
- 游记：空想之龙制，内有空想／真实梦境世界；结束召唤可依灰雾强脱。
- 谎言面具遮长相。

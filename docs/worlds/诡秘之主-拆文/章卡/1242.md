# 1242 逐光者 第九十三章 忙而不乱

## 打开书
连绵起伏山脉深处那座古老城堡内。乌黯魔狼科塔尔刚从历史迷雾中返回立刻就本能清除起自身与外界种种联系预备直接抛弃这里转移到别地方。虽然祂到现在为止还没弄清楚之前究竟是怎么一回事但在已出现意外前提下祂经验告诉祂不能抱任何侥幸心理该撤退就撤退该放弃就放弃！与此同时旧日都市中克莱恩念头一动身影瞬间出现在灰雾之上古老宫殿内与愚者位置那时而扭曲时而分散深红人影融为一体凝聚成形。这片神秘空间里代表着正义倒吊人星星等塔罗会成员深红星辰正在不断地膨胀和收缩荡出层层波纹交织成浩荡潮水。这是克莱恩提前做预备之一以格尔曼·斯帕罗名义用不同理由让塔罗会成员们相继向愚者先生祈祷请这位存在将某个答案某个情报转告给世界先生。如此一来深红星辰就会共振反向影响源堡让它召唤愚者处理。这是当初克莱恩能从阿蒙手中逃脱关键之一可以帮助他免去逆走四步和诵念咒文工夫直接进入源堡不浪费一点时间。而在这种天使层面争斗里前后一秒钟差别或许就会决定最终结果是什么样子克莱恩想以小搏大必须考虑到每一个细节！坐至属于愚者那张高背椅后克莱恩一边招手摄来星之杖和海神权杖一边观察起源堡其他变化。那片灰白雾气中多了一块深红光斑它正在飞快缩小用不了多久就会消失；愚者座椅旁一圈圈光芒绽开仿佛要形成一条纯净通道。深红光斑上隐约透出巨大魔狼身影这是科塔尔窥视源堡并随着时间推移有一定了解后不知不觉遭遇侵蚀祂因此和源堡建立起初步联系当然作为一位天使作为第二纪愿望之神祂有足够位格和能力切断这种程度联系清除相应污染克莱恩如果不能把握住这一两秒时间将再次失去对乌黯魔狼行踪锁定。而愚者座椅旁那一圈圈光芒中映照出却是戴半高丝绸礼帽穿黑色长款风衣格尔曼·斯帕罗他右眼位置戴着水晶磨成单片眼镜。阿蒙！这位渎神者分身不知利用什么漏洞减缓克莱恩历史孔隙影像消散速度然后利用他与本体与源堡微妙关系试图在源堡做出召唤特殊场景下直接侵入灰雾之上！光晕荡开间格尔曼·斯帕罗修长有力手掌穿透屏障猛地探进古老宫殿内就像打开无形大门。克莱恩虽然早就做好预案知道阿蒙没那么容易打发但看到这一幕时还是忍不住头皮发麻害怕下一秒钟自己手就拿着个水晶磨成单片眼镜往右眼凑。这也是必须在一两秒内解决事情否则源堡归宿将重重打上一个问号。克莱恩没有犹豫让皮肤表面钻出一条又一条扭曲透明灵之虫它们飞快聚合形成另一个克莱恩。这克莱恩接住海神权杖撬动源堡力量在层层无形波浪加持下让青蓝色宝石全部亮起让一道又一道狂暴闪电组成银白球体滚入那层层荡开光圈中。噼里啪啦声音里那只穿透入源堡手掌瞬间四分五裂消融蒸发。充满毁灭气息球形闪电往外扩展降临于现实笼罩那戴着单片眼镜格尔曼·斯帕罗。这来自历史孔隙里影像本就是利用漏洞才勉强维持遭遇这样打击后再也无法保持状态只能一边正正水晶磨成单片眼镜惋惜摇头一边看着自己身影飞快透明被电蛇寸寸击碎。分出小半灵之虫响应阿蒙祈祷时克莱恩本体拿到星之杖。他握住镶嵌着多种宝石杖头将这件0级封印物对准急速缩小深红光斑。与此同时他脑海内浮现出一幕画面。星之杖上红宝石祖母绿蓝宝石和珍珠钻石随之不分先后亮起来。当！一声悠远钟鸣仿佛跨越无穷时光降临回荡在灰白雾气中回荡在那深红光斑内。乌黯魔狼科塔尔眼前漆黑骤然褪去显露出一个巨大石制壁钟。这壁钟古老而斑驳盘面被灰白和青黑分成十二格每一格内都有着不同符号代表着不同时间。壁钟核心位置三根似乎由时之虫构成指针一长一短一中等充满沧桑感。这是来自时天使阿蒙非凡能力克莱恩依靠星之杖将它做一个重现！正常来说这种层次非凡能力绝不是看一次两次就能了解没那么容易记录但克莱恩不是一个人在战斗。这段时间里他借助魔术师小姐召唤频繁返回贝克兰德到星星伦纳德那里与帕列斯·索罗亚斯德直接交谈深层次掌握相应神秘学知识和超凡细节。——帕列斯虽然已掉落至序列2位阶没法再使用时间领域能力但经验和见识还在没有丢失。当！古老神秘石制壁钟上秒钟猛然跳动一下让乌黯魔狼科塔尔周围一切都变得迟缓就连幽邃黑暗都似乎凝固。这位正要完全切断与外界联系通过自我许愿自我实现转移去远方奇迹师顿时僵立在原地有那么一个短暂定格。利用星之杖再现高层次非凡能力和原版毫无疑问是有不小差距但对克莱恩来说现在效果就已经足够。一看见乌黯魔狼被古老壁钟影响他立刻丢掉星之杖让刚才分出去灵之虫全部飞入体内。思绪一转克莱恩回归第一纪之前旧日都市然后提着散发出昏黄光芒马灯出现于被黑暗笼罩荒原内。他右手随即往前一抓顺利拖出拿着星之杖投影自己。——这种方式能有效提升召唤星之杖成功率但会明显降低这件0级封印物威能毕竟召唤来是历史投影中历史投影。当然因为现在属于必须争分夺秒情况所以怎么选择是一件很简单事情。克莱恩本体没再进入历史迷雾探手抓住自己肩膀并利用梦境占卜技巧于脑海内勾勒出之前利用源堡污染乌黯魔狼时获得反馈场景：古老城堡内没有点燃蜡烛黑暗大厅中小山般魔狼站起来。一个又一个细节飞快填充克莱恩根据目标被定格时画面微调具体情况。那根黑色手杖上相应宝石一下亮起。克莱恩脑海内那幕油画般场景猛地膨胀出来与现实交织在一起再也难分彼此。他降临在那座古堡内降临在那个黑暗大厅中降临在八条腿同时撑起身体乌黯魔狼科塔尔身前。他与这位第二纪存活下来愿望之神终于正式见面！没有犹豫趁着乌黯魔狼刚摆脱古老壁钟影响克莱恩一边散去自身历史孔隙影像一边从衣物口袋里拿出一个铁制卷烟盒啪地将它打开。这卷烟盒内安静躺着一枚鲁恩金币金币表面光芒一闪映出身穿阴沉繁复长裙提着四个金发红眼脑袋蕾妮特·缇尼科尔。克莱恩提前准备之一就是用当初携带血之上将塞尼奥尔办法将信使小姐弄到神弃之地！——蕾妮特·缇尼科尔毫无疑问也是怨魂并且是更加强力怨魂同样可以寄居在金币表面光滑地方另外祂是灵界生物本质是灵可以像正义奥黛丽灵体一样进入灰雾之上降临神弃之地。基于这样条件克莱恩为不暴露源堡内部秘密不暴露愚者真实身份先让信使小姐附身在金币上接着用那个铁制卷烟盒做层层封印然后再将这物品献祭到灰雾之上通过赐予仪式弄入神弃之地。当然这些行动前提是克莱恩在源堡内有序列2天使位格和实力哪怕蕾妮特·缇尼科尔出现不对情况也能应付得过来。而蕾妮特·缇尼科尔因为格尔曼·斯帕罗刚帮祂拿回一部分躯体欣然答应这件事情。无声无息间这位信使小姐离开金币出现在乌黯魔狼那占据眼睛四分之三空间漆黑瞳孔内。怨魂附身！

## 这场戏有没有翻
翻了。开头魔狼要弃城；克莱恩星潮瞬入源堡同时打退阿蒙探手、壁钟定格、星之杖瞬移当面、金币放信使附身。翻的是逃狼翻成见面附身，忙而不乱争秒。

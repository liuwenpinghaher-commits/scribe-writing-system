# 858 不死者 第一百二十七章 新的蘑菇

## 打开书
未来号船舱底层。弗兰克点烛，推开血肉蘑菇小麦鱼，写信：干蘑菇停产只剩三；新产物黑暗吞血肉繁殖——小麦磨粉、奶牛榨奶、鱼类口感；须90度以上煮五分钟灭活，否则吸脏器；不辨人怪血肉积毒疯；缺怪物尸体求寄。搬开附近泥土再召信使。皇后区霍尔家：奥黛丽瓶中催眠师魔药，安抚后灌下。意识炸、体虚化，感集体潜意识大海与灵性天空；克制融入，鳞片金发异变退。镜中碧眼藏漩涡——灵性未敛。自语：你可已是序列6。能力：身体增强与鳞片；心理暗示质变催眠改意识；战斗催眠短时反常；心理学隐身意识死角。憾无直接攻击。苏茜配合练习。女仆安妮：周六教会慈善晚会助学基金，邀父母希伯特。奥黛丽：参加；问清基金再定捐额。夜因蒂斯塞伦佐：佛尔思叹华丽；休贬因蒂斯无内涵。开门入小包厢橱柜。聊3%至少几千。唐泰斯与马赫特一家入座。休感异常又压下。克莱恩灵视：金发红眼头咬胀信钻出，奶麦鱼味；接信入兜，三人未觉。侍者上黄油煎蘑菇——反胃，左掌轻抖。

## 这场戏有没有翻
翻了。开头还在船舱写蘑菇说明书；章末同一味觉撞上晚宴煎蘑菇与信使头。翻的是新蘑菇能否当助兴特产，不是序列6独自闪光。

# 981 红祭司 第三十六章 “诡法师”VS“寄生者”

## 打开书
目光投花园：灰白鼠绕核心疯转挤入；核心近短毛猫大的灰鼠血红眼甩尾，近者按咬，尸堆旁仍涌。两个想法：灰雾加强的直觉预感帮分灵体之线——城市建筑里否则难精准，除非行为特殊或无差别控；寄生半神已失控边缘，体型大数倍暴虐。直线＜50米可直控。巨鼠察觉转厨，红光闪——「窃取」格尔曼两秒主念，未做窃梦家式动作；右爪欲窃非凡能力（同目标可盗三种、维持2小时，一次一种）。思绪滞涩：灵体之线初控。窃念成功只是幻术！克莱恩已与恩尤尼换位，秘偶无自我念头偷不走。本体在庄园外＞500米；能力可赋秘偶含控线——隔约1千米一偶可延伸，但总偶≤50；不能赋思维；偶控偶极限＝自身极限1千米；赋能实质分神话蠕虫，超50精神分裂难愈失控加重。试验极限1000+150米，新偶完全掌控须≤1000米；偶死蠕虫依聚合回归，打断或丢。鼠偶冲花园张嘴空气炮。巨鼠红亮：「窃取」位置——斯帕罗落尸鼠间、半神上长桌。炮犁花园，土削薄，恩尤尼放尽好运无伤；控线断。半神窃走控灵体之线；大范围盗鼠行走，鼠偶软倒。红眸符号解密找本体；窃距离到身前。消瘦男子消，余灰鼠；树虫张嘴空气炮淹没。坑中血肉碎，无非凡特性析出。弹金币占卜，半神星灵体启示更多。

## 这场戏有没有翻
翻了。开头花园巨鼠尸堆旁；章末轰炸现场无特性、金币启示未完。翻的是「当场打死」变成「壳碎人逃」，不是空气炮热闹。

麋鹿庄园夜。厨－花园直线战。庄园外五百米外本体。尘土血肉坑。金币弹起。

## 这一章新讲明的规矩
- 直觉预感＋灵体之线：城市建筑中定位关键。
- 序列4窃取：同目标可盗三种非凡能力、维持约2小时，一次一种；可较准三选一；低层次深了解可想偷就偷；可窃位置、距离、行走等。
- 秘偶无念头 → 窃想法无效。
- 能力赋偶、偶链延伸：约1千米间隔；总≤50蠕虫；偶控偶≤自身极限；不能赋思维；超负荷精神分裂。
- 操纵极限试验：1000+150米；新偶全掌控≤1000米。
- 好运可挡致命齐射但打断控线。
- 无非凡特性析出＝未真死。
- 半神简化占卜信息量更大。

## 热怎么变冷
直线五十米可控还热。冷切在窃念呆滞——原是幻术。空气炮犁园还热。冷切在好运无伤控线断。贴身窃距还热。冷切在换鼠设陷阱。血坑还热。冷切在无特性析出。

## 怎么起、怎么收
第一段接花园鼠绕核心。最后一段停在金币下落、启示画面浮现。章题带引号：诡法师VS寄生者——途经对撞课。

## 叙述怎么插手
两个想法长段：战前能力课。根本就没有的东西怎么偷走：原理刺点。不受限制吗：立刻列50与1千米限。半神占卜更多信息：位阶变化旁白。

## 这一章放了什么
- 失控巨鼠战场与直觉控线：硬仗。
- 诡法师偶链／蠕虫／距离极限：体系课。
- 偷盗者窃念位距能：对手课。
- 无特性＋金币占卜：逃遁钩子。

## 这一章收了什么

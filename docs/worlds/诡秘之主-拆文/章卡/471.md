# 471 无面人 第二百五十九章 隐患

## 打开书
起居凯特琳沙发吩咐晚宴——奥至：「妈妈有事讲。」路感地轻震两下。颔：「你们等下再进。」静；苏茜眼神支外。「应常伴学处事…小天使何事？」欲优雅笑翘不起角。抿干唇：「有事瞒你们。」「嗯？」顿涩转流畅：「已是非凡者；服魔药。」金发碧眼凯特轻挑眉不见诧：「我知道。我和你父亲都知道。」「啊？」掩嘴笑：「宝库拿那么多神奇材天真以为我们无察？父边别墅领地多非凡——雇／女神派／霍尔成员；国王默许；我等默许小小冒险；终须独面；额外能力底牌更好。始段不那么危升需一二三年；拟成年再告诫停现位。」不——不知扮演；新年前可心理医生；不想停尼根明世界不安；愚复苏邪神降临潜危…卸负避叮嘱：「后加隐秘组织偏学术不拜邪；恕不能名详；已立誓。」抢正题：「今收消息：埃爱上平民女是魔女；策划阴谋。」语序：真句可卜认却让人信来自心炼金会。笑消郑：「魔女？」「欢愉魔女。更惧名特莉丝奇克。」「何问题？」「组织成员古书见奇克；四纪或更早属原初魔女。」凝：「邪神！」凯特懂邪神——坐不住：「确定？」「…不确定。」信愚表面不能：「有必要请王室不请女神教会非凡确认；涉邪神再慎正确。」诧抬眼：「…奥黛丽你长大了。」紧顾不上谦——忧紧浮表：「能隐瞒？教会王室憎非己隐组；可说爸爸消息他渠道多。」起拥抱：「放心不让你卷入。父傍晚回；先让隐藏守卫出假装他传讯；再找女神教会派护我等非凡。」「好！」舒气紧张疲。切陨石笼林——无力绝望等死。焰跳亦难砸前脱核；占卜途身脆无法硬扛；活尸亦焦碎…焰跳！偏黄白映眸——有想法秒决。响指燃余火柴赤裹——闪现陨石上方焰！刷坠出焰入高热气。跃中不怕常焰；离态竭操避仍灼；高温气不在跳范围。再响指临界气爆燃闪他焰——避第一波冲击。仍无法脱：或跳偏林承波及；或上跳等蘑菇云吞。幻四分五裂焦黑…念闪眼前红更红黄更黄白更白浓色叠奇油画！油画离现实旁观陨「缓」落砸地——林毁地晃火烟蘑菇云。冲击未及——无法入色块静油画世。愣旁人影：中等古铜黑礼服半高礼帽沧桑褐眸柔和右耳下细黑痣。「阿兹克先生！」喜——卜启即今！血海必死；被阿兹克拉起＝解救！摆手抓臂向浓彩深穿行！切普羽笔停黯——瞎眼严肃中年握通灵快写：「阿兹克明显未恢复全记忆实力；借灵界星界穿行此时恰好因隐患出问题；于是与夏洛克落到距因斯赞格威尔和他朋友不远地方。」

## 这场戏有没有翻
翻了。开头奥坦白非凡；章末救离陨又恰好落因斯旁。翻的是父母早知＋教会将动、油画逃陨，不是隐患解除。

## 话

## 热怎么变冷
早知还热。冷切在啊？邪神还热。冷切在长大了。阿兹克还热——恰好落旁冷切。

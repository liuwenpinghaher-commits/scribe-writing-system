# 503 旅行家 第二十二章 红骷髅海盗团

## 打开书
一位非凡者被允许离开舰队？不需要达尼兹特别说明克轻松就明白为什么觉得奇怪。在值夜者小队即使纯粹文职人员也会受到严格限制正常离职会签终身保密协议不得批准不能离开原本所属值夜者小队辖区获得批准搬迁去别城市后则需要第一时间找当地黑夜教会登记。从这样规定就能看出官方在对待超凡力量及相应事物上态度一位喝过魔药非凡者不可能那么轻松就脱离组织。清楚记得正义小姐最早明明有成为非凡者渠道和办法却不愿意尝试给出理由就是不想失去自由。类似想法脑海内打个转但未化成言语因为礼貌却冷淡格尔曼·斯帕罗是不会对这种传闻感兴趣的。「那又怎么样？」望着桌上餐具平静反问。会不会聊天！烈焰暗中吸口气挤出笑容：「哈哈我只是觉得奇怪我们都怀疑他加入了军情九处以船长身份监控着航线上事情。」有可能…端起装白水杯子抿一口。点的菜肴按分类陆续开始上来餐厅还赠送两杯甜甜冒泡淡金色餐前酒。不再说话专心享用美食觉得这果然比二等舱餐厅好不少。小提琴声悠扬回荡刀叉与瓷盘间轻微接触间杂发生窗外蔚蓝而开阔海面静静荡漾一切都显得如此美好。就在进入餐后甜点环节时一位船员蹬蹬蹬跑进来冲向艾尔兰所在桌子。「船长有海盗船！」没有掩饰自己声音。大部分乘客悚然一惊停止用餐。抬起头眼神幽暗而冰冷望向对面达尼兹。烈焰僵硬一秒钟泛起苦涩笑容压低嗓音：「我说这和我没有任何关系你相信吗？」舒缓下因表演差点抽搐眼睑肌缓慢勾勒嘴角：「你猜。」我猜你个婊子养的！一阵恼怒险些脱口喝骂。保持笑容：「你的智慧足以判断一切。」这时艾尔兰已快速问清楚情况站起身对有些惊慌一等舱乘客：「只有一艘海盗船我们有足够能力应付。女士们先生们请你们有序返回自己房间等待好消息来临相信我混乱造成伤害远远胜过海盗袭击我不希望将来有这样流言说我们白玛瑙号虽然成功打退海盗但有五六七八名乘客自己摔伤。」在他安排下在一位位船员维持下堂娜等人依次离开餐厅回到本身舱房这里面包括克和烈焰。「我以为你会临时接管白玛瑙号争取让这艘船不受任何伤害。」312房间内达尼兹边关门边抱着看戏剧心态问。能够在发现合适人选后立刻抛出橄榄枝并大谈纲领和待遇足以说明他本身就是一个性格外向乐于交谈水手长。瞄他一眼走到窗边望向外面看见海天一色地方有一艘飘着红色骷髅头旗帜大型船只往这边驶来有烟囱也有风帆。「认识他们吗？」双手插兜立在厚厚玻璃窗后。来到斜后方眺望两秒：「红骷髅海贼团中小型势力。船长是赏金900镑海狼约翰逊大副是赏金500镑独眼安德尔森。」在海盗界赏金是身份和地位重要参照物。考虑自己目前还不具备太好水下活动能力而让海盗登船很容易造成无辜人员伤亡沉默几秒：「他们认识你吗？」「当然！」瞬间挺直腰背：「他们有资格参加海盗间盛会曾经被我踢过屁股。」不愧是3000镑知名海盗…表情不变再问：「他们有望远镜吗？」「这是必须物品即使控制住这艘船也会有水手站在瞭望台上用望远镜观察周围情况防止被人突袭。」暗藏不屑回答。他算是看出来这个危险家伙是新晋冒险家而且很可能第一次到海上来。以前是有名赏金猎人？隐秘组织成员？下意识猜测格尔曼过去。「这种时候船长和大副会用望远镜观察这边吗？」本想用900镑和500镑来代称但又觉得有点不礼貌。「肯定的他们必须时刻把握劫掠对象情况。」略感迷惑回答。不明白格尔曼问这些问题目的是什么按照他想法如果自己拥有对方那样强大实力肯定会放任红骷髅靠近找机会登上他们船只将所有人全部干掉。侧过头看向达尼兹露出斯文和煦笑容：「这就好。」你想做什么？不要这样笑！忽然恐慌鼓起奋力反抗勇气。「摘掉你的假发。」平静吩咐。啊？一阵疑惑动作缓慢取下头顶假发。从衣物暗袋内掏出一瓶特制纯露递过去：「擦干净你眉毛和脸。」这是晋升无面人前为小丑伪装准备神秘系卸妆露在围杀玫瑰学派那位怨魂时用过。现在自然不再需要这种东西但一直没舍得扔。「…」愈发不解但在对方有实质攻击前不愿意弄到无法返回地步只好按照吩咐清洗掉脸上伪装恢复原本样子。收回金属小瓶拉开窗户让外面海风倒灌进来。「你站到这里朝向外面。」指窗户正后方对烈焰。茫然又警惕走过去稳稳立在窗户后。审视几秒平静：「你有两个选择一是自己爬出去显眼地挂在那里二是被我提着衣领显眼地挂在那里。」「你想做什么？」脱口问。再次露出和蔼笑容：「把你展示给那个海盗团人看冰山中将第四水手长应该有足够分量劝退他们。」「不不能这样！」下意识选择拒绝。能够想象红骷髅人发现自己后会做出什么样判断要么是烈焰被抓捕船上有非常可怕强者要么是这艘船已被冰山中将盯上其他海盗立刻远离。而我被挂出去姿态就决定他们会往哪方面想…悲哀想。笑得愈发和善：「我是一个很好相处的人真的只要你按照我吩咐做。」这瞬间又感受到那种难言喻无法描述饥饿感只觉身上血肉和体内灵魂随时会被撕掉一块。权衡一秒半举起双手咬牙笑：「我自己来。」忍着愤怒和憋屈转身爬出窗户靠着常年练就平衡和力量以向后双肘为支撑挂在船舱外。「不要试图逃跑我不是一个有耐心的人。」表情转冷语气温和提醒一句。呼…忍住松开手肘直接跳下去冲动。远处海盗船上负责观察白玛瑙号船员向海狼约翰松传递消息：「头儿那边有个奇怪家伙自己挂到窗户外！」愣一秒抬起望远镜抵至眼前。很快发现手下口中奇怪家伙因为对方位置实在太显眼。这这不是烈焰达尼兹吗？眉头一跳认出对方。他怎么会出现在白玛瑙号上？他挂在外面是什么意思？这是冰山中将猎物？一连串疑问后海狼做出判断。举起右手：「全部注意立刻远离这片海域！」……305房间内克里维斯紧握左轮站窗边预防可能发生接舷战。堂娜一家有些害怕没有返回各自卧室就那样坐客厅内等待炮击开始塞西尔和另一位保镖蒂格则守身边全神戒备。就这时克里维斯略显沧桑眼睛里露出不解神色。过好几分钟后退一步垂下枪支对众人：「海盗离开了。」「什么？」这样发展让乌尔迪·布兰奇等人既惊讶又不解完全弄不清楚那群海盗在想什么。……312房间。烈焰爬回来难以忍耐哼一声：「你这是在借助我们船长名望！她很厌恶这种事情的！」你等着被冰山中将教训吧！心里愤恨想。安静听完若有所思反问：「我记得她在鲁恩赏金是26000镑？」…这个疯子…完全找不到语言来应对。

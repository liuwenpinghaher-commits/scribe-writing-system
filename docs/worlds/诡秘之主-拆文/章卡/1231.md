# 1231 逐光者 第八十二章 对比实验

## 打开书
克莱恩成为半神能初步控制源堡不让它气息渗透入现实附加于自己身上后就没再考虑过类似方面问题毕竟这会呈现异常导致他一眼就能被命运相关途径非凡者认出相当不安全而此时此刻一得到威尔·昂赛汀提醒他只觉思路豁然开朗。当我还只是附属于源堡有一定使用权时附带源堡气息和投影就能让一位命运途径圣者不敢直视让相应中低序列非凡者就如同看见神话生物现在已经初步掌控源堡我大概率能让效果变得更好……这可以影响到本身就是完整神话生物天使？源堡层次至少达到序列0？嗯按照我推测这说不定比序列0更高一点……有类似了解就会承受污染特质？克莱恩念头一下活跃仿佛一道道闪电在他脑海划过。他迅速决定返回神弃之地后找黑暗深处怪物和历史迷雾内秘偶做些实验以此推测自己想法是否有用。他脸上随即露出些许笑意对黑色婴儿车内一岁多小孩：我大概明白你意思最近我会让人给你送冰淇淋。裹着银色丝绸威尔·昂赛汀缓慢别过脑袋望向旁边：不不用。我这段时间吃太多冰淇淋都有点影响身体发育……克莱恩挑下眉毛：纯正因蒂斯首都特里尔出产顶级冰淇淋。……下周再给我。威尔·昂赛汀犹豫下回答。说完这肉乎乎一岁多小孩翻个身将脸埋到婴儿车内小枕头里。由于魔术师小姐能维持历史孔隙影像时间有限克莱恩没再多说什么借助本身特质强行挣脱梦境醒过来翻身下床。紧接着他探出右手往空气里薅一下又一下。四五下后他手臂一沉拖出一位着简朴亚麻长袍系树皮腰带赤着双脚披着乌黑长发容貌普通女士。黑夜教会苦修士首领隐秘之仆阿里安娜！同一刻希尔斯顿区一栋房屋内安乐椅上佛尔思似乎被无形丝线拉着猛地坐起来身体挺得笔直额头血管直跳。她感觉自己灵性就像决堤洪水汹涌着奔向前方虚空怎么都遏制不住眼看就要变得干涸。下一秒钟这种趋势缓解不少但依旧吓人不是现在她能完全承受。旅馆房间内见阿里安娜女士历史孔隙影像获得意识克莱恩长话短说直接开口：我打算与人合作共同对付玫瑰学派某位巫王。阿里安娜轻轻点头表示知道但没有给出自己建议。见这位苦修士首领未做警示克莱恩对狩猎巫王计划放心不少转而：我最近要筹划针对乌黯魔狼行动。阿里安娜嘴巴微张：谨慎。……意思是不要小瞧乌黯魔狼科塔尔？克莱恩正要反问一句意识突然模糊看见对面女士和祂眼中自己同时虚化飞快不见。啪！佛尔思倒在安乐椅上脸部肌肉轻微抽搐。这比以前赶稿通宵写作还累……她呲牙咧嘴一阵赶紧尝试冥想以此入睡。——人在极端疲惫情况下有时反而会出现睡眠障碍。……神弃之地北方遗迹诺斯古城附近无人深黑旷野内。克莱恩提着散发昏黄光芒马灯转一圈确认周围情况。然后他找块石头坐下不再屏蔽灰雾气息对现实渗透。在这个基础上克莱恩还有意识加强源堡在自己身上投影。做完准备克莱恩迅速将周围黑暗里潜藏一个怪物转化成秘偶。秘偶走出没有光芒区域在马灯照耀中靠近克莱恩将目光投到他身上。这普通怪物制成秘偶眼里穿黑色风衣戴半高礼帽克莱恩除眼眸变得更为幽邃气质变得更加难以描述外与之前没什么区别。连续让不同类型怪物秘偶试一遍后克莱恩确认普通人或者说绝大部分非凡者是没法发现自己身上附带源堡气息。接着他探出右手拖出半天前自己并操纵这个颇为呆滞历史孔隙影像将目光投过来。这一次克莱恩看见自己身上笼着一层灰白雾气内里点点光芒闪烁却没呈现出具体模样。他随即解除对这个历史投影维持尝试着抓出秘偶大师罗萨戈等占卜家途径非凡者重复起刚才实验。嗯加强投影后占卜家途径非凡者是能够直接发现一定异常不过至少天使以下只能确认我与源堡有关无法直观看见那扇奇异光门也就是源堡投影……克莱恩对这样结果并不是太意外。他深吸口气在做好自我抢救准备后抬手一拉拖出刚成为自己秘偶没多久时赢家恩尤尼。恩尤尼一点点抬头眼睛里逐渐映出克莱恩身影映出淡薄往外弥漫灰白雾气。雾气深处或透明或半透明扭曲蠕虫合抱成数不清光球光球层层叠叠组成一扇染着些许青黑光门。光门比以往清晰很多更加具有质感同时它形状也发生变化往顶部拉伸变高不少。这让它就如同一道瘦高灿烂人影而周围灰白雾气就是这人影带兜帽长袍。不同光球辉芒不断闪烁让克莱恩就仿佛被这深沉神秘高远恐怖人影用一只只眼睛注视着。轰一下克莱恩脑袋不由自主向后仰起一股股鲜血夹杂着一条条透明蠕虫从他毛孔里喷出来。那一条条灵之虫落到地上疯狂翻滚挣扎有部分迅速溃散有部分最终平静下来又爬回克莱恩身体钻进毛孔里。嘶……比上次直接昏迷过去失忆一样好多……克莱恩揉揉额角无声感叹一句。他面前赢家恩尤尼已因为他刚才受到冲击无力维持历史孔隙影像直接消失不见。这也是克莱恩这次没遭受太严重伤害原因之一。——没有赢家恩尤尼他就无法看到那出现变化奇异光门不用被持续冲击。缓两秒后克莱恩进入历史迷雾里逆走四步来到灰雾之上。看着一丝丝虚幻幽暗光芒从体内腾起消融殆尽克莱恩终于松口气自嘲一笑：差点自己污染自己自己侵蚀自己……之后再用罗萨戈等占卜家途径非凡者做另外实验：在不直接遭受冲击情况下随着观察时间增加是否会被源堡投影反向污染…………南大陆东拜朗遭受攻击凡尔特克城。绯红之月照耀下躲在简易工事后鲁恩士兵们正抓紧时间轮流休息以恢复精力。他们脸上黑乎乎尽是硝烟痕迹时而有人醒来拿出晒干烟草随意裹一下就用仅剩火柴点燃凑至嘴边深深吸上一口眼中透出更多是麻木和茫然。值守着这道防线几位士兵闻到烟草味道下意识抽抽鼻子回头望一眼。你还有烟草吗？一位提着连发步枪士兵压低嗓音向同伴询问。他战友摇头：早就抽完。也不知道下一批什么时候才能到……没有烟草我都快疯！最开始说话那个士兵用下巴指指工事外面：看见了吗？那么多尸体那么多手那么多脚之前都是属于活人。太阳下山前反抗军发动一次猛攻疯一样冲击着凡尔特克城各条防线他们不要命姿态吓到坚守鲁恩士兵和仆从军们险些就取得胜利但最终他们还是未能突破关键防线丢下大量尸体潮水一样退走。他战友沉默一下：也许明天也许后天我们也会变成这样。说到这里他抬头望向那绯红月亮梦呓般：不知道贝克兰德怎么样了我很久没收到家里信……不知道他们有没有足够食物生病了能不能找到医生……刚才想要抽烟士兵正想骂一句脏话诅咒这该死战争和该死敌人眼睛突然发直颤抖着抬起右手指着前方：活活了活了……一个个士兵随之望过去只见绯红月亮下之前反抗军丢下残缺尸体们一具又一具爬起来摇摇晃晃着试图靠近防线。远处一位神秘人戴着兜帽身穿绣有绯红花纹黑色长袍立在反抗军后方微微张开双臂。整个战场灵性正飞快滋生。

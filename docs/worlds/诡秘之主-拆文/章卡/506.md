# 506 旅行家 第二十五章 风中的班西港

## 打开书
堂娜身体猛地后躲瞳孔剧烈收缩嘴巴半张开尖叫之声已至唇边。如果没有之前看见信使经历她肯定早控制不住自己惊恐而踉跄站起不管桌椅是否会倾倒。幸运已非初登白玛瑙号时对海上之事完全不懂那个小姑娘嗓音只是略微变尖指着窗户外面结结巴巴：「有有活尸！没脑袋活尸！」用民俗传说里最常见活尸来描述刚才见到那个可怕东西。塞西尔刷一下站起两步来到堂娜身边疑惑望向狂风大作窗外仔细审视几秒。「什么也没有。」如实说。堂娜往后缩缩鼓起勇气小心翼翼前倾身体凑拢过去只见外面树木摇曳杂物乱飞一个行人都没有。「刚才刚才真的有他他披着黑色斗篷没有脑袋脖子在流血！」边说边比划想让在场成年人相信自己。父亲乌尔迪撑着桌子站起来走至窗边凝望一阵：「堂娜今晚不准再看那本梵西恐怖小说集！」「可是可是…」委屈想要申辩。就这时克里维斯上到二楼靠拢过来：「发生了什么事情？」「堂娜说她看见外面有活尸没脑袋活尸。」另一名保镖蒂格轻笑解释。克里维斯默然两秒对堂娜点头：「没事会过去的。外面风很大更危险等平静下来我们再离开。」于堂娜眼里克里维斯叔叔话语表明他相信自己并选择最稳妥解决办法而在乌尔迪蒂格等人看来这是安慰小孩拙劣伎俩。见堂娜还有些紧张真正雇主也不太满意克里维斯边拉开椅子坐下边沉稳：「班西港有一种奇特风俗在天气变化剧烈夜晚不要离开房屋不要回应任何敲击声。」「如果开门就会被那个活尸抓走？」和姐姐一起见过白骨信使丹顿恍然问。「可以这么理解。」端起白水喝一口。原来是这样…堂娜安定下来相信自己只要不离开餐厅就不会遭遇刚才那恐怖活尸。直到这时才发现周围食客早因这边动静纷纷将视线投过来。被一道道目光注视只觉全身上下都不自在本能就想埋低脑袋躲避一切。我又没做错什么！我真的看见了！倔强挺直脖子环视一圈。看见一位位穿燕尾正装绅士和衣裙漂亮女士收回视线看见他们低下脑袋拿起汤勺将瓷碗内放了好几种香料暗红血块舀入口中。他们唇边染上一抹血红脸色在水晶吊灯光芒照耀下显得颇为苍白两者对比鲜明让堂娜莫名多了些名为恐慌情绪。忙转正脑袋等待晚餐并暗中向女神祈祷希望狂风尽快停止。……班西港电报局。艾尔兰和大副刚拍完给海军情报就发现外面风声呼啸拉扯地附近门窗哐当作响。「真是的这里天气总是这么不稳定。」戴上船形帽叹息笑。大副哈里斯哈哈一笑：「要不然怎么会有天气博物馆这个称号？」「你们最好不要出去传说会因此失去自己脑袋。」电报局工作人员一位棕色卷发小姐语速缓慢提醒。「我知道但我试过几次什么事情都没有发生。」哈里斯一点也不在意就要拉门离开。艾尔兰阻止略作思考：「去旁边教堂没问题吧？你们电报局应该是要关门了对吧？」「没问题。」还是那副慢条斯理样子。艾尔兰点头拉开电报局大门逆着能卷起小孩般狂风向几十米外风暴教堂艰难行去。大副按帽子跟在船长身旁似乎想表达可直接冲回白玛瑙号想法。但他刚一开口就被狂风灌入嘴里所有声音都惨遭塞回。支支吾吾一阵明智闭上嘴巴不再做明显不现实提议。此时距离7点还有一刻钟只能算傍晚风暴教堂大门依然敞开面向信众。狂风来到这里变得柔和许多至少不需要再担心帽子随时会抛弃自己。进入教堂走完那条阴暗森严过道两人踏足大祈祷厅看见一位穿深蓝色牧师袍男子坐在最前排安静望着圣坛上那枚由狂风海浪雷霆等符号组成巨大风暴圣徽。艾尔兰笑着靠拢过去拍下那熟悉身影肩膀：「杰斯你们主教呢？」被这么拍一下后那位牧师脑袋出现明显晃动。接着它向前一倒砰当一声掉在地上连续做出翻滚。牧师脖子处鲜血如喷泉般涌出淋了艾尔兰一脸。冰凉湿漉感觉传入心里鲜红浓烈颜色蒙蔽眼睛。视线中只剩下一片血色世界以及那个终于停止滚动两眼茫然朝上脑袋。……7点15分从一等舱餐厅出来克和达尼兹发现刚才吹得船只摇摇晃晃狂风已平和不少。想两秒一路走至船舱入口询问守在那里船员：「还有谁没回来？」那名船员见过这位乘客和船长一起享用美味鱼人肉没做隐瞒：「除了去青柠檬餐厅布兰奇一家迪默多一家其他乘客都在风起前回来了呵呵那里比较远用餐时间也比较长。啊对船长和大副去了电报局也还没回来。」微不可见颔首沉默返回312房。站窗边望着被风吹起一道道海浪哪怕不去灰雾之上神秘空间占卜仅凭本身灵性直觉也能隐约察觉正有什么不好事情在酝酿在发生。又等待五分钟依然没看到艾尔兰船长和堂娜一家返回。侧头瞄达尼兹一眼让正懒散躺安乐椅上知名海盗一下坐直。收回视线什么也没说走入盥洗室。熟练关门抽纸人做伪装来到灰雾之上准备再做一次占卜。之前考虑班西港潜在风险现在风起之后打算确认目前危险程度。「班西港有危险。」持握灵摆低念语句。一遍又一遍后睁开双眼发现黄水晶吊坠虽然在做顺时针转动但幅度不大速度不快。有危险但属可接受范围…这和之前启示矛盾啊…双肘支青铜长桌边缘疑惑自语。迅速想到一个可能那就是当前危险不等于潜藏风险除非触发了什么或者深入调查出了什么事情才会让海平面下藏着冰山呈现。这潜藏风险也许已经存在三四百年甚至更久并非因为我到来才有…嗯当前危险甚至可能和潜藏风险一点关系也没有可惜缺乏必要信息无法就这个猜测做占卜…做完解读迅速返回现实离开盥洗室找张椅子坐下。沉默着犹豫着许久没有动作这让烈焰莫名感觉不安。自从格尔曼说出班西港有潜藏危险后这位知名海盗就一直有些担忧。能让这怪物改变注意不去青柠檬餐厅危险肯定非常可怕…我这次度假怎么就这么惨？简直厄运缠身！被近乎凝固气氛弄得实在坐不住只好站起身来回踱步。就这时看见格尔曼这怪物突然站起边扣上双排扣长礼服纽扣边走向门边衣帽架。取下半高丝绸礼帽望向烈焰没有表情：「你自由了。」「啊？」只觉这一点也不真实。忽然明白对方想做什么愕然脱口：「你要去救那个船长还有那些普通人？你你自己说外面很危险的！」戴上半高丝绸礼帽拿起黑色硬木手杖边拧动门把手边平淡回应：「他们和我合作过。他们替我保守了秘密。他请我吃过鱼人肉。他帮我赔偿白鲨损失。」…一时没反应过来下意识问：「赔偿了多少？」「几苏勒。」打开房门走出去。疯子！这家伙是彻头彻尾疯子！不管对别人还是自己而言他都是疯子！嘴巴半张难以成言。还好我是一个正常人！我会待在安全地方！收回视线半嘲笑半愉悦想。念头刚落狂风再来吹得玻璃窗吱嘎作响让屋内蜡烛光芒摇摇晃晃。看着这昏暗涌动一幕突然想到一个问题：这艘船停在港口也算是班西港一部分也不安全也有可能承受风险！我自己一个人待在这里还不如跟着那个怪物至少至少他很强大！身体比脑子快蹬蹬蹬就跑出312终于在克离开舱房前赶上。侧头看他一眼虽然没有说话但疑问意思已非常明显。忙哈哈笑：「只是这么小危险就选择退避我会被苏尼亚海上所有海盗嘲笑的！」借口…没有戳穿从门口船员那里借盏马灯。提着昏黄马灯握着硬木手杖身穿黑色长礼服沿着船舷进入昏暗港口。达尼兹一边哀叹一边牢牢跟在旁边。

## 这场戏有没有翻
翻了。堂娜尖叫开；章末提灯入港。翻的是几苏勒人情＝救人出门，不是躲船等风停。

班西傍晚狂风；青柠檬；电报局／教堂；船舱再出。

无头活尸民俗对上；牧师头落；克放自由救人。

## 话
「没脑袋的活尸！」「杰斯，你们主教呢？」头落。「你自由了。」「几苏勒。」局面是从活尸收到风俗安；从教堂收到血脸；从占卜矛盾收到犹豫；从自由收到跟出。

## 热怎么变冷
尖叫还热。冷切小说集。头落还热。冷切血色世界。自由还热。冷切几苏勒。借口还热——入港哀叹冷切。

# 1314 倒吊人 第四十九章 总结报告

## 打开书
贾斯敏认为自己应该恐惧可面对眼前女性警官却难以产生太过强烈情绪波动有种哭很久后身心不自觉沉淀感觉。好的你们想问什么？她看眼表情复杂父母后略显迟疑问道。那位戴警司衔女士指指房门道：进去再说。……你们可以称呼我格蕾女士。……我收到汇报说是你身边发生一些难以理解事情比如男性侵害欲望明显高于正常水准……据我所知你在之前一次火灾里受伤严重出现无法挽救毁容情况可现在我完全看不出这一点对此你有什么想说？……我今晚出门去市政广场参加狂欢节路过一条街道时候遇到一个自称梅林·赫尔墨斯流浪魔术师他说他发明一种机器叫做全自动许愿机只要投入1便士硬币小声说出自己愿望并转动扳手就能让愿望得到实现。他说我是第一个体验者可以免费尝试一次然后然后我就变回原本样子所有伤势都好了。警官事情就是这样你们一定要相信我。……这怎么可能？怎么会有自动实现别人愿望机器？……继续。格蕾见她停顿下来鼓励点点头。……我确实变得非常美丽……加上爸爸和妈妈认不出我将我赶出家门我很害怕……又回到那里许下第三个愿望……我又变回原本样子然后就遇上你们。听到这番话语贾斯敏父母瞬间联想到之前那个美丽小偷。……我见过许多超乎你们想象事情但还是第一次听说全自动许愿机这种东西。和民俗传说里许愿神灯愿望水池相比这实在是太现代化了。……作为一名还算有经验执法者我给你们三个建议：第一从此之后不要再相信类似事情绝大部分情况下愿望轻易实现都伴随着巨大灾难说是魔鬼诱惑完全没有一点问题。……第二尽快前往教堂向主教忏悔这件事请他给予净化你们一家都必须去。……我部门还缺少一些文职人员你可以考虑加入我们这样一来我可以随时监控你情况及时处理异常至于薪水相信我和政府雇员差不多。……是什么部门？我给你一个地址你明天到我办公室来找我了解具体情况。……好。贾斯敏正处于惶恐不安状态中眼前哪怕出现一根稻草都会伸手抓住。一周后贾斯敏正式入职利蒙市值夜者队伍担任文职人员。队长那台有线电报机坏掉了。……报给警察局让他们来处理。真是以前可以直接让机械之心人帮忙修又快又好现在哎……这是最近一周以来值夜者们搜集到与全自动许愿机有关情报。……本市最近一周已发生多起超凡事件涉及一台叫做全自动许愿机奇特机器……案例1……案例2退伍士兵……案例5老师得人偶夫……结合这些案例可以初步得到一些猜测：全自动许愿机能出现在利蒙任何地方随机性非常强……向它许下愿望大部分都能得到正常实现可有小部分会出现扭曲后者基本集中在第三个愿望上……它实现愿望以改变容貌居多但涉及范围很广近似全能……这是一件典型需要封印神奇物品且明显超过2级封印物这个层次希望大主教和高级执事亲自前来处理……离开利蒙蒸汽列车上克莱恩审视起自己奇迹师魔药消化情况。

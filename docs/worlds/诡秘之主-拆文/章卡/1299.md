# 1299 倒吊人 第三十四章 第四个人

## 打开书
贝尔纳黛长久凝视着那些轮廓直到它们随着黎明号靠近逐渐清晰勾勒出一座面积不小岛屿。岛屿上一棵又一棵深绿近黑巨大树木高高耸立覆盖地面遮蔽山峰。虽然贝尔纳黛还无法肯定这就是自己父亲曾经到过那座原始岛屿但一名预言大师直觉告诉她这很可能就是她追寻那个地方。随着海岸线映入她眼帘她抿下嘴唇埋低脑袋诵念出一个尊名：不属于这个时代愚者灰雾之上神秘主宰执掌好运黄黑之王……紧接着神秘女王贝尔纳黛抬下手让没有船员黎明号停在近海不靠近岸边。……这位神秘女王没急着深入寻找可能存在黑皇帝陵寝谨慎让蔚蓝如大海眼眸变得幽深短暂失去焦距似乎在窥视那条命运河流。……当然这是她预料之中事情因为她主动诵念愚者先生尊名。灰雾之上古老宫殿内克莱恩容纳愚者牌披着那块幕布拿着星之杖正通过神秘女王祈祷光点审查那座岛屿情况。……即使不是罗塞尔大帝发现那座原始岛屿这里也不简单……克莱恩微不可见点下头等待着神秘女王做更多探索。……这同样是来自神秘再现童话魔法之一核心是一顶能让人隐身帽子。……然后这双窥秘之眼被看不见双手拿住安放在一个透明人脸上。这是属于贝尔纳黛无形仆役。这无形仆役带着窥秘之眼快速通过剩余道路来到开阔林地处。……终于这无形仆役抵达开阔地带边缘将那里情况通过窥秘之眼传递回贝尔纳黛视野中：……她从星之上将嘉德丽雅那里知道自己父亲发现那个原始岛屿曾经存在某种奇特污染可以让因此死亡生物不管尸体在何方都回归这里回归源头。当初追随罗塞尔大帝骑士里先是格林因此身亡之后是威廉和珀利但除他们三位再没有别的人牺牲于相应事件中而此时那些超凡或异变生物里有足足五个人存在。……难道不是那个岛屿？这位神秘女王通过窥秘之眼挨个审视起那五个人类。……因为这五个人都匍匐于地上贝尔纳黛暂时看不到他们容貌只能耐心地等待祈祷结束。……格林他真是格林这里就是那座原始岛屿……这是威廉叔叔我记得他样子他曾经教过我剑术……珀利叔叔……而据她从冰山中将艾德雯娜那里获得情报显示爱德华兹活到近一百岁非常安详逝去葬在伦堡郊区一处墓园内。爱德华兹叔叔也回到这座岛屿……他不是没遭遇污染没因此死亡吗……贝尔纳黛脑海里闪过一个又一个想法以至于那双安在无形仆役脸上窥秘之眼一直注视着疑似爱德华兹那个人类。那位先生容貌苍老头发已经全白与艾德雯娜·爱德华兹展示祖先晚年画像一致而从五官和轮廓里贝尔纳黛也能看出对方壮年时样子。……突然疑似爱德华兹那个人类转过脑袋用冷漠木然眼睛望向无形仆役所在地方。贝尔纳黛虽然继承罗塞尔大帝不少遗产但能在神秘世界一步步走到现在靠得绝对不只是物品这个瞬间她当机立断直接让窥秘之眼散去让无形仆役回归灵界。……这是发生什么异变？……过一阵精通预言贝尔纳黛终于确定那片开阔空地上已没有生物存在遂又一次召唤出无形仆役将窥秘之眼给它。这无形仆役穿越森林稀疏部分和完全空旷地带小心翼翼抵达刚才那些生物膜拜地方。……无形仆役绕半圈来到神龛正面发现内里空空荡荡没有神像也没有象征符号组成徽章等物品。这座岛屿上生物们朝拜似乎是并不存在东西。

## 这场戏有没有翻
翻了。开头见岛诵愚者；仆役窥五人；认出格林威廉珀利＋第四爱德华兹；章末空神龛拜虚无。翻的是第四个人＝安详死亦归岛。

# 1197 逐光者 第四十八章 “狂乱”

## 打开书
秘之圣者布提斯进入灵界后立刻开始穿行直奔苏尼亚海最东面神战遗迹。就在这个时候他思绪突然模糊一下身体直接转向从另一个地方离开灵界。等到布提斯灵性预警精神紧绷找回属于自己念头映入他眼帘已是一片叶子近乎落尽光秃秃树林周围寂静无人高空红月高悬。作为曾经旅行家和占星人布提斯立刻就辨认出自己所在位置发现依旧在贝克兰德只不过从城区移到郊外偏远之处。与此同时他也明悟究竟发生什么事情：他心灵世界不知什么时候潜入别人意识在关键时刻影响他念头修改他预定目的地！那个观众途径半神！我竟然没有发现！布提斯瞳孔猛地放大倒影出一本银白色虚幻书册。那书册哗翻动一下就到其中一页。布提斯当即抬手抓向自己眉心从没有实体意识岛屿内直接抓出一团黑暗将它丢入自己影子里。他影子随之和他分离扭曲站起呈现出女性轮廓。黑骑士堕落之影！这是布提斯从幽暗圣者克斯玛那里记录来能力可以将自己内心堕落意念分离出来和影子结合形成一个不受控制独立生物。布提斯利用它清除内心不属于自己意识摆脱操纵师影响！同时这也是布提斯反击只要潜藏那位观众途径半神不能很快解决这个阴影她分化出来意念就会逐渐独立导致本人半疯甚至失控。一解决掉心灵隐患布提斯毫不犹豫就要脱离敌人预设战场传送去别地方。可这个时候他精神突然变得狂躁只觉整个环境都在为难自己怒气再也无法遏制。随着布提斯眼眸内那本银白书册翻动整片树林轰隆一声塌陷那个黑色阴影几乎摊成一团。狂躁之后布提斯情绪又变得极为低落对任何事情都打不起精神感觉自己毫无用处是别人是世界负担。精神瘟疫！在之前那场战斗里布提斯就感染精神瘟疫到现在终于发作！嘉德丽雅之所以最开始就用卖火柴小女孩不仅仅因为想干扰布提斯传送离开还是在帮正义小姐遮掩痕迹让她虚拟人格能在不引发布提斯灵性直觉情况下潜入对方心灵世界引而不发只是悄然种下精神瘟疫源种。正因为如此在突袭未能成功时嘉德丽雅和奥黛丽才敢于启动预案自行退去让秘之圣者和幽暗圣者在没有危险后主动分离各回各处。嘉德丽雅最后燃烧青绿藤蔓制造极大动静表面看是引来官方势力注意让敌人放弃追踪实际是逼迫秘之圣者尽快离开没时间仔细审视和检查自己深层次状况。于是他传送关键时刻被奥黛丽虚拟人格篡改念头直接来到贝克兰德郊外来到塔罗会挑选好无人之地。而等到他解决操纵师虚拟人格精神瘟疫又紧跟着爆发。其实如果布提斯早点使用命运之重启那他肯定能回到没有隐患潜藏状态但直到差点被朗基努斯之枪杀死他才决定掀开这张底牌而那个时候距离心灵世界被侵入已远超三秒钟！这个时候失落低沉努力对抗着精神疾病布提斯看见前方虚空里滚出来一个不够真实线团。这线团后方鲜艳毛线一直延伸向无穷远处。沿着这一根线穿紫纹黑袍戴深色兜帽嘉德丽雅从灵界走过来出现于秘之圣者面前。她是没有办法追踪进行干扰敌人但可以和预定战场建立联系可以追踪正义奥黛丽虚拟人格！刚一抵达嘉德丽雅就闭上眼睛分化出一道虚影倒向无形棺材。本就低落沉郁布提斯瞬间觉得极度疲惫眼睛止不住合拢想要倒下。睡美人！另外一边还没有真正独立奥黛丽虚拟人格如一道深黑影子带着堕落滋味抬手捏捏自己额角。她瞳孔无声无息竖起来淡金而冷漠。布提斯脑海顿时炸裂体表出现一个又一个光之泡沫泡沫之中一条条星辉凝成头尾皆融入虚空虫豸想要钻出。心理医生狂乱！这能彻底引爆目标情绪甚至导致他失控。布提斯本就感染精神瘟疫处于极不正常状态后续又遭遇睡美人影响心情极为低落此时被狂乱引爆这一切顿时有点难以自控出现失控征兆。抓住这个机会嘉德丽雅睁开眼睛抬起右手让掌心飞速形成一团缓缓旋转星沙。黑夜下树林变得更加幽暗高空红月消失一颗又一颗星辰浮现出来密密麻麻璀璨夺目。这些星辰洒落一道又一道辉芒交汇成恢宏光之巨柱笼罩秘之圣者和他周围那片区域。应激之下布提斯清醒一些身影飞快虚化不断闪现在树林内制造十几道残影。可是他怎么都摆脱不了星光笼罩无法瞬移出去。一个又一个布提斯被星光溶解崩溃消散最终只剩下一个单膝跪地将手掌按在地面布提斯苦苦支撑。这个布提斯身体破破烂烂眼睛已一片暗红近乎疯狂。等到星辉无法维持他一个闪现避开奥黛丽虚拟人格后续攻击。然后他不断闪现在嘉德丽雅和奥黛丽虚拟人格旁制造一个又一个分身。他其中一个分身左手一抓扭曲奥黛丽虚拟人格对应黑影所在区域将它隐藏起来借此限制住敌人。而他另外一个分身则张开双臂招来缭绕着神圣火焰粗大光柱让它落向被隐藏起来那片空间。这个过程中布提斯别分身悄然解除对空间隐藏。于是奥黛丽虚拟人格对应阴影刚一脱离限制就被神圣炽烈光柱笼罩飞快消融不见。——处于闪现状态布提斯能比正常更快使用非凡能力但无法持久这是通过一条条星之虫分别发挥作用实现。另外一边秘之圣者同样在围攻嘉德丽雅他使用出一种又一种能力彼此配合在短短一两秒内向目标倾泻大量攻击。这逼得嘉德丽雅只能不断利用皇帝新衣规避一时无力反扑岌岌可危。几秒之后布提斯闪现终于慢下来他心中狂躁也舒缓不少。就在这个时候树林外面突然浮现出一片片灰白厚重鳞片它们若隐若现仿佛构成一个极有压迫感庞然大物。红月被遮蔽深沉黑夜里一道近乎无形透明吐息从上而下笼罩布提斯和嘉德丽雅。两位半神顿时如遭雷击精神产生撕裂灵体似被洞穿。心灵巨龙吐息！精神状态本就非常糟糕又用好几张底牌布提斯脑海随之空白眼前有一道又一道光闪现身体忍不住微微颤抖。而嘉德丽雅携带着从魔术师佛尔思那里拿来月亮纸人这能帮她承担一次精神刺穿！虽然这无法完全消除心灵巨龙吐息影响但可以让嘉德丽雅更快恢复。这在半神层次战斗里就意味着机会！也就是一两秒工夫嘉德丽雅眼神恢复正常而藏在树林外黑暗中巨龙化奥黛丽又给布提斯补一次心智剥夺。没有犹豫嘉德丽雅抬起右手凝出那把染着鲜血可怕长枪将它投向秘之圣者。这一次布提斯再也无法躲避和化解胸口被那把朗基努斯之枪直接贯穿。他身体僵硬一下后急速崩溃瓦解变成一条又一条闪烁璀璨光辉星之虫。这些星之虫有直接消失有彼此吞噬有在远处融合重新组合为布提斯。布提斯眼神已完全没有理智身体在不断崩溃行将呈现出不完整非常虚弱神话生物形态。这时他身边突然出现一扇虚幻之门灰蓝色有七个黄铜锁孔虚幻之门。这虚幻之门飞快敞开吐出来一个银黑色镶嵌着各种宝石三层首饰盒。被放逐旧日之盒回归了。眼神疯狂布提斯接住这个盒子露出残忍嗜血笑容猛地就要将它打开。第三层！

## 这场戏有没有翻
翻了。开头还在布提斯自以为逃脱灵界；章末郊外陷阱连环＋龙息枪穿＋旧日之盒回归他要开第三层。翻的是逃变死局又变开盒危机，不是狂乱厉不厉。

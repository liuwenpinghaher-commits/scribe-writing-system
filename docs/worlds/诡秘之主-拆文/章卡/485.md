# 485 旅行家 第四章 克莱恩的猜测

## 打开书
同样很懵还有月亮埃姆林——什么救赎蔷薇什么命运天使什么破坏循环都在知识范围外；只觉每一个单词都能听懂连在一起就不知道什么意思。难道看起来年纪不大太阳刚逃脱一位天使追杀？根据能理解那小部分内容做猜测。而在太阳戴里克感谢过愚者后倒吊略微改变坐姿斜向对方从正义小姐问题出发语气平常：「具体经过是什么样子的？」戴里克无隐瞒坦诚：「正义小姐倒吊人先生魔术师小姐世界先生谢谢你们关心也谢谢你们之前给出意见在第六次探索里我尝试着…」原原本本描述自己做出那些举动和相应结果；重点强调小男孩杰克来自恩马特港这事和救赎蔷薇所在壁画细节性内容。恩马特港…那奇怪小男孩杰克真是鲁恩王国人也就是说白银城所在神弃之地以某种方式与南北大陆连接着只要找准办法找准地点就有可能进入…克状似悠然听着心里做出一定判断。恩马特港位于廷根市东面是鲁恩王国中部最出名海港之一；它和普利兹港一北一南共同支撑贝克超过一半物资补充。通灵者戴莉女士曾经定居那里；极光会Z先生似乎也在那里…回忆起过往一些事。同样判断也出现于倒吊正义魔术师心里；对此有的纯粹激动有的则好奇里掺杂担忧害怕白银城周围那吞噬一切般黑暗会不断扩散最终笼罩南北大陆和五大海洋。「首席告诉我他通过之前事情和我给出提醒想到一些古老典籍里记载不知道真假内容；传闻创造一切的主全知全能的神注视着这片大地时候身边环绕诸多天使；而天使们首领最接近神座王者共有八位其中包括了神的子嗣。」太阳边回忆猎魔者科林话语边缓慢说：「他怀疑阿蒙就是天使之王里时天使；壁画上那位则是命运天使吞尾者乌洛琉斯。」八位天使之王？最接近造物主神座八位天使之王？正义听得莫名兴奋。难忍好奇问：「太阳先生另外六位天使之王称号和名字是什么？」「首席没有说我没敢问…」有些惭愧回应。好想知道答案啊…奥黛丽下意识望青铜长桌最上首用渴求目光看着笼罩灰雾愚者希望获相应解答。她已想好愿意为此付出什么代价。看我做什么…我也不知道啊…克控制住嘴角抽动。当然也不是完全无线索——勉强猜得到其中两位天使之王是谁。地下遗迹恶灵将梅迪奇家族描述为救赎蔷薇创建者之一；而从那副壁画看命运天使乌洛琉斯大概率是救赎蔷薇首领之一两者地位基本等同；也就是说梅迪奇家族拥有一位天使之王但无法确定祂是否已陨落…梅迪奇家族疑似掌握猎人途径也就是红祭司途径那位天使之王称号应该为红天使或者战争天使…既然神子是天使之王阿蒙是其中之一时天使那亚当没可能不是但无法确定称号…另外四位就猜不出来是谁了…也许他们其中之一或之几在黄昏隐士会里面…有可能！黄昏隐士会敌视堕落造物主与崇拜这位邪神救赎蔷薇对应或许真来源于当初几位天使之王…对了有一个侧面不够有力证明根据白银城神话传说空想之龙安格尔威德这位古神权柄被那位造物主收回；从逻辑上那位创造一切主将这个权柄分一部分给神座旁天使之王不是没有可能；而罗塞尔日记里描述和猜测表明黄昏隐士会也许拥有观众也就是空想家途径天使级力量甚至更高两者可形成对应…赫密斯是经历过那段历史人…念头闪动间微微一笑：「以后你们会接触到的。」等我弄清楚了就会把相应情报卖给你们…心里补一句。见愚者没有作答想法正义略感失落收回目光示意小太阳继续讲述。倒吊则有了个大胆想法：大灾变前历史已不可考证；第三纪末尾第四纪初期只有六位正神加上阿蒙和吞尾者不就刚好八位吗？祂们从造物主逝去里获好处成功晋升序列0？一时之间阿尔杰又觉自己想法是可判处火刑亵渎举动又心怀难遏激动好不容易才平复专心听小太阳讲故事。对这一切月亮只能以茫然表情应对。虽然血族历史悠久生命漫长知道不少大灾变前历史但都集中始祖沉睡前并不涉及所谓天使之王。太阳讲述白银城首席科林破坏命运循环细节时克想却是另外一事：大致可确定吞尾者乌洛琉斯是怪物途径序列1水银之蛇；所有天使之王都对应序列1位格？那位命运天使会是追杀威尔·昂赛汀那条水银之蛇吗？如果是那说明真造在贝克势力绝不止于A先生和他手下只不过两条水银之蛇为序列0位置争斗牵扯去吞尾者所有精力无暇他顾…当然不排除威尔·昂赛汀就等于乌洛琉斯可能但概率不大；救赎蔷薇有不少半神甚至天使不至于让吞尾者无保护地依托一位普通人重启。还有一个可能贝克两条水银之蛇都不是命运天使后者依然活跃于神弃之地这样一来三条水银之蛇就凑齐了。讲完脱困事太阳又一次表达谢意；而那反复循环经历即使第二次听闻仍让正义等人骨头发冷寒毛耸立又好奇又害怕。这已超越我对非凡力量认知多亏有愚者提供帮助！奥黛丽心里由衷赞美塔罗会主人只觉自己充满底气。倒吊等人想法和她类似都认为那反复循环经历接近神迹唯有神灵才能打破；而幸运塔罗会主人就是神灵愚者先生就是神灵！这时太阳望向对面诚恳：「魔术师小姐因为返回白银城路上出现一些意外情况虽然都已解决但延缓我们速度让我们未能及时回白银城您的食灵者胃袋还需要等待一到两天嗯我感觉对我监控已经没有了。」「没问题我能等待我准备好了足够金镑。」魔术师松口气。她已把镜龙眼睛卖给正义小姐收获1000镑现金。在把具体结果告知老师多里安后诚实得赞扬褒奖；多里安告诉她之所以开价800镑考虑就是要给她100镑左右辛苦费；如此一来多余200镑将属她额外收获也就是说这一笔她赚了300镑加上原本存款共有650镑足以购买食灵者胃袋。有了这事多里安对她信任不少透露不少材料消息。我至少得两周才能消化完多余魔药不用着急…看着斜对面：「倒吊人先生你需要的龙眼海雕眼珠有消息了2200镑。」多里安给指导价格2000镑；佛尔思一方面预留还价空间另一方面想多挣一点。2200镑…倒吊忍不住皱眉。在买下风眷者魔药配方后财政状况已不容乐观虽然还有些私藏但要么自身有用要么长久找不到出手对象。呼暗自吐气不动声色：「很好但我需要一定时间凑集资金另外你这太昂贵了我有不少渠道能得到更加便宜的1900镑这是我能接受最高价格。」「不行2000镑这是底线！」毫不犹豫回应。她害怕喊得太高对方会放弃交易。阿尔杰当即点头：「成交！」这…佛尔思一时有些愣。旁听月亮见证一桩交易达成想了想跃跃欲试问：「诸位谁知道血族该怎么提升实力在不依靠长辈赠予情况下？」话音刚落感觉一道道目光望过来。血族？这就是传说里吸血鬼？正义眼眸发亮审视月亮先生。而作为小说家魔术师毫无疑问对血族有着各种或美好或奇葩想象眸光同样晶亮有神。血族？倒吊先是一愣旋即舒展眉头。藏黑暗深处浑身流脓行动像风吸血鬼？太阳也忍不住侧身打量埃姆林。血族？世界迟了一秒才给出正常必须反应。

## 这场戏有没有翻
翻了。月亮懵开；章末血族目光齐射。翻的是克心里拼天使之王，不是愚者当场答全名。

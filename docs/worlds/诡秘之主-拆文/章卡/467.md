# 467 无面人 第二百五十五章 月亮

## 打开书
一瞬埃僵如大理石像。浓雾影淡然：「你为什么向我祈求？」脑海嗡脱口：「始祖启示！梦告末日将临须备；我几个关键之一；任务向愚向您祈祷！」噼里啪啦无藏——克预备话术反不知从何问起。始祖？莉莉丝二纪陨／权收回？故血试原始月惨；门：月亮牌空＝原始月或神／高魔化身；莉莉丝失序0≈死。原猜回应血＝遗物／唯一性呆板——今主动启否定。两可能：假扮挡月亮序0试探（绯红之主女神疑但已序0星牌何觊月？破敌？）；死而未僵待归如黑皇帝；女神加绯红或破此事。末日启＝复活努力；愚预言关键≈合作邀——序6拿何与古神合作？拉埃入塔罗？血知秘多；每次会前卜是否拉。灵界见闻黄光威尼坦末日预言＋亚伯咒被隐存助学徒解＝魔术师状；擅预言高位皆见末＋愚作用？表无变靠椅慢笑：「始祖让你向我祈何事？」埃呆摇：「不知…」椅背星飞组成绯红月符！果然血途指月亮。低笑：「七正神诸多隐存下何认我将是末关键？」「愚态度让埃平——真被拉神奇地！愚未怒因代表始祖？我特殊…」坐直：「尊愚；启示：我埃将成为拯血胜末关键；从向您求始。」隐：关键是我非您！中二傲…好笑：「同问何向我非七神他隐？」「不知。」故：「大概明白：望你在我助下成长真高位末时拯血。」「成长？血无法自成长；须仪长辈馈赠先祖遗升。」果然守恒——另法合律。「见识蒙蔽；答须自寻；我只供机会。希望有？」「愿！」起礼。傲哪去只谦？敲桌：「须守：勿向任何人透露与我相关除非允——含仪在场血。」「可…」温反：「莉莉丝未让事后汇报？」启连祈内容无即可推。直呼名讳如老友——颤低：「没有。」「隐秘交易故离注视后应；勿向莉莉丝汇报免某察觉。」补：「成关键须承荆棘：不被理解污蔑轻视；暗中负使命默行。」埃想：人偶笑→丰收耻辱→长辈不看好→角落默守族群…自感动：「您意愿必将贯行于大地。」后靠云淡：「默许隐秘聚会成立于此。愿加入寻强大拯血法？」「愿意！」点：「他请？」「请解除心理暗示大地母神主教…」「我知道。」打断——隐存…轻笑：「可帮；愿付何代价？」灵视：幽黑暗示已消大半稀薄脆——密契＋黑皇帝牌压＋太阳胸针净可彻驱。埃想不出兴趣物。主：「对血族某些史感兴趣；可交换。」略思答应。「先想描述内容；此前选代号——」具现未挑主牌。埃有趣细看：「月亮。我选月亮牌！」

## 这场戏有没有翻
翻了。开头僵硬被问；章末选月亮牌入会。翻的是莉莉丝合作猜＋中二关键自我感动入塔罗，不是当场揭穿尼拜斯骗。

## 话
「你为什么向我祈求？」「我选『月亮』牌！」局面是从脱口启示收到莉莉丝猜；从中二关键收到荆棘戏；从代价收到月亮。

## 热怎么变冷
启示还热。冷切在不知祈何事。关键是我还热。冷切在成长守恒。月亮还热——章收。

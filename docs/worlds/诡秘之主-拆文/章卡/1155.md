# 1155 逐光者 第六章 思考

## 打开书
神弃绝大部分无正常道路也不算难走——大片荒芜旷野深黑主色。偶见顽强植物奇形扭曲无从辨原型。灯笼光照不到处黑夜似有生命深沉无声蠕动要吞噬覆盖一切。古代学者眼角一扫见深黑伸出无数虚幻细密灵体之线——暗藏大量怪物。怪极安静注视古魔法师阿蒙与当世绅士克莱恩在昏黄光下走旷野。他目视前方随意提皮灯丝毫不担心何时熄。将离旷野入山丘时斜后黑暗一畸形两头五臂卷肉团怪突抖——已成其秘偶。操纵灵体之线无声未超五百米。下一秒怪安静瘫失生命。左行尖顶软帽阿蒙笑抬右臂摊掌显立体花纹透明蠕虫。灵之虫！从秘偶连灵体之线一并偷来。未等开口轻松惬意屈指成拳捏碎。他顿感灵魂深处疼头似裂。——多次做昨日重现与控灵子弹较适应，仅扭曲脸未太失态。阿蒙保持笑甩掌：你太拘谨了，可以大胆一点。缓和后揉额身心疲惫每条灵之虫呼唤休息。被查拉图追赶借过去灵性近耗尽，后续传送天使之拥消痕近极限；回安全区本拟上雾检查即沉眠却遇阿蒙埋伏寄生一路折腾神弃，若非绝境压榨潜力或途中昏睡失控。坦然：我现在需要休息。信阿蒙会满足——越竭力无法逃越满足恶作剧之神愉悦。好。单片脸稍转向山丘一侧：那里有休息处很快抵达，当然想露宿荒野也不介意，只觉你们人类更喜欢能提供安全感场所。就去那里。本想操纵灯焰跳跃干涸灵性阻止，只好跟双脚一步步。途中多问：为何不偷走距离直接抵达？侧头水晶单片右眼看他嘴角微勾：想休息的不是我。……闭口安静前。十数次闪电后抬手指斜前：到了。不到百米山丘阴影散落尖塔顶几座半截建筑，地凸十几根仅膝高巨型石柱，少量荒草缝隙长出尖端暗红如血。这里曾经有人居住？又揉额问。右食指第二关节抵单片边缘微笑：原本很大城邦，大灾变来临时大地裂开整城被吞噬，只剩这些证明曾经存在。文明的毁灭……加快步抵荒草中目的地。进半坍建筑本能环顾。裂开道道缝灰白石壁历几千年壁画模糊，隐约城邦人以死后入天国为荣。调呼吸扔皮灯靠粗石柱勉强观想层叠光球。根本不管此处沉睡危险。让危险来得更加猛烈吧！睡前心里呼喊。古典魔法师长袍阿蒙看他一眼随意坐旁啪响指。灯内将燃尽烛停融化昏黄火光续发散——本仅再几分钟似又能坚持几小时甚至几天。像错误，违背自然规律的错误。昏沉不知睡多久总算恢精力，在魔术师小姐祈祷声里苏醒。暂无法回应闭眼装仍梦中。非深寄生阿蒙应监控不了想法只能辨转动念头是否有害……心一动悄向灰雾召——从史隙过去己处借一状态：心灵岛屿遭赫温·兰比斯入侵时状态，不直接针对逃脱。尝试未被阻未被偷。借此状态与被入侵梦／心灵可清醒之特，自我认知分化一部分居灵性天空冷静俯视意识岛。审查心灵有无不正常被寄生念。严格分辨初步确认心灵无问题——即使留时之虫亦浅层寄生无法监听想法。找到安全区后放开束缚分析遭遇考虑自救：阿蒙恶作剧之神亦欺诈之神，玩这游戏绝非单纯愉悦……真要等与本体会合窃命运得源堡再试，意外也主目的达成无损失……此事究竟藏何目的？抓住关键或真生机……中文念转运仪式咒文后对特殊语言漠不关心未提问完全不符好奇心……呃之后说Bug是否刻意试探会联想到什么……但未偷想法啊——若整段无关想法全被偷发现不了……回忆依前后逻辑确认当时未被窃。反向肯定：深寄生下阿蒙可直接监听想法无需窃取！表现须先察有害念才操纵＝欺诈！就说与帕列斯描述似有点不一样……推断沿途内心想法应都被听到含地球老乡对孩子教育……可怕……还好谋划破乔治晋升时预想身陷绝境被寄生，泄露一半本能一半有意放纵——既吐密取信又藏最关键核心。如现在祂肯已清我打算套史隐秘尽快消化古代学者，但不肯知距彻底消化已不远就两三步或一契机……刻意解寄生玩这场是否因曾从远古太阳神听过地球接触某隐秘，拟以自救驱我帮祂完成不便或没法做之事？若真接下来必有情况……得表现未察觉这点像正常谋划逃跑。等调好身体状态就做第一次尝试！又「睡」一阵睁眼。尖顶软帽阿蒙坐旁含笑：想好了吗？什么时候开始行动？表现得像同伙而非逃离目标。

## 这场戏有没有翻
翻了。开头还在旷野试偶被捏虫疼；章末睡醒审心确认浅层、看穿深寄生可直听、决定装作正常逃并准备第一次尝试。翻的是「游戏＝找乐子」收成可能有地球隐秘任务，不是捏虫疼不疼。

## 热怎么变冷
试偶还热。冷切在灵之虫被捏。休息还热。冷切在想休息的不是我。文明毁灭壁画还热。冷切在让危险更猛烈。审心安全区还热。冷切在沿途想法都被听到。同伙催行动还热。冷切在游戏藏目的。

# 1235 逐光者 第八十六章 联动

## 打开书
巫王卡拉曼眼中一轮带点银白皎洁明月冉冉升起迅速占满他瞳孔。这与常见红月截然不同也非偶尔会出现血月倒是和前不久月亮异常状态类似但又有一定区别。它照亮卡拉曼眼眸照亮他身体让他瞬间失去与绯红之月联系。也就是说在恢复正常前卡拉曼无法再尝试月光化也不能在绯红月华覆盖一定范围内瞬移般闪现。霍然之间这位月亮领域巫王脑海里冒出一个单词：莉莉丝！曾经执掌月亮途径古神莉莉丝！这样变化出乎埃姆林预料但擅于克制情绪和想法莎伦未受影响在已变成卡拉曼木偶情况下抬起右手扯下额前黑白交杂一搓头发。几乎是同时卡拉曼这位巫王头顶一搓斑白头发在没有受到任何攻击情况下自行飘落。他刚才打开那扇召唤之门则在纯白之视全力爆发太阳光辉中黯然消融寸寸破碎。这不是被召唤来玫瑰学派天使无法对抗纯白之视这1级封印物而是那扇召唤之门难以承受如此程度如此特质攻击。另外那位诅咒之王巴兰卡只是刚探出两只手能隔空降临力量还相当有限渗透入现实邪恶气息又遭遇纯白之视净化没能影响到莎伦和埃姆林。此时此刻没了召唤之门这媒介巴兰卡只能退回原本所在地方等待下一次召唤或者巫王卡拉曼做出祈祷。——作为一名天使祂位格足够能在全世界范围内回应祈求！看见那缕头发飘落后莎伦变成卡拉曼木偶没有犹豫让右手从额前自然滑落少许捏住镶嵌着血红满月夸张缝隙猛地用力往内一合。卡拉曼难以遏制发出一声惨叫额头血肉诡异模糊纷纷填充入那个瘆人缝隙内遮挡住微缩满月。这是异种途径序列4木偶非凡能力之一叫做诅咒之源。木偶们除能影响非生物还可以变成秘术木偶神奇纸人等物品通过建立起来联系用各种方法诅咒目标。这个非凡能力到序列3会发生质变当前阶段属于伤害到敌人也会伤害到自己类型一般情况下木偶半神们很少使用。换句话说就是木偶借助伤害自己来伤害敌人。莎伦之所以敢于这么做是因为她确信既然大家同为序列4那怨魂和活尸肯定比吸血鬼更能承受伤害。——在提前知晓巫王卡拉曼有无瞳将军这个1级封印物情况下莎伦最开始怨魂附身根本没想过能真正成功主要目的是借助这种方式与卡拉曼建立起联系为后续诅咒做准备。她拔下那缕头发就是正式开始诅咒标志破坏目标额头血红满月是防止他再次建立召唤之门将玫瑰学派天使拉入战场。当然作为一名半神卡拉曼是不会这么容易就被诅咒致死。换做以往他能利用月光化幻化蝙蝠等办法削弱诅咒带来伤害并不断地高速移动边规避攻击边诵念玫瑰学派天使尊名但是那轮染着些许银白皎洁月亮照耀下他身体就像冻僵凝固一样无法再完成类似行为。卡拉曼思绪电转间坐在他肩头木偶无瞳将军站起来发出刺耳到极点叫声。周围玻璃窗纷纷破碎化作一枚枚子弹激射向半空中漂浮莎伦那枚眼珠状玻璃球在没有掌控者情况下自行飞起来让半空降下一道缠绕着无数火焰巨大光柱。这光柱笼罩莎伦让周围一片透亮仿佛来到白昼。无瞳将军可以影响失去持有者神奇物品让它们帮助自己！阳炎之中变成卡拉曼模样莎伦身影出现明显融化脸部表情不受控制扭曲起来。那大量玻璃碎片一半消融在光柱里一半射穿她身体。卡拉曼又一次发出惨叫听得埃姆林身体冰冷血液似乎凝成霜华。这位巫王体表出现一个又一个血色窟窿整个人就像丢入壁炉蜡烛缓慢软化着滴落起油脂。对诅咒之源任何伤害都将反应在目标身上！作为玫瑰学派半神卡拉曼毫无疑问是知道这点他刚才举动是想以伤害换伤害逼迫莎伦主动停止诅咒。在太阳领域神术下木偶怨魂活尸狼人等黑暗邪异生物明显会比吸血鬼魔药教授深红学者巫王等受伤更重！也就是说连续阳炎打击会让莎伦直接消逝但却只能重创卡拉曼而月亮途径半神是拥有超强自愈能力。这短短一秒间巫王卡拉曼凭借丰富经验和渊博神秘学知识精准把握到诅咒之源问题选择最适合自身又能在最短时间内见效方法。可就在这个时候失去纯白之视召唤出奇怪月亮埃姆林·怀特已回过神来拿出一本有着坚硬外壳铜绿色笔记本将它翻到其中一页。噼里啪啦声音随之响起一道又一道闪电凭空跃出交织成散发出强烈毁灭气息风暴一下就将巫王卡拉曼卷进去。莱曼诺旅行笔记闪电风暴！短暂失去月光化和一定范围内闪现能力卡拉曼根本无法躲避被一道又一道银白闪电狠狠劈在身上。莎伦趁机解除诅咒之源状态免得目标遭受伤害反映到她这边。不过她脸色明显比之前苍白不少气息也变得颇为虚弱。刚才阳炎光柱确实给她带来不轻伤害。爆发那团银白很快熄灭卡拉曼体表已变得一片漆黑。那些焦化皮肤和血肉不断地脱落下来原本位置则不断有新血肉在蠕动生长。无瞳将军身体飞快虚化似乎变成幽灵准备附身于卡拉曼带着他横移出当前区域免遭后续打击。就在这个时候一个金发红眼脑袋突兀浮现一口就咬住精致人偶头部。还残余些许麻痹卡拉曼下意识望去看见一位没有头部女士。这女士穿着阴沉繁复哥特式长裙提着四个金发红眼脑袋。蕾妮特·缇尼科尔！……那片浩瀚沙漠中与阿兹克阿里安娜银白巨蛇一起围攻神孽斯厄阿蕾妮特·缇尼科尔眼神突然变得呆滞动作也随之呆板全凭本能而为。这是克莱恩计划中一环当这边战局稳定神孽斯厄阿一时摆脱不了也短暂没有生命危险时蕾妮特·缇尼科尔本体就脱离隐秘状态回到现实世界帮助莎伦和埃姆林快速解决战斗。看眼半空中呈现凄惨木乃伊投影克莱恩一边操纵三大天使缠住神孽斯厄阿一边借助祂们气息对身侧环境影响改传送为火焰跳跃继续与那位玫瑰学派巫王周旋。这个过程中他看似潇洒自如实际却发现自己身体与灵魂契合程度在一点点下降身体逐渐成为灵囚笼让他动作越来越僵硬越来越沉重。这让克莱恩想到囚犯核心描述：身是心囚笼世界是身囚笼。随着时间推移他从另一个角度直观体会到这句话含义。神孽斯厄阿开始重视他后哪怕没机会直接攻击他也让他不知不觉遭受侵蚀！……蕾妮特·缇尼科尔一个脑袋控制住无瞳将军后另一个脑袋扬起牙齿咬住黑色手杖。这手杖镶嵌着多种宝石亮起濛濛光辉。一道人影飞快成形正是戴礼帽穿风衣拿着丧钟左轮格尔曼·斯帕罗。砰！一抹银黑色流光随之飞出准确命中卡拉曼身体。卡拉曼思绪一下停滞整个人完全僵硬在原地。控灵子弹！这是星之杖再现格尔曼·斯帕罗射出控灵子弹！——这编号0-62封印物能让持有者脑海内浮现非凡能力和人物降临现实而后者可以发动一次攻击。另外一边莎伦当即又变成和卡拉曼一模一样木偶将右手回收狠狠插入自己胸口。鲜血猛地喷出卡拉曼嘴巴张开却无法发出声音。对怨魂来说心脏绝对不是要害但于吸血鬼而言这非常致命。没给卡拉曼硬抗过去机会埃姆林又一次翻动莱曼诺旅行笔记释放上面记录召唤历史孔隙影像拿出那个满是铜锈无暗十字。他手指猛地按住尖刺任由鲜血流出洗净十字架斑驳。一把纯净到极点炽白到极点长枪瞬间凝聚。当莎伦解除诅咒之源状态后埃姆林投出这把光之长枪看着它穿透巫王卡拉曼胸口将他钉到教堂高处墙上。灿烂光芒骤然膨胀彻底泯灭卡拉曼最后气息。无暗之枪！……浩瀚沙漠内克莱恩突然停住对着神孽斯厄阿和那位巫王摘掉礼帽以手按胸行一礼。他身体旋即淡化消失不见。这个过程中克莱恩一点也没担心会受到干扰因为不是他自己试图离开而是蕾妮特·缇尼科尔解除对历史孔隙影像维持。这也就意味着另外一个战场行动取得成功！

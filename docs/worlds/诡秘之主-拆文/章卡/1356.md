# 1356 倒吊人 第四章 见面

## 打开书
神弃之地深处一座山峰顶端竖立着一个介于真实与虚幻之间巨大十字架。那里倒吊着一个模糊人影多根古老木桩穿过祂身体染着还在流淌却没有往下滴落鲜血钉到架上。十字架底部穿着简朴亚麻长袍留着银色及腰头发命运天使乌洛琉斯跌坐在那里神情柔和而虔诚闭着眼睛做着祈祷。……祂一手拿着魔镜阿罗德斯一手提着第二块亵渎石板眸光澄澈表情平淡。……亚当随即抬高左手让式样古老神秘魔镜绽放出濛濛微光。……紧接着亚当将第二块亵渎石板放进这幻象一样场景里。那处在无穷远处虚幻大海景象轻轻晃荡起来围绕着第二块亵渎石板与它产生一定联系。——第二块亵渎石板是当初非常接近旧日位阶约等于混沌海主人远古太阳神部分尸骸所化。看到这一幕亚当左手微动让魔镜阿罗德斯飞起来落向巨大十字架底部命运天使乌洛琉斯。祂自己则拿着发生微妙变化第二块亵渎石板通过阴影帷幕上裂口一步一步走入里面。……整个过程里没有谁开口说话所有事情都在无声中进行命运天使乌洛琉斯更是未尝试睁开眼睛。与此同时阿蒙成神利用第一块亵渎石板堵住堕落母神入侵通道风暴之主则劈碎空想出尸骨教堂和亚当其中一个身份。……又过一阵吞尾者乌洛琉斯睁开眼睛将目光投向落到自己腿上魔镜阿罗德斯。魔镜表面一个个银色单词在晃荡虚幻水波中凸显出来：您应该知道虔诚信仰和追逐一位伟大存在感受吧？……所以能将我送回我主身旁吗？魔镜表面那一个个银色单词蠕动着重组形成新句子等您回答完可以向我提两个问题。……终于魔镜阿罗德斯忍不住浮现出新问题：您为什么不回答？……我还没有想好。三个问题……魔镜表面银光缓慢勾勒出两个单词。……——自这条命运之蛇出生艾伦·克瑞斯事业就一天好过一天如今他已拥有一家私人医院专门为上流社会提供医疗服务。……我总觉得你会说：你尽情呼救吧没有谁能听见。这打扮阔气两岁小孩回过头来咕哝着说道。……总之得祝贺你成为天使之王。欺负小孩并不符合你现在身份。……你知道该怎么愚弄命运吗？……给我虚假冰淇淋并不等于愚弄命运。……你为什么不蹲下来？在我这个年纪如果一直这么扬着头会对颈椎发育不好。……除非我已经晋升序列0成为命运之轮否则对我任何愚弄都不等于愚弄命运。……你还没找到容纳概率之骰契机？没有。威尔·昂赛汀摇下头旋即补充道我有预感它快要来了。……如果把你和概率之骰都送给乌洛琉斯祂会不会很快晋升序列0？……祂也需要等待契机才能容纳而且成为命运之轮需要契机和容纳概率之骰需要并不一样。……如果你只要求容纳愚者唯一性那相应仪式可以简化不会那么困难。这种情况下巧妙利用命运木马能力并做出一定程度内牺牲就有机会愚弄命运。不过等你尝试晋升序列0时候哪怕已容纳唯一性分别吸收三份序列1非凡特性也得真正不打折扣地举行一次仪式让相应事物完全聚合发生质变。……我大概明白了。……好好享受你童年吧这不知道还能维持多久。……就这样走了……真是没礼貌上门拜访竟然不准备礼物……这小孩忍不住嘀咕两句。……比星空更崇高比永恒更久远黑夜女神您是隐秘之母厄难与恐惧女皇……不知过多久他眼前出现一片无边无际黑暗脚边是一丛丛夜香草和深眠花。……好久不见。这身影在克莱恩说话前轻柔开口道。……这是在对曾经诡秘之主说还是悬吊于源堡之上我？……黑夜女神投影带着一点笑意道：我不确定你在那扇光门之上悬吊于哪个位置。从那里离开后我就再也没有回去过。果然……克莱恩暗自感叹一声从细节中肯定黑夜女神阿曼妮西斯来历。破开三个光茧是挨在一起。他简单回应道。……那里人都是诡秘之主复活备选但祂不知出什么意外对很多事情失去掌控。如果不是这样我早就已经死去以诡秘之主身份活着而你和罗塞尔也没有机会回到现实。这说明天尊陨落比较彻底只能依靠非凡特性内残留意志和源堡机械安排复活？克莱恩叹口气笑笑道：我已经能听见祂在我耳畔低语。

# 515 旅行家 第三十四章 “倒吊人”的猜测

## 打开书
震惊之余另一个疑惑浮上倒吊人阿尔杰心头：既然愚者先生早有预见那祂为什么还要开口指出班西港事情与救赎蔷薇和天使之王梅迪奇有关？祂故意告诉我们？希望通过我们将这件事情宣扬出去？目标直指天使之王梅迪奇？不更大可能是真实造物主！愚者先生之前就屡次破坏真实造物主图谋这次应该也不例外…救赎蔷薇这个名词出现于真实造物主废弃神庙内由天使之王梅迪奇和乌洛琉斯创立显然与真实造物主有很深联系…班西港只有我们风暴教会愚者先生真正告知对象是我？隐约明白点什么。旋即又敏锐察觉一个问题：世界上次提及贝克兰德将有大事件立刻被愚者先生证实之后牵扯出原初魔女苏醒和真实造物主降临这次他讲班西港异变同样得到愚者先生回应揭开古老宾西隐藏秘密让救赎蔷薇和天使之王梅迪奇呈现于塔罗会众位成员眼前…这会不会太太巧合了？嗯世界之前说消息都与贝克兰德有关这是初次涉及海上之事而愚者先生上周提过他眷者因为大雾霾惨案不得不离开贝克兰德两者吻合。所以世界其实是愚者先生眷者？不应该是祂所有眷者在塔罗会里代表替愚者先生完成一些祂不方便直接做事情当然眷者也会通过这聚会交易物品和知识达到提升自己目的这算是愚者先生对他培养。仔细想一想这猜测很可能是对至少世界从来没有搜集过罗塞尔日记以此从愚者先生那里换取知识或情报…身为眷者这是他职责私下就已经提交！从这个结论出发世界某些刻意问题和矛盾表现是在掩饰自己眷者身份这符合他经验丰富老练狡猾特点。愚者先生组织塔罗聚会除了隐藏有暗中复苏一步步解开封印企图还存着利用我们干涉某些事件目的这从成员构成可以看出一定端倪上层贵族教会主教级非凡者神弃之地幸存者亚伯拉罕家族学生成年吸血鬼各自都代表着一个势力或一个圈子一条渠道。许多想法闪现倒吊人不仅没被自己猜测弄得压抑反倒有些激动对他来说愚者先生目的未知才是最恐怖事情初步明白了祂想做什么就可以有效规避风险并借此提高自己。只要愚者想利用我们做事那就肯定会给予一定好处这正是我期待的…否则我不知道什么时候才能看见半神半人希望…呵世界你肯定想不到我已经看穿你伪装…惊惧心情缓解开始思考该怎么利用班西港情报问题。他不可能直接就这样将消息汇报上去那会引起怀疑必须耐心等待一个机会既让高层欣赏给予奖励又不会受到监控机会。正义看得出来倒吊人先生有了番心路历程但想不到对方能在很短时间内浮现出那么多念头那么多猜测。而从愚者先生话语里她欣喜知道了救赎蔷薇是一个隐秘组织由部分天使之王建立与真实造物主有一定关系。同时她也隐约察觉世界古怪发现这位最难读出情绪组织成员总是涉及大事总是能打听到很重要情报而且不断出手着配方材料和特性似乎一两周就能狩猎一位非凡者！他离开贝克兰德到了海上？或者还是在贝克兰德听到传闻？我该不该把这情报告诉教会？唔倒吊人先生和风暴教会关系密切由他去做效果更好更不会出现问题…压下窥探想法好奇又问一句：「尊敬愚者先生天使之王梅迪奇称号是什么或者说祂属于哪条途径？」克靠着椅背低沉笑道：「红祭司。」红祭司？这是哪条途径？听起来和黑皇帝很接近呀难道又是一个序列0称号？正义兴奋又愉快想着。红祭司…太阳默念这名词发现白银城历史里并没有相应记载。也可能是我读过资料不够多只接受了通识教育…略感后悔想着。魔术师和月亮就像听故事一样听着对类似情报同样相当感兴趣。唯一问题是不能向别人吹嘘不能写进小说里！佛尔思一阵遗憾。倒吊人先生应该会往上面汇报希望他不要拖延太久…以他精明或许已经看出世界一些问题把握到他和愚者之间关系还好从很早之前开始我就刻意将世界人设与夏洛克重叠给予眷者身份倒吊人先生顶多能察觉到这一层没法想象世界其实是个假人…愚者抬手摸摸下巴含笑说：「你们继续。」见愚者先生不再提刚才话题从救主情绪里挣脱出来月亮开始面对现实难题。那就是缺钱！不管怎么样他从未考虑过卖掉那些人偶只是告诉自己今后要节省半年甚至一年才能奖励自己一个新人偶才能为已有那些买一套新衣服。除此之外能想到赚钱办法就是卖一些有神奇效果药剂但这很容易给隐藏在贝克兰德族群带来隐患。这是始祖安排按道理来说该由尼拜斯大人提供相应帮助可愚者先生又要求我保密做黑暗里负重前行救主不能主动透露…思考几秒嗯嗯两声清清喉咙道：「诸位我有一个问题。事情是这样的假设有一位强者安排你去调查某件事情你虽然成功获得情报但却碍于某些原因不能向那位强者汇报那么该怎么继续从那位强者处获得支持？」说完之后忽然觉得这种行为有些可耻。这这很像是叛徒和内奸啊…不我是为了整个血族延续才这么做为此必须舍弃名声背负不解等到事情结束真相呈现他们将会为我感动…迅速缓解刚才感受。这时正义魔术师和太阳等人都将目光投向阿尔杰在他们心目中倒吊人先生在这方面有着丰富经验是最好老师。愚者也是这么认为。倒吊人扫了月亮一眼嘿一声：「很简单但你必须承受一定风险。」埃姆林下意识就否认：「不是我！」「假设是你。」倒吊人轻笑回应。接着描述：「你在日常生活里慢慢表现出一定异常让那位强者察觉你出了问题。他会有两个选择一是直接拷问你但这很容易断掉线索二是不经意间提供你帮助让你能更加深入做调查然后派人监控你。我认为第二种可能最大你需要承担风险是怎么在监控下不暴露想隐藏情报。」还能这样？其实也不会暴露每次塔罗会时我都在丰收教堂休息外表没有任何异常而献祭物品和接受赐予仪式本身就是可以展现给尼拜斯大人他们看东西让他们能猜到我与愚者先生建立了一定联系却无法想象我已经加入一个隐秘聚会…很好我将在学习历史时主动向威曼迪男爵询问白银城事情！眼睛一亮有了主意。旋即想起一件事情转而对倒吊人道：「你上周不是问过怎么让一条船上所有人同时沉睡办法吗？很简单我可以提供一种神奇麻醉气体它能有效蔓延没有刺激性气味即使在甲板上直接嗅到也会导致昏迷当然你最好选一个没什么风夜晚还有目标不能有危险预感体格也不能太健壮序列9里面以身体出名那种非凡者是极限。它能制造超过三小时沉睡之后效果不断降低。100镑一罐额外再给我30镑报酬。」倒吊人想了想幽灵船上水手情况并未还价道：「好。」他要在月亮面前竖立一定形象为后续大交易做准备——曾经考虑过用沉眠符咒但那需要念出开启咒文会让水手们察觉不对事后怀疑。交流环节渐进尾声克手指轻敲下斑驳长桌表面悠然笑道：「我已经预见下周各位将有新面貌。这次聚会就到这里。」「谢谢您祝福。」正义率先起身连告辞带感谢。有了愚者先生这句话她对服食心理医生魔药又多了几分信心。随着魔术师等人重复同样话语一道道身影消失在宫殿内灰雾之上又恢复了亘古不变般寂静。

## 这场戏有没有翻
翻了。倒吊人脑补；章末预见散会。翻的是「世界＝眷者代表」猜对半层，不是拆穿假人。

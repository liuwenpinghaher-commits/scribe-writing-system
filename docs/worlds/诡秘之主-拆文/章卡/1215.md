# 1215 逐光者 第六十六章 耐心终有回报

## 打开书
白银城圆塔顶部首席房间。头发花白脸有陈旧疤痕科林·伊利亚特眺望着窗外深沉黑暗直到一团银白锐芒在远处突然爆发带来几秒光明才收回目光轻轻颔首：希尔蒙成功晋升了……他视线随即落在站立于房间中央那个只有两米出头少年身上：戴里克你知道为什么初次探索巨人王庭后已成为序列3银骑士我要将后续计划一直压着不去实施？戴里克想：首席阁下您一方面是想看有没有别路能绕到海边另一方面是在等六人议事团其他长老里有人能晋升序列3。而现在这两方面事情都完成：近五个月前白银城一支探索小队发现一条隐蔽道路从那里绕过巨人王庭所在山峰抵达海边然而那片大海是虚幻根本没法通过强行下水只会导致身体逐渐崩解；如今六人议事团另一位半神韦特·希尔蒙终于晋升成为序列3银骑士可以拥有自己尊名在一定范围内响应白银城其余居民祈祷。科林·伊利亚特叹口气：很好对事情认识很清晰很全面。如果不是实在没有办法我确实不希望带着你们再次进入巨人王庭尝试打开沉睡着暗天使宫殿……说到这里猎魔者科林停一下才继续：我不知道这样探索会带来多大危险只能提前做好充足准备现在希尔蒙总算成功即使之后发生意外我们无法返回他和其余长老也能支撑起白银城让一切可以继续维持等待下一次机会。他打量戴里克几秒认同点头：你成长比我预想更好如果不是巨人王庭之事由你而起我真很想将你留在白银城以六人议事团预备长老名义。听到这里戴里克·伯格毫不犹豫回答：即使您想将我留在白银城我也要申请前往。这是他看见曙光这是他心目里能拯救白银城一个机会为此愿意付出一切。科林·伊利亚特少有露出些许微笑：你还太年轻等你像我这样经历很多事情后就会明白比起拔出长剑充满热血牺牲忍受屈辱和无奈在黑暗中坚守是更加困难更加让人痛苦一件事情。如果你不相信你等下可以去问希尔蒙问他是愿意率领探索小队前往巨人王庭还是留在白银城。戴里克陷入沉默张张嘴却说不出话。科林·伊利亚特未再继续这个话题转而问：你光之祭司魔药彻底消化了吗？上周就已经彻底消化。戴里克坦然。科林点头：辅助材料搜集齐了吗？戴里克嗯：都搜集到只差仪式还没准备好。他仪式需要剥离最强烈最不愿意舍弃情感并在服食魔药后回输。经过塔罗会几次聚会探讨以及正义小姐私下尝试目前已经有成熟方案：借助这位序列4操纵师对心灵领域掌控以愚者先生天使之拥为凭依来完成。猎魔者科林未做催促平静：不要着急对巨人王庭第二次探索还要等一段时间。等我成为无暗者？戴里克主动问。科林没有否认微微点头：也在等洛薇雅成为黑骑士她材料和仪式都已经准备好。……罗思德群岛首府慷慨之城拜亚姆海浪教堂附属钟楼顶端。风暴教会枢机主教代罚者高级执事海王亚恩·考特曼立在栏杆后眺望着已不是那么蔚蓝大海以及上面漂浮燃着火焰船只残骸。哼在我领海哪怕战争主教也得低下头颅……这位身体肌肉块垒分明脸庞线条刚硬深刻半神边收回视线边低语。他有一头粗如小虫深蓝头发和一双深蓝眼睛掌控着罗思德群岛周围天气和海洋。立在这位海王旁边阿尔杰·威尔逊没有表现出丝毫烦躁耐心等待着亚恩·考特曼将注意力转移到自己身上。——水手途径非凡者除大部分比较暴躁还有面对同途径高位者时往往战栗服从共同点这源自暴君特性。低语之后海王终于将目光投向领导着一支海盗舰队阿尔杰没什么表情：这次表现很不错枢机会议通过了对你审核决定让我主持你晋升仪式。接收天灾女王高希纳姆遗物后阿尔杰找机会将这件事情上报给海王。他从到苏尼亚岛原始森林内探寻精灵遗迹之事说起原原本本交代自己遭遇仅仅只修改两个细节：一是将主动前往精灵遗迹说成为埋伏弗萨克人部队特意寻觅合适场所这有当时在场多位水手证实；二是淡化之后行动自主性只说探索精灵遗迹当晚梦到某个女性上位精灵喝她一杯酒之后没发生什么异常也就没太过在意等来罗思德群岛某天晚上熟睡醒来后突然发现自己进入一座海底华丽宫殿拿起一根冒着电光珊瑚。虽然有多方面人证物证说明阿尔杰描述真实但海王并没有完全相信将他送回帕苏岛接受教皇迦德二世审查。借助天使之拥阿尔杰在那暴君般气息面前看似瑟瑟发抖毫无保留交代自己在梦中遇见那个女性上位精灵后产生一定野心为此主动前往罗思德群岛希望能接收遗产但实际上却掩盖住最核心秘密最严重问题。他用坦白自己野心方式通过这次审查至于那个女性上位精灵是看他有一些精灵血脉给他奇遇还是隐藏一些目的他表示并不清楚希望教皇冕下能调查出答案让自己安心。阿尔杰展现出对那种未知恐惧让枢机主教们相信这是他上报奇遇主要原因。这个方案是阿尔杰自己设计但有得到正义小姐建议让每一个环节都变得更加符合人性。当然和预料发展一样那之后阿尔杰并没有等来晋升仪式而是进入一段考察期。——风暴教会那位教皇冕下地上天使加固阿尔杰体内封印让灾难主祭特性在两年都无法渗透出来影响到他。这大半年里阿尔杰带领着分配给自己海盗舰队努力骚扰着弗萨克费内波特船只甚至直接参与海战冒着不小风险立下一次次功劳充分展现着自己对风暴之主虔诚对教会命令遵从。终于最近这场罗思德海战后局势愈发困难后他等来枢机会议认可。阿尔杰明显吸口气然后握右拳击左胸高声喊：风暴在上！他激动半是表演半是发自内心因为这大半年来他真承受不小压力：隐者女士已消化完神秘学家魔药正在为晋升序列3预言大师做准备；正义小姐虽然还未彻底消化操纵师魔药但也有不小进展而且她最初加入塔罗会时是彻头彻尾新人现在已经成为真正半神半人比阿尔杰高不只一个序列而是一个层次；用不了多久太阳就能晋升序列4无暗者获得神性；星星也已消化完序列5魔药积攒不少功勋就等上层给予机会；魔术师小姐经过一次又一次旅行距离魔药消化完已经不远而她老师为她准备好相应序列4秘法师魔药材料；世界格尔曼·斯帕罗不用说哪怕他突然表示自己已经成为天使阿尔杰也不会奇怪；审判小姐目前是序列5惩戒骑士正在消化魔药中努力追赶着大家进度；本质不喜欢拼搏月亮因此产生一定焦虑正在寻求成为血族伯爵可能。面对这些情况作为塔罗会最资深成员之一阿尔杰当然不想被甩在后面他迫切渴望着晋升序列4成为半神。这么多天过去他始终压制着心里焦躁情绪耐心做着等待两次出现失控征兆以至于不得不请正义小姐做治疗。而现在他终于等到他最想得到那个答案：通过考核准备仪式！

## 这场戏有没有翻
翻了。开头还在白银城希尔蒙晋升压计划；章末阿尔杰耐心考察终过审、准备海王主持晋升。翻的是两地「终于等到」并置，不是战争主教厉不厉。

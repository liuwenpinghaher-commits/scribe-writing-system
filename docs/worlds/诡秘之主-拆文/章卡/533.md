# 533 旅行家 第五十二章 梦中课堂

## 打开书
达尼兹担忧并没有变成现实克只是看他一眼就走进卧室准备休息。乘坐客轮那5个小时里精神始终处于高度紧绷状态昨晚又被惊扰没有睡好此时难免有些疲惫。哐当一声关上卧室门。呼…吓死我了！整个人一下放松瘫坐到安乐椅上。刚才脑海内已浮现出自己变成金镑场景一幕接一幕难以停止。平静一阵在酒吧鬼混至天亮才返回旅馆不知不觉又睡过去梦见船长来救自己结果未能成功反被格尔曼抓住让这疯狂冒险家多了位女仆。就在气愤难平却不敢反抗即将醒来时忽然看见周围模糊场景变得清晰定格在蔚蓝之风旅馆豪华套房内。咚咚咚。听见一阵沉缓有致敲门声。我不是在做梦吗？抱着这样疑惑走到大门边拧动把手。门缝越来越大看见一道熟悉身影。这是位美丽女士脸型如同鹅蛋鼻梁高挺嘴唇较薄有一双仿佛清澈泉水浅蓝色眼眸。棕色长发从中间分开于脑后打了个简单却精致结接着顺滑往下。没有戴帽子穿着件腰部收紧米色外套领口位置有大片白色蕾丝编织成巴掌大小花朵型装饰蔓延往下。与外套搭配是深色及膝裙裙摆褶皱相连略显蓬松脚下则是双与发色相近皮靴。「船长！」惊呼出声。旋即醒悟过来连忙转过身体对着格尔曼卧室做出防御姿态：「小心！快跑！有个疯子想找你！他背后有个恐怖组织！」牺牲情怀喷薄而出同时听见自家船长平静说一句：「这是梦。」梦…对啊我在做梦有什么好害怕…左右看一眼收起双臂边转身边后退道：「船长你模拟出了梦魇能力？不对你上周还在苏尼亚岛附近。」苏尼亚岛是这片海域最大岛屿也是苏尼亚海名称来源近乎等于一个小型大陆它原本是大灾变后精灵仅剩聚居地但随着时间推移这古老非凡种族被各种各样因素困扰逐渐消亡只剩偶尔零星露面证明他们还没有彻底灭绝。在第四纪末尾鲁恩王国占据这座岛屿但二十年战争里他们惨遭失败将苏尼亚岛拱手送给弗萨克帝国距今已七百多年。苏尼亚岛位于罗思德群岛西北偏北方向坐船需要接近半个月时间上周还在苏尼亚岛附近冰山中将不可能这周就抵达拜亚姆除非她会飞或者借助灵界穿梭。被达尼兹称为船长美丽女士点点头：「我们刚进入罗思德海域距离拜亚姆1000海里。」也就是说还有三四天才能抵达？这才正常嘛…好奇说：「这应该已经超过梦魇范围了？」而且是远远超过…心里补一句。冰山中将进入房间走向桌椅位置：「不是梦魇是一种秘密仪式魔法借助你留在船上某些物品于很远地方进入你梦境…」听着船长一丝不苟讲解瞬间就有了重回黄金梦想号开始上课感觉。我之前都没听说过这种仪式魔法…也是船长掌握了许多奇怪而稀有魔法和巫术没人能弄清楚她究竟拥有多少知识…她好像提过她序列称号是秘术导师…唉如果先前就知道她有这种秘术我也不会烦恼于怎么将拜亚姆变故通知她问题了…思绪纷呈打断艾德雯娜描述：「船长你察觉到这里联络点出问题了？」「嗯这是另一种秘术…」似乎有详细描述具体方法倾向。见状忙叹息一声：「可怜老林恩他们…」艾德雯娜遂停住脚步背对窗口简洁问：「发生了什么事情？」「这需要从达米尔港说起。」精神一振只觉长久压抑终于在这一刻获得回报。语言啰嗦描述自己试图招揽格尔曼却发现对方是个疯子过程并夸大在白玛瑙号上悲惨遭遇。按照昨晚想好腹稿原原本本将班西港诡异与惊悚钢铁埋伏与围杀联手格尔曼后反扑和狩猎全部讲一遍并认真阐述自己对格尔曼能力与背景猜测这包括蠕动饥饿和隐秘强大组织。这过程里尽量还原真相只是略微夸大自己发挥作用将地位从仆役侍从提高到助手合作者这层次。冰山中将一直安静听着没有打断话语末了轻轻颔首道：「他没有恶意。」他？格尔曼没有恶意？连忙说：「船长不管怎么样他都是一个危险家伙！你确定他没有恶意？」「不确定。」非常平静回应。「…那你刚才？」无声吸口气只觉船长和格尔曼类似属于没法好好对话类型。表情不见异常说：「那是我推测和判断。」「…」用右手揉揉额角「总之他很危险背后有个隐秘不知道情况组织船长我认为你不应该冒险和他交流即使他声称自己有事情询问。」艾德雯娜想了下道：「不需要冒险。我可以通过你和他交流。」先是松口气接着好奇又期待问：「船长怎么做？或者说我怎么配合你？」抬起右手在梦境里具现出支架和一块黑板：「需要你举行仪式。它叫降灵仪式能让我精神穿过灵界附着于你身体直接和格尔曼对话在半神以下有效距离不超过500海里…它涉及理性与交流属于知识与智慧之神领域你必须描绘对应象征符号和魔法标识…在神秘学里对应知识与智慧之神是蓝星需要使用水银黄铜薰衣草胡椒薄荷作为材料…蓝星对应周六蓝星时有周五零点到1点周六中午11点到12点…」边讲解边在黑板上书写着需要记住重点达尼兹本能就坐下来摆出专心听课姿态。听着听着忽然有些茫然：为什么我做梦也要学习？……卧室内正在熟睡克忽然惊醒隐约察觉到点什么。翻身起床侧耳倾听一下发现客厅内达尼兹虽然在打呼但比之前平缓不少。这不是太奇怪表现可对这种经历过许多事情神秘学资深人士而言却足够反常。放轻脚步来到分隔卧室和客厅门边探掌握住把手缓慢拧动。无声无息间走出卧室看见达尼兹躺在安乐椅上睡得正香周围一切则正常如前。悄然打开灵视检查起烈焰但未发现任何问题无论气场颜色还是情绪变化对方都毫无异常在合理范围内。俯视一阵微皱眉头伸手掏出枚银制符咒。「梦境符咒！」……梦境之中达尼兹脸泛苦色学习着降灵仪式半点不怀疑面前船长是别人伪装。这样风格这样爱好这样特长没人能假扮！就这时听见锁芯转动声音。下意识间回头望向卧室只见那里门缝越来越大上身只穿了件白色衬衣格尔曼面无表情走出来。「你！你怎么出来了！」猛然站起惊愕脱口。迅速回过神来结结巴巴说：「这这是我梦境啊！」格尔曼这家伙怎么说出现就出现！单手插在深色长裤裤兜里边走向背对窗户女士边低沉回应：「一枚符咒。」接着直视那个女子近乎肯定反问：「艾德雯娜·爱德华兹？」这穿着打扮有点奇怪啊…既不像冒险家更不像海盗有点类同从事体面职业独立养活自己那种女性…类似风格衣物好像是从因蒂斯那边传过来…略微有些不适应想着。艾德雯娜轻轻点头同样反问：「格尔曼·斯帕罗？」「是的下午好女士。」一点点露出笑意以手按胸行一礼。艾德雯娜点头回应：「下午好。」维持人设不再开口等着对方主动询问自己目的。……他看着艾德雯娜。……艾德雯娜看着他。……梦境里忽然出现好几分钟沉静。达尼兹时而看看右边时而望望左侧莫名觉得这一切可能真的只是场梦。

## 这场戏有没有翻
翻了。梦救／课堂；章末对视沉静。翻的是梦境符闯入＋「他没有恶意／不确定」，不是开战。

回旅馆午睡梦。

## 话
「这是梦。」「他没有恶意。」「不确定。」「为什么我做梦也要学习？」局面是从金镑噩梦收到船长门；从汇报收到恶意判；从黑板收到茫然；从符咒收到对视沉静。

## 热怎么变冷
牺牲还热。冷切这是梦。汇报还热。冷切不确定。听课还热。冷切克闯入。对视还热——沉静。

# 483 旅行家 第二章 不对称

## 打开书
回想最近大事月亮埃姆林迅速锁定大雾霾瘟疫爆发——猜对面小姐指这个。可听说一名绝望魔女谋求晋升弄出来…而且风暴教会很快应对造飓风吹散一切；这怎么能说愚者先生拯救贝克？有族群后盾消息还算灵通；两相比较难免又诧异又疑惑。一向骄傲不愿花心思社交往来；面对能用祂称呼隐秘存在仍本能畏惧不敢贸然开口询问——打算先旁听一阵再说。倒吊人阿尔杰即使飘荡海上亦收贝克大雾霾消息；对其中隐藏秘密幕后真相颇感兴趣坚信绝对涉及神灵间争斗毕竟引起愚者注意！等交流消息时询问正义小姐不过她也未必太清楚所处位置没法了解那么多真实细节；呵呵她好奇心很重有了这样开头她肯定会尝试从愚者那里获解答希望有机会旁听…想到侧头望太阳一眼见不急不躁沉稳内敛就知他和白银城探索小队已摆脱命运循环。同样正义奥黛丽也从小太阳反应读出行动顺利悄然松口气准备等下再详细了解经过。对愚者庄重行礼后又感谢世界感谢这位看起来不像好人的塔罗会成员提前做出警告：「…世界先生如果不是您预先提醒或许这次大雾霾里贝克将死去几十万人。」「事实上这也拯救了我自己。」克操纵世界嘶哑笑。说得真心诚意无一点演戏——要不是预先通知正义经由对方提醒黑夜教会那位抹掉A先生强者不会那么及时赶到；而自己未必还能支撑太久。如果被A拆散吃掉也许就无法复活了…庆幸。A先生的吃可是真正的吃！紧接着身为愚者靠住椅背含笑回应：「我只是提供了一点微不足道的帮助。」「不您的眷者真正拯救了贝克他的贡献是所有人里面最大的。」正义由衷赞美：「他的提醒让女神让黑夜女神教会做好准备及时清除绝望魔女阻止原初魔女苏醒让大雾霾被污染程度处在可控范围内；而且他还直接破坏极光会仪式又一次将试图借此降临真造隔断在现实世界之外。」因提供最重要消息奥黛丽得霍尔伯爵与伯爵夫人一致称赞；他们并未对她隐瞒调查结果和打听到一些细节。当然也提出为人父母希望：让女儿尽量不要和那个隐秘组织有太深牵扯处外层圈子收获一些消息并将实力维持序列7以下就足够。原初魔女想苏醒…真造试图降临…贝克究竟发生什么？同一时间倒吊与月亮有同样反应但表情有所区别：前者只眼皮微抬瞳缩不自觉斜坐一点；后者却给人快要跳起来错觉。母神不月亮在上贝克什么时候变得这么危险？一次大雾霾里竟有两位邪神现身！那位小姐是骗人吧？愚者虽疑似神灵存在但也不可能同时得罪两位同层次祂啊…难道说祂其实哪位正神化身？或背后有神灵间联盟？这就是始祖让我向祂祈求原因？埃姆林越想心跳越快可又无法获证实。——血族有吸血鬼外号并不表示他们无心跳只相对缓慢许多；心脏本身也是血族致命弱点之一。果然！不愧获愚者关注事件…可祂又能从破坏邪神们图谋里获什么好处？倒吊暗中吁口气。魔术师佛尔思则又惊讶又后怕——没想到已带走几万条人命恐怖大雾霾背后还藏更加恐怖真相。如果没被及时阻止整个贝克都将毁灭而我和休也必然无法幸存…艰难吞唾沫。她感受也是奥黛丽想法；借助这事贵族少女真切认识到一点：自身认为安乐平和正常稳定生活在神灵间碰撞里就像肥皂气泡稍有刺激就会立刻破碎。或者说整个王国整个人类社会只因神灵之间平衡才得以存在而这个平衡异常脆弱…每涌出类似想法奥黛丽就一阵黯然。见有人知道并记得自己做出贡献克顿时有些欣慰笑笑：「可惜的是他因此不得不远离贝克。」愚者眷者暂离贝克？正义再次起身真诚行礼：「请向他转达我的感谢。」克维持形象没出声回应只点下头。这时奥黛丽又补充：「很抱歉因为三大教会和军方在对贝克进行清理我没能拿到后续罗塞尔日记还请您再等待一周。」「可以。」平淡无波澜。听到两人对话魔术师佛尔思一下惊醒忙望青铜长桌最上首：「尊敬的愚者先生我有收到三页罗塞尔日记。」不错成员越多渠道越多很多东西就会像滚雪球一样飞快壮大…轻轻颔首：「很好。」罗塞尔日记？月亮觉得自己好像又听到什么了不得事情。在他疑惑目光里佛尔思具现三页日记传递给愚者。直到这时克才想起自己遗漏某只吸血鬼轻笑介绍：「这位是新的成员月亮先生。这个聚会叫塔罗会他们分别是…」月亮先生我以为选月亮牌会是女士…正义一边礼貌性致意一边心情有所纾解发散思索。同样埃姆林也在猜想倒吊正义等成员究竟是人还是超凡生物处什么途径等于序列几属哪个组织对血族是否友好。克没在意互相打量目光投手里日记：「二月十一日今天知道了索伦家族一个秘密哈哈哈笑死我了！哈哈哈！原来他们掌握猎人途径会在序列4变性男人不变女的变男！难怪我了解索伦家族高序列强者没一个女的铁血骑士果然是铁血真汉子！哈哈哈要不是这秘密来得隐蔽下次都想以此嘲笑弗洛朗他像那位索伦家族先祖也许原本是个女的！这魔药也太坑了吧？希望通识者高序列之后不会有奇特变化我可不想哪一天突然发现要么不能晋升要么必须变成女的。」看到这则日记克瞬间闪过第一个想法：大帝你不会变女性但你上过一个魔女也许不止一个…果然有女变男途径而且在我预测那几个里面…猎人代表着战争会在序列4导致女士变性…这有点不对啊魔女途径是在序列7女巫这个阶段啊竟然没有严格对应…越想越体会一种扭曲疯狂感由极致不对称带来。难道这个世界底层逻辑就是混乱扭曲疯狂和不对称？竭力控制自己没去皱眉。「二月十二日不行我一看到弗洛朗就想笑。哈哈哈哈！」「二月十五日我设计并督造改进型火炮完工了效果比预想差一点但问题不大有了它有了量产我将让这个世界这个时代见识真正先进的战术！为了庆祝我决定举行一场宴会邀请那些看不起我的家伙你们等着被啪啪打脸吧！」大帝真是仇不过夜啊…一边感叹一边翻到第二页日记：「五月五日那个不可说的组织又一次召集成员聚会。我每次都为他们召集成员方式感到震撼这简直是奇迹不神迹。经过前面观察我在这次聚会上提出一些问题比如亵渎石板上所有序列0名称都位格足够只有红祭司显得独特不够高大上；坐我旁边老先生告诉我红指战争之红祭司可理解为力量本质祭祀者。有人反对他相信红祭司祭司是指最初那位造物主祭司。我倾向于前者于是小声询问起那位老先生名字我并不清楚这里每一位成员身份极端地说甚至只知道其中一部分。那位老先生笑眯眯回答我说他叫赫密斯。赫密斯？创造古赫密斯语那个赫密斯？人类神秘学奠基者赫密斯？」

## 这场戏有没有翻
翻了。月亮猜雾霾开；章末日记落到赫密斯。翻的是不对称＝猎人序4变性，不是雾霾复盘收束。

# 1342 倒吊人 第七十七章 编织噩梦

## 打开书
真就这样回到乌托邦了……看到外面场景文德尔竟莫名有些释然和放松感觉对自己选择出庭作证再没有疑虑。要知道他刚才所处位置是军情九处总部盥洗室就算有一支全副武装军队都没可能攻打得进来。缓慢吐口气文德尔走出盥洗室向大厅入口行去。……我知道你肯定会来因为你是一个善良人。拜尔斯笑着迎向文德尔。……暴怒先生……虽然对方没有戴那副人格面具但那让人难以忘怀特征还是帮助奥黛丽一眼就认出是谁。在她看来要想对付艾瑞霍格这条古老心灵巨龙仅凭暴怒先生应该是不够哪怕愚者先生提醒过她要提防这位。毕竟心理炼金会幕后首领曾经那位天使之王已成为序列0真神按照塔罗会内分享知识现实世界中不该也不会有另外作家。这样一来即使暴怒先生再怎么厉害只要它还在观众途径内那就顶多和艾瑞霍格位于同一层次……或许因为身在梦境与心灵岛屿集体潜意识海洋密切相连不需要别人做出解释她就直观知道暴怒先生在做什么。——在观众途径高序列战斗里双方如果处在同一层次各种手段都很难产生真正效果……所以同一序列观众圣者战斗往往呈现固定化三种风格：一提前设下陷阱……二自身偏重于防御和辅助依靠强大封印物击败敌人；三在精神瘟疫心智剥夺……第三种战斗中谁对心灵领域研究更深入谁意志更为强大和坚定谁就能依靠更长龙化时间来取得优势……而到天使层面大家都是真正神话生物龙化时间长短已没有意义这个时候主要依赖是洞察谁能更好地找到对手心灵漏洞谁就可以编织出相应噩梦直接攻击敌人精神薄弱处一步步摧毁心灵防线达到吓疯或者吓死效果。由于奥黛丽身处同一个梦中哪怕这场噩梦针对不是她她也会遭受波及被相应情绪特质位格影响甚至污染。就像现在她明确知道暴怒先生编织出噩梦代表远古太阳神这是艾瑞霍格心底最恐惧存在而同时远古太阳神影响会不受控制污染周围直至整个梦境。……巨龙吼声回荡之中祂头顶变得幽暗浮现一片包容所有颜色所有秘密难以用语言描述海洋。……这是在巨型白兔心中留下深刻阴影事物这是被地底侵蚀后安格尔威德这是那位古神分割出来封印于青铜大门后一个虚拟人格一段精神污染。……她当即给自己一个安抚毫不犹豫就依靠本身清醒强行脱离梦境迷宫。……奥黛丽眉头一皱当即分化出一个虚拟人格让它进入一位巡夜者心灵岛屿内。……敌袭！敌袭！……亚当不一定就是亚当就像我不一定就是艾瑞霍格。……亚当没有出手？愚者克莱恩眉头微皱将注意力放回乌托邦取代灵之虫们本能监控。

## 这场戏有没有翻
翻了。开头盥洗室直达乌托邦；暴怒织远古太阳神噩梦污全梦；安格尔威德污海；奥脱梦喊敌袭；章末「亚当不一定是亚当」＋愚者转注乌托邦。翻的是编织噩梦＝天使级洞击＋真假亚当疑。

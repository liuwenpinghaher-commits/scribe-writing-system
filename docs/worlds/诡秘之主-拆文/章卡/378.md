# 378 无面人 第一百六十六章 魔术的关键环节

## 打开书
囚禁解；帕克软倒寒颤魂伤未复再吸毒——眼直爬向撕皮露骨卡平；卡平预感无力躲惨叫代「不」。克古赫「神圣」搓指太阳胸针空气弹染圣光奔赫面——神圣誓约伤！赫敏如格斗躲；示凯蒂鞭缠；暗袋铁黑金属手套欲戴左。克飞避鞭掠吊灯扑——赫「流放！」灵被吹撞禁闭壁未穿；赫戴手套高大威严主宰感。克无来由极惧欲匍匐听令迟缓——凯蒂鞭穿灵烙铁痛惨叫；淡金弹两发——又纸人灰！角落现太阳胸针免疫恐惧。两纸人；帕克废减险；预定四纸人尽无机会则弃——灵负四次；禁闭不惧：召唤灵结束即回雾非神／01级难断（窃牌先例）＝敢挑战依仗。赫「此地禁止幽灵与怨魂！」晃斥——黑皇位格压下。怪；「禁止飞行与漂浮」坠地；凯蒂弃轮改鞭（怨魂弹＜3）。团身滚躲；凯蒂咳失连续——毒征！赫「惩戒对象：怨魂和幽灵」体表晨曦拳明净如骑士扑；拳爆空克撤；鞭逼滚游斗。＜两分逼无可避；鞭中臂僵稀；赫左拳「死亡！」残影撞——第三纸人蝶碎！「还有几个替身！」顾不得帕克蠕卡平血腥须速灭敌防毒深。示凯蒂缠；「非法入侵他人住宅即为有罪！」三遍喘难中断再完；克凉意。凯蒂咳缓；克摆脱尖啸——凯蒂晃；赫「有罪者当受限制！」无形镣铐僵。凯蒂换弹含净化；赫酝拳梯次。黑甲克微笑——时机至！毒瓶目的：削弱＋掩瓦斯味归因毒素；亮灭灯扰视兼毁隐蔽煤气管；险境骗怨魂弹防盲射；纠缠等瓦斯满；忍焰跳焰操！禁闭预料且入前检门窗紧＋毁大厅管内外大弹；幽灵不惧爆（低魂惧焰幽灵顶多伤）。凯蒂将射赫将死宣——克笑响指。赫危预——壁炉一点燃周气。轰！眼满焰如盛大烟火。

## 热怎么变冷

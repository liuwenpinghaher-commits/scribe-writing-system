# 386 无面人 第一百七十四章 灵界的特殊

## 打开书
送艾伦后沉凝：解读对但非灵性自主启示——否则出院前应梦；疑千纸鹤灌梦！灵视无光彩；灵感直觉奇妙涉命运。威尔本身奇非牌；银蛇倒霉幸运→水银之蛇怪物序1？灌法：排怨魂（气场无黑绿）；①类梦魇引导勿深；②经灵界——星灵遨游灵界细节／外启示转象征告精神＝梦；伪造启示让星灵获无痕。己办不到略撬雾亦难。或纸鹤暗示翻出即梦——通灵可验／心魇？认者埃姆林非乌特拉。决雾上占危可则夜潜艾伦家梦境符咒观来源；找间接痕难；非旁坐冥想即同游——须定位。秘密之书：灵界与现实全叠无上下左右过现未交汇＝压缩象征海；星灵游哪与地时身心态关无定位难锁；深入迷失痴／植物；肉入灵界跳板传送易永迷路腐。怀表思久餐凉；迈克未来＝委托推迟。吃完占危——诧无一危。换夹克鸭舌带词册出。原计划陪访暗示科勒勿提义工寻女；推迟更从容。东区深处三层：高低床破褥杂物；喊科勒——翻起惊喜「猜您今来未去码头等」。问收入可租更好何仅地铺改高低床？「钱多帮您搜消息；为衰弱攒」。建议孤寡老人救助险——曾工时周交3便士后无收入。去丽芙还册；随意：「前天义工寻黛西昨天警送回勿提免笑」科勒「好心无人笑」。黛西熨衣滴水如故；递册谢；丽弗谢；重申勿提；递2镑零钱「明记者访预酬当面勿提或再给少」；黛猛摇「揭恶不要钱」——「规则不能破」；望丽芙「收；两女多识词才能脱困」。本欲劝搬东区缘／多助——克制：似家数千上万东区乃至鲁恩个人无浪花。丽收「谢记者」。匆离如有鬼噬心；外回头吐气小声：「从来就没有什么救世主……」

## 这场戏有没有翻
翻了。开头还在灌梦机制；章末还册封口垫访酬、克制慈善、「没有救世主」。翻的是个人英雄主义碰壁，不是探索梦境。

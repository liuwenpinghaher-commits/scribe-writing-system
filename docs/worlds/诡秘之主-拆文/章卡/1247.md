# 1247 逐光者 第九十八章 千年的等待

## 打开书
罗思德群岛拜亚姆城外原始丛林内。反抗军首领们聚集到一处山洞中尊敬望着前方那位披着黑色斗篷眉毛焦黄眼眸深蓝海神眷者。达尼兹大人现在是一个机会！剃着光头坐着轮椅留着发青胡须卡拉特略显激动开口。他搭档脸上涂抹有红色短纹埃德蒙顿紧跟着：达尼兹大人据我们情报人员反馈拜亚姆现在局势很混乱无论风暴教会还是总督府人都因弗萨克军队围困贝克兰德而焦虑。说到这里埃德蒙顿望眼卡拉特让这位更了解情况相应领域负责人做更具体描述。卡拉特看看表情肃穆达尼兹大人斟酌下语言：他们内部已出现分歧有人想抽调殖民地力量回援贝克兰德有人想坚守这里作为复兴火种。这样分歧导致军方和风暴教会非凡者们也产生一定茫然各个方面都出现漏洞。达尼兹大人这就是我们机会我们完全可以答应弗萨克和费内波特海军条件配合他们进攻拜亚姆拿回属于我们国度！确实是机会……但这是我能决定事情吗？我又不傻！达尼兹安静听完反抗军首领们陈述在心里嘀咕两句。作为一名因蒂斯人有名大海盗宝藏猎人对进攻鲁恩殖民地确实没一点精神上负担毫无犹豫和徘徊情绪。当然他对因蒂斯共和国归属感也不强甚至在偶尔兼职做海盗时候更喜欢以因蒂斯商人为目标因为他们随身携带有价值奢侈品更多。达尼兹没当场答应反抗军首领们请求原因只有一个那就是已成为阴谋家他非常清楚自己定位究竟是什么：一个人形传话筒！一个负责在格尔曼·斯帕罗和反抗军首领之间传话工具！格尔曼大概率是鲁恩人我要是敢直接答应你们也许就见不到明天太阳……不过他表现得一点也不在意鲁恩……狗屎！不能被表面现象蒙蔽！达尼兹清清喉咙环顾一圈：这件事情关系重大立刻给我准备一个干净安宁祭坛我要向神祷告。在一个普遍信仰海神组织里这样要求没让卡拉特埃德蒙顿等人有一点意外甚至正符合他们期待于是他们当即安排人手准备祭祀。……罗思德群岛反抗军也坐不住啊……他们本身也是得到弗萨克因蒂斯和费内波特等国支持才能坚持下来没被鲁恩和三大教会剿灭……我还让他们从各国榨取不少补助……听完达尼兹祷告克莱恩一阵感叹。坐在古老宫殿内他手指轻敲起面前斑驳长桌边缘思索几秒具现出世界格尔曼·斯帕罗。这位疯狂冒险家旋即摆出祈祷姿态沉声：……借助当前局势直接找风暴教会和罗思德总督府高层谈判施加必要压力……目的是逼迫他们退让接受罗思德人治理罗思德群岛理念……反抗军可以保障鲁恩人目前拥有大部分利益让他们能安心抽调军队和非凡者回援贝克兰德…………那处干净整洁祭坛内得到反馈达尼兹直起腰背。他转过身来将目光投向等待在外面反抗军首领们表情庄严：我已获得神谕。神告诉我们祂每一个子民都是宝贵不要为了不必须战争而牺牲。我们绝不轻启战争但也不会害怕战争总之我们先尝试利用现在情况和我们势力与鲁恩人谈判逼迫他们做出能满足我们绝大部分人让步如果不行再考虑战争。神说谨记仇恨但不要被它蒙蔽理智身边人们和美好未来才是最重要。成为阴谋家之后达尼兹发现自己编造理由说服他人能力是蹭蹭上涨很多时候张开嘴巴就有思路成形。卡拉特埃德蒙顿等反抗军首领都是和鲁恩殖民者有很深仇恨但海神话语和达尼兹大人说辞还是成功让他们出现动摇。那位海王究竟有多么强大他们这段时间是有明确认知如果战争发展到双方都红眼睛程度拜亚姆所在蓝山岛说不定都会被海水整体淹没成为遗迹所有本地人都将被拉着殉葬。弗萨克费内波特强者们确实有能力阻止事态崩坏但他们又能分出多少力量在罗思德群岛这个边缘战场？对于他们卡拉特等反抗军首领并不是太相信认为这些家伙和鲁恩人没本质区别都是来自北大陆强盗随时可能撕下面具成为新殖民者。一阵沉默后坐在轮椅上卡拉特望着祭坛上那位披黑色斗篷男子：达尼兹大人我们愿意为和平解决努力。他顿顿又道：情报显示目前罗思德群岛拥有最终决断权是那位海王亚恩·考特曼我们最好直接和他谈判。达尼兹轻轻颔首：这正是我想法。我们需要派一个人作为全权代表进入拜亚姆面对亚恩·考特曼……他正想问谁愿意去忽然发现卡拉特埃德蒙顿等人目光齐刷刷投到自己脸上仿佛在说海神眷者地位相对超然因蒂斯海盗是最合适对象。……狗屎！达尼兹暗骂一句看着众人念头飞速转动：嗯这是一个荣誉也包含着极致危险我知道你们有人充满牺牲精神想要做出应有贡献呃这样吧抽签决定这样最公平。我没有意见。卡拉特等人毫不犹豫做出答复。几分钟后达尼兹看着手中纸牌脸庞肌肉出现不明显抽动。……白银城圆塔顶部首席房间内。科林·伊利亚特将目光投向与周围对比显得发育不良戴里克·伯格：做好准备了吗？戴里克提着那把握柄似腿骨表面幽蓝缠绕电光雷神怒吼巨锤重重点头：准备好。他表现得一点也不像太阳领域非凡者更接近狂暴战士。头发花白脸上有陈旧疤痕科林·伊利亚特随即移动视线望向洛薇雅：你准备好了吗？有着一头银灰色卷发和一双淡灰色眼眸洛薇雅没再像往常那样穿黑底紫纹长袍换上一身暗黑盔甲。她微不可见动动脑袋：没有问题。已成为银骑士猎魔者科林又将目光投向房间内其他人依次询问有没有准备好。全部得到肯定答复后科林·伊利亚特缓步走到一堵墙边取下上面悬挂两把直剑将它们背负在身后。出发。这位白银城首席旋即言简意赅下达命令。他率领这支探索小队将再次前往下午镇营地对巨人王庭做更进一步探索找出通往真正大海道路。金属甲叶碰撞声音里洛薇雅戴里克等人沉默跟在首席身后鱼贯走出房间沿着楼梯一路下行。途中他们看见韦特·希尔蒙等六人议事团长老看见维持圆塔秩序一位位白银城居民。这些人或趴在栏杆上或等在楼梯口表情都异常肃穆似乎在为这支肩负着希望探索小队送行。没人开口场面一片静默但在科林·伊利亚特戴里克·伯格等人经过时那些白银城居民纷纷抬起右臂将拳头杵在额前。这个动作带起声响里科林等探索小队成员离开圆塔来到路上。他们随即点燃一盏盏兽皮蒙成灯笼。昏黄光芒照耀下一位位白银城居民从房屋内走出来停在路边。他们饱含敬佩和期待望着戴里克等人相继抬起右臂将拳头杵在额前。戴里克下意识就挺直腰背心中一片火热。就这样他们这支探索小队在人群簇拥下沿着道路来到城门口走出白银城。似乎有默契科林戴里克洛薇雅等人刚脱离城墙保护就同时回头望眼那在黑暗中已坚守两千五百八十四年家乡。他们看见白银城居民们没有离去全部都立在城门附近望着自己等人。刷地一下黑压压人们齐齐抬起右臂将拳头杵在额前。这既是在表达最高敬意也是给予最深沉祝福。科林·伊利亚特无声凝视几秒闭闭眼睛举起右臂猛地往下一挥：出发！戴里克等人当即转身提着散发出昏黄光芒兽皮灯笼沉默而坚定踏上黑暗笼罩道路。目标：巨人王庭。

## 这场戏有没有翻
翻了。开头反抗军要打拜亚姆；达尼兹传话成先谈后战并抽签中招；白银城送行拳额、科林挥臂出发王庭。翻的是海线从开战翻谈判、陆线从等待翻千年再出征，不是抽签好笑。

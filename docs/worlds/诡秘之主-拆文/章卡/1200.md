# 1200 逐光者 第五十一章 专业

## 打开书
布提斯两颗眼珠瞳色已变得深黑凝固着难以言喻惊恐让克莱恩只是看到就莫名心悸似乎能体会到对方临死前情绪剧烈变化。经过一番检查再结合占卜办法克莱恩确认这两颗眼珠并不蕴含非凡特性但却藏着强烈污染和来源不明力量可以作为诅咒媒介也能直接影响目标属有效期特别长也相当危险灵性材料。不能长期携带否则自身也可能精神衰弱每天噩梦身体畸变……克莱恩随手招来一个方型铁盒将布提斯两颗眼珠放进去。他没尝试净化因为一旦粉碎这物品驱除污染那就什么都不会剩下太过浪费。由于星之虫没什么问题也是克莱恩相对最了解材料他很快将注意力放到那个黑色口袋上。占卜结果让他有些惊喜因为这是一个所谓空间型物品。那口袋表面看只能插入一只成年男子手掌实际上有莫雷蒂家最早在廷根市时租住两居室房间大小可以装不少东西。这是布提斯利用秘法师能力制作从本质上来说口袋不是物品而是一个出入口。……先是依靠空间隐藏能力在灵界扭曲隔离出一片区域然后再利用灵界与现实重叠且混乱只要有正确坐标就能直接抵达目的地特点将那片隐藏区域门开在这个口袋里……这和封印旧日之盒办法很像只不过一个门在灵界一个在现实这导致空间口袋内封印物神奇物品负面效果同样可以影响携带者……这么看来作用不大啊不能消除负面影响……而且我在神弃之地没法连通灵界有这个口袋也没用……还有必须每隔一段时间就加固空间隐藏力量否则这会逐渐失效……只适合学徒途径半神啊或者有学徒途径半神封印物提供辅助组织……空间口袋这名字太俗也不知道布提斯原本怎么称呼这件物品……就叫旅者的行囊吧……克莱恩确认好危险程度具现出一只假手让它探入黑色口袋。哗啦啦一堆各式各样宝石随着那只假手回缩倾泻出来落在斑驳长桌上那晶莹火红湛蓝碧绿淡白深黑和透明瞬间映满克莱恩眼眸。……我早该想到会是这样……学徒途径对应材料就是宝石所有宝石……克莱恩神情一下生动笑着叹息两句并伸出另一只手拿起好几颗宝石感受下重量和材质。除这些旅者行囊里还有不少灵性材料有属常用类型有较为少见。旧日之盒秘法师非凡特性九条星之虫布提斯眼珠旅者行囊大量宝石和材料……这次行动算得上丰收了足够大家分配……可惜布提斯可以记录非凡能力和某种状态没必要带太多封印物和神奇物品在身上那样反而会被众多负面效果影响……作为一名半神他应该有几件不错封印物也不知道是藏在灵界哪个地方还是极光会总部……可惜啊刚才布提斯连灵魂都崩溃了没法通灵……克莱恩摇头当即返回现实世界找个有遮掩地方放好马灯布置起祈求赐予仪式。他想试试能不能将0-61也就是旧日之盒弄到神弃之地。如果可以他就能将白银城整体玩具化放入那封印物第一层直接通过献祭和赐予仪式送到外界这样一来就等于绕过巨人王庭和暗天使萨斯利尔巧妙完成奇迹师仪式。一番忙碌后完成前置准备克莱恩伸出右手往前一抓从空气里拖出另一个自己本体则跃入历史迷雾内一路躲到第一纪前孔隙中。他这是担心旧日之盒通过献祭与赐予之门后会让旁边自己随机性暴毙。灰白雾气深处光之碎片里克莱恩逆走四步回到灰雾之上自己响应起自己祈祷。等到神秘古老献祭与赐予之门成形并缓慢打开他招手摄来层层力量包裹旧日之盒将它丢向虚幻大门缝隙丢向门后那深沉无垠黑暗。就在这时那虚无黑暗突然有实质感似乎形成一道无形屏障将旧日之盒挡在刚通过对开大门地方让它漂浮着无法前行。克莱恩微皱眉头看着这一幕尝试撬动源堡力量以天使层次做出推动可依旧无法让旧日之盒打破那屏障。……果然神弃之地是有封印只不过我本身与源堡关系密切可以利用它做出响应但这不能超过一定限度。克莱恩幅度很小点头将旧日之盒收回来丢入杂物堆。然后他具现出世界格尔曼·斯帕罗让这个假人将旧日之盒详细情报告诉隐者女士和正义小姐。这是提醒她们一定要在24小时内将旧日之盒拿回现实放出魔术师佛尔思。其中克莱恩有告知正义小姐祈求赐予旧日之盒前记得向某条命运之蛇眷者献祭点顶级冰淇淋至于隐者嘉德丽雅由于本身有短暂幸运倒是无需外求但她必须在几分钟内完成一切再次将旧日之盒献祭到灰雾之上。……贝克兰德东区和桥区交界之处一栋年久失修公寓内。戴着红手套穿黑色呢制大衣伦纳德正领着自己队员认真检查现场。作为黑夜教会机动力量在这近十点夜里他们毫无疑问充满活力。队长这里墙壁有出现严重开裂部分地方甚至已经粉碎这栋公寓也许撑不过明年夏天飓风季。留着酒红色长发辛迪靠拢过来向伦纳德汇报。伦纳德碧绿眼眸扫周围一圈轻轻颔首：还好这里本来就是危房早就没什么人居住不过连流浪汉都没有这一点非常奇怪。辛迪想：队长你意思是有非凡者在利用这栋公寓悄然驱赶睡在这里流浪汉们？然后他们自己发生内讧爆发战斗点燃什么东西？另一位红手套鲍勃刚好在旁边检查墙底随口接续。不排除这个可能。伦纳德相当专业回答：但你们有注意到吗？这房间每一个地方都有一定腐蚀痕迹并且缺乏应该存在桌子和椅子残骸显得太过空旷……这不太像中低序列非凡者能够弄出来我怀疑可能涉及较高层次力量。经过一番检查发现不少异常后属于伦纳德这支红手套没能找到更进一步线索只能先行返回圣赛缪尔教堂。他们刚抵达地底就有一位主教来找伦纳德让他带两名队员去楼上参加一场会议。伦纳德若有所思点头什么都没问领着鲍勃和辛迪经过秘密通道进入圣赛缪尔教堂。接着他们沿着盘旋楼梯在透过彩绘玻璃红月光芒照耀下来到一个放着黑板挤了不少人房间。只是一眼扫去伦纳德就发现不少合作过代罚者机械之心和军情九处成员。然后他注意到霍拉米克·海顿雷达尔·瓦伦丁和安东尼·史蒂文森这三位半神以及一位明显和他们层次相当黑发金眼男子。不等伦纳德问好穿黑底红纹长袍圣安东尼站起来沉声：贝克兰德郊外发生一场高层次战斗现场有遗留可怕污染和一张塔罗牌隐者牌。我有注意到你曾经针对涉及塔罗牌大量事件做过一定调查并提出相应猜测现在你为大家做个详细介绍。……隐者牌？伦纳德表现出真实惊讶但这更多是因为自己被赋予这么一个任务。咳他清清喉咙走到黑板位置转身面对三大教会和军方半神非凡者们在胸口顺时针画个绯红之月。组织下语言这位红手套队长郑重：最近两三年涉及塔罗牌事件真正进入我们视线是兰尔乌斯之死他卷入一场想让真实造物主降临阴谋他身上洒满塔罗牌。之后卡平案里再次有塔罗牌出现但这次塔罗牌摆放方式有变化重点强调审判和皇帝牌……我当时将这些事情和贝克兰德突然出现一个信奉愚者组织联系一起你们知道愚者是塔罗牌起始牌。这个大胆猜测听得在场几位半神和众多非凡者微微点头觉得这确实可能存在神秘学意义上联系。伦纳德顿顿又道：而愚者之下这个组织可能有不少位正式成员他们以塔罗牌为代号比如审判比如皇帝比如这次事件里隐者……说话间伦纳德拿起旁边用做演示塔罗牌随手抽一张。他看一眼呵呵笑：也比如星星。

## 这场戏有没有翻
翻了。开头还在灰雾清点眼珠口袋；章末神弃之地送盒失败＋伦纳德专业勘察切联席会点名隐者／星星。翻的是战利品线切官方调查线，不是行囊厉不厉。

- 眼珠：无特性有污染；诅咒媒介；不可久携。
- 旅者行囊＝空间门口袋；负效仍影响携带者；需半神加固；神弃之地无灵界用不了。

- 放人：24小时；正义先献冰淇淋求幸运；隐者几分钟内再献回。

## 热怎么变冷

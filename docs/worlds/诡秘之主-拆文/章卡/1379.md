# 1379 倒吊人 第二十七章 一个奇迹

## 打开书
上千个阿蒙各自做出窃取。以祂们数量只要不是运气差到极点总会有那么几个获得成功而且那团愚者魔药现在是无主之物偷盗它不存在任何难度。窃取同时阿蒙们还解除对自身某种封印让来自学徒和偷盗者非凡特性展现出自身聚合能力。这对愚者魔药相当有效可以最大程度提高阿蒙们窃取成功率。……因为特伦索斯特黄铜书上出现一条新规则：此地不允许偷盗行为存在！之前为对付复苏诡秘之主阿蒙们削弱这里所有封印帮助特伦索斯特黄铜书摆脱愚弄可以有限度在反复循环中制定一些短时间内有效规则而现在这反向影响到祂们。……他身周淡薄灰白雾气交织起来构成一个薄薄蚕茧。他全力激发源堡配合本身诡秘侍者非凡特性对愚者魔药制造出极为强大聚合效果。……安提哥努斯晋升愚者努力因种种缘由最终失败了。……克莱恩·莫雷蒂晋升失败和安提哥努斯成为愚者有什么关系？……若他放弃安提哥努斯身份和命运那他体内序列9至序列1非凡特性将不再真正意义上属于他没被消化过——那是安提哥努斯曾经掌控非凡特性目前和克莱恩·莫雷蒂无关他只是强行吞了它们。这种情况下即使没有别因素仅是那些没消化非凡特性都大概率导致克莱恩当场失控而以这种状态服食愚者魔药完成晋升仪式毫无疑问没有一点成功可能！远古太阳神书写下这段话语时星界中永恒烈阳风暴之主和知识与智慧之神都察觉到什么各自做出最猛烈反扑试图干扰对方行动。……大地母神蒸汽与机械之神对阵原初魔女隐匿贤者战斗又变得激烈不过前两者还是能分出一定余力向阿蒙分身施加影响阻止祂们破坏克莱恩晋升仪式。阿蒙们被逼迫到处闪现可依旧有部分变成植物开花结果回归大地有部分坍缩成文字被印入虚幻书籍中。除这些祂们还有很大一部分在加强封印限制特伦索斯特黄铜书让它制定规则无法起效或者只能发挥刹那作用。……这不是窃取而是归还。阿蒙们选择在这一刻将曾经从克莱恩那里窃取来事物还给对方。……当初克莱恩被阿蒙抓到神弃之地时多次想要自杀却未能成功被对方窃取走相应念头。……此时此刻被那团愚者魔药紧紧包裹住克莱恩思绪已变得混乱发散开来感受到体表极度冰冷黏稠液体正一点点侵蚀而入。……这是克莱恩完全没有预料到变化他早就忘记自己被阿蒙窃取过自杀意念而且没想到对方不仅未随意丢弃这些反倒将它们认真保存起来。……这样平衡下克莱恩精神和身体进一步受到愚者魔药侵蚀。他思绪和之前晋升诡秘侍者时一样彻底发散开来。……用不了多久克莱恩将完全失去自我被愚者魔药被里面各种精神烙印主导成为真正意义上怪物。……化入万物克莱恩精神因这点不协调和不自然弹出少许找回一点自我认知。以这点自我认知为核心他飞快聚拢着发散精神主导起愚者魔药融入身体过程。可这个时候安提哥努斯失控疯狂命运在远古太阳神预言下提前到来克莱恩身体又一次崩溃无力去承受愚者魔药。没有犹豫也没时间犹豫克莱恩当即解除部分窃取效果将安提哥努斯身份命运和自我认知还给原本主人让坐在巨大石椅上缓缓睁开眼睛一脸茫然安提哥努斯逐渐变得清醒。祂没立刻失控因为祂失控疯狂主要原因在于诡秘之主意志较大程度上复苏了而现在承载那部分意志愚者唯一性和大部分非凡特性都已经不在祂体内。……远古太阳神预言因此实现了：安提哥努斯确实没能晋升序列0愚者。而克莱恩没有祂身份后体内序列9到序列1占卜家途径非凡特性都变成没有消化好那种这让他一下就处在失控边缘。斗篷一样包裹住他身体愚者魔药顿时完成渗透福生玄黄天尊意志又一次复苏了！放弃吧……将所有都交给我吧……这一次我不会再容纳别源质……我不会帮助你想要保护生灵但也不会去伤害他们……这不是我信守承诺而是他们太弱小了根本不值得我关注……这里将是外神禁地……这时本无力再劈下那把黄昏巨剑黑夜女神突然放弃对阿蒙真身控制。……噗一声他被黄昏象征之剑斩中碎成一摊腐朽烂肉往外析出着非凡特性。克莱恩死了在阿蒙们对他采取各种措施前在仪式失败彻底失控前被黑夜女神杀死了。下一秒黑夜女神将那个鸟型黄金饰品戴到头上身体虚化膨胀笼罩整座古老宫殿让阿蒙真身分身大地母神原初魔女蒸汽与机械之神隐匿贤者和安提哥努斯都如同素描一样被橡皮擦瞬间擦掉了。隐秘！远古太阳神似乎明白黑夜女神想要做什么可已是做出两次预言祂怎么都没法再写下第三段话语而风暴之主这三位真神继续着之前爆发牢牢将祂拖住。下一秒奇迹发生了克莱恩从历史迷雾中回归了。刚才已属于他愚者唯一性三份序列9至序列1非凡特性都急速往他体内返回。害怕他被干扰灯神忙利用特伦索斯特黄铜书添加一条规则：此地适宜非凡特性回归。霍然间克莱恩回到喝下愚者魔药时状态。……这样一来他就有真正支柱可以容纳愚者唯一性和剩余特性支柱。——克莱恩现在就相当于刚到霍纳奇斯山脉主峰时自己一个消化完诡秘侍者魔药可以尝试晋升序列0愚者自己。……这是他从罗塞尔复活这件事得到灵感当然整个过程和黑皇帝复活还是有所不同。克莱恩原本安排杀掉自己角色是灯神没想到事前未做沟通黑夜女神竟如此默契。……这个过程非常短暂也就是两秒不到时间而黑夜女神一下隐秘掉那么多神灵举动明显是没法维持多久。瞬息之后被隐秘世界表面出现一扇飞快游走光门。这扇门轰然打开戴尖顶软帽穿古典黑袍阿蒙真身跃出来。……愚者诞生了。

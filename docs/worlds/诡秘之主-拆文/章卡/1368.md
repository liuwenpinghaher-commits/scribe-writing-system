# 1368 倒吊人 第十六章 大手笔

## 打开书
掂量下手中鸟型黄金饰品克莱恩很快返回现实随意挑个空旷之地布置祭坛举行献祭仪式。对于卡尔德隆这座亡者之城隐藏其他秘密对于永暗之河与徘徊其中模糊身影们他暂时没有深入探究想法因为他还有更加重要事情准备做还有一个关键问题想请教黑夜女神。很快他举行好仪式让烛火与灵性材料结合形成一扇献祭与赐予之门。没有犹豫克莱恩将那个鸟型黄金饰品放入风中任由它穿过缓缓敞开神秘大门消失在无垠黑暗中。……大厅最深处黑夜女神坐在一张形制古老高背椅上依旧穿着那身层叠却不繁复幽黑长裙。……脸孔仿佛蒙着层层薄纱黑夜女神拿着那个鸟型黄金饰品缓缓站起来沿台阶往下走到克莱恩面前。……你有什么想问的？……我想知道笼罩永暗之河灰白雾气是否与那位诡秘之主有关。也就是福生玄黄天尊。黑夜女神头部虽然让人看不清楚但却直观让克莱恩感觉到祂似乎笑一下：是的而且不止永暗之河被灰白雾气笼罩班西港那扇门后城市和整个西大陆都被灰白雾气笼罩着。……这是一种封印？黑夜女神梦境投影颔首道：对除源堡和混沌海其余所有源质都被那位诡秘之主封印在西大陆。永暗之河母巢灾祸之城暗影世界失序之国知识荒野和光之钥都被天尊封印到西大陆？这会不会太过分了？真是大手笔啊……难怪班西港那扇门后城市就如同曾经魔都……这是灾祸之城影响现实中那座城市以及班西然后在某种程度上也因它们产生……之前在班西看到门后景象时他就怀疑那与西大陆有关并且根据班西是红天使梅迪奇家族所在地这条线索怀疑门后是灾祸之城这份源质映射。……那位诡秘之主强大超乎我想象……这样一位能称之为宇宙支柱旧日怎么会无声无息陨落？黑夜女神梦境投影摇下头：并非没有声息。从现在一些线索可以推断祂是和古老年代里那位上帝一起陨落。那位上帝尸骸在混沌海中形成第一块亵渎石板石板旁边就是偷盗者途径唯一性。也就是说第一纪中期诡秘之主与那位上帝发生一场异常激烈却动静不大战斗最终双双陨落？这能解释为什么远古太阳神走出混沌海时拥有或放牧偷盗者途径唯一性那是古老年代里上帝从诡秘之主身上撕扯下来……克莱恩思绪纷呈间略感疑惑问道：祂们为什么想杀死对方？同为支柱且属于不相近途径应该没有你死我活无法化解矛盾。黑夜女神梦境投影嗓音轻柔舒缓说道：聚合是本能。层次越高本能越强。那位诡秘之主和古老年代里上帝都有无法遏制重新聚合在一起成为整个宇宙化身也就是最初造物主本能。越强大越疯狂？在狡诈强大恐怖充满智慧之外福生玄黄天尊还有这样一面？克莱恩想想道：那位诡秘之主和古老年代里上帝从本质上来说应该都是最初造物主不同侧面？黑夜女神梦境投影用带着安抚意味嗓音道：用同一个存在不同人格来比喻可能更加准确。最初那位造物主是宇宙开创者也是终结者是白昼也是黑夜是神圣之光也是堕落深渊是所有矛盾概念和象征聚集体。所以祂天然具有无法控制分裂倾向而一旦分裂又会产生强烈聚合趋势。比我们曾经生存那个年代更加古老历史里沉睡中最初造物主就已经自然分裂出多个人格它们同样处在沉睡状态中但开始利用自身掌控权柄和非凡特性间接影响着世界为最初造物主苏醒后真正分裂做很多准备。这里面最强大也最活跃就是上帝和诡秘之主后者在西大陆有另外尊名。第一纪中前期祂们应该有通过不同办法掌握额外复数源质这让祂们聚合本能更加强烈以至于无法自控针对彼此展开行动。根据远古太阳神研究支柱是自身状态能稳定最高层次。旧日如果超过这个限度哪怕只多容纳一份别源质也必然会被聚合本能控制无法逆转。那场战斗具体情况怎么样没谁知晓就连灵界七光都无从了解。我们只知道从那之后两位能称为支柱旧日彻底消失而混沌海和源堡之外其余源质都被源堡力量封印到西大陆——那里曾经是诡秘之主统治地域。这样布置导致一个问题那就是诡秘之主和上帝重新出现解除和打破西大陆封印前这个世界没有哪位序列0能成为旧日对抗外神。随着末日越来越近这个问题就逼迫所有真神去培养一位诡秘之主或者上帝出来而之前诡秘之主和上帝就有很大可能在祂们体内苏醒。这……所以封印其余源质是天尊有意做防止后世序列0真神们刻意避开自身所在途径扼杀新诡秘之主诞生？而只要有新诡秘之主诞生祂就有很大概率复活归来彻底苏醒……这也太阴险太过分了吧？从某种程度上讲这样布置根本不怕被人知道知道存在越多越会倾向于……不愧是能让灯神落到现在这种处境支柱级旧日……那为什么不在第四纪就扶持一位诡秘之主出来？这个问题答案他其实已经知道因为随着时间推移作为最初造物主不同人格天尊和上帝意志也是在不断衰退。越是接近末日相应意志越弱后来者越有可能去对抗去压制不至于直接失去自我。从亚当一直等到最近才晋升空想家就可以证明一二。黑夜女神梦境投影带上几分笑意：当时阿蒙和伯特利都不愿意祂们都希望做好各种准备等到末日将近时再尝试。而萨林格尔打算间接利用永暗之河融合红祭司唯一性开创一条新旧日之路然后祂就疯了再无法克制自己对黄昏和黑暗途径聚合渴望。死神也是被逼没办法啊一方面是末日只剩一千多年另一方面是永暗之河被天尊这个支柱封印无法尝试掌控……太阴险太过分了！克莱恩忍不住又在心里批判天尊一句。这时黑夜女神梦境投影继续说道：随着时光流逝西大陆封印是在逐渐减弱那些源质或本能或有意识利用起自身象征范围内唯一性和高序列非凡特性间接侵蚀它们影响外界。最早渗透出力量是永暗之河它在第二纪就通过格蕾嘉莉在外界形成一条支流。之后到第四纪更多源质开始在南北大陆和五海岛屿出现踪迹。这是第四纪很多异变背后隐藏重要因素。……我大概明白了。这就是您一直帮助我原因？

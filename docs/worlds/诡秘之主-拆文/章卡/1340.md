# 1340 倒吊人 第七十五章 梦中

## 打开书
回过神后奥黛丽一边保持着浅笑状态一边变得警惕。她隐约觉得冥冥中有股力量在推动着自己来赫德拉克这有巨龙崇拜风俗村庄。这就像是命运安排。奥黛丽曾经进过诚实大厅发现里面壁画都变成现实而且她知道观众途径序列1叫作家从这个名称出发展开过一些联想此时难免怀疑不对。……我听过这个村庄我记得家族在附近有一个庄园。……快要傍晚了不如留宿在这边明天继续狩猎？……那派人回去告知爸爸和妈妈一声。……还是回去吧这边庄园没有提前得到通知肯定没什么准备或许没法为这么多马匹猎犬和仆从服务。而且距离傍晚也还有1个多小时足够返回了。……考虑到妹妹也在这里他嗯一声道：那就尽快返回吧。……利用操纵师能力改变两个哥哥想法避免他们靠近赫德拉克村庄奥黛丽掀开天鹅绒被子躺下去进入沉眠。……她现在认为当时应该顺着希伯特想法直接去赫德拉克村庄附近那个家族庄园然后合理地安排希伯特和阿尔弗雷德回到这边只剩自己留守那里等待可能发生变化。……不过她那个时候主要想法就是不能跟着命运安排走能避开赫德拉克村庄就尽量避开。……她已初步确认以自己半神层次梦境行者水准能直接脱离这个奇怪梦境回到现实世界再次规避掉疑似邀请。……这个过程中她其中一只手手背处凸显出一片星辰般深红纹身。纹身随即消逝仿佛从未出现过。这是她第一次进入灰雾之上那座古老宫殿后遗留印记……愚者先生才告诉他们在来不及祈祷时可以用激发相应纹身办法代替诵念尊名这个步骤。简单来说这就是一位神眷者待遇。……所以奥黛丽给自己制定行为准则是对熟人只观察和读心尽量不入梦对陌生人则没有入梦限制而若非必要不进入每个人心灵世界。……你曾经去过利维希德。……奇迹之城利维希德……它怎么知道……奥黛丽刚闪过这么两个想法就听见对面心灵巨龙开口说道：每个心灵里意识都在和集体潜意识大海做着一定交换而利维希德是非常特殊存在它于你心灵里形成印记同样如此。当你虚拟人格遨游于集体潜意识大海且距离我不远时我自然就能感应到这一点。这已经超过我能力范畴也不是织梦人能办到……这条心灵巨龙对应序列2洞察者？祂竟然没有直接操纵我……奥黛丽念头闪烁间那心灵巨龙又一次开口了：我很确定你目前没有恶意。……你不担心是陷阱吗？

## 这场戏有没有翻
翻了。开头觉命运推；改哥想法避村；夜梦难逃；神眷纹身；章末巨龙感应利维希德印问陷阱。翻的是避命运＝仍入梦见龙。

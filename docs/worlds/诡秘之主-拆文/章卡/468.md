# 468 无面人 第二百五十六章 吸血鬼女王

## 打开书
灰雾宫月亮埃思讲何史。愚＝始祖老友灾前勿重复；四五纪荣光多唯一点关键。认愚＝灾前古神未陨沉睡渐苏——解千年记载无此类至尊名突传。挺腰：「灾后血离南北舞台中央；个体非族群成各帝国朝贵族辖地／守关键堡。至女王血月女王奥尔尼娅＝特伦索斯特夜皇妻；血凝聚成王朝重要支持；奥古斯都艾因霍恩须尊称皇后陛下。奥尔尼娅美象征；魔镜问世界最美女答案只能她…」越说越傲滔滔。魔镜＝阿罗德斯？机械之心闲否魔镜魔镜谁最美…转严：「四皇之战破灭；夜皇陨女王陨血重创；七神支持四大贵族瓜分灭缺高位皇室；血退深山阴角保延续。」七神四皇时已七——六神像。幸七神裂四国互攻付代价脱厄。炯望：「还有空听血月女王生平与荣光？光辉篇章沉重典籍可复每部。」能讲一天一夜…人偶耻竟学术；不爱出门深研寿长…婉拒：「足够。喜等价交换；以后有机用相应史换想要。」失落——首有机向他者讲荣光；平隐身无法炫；内该知皆知轮不到己教新生。居高：「回去吧。」深红吞——眩仍租车；虚幻羊皮密契求愚助知。午空回家即仪请解暗示！抵丰收车资；乌特布道——不苦恼轻：乌特似从未阻我寻解暗示？想何…切东区油腻咖：克沾嫩豌豆炖羔羊汤燕麦听科勒周讯——无大价值。又推两镑。「刚给过！」愕摆。「周内南度假辛苦一年该休；或两三周回；提前付酬勿忘搜。」接欣：买舍不得腌火腿配面包；谢莫里亚蒂吞咽。帽：「近东区乱。勿为探险；不对即避勿掺。」埃事忧。「明白；我胆小。」「好。」想丽芙弗莱娅黛西：「留意丽芙一家勿被欺；东区暴动类带避安全。」「暴动工人抗争？」「差不多。」极限。切人偶房午埃归昏暗握拳：「为我加油！」写愚尊名符密契——灵飘高处见难描影七道光芒灰雾上古殿影。见威严金影背遮天黑羽——未细数对即上浮触金影。「啊！」惨捂头满地滚青烟！缓闻愚低沉：「你的心理暗示已解除。」真痛…坐地喘乱发。灰雾克点自语：太阳胸针净驱同步伤血；推算阳光不足重创懒改复杂＝预期。取黄水晶卜：「今天下午适宜去红蔷薇庄园。」七遍——摆静止！0级／强者卜难无效。再卜明午亦败。占卜非万能印证；须自决；此步须走否则无法不引人退舞台转幕后；越早越好…决断。返现实双排扣半高礼帽出明斯克——目的地红蔷薇。

## 这场戏有没有翻
翻了。开头血月女王史；章末解暗示痛＋决赴红蔷薇。翻的是四皇之战血退＋延迟密契落地，不是听一天女王传。

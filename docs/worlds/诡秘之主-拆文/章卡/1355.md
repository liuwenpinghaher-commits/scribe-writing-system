# 1355 倒吊人 第三章 紧迫

## 打开书
稳定住锚天尊意志自身意识脆弱平衡后克莱恩靠住椅背审视起诡秘侍者非凡特性带来种种能力。其中最为主要有三种都是克莱恩之前就已经借助源堡和幕布掌握但不清楚具体命名：第一种是再生：如果一个物品构成材料曾经有灵体那诡秘侍者可以利用再生能力将相应灵体之线唤起让物品成为自己秘偶并使和这物品建立了深层次联系生灵也自然转变为秘偶。简单来说就是诡秘侍者不能让原本不存在灵体之线事物产生灵体之线但可以让某些物品曾经拥有但早就消失灵体之线再生前者代表是钢铁制品金币金镑等后者以牛肉鱼肉等食物为主——人类一旦吃下变成秘偶食物自身也会随……第二种是重组也叫篡改：这能将许多实体事物或抽象概念重新组合在一起达成不可思议效果就像在篡改定义逻辑指向或规则。第三种是诡秘之境：这是用来创造神国雏形能力可以带来一定隐秘效果。重组体现是变化领域权柄诡秘之境侧重隐秘领域愚者符号两个要素都已经齐备了……不过重组和篡改都不够好听含义也不够清晰还是我取嫁接好一目了然……克莱恩在心里咕哝几句后将目光投向四周。现在他已更进一步掌控源堡能够直接借用占卜家途径接近序列0位格能力也可以使用偷盗者途径序列0和学徒途径序列0之下大部分非凡能力和当初暗天使萨斯利尔差不多。……更进一步掌握源堡后我在这里和在外界各种差距也近乎没有了不会出现在外界是天使之王回到源堡就是真神情况……这里最大优点是提供一个就连真神都无法打破防御屏障嗯外神们行不行目前还无法判断……克莱恩缓慢吐口气……一是原始月亮也就是堕落母神虽然没能借助门先生回归完全降临于现实世界但祂也有侵入一点力量并且在黑夜蒸汽等五位真神攻击下维持好几秒钟这是否会对周围环境相应途径部分事物带来某种程度影响还有待观察。二是时天使阿蒙已窃取走门先生仪式成为偷盗者途径序列0错误祂将是克莱恩最直接也最厉害那位敌人。……不知道阿蒙有没有顺势容纳门先生唯一性和一份序列1星之匙非凡特性……正常来说阿蒙应该来不及容纳学徒途径唯一性……也就是说阿蒙之后重心是容纳学徒途径唯一性成为两条途径真神否则在其余真神注视下祂想解决我这么一位天使之王将非常困难。……而且就算祂确实做出冒险并已经成功现在已容纳学徒途径唯一性接下来也得慢慢适应和稳定自身状态短时间内没法对付我。我得抓紧时间成为愚者只有这样才能凭借源堡和本身位格对抗阿蒙。留给我时间不多了……克莱恩无声自嘲一句后前倾身体轻敲起斑驳长桌边缘。他在分析自己短时间内成为愚者可能性：诡秘侍者魔药消化相对简单等到克莱恩凭借锚和自身意识就能压制住福生玄黄天尊复苏意志不至于失控疯狂或变成另外一个人后他可以借助源堡像阿蒙那样弄出一个分身然后让这分身分调源堡力量将本体尚未消化来自查拉图……这样一来克莱恩就降级为已完全消化好魔药诡秘侍者并且拥有一个诡秘侍者秘偶——这将是魔药主材料之一。而消化好魔药诡秘侍者是有资格服食愚者魔药成为序列0真神。……所以于克莱恩而言最麻烦反而是另外两件事情：一是如何对付安提哥努斯家族那半个愚者二是怎么完成愚弄时间历史或者命运仪式。……愚弄历史……愚弄历史……克莱恩再次轻敲起斑驳长桌边缘脑海内不断闪过各种各样想法又不断做出否定。……当前真实历史是这样：塔罗会众位成员认为自己追随是不属于这个时代愚者——一位复苏古神或超越古神存在而实际上愚者先生最初只是一个被吊在灰雾之上普通人借助各种资源一步步包装着自己提升着自己。……利用源堡制造一个分身让这分身借助源堡将本体命运意识锚和属于查拉图那份序列1诡秘侍者非凡特性窃取过去。于是本体非凡特性将纯粹由那块幕布组成福生玄黄天尊将一点点苏醒。这样一来塔罗会众位成员认知就是正确：愚者先生是复苏伟大存在。……当然前提是分身窃取这件事情要发生在源堡之内或其余隐秘地方否则它也会被历史记录达不到愚弄效果。至于福生玄黄天尊苏醒了该怎么对付分身又如何宰掉本体将祂制成魔药克莱恩暂时还没有办法。这么尝试结果就等于自杀呵被天尊弄死前分身诡秘侍者非凡特性肯定也消化了毕竟成功复活诡秘之主……克莱恩摇下头将那只管开始不管收尾思路抛到脑后。……他目标有两位：一是命运之蛇威尔·昂赛汀二是黑夜女神。前者对愚弄命运可能有一定想法后者大概知道安提哥努斯家族先祖当初是依靠什么样仪式容纳愚者唯一性。……稳定下精神状态克莱恩离开源堡直接传送去贝克兰德。

# 1276 倒吊人 第十一章 层次的变化

## 打开书
听到愚者先生话语倒吊人阿尔杰心中莫名一颤突然有种在帕苏岛向风暴之主祈祷时感觉。他刚才向愚者行礼问好时并未察觉对方有什么变化一切似乎都与往常一样可这个瞬间他相信愚者先生和过去不同了。这是一种灵感上体验阿尔杰无法准确地用语言来描述只是觉得那层灰白雾气包裹下身躯蕴藏着以往几千几万倍恐怖看似平淡一句话或者简单一个动作就能给人位格上绝对压制。愚者先生更进一步复苏了……世界去神弃之地转一圈将白银城带出来后愚者先生更进一步复苏了……祂现在已经有序列0位格？如果不是水手途径对高位者层次敏感我甚至发现不了……倒吊人阿尔杰本来想开口说话……星星伦纳德环顾一圈见其余成员都保持沉默遂试探着开口道：根据目前搜集到情报显示之前确实发生一场神战其中可以肯定是出现于贝克兰德高空有黑夜女神战神和大地母神至于结果我想大家都很清楚你们对此有什么想法？上周塔罗聚会里伦纳德已经提过相应事情并主动向愚者先生询问究竟发生什么事情。可惜愚者先生只是告诉他祂最近关注是神弃之地未做正面回答。我无法理解为什么会出现那样结果大地母神战神这对母子联手竟然都被黑夜女神击败……隐者嘉德丽雅没有掩饰自己疑惑。倒吊人阿尔杰收回思绪斟酌着说道：我收到一份情报神战刚刚结束费内波特就倒戈了。这说明……正义奥黛丽隐约把握到什么。就在这时太阳戴里克学着对面女士抬下手臂道：我大概知道为什么。你？月亮埃姆林发出不信任声音毕竟太阳之前隔绝在神弃之地对外界了解全靠塔罗会其余成员灌输他怎么可能比在座诸位都更加了解神战细节。知道太阳一向诚实倒吊人阿尔杰按耐住好奇和发自内心些许激动低沉问道：为什么？你们必须在愚者先生面前承诺不能泄露我接下来要告诉你们事情。没问题。隐者嘉德丽雅带头说道。等到众人在愚者见证下做出承诺太阳戴里克点头：大地母神不是巨人王后欧弥贝拉真正欧弥贝拉早已死去祂遗骸就在白银城。一时之间倒吊人阿尔杰正义奥黛丽等人都无法成言就像遭遇雷劈各自麻痹在位置上如同一尊尊石制雕像。过了好一阵星星伦纳德才难以置信开口问道：确定？下意识间正义奥黛丽魔术师佛尔思和审判休等人都将目光投向斑驳长桌最上首那道身影发现愚者先生眸含笑意保持着刚才坐姿没有一点改变。这间接说明祂认可小太阳刚才提供情报……正义奥黛丽抢在太阳回答星星疑问前微不可见点头道：这能解释许多事情可如果大地母神不是巨人王后那为什么命运天使乌洛琉斯会认为祂是欧弥贝拉？唔为什么战神要找祂合作？祂究竟是谁？听到正义小姐一连串问题倒吊人阿尔杰突然有些感触……隐者嘉德丽雅专注于正义小姐提出问题思索着说道：或许那位大地母神一直在伪装成欧弥贝拉这瞒过命运天使也瞒过战神……怎么可能……审判休本能低语一句。魔术师佛尔思则轻吸口气道：真是一个恐怖故事啊。这时一直沉默世界格尔曼·斯帕罗开口道：没什么不可能。如果这种隐瞒有黑夜女神和别真神帮忙呢？……一个长达两三千年阴谋……倒吊人阿尔杰眸光略有凝固本能缩缩身体对黑夜女神和大地母神有种源于灵魂恐惧。塔罗会成员们又一次沉默直到星星伦纳德重复起正义小姐最后那个问题：大地母神究竟是谁？说话间他看眼世界克莱恩·莫雷蒂试图从前同事那里得到答案。……那是愚者先生在轻敲桌面。正义奥黛丽等人精神一振同时转向青铜长桌最上首恭敬等待着愚者先生给予答案。愚者克莱恩轻笑一声道：我可以给你们一些提示。大地教会为什么喜欢将血族发展成信徒？大地和月亮是两条相邻途径。传闻第二纪时代表月亮古神莉莉丝是因巨人王背叛才陨落。祂偶尔会回应血族祈祷似乎并没有完全逝去。四个提示后包括月亮埃姆林在内所有塔罗会成员都想到一个答案：大地母神真实身份是血族始祖莉莉丝！星星伦纳德先是错愕接着若有所思低语道：前几天开始黑夜教会不再宣传绯红之主这个称号并且将画红月祈祷手势改名为点繁星……他是值夜者高级执事有资格阅读相应文件。黑夜女神用月亮领域权柄做一次交换？隐者嘉德丽雅说出徘徊于大家心中结论。感谢您提示。正义奥黛丽当即向愚者先生行一礼。其他人分别表示感谢后相继望向还呆在原位月亮埃姆林。……魔术师佛尔思饶有兴趣笑道：月亮先生再等一段时间也许你就要担任大地教会大主教了不应该是大地教会驻血族全权代表。……为什么？月亮埃姆林有点不解反问道。星星伦纳德笑笑道：既然黑夜女神没有绯红之主称号那大地母神很快就将拥有类似尊名没法瞒过别教会。月亮埃姆林大概明白这位黑夜教会高层意思轻轻颔首联想到一幕幕场景：之前嘲笑他信仰大地母神同族们将排队走到他面前接受他洗礼。……几秒后倒吊人阿尔杰打破这种状态沉稳说道：我们之中绝大部分成员都已经是半神提升周期变得很长且有着自己势力对非凡特性魔药配方和封印物需求可能得几年才有一次聚会重心也许得转往情报交流和隐秘合作上。正义奥黛丽隐者嘉德丽雅和星星伦纳德等人纷纷点头赞同倒吊人先生话语。这时愚者克莱恩环顾一圈轻笑着说道：随着神弃之地相关事情结束我状态恢复不少你们可以从我这里换取更高层次事物了。他故作坦然说出自己正在复苏事实而这对塔罗会每一个成员来说是早就猜到答案。就在正义奥黛丽等人于心中猜测愚者先生目前已复苏到哪个层次时克莱恩含笑补充道：那些高层次事物包括：海神身份位格和实力。

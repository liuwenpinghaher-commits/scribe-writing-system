# 1298 倒吊人 第三十三章 奶和蜜

## 打开书
神弃之地月城。阿达尔辛和鲁斯等人听到大祭司响彻整个城邦声音一下变得异常激动。他们几乎同时站起将早就准备好兽皮包袱背到身后。——在闪电交替好几次前月城祭司们就得到愚者先生神启不再往外派出狩猎小队并叮嘱每一位居民收拾好重要物品随时准备离开。……各位我得到神谕。愚者先生即将帮助我们离开这片被诅咒大地重获新生。赞美愚者先生！这是他们自己发明地赞美愚者先生手势而愚者先生未做否定。赞美愚者先生！月城居民们齐齐将右掌按在左胸高声表达出自己感激和虔诚。……我们会先去白银城和那里存活者会合一起前往外面那个光明世界。不要担心愚者先生会庇佑我们。好了闭上双眼开始祷告。说完这位大祭司就交握双手抵于唇边虔诚向愚者先生祈祷希望那位伟大存在能满足月城在过去两三千年中一代又一代积累下来最大愿望。下一秒钟这位黑夜途径半神敏锐察觉到周围发生变化遂睁开眼睛打量四周发现一根根石柱正变得清晰一盏盏灯笼正悬挂于上一道道高大身影正飞快勾勒。这就是白银城？我们已经到白银城……这就是神灵威能……赞美愚者先生！阿达尔和辛等人紧跟着观察起周围。……这熟悉一幕让月城人渐渐放松下来将那些半巨人当成同类。六人议事团首席韦特·希尔蒙对月城首领据说叫尼姆大祭司点头道：你们准备好了吗？他目光平和自然没因月城大部分人都容貌恐怖有一点歧视。……准备好了。……三分钟内结束用餐开始祈祷。没到一分钟白银城居民们就喝完牛奶收起手中剩余食物虔诚向愚者先生做起祷告。——月城古代遗民们异常神奇降临于他们面前让他们对离开神弃之地多好几分信心真正信仰起那位愚者先生。……这是克莱恩刻意而为给这些神弃之地古代遗民们一个告别过去仪式。月城人震撼于巨人王庭恢弘感史诗感和神话感时白银城大部分居民下意识转头望向下方望向远处。……大部分白银城和月城居民或低下脑袋或跪在地上大声赞美起愚者先生激动亲吻起那仿佛带着芳香泥土。其余人等并不是不感激愚者先生而是还沉浸于这样场景变化中身心都遭受震撼。……我们我们有新家了……话音未落这近两米五半巨人慌忙将手探入衣兜又伸出来递向自己妻子和女儿。这是神使大人分给我们奶糖他们他们都说很好吃……利亚瓦尔脸上堆起笑容。……奶糖……利亚瓦尔妻子不是太理解这个词它是巨人语里奶和蜜构建新单词。……不不不要剥掉外面那层。利亚瓦尔忙将两颗奶糖拿回剥掉包装纸一手一颗递到妻子和女儿嘴边。……神使大人说我们可以去拜亚姆城里找工作接委托赚金镑那样就能买到更多奶糖也可以把不要非凡特性和怪物皮革卖给海神教会……海神是愚者先生从神……等下就要天黑了我带你们去海边看落日那真很美我每天都会去看总想着等你们来了也带你们去……总算解决锚稳固不少……而且实现白银城和月城人愿望让我奇迹师魔药又消化不少但没有重现康斯顿城多果然愿望之神不是最正确扮演……灰雾之上克莱恩缓慢吐口气将……而扮演奇迹师下一个阶段克莱恩打算积攒修改容貌和身材方面愿望直至能解决月城畸形者们问题再创奇迹。……那样我就能自称美容行业主宰设计师和建筑工人保护神长途旅行奇迹创造者……进入没有安全航道海域后神秘女王贝尔纳黛似乎丧失对时间感知若非她船长室内还挂着一架精准壁钟她肯定会遗忘自己已进入这片危险地带究竟有多少天。……贝尔纳黛冷静看着耐心等待着并没有过多干涉黎明号状况。……就在这时远处出现一些黑色轮廓。

## 这场戏有没有翻
翻了。开头月城迁白银城；王庭告别；落地奶糖落日；章末黎明号见黑轮廓。翻的是奶和蜜＝新家甜＋远航钩。

## 地与走
月城→白银城→巨人王庭礼→新港→切黎明号。

## 这一章新讲明的规矩
- 愚者可整城传送；王庭作告别仪式。
- 奶糖＝奶＋蜜巨人语新词。
- 海神＝愚者从神（对外口径）。
- 愿望之神非最正扮演；下阶攒改容愿。

## 热怎么变冷
赞美还热。冷切在白银城石柱。王庭还热。冷切在芳香泥土。奶糖还热。冷切在黑色轮廓。

## 怎么起、怎么收

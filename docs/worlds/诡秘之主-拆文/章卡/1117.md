# 1117 红祭司 第一百七十二章 克莱恩的畏惧

## 打开书
救赎蔷薇简直诸神联盟，远古太阳神威压下仍须黄昏殿密谋——祂究竟多强。塔罗会比之如小孩游戏；加威尔帕列斯阿兹克蕾妮特仍逊全盛；缩水版都差，召集者只序列4。对照十一影：风／智／纯白＝风暴之主、知识与智慧之神、永恒烈阳，背叛并分食远古太阳神／白银城造物主；战神大地母神＝王庭幸存者，长子与王后母子，费内波特未助弗萨克打鲁恩可玩味；女神＝毁灭魔狼从神厄运女神阿曼妮西斯，掌黑夜登序列0，灭弗雷格拉后裔，封安提哥努斯天使于夜之国，用天之母亲身躯做容器——真狠。眷者本能环顾怕泄密。迷雾小镇后已猜真身：魔狼掌黑夜权柄；安提哥努斯占卜家途径＋天之母亲属黑夜→弗雷格拉或混两条不相邻途径故疯。格罗塞尔游记：魔狼两从神一失踪一投不死鸟，真名对第四纪死神／阿兹克父——厄运与黑夜联系。畏惧未敢多想。今见真名更多释然靴落地，对女神愈畏：控占卜家途径防弗雷格拉复活？下午镇虚影诱惑萨斯利尔名被抹＝隐秘；王庭外难把黑夜与阿曼妮西斯并提；救赎蔷薇双召集＝暗天使萨斯利尔＋女神；密谋处外弥漫隐秘——女神一手导远古太阳神陨落开大灾变结第三纪？亚当阿蒙差远；会否那么易被亚当困？「这也是祂的想法」祂指谁？古代学者魔药或当场消化……揉额强迫转念：第四天使之王虚影自毁因余三位成神？巴德海尔赫拉伯根常念无异常差在哪？萨斯利尔失踪或＝真实造物主／宇宙暗面／欲望母树？阶外堕落残存或祂留？壁画对真实造物主何反应？望洛薇雅：迷茫，认乌洛琉斯——她在其壁画神庙成信徒。戴里克偷瞄无大变；他最知外界，震于层次：难怪主陨落。首席侧脸苍白：这不可能……戴里克疑他想到主不再回来，可早从自己处知——表情复常嘴紧抿。余人忆下午镇预言：忏悔…诱惑萨斯利尔…王们黄昏殿密谋…太晚…灾难从此始。海因姆：这里黄昏宫殿？密谋致主遗弃大地？科林：很可能。安提尔娜：弄清经过能否取悦主再注视？首席眼含怜悯悲伤：也许。众人灼热求续探——两千年苦难最近希望。科林：勿忘守则勿冲动；与救赎有关可二三次来，不必急。是，首席阁下。分组搜厅：壁画外无便携实用物；侧壁画组成立体场景。至后方灰蓝非对开大门。科林隔十米余观察：「门外有强大的守卫。」

## 这场戏有没有翻
翻了。开头还在雾上炫强对比塔罗；章末队把壁画收成「主为何遗弃」的希望燃料，门外商外又有强守卫。翻的是白银城还能否把神国当单纯寻宝，克莱恩侧则靴落地成对女神的更深畏。

取悦主换再注视＝两千年苦的近希望。科林用「还能来」压牺牲冲动。怜悯悲伤对安提尔娜的「也许」。

## 话
「这不可能，不可能……」「这里就是黄昏的宫殿……让主遗弃了这片大地？」「很可能。」「也许。」「门外有强大的守卫。」局面是希望灼热被守则按住；章收在又一道门卫。

## 热怎么变冷

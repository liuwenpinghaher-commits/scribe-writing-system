# 544 旅行家 第六十三章 狂怒的卡维图瓦

## 打开书
达尼兹被噎得说不出话怏怏退到一旁看着格尔曼点燃蜡烛焚烧粉末滴坠纯露。闻了下弥漫出来味道忍不住拔高声音：「用用错材料了吧？」他记得反抗军祭祀海神时用的不是满月精油深眠花洋甘菊这些东西又不是在向黑夜女神祈求！侧头看他一眼重新将视线投回祭坛：「没问题。」作为时常献祭和被献祭专业人士很清楚燃烧纯露精油草药粉末作用主要两个：一是帮助仪式主持者更好调整灵性进入状态二是取悦相应神灵讨好献祭对象提高回应概率这方面每一位神灵都有所属偏爱事物。而这次献祭主要依赖于卡维图瓦精神不正常已彻底疯狂和它渴求灰雾气息两点二者缺一不可其他并不重要。只要满足以上两个条件取不取悦都不会影响仪式举行既不会提高成功率也不会增加失败可能完全可以敷衍处理。如果卡维图瓦还有理智就算严格遵循仪式要求你认为它会回应我吗？腹诽一句往后退出半步准备开始最关键环节。想了想没有侧头直接说：「离远一点。」我？不怒反喜连忙点头：「好好的！」蹭蹭蹭就跑到仓库门口打算一有不对立刻逃跑。半闭眼睛冥想起重叠光球迅速进入状态。用精灵语低沉诵念：「大海与灵界眷者罗思德群岛保护者海底生物支配者海啸与暴风掌控者伟大卡维图瓦。您忠实仆人祈求您注视；祈求您收下他奉献；祈求您打开国度大门。」随着艰涩拗口单词一个又一个吐出灵性之墙内风声渐起逐渐剧烈似乎要掀翻一切。衣角飞扬拿出早就准备好另一个金属小瓶将里面剩余千面狩猎者血液往空中倾倒大概5毫升。这是极富灵性材料！狂风吸走滴滴血液呼啸钻入象征海神卡维图瓦那朵烛火。无声无息间烛火膨胀扩大成一扇虚幻之门表面全是象征符号和魔法标识内里隐约传出海水哗啦声音。忽然一切动静消失只有一道喘息隔着虚幻大门回响就像背后藏有艰难压抑饥饿庞然大物。呼呼呼……巨大喘息声越来越明显越来越清晰听得仓库门口达尼兹都有些头皮发麻。砰！虚幻大门突地敞开近乎可以看到形状飓风奔涌而出。尖锐呜啦声里达尼兹感觉到无形灵性之墙破碎发现自己直接被抛飞起来就像暴风雨中小船狠狠撞在门上撞出砰一声闷响。摔到仓库外面背后多有木刺划出伤口。手里本能凝聚赤红火球则在暴风里瞬间黯淡迅速熄灭就像一根燃烧近尾声蜡烛。而他飞在半空时候有看见敞开虚幻之门后出现一张仿佛染血大盆狰狞巨口露出比人类手臂还长略显弯曲乳白尖牙疯狂撞击虚幻大门想直接进入现实世界野兽般嚎叫之声则先一步回荡于仓库内部震得达尼兹耳畔鼻端同时流血。也在刚才飓风里飞起来视线旋即被一条血腥分叉迸发出嗞嗞闪电巨大芯子占据。身体一下焦黑僵硬在空中被蛇芯贯穿化成纸张燃烧后灰烬。身影浮现于另外一侧帽子掉落衣物凌乱相当狼狈。幸运是他知道会出状况知道会有危险一直高度戒备没有放松警惕及时用出纸人替身。这时没有丝毫晃动虚幻大门后卡维图瓦终于发现疯狂撞击无效停下来。猛地吸口气让蔚蓝海水从四面八方涌来于喉咙深处坍塌成散发恐怖吸力漩涡可以吞食一条货轮漩涡！祭台上铁制卷烟盒飞起来投进那个漩涡。盛放草药灰烬小釜飞起来投进那个漩涡。仓库内许多杂物连同泥土飞起来投进那个漩涡。也飞起来难以抗拒投向那个漩涡！试图打出响指点燃火焰跳跃至漩涡影响范围外可却被吸力伴随飓风破坏计划。身影霍然变薄成为一个纸人。随着纸人投入漩涡浮现于另一个位置克莱恩再次腾空无法摆脱恐怖吸力！关键时刻不再犹豫让左掌戴着黑色手套变得苍白染上些许阴绿。启用蠕动的饥饿直接驱使起钢铁麦维提灵魂！身体一下变得沉重然后往前推出左掌。一面不算太厚冰墙凝固于前方帮他短暂隔绝海神漩涡。借此机会落下来双脚重重一踩陷入地面。喀嚓！冰墙只维持一秒钟就被磅礴吸力撕成碎片飞入巨大海蛇喉咙里。依靠活尸力量双脚用劲固定住身体没再飞起但依然不可遏制往着虚幻之门滑行往着卡维图瓦血盆巨口滑行在地上拖出两道深深沟壑。仓库外达尼兹没怎么受到漩涡吸力影响想要凝聚火球砸向侧方让格尔曼跳跃出来却一次又一次被肆掠飓风吹灭。离虚幻之门越来越近鼻端钻入血腥与腐烂混杂恶臭眼前是沾着污迹散发寒气乳白尖牙。念头急转迅速有了办法。那个办法很简单就是把源自秘偶大师罗萨戈全黑之眼扔出去！既然你卡维图瓦制造海水漩涡想要吞噬一切那我就让你再服食一瓶没有辅助材料魔药并附赠真实造物主精神污染！这样一来就不信本来就快要崩溃的你能支撑得住！咬紧牙齿将手伸入衣兜。或许本能察觉到险恶意图也或许疯狂卡维图瓦缺乏耐心此时此刻猛地仰头长嘶让喉咙处海水漩涡崩坏瓦解化成无数水滴喷向虚幻之门外面。哗啦啦！仓库内下起暴雨卡维图瓦喉咙处则又凝聚出一团银白耀眼无数电光纠缠雷球。轰一声吐出那个雷球。暴雨之中银白雷球化成一道道醒目闪电飞快扩张往外破坏简陋祭坛占据整个仓库。嗞嗞嗞雷电海洋里克莱恩身影不断浮现又不断焦黑变成纸屑仓库外达尼兹同样受到影响头发全部竖起来身体抽搐般抖动着。连续用掉好几个纸人替身快要接近极限终于等到电光平息。而那扇虚幻大门受到仪式被彻底破坏影响飞快不可阻止合拢。哐当！海神卡维图瓦不甘嘶叫被隔离在门外。瞬息之后虚幻大门完全消失四周一片狼藉祭坛之上也只剩下一根蜡烛虚弱摇曳着火光。砰！达尼兹前倾到仓库墙上勉强站立于门口。想要说话却止不住抽搐唯有用眼神表达憋屈：格尔曼真的是个疯子！班西港时候那体验到惊悚感我现在还能回想起来还会因此做噩梦……之前挑选反抗军出品事物时又惹来海神诅咒一路之上吓得差点逃跑……这次又弄什么献祭险些把卡维图瓦召唤过来刚才真是危险到极点……他怎么就这么热爱冒险热爱弄出大事呢？一次又一次在死亡边缘寻找刺激！这是他疯狂表现还是原因？卡维图瓦这海神还是很强啊哪怕已经濒临死亡哪怕隔着献祭之门只能透出一部分力量也差点轻松解决掉我……不愧是可以抗衡海王半神……从地面拔出双脚看见皮靴已然破烂。与此同时发现不管幸运还是必然从任何意义上讲卡维图瓦都算接受了他献祭因为这巨大海蛇制造漩涡时吞掉了那沾染着灰雾气息铁制卷烟盒和其他很多东西。也就是说可以试着在灵界定位它藏身地点了不过得等它死亡不会再干扰和对抗我占卜……这种寻找必须进入灵界无法一直利用灰雾……刚悄然吐口气就感觉到左掌手套一下弥漫出难以言喻疯狂和饥饿似乎再等不到食物就要吞噬佩戴者。附近没有罪恶深重家伙啊……侧头望向门口达尼兹。达尼兹精神突然一紧只觉自己被某个怪物盯上即将成为对方食物。那灵性层面饥饿感压迫得他微微颤抖恨不得立刻转身逃跑。然后听见格尔曼淡漠声音：「从外面把门关上。」「……好！」强忍着电击残留疼痛将撞飞出去门板搬回来勉强堵住空洞。则抓紧时间举行献祭仪式自己向自己祈求自己回应自己将快要失控蠕动的饥饿丢到灰雾之上。这吓得达尼兹不敢反抗神奇物品立刻变得安分温和而驯服。

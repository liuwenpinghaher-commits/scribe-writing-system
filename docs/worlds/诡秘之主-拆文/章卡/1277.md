# 1277 倒吊人 第十二章 提醒

## 打开书
海神身份位格和实力……听到愚者先生举例子倒吊人阿尔杰脑海空白近乎两秒。这是他做梦都没有奢想过事情！在他看来愚者先生通过格尔曼·斯帕罗拿到海神权柄取代卡维图瓦获得稳固且数量不少信徒是祂复苏过程中相当关键一步因此这位隐秘存在肯定不会放弃相应身份。谁知道这一刻他竟然听见愚者先生告知大家海神身份位格和实力都可以换取。更进一步复苏后愚者先生已不再需要海神这种层次身份和对应信徒？这才是一位伟大存在表现啊不够位格事物都只是短暂借用不会占据……倒吊人阿尔杰先是暗自感慨旋即一阵激动只觉愚者先生刚才话语就是对自己说……阿尔杰目前是风暴教会负责罗思德教区枢机主教一旦他暗中成为海神掌控那片海域权柄那他就将是罗思德群岛王真正王！想到这点倒吊人阿尔杰险些就无法自控好不容易才平复下自己状态。正义奥黛丽太阳戴里克等人虽然也因塔罗会开始交易一位神灵身份位格和实力而难掩震惊——哪怕那只是一个伪神但毕竟都没有转到风暴途径想法相对阿尔杰来说不至于那么激动很快就控制住自己纷纷将目光投向倒吊……尊敬愚者先生需要付出什么样代价才能换取这些事物？愚者克莱恩就等着倒吊人提问含笑说道：我给予一些任务以及时常祈祷虔诚许愿。……至于怎么完成相应愿望他目前有两种方式一是用自身拥有其他非凡能力达成相应效果比如召唤历史场景重现给予啤酒环节完成让酒吧老板请客愿望二是依靠已有一定积累愿望能力直接回应较低层次愿望创造真正……另外在灰雾之上克莱恩可以调动源堡位格和力量相当于一位没容纳唯一性天使之王换句话说就是他在回应祈求时能使用本途径序列1核心能力也就是诡秘侍者核心能力。……一是创造神国雏形二是嫁接。嫁接是克莱恩自己命名毕竟他还不是真正诡秘侍者没获得对应神秘学知识。这个能力可以将正常情况下无法产生直接联系事物嫁接在一起达成不可思议效果。一个简单例子是将一条路终点和起点概念糅合于一让走上那条路人永远都无法离开。对非凡者来说有不少能力可以办到类似事情但诡秘侍者嫁接是直接作用于概念本身不仅层次极高就像真正神灵降临而且效果诡异带有隐秘意味。再加上0级封印物星之杖模拟能力克莱恩身在源堡时完全可以像一位天使之王般回应祈求而且能做到事情更多。听愚者先生提及任务倒吊人阿尔杰一下想起某件事情忙低头问道：尊敬愚者先生对于弗萨克帝国参加过科诺托海战三个目标还需要做更进一步调查吗？他之前初步搜集那三位疑似蠕动饥饿前主人情报但并没有发现什么异常。愚者克莱恩轻轻颔首道：不用了。他本来是想借这条线抓住黄昏隐士会尾巴但既然亚当大概率已经成神那还是避忌一下比较好。不等倒吊人阿尔杰再次开口愚者克莱恩语气舒缓继续说道：你现在任务是配合海神信徒安置好离开神弃之地人们。您意愿就是我意志！倒吊人阿尔杰毫不犹豫回应道。这让太阳戴里克无声松口气对接下来发展不再有疑惑顾虑和担忧。他对倒吊人先生处理事情能力有着充分信任。这时愚者克莱恩环顾一圈笑笑道：除海神身份位格和实力能换取还有很多比如律令法师魔药配方和非凡特性。他没过多举例免得有损愚者位格至于之前说那么多可以理解成更进一步复苏愚者先生心情很好。——月城有律令法师传承克莱恩能以完成获得拯救这个愿望去换取当然即使他直接让月城居民献祭相应事物那些终于找到庇佑人们肯定也非常乐意。他们就害怕愚者先生抛弃月城不接受他们献祭。除此之外克莱恩本人还有一个银骑士秘偶占卜家途径序列9到3非凡特性封印物无瞳将军一滴原始月亮祝福过血液和各种各样灵之虫相关符咒与命运。……律令法师魔药配方和非凡特性……审判休莫名觉得愚者先生看自己一眼。……当然如果有晋升半神机会她也不会放过因为之前那场战争里她体会到一个序列5无力而且塔罗会中除她和魔术师佛尔思别人都已经是半神她毫无疑问不是太想掉队。想法纷呈间审判休看看魔术师佛尔思然后对着斑驳长桌最上首埋低脑袋表示自己会努力。魔术师佛尔思大概能猜到好友心态因为她也差不多。如果不是提升到序列4才能有效对抗满月呓语不用再时常麻烦愚者先生而且亚伯拉罕家族已经给她准备好魔药配方和非凡材料她都不是那么迫切想成为秘法师。作为一名旅行家想去哪里就能去哪里想吃什么美食可以立刻到现场去吃完全满足佛尔思对超凡概念最初期待。见笼罩着灰白雾气愚者先生后靠住椅背不再说话正义奥黛丽犹豫下张张嘴道：女士们先生们我有一个问题。如果一件事情你知道结果怎么样完全与你无关只是看某些存在心情和博弈你会怎么做？她话音刚落倒吊人阿尔杰就笑一声道：每个人都注定要死亡无论怎么努力都难以更改那他一生是不是就毫无意义？既然目前你无法改变事情结果那就努力提升自己获得更强大力量掌控更多权柄直到有一天能够参与那些博弈如果死在这个过程中总好过什么都没有做。这是倒吊人先生说过最诚恳一些话似乎发自他内心……渺小也能变得伟大……正义奥黛丽受到触动微不可见点头。这个时候世界格尔曼·斯帕罗环顾一圈道：各位我有必要提醒你们一件事情。等塔罗会成员们同时望过来克莱恩操纵假人世界低沉开口道：末日还有十几年就将来临每个人都可能毁灭包括神灵。

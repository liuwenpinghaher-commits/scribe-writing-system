# 1285 倒吊人 第二十章 老法新用

## 打开书
真正机会……帕莎拜尔斯和菲尔听得心中一喜仿佛在黑暗夜晚摸索前行很久后终于看见曙光。什么样机会？从麻痹状态缓过来罗伊脱口问道。克莱恩一点也不着急微笑说道：你们难道没有察觉吗？那些公告里面并没有明确执法主体是谁。作为曾经键盘强者克莱恩一向自诩为什么都懂一点而且他这辈子也和不少律师打过交道并拥有过一个堕落伯爵秘偶在律令规则方面还是具备基本素养。……克莱恩见状伸手抚摸起魔镜表面就像在给一只动物顺毛：正常情况下大家都默认由警察局和处理超凡案件官方组织来执法这是通过一系列法律条文或相应民众认知来确定但这一次规则还没达到这么严密程度。如果说新规则空白是由原本法条律令规定来组成那么我们做出违法犯罪行为时肯定会看见警察值夜者或者代罚者可实际并不是这样。也就是说相应执法主体确实是模糊。……或许执法主体是一个抽象意义上概念也或许它默认等于那位新任执政官。后者同样不明确没说明谁是新任执政官这样一来任何人都可以是前者则属于未尽告知义务……克莱恩简单回应两句。……可是我们和市民们同样不能执法。这是通过一种贴标签式排除式划分来确定相应权限。克莱恩笑着解释道外乡人是被排挤追捕对象当然没有执法权市民们则只有在对付外乡人时才拥有这点是通过公告确定。……所以我刚才通过这里面隐含矛盾让罗伊试了试结果正如我预测那样。首先魔镜不属于外乡生灵也不是本地人它只是一件有某种程度智慧物品不在规则划分出来任何一个群体内这样一来在执法主体不明确情况下未被排除它理论上是拥有执法权；其次它惩罚是外乡人那些公告隐含着一个对付外乡人都是执法者定义；最后魔镜本身是具备惩罚规则在这种规则未被宣布非法前它是拥有处罚权。基于以上三点我想0-02现在应该陷入多重矛盾里接下来它肯定会颁布新条文来明确执法主体修补这方面漏洞而一旦明确执法主体就会透露很多信息这能有助于我们锁定目标。呵呵0-02如果采用禁止办法那肯定会限制到和魔镜同样属性自己这绝对不是它第一选择。……难道这位魔法师先生就是神话传说里喜欢行于民间智者？四位非凡者各自做出相近但不相同猜测。就在这个时候克莱恩手中魔镜散发出濛濛水光。……所有执法行为必须且只能由特伦索斯特黄铜书或者它授权人群做出。任何私下规定都不能凌驾于正式律令上。特伦索斯特黄铜书……这就是0-02全称？机会来了！克莱恩神情一正当即进入冥想状态。他逼迫0-02明确执法主体就是为获得更多信息以便更进一步了解这件恐怖封印物情况。而据克莱恩推断0-02或多或少与某份源质存在关联就像当初还未真正成为源堡主人自己。……在他看来0-02被源质污染程度肯定超过自己毕竟封印物都呈现某种失控状态所以才需要封印。这种情况下对0-02只要再多一点了解污染就会随之而来。也正是因为有这样危险他没有将魔镜阿罗德斯呈现新内容展示给那四位非凡者看。……他弹出一枚金币同时利用源堡气息切断联系隔绝污染。……他利用短暂感应到联系做出占卜然后依靠源质间吸引让传送变得异常精准！——源质间聚合定律可以让克莱恩在某次闲逛里不小心进入这座图书馆发现这本黄铜书但这或许是在两天后两周后甚至两年后根本来不及阻止什么而且前提是0-02本身没做相应干扰和规避。……他没真正拖出苦修士首领阿里安娜身影因为对不认同人来说历史投影是一种诈骗他只是利用这种方式将自己位置信息传递给那位隐秘之仆。……当理智降低到原本20%就会出现失控征兆……古代学者拥有召唤历史孔隙影像能力召唤成功率取决于和目标熟悉与友善程度……特伦索斯特黄铜书是最珍贵事物任何生灵不得允许都不能触碰违者死刑！不能以任何方式改变特伦索斯特黄铜书状态违者死刑！……这导致他体内原初精神烙印活跃一些。前面部分规则呈灰黑色似乎处在不可更改状态……这需要0-02更进一步苏醒？它如果苏醒到能改前面部分规则程度那就很可怕了说不定可以让我召唤成功率下降让非凡者理智只要稍有变低就会出现失控征兆……后面文字呈水银色……这表明这部分规则可以修改或增加？不能触碰不能改变状态也就是说既不能拿走也不能直接将这件封印物隐秘……也许可以用星之杖或旧日之盒将这个图书馆直接转移去星空让0-02去面对那些外神们……但要是被外神们掌握这件封印物那问题……下一秒钟他耳畔响起啪声音。……第一个问题已经解决现在需要考虑第二个问题了那就是怎么封印这家伙。克莱恩抓紧时间开口说道。……相应资料已被摧毁我们只能通过试错来解决。……他隔着0-02制造无形屏障对正等待幕布消失战神教会大牧首拉里昂道：或许我们可以做一笔交易。你想要封印0-02办法？拉里昂转过身来呵呵笑道你认为我会答应吗？其实我很费解你为什么一定要为陨落战神牺牲自己？投入黑夜教会你一样可以做天使一样能得到庇佑一样可以活很久很久。克莱恩没直接回应转而说道。……你这种没有虔诚信仰神话生物是没法理解我。作为一名邪神我没有虔诚信仰不是很正常吗？克莱恩忍不住在心里咕哝一句。这就是他人性。

# 1172 逐光者 第二十三章 建议

## 打开书
好问题……愚者暗赞一声将红天使恶灵解释用自己话语表述出来：七神都希望有一位黑皇帝但由谁来做这位黑皇帝祂们意见并不统一。当乔治三世通过隐秘准备成功拿到那张门票后七神无论是否认同祂都只能默认。这样啊……除不在状况中月亮与太阳其余成员都有所恍然大致明白几大教会在贝克兰德大雾霾惨案弗萨克飞空艇袭击和乔治三世遇刺身亡等事件里颇有些矛盾表现。紧接他们突然都冒出一个疑问：既然乔治三世已做好准备到了最后举行仪式一步且获七神默许那祂为什么还会失败？旋即想到一个答案：因为愚者先生不同意。嗯……在乔治三世黑皇帝仪式被破坏这事上教会应该是没太认真阻止说不定还为愚者手下们提供一定帮助……风暴教会有没有利用这次混乱暗中做些事情？不他们应该不会做太多掩饰……星星回忆之前察觉种种细节对这次事情有了整体性把握。七神默许……愚者投了反对票派出世界等眷者暗中破坏乔治三世成神仪式……可这和女王有什么关系？她为什么会发现格尔曼失踪了？嗯黑皇帝……女王也许参与了愚者主导这次行动事后发现合作者不见了……隐者利用自己丰富见闻和知识对事情真相做出猜测。而直到这个时候月亮才将刚刚讨论点点滴滴串连起来明白自己被关押性保护这段时间外面局势究竟发生什么变化：乔治三世密谋成神得到七神默许结果被愚者派眷者破坏仪式当场陨落！见大家一时都有些静默愚者望向隐者：还有问题吗？这次没有了。嘉德丽雅脑袋埋得更低比以往更加敬畏最上首那位伟大存在。她虽然早知愚者座下有命运之蛇死亡执政官和古代邪物三大天使且暗中掌控生命学派但依旧没想到愚者在现实世界可动用力量能破坏一位国王成神仪式而且还挫败一位天使之王造物主之子图谋。愚者藏于暗中势力比我想象更为夸张……我们这些塔罗会成员对祂究竟有什么作用？背后势力？自身成长性？或者只是备选方案？隐者在这个瞬间想到很多短暂竟有点忘记自己已经是序列4半神无论在哪个组织都算得上高层。仅仅只是愚者展示出来那些东西就让一位圣者缺乏自信……正义只是看一眼隐者女士就解读出她心理状态。这时愚者点头：你们开始吧。听到这句话星星立刻转向斑驳长桌最下方对世界：你现在情况怎么样了？魔术师审判正义等也将目光投过去对世界处境表达关切之意。在他们看来夹在愚者与时天使阿蒙间作为他们争斗道具的世界处境可能不是太好还能活着已经算足够幸运。感受到这些或多或少关心他操纵假人世界低哑一笑：不是太差但也不算太好。有赖于愚者先生眷顾我终于从阿蒙那里拿到了某个秘密但我还没有彻底摆脱祂。不等在座诸位给出反应自顾自又说：我现在处在了一个比较麻烦困境里。我依靠愚者先生力量进入某种隐秘状态暂时摆脱了阿蒙不过如果我解除这种状态回归现实只能出现于原本身体所在地方而阿蒙很可能还徘徊于附近。我想先试着找一找办法不知道你们有什么意见？世界表面意思很明白想先靠自己实在不行再向愚者祈求帮助。而他实际含义与此本质上一致：先找有没有绕过限制办法实在不行就考虑以死灵状态存活。办法？倒吊人等人突地有点兴奋因为他们提供意见将用于对抗一位天使之王。如果被采取而且发挥了作用那简直可在心中吹嘘一辈子事情！正义兴致勃勃正要开口可话到嘴边又缩回去因为她知道建议不能乱给说不定会害得世界被阿蒙抓住。审判认真想了想发现自己提不出什么有用意见只好选择旁观与学习。必须是原本身体所在地方吗？你有没有血液头发保管在别地方？倒吊人思索一阵用提问方式给出一个建议。愚者想了想让假人世界摇头：不行。和原本身体相比一两管血液占比太少了。想到这里忽然有了个灵感：也许可用那两管血液为材料结合其他采取生命炼成方式弄一具新身体出来！两个问题一是生命炼成得有灵体参与否则最后产物未必算我身体二是我现在也不认识能完成生命炼成半神唯一沾点边是弗兰克·李……最后我变成一个蘑菇人？那我还是做死灵比较好……想着想着险些打寒颤。在倒吊人提议被否定后隐者从自己神秘学知识出发斟酌问：你有序列3封印物吗？为什么这么问？世界反问。序列3封印物能在一定范围内回应祈祷你可利用这点。隐者简单解释。大致有点明白隐者想法：你是说降临？对找人于范围边缘布置降临仪式而你在主动隐秘状态中应该也可以回应。隐者先看太阳一眼描述下具体方案接着才有所明悟问：你真的有序列3封印物？她原本还想让世界向愚者寻求赐予。我已经有序列3。操纵假人世界简短给出回答。……塔罗会成员一下都说不出话了。他们都很清楚世界应是在六月底才晋升序列4成为半神。而现在是同年12月！女王曾经说我用了命运之蛇血液晋升将来成为序列3预言大师要比其他人容易……而且塔罗会给我带来很多珍贵神秘学知识让我很大幅度消化掉了魔药……可就算这样我也还得大半年才有希望冲击序列3……隐者下意识看看周围发现其他成员都呈现一种半麻木半艳羡状态。无声叹口气：我的建议有用吗世界先生？世界摇头：那种状态下做出回应有很大限制。一旦选择降临就意味他要以死灵状态开始之后人生不鬼生。或许可把两种办法结合一下……嗯可用祈求愚者海神或魔术保护者降临办法脱离神弃但这个不急太容易暴露真相……愚者若有所思让假人世界望向星星伦纳德。伦纳德瞬间明悟他意思嗯一声：我回去翻一下资料看有没有别的思路。很明显真实意思是回去问问老头那位是对阿蒙有相当程度了解天使也许能提出其他人想不到建议。这正是他想要答案旋即让世界：好。脱困办法讨论暂时告一段落世界望向魔术师：帮我问问亚伯拉罕家族还有没有灵性未完全流失星之虫如果有需要用什么交换。星之虫是一种高级灵性材料绝大部分时候不蕴含非凡特性所以它们灵性会出现不可逆转流失没有特殊办法难以保存太久。星之虫……魔术师怔一下才点头：好的。得到答复后又让世界目光投向隐者：如果魔术师小姐没能从亚伯拉罕家族交易到星之虫我想委托你一个任务。什么任务？嘉德丽雅颇感兴趣问。世界笑了笑：猎杀极光会秘之圣者布提斯。

## 这场戏有没有翻
翻了。开头七神默许还在消化；章末建议讨论收成星之虫与猎杀布提斯。翻的是脱困问计变成材料军备，不是序列3震惊厉不厉。

## 地与走
愚者答话→世界席问答→各席建议链→委托两线。

## 这一章新讲明的规矩
- 七神望有黑皇帝但人选不一；拿到门票后只能默认。
- 失败归因愚者不同意（成员共识）。
- 隐秘态回归只能现身原身体处；阿蒙或守附近。
- 血液占比不足；生命炼成需灵体且缺可靠半神。
- 序列3封印物可范围应祈→降临策；隐秘态应祈限制大。
- 星之虫灵性易不可逆流失难久存。

## 热怎么变冷
七神答还热。冷切在因为愚者不同意。开始吧关切还热。冷切在隐秘态只能回原处。序列3还热。冷切在降临＝鬼生。星之虫还热。冷切在猎杀布提斯。

## 怎么起、怎么收
第一段好问题……转述七神。最后一段猎杀秘之圣者布提斯。章题建议——问计变派活。

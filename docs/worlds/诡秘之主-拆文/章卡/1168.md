# 1168 逐光者 第十九章 克莱恩的打算

## 打开书
闪烁深红光芒让心里多些暖意有种自己不是那么孤独还是有人记挂着感觉。在那虚幻重叠祈祷声越来越清晰真实也越来越嘈杂混乱时就已发现源堡在召唤自己两者间共鸣正不断增强。等到所有塔罗会成员都完成祈祷更是隐约觉得随时能进入源堡意识即将在那里显化但又始终差一层阻碍无法突破。这问题在彻底消化完古代学者魔药后终于被解决。也正因为如此才能抓住机会抢在阿蒙突破荣誉之神布拉德尔阻拦前回归源堡。短短两天内塔罗会成员竟然全部做了一次祈祷正常来说应没那么巧……有的没问题有的应是被女神威尔祂们施加了影响……我好运足够自然就会有好的发展……仔细一想就察觉不够合理地方但这都可解释也无需太过在意。稍微改变坐姿目光逐渐变得幽深。虽然在看见光门和蚕茧那次就觉得自己很可能回不了家但真正确定这一点发现这世界就是自己故乡后还是有种希望彻底破灭曙光被黑暗吞没感觉。当初用不属于这个时代的愚者做尊名或许就是灵性直觉给予启示……在内心最深处可能有那么一点点察觉……对了我记得是睡觉时穿越为什么悬吊在蚕茧内的我穿的是T恤和休闲裤？微皱眉将目光投向源堡之下那片灰白雾气。一边从历史迷雾里光之碎片寻找原因一边努力回忆当晚每一个细节。终于找到对应历史片段：穿T恤和休闲裤的周明瑞在晚饭前布置起转运仪式逆走四步诵念出福生玄黄仙尊等咒文。在他记忆里当时什么事都没发生可历史片段中场景不是这样！周明瑞走完四步完成仪式后整张脸刷地苍白眼神呆滞了不少。接下来动作略显卡顿地吃饭看书刷剧玩手机似乎在完成预定程序。最终来到洗漱台前看着镜中双眼无神自己木然刷牙洗脸上床睡觉。这过程中一直没更换外出时穿的T恤和休闲裤就那样盖着被子闭上眼睛。没过多久强烈光和剧烈晃动结束了对应历史片段。忍不住抬手揉额角自嘲一笑：原来转运仪式后什么变化都没有一切都很正常只是我自己的认知实际上我本身就已经发生了异变……换做以前肯定会为这事真相感觉惊悚后怕但这么久以来遭受惊吓已太多太多就在刚才世界观都差点崩溃这种小事没法再让他产生太过强烈涟漪。不过发现这点后结合大帝穿越是因为买到一块有神秘意味银牌以及光门之上某个透明蚕茧内被悬吊灵体竟然还带着手机对当初情况迅速有些猜测：应该是源堡主人影响现实传递出转运仪式神秘银牌异变手机等事物凡是得到它们做出相应操作的都将在某一刻被它拉到灰雾之上悬吊于那扇光门处……这是一种随机性挑选不指向特定对象我也不知道我这算走运还倒霉。不过为什么要以秦汉秘传方术纪要来命名？是被影响人类随便编的还是真从秦汉年间传下来？不是没这种可能如果那个群星归位预言是真且对应最初那位造物主那祂一直沉睡于地心在比古老更古老年代就是这样而源堡传说是祂身体某些部分衍化成的……这不是避难所或者维生舱……那位最初一边等待苏醒毁灭世界一边持之以恒小幅度影响现实做出传授仪式等布置会不会有点自相矛盾？那个预言肯定也是受祂影响人类做出的……伸右手轻敲斑驳长桌边缘陷入暂时无法解答难题。很快想起一句话和一些事情。那句话：凡分离的必聚合凡聚合的必分离。那些事：远古太阳神阿蒙和亚当父亲刻意将自身负面人格分离出来；靠近地底或遭遇某些污染非凡者体内会逐渐产生全新自己；去了月亮之上后罗塞尔性格不自觉发生一定程度偏移；二十二条非凡途径很多都彼此矛盾就像魔女和猎人。也许最初那位造物主本身就是一个矛盾集合体只能通过沉睡来缓解……有一定猜测但无从证实。就连上辈子那个预言里将在群星归位时苏醒的最初是不是当前时代神话传说里分裂成万物那位造物主都无法肯定。这需要更多线索更多证据确认不能全凭推测想象。我又不是空想家。自我吐槽一句将目光投向上方近乎灰色虚无部分地方飘荡灰白云气：需要确认事情还有很多很多比如那个所谓切尔诺贝利是不是最初苏醒前后人类改造出的避难所比如二十二条非凡途径特性是不是真全部源于那位最初比如群星位置现在究竟正常还是不正常1368年末日来临是否就是群星再次归于正确位置比如第一块亵渎石板来历比如月亮之上究竟有什么……想到这里敲动手指突然停顿一下低语：比如精灵故乡传说中西大陆是否还存在为什么没人能前往……回答是长久沉默缓慢向后靠住将双臂支撑到扶手上。好几分钟过去闭下眼睛有了一个想法或者说决定：等成功复活打算在神弃之地停留一段时间寻找部分疑问解答。就像罗塞尔大帝说过许多事情答案都在神弃之地渎神者阿蒙更是在这里游荡一千多年探寻超越第一纪历史。而且在神弃一直往东走说不定会抵达传说中西大陆……将目光投向古老宫殿外眺望看不见尽头远方。于他而言在神弃留一段时间也是一种策略至少这会引来阿蒙注意让祂不需要动员外界分身在鲁恩在贝克兰德搜寻格尔曼·斯帕罗那会给认识的人熟悉的人带来极大危险。还好之前那些认识到我心软的阿蒙分身已被清除相应情报也因隐秘存在没传递出去……如果不是这样阿蒙可能会直接拿班森梅丽莎伦纳德正义小姐他们生命来威胁我结果不堪想象……呵呵执掌好运黄黑之王总算有点体现了……呼就算我想离开神弃现在也没有办法那必须强闯暗天使沉睡地方……摇头一笑觉得接下来即使能复活也将危机重重。一个古代学者被一位天使之王追踪怎么想都坚持不了多久！最为重要黑夜女神目前还在消化死神途唯一性能渗透进神弃力量有限一旦执掌错误权柄时天使阿蒙有了正确防备再想做到今天事情几乎不可能。一方面得寻求其他可能存在援助等成功复活就尝试用秘偶诵念风暴之主永恒烈阳知识与智慧之神尊名看祂们有没有办法降临一定力量于神弃——祂们当初分食远古太阳神肯定不会希望阿蒙拿到源堡……另外一方面既然古代学者魔药已彻底消化那就得考虑成为奇迹师事情了只要有了天使位格变成完整神话生物处境相对就会好很多至少面对阿蒙本体时不至于连一波呓语都撑不过去……决定等灵体状态恢就利用媒介窥视霍纳奇斯山脉主峰夜之国内那团可怕蠕虫从中获得对应奇迹师知识。那大概率是安提哥努斯家族半个愚者！考虑好未来安排环顾一圈同时回应那一颗颗深红星辰：今天塔罗会照常进行。他想看隐者女士倒吊人先生他们能否提供灵感让他在远离阿蒙地方复活。当然一个巧妙借口是必须的已经想好。做完回应灰雾之上又变得极为安静坐愚者座椅暂时无处可去。一阵静默后微倾身体用右手撑住脑袋就那样平视前方。那张斑驳长桌上随之出现一份份色香味俱全美食和一根根精美蜡烛周围高背椅变得更加贴近当前时代。一道道人影相继具现：有的嗓音洪亮黑发已能看见些许银丝中老年男子有的东方面孔留及耳短发年龄已近半百女性有的边玩手机边享用美食青年有的嘻嘻哈哈说笑不停小姑娘……在他们之后又有新人影一道道勾勒分别是发际线较高灰眸幽邃邓恩涂着蓝色眼影腮红戴莉……他们噙着笑容在灰白雾气之上围着烛火闪耀温暖长桌欢快交流时不时品评一下美食。保持刚才表情和姿态手撑侧脸无声看着这一幕许久没有一点动作。

## 这场戏有没有翻
翻了。开头还暖在全员祈祷；章末决定留神弃求奇迹师却用手撑侧脸无声看家宴幻影。翻的是打算落成孤独凝视，不是转运仪式厉不厉。

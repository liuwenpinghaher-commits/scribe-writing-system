# 537 旅行家 第五十六章 驱散

## 打开书
什么情况？达尼兹简直不敢相信自己眼睛看见画面。这并没有让他感觉震撼反倒莫名惊悚就像喝醉以后跳进装满冰块水桶里从脚底到头顶都渗入刺骨凉意。究竟发生什么事情？怎么会变得这么诡异？吸口气强迫自己扭回脑袋追向格尔曼背影。发现这位疯狂冒险家越走越快以至于自己必须小步快跑才能跟上。穿透街道走过巷子忽然看见树上掉下来一道青绿色影子。啪它覆盖着鳞片扭动着滑腻身躯顶着三角形脑袋吐着细长猩红芯子竟是条不短毒蛇！狗屎！这个季节这种天气怎么会有蛇出没？并不怕这种生物甚至还烤过蛇肉吃让他受到刺激是这反常情况。绕过那条原地盘缠毒蛇下意识望向左右发现两侧排水沟里房屋破损墙角中表面生锈自来水管道内侧有一双双冰冷竖直不同颜色瞳孔望向外面。本能打个寒颤只觉头皮似乎被人用密密麻麻细针扎一遍。不敢再停留也不敢离去再次加快速度紧紧跟在格尔曼身后。进入蔚蓝之风旅馆沿着木制楼梯往上时忍不住抬头想要询问一句。突然胸口一闷呼吸为之滞涩一下。这一刻就像潜入海底正被沉重水流从四面八方挤压。哗啦！隐隐约约间听到潮水奔涌声音看见格尔曼四周荡起虚幻层叠波光仿佛生成一片无边无际深不见底蔚蓝海洋。那海洋之中有一道巨大青蓝身影如同高塔支起一切。这…右脚停在半空竟踩不下去。类似感觉并不陌生上次海盗大会时五海之王纳斯特比这更加威严更加恐怖几乎所有海盗都抬不起脑袋只将军级强者才能勉强对抗。很清楚这绝不是格尔曼本身表现。如果对方处在半神半人层次狩猎钢铁时根本不需要引入代罚者！海洋…潮水…脑海内先飞快闪过这两个名词旋即又联想到反抗军基本信仰海神事情。「难道难道格尔曼刚才触摸那把骨剑时由于未知因素遭受海神诅咒？那具完全缺失水分信徒尸体就是诅咒发动条件之一？刚才车夫跪拜匍匐亲吻地面是因为感受到海神气息？嘶…格尔曼今天恐怕会死在这里…我要不要逃远一点免得受到波及最多最多之后回来给他收尸…也许还有救我用降灵仪式请教下船长她懂那么多奇奇怪怪秘术应该能解决这问题…不主啊降灵仪式条件是500海里以内他们还得航行至少一天半才能进入这范围…」竭力思索办法中不再那么恐慌踏实脚步跟着进入那间豪华套房。克依旧没有说话深棕眼眸似乎染上浓郁到近乎黑色蔚蓝。直奔卧室喀嚓一声反锁住房门。达尼兹立在外面一会儿想跑一会儿觉得还能抢救下对方。卧室之内闭上眼睛等待着契机。忽然逆走四步每一步都伴随着一句诵念。耳畔迅速响起一阵阵或躁狂或尖锐呓语灵体虚幻往上直入灰雾。无声无息间听见一道凄厉痛苦难用语言形容嚎叫。出现在古老宫殿内出现在斑驳长桌最上首。下方安静不动灰雾里呈现出一条虚幻巨大青蓝色海蛇。它置身于一片古老晦暗遗迹内盘绕在半倒支柱上狰狞头部扬起血腥巨口张开露出一根根比人类小臂还要长弯曲尖牙。乳白色尖牙上血色层叠黏液流淌。这条海蛇疯狂甩动着尾巴掀起恐怖海浪荡起夸张涟漪让整座遗迹摇摇晃晃似要坍塌。这画面飞快破碎飞快黯淡无论那巨大到超乎想象海蛇如何挣扎也难扭转只能痛苦长嘶着化为一点点光芒泯灭于灰雾之中。坐在属于愚者高背椅上静静注视着这一切许久没有额外动作。灰雾悄无声息蔓延着这里场景似乎亘古未变。过几十秒后靠住椅背轻叹一声吐出对方名字：「海神卡维图瓦…」触碰到那把骨剑后已然感受到异常并在和光头卡拉特对话中敏锐发现一股细小微弱但本质极高阴冷邪异力量不知什么时候侵入自己体内正缓慢污染着自身灵魂。当机立断掉头就走然后察觉到那邪异力量在与周围产生关联逐渐强壮一点点连通某个未知所在。所以一边分心对抗那种侵蚀一边控制自己不与周围交互。相信只要自己对途中异常做出反应侵蚀就将更加剧烈甚至无法逆转。原本想就近找个盥洗室借助灰雾屏蔽与隔绝消融掉那邪异阴冷力量但考虑再三后还是决定远离那片区域再说因为周围海神信徒非常多极有可能造成意外。这过程里又把握到一点那就是如果自己提前驱除海神卡维图瓦投射来力量会有部分残余于血肉内后果与影响未知。不得不耐心等待起契机等待着那阴冷邪异力量彻底渗透入自己灵以便一举净化。回味下整件事情手指轻敲桌缘低声自语：「并不强啊…」海神位格比想象得要低不少！原本打算用招待阿蒙分身那一套来对付试图侵蚀自己灵魂抢占自己身体海神卡维图瓦投影结果还没融入黑皇帝牌未丢出纸天使对方就直接被灰雾给驱散一点痕迹都没留下。据此得出结论海神卡维图瓦位格要低于渎神者阿蒙——虽然后者可能更擅长侵入但当时只是一个分身。是被风暴之主捶到位格掉落还是本身就不到天使阶只是较强大可以在一定范围内回应信徒半神？疑惑回忆发现海神卡维图瓦状态很不正常：「这邪灵存在基础相当脆弱似乎随时会崩坏瓦解…而且它和它置身那片遗迹有与灵界交融感觉正因为如此当初躲过风暴教会围剿？」往后靠住椅背隐约间有猜测：「今天事情不是偶然都源于考古学家拉蒂西亚拿走被遗忘神庙内某件重要物品导致苟延残喘海神卡维图瓦情况一下恶化难再长期维持自身存在…它一边让信徒寻回那件物品一边为附身存活做着准备那把骨剑应该就源于它半神之躯隐藏着它投射过来一点力量只要目标合适就会侵入触碰者体内污染灵魂建立坐标让本身灵在消散前转移过来…但是它明显不擅长这方面事情嗯它不是水银之蛇没法自我循环转世重来也不像渎神者阿蒙可以寄居于别人灵魂内真要占据这具身体只会导致血肉彻底崩溃制造出一个恐怖怪物。」按照这逻辑发展濒临彻底陨落卡维图瓦接下来还会有很多疯狂举动…微皱眉头不再耽搁坠入灰雾返回现实世界。解除反锁拉开房门进入客厅吓来回踱步达尼兹一跳。达尼兹上下审视几眼谨慎又戒备问：「你没问题吧？」维持人设平静回答：「解决了。」解决了？左看右看又眺望卧室一眼怀疑自己之前感受全是幻觉根本没什么海神诅咒。他在卧室里做了什么？才一两分钟就解除海神诅咒？嘶这家伙秘密不小啊…倒退两步让开道路。……摆放着不少杂物桌子旁坐在铁轮椅上光头卡拉特一脸遗憾对纹身男埃德蒙顿道：「真是可惜啊。」「只差一点…他没有拿起仅仅碰一下。」同样叹息。卡拉特望着那略显弯曲骨剑狂热自语：「当有外来者拿起这把圣剑神将重现于大地…」埃德蒙顿随之跪下来似乎在对神灵告解。时间一分一秒过去卡拉特和埃德蒙顿突然听到两声惨叫。抬头望去发现有两位同伴直直栽倒皮肤如同风化岩石失去所有水分。对视一眼感受到某种异样氛围。两人同时直起身体看向桌子。那把乳白色圣剑喀嚓一声裂开碎成无数小块。

# 330 无面人 第一百一十八章 被诅咒者

## 打开书
莎伦点马里奇讲：知囚犯途？——非凡圈听过（值夜／塔罗）。默十余秒：囚犯＝狱中人亦灵欲被缚压抑者；体强敏锐；沉默外疯狂内；擅犯罪随物杀人。序列8疯子：教会亦不详；组织对成员束缚极紧难通灵占卜；二人久忍始解缚逃离；因诅咒易狂不愿投教会失自由。疯子可主动牺牲理智爆发欲望换力升抗精扰——「先干掉自己你就杀不了我」。诅咒自此易失控。序列7狼人：满月失智黑毛嗜杀巅；自愈力敏爪牙含毒；黑暗法术；毒控目标转属狼怪寿短；实战序列7中上；难抑则冷酷失情（合阿兹克异种述）。马里奇舔唇危险感：己序列6活尸——体如钢，左轮顶脑最多晕，同点五发才破；脑不碎难致命；力超狼人；死法唤尸控幽寒腐。诅咒：渴温血鲜肉满月尤甚；活尸咒替前咒不叠；满月抑则痛失战，放纵失人失控；平日抗欲抗恶意。莎伦：序列5怨魂——转真幽影穿障藏镜攻魂跳反射面；非高序难察；死法附体等；咒：满月吸魂或极弱，吸则走失控边。目标亦怨魂；低序能不因晋失。克莱恩怕子弹无效难火攻＝怕鬼。问封印：深红月冕——范围造满月效，冷酷者助爆，节制者虚弱；佩戴者免疫满月并获速愈黑暗法，血渐冷结冰须停或吸活人血否则霜死。同伴：活尸杰森、狼人泰尔；杀史蒂夫则余非题。分赃：史蒂夫特性归马里奇，月冕归莎伦，余战利＋《秘密之书》归克莱恩。

## 这场戏有没有翻
翻了。开头还在补囚犯途课；章末深红月冕与分赃合同摊开。翻的是帮不帮还能否只听故事，不是「怕鬼」。

## 热怎么变冷
疯子自干还热。冷切在狼人满月。活尸钢体还热。冷切在渴血自白。怨魂怕鬼还热。冷切在月冕与分赃。

## 怎么起、怎么收
第一段「你应该知道囚犯途径吧」。最后一段密书归你。章题：被诅咒者——自述与敌述一体。

值夜资料缺口。腹诽自干。莎伦狼人想象被瞪。怕鬼自嘲。马里奇坚持赞。

## 可搬走的一条作法
以后写别的书：让雇佣前先把「我怕什么」写进角色反应，再甩出克制双方的神器名。书证 L29057 简单来说就是，我怕「鬼」。

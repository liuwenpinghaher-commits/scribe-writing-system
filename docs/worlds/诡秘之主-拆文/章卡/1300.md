# 1300 倒吊人 第三十五章 “新生”

## 打开书
透过窥秘之眼贝尔纳黛看见暗红神龛内部空空荡荡什么都没有只得往常笼罩着现实那层阴影帷幕。她无法从中预言出什么不得不收回目光依循本身直觉让无形仆役走向开阔地带另外一头那里同样属于树木巨大耸立原始森林。与此同时因为无形仆役没法离开她太远戴着隐身帽她安静跟在后面不快不慢通过之前聚集整个岛屿所有生物区域。在这里高空似乎总是有点阴沉弥漫着淡淡黑色。时间飞快流逝中无形仆役进入树枝横斜遮蔽天空森林内部眼前骤然黯淡下来。紧接着那双近乎透明冷漠无情难以察觉窥秘之眼看破昏暗环境注意到树木间摆放着一具又一具苍白尸骸而许多枝干上也垂落头骨腐尸等事物。……这里对它们有什么意义？作为一名预言大师贝尔纳黛充分相信自己脑海内产生那些画面就是真实发生过事情只是疑惑究竟有什么力量让这座原始岛屿上生物选择这里作为自己墓地。……这让贝尔纳黛微皱下眉头驱使无形仆役继续向前往生物坟场深处行去。就这样无形仆役在这片充满白骨和腐尸森林内前行近一刻钟。……贝尔纳黛让窥秘之眼注视那根石柱好几秒可却没有发现它存在任何神秘之处似乎只是一个随手竖立象征。无形仆役环顾起四周发现这根石柱周围区域尸骸腐烂得都不算严重还覆盖着相当完好血肉和皮肤。……她未使用自己预言能力来寻找原委因为预言实质是窥视命运之河涉及问题越严重位格和层次越高对她带来反噬伤害越大而当前这种难以理解情况由不得贝尔纳黛不谨慎害怕会关联……另外这本身也还未对她产生危害她没那个必要冒风险做预言。无形仆役搜寻一阵没发现任何线索后继续往前试图穿过这片坟场前往原始森林别区域。……下意识间她让无形仆役回过头望向那根黑色石柱处。窥秘之眼里石柱周围那些尸体腐烂部分一块又一块掉落新血肉如有自身灵性般滋长出来皮肤一寸又一寸将这惊悚画面逐渐覆盖。……而且这不是死灵导师唤起活尸和骷髅那种复活是有一定意志和生命力新生。世界底层规则在这里出现扭曲和混乱？另外似乎也带着一点黑皇帝复活神秘……不过那些获得新生亡者状态都不是太对更接近活尸……这样复活存在很大问题啊……灰雾之上克莱恩也……贝尔纳黛同样做出一定猜测没让无形仆役停留于原地等待下一次新生潮汐。……无形仆役被新生潮汐多次影响后奇异产生某种意志活过来！另外无形仆役之前也不是没做过探查可始终没能发现那根黑色石柱特异之处贝尔纳黛不认为它继续停留会有额外收获。……巨树间和枝干上尸骸随着无形仆役前行逐渐变得稀少这个过程中贝尔纳黛又发现一个现象：新生潮汐中不是一定会有尸骸得到复活可一旦出现复活留下空白区域接下来五分钟内其余尸骸会如同金属受到磁铁吸引僵硬呆板移向中央区域依次填补相应位置就像在排队等待恩赐。……等对这座岛屿情况有较完整把握可以找一个复活者来试验一下……贝尔纳黛迅速做出决断沿着无形仆役探明道路往前穿行着。她没有使用隐身帽之外任何非凡能力务求不惊扰环境不遗漏细节所以走得并不算快用了又差不多一刻钟才离开这片坟场。这个时候无形仆役已经钻入前方森林听见时而响起鸟鸣声和兽吼声感受到不同于其余区域蓬勃生命力。……还好我现在已经是源堡主人在这里有天使之王位格想注视现实多久就能注视多久不用太担心灵性耗尽嗯唯一需要注意是藏在历史迷雾内第一纪前旧日都市中身体。无形仆役又前行几分钟后突然看见一个与这座原始岛屿环境不太契合事物。……此时那木屋门敞开着让贝尔纳黛能通过窥秘之眼看见里面部分情况：……谁住在这里？贝尔纳黛心念一动间无形仆役迅速靠近那座木屋寻找可能存在线索。……就在贝尔纳黛借助窥秘之眼仔细检查木屋内每一处细节时她心中突然有某种预感忙让无形仆役转过身体。不知什么时候无形仆役背后多了一个人！……这是大帝陨落后还活一段时间那位骑士冰山中将艾德雯娜祖先。爱德华兹注视无形仆役几秒忽然张开嘴巴低沉说道：公主殿下。

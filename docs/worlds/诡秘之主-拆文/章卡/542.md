# 542 旅行家 第六十一章 出乎意料的事实

## 打开书
看来找到目标了…收回视线大致做出判断。因为没有肖像画死去冒险家又被烧得满脸乌黑艾尔兰明显未认出这是目标之一观察下形势倾听几秒让人毛骨悚然笑声后就指着躺在房屋外面不远处三四位军方人员沉声说：「先把他们拖回来等其他小组抵达再发动进攻。或者…」犹豫下抬头望向正在靠拢这边深蓝色飞空艇。没再多说也未指挥克和达尼兹去做自己奔向已冻得昏迷过去脸色青紫军方人员。蹬蹬蹬蹬…越是靠近那边步伐越是无力到后来身体已然变得僵硬每迈出一步都异常艰难。做过皇家海军水手长经验丰富当机立断不再向前缓慢转身一步步往回。越走越是顺畅可浑身上下依旧控制不住发抖眉毛和鬓角蒙上一层浅浅白霜。违反常理速冻…灾难一样极寒…借助艾尔兰尝试把握到那片区域危险程度并油然心里感叹一句：「可惜太阳胸针没法产生真正炎热属于精神上刺激虽然同样会让身体产生明显反应但顶多让人在那样寒灾里多支撑三四秒…」看眼牙齿的的作响想说话却开不了口艾尔兰一眼目光扫向达尼兹。丢掉手杖低沉说：「火。」火？先是愣住但很快明白格尔曼意思。他也看见艾尔兰救人失败全过程！右掌掌心凝聚出一团不算明亮赤红火焰向着军方人员侧面不远处扔过去。火球穿过近二十米距离落在地面没有发出爆炸声音只安静往上腾起焰苗。这赤红火柱发出滋滋滋声音不断缩小飞快黯淡。突然它一下扩张仿佛在垂死挣扎。身穿黑色呢制大衣克从里面跃出来刚好落至那位军方人员旁边。弯下腰背探出双手抓住对方衣物。接着脚下一抵腰背发力猛地往外一甩。这军方人员当即腾空而起平滑飞出落在十米开外脱离寒意最严重区域。而做完这一切啪打个响指在寒意浸入血肉前点燃衣兜内特意分出一根火柴。赤红色焰流如水外涌瞬间将他淹没。等到一切黯淡下来已消失在原地。一道道火光跃出时亮时灭借助达尼兹火球和本身火柴在极寒区域不断闪现简简单单就把几位军方人员丢出去。经过两到三次接力提着最后一位军方人员回到原本位置。艾尔兰已明显缓和下来竖竖大拇指道：「我很庆幸也很荣幸今天做出了请你帮忙决定。」船长我就喜欢你这么委婉赞美…还有记得提高报酬…礼貌点头半转身体望向窗户敞开房屋听见里面笑声越来越奇怪。达尼兹则在旁边撇撇嘴暗骂起艾尔兰：「难道你没有看见我做出贡献？虽然我火球变得像是魔术表演道具但也实实在在做出贡献！这家伙外号公正艾尔兰其实一点也不公正！」嘀咕间阴影笼罩这片区域飞空艇来到对面半空。「疏散周围房屋人！」飞空艇上一位军官远远喊道。等艾尔兰和陆续赶到两个小组清理附近几栋房屋后飞空艇压下高度调整炮口。轰隆轰隆轰隆！火炮连发轰向那有诡异笑声传出房屋。听到一声声爆炸看见剧烈火光闪现拿着手杖一时竟有些唏嘘。这就是他崇尚火力覆盖战术曾经在廷根市提出但无法付诸实践而今天海外殖民地军方向他展现真实场景。震耳欲聋炮声里艾尔兰等分守不同位置防备着里面人或者说怪物突围。房屋很快坍塌硝烟从堆积砖石木块里弥漫往上所有积雪所有冰块已然消散一空。突然一道粗大闪电亮起张牙舞爪劈在飞空艇上。眉头一皱看见飞空艇彻底静止听到蒸汽锅炉发出让人牙酸声音。那深蓝涂装空中怪物有些失去控制冒着不大但也不小烟气向着侧方飘落。看来有做弹药隔离气囊外层保护…我还以为会发生殉爆直接将飞空艇炸成几截…将注意力全部转回那栋坍塌房屋。最初感受到深寒看见男性冒险家被烧焦时还以为又遇上一位魔女——掌握着女巫魔药配方与魔女们打过几次交道知晓这条途径非凡者从序列7开始就能驾驭冰霜和黑焰。但刚才那闪电让他否定这判断相信拉蒂西亚确实是摩斯苦修会或要素黎明人是原装正版女性。念头刚落那堆积砖石木块就一下被掀开鲜红与焦黑混杂人影用手肘支地爬出来。她是位女性隐约能分辨出拉蒂西亚原本样子这让艾尔兰等人愕然发现目标已经找到但和之前相比拉蒂西亚现在状态既恐怖又凄惨。她身上长满黑斑被炮弹撕裂出一个又一个鲜红口子里面蠕动着仿佛有了自己生命白色筋膜。头顶裂开脑浆涌出来黏在表面像是一只又一只小孩手掌重叠于那里。青灰色眼睛失去焦距一只瞳孔藏着火焰一只闪烁电光。腹部位置胸口以下镶嵌着两个痛苦嘶喊脑袋正是另外两位男性冒险家。不仅是失控还有被污染感觉…在刚才那轮炮轰下她已经重伤气息降到极点…没有动手看着那些军方非凡者有层次发动攻击。精神刺穿痛苦之鞭净化子弹小口径火炮射击…这么一轮下来只来得及让地面干裂并往外蔓延失控者拉蒂西亚就彻底崩溃瓦解变成碎尸。啪！躯干倒在地上两个男性冒险家脑袋滚出来。眼睛微眯发现拉蒂西亚腹部血肉内藏着一卷黄褐色羊皮书籍。书籍表面用精灵语写着一行单词：「天灾之书。」这些书啊笔记啊怎么总往别人肚子里钻上次安提哥努斯家族笔记也是这样…先吐槽一句接着怀疑起这本天灾之书就是拉蒂西亚这位伪考古学家从海神遗迹里拿走物品。就这时有军方人员把握住两个男性冒险家脑袋似乎还能说话机会急促问：「你们在海神遗迹里做了什么？」「海神遗迹…」其中一个男性冒险家又痛苦又迷茫回答「我们没有去过…」努力移动眼睛想查看自己脖子及以下位置状况。「西弥姆岛海神遗迹。」那军方人员提醒一句。「不…没有…」想摇头却无能为力「我们去是古精灵遗迹…拉蒂西亚从里面…找到一本书…她很喜欢…她很快就开始研究她她疯了！她疯了！」这男性冒险家嘶喊出声残余精神彻底溃散。不是海神失落神庙而是古精灵们遗迹？这和我想得不一样啊…正要仔细旁听艾尔兰已走过来礼貌请他和达尼兹远离询问现场。拐入另一条街道放慢步伐思考起整件事情：「为什么拉蒂西亚从古精灵遗迹里拿走那本天灾之书会导致海神卡维图瓦再无法维持本身存在逐渐走向崩溃？两者之间有什么联系？精灵…海神…按照小太阳说法精灵王苏尼亚索列姆这位古神掌握着如今风暴之主那些权柄也就是说精灵里面毫无疑问拥有序列3海王以及更高序列2…难道卡维图瓦这条海蛇就是偶然间发现一座位于海底精灵遗迹直接吞食某个上位精灵遗留非凡特性并幸运撑过暴毙和失控两个环节才成功获得半神位格逐渐得到罗思德群岛土著们信仰？」慢慢有了思路这让他不得不感谢倒吊人先生。最初小太阳是没透露八位古神相应权柄后来才在倒吊人一次次引导下讲述一些这里面就包括精灵王大致情况。至于那种直接吞食非凡特性或相应材料提升事情并不是没有发生过在魔药体系尚未构建完善前人类先民们为获得超凡力量做过类似尝试但只有极幸运一小撮人活下来成为非凡者没变成怪物疯子也没当场暴毙血肉崩溃。这样尝试成功概率是千分之一万分之一甚至更低有了魔药体系后没谁再愿意冒这么大风险。「如果真是这样卡维图瓦当初确实非常走运…当然也有它身体粗壮强健因素…不过它智慧似乎提高不多也就能骗骗信仰竟然一直没发现西弥姆岛还有个精灵遗迹且与它藏身那个遗迹有密切联系…拉蒂西亚他们拿走天灾之书后那个遗迹崩溃导致卡维图瓦藏身处发生异变让本就苟延残喘它再也无法维持？这倒是能解释拉蒂西亚他们较为轻松就得手原因那里并没有反抗军和海神信徒看守直到出状况卡维图瓦才发现问题才明白两个遗迹有关联。」根据刚才思路尝试解释整件事情里较为疑惑地方。而这就包括垂死挣扎海神为什么不让信徒成为载体——这能减少很多意外让事情变得简单以卡维图瓦展现残暴理所当然该做这选择。想到答案是卡维图瓦想污染并占据身躯必须有一定精灵血脉只有这样才能在某种程度上承受非凡特性转移。而他触摸时由于灰雾由于本身特殊让卡维图瓦一下找到更好目标。

翻了。火力救人；章末古精灵遗迹。翻的是天灾之书非海神庙，不是魔女线。

- 火跳可穿极寒救人。

## 话
「火。」「天灾之书。」「我们去的是古精灵遗迹……她疯了！」局面是从救人收到炮轰；从闪电收到非魔女；从碎尸收到天灾书；从海神遗迹问收到古精灵翻案。

# 1351 倒吊人 第八十六章 诡秘侍者

## 打开书
随着诡秘侍者魔药进入身体克莱恩顿时有种膨胀起来感觉。转瞬之间他失去对肉体对灵之虫感应眼睁睁看着它们虚化散开融入无法以正常语言描述无法用正常逻辑理解灵界似乎要崩解成抽象庞杂各种信息。这一刻克莱恩只有意识还勉强保存具备自我认知。他就那样漂浮于充斥着无数奇异身影灵界之中在失去对身体和非凡特性感应后进一步承受起各种各样意念信息知识符号和标识冲刷在彻底丢失自我与灵界合二为一边缘徘徊。……这是他制造灾难目的是阻断那片黑暗前进。……而他双手将那蔚蓝之门牢牢按住没让它更进一步敞开。如果只面对这1级封印物阿尔杰完全没有问题甚至有余力尝试封印但此时此刻他周围还有两件同样危险物品。……最多还能支撑三十秒钟风暴之主一直没有回应……阿尔杰脑海念头电转压制住种种不舍和不甘迅速做出决断。……这是他第一次参加塔罗会后遗留印记可以代替诵念尊名让愚者先生目光投向这边。……血肉之门处一层层坍缩凝聚寻求质变光球们似乎组成一道由层层叠叠门构建身影这身影以血色潮水为袍形体一直在扭曲变化映照出不同星球不同地域。……这道阳光外无法看透黑夜涌来试图吞没掉正寻求晋升序列0门先生伯特利·亚伯拉罕。祭坛所在那片大地则猛烈摇晃裂开巨大口子要让血肉之门和伯特利·亚伯拉罕一起落向地心深处直面那片包容所有颜色所有可能般混沌海。……它们注视着血肉之门和伯特利·亚伯拉罕要将它们样子映入自己瞳孔内。门先生发出一声低吼让身上披着血色长袍扬起来。这长袍与血肉之门后涌动邪异潮水连通往周围扩散出绯红月华。……这些阻止和干扰同时陷入混乱让门先生获得喘息机会。……就在这时那血肉之门突然自行坍塌覆盖到门先生体表让祂似乎变成另外一个人。……这一个个人抬起脑袋在灵界之中那个虚幻城市望向无穷高处。他们看见虚幻细密灵体之线看见一个由部分无瞳之眼和部分扭曲之线构成符号。……一条条灵之虫一点点非凡特性一个个自我认知从乌托邦对应灵界区域飞起投向克莱恩略显虚幻身体让它逐渐拥有实质。……他已晋升序列1成为诡秘侍者。……克莱恩透过这些虚幻星辰看到某个岛屿上门先生和阿蒙看到隐秘世界破败宫殿中安提哥努斯看到藏在未知之地查拉图看到伦纳德身上帕列斯·索罗亚斯德看到乌黯魔狼科塔尔……借助更进一步掌控源堡时产生异变克莱恩找到诡秘三途径对应天使和天使之王们。当然这种视野只能存在这么短短几秒钟一旦阿蒙和查拉图祂们反应过来用正确方法隐藏自身克莱恩将无法再锁定祂们本体。……本来放在源堡内星之杖随之出现在他掌中而他也分出部分灵之虫让它们进入源堡预防异变回应信徒。——成为诡秘侍者后克莱恩对源堡掌控进一步加深能随时随地取出里面物品。下一秒星之杖上多种宝石亮起克莱恩身影消失在灵界瞬间漫游到一片沼泽中漫游到查拉图面前。戴兜帽穿黑袍满脸白须查拉图没有慌乱一边利用诡秘侍者非凡能力做着各种各样连接一边伸出左手往前方虚空里抓一下。……难道因为监控维尔杜任务失败愚者先生不再眷顾我？他眉头微微皱起想要放弃又停留在地底。……门先生伯特利·亚伯拉罕被血肉之门覆盖住后耳旁回荡起一道熟悉声音：你想将灾难带回现实？……放弃吧我有办法处理我会让你安眠让你获得想要平静。那熟悉声音又一次响起。

## 这场戏有没有翻
翻了。开头灵界冲刷濒失我；乌托邦灵界城捞回自我成序1；瞬见诡秘三途诸天使；漫游追查拉图；并行门被血肉覆／熟悉声劝弃；阿尔杰印记求愚者。翻的是诡秘侍者＝晋成＋瞬视野＋门危未定。

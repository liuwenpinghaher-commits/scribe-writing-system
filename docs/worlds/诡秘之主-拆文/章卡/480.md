# 480 无面人 第二百六十八章 数字与人

## 打开书
贝克郊外一座小镇内。换上干燥洁净衣物克将浸湿钞票一张张摆桌面——等温暖室内自然晾干。过程动作小心轻柔；连感冒发烧喷嚏咳嗽都强行压制。为确保无失误未自己控火烘烤。做完走向旅馆房间角落——摆一面全身镜。镜内黑发整齐斜梳深棕眼眸脸庞颇消瘦棱角分明。鼻梁架金边眼镜嘴边无胡须看起来既年轻又阅历不浅。这是根据北大陆人种特点魔改周明瑞长相；且读大学那会朝气蓬勃未被社会催胖样子。打算等事情稍平息回贝克转一圈顺便为现在模样弄一套合法身份——与离廷根那会比如今不缺相应渠道：勇敢者酒吧伊恩；莎伦小姐圈子；艾辛格·斯坦顿大侦探。真是怀念啊…低语——窗帘早已拉拢房间内忙碌仪式准备将蠕动饥饿带入灰雾做万无一失研究。寂静无人古老宫殿浮现青铜长桌最上首——拿人皮制成般轻薄手套向后靠椅背。闭眼灵性延伸入这件需封印物。立刻感受手套饥饿——仿佛有永远无法填平胃袋；但灰雾之上如此温驯连一丝恶意不敢流出仿佛趴那里一动不敢动猎犬。然后听到不甘呐喊痛苦呻吟。一张张扭曲狰狞哀嚎透脸孔旋即凸显灵感内洋溢让人不忍目睹悲哀与疯狂。这些脸庞与不同颜色状态表现非凡特性深度融合；灵性蔓延到哪就能与相应脸孔结合使用它所具备能力。这就是使用方式？一次次尝试结合占卜大致弄清蠕动饥饿目前放牧哪五个灵魂。一无面人但只有改变容貌身材能力；二心理医生可让目标陷狂乱可一定心理暗示可模拟龙威震慑个人群体制造混乱；三审讯官能让佩戴者精通各种武器成爆破专家并具备凝聚精神穿刺目标灵体；四梦魇只有一个能力无声无息拖人入梦但与相应非凡不同主要靠蠕动饥饿完成所以佩戴者入梦魇状态后仍可移动自己身体；五光之祭司能产生光环般效果净化一定范围死灵污秽类生物同时具备歌颂者增强自己同伴歌声能召唤比阳炎弱一些神圣之光。极限五个灵魂并在初次放牧时固定可使用能力…并非自己能决定纯看运气也许三个也许只一个…若有所思点头叹气对痛苦灵魂：「无论你们以前是什么样的人我都将逐渐让你们脱离禁锢得到彻底解脱。而以后我放牧的灵魂只会来自罪恶深重无法饶恕的人；每杀死一个这样的非凡者我就让你们其中一个被替换得到解脱不管他的能力是否被我需要。」郑重但柔和嗓音回荡古老宫殿；哀嚎痛苦魂灵安静下来不再那么扭曲狰狞。呼…吐气睁眼手指轻敲古老长桌边缘无声自语：那无面人能力与本身重叠完全无价值等有替换就最先释放；到时可试通灵对话也许得占卜家途径高序列消息以及美人鱼出没线索…不不用等有替换过几天感冒痊愈状态恢复就可尝试…光之祭司对应灵魂应能补全之前获得配方并留相应非凡特性这样一来小太阳就不用担心后续晋升；嗯他将是第二个得解脱…至于每使用一次就要用一个人类灵魂血肉喂饱蠕动饥饿的事倒不需在意；我正常肯定不会动用它需要时必然面对可怕敌人那样战斗里肯定不缺可收割生命；即使没有也能将蠕动饥饿丢灰雾之上不用担心反噬也就不会伤害无辜；最差结果就是无法再使用而已…收起思绪尝试利用蠕动饥饿占卜牧羊人魔药配方——最终只收获失败。未占卜蠕动饥饿来源担心招惹不好存在。虽有灰雾隔断阻挡不害怕危及自身但那样一来蠕动饥饿也许会被损坏。等不再需要时才考虑相应尝试…身体前倾肘部支撑桌面。迅速回忆先前事敏锐注意细节：万能钥被泯灭后非凡特性未消失而是成光粒努力聚合…可预见最终成形学徒特性不再有源于门先生呐喊。换句话说能通过这种方式去除非凡特性内精神污染！但问题在于正常情况根本没法破坏固化为物品非凡特性；当时依靠可让真神降临仪式需要前置包括大量无辜生命…而且全黑之眼一旦被粉碎里面深藏真造精神污染必然爆发到时候谁能承受？在灰雾之上做？想法纷呈间想起东区可能遭遇忙具现纸笔做相应占卜。得启示后失去表情缓缓慢慢往后靠椅背。下方无垠灰雾亘古不变般寂静沉浮。……奥黛丽站窗边看淡黄铁黑交错雾气飞快消散看不属于冬日大雨磅礴而落心情平稳不少。不知过了多久她和苏茜终于等到霍尔伯爵回家。「爸爸怎么样了？」关切问。霍尔一边将外套帽子交侍者一边露温和笑：「解决了但具体过程还不清楚我的小公主你这次真是帮了大忙你值得一吨重的勋章！」这样就好这样就好…多亏愚者先生提醒多亏祂眷者冒险调查…我们塔罗会又一次阻止邪神降临又一次拯救世界！心里充满自豪。霍尔接过女仆毛巾擦脸叹息：「但这次依然造成较为严重伤亡；贝克雾霾竟然能变得如此致命…虽然统计结果还没有出来可我估计东区码头区和工厂区有超过万人因此而死亡并且瘟疫还在蔓延你最近尽量不要出门。」超过万人？这是奥黛丽能理解却无法想象的数字；只有每年立国日花车游行时她才能看到几千上万人聚一起场景。但不妨碍心头沉甸甸情绪一下变低落。……黛西站公寓外看穿白大褂戴大口罩医生护士进入里面抬出一具具尸体。早已知道结果表情麻木眼神空洞下意识往门口靠近。这时负责警戒线警察拦住：「不要过去你想感染瘟疫吗？」黛西停那里看两具尸体被抬出看妈妈丽芙紧紧抱姐姐弗莱娅看她们被抬到围黑布临时征用送货马车上看被盖上白布她们消失眼前。马车缓缓行驶向街道另外一头。这时黛西才仿佛从梦中醒来——转过身体飞快奔跑追逐马车。雨后地面异常泥泞几次摔倒又几次爬起弄得身上都是污迹。然而还是没能追上那辆马车眼睁睁看它消失拐角处。放慢脚步身体轻轻摇晃表情异常呆滞。扶住街道旁树木目不转睛看马车离开地方。突然整个人软下去嗓子里挤出一道哭泣声：「妈妈…弗莱娅…」声音细细低低尖锐又虚弱徘徊而不绝。这一刻在东区在码头区在工厂区有数以万计的人同样悲鸣着哭喊着。……皇后区索德拉克宫。戴王冠脸庞坚毅留两撇小胡子乔治三世坐御座看面前行宫伯爵久久不语。「陛下三大教会的人都在外面等待您的解释。」行宫伯爵额头冒汗问。「解释？埃德萨克王子受魔女诱惑与邪教勾结试图谋反这就是解释！他阴谋败露已经自裁他们还要什么解释！」忽然暴怒。吸口气恢复往常严肃：「你告诉他们不管用什么方式得到相应爵位的人都可以获得上议院议席；关于选举财产限制将放宽无效选区也将得到清除这是对那些工厂主银行家的安抚。同样大气污染调查委员会将立刻给出结论有关法案将很快得到通过；最低保障和工作时长规定也将最近以法律形式呈现！济贫法将按照他们要求改革…允许三大教会派遣人员进入军方！」「陛下…」行宫伯爵听得吓一跳。这样的让步简直超乎想象尤其最后那条。乔治三世再次暴怒：「就这样告诉他们！既然他们想要新秩序那我就给他们新秩序！」「是陛下。」行宫伯爵不敢再说退出宫殿。乔治三世端坐那里许久未动就仿佛一座石像。不知过了多久——他的表情突然柔和。

## 这场戏有没有翻
翻了。晾钞票开镜变脸；章末乔治柔和。翻的是万人从数字落到黛西哭，不是克查清雾霾。

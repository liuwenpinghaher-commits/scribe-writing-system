# 1090 红祭司 第一百四十五章 自问

## 打开书
东区出租屋。夹克克莱恩感应诡法师消化：比前三月加起来还多。生命手杖前难医院怪谈；非战争难找半神主场，不愿转无辜为偶。默念「战争」。路灯外东区漆黑，警察因禁令积极巡逻。结局幻象：乔治冲破桎梏推黑皇帝仪式，能扛魔药则序列0；艾因霍恩借世界大战消化；阿蒙兄弟成空想家。陡问：这样的结局，你接受吗？眼前穿透——大雾霾、流浪汉栽倒、寡妇失子、少女不见未来、孤女、秸秆般倒下、半截学生、一夜孤儿、爬行咽气、墓园哭晕、血地硝烟炮弹；黑手登神座脱衰老。三连问。默然后开口：「不，我不接受。」回荡叠加。自嘲：七神都默许，不接受有何意义？又：「就算没有意义，有些事情还是得去做。」不鲁莽：现层次难撼乔治，乱战时或致弗萨克入侵、死伤十百倍雾霾。目前只准备：提高自己、多布置、等机会。黑浆糊涂镜联络特莉丝——无回应，或被信使天使吓断联。转想魔女助乔治：灾难消化；或承诺公开传教（七神不许）；或红祭司天使特性／0级封印——无序列1时魔女高层最大希望。红天使寻白之魔女卡特琳娜不像口头简单。以卡特琳娜为突破口；先听贝尔纳黛预言与在城要做之事。次日清晨嘉德丽雅转：「今天中午12点到12点半，塞伦佐餐厅，金色剧场。」11:55幻术过服务生。丘纳斯对街看报，恩尤尼发反弗传单，三人时换位。怀表默数十下敲门。「请进。」先见大片金色，再见最上首栗发女子。

## 话

## 热怎么变冷
消化加快还热。冷切在战争结局幻象。七神默许嘲还热。冷切在「还是得去做」。涂镜还热。冷切在无回应。

## 怎么起、怎么收
第一段立书桌测消化。最后一段开门金色与栗发。章题自问——答案是不接受。

## 可搬走的一条作法

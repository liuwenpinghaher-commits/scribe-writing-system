# 1205 逐光者 第五十六章 都是老狐狸

## 打开书
迟了？克莱恩内心一沉后突然感觉手里旧日之盒剧烈震动起来。他忙低头看去只见第一层内缩小为玩具尸骨教堂大门表面焕发出一道又一道光芒其上每一个白色头骨每一张扭曲脸孔都似乎活过来。亚当这座尸骨教堂层次这么高？仅仅一扇门就能对抗0-61第一层？克莱恩没有犹豫又通过代表伦纳德深红星辰锁定平斯特街7号外面一根煤气路灯杆。霍然之间那镶嵌着白骨凸显出扭曲脸孔大门回到现实世界而旧日之盒第一层内多了根玩具路灯。紧接着克莱恩又将目标瞄准尸骨教堂内部阿蒙右手顺势下滑要打开0-61第二层。此时战场已没有帕列斯·索罗亚斯德克莱恩可以毫无顾忌将阿蒙移到别地方。他指定是星界想让阿蒙被七神关爱但这会不会出现随机性异变他就不得而知。就在这个时候那扇大门回归尸骨教堂然后这与平斯特街7号重叠恢弘建筑飞快崩解。崩解过程非常有条理先从穹顶开始接着是拱券和墙壁最后是漆黑石柱。而掉落物品并没有砸在地面于半空就已消失不见。立在十字架前阿蒙也随着整座尸骨教堂崩解一寸寸溃散似乎祂也是空想出来随时可以解除存在东西。当然克莱恩很清楚这只是阿蒙在利用漏洞借助尸骨教堂空想具现结束让自己也成为想象脱离贝克兰德。轰隆！半空不知什么时候多厚厚阴云一团房屋大小球形闪电拖着银白流光狠狠砸在还未彻底崩解尸骨教堂和阿蒙身上。阿蒙那水晶磨成单片眼镜骤然出现一道道细小裂缝头上尖顶软帽一下垮塌。不过这位时天使并没有惊慌在脸庞出现不受控制抽搐后依旧保持微笑拿着那枚光与影聚合成晶柱幻影一样彻底溃散在填满尸骨教堂内部光之海洋里消失不见。下一秒钟深黑为底镶嵌白骨巍峨教堂也完全归于幻想。此时平斯特街7号那栋房屋依旧存在只是客厅地面多道夸张痕迹。那痕迹就像一个人躺在那里化为焦炭。这是阿蒙不知多少个分身被劈死后留下但克莱恩知道阿蒙本体成功逃走并且达成预期目的。等到祂恢复过来这位天使之王只需要一个仪式就能登临神座成为这个世界所有错误化身。在我换走尸骨教堂大门后最先察觉最先反应过来最先降下力量竟然是风暴之主……女神是真没法神降啊只能利用各种媒介稍微干涉现实难以在阿蒙本体有准备情况下影响到祂……我还在为自己摆脱阿蒙高兴为连续避开祂没踩中陷阱满足结果祂不声不响就做成这么大一件事情……祂是什么时候将重心转移到贝克兰德？嗯应该是我利用欺诈规律办法异地重生后他察觉到帕列斯影子以及与我之间存在联系事实开始将目标放在拿到最后一份序列1非凡特性成为真神上……伦纳德之前祈祷时说不够详细只提一句是雅各宝藏出问题……能让帕列斯这么熟悉阿蒙这么谨慎序列1天使都没察觉异常直接踩进陷阱阿蒙肯定又做了什么了不得事情……呼我虽然在和阿蒙斗智斗勇中飞速成长完成蜕变但和祂这位顶级欺诈师相比还是差得太远太稚嫩……一旦阿蒙成为序列0错误并且还可以行于地上那我就真太难……不行得弄清楚偷盗者途径成神仪式想办法做些破坏不能让阿蒙轻轻松松就登临神座……可这会不会正是阿蒙希望发生事情？祂故意举行仪式就等着我送上门？思绪电转间克莱恩长长叹口气。然后他以愚者姿态和口吻向伦纳德传递信息：不用祈祷了。……圣赛缪尔教堂内伦纳德刚从花园泥土里冒出试图冲进大祈祷厅就听见愚者先生话语。不用祈祷了……伦纳德脚步逐渐放慢失神重复这句话。他越来越慢最终停在一根石柱旁埋低脑袋抬起双手捂住脸孔。就在这个时候他脑海内突然回荡起一道略显苍老嗓音：难过什么？我还没死透呢！啊？伦纳德松开双手又茫然又惊喜：老头你还没死？他眼眶已是略微发红。瞧瞧这叫什么话！帕列斯声音透着明显虚弱：咳简单来说就是我老人家死了一次但还没有死彻底。伦纳德终于松口气左右看一眼见无人注意才压低嗓音：你成功欺诈阿蒙？也不能说是欺诈。帕列斯叹口气：这么多年以来我想最多事情就是如果真被阿蒙本体找到该怎么办经过一次次试验我也创造一种办法那就是本体死后可以在分身处复活但会失去序列1非凡特性被动降低一个层次嘿我也不算太落后于时代嘛。也就是说阿蒙杀你一次拿到你序列1特性而你以序列2位格复生？伦纳德大致明白确认般反问。帕列斯叹息：差不多是这样其实吧阿蒙也不是没有察觉将你推出尸骨教堂时候祂没做阻拦就是给我留一点希望让我在接下来战斗里失去拼死决心哎如果不是这样我也不至于那么快就被祂解决好歹我吸收宝藏内非凡特性后已基本恢复……伦纳德略感愕然脱口：老头你把我推出尸骨教堂是因为我体内有你分身？帕列斯顿时嗤笑：你觉得呢？真以为我拿你当孙子看啊？……你不是还有别分身吗？伦纳德嘀咕。帕列斯哼一声转而叹口气：阿蒙竟然连自己分身都骗这一次我输得没有话说。如果不是从吸收阿蒙分身处知道这位时天使并不了解雅各宝藏具体情况祂在这件事情上肯定会更加谨慎会对阿蒙出现有更充分准备。这一点是最至关重要原因其他无论是雅各家族始祖事情还是克莱恩正与阿蒙本体在神弃之地周旋情况都不是让祂下定决心要素。伦纳德想宽慰：老头这是这个宝藏最致命陷阱无论怎么样你都会踩中能活下来就算不错。那不是。帕列斯立刻反驳：如果有危险预感我会直接选择一位正神信仰成为祂地上天使在祂庇佑下前往雅各宝藏哎我之前吸收完特性恢复序列1实力后就在考虑这个问题是直接加入黑夜教会还是和你们那位愚者合作或者解除寄生像过去那样躲躲藏藏避开阿蒙。说到这些时候祂情绪又变得很是复杂。……老头真有规划……为什么你对投靠这种事情这么熟练……伦纳德暗自感慨将注意力放回最重要那件事情：老头阿蒙拿到你序列1非凡特性后是不是就要准备成神仪式了？嗯。帕列斯嗓音低沉：这意味着很长一段时间内你前同事和我们顶多遭受阿蒙较低层次分身骚扰甚至没有。祂成神仪式要求是什么？伦纳德追问。帕列斯沉默一秒：在别人成神仪式上顶替祂位置。说到这里帕列斯自嘲般笑：阿蒙接下来重心肯定是成神仪式这将是我们最后一段安静时光。祂一旦成神肯定会来找你通过你对付那位愚者。我虽然能提前扔下你跑掉但也得担心祂有回收天使层次全部特性想法。尽快掌握那些稀有灵消化掉魔药成为半神执掌圣物获得黑夜眷顾吧。伦纳德表情一下变得凝重缓慢点头。他旋即找安静地方将一些必要情报通过祈祷告知愚者先生。……别人成神仪式？最近有希望成神似乎只有亚当……祂们两兄弟打起来就好了……最后安宁期啊……希望阿蒙留下来干扰我分身们不会太强希望能尽快找到乌黯魔狼踪迹希望多里安能答应那笔交易……克莱恩叹口气返回现实世界继续在黑暗中提着马灯前行。

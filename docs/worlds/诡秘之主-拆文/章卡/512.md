# 512 旅行家 第三十一章 吓唬

## 打开书
如果深入探究下去大概率会引出救赎蔷薇甚至一位潜藏红天使…刚才有好几次都是在悬崖边缘翩翩起舞啊…还好克制住冲动按捺下对青柠檬餐厅和电报局里诡异情况好奇心…克收回视线只觉太阳胸针都无法避免自己背后沁出一层冷汗。比起真实造物主降临这种事件未知未被引爆情况更加恐怖至少现在就忍不住去想象如果自己一脚踹开电报局大门或者绕到后面翻窗进入究竟会看到什么发生什么。不断脑补着各种诡异可怕场景把自己吓得不轻。同时决定等下制作太阳圣水给昨晚在班西港吃过东西乘客避免有隐患残留。「怎么了？」艾尔兰察觉到格尔曼异常。「想起了一件往事。」用小丑能力让脸部表情依旧正常内心则庆幸昨晚没有冒险现在也顺利离开班西港。对于这里潜藏救赎蔷薇和天使之王秘密他只有一个想法：赶紧举报！不举报难道留着他们过1351年新年？如果选择隐瞒等到自身有足够高序列和足够强实力再来探索收获相应好处那中间要是发生什么事情危险被提前引爆或者邪教徒依旧残存害死一位又一位无辜旅客觉得自己肯定会非常内疚背上沉重包袱这样一来距离失控也就很近了。当然举报也要讲方式和方法没傻到直接告诉艾尔兰或写匿名信给风暴教会这会引来很多很多麻烦首先官方肯定会强势调查格尔曼背景不少事情只要深入探究必然会被拆穿其次也许会将目前这个身份暴露给救赎蔷薇引来一位天使之王追杀。打算过两天塔罗会召开时候用世界提一下班西港异常由愚者轻描淡写引出救赎蔷薇和天使之王作为风暴教会相关人士倒吊人自然明白接下来该怎么做。这将是他立功机会！至于梅迪奇家族直系后裔血液问题压根儿没去考虑因为他和莎伦小姐都没解救地下遗迹内那个恶灵想法。见格尔曼明显不愿意提往事艾尔兰笑一声掏出个黑色小木盒丢过去。伸手接住用眼神表达疑惑。「鱼人的鳔可以拿去制作物品在海上很有用。」鱼人身上非凡材料…150镑朝上…船长很慷慨啊…险些忘记格尔曼此时该有什么反应。还好在扮演上也颇有经验立刻沉下脸孔道：「我救你不是为了报酬。」艾尔兰哈哈一笑道：「我给你这东西也不是为了回报你搭救。我们算是朋友了吧？我看见朋友没有类似物品帮他补足短板不是很正常吗？」说得好有道理完全无法反驳…握着黑色小木盒沉默几秒终于点下头。艾尔兰捂嘴打个哈欠取下头顶船形帽道：「我得回房间补充一下睡眠了中午见。」礼貌挥手领着达尼兹一路走到312房间外面。看见堂娜和丹顿两姐弟已早早起床等在门口。「斯帕罗叔叔你手里拿着是什么？」堂娜好奇问一句。没有说话直接打开黑色小木盒盖子。里面铺着一层黑色天鹅绒中间静静摆放着一个圆形宝石般透明物品蔚蓝如水光华一层层荡开。「那天的鱼人的…」丹顿想一阵重重说「鳔！」此时在眼神示意下达尼兹打开房门。堂娜边脚步轻快入内边伸出背在身后手。握着厚厚一叠现金有10镑和5镑两种。「我爸爸妈妈以及克里维斯叔叔他们还有迪默多叔叔一家让我转交给你的150镑！」堂娜甜甜一笑道「他们说这不足以表达他们感谢只是补充一下你消耗掉物资额…那些东西很贵吧？」「还好。」想了想收下150镑感谢金免得乌尔迪等普通人内心忐忑不安。见格尔曼叔叔将现金和黑色小木盒同时塞入衣兜堂娜为终于完成父母交待任务松口气。迅速进入状态找回前来拜访真实心情又好奇又有点害怕问道：「斯帕罗叔叔昨晚那些都是什么怪物啊？鬼故事都是真的吗？你从火焰里跳出来和让光落下本事是天生的吗？这是魔法还是巫术？」停停停你问题太多了…热得受不了摘下太阳胸针丢到客厅书桌并随口回答：「这叫非凡能力通过一些仪式和魔药获得。很多鬼故事都有原型昨晚怪物是依靠邪恶仪式制造出来的。其他事情你问他。」侧头瞄眼达尼兹。「好神奇啊…」丹顿和堂娜同时感慨。紧接着堂娜眼睛发亮开口：「斯帕罗叔叔你就和罗塞尔大帝描述超人一样！我们我们也可以通过仪式和魔药成为你这样人吗？」丹顿重重点头附和姐姐话语两人同时涌起强烈期待。就这时堂娜发现格尔曼叔叔眼神里隐约多了点黯然。旋即看见这位神奇叔叔嘴角咧开往上翘起露出一个有些奇怪笑容。嗓音低沉说：「这不是一件值得羡慕和期待事情。只要选择了这条路就将时刻与危险和疯狂为伴。你可以赢它们一百次一千次但只要输掉一次就会像那个堕落主教一样。」说话间靠好手杖脱掉礼服挽起衬衣袖子。一条手臂已变得干瘪发皱仿佛过了百岁老人另外一条则透明无色能直接看到皮肤下血管肌肉和腱膜。与此同时脸上长出密密麻麻淡色肉芽吓得堂娜和丹顿惊恐失措连续倒退撞在门上。满脸细小肉芽保持嘴角上翘道：「看清楚了吗？这就是疯狂。」不…堂娜和丹顿几乎失去理智跌跌撞撞开门跑出去。前冲几步后难以保持平衡摔倒在地。「好可怕好可怕…」丹顿不断小声哭喊。这时听到312房间大门哐当合拢声音。堂娜逐渐平静下来不敢想又忍不住去想格尔曼叔叔刚才样子：一粒又一粒肉芽占领脸部每一寸皮肤双臂或发皱或透明不比昨晚那些怪物好看多少。不知为什么想起对方眼睛想起那一句这就是疯狂。视线突然模糊眼泪止不住下落。「堂娜堂娜你怎么了？」丹顿被她反应吓到忘记自己也很害怕。堂娜抽泣说：「我不知道…我只是我只是忽然觉得好好难过。」312房间内。达尼兹看见克已恢复正常样子忍不住啧一声：「其实没必要这样吓小孩子会让他们做噩梦直接告诉他们服食魔药很危险就行了。」话音刚落就看见一根满是血迹和污痕硬木手杖飞过来并伴随一句没有情绪起伏话语：「洗干净。」伸手接住笑容僵在脸上。……贝克兰德皇后区霍尔伯爵家豪华别墅内。奥黛丽站在二楼白色镶金栏杆后看着一楼仆人来来往往忙忙碌碌。根据鲁恩王国习俗有封地贵族会在新年舞会一周后陆续离开贝克兰德返回自己领地享受愉快乡村或城堡生活等到六月份才重新来首都开启日复一日社交当然霍尔伯爵这种实权贵族兼大银行家肯定得时常往返两地处理事务。而搬家并不是一件轻松事情许多东西得提前整理由部分仆人预先带回庄园或城堡一切准备就绪后主人们才会踏上路程。等这次塔罗聚会结束我应该就坐上回东切斯特郡蒸汽专列了…希望那位吸血鬼先生真的可以弄到长者之树果实和镜龙血液让我能在离开贝克兰德前成为心理医生…思绪发散想着。就这时伯爵夫人凯特琳走过来微笑问：「在想什么？嗯…你已经成年等六月份回到贝克兰德就可以找些事情做了有什么计划吗？」几乎没做思考直接回答：「妈妈我想去教会慈善组织。」我想真正认识一下这个世界…心里默默补一句。「不错主意。」伯爵夫人表示赞同。随即叮嘱几句走下二楼检查起家里事务。奥黛丽收敛心情侧过脑袋浅笑着对蹲在一旁金毛大狗道：「苏茜期待吗？你又能尽情奔跑在碧绿田野上追逐于葱郁树林内了。」这是在打趣苏茜因为对方并不是一只合格猎犬所以才成为赠品。苏茜本能想吐出舌头但又淑女制止这种行为。没有掩饰情绪回答：「当然我喜欢奔跑但我讨厌那群野蛮家伙。」这是指爸爸他们养那些猎狐犬？抿住嘴巴不让笑意流泻。抬头看眼壁钟发现塔罗聚会时间快到了。

## 这场戏有没有翻
翻了。脑补吓人；章末奥黛丽待塔罗。翻的是「这就是疯狂」吓退姐弟，不是科普收徒。

# 513 旅行家 第三十二章 古神的传说

## 打开书
漫无边际灰雾之上宏伟宫殿静静屹立。又一次来到这里月亮埃姆林刚恢复视线就看见对面正义小姐望向斑驳长桌最上首语气轻快打招呼：「下午好愚者先生~」正义奥黛丽依次问好从愚者起至世界终。这顺序并非根据座位排列而来依循于塔罗牌规律愚者是包含所有可能开始世界是完美升华结尾。这是神秘学爱好者奥黛丽小姐一点强迫症在塔罗会成员越来越多越来越整齐后出现。真是一个出身良好无忧无虑女孩…埃姆林故作深沉评判一句礼貌回应对方问好。这过程中眼角余光扫到旁边太阳不由想起最近几天在威曼迪男爵家里学习血族详细历史经历。确实有很多不知道细节专业研究者和业余爱好者果然还是有区别但从这周开始我埃姆林就将是专业研究者…威曼迪男爵一直没提白银城有关事情也不能直接问作为背负隐秘血族救主在类似方面必须足够谨慎…半天听课半天去教堂晚上陪伴人偶这样生活似乎还不错…思绪渐渐发散开来。突然皱下眉头发现一个很重要问题：「我为什么还是每天都去丰收教堂？」嗯作为一名高贵血族做事必须有开始有结束最近又多了不少病人哎名声传扬出去并不是一件好事…眉头逐渐舒展变得柔和。见正义小姐已完成问候伸手敲下桌子望着对方道：「你需要的…」正义右手下压做了个停止手势接着浅笑说：「等交易环节再讲。这是属于愚者先生阅读时光。」听吸血鬼先生语气长者之树果实和镜龙血液至少有一种了…奥黛丽你就快成心理医生了！就快是中序列非凡者了！心情愈发愉快眉梢眼角皆是笑意。看向浓雾中身影尾音上扬说：「尊敬愚者先生我又拿到了三页罗塞尔日记~」只差四页了…抿嘴想着。有了正义小姐做示范魔术师佛尔思也开口：「愚者先生我这里也有三页新罗塞尔日记。」她对这次塔罗聚会同样充满期待因为第二份学徒魔药消化进度比预计快不少前天已彻底解决掉这隐患。太阳戴里克紧随其后：「伟大愚者先生我抄录了一些古神传说。」接着又对倒吊人道：「周围区域怪物清单也整理好了。」真是一个实在孩子啊不需要别人提醒…收获颇丰克悠然感慨。真是的一点进步都没有…虽然这会让我获取好处难度降低但也潜藏失去白银城资源风险…暴露是一个必须时刻警惕问题…倒吊人阿尔杰微不可见摇摇头。罗塞尔日记和古神传说很快具现出来闪现至克掌心。飞快浏览一遍发现六页日记里有两页是以前重复比如正义小姐贡献其中一张就和倒吊人去年提交一份吻合。这是无法避免事情除非我能让他们真正学会简体中文…暗叹一声用意念将那两页日记转移到最后。剩余四页日记并没记载太有价值信息它们大部分属于罗塞尔失去理想沉迷于金钱时期通篇充斥着我今天发明了什么我明天准备发明什么卖出了多少金币得到了多少投资等句子看得差点控制不住表情只想一巴掌把这些日记呼到罗塞尔脸上。而这时正义也敏锐发现那张黑皇帝牌回来了静静覆盖于愚者先生手侧。果然是赐予眷者帮助他完成任务吗？唔还有另外一个可能这是新亵渎之牌不是原来那张！奥黛丽饶有兴致猜测着。翻完日记忍住吸一口气平复心情冲动将目光投向小太阳提供古神传说。这属于比较粗略讲述将第二纪元那八位古神分为三个阵营巨人王奥尔米尔精灵王苏尼亚索列姆和吸血鬼始祖莉莉丝是盟友对抗着空想之龙安格尔威德不死鸟始祖格蕾嘉莉异种王克瓦希图恩而恶魔君王法布提和毁灭魔狼弗雷格拉属于想要颠覆一切秩序污染所有生灵存在。在白银城记载里八位古神都有暴虐邪恶残忍恐怖等描述即使外形最正常被称为美之化身吸血鬼始祖莉莉丝也有恶心狰狞一面比如化作一个堪称山脉肉团上面长满各种各样生殖器官并喷薄出浓郁黑雾不断制造各种奇异生物凡是靠近祂强者都会被交配和繁殖欲望支配成为行走相应器官。而看到这一幕生灵除了另外古神无一例外失去理智或当场变异或成为疯子白银城记载则源于巨人王庭典籍当然这是他们自称。不排除是对盟友诋毁…这种表现和血族祈祷原始月亮后失控相当接近…这是月亮途径走到最后特征之一？想到这里差点抬起脑袋扫埃姆林一眼。在白银城传说里吸血鬼始祖莉莉丝确实执掌着红月只要祂愿意祂可以让一年三百六十五天天天都是血月让阴性力量肆掠大地让灵界与现实长期交互放出无数难言喻怪物和恶灵。这就是神灵力量啊…也不知道古神和现在真神存不存在区别怎么都是一副邪神样子…在血族传说里莉莉丝并不是这样他们和白银城之间有一方在撒谎？或者中间出现了一定变化莉莉丝从白银城记载里样子变成了血族传说中样子？收回视线记下这些细节。让手中纸张消失往后微靠道：「你们可以开始了。」正义当即开口目光明亮望着埃姆林道：「月亮先生有长者之树果实和镜龙血液情报了吗？」埃姆林下巴轻点道：「一共750镑。只要付出这么一笔钱它们就将属于你。当然还有我报酬100镑。」奥黛丽根本没去算总价多少欣喜回应：「成交！我希望今天或者明天就能完成交易。」「没问题。」即将赚100镑月亮无法拒绝正义小姐要求。太棒了！右手垂下握成拳头轻晃两下。这时倒吊人侧头望了吸血鬼先生一眼：「那位血族男爵遗产你还要吗？4500镑这是我为你争取到最好价格。」实际上那位海盗3200镑就愿意脱手。埃姆林表情顿时变得有些扭曲。如果只有1000镑我肯定要但…心里回应一句。虽然他们一家都是相当不错药师和医生每年收入并不算少且活得足够久理应能攒下一笔不菲财富但自从迷上人偶就再也存不住钱偶尔还会主动订制。即使算上还未收获100镑酬劳个人存款也还不到500镑这里面夏洛克大侦探贡献了150镑。「我我再考虑一下。」艰难开口突然觉得自己该找一些能快速攒钱办法。埃姆林这家伙发出了贫穷声音…看到这一幕克在心里愉快调侃一句。现实里和吸血鬼先生是朋友听对方提过历年以来花在人偶上钱总计超过7000镑这让颇为感叹人偶昂贵和埃姆林奢侈。「没问题。」倒吊人并未催促。转而望向正义：「尊贵小姐工匠已经完成制作得到了一件相当神奇物品。它能让你真实地变化样子并掌握操纵火焰伤害转移和危险直觉三种非凡能力提升你平衡和敏捷它是一张银白色面具也是帽子耳饰它能变化自己外形你可以为它命名。当然它也有自己小小缺陷当你佩戴它时候你情绪会被放大你必须懂得控制自己否则很容易出问题。它价格是5500镑。」说到这里倒吊人轻笑一声对世界道：「你提供非凡特性4500镑工匠制作价值1000镑。」4500镑比预想得好很多虽然要分15%也就是675镑给倒吊人先生…当即操纵世界点头同意：「没问题。」情绪会被放大？根据伊思兰特老师说法等我晋升为心理医生就有影响别人情绪和心理状态能力对自己应该也可以…嗯那个缺陷不是问题！正义轻巧点头：「我会在收到那件神奇物品后两天内支付。」为了不暴露塔罗会秘密她必须等确切拿到东西才能找父亲霍尔伯爵报销。「可以。」倒吊人对正义小姐信誉没有丝毫担心。真有钱…月亮和魔术师同时受到刺激。呼…克悄然松口气这意味着他三千多镑很快就能拿到。感谢正义小姐！默默在心里画了个绯红之月。

# 1310 倒吊人 第四十五章 新的任务

## 打开书
埃姆林隐约感觉到大地和月亮两条非凡途径可能存在一些异常但没有当面向洛雷托大主教提出这个问题。他看起来不会回答……还是等下次塔罗聚会请教世界倒吊人他们……他没考虑寻求愚者先生解答是觉得相应问题也不会太大没那个必要……同时刚才猜测也让埃姆林联想到原始月亮……祂对月亮途径有着明显影响力曾经让不少向祂祈祷血族当场失控变成只知道交配和生殖怪物。埃姆林怀疑这就是给予假神启假神谕邪恶存在之一。……这就是需要特别注意问题。另外宗座希望你能在贝克兰德组建起三到五支以血族为核心非凡小队。……黑夜教会和风暴教会没有意见吗？……这正是他们要求。……随着蒸汽教会绝大部分势力退出鲁恩官方非凡者相当紧缺。……所以希望我们能提供一定帮助。这对我们在鲁恩传教有不小好处不过你要记住在这里我们必须足够克制不能大肆传教和残存蒸汽教会处于同一水准就行了……好。……苏尼亚海慷慨之城拜亚姆。……这都是愚者先生信徒得慢慢引导他们融入罗思德群岛这个整体……暂时可以先不惊扰那些畸形者让白银城居民带长相还算正常部分月城人多来拜亚姆……阿尔杰认真思索着接下来该做事情。初步安置好白银城和月城居民后他其实已经完成愚者先生给予任务但他认为自己距离换取海神相关身份权柄和位格还有很远所以尽心尽力处理起大迁徙遗留各种问题。坦白讲阿尔杰现在最担心就是愚者先生不给自己事情做那样一来他不知道什么时候才能攒够功勋。……白银城有两件0级封印物一位序列3圣者三位序列4圣者……月城有三位半神……阿尔杰越想越是心惊发现……不知不觉间愚者先生势力已经发展到堪比正神教会程度……如果不是我亲身经历这些变化肯定不会相信。阿尔杰在心中感叹一声愈发热切想要为愚者先生做点事情以便尽早攒够化身海神需要贡献。……随即他看到位于雾气中央古老宫殿和模糊人影听见来自愚者先生话语：一个任务监控一个叫做维尔杜·加西亚的人。……谨遵您意志。阿尔杰不惊反喜恭敬低头回应道。……而他很早就清楚那位叫做维尔杜的人渴望拯救门先生让这位天使之王能回归现实世界。克莱恩之所以会让魔术师小姐将帮助门先生脱困其中一个仪式告知亚伯拉罕家族人是因为双方信任度还不够……所以克莱恩认为给出其中那个非常难完成仪式可以有效取信亚伯拉罕家族成员让他们更进一步信仰愚者先生变得越来越虔诚然后他就可以通过这些虔诚者监控表现出激进一面人掌握他们轨迹及时进行干预。

## 这场戏有没有翻
翻了。开头埃姆林忍问＋组小队；切阿尔杰迁徙善后怕无事；章末愚者派监控维尔杜。翻的是新任务＝海神攒功＋门线暗控。

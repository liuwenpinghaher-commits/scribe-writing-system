# 1306 倒吊人 第四十一章 见面

## 打开书
原始岛屿中部黑皇帝陵寝内。送走贝尔纳黛罗塞尔没有立刻进入沉眠他缓慢抬起头又一次望向无穷高处。灰雾之上克莱恩无声叹口气放下星之杖摄来一张纸人随手抖一下。啪声音里那纸人急速变厚膨胀开来并飞入愚者座椅旁由虚幻神秘符号组成半透明漩涡。——虽然贝尔纳黛已被移到原始岛屿边缘克莱恩无法再通过代表她祈祷光点看见黑皇帝陵寝内部情况但他可以借助已经融入罗塞尔身影那个愚者符号在一定程度上维持住和大帝联系。纸人穿透那缓缓旋转漩涡后降临到光源不知从何而来显得颇为黯淡陵寝内部于中央高台前变成一个人类。这个人类黑发棕瞳与格尔曼·斯帕罗有几分相像但轮廓不够刚硬线条不够深刻气质不够冷峻五官也存在一定区别下巴和肚子上还多了点社会催生少量肥肉正是克莱恩原本周明瑞形象……你来了。我来了。克莱恩微不可见点点头。你不该来。罗塞尔叹息一声道。我已经来了。克莱恩很自然就接住这个梗。……本来打算问问你是哪里人看需不需要做地域歧视但想了想又没这个必要都是不属于这个年代没有故乡可怜虫。……你知道末日真相了？知道了。克莱恩轻轻颔首道。……你知道这里就是地球了？嗯。克莱恩坦然回答道。……你竟然这么早就知道了我直到前往月亮之上从高处看见这个星球真实模样才敢最终确认。……月亮之上是那样诡异我明明感觉到恐怖却一点也没有去想自己是否会被污染然后越来越偏激越来越极端。不过我偶尔还是会从周围人看法里获得一定清醒但我不敢在那个状态下写日记害怕泄露秘密失去最后机会。我最终决定利用之前各种铺垫转到黑皇帝途径上除因为末日来临只有序列0才有可能保护住想保护人带着他们躲去浩瀚宇宙其他星球利用相应权柄于荒芜死寂地方重建起可供人类生存……只要我能在成为序列0黑皇帝并半疯之后被真正杀死那我就有机会在陵寝内或星界中复活那个时候回归我将是纯净唯一性和三份序列1非凡特性不再有丝毫污染不再蕴藏无法遏制疯狂。说起来当时永恒烈阳蒸汽与机械之神也算在某种程度上被我利用。可是旧日恐怖超越想象伴随我复活还有重获新生污染……也许只有旧日才能对抗旧日。我只好中止复活进程以现在这种状态苟活于最后这座陵寝内不让那个旧日借助我身体出生于现实世界那会带来毁灭性灾难。……污染你外神叫堕落母神祂以原始月亮这个化身蛊惑不少信徒。……我知道原始月亮但不清楚祂真实尊名是堕落母神。现在想一想我能发现门先生在求助也许不是偶然……我前半生最大问题就是太过自信总有种随时可以读档重来感觉对很多细节审视不够。当初格林被这座岛屿上奇异力量污染死后回到这里重获新生这不就是来自原始月亮影响吗？我之后做完各种检查进行相应净化就觉得自己没有问题了可实际上命运也许早就在那一刻……这不能怪门先生祂状态也许比现在我还要糟糕。大帝意思是从他发现这座原始岛屿开始他就被堕落母神盯上？克莱恩叹口气：那个时候谁又能想到问题会如此严重？……是啊。罗塞尔似乎很欣慰自己犯下是几乎所有人都会犯错。……那个古老隐秘组织里也几乎不提旧日外神们事情。……你应该看过我日记清楚那古老隐秘组织是一个代指。……我知道它指哪个组织没想到你有序列0位格还不敢提祂组织名称。我总觉得祂不简单对外神可能有着我们无法想象了解所以还是谨慎一点比较好毕竟我现在不算完整序列0真神。罗塞尔简单说一句后他隐约可见眉头突然皱起你看过我多少日记？如果气氛不是那么压抑和悲凉克莱恩此时肯定会忍不住回一句魔女滋味还真不错以此调侃罗塞尔这位老乡。……很多。我还搜集到几张亵渎之牌。哪几张？罗塞尔脱口问道。……黑皇帝暴君红祭司和愚者。呼……罗塞尔吐口气隐约可见紧皱眉头松开来还好不是魔女牌月亮牌和母亲牌。……都是看过直播应该很清楚这是一件多么正常事情……你是哪条途径非凡者？占卜家。克莱恩言简意赅回答道。……可惜啊如果大家都处在正常状态下这个时候就应该由你从历史孔隙内弄一台大屏幕电视一台游戏机出来大家边玩边聊这才是男人浪漫啊。……希望有这么一天。……我很好奇为什么你制作亵渎之牌能让神灵都无法找到？这种程度反占卜反预言让人惊叹。……因为知识可以带来力量力量也可以赋予知识这就是知识皇帝权柄。我将二十二条途径魔药配方都附着上力量后它们自然就产生非凡特性间聚合之力并有某种程度上反占卜反预言效果。然后再以……制作亵渎之牌是在我举行黑皇帝仪式之前一年那个时候我已经遭遇原始月亮污染而自身在大部分时候都没有相应认知。这二十二张牌为什么能让神灵都无法找到呢？……不要集齐二十二张牌！小心母亲牌！这两句话回荡于深沉黑皇帝陵寝内部久久没有平息。

# 1318 倒吊人 第五十三章 “保命咒语”

## 打开书
见奥黛丽愿意试着调查德尔劳轻轻颔首道：详细资料之后会给你但我必须提醒你一句这件事情相当危险绝对不能大意。说到这里德尔劳停顿一下道：如果遭遇意外依靠自身无法解决你可以试着说出一个名字这会让你得到拯救。什么名字？奥黛丽心中有所猜测问道。……它来自第三纪那位造物主圣典涉及心灵领域最高奥秘与我们心理炼金会某件事物有密切关系。它是亚当。……作为评议团一名委员你理应执掌一件1级封印物但你和暴怒才刚步入这个行列还需要一段时间考察而且贝克兰德区域前任委员赫温·兰比斯弄丢一件相当重要封印物我们正在考虑是否改换封印物使用方式……也就是说所有封印物都保管在这座心灵城市内你们平时并不占有必需遭遇事件做出申请才能短暂使用。……这种方式有一个很严重缺陷那就是我们无法应对意外……我认为当前这种方式已经足够好每人执掌一件1级封印物用来应对意外等到有需要时再申请别物品。……以前确实是这样更好但现在你们不用担心了。只要你们在意外中还有反抗机会那你们就能直接进入这座心灵城市躲避敌人顺便申领物品。若是没有机会就像我刚才说那样念出亚当这个名字。……你说两次亚当那位很可能已经在注视这里不祂也许从最开始就已经在注视这里……奥黛丽听得心跳都差点加快一些。那我们该怎么进入这里呢没得到你邀请情况下？……从这次评议团会议开始你们可以将属于自己人格面具带出这座城市。无论你们身在哪里只要周围有至少两名人类嗯除开你们自己就能通过戴上相应人格面具进入这座城市。而这七张人格面具本身是虚幻与你们某些认知密切相连不需要用特别方式保存只要你们想随时可以从周围集体潜意识大海里将它拿出。……将人格面具带出这座城市是否会对我们精神状态和真实人格产生负面影响？会有一点需要注意但我想你们都是心灵领域专家有足够能力解决这方面问题。……1级封印物两种保管方式我都能接受我会耐心地等待考察期结束。小姐你一点也不傲慢。一副睡着模样懒惰小姐笑着评价一句。……康斯顿区域最近不够平静连续发生多件近乎奇迹事情：一是康斯顿城一夜完成重建；二是贝尔丹城市民同时丢失一段时间记忆；三是有以实现别人愿望为乐强大魔法师在间海东岸流浪叫做梅林·赫尔墨斯与此相关还有一件叫做全自动许愿机物品。除这些我还察觉到一点异常——康斯顿城不少老鼠蟑螂乌鸦失去自己心灵在城市奇迹般恢复后几天内。……好了这次评议团会议就到这里结束。……会长先生这座城市有名字吗？有。德尔劳笑着说道伊甸园。……这里有很多教堂应该象征着信仰本身呃不知道这里居民都信仰哪位存在？全知全能造物主。……伊甸园……全知全能造物主……这不是亚当弄我把名字倒过来写！灰雾之上古老宫殿内部克莱恩看着代表正义小姐那颗深红星辰无声自语几句。而且遇到危险时念出亚当这个名字对策几乎不加掩饰地说明问题。——自正义小姐进入伊甸园源堡提供真实视野就受到压制……基本前提是：亚当已借助之前全面战争晋升序列0成为真神可以被称为空想家了。……祂真正目标是那条心灵巨龙还是正义小姐背后我？……对了德尔劳这位心理炼金会会长说过于观众而言死亡只代表一个身份终结……综合起来是否可以认为观众途径到序列3或者序列2就能分离出自己曾经拥有一些身份让他们变成活生生的人而这些身份就算死去也不会导致本体陨落？……嗯赫密斯将自己被诅咒后变成兔子作为一个身份分离出来直接参与心理炼金会？……而这个时候正义奥黛丽已乘坐来时马车驶出伊甸园回到皇后区那个有人工湖公园内。她没急着向愚者先生祷告希望能有更好办法封印傲慢面具她什么事情都没发生一样回到自家那栋豪华别墅内。

## 这场戏有没有翻
翻了。开头保命名亚当；封物集中申领；面具可外带入城；暴食报康斯顿奇迹；章末城名伊甸园＋克莱恩倒写亚当＋奥若无其事回家。翻的是保命咒＝亚当真神在场证明。

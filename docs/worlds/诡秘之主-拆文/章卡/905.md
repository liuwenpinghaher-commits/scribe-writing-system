# 905 不死者 第一百七十四章 伦纳德的提醒

## 打开书
贝克兰德北区红月被云遮，平斯特街7号信报箱在明暗交界。投递口涌出报纸账单来信，无形托着钻门缝：报纸自翻至末版落椅叠放；账单铺茶几；信有封脱封、无封自开。部分上书房架，部分冲向剪刀四分五裂排入马桶冲走。屋复静如无人。东拜朗古拉因城，伦纳德住所，帕列斯苍老嗓音：有重要的信。能往7号寄重要信不顾有人无人的：克莱恩与道恩。老头隔海读信——伦纳德猜分时之虫寄生昔日所抓幽灵当北大陆眼耳口。信：道恩途经狂暴海中程岛发现因斯踪迹。伦纳德沙哑：他果然没忘复仇；我能做点什么？帕列斯严：你才序列6，因斯不掌0-08你也无资格；部分显神话形态即可让你失控疯——成功复仇概率0，神性质变。又笑：你比以前认清自己，懂问能做什么。目下：给克莱恩情报，等回信再配合。勿急告知教会——0-08喜害死拥有者更不愿回封印，教会追捕它即知并安排；须提示克莱恩。伦纳德：你对0-08很熟。帕列斯：第四纪造成过天使陨落；知它则它知你，越了解越可能成故事一员。伦纳德自拟侧面提示：暂不把行踪转教会；写「你知道了它，它也就知道了你」不提0-08用人称。帕列斯：人得有压力才成长。召格尔曼信使发信。中程岛客轮一等舱，克莱恩就烛读回信：暂不告知教会——红手套为复仇却不报=有理由；「你知道了它，它也就知道了你」眼熟如黄昏隐士会凡有言必被知→疑0-08观众途径。庆幸没开口请蕾妮特出手。未准备好则谋划易被0-08察觉造巧合。能加快的只有消化秘偶大师——短时间弄两个秘偶；南大陆可把上绞刑架恶棍先转化，要求降至懂都坦语共享感官即可。古拉因码头登岸：离开时得有两个秘偶；先甩掉军方跟随者——乔装再好，无面人眼中如黑夜萤火虫。

## 这场戏有没有翻
翻了。开头信报箱自行消化邮件还像空屋把戏；章末伦纳德改「不急报教会」并点出知即被知，克莱恩落地南大陆、秘偶指标降到都坦语。翻的是复仇还能不能正向教会倾倒、主角下一刀先砍谁，不是马桶冲信滑稽。

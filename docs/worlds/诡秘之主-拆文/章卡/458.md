# 458 无面人 第二百四十六章 错过

## 打开书
埃想：一直有祷愚脱暗示冲动——诵不明尊名险如鲨闻血；今始祖何意？荒谬：「非常非常非常危险。」棺尼拜斯苍：「正常是。但隐存亦有守规喜交易如灵界七净光。始祖启示＝愚险或不严重甚至无。我旁护。不想脱暗示？已成大地母神信徒背月？」「没有！」咬牙：「望几天考虑。」「好；信你做合高贵选。」送二楼后卡再入不解：「启示怎有埃？刚成年弱血。」棺嗡：「启示从无埃姆林怀特。只展末降临红月侵蚀＋愚尊名。无关血出；关键＝我为说服虚。但为血未来冒险亦称关键。」「为何选他？」「他一直嚷祷愚；怨我等不重视不愿敌乌特想另寻助——今满愿。」卡久无语。埃栏俯忐喝「酒」自宽：未闻祷愚惨；或如七净光守序热心？七净光啥？或能脱暗示…切周一上午明斯克：克蹲马桶刷污——预定休整明交王子；屋脏想起：雇萨默尔女仆周两清；一家迪西度假女仆随／回乡——久未扫。本忍两天即离；闲不敢克拉格恐怒王子——换旧衣新年大扫除刷洗拖浆8–11点随便弄。租太大…净手擦脸；阳光金斑成就愉——午奖好餐厅。翻报候——门铃。拒新委托仅34镑须南度假。出＝王子老管燕尾：「殿下街口马车等；望知进度。」心急也好省跑庄。重组说辞「好。」取帽——肚剧痛蹲厕！忍不住歉：「先盥洗肚不适。」「你的自由。」畅解残渣洗手回——管已无；棕卷侍女外：「殿下抱歉另事无法久等；请明／后下红蔷薇。」＜10分已尽快…「无问题。」侍卸负轻笑：「您又和那位小姐错过了。」「啊？」「她这次随殿下；她提议绕访您。」因肚痛错过？不对劲…切厚软毯房：羽笔停；笔记涂抹行：目标试脱控憾侦下楼前已离；目标影响侍女被管芬克尔偶发现处理；目标再脱轨代葬塔利姆却识不出夏洛克可怜错过；侦访庄时机错目标恰高尔夫；目标再胜安排怂恿访侦可惜肚疼盥洗7分45秒王子无法等。瞎一眼中年放笔望侧女：「她身放何？屡冲限大问题。」女低笑：「意外；勿忧。」挽发露颈慢涂脸愈艳；穿衣饰。暗金中年皱：「去哪？」「小心你羽笔；上次差点与人换身。」「不用提。」深蓝近黑板脸。女收带纤伸懒哈欠：「访极光会A先生。望如传闻疯。」语间瞎眼男沉——普羽笔自书如无形手持！

# 415 无面人 第二百零三章 正正得负

## 打开书
喀嚓——艾背凹陷；克脊椎隐痛。扑通跌地似失知觉。卡斯茫然喘冷汗无后续——情绪噩梦醒力气尽；摇晃将软。克眯两步半蹲搀——艾痛喊：「快逃！不要管我！」瞬重伤＋失力难拖；外逃会合官方；难抬右手欲示警；喇叭电报机飞墙边。克犹豫——天花黏黑液流凝漆黑身影帘裹唯冷酷蓝眼！见之生灵最强情绪欲望：惧怒贪嫉饿色…使徒不浪费局面入起居。三组：卡斯虚脱；艾脊椎重创；唯克完好——但神奇物在雾；对面序5！嘴角微翘——右抹艾背伤诡异移侧肋！魔术师伤害转移：本伤移一次化重为轻；不可移他人物！见伤已策：假无法诱使徒现身→转移仅肋折轻伤→艾本能同步对使徒→缠至官方！几乎同刻艾戒绿意光华复原——肋折治愈！痛苦真束手假！与克治疗重叠。使徒眼睁大身顿——未纠缠转身奔窗；身垮黏黑液渗地墙瞬消！克响指空气弹出窗火星——使徒已彻消。跑真快…还恶魔？麻烦大…转头——艾翻身起；两人同问：「你会治疗？」对视艾苦笑：「想不到预设陷阱让他逃。」戒微光确认已远。解：下午无机会拟治疗；后故意夸张包扎左臂垫高设陷诱现身；果用上——未料你也能处理重伤…结果双方优先治疗无人纠缠＝正正得负！克无奈：「不够了解配合欠默契。」艾诚：「见你不逃反帮应推你有底气有办法；戴戒大脑高负荷难额外思。」2-081被动降智！克：「非问责时；逃了后续怎办。」摘戒：「官方快到；我外安抚斯等商量；你跟我或先做己事？」值夜机械心军方——勿熟人；灵无警；给机会收拾敏感物！问使徒定位何处——「你卧室桌前。」嚣张！「我去检查痕迹；掌握真貌追捕简；其余麻烦你。」艾搀卡斯。克滑稽：准备陷阱仍未拖——意外总比准备多；魔术师只序7。奔二楼卧——布置未变椅距同；恍见黑液影坐待时机。「冷血者」…凸窗或占卜映照；擅犯罪难留痕——雾上试。烧随手神秘笔记。未久陌生人上二楼；首刚硬脸蓬松倔褐发；手奇异古银镜两侧黑宝「眼」。「蒸汽教会伊康瑟·伯纳德；可检查？」「无问题。」「需我旁答？」「好；斯坦顿提过你情况。」队员态度无视好奇敌意。编何故事？跟入卧。「使徒坐过？」「是。」抚镜三：「尊敬的阿罗德斯，我的问题是，之前坐在这里的恶魔长什么样子？」灯深邃雨氤；镜水光汇：黑液人坐椅背窗面床；改穿衣镜映侧脸漆黑遮——颧骨高冷酷蓝眼。

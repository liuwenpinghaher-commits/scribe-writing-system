# 1327 倒吊人 第六十二章 台下功夫

## 打开书
创建秘偶城镇前期准备是相当枯燥和繁琐至少克莱恩是这么认为。偌大一个古老宫殿内克莱恩一边坐在属于愚者那张高背椅上拿着吸水钢笔就着普通纸张为每个秘偶编写姓名年龄和命运一边让一条条灵之虫钻出身体于旁边重组为一个又一个分身。这些克莱恩有席地而坐有占据愚者之外二十一张座椅有具现出睡床靠躺上去……然后他们分别从杂物堆里招来不同书籍认真阅读起来。……这简直就像是在导演一部超大型电影而且编剧是我灯光师是我道具师是我化妆师是我所有演员也都是我……这个仪式弄下去我真是在失控边缘徘徊一不小心就会人格分裂堕入疯狂深渊……还好我有称职心理医生……嗯秘偶城镇运转中得注意一个问题：虽然我个人是有礼貌有修养绅士但一个城镇里大部分居民都是底层无论说话还是行为都会偏向粗俗……不能在扮演时端着突破不了心理障碍……克莱恩无声感叹中让周围分身崩解成一条条灵……当然这并不是全部还有一个克莱恩保持着刚才状态准备轮值源堡。下一秒钟克莱恩本体回到现实从历史孔隙里拿出蠕动饥饿戴上。然后他传送到一座位于狂暴海但明显偏离安全航道岛屿上。这是他之前就挑好舞台。……我希望这里有一座适合五千人生活城市。……霍然间这片开阔地带变得极为平整周围森林也一下后退很多提供大量树木石头和泥土。……这是属于黑夜女神教堂因为要符合这座城市背景设定。我希望这座岛屿有一个深水港。克莱恩没有停止向自己许下第二个愿望。……我希望港口和城镇有便利交通。克莱恩许下第三个愿望。……欣赏看空荡无人城市克莱恩按下头顶礼帽直接传送到市政广场旁边一步步走入那座被他命名为圣阿里安娜教堂。……亚楠。想了想这男子擦掉亚楠重新写个名字：乌托邦。……阿尔弗雷德已经登上返回北大陆客轮？奥黛丽没有掩饰自己惊喜。……而心理炼金会也没有催促——那之后到现在心理炼金会评议团会议总共召开三次主要是在交流各自研究成果和管辖区域内种种情报。对那条心灵巨龙线索只贪婪女士问过两次。坦白讲若非愚者先生提醒过奥黛丽要注意那只暴怒兔子和容易被遗忘会长她肯定会觉得评议团会议很有意思……对客轮已经离港。霍尔伯爵微笑点头道等阿尔弗雷德抵达贝克兰德完成必要社交我们就回东切斯特郡猎狐。……好的。……那来自一座灯塔。

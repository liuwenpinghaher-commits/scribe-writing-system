# 1223 逐光者 第七十四章 对末日的猜测

## 打开书
鲁恩贝克兰德还在酣睡佛尔思忽然从梦中惊醒下意识将目光投向窗外。类似经验她并不缺乏在成为塔罗会成员前她好几次因满月诅咒在半夜这样醒来但今天她没有感受到熟悉痛苦只是内心产生些莫名悸动。因为帘布封锁窗户佛尔思无法从微弱光芒判断现在究竟几点下意识翻身起床走到窗边刷地将一布一纱两层窗帘拉开。穿透淡薄雾气阳光一下照入房间驱散积攒黑暗佛尔思立在窗口望着高空脸上露出明显困惑：太阳已经升起红月早就落下为什么自己还会有满月诅咒来临前那种感受？而且距离满月还有不少天！……因蒂斯首都特里尔一位位早起天文学家一个个神秘学爱好者以及隐藏在普通人中非凡者都将目光投向高空。夜晚层云消散一空巨大而皎洁月亮将繁星光芒全部遮掩。这月亮颜色不再是常见绯红一片洁白明亮异常。所有目睹者都惊呆这是他们从未见过月亮。无论人类社会正常教科书还是神秘学相关书籍都没记载过类似现象！除常见缺月满月和偶发血月月亮从未出现这样变化至少第五纪以来这一千三百多年里绝对没有！这一刻目睹者们才认识到除绯红和血红两种状态月亮还有别颜色。……神弃之地白银城。由于正处闪电频率很高下午戴里克等人都注意到高空异常。他们习惯熟悉闪电和黑暗在那么短短几秒钟内完全消失没有一点残留占据半个天空血色圆光是那样明显那样巨大将所有事物都照得无比清晰。白银城居民里思维较为敏捷那些人一下就联想到通识教材内对月亮描述和相应图画心中瞬间闪过一些又愕然又迷茫念头：这难道就是月亮？绯红之月？我们竟然看到红月……很快他们眼前红月一寸寸褪去血色展现出皎洁清冷身姿。白银城居民们愈发茫然不清楚究竟发生什么事情。听倒吊人先生正义小姐等塔罗会成员讲过外界情况戴里克·伯格比他们更为错愕和惊讶因为这是神弃之地外也没有自然现象。几秒后月亮消失深沉黑暗重新淹没一切频繁闪电成为光照主要来源。刚才发生什么事情？你们有看见那团红色吗？月亮！那是月亮！那是绯红之月！这是不是我们快要摆脱当前处境征兆？我们对巨人王庭第二次探索会很顺利将打开通往外界门？疑惑迷茫之中绝大部分白银城居民都下意识将这个现象当成好事当成神秘学里好预兆只有首席科林·伊利亚特六人议事团长老洛薇雅等人一脸凝重眉头紧皱。……灰白雾气之上古老宫殿内部。大致弄清楚阿蒙欺诈手法克莱恩本能就将注意力转回这次收获隐秘上。相应内容他曾经有过一些猜测可真正揭开时却发现比自己想象得更加可怕更为夸张更令人绝望：能成功让星空注视到我说明阿蒙透露隐秘至少大部分是真实……在序列0上面真还有一个层次这应该就是远古太阳神所在位阶只是祂状态似乎不是太对惨遭背刺陨落分解。……按照阿蒙说法用造物主来描述这个层次不够准确祂是用序列之上来命名……也有存在用超越序列来形容那个位阶表示摆脱非凡途径限制？……神灵称呼这个位阶为旧日外神星空……从这里可以看出两件事情一是在这个世界外面广袤宇宙里在那无垠星空中有着旧日外神也就是造物主层次存在比如包容了月亮那位……褐星橘星等看来就是原本行星它们有了变化让罗塞尔大帝也无法认出……这是因为上面有旧日或者外神盘踞注视着我们这个世界？……旧日之盒旧日就来自被星空污染后异变啊……嗯旧日或外神大概率不止一位……祂们怎么都在这个星球周围？在窥视着什么？……祂们没有直接入侵是因为有力量暂时隔绝着内外？……这来自七神？……联系1368年末日来临预言看七神未必起到最关键作用祂们还未超越序列……等到1368年真正屏障消失旧日或外神们将不再受到阻隔然后世界末日就降临了？想到这里克莱恩脑海内忽然闪过以前积攒一些疑问：为什么黑夜女神要冒着挑起神战危险夺取死神途径唯一性？为什么七神会默许一位黑皇帝出现？为什么亚当阿蒙等天使之王在沉寂不知多少年后于当前时代走出幕后登上舞台？为什么第二纪古神们遗留会纷纷出现？为什么源堡内下放穿越者在前面四个纪元只有一位而第五纪才一千多年就有两位？呼不管本身是好是坏都在努力提升自己迎接末日啊……女神这么擅于布局存在选择这么冒险手段是在为超越序列成为旧日做准备？只有十几年了时间不等人啊……祂暗中扶持我也是抱着类似期待？亚当至少两次能直接解决我都没有动手除我和祂确实没什么太大仇怨也有这方面因素？克莱恩轻敲起斑驳长桌边缘低声自语一句：成为旧日或者外神关键是九大源质之一？环顾空空荡荡源堡一圈克莱恩叹口气在心里自语：具体是什么情况还得看过第二块亵渎石板才知道可惜不知什么时候才有机会……他旋即将注意力放到别事情上：远古太阳神不知有没有完整地超越序列……如果真有一位本土旧日诞生末日来临时人类至少还有那么一点希望……祂陨落比我想象得还要复杂啊……难怪罗塞尔大帝说必须序列0才能保存自身保护重视人……那些旧日或者外神不知道有没有渗透力量进来？嗯根据七位正神和真实造物主等邪神都敌视着原始月亮欲望母树来看祂们真身或许就是旧日或者外神……难怪欲望母树可以直接误导我在灰雾之上占卜是我认知里最危险存在！我明白那些旧日和外神聚集在这个世界周围是想得到什么了……祂们应该是想拿到九大源质毁灭世界只是顺便……想到这里克莱恩突然记起欲望母树借辛西娅之口说一句话：将军我想和你有个孩子。克莱恩顿时忍不住打个寒颤认真思考起返回现实世界后安全问题。他对星空已有一定了解只要下意识转过相应念头就会与那些旧日外神们直接建立起联系惨遭侵蚀！如果不是源堡已经切断之前联系我都不敢返回现实了……克莱恩想了想决定请自己心理医生正义小姐帮忙催眠自己将相应信息封存于潜意识深处直到看见设置好提示才能记起。他本想直接召唤历史孔隙内正义投影来做这件事情但考虑到这是一个精细活操纵者如果对心灵领域没有深入了解很可能出一些纰漏而一旦有纰漏旧日和外神们目光就投过来了。呼记得让正义小姐也催眠自己忘记这件事情……克莱恩斟酌衡量一阵将相应请求化成流光投入代表正义深红星辰。没过多久刚用完早餐还未离家正义奥黛丽来到灰雾之上。那张青铜长桌已消失不见古老宫殿内摆放是一张书桌和两把椅子。世界先生这次要忘记是什么事情？奥黛丽看着坐于对面格尔曼·斯帕罗提出最关键问题。克莱恩揉揉额角用低沉嗓音将星空旧日外神等隐秘说一遍。这听得正义奥黛丽眼睛一点点睁大整个人就仿佛被邪神入侵一样。等到克莱恩讲完她沉默好几秒用同样低沉嗓音略显迷茫说道：这就是末日真相？哪怕七神也无法拯救我们？不等克莱恩回应奥黛丽自嘲般笑笑：我以为我最近做事情都很有意义……我以为我能想到最坏消息是鲁恩战败教会覆灭……可和你告诉我隐秘比起来这一切都是那样渺小。

## 这场戏有没有翻
翻了。开头还在佛尔思白天悸动／全球见白月；章末克莱恩把阿蒙隐秘推成末日猜想并告知正义——七神未必能救。翻的是战争渺小对上外神末日，不是月亮变色厉不厉。

# 381 无面人 第一百六十九章 侠盗

## 打开书
休推门；佛犒烟——「吸烟有害」。黄金面具联：查打听卡平；初30镑或暗险。佛损：「背后有组织拉你不怕智商灭团？矮命值钱…」休惯：「人贩该死火刑」已惨死；尸满塔罗脸审判＋皇帝。佛读：「审判＝死刑；皇帝＝凶手／英雄身份？」愣——塔罗会！内部？无皇帝代号；首现现实痕；惊喜忧。切智慧之眼起居：单烛铁面黑袍。克莫名：烛盯己／焰燃发袍／帘笼憋死；椅将爆木刺贯体（劣质气压椅联想）。药师仍缺。聚始：吊灯坠／茶几绊／成员暴起——电钻般抖难交易；触铁面觉凹嵌脑。弃求千面狩猎者。离袍面直觉霍消！非灵伤——室内有看不见恐怖存在刺激占卜灵感＋小丑预感却被压成丰富联想。猜：勇敢者周怨魂监控区；玫瑰高序怒投目光？今晚毒瓶太阳胸针留雾免占；否则不可能表演后死此。非凡世界真危险。切圣风：斯内克问卡平谁？何地下监牢？富豪人贩奴隶贸易证；为何数非凡护且序不低？查败非凡手段；「我也试过」续查＋找序6／5幽灵。记本：卡平人口贸易塔罗仪式怪幽灵隐秘图谋。切霍尔早餐：伯爵笑「卡平死了」；奥黛丽配合问。报：私下或人贩与某些人关系好；昨晚杀现场审判痕；报称凶手侠盗「黑皇帝」古所罗门帝国统治者代号。奥联亵渎黑皇帝牌兴趣：「做得真漂亮过程？」报：黑甲冠披风入宅盗保险柜全财＋盗生命解救地牢少女；身满塔罗脸审判＋皇帝。奥眼陡亮。

## 这场戏有没有翻
翻了。开头休任务塔罗会联想；章末玫瑰压迫聚、官方查幽灵、报纸封「侠盗黑皇帝」奥黛丽眼亮。翻的是称号公开化，不是回家细读。

## 热怎么变冷
火刑喜还热。冷切在塔罗会忧。电钻抖还热。冷切在离屋消。查幽灵还热。冷切在记本。侠盗还热。冷切在眼亮停章。

## 怎么起、怎么收
第一段休推门。最后一段奥黛丽眼亮。章题：侠盗——公开称号。

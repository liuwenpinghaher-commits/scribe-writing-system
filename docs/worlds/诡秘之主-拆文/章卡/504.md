# 504 旅行家 第二十三章 价值3000镑的仆人

## 打开书
「船长红骷髅跑了！」一位水手冲进船长室。「跑了？」艾尔兰举起单筒望远镜疑惑审视波涛平缓海面刚好看见红骷髅号消失天边。眉头一下皱起完全不明白为什么会有这样发展。在他看来白玛瑙号武装力量肯定没办法直接吓退红骷髅海盗团双方必然会绕上几十个圈子来上多次齐射才能出现对方感觉啃不下这个硬骨头不敢长期纠缠于是理智退走结局。难道红骷髅号只是路过没有劫掠想法？可是不劫掠他们进这条航道做什么？这是最容易被海军舰队和教会船只堵住地方哪怕四王七将军途经附近海域时也会尽量低调…内心充满疑惑觉得事情不那么简单。谨慎使人免于灾难不能大意…收起黄棕色单筒望远镜来回踱几步。半抬起手对航海长：「今晚停靠班西港。将遭遇海盗事情汇报给海军和教会。」按照正常计划白玛瑙号下一个停靠地方将是提亚纳港大概还需要以13节速度航行三天才能抵达从提亚纳港出来就将直达最终目的地罗思德群岛首府慷慨之城拜亚姆。而从普利兹港到拜亚姆有更快速航行方式那就是中途只停留一次在距离达米尔港120海里班西港。……「红骷髅真的离开了？」堂娜父亲乌尔迪·布兰奇走到窗边眺望远方。克里维斯沉静点头：「是的。」话音刚落外面就传来水手呐喊：「危险解除！危险解除！」听到官方确认堂娜丹顿姐弟俩终于放松下来有勇气来到窗户附近打量外面情况。「红骷髅海盗团很厉害吗？」堂娜睁大眼睛寻找已远离船只。「很厉害。」给出答复。「有多厉害？」丹顿当即追问。另外一边保镖蒂格理下头发呵呵笑：「即使不算船上火炮和几百名海盗仅是船长约翰松和大副安德尔森也非常厉害。安德尔森绰号独眼在王国悬赏金额是500镑我们这个房间所有人加在一起再得到几位水手帮助或许才能在遭遇战里击败他而外号海狼约翰松则可以轻松解决这样对手如果他们登船海狼将没有人可以抵挡他的悬赏金有足足900镑接近1000镑！」「这很多吗？」又震惊于海狼和独眼厉害又诧异于他们赏金。在她印象里自家父亲一年收入足足有1500镑！「很多这是他们或他们人头可直接换取到赏金他们身上物品他们劫掠东西同样属于你王国会以市场价格购买并且你还有机会拿到其他国家赏金。」塞西尔在旁边解释：「在海上悬赏金额在300镑以上海盗都相当厉害接近或超过1000镑那种至少在本身所处海域会很有名我是指苏尼亚海迷雾海这种大海域。」「所以四王七将军属于五海闻名？」略显天真问。克里维斯认真回应：「是的。」「那么红骷髅海盗团在整个苏尼亚海都很有名气？」逻辑清晰追问。「对。」蒂格点头。「可他们为什么要跑？」眨巴眼睛。「不一定是跑…」塞西尔自己也不是太明白缘由。克里维斯再次望向窗外额头略呈川型：「也许有别原因也许他们这次根本不想劫掠只是单纯遇上。」别原因？胡思乱想中突然有猜测。难道是斯帕罗叔叔那个房屋一样高温和信使把他们吓跑？嗯嗯！它真的很吓人！心灵就像煮沸水咕噜咕噜冒起气泡。兴奋扭头看向斜下发现弟弟丹顿眼睛同样发亮。两人不分先后抿紧嘴巴旋即明白对方和自己想差不多。「我们出去吹下风就在这一层。」找理由拉着弟弟离开305房。到外面丹顿压嗓音：「我们要去找斯帕罗叔叔？」「答案正确！」精神奕奕笑：「我之前看见他进了312。」……312房间内。不再提冰山中将烈焰重新望向调转船头红骷髅号啧啧笑：「他们肯定是被海军巨舰大炮宣言和之前有海盗团被摧毁消息吓到竟然冒险进入这条航道劫掠想早点赚够钱离开大海。呵有巨舰大炮又怎么样？海军和教会强大东西很多一直都存在也没造成做不下去海盗情况正面打不过我们总能逃跑对吧？他们不可能一直为那些商船护航吧？我知道铁甲舰越来越大装蒸汽机也会越来越厉害速度总有一天能突破18节20节一旦被他们咬住就只能等着被追上可大海这么广阔几千几万条船扔下去也填不满一个角落人类未探索海域也还有很多很多做了什么事情往那些地方一躲虽然危险但同样存在机会。」这家伙果然是话多类型…你不觉得一位疯狂冒险家根本不会在意这些事情吗？收回目光扫下房间。视线最终落在自己皮制行李箱上然后对那里扬扬下巴：「把里面脏衣服洗了。」本待长篇大论达尼兹表情一下凝固恨不得一把火将整条船都烧掉。觉得自己怒意就像喷薄而出蒸汽顶起名为理智闸门。张张嘴吸口气又张张嘴吸口气。涨红脸色缓和下来不见笑容问：「是所有吗？」「只管脏的外套刷一下就行了。」差点被对方强憋怒气表现给逗笑认为这是达尼兹抢过无辜者后应该获得待遇。——行李箱内是他昨晚换洗下来衣物因为有点犯懒暂时只搓了内裤。冷静不能失控冷静不能失控…连续告诫自己几句走到行李箱旁打开取出需要清洁衣物。刚在盥洗室开始忙碌就听见门铃被拉得叮叮作响。打开房门发现是堂娜丹顿姐弟俩。「斯帕罗叔叔没打扰你吧？」眼珠左右转动。「没有。」让开道路。两个小家伙进房间一脸意外看见达尼兹在浆洗衣物。「仆人呢？」丹顿下意识问。「没带。」替达尼兹做出回答。堂娜略显迷茫：「可一等舱有专属浆洗女佣呀收费按桶来计算。」话音未落达尼兹已然僵住。之前太过愤怒竟然忘记这件事情。甩甩手上水珠转过身体挤出笑容对格尔曼：「我可以请浆洗女佣帮忙吗？」没有一定要看对方出糗恶意笑笑：「我只认结果。」呼明显松口气。两人这番问答让堂娜察觉点不对小姑娘狐疑开口：「斯帕罗叔叔你们不是朋友吗？他他怎么和刚才长得不一样了！」找张椅子坐下未做掩饰平淡：「准确来说他是我战俘。」「战俘？」丹顿呆乎乎左看右看不记得两位叔叔间有发生过冲突。堂娜先是疑惑接着心中一动欢快问：「他是他是海盗？」「嗯。」轻轻点头。「红骷髅海盗团也是斯帕罗叔叔你吓跑的？」兴奋追问。瞄眼达尼兹没什么表情回答：「算是。」疑惑全部得到解答让堂娜异常满足瞅眼达尼兹不自觉放低声音：「斯帕罗叔叔他有名字吗？不他有悬赏令吗？」不！不能让人知道我有过这样遭遇！张开嘴巴抢先回答：「我叫齐格！」这时克轻飘飘说一句：「达尼兹。」「达尼兹…」姐弟对视一眼未再多问。没待多久就告辞离去总觉得那位海盗眼神很凶。回到305房见爸爸和克里维斯叔叔他们还在讨论堂娜故作天真插言：「刚才不少人在讨论海盗有提到什么达尼兹他很厉害吗？」「达尼兹…烈焰达尼兹他是冰山中将手下黄金梦想号第四水手长…」简单回答。说到这里忽然沉默眼神内收仿佛在回忆什么。海盗将军手下…好奇追问：「他有多少悬赏？」恢复正常低沉：「3000镑。」三三千镑？姐弟嘴巴一点点张开险些忘记合拢。红骷髅船长才悬赏900镑刚才那个看起来像仆人家伙竟然值3000镑？你看我我看你说不出话来。……傍晚6点白玛瑙号再次进港。「班西港？艾尔兰很谨慎嘛…」达尼兹站窗边望着已然昏暗港口和高高灯塔。不等克回应自顾自笑一声：「这里似乎有一些不好传说。」

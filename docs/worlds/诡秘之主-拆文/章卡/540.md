# 540 旅行家 第五十九章 访客

## 打开书
海王…听到亚恩·考特曼序列名称第一时间联想到却是风暴之主完整尊名：「空之王海之皇天灾君主风暴之神！」序列3是海王…序列0包含海皇要素还是挺对应嘛…也不知道风暴途径序列0叫什么…再次望向窗外只见天气虽然还略显阴沉但晨曦已降潮声退去雨水彻底中止。思绪拉回从达尼兹透露信息里分析起情况：魔药名称是海王也就是说相应序列3半神圣者得扮演海王而所有扮演都具备一个前提那就是本身拥有需要全部能力…身为海王即使有范围限制在自身掌控海域也肯定是强大支配者可以自由行走于海底可以肆意掀起海啸可以让海水上涨可以支配海洋生物…在主场作战他们绝对能力压同层次所有半神…五海之王和神秘女王也差不多在这位阶只是因消化程度不同对力量掌握不同有一定强弱区分？但不管怎么样只要在海上他们就很难赢海王…以海王表现出来能力配合大洋环境如果没见识过永恒烈阳真实造物主等真正神灵崇拜他信仰他向他祈祷并不是什么太难理解事情…许许多多原始崇拜里神灵也许都是这位阶大概率连天使都不是…嗯不可直视神指真正神灵之前海神卡维图瓦并没有给这种感觉阿蒙分身也没有当然无法确定天使之王本体是否也有不可直视属性…一个是濒临崩溃现在顶多也就序列3层次海神一个是状态良好且随时可以动用封印物海王胜负可想而知亚恩·考特曼绝对能一直压制卡维图瓦疯狂不让海水淹没拜亚姆不让整个蓝山岛和上面多座城市成为失落海底遗迹…再等几天卡维图瓦最后疯狂过去彻底崩解消散事情也就解决这是最简单最有效处理方案不会带来任何恐慌气氛甚至这里大多数人都无法察觉异常。但这也有些问题首先是不能有别意外拉蒂西亚这考古学家不知在西弥姆岛上做了什么一手导演海神灭亡她背后摩斯苦修会或者要素黎明也许会趁机谋求些什么这是最大隐患额总督府军方那边在这里应该也有一位高序列强者这是王国在中苏尼亚海域殖民统治支点…事情不会太恶化…其次是那些狂热信徒当卡维图瓦越来越疯狂越来越濒临死亡时他们大概率会成为祭品就像丰收时秸秆一丛又一丛倒下。不过这对风暴教会来说并不是太坏发展最为虔诚异教徒随着他们神灵一起死亡能省去后续甄别处理麻烦不是那么虔诚则不会受到太大影响将来具备改造可能…唯一不足是很长时间内罗思德群岛会出现劳动力不足情况这样问题虽然麻烦但只要咬咬牙也能解决所以风暴教会海王大概率会坐视不理…呼本地人聚集区域中贫民窟里面不知会有多少人因此死去…思绪突然被整齐划一步伐声和高空轰鸣感打断。本能抬头看见几艘炮口外露机枪伸出深蓝涂装飞空艇驶过眼前飞向不同区域。而大街上红外套白裤子黑皮靴鲁恩士兵扛着步枪拖着火炮排着整齐队伍一列又一列经过。紧张肃杀氛围霍然扩张。这就是殖民地…莫名感触叹息自语。「不知道教会多久能干掉那海蛇找到它之前隐藏地方那里绝对是一个宝藏有数不清贵重物品…」主职是宝藏猎人达尼兹突然开口有些期待又有些遗憾。态度变得非常快已经将海神降格成海蛇并用它来代称。教会什么都不做就这样压制着等待几天就能看见卡维图瓦陨落了…当然风暴教会人未必有这耐心尤其我听说亚恩·考特曼本职是代罚者高级执事只是群岛孤悬于海外为了事权统一才兼职枢机主教行事风格也许更贴近代罚者…卡维图瓦隐藏地方？那遗迹几乎融入灵界想要找到不是那么简单事情否则它也无法苟延残喘到今天…想到这里忽然产生灵感。想找到卡维图瓦藏身遗迹从现实世界出发很困难即使对方已经陨落也不是一年半载能发现除非得到更为准确情报。但要是从灵界着手了？灵界更加无法定位但也不是完全没有办法水银之蛇威尔就借助自己折叠纸鹤表演过一次…具体该怎么做还是没有思路但这不重要我可以请教阿兹克先生死神领域掌控着灵界部分权柄…冥界或者说地狱就是不死鸟始祖格蕾嘉莉这位远古死神在灵界内开辟出来…念头一闪掏出古老精致铜哨凑到嘴边吹一口。相信即使回到卧室或进入盥洗室信使那庞大身躯也必然会被灵感不低达尼兹发现所以也就没避讳对方。达尼兹正在想象海神宝藏忽然觉得脖子有些凉飕飕。心有所感忙开启灵视望向侧后方只见一根根白骨从地板上喷出往上抛飞组成一个脑袋虚幻穿透天花板巨大骷髅。那骷髅微微低头两点漆黑火焰哪怕隔着天花板也能隐约看见。它庞大身躯带来压迫感让达尼兹一下侧跃半弓身体于右掌掌心聚集起赤红火焰。这什么怪物？愕然望向格尔曼只见他手握一枚铜哨脑袋上抬与骷髅怪物静静对视。仰望着巨大信使巨大信使俯视着他双方似乎凝固在那里。…嘶太急了都还没写信就把信使召唤出来了…我是让它原地等一等还是先回去等会再来…我现在是格尔曼对格尔曼！什么也没说淡漠收回视线动作不快不慢翻找出纸笔刷刷刷开始写信。大致描述海神事情但隐去自己差点被附身必须借助灰雾驱散细节将对方藏身遗迹糅进刚才那场梦境。「…也许可以从灵界想办法但我缺乏相应知识希望能得到您指导。」折好纸张转过头来发现信使垂下手掌不知什么时候已握起来。装作什么也没发现将信丢上去。信使静止一秒才摊开手掌接住那封信。身躯霍然崩解白骨哗啦啦落下钻入地板。「这这是什么？」达尼兹终于发出声音。瞥他一眼平淡回答：「信使。」信使？愣愣才明白对方意思。这么庞大这么可怕怪物竟然是送信信使？格尔曼背后果然有个强大隐秘组织！如果如果我有这么一个信使船上所有人都会羡慕我这真真太酷了！畅想起回船吹牛并炫耀信使场景。收起阿兹克铜哨找张椅子坐下准备等一会儿去享用早餐。过一阵听见咚咚咚敲门声。达尼兹警惕过去借助猫眼发现外面敲门是戴船形帽中年男子。「艾尔兰？你怎么找到这里来了？」开门问。来访者正是白玛瑙号船长公正艾尔兰。眼角有些皱纹望眼房间里面轻笑道：「你们住进这间旅馆时候是用格尔曼身份登记一查就能查到。」因为这身份还很正规很清白而且在风暴教会眼里属于军方人…缓缓起身对进入房间艾尔兰道：「有什么事情？」艾尔兰指着外面道：「拜亚姆出了点意外但问题不大军方联合教会正在做全城搜捕那是几个实力不错非凡者名义上考古学家。为了尽快找到目标军方动用所有资源但相对这么大城市来说依然不够呵呵他们相信你虽然来历不明但对我们态度很友善希望你能帮忙排查预防意外事后会支付相应报酬。」这应该是你功劳夸大了我友善程度…也就是说继女神教会蒸汽教会之后我又能从军方领到钱了？感觉一时竟有些复杂。见他没立刻回答艾尔兰补一句：「虽然不会有大问题但早一点找到目标就能早一点控制相应灾难。而这或许就能多挽救几个人。」沉默一下轻轻点头：「好。」

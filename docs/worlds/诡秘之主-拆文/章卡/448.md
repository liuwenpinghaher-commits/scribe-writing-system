# 448 无面人 第二百三十六章 更好的选择

## 打开书
霍尔宅暖壁炉。奥受吉尼娅量身新年舞会服。安妮耳语：「伊思兰特来访。」这么快？浅笑：「请画室等；五分钟。」「画室？」「请赏近作——松态绘易露真想法情绪。」入：伊赏墙画。「森西《内心夜晚》——塔索克百年百大前十？」微不足道应。值庄园咽庸俗。打发安妮；苏茜门外站岗。伊关门主动：「人皮特性＋风眷方都有；无卖必要除非无法拒回报。」有望！「希望何？」「人皮2500；风眷方3000。」溢价＞50%；序6方正常＜2000越高越稀难验真。「神物等价可换」——更想神物可降；心炼金年轻积薄。「反馈不保证受。」日程密掩聚会难查。「原以为不卖序6风眷？」「传播或更有用。」含糊新成员勿多知。天真：「成交算我贡献？」「算。」笑。切克假忙一上午返明斯克饱腹灰雾听祈。正义也有人皮？不来则两份！幸福烦恼。现金算倒吊未给500仅1335仍认真虑。先传正义语给倒吊看选。慷慨城倒吊被3000棒敲——幽蓝复仇战利＜2000分水手；船炮上交；海盗穷刚收就挥霍难暴富。踱定：取黄金古朴面具原始五官——愚尊名：「愿用神物换风眷方。」戴＝极冷静无情绪＋强恢复速力＋黑魔原始咒；缺＝次数增不像人冷酷终自当神。愚位：500镑现＋5深蓝蛇发＋金面具前——敲桌盘点可换：全黑之眼秘偶主材否；黑皇帝牌见不得光；阿兹克铜哨否；灵教铜哨险；太阳胸针自用；万能钥匙门隐秘；毒素瓶配灵；弹药耗材；秘密之书非神物；审讯特性非神物且贝克易露黑皇帝…完善想：具现世界嘶哑：「受2500；给我两天筹。」影丢正义星。无问题后等一下午。黄昏近卡尔森门铃→杠杆教堂邻三层「贝克兰德机械研究会」。穿怪装置无窗房：长桌灵性强物含人皮特性黑布幽灵框——无死者特性（掩守恒）。伊：「可挑一件。」「仔细」叹：「无想要。折金镑多少？」决不在机械拿人皮——解释制作／仪仍露序列险；更好选择纯拿钱凑2500＋消戒备。伊松气笑：「1500。鼓励选金钱＝总计2000。」真心笑：「好！」

## 这场戏有没有翻
翻了。开头量身舞会；章末拒人皮拿2000镑。翻的是双渠报价＋面具换方＋更好选择纯现金，不是陵墓酬直接拿特性。

# 1085 红祭司 第一百四十章 很简单的推理

## 打开书
见红天使，手套透明欲传；灵界铁血硝烟，七光被遮——不敢莽传。恶灵笑：怕查拉图？指沙发：若已告查拉图唐泰斯=格尔曼，酒窖等的是风干火腿管家仆佣。坐，先听意图。谈条件意图；克莱恩以简单推理串联时代潮流与神秘推动，明悟多项。记：上一位想成黑皇帝是罗塞尔，正与阿蒙兄弟有关！

## 这场戏有没有翻
翻了。逃生本能被铁血灵界按住；被迫听意图；推理收成黑皇帝=罗塞尔=阿蒙兄弟线。翻的是逃还能否，不是沙发寒暄。

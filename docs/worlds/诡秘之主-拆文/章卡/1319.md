# 1319 倒吊人 第五十四章 心灵邮件

## 打开书
苏茜正蹲在门口等待奥黛丽归来。此时一看到她靠近这金毛大狗就立刻迎上去并且相当有表演天赋汪两声摇起尾巴。她没当场询问一直陪着奥黛丽回到卧室内才关切道：结束了吗？奥黛丽嗯一声表示已经没有问题了。有什么需要帮助吗？暂时不需要。……因着苏茜关心她本能回想一下刚才经历谁知却发现自己已完全想不起心理炼金会会长形象和名字就连原本从世界格尔曼·斯帕罗处知晓部分情报也得集中精神才能记起。……她对苏茜使个眼色让这条金毛大狗守到房门外面自己则于脑海内勾勒出那张代表傲慢人格面具。……只要认真去想这张傲慢面具就会来到我身旁？……这让她愈发戒备决定一有机会就向愚者先生祷告许下封印这张人格面具愿望。正当她想多做几次实验从傲慢面具处窥探出更多知识时她无需使用操纵师非凡能力就看见集体潜意识大海轻轻晃荡起来。一点微光从远处游来越变越大越来越明显最后化成一封虚幻信件。这信件停在奥黛丽心灵岛屿前似乎在寻找道路以完成投递。……想到这里奥黛丽虚拟出一个人格做主导并戴上恐惧之手这黑色薄纱长手套。……用集体潜意识大海传递信息……观众途径高层次能力真是神奇啊……这是她不让自己迷失于操纵体验不被集体潜意识大海逐渐同化办法之一。……她依旧没急着向愚者先生祷告按照之前安排出门忙碌起别事情。……下一秒钟奥黛丽看见那张灰白色傲慢面具从身前集体潜意识大海内浮现出来……奥黛丽拿着这张傲慢面具尝试着取下变成绿宝石项链谎言将两者重叠在一起。和她预料一样半真实半虚幻傲慢面具镶嵌到谎言上变成一团粗看像是人脸花纹。以后就用这种方式随身携带不让人格面具和我心灵身体有一点接触直到需要使用它……奥黛丽思绪一转间诚恳感谢起愚者先生。……一个好消息。霍尔伯爵笑着说道。……阿尔弗雷德要回来了？……你竟然能猜到？霍尔伯爵略感诧异说道等到下半年他会以将军身份回归贝克兰德。下半年……苏茜都是梦境行者了……奥黛丽想了想又问道：爸爸我们什么时候回东切斯特郡？大概得四月。……心灵邮件……小心病毒不要乱点啊……克莱恩边叹息边将那块代表诡秘侍者非凡特性幕布扔回杂物堆让它覆盖住那里所有物品。他刚才满足正义小姐愿望用就是自己命名嫁接能力把人格面具虚幻概念和一张普通铁面具金属质感连接在一起……从心理炼金会那位暴食先生描述看查拉图似乎已经追踪到康斯顿城我必须更加小心了……克莱恩手指轻敲下斑驳长桌边缘让体表钻出一条又一条灵之虫。他身影随之消失在源堡内。……以满足别人愿望为乐流浪魔术师梅林·赫尔墨斯……一夜重建康斯顿城……全自动许愿机……占卜家途径序列4叫诡法师序列3叫古代学者序列2叫奇迹师……老头占卜家途径天使还有多少位活跃于地上？帕列斯·索罗亚斯德啧一声：这是在扮演啊目前还需要扮演奇迹师应该只有一位。你应该知道我说是谁。……玩得很开心嘛……他已经决定这次任务主要目的是扮演守夜人消化体内魔药顺便旅行至于事件处理重点是找个合理解释。……他要去领取属于自己这位高级执事1级封印物了。……太阳戴里克已好多次不需要默数心跳只用看一看壁钟……下午好愚者先生。……我想知道耕种者和月亮途径相比别途径是否存在一定特殊？……我最近了解到大地教会内部体系与正常不同分为神恩者和神眷者两个部分……等月亮埃姆林简单描述完倒吊人阿尔杰隐者嘉德丽雅星星伦纳德等人彼此看一眼皆给不出合理解释。……这叹息仿佛从比古老更古老年代传来源自斑驳长桌最上首愚者先生。

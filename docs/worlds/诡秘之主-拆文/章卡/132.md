## 这一章新讲明的规矩
- 梦境占卜：让人睡再现梦；不保证一定做那个梦只是尝试。
- 梦境符咒半圆形；沉眠长方形；安魂三角形——手感区分。开启咒文他自己定为绯红简短好记再灌灵性。透明火焰烧出黑色罩住两人见孤单光球触碰入梦。
- 梦里人诚实除了他这个愚者。
- 魂类：怨念不甘最弱 → 幽影 → 怨魂 → 恶灵棘手最恐怖的不比高序列弱。本章骑士是怨魂的意念还不到恶灵。
- 黑夜女神领域符咒纯银平均6到8苏勒一枚；太阳领域对应金属黄金。

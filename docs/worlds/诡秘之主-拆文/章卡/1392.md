# 1392 倒吊人 第四十章 梦开始的地方

## 打开书
返回现实世界后阿尔杰耐心地等待起愚者先生口中任务来临。这一天穿着教皇衣物戴着银黑面具他正在和神使达尼兹商谈海神教会内部事情突然看见有位主教进来。教皇冕下风暴教会派使者送来两份礼物祝贺您担任神代行者。这位主教捧着一个白锡制成盒子毕恭毕敬行礼道。一直暗中庆幸之前拜亚姆电报线路出故障达尼兹闻言诧异脱口道：那名使者呢？他留下礼物就走了。门口主教相当无奈回答道。……他们能不敌视我们派使者送礼物过来已经足够了。……天灾之书。天灾之书……看清楚这行单词后阿尔杰一阵恍惚有种自己在做梦感觉。但很快他就明白这是真明白愚者先生说任务是什么。……第二份礼物是什么？是一艘叫做幽蓝复仇者幽灵船已经停在港口。那名主教不觉有任何异常回答道。幽蓝复仇者……达尼兹听到这个名称本能就将目光投向旁边教皇阿尔杰。……替我回一封信给风暴教会感谢他们礼物。阿尔杰已然沉稳下来平静吩咐道。……神使我已收到愚者先生神谕接下来将去完成一个任务或许几年后才能回来。神谕？达尼兹愕然脱口道。……愚者先生即将进入沉眠。不过这不影响你祈祷获得回应。……达尼兹太过震惊以至于说不出话来。……格尔曼·斯帕罗也跟随沉眠了。等我离开教会事务将移交给新白银城戴里克·伯格长老你需要配合他将海神是愚者先生从神这件事情写入典籍让所有信徒都接受。我们信仰是愚者先生苏醒关键你是祂神使更要在这方面做出表率。当然祂随时可能给你新神谕交给你别任务。……好。……阿尔杰抬起脑袋望向外形上比自己高大不少太阳戴里克笑着说道：你这段时间做得很好海神教会运转得很正常。……倒威尔逊冕下您什么时候能够回来？……前方一切都还未知谁也说不清楚。……你已经足够成熟和稳重我没什么可以再叮嘱你。……如果罗思德群岛遇到无法抵御灾难你不要为保护这里牺牲自己。……啊？戴里克一下愣住。这可是愚者先生最重要信仰之地是白银城新故乡怎么能就那样放弃？……对愚者先生来说最重要是这里信徒而不是这些岛屿对白银城来说最重要是民众而不是城市。只要能保护好愚者先生信徒们保护好白银城民众们及时将他们转移那就算失去拜亚姆失去新白银城失去罗思德群岛我们也随时可以在别地方重建起新城市新家园。记住不要为形式而损害实质。……我明白了谢谢您倒威尔逊冕下我会保护好愚者先生信徒保护好这里民众。阿尔杰不再言语转过身体走向停于这处码头幽蓝复仇者号。……阿尔杰嘴角微微上翘脚步一迈乘风而起落到幽蓝复仇者号甲板上。……出航！……我们小公主在想什么？……你猜。我猜你在想今天舞会穿哪条裙子配什么样发型和妆容。希伯特神情轻松代替父亲说道。……答对了但没有奖励。……我去楼上换礼服了。……不用着急所有人都公认你值得等待。……晚上好正义小姐～这少女语气轻快打起招呼。……晚上好奥黛丽小姐。那次临时塔罗聚会后她终于下定决心晋升为织梦人准备分割一个身份出来陪伴家人自己则远离他们不让他们被自己引来各种危险事情波及。……苏茜你确定要跟着我？嗯我们是永远朋友。金毛大狗苏茜认真回答道。正义奥黛丽没再多说分出一个虚拟人格进入苏茜自行放开限制心智体内。……这苏茜刚一成型就张开嘴巴汪一声。……以后以后就拜托你了。记得多向爸爸撒娇让他不要那么忙碌他年纪已经不小需要注意身体健康很多事情完全可以交给希伯特和阿尔弗雷德交给管家们。还有慢慢开导妈妈告诉她不需要太在意别人看法不用在社交场合保持完美这会很累。嗯不要忘记希伯特经常逗他笑一笑让他不要那么阴沉不要总是把事情想得太复杂阿尔弗雷德不会威胁到他地位。阿尔弗雷德阿尔弗雷德他需要一个好妻子来让他不想再冒险……唔你哭什么？我们已经长大不能再像个小女孩了。……我知道我知道。那个奥黛丽说完之后紧抿住嘴唇表情凄然重重点头。正义奥黛丽收回目光拿起放在旁边斗篷将它披在身上。……走吧。奥黛丽嗓音略显低哑对苏茜说一声。……一定要回来啊！

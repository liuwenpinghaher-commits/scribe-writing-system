# 359 无面人 第一百四十七章 一个困难的问题

## 打开书
克莱恩猜地球与此界流速不同：间隔＜一年此拉近两百年→花两百年找归路顶多失踪一年——踌躇满志又冷水：或罗后穿时空乱流。日记续：二二五无报小说少文化扶贫须钱造纸印刷；零花钱费尔金偶见狩猎有趣。二二八林迷旁观战：被围男脸长四眼喷墨绿光「不科学」；对手金焰光柱；未发现；自认主角欲自破银牌花纹却记不清鬼画符。解除屏蔽「自行交易」。魔术师求食灵者胃袋＋20ml深海枪鱼血金镑付（自有430）；倒吊：海盗聚见过枪鱼血已错过；海广半年难碰面材料聚大都会——暗示自寻贝克兰德。太阳：知食灵者活动范围不要金镑要太阳神官配方。佛尔思：序7最少750急可千＋；胃袋／血各≤400常300——太阳「可给两三个胃袋」。佛尔思假笑会搜集（想A先生烈阳信徒光之环）钱不够——环顾诚恳：「各位有什么赚钱的好办法吗？」全场沉默；愚者不需钱。世界阴沉：留意千面狩猎者脑部异变垂体血、人皮幽影特性、深海娜迦头发（克莱恩589＋狼人特性毒素瓶可卖）。太阳先应未诺；正义似见化石（尼根宝库）。倒吊：留意巴伦——棕红南大陆貌贝克兰德腔、左三齿缺或补、貌身高普通；奴隶失踪相关；报酬≥100镑。愚者「自由交流」。散后太阳回暗室无异常；敲邻墙三笃久无人应——背后床沿苍老飘忽：「你在找我吗……」

## 这场戏有没有翻
翻了。开头还在时差推断踌躇；章末赚钱全场哑、巴伦悬赏、邻人进房「你在找我吗」。翻的是圆塔安全幻灭，不是半透明虫细写。

## 热怎么变冷
时差好心情还热。冷切在时空乱流。主角日记还热。冷切在交易价差。赚钱问还热。冷切在沉默。找我还热。冷切在背后。

## 怎么起、怎么收
第一段流速推断。最后一段「你在找我吗……」章题：一个困难的问题——赚钱＋封印破。

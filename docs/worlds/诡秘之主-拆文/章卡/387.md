# 387 无面人 第一百七十五章 探索梦境

## 打开书
科勒「什么？」克目坑洼路：「希望丽芙家越来越好。」内：革命本能vs超凡怨魂枪炮难解；特性守恒材料难普及失控灾；半神封印物真神在——罢工游行尚可持武建军必遭天灾心理暗示反扑；抗官方多邪隐秘合流更惨；革命望教会支持；罢工让步有限收买易；真造贫民降临触动女教贵族（迈克调／正义反馈）。讽：借邪神威胁最可能改善；邪神又最噬血魂——绝妙讽刺。切奥黛丽提前第二心理课；苏茜丢圆球冲书房。故意问神秘交叉；收尾伊思兰特：「有研讨会交叉领域；兴趣加入？」「当然！」符天真设。「保密；长辈偏见；下次课带你。」镜前转圈嫣然：「奥黛丽你真棒！」外围门已推开全凭观察表演瞒伊自豪。苏茜「我能加入？」沉「太显眼…可带着你」。周六夜万能钥匙＋黑手杖出（无杖恐回不来）→希尔斯顿伯宁翰3艾伦宅。11点后黯静；币占穿栅侧墙钥开无形通道黑廊；无声二楼空客房。夫妻睡——沉眠符咒妻真眠；握梦境符咒古赫「绯红！」符轻虚幻透焰幽黑罩艾伦＋己。冥想深黑椭圆光球触——荒芜漆石平原央黑尖塔盘银白巨蛇竖头红眼。异于艾伦述：无实质鳞＝密花纹符转轮相连；头尾轮各半不协调；若咬尾则圆满无残。艾伦茫然近塔；确认无梦魇引导。跟侧后几步目标已近；蛇探上半琢磨享用；大口无腥红眸冷平等渺小无杀残忍。未攻；穿古朽木门入——布局乱梯上斜坠厅馆倒立镶嵌不可能建筑。穿门墙不知尖顶或地下室；暗角蜷影单腿跳近＝威尔十岁虎头缺左小腿持塔罗又惊喜畏：「艾伦医生有蛇想吃我！」惨叫映银蛇；牌落仅握一张——命运之轮！哗梦碎；克仍坐梳妆椅。

## 这场戏有没有翻
翻了。开头还在革命讽刺；章末炼金会邀成、入梦见转轮银蛇命运之轮碎梦。翻的是梦源非引导＝灵界灌，不是值夜者退缩细写。

## 热怎么变冷
讽刺还热。冷切在「你真棒」。绯红入梦还热。冷切在咬尾圆满想。命运轮还热。冷切在梦碎椅。

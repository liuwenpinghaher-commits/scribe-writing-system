# 1346 倒吊人 第八十一章 支柱

## 打开书
灰雾之上古老宫殿内愚者座椅旁。一个祈祷光点膨胀开来往外荡出一圈又一圈光晕。这就仿佛在一个幽闭房间内突然拉开窗帘让阳光照入刺向沉睡者眼睛。……克莱恩目光划过与诡秘之主有关部分解读起后续内容：永暗之河加黑暗唯一性死神唯一性黄昏巨人唯一性加……母巢加母亲唯一性月亮唯一性加……失序之国加黑皇帝唯一性审判者唯一性加……灾祸之城加魔女唯一性红祭司唯一性加……暗影世界加深渊唯一性被缚者唯一性加……知识荒野加隐者唯一性完美者唯一性加……光之钥加命运之轮唯一性加……在某些时候哪怕不使用非凡能力知识也完完全全等于力量……大地和月亮两条途径组合起来称号与堕落母神有一定区别看来确实只是祂一部分……看起来全知全能者最强诡秘之主和时空归一者排第二档次其余位于第三层。亚当看着那块亵渎石板平和而舒缓说道：不是这样。权柄数量和位格层次有一定关系但不是全部相应特质威能和象征同样重要。在最初那位造物主分裂之后位于所有旧日顶端是三支柱一位是上帝全知全能者一位是诡秘之主时空之王一位是堕落母神邪恶之始。听到亚当最后那句话克莱恩忍不住低头看眼自己左袖魔镜阿罗德斯就藏在里面。难怪阿罗德斯说从我身上看见支柱支配……他顿时恍然对空想家亚当说法又相信几分。……当前前面两大支柱还只是以源质形式存在而堕落母神分割出去母巢和两条非凡途径之后也和其余外神没有太大区别了只是支柱象征还在。……当然我是那个餐……不得不说观众影响他人认知体验和状态能力实在太强……克莱恩一边告诉自己要警惕一边疑惑说道：我以为堕落母神这种有两份甚至三份源质外神才算支柱。……祂只有一份源质。正常情况下源质无法分割只有最初那位造物主分裂时产生聚合与分离化身才能撕裂源质将它们其中部分吸聚到我们这个星球。……也就是说现在堕落母神源质是残缺将来旧日万物之母也不是完整旧日？……最开始时候是这样但源质是有补全自身能力现在堕落母神源质并不残缺母巢也同样能造就一位旧日唯一问题是堕落母神如今只能部分利用自身具备支柱象征除非重新融合母巢。……最初那位造物主至少包容九份源质这不能说明拥有两份甚至三份源质会出问题这应该存在一个临界点。……哪些存在？……第一纪早期那位上帝也可以称呼祂原初另外还有诡秘之主也就是你经常念……福生玄黄天尊。……我能确定一点是某些源质没法同时包容。在这个宇宙还有一个隐含第四支柱代表着万事万物包括旧日和宇宙本身终结它对应永暗之河与灾祸之城这两份源质。简单来说就是如果黑夜能成为永恒之暗万物奇点时空归一者那祂可以更进一步占据魔女和红祭司两条途径包容灾祸之城成为真正第四支柱但到那个时候祂要么进入沉眠要么被动分裂要么导致包括祂和我们在内……也就是说不眠者途径半神可以转去魔女途径？没错。……与旧日有关魔药配方来自哪里？第一块亵渎石板上似乎没有……它们蕴藏在不同序列0魔药中？……初步拥有全知全能权柄后我就在推演成为旧日方法和途径最终找到合适配方弄清楚不同象征。可惜那个时候原初也在我体内苏醒了……所以你作为远古太阳神陨落时用部分残躯和意志制造第二块亵渎石板？克莱恩叹口气道：从此之后末日中有曙光。……你给我那个秘偶编织什么样人性？他太累想要休息想要自由哪怕只有几秒。……你为什么不称呼他格尔曼·斯帕罗而是用那个秘偶来代替？亚当和煦问道就像在开解信徒。……我就是格尔曼·斯帕罗格尔曼·斯帕罗是我一部分如果我将两者分开即使我能逃出你神国接下来也会难以逆转失控。……你只剩下神性？……罗思德群岛慷慨之城拜亚姆。回到这里维尔杜·亚伯拉罕经过研究知道战争之神是第四纪较为活跃存在有可能回应信徒。然后他请一位自愿付出生命贫民向战争之神祈祷确认有无危险。

## 这一章新讲明的规矩
- 旧日顶＝三支柱：上帝全知全能／诡秘时空王／堕落母神邪恶之始。
- 权柄数≠全部；象征重要。
- 母神一份源质可补全；支柱象征需融母巢全用。
- 隐含第四柱：永暗之河＋灾祸之城＝终结；全占则沉睡／分裂／终。
- 不眠者可转魔女但难成旧日。
- 旧日方＝亚当推演；陨落制二板＝末日曙光。
- 人性内容：太累想休息几秒。
- 我＝格尔曼不可分。

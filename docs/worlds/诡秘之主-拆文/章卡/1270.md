# 1270 倒吊人 第五章 七光

## 打开书
听到靛光赫苏斯回答克莱恩精神一紧脑海内相继浮现出红月褐星赤星蓝星金星等星体有种它们都是眼睛正居高临下俯视自己感觉。无声无息间微妙联系建立即将到来致命侵蚀让克莱恩每一条灵之虫都出现不安。作为一名掌控着源堡天使克莱恩有太多办法切断这种联系一是利用完整神话生物位格和力量二是压制自身锚们借助原初遗留精神烙印三是依靠目前能更进一步调动源堡气息。没有犹豫他选择最简单最方便也最不会留下隐患办法。他身周隐隐约约浮现出一片灰白雾气脑海内各种星体投影随之消失。怔了一秒克莱恩组织了下语言道：这么多外神？靛光赫苏斯是祈祷领域象征祂摸了下右手戴着红宝石戒指点了点头道：自从最初苏醒又分裂整个宇宙最为强大那些外神就聚集到这个小小星系内祂们有的是要拿回自身被撕裂吸引过来源质和特性有的希望获得与本身接近可以容纳源质和高位特性。最初……七光对最早那位造物主称呼是最初而不是原初……语义上来说也没有太大区别就是了……克莱恩斟酌着问道：被撕裂吸引过来源质和特性？刚才靛光说其余内容他都能够理解并且预先就有一定类似猜测只这一条有些意外。作为冥想领域象征以爱与智慧为自身特质蓝光库图弥态度和蔼解释道：殿下您对非凡特性聚合定律应该不会陌生。见克莱恩点了下头这位额头绑着一块蓝宝石嘴巴周围留着浓密胡须老者继续说道：这不仅是序列途径规律对于源质和外神相关特性同样适用尤其本身是最初直接孕育和创造出来那些比如堕落母神混沌之子和欲望母树至于还有没有别外神属于这类我们就不太清楚了总之这三位丢失了部分源质和特性旧日……也就是说当前二十二条途径和九种源质有部分属于外神？对。拿着紫水晶象征仪式魔法领域圣热尔曼抓住机会回答道当达到二十二条途径九种源质后一切才平衡下来这也许是源自最初神秘学联系。具体有哪些？比如月亮和大地途径它们都属于那位堕落母神这是站在所有外神顶端存在哪怕被分割出去了部分源质也就是母巢也同样如此祂是整个宇宙所有阴性力量主宰。圣热尔曼刚说到这里绿光塞拉皮斯忽然笑一声：其实仔细分析那二十二条途径就会发现月亮和大地两条最为违和呵呵魔女途径代表最初阴性部分红祭司途径代表最初阳性领域刚好形成某种畸形对称可月亮和大地同样能让本途径非凡者在高序列变成……见克莱恩动了下眉毛留着艺术家长发绿光笑着补充道：大地途径序列2叫荒芜主母月亮途径序列1叫美神所以血族只有女王没有男性亲王。原始月亮就是那位堕落母神？是的。戴着钻石头冠红光艾尔·莫瑞亚威严点头道祂占据月亮通过本身位格和对母巢两条途径唯一性影响逐步侵蚀着现实原始月亮是祂在这个世界化身。祂全称是堕落母神邪恶之始不灭者污秽母巢。克莱恩想到自己刚知晓星空秘密时月亮夸张反应油然产生一阵凉意忙转而问道：恶魔和囚犯途径来自欲望母树？穿着柠檬黄长袍黄光威尼坦叹息道：嗯祂全称是欲望母树恶魔之父永世嘶吼者失心之神所以被缚之神才会在出现问题时被祂抓住机会相对容易完成侵蚀。母……父……那家伙究竟是男是女……呵还想给我生个孩子从被缚之神状态看我真要被抓住生孩子恐怕是我然后那孩子将继承源堡让欲望母树间接侵蚀和掌控……从这个角度出发也许囚犯途径放纵欲望才是扮演正途但这条正途是通向外神还是节制好啊……克莱恩眉头微皱提出一个自己有过猜测渴望得到解答问题：既然有这么多外神那祂们为什么直到现在都还没能侵入我们这个世界？从克莱恩目前了解到信息可以推测即使只有堕落母神和欲望母树外神也能轻松解决之前七神加真实造物主原初魔女等存在。胖乎乎橘光希拉里昂笑了笑道：我们一切苦难都来自最初所有幸运也来自最初。祂遗留不仅有精神意志烙印污染还有源质特性和力量。祂残余力量在星球之外构成一个无形屏障让那些外神没法直接侵入不过随着时间推移由于最初一直没能真正复活祂意志和力量都在消退第四纪尾声这达到很严重程度那无形屏障因此出现裂缝七神不得不将神国移到星界弥……等到最初意志和力量进一步衰退无形屏障消失末日就将来临？始终笑眯眯橘光希拉里昂看了眼黄光威尼坦表情一下变得严肃：是的。到时候堕落母神欲望母树混沌之子那么多外神入侵即使女神成为旧日也根本挡不住啊……其他序列0神灵联合起来能拖住一到两位外神就属于创造奇迹了……一比九甚至更多……克莱恩想得头皮发麻再次深刻体会到什么叫绝望。情绪波动一大他立刻就感觉原初精神烙印得到增强更多地侵蚀了被锚定位部分。……这就是源因地底污染不去靠近不去对抗就会自然消退原因？殿下您说得对。那是否意味着越靠近末日晋升越容易因为最初意志在消退祂苏醒会变得困难甚至不再苏醒？威严红光艾尔·莫瑞亚想了想道：这就是七神一直等到最近才真正将目标瞄准序列之上并付诸实际原因。但是最初意志会消退精神却将永远存在不会磨灭除非整个宇宙归于一点所以相应高位存在体内依旧有最初苏醒可能位格越高这个可能越大相应影响和侵蚀越严重。你们知道诡秘侍者魔药配方吗？拿着紫水晶紫光圣热尔曼回答道：这方面知识有对应神秘附着没在灵界但据我们观察诡秘侍者仪式应该和灵界有密切联系。橘光希拉里昂当即冲着克莱恩笑道：殿下到时候如果您需要我们会全力提供帮助。这热情让我有点害怕啊就和面对魔镜阿罗德斯一样……克莱恩轻轻颔首准备转移话题。你们知道福生玄黄天尊吗？过了几秒橘光希拉里昂才叹息道：我们依旧无法确定您是否就等于祂。祂是活跃于上个文明结束到第一纪中期旧日是我们口中灵界之上伟大主宰。福生玄黄天尊是祂在西大陆称号祂别称号是：时空之王命运道标源堡化身灵界支配者以及……说到这里橘光顿了顿道：诡秘之主。

# 408 无面人 第一百九十六章 十二月

## 打开书
又查自己？疑试探。塔罗组织趣但不卖己；卡平四非凡＝不小势力≈上流倾轧——夏洛克不该知。斟酌：「寻神秘组织不易且危。」塔早料笑：「不必冒险；多留意搜集情报传闻；5镑活动经费未获亦不还；有用线索逐条付＋报销花费。」条件好——重此事；报销久未闻；拒则可疑；查己宜自掌握。犹豫：「尽力。」接五张1镑；隔一两周似是而非线索。内：极光寻愚＝塔罗；望大人物追除掉A。切圣赛缪尔：索斯特考校伦怎查两塔罗仪式案。伦梳发：「一反向追寻愚者；二重查两案涉人人名单无嫌亦入；梦魇逐问排除——魔鬼藏细节看似不可能者。」索笑：涉人多居散重排难；有地下非凡善隐——需再投五序7＋辅；重点恶魔召唤。伦未恼：「只供意见采否队长定。」不解：塔罗案优先不高——前者邪神降临远重恶魔？索咖啡慢：「人手有限须优先；塔罗组织暂无明显恶意；行动反助——破真造降临／揭卡平不简单；或再帮查不好；必要调查仍须——难保将来敌。」伦：「明白；重点恶魔。」切冬壁炉雾飞逝——距新年半月。克熄炭披大衣：近三周雷帕德得脚踏车专利；蒸汽车大亨弗兰米·凯奇兴趣；今日末谈。月余波澜不惊查案细碎消化；差一次大主动表演；无迫切可再一月。兰尔乌斯1月4日聚非必去。塔罗周一次；几页罗塞尔早期日记弱鸟→花花公子。狼人倒吊代卖千镑难；诅咒望却步；前天倒吊联蒸汽工匠心动——望本周搞定；风眷配方无讯月余。正义久察终获心理炼金会认可——本周正式加入求庇佑；愿刮≥10页日记献愚无酬。尼根巨龙标本＝千面狩猎者但无特性无血。欠眷者2000至明二三月（成年财产仍受监＋格莱林特尾款）。佛经倒吊得深海枪鱼血付320存余120；狂赶稿新书冒险爱情游记风暴海盗。与多里安通信不绝——将来贝克兰德拜祭。太阳无异巡逻积功无仪；聚会假睡间歇补眠；洛薇雅七日后仍关圆塔底原因不明。A寻愚无获；知尊名者勿乱诵。埃姆林有材线——钱不够。提杖于尔根门；本能退两步。多丽丝张臂拥抱——站远收臂：「上次介绍医生太棒！近十年最健康！」克叹：「第九次说。」黑猫布罗迪衣帽架顶平衡——我亦行。「找于尔根？」「是。」谈判须专业律师。

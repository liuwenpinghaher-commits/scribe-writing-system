# 1350 倒吊人 第八十五章 抓住机会

## 打开书
向代罚者们传递信息时阿尔杰已飞快在脑海内制定接下来怎么做计划：他将抓紧时间向风暴之主祈祷希望能得到主庇佑或帮助然后立刻赶往地底利用本身非凡能力强行压制蔚蓝之门在内三件1级封印物。这个过程中如果风暴之主回应祈祷或者封印失效异常及时结束那自然不需要再考虑别应对但若是这两件事情都没有发生而自己开始感觉吃力那就向愚者先生求助。对阿尔杰来说一旦必须这么做不管采用什么方式事后怎么遮掩都难以逃脱被怀疑命运毕竟靠一人之力压制三件1级封印物确实匪夷所思。……至于拿到天灾之书概率将直线下降等后果阿尔杰目前倒是并不在意他距离需要考虑这方面问题层次还远……而在这件事情上他只能依靠愚者先生。……统治天空王者主宰大海皇帝伟大风暴之神我祈求您注视祈求您庇佑。……亚当尸骨教堂没能遮蔽住地方查拉图秘偶神孽斯厄阿历史投影连同克莱恩秘偶都在狂暴雷霆中瞬间支离破碎然后或直接消失不见或缩小焦化成一道道痕迹。……趁着空想家挡住暴君机会查拉图向前迈出那一步走入前方虚空。而这虚空被祂利用诡秘侍者非凡能力与祂提前定位狂暴海另外一个岛屿连接在一起两者间距离缩短为零。查拉图穿黑袍戴兜帽身影飞快消失在被闪电照亮虚空中可下一秒祂出现地点不是远方岛屿而是乌托邦鸢尾花旅馆上空。就在刚才查拉图被风暴之威震慑一个刹那时源堡内克莱恩抓住机会利用披在身上幕布调动源质力量强行将目标身前虚空嫁接到鸢尾花旅馆处悄然改变查拉图关键布置。……坐在愚者那张座椅上克莱恩当即将目光投向下方灰白雾气投向雾气之中无数光斑。他暂时没法找到查拉图因为对方必然掌握着只有祂或极少数存在才知道隐秘历史但无法找到不代表克莱恩只能这么看着耐心等待对方抵达极限难以再停留于历史迷雾中作为源堡主人位格达到天使之王存在克莱恩哪怕只能对这份源质做初步……下一秒克莱恩打开盒子招来愚者牌将它包容在体内。瞬息之间他变成穿五彩衣物戴华丽头饰气质幽深恐怖中带着几分滑稽荒谬感觉愚者整个源堡随之轻轻晃动。……愚者克莱恩用右掌握着星之杖尾端杵下斑驳长桌边缘。……克莱恩借助源堡将非凡特性间聚合之力直接投射到历史迷雾中！……祂本体随即出现在狂暴海另外一个岛屿上并快速利用诡秘侍者非凡能力将聚合倾向连接到一张张纸人上。……我希望我非凡特性短暂平静。祂话音刚落双掌一合已然实现自己愿望这让祂摆脱源堡加愚者牌加诡秘侍者非凡特性带来吸力。……愚者克莱恩目光从无穷高处投下来于周围扫视一圈没能找到查拉图身影。……他早有准备地让星之杖上各个宝石亮起模拟出偷盗者途径欺诈规则能力将自己肉体复活地点改到某个不在乌托邦秘偶处。……随着复活后半段进行克莱恩取出愚者牌招来之前准备好九种灵界特产将它们和那块幕布一起容纳到自己体内。紧接着他又用星之杖调动源堡力量再次模拟偷盗者途径欺诈规则能力让九种灵界特产和那块幕布成为他身体一部分。……而那个秘偶体内一条灵之虫飞出来不断裂变与光之碎片们结合在一起。……克莱恩身影刚刚勾勒完毕就化成一条条透明扭曲蠕虫向着四面八方散开让那块幕布和九种灵界特产掉落于地。然后灵之虫们完成重组部分衍变为半高丝绸礼帽和衬衣马甲正装长裤。克莱恩没有浪费时间立刻摄起那块幕布和灵界特产们认真调配起魔药。于他而言这是晋升诡秘侍者最好时机。一方面仪式效果已借助灯神完成而这不会一直维持将逐渐消失另一方面最有可能破坏他仪式亚当正被风暴之主压制腾不出手来干扰。如果平时服食魔药晋升序列1克莱恩真担心空想家亚当会于关键时刻借助集体潜意识大海悄然给自己一个负面情绪那样一来失控是必然结局。他刚才呼喊列奥德罗主要目的不是对付查拉图而是拖住亚当这位真神！——举行诡秘侍者仪式时没法提前用源堡力量扭曲一个神国雏形出来隔绝内外让克莱恩在里面晋升因为那会导致仪式与灵界对应区域无法建立起联系从而失效。不到十秒一瓶幽暗仿佛夜晚海水魔药出现在克莱恩掌中与此同时他留在源堡内身影啪打个响指满足祈祷光点和深红星辰内积攒少量愿望让奇迹师魔药最后一点彻底消化。源堡内身影随即自行淡去让克莱恩本体变得完整让他能以最好状态服食魔药。雷霆又一次照亮大海时克莱恩抬起右手将来自秘偶那个瓶子凑到嘴边咕噜喝下里面轻如空气般魔药。

# 1295 倒吊人 第三十章 天文学爱好者

## 打开书
埃里克是在之前那场战争后期成为红手套队长并晋升为序列5灵巫。他见证过前任和前前任队长身亡知道更高序列不是让自己更安全第一保证谨慎和小心才是。对于值夜者里面精英红手套来说这是一个几乎所有人都信奉理念因为普通值夜者遭遇或许只是看起来像超凡事件普通问题偶尔出现疏漏也有极大概率靠自身非凡能力扭转局面……已经有两名值夜者在这里失踪我们绝对不能大意。……警察局确定这一点后立刻将案子转交给黑夜教会可前来处理两位值夜者同样失踪403室房门依旧紧紧闭着。基于这样前提黑夜教会间海郡大主教将事情委托给埃里克小队并允许他们申请一件1级封印物辅助。是队长。这支红手套小队成员们或点头或开口相继给出回应。……最先是站在门边那位前值夜者最后是坐于天文学望远镜后面那个穿棉质衬衣男子他一只黑白分明眼珠还粘在镜片上只能用剩余那只和黑幽幽窟窿扫过门外红手套小队。……埃里克本能就要抬手敲击牙齿释放更多灵出来然后用梦魇非凡能力将面前目标全部强行拖入梦境。但是无论他怎么敲动牙齿都没有灵被释放出来他与灵巫相关非凡能力似乎一下消失。与此同时红手套小队中一位梦魇也惊讶发现自己无法拖人入梦了！……离开这里！埃里克没有犹豫低声下达命令。……他和他红手套小队还没有和目标真正接触就陷入一场看着自己一点点死亡并肿胀腐烂清醒噩梦难以挣脱。……403室深棕大门又一次关闭将埃里克和他红手套小队与房间内生物隔断。……我真诚建议你们现在就回去将事情交给大主教或高级执事们处理当然你们还有另外一个选项那就是向我许愿我是一个流浪魔术师叫做梅林·赫尔墨斯最擅长满足别人愿望。克莱恩不遗……如果我们不向你许愿你是否就不会解决房间内异常？……即使你们不许愿我也会尝试解决。……向你许愿需要念出你尊名或者真名吗？埃里克与队员们交换下眼神后问道。……不用说出你愿望就可以了。……那我希望这个房间内异常得到解决不再对周围产生影响。……你愿望将得到实现。……里面异常能压制非凡特性让相应能力失效但这不是绝对。一般遇到这种情况我建议是……我建议是用太阳领域1级封印物做覆盖式净化。将刚才那句话说完同时克莱恩想起廷根市查尼斯门后变异太阳圣徽这虽然只是一件3级封印物但只要给它足够时间一样……解决了？埃里克犹豫下问道。……没有问题根源还在。你们对这里主人做过身份调查吗？……他自称约翰是一位天文学爱好者喜欢在夜晚用专门望远镜研究星空。……你们搜查一下这里寻找可能存在线索。不知为什么埃里克突然觉得梅林·赫尔墨斯先生像是自己刚加入值夜者时队长专业镇定让人信赖。……这眼睛仿佛直接贴到天文学望远镜另外一端透镜上灰白为底淡黄做瞳内部一根根血管肿胀起来渗透出恶心半透明脓液。

# 525 旅行家 第四十四章 永恒之梦

## 打开书
罗思德群岛是鲁恩王国在中苏尼亚海域统治支点同样也是风暴教会关键教区长期有一位能参与枢机会议高级执事驻守此地。当然将军这个层次海盗都未必能惊动这样大人物更何况只是所谓二副和水手长执事科尔多瓦·罗耶愉快接受命令带领两支代罚者小队启用了封印物2-37和2-166埋伏于距离香树大道15号较远地方务求万无一失。在科尔多瓦看来一支代罚者小队配上两件封印物就足以对付钢铁一群人加烈焰但后者反向留意追捕者行踪表现让他有些担忧直觉认为藏着一定问题所以又多叫了一支代罚者小队。其实有2-37就足够了…等待间忽然感叹一句。在他看来这件封印物将是钢铁和烈焰等人噩梦。闭闭眼睛脑海内自然浮现出相应资料：「编号：37。名称：永恒之梦。危险等级：2危险谨慎且节制利用只有三人以上行动或执事教区主教才能申请。保密等级：主教小队队长及以上。封印方式：放置于煮沸水中。描述：外形如同一颗心脏颜色深黑触感冰冷布满空洞时常发出风笛般声音。这件物品来源于南大陆西拜朗一个原始部落他们以灵巫为首领过着白昼休息晚上行动生活。一支鲁恩军队征服了这部落得到了被供奉于祭台上这件物品并于之后一周内陆续出现士兵失常发疯自杀等事件。研究表明只要接触过这件物品就会进入一场漫长梦境如果不被人唤醒将永久停留在那个虚幻世界里外在表现出焦躁恐惧迷茫等情绪心理和生理状态逐渐改变。被唤醒研究员依然长时间分不清楚现实和梦境这导致了一系列悲剧事件发生包括但不限于向上司示爱亲吻毒蛇嘴巴罹患忧郁症脱掉衣服裸奔试图用沸水洗澡…如果不将他们调离至另一座城市结局只有疯掉和自杀两种可能。这件物品可以被利用将让目标范围内活着生物进入同一场梦境…使用者可以在一定限度内选择目标排除同伴…范围最大值为半径50米超过将对使用者造成极大负担留下强烈精神创伤…使用者事后会进入分不清楚现实和梦境状态必须离开2-37所在城市才有希望康复。多起例子表明即使不接触这件物品也会广泛影响周围人群除非将它放置于煮沸热水里…附录：1.与黑夜途径梦魇效果类似但更为突出且不受控制。2.例子1：一位看守者忘记添加木炭导致火焰熄灭沸水温度降低他很快有了异常表现疑似梦到心爱姑娘对着自己拳套做出热情洋溢表白并试图与它发生超友谊关系…」思绪转动间突然看见烈焰这位黄金梦想号第四水手长果然来到这联络点想要收取情报。做了个手势示意旁边代罚者队员打开铭刻着诸多象征符号和魔法标识金黄色方盒将浸泡在沸水里封印物2-37取出。这黄金铸就般盒子则是另一件封印物2-166。它能让内部物品保持原本温度并一定程度上改变天气下一场太阳圣水雨。当然它也有很大负面作用否则代罚者们早就用它来封印2-37而不是临时取巧其中最让人无法接受是不管什么物品只要与它接触时间足够久都能染上活着特性并且虔诚信仰永恒烈阳在代罚者内部已经出现过天天歌颂永恒烈阳桌子每一秒钟都想点燃自己净化一切蜡烛。——暴躁代罚者让那张桌子变成一堆木柴点燃它正是后面那根蜡烛。眼见一道道人影出现冲入香树大道15号毫不犹豫就按下右手让身旁队员启用封印物2-37。那位队员手掌表面当即浮现虚幻鱼鳞直接从沸水里抓出漆黑心脏般封印物。悠扬风笛声随之响起氤氲夜色笼罩香树大道15号那栋房屋。冒险家约翰·史密斯等人眼前景象未变依然是没有家具空荡客厅和披着黑色斗篷烈焰毫无进入梦中感觉。他们努力奔过去努力开枪射击努力使用自身能力成功重伤烈焰并抓住这位悬赏金额3000镑且涉及死神钥匙知名海盗。然而现实世界里他们在原地做着高抬腿或游泳般伸展双臂或用手指做枪嘴里发出砰砰砰声音。「行动！」科尔多瓦当先离开隐蔽处冲向香树大道15号那栋房屋其余地方代罚者小队队员分成两批从不同位置完成包围。科尔多瓦未抵达前客厅里面已光芒大亮仿佛有一轮太阳正冉冉升起神圣纯净水滴则如同雨水洋洋洒洒落下正是封印物2-166在发挥作用。距离较远地方飞毯静静悬浮被黑暗遮蔽钢铁等人一看到代罚者们出现就明白这果然是烈焰陷阱。「这婊子养的竟然投靠了风暴教会！」麦维提眼神疯狂低吼。「血色荆棘」看了冷静斯考尔一眼由衷赞：「幸运的是我们没有大意。」「其实我也没想到烈焰这头蠢驴会和风暴教会合作。」斯考尔平静说「也许受伤他早就被代罚者抓住不得不配合。」他们正要就此离去忽然看见香树大道15号那栋房屋外阴影里有什么东西凸显出去贴于地面飞快向远处游走。「烈焰！」钢铁回想起之前埋伏失败场景。「达尼兹！」亨特利也认出这以奇妙能力尝试逃脱家伙是谁。斯考尔先是一愣旋即明白过来：「要么是烈焰想趁这机会逃离代罚者控制要么他另有陷阱对付我们结果不知为什么惹来代罚者只好果断放弃慌忙逃跑。」「不管怎么样这都是一个机会！」血色荆棘望眼刚冲进房屋代罚者道「只要把握住那短暂几十秒时间我们就能在代罚者眼前杀掉或掳走烈焰！」钢铁一下兴奋眼神变得异常疯狂。在斯考尔点头后对另外两位非凡者道：「你们带着我活尸和傀儡守在这个位置一旦代罚者追过来就让它们制造混乱自己趁机脱离！」「是头儿。」两位非凡海盗与那些活尸傀儡同时跳下飞毯。孔雀蓝地毯转了个弯追到烈焰前方。「你辅助我们主要防备周围我担心达尼兹还有别帮手。」斯考尔抓紧时间对血色荆棘说。亨特利略显苍白脸上露出笑容：「好！」斯考尔不再多说对钢铁点下头。靠着居高临下优势麦维提分辨出那几乎没有异常多余阴影判断出目标游走方向。猛然跳下飞毯如同巨石重重落在地面脚底白霜凝聚寒冷而透明冰层飞快往侧方蔓延。黑色阴影当即被冻在墙角！喀嚓一声烈焰竭力挣脱从阴影里长出来。飞毯上亨特利则配合良好丢下早就握在掌心事物那是片片绿叶朵朵鲜花和根根荆棘。树叶花瓣荆棘或疯狂变大或连接在一起贴住缠绕住烈焰让他寸步难移。斯考尔趁机跳出飞毯借助下落之势将右掌中锋利手术刀插入达尼兹脖子。噗嗤！右手拖住刀柄一绕一转来到目标身后。达尼兹脑袋一下掉落身体飞快扁缩化成一个薄薄破烂纸人。与此同时钢铁感受到一种难言喻强烈饥饿感只觉它就像潜藏于黑暗中恐怖怪物正静静注视着自己。不不是烈焰！心中刚闪过这样念头一个压缩到极点炽白火球就从某个屋顶飞过来砸向他身体。钢铁对此只做一个动作那就是抬起手臂挡在身前。轰隆！火焰爆开气浪横飞阻挡住斯考尔和亨特利视线但他们却一点也不慌张对钢铁有着强烈信心。果然麦维提只是衣服破碎皮肤略有白痕未受任何伤害。可就这时他突然看见半空翻滚火浪里走出一道充满疯狂意味人影明明穿是烈焰黑色斗篷却有着梳理得很整齐黑色头发毫无情绪波动深棕眼睛瘦削而冷酷脸庞。刚才达尼兹一直是无面人克一直是准备狩猎格尔曼·斯帕罗！

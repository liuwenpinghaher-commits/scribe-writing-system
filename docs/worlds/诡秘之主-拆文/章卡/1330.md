# 1330 倒吊人 第六十五章 助人为乐

## 打开书
对于杀人文德尔一点也不陌生闻言并不惊恐相当冷静让目光越过门口那位女性投入房间内部。他旋即看见一个倒在地板上男子看见对方胸前一片血红。确定已经死了吗？文德尔平和提出一个问题。那名二十来岁小姐先是茫然接着不太确定回答道：应该……我不知道……如果还有救需要立刻送医院。文德尔口吻就像在对患者家属说话而不是一名凶手。……确实已经死亡。……你报警吧。怎么称呼？文德尔已听见楼梯上传来急促脚步声。……翠西……那位野性与清纯皆备小姐低声回答道。……女神啊！这位上年纪老者看清楚房间内情况后忍不住喊叫一声。……你立刻去报警我会看住这里。……杀人并不是都会被判重刑这分很多种情况。……他殴打你？嗯。对方似乎有着某种权威性让想要保持沉默翠西最终还是做出回答。……是你带到这里来还是他？他。……正当防卫是符合法律规定我可以向警察证明你们事前正发生激烈争吵并且出现打斗很显然在这方面男性是天然占有优势。我不是歧视女性而是科学和经验都这么告诉我们。……你们之间究竟是什么关系发生什么事情？……我是呵我是他情妇。……我曾经是一个追逐金钱到失去理智丑陋女人在离开文法学校没多久就在他引诱下成为他情妇。他给了我一家旅馆让我待在那边每周等待他来临或者召唤。我对这种生活逐渐失去兴趣我越来越压抑和自卑我想把所有东西都还给他彻底摆脱他可他不同意他用各种方式威胁我不让我离开他我们最近几次碰面都是在争吵中度过。刚才他说离开他只有一个办法那就是死亡然后他殴打我并拿出匕首后来后来事情你都知道了……现场痕迹也初步证明事情发展。……谢谢。……先带她去验伤处理伤势避免出现意外。……感觉到了吗？生命美好。文德尔认真对翠西说一句。……谢谢。……做完他该做事情文德尔走到街边预备乘坐出租马车返回鸢尾花旅馆。……这就是小城坏处不够方便。文德尔低语一句撑开出门时带上雨伞辨别好方向原路往鸢尾花旅馆返回。作为曾经治安官他对自己走过路线有着神秘学意义上记忆能力根本不担心会在陌生小城内迷路。……乌托邦是个不大城镇文德尔走差不多一刻钟就看见鸢尾花旅馆这个时候他礼帽和衣物都因风太大被淋湿一些。……刚才那位翠西小姐你认识吗？不认识。……我听说她确实是本地人可我今年之前一直生活在城外种植园内。你对她有什么了解？文德尔下意识追问一句。她每个月会来我们旅馆三到五次和死掉那个男人。服务生忽然叹口气她一点也不开心。……乌托邦。文德尔精神一下绷紧只觉外面风声和雨声骤然停止了。

## 这场戏有没有翻
翻了。开头冷静验尸助翠西正当防卫；生命美好；回鸢尾花问翠西；服务生「本地人每月来」；章末念城名风雨骤停。翻的是助人为乐＝戏中戏圆＋城名触发异。

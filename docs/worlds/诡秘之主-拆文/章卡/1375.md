# 1375 倒吊人 第二十三章 半个旧日

## 打开书
比灵界更加抽象仿佛囊括着整个宇宙所有权柄和象征星界之内所有事物都呈现出来而照亮这里光芒并非平均分配它们主要集中在几个地方层层叠加交织成仿佛厚棱镜斑块。这样斑块共有三个它们分别封住不同虚幻国度。那些国度有的长满鲜艳花朵天空一直明亮有的似乎由一本本或摊开或合拢书籍组成不同身影穿梭其间以阅读为乐有的是一片笼罩着狂风暴雨电闪雷鸣永不停息无垠大海。下一秒这三个不同国度内同时产生剧烈变化。……它带着部分物质接近速度极限以此创造出可以毁灭星球狂暴波浪。这样波浪连同那点光芒接连不断地拍打着厚棱镜般光之斑块让它掉落数不清辉芒。……以混沌海为源泉以自身和真实造物主为支柱空想出三个唯一性并将它们纳入这个体系亚当似乎超越序列限制成为半个旧日仅凭一己之力就强行压制住永恒烈阳风暴之主和知识与智慧之神将这三位序列0真神困在各自神国内部！……祂以空想家和倒吊人这两条途径为重生后根基除它们各自具备复活特殊还因为这是祂研究出来最有概率成为上帝选择：以空想家和倒吊人两条途径之一成为真神初步掌握混沌海后依次收回剩余唯一性和序列1非凡特性是晋升星界之主相对最容易风险最低道路。而这里面空想家相比倒吊人还多一点特殊之处。当空想家初步驾驭混沌海并在某种程度上容纳第二份唯一性和相应序列1非凡特性后祂可以依靠空想具现出剩余虚假象征和权柄让自己短时间内获得超越序列层次拥有半个旧日实力。不过在第三纪尾声远古太阳神计划是：在被刺杀后立刻于巨人王庭萨斯利尔处复活先行收回倒吊人唯一性和三份序列1非凡特性重新成为序列0真神然后再借助放在旁边第一块亵渎石板初步掌控住混沌海……等到搭建起这样体系远古太阳神会利用倒吊人放牧能力和空想家分离虚拟人格手段驾驭太阳阅读者水手三条途径唯一性和各一份序列1非凡特性让自己在位格和实力上无限接近旧日且保持住最低限度稳定。祂不直接包容混沌海容纳其余三条途径唯一性和序列1非凡特性是不想在当时那个年代晋升旧日变为支柱那会不可避免导致上帝复苏让祂自我失去。……而当时祂没准备以空想家为基石是因为祂没拿到阿勒苏霍德之笔缺乏一份主材料等到天使之王们背叛计划惨遭失败在亚当身上复活过来之后祂才决定趁这次灾祸带来机会走最好那条路。……第一块亵渎石板！阿蒙曾经用它来封堵门先生回归仪式带来缺口阻止堕落母神入侵。等到回归仪式结束血肉之门彻底坍缩不再有通道能够维持祂又取回这块亵渎石板。……第一块亵渎石板落下后准确地插在山峰顶端幻化出一片包容着所有颜色虚幻大海。与此同时阿蒙进入星界看到那座被嫁接到此处霍纳奇斯山脉主峰看到峰顶古老破败宫殿。……黑夜女神！……黑夜女神空着两条手臂抬起来托住一团近乎无形迷蒙雾气。这雾气表面一道接一道不同形状门于不同位置飞速打开却又被瞬间堵住没法产生漏洞。黑夜女神漂浮在星界之内霍纳奇斯山脉主峰顶端专注掌控起手中那个迷雾世界不让阿蒙真身逃脱出来。随着门出现越来越多打开越来越快这位女神仅凭自身已无法应对只能抬高另外两条手臂举起长长巨镰。……那近乎无形迷雾世界被塞入这棺椁中所有动静瞬间停息似乎已同时死亡。可这样安静只维持一秒构成棺椁浓黑雾气表面又有一扇接一扇门成形并打开。黑夜女神一边封堵着这些门一边扬起拿着鸟型黄金饰品手臂。……门成形和打开随之放缓双方进入拉锯阶段。就在这个时候黑夜女神脚底霍纳奇斯山脉主峰轰然坍塌了。……灰白急速蔓延中这些触手疯狂涌向古老破败宫殿涌向正要容纳愚者唯一性克莱恩。原初魔女奇克！

## 这场戏有没有翻
翻了。开头亚当半旧日一压三正神神国；空想家基石密研／旧计划对比；阿蒙投第一亵渎石板；女神棺雾困阿蒙真身＋鸟饰缓门；峰塌奇克触手扑克莱恩。翻的是半个旧日＝亚当顶三＋魔女破峰。

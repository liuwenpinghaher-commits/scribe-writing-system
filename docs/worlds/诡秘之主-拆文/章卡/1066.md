# 1066 红祭司 第一百二十一章 精灵编年史

## 打开书
克莱恩腹诽防火防盗防从神——赫拉伯根萨林格尔巴德海尔欧弥贝拉托尔兹纳阿曼妮西斯皆可能活远。奥黛丽扮女性精灵套话。编年史无第一二纪概念：初混沌疯狂萌芽年代；后火之初耀（泛人类抗非人，人是巨人精灵血族附庸，<千年）；莉莉丝等背叛陨落后双生年代（巨人巨龙强势）。要点：确有东大陆=巨人王庭所在；萌芽后已有文明非无理智。精灵语：王萌芽年代创，一词一生初代精灵。回珊瑚宫窗：故乡在哪。出梦见莫贝特被精灵缠床。奥黛丽柔笑。遇龙泽尔：一百多年前士兵？要法官惩戒骑士配方；引导美梦与家人团聚。赴格罗塞尔家——探索末站，将入集体潜意识寻书存在秘密。

# 1296 倒吊人 第三十一章 奇迹之“森”

## 打开书
砰！高度戒备红手套队长埃里克身体莫名一颤看见那位自称梅林·赫尔墨斯流浪魔术师在天文学望远镜后面直接爆炸。但是这并没有飞溅出血肉破碎肢体就像肥皂泡沫一样迅速消失在空气中。……埃里克和闻声望过来小队成员们全都陷入呆愣状态不明白怎么会突然发生这样变化。……撤离！……问题根源确实是那架天文学望远镜。……这究竟是怎么一回事？埃里克强迫自己忘记对方死去又出现事情斟酌着开口问道。作为一名经验还算丰富红手套队长他对整件事情真相是有一定猜测提问目的主要是寻求确认。……简单来说就是这架天文学望远镜不知因为什么出现异变导致房间主人看到不该看见事物。如果你们想了解更详尽细节只能自己搜集线索我也不太清楚。……房间内遗留线索不多我们只能确定几件事情：一约翰是本地居民在战争中服过役精神状况似乎因此出现一定问题；二他很早就是天文学爱好者战争结束后加入一个叫做天体研修会学术组织但我们之前并没有搜集到关于这个组织……说到星空这个单词时埃里克稍微停顿一下似乎得到过夜黑教会上层警告。战争结束后加入一个叫做天体研修会组织……寻找看见真实星空办法……克莱恩结合刚才体验对事情有一定程度上把握遂轻轻颔首道：你们应该都清楚星空意味着危险甚至不能去了解。我们会尽快把这起案子上报给大主教将天体研修会定义为危险组织。埃里克就像在和不直接负责值夜者上司交流一样说道。……战争确实对各个方面都产生不可逆转影响……战神陨落后本就摇摇欲坠原初屏障失去一部分支撑而黑夜女神暂时还未完全掌握相应唯一性至于成为旧日更是不知道还要等待多久这种情况下外神们对这个世界侵蚀自然就……克莱恩怀疑战后重建这段时间内鲁恩各地已悄然出现不少指向星空指向不同外神邪教组织如果放任他们发展信徒做各种高危尝试末日肯定会提前。……克莱恩穿行于墓园内依靠灵性指路找到一块墓碑。……韦尔奇·麦格文。这是克莱恩原身大学同学因为买到安提哥努斯家族笔记诡异死于廷根这间接导致周明瑞穿越。……你是谁？韦尔奇父亲望向坟墓前陌生人既疑惑又警惕问道。……叔叔我是韦尔奇朋友最近刚好经过康斯顿城。……他是个喜欢交朋友人我只认识其中一部分。……您有什么需要帮助吗或者说您有什么愿望想要实现？我希望能提供一份力量。……你能让这里所有死者重新站起来吗？……那你能让康斯顿恢复原本样子吗？韦尔奇父亲苦笑着又问一句。……没必要提供帮助能实现我自己就能做不能实现只能祈求神灵。……我会尽力。……我是一名记者想从不同人身上搜集战争中发生各种故事最好是自己亲身经历过我能提供报酬是免费满足你们修缮和重建房屋愿望我在这方面有足够资源。梅林·赫尔墨斯。……看得懂上面文字吗？坐在木板旁一个瘦弱男子抓住机会开口问道。……这是真？真那位记者先生就坐在那个角落里戴着很高礼帽。瘦弱男子热情指出方向。……你真会帮我重建房屋吗？他有点忐忑有点担忧询问道。……我们可以签合同。……不用哪怕你只是提供一些材料我也很满足了。那男子坐到克莱恩对面颇为拘谨说道我没有太生动故事。足够真实就行。克莱恩微微点头给予鼓励。……我是康斯顿本地人曾经有一个还算体面工作在淡潮街买下栋联排房屋后来战争爆发我房子在一次轰炸中变成废墟我长子那个刚进入初等学校孩子被埋葬在里面……我们不得不又租两居室房间直到弗萨克人占领康斯顿他们他们拖走我妻子她再也没有回来……前段时间有人通知我去认尸我没法认出她她腐烂得已经不像样子不过她残余衣物口袋里还装着还装着我们自来水账单……她在出租屋时候一直很怀念我们家我小女儿也是我现在没什么钱只能勉强维持生活但我希望能一点点重建那栋房屋。坦白讲我非常不喜欢将自己不幸告诉别人我宁愿沉默可如果真能在重建这件事情上获得帮助那我可以……你愿望会实现你明天去淡潮街那栋房屋废墟前等我。……这是请你喝酒钱。……曾经康斯顿城完整重现在他眼前沐浴着橘红晨曦。

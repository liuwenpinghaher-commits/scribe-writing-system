# 1268 倒吊人 第三章 “愿望”之力

## 打开书
克莱恩原本以为愿望能力是自己随意发挥只要不超过一个上限谁知道它效果并不仅仅来自非凡特性。简单来说奇迹师必须先搜集和满足各种各样愿望然后才有可能在战斗时通过向自己许愿方式将相应情况变为现实而且最开始时候克莱恩能实现愿望都很小必须一步步积累才能创造奇迹不能想怎么来就怎么来。嗯如果想像乌黯魔狼科塔尔那样以许愿方式转移位置那我必须预先满足过许多类似来自他人从简单到困难愿望……这方面倒是有取巧办法我可以利用蠕动饥饿和星之杖来满足相应愿望无需从最简单开始……说起来愿望能力有点像利用锚属于集众类型既然信众们对神灵认知可以有效影响到神灵成为某种程度定位帮助祂们对抗非凡特性内原初精神烙印那不同灵性生物相似愿望确实可以帮助我创造奇迹……这也许和集体潜意识海洋有关不够科学但足够神秘学……弄清楚愿望能力情况后克莱恩对怎么扮演奇迹师也有初步想法。那就是行走于现实世界作为最高级魔术师让不同人见证奇迹满足他们愿望。难怪乌黯魔狼当初称号是愿望之神……当这样信仰传播开来不少人通过祈祷方式说出愿望让奇迹师能够隔空回应扮演确实会简单不少能节约很多时间但问题在于魔药名称叫奇迹师而不是愿望之神需要扮演不是一个神灵……我可以一边流浪于各个国家让不同人见证奇迹一边以愚者名义部分满足信徒愿望看哪种更有效果……不过奇迹师扮演守则不会只有这么一条……还要主动地在现实创造近乎奇迹事情留下相应传说？克莱恩手指轻敲起斑驳长桌边缘于心中无声自语几句。在刚才审视中他发现自己刚服食完魔药就消化大半毕竟他已经屡次创造奇迹就连复活都达到三次。当然克莱恩认为这非常取巧因为他能创造奇迹提前扮演更多是依赖源堡。简直就像是被人安排好一样……克莱恩暗叹一句心中不觉轻松反而愈发凝重和戒备。……远古太阳神口中诡秘疑似福生玄黄天尊那位存在。而更让克莱恩疑惑是在自己晋升序列2成为天使完成质变后福生玄黄天尊并没有出现并没有在他体内初步苏醒。甚至一点痕迹都没有除了必然会到来原初精神烙印污染嗯应该是原初遗留在非凡特性内精神烙印……难道福生玄黄天尊在安排好一切后已经死透了没有能力再影响我从我体内复活？如果真是这样那我必须得好好感谢祂！克莱恩自我调侃两句……瞄了眼悬吊于头顶诸多透明蚕茧克莱恩缓慢伸出右手触碰向光门。已真正成为这片神秘空间主人他在回归时就清晰认知到一个事实那就是奇异光门才是这里核心是真正意义上源堡而这片无垠虚空属于源堡自带神国。至于古老宫殿有二十二张高背椅青铜长桌和塔罗会成员们平时具现物品克莱恩认为是愿望之力一种体现。也就是说当他心中想要那么一个宫殿一个聚会场所时源堡满足了他愿望。而由于他愿望没有具体描述源堡是从过去类似愿望里提取场景——克莱恩怀疑古希腊式宫殿和刚好有二十二张高背椅古老长桌都是当初疑似福生玄黄天尊那位存在具现过。霍然之间那扇光门出现轻微颤动连带上面悬吊有着一个个人影蚕茧都开始按照同样规律晃荡。果然我能初步使用源堡力量了……靠着这一点如果我在灰雾之上已接近天使之王层次而且展现权柄不仅仅是奇迹还包含部分旅法师和部分命运木马……若是回到现实世界除了能更进一步利用源堡气息还可以直接索取部分力量……这应该可以让我构建一个神国雏形在里面达到序列1层次……可惜现实里还没法使用偷盗者和学徒高层次非凡能力……克莱恩一边评估一边将目光投向悬吊……确认好各方面情况克莱恩返回古老宫殿内坐到愚者那张高背椅上。……旧日外神星空造物主序列之上……原来是这样……这一刻他完全明白之前神战意义明白末日可能来源明白七神对黑皇帝诞生默许对红天使恶灵回归现实漠视。从伦纳德正义小姐提供消息看鲁恩获得最终胜利战神很有可能已经陨落……也就是说女神成功了但不知道祂距离序列之上旧日还差什么条件……等下召唤阿罗德斯询问询问各方面具体情况把握住当前局势……想到这里克莱恩回……那位不知道究竟是谁大地母神能成功扮演巨人王后欧弥贝拉几千年而未被识破没有隐秘帮助是绝对不可能……嘶女神从第三纪甚至第二纪尾声就在谋划相应事情了？感觉感觉比阿蒙还恐怖……嗯隐秘仅能隐藏各方面痕迹误导相应窥探和占卜没法让一个人做出伪装大地母神能假扮欧弥贝拉而没被战神怀疑可能还有别因素……比如某位存在帮祂窃取到巨人王后命运？……如果真是这样女神和远古太阳神应该很早就有合作关系了直到那位新造物主体内苏醒了原初……这也能够解释为什么暗天使萨斯利尔寻找帮手时最先考虑存在是女神……从拿到死神途径唯一性开始女神就在布局了……之后无论是默许乔治三世成为黑皇帝还是为我破坏对方仪式提供帮助女神都不在乎事情最终结果是什么样子祂主要目的是展现自己没有能力直接插手现实状态更进一步深化祂正在容纳死神途径唯一性形象……于战神而言……先动摇女神锚……然后才连同大地母神一起围攻女神……这正好落入女神陷阱……换句话说就是女神之前种种表演真正目的不是在死神途径唯一性上挖坑而是让其余神灵将关注点放在这件事情上忽略掉大地母神有问题可能……真是可怕啊……他摇了摇头具现出纸笔写下对自己告诫：永远记住自己是他而不是祂。

## 这场戏有没有翻
翻了。开头愿望须集众积累；消化大半像被安排；触光门近天使之王；章末看穿女神局写下他非祂。翻的是愿望之力＝集众奇迹＋认知升级戒神化。

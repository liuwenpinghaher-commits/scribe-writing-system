# 1317 倒吊人 第五十二章 七位委员

## 打开书
奥黛丽右手略有停顿旋即恢复正常拿起那张被称为傲慢人格面具。50%概率并不低。她简单回应鲍利·德尔劳一句。这是在说二选一情况下挑中赫温·兰比斯曾经戴过那张人格面具不是一个让人诧异巧合。说完奥黛丽将那张冰冷灰白面具戴到脸上。几乎是瞬间她感觉自己心灵岛屿内多了个虚拟人格。……他们受教育程度很低必须在我引导下才能做出正确选择。不是每个人都有足够智慧恰恰相反绝大多数人都很愚蠢。……他们值得怜悯但不值得交流。……这就是傲慢吗？如果不是她早就通过与世界先生倒吊人先生隐者女士等人交流摆脱认知误区刚才说不定会被傲慢面具虚拟出来人格真正影响到。……你恢复正常速度比我想象快很多看来你并没有迷失在操纵别人体验里。德尔劳赞许说道。……赫温·兰比斯先生一直表现得有点傲慢……你能观察得出来？只是偶尔一些细节。……赫温·兰比斯被这张人格面具影响程度比我预计严重……傲慢会让他看不清脚下道路会让他瞧不起弱于自身非凡者而这往往会带来极大危险。……这七张人格面具可以放大相应认知和情绪帮助我们意识到自己问题从而有针对性地解决同时它也会带来一定负面影响不知不觉改变佩戴者人格？……在心灵领域很难有纯粹没有伤害外在帮助必须有足够内生力量才能避免相应负面影响。……这是我们心理炼金会评议团委员之一暴食先生。德尔劳为奥黛丽做下介绍。接下来其余几名心理炼金会评议团委员相继抵达分别是色欲先生贪婪女士懒惰小姐和嫉妒先生。……我们再等一位朋友他将是评议团第七名委员呵第八我忘记算自己了。……很不幸你只有一个选择了。德尔劳微笑指指桌上暴怒面具。……我一向很温和正好可以体验一下暴怒感觉。……等这位暴怒先生坐到奥黛丽旁边德尔劳轻拍手掌道：我正式为大家介绍新加入评议团两位委员。这位是傲慢小姐这位是暴怒先生他们都是半神……其中傲慢小姐负责是鲁恩王国贝克兰德大区。……你或许还不清楚我们根植在心理学家精神科医生和相应爱好者这几大群体内力量主要集中于大都市而不是小城和乡村所以每一名委员负责是某个城市连带周围区域。……暴怒先生负责伦堡首都艾萨拉；色欲先生负责因蒂斯首都特里尔；贪婪女士负责弗萨克首都圣密隆；懒惰小姐负责费内波特首都费内波特城；嫉妒先生负责因蒂斯共和国第利斯城；暴食先生负责鲁恩王国康斯顿城。……傲慢小姐受战争影响贝克兰德心理炼金会有不小损失很多成员都失去联络我之后会将具体名单给你你负责确定那些成员下落并重新将他们组织起来。在这个过程中我建议你不要用自己真实形象和真正姓名虚拟一个甚至多个身份来完成这些事情赫温·兰比斯在这点上就做不够好我想他确实有一点傲慢。……今天要讨论第二件事情是鲁恩王国东切斯特郡那条心灵巨龙下落。赫德拉克村庄巨龙崇拜风俗在这两年内没有一点弱化我怀疑那条心灵巨龙还在以某种方式影响着那里也许我们可以借此找到它下落。……这是鲁恩事情我们不太适合插手。色欲先生环顾一圈道除非傲慢小姐和暴食先生确实没有时间。奥黛丽又等几秒见暴食没有开口才看向德尔劳道：我会试着调查但我需要更详细资料。

# 497 旅行家 第十六章 人设

## 打开书
对峙壮汉一个穿海军特有蓝白条纹衫在接近零度寒冷天气里依然裸膀子。手拿匕首抵住对面男子喉咙但自身却被一把能进入博物馆陈旧手铳正正指着眉心。手铳主人同样超过一米八肌肉结实脸现油光壮汉剃掉头发纹着海雕嘴里骂骂咧咧：「狗屎海军！在达米尔港还没有人敢诬蔑我是海盗线人！」那海军毫不示弱与他对骂双方尽情展示海上丰富脏话用词。克旁观几秒沿边缘绕过到来腰佩直剑暗藏手铳艾尔兰船长身边冷静随意问：「发生了什么事情？」「两个醉鬼争吵在达米尔港在周围海域一直有这样传闻海雕洛根服务于黑色郁金香号主人。刚才那位海军提到这点却正巧被海雕遇上。」黑色郁金香号主人？不就是地狱上将路德维尔吗？转身坐至吧台前高脚椅轻敲木制台面：「一杯南威尔啤酒。」「6便士。」肤色古铜牙齿洁白酒保擦着杯子一点也不热情说。在陆地特产上物价比贝克和廷根高不少…掏出一把铜币数了6便士给对方。这时洛根和海军冲突被酒吧守卫阻止各自说着狠话向不同角落退去。也许丢面子关系那海军隔十几秒就匆匆离去酒吧内氛围重新变得热烈。「要玩牌吗？」艾尔兰指酒吧侧面楼梯。「不。」主要目的来搜集情报。艾尔兰下意识想拍他肩膀但却被冷峻锐利气质阻止只能顺势整理暗红外套提醒一句：「不要在这里找女人。」点下头拿起装南威尔啤酒杯子咕噜喝一口。「还有不要相信这里任何人他们只有很少一部分话语是真的。」端着属自己烈朗齐踏上通往二楼阶梯。侧头望他一眼表情不变反问：「包括你吗？」「…也许。」先是一愣旋即哈哈大笑：「至少我刚才提醒是真的嗯我是个男人也是真的！」那可不一定…这世界上有种魔药叫女巫…收回视线边慢悠悠喝酒边听周围酒客吹牛。过两三分钟一个矮小瘦削男子端着自己酒坐到身边。「伙计你像是个冒险家。」微微侧头露笑容。打招呼男子黑发蓝眸五官显老气质颇猥琐。「可以这么说。」冷淡回应。「看得出来你是一个猎人追逐赏金和财富猎人。」左右看一眼低下脑袋压嗓音：「听说过幽灵帝国吗？」我听说过安利也听说过被封印海底天父与救主…利用无面人能力散发出不要靠近我信号：「知道一艘巨大古老装满宝藏幽灵船。」「我们有它线索！」矮小男子用富有感染力口吻：「我们找到一些资料知道它下次会出现在哪里！我们不想便宜海盗和海军不想被别人抢夺财富所以决定自己租用武装商船去那个海域等待这大概需要1000镑我已经找到15位同伴筹集了720镑你有兴趣参与吗？」不等开口摸索拿出一叠黄褐色书信：「我知道你不会轻易相信事实上没人会相信但前面那15位朋友在看完这些资料后都决定加入我们计划。」…我长了张容易被骗脸？还是说只要外乡人都逃不掉这种事情？正考虑要不要鉴定那些书信眼角余光却看到刚才和人争执海雕洛根走过来。「伍迪你又在骗人了！你这个该死在污水里老鼠！」一把提起矮小男子将他扔到酒吧中央空地摔得四脚朝天。这头部有青色纹身壮汉顺势坐到伍迪刚才位置豪爽笑：「不好意思这是我们达米尔港老鼠总是做一些破坏我们声誉事情。事实上我们都很友善你有什么事情想打听尽管找我。呵呵不要相信那些家伙诬蔑我是一个正直人和地狱上将没有一点关系！」你越是这么强调越是让人怀疑…略一思索表情不变语气平淡：「我想知道最近传闻。」「没有问题。」拍下吧台桌面对酒保：「来一盘特制腌肉我请这位伙计品尝下我们达米尔最著名美食。」酒保还是那副冷淡脸推门进入后面厨房很快端出来一盘红白分明纹理细腻切片腌肉。「5镑。」没有看洛根直接望向克。「5镑。」洛根侧过头边和煦微笑边抬下胳膊显示肌肉：「刚才所有人都听到了你为了感谢我要请我享用特制腌肉。」一时竟没反应过来遭遇什么等酒保第二次催促才明白自己被人讹诈而且对方套路相当深。先用一个很容易识破骗局让海雕洛根出场顺利获得目标好感接着以请客为由点一份标价昂贵特制腌肉最后翻脸不认人颠倒黑白强买强卖…难怪老鼠伍迪被扔出去时候那些醉鬼没一个起哄…他们都很害怕据说服务于地狱上将洛根…该怎么应对呢？我现在人设是格尔曼·斯帕罗一个略显疯狂冒险家和赏金猎人…端起杯子喝口麦香浓郁啤酒语气如常问：「为什么不直接抢？」「为什么不直接抢？」洛根被问有点愣住。紧跟着看到一个拳头越来越大。咚！左手挥拳砸中海雕洛根下巴打得他往吧台位置翻倒。右掌一撑敏捷离椅靠近洛根正要倒下身体。大腿绷紧膝盖猛地往上一提直直撞在洛根下腹部。噗！向后扬起眼睛凸出嘴巴半张。顺势拔枪将左轮塞进对方嘴里往后拉起击发锤。「我…我是…」含含糊糊喊。注视他眼睛忽然抽出左轮一个猛挥连枪把带拳头打在洛根侧脸上。牙齿当即一颗颗脱落满嘴都是血污。面对这样重击和超过极限疼痛眼睛一翻直接晕过去。撑住他身体从衣兜内找出一把零碎钞票和硬币。因为目测没有超过5镑直接将它们丢到吧台上冷静：「不用找。」酒保古铜色脸庞有些泛白慌张喊：「我老板是白鲨！」看都没看他一眼松开手任由海雕洛根倒地然后重新坐下叉起一片腌肉塞入口中品尝只觉风味还算独特香料味道丝丝缕缕外扩抓挠胃部和喉咙。连吃两片才抬头问：「你老板知道你和海雕勾结吗？」「不他不…」嗫嚅回答。见没有继续攻击倾向且爽快付了钱靠拢过来几名守卫又默默退开。喝口酒瞄眼地上海雕洛根平静对酒保：「他是路德维尔线人可以领取多少悬赏？」「不他不是。」摇头：「这都是他自己散布出去消息刚才那个海军就是他花钱请来的！只有这样才能让这里人害怕他…」听到这答案吧台喝酒人们都愕然放下杯子甚至有醉鬼踉跄走到洛根身旁往他脸上吐口唾沫。呸呸呸！许多酒客相继仿效。重新低头边吃特制腌肉边说：「讲一下最近传闻。」酒保松口气边擦杯子边断断续续介绍这两个月内传闻里面有听说过也有刚才知道。皇家海军普利兹号铁甲舰在常规训练里摧毁一只路过海盗团…对巨舰大炮恐慌开始传播于一些中小海盗势力里…他们有的想趁铁甲舰队还未成形机会疯狂作案拿一笔钱退出这行当…未来半年到一年海上不平静啊…血之上将塞尼奥尔和黄昏中将布拉托夫·伊万在苏尼亚岛南部海域发生冲突大战一场各自沉了两条船…只听不问逐渐填饱肚子。见装特制腌肉盘子被清空于是喝掉剩余啤酒缓缓站起来。「记住今天教训。」将盘子递给酒保。酒保刚要伸手突然被他探掌抓住脑后头发。砰！用力一按将酒保脑袋砸在吧台上砸得木屑纷飞鲜血外流砸得酒客纷纷躲避守卫高速赶来。做完这一切拍下手拿起自己酒杯试图将里面剩余残酒倒在酒保头上。一滴两滴三滴…默默放弃转身弯腰抓起海雕洛根将他丢向赶来守卫们。趁守卫躲避酒吧混乱机会快速奔跑敏捷绕行轻松离开飞鱼与酒。按下帽子快步前行转入旁边街道。连续变向后突然放缓脚步手中多了枚金币。那金币不断在指间跳跃似乎在侦察着什么。

## 这场戏有没有翻
翻了。吧内对峙开；章末金币侦察离场。翻的是人设＝略疯冒险家用拳枪砸出来，不是真打上将线人。

## 话
「不要相信这里任何人」「为什么不直接抢？」「不用找。」「记住今天的教训。」局面是从对峙收到啤酒；从幽灵局收到讹诈；从直接抢收到砸晕；从假线人收到吐唾；从砸酒保收到逃。

## 热怎么变冷
脏话对峙还热。冷切6便士。讹诈还热。冷切为什么不直接抢。砸晕还热。冷切不用找吃肉。砸酒保还热——残酒三滴冷切放弃。

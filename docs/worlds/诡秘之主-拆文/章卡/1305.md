# 1305 倒吊人 第四十章 封印

## 打开书
那黑色身影僵硬于那里松开捏住贝尔纳黛脖子手掌似乎正用根本不存在眼睛凝望这位神秘女王。一道干涩沙哑声音随即回荡在被隐藏起来空间内：故乡……这声音带着一点迟疑一点茫然一点寻求确认感觉仿佛是从另外一个世界传来。贝尔纳黛遭遇侵蚀消失她与自身封印物之间联系瞬间得到恢复。苍白的死亡又开始让她一点点死去这帮助她对抗住念头逐渐混乱保持住基本清醒和理智。就在她开口想要再说点什么时候那黑色身影突然又往前伸出手掌。……离开！……可是那眼睛却没有瞳孔一片血色。紧接着又是一道缝隙裂开于两只眼睛下方里面充盈同样是纯粹血红光芒。这让黑色身影终于有了张嘴巴。……离开这里！贝尔纳黛被推出十几米后轻松站稳脚跟但却没遵循那声音命令离开这座黑皇帝陵寝她立在那里怔怔望着中央高台望着那道黑色身影表情里流露出难以掩饰也不想掩饰悲伤。她能感应得出来她已经可以确定那黑色身影就是她父亲那个自称凯撒男人罗塞尔·古斯塔夫。……他身上血红裂缝产生频率顿时降低到极点但之前已存在眼睛们竟开始眨动一下一下又一下。不过这并没有给周围带来不好影响似乎只是一种单纯秩序变化——一直有血红裂缝新生趋势被扭曲到原本那些逐渐活跃。……你真成为神秘世界大人物了可以自己一个人来到这里。过来吧让我看清楚我小公主现在是什么样子。……给你弄绘本编教材发明各种小游戏时候你才只有那么一点大现在都能来拯救你可怜老父亲了。我记得你小时候很喜欢我给你设计各种衣物可惜长大之后不能再穿蛋糕裙……停下！……你是不是很想问为什么黑皇帝陵寝外要铭刻自身制定秩序引导风尚其实这并非必需我只是想让看见者牢记我伟大……不要靠近！我被污染了……此时罗塞尔脸上那一道道鲜红缝隙出现混乱时而闭上时而睁开不再有统一意志。……封印我！封印……神秘女王贝尔纳黛无声重复一遍那个单词蔚蓝眼眸飞快变得湿润蒙上淡淡雾气。……她如这些年里面对要素黎明遭遇种种大事时一样异常冷静做出决断。苍白的死亡表面金属瞬间柔化重组出新脸孔有了双黑色眼睛。……这符号吸收起周围光芒迅速有实体然后脱离贝尔纳黛眼睛舒展开身躯飞向铁黑色座椅上罗塞尔·古斯塔夫。……随着那个符号融入他身影他顿时与苍白的死亡产生联系看见高踞无数亡灵之上虚幻神灵看见水鬼般徘徊于一条暗河中肿胀身躯。……而那个符号将固化于罗塞尔身影内始终施加影响直到苍白的死亡不再回应这里。……他身上披着那块幕布一下扬起来整个源堡出现明显沸腾。……消逝到一定程度后它再次获得新生然后被苍白的死亡影响继续消逝。克莱恩利用那份诡秘侍者非凡特性和源堡力量直接将新生和死亡嫁接在一起省略中间过程。……接着克莱恩伸出右手调动源堡力量于身前勾勒出愚者高背椅后神秘符号——那由半个无瞳之眼和半个扭曲之线组成。这符号吸收着源堡气息迅速变成实体随着克莱恩手腕一挥落入代表贝尔纳黛祈祷光点内落到罗塞尔那道黑色身影上融入他体内。——每当那种嫁接行将消失这直接关联愚者和源堡符号就将引来新力量再次完成嫁接。……这个封印好我能安静睡上一觉了……你怎么穿成这个样子谁教你？……爸爸……离开吧。永远不准回来！……很快她回到黎明号走入船长室里打开专门用做收藏房间。……不知过多久船长室内响起一道压在喉咙里般声音：爸爸……

## 这场戏有没有翻
翻了。开头故乡确认；父喊离开／污染；求封印；嫁接永续；章末永远不准回来＋船舱爸爸。翻的是父女封印＝永别令。

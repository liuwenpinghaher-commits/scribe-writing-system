# 1378 倒吊人 第二十六章 联手

## 打开书
笼罩着安提哥努斯宫殿那层幕布瞬间消失某种无法言喻气息回归现实让整个星界都仿佛摇晃一下。布满裂缝世界屏障外那一张张难以用正常词语形容恐怖脸孔同时出现异动。无形屏障开始剧烈颤抖似乎随时会寸寸崩塌。内部星球每一块大陆都发生地震不算严重但较为明显地震。……正午天空中绯红之月陡然凸显颜色变得极为浓郁并夸张膨胀开来仿佛悬挂到每一栋房屋屋顶除此之外褐星橘星赤星金星蓝星等同时大亮散发出不同质感光芒。……比起被挡在现实世界外祂们最先做出反应是就在克莱恩本体衣兜内许愿神灯。……它手臂一伸将特伦索斯特黄铜书摄到掌中。……此地禁止亡者复活！……以下规则无效！哪怕还没有真正复活还未吸收愚者唯一性和两份序列9至序列1占卜家途径非凡特性克莱恩本体内福生玄黄天尊也可以掌控源堡借助位格调用力量。……真实历史明明是融合史前人类灵魂克莱恩·莫雷蒂假扮愚者组建塔罗会一个序列一个序列变强最终到接近真正愚者程度现在历史则是愚者先生是复苏伟大存在是古老年代里那位福生玄黄天尊祂终于复苏了！此时灯神利用特伦索斯特黄铜书完成规则限制虽然只起效不到一秒钟时间但还是让克莱恩本体内诡秘之主意志衰减不少就像遭遇一次致命打击。而大地母神和蒸汽与机械之神都放弃对阿蒙分身们干扰似乎想让这位错误先生腾出手来对付复苏中诡秘之主。不过明明有些余力祂们却没尝试影响克莱恩本体只是继续压制着原初魔女和隐匿贤者。……于祂们而言诡秘之主复活同样能达到自己目的：最短时间内诞生一位支柱；不让仇视自己家伙成为诡秘之主。另外祂们所在途径都不属于诡秘之主支配那三条而且祂们和对方没有任何仇怨和利益冲突。不再受影响阿蒙立刻改变目标将绝大部分注意力放到克莱恩本体上。……没有犹豫阿蒙们同时抬起右手轻轻一握郑重窃取起目标身上永昼效果。不过阿蒙们也未放弃对克莱恩施加影响祂们仗着自己足够多分出少量成员望向目前是序列1诡秘侍者且背负着安提哥努斯身份克莱恩。这些阿蒙单片眼镜猛然亮起利用门相关权柄将克莱恩移出现实世界移到星空之中。……克莱恩利用嫁接和纸人替身挡住阿蒙们袭击。与此同时另外阿蒙们取得成功从克莱恩本体处窃取走永昼效果。但是下一秒钟这永昼效果又被对方窃取回去。这就是诡秘之主对本途径能力掌控哪怕祂还没有真正复活只是开始这个进程。……祂们之中大部分继续窃取赠予出去永昼效果对抗诡秘之主小部分锁定巨大石椅上安提哥努斯不分先后窃取起对方永眠状态。……不再被阿蒙们攻击克莱恩同样未反击对方他注意力也放在自己本体身上。那里复苏诡秘之主才是最大问题！……克莱恩开始和诡秘之主抢夺源堡控制权以此让对方没那么容易借助位格调用力量！而这在诡秘之主还没真正复活还没容纳愚者唯一性和相应非凡特性情况下可以有效降低对方实力让祂很多操作失败率提升效果显著变差。有了他加入有了他对源堡掌控特伦索斯特黄铜书受到愚弄立刻弱化阿蒙们窃取成功率也提升。……诡秘之主这次复活因多方干扰最终失败了。随着这句话语成形随着克莱恩争夺起源堡掌控权阿蒙们又一次窃取走附加于诡秘之主身上永昼效果。另外一边祂们也偷到安提哥努斯永眠状态。没有一点迟疑阿蒙们将永眠状态转赠给克莱恩本体转赠给诡秘之主。……就在这个时候封印弱化特伦索斯特黄铜书上相应条文又一次成形：此地禁止亡者复活！骤然间克莱恩本体内那恐怖意志急速衰弱产生强烈重新沉睡趋势。可这意志是如此强大哪怕漫长时光都没法彻底消磨它两重限制之下它依旧在坚韧一点一点滋长复苏并尝试起用篡改和愚弄解除当前困境。克莱恩感受到对方在调用源堡力量当即集中精神做出干扰。与此同时漂浮于古老宫殿上方黑夜女神稍微放松对阿蒙真身控制抽回那个鸟型黄金饰品将它头部对准下方。这鸟型黄金饰品青铜眼珠内部虚幻层叠门涌出来让一滴没有颜色带着强烈永寂气息水液落往古老宫殿内克莱恩本体处。这是一滴永暗之河河水！黑夜女神做这件事情过程中阿蒙真身开门逃离尝试默契放缓。这滴水液下落速度极快大地母神构建自然屏障和蒸汽与机械之神呈现文明画卷同时收缩一点为它让开道路。啪这永暗之河河水准确滴在克莱恩本体头顶无声无息钻进去。正一点点滋长诡秘之主气息当即回落失去波动又陷入永眠状态。……这时黑夜女神空着最后那只手从虚空里抽出一把巨大长剑。……这是黄昏巨人象征。黑夜女神那条覆盖漆黑短毛手臂一展将这把夸张巨剑劈向下方。……紧接着它斩中还未摆脱永眠状态克莱恩本体。诡秘之主复苏那部分意志急速消亡那具身体也以不可遏制趋势衰败崩溃连带脸部愚者唯一性和体内两份序列9至序列1非凡特性也跟着坍塌聚合在一起。克莱恩见状没有做任何思考按照预案调用源堡将四分之一历史迷雾拉下来包容住那团事物。灰白雾气弥漫中愚者唯一性和那些非凡特性彻底聚合。……愚者魔药！阿蒙们同时伸出右手窃取起这份魔药。

## 这场戏有没有翻
翻了。开头幕布消＝天尊气震星界／外神躁；灯书禁亡者复活一瞬伤；母神蒸汽放阿蒙打天尊；克莱恩抢源堡＋阿蒙赠永眠；女神滴永暗再眠＋黄昏剑斩壳；迷雾聚成愚者魔药；章末阿蒙齐窃。翻的是联手＝克莱恩×阿蒙×女神共灭壳内天尊。

## 日子
幕消地震。禁亡者。抢源堡。河水滴。剑斩。魔药成。

## 这一章新讲明的规矩
- 未全醒天尊亦可控源堡；史被愚＝「愚者即天尊复苏」。
- 母神／蒸汽利支柱诞但勿仇敌成诡秘→放阿蒙。
- 永昼可互窃；永眠可转赠。
- 女神永暗＋黄昏剑可灭壳内天尊意志→特性聚魔药。

## 钱与人情

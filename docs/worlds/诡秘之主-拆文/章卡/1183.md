# 1183 逐光者 第三十四章 “记录”

## 打开书
目前没有星之虫……让我留意求购星之虫的人还需要什么……佛尔思浏览老师来信无声松口气。可想到接下来将开启狩猎秘之圣者布提斯行动又一阵紧张毕竟这是一位半神半人存在在一两年前就是序列4圣者如今日说不定都已经序列3了。虽然行动主导者是隐者女士但作为一个诱饵还是需要担忧一下自身安全……而且极光会背后还有救赎蔷薇还有天使天使之王……并不后悔自己答应格尔曼要求这本身就是她想去做事情只是因为风险太高难免有点慌乱和不安。这让她忍不住设想起另外一个可能：如果世界先生能参与由他主导那我肯定不会这么紧张和担忧。这不是不相信隐者女士实力和经验而是世界格尔曼战绩摆在那里猎杀过半神不是一个两个让人一想到由他来执行类似任务就感觉安心。坐在壁炉旁休看好友一眼开口问：要开始狩猎了吗？嗯。郑重点头旋即：还没那么快大家都需要一定准备时间。狩猎一位半神不是秋季去郊外猎狐带上装备召集齐朋友就可以出发这需要绝对严谨绝对细致规划相信隐者女士得亲自来贝克兰德或者在预定别战场居住一段时间摸清楚具体状况才能制定足够有效计划。而正义小姐还在加速消化梦境行者魔药这可能还需要一到两个月甚至更久。对她来说等待得起因为她也想在正式行动前消化完记录官魔药布置仪式成为旅行家。她唯一不能确定是世界会不会催促。我会努力说服他不让正义小姐说服他这是观众强项……刚咕哝两句就看见休转过身体略显犹豫：那位军情九处联络官今天提议我正式加入他们说新国王继位以前许多事情不需要再担忧了像他和我这种人也有机会得到重用了。专心听完斟酌：不是有针对我们展开调查吗？这应该能发现你背后存在某个势力。休点头：他们认为上次那件事情后我就被放弃了还有他们怀疑那个势力属于教会黑夜教会。休本身信仰黑夜女神提及教会毫无疑问指黑夜教会但考虑到好友是蒸汽与机械之神信徒又补一句免得出现歧义。呵呵那是世界先生让我们伪装出来的。神情放松捋发丝笑着说。随即让自己变得严肃成熟：休这对你来说是个机会法官扮演明显需要官方支持纯粹靠自己做贝克兰德地下世界法官你实力和层次都还不够也缺乏足够帮助。如果你真能进治安法庭巡回法庭刑事法庭任职几个月你魔药应该就能彻底消化啊对听说军情九处内部有一个异常事务法庭专门处理非凡者案件你要是成为里面法官也许明年二三月份你就能冲击惩戒骑士位阶。见休明显意动忙又加一句：等你立下足够功勋你说不定就能在一定程度内恢复你父亲名誉反正乔治三世已经死了只要不把事情引向他名声哥温顿二世未必会阻止。哥温顿是乔治三世长子目前已继任鲁恩国王戴上拜朗皇冠。休沉默好阵终于缓慢点头：我试一试。嗯等稳定下来你就可以把你母亲和弟弟接到贝克兰德虽然现在局势紧张粮食价格飞涨但你在军情九处内部肯定有配额养得活他们！越说越觉得加入军情九处是一件好事。说服休后进入自己卧室向愚者先生祷告请祂将自身话语转给世界先生。紧接提炼老师回信要点阐述自己想法希望格尔曼能耐心一些。刚结束祈祷准备离开房间眼前突然一花看见深红潮水自虚空涌出瞬间就淹没自己。随即发现自己来到古老宫殿内坐在平时那张高背椅上但青铜长桌最上首却没有了那道笼罩灰白雾气伟岸身影。此时斑驳长桌四周只有她和世界格尔曼。……精神骤然紧绷脑海念头一下变得活跃飞快转动：世界先生我刚才刚才意思是您有耐心是最好这能让事情变得简单没有也没关系我们会尽快展开狩猎行动。低哑笑一声：不用紧张我并不着急。当最终目标变成天使层次魔药配方和0级封印物后他在这件事情上有足够耐心。呼……暗中松口气疑惑问：那您找我有什么事情？语气没什么波澜：你不是希望尽快消化掉记录官魔药吗？除了记录不同地方民俗风情我想你应该还需要记录各种各样非凡能力相应层次越高消化效果也许就越好。听得眼睛一亮：是的！脱口而出后感觉态度有点问题忙又隐含些许怯意补一句：这是您之前说预支报酬吗？轻轻颔首：开始吧做好准备我从愚者先生那里借来了1级封印物这对应圣者层次。于一名序列6记录官而言记录天使层次非凡能力成功概率极低接近于没有所以没试图从历史孔隙召唤出信使小姐阿兹克先生祂们展示技能。一下坐得笔直重重点头：嗯。下一秒看见世界举起一根顶部镶嵌满青蓝色宝石白骨权杖。光芒骤亮中一道道闪电从虚空跃出纠缠在一起化成一座散发毁灭气息雷霆森林。眼眸被映得一片银白身心皆受震慑。等到闪电风暴平息怔两秒才略显畏缩：失败了……再来。语气平淡回应。闪电风暴一次又一次降临灰雾之上古老宫殿内不知过了多久吐口气向后靠住椅背难掩欣喜：成功了成功了！她终于记录下一次闪电风暴。总算结束了……顿时放松下来然后听见世界不含感情开口：好下一个非凡能力。……下一个？只见斑驳长桌最下方那位疯狂冒险家探出右手往灰白雾气里抓一下凭空拿出一根长有荆棘布满铜绿十字架。记录这十字架能力？努力让表情显得正常。——记录官魔药有较大程度消化后她能记录神性能力已从一种提升到两种。不。瞥魔术师小姐一眼：记录我召唤无暗十字的能力。……失败了。小声说。这次失败原因是她没来得及记录。解除对无暗十字维持又一次将手伸入历史迷雾拿出一把铁黑色左轮。没成功……表情复杂做出回应。她现在只想返回现实世界好好消化刚才收获可却迟迟听不到下课钟声。近三十次后当脑袋出现抽痛精神开始枯竭时总算记录下一次历史孔隙影像召唤。这一刻觉得自己饱含热泪但还是强忍疲惫竭力展现一名好学生态度：这可以从历史孔隙里召唤出与自身存在一定关联人和物？到时候我该召唤谁或者哪件物品？看着魔术师小姐略显冷漠答：我。……挤出笑容：哪个时期您？上次见面时的。早已想好答案。那是在破坏乔治三世仪式前特意将魔术师小姐从冰雪天地带回贝克兰德他已成为古代学者他。郑重点头下意识问：失败了怎么办？召唤超越我自身层次人失败概率应该会很高……你明天再来记录一次这个能力用莱曼诺的旅行笔记。嗓音平缓说。两次就能成功？本能冒出这么一个疑问可见世界是那样笃定又不敢开口了。抬手比划一下：那我可以回去了吗？嗯了一声让魔术师小姐在一脸欣喜中离开源堡。……苏尼亚岛原始森林内。阿尔杰带着几名手下进入一处平时少有人至精灵遗迹。

# 1335 倒吊人 第七十章 交互

## 打开书
贝克兰德蒸汽列车站第三站台。阿尔弗雷德与父母妹妹交谈一阵后抓紧出发前空隙离开列车来到站台上对一名扈从道：给我一根东拜朗烟。……当然他烟瘾并不大一个惩戒骑士有足够体魄和精神来对抗这方面影响阿尔弗雷德之所以到站台上来抽烟是因为他觉得车厢里太闷母亲又总是提及自己婚姻问题。……希伯特我以为你不会回东切斯特。……我只是内阁秘书不是内阁首席秘书不会忙碌到连一个周末都没有。……周末愉快。……那辆列车为什么没有乘客等待？它似乎没有坐满。哈哈那是一辆专列是一位大人物花费不菲金镑提前预定好……不知道是哪位大人物？……他们是？阿尔弗雷德侧头询问起自己副官。……将军他们是来自王国各地列车调度员正在贝克兰德接受一个短期培训。……苏尼亚海慷慨之城拜亚姆。……学徒途径序列7并不怎么擅长战斗而维尔杜虽然有携带神奇物品但相当害怕负面效果不到关键时刻不愿意使用所以为规避危险对海盗缺乏信任他尽量没带容易引起别人贪欲东西。……不用害怕我们都很信守承诺只要你付够船票钱我们肯定不会把你扔到海里去在这里你甚至比坐客轮更安全至少不用担心遇上海盗。……甲板上第二层最里面那个房间。……要住我这里吗？那女郎见维尔杜望过来媚笑问一句……请进。休从宽大座椅上直起身体道。……上校我们对乌托邦调查有些收获。……这几天里我们趁上个任务已经交接空闲亲自和通过线人走访那列蒸汽列车乘客在贝克兰德所有乘客。……我们初步确认顺利抵达贝克兰德那些乘客都没有出现异常精神状态不错认知也没有问题。不过我们发现一件事情当时并不是所有人都回到列车上据两位乘客讲他们同座选择留在乌托邦。那是一位热爱旅行和探索女士……决定放弃原本行程在这座具有独特气质小城多待一段时间……那家旅馆和我们那位情报人员住是同一家叫鸢尾花。……调查出那位女士现在情况了吗？她叫什么？没有我们无法确定她现在是否已离开乌托邦。另外一位……回答道那两位乘客只知道那位女士叫莫妮卡不清楚她姓氏和来历。休嗯一声：你们之后任务是调查这位女士来历找到她家人和朋友确认她是否已经回来。……最近有什么可疑人吗？很多人都相当可疑但他们没有悬赏金。酒保随口回应一句。……你听说过乌托邦吗？听说过。酒保边擦杯子边回答道。……你在哪里听说？之前来了位客人喝得很节制……问他来自哪里他说乌托邦。……请问有什么事情吗？文德尔礼貌问道。……你好我是拜尔斯一名警察有起案子想请你出庭作证。什么案子？文德尔微微皱起眉头。……乌托邦翠西杀人案。……文德尔瞳孔瞬间放大。

## 这场戏有没有翻
翻了。开头站台烟／专列调度员；维尔杜登海盗船；休获留乌托邦莫妮卡；酒保闻乌托邦客；章末拜尔斯请文德尔证翠西案。翻的是交互＝城触现实多点开花。

# 1322 倒吊人 第五十七章 发展大计

## 打开书
听完白银城居民们愿望克莱恩脑海里瞬间浮现出一个念头：怎么都和吃有关……倒吊人阿尔杰想了想对太阳戴里克道：你们完全可以让有这种想法人到拜亚姆加入行业工会通过他们寻找合适老师也可以直接邀请有这方面特长人到新白银城教学给予丰厚报酬。当然前提是你们必须尽快让居民们掌握罗思德群岛通用语言在这个基础上鲁恩语古弗萨克语都坦语也可以提上日程。等倒吊人说完隐者嘉德丽雅也给出自己建议：除组织佣兵队伍你们也可以尝试应聘罗思德群岛各大城市公共职位负责处理超凡事件。……对于隐者女士这个建议克莱恩相当赞同而且认为有必要给达尼兹神谕让罗思德群岛政府和海神教会在一定范围内增加属于官方非凡者数量。……你们现在应该掌握着很大一笔流动资金可以尝试着投资罗思德群岛矿场香料庄园种植园购买肥沃土地和出产丰富林场它们现在都很便宜……隐者嘉德丽雅这个建议给其他人灵感正义奥黛丽当即补充道：你们去谈判时候最好请几位专业律师要不然很容易被骗唔如果认为有必要可以将城内精神分析师也带上。还有你们背靠一个中等规模港口可以发展相应经济……针对罗思德群岛政府和海神教会官方非凡者都缺乏足够常识情况你们可以在新白银城通识学校开设面向外来者收费课程唔把和正神教会容易起冲突部分知识删掉……连通新白银城和其他城市铁路必须尽快修建好……太阳戴里克听得一愣一愣忙举下手道：抱歉我需要把刚才说先记下来。忘记他没有经济学方面基础了……正义奥黛丽小小反省一下闭上嘴巴微笑示意小太阳向愚者先生寻求帮助。等戴里克具现出纸笔记下之前那些建议正义奥黛丽月亮埃姆林星星伦纳德等塔罗会成员你一言我一语给出自己想法并反驳起彼此不太成熟不够切合实际那些提议。这样热烈场面持续近两刻钟才结束太阳戴里克看着面前那叠不算厚但也不算薄纸张难以遏制露出笑容。坐在斑驳长桌最上首愚者克莱恩却莫名唏嘘心情沉重不少……我们已修建好属于愚者先生神庙与教堂想向群岛各个城市传教这需要注意什么？倒吊人阿尔杰微皱眉头道：你们编写出圣典了吗？设计好弥撒流程和祈祷细节了吗？嗯。太阳戴里克重重点头道。……教会内部体系构建好了吗？戴里克下意识看眼被层层灰白雾气笼罩着愚者先生回过头来道：目前是模仿其他教会内部体系由我们六人议事团首席兼任大主教并任命一批有传教热情居民为主教和牧师。……可以先试着这么做。……但要注意两点一是不要宣扬其他教会不好免得造成冲突二是尊重现在神使在愚者先生没有任命教会首领情况下神使就是神灵代行者。……三是不要以骚扰方式传教……而且我对白银城那些主教牧师们口才深表怀疑得让达尼兹找专业人士做下培训……安静旁听愚者克莱恩在心里咕哝两句。……也许哪一天威尔·昂赛汀看到愚者教会圣典会惊讶脱口而出：我什么时候成愚者座下天使了？然后伦纳德老爷爷醒来阿兹克先生努力恢复信使小姐会跟着说：什么我也是？交流完白银城和月城相关事情隐者嘉德丽雅不是太抱有期待环顾一圈道：你们谁有窥秘人途径序列3非凡特性？……太阳戴里克回想下白银城拥有那些半神特性缓慢摇摇头。就在这时世界格尔曼·斯帕罗嘶哑笑道：我建议你直接问神秘女王。……问女王？隐者嘉德丽雅从世界格尔曼·斯帕罗回答中品出一些端倪怀疑女王身上发生一些事情。好。她控制住自己追问冲动。克莱恩继续操纵世界对隐者女士道：我有个长期委托：帮我搜集隐匿贤者突然活过来各方面资料。相应报酬你可以现在提也可以等将来有需要了再说。……没问题。……未来号船长室内嘉德丽雅推推鼻梁上架着沉重眼镜思考起给女王信该怎么写。……刚才塔罗会上愚者先生说耕种者和月亮是较为特殊两条途径来自星空易受污染听到不知是真是假神启。弗兰克正是耕种者途径非凡者……而且他曾经抱怨过大地教会没能理解仁慈母亲真正意志……嘉德丽雅被厚重镜片挡住眼睛顿时微微眯起来。

# 1288 倒吊人 第二十三章 “愚弄”

## 打开书
回到拜尔斯家中后不等罗伊等人询问什么克莱恩就拉过一张椅子坐下来颇为虔诚向自己许愿：我希望我灵性得到恢复。话音刚落他抬起右手啪地打个响指让这个愿望得到实现让自身灵性回到状态完好时水准。紧接着他探出左掌准备结束对那块幕布历史投影维持然后再召唤一块继续封锁贝尔丹对应灵界区域不让战神教会大牧首拉里昂有逃脱机会。没有必要错过这次还有下次。这时阿里安娜缓慢摇下头示意克莱恩不用再召唤那块源自乌黯魔狼幕布。愿望能力有一个限制是奇迹师不能在短时间内满足同一个祈求者多个类似愿望也就是说在接下来一两个小时内克莱恩不能再通过这种自我许愿方式恢复灵性。当然对一位合格占卜家途径天使来说这种限制是有一定办法绕开比如他可以让帕莎罗伊菲尔拜尔斯和阿里安娜轮流许下让克莱恩·莫雷蒂恢复灵性愿望然后作为奇迹师去满足他们。但问题在于即使他能这么多次恢复灵性也没法将那块有序列1位格幕布维持一小时以上而0-02擦去规则重新再写需要等待一个小时。……先试一试反正现在比较空闲等到最后一次恢复灵性再放弃嗯这纯粹看那位大牧首运气怎么样也许在这个过程中祂就因为焦虑烦躁和紧张失控了呢？说话间克莱恩解除对原本幕布维持左手衔接紧密往前一薅拖出新幕布让它呈现于贝尔丹城对应灵界内。那色块浓郁重叠地方穿黑底白边长袍戴方型帽子拉里昂刚感觉到限制消失准备穿梭离开就看见新幕布落下再次隔离这片区域。……他有尝试寻找其中规律试图弄清楚相应时间间隔把握住那转瞬即逝机会在旧幕布消失新幕布还未产生瞬间冲出屏障。……时间一分一秒流逝中拉里昂再次感应到旧幕布瓦解。不过这次并没有新幕布产生。……克莱恩之前几次召唤出来幕布都是浸染过源堡气息那个历史孔隙影像自然能吸引来对此敏感事物就算阿蒙出现在这个队伍里他也不会奇怪！……还是很厉害嘛……他随即又变得沉默直到魔镜散发出濛濛水光映照出布告牌当前状态。这意味着0-02开始擦除之前制定规则准备重新再来。等到宵禁令被废除精神高度集中克莱恩立刻拉着阿里安娜女士通过火焰跳跃出现在缩水贝尔丹市立图书馆外面。他一眼望去就发现0-02黄铜书页上规则被擦除速度已变得极快只是一个眨眼工夫后半部分就只剩以下规则无效条款。……特伦索斯特黄铜书是最珍贵事物任何生灵任何事物不得它允许都不能触碰它……不过随着阿里安娜手指略显艰难滑过新生第一条规则还未完全展现就被橡皮直接擦掉进入隐秘状态。而0-02制定所有规则必须经过公示或告知才能真正起效！哗啦一声阿里安娜抓起这本特伦索斯特黄铜书将它扔给落地窗外克莱恩。克莱恩在之前一个小时内已预想过接下来可能种种发展并和阿里安娜做相应讨论此时一点也不紧张和慌乱趁0-02还在半空机会从虚空里拖出戴着人皮手套自己。然后他一把抓住特伦索斯特黄铜书利用自己历史投影直接传送离开。……也就是几秒工夫拿着0-02克莱恩出现在霍纳奇斯山脉主峰顶部并利用天使层面灵视看见那个墙壁坍塌破败不堪笼罩着迷雾古老宫殿。没有犹豫克莱恩让自己历史投影接过特伦索斯特黄铜书闪现至宫殿正门处伸手将它推开。……这是安提哥努斯家族那半个愚者已失控疯狂半个愚者！……抢在自身消散前这历史投影将手中特伦索斯特黄铜书扔向那团恐怖蠕虫堆。那一根根透明滑腻触手察觉到危险本能就做出应对它们同时缠绕过去捆绑住0-02这个封印物。这样干扰中无形狂风里那张愚者牌比诡异触手们抢先一步抵达门口。克莱恩历史投影已是崩溃大半见状机械探出右手抓住这亵渎之牌将它扔向后方。……也就是说我用0-02换来愚者牌？女神暂时不用我去卡尔德隆找永暗之河线索？克莱恩无声自语两句走出隐藏之地来到那座古老宫殿不远处弯腰拾取那张亵渎之牌。……序列0：愚者！……那古老宫殿内部特伦索斯特黄铜书落在地上自行摊开至后半部分第一页。……特伦索斯特黄铜书是最珍贵事物任何生灵任何事物未得它允许都不能触碰它违者死刑！……不能以任何方式改变特伦索斯特黄铜书状态违者死刑！这两条规则刚有浮现还未告知这里主人前半部分和后半部分间隔处就突然出现一行单词：以下规则无效。一个小时后那两条规则被擦除新规则被书写出来但仅仅两条之后它们前方又多了那条以下规则无效条款——0-02似乎一下从基本空白现状直接跳到书页已被填满状态。一次一次又一次特伦索斯特黄铜书陷入无尽循环。

# 1323 倒吊人 第五十八章 处理

## 打开书
注视下方甲板一阵嘉德丽雅离开船长室步行至舱房入口等到提着一桶无酒精啤酒进来弗兰克·李。船长要来一杯吗？弗兰克单手就举起那一大桶啤酒。嘉德丽雅坚定摇下头状似闲聊般问道：这又是仁慈母亲意志？不。弗兰克相当认真说道我只是觉得长期喝加了改良型镇静剂烈酒对身体还是有点不好希望他们能接受这种喝起来有酒味实际没有酒精饮料……你有听见过仁慈母亲声音获得神启吗？没有。弗兰克一点也不在意地摇摇头。……这时弗兰克随口补充道：仁慈母亲意志在小麦结穗中在奶牛产奶中在蘑菇生长中在大自然每个角落每件事情中不需要神启就能感受到。嘉德丽雅目光瞬间投向弗兰克眼睛从中没找到一点疯狂只有纯粹。……不知道你对弗兰克表现有什么想法？他自称没有获得神启认为仁慈母亲意志藏在大自然每个地方。……刚开完塔罗会隐者女士就给我写信……克莱恩正乘坐一艘轮船在塔索克河上旅行。……这……克莱恩眉头顿时微微皱起。或许因为弗兰克平时表现得已经足够危险足够疯狂他之前竟忽视这位德鲁伊被堕落母神影响可能。……要么弗兰克受到污染很隐蔽让大地教会审判庭都无法确定要么他根本就没被堕落母神影响纯粹是自己脑子有问题以至于看起来像是邪神眷者。……他记得很清楚弗兰克蘑菇实验有突破性进展是因为配备一个信仰原始月亮助手而原始月亮是堕落母神其中一个化身。……当然不排除弗兰克太过疯狂导致堕落母神主动移开视线可能……克莱恩苦中作乐嘀咕一句。……弗兰克目前为止发明那些蘑菇应该没什么大问题我都拿到灰雾之上做过处理了……加大监测力度！……比起张扬肆意欲望母树一直都显得极为低调堕落母神可怕程度简直高不止一个层次！门先生和大帝都无声无息被祂侵蚀了。不愧是失去两条非凡途径和一份源质都能站在外神顶端存在……克莱恩暗自感叹一声拿出纸笔准备书写给隐者嘉德丽雅回信。……你对弗兰克有什么看法？克莱恩犹豫下开口问道我是说绰号之外。……只是……像……外神……养子……也就是说弗兰克之前确实没被堕落母神影响纯粹是自己脑子有问题……克莱恩长长舒口气。……那现在呢？……身体……暂时……未……被污染……意思是精神有没有被影响就无从分辨了？……克莱恩吐槽一句拿出一枚金币铮地弹起来。借助这个媒介他迅速进入梦境占卜状态。……嗯目前最大隐患是那个原始月亮信徒必须将他和弗兰克隔开否则事情会变得非常麻烦和危险……弗兰克若是在未来不接触到堕落母神相关任何事物也没晋升半神基本没什么问题……或许由于弗兰克本身层次太低受到影响也不深克莱恩占卜还算顺利没遭遇危险。……它……具备……源堡……气息……这是我经常用来占卜五枚金币之一已经浸染上源堡气息了？……收回金币克莱恩给隐者女士写了封回信通过蕾妮特·缇尼科尔交给对方。……尊敬女王陛下：我梦见您已经找到那座原始岛屿并顺利返航……那位大帝后裔状况越来越糟糕再继续待在未来号上我怀疑他会疯掉如果您不介意我想把他送到您那边。需要注意是他虽然声称自己不再信仰原始月亮但没人能证实这一点。……我现在最大困扰是难以得到预言大师主材料……如果您已经返回我希望找个时间将许愿神灯还给您……

## 这场戏有没有翻
翻了。开头问神启得自然意志答；克莱恩后怕母神；信使像外神养子／身暂未污；占卜须隔原月信徒；章末女王信送后裔＋还灯。翻的是处理＝隔污源非杀疯。

## 日子
无酒啤酒。河船回信。金币占卜。女王信。

塔罗后即时。

## 这一章新讲明的规矩
- 无神启≠安全；自然意志说亦可像眷。
- 最大隐患＝原月信徒接触；不触母神物＋不晋半神≈稳。
- 母神低调＞母树张扬；失两途仍外神顶。
- 常用金币可浸源堡气。

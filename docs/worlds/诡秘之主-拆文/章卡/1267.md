# 1267 倒吊人 第二章 “奇迹师”

## 打开书
那瓶奇迹师魔药刚一进入克莱恩胃袋立刻就分化为无数冰冷小虫向着身体每一个地方游去。轰然间克莱恩精神被撕裂变成无数小块与不同灵之虫结合再也没有谁是本体谁是主导区别。不知什么时候他进入那片灰白雾气半高丝绸礼帽和黑色长款风衣下身体飞快瓦解爬出一条又一条透明扭曲蠕虫。这些蠕虫迅速向着历史迷雾深处飞去各自占据不同光之碎片与历史孔隙中自身影像重叠于一。只是两三秒时间克莱恩刚才所在地方就只剩下失去全部支撑半漂浮状态风衣衬衣礼帽袜子皮鞋和贴身衣物。我……我是谁……谁是我……我才是主体……那一条条灵之虫分别闪过不同但类似念头没有一个愿意主动回归身体反倒对别同类产生强烈敌意只是因为还有克莱恩残留精神影响暂时没做出过激举动。这涟漪并不是恰好浮现它早就存在于迷雾中只是相对克莱恩整体来说显得微不可见但于一条灵之虫而言这足够明显。这样涟漪对那一条条灵之虫似乎有着强烈吸引力让它们纷纷从历史片段里探出脑袋。短暂凝固后其中一条灵之虫半是忍耐不住半是受到克莱恩残余意识影响爬出之前占据光斑飞向涟漪核心位置。紧接着一条又一条灵之虫从历史迷雾不同地方回归来到白银城历史在当前时代形成光之碎片内。当它们彼此靠近到一定距离后强烈聚合力终于凸显将数不清灵之虫拉扯一起糅合于一。这不是两条三条灵之虫接近就能产生效果必须有足够数量才会出现。而当那部分灵之虫重新形成整体克莱恩残缺意识完成本我拼凑事情终于往简单方向变化。那一条条灵之虫形成透明而巨大漩涡它散发出强烈聚合力将剩余迟疑不愿意回归距离不算远灵之虫相继吸过来。等到灵之虫回归超过三分之二时那漩涡内长出一条条滑腻透明触手。它们延伸向第二纪第一纪乃至史前时代旧日都市将最后那部分灵之虫一条接一条抓出来塞回漩涡内。那由无数条灵之虫组成人影随即按了按头顶礼帽让身上透明感飞快淡去凝出一层肉色皮肤长出乌黑短发和褐色眼睛。……一种来自融合于他身体非凡特性某个强烈可怕高高在上让人无法抗拒意念似乎苏醒一点传递出一副又一幅画面……另一种是浮现于克莱恩眼前一颗又一颗深红星辰和数量众多璀璨光点：那些星辰内传来正义倒吊人月亮等塔罗会成员祈祷声光点中回荡则主要是月城居民祷告它们共同营造出一个形象笼罩着灰白雾气怜悯注视世间至高至大……这海神权杖周围一个又一个祈祷光点环绕借助那个媒介传导到克莱恩身上。他终于晋升到序列2层次有了天使位格是真正奇迹师。本来源堡即将被他变化引动但随着他念头一转所有异常都恢复平静。这证明他已经真正掌握源堡成为这份源质主人至于这在现实世界能发挥多少威能他目前还无法评估。……这种平衡并不是太稳固经常会在一定程度内偏斜这会导致我状态不够稳定时不时会惊吓到周围人幸运是这可以提前预知到能有效避开……还有处于微妙平衡状态时尽量多展现自身人性一面以此强化这方面自我认知……可是阿蒙信徒都是自己祂怎么维持平衡？难道天生自带唯一性神话生物本身就有原初意志融合阿蒙早就习惯半疯状态不这就是祂正常状态……是每一个阿蒙都投票同意形象……这倒是一个思路我可以组建一个秘偶团让每一个秘偶都是愚者信徒并且以我最真实模样作为神灵形象这可以有效提供最好锚……当成为奇迹师成为祂成为源堡主人后他无需再逆走四步诵念咒文或者让塔罗会成员全部祈祷就可以轻松返回这里。不过似乎是能发挥源堡作用还不够他依旧只能灵体进入无法带着肉身一起。坐到属于愚者位置后克莱恩没急着检查源堡变化先行确认起自己提升消化刚才获得神秘学知识：嗯奇迹师非凡能力来自两方面一对历史迷雾更进一步利用二是愿望这个新增加核心能力。对历史迷雾更进一步利用包括好几种能力：一借助过去灵之虫复活但四次之后就会无效我目前已经用了三次奇迹师阶段只能再复活一次等到晋升为诡秘侍者应该会有相应提升；二对未来施加一定影响让某些事情发生概率在一定程度内变大或者变小相当于干扰目标命……嗯我现在能召唤物品加场景总量是九个但天使层次依旧只有三个……愿望已经是标准神灵之能了但有点奇怪只有先满足别人愿望才能满足自身愿望只有先实现小愿望才能逐步实现大愿望……

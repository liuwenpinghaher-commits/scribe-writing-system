# 1381 倒吊人 第二十九章 主场“优势”

## 打开书
阿蒙说话时候克莱恩看似在听实际却已尝试起离开源堡。这绝非他想要放弃或投降也不是他太过胆小下意识就先考虑躲避而是认为这是当前情况下最优解：若留在源堡克莱恩将面对三大难题：一是他刚晋升愚者本身状态极度不稳定得分出大部分精神来压制福生玄黄天尊复苏意志二是没法获得盟友们帮助只能单独奋战三是在大家都能影响源堡情况下克莱恩即使要比阿蒙更进一层掌控这份源质也没法体现出压倒性优势甚至会因对方擅长利用漏洞创造Bug……这样一来序列0愚者面对半疯错误和门双途径真神哪怕不是百分百失败获胜概率也极为渺小。而抓住机会脱离源堡后克莱恩将立刻获得盟友们帮助逆转双方处境：阿蒙要是追赶克莱恩将干扰祂返回源堡举动让祂直面自己盟友那个时候原初魔女肯定不会再出手远古太阳神未必还能于短时间内再现半个旧日威能以黑夜女神为首六位正神足以解决阿蒙。即使掌握错误和门两个领域所有权柄阿蒙不是那么好杀死正神们也肯定能削弱祂封印祂等克莱恩稳定住精神状态对源堡掌控加深后再有针对性地杀死祂。这样进程几乎不可逆转哪怕远古太阳神依旧能爆发出之前那种位格层次和实力也没法改变——祂极限看起来是同时压制三位正神这其中还不能包含黑夜女神。当然外神们毫无疑问不愿意看到新诡秘之主诞生一旦出现类似情况祂们必然会尽力干扰不让阿蒙陨落但在世界屏障还未崩坏前祂们能施加影响相当有限未必能产生太大作用就像之前克莱恩认为宇宙暗面和被缚之神可以发挥实力加起来都低于隐匿贤者。即使真被外神们影响局势克莱恩也没有太大损失反正那些存在也不会允许阿蒙反向干掉他他可以从容找地方躲避稳定精神状态等到准备妥当再重新谋划——黑夜女神迷雾小镇就是一个很好选择。阿蒙如果不追赶依旧留在源堡内部克莱恩则可以凭借自己源堡主人身份和随时可以影响里面各种事务掌控力让阿蒙在源堡内什么都干不成哪怕想通过深红星辰对付塔罗会成员也办不到。总之祂们谁想更好地利用源堡都会非常困难但破坏对方尝试绝对简单。这样僵持下克莱恩完全有空闲稳定自己精神状态加深对源堡掌控一点点扭转局面。到最后阿蒙要么逃和躲要么让福生玄黄天尊彻底复活拉着克莱恩一起死。……现在离开源堡是最优选择。可是他意识刚下沉至源堡边缘就看到一块水晶磨成单片眼镜。……你觉得我会留下这么明显漏洞？当然你也随时可以阻止我离开源堡。阿蒙右手食指弯曲抵着单片眼镜下方笑道。祂坐那张椅子背后璀璨光辉勾勒符号急速变化时而由寄生时间命运对应象征杂糅而成时而是一扇扇层层叠叠门。……克莱恩没去听阿蒙说什么脱离刚一失败他就制造出真正诡秘之境完整愚者神国。……这古老城堡具体长什么样子阿蒙并不清楚因为他正站在城堡内部一条走廊上仅能感知到源堡种种变化看见视野所及有限景象。……有点意思。作为最强大解密学者祂当然清楚这是一个神国而且是不能用蛮力去打破那种神国。这是因为每一扇门都和不同事物重组到一起强行打破不知道会触发什么效果——阿蒙并不会小看一位序列0愚者能力和智商不打算就此体验多重惊喜和意外。……想靠这种方式拖延时间稳定精神状态？阿蒙不知是在对谁说话般低语一句。……阿蒙依靠门权柄和Bug能力强行在门上开扇窗户而不触发效果。……果然将这扇门和外界大海组合在一起。阿蒙一点也不意外笑笑。一旦祂拧动这扇门祂将直接脱离源堡出现在那片大海里。而那个时候在克莱恩有防备情况下祂想再次进入源堡几乎没有可能就像克莱恩现在无法离开源堡一样。这就是阿蒙不强行破坏愚者神国而是一扇门一扇门打开原因。……为什么你不自己去寻求刺激？……愚弄效果。站在原地阿蒙微微点头。……等到非凡特性全数回归阿蒙放出一团窃取来火焰烧掉那条时之虫尸体。……这是解密学者解密之能和星之匙定位权柄结合。阿蒙刚才两次尝试主要是搜集情报把握规则为接下来破解愚者神国奥秘做准备。……那个有着愚者气息克莱恩飞快变薄化成一张纸牌。……愚者牌。亵渎之牌里愚者牌。克莱恩知道单纯依靠纸人替身哪怕附加愚弄效果嫁接真实气息也没法欺诈到阿蒙这位顶级诈骗师所以他用有对应聚合能力愚者牌做纸人。源堡虽然没法再利用但这里毕竟是克莱恩主场有他杂物堆有他搜集各种物品有刚收获特伦索斯特黄铜书和借来许愿神灯。

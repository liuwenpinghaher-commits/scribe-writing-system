# 1354 倒吊人 第二章 事情的收尾

## 打开书
近乎凝固静默维持近十秒后维洛斯等亚伯拉罕家族成员刷一下将目光投向佛尔思。感觉到那种警惕提防和恐惧混杂情绪后佛尔思主动向旁边退好几步并开口提醒道：小心负面影响。……等你消化完秘法师魔药就可以考虑晋升序列3漫游者了我会给你魔药配方替你准备相应材料。当然到了这个层次序列越高面对危险将越大这是客观情况不以个人意志和布置为转移。到时候是否需要晋升由你自己决定。……而一下收获这么多高序列非凡特性后维洛斯等亚伯拉罕家族成员对一份漫游者非凡特性倒是没什么不舍甚至认为用它来换取和平是绝对超值毕竟这里只有一位半神那就是佛尔思。在亚伯拉罕家族成员们来不及动用0级封印物也因刚才封印接近失效没敢取出大部分1级封印物情况下佛尔思完全有能力解决他们所有人。面对老师承诺佛尔思嗯一声道：这是隐藏空间门被打开了？不是。多里安缓慢摇头一脸迷茫。……要不要向愚者先生做次祷告？佛尔思试着提出自己建议。隐约有点猜测多里安当即看向维洛斯等家族成员见已经改信愚者先生都点头同意尚未改信都明显犹豫想要反对。……你们将负面效果是范围型部分特性按照正确方式搜集起来防止它们与周围事物结合。我到旁边向愚者先生祷告。好。在场其中几位亚伯拉罕家族成员迟疑两秒后都答应下来。……等这部分成员已有一定收获多里安才退到学生佛尔思身旁低头向愚者先生祈祷。……这是门先生遗物。你们血脉诅咒彻底解除了。门先生遗物……遗物……多里安咀嚼着那个单词睁开眼睛再次将目光投向那些高序列非凡特性。……刚弄清楚先前爆炸声和敌袭呼喊来源阿尔弗雷德等人看见门与窗同时打开哐当撞到墙上。……先退回主屋防备接下来可能发生意外。同时给东切斯特教区大主教拍电报请求援助。……确实有异常但那名守卫没法描述出自己看到什么只是说那一刻感觉到极大恐惧。……等天亮后再做进一步调查。你先坐下休息。……过几分钟她略显失望结束调查暂时将这个异常归类于心灵巨龙艾瑞霍格和暴怒先生遗留影响。……你发现什么？奥黛丽直截了当问道。……我嗅到浓郁血腥味在庄园边缘在门窗打开之前一段时间嗯大概是爆炸声响起后十几秒内出现。……去看看。……这个过程中时不时有人看向她但都没有在意没尝试阻止毕竟这只是一条狗掌握心理学隐身狗。……身穿绣风暴符号长袍阿尔杰一步步从地底走上来对等在两侧代罚者和牧师主教们点点头道：封印及时恢复正常。你们可以将自身监管物品放回去了。是威尔逊阁下。代罚者和牧师主教们齐齐松口气握右拳击左胸道。……不属于这个时代愚者……阿尔杰近乎无声向愚者先生祷告表达自己准备离开风暴教会想法。——封印及时恢复正常说法只能取信较低层次教会成员根本瞒不过任何一位枢机主教或高级执事更别提教皇和风暴之主。而如果没得到愚者先生同意并提供庇佑阿尔杰也不敢随意脱离风暴教会那必将遭遇神谴。隔几秒他看见熟悉无垠灰雾听到愚者先生回应：可以。去海神教会。……克莱恩静静坐在属于愚者那张高背椅上。……天尊意志复苏比我预想得更快更强烈……要不是吞了查拉图非凡特性利用祂残留精神印记做平衡拖延足够时间我根本来不及调整无法阻止祂苏醒……而他没因此直接失控是由于奇迹师魔药已完全消化而新吞下第一份诡秘侍者非凡特性也在他服食魔药之后很短一段时间内消化得差不多了——世界这个身份定位就是源堡主人眷者直接等于诡秘侍者所以克莱恩提前扮演……至于第二份诡秘侍者非凡特性则还有待于消化。

## 这场戏有没有翻
翻了。开头亚伯拉罕收门遗物／咒解；东切斯特门窗齐开；阿尔杰封复获准去海神教会；章末天尊复苏快靠查特性拖。翻的是收尾＝门死遗产＋阿尔杰跳槽＋天尊紧迫。

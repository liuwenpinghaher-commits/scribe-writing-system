# 441 无面人 第二百二十九章 探索任务

## 打开书
倒吊反问佛：「被迫喝第二份学徒？」当场看穿？清喉：「是…何解？何换？」「无需酬——肯定满足不了。」解释：高序自主决遗传多少；序6／5自然遗传一部分可多子倒退；半个序9高灵感不完善能力——对应途；亦神眷恶灵等；极少数高序子生即序5越阶少失控。奥恍然特殊人群。佛：「序7／8／9？」「理论不遗传；超量有几率——怀生降残余；一或不够三四个把握大。」目瞪。克笑话：喝药送的！扮演两月可消化起始——佛勉强：「最好仍扮演。」「序7及以下是。」高序久消化生子或更简。静几秒。太阳调姿：「又被安排探索。」「哪？」「半毁堕落造物主神庙。」牧羊长老仍地牢？「是；首席率。」危降可试。倒吊望愚无表：「彻底解监控前最后考察；先传阿蒙与堕落死敌——不表异常六人团可认不受阿蒙影响。」「还注意？」「血肉，呓语。」大人物两词。倒吊译：不该看听吃触别做。「哪些？」「入庙一切。」「怎探？」「还有队员首席！」奥欲捂脸改捋发。太阳难受。倒吊暗骂改：「听首席吩咐；勿自拿主意。」「明白谢！」吐气问正义：尼根死后贝克政局？上院裂；长子承位威不足；近十议员联名：政治慈善购地敕封贵族亦固议席。倒吊嘲鄙视→奥：「几万十几万债也会选——土地抵债摇贵族。」争执搁置劳工济贫；雇员统考稳进；大气污染查深入。「短时无战…」他交流。克虑盥洗久——宣布结束。奥镜前：明午心理课告伊思兰特求购人皮异常丰酬炼金会否兴趣；日记风眷勿忘；心理医生材勿懒——苏茜序8勿被追！佛踱定写信多里安：人皮风眷需求＋罗塞尔笔记好奇。阿尔杰出旅馆奔隐秘地下市——娜迦发；有人皮亦不放过。克客厅哀：「缺钱啊…」差现金直购；虑卖审讯者特性不等休。不知多久——门铃叮。

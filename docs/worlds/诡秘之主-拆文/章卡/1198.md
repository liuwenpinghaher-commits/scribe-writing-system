# 1198 逐光者 第四十九章 不祥之盒

## 打开书
对于布提斯0级封印物回归或者说恢复正常情况隐者嘉德丽雅和正义奥黛丽是有做一定预案毕竟她们没有把握在那么短时间内杀死一位半神。如果不是布提斯落入陷阱连续遭遇精神瘟疫睡美人狂乱和致命打击处于疯狂失智状态他其实有许多机会直接传送离开没法阻拦。那样一来嘉德丽雅和奥黛丽只能等待布提斯回到安全屋放出佛尔思等待佛尔思身上窥秘之眼给予反馈然后远程施加影响给那位魔术师小姐创造出召唤历史孔隙影像机会。此时此刻面对明显已在失控通道无法逆转布提斯面对他试图完全开启那件0级封印物疯狂举止现场中央嘉德丽雅和树林外潜藏奥黛丽同时做出相仿动作那就是拿出一枚略显透明幽暗符咒并开口念出一个巨人语单词：星！这是传送符咒克莱恩根据莱曼诺旅行笔记上记录花纹标识和符号自行制作符咒。——既然源堡能调动偷盗者途径力量没道理不能响应学徒领域祈求！至于符咒所需材料是什么无论神秘学家嘉德丽雅还是旅行家佛尔思都有一定了解无需愚者先生另行教导。当奥黛丽两人行将激发符咒传送离开预备过一两分钟再回来确认情况时带着残忍笑意双眼满是疯狂布提斯动作突然僵硬。无论他怎么用力都没法打开旧日之盒第三层！这极为沉重仿佛被一层又一层力量包裹着压制着根本没法开启。这让布提斯就像在试图打开一个新世界而不是盒子。刹那之后他不知感应到什么眼中疯狂退去涌现出极为惊讶极为骇然极为恐惧情绪。滴答滴答布提斯体表滑落一个又一个光团它们触碰到地面化为一条又一条璀璨星光凝成虫豸。这些虫豸身体弯曲成半圆围出一片奇妙光芒如同一扇又一扇虚幻之门。正在往不完整神话生物形态变化布提斯就这样突兀不可遏制崩溃瓦解。啪啪两声他两颗眼珠落到地上沾染到尘埃。这两颗眼珠凝固着难以言喻惊恐保持着足够完好和身体其他部位截然不同。一位序列4秘法师就这样死亡了。啪！表面银黑镶嵌着多种宝石旧日之盒砸落在布提斯那两颗眼珠旁就像贵族家庭里常见那种首饰盒。灰雾之上古老宫殿内克莱恩松口气满含疑惑放下手中海神权杖。他刚才正要调动源堡力量以天使层次推动闪电风暴阻止布提斯打开旧日之盒第三层结果那位秘之圣者拉着所有人一起死反扑未能成功刚开始就遭遇他意料之外失败。——审判休脱离第一战场后立刻就按照预案向愚者先生做祈祷克莱恩借此得到提醒找机会进入灰雾之上通过隐者和正义对应深红星辰监控起战斗。而在转移到第二战场过程中正义奥黛丽也找机会做祈祷让克莱恩能借助她深红星辰直接干涉现实世界。这也就是奥黛丽本体比隐者嘉德丽雅迟一会儿抵达目的地原因。按照魔镜阿罗德斯说法这旧日之盒第三层藏着很可怕东西我还以为真实造物主将它赐给布提斯是为关键时刻制造可怕灾难以此表现邪神本色谁知根本就打不开……克莱恩瞄眼代表魔术师那颗深红星辰发现它蒙上一层黑灰似乎凝固起来以至于自己根本无法看到里面场景确认魔术师小姐状态。这还是他第一次遇到类似情况足见旧日之盒层次和奇诡。而之前看到睡美人魔法和朗基努斯之枪也让他有些想法：私下聚会里知晓神秘再现这个非凡能力后克莱恩就推翻过去对贝尔纳黛那些童话魔法猜测。他原本以为那是大帝根据地球童话专门弄出来给女儿或是贝尔纳黛在父亲陨落后依照他讲过童话刻意创造寄托哀思而现在看来答案应该不是这样第一纪之前某些童话也许就是神秘。这就意味着那些童话源自真实发生过神秘事件它们在民众中流传逐渐成为故事被作家记录下来做再加工。这和群星归位那个预言对应神秘从未远离一直都在只是第一纪前地球时代里它们被某种力量压制着或者封印着……如果真是这样地球某些传说和故事就有另一个角度解释了……难怪有朗基努斯之枪……不知道桃花源涉不涉及神秘回头告诉隐者女士看她能否据此创造新魔法……也不知道大帝陨落前贝尔纳黛有没有成为神秘学家如果有还真说不清楚这些童话魔法是转到窥秘人途径序列1大帝弄出来还是神秘女王贝尔纳黛自己创造……但不管怎么样大帝晚年应该已经发现这些童话也属于神秘可以从中汲取力量嗯贝尔纳黛没有对应日记我没法看到大帝当时反应和做出猜测……他执意去月亮之上其中一个原因是否就是想验证某些事情？可惜啊大部分神话是假没法汲取力量网络时代小说也是……克莱恩微微叹口气后靠住椅背继续关注战场。那片塌陷树林内隐者嘉德丽雅和正义奥黛丽面对布提斯异变默契放弃灌注灵性使用符咒。保持着龙化状态奥黛丽依旧藏在树林外黑暗里戒备着可能发生意外和也许感应到动静前来查看官方半神。隐者嘉德丽雅则被风推动着靠近布提斯死亡那片区域小心翼翼避开那个旧日之盒。由于记录官本身能使用多种能力而半神级封印物往往有极强负面效果布提斯除旧日之盒只留下一个黑色口袋这似乎是他身上那件长袍一部分。除此之外就是正在聚拢非凡特性两颗眼珠和大概十条星之虫——大部分星之虫都被摧毁。考虑到旧日之盒表现出来恐怖以及布提斯是极光会高层也许有神眷在身嘉德丽雅没有贸然拾取那些物品害怕出现意外让局面往不好方向发展。事前私下聚会里讨论时他们有交流类似情况该怎么处理那就是如果有时间和机会先献祭给愚

# 1324 倒吊人 第五十九章 半年多后

## 打开书
慷慨之城拜亚姆一间点着煤气壁灯出租屋内。戴金边眼镜维尔杜·亚伯拉罕拿着一叠厚厚资料就着不算太明亮光芒认真做着阅读时不时用笔画一个符号记录下感觉会有用处内容。他离开鲁恩前来罗思德群岛主要目的是摆脱多里安等家族成员视线安心研究神秘学寻找救回先祖伯特利·亚伯拉罕有效办法或者说降低那个仪式难度可靠知识。可是半年多过去他依旧没有一点头绪似乎除猎杀诡法师寄生者和秘法师再没有别选择。……难道只能像多里安他们一样寄希望于那位愚者？想到愚者维尔杜忍不住皱起眉头因为在拜亚姆城内宣传愚者信仰半巨人是越来越多以至于他这个较少外出人都有听闻。这让他怀疑自己是不是来到愚者教会总部附近。……不能再滞留了尽快订船票去东拜朗……维尔杜刚在心里做出决断就产生一丝动摇多里安和愚者教会应该都想不到我就躲在他们总部可以辐射区域内罗塞尔大帝曾经说过最危险地方也是最安全地方……然后他拿出纸笔刷刷将今晚监控情况书写成报告塞进某个缝隙里。……这只手属于风暴教会枢机主教阿尔杰·威尔逊。——哪怕在无光深海阿尔杰也能看清楚周围事物。维尔杜离开拜亚姆想法越来越明确了……阿尔杰微不可见点下头在心里做出总结。这半年多来他按照愚者先生吩咐一直监控着那位亚伯拉罕家族成员可始终没发现对方有什么较为异常举动。……不过阿尔杰并不想就这样结束他认为自己还没有做出足够贡献只是非常简单地监控一个没什么特殊序列7。——隐者已从神秘女王那里拿到序列3非凡特性并搜集齐相应辅助材料正在忙碌着准备仪式这给阿尔杰很大心理压力。……有那么一瞬间阿尔杰想通过各种方式间接逼迫维尔杜·亚伯拉罕让他主动暴露出自身问题但最终还是放弃这个想法因为他无法确定愚者先生对那个目标抱有是善意还是恶意。——之前白银城月城抛售非凡特性和魔药配方时阿尔杰有在塔罗会采购一些用以培养独立于风暴教会之外只忠于他藏在黑暗中非凡者队伍监控维尔杜人员就来源于此。……作为统领一个教区枢机主教阿尔杰随随便便就能省下一笔钱给自己花……收回思绪阿尔杰决定通过自己影子卫士在拜亚姆部分非凡者圈子里出售一些神秘学知识以此钓住维尔杜·亚伯拉罕能拖延对方多久就尽量拖延。主要原因在于白银城传教吓到那位先生……阿尔杰摇摇头在心里自语一句。……他刚从一个小贩手中买下用果实外壳装着特亚纳饮料突然就感觉身旁出现一大片阴影。……这位先生能占用一下您时间吗？我想给您讲一讲我们道标和救主愚者先生。这半巨人弯下腰背努力让自己笑容显得和蔼。那青年喝口特亚纳指着旁边微笑点头道：好但不要在这里。……你可以讲了。那青年完全没掩饰自己好奇。……我主自称愚者在过去在现在也在未来他是支配灵界伟大主宰也是执掌好运黄黑之王更是每个生灵追求永恒道标。我主居于现实和灵界之上仁慈洒满天国和大地祂座旁共有六位天使侍立……水银天使是命运化身是我主最宠爱天使；死亡天使是跟随我主最久存在是冥界执政官；救赎天使是我主号角是祂神谕传达者；生命天使是智慧结晶是每个人体内永不磨灭灵性。……你们主真是厉害啊竟然有这么多称号天使侍奉。不止。半巨人温和回应道主神座旁边还有惩戒天使祂是主雷霆主怒火主手掌是所有堕落者和不洁者审判官及处刑人。和惩戒天使相对是时之天使祂是古老年代里王最终臣服于我主为祂敲击天国之钟。……厉害厉害。那青年由衷赞叹道。……已经过去一刻钟就不浪费您时间了如果您感兴趣可以到菲利普斯街16号愚者教堂做更多了解这是我们在拜亚姆城中最大教堂呵呵其他还在规划中。……如果我有空闲会去看一看。……巴德尔你又去传教了？餐厅老板笑着问一句。……唯一问题在于巴德尔每天早上会外出一次宣扬愚者信仰。……今天可以教你怎么做烤鱼了。……我等下得先做个祷告。愚者先生降下神谕让所有月城人在今天早上九点向祂许愿希望不再有畸形。

## 这场戏有没有翻
翻了。开头维尔杜半年来无解欲逃；阿尔杰深海监／卖知拖延；半巨人街上讲六天使；章末月城九点许愿去畸。翻的是半年＝传教成景＋监控胶着＋神谕将至。

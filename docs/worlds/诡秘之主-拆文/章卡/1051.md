# 1051 红祭司 第一百零六章 三打一

## 打开书
轰隆。闪电覆红月全域，银白森林。灰白巨龙鳞裂显形——心理学隐身靠消存在感，互动一强即露。风暴未尽，屋顶格尔曼闪至龙斜下，蠕动的饥饿吐恶魔语「缓慢」。赫温拟举冰蓝圆筒「腐烂的流星」——星空材，墨绿弹命中即毒腐灵体，持有者或被星空注视；觉污秽之语伤不了神话己。身却真慢。屋顶又现一格尔曼：堕落伯爵丘纳斯「放大」——放牧能力近序列4，一次一项。赢家恩尤尼抓窗控灵体之线；神话本拖时长，丘纳斯再放大操控，三秒可初控。龙已挣缓慢——砰，控灵子弹命中，花园第三格尔曼；龙僵翅凝落地。控灵子弹：灵之虫+灰雾力，圣者亦麻一两秒。律师半神秘偶一体故放大如自增。初控成，拟扰反抗至成秘偶——忽抽痛狂躁低落自厌又亢奋血红恨毁：精神瘟疫！秘偶岛埋疯狂种子，感染集体海与灵体之线反向，天使难隔。操纵师能力；古谣七少女九男子城疯——半神实验真有过。几秒内本体疯则失秘偶。赫温不惧窃运对换。屋顶格尔曼对持丧钟者「扭曲」病轻缓恶；再射控灵，丘纳斯放大；第三枚放大未尽，龙颤「恢复正常」。

## 这场戏有没有翻
翻了。开头覆盖雷破隐身三秘偶连环将成；精神瘟疫反咬；扭曲+控灵再压。翻的是三打一还能否单边碾，不是龙落地说赢。

## 这一章新讲明的规矩
- 心理学隐身怕饱和覆盖。
- 放大可抬放牧能力近半神；一次一项；秘偶一体视同自增。
- 控灵子弹麻痹圣者级一两秒。
- 精神瘟疫：秘偶埋种→染集体海/线；源自自身天使难隔；操纵师高序列。
- 腐烂的流星：星空注视负面。

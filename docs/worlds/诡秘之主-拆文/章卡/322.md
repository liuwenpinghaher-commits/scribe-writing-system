# 322 无面人 第一百一十章 开启咒文

## 打开书
灰雾审帝服书签：外表寻常；戳印确认正义所验。灵性覆盖不渗——有缘人非限定非凡。试「海盗王」弗萨克／古弗萨克／因蒂斯／鲁恩及巨人精灵龙语：皆无。再试「One Piece」多语：无。反省：青年梗≠老年大帝。纸笔梳：疯狂绝望兼恶趣味；「有缘者得之」；咒文须日常可偶念；每牌不同咒；排除常用口头禅；代入绝望留恋愤怒心境。咒骂希冀失败。留恋：妻玛蒂尔达浅；子女——最难释长女贝尔纳黛。因蒂斯／鲁恩／高原／弗萨克「贝尔纳黛」无；古弗萨克再念——书签一沉！漩涡吸精神；序列7轻松撑过。光腾：罗塞尔黑冠盔甲披风石座冷望；左上星辉「序列0：黑皇帝！」牌立体如微缩书：律师→野蛮人→贿赂者→腐化男爵→混乱导师→堕落伯爵→狂乱法师→熵之公爵→弑序亲王→黑皇帝；各附配方能力。叹成神奥秘；高序列建国度因仪式：弑序→黑皇帝须己国、名与皇帝常识化、违常严密规则与建筑；驱民密建九陵寝入其一、众城祭祀服序列0药；九陵尽毁前不死可醒；弑神毁陵若秩序残存仍可能复生——新黑皇帝方可泯。非凡特性守恒：有序列0则无序列1；无0则同途序列1最多三。途质：渐成秩序阴影。高序列持牌可感对应材料（限本途）——对己无用。牌显形扑克：不再伪装。最大用：换配方／神序知识；愚者塔罗不再空壳。忆智慧之眼聚会有人求野蛮人方。笑罗塞尔每序自拍；好奇魔女牌。毁验另签＝普通。靠椅回正义：「那是一张罗塞尔制作的『亵渎之牌』。」

## 这场戏有没有翻
翻了。开头还是普通书签试咒失败；章末黑皇帝全途径摊开、愚者有货可答正义。翻的是窃来的纸片还能否只当纪念品，不是 One Piece。

## 热怎么变冷
多语试咒还热。冷切在反省梗错。代入心境还热。冷切在古弗萨克「贝尔纳黛」一沉。序列0还热。冷切在「对我没什么用」与换配方定位。

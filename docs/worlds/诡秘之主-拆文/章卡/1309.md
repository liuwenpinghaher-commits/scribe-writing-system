# 1309 倒吊人 第四十四章 使者

## 打开书
黑夜教堂祈祷厅一如既往昏暗只有墙上那些孔洞才有些许光芒渗入仿佛夜晚一颗颗星辰。克莱恩坐到不引人瞩目角落摘掉高高礼帽像一个虔诚信徒般开始祷告。他简单提了提罗塞尔已在最后那座陵寝复活事情将重点放在原始月亮污染上特意强调那位大帝为不让体内红月出生于现实世界主动中断黑皇帝途径唯一性和三份序列1非凡特性回归进程。祷告尾声克莱恩点明亵渎之牌存在隐患并对母亲牌和月亮牌下落表示忧虑。其实罗塞尔只说要小心母亲牌并未提月亮牌但克莱恩知道大地和月亮两条途径都曾经属于那位堕落母神所以谨慎为重特意加上月亮牌。这也是他担心大地母神莉莉丝主要原因。……地底污染越来越薄弱同时无形屏障也越来越脆弱出现一些裂缝这种情况下大地母神莉莉丝处境越来越困难因为祂直面是越来越强大越来越可怕堕落母神侵蚀……对他来说这主要是尽告知义务至于黑夜女神打算怎么做会不会提醒他一些事情他完全干涉不了。……那枚戒指通体呈半透明状仿佛由淡红琥珀制成顶端镶嵌着一颗血红色宝石正是埃姆林很久前获得奖赏：莉莉丝指环。……早上好伯爵阁下。……米斯特拉尔还没来吗？米斯特拉尔伯爵在家里布置一个小教堂。欧内斯简单解释一句。……但举行弥撒时候还是得到这里来。……乌特拉夫斯基主教呢？主教在后面等您教会使者到了。……这位是大主教洛雷托阁下。……早上好洛雷托阁下。……不用称呼我阁下你虽然不是大主教但有着大主教地位从今天开始你就是教会负责贝克兰德血族事务圣职者高级执事了。……我来贝克兰德是受宗座嘱托将教会内部需要注意一些事项当面告诉你。……首先最重要一点无论是教会神职人员还是母神信徒只要声称自己获得神启都是受到魔鬼诱惑没有例外。……母神启示就在祂圣典里在那一条条教义中除此之外都是邪说。……那需要注意第二点是什么？如果你收到神谕不要盲目相信请立刻向乌特拉夫斯基主教寻求确认。……因为我们大地母神教会主要两条途径都和生命有关所以受到影响比其他教会要严重……为遏制这样趋势我们从很早开始就在母神意志引导下改组教会确立神恩者和神眷者这两大体系。……神恩者是指大地和月亮两条途径内受到母神恩宠神职人员神眷者是指来自外部来自其他途径母神眷顾者。后者受到魔鬼和邪神影响较少可以帮助我们鉴别神谕真假。在这样前提下哪怕是宗座颁布谕令也必须有至少一位神眷者副署否则可以视作无效。……神眷者都不属于大地和月亮两条途径！所以有问题不是神恩者而是这两条途径本身？埃姆林隐约觉得自己这个猜测或许就是真相。

## 这场戏有没有翻
翻了。开头克莱恩告女神；切埃姆林升高级执事；使者两条戒；章末猜途径本身有问题。翻的是使者课＝神启全邪＋神眷副署＝途径自危。

## 这一章新讲明的规矩
- 自称神启＝魔鬼诱惑无例外。
- 启示只在圣典教义。
- 神谕须神眷确认；宗座谕须神眷副署。
- 神恩＝地月途内；神眷＝外途。
- 地月途无原初苏醒优势反成母神直侵弱点（克莱恩独白）。

# 1321 倒吊人 第五十六章 遇事不决先拖延

## 打开书
听到世界格尔曼·斯帕罗问题塔罗会其余成员总共出现三种反应：这是谁我似乎听过……他是四王之一？这是谁我怎么没听过……唔我又忘记询问心理炼金会相关事情了刚才还打算以更加委婉方式寻求一些建议……第一种反应源于倒吊人阿尔杰隐者嘉德丽雅和在海上生活过一段时间魔术师佛尔思第二种反应来自星星伦纳德月亮埃姆林审判休和太阳戴里克第三种反应则独属于正义奥黛丽。见没人给予回答世界格尔曼·斯帕罗并未进一步询问他主要目的其实是借此提醒正义小姐让她将可以绕过承诺事情拿出来讨论一下。……此时正义奥黛丽想了想道：你们还记得我曾经追寻心灵巨龙踪迹去了一个有巨龙崇拜风俗地方吗？……这过去差不多已经两年某个对我不是太信任隐秘组织突然又提及此事委托我做进一步调查说是对我一次考察他们有什么目的？……月亮埃姆林初步缓过来笑一声道：这应该是一个试探。……正义奥黛丽不是太认同说道：我怀疑他们已经知道我有问题甚至知道我问题在哪里牵涉哪个势力没必要再做试探。……也就是说黄昏隐士会或者空想天使亚当肯定已借此攫取不少好处有相应成长。而在此之前愚者先生提示亚当距离神位更近了。综合这些信息奥黛丽初步判断空想天使亚当有不小概率已登临神座成为序列0空想家。……或许那个组织想试探是我们塔罗会究竟有多少成员各自是什么身份。……不排除这个可能。……这时听完他们对话倒吊人阿尔杰提出一个全新可能：如果那个隐秘组织确实对你不太信任那他们做考察也许只是一个借口主要目的是通过你与我们塔罗会与愚者先生进行一些合作。……唔这就等于我成了塔罗会驻心理炼金会大使？正义奥黛丽微微颔首道：也有这样可能。那我接下来该怎么做？倒吊人阿尔杰想了想道：先拖延。……先拖延去那个地方时间不到最后一刻都找借口不去。到了那个地方先从外围区域查起以谨慎为借口放慢调查速度。等到实在拖延不下去可以在某些事情上故意出现疏漏制造一定动静让那条心灵巨龙提前察觉消除痕迹。那个隐秘组织如果真有什么额外目的你拖得越久他们越是坐不住而他们一急躁就会暴露问题。……这是当前最合适应对。……我明白了谢谢大家。……尊敬愚者先生空想天使亚当是否已晋升序列0？不错能认知到这一点……愚者克莱恩后靠住椅背低笑一声道：直至末日将近祂终于迈出这一步。……空想天使亚当成神了？这个消息顿时回荡在太阳戴里克等人脑海中久久无法平息。果然……正义奥黛丽抿抿嘴唇道声谢然后问道：我需要为这个答案付出什么报酬？愚者克莱恩环顾一圈道：不用。这是一个提醒。……隔几秒太阳戴里克左右各看一眼试探着问道：白银城已开垦好周围田地种下小麦等作物但丰收无法立刻到来我想知道我们能做些什么来赚取金镑购买物资？……正义奥黛丽想了想道：你们最擅长什么？战斗。太阳戴里克回答得一点也不犹豫。倒吊人阿尔杰闻言微微点头道：虽然世界大战已经结束但南大陆殖民秩序并未得到有效恢复那里依旧很混乱时不时有小规模战争爆发。你们可以尝试着组建两到三支佣兵队伍接受任何势力雇佣。……这是一个好办法。戴里克听得眼睛一亮。倒吊人阿尔杰随即又问道：战斗是生存本能除这个你们还有想做事情吗？太阳戴里克略有点不好意思回答道：不少人希望做厨师酿酒师希望去糖果工厂工作……

## 这场戏有没有翻
翻了。开头三种反应；正义巨龙考察三解；倒吊人「先拖延」战术；愚者确认亚当成神免酬；章末太阳问生计→佣兵／想做厨。翻的是遇事不决先拖延＝标准对策。

# 930 不死者 第一百九十九章 获取情报的新方法

## 打开书
安德森见达尼兹苍白汗多：日射病？猎人适应不该本能？达尼兹抹汗挤笑：一信邪神再摆脱几乎不可能——下巴一抬看你怎么死，没想自身也信疑似邪神愚者，也没想格尔曼刚得罪极光。安德森笑：我未真信，尊名从知识与智慧之神改来，他们没脑子，装虔诚即可。你为何突提极光？达尼兹咬肉隔二三十秒：格尔曼被极光高度重视须清除，还有灵教团，你我公认有联系。安德森：类似话近说过，玫瑰风暴军方……有时觉得他比我更适合作猎人。达尼兹重点头。安德森转：你来西拜朗想做什么？信仰情况调查——与艾德雯娜确认：查隐秘组织势力，附带军火需求。安德森揉额头疼。克莱恩结束塔罗，提醒星之上将注意极光灵教团、最好寻摩斯苦修会；忙完世界月亮太阳三方交易，收五千镑。晚餐叼装饰烟斗读报，蕾妮特送信即回灵界——伦纳德已付邮费。信：因斯出现东拜朗，疑与人造死神派帕伦克碰面；望暗中查目的。靠椅：0-08凡有言被必知，查易暴露。重读：东拜朗、人造死神派……记起几乎仅自己与阿兹克知——女神初步控制死神途径唯一性即人造死神，在篡夺消化权柄。古文献：人造死神派每日向唯一性祈祷唤灵智。帕伦克或在祈祷时提因斯目的求庇佑；对面已失自由。布置仪式向女神求或可得目的——敌人首领是我们卧底。犹豫：女神或乐意清叛徒，但正消化关键期未必回应；且不能全信依赖女神，求神谕想保持距离。更荒谬：直接向人造死神求！本身不应回应，有反馈则本质女神操作；手头羽毛与阿兹克铜哨够材料；隔一层或助掌握权柄。献祭取羽毛、满月精油、夜香草等，懒另购死神材料。点燃滴油，羊皮人与隐秘符号，铜哨压上，白羽入银碗不卷不焦。赫密斯：您是死亡的本质；亡者之主；生灵最后归宿。求因斯与灵教团联络目的。烛火胀阴绿森冷。再滴精油，烧羊皮入碗，白羽苍白焰覆碗。退后粉末无风成词：恶灵附身，需要驱除。

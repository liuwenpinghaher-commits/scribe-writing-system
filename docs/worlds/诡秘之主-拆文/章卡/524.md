# 524 旅行家 第四十三章 冷静的斯考尔

## 打开书
抬头看眼壁钟见时间已经过了8点阿尔杰放下厚实玻璃制成酒杯挤过来来往往醉鬼来到大街上。因为罗思德群岛有丰富煤炭资源拜亚姆就像贝克兰德普利兹港等大陆城市一样街边竖立着一根根人高黑色灯杆瓦斯燃烧光芒从金属围成栅格里透出照亮还算整洁地面。扯下头巾慢悠悠拐向旁边小巷子在封死尽头闻到夹杂酒味尿臊气——香树叶酒吧虽然有盥洗室但数量相对高峰期顾客来说明显不够某些憋不住无法等待酒鬼只好出来找僻静地方解决。红色月光穿过云层照入这条巷子还在考虑要不要装样子装得像一点时背后就传来一道结实饱满隐含笑意声音：「你是故意把烈焰消息透露给我们？」还不笨…自语一句缓慢转过身体似乎在防备对方突袭。看见七八步外有道人影倚着墙壁站姿很差。这人影1米78左右戴着顶船形帽脸庞消瘦棱角尖锐外表极具攻击性。有一绺黑发垂下半遮住左边墨绿色眼睛这让他本身冷硬柔和不少。虽然通缉画像与本人往往有不小差别许多知名海盗甚至不需要做伪装就能在城市里游荡但作为教会内部人士看过许多利用仪式画出来近乎照片肖像且参加过海盗大会还是顺利将眼前家伙与悬赏令上某个名字联系在一起。没有表现出这点故意迟疑着犹豫着反问：「冷静的斯考尔？」这是钢铁麦维提主要帮手一个擅于控制情绪冷静思考但又毫无人性非凡者悬赏金额1500镑。那男子拉拉黑色风衣露出笑容却不带笑意说：「我可以否认吗？嗯…看来不行就像你不能否认自己是故意在奥鲁马面前提到烈焰一样他不是一个喜欢动脑子人而我正好相反。」「我从没想过要隐瞒我只希望用我获得消息换取一些报酬。独自一个人烈焰和帮手众多钢铁之间脑袋正常人都明白该选哪个当然我希望你们为我保密我并不想被冰山中将追杀。」坦然回应。斯考尔悠闲而缓慢点头道：「具体讲一讲。」「和我之前提到过一样我在金币赌场遇到并认出烈焰他委托我帮忙留意钢铁行踪呵呵他似乎想做出反击。」嗤笑「我们约定了联络点我认为这是至少价值1000镑情报。」「1000镑？抬头看看红月你不是在做梦！」呵一声「这也许是陷阱你还不明白吗？烈焰很可能找到了帮手所以才敢于反向寻找我们。」「是否为陷阱不应该由我来判断500镑低于这数目我宁愿装作什么事情都没有发生过。」为了报酬据理力争。「300镑你跟我去一个地方待上一段时间避免你再把这消息卖给其他人打乱我们计划等我们确实借助这情报抓到烈焰或者通了他灵再支付你报酬不用担心食物美酒和床全部免费不管怎么样你都赚了！如果有什么来源于你意外嘿嘿你应该知道后果。」以一种不容拒绝口吻提议。果然和我预料一样在我背景不明且没有太大危险性情况下他们选择临时拘禁可能远远高于灭口…不过我也做好最坏打算有了相应准备只要不大意逃还是不成问题…故作为难想了想道：「不能超过两天否则我船员会带着我船离开。」「超过两天我会通知他们。」斯考尔掌中不知什么时候多了把锋利手术刀并玩杂技一样让它跳跃旋转着。等阿尔杰详细描述香树大道15号这联络点和相应联络方式斯考尔没再多说转身于前面带路领着阿尔杰七拐八绕来到不知哪条街道进入一栋毫无特点房屋。「好久不见蓝发幽灵船船长。」开门是位头发白多黑少老者做本地人打扮穿着条宽松阔脚裤。「老奎因你真是血之上将情报官…」故作诧异开口。老奎因嘿嘿一笑道：「传闻总是有真有假你以为是假也许是真。」没有开煤气壁灯手里托着个银制烛台引着阿尔杰和斯考尔通过黑暗大厅进入宽敞结实没有窗户地下室。「你在这里住段时间我和我几个朋友负责看守并提供酒水和食物。」笑着说「为了表示我们诚意我们不会解除你武装。」「好。」主动走到地下室矮脚床边。老奎因随即关上厚重石门锁住地下室。斯考尔未停留此地匆匆远去并反复确认是否有被人跟踪。换乘一次出租马车后来到拜亚姆鲁恩人聚居区也就是上等人居住地。进了栋花园洋房看见麦维提正靠坐在客厅沙发上等待自己其余几位同伙或躺或站或坐形成半圆傀儡和活尸们则充当着警戒四周角色。钢铁嘴唇较厚皮肤黝黑头发一绺绺卷起仿佛工厂里常见那种钢珠。「消息可靠吗？」胳膊肌肉一抖一抖极具力量感可整体却给人冰冷阴森不像活物错觉。斯考尔点下头道：「一个为金钱服务海盗船长我已经将他拘禁在老奎因那里如果真有什么问题他肯定无法活着出去我想他应该很明白这点。」说到这里露出冰冷笑意：「不过我们依然得提防意外这可能是烈焰陷阱。」「你们有什么办法？」麦维提直接询问。目光最先望向躺在长沙发上一个海盗对方套着咖啡色本地短袍手指旋转着一顶中间凹陷黄棕色草帽。这是麦维提本次行动副手在之前和黄昏中将战斗里失去自己船只第六舰长血色荆棘亨特利悬赏金额3800镑。「很显然斯考尔已经有了办法。」亨特利用草帽遮住自己略显苍白脸孔。斯考尔呵呵笑道：「约翰·史密斯那伙冒险家不是派摩多隐藏身份加入我们吗？不小心把这消息透露给他并让他以为我们还在等待帮手需要后天或者大后天才能动手就行了。那群贪婪冒险家肯定不会放过烈焰必然抢先下手到时候我们找个地方旁观如果真有什么意外就让他们承受要是一切顺利正好连他们一起吃掉！」「好。」钢铁眼珠微动迸射出强烈嗜血冲动。……凌晨时分一切准备就绪。血色荆棘提过皮制行李箱从里面取出一张孔雀蓝地毯将它缓慢铺到面前其上有诸多神秘奇异图案带着些许不属于人类般风味。麦维提斯考尔另外两位非凡者七八个活尸和傀儡相继站上去。亨特利最后进入半闭上眼睛默念出一个精灵语单词：「飞行！」孔雀蓝颜色地毯猛然绷紧浮起来载着众人离开地面升入半空向着香树大道飞去。这过程里亨特利掏出张黑色手帕抖腕一甩化作夜幕将月光下较为明显踪迹全部奇妙遮住。也就七八分钟样子他们抵达香树大道20号附近斜对面就是目标房屋。没再前行让那张飞毯安静悬浮于一株粗大树木冠顶前自身则俯视起对面目标状况。时间一分一秒流逝亨特利稳稳驾驭这神奇物品未有灵性不足征兆。长夜缓慢过去天边泛起微红太阳即将升起钢铁这一伙海盗开始准备寻找另外适合白昼监控地点。就这时一道身影伏着腰背动作敏捷穿行于各个屋顶来到香树大道15号上方。披着黑色斗篷眉毛焦黄眼睛深蓝五官和轮廓都较为柔和正是烈焰达尼兹！谨慎左顾右盼一阵爬上耸起烟囱将手一撑钻进去往下滑落。真的来了？钢铁血色荆棘斯考尔等人同时精神一振。这个时候几道身影从13号14号17号房屋烟囱和外围隐蔽处蹿出以迅猛姿态从不同位置或撞破窗户或踢开大门或利用烟囱地进入15号房屋。

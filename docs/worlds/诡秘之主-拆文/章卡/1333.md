# 1333 倒吊人 第六十八章 月夜

## 打开书
军情九处办公楼位于西区贝洛托街是栋看起来毫不起眼三层小楼。它门口没有任何可以说明自己身份标识只简单地挂一个门牌：9。这栋办公楼最核心部分在地底上方主要是文职人员当然大部分隶属于军情九处非凡者没事也不会去地底那里环境不好气氛压抑随时都有可能因封印物看管不当出现事故。休目前已担任国内安全和反间谍组副组长直接管理着一支规模不算小非凡者队伍负责处理贝克兰德大区与因蒂斯相关间谍案件。这里有个任务。她顶头上司军情九处副处长兼国内安全和反间谍组组长潘特克中将拿起一份文件递向办公桌对面。很紧急吗？休伸手接过谨慎问一句。……不紧急低危险度。事实上这个任务将下发给所有成员寄希望于有人能凭运气完成。……我会转告我组员们。……过去半年多里为应对预告中末日休每天都很忙碌一边处理军情九处事务一边完成着愚者先生给各种任务以此在两边都积累贡献为兑换律令法师魔药配方和非凡特性实现成为半神愿望做准备。……若非还能在军情九处领一份丰厚薪水享受各个方面福利且可以依靠地位和身份占据大量情报以此帮助自己完成愚者先生给予任务休都想直接辞职重做赏金猎人那样时间会更自由。下次塔罗会上可以问一问这个案子也许世界先生他们会有一定线索……休一边想着一边推开组员们所在房间大门。……如果情况不对即使有机会进入乌托邦也可以直接放弃。那个不知真假城镇没有展现出危害性也许只是因为没受到刺激。……血月……休猛然转头关切望向隔壁有些担忧好友状态。不过她很快记起佛尔思已是序列4半神不再害怕满月呓语影响。……隔壁房间内佛尔思正靠躺在床上边欣赏窗外血月边忍着脑袋被针扎痛苦听门先生说话：虽然序列3到序列2不完整神话生物到真正神话生物确实是一次质变但我认为序列4到序列3同样有某种程度上质变甚至可以这么说序列3是非凡途径中最美好那个层次。在这个层次既不需要依靠外力来对抗疯狂和失控倾向不用每时每刻都承受煎熬也有着完全超越普通人非凡能力更像神而非人并且还可以少量收获锚更进一步稳定自身精神状态。若非大部分序列3生命还不够漫长很难活到500岁以上我想应该没多少圣者有动力晋升为天使……嗯嗯。佛尔思连连点头表示自己已经清楚。……学徒途径序列3叫漫游者这意味着灵界也无法再困住你可以进入星空遨游星界前往不同星球见识真正死寂真正荒芜真正恢弘以及与本地完全不同文明。只有亲身体会过这些你才能知道你生活这个世界有多么渺小……门先生简单地讲讲自己经历以此展现星空雄伟和瑰丽展现不同文明厚重和魅力。……只要你帮我脱困我就会给你漫游者魔药配方和非凡特性并助你完成仪式当然这都可以预付。满月呓语尾声门先生又一次给出承诺。真是让人向往啊。佛尔思由衷赞叹道。等到门先生声音逐渐减弱消失不见佛尔思猛地抽掉腰部靠枕躺下去。……等旅游完南北大陆和五大海洋所有地方再考虑……睡梦之中佛尔思近乎无声自语一句。……刚才梦不简单。作为一位巫王他对梦境领域有着足够了解。这难道就是所谓神启？可我什么启示都没有获得……埃姆林想几十秒没找到答案然后就决定不再去管这个问题准备有时间询问一下乌特拉夫斯基神父。……阿尔杰伸手接住狂风送来纸条展开看一眼：维尔杜在寻找去班西海盗船或走私船。——班西港尚未重建各地都没有通往那里客轮珍惜传送机会维尔杜只能依靠非常规办法。……另外他还从愚者先生和世界格尔曼·斯帕罗那里知道更多。……当然在罗思德群岛走私船往往也等于海盗船。

## 这场戏有没有翻
翻了。开头休接乌托邦低危广发任务；血月门先生推销漫游者；埃姆林异梦；章末维尔杜寻班西船。翻的是月夜＝多线并行：乌托邦任务／门诱／班西动。

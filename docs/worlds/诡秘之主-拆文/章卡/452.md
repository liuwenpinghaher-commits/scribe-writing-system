# 452 无面人 第二百四十章 “阶梯”

## 打开书
红蔷薇古董房外问第六女仆——黑白佣裙棕天然卷俏。「塔利姆访接触谁？」麻木重复。「求见王子骑马商量；王子不在见那位小姐——好友；管允。」劝离护声誉？「聊何？」「请出房。」狗血脑补涂层礼帽…女仆轻笑：「想知聊何直接问她。」「管不许。」盾。「你知更多还称莫里亚蒂侦探？」「轮换伺她；她想见你——友在意死。总错过。」敏感总恰错。「首邀时她故发脾气想下楼见；您匆离。后代王子墓献花；不清长相未找着。今日正巧后高尔夫骑马否则想办法见。」巧——关键：葬礼代献花＝平民女！最在意蓝宝戒黑纱女＝0级／半神？闪：蓝戒女黑裙两侍远——一侍棕天然卷＝眼前女仆！绷背心汗——小丑笑：「葬礼你跟小姐？」「是。」草真她！笑：「很好下一问。」缩流程加速——抢她骑马归前离！四点未暗提前告辞管车返城。松回味：咒杀＝王子心爱平民女？报复拆散？何必亲自动——床上抖王子有办法消塔…塔死前热恋；劝离后迹象——奸情？带回女消隐患咒杀？逻辑通——但0级怎被王子限？天使家亦须巨力；此人物怎看上塔？想见我？察灰雾窥？否——葬礼当天就该跟葬；最早想见时未拿物未卜！决埋心底不查！望机械因提醒察王室异重视或另因；望王室续限她勿访我；几日交无力＋南方度假变身份躲！心渐平。黄昏雨湿街飞回明斯克。逆四步灰雾——查晋后空间变；排扰卜：晋后灵未稳未闻「霍纳奇斯…弗雷格拉」呓！宫殿桌椅雾似未变——灵觉有异。写：「晋升后未听到呓语的原因。」梦定格：肉芽己周稀薄灰白雾人难察。悟：灰雾交现实屏蔽呓；序6联更紧可自然借少力。循感雾上行——将弃忽光闪。喜近：纯粹光芒天国阶！神圣通透四层；每层极高为超巨人。上望灰白雾凝半空托物；阶与彼有距。四层＝喝完9–6？雾上何？踩实如石；翻爬第四层眺——视穿不过。前两步跃离阶——失冲力灵飞坠回底雾。须再升两三序列；序4质变半神或可…望上判断。

## 这场戏有没有翻
翻了。开头问女仆麻木；章末光阶四层坠回。翻的是蓝戒＝小姐＋侍女对上、决埋案，不是庄园问出真凶口供。

## 话
「总是错过」「除了那位小姐」（上章）「草，真的是她！」局面是从女仆收到对上蓝戒；从埋案收到光阶；从跃收到坠回。

## 热怎么变冷
好友聊还热。冷切在请出房。蓝戒对上还热。冷切在埋心底。光阶还热——跃坠冷切。

## 怎么起、怎么收

# 1347 倒吊人 第八十二章 仪式的准备

## 打开书
蓝山岛一片原始森林内。做好准备维尔杜·亚伯拉罕担心在城外举行仪式会被官方非凡者发现遂利用封印物传送离开拜亚姆到了这人迹罕至地方。摸了摸又开始疼痛肋骨维尔杜脱下古典长袍将它放在一边。紧接着他布置祭坛点燃蜡烛焚烧正确精油纯露草药粉末等物品。……伟大战争之神；铁与血象征；动乱和纷争主宰……它们对应烛火一下暴涨从树苗蹿升成巨木。……伟大战争之神卑微信徒想祈求您帮助。……——他从家族某本典籍里知道向战争之神祈祷时最需要做事情就是告诉自己不要生气。……卑微凡人神灵不是用来满足你愿望。说吧说出你祈求而最终是否帮助你由我决定。……伟大战争之神我该怎样才能让我先祖门先生伯特利·亚伯拉罕回归现实世界？一个仪式献祭一个诡法师一个秘法师一个寄生者仪式你应该早就清楚。火焰巨人低沉而威严说道。……伟大战争之神如果想请您帮我完成这个仪式那我需要付出什么？火焰巨人俯视着这名占星人道：相应代价不是你能付出你那苍白而渺小灵魂连做余烬资格都没有。……但门先生可以。而且我今天心情不错。将你血液献祭一部分给我作为契约印记相应代价我将向门先生索取。……确实只有先祖伯特利·亚伯拉罕才有资格和战争之神这种隐秘存在交易！至于门先生是否愿意进行这场交易维尔杜从未考虑过在他看来任何人处在被放逐和封印状态都毫无疑问想脱困哪怕为此付出不小代价！是伟大战争之神。维尔杜思索片刻后脑袋一热答应下来。……等他血液化作一粒粒红色珍珠穿过献祭与赐予之门后那里变得极为幽暗仿佛潜藏着数不清怪物。……紧接着又是一团事物被献祭与赐予之门吐出来。……星之虫……这是拥有秘法师非凡特性怪物？之前那个对应诡法师……确实秘法师和诡法师都只是魔药名称并不单纯指人类半神这个称呼同样如此除非特别加上半人这个修饰……而这就意味着帮助门先生脱困仪式可以用占卜家学徒和偷盗者对应怪物半神做祭品并且无需维尔杜亲自动手伟大战争之神已经准备好一切。这让维尔杜难以压制内心欣喜极为期待看着献祭与赐予之门等着第三个祭品被吐出。……寄生者对应怪物……维尔杜心中一喜真诚赞美起伟大战争之神。……你只剩下神性？克莱恩望着前方巨大十字架低沉问道。……是。只有和真实合二为一我才完整。……虽然真实造物主是负面人格极端情绪化身但祂也因此继承人性？所以祂疯掉。亚当就像在说一个陌生人。克莱恩想了下边解读第二块亵渎石板上剩余内容边开口问道：如果真合二而一你们之中谁会占据主导位置？这就是我们苏醒之后一直在竞争事情。亚当松开握着银制十字架吊坠手掌道。所以你才通过阿蒙拿到第一块亵渎石板希望能借此掌握混沌海获得主动权？克莱恩一阵恍然眉头微皱点下头道：在这件事情上你们似乎很有默契真实造物主从来没有用你身份做文章引入外力来对付你。这是我们之间事情。亚当态度平和回答道。克莱恩默然几秒后转而盯着亵渎石板道：我总觉得红天使死和第四纪很多事情不是那么简单。……为什么这么说？亚当不答反问一副随时开始祷告模样。……黑皇帝归来前所罗门帝国只有真实造物主一位真神以及红祭司唯一性……这种情况下你就算不谋划针对红天使行动也不会有人怀疑你……你不理解是因为你了解不够多。第四纪除三大帝国和它们背后真神天使之王们活跃于历史舞台还有魔女教派还有摩斯苦修会还有深渊渗透和隐蔽发展工匠还有南大陆拜朗。而且这并非全部另外足以称得上关键因素并不少。……比如六神之间矛盾？不止。……你应该去过班西。……另外我陨落之后外神们对现实侵蚀明显加深。……代表贝尔纳黛那个祈祷光点由于无人响应一直在膨胀收缩荡开光晕。一次次轮空后它其中一根触手碰到正确祈祷光点。

## 这场戏有没有翻

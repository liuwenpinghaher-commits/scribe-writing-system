# 1077 红祭司 第一百三十二章 隐藏的秘密

## 打开书
秘之圣者布提斯。佛尔思可能被天使之王注视过，承受力够，自然收回目光，迎着黑风衣走过去。擦肩。他若知道老师在，该直接传送，不会这么慢；老师已上车。心落下，抬头望天像在看会不会下雨。一只乌鸦落到行道树，正面朝向她刚路过处。她保持速度离开。极光会好久没在贝克兰德聚会，目标又是半神，暂不复仇——锁定一位秘法师都难。等旅行家或偶遇，再委世界，先攒报酬。能确定的是极光会有圣者在城；也不排除布提斯旅行时被特性吸引迷路。世界三个月内至少亲手杀掉两位半神；教会高层真正半神不过十来位，按这进度两年能清空一个教会——现实不是这模型。外科医生式发散着上了出租马车。切灰雾。太阳、倒吊人、世界的小会，这次愚者见证：戴里克要问哪件更能取悦，好换十字架。四件能力负面都出众，也说明白银城没有工匠，收获靠天然，神级也只能粉碎不能重组。克莱恩先排除黄昏面具：秘偶可避尖啸与为奴，本体仍会进无端死亡名单。再弃堕落长笛：预知危险胜过蠕动饥饿里的欲望使徒，本体会失情感，交秘偶则周围变笨，伤占卜家核心；还不愿伯克伦德街变成欲望横流、私生子一堆。剩剑与杖。剑的人头可沟通以降负面，身高只要高度不要厚度，小丑能平衡。杖的异变交秘偶、用血之花戒指修，区域茂盛不算太负。剑是猎魔者攻防，杖邪异能创造畸变。太阳问答案，愚者平常道：就手杖吧。不太常见的理由：邪异当得起诡秘，助诡法师扮演消化。戴里克欣喜。问世界：除成年心灵巨龙完整大脑，还要耕种者高序列配方吗？通道是世界分享的，只能问他。克莱恩头痛。首席一边探巨人王庭找光明，一边做好在黑暗坚守，用配方试愚者有没有改环境的权柄。弗兰克来信研究只差一步，成德鲁伊或能成；序列5无神性弄不出太大乱子，隐者已是半神能看住。世界：序列5。还有更高呢？如果你们想给，也可以。戴里克转问倒吊人：首席为何突然提耕种者。阿尔杰：试探环境能不能变。月亮称丰收女神欧弥贝拉，白银城最初信的是祂；首席忽然拿出城中本不知的高序列配方，让他疑月亮是对的——城藏过这信仰，连真名都刻意不提。这里面肯定藏着不小的秘密。戴里克想不出。结束交流，返回白银城，准备交换。

## 这场戏有没有翻
翻了。擦肩还靠自然和老师已上车；小会上四件收成就手杖吧，理由不是最强是邪异能助扮演；耕种者配方把取悦题再翻成白银城藏着不小的秘密。翻的是清单还能否只挑剑，不是街口松气。

## 日子
贝克兰德街，乌鸦落在行道树。出租马车。灰雾青铜长桌，愚者见证的三人小会。

## 这一章落在哪一天
撞见布提斯同日。小会紧接在擦肩之后，正文未写到间隔钟点。

## 人
- 佛尔思：擦肩不露异常；把偶遇写成特性吸引或迷路；暂不复仇，攒报酬等旅行家；上马车前发散清空教会。
- 布提斯：慢吞吞走过，未传送。
- 戴里克：问哪件取悦；欣喜到手杖方向；追问耕种者更高序列；想不出秘密。
- 克莱恩／愚者／世界：排除面具与长笛；要手杖助诡法师；头痛后只收序列5，更高也可以。
- 阿尔杰：判首席试探环境；用月亮的欧弥贝拉把配方收成隐藏信仰。
- 科林：话里的思路，未出场。
- 弗兰克·李、隐者：来信与看住，未出场。
- 乌鸦：落到树上朝向刚路过处，未再写它做什么。

## 地与走
街道擦肩 → 望天、乌鸦、离开街道 → 街边出租马车 → 灰雾小会 → 返回白银城准备交换。伯克伦德街只在长笛会让人心堕落的担心里。

## 这一章新讲明的规矩
- 非凡特性吸引力可致旅行者迷路或偶然路过。
- 秘法师难寻难锁；半神仇暂不报，等旅行家再委世界。
- 黄昏面具：秘偶可避尖啸与为奴，本体仍会进无端死亡的名单。
- 堕落长笛：本体失情感，秘偶则周围变笨，伤占卜家核心；还会让地方欲望横流。
- 曦银之剑人头可沟通以降负面；身高可只要高度不要厚度，小丑能平衡。
- 生命手杖异变可交秘偶、用血之花戒指修；邪异助诡法师扮演。
- 白银城没有工匠，收获靠天然形成，神级也只能粉碎不能更好重组。
- 耕种者高序列配方：首席试探愚者权柄能否改环境；阿尔杰由此疑白银城隐藏过对丰收女神欧弥贝拉的信仰。

## 钱与人情
换十字架是取悦题，手杖定了尚未交割。佛尔思要攒报酬再委托世界复仇。戴里克因世界分享过秘密通道，配方问世界不问愚者——把人情记在眷者账上。

## 话
「就手杖吧。」「是，『愚者』先生！」「您还需要『耕种者』途径较高序列的魔药配方吗？」「序列5。」「如果还有更高的呢？」「如果你们想给，也可以……」「这里面肯定藏着不小的秘密。」局面是秘密三字把四选收成生命手杖，又把配方收成不敢提的真名。

## 热怎么变冷
擦肩还松。冷切在乌鸦朝向刚路过处。就手杖吧还轻。冷切在诡法师消化。序列5还顾眼前。冷切在不小的秘密。

## 怎么起、怎么收
第一段接秘之圣者布提斯。最后一段停在返回白银城准备交换。章题隐藏的秘密：阿尔杰点的是丰收女神，克莱恩要的手杖里也藏着不小的用处。

## 叙述怎么插手
特性吸引、老师已上车：佛尔思心里过一遍。清空教会的理想模型：外科医生式发散。白银城无工匠：愚者听描述时的判断。不要厚度只讲高度：小丑的算法。首席两手准备：克莱恩替科林说的思路。月亮记载与隐藏真名：阿尔杰收束。

## 这一章放了什么
- 生命手杖偏好与诡法师扮演：交换核。
- 耕种者序列5、更高也可以：给白银城的口子。
- 隐藏丰收女神信仰：秘密点名未打开。
- 布提斯在城、暂不复仇：街上那条线的处理。

## 这一章收了什么
上章四选：本章排除两件、定手杖。擦肩：本章走过去并上车。欧弥贝拉这个名字：从月亮说过收到白银城故意不提。

## 谁比谁多知道
愚者知手杖对扮演的价值，戴里克只知取悦成功。阿尔杰知隐藏信仰这件事值得疑，戴里克想不出秘密。佛尔思知圣者在贝克兰德；布提斯正文未写到他知不知道老师刚走。乌鸦朝向刚路过处，正文未写到它属于谁。

## 可搬走的一条作法
以后写别的书：让「哪件取悦神明」的答案不是最强兵器，是一件邪异得能助扮演的园艺杖；再用一句「你们为什么不提这位女神的真名」把交换题翻开。书证 L91271：「这里面肯定藏着不小的秘密。」

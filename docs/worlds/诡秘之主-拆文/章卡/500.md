# 500 旅行家 第十九章 诱饵

## 打开书
发出电报收拾好桌子后白鲨汉密尔顿彻底放松下来有心情和能力去思考事情细节。最先跃入脑海问题则是：「外面守卫呢？」双手一撑猛然站起脚步沉重走到门边拉开一瞧发现几名手下正歪歪斜斜站那里讲着与女人有关笑话。先是怒火冲脑旋即冷静下来脸部肌肉略微跳动捶下敞开房门。咚！几名守卫吓一跳本能转头望向门边。「老板…」「头儿…」看到发出声音是谁后慌忙站好嗫嚅开口。白鲨无声吸口气：「你们刚才有看见谁进入我房间？」「有拉尔德罗说是楼下有状况。」对这问题异常迷茫：「老板您让他进去的…」话音刚落忽然想到别解释纷纷询问：「头儿老板里面有物品失窃？」表情下沉摇头：「不要走神！」哐当！缩回身体关房门留下几名守卫在那里你看我我看你怀疑头儿已经喝醉。房间内又高又胖汉密尔顿皱眉头来回踱起步。「拉尔德罗拉尔德罗他们看见是拉尔德罗…那个家伙那个家伙能变化成其他人样子？」身为帮海盗销赃并搜集情报合作者对海上各种传闻并不陌生最先想到据说能变成任何人前海盗将军齐林格斯。但是很快联想到更多：不一定是这种神奇能力如果真和流言里描述接近幻术暗示精神方面操纵都可以办到类似事情。嘶有个地方感觉不太对刚才那个家伙外表斯文内心疯狂实力恐怖怎么会为了潜入假装我下属并且称呼一声老板以他表现出来性格他应该打晕或杀死沿途见到所有人散步一样走到门口然后再非常有礼貌敲门！如果说是为了不制造大动静不留下太多信息不暴露自身序列相关秘密那他完全可用更隐蔽方式比如爬窗…很矛盾…这样矛盾只有一个解释他在伪装！伪装性格还是伪装强大？或者两种可能都有？想到这里突然顿住脚步将所有细节串起来：那个家伙是个新手！他的疯狂是伪装的！他的强大是依赖某件神奇物品表现出来的！对一定是这样！只有这样才能说明那些矛盾地方他不攀爬外墙从窗口进入是因为本身序列低且不擅长这方面事情神奇物品侧重也不在这领域…他为了顺利进入房间愿意低下脑袋称呼我老板是因为纯粹依靠神奇物品对本身没太大信心不够高傲和疯狂…他表现得像疯子是为了配合神奇物品让人产生恐惧效果制造压力询问消息。这也能非常完美解释他为什么就那样离开问题他之所以找上我是因为得到一件强大神奇物品野心膨胀想通过抓捕和猎杀一些海盗发财等知道我是在为银币毒蛇奥德尔和血之上将情报官老奎因服务且可能涉及神秘女王后就害怕了畏惧了稍做敷衍就选择离去不敢杀人！越想越觉得自己找到真相忙重新弄好电台翻出密码本补发一则情报将自己猜测简略描述一遍。他认为自己并没有被猎手盯上之前事情纯粹源于一个获得奇遇年轻人膨胀野心而对目标他也给出相应特征：「金发蓝眼并不疯狂甚至有些胆小。拥有一件相当神奇物品也许能变化长相和身材也许能制造幻觉结合恐怖感后者可能性更大总之无从知晓他真正样子。是个没什么经验新手擅长借助物品伪装出强大气势！对我有一定了解不像是第一次来达米尔港外乡人。」哒哒哒停下手指满意往后一靠压得椅子吱嘎作响。嘴角一点点翘起似乎已经看到刚才那个混蛋结局：「一个序列很低却拥有强力神奇物品家伙在海上不会有什么好下场多的是贪婪鲨鱼涌向他！到时候就不需要再担心我问题会暴露出来！」……夜色下港口颇为安静离开飞鱼与酒克绕向远处先快后慢逐渐进入散步状态。等确认没人跟踪后在途经阴暗地带时将脸孔变回格尔曼·斯帕罗将衬衣下摆扎进裤子里。理下鬓角抽出金边眼镜架鼻梁上外表斯文里透着些许冷峻。开始依靠星辰辨别方向往白玛瑙号停靠位置返回。走着走着低笑一声在寒风扑面中悠然想：「希望白鲨不是那么愚蠢能看得出来我留下那些破绽…」他为今晚拜访者做人设是经验不多会犯错误新晋冒险家而这个人对达米尔港和白鲨颇为了解身上带着一件引人垂涎神奇物品被强大力量弄晕脑袋内心显得有点疯狂。最初想法是海盗流窜于大洋之上即使海军也很难找到他们如果自己能从白鲨那里获得较为确切情报那当然可直接上门服务要是不行就以这身份这样子为诱饵将一些识货海盗吸引到预定地点完成初步狩猎。等发现白鲨能联络上血之上将情报官老奎因后计划随之完善那就是获得密码内容和频谱波段监听相应情况掌握目标动向并干扰占卜然后在最适当时机以强力神奇物品和弱小冒险家组合为诱饵钓几条大鱼。「现在问题是我没有用来做监听装置…海上基本买不到…得以世界身份请正义或者魔术师小姐在贝克帮忙采购一套用献祭方式发货…这就是塔罗会优势啊！」想到一阵感慨。眼见白玛瑙号在望稍微加快脚步发现堂娜一家和克里维斯等人从另一条街道返回。克里维斯以颔首方式和他打招呼于正式相遇时低沉开口：「我听说飞鱼和酒那里有人闹事？」消息很灵通嘛对达米尔港相当熟悉啊…勾勒嘴角平淡回答：「只是教训了两个骗子。」眉头微动忽然觉得自己对格尔曼·斯帕罗判断有些错误。经过之前观察和相处他认为这年轻冒险家虽然锋锐了点内敛了点冷了点但还算是个有笑容懂礼貌知进退人而现在有些把握不准了只觉对方内心深处也许藏有疯狂火焰。这时堂娜父亲插言问：「克里维斯先生这位是？」「一个同行格尔曼·斯帕罗。」非常简单介绍。礼貌微笑伸出右掌：「很荣幸遇见您以后如果需要雇佣人又找不到克里维斯他们可以考虑我。」「没问题希望你和他们一样强力和专业！」表面热情与克握手并自我介绍：「乌尔迪·布兰奇。」刚松手回退灵感突有触动只觉布兰奇家仆人们提着礼盒内有轻微异常。悄然开灵视发现礼盒内装是一条条腌肉但腌肉表面红很红白很白白黑很黑就仿佛来自灵界事物。有灵界气息但基本没危害…这腌肉很奇特啊…内心一阵诧异。注意到目光堂娜父亲笑一声：「这是达米尔港特产。这座岛屿中央有一座死火山周围几个地洞则存在缝隙有天然热风吹拂在那里晾制腌肉能获得美妙而独特风味它可以作为礼物送给朋友。斯帕罗先生如果你想买一点现在还来得及。」独特风味？灵界口感？大致明白怎么回事。根据神秘学理论灵界与现实完全重叠却又互不干涉必须依靠非凡力量才能打破间隔但这种情况并不绝对世界上存在一些灵界过强隐约影响现实地方。在这样区域里死者很容易变成水鬼僵尸等东西住宅内也有不小可能出现灵异事件。达米尔港地洞内部应该就有类似情况但并不严重未造成异常只是让腌肉染上独特风味…这种东西不一次吃很多没什么问题…微笑回应：「我对腌肉没什么兴趣。」直到这一刻才确认之前酒保给腌肉属普通品种并非特制。就这时小男孩丹顿指着半空月亮道：「好红啊！」「嗯！」堂娜点头附和。好红？抬头看一眼只觉今晚红月与往常没什么区别。因为小孩灵较为纯净吃了这种腌肉沾染灵界气息后具备短暂一定灵视能力？这岛屿上孩子们会不会也有类似情况？呵呵这也许就是达米尔港民俗传说源泉…审视一番找到答案。一行人散步回到船边沿着舷梯上甲板。与他们告辞往二等舱位置行去。突然心中一动再次开启灵视。看见那巨大白骨信使出现于面前将一封信丢下来。

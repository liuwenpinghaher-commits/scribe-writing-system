# 530 旅行家 第四十九章 经验派

## 打开书
有事情问船长？达尼兹皱着眉头目送格尔曼离开房间不知道对方真正抱着什么目的。「这家伙究竟在追求些什么？金钱财富？可他完全有时间有机会拿走钢铁和血色荆棘脑袋换成近万镑赏金额抽成下来也有个七八千镑却没有这么做而且还慷慨分了我战利品这很矛盾啊他听到我是烈焰时第一反应就指向了3000镑悬赏…按照船长说法这不科学…他为什么要故意放弃赏金呢？除非除非他有更好办法更安全地领到或者专门留给谁？嗯…他提前就防备了代罚者出现…他他有自己关系网和情报渠道！这样一来所有事情就得到解释了！加上可能存在杀掉齐林格斯那位半神嘶格尔曼背后有个隐秘强大组织啊！」被自己推测吓到本能想用肢体语言表达这种感受结果忘记左臂还在骨折中顿时痛得呲牙咧嘴。这让他愈发惶恐不想让船长和这么危险这么疯狂家伙见面。甚至怀疑格尔曼真正目的就是船长那26000镑赏金！单挑话那个疯子未必赢得了船长而且我们还有大副二副三副和几位水手长但是他背后有个实力恐怖组织！要想伤害船长除非从我尸体上跨过去！挺起胸膛昂起脖子充满自我牺牲悲壮感。抬手理下头发长长嗯一声自言自语：「再观察观察也许格尔曼真只是想询问些事情。」下意识环顾一圈发现飞毯和阴影斗篷都在没有缺失。「也就是说格尔曼将属于我东西都留下来他就不怕我趁机逃跑吗？或者说他偷偷拿了我头发便于占卜？不不他是个疯狂家伙即使要用头发也会直接走过来伸手拔一根不可能偷偷摸摸去做…对了他背后有个强大而隐秘组织！也许也许这个时候就有那个组织人员在暗中监控我等着我离开等着我去找船长…阴险！格尔曼肯定是故意出门！」觉得自己凭借经验和智慧把握住事情真相。来回踱几步重新坐到安乐椅上无声嘲笑：「我不走了！我要看看你们究竟想做什么！我不会把危险带给船长！」……下午3点过一刻西弥姆岛。这里同样属于罗思德群岛但距离慷慨之城拜亚姆最远需要近5个小时客轮才能抵达。途中采购一套本地特色服装并买了个小行李箱装换下来衣物总计花费14苏勒不到1镑。真便宜啊也就是正装零头…穿阔脚裤披咖啡色厚夹克戴浅棕色鸭舌帽顶着张毫无特色本地脸孔走下客轮进入西弥姆岛有些陈旧港口——花费时间购买服装变化形象错过9点渡轮只能坐10点这班。想到这次扮演开销忍不住又算遍自己目前财政状况：「无面人特性卖了3825镑海盗赏金3000镑这6825镑虽然还未拿到但只要倒吊人先生没暴露就基本可以纳入预算了…堂娜他们感谢金加本身剩下钱零零碎碎有255镑…钢铁身上搜出26镑11苏勒8便士…嗯还有5枚压舱金币…最近都没怎么花钱总计也就1镑出头样子这真是一件让人愉快事情…这么算下来我将有7110镑而且还多了梦魇非凡特性鱼人鳔价值都不算低。想一想这一笔我赚了3000镑赏金加活尸非凡特性后者3000到5000镑也就是说收入七八千镑…这还只是一个钢铁加血色荆棘和斯考尔并且浪费了不少…狩猎海盗真是份不错工作又能主持正义惩罚罪恶保护弱小又能一夜暴富…」下意识转头望向侧方只见这里海水颜色比拜亚姆那边清澈不少整体就仿佛一颗碧绿巨大晶莹宝石在阳光下映照出金灿灿辉芒。果然一代又一代冒险家出海寻找财富不是没有道理即使扣除掉古老怨灵残余灵性六翼石像鬼眼睛苏尼亚金色泉泉水等秘偶大师辅助材料开销剩下钱也能让我在这里在迪西海湾在南大陆殖民地在非大都市区域买一个还算不错庄园了…鲁恩乡村风光据说非常美丽如果最后真回不去可以考虑定居类似地方…嗯我还有10%贝克兰德脚踏车公司股份以后回报不会低…有了底气腰背挺直思考起未来。一阵漫无边际畅想后开始考虑更加现实问题那就是梦魇非凡特性是卖还是找机会归还黑夜教会或者通过工匠制作成神奇物品。看情况吧最理想方案就是卖给教会…顺走了值夜者两份魔药殉职者不太确定想着。同时希望小太阳尽快到序列7有资格接触去除非凡特性精神污染方法。至于释放手套内光之祭司事情并不着急小太阳刚拿到序列7魔药配方对后面暂时没什么需求得等很长一段时间而光之祭司能力用来对付血之上将那伙海盗非常有效比太阳胸针强不少。思绪慢慢沉淀进入港口小镇。这里基本都是本地人种皮肤近古铜黑发天然微卷身上散发着长期与香料打交道气味。变化容貌问清楚蕊妮情况以及是否有温特死讯传回后找了个僻静角落用手一抹脸庞将自己变成五官颇为深刻身材瘦瘦高高温特。提着行李箱绕至小镇靠近郊外地方看见蕊妮家酿酒房。亚麻色头发女孩已经不能称之为少女和温特记忆里相比明显成熟不少。她正在打扫门口周围没什么人经过。呼…深吸口气又缓缓吐出觉得内心充满为难情绪。作为键盘强者他知道方法派体验派等表演学说但缺乏更进一步了解只能自己尝试着揣摩这种场景下温特心情和该有表现。终于眼睛一闭走过去。蕊妮听见脚步声抬起头来看清楚访客。嘴巴微张发出半截惊讶啊声旋即板起脸孔道：「你怎么突然跑回来了？」记住你只是在表演…露出一抹笑容道：「我是来和你告别的。」用本地方言并带上几分不伦不类拜亚姆腔调。——罗思德群岛语言同样来源于古弗萨克语属于另外变种对身为半个历史学家并不困难稍微花费点时间就基本掌握。「告别？」略感诧异反问。侧过脑袋望向旁边笑了笑道：「我要去追逐一个宝藏不知道什么时候才能回来。到时候我会带着大笔金钱出现买下郊外庄园种植些橡胶树弄一个葡萄园有自己磨坊酒窖铁匠铺让空气里弥漫各种各样香料味道然后买几个奴隶请一些佣人就像那些老爷一样呵呵还差一样。」战胜即将冒出鸡皮疙瘩转头看着蕊妮眼睛：「还差一个妻子还差庄园女主人。蕊妮我喜欢你我想娶你我今天说出来不是为了获得答案是害怕再没有机会告诉你。」蕊妮静静听完突然愤怒骂道：「温特你是个懦夫！」啊…这反应有点不对啊…故意露出惊讶表情。蕊妮压抑着嗓音道：「三年前三年前我已经准备好和你一起去拜亚姆结果结果你什么都没说！你这个懦夫！你这个胆小鬼！你现在告诉我又有什么用？你马上要出海了也许再也回不来！」越说越是激动：「你说出口自己是开心了没有遗憾了可我怎么办？一直想着你会回来一直痛苦下去？你这个自私鬼！」挥起手中扫帚猛地打向对面温特。知道真正温特这个时候会打掉扫帚抱住女孩告诉她自己不再出海但他却办不到只能假装狼狈被赶走一路跑到附近巷子内用脑袋轻磕起墙壁无声自骂：「太他妈尴尬了！太他妈尴尬了…」蕊妮回到门口拿着扫帚蹲下来。脸色灰沉不知在想些什么。隐隐约约之间听见一道声音接着整个人就沉睡过去。使用完符咒转出来推了下靠着墙壁坐至地面蕊妮然后快速离开这里躲到远处偷窥结局。蕊妮很快醒转发现自己不知什么时候睡过去刚才一切都仿佛梦境。依旧坐在那里许久未动。忽然埋下脑袋发出一声似乎从喉咙深处挤出尖尖细细低骂：「温特你这个自私鬼！」唉有了点消化感觉叹口气变化容貌离开这里。还得在西弥姆岛住一夜因为上午才有去拜亚姆客轮。

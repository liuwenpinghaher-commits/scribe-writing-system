# 1214 逐光者 第六十五章 时间未到

## 打开书
福生玄黄天尊。听清楚灰白雾气深处那些声音时候克莱恩微微一颤后脑瞬间发麻。这种感觉飞快往他头顶往身体各个部位扩散让他皮肤表面凸起一个又一个细小疙瘩。这是他第二次在现实世界从别人口中听到福生玄黄天尊这个名称而第一次是阿蒙通过窃取他念头说出来实际上并不清楚具体含义也没真正掌握这句咒文。所以从本质上来说现在才是第一次。在传说中西大陆边缘在那消失不见故乡外面克莱恩第一次在现实世界听见导致自己穿越咒文听见隐藏在自己心底最重要秘密之一听见那不知究竟指向哪位存在东方式尊名。他站在那里脑海近乎一片空白耳畔回荡是时而模糊时而清晰诵念声呼喊声：福生玄黄天尊……福生玄黄天尊……福生玄黄天尊……等到这些声音越来越低近乎消失克莱恩终于找回思绪。作为一个做不少亏心事伪神他第一反应是：我把福生玄黄天尊改成执掌好运黄黑之王会不会遭天谴？当初他设定愚者三段式尊名时第一段描述是自身经历和状态那时候以为是穿越害怕暴露问题将来自异世界愚者改成不属于这个时代愚者结果反而道出本质第二段则是将灰雾将源堡绑定在自己身上让指向更加明确。而为完全限定不产生歧义克莱恩在第三段尊名处直接意译咒文最后一句也就是福生玄黄天尊。他原本认为这没什么后来怀疑导致自己穿越源堡之内那扇奇异光门前主人就是福生玄黄天尊或者说披着东方式马甲某位存在当然也可能福生玄黄天尊才是本体之后穿一件更符合当前世界外衣至于是哪件克莱恩目前也猜不出来。因为从未在现实世界在自己之外听到福生玄黄天尊这个尊名所以克莱恩怀疑归怀疑忌惮归忌惮畏惧归畏惧实际并没有太在意这件事情似乎已经习惯。但是此时此刻那一声声福生玄黄天尊就像一门门舰炮不断地轰在他心上轰在他脑海内让他潜意识中积攒担心和恐惧奔涌而出。定定神克莱恩开始强迫自己用理智来思考当前情况：这一声声诵念是蕴藏在灰白雾气里还是来自消失西大陆？我就说这片雾气色泽和状态都很接近源堡下方那些……它力量也源自历史？必须有时光领域正确力量才能打开？天灾女王高希纳姆说过末日来临时西大陆肯定会重现……也就是说只有时间推进到那个节点这片灰白雾气才会活过来才有可能凭借相应咒文打开？让西大陆消失或者将它封印或者做保护性隔离是那位福生玄黄天尊疑似源堡前主人存在？按照各方面说法源堡等九件事物是最初那位造物主留下是祂身体不同部位或祂亲手制造东西……福生玄黄天尊约等于源堡前主人约等于最初那位造物主？可源堡是最初造物主分裂后才有而且福生玄黄天尊这些咒文只能指向源堡没法影响混沌海等地方……还有西大陆消失绝对是第二纪之前事情身为古神精灵王苏尼亚索列姆都没法返回故乡……也就是说在混乱疯狂第一纪甚至第一纪之前在最初造物主分裂出混沌海源堡等事物后古神诞生前还发生一些事情？这些事情导致西大陆消失源堡前主人不见？远古太阳神白银城造物主预言也很有意思说是这片灰白雾气内会有人走出所以派人进驻月城守在这里而严格来讲我其实就是从西大陆从这片灰白雾气内出来只不过我离开西大陆是进入源堡在远古太阳神预言之前很久很久我离开灰白雾气则是在1349年在鲁恩……嗯兜兜转转我又来到这里和月城人碰上了……远古太阳神预言还真实现了只是过程有些曲折实现方式让人意想不到……克莱恩思考之中心情逐渐变好一点因为现场状况和他灵性直觉告诉他被灰白雾气隔绝西大陆还有文明还有不少人活着。这种让西大陆消失方式让我想到奇迹师仪式并兼有时空力量它们主要在学徒途径和偷盗者途径……所以源堡前主人福生玄黄天尊对应真是这三条相近途径？克莱恩收敛住发散念头向前走两步。他旋即转身对月城大祭司尼姆等人：我听清楚那些声音。它们在说什么？尼姆灰白眼眸骤然睁大布满沟壑脸上露出无法遏制激动。阿达尔辛和鲁斯等人也有类似反应甚至更为激烈。他们就连身体都出现明显颤抖。这是一个困扰月城居民一千多年问题解开这个疑难在他们心中已经变成摆脱当前处境象征！克莱恩悄然吸口气用神棍式口吻：他们在向我主祈祷。这绝对不是谎言毕竟他这个愚者已初步掌握源堡尊名最后一句是执掌好运黄黑之王约等于福生玄黄天尊。尼姆等人沉默下来再望向克莱恩时眼神里已多明显尊敬和畏惧。结合对方展现神迹他们逐渐将那位愚者先生视为救世主。克莱恩环顾一圈平淡开口：你们退后至少百米。好的斯帕罗阁下。大祭司尼姆没有犹豫就答应下来。等到月城非凡者们退出足够距离克莱恩右手探入虚空快速拖出一个自己本体随之消失不见。紧接着克莱恩历史孔隙影像走至那片凝固灰白雾气前方伸出右手按上去。那里仿佛有一道无形屏障带着些许冰凉阻隔着一切。凝望两秒克莱恩张开嘴巴压着嗓音用中文诵念：福生玄黄天尊。声音回荡中他眼前灰白雾气没有一点反应依旧静止依旧凝固。他等待近一分钟想想吸口气再次低念：福生玄黄仙尊；福生玄黄天君；福生玄黄上帝；福生玄黄天尊。这是那个转运仪式完整咒文。随着最后一个字落下克莱恩按在无形屏障上右手突然感觉到明显震颤。灰雾晃动起来就像被扔进一块巨石湖泊。那些涟漪飞快传导着彼此重合着隐约间要在克莱恩面前勾勒出一扇门。高空一道闪电划过照亮这幅画面看得不远处月城非凡者们瞳孔放大移不开眼睛。这里面之前未曾目睹类似场景后来者们更是心神摇动难以克制。在他们看来这就是毫无疑问神迹！克莱恩屏住呼吸等待那扇门成形可是那些涟漪最终还是平复下去距离成功只差一步。……沉默一阵后克莱恩又重新诵念咒文不断诵念可灰白雾气内荡起涟漪即使没有消失也无法真正勾勒出那扇门。有那么个瞬间他想附加完整仪式流程来做尝试也就是说摆放四份食物于逆走四步中诵念咒文但很快他就被自己这个想法给蠢笑。因为这么一套做下来他会刷地一下进入源堡而不是打开这里无形屏障。呼口气克莱恩从虚空里抓出一枚金币用占卜方法确认完整仪式效果和自己想一样。真的是时间未到末日还未来临？克莱恩目视着前方灰白雾气好几分钟没有一点动静。当一道闪电划破天际照亮他脸庞他才转过身体提着那盏马灯走到月城大祭司尼姆面前嗓音平缓开口：还没到神谕里打开它正确时间还有十几年。不等尼姆阿达尔等人回应克莱恩用空着右手指指附近黑暗：我将在这里苦修一段时间你们如果想感受主光辉聆听祂教诲在闪电频繁阶段随时可以过来。我每天会做一次净化和治疗在闪电最频繁时候。他没试图让月城居民转信也没打算直接前往那座城邦或询问具体情报给他们留足缓冲余地。月城大祭司尼姆悄然松口气愈发尊敬回应：我将把您话语转告所有人。

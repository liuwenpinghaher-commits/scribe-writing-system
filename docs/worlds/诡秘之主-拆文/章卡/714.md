# 714 旅行家 第二百三十三章 晚年疯狂

## 打开书
我早就从那个最古老的组织拿到了知识皇帝的魔药配方，现在是时候寻求相应的材料了，它也许已经属于一位天使，也许与周围事物结合变成扭曲邪恶的怪物或混乱恐怖的0级封印物，必须足够小心，最好能找到合适的帮手。知识皇帝，这序列1魔药的名称真的有趣，如果不是直接看了亵渎石块，我会以为它属于阅读者途径，属于知识与智慧之神教会，更为奇怪的是，这两条途径并没有互换的关系。我曾经和那位神秘的首领以及赫密斯老先生讨论过，基本达成共识：阅读者途径代表全知全能里的全知，而窥秘人、通识者对应的是知识本身，分属两个方面，一个更偏神秘，一个更接近现实。呵，等我成为知识皇帝，贝尔纳黛就更不用担心隐匿贤者的灌输了，也不用害怕知识的追逐。大帝最后是转向窥秘人途径啊，不知道他有没有顺利成为知识皇帝……或许正是因为这件事情，他才和蒸汽教会彻底决裂，以至于后来举世皆敌找不到帮手，竟寄希望于黄昏隐士会。克莱恩半是感慨半是揣测。他对大帝解释阅读者无法和窥秘人、通识者互换的观点相当感兴趣，认为再深化下去或许就能找到非凡途径互换的规律和原理。在一般非凡者看来，阅读者、窥秘人、通识者都属于知识领域，彼此间应该有很强关联，结果前面是个异端。阅读者属于全知全能里的全知，那秘祈人、也就是牧羊人途径，是全知全能里的全能？然后两者又存在一定交叉，因博学而多能、因多能而博学，所以可以互换。从这个角度出发，风暴途径海陆空全能就可以理解，观众对应的心灵领域则是对风暴的有力补充。那么太阳为什么可以和它们互换？考虑到上一个有全知全能称号的是远古太阳神，是否意味着太阳是容纳全知全能的基石？根据这样的思路，窥秘人和通识者是知识本身的不同方面所以能互换，那么刺客和猎人又是什么的分化？黑夜、死神和战神途径呢？一下想了很多，既没有时间也缺乏足够信息去深入分析，只能暂时抛诸脑后，用意念把第三页日记弄到上方。一眼扫去精神突然集中：这篇和以往大不相同。没有日期，字间距很大，因为是原版，还可以明显看出落笔的重量超乎寻常！不！不可能！怎么会这样！如果我的猜测没有错，当初有那样遭遇的应该不止我一个！不！不！怎么会这样！我看见的东西在告诉我，所有的所有都将毁灭，我缔造的一切同样如此！不！我不接受这样的结局！必须努力自救，不再寄幻想于七神！只有登上序列0的宝座，我自己和我所重视的那些，才能保存！我是不是要尝试将门先生拉回现实世界？不！祂虽然自称只有序列1，但我认为祂绝不是普通的序列1！很大可能给我带来意料之外的灾难！比前面两页大了不少的汉字以稀疏凌乱的姿态占满泛黄纸张，实际内容不多，却看得克莱恩脑袋一阵一阵抽痛。写这篇的时候，罗塞尔大帝很可能已经是序列1的知识皇帝，带着激烈情绪书写的内容有着强大的神秘色彩——如果在现实世界阅读，很可能会精神失常，当场疯掉，甚至失控。还好隐者女士不懂中文，否则她之前强行记忆内容的时候已经变异……就算不懂，她应该也会觉得特别累、消耗特别大……如果长久接触、长久注视，幻听与幻觉不可避免，并大概率会出现失控的征兆。克莱恩略感庆幸。注意力转回日记：大帝究竟看到了什么，让他情绪如此激烈、态度也偏激了不少？不，字里行间的激荡感和冲动感有点不太正常，不符合一位久居高位者的人物形象，更不符合一位天使的位格，即使最后那段日子说出我死后哪管洪水滔天的时候，他也没有这样失态、这样激动。他被谁影响了？或者被什么事物污染或侵蚀了？还有，他提到有那样遭遇的应该不止他一个，是指什么事情？穿越吗？当初在地球之上因莫名其妙的事和物穿越的，确实不止他一个，还有我……甚至更多？一个个想法电闪而过，没浪费时间，让三页日记消失，含笑望向隐者嘉德丽雅：想好请求了吗？嘉德丽雅早有准备般行了一礼：我想知道罗塞尔大帝晚年为何疯狂。同一排的正义奥黛丽眨了下眼睛，怀疑自己听错了，完全没想到隐者女士一开口就是这么重磅的问题。而且她怎么知道罗塞尔大帝晚年疯狂了？她只提交了三页日记，就问这种层次的问题，不符合等价交换的规律呀！内心涌现各种想法，却没有阻止，反倒很感兴趣并莫名激动地等着愚者回应。倒吊人阿尔杰、月亮埃姆林、魔术师佛尔思同样屏住呼吸，将目光投向青铜长桌最上首，只有太阳戴里克和世界对此不太在意。愚者想了想，轻笑一声：首先，我们确定一个事实。我并非全知，也不全能。自嘲般的轻松口吻，隐者等人却没有一点异常，甚至更恭敬了一点。对他们来说，愚者不全知也不全能是显而易见的事情，即使不提各自对愚者状态的揣测，仅是这位隐秘存在尊名上没有类似描述的现实，也足以说明。而且，目前所有的真神、邪神都没有全知全能类型的尊名！不着痕迹铺垫好基调后：我也想知道罗塞尔晚年遭遇了什么。目前可以肯定的是，因某些未知缘由的刺激或影响，罗塞尔将目光投向了序列0。没去解释序列0对应什么，塔罗会里知道的比不知道的多，不知道的也能隐约猜到一点。序列0……大帝想要成神？难怪说他晚年疯狂了……正义知晓序列0代表什么，一时颇为感慨，倒吊人同样如此。隐者显然也明白，若有所思表示感谢，收回目光。月亮和魔术师各自咀嚼这两个单词，似乎这才知道序列1之上还有一个位阶，而这属于真神。太阳则懵懂看着愚者，不明白那个存在感很强的罗塞尔大帝试图冲击序列0有什么问题——在白银城内，如果有机会，每一个居民都想成为序列0的真神，以便为大家创造一个更适合生存的环境，或者引领所有人离开那片被遗弃的土地。克莱恩没再多说，后靠椅背，环顾一圈：你们开始吧。随即操纵世界望向太阳戴里克，低沉笑道：你要的公证人魔药配方有了。谢谢您，世界先生，按照约定，我会记下这笔欠债，等待您提出要求。好。装模作样向愚者提出具现请求。没用多久，配方来到小太阳手中。戴里克欣喜接过，如饥似渴浏览羊皮纸：序列6，公证人。主材料：长者之树的根茎结晶1份，契灵鸟的尾羽5根。辅助材料：光辉契灵树的汁液100毫升，金边太阳花一朵，白边太阳花一朵，水蕨汁液5滴。没等其他人说话，世界看着倒吊人阿尔杰又一次开口：你知道的，你要的海洋歌者魔药配方和主材料有了。啊？正义等人一时都有点傻眼。隐者更是难掩惊讶望向世界，她记得很清楚，格尔曼·斯帕罗上周才狩猎屠杀者吉尔希艾斯，这又是从哪里弄来的海洋歌者魔药配方和主材料？他不会又杀了位海洋歌者吧？这在风暴教会内都算得上准高层了……这才一周啊！嘉德丽雅觉得这一点也不现实。

## 这一章新讲明的规矩
- 知识皇帝是窥秘人序列1，不属阅读者，两条途径不能互换；阅读者是全知全能里的全知，窥秘人与通识者是知识本身的两面。
- 克莱恩由此猜测牧羊人是全能、太阳或是全知全能的基石——本章是他的推想，未写到证实。
- 无日期那页在现实读可能疯掉失控；不懂中文强记也会累，长久注视可能幻听幻觉。
- 真神邪神尊名目前都没有全知全能类型；愚者先声明并非全知也不全能。
- 序列0在会里：有人知是成神，有人刚知道序列1之上还有位阶，白银城居民不觉得冲击序列0有问题。
- 公证人序列6配方材料当场列出。海洋歌者配方和主材料「有了」，来源本章未写到。

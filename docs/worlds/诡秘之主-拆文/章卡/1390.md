# 1390 倒吊人 第三十八章 去面对

## 打开书
狂暴海那似乎永远也不会停息深蓝波涛中未来号就如同一片树叶时而被抛高时而被拍落。在这片海域内还有一些海盗船只在航行对类似情况已经习惯到感觉它和太阳升起一样自然。星之上将嘉德丽雅返回现实后只沉思片刻就摊开纸张提笔写信。她想问一下女王最近有什么大事发生。其实在愚者先生宣布祂将进入沉眠前嘉德丽雅就已经嗅到巨变来临。无论是门窗突然紧闭还是流星群划过高空照亮世界都让身为预言大师她产生一定灵感看到一些模糊画面。当然限于本身层次位格和身份她对具体发生什么没有足够了解难以把握到究竟是什么事情促使愚者先生选择沉眠只好向早晋升天使领导着一个神秘组织掌控着多件强大封印物神秘女王贝尔纳黛询问。……她感觉到愚者先生进入沉眠。难以遏制彷徨迷茫和一点悲伤在这位星之上将心中涌现出来。……她似乎明白什么又什么都不明白只知道愚者先生这次沉眠不知要多久才能醒来。……弗兰克·李正热情请船员们品尝他新酿造啤酒但没有一个海盗敢于尝试。还好提前将夏尔夫送到女王那里现在只需要看住弗兰克……没有愚者先生注视我必须更加谨慎更加重视嗯得给弗兰克找些研究之外事情做他是大副不能总是不做本职工作……星之上将嘉德丽雅表情略显凝重想道。考虑好怎么看住弗兰克以及如何把属于大地和月亮途径少量海盗安排到别船只上不经常和弗兰克接触后嘉德丽雅将思考重心转移到隐匿贤者这件事情上。虽然她已是摩斯苦修会十支柱之一但因为出身来历和受隐匿贤者影响较少问题一直不怎么受到会长和其余高层信任属于游离于组织边缘自有一个圈子自有相应势力被排挤者。……而想弄到隐匿贤者这位象征性神灵突然活过来资料确认祂现在状态必须成为摩斯苦修会核心人员。以我现在身份参与摩斯苦修会内部事务决策是完全没有问题。只有真正参与这些才能接触到更多资料提高本身地位……不过这会相当危险……而确认隐匿贤者当前状态会更加危险稍有不对立刻就会被祂侵蚀和污染……星之上将嘉德丽雅越想越觉得愚者先生给任务困难。她一直游离于摩斯苦修会边缘以海盗身份活跃其实也有着这方面担心害怕太过深入掺和组织内部事情会暴露出自己还在与神秘女王联系事实害怕突然有一天就被其余十支柱同时指认为间谍当场清除。这一刻嘉德丽雅甚至想放弃愚者先生任务和摩斯苦修会十支柱身份回到黎明号上回到女王身边。……自从离开黎明号什么事情都需要自己来承担后星之上将嘉德丽雅一直都有种疲惫感肩头始终沉甸甸。……那就去面对吧。……做出这个决定后星之上将嘉德丽雅不再遮掩自身实力抬起双手使用一个童话魔法。在周围航行海盗船成员眼里未来号和它附属船只们同时变得虚幻化成数不清气泡。……未来号和它附属舰队就这样消失在众人眼里。……大海之上新王者诞生了。星之女王！……你那个任务太危险了！……你没有敲门。这就是和一位学徒途径半神住在一起最不好一点。……你没有关门。……涉及序列1和唯一性任务真的太危险了。说完这句想到休已经接受愚者先生馈赠她眼眶就不可遏制微红起来忍不住嘟囔两句：记得请我帮忙。至少至少能带着你逃掉。于她们而言之前经历过涉及序列1层面事情非常少除愚者先生世界格尔曼·斯帕罗相关也就可能被某位不可直说姓名存在注视过。其余时候她们最多也就是在相应事件边缘做一些很微小工作从未直面过能被称为祂敌人。……只是寻找线索调查真相又不需要直面祂们。……末日将近总得做点什么。你看连愚者先生都要陷入沉眠何况我们这种小人物？如果不能尽快成为半神也许连想做点什么都没有办法现在现在至少还有一定希望至少还可以尝试唤醒愚者先生。……你接下来怎么做？仅靠我自己调查肯定很难必然得借助军情九处情报网络。我打算找个合适机会让他们知道我已经成为序列4半神。为了不被怀疑这也许需要正义小姐给一些暗示做一些安排。休认真回答道。……我给你编一个剧本呃我来扮演反派模拟一个试图晋升序列4律令法师疯子然后被你击败……等编好故事再让正义小姐做些修改让它显得足够合理。佛尔思边写边道。作为一名秘法师她毫无疑问能够让两人谈话不外泄。……你现在最重要任务不是写传记和故事吗？哈那个简单我早就在脑海内想过太多情节有很多素材不没有……佛尔思咕哝两句后全身心都放在给休编写剧本获得军情九处承认上。……虽然去面对军情九处高层会有什么结果未知虽然完成愚者先生任务会遇到什么危险也未知虽然末日来临会是怎样同样未知但休知道如果自己什么都不去做不承担一定程度风险就这样享受家庭美好那最终将像大多数没准备人面对洪水一样扑腾两下就被彻底淹没…

# 1245 逐光者 第九十六章 遵从心的意愿

## 打开书
正在猛烈攻击蕾妮特·缇尼科尔乌黯魔狼似有所觉动作放慢一拍扭头望向刚出现那个怨魂。祂那本就占据眼睛三分之二空间瞳孔猛然放大似乎嗅到某种熟悉又危险气息。转瞬之间那怨魂抬起双臂。周围区域愿望之力消退速度突然加快神性开始回归达到序列4层次而乌黯魔狼脚下泥土内探出一只又一只既苍白又虚幻手臂它们密密麻麻如同森林向上抓住科塔尔八条腿让这位奇迹师陷入死寂冰冷感觉里短暂无法挣脱。利用这个机会因灵体之线被操纵略显呆滞蕾妮特·缇尼科尔身体虚化消失在原地。乌黯魔狼漆黑瞳孔内这位信使小姐披着金色长发穿着阴沉繁复长裙缠绕邪异藤蔓身影骤然凸显完成附身。科塔尔这位愿望之神动作顿时变得僵硬就像从生物退化成傀儡。祂试图影响蕾妮特·缇尼科尔灵体之线以此对抗怨魂附身但时不时被另外那个女性怨魂制造出来苍白冰冷手臂打断难以成功。克莱恩见状一边维持着灵体之线环绕成圈一边颇有点缓慢抬起星之杖让它对准那块化身为斗篷黑色天鹅绒幕布。他脑海内随之构建出一幕场景。四周黑暗陡然流淌起来仿佛蕴藏着难以想象秘密一点点虚幻烛火在这样环境下亮起照出一张摆放着血肉长桌。长桌两侧三道极为模糊人影拿着血肉饥渴吞食着。下一秒这三道人影同时转头将目光投向那块半透明黑色天鹅绒幕布。幕布散发出疯狂吸力戛然而止以斗篷形态悬停于原地似乎一时忘记自己是谁属于哪边该做什么。背叛之宴！童话魔法之背叛之宴！克莱恩刚刚使用正是来自隐者嘉德丽雅童话魔法叫做背叛之宴作用是短暂唤醒目标手中物品或者赋予它们灵智让它们做出背叛举动！这是属于序列4层次非凡能力所以先前在愿望之力压制下无法用出。同时由于星之杖复现法术与原本还是有不小差距且那块幕布对乌黯魔狼恶意不重因此它只是出现迷茫没针对主人展开疯狂袭击。而克莱恩一摆脱这块幕布影响后立刻打个响指让赤红火焰淹没自己。刹那之后他戴半高丝绸礼帽穿黑色长款风衣身影浮现在乌黯魔狼旁边一丛火苗内。那赤红火苗往上蹿升化作一道焰流让克莱恩轻松跃出来。他随即微弯腰背提着星之杖狂奔向那头小山般巨大魔狼。蹬蹬蹬！克莱恩越跑越快仿佛化成一道狂风而迎接他是乌黯魔狼勉强抬起挣脱束缚两只前爪。啪！啪！克莱恩左右各挥一下黑色手杖准确命中科塔尔两只前爪让它们出现短暂停顿。与此同时他身体一矮越过这两只前爪以滑翔姿态来到乌黯魔狼身下空间。呜风声里克莱恩半空扭身往上戳出星之杖。噗一声那镶嵌着多种宝石黑色手杖刺破幽暗短毛覆盖皮肤深深贯入乌黯魔狼体内并强行拖出一道夸张伤口。哗啦！深黑泛红血液如决堤洪水般奔涌而出带着属于神话生物强烈侵蚀感喷向克莱恩。但这时克莱恩已后仰着飞出乌黯魔狼身下空间预备展开第二波攻击。突然他听见一声断断续续吼叫。这来自被怨魂附身行动艰难乌黯魔狼科塔尔包含意思是：列……奥……德……罗！……克莱恩目光一下就凝固脑海内似乎浮现出乌黯魔狼充满嘲讽笑意脸庞。那些残余神力并不是只有他一个人能够引动他可以乌黯魔狼科塔尔同样可以！就算这位奇迹师之前并不知道风天使列奥德罗已成为风暴之主但有克莱恩刚才示范他自然知道该怎么做。简单模仿谁不会？轰隆！轰隆！轰隆！那一道道银白灿亮闪电如同水管中喷薄出激流彼此并排互相重叠浇注在那座古老城堡废墟上将所有身影彻底淹没。克莱恩来不及做出别反应在听到前半个单词后已是利用小丑能力强行扭转身体右脚一蹬回到乌黯魔狼身下蕾妮特·缇尼科尔则跳跃到他衣兜内金币上。紧接着克莱恩半跪下来将星之杖插入地面。轰隆！轰隆！轰隆！浩浩荡荡雷霆风暴撕裂途中遇上一切。等到这煊赫恐怖闪电森林消散那座属于乌黯魔狼古老城堡连废墟都算不上它原本痕迹没一点残留只剩下焦黑深坑。深坑内一个个纸人被吹起化成灰烬。无声无息间一片闪烁着彩色玻璃光芒泥土软化克莱恩有着焦痕手掌探出来。在乌黯魔狼承受大部分伤害情况下他利用纸人替身和地底潜行勉强活下来只是依稀能闻到自己身上有烤肉香味散逸。回到地面后衣物破烂克莱恩目光一转将战场内情况完全收入眼底：乌黯魔狼残骸散落得到处都是血肉全焦毫无生气；那块幕布蜷缩成一团掉在深坑边缘一动不动；愿望力量被彻底清空神性完全回归这片区域；与人造死神建立有联系那个怨魂已被毁灭……换做别非凡者这一刻或许只会认为乌黯魔狼最后选择大家一起死方式但作为占卜家途径半神提前享受过奇迹师待遇克莱恩心中闪过却是另外想法：什么是奇迹？死而复生就是奇迹！乌黯魔狼见势不对毫不犹豫引动神罚试图让大家一起死去然后祂可以于附近某个地方复活！我差点就用掉最后那次复活……对于这方面事情克莱恩是有一定预案立刻就要使用一块铭刻有愚者花纹符咒用它代替自己在信使小姐面前向愚者先生祈祷接着再借助源堡未消去召唤仅凭一个念头就进入灰雾之上依靠祈祷光点自带真实视野审查周围寻找复活乌黯魔狼。这时蕾妮特·缇尼科尔离开克莱恩衣兜内金币出现在那块蜷缩起来幕布旁声音略显飘忽：它有一份奇迹师非凡特性。奇迹师非凡特性？也是乌黯魔狼拥有是诡秘侍者满额情况下六份奇迹师特性之一正常而言剩余那份诡秘侍者非凡特性也会对应一份奇迹师非凡特性……信使小姐说话同时克莱恩灵性直觉也有感应确认对方判断并联想到当初命运之蛇威尔·昂赛汀回答。奇迹师非凡特性总共应该是有九份但在诡秘侍者满额情况下三位序列1肯定会分别占有一份序列2剩余就只有六份奇迹师特性它们分别属于查拉图安提哥努斯许愿神灯永不落幕剧场最后盛宴和乌黯魔狼。克莱恩原本希望获取是乌黯魔狼这份但没想到那块幕布不仅有一份序列1诡秘侍者特性还有一份序列2奇迹师特性也就是当初失踪那份。看来失踪原因也是被灰雾给吞后来才吐出……还要寻找复活乌黯魔狼吗？不真实造物主和阿蒙不知什么时候就会降临而且我准备已消耗大半乌黯魔狼则依旧在完好状态能许愿能召唤能创造奇迹……反正目的已经达到……思绪电转间克莱恩抬起脑袋对信使小姐：我来收起这块幕布。他放弃追赶乌黯魔狼想法打算趁那块幕布处在虚弱状态将它控制住。蕾妮特·缇尼科尔轻轻颔首脑袋一转将目光投向乌黯魔狼焦黑残骸。那些残骸顿时腾起微光或变成白兔或化身为山羊都是肉香浓郁那种。……附近一个隐秘地方乌黯魔狼科塔尔覆盖幽暗短毛身体飞快凝聚成形。祂直接放弃原本尸体当即自我许愿自我回应转移到遥远某个地方然后头也不回狂奔而去。这位愿望之神根本没去考虑那块幕布丢失祂不选择原地复活就是希望用那块幕布拖住那和黑夜有密切关系家伙为自己逃生争取更宽裕时间。能从第二纪存活到现在科塔尔靠是遵从心意愿不该贪婪时绝不贪婪。光芒闪烁间这额头长着灰白毛发魔狼消失在黑暗深处。……克莱恩没去阻止信使小姐泄愤一边靠近那块幕布一边在心里感叹：一位天使真难杀占卜家途径尤其如此！念头转动间克莱恩正要拖出过去自己让他拿起那块幕布突然感觉到有某种熟悉气息降临。这气息阴暗污秽充满堕落意味让克莱恩一下就联想到真实造物主！那块幕布猛地浮起再次变成一个斗篷。斗篷内深沉黑暗化为漩涡发出嗡嗡声音：诡秘。

## 这场戏有没有翻
翻了。开头女神道抓腿附身成；背叛之宴迷幕、刺腹见血；魔狼学喊列奥德罗同归于尽式神罚；克莱恩识死而复生弃追收幕——章末真实造物主气息幕呼诡秘。翻的是杀机翻成弃杀保财＋更大阴影降临，不是烤肉香味。

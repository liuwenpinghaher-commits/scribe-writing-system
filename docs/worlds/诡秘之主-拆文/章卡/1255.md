# 1255 逐光者 第一百零六章 我有你没有

## 打开书
那片幽深海洋一下吞没煊赫光球让整个无暗之域都黑沉不少。它内部旋即迸发出一道又一道银白闪电将恩尤尼和科林激战区域变成雷霆森林。嗞嗞嗞声音里科林身上银色盔甲表面数不清电蛇乱窜往上奔腾钻入面甲空隙处。这位展现本身不完整神话生物形态银骑士顿时出现僵直似乎被电光弄得有点麻痹而恩尤尼那身仿佛由堕落力量组成黑色盔甲完全吸收雷霆通过自己四分五裂避免本体受到影响。抓住这个机会漆黑碎片不断掉落恩尤尼双手握住那把幽沉巨剑往斜前方斩出去而这个时候科林还未完全摆脱麻痹状态。刺的一声他左肩位置出现一道深深裂缝那坚固银色盔甲仿佛失去防御力被幽沉笔直巨剑直接劈开来。这是黑骑士灵肉之刃它不仅能腐蚀血肉泯灭灵魂斩破屏障还可以让任何有堕落意念生物防御失效属于黑骑士最核心非凡能力源于堕落领域。眼见灵肉之刃斩开科林左肩银色盔甲让裂缝飞快变深直奔心脏部位戴里克精神一紧当即凝聚出一柄似乎由纯粹阳光组成噼里啪啦作响长枪并挥动手臂将它投向恩尤尼。无暗之枪！恩尤尼没放弃攻击也未做出闪避只是扬起残余虚黑羽翼用它们覆盖住自己。滋！那柄无暗之枪穿透两层虚黑羽翼爆发出炽白到极点光芒让那里仿佛升起一轮微缩太阳。依靠着水银化科林用一条手臂为代价躲过恩尤尼致命一击。另外一边戴里克飞快凝聚着无暗之枪让一柄柄光之长矛噼里啪啦飞向恩尤尼。神说净化有效。这是公证人非凡能力在无暗者阶段表现。它与太阳圣者弄出无暗之域是那样契合以至于战场又明亮不少让恩尤尼和洛薇雅身上堕落气息再次衰减。神说无效！那位太阳圣者当即否定戴里克话语使无暗之域本身净化效果回归之前那种状态。眼见一柄柄灿烂纯净光芒长枪接连而来自身则被科林纠缠难以做出有效闪避恩尤尼又让一对虚黑羽翼完全展开崩解成一片幽黑。那一柄柄无暗之枪刚一接触这片幽黑就沾染上一层黏稠漆黑或瞬间腐蚀断裂贯入恢弘阶梯之内或于半空划了个弧形掉头奔向戴里克。……另外一边克莱恩和自己影子打得异常激烈砰砰砰空气炮弹声里一丛丛赤红火焰相继腾起一片片碎纸四散飞落一道道幻影化成泡沫。那个银骑士秘偶则基本压制观众圣者毕竟心灵巨龙再是肉身强悍力量奇大在近身战斗里也不会是巨人途径半神对手。观众圣者只能利用催眠师战斗催眠强行让目标作出反常举动借此摆脱纠缠重新进入心理学隐身。当然观众圣者战斗催眠对象肯定不是银骑士秘偶因为这本质上是一个死人免疫所有心智影响他干扰目标是克莱恩借助灵体之线传递过来意念。……这个观众圣者没尝试修改克莱恩心灵岛屿内意识只是捏出一团往外滋长触须幽暗光球让它化作一枚难以发现种子落向地面。精神瘟疫源种！克莱恩没有犹豫立刻和银骑士秘偶互换位置让精神瘟疫种子无法在他心灵岛屿内落地生根。观众圣者察觉这个变化不仅没有失望反倒露出一抹微笑。因为他早就借助虚拟人格暗中在银骑士秘偶死寂意识岛屿内埋下精神瘟疫种子这虽然无法影响到秘偶但可以不知不觉污染与秘偶互换位置敌人以及周围区域其他目标。这是一种针对意识岛屿精神世界侵蚀和感染不是直接攻击难以靠虚拟人格来抵消。到时候克莱恩靠虚拟人格短暂隐藏起来问题将彻底爆发迅速进入失控通道再也无法逆转！那影子对这种状况并不陌生因为赫温·兰比斯曾经采用过类似办法。他一边暗笑本体变得疯癫鲁莽狂妄形似小丑忘记过去教训一边啪地打出响指招来一道赤红焰流借此跳跃过去纠缠住克莱恩。哈哈哈哈哈哈。他发出满是癫狂意味笑声疯子般操纵起周围灵体之线不再区分敌我。他右侧脸颊上一个个淡色肉芽凸了起来似乎是即将钻出灵之虫。影子见克莱恩变得疯狂行将失控担心被精神瘟疫感染忙让一道赤红火焰蹿起吞没自己。这个时候银骑士秘偶时而展开攻击时而跳起抽搐式舞蹈明显受到不正常操纵。他无力再阻止观众圣者化成那条心灵巨龙任由对方舒展皮膜覆盖翅膀飞到克莱恩上空预备喷出心灵吐息。观众圣者不想给被精神瘟疫感染敌人喘息机会打算让他立刻失控！下一秒钟银白锐芒从他体内爆发而出分割着他血肉撕裂着他灵体。弯腰大笑克莱恩一下变得平静缓慢直起身体松开捂住左脸手掌对着远处影子翘起嘴角。他背后那条心灵巨龙在一波又一波银白锐芒撕扯下变成一块块乌黑血肉啪啪掉落于地身穿银色盔甲骑士秘偶随即收回手中大剑冰冷望向影子。克莱恩看着略显迷茫影子左脸几条灵之虫弯曲延伸模拟出嘴角上翘：你似乎没有注意到有一样东西是我有你没有的。

## 这场戏有没有翻
翻了。开头海吞光球科林断臂；章末假失控杀观众圣者、对影子说我有你没有。翻的是精神瘟疫陷阱被倒吊人侵蚀反吃。

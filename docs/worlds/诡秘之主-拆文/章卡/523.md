# 523 旅行家 第四十二章 见面

## 打开书
下午5点橄榄树大道帕梅占卜小屋。阿尔杰推开上方有一格格玻璃茶色木门进入这家神秘学主题咖啡馆。要了杯产自南大陆星星高原帕斯河谷费尔默咖啡将之前买那副塔罗牌拿出来摆在旁边最上面一张正是倒吊人牌描绘着一位双手反绑倒着吊起天使。与上午不同已改换装扮套着身古典深色长袍戴着顶类神职人员软帽仿佛从民俗传说里走出来巫师或魔法师。无声吸口气慢慢品尝起咖啡完全没有在等待谁焦急。过大概五六分钟镶嵌着厚玻璃茶色木门又一次敞开进来了位穿黑色呢制大衣戴半高丝绸礼帽年轻男子。这绅士外表年龄不到30脸庞消瘦棱角分明兼具成熟与阴郁两种气质正是微调外貌更改些许人设克。未戴金边眼镜但视力却没受任何影响目光随意一扫就落到阿尔杰深蓝色鬓角上。视线随之下移看见摆在最上方那张倒吊人牌。无需言语直接走过去摘掉帽子坐到阿尔杰对面阴沉笑道：「我想占卜。」说话间已将那位塔罗会元老级成员容貌收入眼底：五官深刻轮廓粗犷有明显雨打风吹之色一看就是比较能打且经常奔波在外类型；皮肤偏古铜却和本地人种有一定区别像是纯正鲁恩人常年日晒雨淋后结果但那深蓝色头发又较为特殊不属于鲁恩更接近于迪西海湾靠狂暴海区域殖民地人种。混血…心里做出判断。阿尔杰看着对面男士慢慢将他与世界形象重叠在一起然后推出那副塔罗牌低沉说：「这需要你自己洗牌和切牌。」伸手拿起全部展开看几眼接着将它们合拢在一块哗啦啦做了次洗牌。连续切牌抽出三张摆成过去现在和未来牌阵。身体缓慢后靠右手却将正中间那张塔罗牌翻过来其上有位赤裸仅缠着紫色丝巾女性周围则是如同门扉绿色花环。这正是编号为21世界牌第22则回归于0象征愚者。「该怎么解读？」故意问。虽然倒吊人没有明确提过世界就是愚者眷者但认为没必要在这方面抱有侥幸心思坦然表露更利于建立形象——如果对方还未猜到这就是真诚有底气表现要是阿尔杰已经知晓这能让世界显得从容似乎一切都在自己掌握中。他知道我知道了？在灰雾之上提出那个话题前他就相信我能猜到？厉害啊…心中一凛语速不快不慢回应：「逆位表示事情会因准备不足而失败。」「那要做哪些准备呢？」若有所思点头反问一句。阿尔杰将世界之外所有塔罗牌收回手法熟练重新洗牌和切牌。接着翻开最上面那张牌。这是一张教皇牌！嗓音依旧低沉：「你需要忠告需要信仰与宗教帮助避免走入错误道路。」不等克开口按照顺序翻开第二张牌上面有俯视着大地月亮：「你会迷惑你会困顿你会在梦境中徘徊但这只是暂时。」紧跟着给出第三张塔罗牌那是一张太阳牌。「一切都会过去光芒终将照耀大地。」就像个神棍般说。克沉默几秒确认般问：「教会梦境太阳？」阿尔杰脸上浮现出一丝笑意轻轻点头道：「就是这样。」刚才塔罗占卜里他蕴藏了后续计划暗示。其实以他现在没进入牌局根本未被关注处境完全没必要这么委婉可以直接讲述具体内容但觉得还是该试一试世界这位眷者看他是否拥有足够头脑而不是更多依靠武力。如果双方智商在同一水平线上认为以后可以更多地合作聪明人之间不需要说得太多反之会尽量不让世界深入参与自己事情只在需要打手时请他帮忙除非愚者先生另有命令。现在世界回答和之前表现让他确认对方老辣强悍经验丰富。呵我可是塔罗牌专家…在这方面倒吊人先生你才刚入门…暗笑一声心里贬低对方一句。倒吊人隐藏在解读里内容非常简单教皇牌意思是他想将烈焰和钢铁麦维提事情通报给风暴教会借代罚者力量分割敌人坐收渔利。这是克惯用办法理解毫无难度。之后月亮牌和太阳牌则是倒吊人做出提醒：既然引入代罚者就必须对此做一定防备而根据阿尔杰经验处理类似问题时他在拜亚姆同僚们肯定会启用一件能强行让范围内多人入梦封印物钢铁麦维提特点则决定了必然有太阳领域针对性物品出现。我克制梦境不害怕太阳…伸手将面前逆位世界牌转半圈变成正位意思就是这方案可行我会做好准备。阿尔杰抬起脑袋吸口气道：「这里主人擅长芳香疗法能利用不同精油纯露熏香花精香味治疗相应情绪问题抚平不安心灵你想试一试吗？」利用香树大道那个联络点？微笑回应：「好。」两人你看我我看你谁也没动未再提芳香疗法事情一切尽在不言中。未多停留掏出怀表按开看一眼后慢悠悠站起来。阿尔杰收敛住笑容以手按胸微微鞠躬道：「让我们赞美神灵吧所有占卜结果都来源于祂提供启示。」哟还懂得表忠心了…忍着笑意模仿倒吊人样子严肃回应一句。「让我们赞美神灵。」往外走两步忽然停顿回首望向阿尔杰边戴上帽子边低笑一声：「坦白地讲你并不适合这样打扮。」啊？没能跟上世界先生思路。等到克拉门走出这家主题咖啡馆阿尔杰收回视线望向角落镜子认真审视起自己现在打扮。原本并不觉得这有什么问题可被世界提这么一句后越看越不协调终于明白对方为什么那样说：一位看起来就很粗犷很风霜似乎随时能喊来一百个水手群殴对方或者拿出斧头砍倒一片家伙确实不应该穿这么有神秘感古典巫师长袍气质非常违和。……海浪教堂。换回原本衣物阿尔杰跟随祈祷信众们低调进入大厅利用告解机会通过负责牧师见到教区主教乔戈里。行礼之后直截了当说：「我遇上烈焰达尼兹他声称冰山中将那把钥匙与死神宝藏无关甚至愿意卖出。他有委托我留意钢铁麦维提行踪他之前似乎在这位血之上将二副手上受了伤并且急于摆脱对方追索。乔戈里阁下我想把这消息透露出去让钢铁麦维提和他手下能成功堵住烈焰达尼兹而我们则趁这机会将他们全部捉拿或当场击毙。这能有效打击海盗们嚣张气焰。」乔戈里露出赞赏表情：「很好你办事能力比我预想得好很多。」一脸虔诚回应：「这都源于主指引也得益于您教诲。傍晚我就会找适合对象把消息透露出去如果我再来做祈祷就表示钢铁麦维提暂时没有任何行动如果我未再出现则说明已经被他或他下属控制起来防止消息走漏这意味着他们将进入渔网。」交代完具体地点和其他事项后重回告解室正常离开。……傍晚7点15分香树叶酒吧。穿着阔脚裤用头巾包住深蓝发丝阿尔杰端着杯烈朗齐站在拳击台旁隐含嘲笑看着两位鼻青脸肿比赛者。很快发现目标进来直奔吧台。稍有等待坐到那位瘦削黝黑男子身旁呵呵笑道：「听说钢铁来了拜亚姆？」男子警惕侧头皮笑肉不笑回应：「我怎么不知道？」「是吗？看来烈焰骗了我！」拍下吧台喝口酒。「烈焰…达尼兹？」那男子眼睛一亮迟疑问。「对就是他！」一副咬牙切齿模样「我上午在金币赌场遇到了他这该死家伙声称钢铁就在拜亚姆呸他竟然敢骗我！」黝黑瘦削男子眼珠微微转动没有插言。安静听完站起来呵呵笑道：「我忘记了我还有件事情得去做回头一起玩牌。」拍拍阿尔杰肩膀看似平缓实则急促离开酒吧。阿尔杰端着酒杯半转身体望着他背影眸光深沉嘴角无笑。

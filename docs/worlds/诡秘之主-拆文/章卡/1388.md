# 1388 倒吊人 第三十六章 “愚者”的委托

## 打开书
下午好愚者先生。塔罗会其余成员此时都显得相当凝重跟着正义小姐完成惯常问候。等到他们重新坐下愚者克莱恩环顾一圈低缓说道：我将进入沉眠。听到这句话后倒吊人阿尔杰正义奥黛丽审判休和魔术师佛尔思都油然而生第二只靴子终于落地感觉星星伦纳德月亮埃姆林太阳戴里克等塔罗会成员则心中一沉愈发慌乱充满疑惑。当然他们并不是那么惊讶反常临时聚会反常世界缺席都仿佛在说明今天会有重要事情发生。……这涉及一场超越序列战争与末日程度有关。果然……倒吊人阿尔杰敏锐捕捉到超越序列这个词组。……现在愚者先生终于肯定了他这个猜测解开他许多困惑。隐者嘉德丽雅等人也注意到愚者先生话语里隐含信息……愚者克莱恩继续说道：等你们成为天使才有资格知道具体情况否则仅仅了解本身都会带来污染。这让塔罗会成员们联想到地底和星空一时思绪纷呈难以遏制。……我眷者世界已提前进入沉眠不知何时会醒来。那该怎么办？星星伦纳德险些脱口而出但他明显能感觉得到愚者先生话还没有说完于是强行忍住冲动。愚者克莱恩目光从他身上扫过：接下来有一个对所有成员发布长期委托：更广泛地宣扬我名但不要和正神教会冲突必要时候可以选择用隐秘方式传教。这将有助于我苏醒。还有将世界作为我眷者种种事迹传播出去记载于教会圣典里当然不要涉及他隐私。记住一句话：世界醒愚者归。克莱恩这是要提升自己锚数量这在与诡秘之主梦境对抗中或许会相当有用。同时他要将世界塑造成愚者教会圣徒神座旁天使让这个形象可以大范围分享信徒获得属于自身锚。简单来说就是克莱恩打算让一个信徒贡献两份锚反正于他而言无论愚者还是世界都只是一个身份而已并且锚所塑造形象不会统一各有不同不至于影响到他本身。——愚者层次教会传播是神灵尊名愚者圣徽和各种教义没有具体形象世界方面他有不少身份比如格尔曼·斯帕罗比如道恩·唐泰斯比如梅林·赫尔墨斯不会出现确定下来唯一一个形象。报酬就是过去你们享受便利获得回应和将来祈求对应帮助。愚者克莱恩语气不变说道我沉眠之后同样可以在一定程度内回应祈求但不是每次都会回应。如果确实有非常重要事情需要得到帮助那就多祈求几次。……是愚者先生。塔罗会成员们没有一点犹豫全部接下这个长期委托。这里面星星伦纳德是最发自内心最迫不及待那位。于他而言传播愚者先生信仰和典籍就是在唤醒克莱恩。……这时愚者克莱恩轻轻颔首将目光投向隐者嘉德丽雅：之前委托——搜集隐匿贤者突然活过来各方面资料依然有效。如果你愿望承担风险那就更进一步去调查隐匿贤者现在状态。这会非常危险你可以拒绝而报酬是一个愿望。隐者嘉德丽雅想下道：尊敬愚者先生这和让您苏醒之间是否存在一定关系？是否涉及如何度过末日问题？或许有或许没有我现在无法给你肯定答复只是看见一些画面。克莱恩这次没再特意塑造愚者高位格因为他已经是真正愚者另外看好手下所有大地和月亮途径非凡者。……我接受这个委托。愚者克莱恩随之将目光转向另外一边对太阳戴里克道：你任务是保护好新白银城和新月城保护好罗思德群岛。我信徒越多越安全我苏醒可能就越大。在这个基础上你再考虑怎么扩大教会传播信仰。你报酬是成为我眷者。太阳戴里克眼睛突然有些发热他又回想起自己推开巨人王庭最后那扇门时首席鼓励目光。……是愚者先生！克莱恩点下头看向魔术师佛尔思：你需要保护好亚伯拉罕家族防止他们遭受来自星空诱惑。另外更多地搜集第四纪资料弄清楚那个时候门先生状态弄清楚亚伯拉罕家族潜藏一些问题。这都是我自己希望去做事情。魔术师佛尔思犹豫一下还是表明哪怕没有委托自己也会做这些事情。愚者克莱恩没说可以也没说不行转而道：你如果愿意可以帮世界不同身份写一写传记和故事以不同笔名发表。以上委托报酬是当你有希望成为旅法师必须前往星空时获得我庇佑。克莱恩虽然知道自己于沉眠中能够在一定程度内依靠梦境给予回应但他不确定到时候占据优势是自己还是那位诡秘之主所以希望用完成委托给予报酬方式将比较重要事情以口头契约形式固定下来。到时候他哪怕处于劣势也能借助这种无形约定巧妙完成回应。旅法师？魔术师佛尔思愣一下。……是愚者先生。克莱恩随即将目光投向月亮埃姆林：围剿玫瑰学派事情涉及末日准备相当危险即使有天使参与也要注意自身安全。你委托是尽可能从玫瑰学派内部原始月亮信徒身上搜集原始月亮给予祝福气息和物品这些或许比1级封印还危险。此时克莱恩虽然还保持着愚者语气但话语里已带上些许对朋友叮嘱。……即将进入沉眠时愚者先生人性似乎更浓厚了……月亮埃姆林略感惊讶和疑惑时克莱恩继续说道：在参与围剿玫瑰学派任务外我希望你组建一个药品公司研究如何将具备神奇效果药剂量产。只要量产就没可能具备太神奇效果。月亮埃姆林本能回一句。愚者克莱恩点下头：寻求一个折中。你主要目的是通过这个药剂公司传播我名。报酬也是一个愿望。……是愚者先生。克莱恩看向另外一边对审判休道：末日将近无论红祭司还是魔女都会活跃起来你任务是依托官方势力查清楚红祭司途径三份序列1非凡特性和相应唯一性下落如果有机会寻找线索确认原初魔女当前状态这非常危险。……休实现自己愿望举行仪式成为序列4律令法师。至于红祭司途径三份序列1征服者非凡特性克莱恩之前知道是一份在因蒂斯前王室索伦家族手中一份在弗萨克王室艾因霍恩家族手中一份落到鲁恩王室奥古斯都家族那里后来作为报酬给魔女教派。……索伦家族早在罗塞尔时期就已经衰败……克莱恩甚至怀疑这会不会已被铁血十字会拿到；之前战争失败给艾因霍恩家族造成相当大损伤……奥古斯都家族给魔女教派那份征服者非凡特性是目前下落最为清晰但克莱恩知道红天使恶灵索伦·艾因霍恩·梅迪奇一直在打它主意……相应红祭司唯一性目前没有任何线索最后一次被神秘世界知晓是在第四纪末尾苍白之灾时。

## 这场戏有没有翻

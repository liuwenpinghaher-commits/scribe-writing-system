# 1216 逐光者 第六十七章 五蘑二菇

## 打开书
月城。多有斑驳痕迹但异常坚固一栋栋建筑物内走出不少人类他们有明显畸形有已产生一定异化。这些人类互相看一眼都从对方脸上发现一定疑惑：距离太阳祭礼还有两三个月大祭司为什么要召集所有人去广场？难道发生什么大事？月城居民们带着担忧惶恐与不解情绪从一条条街道进入唯一那个广场。此时高台之上一片空荡召集者似乎还没有抵达。月城居民们按照所属区域很有秩序分别聚集一起低声讨论：大祭司怎么还没到？他不是喜欢等待不愿意被等待吗？究竟出什么事情怎么突然召集守卫之外全城居民？……一道道声音里广场附近一座高塔顶部水晶玻璃后方大祭司尼姆一边靠着墙壁注视广场一边表情扭曲忍耐着什么。他灰白头发扬起来脸庞上长出一撮撮黑色短毛肋间和腰部血肉蠕动凝出肿块。这些异常变化时而消失时而出现就仿佛尼姆在一次又一次发病整个人既邪异又可怕。一分多钟后尼姆终于平静下来长长吐口气抬手抹抹额头沁出冷汗。他刚才是在对抗自己体内积攒疯狂。其实不管哪一条非凡途径都是序列越高疯狂与非人倾向越严重这会逐渐超越本身人性必须依靠外在锚帮助才能维持足够平衡。正常来说序列4和序列3时这种情况还不是那么明显而到天使层次即使有足够锚来固定也会时不时陷入阴暗负面异变状态必须独自忍受和对抗等待缓和。这就像一个神圣庄严存在平时看起来没有任何问题能回应你祈祷与你正常聊天甚至开几句玩笑但某些时候却只能躲在黑暗房间内藏于阴影中撕掉表层皮肤露出阴鸷一面展现种种疯狂迹象。尼姆则是由于经常食用怪物血肉累积不少毒素污染和疯狂才在序列4就承受类似痛苦。当然那种不懂扮演法靠时间或运气提升上来序列4序列3也会这样。调整好状态尼姆转身离开房间借助一扇虚幻之门直接出现于广场中央高台上。所有讨论一下平息月城居民们将蕴藏着疑惑和不安目光投向这位大祭司。尼姆环顾一圈直截了当：阿达尔率领狩猎小队遇到一位外来者。外来者！月城居民们眼睛骤然睁大有种高空雷霆直接降临城中感觉。两千多年了月城第一次遇到外来者！当然这指有理智能交流人类而不是怪物。尼姆无声吸口气继续：他自称是散播神灵光辉传教士他让那片灰白雾气产生明显变化他清除阿达尔他们体内积攒污染和毒素并治疗他们身体异变。说话间尼姆对高台侧方点头躲于阴影里阿达尔和辛立刻穿过一根根火把走到他旁边用自身状况证明着对方刚才话语。嘶……神啊！这是阿达尔和辛？他们真的真的……一声声惊叹脱口而出错愕与诧异情绪交织一起宛如实质。阿达尔和辛对视一眼上前两步将自己狩猎小队遭遇原原本本讲一遍。听到黑暗中浮现那点火光听到那个散发出明净光芒十字架听到那能治疗异变和疾病手杖听到灰白雾气向两侧分开以及形成大门表现听到狩猎小队成员们对自身良好状态欣喜描述月城居民们逐渐沉默下来。他们之中有人已不知不觉流下眼泪那是因为无比疲惫和极端压抑中终于看见一道光。这眼泪带着略温和咸咸感觉淌过脸庞滑过嘴角滴落于地。另外还保持着理智和清醒人抬高手臂表达自己意见：那个传教士会不会是黑暗深处特殊怪物？阿达尔和辛是不是已经被控制被影响才有这样表现？等到疑问浪潮平息尼姆低沉而清晰：我检查过他们也用封印物检查过暂时没有发现任何异常。我会让他们继续待在黑塔接受至少十五天观察。做出承诺后尼姆顿一下：那位叫做格尔曼·斯帕罗传教士将在灰白雾气附近苦修一段时间他允许我们去那里感受他信仰那位神灵光辉聆听相应教诲而他每天会在闪电最频繁时候做一次净化和治疗。所有人都可以选择前往但必须事前报备听从安排不能私自行动影响到城邦防御而去那里人回来之后都将像阿达尔和辛他们一样隔离十五天。月城居民们全部沉默你看我我看你下不定决心。这时之前回城通知大祭司未能得到净化和治疗鲁斯与另一位狩猎小队成员站出来：大祭司我想去！好明天我来带领这支队伍……尼姆轻轻颔首答应下来。他本打算给这样一支队伍按一个名称可始终没想到好描述只能磕巴一下直接略过。在他心里其实有一个名称但不敢说出那是：朝圣者。有鲁斯他们带头好几位月城居民站出来表示自己愿意冒险尝试。当闪电频率由低变高新一天来临由七八个人组成月城队伍提着兽皮灯笼开始在黑暗里跋涉前往那片灰白雾气边缘。黑暗与光明不知交替多少次后鲁斯等人眼中忽然映入一抹火光。那是一堆正缓慢燃烧篝火穿奇怪衣物戴奇怪帽子格尔曼·斯帕罗坐在另外一边拿着一根铁黑色长签正烤着什么。篝火周围躺了一具又一具怪物尸体这些尸体上长着各种各样古怪事物它们有洁白饱满似乎一戳就会有液体喷出有以黑色为底镶嵌着血色细丝和脂肪花纹有布满金色斑点顶部盖子有手掌大小……这些事物密密麻麻覆盖怪物尸体不同部位带着一种妖异而诱人美感。前行几步大祭司尼姆发现格尔曼·斯帕罗烤正是那些奇怪事物里一种一滴滴油脂掉落在火中发出滋滋声响让光亮更加明显让一种诱人奇香散逸开来。咕噜队伍里月城居民们本能吞口唾液产生强烈难以遏制食欲。他们每一个细胞都在疯狂呐喊：我想吃！我要吃！给我吃！坐在一块石头上克莱恩抬起脑袋指指周围怪物尸体上生长鲜艳事物嗓音低沉：它们叫蘑菇分为不同种类如果你们愿意可以自行摘取食用但不能碰全黑那种而且必须足够熟才能入口否则将遭遇可怕诅咒。月城大祭司尼姆想一下代替其他人做出回答：我们想先聆听您那位主教诲感受祂光辉。克莱恩轻轻颔首边转动自己从历史孔隙里召唤出烧烤长签边开口：你们可以坐下听。等到那七八位月城居民坐至篝火对面他表情庄严：我从巨人王庭而来。这是月城居民们都熟悉一个名词他们精神顿时一振将注意力从篝火上烤灼事物移开投向格尔曼·斯帕罗。接下来克莱恩像之前那样描述白银城状态和诅咒之地外情况并说说说自己沿途以来看见城邦遗迹。这听得月城居民们时而唏嘘时而向往时而难以置信时而感同身受悲不可遏。讲到一半克莱恩突然停下来收回手中铁黑色长签将它凑至嘴边咬下一个蘑菇。那浓郁肉汁随之沁出带着微烫感觉洗礼着他口腔。——在神弃之地大半年后克莱恩已战胜对蘑菇反感毕竟达尼兹时常得受他指派去做一些事情没法精心准备食物献祭中间空白只能用蘑菇填补。满足闭闭眼睛克莱恩将手中铁黑色长签递出微笑：你们可以试一试。大祭司尼姆还在犹豫鲁斯已是伸手边感谢边弄一个蘑菇下来送入口中。他吃太急以至于口腔有被烫伤但他表情扭曲一下后却突然凝固。接着他神情一点点舒展逐渐露出沉醉享受渴望感觉。到最后鲁斯眼泪不自觉流出来嗓音低沉抽噎：这是这是我吃过最美好最美好食物……就算这么一代代下来他们对食物口感有出现异变但人类怎么都是适应不了那种毒素和疯狂渴望着糖分渴望着脂肪。这一刻所有月城居民都听出鲁斯感动。

## 这场戏有没有翻
翻了。开头还在全城疑惑召集；章末朝圣队抵篝火、蘑菇解馋泪流。翻的是外来者消息变可吃的希望，不是半神发病厉不厉。

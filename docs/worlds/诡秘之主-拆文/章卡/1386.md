# 1386 倒吊人 第三十四章 办法

## 打开书
无尽阴影帷幕之后一片晃荡着轻微水光黑暗中。一个黑头发黑眼珠宽额头瘦脸庞年轻男子猛然坐起仿佛经历场噩梦。穿着古典黑袍祂伸出右手试图从虚空中拿出水晶磨成单片眼镜戴至右眼位置。可这一次祂什么都没有拿到。……对他来说有比生命更加重要事物。于你而言除自己几乎没有什么值得太过在意。当事情发展到必须以生命为赌注时候就意味着你输了。……作为天生神话生物你缺乏足够正常锚也是一个问题。这让你虽然知道什么是勇气和牺牲但却很难理解。……这似乎很有趣。接下来我打算离开这里潜入星空那里比现实精彩多了刺激多了也许我会因此弄明白你刚才说那两个词语。那很危险一旦进入星空我成功之前没法再提供任何帮助不过至少可以避开祂。那道温和平淡却不含任何感情声音回应道。……随着阿蒙在超新星爆发威能中彻底粉碎克莱恩忍不住松口气。如果有选择他当然不想牺牲自己让福生玄黄天尊复活更希望亲自来守护这个世界重新寻找生命意义。当然若是没有选择他会毫不犹豫让天尊苏醒。这一点他确定自己能做到阿蒙同样清楚所以祂未做逼迫只是试图脱离。……他能感觉得到了他体内福生玄黄天尊在加速醒来而且似乎不可遏制。就算克莱恩直接带着这份意志一起死去然后再依靠奇迹师能力复活也无法摆脱因为诡秘之主同样掌握着奇迹权柄。这一刻克莱恩想起暗天使萨斯利尔也就是远古太阳神说那句话：原初在我体内苏醒了……克莱恩想要阻止这些非凡特性与自己融合却被体内越来越强天尊意志干扰没能成功。……一份时之虫非凡特性一份星之匙非凡特性一份……克莱恩精神就像在被无形怪物一口又一口撕咬吞吃产生相当强烈痛苦。……源堡！这个刹那克莱恩源堡门唯一性错误唯一性有了极端强烈聚合倾向。一旦它们融为一体那位诡秘之主将彻底苏醒完成复活。……靠着信徒之锚带来认知定位和形象干扰克莱恩终于延缓一点诡秘之主意志复苏让聚合之力减弱少许。……哈哈这也算是一种聚变。克莱恩情绪不太稳定笑一声。然后他愚弄一下特伦索斯特黄铜书让它进入封印状态飞到杂物堆中。紧接着克莱恩离开源堡一步来到象征和权柄组成星界。……哈哈。克莱恩笑出声来到一片种满夜香草深眠花黑暗国度外面。与此同时黑夜女神穿着点缀满星屑层叠长裙出现在神国边缘脸上蒙着半透明薄薄黑纱。……福生玄黄天尊意志被动进入永眠状态克莱恩大部分意识也同样如此只留下那么一点清醒。……这不能维持太久只是将事情推迟一段时间。黑夜女神嗓音轻柔提醒道若是反复使用永暗之河河水诡秘之主会苏醒得更快因为祂会应激产生未知变化调整自身状态同样来自源堡特殊和我祝福将逐渐被磨灭你也会进入永眠状态。……我知道了。黑夜女神用一种似乎在安抚克莱恩精神语气道：在这件事情上阿蒙采取办法做出行动都超出我预料祂确实是真正欺诈之神。你接下来不是完全没有机会你可以先试着彻底掌控源堡拉着诡秘之主意志一起永眠在梦中与祂既对抗又融合我可以给你施加一定祝福但最关键还是你自己。成为旧日没有仪式任何仪式都无法改变原初意志苏醒但远古太阳神认为容纳顺序可以在某种程度上提升自我认知增强事情成功率。先成为一条途径序列0接着掌控并融合源质最后才容纳另外唯一性是最优顺序。成为双途径真神掌控融合源质然后容纳剩下唯一性是不好也不坏顺序。到最后一步才融合源质是最差选择。……这是一个好办法只要醒来就会有一位诡秘之主诞生。这可能是祂也可能是我嗯彻底掌控源堡进入永眠后我应该能让西大陆封印出现一定薄弱处可以进入和出来薄弱处。黑夜女神听着克莱恩话语没有说话。……这是我自己选择。我很早前就预料到会有这么一天我终将面对祂。

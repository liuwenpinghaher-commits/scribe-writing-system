# 1203 逐光者 第五十四章 不计生死

## 打开书
对于世界先生此时提出这个要求魔术师佛尔思并不意外略感紧张回答：好好的。具体是什么样交易？她这段时间已和自己老师多里安·格雷·亚伯拉罕通信好几次在正义小姐指导下做不少铺垫。世界克莱恩低哑笑：你暂时不用告诉他我想要什么直接给出我筹码看他是否感兴趣。您筹码还是解除亚伯拉罕家族诅咒承诺？魔术师谨慎寻求确认。克莱恩点头指着斑驳长桌上0-61：也可以是这个旧日之盒。需要0级封印物换取事物绝对不简单……无论正义奥黛丽还是隐者嘉德丽雅都骤然冒出这么一个认知。魔术师倒是更看重那个解除诅咒承诺因为她有过亲身体验知道老师家族究竟有多么悲惨。她没有犹豫郑重：好的。……贝克兰德西区一栋房屋地下室内。藏于阴影中幽暗圣者克斯玛突然从黑暗中长出来。他侧过脑袋仿佛在倾听什么脸颊肌肉逐渐有些抽动不是一片一片而是一点一点它们彼此不仅没能连一起反倒互相干扰看起来极为怪异。也就是几秒后克斯玛露出极端疼痛表情皮肤一寸寸撕裂血肉沸腾般蠕动夹杂着深沉黑色。噗通一声他倒在地上匍匐着朝向祭坛吐出大量内脏和闪烁光点。这位幽暗圣者脑袋紧紧贴于地面疯了般不断自语：布提斯竟然死了……一个携带着0级封印物秘法师就这样死了……现场有一张塔罗牌隐者……动手两个敌人都是圣者一个是神秘学家一个是操纵师……以塔罗牌为代号信仰愚者组织……格尔曼·斯帕罗……阿兹克·艾格斯…………不受控制低语之后幽暗圣者又懊恼又痛苦流下眼泪：我忏悔我忏悔我忏悔……几天后普利兹港一栋公寓内某个房间中。乔装改扮过多里安·格雷·亚伯拉罕辗转收到学生佛尔思来信。他谨慎检查一遍确认没有问题没有不寻常迹象后拿起拆信刀取出里面信件。这封信开头是照例问候接下来佛尔思直截了当写：……我们已击杀秘之圣者布提斯得到他身上物品……本打算先浏览一遍多里安突然就被这句话卡住来回看好几遍忘记往下阅读。布提斯究竟有多么强多里安是有深刻了解并且很清楚一位秘法师有多么可怕。但现在他才教导一年多新学生却以非常平淡口吻告诉他已经解决布提斯。一时之间多里安脑海内回荡尽是不可能谎言有阴谋等念头怀疑佛尔思是不是已经被布提斯被极光会控制。在任何一个大势力内序列4非凡者都是绝对高层是非常重要成员怎么可能那样轻松那样容易就被人击杀！多里安喉结蠕动一下强行收敛住注意力继续阅读书信内容：……我们拿到旧日之盒我想您对它应该不陌生……才又看一行多里安眼皮就跳动几下只觉手里信纸沉甸甸如同巨石。他当然对旧日之盒不陌生这是亚伯拉罕家族0级封印物是他们曾经辉煌证明。……被杀是拿着旧日之盒布提斯……多里安一边愈发惊愕感觉事情超出自己想象一边又莫名觉得也许不是没有可能说不定真正杀死布提斯其实是旧日之盒。那件0级封印物有多么危险他是非常清楚！同时他终于注意到一个单词：我们。这是佛尔思第一次表明她有同伴有合作者。当然多里安早就有所猜测只是默契没去拆穿。果然……多里安叹口气迫不及待阅读起后面内容：……这次针对布提斯采取行动是我有位朋友想向您展现友善他说他愿意用旧日之盒或者解除亚伯拉罕家族诅咒承诺与您达成一笔交易不知道您是否感兴趣？他并不知道您在哪里我也不会告诉他您完全可以拒绝……解除诅咒承诺？多里安直接跳过旧日之盒咀嚼起那对他来说极其重要一段话。经过前面几次通信他已完全弄清楚家族诅咒实质既悲哀又无奈于痛苦中酝酿出一丝希望。在此之前谁能想到让一代又一代亚伯拉罕家族血脉后裔失控竟然是他们始祖求救声？这就像一个来自命运恶劣玩笑。多里安不知道门先生对祂造成后果究竟有没有了解也不知道该如何描述自己复杂感情但忍不住开始寻找让门先生回归彻底解除家族诅咒办法。这是一条希望极其渺茫道路但对亚伯拉罕家族来说却已经足够因为黑暗中终于出现一道光。不知过多久多里安折起信纸苦笑自语：友善……这样友善真是让人害怕啊……自语完他又陷入沉默脸上表情时阴时晴内心似乎极为挣扎。当！壁钟声音准时响起多里安一下被惊醒。他表情逐渐沉凝终于有决断。下定决心后多里安整个人都轻松不少脸上甚至多点微笑。他先是烧掉佛尔思来信接着简单收拾下行囊直接出门前往普利兹港蒸汽列车站点。他这是要去南威尔郡但不是为躲避而是做一些准备。他打算把自己保管家族物品和魔药配方都交给定居在那里一位家族成员然后返回普利兹港以多里安·格雷身份去贝克兰德见自己学生佛尔思见那位展现友善强者。到时候他会提前服食一种药剂让自己承受根植于灵体强烈诅咒必须定时定量服食另一种药剂才能维持生命这样一来即使他被控制无法自杀也能因为没机会服药很快死去伴随灵体消散不至于泄露关键情报。这一趟旅程于多里安而言生死已不放在心上。为那个飘渺希望他愿意付出自己生命。……贝克兰德北区圣赛缪尔教堂地底。刚和代罚者机械之心军情九处成员开一场案情讨论会伦纳德回到办公室坐下来。就在这时他脑海内回荡起帕列斯·索罗亚斯德那略显苍老嗓音：他们终于找到雅各家族宝藏具体位置即将进入。啊？伦纳德一时有些愕然没能反应过来。之前那次

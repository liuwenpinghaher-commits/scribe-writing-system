# 140 小丑 第一百四十一章 梦魇

## 打开书
疲惫的克莱恩解除了密封的灵性之墙让夜晚的凉风带着草木的味道吹在脸上吹得他清醒了几分。摩挲着掌中温润古典的封印物3-0782在内心由衷感叹谁能想到这枚徽章里竟然融合了一滴神血估计永恒烈阳教会的强者们曾经寻找过但没有找到。活动了下脖子不敢再尝试别的想法将变异的太阳圣徽戴到薄风衣内侧。顺着链条掏出有枝蔓花纹的银色怀表啪地按开发现距离收尸人弗莱来换班还有一个多小时。我的眼皮需要两根火柴来支撑这就是作死的后遗症啊。只好从一格格小暗袋取出金属小瓶拔掉塞子凑到鼻端。薄荷和消毒水混杂在一块的呛人味道迅速钻入鼻子刺激得粒粒疙瘩浮现精神为之一振瞬间遗忘了困意。这是他从收尸人弗莱那里学到的配方叫做克拉格之油能帮助人对抗腐烂等恶臭味道兼具提神醒脑的效果。接下来的一个多小时分外煎熬时不时站起来溜达一圈好几次被树林里的蚊虫叮咬吸血。终于看见高鼻薄唇黑发蓝眸的弗莱穿着薄风衣拿着手杖走出了小镇。虽然对方还是一副冰冷阴沉如同活尸的模样但克莱恩就像见到了救世主一边捂嘴打了个哈欠打得眼泪满眶一边迎上去从衣物内侧取下封印物。发生了什么事情弗莱望着队友苍白难看的脸色主动询问。叹了口气我昨晚才值守了查尼斯门今天上午又睡得不太好所以现在非常困。没有多提这件事情岔开话题我是四个小时后来轮换。七个小时队长半夜不需要睡觉。修仙让人快乐无声诋毁了队长一句告别弗莱走向小镇。沿着街道靠近旅馆的途中随手又拿出怀表咦比约定的时间早了快十分钟真是一个温暖的人啊。加快速度回到旅馆推开半掩的大门在老板审视的目光里走上二楼进入属于他的房间。锁好门脱掉外套和鞋子没有清洗自己直接倒在床上。也就十几秒钟鼻息先是变重接着悠长而平稳。睡梦之中回到了地球面前是他还没有玩到通关的游戏左边摆放着冰镇可乐和香辣鸡翅右侧是苦笋肉片汤和米饭。他一直不吃苦笋但非常喜欢用它做材料加肉片煮成的汤那汤清爽开胃里又有点油脂的勾人香味用来泡饭相当完美再配上一碟好的蘸料能比平常多吃整整一碗饭。就在准备好好享用夜宵再疯狂玩下游戏的时候梦中的场景一下变化重新呈现为水仙花街2号的内部格局。忽然警觉清醒地知道自己正在梦中。看见自己坐在餐桌侧方的位置手里拿着一份廷根日报面前放着番茄牛尾汤煎小羊排土豆泥和燕麦面包等食物。下意识转头望向大门位置猛地看见客厅对应的凸肚窗外立着道人影正静静凝望着房屋里面的人影。吓了一跳旋即认出那是灰眸幽邃的邓恩半张脸贴住窗户无声地看着里面的人。队长不要在梦里吓人好不好这就是你扮演梦魇的方式好气又好笑拿出汤勺捞了块牛肉放入口中。嗯是我的手艺明白了自己为什么会突然在梦里清醒为什么地球的场景会瞬间消失当有人入侵他的梦境时他就会自然警觉。就在这时邓恩离开凸肚窗位置直接推开了莫雷蒂家的大门披着黑色风衣安静地走到对面。摘掉帽子轻轻颔首坐了下来半点也不客气地拿起刀叉和调羹用极快的速度将桌上的番茄牛尾汤煎小羊排土豆泥和燕麦面包等食物吃了个干干净净。呆呆愣愣弄不清楚队长究竟想做什么。呼满足地吐了口气对克莱恩竖了下拇指然后拿出烟斗和火柴陶醉地来了一口。吐出烟云站起身拿上帽子老派但稳重地行了一礼迈步离开了莫雷蒂家离开了这片梦境。望着队长的背影好半天都没能回过神来。低头看了看空掉的盘子下意识想要再现刚才的食物。但是这一次不管番茄牛尾汤还是煎小羊排土豆泥都没能继续出现于他的梦中。被彻底吞食了这就是梦魇的能力嘴角抽动了一下无奈所以队长的目的就是让我在梦里都吃不到夜宵这还真是噩梦啊这梦魇扮演得真有创意。失笑一声退出梦境重新再睡。第二天凌晨五点半不得不早起喝了咖啡吃了吐司和培根匆匆忙忙前往小镇外替换了邓恩。七点他们准时启程往廷根市区返回。不到十点抵达佐特兰街36号由精神抖擞的邓恩将封印物3-0782放回查尼斯门后弗莱则坐到机械打字机前在文职人员还没到位的情况下亲自书写昨天的任务报告和相应消耗的报销申请。旁观了一阵满意地看见自己用掉的所有材料都被列入了清单这包括他用来驱蚊驱虫的部分。他没有立刻回家因为已经用写暗号信的方式约好疯人院的达斯特医生在下午一点在预定的场所见面。接着还有三点的塔罗聚会我一个隐秘组织的BOSS为什么要活得这么累无声自语在值夜者休息室里躺了两个小时补了下眠。对于昨晚获得的那些知识和事情他并不担心遗忘这可以用占卜的方法回忆起来他害怕的是自己忽略了这些知识和事情的存在连占卜它们的想法都失去所以他在睡前又于脑海内将种种细节过了一遍以加深印象。这也是克莱恩每周坚持写总结梳理各种情况的原因。用过午餐掏出怀表看了一眼戴上帽子离开黑荆棘安保公司来到位于佐特兰街3号的射击俱乐部。推开大门进入招待厅没有直接去属于值夜者的那个靶场而是在大厅找了位置坐下双手交握住黑色手杖地耐心等待。他与达斯特约定的见面地点就在这家佐特兰街射击俱乐部。而他们约定的方式是写信当克莱恩需要见面的时候会以患者家属的身份写信给达斯特·古德里安医生询问一种叫做人格分裂的特殊疾病在信里会用各种方式提到观众这个词汇以此配合隐蔽位置的墨点来确认自己的身份而信里不经意写到的时间点就是见面的时间点。至于见面的场所在他们第一次的商谈里就已经定好如果觉得该换个地方了会在面谈里交待。当达斯特想要见面但并不急迫的时候可以把信寄给猎犬酒馆或者这家射击俱乐部收信人是霍纳奇斯先生等待克莱恩定时取走。如果他有紧急情况那必须直接将信交给猎犬酒馆的老板莱特而且得提上一句寻找佣兵这样一来作为值夜者外围成员的莱特会立刻把信送到黑荆棘安保公司。等待了一阵一点还差两分钟的时候看见气质相当斯文的达斯特走进射击俱乐部的大厅。他戴着黑色的丝绸礼帽穿着合身的燕尾服手中拿着一根镶银的手杖脸上架着一副金边的框架眼镜。不引人注意地环顾了半圈看见了微微点头的克莱恩于是收回目光走向前台熟练地申请靶场租用枪支他已经来过这里一次。小型靶场7号每小时3苏勒左轮手枪租赁费用每小时1苏勒6便士含六发子弹负责接待的女郎迅速弄好。等到达斯特确认时间为1小时并交了10苏勒的费用后领到了左轮手枪与额外的子弹在服务生的引领下进入相应靶场。克莱恩又等待了五分钟才慢悠悠起身提着手杖来到小型靶场7号的外面咚咚咚敲响了大门。吱呀一声房门裂开了一道缝隙达斯特先是警惕地探头左右望了一眼然后才让开了位置。立刻闪身进去反锁住大门。下午好达斯特先生边说边取出10苏勒的纸币递给了对方我们不会让外围成员负担见面费用的。因为我可以报销他默默补了一句。达斯特没有推辞收下了现金接着沉声问道莫雷蒂警官你这次找我见面是为了什么事情。

## 这场戏有没有翻
翻了。开头还在摩挲神血不敢再想；地球夜宵被队长从凸肚窗走进来吃光再也变不出来；章末暗号信把疲惫的BOSS按进靶场7号。翻的是梦魇把夜宵吞了不是报销驱蚊。神血只在心里感叹未再占。

## 日子
镇外还有一个多小时。弗莱早到快十分钟。倒头十几秒睡着。凌晨五点半换邓恩。七点启程不到十点佐特兰街36号。休息室补两小时。午餐后射击俱乐部。一点差两分达斯特到。再等五分钟进7号。三点还有塔罗。查尼斯门是昨晚值守。

## 这一章落在哪一天
作死能手同一夜后半到次日下午一点。周日值守次日的拉姆德任务后的周一。队长半夜不需要睡觉故他这一班后要隔七小时不是四小时。

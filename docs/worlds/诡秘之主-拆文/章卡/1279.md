# 1279 倒吊人 第十四章 小城偶遇

## 打开书
一列奔驰往间海郡康斯顿城蒸汽列车上。做流浪魔术师打扮克莱恩隔着一张摆放物品窄桌看向对面那名年轻男子和他父母道：我魔术有两种一是让你们愿望得到实现二是用一面镜子回答你问题当然第一种魔术需要付钱第二种则必须回答镜子提出问题你们想看哪种表演？那位年轻男子黑发褐瞳似乎受过较为良好教育他看了看坐在旁边父母笑着说道：我愿望太过困难还是不麻烦你了。相对来说我对可以回答问题镜子更加好奇。……似乎是古董。对面那年轻男子饶有兴致评价一句然后说道我问题是我这次去康斯顿城目的是什么？魔镜魔镜告诉我问题答案是什么。……去结婚。……神奇。那名年轻男子和自己父母对视一眼都露出不可思议表情。……好了该镜子提问了。克莱恩笑着将右手覆盖在镜子表面。好的。那名年轻男子颇为好奇回应道。接下来让我们看一看魔镜会提什么问题。克莱恩就像在做正式魔术表演一样略显浮夸松开右手。……你更希望自己新娘是四十岁以上女士对吧？怎么可能！他当即做出反驳并忍不住侧头看自己父母急促抱怨道这是什么奇怪问题！……它开玩笑的。克莱恩抱歉一笑赶紧将右手按到镜子表面一副自己事前也不知道会出现这种状况模样。……你多少岁？25岁……那名年轻男子小心翼翼回答道似乎很害怕自己掉入陷阱。……好了这个魔术表演到这里结束。克莱恩笑着收起镜子你可以试一试另一种魔术。……抱歉我该下车了。克莱恩拿出金壳怀表按开看一眼道。……其中由于风暴教会存在以及铁甲舰配合高位仲裁人威力弗萨克和费内波特海军始终未能取得预定战果甚至没能掌控住制海权而安曼达山脉战场黑夜教会总部挡住一波又一波进攻直到战争结束都未陷落让凛冬郡……知道星空和地底秘密后他能理解黑夜女神谋划并在某种程度上接受但这不表示他会对那些牺牲无动于衷。同时他也确定一件事情那就是即使自己没能阻止乔治三世成为黑皇帝世界大战依旧会爆发只不过鲁恩将占据优势黑夜女神和祂盟友将正面压迫战神一步步逼得祂寻求大地母神帮助。……祂怎么会到贝尔丹？这个时候祂不是应该已经回到宁静教堂黑夜修道院了吗？或者被派去弗萨克首都圣密隆主持战神遗产接收之事？一位行于地上天使出现在这么一个小城市绝对不会简单……克莱恩一阵疑惑微皱起眉头。……可这个时候阿里安娜已经消失在人潮里而身为隐秘之仆祂让克莱恩想追踪都没有办法同样在关系隐秘事情上魔镜阿罗德斯也有点无能为力。……然后他保持流浪魔术师装扮带着魔镜阿罗德斯依循占卜家灵性直觉一路走到贝尔丹城市政广场。……女士们先生们我是你们新任执政官。现在我颁布三条新律令：第一条没有我允许任何生灵都不能离开这里。第二条律法面前众生平等哪怕天使也能被普通人杀死。第三条有以下犯罪行为者将遭受重罚最高死刑：1杀人；2偷盗；3完整诵念神灵尊名；4祭祀邪神；5诈骗；6泄密；……他本能就转动念头试着让灵体回到源堡。可是一股无形力量阻断他离开让他仅能接触那片灰白雾气却无法通过。……他之前也有过无法返回源堡情况但原因主要是来不及逆走四步诵念咒文或者被自己干扰和阻拦。……那是在迷雾小镇内——那里是由黑夜女神亲手打造隐秘世界强力封印。除这次就连渎神者阿蒙都没做到类似事情当然那个时候阿蒙主要目的是逼迫克莱恩引动源堡然后抓住机会利用漏洞取代他成为灵界之上伟大主宰否则这位时天使完全可以通过窃取念头来阻止克莱恩回归……贝尔丹城新上任这位执政官是谁……这就是阿里安娜女士来到贝尔丹城原因？念头急转间克莱恩让魔镜从自己宽大袖管中滑落至左手。发生了什么事情？克莱恩低声问道。……这里规则被置换几条具体是谁做无法得知伟大主人您可以试着找到隐秘之仆阿里安娜从祂那里了解真相。我回答您还满意吗？规则被置换……律师？仲裁人？或者出了Bug？克莱恩若有所思抬起脑袋望向四周发现广场上市民们都有点疑惑不太理解为什么新布告会提及天使为什么离开需要申请并得到允许。战争都已经结束了！

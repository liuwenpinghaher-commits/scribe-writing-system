# 1187 逐光者 第三十八章 厚颜

## 打开书
召唤信使……作为塔罗会审判军情九处成员休明白信使指什么且知道灵教团中层广泛使用信使。还没来得及开口询问更多细节就看见佛尔思脚步虚浮双眼无神走向一楼客房嗓音颇为飘忽：让我先睡一会儿有什么事情等下再说。这一睡就到第二天清晨被弥漫肉香味从深沉梦境中唤醒。迪西馅饼？揉着眼睛走出房间看见桌上已摆好食物。对。休从盥洗室出来：就街角那家还不错。嗯嗯两声已坐到餐桌旁速度极快拿起迪西馅饼塞入口中。吃完一个喝口甜冰茶满足叹息：这才是生活啊。糟糕忘记刷牙了……忙碌完清洗之事终于找回思考能力疑惑看休一眼：军情九处对你悄悄成为法官没产生怀疑？他们以为是当初指使我那个势力给报酬。说着自己打听到消息。拢头发露笑容：也是让他们找黑夜教会询问吧。随即捂嘴打哈欠：我要召唤那位信使了。经过这段时间记录口头上对某人称呼已从格尔曼·斯帕罗世界先生进化为那位。这一方面表示尊敬另一方面害怕有人窃听。听到好友话语休左右看一眼略显迷惑：不布置仪式吗？她记得召唤信使需要仪式。这只是其中一种方法那位让我用另外一种。看眼自身衣物发现昨晚没来得及更换已睡得皱巴巴。想到等会要见信使决定注意形象忙回到二楼卧室换套米黄色有荷叶边立领长裙。做好准备当着休面抬起右手向前抓一下似乎想从空气里薅出什么东西来。眼眸内一本虚幻书册随之凝聚成形飞快翻动停在其中一页。下一秒手臂一沉从虚空拖出一道人影。这是戴半高丝绸礼帽穿黑色呢制大衣面容冷峻气质刚硬略显呆滞格尔曼·斯帕罗。成功了？这才是我尝试第二次……我只是昨天试过一次还失败了……眼眸一下睁大似乎想容纳更多光看得更清楚一点。她知道召唤出来是历史孔隙影像所以此时不是太紧张反倒休下意识就屏住呼吸戒备看着格尔曼投影无法分辨是真是假。对这位疯狂冒险家战绩她记忆犹新。佛尔思竟然召唤出格尔曼？不应该是他信使吗？格尔曼还能作为召唤物降临？休脑海冒出一个又一个疑问。就在佛尔思不知道下一步该怎么做时那格尔曼眼眸微转目光一下变得灵动不再有呆板滞涩之意给人一种活过来感觉。紧接拿出一个通体银白精美口琴凑到嘴边吹一下。这没有声音传出但周围瞬间变得颇为阴冷刮起一阵阵刺骨之风。然后一位身穿阴沉繁复长裙提四个金发红眼脑袋女士从虚空走出来八只眼睛同时望向格尔曼。格尔曼微微点头指下佛尔思：这位女士需要去灵界深处布置四个特殊坐标您帮一下她。好……蕾妮特其中一个脑袋上下摆动说。格尔曼没再多说边靠近窗户边让左掌戴着手套变得透明。身影飞快消失传送出这栋房屋。走了……走了……我召唤历史孔隙影像就这样自己走了？嘴巴微张看着仿佛正经历一场滑稽剧。按她理解召唤出事物应该能被自己驱使才对怎么可以交待一句就自己离开。难道历史孔隙影像和本人一样有性格……不这简直就像格尔曼本人降临……看眼休发现她也一样迷茫。就这时突然打寒颤似乎某种极端可怕生物盯上。下意识转头发现格尔曼信使正用八只红色眼睛看着自己仔细打量。和格尔曼一样让人害怕……堆出笑容：……麻烦您了。这时蕾妮特四个金发红眼脑袋依次：需要……付钱……八百……金币……还还要收费？再次微张嘴巴不知道该怎么回应。过好几秒思绪才猛活跃起来盘算存款：借了2400镑给休之后原本还剩780镑……这段时间开销不小但之前小说版税陆续还有到账再加上其他一些收入和休还300镑共有1258镑……够了……当即就要开口答应可立刻发现一个问题：全要金币？四个脑袋微微摆动：对……你……可以……欠着……果然全要金币……记得世界先生有段时间一直尝试搜集金币兑换金币……也是为支付这位信使？他和自己信使关系好复杂……呃世界先生那里应该还有不少金币我之后找他换800枚就行了……暗自松口气：好的。答应下来后看见那位无头信使手中提着一个脑袋扬起来咬住自己肩膀处衣物。四周颜色随之变得浓郁鲜明红更红黑更黑白更白。就这样不辨东南西北上下左右被蕾妮特带着穿行于类似场景内没用多久就抵达似乎弥漫浅浅雾气地方。雾气深处一只只眼睛似乎望过去但又很快缩回去。……当魔术师将格尔曼投影从历史孔隙召唤到贝克兰德后克莱恩本体立刻进入历史迷雾一路狂奔到第一纪前。意识随之在那个投影内活过来减少佛尔思消耗。这样一来就间接回到贝克兰德这也正是他让魔术师用这种复杂办法召唤信使原因。至于用冒险家口琴召唤出信使属客观存在不会增大佛尔思灵性负担哪怕这历史孔隙影像消失蕾妮特如果自己愿意依旧能留现实世界。一次传送后身影出现在圣赛缪尔教堂附近僻静巷子并利用无面人能力改变容貌和身材。这过程中虽然巷子内还是有几位行人存在但都被幻术影响没能发现突然多一位同伴。紧接理衣物按帽子快步走向圣赛缪尔教堂于大祈祷厅内找个靠边位置坐下。摘掉礼帽诵念完尊名虔诚在胸口画绯红之月接着交握双手闭眼睛低声向黑夜女神祈祷：……我正在寻找乌黯魔狼过去痕迹以掌握祂具体情况……说到这里想起乌黯魔狼也许是黑夜女神前同事彼此间应该有足够了解忙又补一句：……不知道您是否能给予我一些启示……没去等待响应保持平和心态继续：……等完成这件事情我打算一直往东看是否能抵达西大陆看那里究竟处什么状态也趁这个机会跳出阿蒙追踪另外寻找可能……祈祷完毕又一次在胸口顺时针点四下低声：赞美女神。话音刚落眼前突然浮现一片点缀无数繁星深黑夜空脑海内则不知不觉多了一段信息。那是关于乌黯魔狼科塔尔信息。……怔一下直到眼前星空彻底消失才回过神真心诚意再次赞美女神。出了圣赛缪尔教堂利用蠕动饥饿又是一个传送来到位于乔伍德区圣风大教堂附近。他想向风暴之主也做一次祈祷。抬头望眼高耸尖塔一时有点犹豫不知要不要真进这风暴教会贝克兰德教区总部。我只是历史孔隙影像不怕……祈祷一下又不会损失什么万一风暴之主听说阿蒙情况决定将0-32赐给我呢？那样一来就不用冒极大风险狩猎乌黯魔狼了……做人总是要抱有点期待！思索片刻最终下定决心。谨慎抬手从历史孔隙招还未被阿蒙寄生过赢家恩尤尼出来让这个秘偶变成自己样子走入圣风大教堂。也就是一两分钟后贝克兰德上空突然飘来一片阴云圣风大教堂内则似乎有银白电光一闪而过但无人察觉。

# 519 旅行家 第三十八章 血之上将

## 打开书
「狩猎他们？」达尼兹下意识反问一句。等真正弄明白格尔曼意思瞬间变得兴奋改换坐姿压着嗓音道：「有什么需要我配合吗？」作为一名合格兼职海盗他与宽容怜悯仁爱等美好词语毫无关系既然差点死在钢铁麦维提手上又有机会报复回去那肯定不愿意错过！自认为能在海盗这行业生存下来靠是对形势准确把握知道什么时候该反抗什么时候该拼命什么时候该假装看不见仇人什么时候可以畅快清算旧账。而现在就是机会！格尔曼这个疯子究竟有多么强大还不敢下准确判断但从对方十秒内就解决堕落主教米勒这点看对付钢铁麦维提不会太困难即使遇上血之上将塞尼奥尔也不是没有赢希望。当然这是指一对一情况但海盗们从来不讲骑士精神…深有感受想着。克身体略微前倾双肘支在膝盖之上手掌交握道：「我说过了。」啊？什么？觉得自己常常跟不上格尔曼思路。对此只能安慰自己正常人和疯子是不同。见对方没再说话仔细想了想终于记起自己该做什么：写血之上将和他海盗团做过事情！嗯…格尔曼肯定是想了解他们劫掠过多少东西…迅速确定思路翻找出房间内纸笔刷刷刷写一大堆。这过程里分外庆幸伤是左臂。等他写好克伸手接过仔细阅读一遍从达尼兹没有详细阐述部分确认血之上将一伙确实是最典型最恶劣海盗不仅仅劫掠财物还掳走人口屠杀船员凌虐女性。达尼兹这海盗竟然懂得写古弗萨克语…也是受过教育啊…心里嘀咕两句掏出枚铜便士用占卜方法确认材料真实性。接着用吩咐明早吃什么语气道：「讲讲血之上将和他手下。」要详细资料…这是准备狩猎他们了？心头一喜只恨自己了解得还不够多：「血之上将塞尼奥尔疑似恶灵凡面对他的人都会离奇死亡或自己掐死自己或吞枪自尽或主动拥抱炸弹或屠杀同伴我们船长说这是恶灵附身。」很像莎伦小姐非凡能力啊…怨魂？没有说话沉默听着达尼兹往下述说。「塞尼奥尔能发出很可怕尖叫上次和他们战斗时我差点被弄得晕过去从甲板掉到海里呵呵我还了回去点燃了他们一艘船。塞尼奥尔懂不少死灵类魔法残忍嗜血欲望旺盛目标是男是女甚至类人形生物都行。」符合玫瑰学派放纵特性嗯准确说是囚犯这途径某方面特性…大概率是怨魂…若有所思点下头。得到回应达尼兹更加积极语速变快少许：「我们船长认为塞尼奥尔身上有一件很厉害神奇物品这让他变得相当走运总是能得到神灵眷顾比如关键时刻对手突然滑倒或者能力失效比如赌博连赢21把。」能让人幸运神奇物品？这很罕见啊…源于怪物途径？或者与哪位邪灵有了关联？根据自己了解神秘学知识做着猜测。「我没有和塞尼奥尔直接交过手知道只有这么多。」本想摊手却被左臂疼痛及时阻止「他有大概七八艘船旗舰是血肉之树号呵呵这和我们不同我们主要是追逐宝藏不会滥收手下只有黄金梦想号一艘船。」难怪血之上将在赏金上比冰山中将多不少达到42000镑…实力上应该也要强一点…顿时有些恍然。保持着刚才姿势不变似乎未受血之上将情报影响：「手下呢？」达尼兹早有准备当即说：「塞尼奥尔手下最强有十个人旗舰大副二副三副和每艘船船长…钢铁麦维提是旗舰二副我们猜测有序列6身体如同钢铁能硬挡子弹和炮弹不怕火烧不怕溺水不怕多种魔法力量强大动作迅捷能直接撕裂对手掌握了一定死灵类法术可以唤醒活尸培养傀儡…」活尸？直接就联想到那位和活尸打牌马里奇。结合血之上将塞尼奥尔怨魂特点是否可以认为这伙海盗其实是玫瑰学派外围组织或者说用来赚钱组织？可惜没有信使也没问莎伦小姐有没有否则可以联系她确认血之上将身份…略感遗憾猜测着。并没有因为这可能涉及玫瑰学派就放弃反正事后可以变张脸换个身份而且极光会魔女教派救赎蔷薇黄昏隐士会都招惹了也不怕再多得罪一个。其实我也不是没对抗过玫瑰学派之前已经杀了一个怨魂一个活尸一个狼人抢了深红月冕和生物毒素瓶…忽然发现自己惹过事真的蛮多。麦维提应该没有特别厉害神奇物品否则我之前很可能逃不掉。达尼兹颇感庆幸说「他身边有一群傀儡和活尸还带着几位序列7序列8手下作为旗舰二副既然他在这里就应该是附近人员首领我们可以考虑先狩猎他。」在高序列以下非凡者人数一多是会产生质变不同能力配合足以让他们击败比本身强非凡者就像一支值夜者小队绝对能拿下一位序列6甚至序列5一样…并没有因为得到蠕动饥饿实力大增就轻视钢铁麦维提和他手下依旧如往常一样谨慎。必须谋划好行动做足准备嗯从白鲨那里得到波段和密码可以派上用场了等魔术师小姐无线电收报机送到就让达尼兹日常监听看能否获得相应情报让我抓住快速收割机会…而我趁这空隙寻觅下真实扮演可能…很快有了腹案继续听着达尼兹讲述血之上将其他手下情报。好一阵子达尼兹终于说完兴致颇高总结：「如果能杀掉钢铁麦维提并留下我名字这件事情肯定会上报纸传扬出去我就不用发愁怎么通知船长了！」他害怕内部出了叛徒整个罗思德群岛联络点都已经被敌人控制住不敢贸然联系正烦恼如何让船长警觉问题。还是很有想法嘛…点点头道：「你负责搜集钢铁各方面情报。」「好！」想到傍晚那差点穿透自己心脏一拳笑容略显狰狞回应。克则缓缓起身走到窗口只见外面天色黑沉大风呼啸雨水滂湃就仿佛末日已经来临。想到接下来要做事情不由有了另一种意义上扮演感微笑着低沉着自语一句：「今夜格尔曼加入狩猎。」……慷慨之城拜亚姆海浪教堂内。拿到血族麻醉气体阿尔杰正准备扬帆出海获取风眷者另一件主材料结果却被本地教区主教召唤过来。「最近有流传一个消息说是冰山中将得到了死神钥匙整个苏尼亚海海盗都沸腾了。」教区主教沉声说「你追查下这件事情。」这是位头发已经花白老者但精神依旧矍铄语速比年轻人还快似乎随时会冲出去亲自解决一切问题。身材健壮肌肉撑起主教袍呼吸间周围风声鼓荡空气湿润。每年都有类似传闻结果都是假的…海上总是喜欢流传这样消息…而且就算是真我也没资格掺和没必要因此冒险在外围打听下就行了…心中嘀咕两句。庄重握拳击打下左胸：「好的乔戈里阁下！风暴与你同在！」教区主教乔戈里对阿尔杰态度很满意回以相同礼仪：「风暴与你同在！」得到勉励阿尔杰很快离开教堂回到外面广场。昨晚暴风雨已经平息只有地面零散叶子和或大或小水渍证明它们来过。呼吸口雨后新鲜空气决定先去几个可能有海盗地方转转打听打听消息做出努力样子。如果能遇上赏金几百镑家伙他不介意做一次抓捕在他看来这就是流动储备金钱。

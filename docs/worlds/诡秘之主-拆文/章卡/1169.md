# 1169 逐光者 第二十章 仪式

## 打开书
贝克兰德北区。刚安排好直属小队任务的伦纳德看见无边灰雾听到愚者先生回应。长长舒口气压低嗓音：看来没什么问题了。既然愚者能像正常一样给予反馈召集塔罗聚会那就表明祂已在与阿蒙对抗中胜出。这样一来克莱恩应该也能摆脱困境。脑海帕列斯略显苍老嗓音呵一声：不要高兴得这么早你进入源堡后观察一下那位愚者看祂右眼有没有戴上单片眼镜。你你是说现在的愚者有可能是阿蒙假扮的？眼皮一跳连忙问。帕列斯叹气：不排除这个可能阿蒙真能做出这种事情来。……我会注意的。已放松心态瞬间又紧绷。……未来号上。愚者先生竟然隔了这么久才回应……这是否说明世界格尔曼失踪与祂想谋划事有关？不能肯定也许愚者未做回应这段时间就是在拯救格尔曼而现在祂成功了……祂没直接提这事是打算让世界自己在塔罗会上讲述？耳畔响起愚者声音后星之上将嘉德丽雅脑海瞬间闪过一个又一个想法。借助女王来信内容她怀疑乔治三世陨落离不开愚者插手世界之前失踪也是此事延续。第一反应就是写信给神秘女王贝尔纳黛告诉她格尔曼找到了可想了想又按捺住性子准备参加完下午聚会了解具体经过弄清楚哪些能讲哪些不能讲再反馈给女王。不管怎么样事情似乎解决了。呼口气安心坐到窗边眺望湛蓝天空。……苏尼亚岛原始森林边缘。阿尔杰立在一根细细树枝上眺望不远处港口和那里蓝天。周围狂风缭绕却又没发散开来影响旁边树木。虚幻灰白雾气呈现中先是一喜旋即有些惶恐：愚者隔了一段时间才回应……说明祂之前状态确实有点不正常。不过祂现在已恢复过来……祂没回应我向太阳借取无暗十字祈求是发现了我试探发现了我潜藏那一点心思……以后不能再做这种事情了！愚者这次只是简单做了个警告下一次很可能就会直接给予惩罚。不可试探神不可试探神。思绪电转低下脑袋虔诚：感谢您的仁慈和宽容。……霍尔伯爵家豪华别墅。愚者没将我疑问转达给世界先生呀……这是因为下午塔罗会将正常进行到时候有交流时间？奥黛丽从反馈有所延迟这点分析出一些问题：正常来说愚者回复都很及时这次超过一刻钟……祂在处理别的事情非常重要事情？乔治三世之死相关？不管怎么说一刻钟延迟并不算太严重问题迅速收回思绪心情变好不少：等会就能从世界先生那里知道真相了。希望这次事件除引发全面战争不会再有更加严重后果而战争是目前无法避免的……圣赛缪尔教堂地底。愚者先生没说会帮助我……埃姆林拿着一杯红色液体眉头微皱。旋即从另外角度解读本次回应象征意义：愚者专门强调下午塔罗会照常进行是想告诉我脱离困境机会在某位成员身上？不会还是那个星星吧？呃总之我这周应该就能离开这里。——因被保护性关押查尼斯门后不管贝克兰德郊外出什么变故都不太可能影响他而他也不可能突然成功越狱前往有血皇帝遗迹地方所以克莱恩上周周中暗示其他成员时遗漏了他。……白银城伯格家。听到愚者回应后戴里克一下从床上翻起来激动神情溢于言表。愚者没有消失！愚者没有像造物主那样抛弃白银城！来回踱几步立刻就要冲出房间前往双塔所在将好消息告诉首席。但一年多成长还是给他打上鲜明烙印最终冷静下来决定参加完塔罗聚会得到祝福许诺再去寻找首席。也许这段时间不回应是愚者对我对首席对白银城考验看我们是否会迅速倒向堕落造物主……不知从什么时候开始思绪模式就带上几分倒吊人色彩。当然没因此出现多余想法在认知里神灵考验信徒再正常不过当初造物主就留下不少类似传说。结束思考还是坐不住依旧房间里来回踱步。前所未有期待起下午塔罗会。——在白银城在神弃下午是相对抽象概念因为没有足够标识确定只能勉强以闪电多寡定义白天黑夜无法做更进一步细分。……东区两居室。哈。佛尔思得到愚者回应后忍不住笑出声音。作为畅销小说作家有丰富想象力在愚者未做响应这段时间已于脑海里编织一个又一个可怕故事：愚者以自己陨落换取乔治三世失败；愚者谋划被诸神发现惨遭围攻；愚者旧伤复发重新陷入沉睡世界格尔曼无人眷顾正被仇敌追杀……这些故事发展并不相同但结尾却非常一致那就是自己重陷满月呓语失控成了怪物。呼……吐口气笑容满面对休：我今天才发现愚者先生是我心中最重要那个男人呃那个祂。更重要是你要尽快成为半神彻底摆脱满月诅咒。休认真回应。加入塔罗会后已知晓好友真实境况。嗯！点头笑容不变：总之我现在得喝杯酒庆祝一下！……灰雾之上源堡内部。平静下来借助冥想恢灵体状态。初学冥想时需要想象一种这世界上不存在东西替换掉原本脑海内事物以此真正进入冥想那个时候第一反应勾勒地球上洲际弹道导弹结果没能成功……呵呵当时没多想现在看来这也许已说明一些问题……那并非这世界上不存在东西只是已经湮灭在历史迷雾里……揉额角自然回忆往事。随即收敛精神打算在塔罗会前将奇迹师魔药配方拿到手。——此时阿蒙正耐心守着他死去地方他只能待源堡内没别事情可做。考虑一下方法往古老宫殿外一抓以居高临下姿态从灰白雾气里历史孔隙中拿出一件物品。那是一本封皮由硬纸制成完全染成黑色笔记。安提哥努斯家族笔记！果然可以……它不是唯一性衍化只是有安提哥努斯家族那半个愚者一点力量残留……感叹一声将笔记丢到面前青铜长桌。因这本笔记内容很可能有问题并不打算从上面解读序列2奇迹师魔药配方只是以此做占卜媒介。紧接具现纸笔写下一条占卜语句：这本笔记最初的主人。放好钢笔拿起纸张和笔记后靠椅背低声重复刚才写下话语。一连七遍后进入灰蒙蒙梦境看见一座伸入白云山峰看见位于山峰顶部与现实隔着透明界限破败不堪巍峨宫殿。那宫殿内不少地方长着青苔和杂草最上首安放一张巨大石头座椅表面镶嵌黯淡宝石和黄金中央有无数透明蠕虫抱成一团缓慢扭动肆意滋长延伸出一条条布满花纹滑腻触手。与以往不同这一次直接看到那怪物看清楚了祂具体样子。骤然间灰雾之上宫殿出现剧烈摇晃身影直直往上被悬吊半空。下一秒灵体崩溃成一条条蠕动灵之虫在地上到处乱爬。源堡随即发生震荡一切归于原状灵体也重新凝聚出来。坐愚者位置揉额角苦笑一声：真是有唯一性的半个愚者……自语完略作回忆拿起钢笔在纸上记录起刚才窥视神话生物得到知识：序列2：奇迹师。主要材料：乌黯魔狼（愿望之神）的心脏一颗或者别的奇迹师非凡特性。辅助材料：乌黯魔狼血液三百毫升时之虫一条星之虫一条。晋升仪式：让一段遗落的历史重回当前时代。

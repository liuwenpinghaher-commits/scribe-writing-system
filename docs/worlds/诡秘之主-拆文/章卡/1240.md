# 1240 逐光者 第九十一章 灯神

## 打开书
那灯芯散发出光芒异常粘稠就如同融入不少糖分水流它们喷涌往上汇聚成一道扭曲而模糊淡金人影。这人影瞬间占据满代表隐者那颗深红星辰让克莱恩一时失去对星之上将嘉德丽雅感应。坐于青铜长桌最上方克莱恩眼眸骤然睁大脑海内下意识就闪过一个念头：不愧是编号0-05封印物！虽然0级封印物编号往往依照它们被正神教会掌握或了解时间顺序但要知道这套命名规则正式成形是在七大教会真正统治这个世界后也就是第四纪末到第五纪初。当时绝大部分0级封印物已经出现且被正神教会们知晓或得到！这就造成一种情况初次排序时会把更厉害更恐怖更匪夷所思0级封印物往前面放然后于同一层次里按照出现时间顺序编号。另外虽然没有越古老物品就越强大这种说法但能从古神都无法溯及第一纪存留下来物品必然有着连神灵都无法完全弄清楚秘密。这样一来编号越靠前0级封印物越可怕在某种程度上也是成立。当然基于这种规则0级封印物里编号在末尾那些未必比前10差也许单纯只是因为被发现迟或者被教会得到晚前面没有空余编号留给它们只能按照正常顺序依次排列。就在克莱恩闪过那么一个念头之际那金色人影目光穿透代表隐者深红星辰投向灰雾之上古老宫殿。随即他嗓音异常恢弘回荡起来：好久不见。好久不见？好久不见！他他认识源堡前主人那位福生玄黄天尊？不应该是祂那位自称永恒灯神……祂竟然可以借助隐者女士祷告直接和我对话……克莱恩瞬间思绪电转精神骤然紧绷。基于这些年经验依靠着小丑能力他身体猛地放松下来悠然靠住椅背。紧接着克莱恩张开嘴巴给予回应：呵。他未做肯定答复也没申辩自己是假只是表现出一种轻蔑自然居高临下态度。那扭曲模糊金色人影哼一声：你竟然虚弱到这种程度难怪这几千年来我都没再听见你尊名流传。尊名……虚弱……祂真认识源堡前主人啊……那是活跃于第一纪存在？想法纷呈间克莱恩笑：你看见未必是真相。哈哈。那扭曲模糊金色人影笑两声：你还是一样喜欢欺诈但源堡状态是没法骗过我正常情况下我根本没法穿透外层保护这样和你交谈。你怎么知道这不是我故意表现出来？克莱恩表面放松反问。你欺诈我没有任何意义。扭曲模糊金色灯神当即回应。……怎么有种诈骗受害者在说我已经一无所有连肾都卖掉感觉……当初源堡前主人疑似福生玄黄天尊那位存在究竟对灯神做过什么……嗯组成这盏许愿神灯部分特性属于奇迹师……克莱恩用吐槽缓解着内心压力然后笑：有没有意义不是由你来定义。灯神金色模糊身影略微晃动一下：从源堡现在状态看你对一份奇迹师非凡特性似乎有需求。祂没再纠缠刚才那个话题转而直指自己观察到情况。……这家伙竟然能看出这件事情……祂位格真很高……祂能自行分离出许愿神灯内奇迹师非凡特性？克莱恩眸光微凝险些失态。他随即控制住自身动作和表情含笑回应：你认为是那就是。模糊扭曲金色人影再次让恢弘高渺嗓音回荡在灰雾之上：我们可以做一笔交易。你解除我封印让我回归自由我将奇迹师非凡特性留给你只带走属于自己那部分。至于见证就用自身源质虽然你和我都有办法对抗反噬降低毁约带来伤害但不会完全没有代价需要考虑一下后果。我保证不再停留于这里。封印……源质……许愿神灯可怕本质是里面封印着一个至少真神层次存在？克莱恩心中一动快速分析一下事情可行性。很快他有决断那就是不受蛊惑！这有两方面原因一是他并非真正源堡前主人能做到事情有限能承受意外也有限二是他在值夜者队伍接受神秘学教育和后来种种经历都告诉他不要和未知存在做交易不要抱任何侥幸心理！主意一定克莱恩平静不少将重点放在怎么套取更多情报上。——灯神疑似来自最黑暗最混乱也最神秘第一纪知道肯定不少！想了想克莱恩嘴角微勾：你觉得这样条件就能打动我？他打算看一看灯神能给出筹码最高能到什么程度从而窥探祂某些秘密。听到这句话灯火一样晃动金色人影眸光突然变亮真正意义上变亮！祂目光仿佛直接落在克莱恩身上恢弘嗓音如雷鸣般摇晃古老宫殿：你不是祂！你不是祂……这个瞬间克莱恩有点呆住又有点惊恐就像在做一场盛大魔术表演时忽然被观众指出具体手法。他不知道自己刚才那句反问究竟有什么不对也不清楚具体出什么问题以至于难以在短时间内分析利弊给出最符合当前场景反应。……祂怎么一下发现我不是源堡前主人疑似福生玄黄天尊那位存在……我那句话不是很合理反问吗？既然要谈交易就得允许讨价还价啊……灯神认识源堡前主人不是这样？不可能一个擅于欺诈存在怎么会直接给出自身筹码连商谈和施压都不做？糟糕我想太多时间已过去近十秒……没有及时回应就等于直接承认灯神指控……在被戳穿方面克莱恩经验不是太多没能第一时间想到该说话语。就在他提高警惕预备拿出星之杖调动源堡力量对抗灯神可能做出隔空袭击时那金色而模糊人影忽然笑起来：哈哈哈哈哈哈哈哈哈。这笑声就如同在搅动灵魂让源堡内克莱恩都险些出现失控征兆好不容易才不露痕迹稳住状态。没有攻击意图只是自然散逸影响……灯神在笑什么？这有什么好笑？克莱恩微皱眉头想到一个又一个可能但都觉得不符合实际。过几秒灯神笑声停下来语气愉快：即使对我们这个层次存在而言命运也依旧奇妙。无论你究竟是谁我刚才提议交易都有效只要你能解除封印放我出来我将带着属于我那一部分回归星空剩下包括那份奇迹师非凡特性在内都留给你另外我还会满足你三个愿望。怎么样这应该已经足够丰厚吧？星空……克莱恩听得眼皮一跳敏锐察觉到某种危险。这是源自灵性直觉警示。他原本想着可以假意答应套取更多情报然后依靠源堡赖账但现在忽然觉得不能做出承诺！于是克莱恩当机立断：离开吧。说话间他切断自身与代表隐者那颗深红星辰间联系。那模糊而扭曲金色人影骤然膨胀旋即消散只余声音隐隐回荡：你终究会答应！等到灰雾之上彻底恢复平静克莱恩才缓慢吐口气无声自语：灯神是来自星空强大生物在第一纪或者更早被封印在神灯内？封印祂也许就是源堡前主人疑似福生玄黄天尊那位存在这从许愿神灯组成材料有奇迹师非凡特性可以推测一二……所以灯神才会在我反问时察觉到我不是源堡前主人？可我有考虑到这点啊那么问从逻辑上来说没任何问题除非当初灯神和源堡前主人在这件事情上是存在某些默契或者某些秘密……灯神本身力量应该没法透出封印太多但可以利用组成封印非凡特性……许愿这个特点大概率就来自奇迹师部分然后灯神用自己位格做放大……思绪纷呈间克莱恩抬头看眼代表隐者那颗深红星辰发现星之上将嘉德丽雅对许愿神灯刚才出现异动毫无察觉。呼……克莱恩将自身想做提醒捏成一道流光丢入那颗深红色星辰。

翻了。开头灯神占星寒暄认天尊；中段交易诱饵＋「你不是祂」戳穿；章末拒诺切断、灯神扬言终究会答应。翻的是装前主人翻成被识破仍拒星空交易，不是呵一声厉不厉。

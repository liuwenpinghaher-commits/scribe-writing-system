# 1387 倒吊人 第三十五章 临时的聚会

## 打开书
黑夜女神点点头没再多说什么向前探出手掌捏住虚空一角般轻扯一下。一层薄薄夜幕轻柔飘落覆盖到克莱恩身上无声无息渗透进去。克莱恩静静感受两秒这源于梦境祝福以手按胸弯腰行一礼。他旋即后退两步离开星界。黑夜女神立于神国边缘目送他远去。下一秒克莱恩落到神战遗迹巨人王庭投影内。……通过这扇门克莱恩进入神弃之地依循命运指引直接漫游到一座山脉峰顶。……与此同时无需值守源堡灵之虫们将神秘女王当前定位告诉自己克莱恩抬手从杂物堆里取出许愿神灯依靠它和贝尔纳黛间权属关系又是一个漫游出现在一座相当隐蔽岛屿上出现在翡翠城中。贝尔纳黛正在那里翻看一本因蒂斯最新出版画集刚有察觉到什么就看见格尔曼·斯帕罗将许愿神灯递给自己。谢谢。克莱恩嗓音不高不低很是正常说道。贝尔纳黛轻启嘴唇仿佛想说点什么但这个刹那她眸光一闪似乎又看见点什么预言到点什么于是沉默伸手接住许愿神灯。……这是报酬。贝尔纳黛哪怕不用窥秘之眼也能感觉得到这铁制卷烟盒不凡大概能猜出它遭受过什么侵蚀。……如果还处于之前那种较疯狂状态中克莱恩肯定会在贝尔纳黛迟疑瞬间笑容浮夸说道：叔叔给你你就接着！……离开贝尔纳黛翡翠城后克莱恩抓紧时间漫游到贝克兰德漫游到艾伦·克瑞斯医生家中。……我终于感觉到那个契机。容纳命运途径唯一性契机。……我正是来帮你容纳。我会偷走你童年和少年让你瞬间成长起来然后依靠超越序列但又未到旧日位格帮你强行容纳概率之骰。当然仅这样是没法成功还需要一次愚弄和一次对Bug利用。……原来那两个选择是一样。……威尔·昂赛汀这条命运之蛇很显然没有自带唯一性只能在后面两个选项里考虑。……你现在就让生命学派半神将概率之骰送过来吧正常来说这个时候以你幸运概率之骰应该就在你身边。克莱恩无视威尔痛哭尽快开始吧我没有多少时间了。……算了等下个契机吧。以你现在状态强行帮我容纳是很大负担说不定当场就失控了我可不想面对那位诡秘之主。嗯下次吧我预感到……我预感到下次契机会更好。……这是一个预言？……不这是一个祝福。……他回到源堡内坐至那张高背椅上任由体表覆盖上灰白雾气。……这一次他没再制造世界这个假人。斑驳长桌两侧一道道深红光芒同时腾起定格成倒吊人太阳隐者魔术师等塔罗会成员。这突如其来召集明显出乎正义奥黛丽等人预料让他们一时都有些错愕和惊讶。在此之前虽然他们也在非周一下午时间段来过愚者先生神国但那都是事出有因提前就已经知道会被拉入这里——那要么是预先申请小型聚会要么是躲避满月呓语或者给世界先生治疗心理问题。可以这么说除最初那次这是他们第二次在毫无征兆情况下被愚者先生召集。……再联想到之前世界格尔曼·斯帕罗拜访联想到这位愚者先生眷者说那些话语正义奥黛丽倒吊人阿尔杰审判休都同时闪过类似想法：终于到来了吗？……在她心里世界格尔曼·斯帕罗形象早就从疯狂冒险家极度危险非凡者变成一个外表冷硬内心温柔实力强大富有爱心来历神秘相当孤独背负着很多事情朋友。她自认为在塔罗会里除星星先生自己应该是最了解世界那个。……克莱恩去哪里了……星星伦纳德突然有些慌乱。……老头最近沉默得有些诡异……克莱恩不会真出什么事情吧？以愚者先生层次和位格只要还有机会应该都能挽救得回来……伦纳德心中一紧猛地侧身将目光投向斑驳长桌最上首愚者先生。……这个时候月亮埃姆林隐者嘉德丽雅和太阳戴里克他们也发现世界先生缺席。……作为刚晋升没多久预言大师嘉德丽雅甚至觉得愚者先生也出一定问题。世界先生没来……之前休提过愚者先生和祂眷者们似乎将面对重大挑战很有可能遭受不好事情……魔术师佛尔思同样有些惊慌不可避免因未知变化产生强烈恐惧。她曾经以为自己会因世界先生消失松一口气可现在看来并不是这样她反倒觉得心里沉甸甸有些惶恐。她这才发现不知什么时候世界已成为愚者先生外塔罗会一大支柱让大家看到他就觉得安心。……随着正义奥黛丽等人转过身体看向斑驳长桌最上首已是真正愚者克莱恩嗓音低平说道：这是一次临时聚会。愚者先生很疲惫……察觉到这一点正义奥黛丽内心愈发紧绷。……下午好愚者先生。

## 这场戏有没有翻
翻了。开头夜幕祝福；还灯＋烟盒酬贝尔；威尔拒强容给祝福；源堡召塔罗无「世界」假人；众人觉「终于到」；章末「这是一次临时的聚会」。翻的是临时聚会＝沉眠前召集开。

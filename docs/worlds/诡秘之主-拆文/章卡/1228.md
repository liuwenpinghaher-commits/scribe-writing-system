# 1228 逐光者 第七十九章 集思广益

## 打开书
见魔术师小姐还未完全反应过来克莱恩又让假人世界补一句：你不需要到现场提前召唤出我历史投影就行。……好！魔术师佛尔思忙不迭点头。此时因为格尔曼·斯帕罗接下自己任务月亮埃姆林明显放松下来。在他认知里这就意味着事情成功概率直线上扬。下一秒钟世界格尔曼·斯帕罗望向他嗓音嘶哑问：你能支付什么样报酬？月亮埃姆林默然两秒目光略微上飘：等我成为巫王一次类似事情上无偿帮助承诺。还有战利品我只要巫王非凡特性玫瑰学派节制系人应该也有明确目标剩下都归你。月亮先生很心虚没什么底气呀……正义奥黛丽通过对方动作和话语得出确定结论。埃姆林这家伙也学别人贷款消费了啊……克莱恩暗笑一声让假人世界淡漠回应：看起来你只请得起我这一位半神。如果月亮先生能提供大量粮食我不介意参与……正义奥黛丽随之在心里咕哝一句。不过她无需开口就能知道月亮先生会做出怎样回答：我们血族为什么要囤积那么多零食？——对血族而言主食是灵性充沛人类血液面包和肉制品等食物都属于非必需品。见世界格尔曼·斯帕罗没有拒绝自己开出条件月亮埃姆林暗中松口气：你还有什么要求我尽量满足。格尔曼·斯帕罗想了想：提供一件能短时间内大幅度增强持有者灵性神奇物品或者封印物。这是借给魔术师小姐让她能多维持几分钟召唤来历史孔隙影像而月亮领域毫无疑问是有这方面非凡能力比如深红学者可以制造满月状态让灵性滋生让灵感增强。呼……月亮埃姆林快速点头：好没问题。见一人一吸血鬼已达成协议魔术师佛尔思赶紧举手：不要满月。那样别说增强灵性了不当场暴毙就算她运气不错毕竟序列越高听见门先生呓语效果就越好而佛尔思早就从序列6记录官晋升为序列5旅行家。埃姆林也是知道魔术师小姐满月诅咒事情对此没有疑问嗯一声表示自己会注意。这时旁听完整笔交易倒吊人阿尔杰思索着开口：虽然玫瑰学派放纵系那些非凡者容易被自身情绪和本能控制但这不表示他们脑子已经随着活尸化消失就算真消失他们内部也是有月亮领域非凡者。既然他们半神直接参与南大陆战争暴露本身位置那就不会不考虑到血族节制系等敌人暗中袭击我认为藏着陷阱可能不小。对。星星伦纳德附和：多份卷宗显示玫瑰学派放纵系非凡者虽然以血腥残忍纵欲闻名但在做事上还是很有规划会体现出一定狡诈和阴险。审判休看好友一眼跟着：我两个月前遇到一起涉及玫瑰学派超凡事件目标明显有受到欺骗踩中陷阱。世界格尔曼·斯帕罗专注听完笑一声转而对月亮埃姆林：你目标是哪位巫王？埃姆林未做隐瞒：在东拜朗北奥利特邦率领当地土著围攻鲁恩主要殖民城市那个巫王。听到这句话克莱恩莫名闪过一个念头：欲望母树似乎也不想看见女神掌握死神途径唯一性祂在驱使土著利用战争动摇黑夜教会在南大陆传教基础。念头电转间克莱恩让世界格尔曼·斯帕罗看着月亮埃姆林低笑：那我目标将是另外一位巫王这和你们行动无关。无需他说得太直白月亮埃姆林和隐者嘉德丽雅等人都迅速明白他计划。这是一个简单计划：格尔曼·斯帕罗狩猎另外一位巫王主动踩中陷阱将玫瑰学派埋伏力量吸引过去而这个时候月亮和玫瑰学派节制系人抓住机会围攻真正目标。这会不会太危险？月亮埃姆林下意识回一句。危险当然是指引爆陷阱格尔曼·斯帕罗危险。世界格尔曼·斯帕罗非常平静回应：那只是一个历史投影。死了也就死了……听到这样回答月亮埃姆林星星伦纳德等塔罗会成员都有点不知该以什么样表情来应对也不知是该感慨序列3半神就是不一样还是羡慕古代学者有这种非凡能力。克莱恩则继续让假人世界：如果玫瑰学派对我突然袭击有怀疑只分出一部分力量来阻止依旧保留较为完整陷阱那我会试着强行狩猎那位巫王将虚假目标变成真实目标反正你们只是想要相应物品并不在意原主是谁。简单但有效计划……关键点就在于格尔曼·斯帕罗必须有超出限度实力哪怕面对天使也能反抗……正义奥黛丽认真做着学习并在内心评价两句。月亮埃姆林不再有疑惑思考一下：在正式行动前有必要和玫瑰学派节制系人见一次面敲定细节。世界格尔曼·斯帕罗点头：你来安排。这件事情交流结束后克莱恩让假人世界具现出一叠纸分发给塔罗会众位成员：我和某些存在将对付一个神话生物你们可以提提意见说说想法。那张纸上写着乌黯魔狼科塔尔性格和具体行为以及正义小姐据此作出各种分析。克莱恩希望通过不同性格不同见识人提供不同意见来寻找灵感。神话生物……世界目标已经瞄准神话生物了？比往常沉默不少倒吊人阿尔杰忍不住抬头看青铜长桌最下方一眼。虽然他对此已有一定心理准备觉得哪怕世界格尔曼·斯帕罗突然自称天使也不会让自己惊讶但发现对方真将神话生物作为狩猎目标后还是难免有点错愕有些震动。隐者嘉德丽雅也有类似感受但她旋即想起那条命运之蛇想起死亡执政官想起古代邪物。这与世界格尔曼·斯帕罗话语里某些存在吻合。三大天使加一位序列3神灵眷者狩猎一个神话生物是非常正常事情！一道道目光随即从斑驳长桌最下方收回来认真阅读起手中资料。这一刻因为不涉及委托不牵扯交易也不算信息分享塔罗会成员们莫名有种共同为一件事情努力感觉有松散聚会开始像一个组织感受。看完纸张上书写内容倒吊人阿尔杰率先开口：按照正义小姐做出分析任何诱饵都不会让那个多疑神话生物上钩只会让祂躲得更远。在疑似拿着序列1非凡特性情况下祂确实没必要追逐其他提升自己才是最重要如果要对付祂只能从这方面考虑。听到这里审判休从自己专业出发：可这个神话生物非常谨慎没有留下一点线索而情报显示祂准备序列1仪式地点在神弃之地那种环境下其实是不受限制。对有太多怪物供祂使用。太阳戴里克确认审判小姐说法。场面顿时显得沉闷星星伦纳德想一下：是否可以依靠非凡特性聚合定律？他边说边看向克莱恩·莫雷蒂：那个神话生物似乎和你在同一条途径。单纯依靠这种层次非凡特性聚合能力想通过偶遇来找到那个神话生物也许得一年两年甚至更久而且对方是完整神话生物有能力对此做一定干扰。克莱恩否定伦纳德建议。当然他如果将源堡聚合能力也附加到自己身上说不定下一次用星之杖随机转移就能直接碰到乌黯魔狼但问题在于那样一来偶遇阿蒙本体概率会更大大很多这就是标准送货上门。隐者嘉德丽雅听完大家讨论根据女王忌讳思索着：是否可以利用这个神话生物尊名来建立联系？如果乌黯魔狼没被阿蒙追踪过这未必不行但现在嘛该想到阿蒙肯定能想到这种情况下乌黯魔狼还没陨落就说明祂必然有提防这方面事情……世界格尔曼·斯帕罗缓慢摇头：以祂多疑性格肯定不会做自动响应。话音刚落克莱恩突然产生一个灵感：乌黯魔狼不做回应不表示祂不会关注相应祈祷光点！

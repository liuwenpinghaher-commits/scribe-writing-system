# 1336 倒吊人 第七十一章 连锁反应

## 打开书
这一刻文德尔只觉自己小腿肚在轻轻颤动仿佛已无法支撑身体重量。离开乌托邦后他有预想过最坏结果是什么样子那就是某天突然暴毙没有原因。可是他怎么都没料到自己还会遇见来自乌托邦人在贝克兰德这现实中大都市里。而更为重要是来客还邀请他再去乌托邦。……我最近有很多事情……开庭在两周之后这是相关文书。……这关系到一位女士未来我真诚希望你能出庭作证。看情况……文德尔既不想答应也不敢拒绝。……我会在乌托邦等你希望能有机会再见。……赶紧赶紧将这件事情汇报上去！抓住那个来自乌托邦警察弄清楚这诡异城镇真实情况找出合适办法彻底解决问题！文德尔回过神后强行打起精神准备通知暗中监控自己军情九处人员。……两周之后如果我没去乌托邦出庭作证会发生什么事情？……这也是仪式要求？这些居民真实身份又是什么愚者先生信徒世界格尔曼·斯帕罗同伴？休在问清楚乌托邦来客大致模样之后因为缺乏更进一步情报只好先行返回军情九处总部犹豫着要不要派属下做大范围搜寻。她不确定世界先生是否乐意看见这样行为也担心会影响到那个仪式。在办公室内来回踱几步后休准备向愚者先生祷告请祂将自己疑问转给世界格尔曼·斯帕罗。……请进。休犹豫下道。……上校文德尔遇见来自乌托邦人他直接上门拜访了！洛克语序有些混乱说道。……他为什么要拜访你？他请我去乌托邦出庭作证为我报告里提及翠西杀人案。比起之前文德尔已明显冷静不少。……他是一名警察叫拜尔斯我没敢问他住哪里准备什么时候离开打算乘哪个车次蒸汽列车。……洛克立刻召集你小队成员寻找经常在文德尔住处周围等待客人出租马车车夫以及经过附近区域公共马车车夫询问他们是否见过拜尔斯如果见过将对方载到哪里还有派人到蒸汽列车站等待在入口观察来往乘客……你配合他们将拜尔斯样子画出来。……很快她得到愚者先生回应看见在灰雾中祈祷世界格尔曼·斯帕罗。……可以正常做调查。必要时候可以提出仪式这个猜测但必须包含在几个选项里。……我们找到搭载那个乌托邦人出租马车车夫！……那个叫做拜尔斯乌托邦人原本是让车夫去码头区但马车刚进入相应区域他就要求下车说是已经到了。那条街道对车夫来说相当陌生让他有种迷路感觉。等到离开那条街道他又发现周围变得熟悉了。我们人有陪他再次前往那里但他怎么都找不到那条街道了。……和之前案例里进出乌托邦相关描述初步吻合。上校你意思是能在任何一个城市任何一条街道进入或离开乌托邦？洛克还是有点不敢相信。……目前看来是这样但我总觉得有点问题嗯……乌托邦是怎么与不同地方连通是依靠什么来定位……去告诉文德尔之后两周他将在这里度过直到那份文书过期。……那是一片深黑没有月亮也没有星星夜空。

# 1217 逐光者 第六十八章 线索

## 打开书
你们也试试。克莱恩将手里铁黑色长签递向别的月城居民。那些人喉咙蠕动一下忍不住又吞口唾液但没立刻做出回应纷纷将目光投向大祭司尼姆等待他点头。尼姆从裹在身上兽皮衣物内拿出一件物品那似乎是一个有柄放大镜。乍眼望去克莱恩差点看成单片眼镜吓得心脏都停一拍还好及时控制住自己确认细节。尼姆握着金属细柄将那玻璃制品凑至右眼前方隔着镜片审视鲁斯几秒。短暂静默后他放下这件物品对其余月城居民轻轻点头。鲁斯之外人们终于伸手小心翼翼很有秩序分别从铁黑长签上取下一个蘑菇将它塞入口中。那不含一点恶心异味和污秽之意口感让他们瞬间陶醉顾不得烫伤口腔三两下就将蘑菇吞进肚子里并本能伸手想要再来一个。可是铁黑长签上蘑菇都被分完。尼姆将目光从铁黑长签上收回等待格尔曼·斯帕罗继续讲述他经历和愚者教诲。克莱恩环顾一圈重复起之前说过话语：周围蘑菇可随意摘取除纯黑那种另外必须全熟才能入口否则会遭遇诅咒。月城居民们不再有丝毫迟疑当即起身选择自己心仪已久蘑菇。克莱恩瞄一眼又补一句：洁白那些蘑菇烤到熟后很容易裂开流出液体你们需要准备一些器皿或者及时喝下。没等鲁斯等人回应他拾起先前中断话题一直讲到自己听见灰白雾气里传出诵念愚者先生尊名声音。见大祭司尼姆都听得入神并有不小触动克莱恩斟酌着开口：能让灰白雾气产生反应办法还有不少但都与我主有关。他这是一个合理猜测因为被悬吊人不只一个进入灰雾之上办法不只一个如果罗塞尔大帝拿着他仿制神秘银牌来到这里大概率也能让这无形屏障出现异变当然前提也许得是大帝属占卜家学徒偷盗者三条途径之一。见尼姆等人没提出疑问克莱恩和煦：据我观察月城非凡途径并不单一。灰白头发尼姆未做隐瞒简单回应：是的我们被挑选来月城时神使有意识让非凡途径全面可惜这么多年过去一次次灾难后许多途径魔药配方和非凡材料都已经遗失。你是哪条途径？克莱恩看着月城居民们利用怪物骨头翻烤蘑菇状似随意问一句。我是守夜人。尼姆坦然。黑夜途径序列4守夜人？克莱恩轻轻颔首转而问：这片灰白雾气附近是否有发生过异常？脸上有一条条沟壑尼姆思索十来秒：有。克莱恩心中一动表面平静就着这个话题问：什么样异常？尼姆扫那些冒出阵阵香味蘑菇一眼斟酌下语言：一座小丘突然消失原地只留下一个深坑。那片区域没有爆炸痕迹周围也没有泥土洒落。这是什么情况？有点诡异场景……克莱恩一边将蘑菇根须丢进火堆让它们成为燃料一边没任何表情变化问：你们有做更进一步调查吗？有。月城大祭司尼姆点头：一支调查小队在那里遇见一条魔狼不是已经腐烂或异变怪物魔狼而是原本那种魔狼。魔狼？克莱恩没想到会听见这样情报瞳孔略有变化追问：那魔狼长什么样子？尼姆不自觉吸口空气：和古代文献里描述魔狼一样但更为巨大哪怕八只脚同时着地也有两三个人加起来那么高。它毛色不是纯粹漆黑给人一种幽暗深邃感觉它眼睛很奇怪大部分是瞳孔黑色瞳孔还有它头顶有一撮灰白短毛……这……这不就是乌黯魔狼科塔尔？它居然来过神弃之地最东面和一场异变有关？如果让西大陆消失力量真来自源堡将对应奇迹师神话生物吸引过来也还算正常……克莱恩眉头微不可见皱一下：它没有袭击你们调查小队？克莱恩有意用了它而不是祂以免吓到月城人。在他想来乌黯魔狼科塔尔灭掉一支调查小队是非常轻松事情甚至不用付出太大代价就能将月城变成祂秘偶国度谁知这神话生物似乎放过月城。若非克莱恩提前就看过尼姆鲁斯等人灵体之线确认他们状态此时肯定会怀疑和自己对话只是一些秘偶。没有它很匆忙就离开了。月城大祭司尼姆如实。这不符合乌黯魔狼多疑谨慎性格啊……什么事情吓得祂如此仓促逃离甚至都顾不得灭口看见自己人……或者说受远古太阳神神谕在这里看守月城人有某种特殊若非必要乌黯魔狼不想袭击他们？克莱恩语速没有任何变化继续问：它有留下什么痕迹吗？没有。尼姆笃定摇头：除山丘变成深坑我们什么异常都未发现。克莱恩念头电转试着从另一个角度问：这是什么时候事情？对过去一件事一个物品越了解他就越能在历史迷雾里触及。尼姆回想一下：两年两个月零十天前。他旋即解释一句：值得记录事情太少我印象很深刻。两年两个月零十天前……当前是1351年9月8日倒推回去就是1349年6月28日……这……克莱恩右手突然轻微震颤一下。他瞳孔他表情都很正常但这是小丑有意控制结果。他记得很清楚1349年6月28日是自己穿越过来成为克莱恩·莫雷蒂那天是自己重复举行转运仪式真正意义上进入源堡那天！这里异变乌黯魔狼出现以及这神话生物仓促离开都和我有关？克莱恩心中一下涌起极大波浪。他一时找不到解释假装没任何事情发生一样略过这点想：过去两三千年内还有类似情况发生吗？没有。尼姆做出非常确定回答。两百零八年前呢有没有特别事情？克莱恩追问一句。那是罗塞尔大帝穿越到这个世界时间。尼姆迟疑两秒：我无法告诉您准确答案需要回去翻看相应记录。还好最近三百年内资料和文献没遭受破坏。说到这里他补一句：我有限印象告诉我应该没有特别事情。如果真是这样那引起这里异变让乌黯魔狼出现源头是我进入灰雾之上将源堡与自己绑定一起？克莱恩轻轻颔首没再提问简单：告诉我那个深坑在哪里。等大祭司尼姆做出回答月城居民们烤制蘑菇已可以食用他们有轻咬一口洁白蘑菇被里面牛奶烫到又舍不得吐出有反复咀嚼回味着那种淡淡甜香有一个接一个根本停不下嘴巴。尼姆看得有些怔住似乎不敢相信这些是月城人：他们每一个都透着饥渴和满足这两种矛盾感受脸上表情看似扭曲却洋溢着纯粹快乐。大祭司您也尝尝。两只眼睛挤得很近鲁斯将一个布满金色斑块散发奇特甜香蘑菇递给尼姆。尼姆犹豫下先谨慎用那个放大镜照照然后才接过蘑菇塞入口中。下一秒钟他神情微动缓慢半闭上眼睛。他在某些变异树根里有尝到类似味道但都没有这么纯粹这么回味无穷。不知过多久尼姆望向表情淡漠格尔曼·斯帕罗异常诚恳：阁下我们想聆听一下愚者先生教诲。我这还没来得及编呢……不过随着我距离天使位阶越来越近相应事情是该提上日程了……锚得预先准备好……克莱恩思绪电转间想起当初忽悠不改造海神信徒时话语。他表情迅速变得肃穆抬起右手往虚空里抓一下拖出一根布满铜绿多有尖刺十字架。克莱恩旋即将右手拇指按在一根荆棘上让鲜血浸入无暗十字内。无暗十字表面铜绿飞快剥离露出纯粹由阳光组成本体。神说……克莱恩张开嘴巴低沉出声并将手中光辉十字架举高不少。温暖明亮透彻光芒潮水一样奔涌而出瞬间就填满周围区域。尼姆鲁斯等人体内积压阴暗和不适开始飞快消融身心都仿佛得到净化。他们隐约有点恍惚只听见那举着光辉十字架浑身笼罩神圣色彩神使庄严：神说……第一诫不可活祭不可以人为祭品。第二诫不可妄称我的名。

# 495 旅行家 第十四章 让人向往的大海

## 打开书
「不老泉？喝了真的能永远年轻吗？」堂娜睁大眼睛好奇问。她并没有什么期待情绪因为还足够青春。艾尔兰未立刻回答叉片油炸鱼人侧肋肉两口撕咬吞下然后抿少许苏尼亚血酒。「甜润口感完全冲淡油炸腻味…」半闭眼睛一副美食家做派。回味几秒才慢悠悠解答堂娜疑问：「我不清楚是否有不老泉也无法确认不死之王阿加里图是否喝过它泉水我只知道一件事那就是在我很小时候我就有听到这位海盗王者传说就像五海之王纳斯特似乎永远活着一样。」「他们胡须肯定很长很长超过胸口！」丹顿发表意见。「事实上五海之王纳斯特胡须只到脖子下方他坐在甲板上披着黑底银边华丽长袍戴着比他脑袋高两倍尖塔皇冠就像神灵一样俯视周围一切…」语气逐渐低沉仿佛陷入回忆泥潭难挣脱。「船长叔叔你见过五海之王？」堂娜兴奋问。这是最传奇海盗名字通行海上就连港口城市小孩们都熟知。整整几代人是听着有关他故事长大！从某种意义在许多人认知里纳斯特就等于真正海盗王…我记得黑皇帝晋升条件之一是将本身名字与皇帝称号挂钩深入民众心里…这算初级版简陋版尝试？也不知道五海之王达到序列几了…克虽然专注品尝炸鱼人肉但还是被众人话题勾动思绪。面对堂娜提问艾尔兰叹口气：「那时候我还很年轻还在威廉五世号上服役有一次我们舰队试图穿过狂暴海天灾海峡在那里遇到黑皇帝号。那几分钟里包括舰队长官在内所有人都失去反抗意志幸运是纳斯特并未下令攻击我们。」「很酷！」男孩丹顿眼睛发亮赞美。艾尔兰不再继续这话题笑笑：「至于不死之王阿加图里我并没有实际见过只知道悬赏令上他是个脸色苍白中年男苍白到什么程度呢我举个便于理解例子像死了一段时间刚开始腐烂尸体。」堂娜丹顿听到这比喻下意识望已千疮百孔鱼人尸体一眼不自觉蠕动喉咙。「当然悬赏令重点不是长相是金额仅在鲁恩阿加图里就价值10万镑而他是四王里悬赏金额最低。」岔开话题：「我们继续宝藏故事排在第三是所罗门帝国遗产在第四纪那个庞大帝国被肢解和覆灭时它王族带着神灵都嫉妒宝藏登上船只驶入迷雾海深处等待重建王朝机会可是五百年过去一千年过去一千五百年过去他们却再没有出现。」「据说五海之王纳斯特就继承了所罗门帝国部分遗产没人知道他是不是真正黑皇帝后裔。」塞西尔饶有兴致补充。「迷雾海？北大陆西岸？」堂娜回想地理学知识。「对。」克里维斯简洁回应。北大陆西边迷雾海东边苏尼亚海南边狂暴海北面北海南大陆东西两侧与北大陆类同南面则极地海它们合一起就是所谓五海。鲁恩背靠霍纳奇斯山脉和内陆间海东临苏尼亚海南抵迪西海湾占据前往狂暴之海数个优良出海口但并不涉及迷雾海。「这样啊…」堂娜对太远宝藏没什么兴趣转而问：「第四个宝藏呢？」「那属于第四纪最后一个帝国特伦索斯特传闻他们建造一艘相当于一座城市巨大船只将所有珍藏所有财富都转移到上面可笑是他们逃避没能产生作用预定乘客和船员们都没能及时抵达港口没一个存活下来。不过那艘船却自己消失了直到今天依然时常有人宣称自己在某个充满迷雾夜晚看到那巨大船只无声驶过它被称为幽灵帝国出没地点遍布苏尼亚海呵这是从那些故事里总结出来的。」抬头望高空红月语气里带点嘲笑又藏难掩饰向往。「也许明晚不今晚我们就能看到它从旁边驶过！」堂娜又期待又兴奋畅想。克收拾好剩余食物喝口红茶颇感兴趣听艾尔兰讲述剩余宝藏：「第五个是失落的纽因斯传闻在迷雾海底有一个属于智慧生物文明。那片海域航海家冒险家经常会找到些奇特物品它们都指向着古老年代里纽因斯但这个文明成员从未出现过像是早就消失于这个世界。」喝口剩余苏尼亚血酒：「那是一个文明留下遗产丰厚程度绝对难想象。」顿两秒放下酒杯笑一声：「其实我最向往也是实际多过传说宝藏是沉没的月桂号一百多年前它装载着王国从东拜朗获得黄金珠宝和各种贵重物品因为偏离航道沉没在狂暴海和苏尼亚海不知哪个地方直到今天也没被发现。据说上面物品总计价值几百万镑！」「几百万镑？」数字让堂娜惊愕脱口。作为商人女儿而且已接受过好些年教育她对这数字代表着什么隐约有点了解。在鲁恩百万富翁是绝对有钱人仅次于最顶尖大贵族大富豪！几百万镑？让我免费加入克拉格俱乐部玛丽太太身为王国大气污染调查委员会委员考伊姆公司大股东身家也才几万镑而就算这样她在贵族商人圈子里也足够富裕是相当受欢迎离异女士甚至有贵族子弟求娶…迅速找到比较对象。艾尔兰嘴角含笑感叹：「如果能找到沉没月桂号那我就不再做船长我要前往贝克我要成为慈善家我要购买土地捐助政党拿到一个世袭爵位！」我听塔利姆提过勋爵也就是从男爵爵位大概要30万镑男爵是80万镑左右…如果你打捞出宝藏子爵甚至伯爵都可想象…几百万镑啊！心里帮对方完善计划。「如果是我我不会这样我要购买一个很大庄园。」塞西尔也开始畅想收获宝藏后生活：「我要请很多仆人和帮佣种大片小麦建立葡萄园专门给自己酿酒…还有可以晒到阳光大房间悠闲活动牛羊和马自家磨坊出来面包就像画一样美好景色…」艾尔兰听得笑出声：「女士你知道这样的一个庄园价值多少吗？」「不不知道。」摇头。「也就几千镑只要打捞出沉没月桂号你可以买下一千个类似庄园！」用具体数字阐明宝藏价值。一千个庄园？塞西尔忍不住端起杯子喝口红茶。在此之前她知道几百万镑是非常多钱但没想到能多至这种程度！为缓解内心震动她看向克里维斯：「头儿如果你找到沉没月桂号你打算买什么不过什么样生活？」克里维斯沉默一下：「回家拥抱我妻子和孩子告诉他们我不用再出海冒险了。」不错家伙…微微点头。堂娜则好奇望向他：「冒险家叔叔你呢？」没什么表情回答：「告诉自己不要再睡快点醒来。」噗…堂娜把刚喝甜冰茶喷出来幸运桌上炸鱼已被吃光。此时克心里却感叹：虽然知道基本没可能找到宝藏否则各大教会那么多强者早就完成了但刚才讨论相应话题时我还是忍不住有些心热这就是宝藏魅力啊！哪怕只是一个传说也能吸引到许多冒险家！堂娜擦擦嘴淑女样坐好似乎刚才失态不是她。小男孩丹顿意犹未尽问：「还有别的宝藏传说吗？」艾尔兰望向克里维斯示意由他解答。克里维斯不慌不忙喝口红茶语气低沉：「海上宝藏传说永远都数不清精灵隐秘聚居地失踪在迷雾深处海盗船封印着强大魔怪海底城罗塞尔大帝最后秘藏等等等等。」啊？大帝已经到了给别人留宝藏传说层次了…如果是真里面会有亵渎之牌吗？会有几张？对了之前死神钥匙传说也许能帮阿兹克先生恢复更多记忆等下写信告诉他…好奇又期待想着。

# 1297 倒吊人 第三十二章 离开

## 打开书
康斯顿居民震撼于眼前奇迹时克莱恩已提着行李箱带着魔镜阿罗德斯离开这座城市。弄出这么大动静后他担心被查拉图锁定位置没敢继续停留。以他目前层次和实力倒也不是太害怕和查拉图硬碰硬但他并不希望遭遇突袭——对占卜家途径非凡者来说有准备和没准备完全是两个样子一旦克莱恩暴露位置又没及时离开那就将是没准备……而且他不知道阿蒙现在究竟处于什么状态是否还在被真实造物主追逐有没有可能突然出现于自己身旁窃取走一切。……事情就是这样。多里安·格雷将学生佛尔思转告门先生话语完整描述一遍多年放逐和封印已经让始祖疯掉只偶尔能恢复清醒哪怕和祂直接对话也要承受污染精神恶意。……原来是这样……我们得想办法帮始祖脱困这样一来我们身上诅咒才会彻底消除。维尔杜你疯了吗？让一位已疯狂天使之王回归会毁掉整个家族！多里安忍不住斥责对方一句。……所以必须尽快趁始祖还有部分意识清醒时候让祂回归现实世界！一旦脱离被放逐被封印状态还有足够锚祂肯定会逐渐恢复理智。多里安你堕落了！你不再想着恢复家族荣光让我们重新回到南北大陆最顶层只希望过安稳但平庸生活！而且你能肯定那位愚者先生会一直提供庇佑吗？也许有一天祂就像七神一样不再回……但这方面风险肯定比帮助始祖脱困低自从信仰愚者先生虔诚向祂祷告我已经有很多个月没再受到满月呓语影响若非已不算年轻我都有信心服食魔药成为序列6记录官。而就算是这样再给我一段时间我也同样有不小把握晋升。我这种超过一定年纪人都可以我们下一代下下一代肯定能摆脱原本限制有机会推开半神半人大门。……他们已让自己部分后裔改信愚者先生并通过几个月观察确定真有效果正打算自己也开始向愚者先生祷告。……更重要是我们现在根本没有完成那个仪式实力无论哪条途径半神都不是好对付。其中占卜家和偷盗者对应半神都以狡诈诡异危险著称我们即使愿意牺牲自己动用0级封……我不会阻止你们改信愚者如果你们能请那位存在帮忙助始祖脱困那是最好发展但在此之前我会尽力去准备仪式多里安你们必须记住亚伯拉罕家族血脉和荣耀都来自始祖没有祂就没……如果这件事情需要牺牲者那就由我来担任。……维尔杜一直在研究各种神秘学资料希望能找到彻底解决家族诅咒办法我想这样坚持已经融进他血脉……等他确认自己没法完成那个仪式后应该就会放弃了……慷慨之城拜亚姆所在蓝山岛上原本属于反抗军私港处。一批刚完成煤气管道铺设工人正要找个地方休息等待海神教会派来马车接自己等人返回拜亚姆就看见那些据说来自弗萨克北方海岛半巨人们扛着沉重灰白石材走过来一步一个脚印。……他们记得在圆木马匹机械辅助下人们搬运类似石材都很艰难而这里半巨人们就像拿玩具一样轻松。……该返回白银城将这里情况告诉首席他们了。……虽然来到这里不算太久但他们已经深深喜欢上新家乡喜欢上阳光照耀下温暖喜欢上红月夜晚宁静迫不及待想让亲人和朋友们也能体会到享受到。……你和我一起回白银城将这里情况告诉首席和六人议事团其他长老。嗯吉诺德你也一起利亚瓦尔你负责维持这里秩序。……交代完相应事项后戴里克领着坎蒂丝和吉诺德来到新白银城僻静处低下脑袋交握起双手向愚者先生祈祷许下立刻回到白银城愿望。……这是神迹啊……坎蒂丝用没有持握武器手揉揉眼睛由衷赞叹一句。……这比兽皮灯笼亮多了……我们立刻去找首席安排大家做好搬迁准备。他听倒吊人先生讲过很多只差最后一点就成功事情不希望白银城也有类似结局。……利亚瓦尔他们没回来吗？有人担心地询问一句害怕其余探路小队成员已经牺牲。……他们留在外界修建临时营地。……没过多久戴里克和坎蒂丝吉诺德见到首席韦特·希尔蒙和六人议事团其余成员捡重点将自身小队在外界见闻描述一遍。……头顶纹着暗青符号身高超过两米五韦特·希尔蒙和戴里克之外六人议事团成员们对视一眼感叹道：你们经历就像是一场美梦不我就算做梦都梦不到那样场景。……保存封印物地牢修建好了吗？这是我们最先完成建筑。戴里克给出非常确定答案。让所有人带好必须物品到训练场集合。为防止意外我们直接向愚者先生祈求请祂将我们转移过去。……愚者先生之前降下神谕让我们再等待三个小时等来自月城古代遗民过来会合不过这不影响我们提前做准备。还有告诉大家月城生存环境艰难许多人已出现畸变要用正常眼光看待他们。……好！其余六人议事团成员皆毫不犹豫做出回应脸上都难以遏制露出振奋神情。这一次他们已不再只是看见曙光他们正在迎接白昼。

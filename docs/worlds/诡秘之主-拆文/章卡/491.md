# 491 旅行家 第十章 冒险家

## 打开书
刚踏上甲板还未来得及进入船舱——克用眼角余光看见一道身影从人群穿过走向自己。表面漫不经心内在暗藏警惕侧头望过去——发现是位戴半高黑礼帽着同色长风衣三十来岁男子。对方拥有风霜打磨脸孔粗犷但极有男人味；淡蓝眼眸不含笑意仿佛沉淀诸多往事。有点眼熟…对了昨天票务公司遇到那个家伙似乎同样也是冒险家…身在1月海上竟然穿风衣很强壮嘛…边一派轻松提手杖往斜下虚点边微笑：「上午好我们又见面了。」就像招呼一位老朋友。那个粗犷男人却没感觉意外停下来略显内敛点头：「克里维斯前冒险家。伙计你是同行？」「我以为你昨天就知道了格尔曼·斯帕罗。」含笑回应。并未将手杖交左掌因为不打算与对方握手。「看得出来。」沉默两秒：「冒险家并不是一个美好职业我已经转行成为保镖这次是跟随我雇主一家去罗思德群岛首府。」半转身体指甲板另一个位置。循迹望去看见聚一起近十人；为首中年发福绅士脸颊红润眼睛有神双排扣长礼服上能见怀表金链和镶嵌宝石领针。身旁戴宽边圆帽女士脸孔被垂下深蓝细纱完全遮住身材保持还算不错。两人前方站一大一小两个孩子；小男孩不到10岁穿儿童版燕尾正装；大十五六岁朝气蓬勃少女长相不算特别出众但一双褐眸颇灵动淡淡雀斑和蓬松褶起裙摆则为她添加几分俏皮。旁边围绕提行李箱拿各种物品三人一男两女皆做仆人打扮其中一位女佣肤色棕红明显南大陆人种。保护以上七人是一男一女穿得简便干练都做白衬衣浅毛衣黑大衣深色长裤结实皮靴打扮。这两位保镖没专门遮掩腰间枪袋制造痕迹毫不松懈审视来往靠近行人目光锐利气质沉稳。「三个仆人三位保镖？」随口问一句。这配置还挺奢侈说明雇主是有钱人…本能判断。「对。」点下头。不再多说迅速转身走向雇主一家。……愣在那里不知道对方专门过来打声招呼代表什么。回忆上辈子看过小说电影电视剧渐渐明白克里维斯潜藏意思。他对我或者说自称冒险家且看起来不太好惹的人有点警惕于是提前介绍自己表明身份和要做事情让我不要打他雇主一家主意；简单来说就是你做你的我做我的互不侵犯…这算老练冒险家或资深赏金猎人间默契？有点意思…低笑一声提行李箱拿黑手杖进入船舱根据票证找到属于自己房间。吱呀推开木门走入。房间并不宽敞刚好能摆下一床一桌一柜连椅子都没有。最大优点是具备窗户海港阳光照入在桌子和床边洒下纯净金斑。「刚才船员说盥洗室洗澡间是公用大概八个房间一个如果太着急可以提供木制马桶但必须支付清洗费用1次3便士…不得不感谢是白玛瑙号经过改造铺设许多金属管道且有锅炉燃烧有热水供应提供相对便捷生活方式否则旅行不会是什么愉快事情…」无声感慨几句。迅速拿出必须物品摆桌子上便于日常取用。收拾完毕坐到不高床沿听悠长汽笛呜呜作响感受里面蕴藏那种来自蒸汽与机械力量。船只开始航行看了会窗外海景就逐渐收回思绪开始考虑接下来最重要一件事——该怎么扮演无面人问题。在面对真造降临仪式和强大A先生时放弃逃跑尝试破坏决定让魔药有消化一点基于这样反馈对无面人扮演有了些新认识。「可以假扮成任何人但只能是自己这是秘偶大师罗萨戈被要求记住守则…我最初以为自己就是指原本身份可现在看来这不够完善什么是自己必须真切弄明白…」身体前倾沐浴阳光仿佛一尊在思考雕像。过一阵逐渐有思路：这是否和本身灵对应指内心最真实自我？哪怕在地球时周明瑞也有很多伪装以此形成社交意义人格面具从某种意义这有很大虚假成分。嗯…当我变成其他人样子顶替掉他们身份为了不被发现也得做人际关系上伪装等于戴了不同人格面具。等所有人格面具被取下不再有任何残余无面人最终看见会是什么样自己？这就是那条守则里自己深层次意思？当我直面内心想法战胜恐惧不因社交意义理由挑战不可能时就真正做回自己？有待探索和验证…想到换姿势以求坐得更舒服。回味之前种种又发现一个扮演问题：在地下遗迹时我曾经伪装成因斯顺利逃出困境可为什么完全没有魔药出现消化迹象感觉？这是否说明要想消化无面人魔药这种浅层次伪装不够？嗯这更接近非凡能力应用而不是扮演！能推动魔药消化扮演是深层次伪装是真正真正代替一个人成为社交意义他？等他亲属朋友长时间都无法发现时才表明伪装成功？这么说来我感觉自己与无面人魔药契合是因为之前成功伪装了克莱恩·莫雷蒂？无面人守则第一条可以假扮任何人但只能是自己…第二条进行瞒过所有人深层次伪装？可是顶替一个人成为社交意义他仅是想象就很邪恶…难道要找那种死在异国他乡但有心愿未完成？沉淀下莫名恐惧情绪初步拟定一个尝试方向。「序列越高越不好扮演了…」叹口气掏出怀表按开看时间。见午餐还早房间又太过窄小颇拘束决定去甲板走走吹吹海风欣赏景色。经过刚起航那一小时热烈甲板上人已不算多沿着船舷走着走着就到有大块阴影僻静地带。今天阳光很好很温暖…除了风比较大得小心帽子没什么缺点…按了按头顶半高礼帽悠闲审视船舱聆听里面隐约传出音乐声。忽然看见前冒险家克里维斯在角落忙碌面前似乎摆着一根三棱刺一把匕首和一把短刀。克里维斯有所察觉抬头望他很有风霜感不苟言笑：「都是老伙计得经常保养它们。」说到这里补一句：「船舱里有小孩。」「理解。」笑笑回应。埋下脑袋继续忙碌状似随口问：「你似乎没带这些东西？」「我习惯用紧跟时代潮流武器。」隐晦说：「而且我也经常做保养。」沉默举起匕首迎阳光看一眼自言自语般：「在海上仅靠枪是不够的。海盗会登船会有很多人你打完子弹就不会再有装填机会这些伙计虽然已不是时代潮流但却足够有用。」很专业嘛…不愧前冒险家…靠住船舷半开玩笑：「如果真有海盗登船我大概率会选择不反抗。」侧头凝望他足足三秒才收回视线然后边收拾物品边低沉：「看来你并不需要提醒你已经明白了海上规则。行走大地赏金猎人往往做不了海上冒险家。」动作熟练把匕首短刀三棱刺等武器藏入衣物下看得眼花缭乱。「谢谢。」笑着点头。没再啰嗦转身返回船舱只留下宽阔深沉背影。勾勒嘴角摇头将目光投向船舷之外。蓝色波浪轻轻起伏一条条银白飞鱼时而跃出水面翱翔半空。这种鱼能飞能游被渔民和水手认为是风暴之主眷属即使打捞上来也会放回海里…悠闲欣赏阳光下海平面以及海平面上一条条飞鱼脑海内难遏制闪过一个想法：嗯不知道它们肉质怎么样…

## 这场戏有没有翻
翻了。甲板上又见人开；章末飞鱼想肉质。翻的是无面人守则加深＋海上规则互不侵犯，不是开打。

## 这一章新讲明的规矩
- 无面人：假扮任何人但只能是自己；浅伪装≠扮演消化。
- 深伪装＝社交意义顶替；邪恶感。
- 海上：仅枪不够；赏金猎人≠海上冒险家。

## 钱与人情

## 话
「格尔曼·斯帕罗。」「你做你的，我做我的」「可以假扮成任何人，但只能是自己」「大概率会选择不反抗。」局面是从招呼收到默契；从房间收到扮演想；从刀保养收到海上规则；从飞鱼收到肉质。

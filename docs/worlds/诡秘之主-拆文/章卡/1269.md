# 1269 倒吊人 第四章 “拜访”

## 打开书
海神号上利亚瓦尔和坎蒂丝等白银城探路小队成员坐在不太适合自己椅子上警惕注视着周围来来往往矮人们。当然他们都很清楚这应该是正常人类毕竟他们都知道自己夸张身高是魔药带来但他们还是觉得这条船上人太矮了包括那位自称神使达尼兹大人要知道在白银城除开幼童进入发育阶段又未提升至序列6居民平均身高都超过1米8……船只轻微摇晃让这些半巨人或多或少感觉到不适但强健体魄帮助他们迅速克服这方面影响而窗外没有边界大海与孤单船只对比让他们难以遏制产生不安恐惧和紧张等情绪就像第一次参加探索任务……就在这时达尼兹进入这个餐厅改造成房间对拘谨提防坐姿僵硬衣物奇怪高个子们笑道：你们食物已经准备好了接下来你们可以尽情享用美食。对了不要忘记我刚才告诉你们注意事项这片海域是非常危险。不用起来坐着就行。达尼兹看到那位自称戴里克年轻长老和几位半巨人想要起身用最礼貌态度和自己对话忙下压双手制止他们这个不文明行为。迪西式烤肉。达尼兹指着门口进来一个船员道。牛排香煎肉鱼白面包海鲜清汤淡啤酒……达尼兹一一作出介绍末了笑道你们不用担心什么可以完全放开自己肚子我们有非常充足食物储备。说完他瞄了眼那一个个似乎想要站起来半巨人呵呵退出这个房间。戴里克长老现在怎么做？虽然戴里克相信愚者先生神使不会谋害自己等人但还是习惯性给出非常谨慎意见：分成两组一组等待下一餐一组现在尝试。好的戴里克长老。坎蒂丝猛地站起道我申请加入尝试组！……甲板上达尼兹眺望了下神战遗迹内安全航道考虑起之后怎么安置这些愚者先生信徒问题。神使大人他们已经吃完了希望能再来一些！再给他们各准备一份。明天开始组织船员钓鱼！……克莱恩初步适应当前状态收敛住灵性打算传送回贝克兰德召唤魔镜阿罗德斯询问一些事情。他没急于将月城居民弄到外界准备等达尼兹安置好白银城先头部队有足够经验再做这件事情反正离开神弃之地道路已经打通他可以利用回应祈求方式依靠星之杖能力直接将整个月城转移出来。当然如果那扇大门又一次合拢克莱恩同样有办法那就是先将月城居民转移到巨人王居所让他们自己开门——没有第一块亵渎石板和暗天使恶灵情况下普通非凡者就能推开大门。至于真实造物主是否会干扰和阻拦问题克莱恩没做考虑因为那位序列0真神现在就能这么做他不愿意也无法阻止。另外克莱恩认为真实造物主当前重心不在这方面祂最迫切事情是抓住阿蒙拿回第一块亵渎石板。严格来讲这是一出家庭伦理戏……克莱恩在心里吐槽一句从空气里抓出蠕动饥饿将这件陪伴自己很久封印物戴到左掌。……之前碍于序列较低不敢在灵界乱跑没有试着拜访对我有一定善意七光现在似乎可以了……他们本身是各种知识化身且于灵界不知存活多少年也许了解不少隐秘……克莱恩刚转过这样思绪眼前忽有光芒腾起出现一位穿着橘色长袍老者。殿下请允许我做一下自我介绍您应该还记得我我是橘光希拉里昂。你似乎预知到了我想要拜访你们？灵界本身就是各种信息交织成这有的来自过去有的源于现在有的昭示着某些未来无论占卜还是预言大部分办法其实都是在利用灵界其次才是依靠对命运窥视。这位橘光意思是既然克莱恩身在灵界有了拜访想法并准备付诸实践那必然会有对应信息产生让某种程度上掌控着灵界七光感知到做出预言。除了你还有谁想见一见我？他本来打算用敬称但考虑到七光态度和橘光对自己称呼又放弃这个打算以维持源堡代行者位格。橘光希拉里昂当即笑道：都想都想殿下您不介意吧？当然这是我荣幸。殿下请允许我为您介绍。橘光在看见克莱恩点头后指着一位身穿大红长袍极为威严老者道祂是红光艾尔·莫瑞亚。希拉里昂依次又介绍黄光威尼坦蓝光库图弥绿光塞拉皮斯靛光赫苏斯紫光圣热尔曼。黄光威尼坦……这就是对亚伯拉罕家族先辈做出末日预言那位？克莱恩看了眼穿柠檬黄长袍留着白色长须瘦削老者笑着说道：那我们坐下来聊吧。请坐。克莱恩面朝七光笑着指了指沙发和高背椅们。坦白地讲我一直都想拜访七位只是始终找不到机会现在终于实现这个愿望。这也是我们愿望。橘光似乎是七光里最开朗最外向那位当即代表所有同伴回应道。七位你们对星空或者说旧日外神有什么了解？相貌相对年轻套着亚麻长袍靛光赫苏斯表情严肃回答道：殿下目前窥视着我们世界旧日有堕落母神欲望母树混沌之子原初饥饿宿命之环超星主宰不熄呓语衰败君王高维俯视者……这会不会太多了？克莱恩听得点呆住。

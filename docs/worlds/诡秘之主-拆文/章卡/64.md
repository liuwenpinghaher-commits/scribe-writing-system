# 64 小丑 第六十五章 非凡者资料

## 打开书
邓恩签字的文书。武器库。老尼尔：明天晚上一块去地下交易市场。有债务就无法安心睡觉。查尼斯门后一大叠，只能在这里阅读。读完：占卜家序列8、7没有魔药名。8擅长技巧性格斗而且狡诈。7掌握许多能快速施展的法术。途径最早成型于所罗门帝国查拉图家族，疑似密修会。罗塞尔的扮演法来自查拉图。水手属风暴之主。观众与倒吊人说的一致。通识者知识就是力量。学徒、偷盗者只到8。最后看见特里斯：教唆者。眼睛跟桌上的纸。

## 这场戏有没有翻
翻了。开头他还当内部资料能把进阶看全；章末占卜家后面是格斗，查拉图把扮演绕回这条。翻的是这条路还能否按常理往上走，不是资料详细热闹。教唆者只点到名称。

## 日子
地底武器库。手工咖啡。只能现场读。考古资料和历史文献多，非凡者隐秘组织少，基础常识。

## 这一章落在哪一天
通缉令同一天。昨天下午罗塞尔日记里有查拉图。明天晚上去地下市场。2-049还没到。

## 人
- 克莱恩：先整体浏览。保密等级只到序列7。希望正式队员。
- 老尼尔：不诧异。去查尼斯门取。叮嘱不能带走。
- 查拉图家族：所罗门帝国。第四纪未完全毁灭。第五纪偶尔还能听到。
- 倒吊人：他猜不是风暴守卫就是航海家，后者可能大；不是代罚者就是被风暴教会暗中吸纳的海盗。
- 特里斯：资料末尾的魔药名。

## 地与走
接待文书 → 武器库 → 老尼尔去查尼斯门他看守 → 桌上读。圣堂不在本章。

## 这一章新讲明的规矩
- 涉及非凡者和隐秘组织的资料多在查尼斯门后，武器库这边不多。有签名印章才能取。不能带走。
- 有的途径完善，有的只有魔药名，有的只有表现，有的空白。
- 占卜家序列8名称未知：技巧性格斗，狡诈。序列7名称未知：许多能快速施展的法术，技巧和超自然结合。
- 查拉图家族成型这条途径，疑似密修会。罗塞尔扮演法来自查拉图提醒——他后悔没选占卜家？宿命感在神秘学往往昭示东西。
- 水手属风暴之主。序列8暴怒之民，古称风暴守卫，愤怒时力量速度极大提升。序列7航海家，古称风暴牧师，磁场洋流风向云朵直觉，船不迷路，水下超过半小时，有限水相关法术，有的来自本身有的风暴之主恩赐。
- 观众缺直接克敌，观察影响引导。读心者深入气场以太体，很难有秘密。心理医生能治疗狂乱或让人丧失理智。很难被发现的非凡者。
- 通识者：知识就是力量，粗略神秘学，王水硝酸甘油复杂齿轮。序列8考古学家。序列7鉴定师。
- 收尸人后续掘墓人、通灵者。窥秘人序列8缺名称也缺描述，序列7巫师。学徒很少被困住；戏法大师奇怪但不强力的法术。偷盗者难与普通盗贼区分，像履行使命；诈骗师以欺诈为乐。
- 资料只到7。正式队员更高保密。

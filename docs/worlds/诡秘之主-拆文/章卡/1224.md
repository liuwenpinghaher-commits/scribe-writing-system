# 1224 逐光者 第七十五章 开解

## 打开书
听到正义小姐略显萧索和迷茫话语克莱恩颇有点感同身受因为他之前也产生类似想法。回忆几秒上辈子看过心灵鸡汤他斟酌着：一个父亲死去对整个鲁恩来说是那样渺小每天都有可能发生甚至不止一起但于他孩子他家庭而言却是一件足以改变命运大事。同样不到天使层次每个人结局都是注定必将逝去必将被埋葬但这不等于我们从出生到死亡这段时间毫无意义。正义奥黛丽听得微微点头再次用那种自嘲口吻：这些道理我都懂只是你刚才讲隐秘带来太大冲击我一时无法控制自己情绪。作为一名心理医生竟然需要别人来开解……克莱恩笑：这不是很正常事情吗？很多时候我们能认知到别人状态是否正常却无法看清楚自己问题。你之前不是也说过吗？偶尔会和苏茜互相开解。因为道恩·唐泰斯见过苏茜这条金毛大狗所以奥黛丽在闲聊中并未隐瞒相关事情。奥黛丽轻轻颔首：唔……是这样没错。我已经想明白了做自己能做不留下遗憾。她逐渐调整好心理状态。克莱恩随之：不仅仅是不留遗憾问题说不定我们做事情还能为对抗末日积攒力量。和整体相比这虽然渺小但再宽广沙漠也是由一粒粒沙组成再看不到边际海洋也是由一滴滴水汇聚成只要每个人都有一分热发一分光也许就能带来一点希望。有一分热发一分光……奥黛丽低声重复起世界格尔曼·斯帕罗话语里关键词。这不是我说。克莱恩笑着补一句。奥黛丽勾勒嘴角浅笑：难道是罗塞尔大帝说？这我就不知道他有没有说过了……翻他语录我得忍着强烈羞耻感一直没能看完……克莱恩没做肯定回答也未否定转而：开始催眠我吧让我遗忘掉星空有关事情只记得相应警告。再等一下我有件事情想请教你。奥黛丽大大方方做出请求趁这个机会说了说自己最近做事情以及遇到困难心里困惑……世界先生你有什么建议？我该怎样才能让贝克兰德民众在战争结束前不遭遇太大灾难？至于阻止战争她虽然很想但理智知道自己没那个能力。同时她也明白即使世界先生也没法办到甚至愚者先生亲自插手也顶多扭转局势无法中断战争毕竟这次世界大战本质上是神灵之间争斗。克莱恩犹豫几秒还是坦然：虽然观众途径尽量得在幕后虽然我本身做事都牢记着谨慎和小心等单词尽量不把自己放到危险处境里……他说到这里正义奥黛丽下意识就在心中回两句：从海上种种传闻佛尔思她们描述和我见证那场半神战斗里我完全看不出谨慎和小心只有强势和激进……唔能做到那些事情还活下来仅靠实力确实不够……克莱恩见正义小姐听得很认真碧绿眼眸写满专注遂继续：但这个世界上不可能任何事情都能轻松简单就解决不需要冒险。有时候我做一件事情是抱着可能会死这个想法。正义奥黛丽心中咕哝停止她沉默好一阵才缓慢开口：我明白你意思了。做自己想做事情和绝对安全在很多时候是没法兼顾只能选其中一项。克莱恩点点头决定让正义小姐更清楚地认知到这个世界真实避免她做事时太过理想主义：你刚才说办法里目前最可行风险最小最能帮助到贝克兰德民众是从贵族教会大商人王室手中获取粮食。为什么不是去抢夺弗萨克因蒂斯和费内波特军队粮食？奥黛丽下意识问一句。克莱恩平静：因为这三支军队已深入鲁恩国境即使你能突破半神看顾成功抢走粮食他们也不会崩溃必将搜刮周围民众食物来维持短期内受到影响不大至于长期可能等不到那个时候了。那样一来真正受伤害是谁奥黛丽一听就清楚。这就是神战前战争与普通战争不同。而且我也没法做到这件事情旅者行囊容量有限莱曼诺旅行笔记能记录传送也是。正义奥黛丽自我开导一句思索着问：如果我真从贵族商人王室那里获取粮食教会又发现痕迹会有什么反应？克莱恩保持刚才语气：默许。……奥黛丽隐约觉得答案就是这个却一时想不通理由。克莱恩继续：信徒是神灵锚一个信徒是一个锚点在这方面一个贵族和一个贫民在本质上没有区别没谁更高贵没谁更低贱。正常时候贵族和商人们可以利用自己地位权势财富和影响力帮助教会维持体系传播信仰所以更受重视但现在这种局势下几千个锚和几十万上百万锚谁更重要？这是一道简单数学题。面对这扯掉温情面纱真实正义奥黛丽短暂竟说不出话来。克莱恩见状补一句：从这方面讲你想做事情在大层面也是有意义：你帮助黑夜女神风暴之主稳固锚在将来这也许就是对抗末日关键点。正义奥黛丽嘴唇一点点抿起好久才松开低笑一声：我这才发现我内心其实还是有点骄傲于自己贵族身份。高贵是品格而不是身份。克莱恩帮她说出剩下话语。奥黛丽缓慢吐口气安抚起纷乱内心并未就此下定决心。她随口：我们塔罗会和教会呃黑夜教会关系似乎还不错。愚者先生和黑夜女神是盟友？这个问题难到我了……我倒是想和女神成为盟友但女神未必看得上啊……克莱恩腹诽两句后颇为严肃：目前算是盟友。他刻意强调目前免得将来被现实打脸。与此同时他在心里咕哝起真正答案：从现在情况看女神是塔罗会天使投资人主要股东……正义奥黛丽缓慢点下头忽然展颜一笑：我在想你回答目前算是盟友时心里在嘀咕什么这一定很有趣就像探索利维希德时那样。……小姐心理医生不适合和病人开这样玩笑……是因为最近大半年闲聊太多熟悉不少展露出本性？请尊重一下你面前这位以冷酷疯狂闻名冒险家……嗯不得不说观众途径调整自身情绪能力就是强……那次都怪伦纳德……克莱恩先是错愕旋即装作无事发生后靠住椅背：开始吧。奥黛丽立刻收敛起所有情绪开始认真而精细地尝试催眠。等到一切结束克莱恩通过深红星辰确认正义小姐返回现实世界后并未被旧日们注视。当然他已经遗忘这事与旧日或者外神有关只是从正义小姐状态肯定没有异常发生。呼……克莱恩松口气将能唤醒自己这段记忆纸张丢入杂物堆里并告诉自己等成为天使再看。……贝克兰德桥区一栋公寓内。埃姆林·怀特看着对面突然出现马里奇摘掉礼帽极有风度行一礼。你有什么事情？马里奇坐在沙发上前倾身体交握双手。埃姆林拉张椅子坐下微笑问：你们还想对付玫瑰学派放纵系重要人物吗？你有线索？马里奇一脸淡漠反问。埃姆林肯定是做好准备才来拜访不慌不忙：对于贝克兰德玫瑰学派负责人我确实没有一点线索。但是战争白热化之后南大陆东西拜朗星星高原帕斯河谷和哈加提草原都变得一片混乱许多玫瑰学派半神浮出水面走上舞台不再那么难以锁定。马里奇看红眸薄唇埃姆林一眼：你是代表血族哪位公爵或者侯爵来说这些话？我代表自己不可以吗？埃姆林微抬下巴笑着反问一句。马里奇认真摇头：你只是一个序列5你还不够资格。他说得太过直接埃姆林一时竟不知该怎么接这句话了。

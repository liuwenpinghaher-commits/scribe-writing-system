# 339 无面人 第一百二十七章 过去

## 打开书
艾伦劝改信——克莱恩险画绯红之月忍住：「信仰决定则不改。」艾伦抱歉；「信仰不同不妨碍朋友」——克莱恩：弗萨克／费内波特不成立，鲁恩因蒂斯因多教会并存较开放。转话题：再见威尔·昂赛汀？——出院后再无；值夜或依址查，己不便插手。赴靶场遇玛丽夫人与房东斯塔琳：带打网球壁球（生命在于运动）。克莱恩赞美丽；玛丽见议员招呼，斯塔琳留。问忙？——帮查连环案得赏。凶手长什么样？保密（心嘲黑毛狗）。赏多少？「多人瓜分」「有没有50镑？」「有。」斯塔琳笑认赚钱力——下周日家宴请帖，多未婚小姐（父／母体面、年入≥200、或兼职打字员）＝相亲宴！配这层？为邻里与免自炊含笑允。练枪能力。夜9点看满月渐圆；10:15虚祈——魔术师求救。上雾：佛尔思门符座舒气谢再救；云淡回应。双人沉默压抑如新职遇上司——愚者笑：「或许讲讲你怎么成为非凡者。」佛尔思：近三年医学院毕业；父助入私人诊所，父赴东拜朗追财留母女丧偶般；母重病死，父隔月信告已新家新生命、财产归女。东拉西扯后：退役军官介尤瑟夫诊所；陪孤独遗孀——见其穿墙；遗孀称夫遗、非某族则无咒；病逝前予学徒方、守尸取发光主材、手链叮勿轻用勿太在意满月呓；终用一次呓加重。克莱恩：亚伯拉罕遗孀证咒在血脉；「等高序呓语无大用。」「希望如此。」又周一：茶几纸条「有效。」松气。下午2:45上雾筹塔罗会。

## 这场戏有没有翻
翻了。开头还在挡改信；章末佛尔思过去摊开（亚伯拉罕遗孀线）、马里奇镇静「有效」、塔罗会将开。翻的是「过去」还能否只当闲聊，不是相亲宴。

## 热怎么变冷
改信还热。冷切在威尔无见。相亲还热。冷切在练枪。满月祈还热。冷切在双人沉默压迫。遗孀故事还热。冷切在「有效」。

## 怎么起、怎么收
第一段「这不是在为难我吗」。最后一段筹备塔罗会。章题：过去——佛尔思源与满月夜。

险画月忍。多教会开放。狗形凶手吐槽。相亲层次自嘲。职场上司感。东拉西扯作家技。血脉咒点破。

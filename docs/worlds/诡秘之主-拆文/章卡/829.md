# 829 不死者 第九十八章 潜入

## 打开书
枕上魔镜辉芒：阿罗德斯自称仆人。克莱恩问安提哥努斯家族笔记在圣赛缪尔教堂查尼斯门后哪——1级封印物，第二层靠右，更细看不清。吩咐像之前看幻象应对意外；镜中道恩假人躺床谄媚拉被。他变格尔曼旅行到佩斯菲尔街教堂外广场阴影。夜弥撒散，仆役清垃圾；一人渐远，虚空手抓住旅行到东区廉价公寓——提前租的两居室。仆役喝安眠药剂沉睡，他烂泥般无面成仆役样，换衣拿扫帚回广场混入。仆役房左右抓瞎，扫帚卜杖寻路进右房，学洗脸冲脚占空床。冥想强睡数小时，放塞尼奥尔：侵蚀气息让查尼斯门当自己人，半神大主教灵性未动。怨魂找霜白稀疏发大鼻老看守，附身灌安眠药。克莱恩吃阴冷入体，无面成看守，衣物塞床底。五点半吃白面包下楼，牧师密门前互赞女神，左拐地下。迎面墨发绿瞳红手套——伦纳德·米切尔。

## 这场戏有没有翻
翻了。开头他还在主卧问镜；章末已是内部看守走进地底，与伦纳德近在咫尺。翻的是还能否当道恩睡觉、有没有摸进查尼斯门前最后一道人墙，不是换装热闹。

## 日子
周日夜潜入到周一黎明五点半。仆役呼噜。月光照不到的阴影壁画。

## 这一章落在哪一天
接召阿罗德斯当夜；正文到天色刚亮、内部看守上班点。明天周一在心里算轮值。

## 人
- 克莱恩 / 道恩假人 / 格尔曼 / 仆役模样 / 看守模样：潜入全流程。
- 阿罗德斯：答位置、看幻象、发誓控本能。
- 仆役们：清垃圾、高低床打呼噜。
- 塞尼奥尔：附身灌药、镜面跳跃。
- 霜白发大鼻老看守：目标，被灌睡。
- 密门牧师：愿女神庇佑。
- 伦纳德：章末迎面，哈欠。

## 地与走
主卧镜 → 佩斯菲尔街广场阴影 → 东区廉价公寓换装 → 回广场混仆役 → 右侧仆役房 → 二楼看守区 → 一楼密门地下阶梯 → 十字路口左拐遇伦纳德。

## 这一章新讲明的规矩
- 笔记是1级封印物，第二层靠右；魔镜看不清更细。
- 旅行每次要用需海盗献生命——腹诽。
- 不涉非凡的左右可用卜杖寻路。
- 被侵蚀的怨魂加纸人天使干扰：封印核心默认、大主教灵性不触。
- 前值夜者经验：牧师守通往地下密门，互画绯红之月。

## 钱与人情
东区廉价公寓提前几天租下。安眠药剂两支（仆役与看守）。白面包清水当看守早餐。旅行家方便的代价在腹诽里。

## 话
「那本安提哥努斯家族笔记在圣赛缪尔教堂查尼斯门后哪个地方？」「它是『1』级封印物，在第二层靠右区域，更具体就看不清楚了。」「像之前那样看着我的幻象，应对意外。」「愿女神庇佑你。」「赞美女神。」局面是魔镜把位置收成第二层靠右；哈欠把红手套收成还没察觉的擦肩。

## 热怎么变冷
阿罗德斯效忠还热。冷切在高度紧绷说不出暗啧。假人谄媚拉被还热。冷切在变冷峻冒险家。混入仆役还热。冷切在左右抓瞎。附身灌药成功还热。冷切在阴冷入己身。密门互礼还热。冷切在红手套迎面。

## 怎么起、怎么收
第一段接镜子焕发银光、阿罗德斯效忠。最后一段停在墨发绿瞳红手套伦纳德迎面走来。章题潜入：从广场阴影走到地底阶梯。

## 叙述怎么插手
如果处在正常状态肯定暗啧：紧绷对照。旅行家太方便唯一问题海盗：腹诽减压。真累啊：仆役闲话。还能操纵：他微不可见点头。这是前值夜者经验：解释不慌找路。

## 这一章放了什么
- 笔记第二层靠右：目标坐标。
- 道恩假人应对意外：家中掩护。
- 仆役换装与卜杖进右房：潜入第一段。
- 塞尼奥尔附身灌看守安眠药：顶替完成。
- 伦纳德迎面：章末危机。

## 这一章收了什么
上一章画召镜符号：本章镜出、问位置。恐惧侵蚀塞尼奥尔：本章当自己人进看守区。箭在弦上：本章人已下到密门后。

## 谁比谁多知道
读者跟克莱恩知假人、公寓仆役、顶替。阿罗德斯知幻象任务。伦纳德本章尚未察觉。牧师当他真看守。真看守无梦沉眠。

## 留给下一章的日子
人已在地下路口，伦纳德迎面。笔记还在第二层靠右。五点半后窗口有限。

## 这一章回不去的事
已经弄晕仆役顶替、附身灌倒看守并穿上神职黑袍下到密门——回不到「还在主卧睡觉的道恩」。

## 这一章人怎么叫人
主人。阿罗德斯。赞美女神。内部看守者。红手套。伦纳德·米切尔（叙述点名）。

## 可搬走的一条作法
以后写别的书：潜入成功后的第一道闸不要放守卫盘问，放一个最熟的熟人迎面打哈欠擦肩。书证 L71387：「就在这个时候，他看见位戴着红手套的男子迎面走来。」

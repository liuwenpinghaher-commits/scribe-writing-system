# 1377 倒吊人 第二十五章 改变计划

## 打开书
不同模样阿蒙脸上以不同形态存在单片眼镜同时发出纯净光芒。这是祂们在神战遗迹深处窃取来源自远古太阳神永昼效果这可以净化污秽和邪异之物唤醒沉睡中生灵。祂们将这份礼物赠送给克莱恩。这结合学徒领域相关权柄赋予操纵封印强度能力足以打破永眠状态。刹那之间克莱恩体内安提哥努斯精神烙印和福生玄黄天尊意志全部苏醒疯狂苍茫残忍嗜血冷酷感觉如同无形风暴肆虐于克莱恩心灵中。几乎是同时他脸上覆盖还未彻底容纳愚者唯一性里福生玄黄天尊强大意志仿佛在黑暗中沉睡上千年可怕怪物骤然睁开眼睛。这一刻之前那种混乱和失控又席卷而来但克莱恩并没有惊慌按照备份某个方案冷静利用嫁接能力将安提哥努斯精神烙印引导向愚者唯一性内天尊意志让纠缠一二千年它们重新碰撞在一起。另外一边克莱恩依靠自我意识和来自愚者信徒海神信徒们锚主动平衡起体内非凡特性蕴含那部分天尊意志就如同分离诡秘侍者秘偶时那样。如果没意外这么一直发展下去克莱恩有一定概率能在两边都取得平衡彻底容纳愚者唯一性步入仪式最后阶段可是在被阿蒙们包围情况下怎么可能没有意外？部分阿蒙加强特伦索斯特黄铜书和许愿神灯封印对抗前者规则限制部分阿蒙将永昼赠送给克莱恩时还有小部分锁定克莱恩做出窃取。……一个又一个阿蒙失败了但最终还是有几个阿蒙成功祂们窃取走克莱恩自我意识接下来两秒内清醒。克莱恩思绪一下模糊了失去他引导安提哥努斯精神烙印两部分福生玄黄天尊意志和来自信徒锚顿时失衡疯狂地彼此侵蚀影响和污染。……而这个时候特伦索斯特黄铜书上规则被抹去重新开始书写：此地禁言！此地禁止互相攻击！……以下规则无效。在封印加强之后特伦索斯特黄铜书似乎又进入新循环而灯神能施加影响变得相当有限。……不仅如此克莱恩还让那个诡秘侍者秘偶主动化成蠕虫漩涡带着查拉图精神烙印投向本体融进去。……不过阿蒙分身们不会放任他做任何尝试除去对抗许愿神灯和特伦索斯特黄铜书那部分阿蒙其余都再次开始窃取要让克莱恩思绪一次又一次陷入混乱直到失控彻底来临。那个穿着邮差制服阿蒙成功了可是祂窃取来却不是克莱恩清醒而是一滴鲜活血液。……祂刚才窃取来是原始月亮也就是堕落母神祝福过血液！克莱恩不再将绝大部分意识放在平衡体内安提哥努斯精神烙印福生玄黄天尊复苏意志和锚这件事情上后无需再像刚才那样被动承受勉强可以对阿蒙窃取做出一定回应了。他利用嫁接将那部分阿蒙窃取目标篡改到源堡内部篡改到杂物堆中篡改到那滴有原始月亮祝福血液上。——这来自巫王卡拉曼。……这导致其余窃取都不可避免失败了。克莱恩抓住这个机会依靠无法维持太久清醒调动源堡力量让整座古老宫殿蒙上一层阴影般幕布。……然后他无视着体内安提哥努斯精神烙印查拉图精神烙印开始融合两部分福生玄黄天尊意志让立在不远处还未出现崩溃脸孔空白那个分身向本体伸出手掌。……因为克莱恩自我意识没有抗拒甚至在主动配合所以分身没失败几次就依靠源堡帮助成功从本体处窃取走自我意识命运锚和大部分身份。他留在本体处只有与愚者相关身份。与此同时他还窃取走安提哥努斯家族那位先祖身份命运和精神烙印——这也是在他自我意识配合下才能几次就成功。……另外一边克莱恩原来本体处剩下愚者唯一性所有来自幕布非凡特性源于查拉图非凡特性克莱恩曾经服食并消化少量其他来源非凡特性和复苏福生玄黄天尊意志残余查拉图精神烙印以及愚者身份。而在没有克莱恩自我意识安提哥努斯精神烙印和大量锚牵扯后查拉图残余精神烙印迅速就被正在二合一福生玄黄天尊复苏意志击溃并侵蚀了。下一秒克莱恩本体突然变得沉寂。……克莱恩没去管这边只是迅速将自身与本体部分联系嫁接到灰雾之上。……这曾经半个愚者没有得到阿蒙帮助并未摆脱永眠状态。克莱恩又一次探出右手窃取起对方剩余序列9至序列1非凡特性各一份。虽然他现在顶着安提哥努斯身份和命运但这样窃取依旧困难失败不可避免重复起来。此时源堡制造诡秘之境外阿蒙从最初混乱中找回意识。……祂将诞生婴儿都变成自己分身以免有一定原始月亮污染祂们干扰自己。而这个时候大地母神和蒸汽与机械之神在各自战场上都取得一定少量优势终于能腾出手干涉宫殿内部情况。……不过还是有部分阿蒙或利用闪现或依靠漏洞或借助对规则欺诈成功避开两位真神施加影响。祂们一边继续增强许愿神灯和特伦索斯特黄铜书封印一边在克莱恩诡秘之境上开起门。与此同时天使们也注意到星界变化但祂们目光没法穿透大地母神自然屏障和蒸汽与机械之神文明画卷根本看不见内部场景。……源堡制造诡秘之境内克莱恩在一次次失败后终于成功窃取安提哥努斯从序列9到序列1各一份非凡特性已经消化掉非凡特性！——后者因为非凡特性聚合定律于漫长历史里引来许多同途径非凡者在将他们变成秘偶同时祂也吸走他们非凡特性所以此时安提哥努斯体内还剩下大量占卜家途径非凡特性包括一份奇迹师。……这样一来克莱恩重新成为序列1诡秘侍者已消化掉魔药命运指向失控结局诡秘侍者。就在这个时候他原来本体抬起脑袋双眼一片幽黑。……他非常熟悉那股强大意志开始一点点攀升尝试起影响源堡。那位诡秘之主在克莱恩本体内初步复活了。愚者成为真正意义上复苏伟大存在与塔罗会众人猜测吻合与真实历史矛盾。克莱恩在思绪进一步滞缓前主动配合起阿蒙解除诡秘之境让里面情况与外界互通。他已毫无问题愚弄历史像最早想那样至于接下来怎么收尾他一直没有好思路。……不留任何退路从容纳愚者唯一性变成晋升真正愚者！这反正不会比刚才情况更差。

# 1252 逐光者 第一百零三章 祝安好

## 打开书
一直到克莱恩即将走完石制阶梯巨人王庭正门外那两个银骑士守卫才有一点反应。他们转动脑袋面甲后橘红光团闪烁两下仿佛在确认来者身份并且有那么一个刹那困惑。克莱恩一半正常一半恐怖脸庞上右侧嘴角浮夸翘起左边透明蠕虫缓慢扭动呈现出既惊悚又漫不经心笑容。啪！他右脚跨越最后一层台阶来到巨人王庭正门所在平台。突然克莱恩额头裂开一道银白缝隙体内随之迸发出数不清银色锐芒。他整个人瞬间四分五裂被切割成一个又一个血肉碎块。克莱恩戴丝绸礼帽穿黑色风衣身影接连呈现在不同位置但都被一道道银色剑芒搅碎或退化为幻影或异变成了纸人。就在这个时候巨人王庭那不见了两名守卫正门外面突兀浮现出一道身影。蕾妮特·缇尼科尔！克莱恩攀登石制台阶时召唤正是这位信使小姐不过祂是以怨魂状态出现没让科林洛薇雅戴里克看见。此时此刻两位借光躲藏隐去恶意银骑士都本能追杀着克莱恩在暗中观察好一阵天使位格强者面前已暴露行踪。他被怨魂附身了！以自己做诱饵克莱恩停止闪现以手按胸非常有仪式感行了一礼：找到你们了祝安好。然后克莱恩一步步走向那个竭力挣扎却没有效果银骑士守卫。当两道身影有所交错时蕾妮特历史投影回归迷雾而那名银骑士紧跟在克莱恩身后非常听话地与他一起返回石制台阶边缘。可以进入了。克莱恩笑着对台阶下方科林等人说道。世界先生真的很厉害这么快就单独解决两个银骑士守卫！异种？克莱恩将一条构成左眼眼珠灵之虫按了回去笑了笑未做回答。等到戴里克和洛薇雅走完台阶一行四位半神加一个秘偶转身抵达正门。这个过程中克莱恩将那只白色长毛兔析出银骑士非凡特性收了起来。这一次蕾妮特拿非凡特性克莱恩获得银骑士秘偶。抬头审视正门克莱恩让那个比自己高很多银骑士守卫跨前几步将手中大剑插入地缝。然后这银骑士伏低身体伸出双手按在几十米高正门上。这个时候高空太阳跳跃整个巨人王庭都凝固到橘红黄昏光芒里。开始你们表演吧。克莱恩侧过脑袋笑容浮夸对科林和洛薇雅说道。曾经猎魔者科林微微颔首没有异议洛薇雅身后则浮现出好几米高穿银色全身盔甲眼睛暗红如火虚幻身影。绽开银白花朵不断地往上蔓延就像在迎接贵客。这时巨人王宫殿区域飞出两道身影滑落往三位银骑士所在地方。他们是被暗天使影响不知发生什么异变恩尤尼和原本属于克莱恩影子。……贝克兰德。作为一名观众途径半神奥黛丽当即收回目光安抚精神控制住失控征兆。思绪电转间她后退几步使用心理学隐身躲进浓雾没急着潜入因蒂斯和弗萨克联军阵地。躲在不远处奥黛丽同样睡了过去但作为提前暗示过自己梦境行者她很好地保持清醒。然后她抓住不知能够维持多久机会利用梦境穿梭进入联军阵地游走于一个个士兵间隐蔽留下一个个精神瘟疫种子。这瘟疫会让感染者惶恐慌乱情绪崩溃难以被正常办法安抚。奥黛丽没有犹豫在梦境彻底破碎前刹那穿梭到阵地另外一侧远离已埋下精神瘟疫种子人群。进入联军阵地之后她就知道自己心理学隐身很可能被人通过别线索识破比如没能彻底掩盖恶意。所以她在心理学隐身外还利用类似技巧和恐惧之手带来混乱在身边额外塑造一个虚假自己以误导可能存在突袭者。也就是说她心理学隐身下还藏着一层幻影。……恩尤尼和克莱恩影子落在一层蒙着橘红光芒台阶上而三个银骑士各自退后返回到戴里克和克莱恩身边。克莱恩抬手捂了下左脸对着影子和恩尤尼哈哈笑道：你们看起来没法离开那片区域啊。真是遗憾啊这样你们就打不到我了。砰！影子张开嘴巴发出一枚空气炮弹。

## 这场戏有没有翻
翻了。开头银骑士慢反应；章末诱饵礼＋祝安好换秘偶；奥黛丽埋瘟疫；影子开炮。翻的是玩具守卫被天使怨魂翻成听话秘偶。

## 日子
正门平台。黄昏跳跃。联军梦境阵地。橘红台阶嘲讽。

## 这一章落在哪一天
登阶同日；神战前线同刻；门内再会异变。

## 热怎么变冷
四分五裂还热。冷切在祝安好。瘟疫下种还热。冷切在双层幻影。嘲讽还热。冷切在空气炮弹。

# 488 旅行家 第七章 搁浅的提议

## 打开书
又交流一阵太阳戴里克突然冒出问题：「尊敬的愚者先生我们平时感谢您时候该用什么手势？」手势？克一时竟被小太阳考住。从未想过仿造女神教会顺时针点四下画圆风暴教会以右拳击左胸等动作为自己设计一个祈祷手势。这大概是一名伪神最后底线吧…心里吐槽。见愚者目光含笑却不言语仿佛等待自己等人发挥正义顿时有诸多灵感并联想到新问题。目光熠熠环顾一圈：「诸位我们是否也同时设计一个表明自己身份隐蔽动作？我们塔罗会现在成员还不多还不需要担心彼此出现于同一个场合因种种理由变成敌对双方但将来却很难避免我们需要一套特别暗号以分辨谁是朋友谁是敌人。」这个我有想法…一下记起上辈子知道那些秘密手势比如揣手礼。刚要操纵世界提出建议倒吊却开口：「不正义小姐我并不认为这是一个好主意。和其他隐秘组织相比我们塔罗会最显著特点之一是成员互相之间不认识即使额我举个最极端例子即使我们有一位成员被逮捕被拷问也不会影响到其他人除非有谁能对抗愚者先生直接进入这里而这显然不可能。一旦有了整套暗号和密码叛徒出卖就能让敌对势力借助这些方式将我们一个一个钓出来。你们迫切想向别人炫耀自己塔罗会成员身份？」「…」奥黛丽短暂无法反驳只能嗫嚅：「可是…」「你担忧情况也有道理但这可以靠每周固定交流提前设计临时手势向愚者先生祈求等办法来规避。」考虑对方即将提供自己大量金镑语气逐渐和煦。正义有所明悟反问：「最简单例子就是在周一塔罗聚会上提前了解到与某位成员碰面甚至发生冲突可能于是设计一套临时手势以表明彼此身份等事情过去立刻将那套手势废除唔如果遇到突发情况来不及沟通又有些怀疑可以找机会向愚者先生祈求确认是否有别成员参与？」「大致是这样。」无声吐口气。这时太阳也恍然：「抱歉我问了一个愚蠢问题愚者先生从来没提过在感谢祂时用什么手势就是担心我们暴露。」当即又望最上首：「您的意愿就是我们的道路。」我刚想好一个特别手势…轻笑：「不错。」视线移向别成员平和无波澜：「今天的聚会就到这里。」「遵从您的意愿！」月亮之外所有成员同时起身。埃姆林愣一秒才慌忙站起学着其他成员行礼。眼前当即浮现深红色光芒身体有轻微下坠感。紧接着视线恢复正常看见房间内大大小小人偶。呼…直到这时才冷静下来回味第一次塔罗聚会：除了愚者其他成员实力不会太强难道都像我一样基于种种理由被挑中？我背后有始祖他们背后又有谁？真可笑我最开始竟以为太阳是半神级强者刚摆脱一位天使追杀谁知道他才序列8正谋求晋升序列7！一个不懂礼貌小孩肯定还没成年！不过他提到白银城和一直循环经历都很古怪我得找机会询问尼拜斯大人不先询问卡西米以及我父母看他们是否知道白银城哼白银城历史文献竟然敢篡改我们血族事迹！正义小姐是贝克人很有钱很有钱是哪位大银行家女儿或者大贵族子嗣？也许她本身就是银行家爵位贵族…魔术师小姐看我眼神很奇怪一定是仰慕高贵血族她说话不多没怎么透露自身信息嗯是个安静女孩。倒吊先生是位成熟绅士懂得很多品格很高尚愿意为新成员解答问题并提供相应帮助和信息看得出来他很受欢迎太阳和世界都愿意请教他或找他帮忙。世界是个不太让人喜欢家伙说话时候就像嗓子里有口痰始终吐不出来这样人我都不屑于喝他血液有股肮脏味道…他很孤僻很擅于隐藏自身情绪并且轻松就能拿出序列6非凡者特性并承诺两个月内提供一位心理医生非凡特性…很厉害！种种细节闪过发现塔罗会简单又不简单而愚者并没有过多插手聚会进展。祂似乎只对所谓罗塞尔日记感兴趣…但祂愿意为成员们提供神迹般便利。想到这里不自觉有些骄傲于月亮这个身份。环视房间人偶一圈回忆自己问题：4000到5000镑遗物短时间内成为男爵希望真是让我为难啊…这瞬间虽还没做出最后决定但却感觉房间变得更加阴沉感觉自己已背负起沉重债务。……灰雾之上古老宫殿内。克用右手拇指和中指分别按住一侧太阳穴轻轻揉两下。寂静无声环境里很快坐直身体让一枚小型徽章从杂物堆飞出落到面前青铜长桌。那枚徽章只得眼珠大小表面是象征命运与隐匿符号正是当初从兰尔乌斯身上搜出遗物。背后绘刻持有此物即可加入古赫密斯铭文并提供相应聚会信息：「1350年1月4日傍晚8点巴布尔河谷。」现在需要考虑问题就是明晚是否要拿着这枚徽章去巴布尔河谷碰运气。坦白讲内心倾向于不去哪怕已晋升无面人能做相当完美伪装也不太想冒险因为对那聚会没有任何了解。魔术师不做无准备表演…低语掏出枚金币夹于两指之间。用另外一只手拿起徽章低声自语：「参加巴布尔河谷内聚会有风险。」连续几遍后铮一声弹出金币。金币翻滚下落竖直立在掌心。这表明占卜失败。「果然…」并不意外。这不是前置信息不足问题而是根本就没有。沉默坐那里只有金币在指缝间翻来滚去。最终战胜好奇心和冒险精神决定不去。「但这不表明我不能掺和这件事情明晚8点嗯…」勾勒嘴角微微一笑返回现实世界。……1月4日上午10点35分。站桃花心木制成桌子前拿起一叠钞票。这叠有5张10镑面额有10张5镑面额总计100镑正是倒吊刚刚通过献祭方式支付报酬。这15张金镑让钱夹丰满不少终于能安心去购买船票了。放好钱夹又拿起桌上薄薄人皮手套戴到左手。蠕动饥饿一大特点是未使用时本身有伪装效果不会被大部分非凡手段检测出来所以能让它在原本样子各种颜色手套伪装皮肤间切换这一次选择黑色手套。为此还专门准备单独右侧黑手套。紧接着将棕色生物毒素瓶放入铁盒以灵性之墙封锁塞进衣物内侧口袋。至于太阳胸针只要佩戴只要随身携带都会制造出炎热夏季般感受不得不将它放入铁制卷烟盒藏到皮箱底层。「9枚净化子弹15枚猎魔子弹3枚驱邪子弹…」拿出左轮手枪和放子弹盒子边默数边装填。啪！合拢转轮将手枪放入腋下枪袋然后穿上黑色呢制大衣戴好半高丝绸帽子提起手杖和皮箱走出旅馆房间门。除了全黑之眼等无法使用物品还在灰雾之上他做到了全副武装。乘坐马车抵达位于白玫瑰区普利兹港票务公司。这公司位于一座颇为陈旧三层小楼内门口挂着贴有通告木牌。走过去驻足那里随意瞄一眼：「注意事项：1.遵守秩序严格排队；2.不得随地大小便不得随地吐痰；3.有争执请找大厅守卫；4.不能在任何一个房间内开狼鱼罐头！」狼鱼罐头？这是什么？挑了下眉头。

## 这场戏有没有翻
翻了。太阳问手势开；章末票务注意事项狼鱼罐头。翻的是暗号提议搁浅＋不去河谷改掺和，不是入会。

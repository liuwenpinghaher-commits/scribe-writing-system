# 445 无面人 第二百三十三章 “机械之心”的战斗风格

## 打开书
瞬切愚者俯视颔：「不错。」河奔白词改：「忠实仆人阿罗德斯记录探索；可加快跳过。」凝固两秒画面拉近——身旁伊康瑟无人觉；真人真景。虚拟家庭影院？审视：白牧袍软帽慈祥老者＝大主教霍拉米克·海顿半神！慎重或携1级；窥秘占卜——灰雾反卜呈最正常；己莎伦场或现看怨魂／阿罗德斯马赛克讨好。霍画三角：「开始；神庇佑。」不快进跟下。黑大理石阶千年末蚀；不对称石柱刀劈花纹；巨深灰对开石门裂两人缝幽深。马灯搜外围无物。「第一组初步清理。」魁梧二放黑长盒：铁黑炮管密纹＋淡金弹链奇特枪。炮管扛门缝亮炽——轰！微缩太阳金火球入暗！震颤光冒。连发不同位陵摇无尘落。枪队员哒哒淡金弹净化！炮火洗地净化弹——奢侈！这战斗方式？眼圆嘴张。回声伊拔高：「第二组后续清理。」还有…麻。二组皮卷轴咒丢——柔纯光笼；淡金圣雨哗清洗。荒谬：考古学家？不怕垮？「结构未破如预想。」有备。「继续。」门内污迹碎片辨不出怪／机关。几波洗地高序下扛不住——暴力美学。反复推进偶收特性。「没有壁画…」主墓在望霍停疑。克同不解：贵族坟应壁画述一生。伊吩咐两人组搜。想快进——左侧二变三！其一＝伊康瑟帽顶蓬！怔猜。「伊」近队员压嗓：「有发现？」「没有…」话未了变人皮罩身苍白裹勾五官无声！皮下日升光——人皮半透灼腾；黑鞭抽缓；非凡武卷轴淡金弹淹没。灰烬微光奋力聚！人皮幽影！队员扯领太阳护符：「幸好大主教让戴！」领针夜安；指环风暴；皮带力量——符咒武衰减亦贵；工匠富豪才弄齐。烧钱风格！打击呆久。特性聚成巨钻多面各映不同脸密密眩晕。就差它！欣喜。收好继寻壁画无；集合向主墓甬道。

## 这场戏有没有翻
翻了。开头阿罗德斯开播点头；章末人皮幽影特性成型眼前。翻的是炮火洗地烧钱风＋无壁画怪，不是考古收获壁画。

「不错。」「第一组做初步清理。」「没有壁画……」「幸好大主教让我们戴上了这些东西！」局面是从点头收到影院感；从洗地收到暴力美学；从三人收到人皮钻。

# 1262 逐光者 第一百一十三章 最后的守护

## 打开书
短暂停滞后灿烂银白在噼里啪啦声音中向着前方不断延伸彻底淹没科林戴里克和洛薇雅所在地方但却被那两层无形屏障阻隔而没能侵入内部。爬满银白电蛇屏障剧烈摇晃起来出现一道道树枝般裂痕不知道还能在闪电风暴里坚持多久。这个时候暗天使萨斯利尔背后铁黑色宝座侧方雷霆森林没有覆盖到区域克莱恩戴半高丝绸礼帽穿黑色长款风衣身影凸显出来。他就像一台精准冰冷机器没有一点迟疑将手中星之杖对准那特殊恶灵侧后于脑海内飞快勾勒出某种非凡能力相关各种内容。——克莱恩之前已经试验过在巨人王庭内部没法借助星之杖漫游太远只能在小范围内闪现所以他放弃直接将暗天使萨斯利尔送到巨人王庭外面趁机拿走第一块亵渎石板并打开离去之门想法。随着星之杖上镶嵌各种宝石部分亮起萨斯利尔燃烧着漆黑光焰眼睛突然又闭起来。他被克莱恩强行拖入梦境！这是属于黑夜途径序列7非凡能力但克莱恩再现是黑夜修道院院长隐秘之仆阿里安娜使用那个版本——天使层次强行入梦！灰蒙蒙梦境世界里暗天使萨斯利尔穿着缠绕银色丝线铭刻复杂符号悬挂华丽配饰黑色长袍浮现在一片荒野里。观众也属于混沌海相关途径而它序列5叫做梦境行者序列3叫织梦人！祂高大如巨人身影随之淡化面前出现一层异常浓厚阴影帷幕。这阴影完全挡住萨斯利尔只隐约能看出有一双眼睛藏在帷幕后面。转瞬之间这帷幕向着两侧分开露出一片难以描述具体颜色似乎蕴藏着所有秘密海洋。……他嘴角本能上翘虚拟人格瓦解大半险些就发出惨叫他左脸皮肤下隐约可见透明蠕虫一条条扭曲着钻出右脸肉芽越来越多越来越明显也越来越淡越来越接近灵之虫。那强行营造梦境随即瓦解暗天使萨斯利尔意识回归现实。科林直起身体向前劈出右手那把晨曦直剑让银白凝聚锐芒一下闪现到萨斯利尔体表；洛薇雅一边抗衡自身阴影斗篷限制一边让自己放牧那个银骑士恶灵从下往上挥出巨剑带起片片光斑组成可怕风暴；戴里克凝聚出一柄炽白灿烂……太阳照耀下无暗之枪融化了光之风暴平息了银白锐芒黯淡了只能搅碎目标气息无法伤害到祂身体。这真神降临般场景震撼洛薇雅和戴里克让他们忍不住想埋低脑袋顶礼膜拜而那个银骑士恶灵在如此炽烈阳光中飞快消融彻底蒸发了。祂侧后方克莱恩在身上灵之虫不断蒸发消失情况下顽强承受着烈日暴晒将星之杖指向这天使之王衍化出恶灵。他重现还是刚才那个非凡能力再次强行将暗天使萨斯利尔拉入梦境！但和刚才不同克莱恩一进入梦境就立刻展现出本身源堡气息化身为那扇沾染着些许青黑奇异光门光门由数不清层层叠叠虚幻光球组成每一个光球本质都是合抱透明和半透明扭曲蠕虫。和他一样暗天使萨斯利尔显露出来自混沌海特殊祂先是变成森然浓厚阴影旋即拉开帷幕让那片包容了所有颜色无法用人类语言描述海洋呈现于梦中。……他们一个覆盖上淡淡阴影一个表情变得扭曲狰狞有不少灵之虫于体表到处乱爬。趁着萨斯利尔受到影响机会披着阴影斗篷洛薇雅淡灰眼眸闪烁一下用那团两米高蠕动血肉里长出没有皮肤流淌着鲜红黏液一双双腿脚同时往地面一踩借助卷起狂风扑向那位暗天使。呜风声里她崩溃身体连带那阴影斗篷落在暗天使萨斯利尔体表。进攻！他两把晨曦直剑同时斩破虚空让银白光芒在纠缠于一洛薇雅和暗天使萨斯利尔身周爆发开来。笼罩着森然阴影宫殿一下变亮布满神圣火焰巨大光球凭空浮现将暗天使和洛薇雅包容于内飞快消融着他们点燃血肉。阳炎！我没有背叛白银城……话音未落她覆盖在暗天使萨斯利尔身上血肉和阴影斗篷同时膨胀起来。暗天使萨斯利尔变成一片漆黑粘稠满是堕落气息海洋将残余银白锐芒和阳炎吞进去消弭于无形。……心智剥夺！戴里克刚凝聚成形无暗之枪戛然消失整个人因震撼僵立在原地；科林虽然意志无比坚定但也被唤起不完整神话生物形态自带疯狂残忍与嗜血只能分出精神对抗起这方面影响以免直接失控；克莱恩刚平复状态让身上灵之虫钻回去……这时暗天使萨斯利尔抬起左掌眼中金黄被两团炽白微缩太阳取代。她崩溃成一团血肉身体蜷缩起来用那一条条没有皮肤满是鲜红黏液手臂将那个乳白色偏大型人类头骨紧紧抱在胸前压到身下。炽烈阳光照射中神圣火焰燃烧里洛薇雅保持这个姿态不让自己有丝毫动弹不让那个人类头骨显露出来受到伤害。……暗天使萨斯利尔击杀洛薇雅过程中克莱恩依靠本身特殊和过去经历快速从心智剥夺带来影响里恢复过来对于这场战斗产生一种难以遏制绝望。怎么办？克莱恩一边使用蠕动饥饿改变自身位置一边思绪电转寻找对方可能存在弱点。部分恶灵有非凡特性但大部分没有它们力量源于别地方比如灵界；恶灵存在需要凭依这或许是祂诞生领地也或许是特殊事物共同点是恶灵可以借助它们连通灵界甚至冥界获得维持自身存在力量。而当前这个源于暗天使萨斯利尔也许还糅合一点原初意志恶灵祂力量来自哪里？这里是神弃之地和灵界联系被封印近乎完全中断很难有效利用克莱恩能够传送靠都是神国或神国雏形特殊而巨人王庭显然无法为恶灵提供观众太阳倒吊人阅读者和暴君途径力量暗天使曾经拥有特性则明显归属了……混沌海！阴影宫殿内与混沌海有直接联系则是那块亵渎石板！克莱恩望向铁黑色宝座时发现白银城首席科林也扫了那里一眼。

## 这场戏有没有翻
翻了。开头侧后入梦翻车见海；再梦对源堡；洛薇雅扑身喊未叛；章末阳炎杀她抱头骨死守、双双望向石板。翻的是最后守护＝头骨／洛薇雅＋弱点钉石板。

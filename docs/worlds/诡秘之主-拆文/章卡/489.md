# 489 旅行家 第八章 前水手的忠告

## 打开书
普利兹港票务公司大厅相当宽敞有足足七个售票窗口但每一个窗口前都已排了十几二十个人。克瞄一眼未直接去人数相对较少那列而是往右跨两步来到笔直竖立一块棕色木板前。木板之上贴着连续白纸将最近一周客船信息全部公布包括目的地所经港口不同舱位价格等。还未来得及细看就有工作人员过来在其中一行二等舱位置画了个红圈标记一个单词：「已售尽。」「很抢手啊…」小声感慨。「当然普利兹港是王国最大港口数不清的人通过这里去南大陆和那些殖民岛屿寻找机会。」一位站木板旁边中年男子略显浮夸回应。戴黑色软帽穿黑白格类警察制服但没有肩章只在胸口挂块海鸥徽章——与普利兹港票务公司标识一模一样。这位中年男子脸庞双手以及所有裸露皮肤都呈古铜色颇为粗糙像长年经受海风吹拂和太阳暴晒以至于给人盐粒渗入皱纹感觉。有争执找大厅守卫…这应该就是守卫了…想起门口注意事项并未介意对方主动搭话微笑：「你对这个港口似乎很了解？」听到这问题那中年男子相当得意：「我曾经是王国海军水手他们主基地就在普利兹港橡树岛我服役了15年在这里在海上度过一段漫长时光如果不是东拜朗战争摧毁了我健康我还能再做10年水手！我对这个港口了解就像我对我妻子身体一样！」有点文化又有些粗俗…本着打探海上消息心思随意闲聊：「退役之后你就到这里做守卫了？」「不我被塞进一个夜间学校足足两年又做学生又当看门人风暴在上你能想象我这个年纪人和一帮几岁十几岁小孩一起朗读场景吗？而且他们认识和记住单词速度都比我快！」守卫露出不堪回首表情。说着拍拍大腿外侧叹息：「可惜每到湿冷天气我膝盖就受不了否则我还会兼职做夜间学校老师那些小孩会让你感觉自己变得年轻不过我不否认我是为了赚更多钱当你有一个妻子和四个小孩时候就必须认识到你得支撑起家庭。」先生你话有点多…这也许就是票务公司雇佣你当守卫原因…没去接对方话题笑笑：「我刚才看了门口注意事项发现这里不准开狼鱼罐头坦白讲我从未听过这种东西。」守卫表情忽然变得复杂。捏了捏鼻子：「那是流行于弗萨克东岸加尔加斯群岛等地方食品是用盐腌制狼鱼但保留着血水气味气味非常非常非常刺激又臭又恶心！」原来是一种黑暗料理…哈哈笑：「但我想没谁会在排队买票时候特意吃罐头吧？」「不你不明白那种感受也许有一天你能体会到。」一脸后怕：「曾经有个北方野蛮人来这里买票但前面已经排很多人将大厅塞得就像装满鱼木桶他很着急于是打开了狼鱼罐头不到十秒整个大厅就只剩下他和少数几个家伙。」这这是生化武器啊…生物毒素瓶普通版…好笑：「最终他顺利买到票而外面多了新注意事项？」「结果并不像他预料那样负责售票女士和先生也逃出去了呵呵你知道野蛮人脑子比卷毛狒狒还差！」啧啧笑：「我还是水手那会海上曾经有这么一个传闻一群海盗控制了一艘来自劳斯商船啊那是弗萨克东岸一座城市总之那些海盗迫切打开自己战利品谁知那是一个个装满腌狼鱼木桶结果你能想象结果吗？他们晕了呕吐了失去战斗力成为船员们赏金。」「不错的故事。」忍着没发出笑声。将目光重新投向木板纸张寻找1月5日船只信息。作为专业人士事前占卜过这周内适宜出航日期一个5号一个8号而在5号前往罗思德群岛客船里最契合他是圣弗尔安号和白玛瑙号。都还有票价格也差不多三等舱4镑二等舱10镑一等舱35镑…靠大海为生人或多或少会信仰风暴之主即使在因蒂斯弗萨克等国也有渔民和船员悄悄信仰这不被允许神灵以求出海顺利…圣弗尔安号这名字一听就来源于风暴教会圣者有一定背景…仔细想了想倾向于选择白玛瑙号。没急着决定转而望守卫：「你知道白玛瑙号情况吗？」守卫顿时露笑容：「先生你眼光不错白玛瑙号是蒸汽船但又保留着风帆最高航速能达到16节。而且船长经验丰富曾经是王家海军威廉五世号水手长不应该是皇家海军国王一直宣称他拿到拜朗皇帝称号呵在皇家海军里普通人再怎么出色再怎么优秀也顶多能成为水手长无法担任军官除非除非你能让你长官满意不管用什么方式任何方式！只有这样你才能被推荐去普利兹海军学院成为预备役军官！艾尔兰就是这样被逼着离开海军加入白玛瑙号一步步成为船长。我建议你选一等舱那样你将有可以睡三到四名仆人房间有接受过礼仪课程侍者有指定手艺出色厨师有能欣赏风景安静餐厅有抽雪茄专门房间有聚在一起打牌场所…」见守卫说得如此详细不由有些狐疑。注意到表情守卫讪讪笑：「艾尔兰以前是我上司他经常会请我喝酒让我帮他推销一等舱但你可以放心我说每一句话都是真的！」这不是真不真问题这是钱问题…无声自语一句。已然有决定斟酌又问：「先生你对一名海上冒险家有什么忠告？」为契合格尔曼·斯帕罗身份之前微调形象让自己显得更为冷峻和锐利。「冒险家？」守卫不自觉拔高声音。排队等票队伍里不少人闻声转头将目光投向克。根据灵性直觉本能循着一道视线望过去。看见位戴黑色礼帽三十来岁男子对方有着粗犷面容沾染风霜线条健壮但不够挺拔身材以及经历过很多事情般淡蓝眼睛。也是冒险家？和那位男子目光略有接触就各自移开。这时守卫挤出笑容：「抱歉我对冒险家这个名词有些过激在我印象里这就等于亡命徒海上恶棍和背弃誓约者不我不是在说你。诚恳劝告？我额你要记住三点。一不要招惹海盗二不要招惹海盗三还是不要招惹海盗！除非你是海军和教会人否则不要和海盗作对！」「额…不要被岛屿上那些女孩热情迷惑她们要么是海盗人要么想让你带她们到普利兹到贝克这并不完全是她们问题许多水手船员和乘客为了欺骗她们身体给她们描绘非常诱人大都市和异常美好生活然后又将她们踢下自己床丢弃在原本地方。」真是一群恶劣人…这个时代在海上讨生活人也不会太善良就是了…海上秩序这么差？海盗竟然这么猖狂？点点头：「谢谢我明白该怎么做了。」说完走向人数最少那列队伍。守卫则在后面喊：「还有海上宝藏传说基本都是假的！」……买了张白玛瑙号二等票后返回旅馆耐心等待夜晚来临。这过程享用普利兹港最出名炸鱼觉得味道还算不错但要是一直这么吃肯定接受不了。当时间接近8点进入灰雾之上一手拿着来自兰尔乌斯徽章一手书写相应句子：「这次聚会的情况。」滴答滴答等怀表指针走到预定8点位置闭上眼睛靠住椅背开始反复念诵占卜语句。有理由相信当聚会之门开启时有定位徽章自己能在灰雾之上借助这个媒介占卜出一定东西！之前失败因为什么都还没有出现这次则不同事情正在发生而克有足够准确媒介！很快进入那片灰蒙蒙梦境世界。看到静静奔涌塔索克河看到夹于两侧宽阔河谷看到十几个人在不同位置被稀薄光芒笼罩或模糊或虚幻消失在原地。其中一位黑发绿瞳长相不错俨然便是克熟人。伦纳德·米切尔！

## 这场戏有没有翻
翻了。票务厅开；章末梦境见伦纳德。翻的是忠告＝别惹海盗＋远程掺会看见熟人，不是上船启航。

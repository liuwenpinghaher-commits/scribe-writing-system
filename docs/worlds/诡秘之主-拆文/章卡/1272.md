# 1272 倒吊人 第七章 可怜的阿罗德斯

## 打开书
克莱恩并没有去看班森和梅丽莎因为他牵扯层次已经太高靠近哥哥和妹妹只会给他们带来灾难——对不清楚克莱恩原本身份存在来说类似行为会帮助祂们了解班森梅丽莎与克莱恩之间关系于知道克莱恩之前经历存在而言这会让祂们确认一件事情……所以远离班森和梅丽莎就是对他们最好爱护。当然克莱恩早就通过正义小姐掌握哥哥和妹妹情况：班森在战争中财政部展现自己老练和圆滑得到多次提升已成为第五司副处长年薪达到300镑；梅丽莎受到导师波特兰·莫蒙特青睐给了她一个机会成为非凡者机会——那位贝克兰德技术大学校长是蒸汽与机械之神信徒早就踏入非凡途径目前是序列7鉴定师他希望梅丽莎成为序列9通识者以便更好地学习知识提升记忆……这是梅丽莎秘密但瞒不过半神层次观众而且奥黛丽肯定告诉克莱恩梅丽莎倾向于答应最近几天就会做出决定。对于这件事情克莱恩态度是默许一方面通识者途径提升灵感相当有限梅丽莎不太会听见不该听见声音看见不该看见画面另一方面随着末日来临较低序列魔药造成疯狂可能进一步降低而且还有他这位奇迹师帮忙降低失控风险……对一名机械爱好者来说序列9通识者足够用了……莫蒙特态度也是这样他并不希望让一位黑夜女神信徒得到太多份来自蒸汽教会魔药……嗯末日一天天临近无形屏障越来越脆弱外神们对这个世界侵蚀会越来越明显普通人遭遇超凡事件概率绝对会逐步变高从这个角度考虑梅丽莎成为非凡者也是一件好事如果她能顺利晋升序列6工匠也就是机械制物专家既可以满足梦想……让正义小姐找机会不露痕迹地将扮演法告诉梅丽莎之后她能成长到什么程度就看她自己了我顶多能给她一些好运呃配方材料……我真像是一个操碎了心哥哥呵本来就是……这算不算某种意义上实现愿望？等等梅丽莎肯定有让克莱恩复活心愿我要是现在直接走到她面前会不会得到足够反馈？……算了这会给她和班森带来毁灭性灾难……克莱恩摇了摇头制止自己找借口行为。——之前那场战争里克莱恩通过正义小姐陆续又捐了14800镑钞票战前就价值14200镑金条和近二十颗高品质宝石目前除了放在杂物堆那些奇奇怪怪物品身上只剩下39枚鲁恩金币和十颗高品质宝石。紧接着他拿出纸笔画下召唤魔镜阿罗德斯咒文。……头发乱糟糟伊康瑟和一位机械之心队员站在某个车厢内专注盯着前方那个金属制成笼子。……执事这次去了因蒂斯你还准备回鲁恩吗？那位有着典型鲁恩人长相机械之心队员看了眼窗外飞快后掠平原忍不住开口问道。战争结束后立场错误蒸汽教会不得不吞下失败苦果必须在黑夜和风暴两大教会规定限期内将半神以上非凡者和2级以上封印物全部转移出鲁恩。如果不是信仰蒸汽和机械之神民众太多部分还属于战后重建关键人物蒸汽教会或许连这样待遇都无法保留。同样少量教堂只需要少量机械之心成员蒸汽教会在鲁恩大部分非凡者都得迁徙去因蒂斯。……我得听从大主教们安排但我会主动申请回鲁恩这里有我童年少年青年有太多我无法割舍回忆……魔镜反应很激烈啊……它以前一直很安静。刚才问话机械之心成员颇为疑惑开口道。并不是这样它有时候也会展现出疯狂一面如果不是发生了那些事情我们还将它当做2级封印物对待。这样啊呵呵我之前没接触过我还以为魔镜不想离开贝克兰德。那位机械之心成员笑着调侃一句。……只维持两分钟比上午好多了。旁边刚调过来机械之心成员正要开口询问突然听见砰砰砰拍打声猛地停止似乎受到什么不可抗拒因素影响。这就是魔镜风格？他转而问道。并不是。正常来说它还会没什么力气一样坚持二三十秒。似乎有点问题……执事不用担心列车上有真正大人物位居大主教们之上大人物。旁边机械之心成员不甚在意地宽慰一句。……他刚勾勒完隐秘与窥视糅杂符号镜子之上就泛起波光浮现出一个又一个金色鲁恩文：至高至大至上主人您终于来了！您谦卑忠诚可怜仆人阿罗德斯好想你啊！如果说魔镜阿罗德斯之前讨好还保持着一丝尊严那现在就是完完全全谄媚甚至让克莱恩看出一丝哭腔。特里尔桃色新闻发生率远超贝克兰德这应该是你喜欢地方。克莱恩笑着打趣阿罗德斯一句。因为主人您并不想去特里尔。镜子表面金色单词相继退去颜色变成淡银。克莱恩暗自啧一声：我有些事情想问你。您尽管提问。阿罗德斯相当谦卑回应道。你知道大地母神究竟是谁吗？克莱恩直奔主题。我不知道……但神战时我有听见深黯天国内传出一个声音祂在喊一个名字……那是那是血族始祖真名。这魔镜没敢直接展现莉莉丝这个名字。……然后他想到月亮埃姆林。如果埃姆林有安德森那种性格现在肯定会对血族大公侯爵们说哟你们也来信仰母神了啊……克莱恩一边想象着好笑场景一边对魔镜阿罗德斯道：该你提问了。至高主人您继续问我最后一起问。惨白单词恢复淡银色泽。克莱恩想了想道：现在局势怎么样比如弗萨克国内情况。

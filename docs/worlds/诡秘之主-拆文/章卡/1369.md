# 1369 倒吊人 第十七章 决断

## 打开书
黑夜女神梦境投影语带少许笑意回答道：如果只是为了扶持一位诡秘之主出来那我更应该押注阿蒙至少祂成功可能要比你高很多。不等克莱恩再问祂语气轻飘如梦境般继续说道：埋葬在旧日那个时代是我们共同回忆也是我们人性初生萌芽滋长关键时期。哪怕我已经拥有漫长生命它依旧是我最美好记忆。你有它烙印所以我更愿意帮助你。……故乡。他满是感慨沉默中黑夜女神梦境投影转而说道：等你准备好随时可以去霍纳奇斯山脉主峰。当然怎么选择是你自由没有谁会逼迫你也没有谁能逼迫你。你完全可以选择停在某一个阶段不成为旧日不让诡秘之主在体内苏醒然后于末日来临时带着自己想要保护人和物漫游去别星系别星球躲避外神们注视再造一个文明。……我不清楚罗塞尔有没有说过一句话：躲得了一时躲不了一世。他和黑夜女神对话用是巨人语那句俗语翻译过来略有点奇怪：……宇宙虽然浩瀚没有边际但外神明显比我们更加熟悉它也更为强大直接代表着整个宇宙某方面象征要想躲过祂们搜寻非常困难。而且即使能够成功也只能安稳一段时间再造文明不超过千年又会毁灭到时候连成为旧日机会都没有了永远无法自我救赎。……黑夜女神梦境投影嗓音轻缓说道：除去直接从外神那里撕扯来事物只是带走其余途径唯一性和高序列非凡特性外神们未必会在意不会花费太大精力去搜寻。您也说了只是未必外神们对相似领域唯一性和高序列非凡特性应该还是有一定渴望这能帮助祂们接近支柱。克莱恩平静回应道我们不能将希望寄托于祂们心情上祂们没有仁慈可言。黑夜女神梦境投影点点头道：在这方面你比罗塞尔清醒当然也是因为他知道旧日外神们事情太迟了。……你还有另外选择：利用帕列斯办法自降位格并让阿蒙窃取走源堡。这样一来你就能以序列1大天使身份很好地活着不用时刻担心诡秘之主在你体内苏醒也不用太累。……听完黑夜女神话语克莱恩沉默很久然后才开口问道：阿蒙可以信任吗？黑夜女神梦境投影坦然说道：我无法给你确定答案。……如果诡秘之主在阿蒙体内苏醒祂是否会收回占卜家偷盗者和学徒三条途径所有高序列非凡特性？我不知道。黑夜女神梦境投影以同样口吻回答道。……对我个人来说我并不渴求成为旧日但是我不能辜负背弃在我身上押注那些存在祂们或多或少都帮助过我。一旦阿蒙成为诡秘之主祂必然会帮助远古太阳神收回风暴之主知识与智慧之神处唯一性和序列1非凡特性导致祂们陨落。而且阿蒙是个肆意妄为神灵。黑夜女神梦境投影轻轻颔首道：你人性维持得不错。……如果人性维持不好让神性获得优势我同样会做出类似选择因为神性本能是以我为主聚合。黑夜女神梦境投影轻柔笑一声：去做准备吧尽快去见安提哥努斯。……阿蒙是否已借助门先生仪式容纳学徒途径唯一性？黑夜女神梦境投影缓慢回答道：如果是别存在那肯定没有。但若是阿蒙有一半概率。他天性喜欢冒险寻求刺激。克莱恩不再多言看着眼前黑夜女神投影消逝看着梦境柔和垮塌。……于他而言前往霍纳奇斯山脉主峰面对安提哥努斯家族先祖需要做准备并不多主要是依靠源堡弄一个分身出来窃取走自己还未消化曾经属于查拉图那份诡秘侍者非凡特性让本体处于可以容纳唯一性状态中。——随着本身精神状态稳定下来哪怕没有查拉图残留精神烙印纠缠克莱恩也能依靠自己人性意识和锚勉强压制住天尊复苏部分意志了。……因为刚写完前一封没多久这次内容并不多他只大概提下卡尔德隆地底永暗之河与徘徊于支流两侧死亡烙印们重点讲讲自己看到多个阿兹克·艾格斯以及对此猜测。……克莱恩将信纸递给它后又从源堡内摸出一枚金币：这是长久麻烦感谢。如果你不能主动接收就交给你主人由祂分配。这枚金币是克莱恩那五枚沾染源堡气息产生一定变异金币之一。……与此同时他让源堡内轮值灵之虫们看某颗深红星辰一眼。……找机会把那枚金币拿到手中。……我似乎错过你两次生日。克莱恩笑着说道这是一份迟到礼物。……这是给你幸运金币。……出生礼物是幸运护符生日礼物是幸运金币你真没有创意。克莱恩笑笑站起身来消失不见。

## 这场戏有没有翻

# 461 无面人 第二百四十九章 什么是奇迹

## 打开书
愚轻笑不语——众收目认神级只给名／启示。正义期心理医生后揣摩。倒吊侧太阳：「半废庙有救赎蔷薇文？」「是；壁画角巨人语衍化；费时破解。」巨人语…杰克疑苏尼亚过…具现古弗萨克源词「救赎蔷薇」。太阳愕：「近；词尾异。你处文字？」重现壁画词。「对；语言演变；你们更早期。」所罗门帝国特征——史家克心答。倒吊：「对应壁画内容？」「未负责区出发未细看…」愧。点：「找机会弄清或关键。」「好！」松。正义疑：「杰克真倾听者子怎与太阳通？」语言异；灰雾畅靠愚伟力赞。倒吊呵：「没怎经历超凡？杰克已怖怪有何不能改？语言获易一两秒。」奥眨暴露无经验。常程：正义「又三页罗塞尔日记；还欠七。」佛「收回复下次有新。」「很好。」太阳愧探索无翻馆。克期待读三页：八月八首入白枫宫舞会——贵族奢侈烤天鹅羊睾；爱干净洗澡厕纸雏≠地球中世——因某途非凡借脏习播瘟疫被迫改。克想：怕瘟何不清街建下水道改贫？同城瘟这边无事？水源隔或可——气传呢！居高必推城建环境！召见：自认平等仍弯腰低头——权势魅力。日常逗笑亦有追求。二页十一月十即将晋序4半神质变非短生。二选：通识炼金术士／窥秘神秘学家——不改路隐匿贤者危疑非真神位低。炼金＝物注魂给生命造物感；构想挂逼有高达！仪抽区域全生命力土沙湖干≈邪祭。魔药系灰暗疯偶绝望。克同感背景灰黑疯；守恒聚合互换残忍向。炼金生命炼成禁忌近神；暗杀前有无高达？神秘学家亦不错。三页四月二三贵族乱：凯伦夫人勾搭——夫香槟伯爵邻偷窥还想肛！踹出：「比他家我纯洁孩！」无言私生活精彩…四月二五天鹅湖钓望海钓美人鱼；振奋发明打烙印——克抽：还是堕落好。末则四月二六查拉图串门故意问何奇迹？反问你觉？心：文明奇观如弗萨克黄昏巨殿巨人王居。查拉图正答：「什么是奇迹？死而复生就是奇迹！」

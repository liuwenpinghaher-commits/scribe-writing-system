# 1361 倒吊人 第九章 见证

## 打开书
作为以密修会成员身份加入因蒂斯对外安全总局非凡者安托万并非第一次遭遇类似事情。在过去某些场景下在每次晋升时他都会听见霍纳奇斯……弗雷格拉……霍纳奇斯……弗雷格拉……呓语好几次险些因此失控。而和以往不同是这次低语内容似乎发生变化。……我最近精神状态很稳定也没有服食魔药尝试晋升怎么会听见隐秘存在低语声？这和之前似乎有一定区别……奥维尔代表什么？我缺乏足够信息完全没办法解读……第兰第兰嗯会内高层提过我们那位神秘可怕首领曾经将一座叫做第兰古堡隐藏起来……嘶一回想起那位存在我就忍不住颤栗虽然祂最近两年恢复正常但祂之前留下那些恐怖传说和实质破坏都足以让人做一辈子噩梦……查拉图还没有死透？克莱恩收回目光低声自语一句。……也就是说这里面只包含一份奇迹师非凡特性。而命运之蛇威尔·昂赛汀说过查拉图和安提哥努斯家族那位先祖一样都多占有一份奇迹师非凡特性。所以现实情况毫无疑问表明查拉图身上有一份奇迹师非凡特性消失不见了……看来祂将那部分包含奇迹师非凡特性以特定方式隐藏在某个地方并做多重掩盖否则我晋升诡秘侍者时就可以借助源堡直接看到了……嗯之后应该就是以预留隐秘方式引导特定对象去复活祂呵祂又没容纳过唯一性没法做全频道广播而且还得提防晋升后我或者阿蒙听到相应内容做出一定破坏所以祂能够引导目标群体相当有限……密修会全体成员或者部分成员？……占卜家途径高序列者怎么就这么难彻底杀死？……对半个愚者来说死亡或许就意味着新生！不过嘛精巧复杂隐秘布置往往意味着承担风险能力较差说不定查拉图复活布置会便宜密修会哪位幸运儿这甚至比祂从历史迷雾里奇迹归来可能要大还有存在被外神干扰影响和利用概率……克莱恩在心里嗤笑一声缓缓站起来。他暂时没有寻觅那份奇迹师非凡特性想法因为阿蒙这个错误带来巨大压力下他不得不抓紧时间增强人性稳定精神状态前往灵界城市卡尔德隆深处取永暗之河河水以便容纳愚者唯一性根本没时间在无关紧要事情上浪费。等到他成功提升让局势重新获得平衡他倒是不介意前往因蒂斯从密修会成员入手找出查拉图隐藏起来宝库让这位第四纪存活下来天使彻底安眠。……属于他自己那部分自我认知和自我意识因此逐渐恢复一点点加强目前已能更好地配合锚压制天尊在一定程度上复苏意志。这让他精神状态稳定性比见黑夜女神时强不少。……最先浮现于他眼前是一个不大广场和一座属于黑夜女神教堂。……还是穿得这么老气还好没弄一套黑色来……克莱恩嘴角微勾嘀咕一句走到教堂一角找个位置坐下。……笑得像只卷毛狒狒……在仁慈女神注视下我将见证一场神圣婚姻。赞美女神。在座宾客们只要是黑夜女神信徒都同时抬起右手在胸前顺时针连点四下画出繁星。……露丝·布鲁克女士你是否愿意身旁这位男士成为你丈夫与你缔结婚约？你是否愿意在之后漫长一生里无论贫穷还是富贵无论疾病还是健康都爱着他尊重他陪伴他照顾他直至生命尽头？那位叫做露丝女士看着黑夜女神圣徽郑重点头道：我愿意。……班森·莫雷蒂先生你是否愿意身旁这位女士成为你妻子与你缔结婚约？……我愿意！

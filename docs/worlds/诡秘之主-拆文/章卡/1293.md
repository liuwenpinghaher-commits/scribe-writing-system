# 1293 倒吊人 第二十八章 对话

## 打开书
如果刚才那个半神生物没有自动撞入恶魔油画我就得召唤世界先生历史孔隙影像了……呃不知道这算不算直接请天使层次帮手……佛尔思一边想着一边喝下魔药。对她来说那瓶魔药就像是温度极低可以将人冻伤冰水所过之处她一切感觉消失只剩下思绪还未凝固。一个人极度寒冷时难免会产生幻觉佛尔思视线内瞬间出现一片夜空夜空里密密麻麻璀璨星辰交织成梦幻河流。佛尔思体表随之映出一点又一点星辉这似乎来自于她本身。……那是她利用恶魔油画完成封印它投射到这因魔药产生神秘世界内形成一个抽象模糊标记。……霍然间佛尔思脑海内那个抽象标记变得相当清晰那是一扇层层叠叠绘满神秘符号门。这扇门将佛尔思隐藏在自己后面让她与周围星空隔绝。与此同时门另外一边被封印那个恐怖生物似乎感应到仇敌气息利用自身神性疯狂侵蚀起那虚幻之门这恰好与外界星空对佛尔思影响抵消。……当然这里面肯定有好运影响。……门先生每当满月就疯狂喊救命简直是天使之王里耻辱……不过哪怕祂是在求助对我来说也是难以承受恐怖……佛尔思腹诽两句思考着是假装没听到等初步收敛灵性掌握秘法师非凡……你用是来自亚伯拉罕们非凡特性。……你是谁？佛尔思定定神故意问道。……你可以称呼我门先生。你对我应该不会陌生。这位第四纪天使之王直接就点明佛尔思与祂有一定联系能听见满月呓语。……尊敬门先生您是亚伯拉罕家族先祖伯特利殿下吗？是的。那您是否知道您求救让整个亚伯拉罕家族陷入长达一千多年诅咒里基本没人能成为旅行家甚至记录官？他们总是在晋升时或满月夜晚失控成怪物。佛尔思觉得自己不能和门先生长久对话……门先生默然两秒道：他们已经没有秘法师没有别半神了吗？在四皇之战后就已经没有而您带来诅咒让他们无人能够晋升半神如果您可以停止呼救十年也许就会有新亚伯拉罕半神诞生这对您脱困更有帮助。佛尔思诚恳提出自己建议。门先生叹息一声道：我被放逐在永恒黑夜里遭受着不会停息风暴阻拦没法知道现实世界发生什么事情也没想到整个亚伯拉罕家族竟然没剩下一个半神。撒谎……冷静做出这个评价不是佛尔思而是容纳着愚者牌拿着星之杖坐在源堡内密切监控着对应深红星辰克莱恩。他记得大帝在日记里提过门先生对现实是有一定了解——祂似乎可以借助满月带来变化看见和听到封印外情况。叹息之后门先生继续说道：而且满月时呼救不是我能够控制。为什么？佛尔思一阵诧异脱口问道。门先生嗓音飘渺说道：你已经是半神应该很清楚一点那就是序列越高疯狂威胁越大。一个正常天使即使能自由行走于地上做自己喜欢事情不需要进行额外战斗也有可能逐渐被非凡特性影响变得不像自己甚至出现半疯情况我一个被放逐被封印一千多年连交流对象都没有天使之……每当满月来临我疯狂部分就会得到加强让我无法控制只能一直不停呼救。……有什么能为您做吗？亚伯拉罕们又该怎样才能消除诅咒？门先生沉默几秒道：布置仪式帮我脱困那样一来诅咒将不复存在。仪式有两种一是以占卜家学徒偷盗者途径半神各一个为祭品……二是抽取亚伯拉罕家族至少九十九位非凡者血液用它绘制一个这样符号……我会转告他们。佛尔思当即回应道。与此同时她在心里补一句：前提是得到愚者先生允许。门先生笑笑道：如果我能因此脱困我会帮助你成为天使……不过这幕场景彻底淡化前佛尔思透过它们隐约看见一片深红岩石组成广袤大地看见那里屹立着一个类似金字塔古老建筑看见那建筑后方黑暗深邃星辰闪烁与自己这占星人在地上所见星空截然……等初步适应秘法师状态她立刻摆出祈祷姿势将自己刚才经历原原本本汇报给愚者先生没有一点遗漏。做完这件事情佛尔思才收起恶魔油画传送回普利兹港与等待在仓库内老师多里安·格雷·亚伯拉罕见面。……感谢愚者先生庇佑。他终于教出一位没有反叛序列4秘法师。因为愚者先生还未回应佛尔思没有将自己与门先生对话告知老师准备等下次满月后再说。……除感谢愚者先生还得感谢老师您。……克莱恩对门先生自称已经半疯事情倒是没什么怀疑只是觉得这里面可能还藏着更多隐秘比如当初门先生为什么要一直诱导罗塞尔大帝去月亮之上那里可是被一位外神占据地方。想了想他从历史迷雾里拿出深红月冕和万能钥匙打算主动制造满月环境再听一听门先生呼喊。……不要救我……不要救我……

## 这场戏有没有翻
翻了。开头灌药成秘法师；门对话给两仪式；克莱恩判撒谎；章末自造满月听「不要救我」。翻的是对话＝求救表象下不要救我。

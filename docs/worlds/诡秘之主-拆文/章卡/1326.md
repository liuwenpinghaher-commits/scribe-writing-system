# 1326 倒吊人 第六十一章 三个方案

## 打开书
对于秘偶城镇克莱恩很早前就在思考该怎么创建已初步有三个方案：如果排除掉外在因素干扰他最好选择就是于北大陆某个国家某个地方直接让秘偶城镇一夜之间拔地而起并且通过铁路河道公路与周围城市相连。这样一来秘偶城镇每天将有大量外来者抵达并和周围区域产生非常强互动……各种强互动影响下用不了多久秘偶城镇就能于灵界诞生对应区域等到居民们命运轨迹随之变得精细和真实克莱恩就可以服食魔药晋升序列1诡秘侍者了。……等到秘偶城镇消息传播出去克莱恩毫无疑问会被查拉图阿蒙本体等敌人盯上到时候破坏肯定比保护容易他只能带着自己秘偶城镇转移地方这会导致前期互动失去效果就和当初乌黯魔狼经历一样。所以克莱恩只是列出这么一个方案基本不会选择除非某个空想家愿意提供帮助让南北大陆所有生灵都理所当然认为那里确实有一座城镇不是突然冒出来。……考虑到各种外来因素影响和自身具备非凡能力克莱恩最稳妥选择是将秘偶城镇建立在偏离安全航道且足够隐蔽无人岛屿上并利用源堡做反占卜和反预言布置。同时克莱恩会依靠那块幕布将部分公路河道和铁路某个节点嫁接到秘偶城镇外面让这成为某些人旅途其中一站。这不能完全保密但等到怪诞现象传播开来可能引起查拉图和阿蒙注意后克莱恩可以轻松解除原本嫁接没有规律改换入口。这样策略下转移就只是入口而不是秘偶城市本身各种互动于灵界产生影响可以保留不会被打断仪式能够稳定推进。……如果选择这个方案意味着克莱恩得花费大半年甚至超过一年时间在仪式上。……在激进和保守两个方案间克莱恩还有一个折中方案。……克莱恩仗着有诡秘侍者非凡特性形成幕布可以有更好选择：将那座城市某个阶段嫁接到自己秘偶城镇上。……过程中克莱恩还会派出秘偶扮演外来者与对应真人保持互动让真正外来者回归现实后可以无缝接入。……这相当符合诡秘这个特点且有一定隐秘性。……笃笃笃克莱恩手指轻敲着斑驳长桌边缘在第二和第三个方案间犹豫不决。……当初查拉图安提哥努斯大概率选择是第三个方案……克莱恩叹口气准备返回现实。……这一点克莱恩早就从夜之启示录风暴之书等正神教会圣典内容里得出结论：……如果说在古老年代里信徒对神灵形象认知确实会对神灵产生一定负面影响那用符号代替神像当前已经没有这个隐患至少黑夜女神风暴之主等神灵都大大方方宣称自己是最初那位造物主某个部位所化一点也不担心这会加剧自身体内原初……也就是说这方面若真存在问题克莱恩相信黑夜女神肯定已经将相应描述改掉……同时信徒对某些事情承认也不会对神灵本身造成神秘学意义上负担否则阿蒙早就秘密帮克莱恩或者说之前源堡准备一批信徒诱导他们形成时天使是诡秘之主化身这个认知并借助符合条件本能回应与源堡建立起足够联系……正是因为有这样认知克莱恩对圣典一直都不怎么重视翻完前面描述自己权柄和尊名部分就尴尬得不想看下去只是用占卜方法确认下会不会与正神教会们发生冲突。……在塔罗会交流里通过世界格尔曼·斯帕罗诱导太阳调整认知将涉及时天使部分往帕列斯·索罗亚斯德方向靠在不引起白银城怀疑情况下让相应内容获得修订。……班西港是一个充满神秘学力量地方那里与灵界星界联系超乎想象……即使风暴教会直接摧毁这个港口也没能完全消除它存在异常……不少神秘学研究者都在高价收购班西相关物品……他开始考虑要不要也收购些来自班西物品深入研究一下毕竟灵界和传送有关星界星空与漫游有关都可能涉及门先生伯特利·亚伯拉罕脱困。

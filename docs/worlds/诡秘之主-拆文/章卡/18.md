# 18 小丑 第十九章 封印物

## 打开书
克莱恩这一场还坐着听可怜虫。邓恩说低序列比不上枪械火炮，只是更难防。当非凡者：够功劳，或看上面有没有新想法。文职：会计和采购车夫周日休；罗珊、布莱特、老尼尔轮接待看守库。他的活两件：每天走韦尔奇家到自家的路，等灵里冒出见过的感觉；不外出就去武器库读书。读完：查尼斯门每座大城市中央教堂地下都有，别靠近会沾厄运；门后底层有封印物，分 0 到 3。三年前新任大主教因斯·赞格威尔带着 0-08 潜逃，外形一支不需墨水的羽毛笔。邓恩看怀表：去武器库找老尼尔。眼睛跟他。

## 这场戏有没有翻
没翻处境。开头他已经是签了合同的文职；章末仍是，只是活派下来，门后多了不能打听的东西。翻的不是分级热闹。0-08 是口头，不是他上手。

## 日子
同一间值守室。门口对着查尼斯门。抽屉底层一张无抬头的黑白照片。金表链、华丽怀表。

## 这一章落在哪一天
签字同一天下午。三年前大主教潜逃是纸上的。没有另报钟点。

## 人
- 克莱恩：听、问啊、接照片。要的是当非凡者的路和别沾厄运；真正缺的是日记在哪条路上。
- 邓恩：喝完咖啡、踱到门口派活、从抽屉翻照片。要的是日记和别让新伙计乱靠近门。
- 罗珊、布莱特、老尼尔：文职轮班。老尼尔曾是正式成员，年纪大未晋升，身体不好，不愿当看守者或在家休养，要与文献为伴。本章没出场。
- 因斯·赞格威尔：四十岁，前大主教，晋升失败的看门人，瞎一只眼，暗金发，蓝到深黑的瞳。带着 0-08。只在照片上。
- 查尼斯大主教：门的名字来源。每个大城市中央教堂地下都有一扇。

## 地与走
桌旁 → 门口指查尼斯门反方向 → 回桌翻抽屉 → 再指那扇黑铁门。圣堂他猜宁静教堂、凛冬郡——心里的。没有人用腿走进门后或上路找日记。

## 这一章新讲明的规矩
- 低序列：低品阶、高数字，链条起始。力量比不上枪炮，某些方面更奇妙更难防。
- 当非凡者：够功劳（解读文献、给案件意见），或上面新想法。
- 他的岗位：专业人士，不跟罗珊他们做接待打扫。一、每天上午或下午走韦尔奇住所到家的各条路，等熟悉处冒出见过做过的感觉。案子因失忆完结，日记失踪，他们疑他带走中途藏，所以人死在家里不是现场。找到日记够当非凡者的功劳。二、每周自定轮休一天；不外出就去武器库读文献，读完再和老尼尔他们轮换。
- 会计、采购兼职车夫：专业不轮换，周日休。其余文职除周日每人轮休一天，值夜自己协商。
- 查尼斯门：正式成员轮守，里面至少两位教会看守者加无数陷阱。乱靠近沾厄运。内有配方材料、临时关押异端异种邪教徒隐秘组织成员，最终送圣堂。高密级文献副本要权限。底层封印物。
- 封印物四级：0 非常危险，最高重视保密，不可打听外传描述窥探，只封圣堂地底。1 高度危险有限利用，教区主教和值夜者执事及以上，贝克兰德等教区总部中央教堂可存一两件。2 危险谨慎节制，主教和队长及以上，大城市中央教堂三到五件。3 有一定危险，三人以上行动可申请，正式成员可知。编号如 2-125。
- 0-08：口头，不写成文字。常见羽毛笔，不需墨水也能书写。就这么多。发现因斯不要惊动，回来禀报，否则百分之一千殉职。

## 钱与人情
派活不谈钱。找到日记用功劳激励。老尼尔的选择是不愿离开文献。照片比封印物写得详细。

## 话
「是不是很失望？非凡者和你想象的并不一样」「有获得，就肯定有代价。」「低序列非凡者的『力量』比不上枪械，更别说火炮」「你目前的事情有两件，第一，每天上午或者下午，出去走一走」「要是能这样找到那本日记，你应该就可以获得足够成为非凡者的功劳。」「你千万不要随意靠近它，否则会沾染厄运。」「在『查尼斯门』后面的底层，还有些封印物。」「不可打听，不可外传，不可描述，不可窥探」「如果有发现，不要惊动，不要打扰，回来禀报，否则，你百分之一千殉职。」「『0-08』的外形是一支常见的羽毛笔，但不需要墨水也能书写，就这么多。」局面是走一走三个字把专业人士按成寻物的脚；百分之一千把那支笔按成不能写的字。

## 热怎么变冷
成熟理智还热。冷切在比不上枪械。走一走还热，冷切在日记失踪。分级还热，冷切在不可描述，再切在百分之一千殉职。

## 怎么起、怎么收
第一段把可怜虫再响一遍。最后一段停在去找老尼尔。章题像差事：封印物。

## 叙述怎么插手
四级分类有上课。学的是 0 级连文字都不准写。他猜圣堂是宁静教堂，叙述没点头。羽毛笔干什么，邓恩不说。

## 这一章放了什么
- 走路上找日记：当场是工作。不要写成已经找到。
- 封印物分级、0-08、因斯：当场认照片。不要猜笔写谁谁死。
- 老尼尔：当场是下一站。

## 这一章收了什么
上一章可怜虫：本章用枪炮和代价按住。失控五种：本章改成岗位。查尼斯门：本章给了别靠近。

## 谁比谁多知道
读者看见他已经盘算不晋升也行、耳语反正躲不掉。邓恩看见失忆的脚。他不知道 0-08 写什么。因斯不知道这张纸到了廷根。

## 留给下一章的日子
去武器库。照片在脑子里。路还没走。合同在。妹妹仍不知。

## 这一章回不去的事
活已经派了。回不到「入伙只听神话」。0-08 的代号已经进耳朵。

## 这一章人怎么叫人
队长。老尼尔。看门人——因斯晋升失败的那档。0-08。圣堂。

## 可搬走的一条作法
以后写别的书：吓人的分级讲完，把最危险的那件收成口头、只给外形；新伙计的第一份工是走路，不要一入职就发神器。书证 L1802：「『0-08』的外形是一支常见的羽毛笔，但不需要墨水也能书写，就这么多。」

## 专名原样记下、下一本换自己的名
- 人：因斯·赞格威尔、布莱特、老尼尔
- 地：圣堂、查尼斯门底层
- 物：0-08 羽毛笔、封印物编号
- 规矩：四级封印；乱靠近沾厄运；走路找日记

学它怎么用不可描述把最高机密收成一支笔；0-08、查尼斯这些名不要搬。

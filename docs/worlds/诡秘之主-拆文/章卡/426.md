# 426 无面人 第二百一十四章 时代的选择

## 打开书
污河无光下水道——灵体克无障映「眼」。互发现。无开口犹豫——无声尖啸直伤灵魂！使徒顿如重击；影表大片黑落如抖最深欲雪；重伤险昏；无实质身＝狂风烛火将熄。影散漆黑液四面流混淆——克背后影突蹿扑！黑液＝道具突袭！克似未反应任扑——使徒寒颤触最阴冷；影缓僵「冻」。怨魂冻僵竟抑同灵体＝位格压制！半转右按僵影头；暗金太阳胸针微光。使徒察末日欲抗暂无力——明净圣光笼头身；四周亮；黑影挣扎蒸发稀薄灵性满烈阳光辉不甘狂喊。再召圣光；白昼两秒使徒倒失气息；影态薄无厚度。刚刺公爵序5无遗言死。见灵将散——特性析出待；仿莎伦附影？不会技。地微震——1-42银甲飞奔！紧裹使徒灵结束召唤。本计官方到即返。红手套见黑冠披风影无声消无痕；眯审视见已死使徒。「清线索毁证？」后红手套到。雾上不急通灵先回现实清烛痕；再替身上雾。可直接通灵残灵无需祷仪（罗萨戈验过）。先问更要情报；恶魔配方放末——获亦不卖免培养冷血杀手。望空洞使徒：「究竟图谋？」「刺杀尼根公爵。」又他？「成功？」「成功了。」绯红月：风暴亦难庇。不问细：「谁指使？」齐林格斯委托组织？「一组织，最隐秘最古老；绝大多非凡不知；成员各域大人物；或各教会各国军方某些高层即其员。」耳熟——罗塞尔加入？亵渎石板？「许何报酬弃十几年身份？」「一张亵渎之牌，『深渊』牌！」罗塞尔二十二亵渎之一深渊＝恶魔途！高序希望！酬＞任务；齐林格斯或另有牌／物；组织握亵渎石板正常。「为何对付尼根？」「不知；只考虑接否。」「听说？」「主旨复活／唤醒真正造物主。干涉历史符己需某节点完成；时代潮流非预计则竭力扭转。此外安静冷漠旁观；或几十年几百年无一行动。」真隐秘；符罗塞尔暗操大势；扯最初造物主。灵将散急：「名称？怎联络？」无感情望前崩散；彻消前答：「黄昏隐士会。」切温室屋：瘦削金边白手套秘书阴沉悲坐。伊问姓名序途？「洛克哈德·西亚卡姆，序5；途向军情九处申请档案。」「公爵周固定来？」「否；不按日程；齐后更是；今前无人知今日来；上午议院才闻。」「若有间谍疑谁？」摇头。问战细节。见苍白伤重礼貌起查卫队。目送离；沉重至尼尸旁——脸余极恐。深看数秒悲低：「抱歉。」背对众人嘴角微翘；平静心补：「这是时代的选择…」

## 这场戏有没有翻
翻了。开头下水道击杀使徒；章末通灵揭黄昏隐士会／深渊牌、秘书洛克哈德「抱歉」嘴角翘＝内鬼。翻的是时代选择收成主谋在侧，不是背锅者展开。

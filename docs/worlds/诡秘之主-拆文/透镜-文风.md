# 文风：可搬的停顿与切法

停在物件和手上。不要原样搬尊名和途径词。

---

**可搬走的。** 停在物件和手上。热过再冷，切在一个动作。独白跟在看见之后。章题像事变：绯红、欺诈、这一晚。先立还在过的房间，再让奇事进。笔帽搁在左轮旁边，评点才来。掌心翻开才看见血污。镜子侧过脑袋才看见脑浆。阿蒙正了正眼镜。触手停了好几秒才拍。

- 第一章 绯红 L14：痛！
- 第一章 绯红 L35：笔帽搁于一把泛着黄铜色泽的左轮手枪旁边。
- 第一章 绯红 L36：手枪？左轮？周明瑞整个人都愣住了
- 第一章 绯红 L75：只见掌心和手指满是血污。
- 第一章 绯红 L82：一个狰狞的伤口盘踞在他的太阳穴位置
- 第一章 欺诈 L97052：这位「时天使」正了正右眼戴的单片眼镜
- 第四十一章 新的旅程 L117797：那花纹隐去的滑腻触手停顿了好几秒钟

**不要原样搬的。** 尊名全文、途径词、吐槽腔、卷毛狒狒当梗、愚者当商标。不要把这本的神名和序列表搬进下一本。卷毛狒狒可以学它当这一户的尺，不要当网络梗搬。

- 第二十七章 兄妹三人的晚餐 L2509：「弗兰奇先生的智商还是要比卷毛狒狒高一点的。」

**上课的地方。** 身份设计、尊名原理、扮演法注意事项——正文会停下来讲。学的是讲完立刻回到人不能动、只能复读；不学讲义本身。归来记大段三层身份，敲门才办事——那一段空了，不要学。牺牲者大段解释如何瞒亚当——人还在搏斗，评点先上课，不要学。希望之地换地没翻，不要学把换城写成翻。

- 第一百六十八章 “小丑”魔药 L14954：记住，你只是在扮演……这是白银城总结出来的唯一注意事项
- 第三十九章 “隐秘”的眷者 L83671：你要记住你只是在扮演，不能被格尔曼·斯帕罗这个身份影响。
- 第一章 归来记 L63753：根据他的想法，道恩·唐泰斯这个身份明面上应该是一个来自迪西海湾的信仰黑夜女神的神秘富翁
- 第一章 希望之地 L18920：「6点39分……没有晚点多少……」
- 第八十七章 牺牲者 L114151：「门」先生由光球坍缩成的人影停滞在了那里

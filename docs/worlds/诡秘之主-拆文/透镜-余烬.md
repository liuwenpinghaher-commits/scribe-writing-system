# 余烬：文末还欠着什么

不要猜。完本感言不算。

---

不要猜。完本感言不算。正表停在阳光里触手和小孩击掌。L117800 以后不是正表。

**他作为人醒来。** 正表停在触手。阿兹克从棺里坐起来；克莱恩不以人的样子出场。没有写成克莱恩坐起来像阿兹克那样。

- 第四十一章 新的旅程 L117748：阿兹克·艾格斯坐了起来，表情颇为茫然。
- 第四十一章 新的旅程 L117799：它和那只小小的手掌拍击了一下。

**阿兹克的旅行。** 信里说了要去。还没上路。

- 第四十一章 新的旅程 L117766：「接下来，我将开始一段旅行，追寻更多的过去，见证这个世界的变化。」

**谁开的枪。** 开篇头上的洞。正文未写到开枪的人。明天还怎么上班、请假，枪已经在桌上。镜子里头破了是当场看见的：狰狞的伤口，边缘烧灼，内里脑浆在蠕动。开枪的人没有走进房间。以克莱恩的家境哪有钱买手枪——问完了，人还是没走进来。

- 第一章 绯红 L27：看来没法继续睡了，明天还怎么上班？
- 第一章 绯红 L36：手枪？左轮？周明瑞整个人都愣住了
- 第一章 绯红 L72：「以克莱恩的家境，哪有钱和渠道买手枪？」
- 第一章 绯红 L82：一个狰狞的伤口盘踞在他的太阳穴位置

**他作为守护者被点名。** 阿兹克坐起来说了。正表没有写成他作为人坐起来回应这一句。

- 第四十一章 新的旅程 L117765：「你从一开始，就是一个守护者，从模仿他人，到被人模仿。」

**空茧、乌托邦文书、男孩冲车厢是否收束。** 蚕茧在半神那章看见了：三个已经破开。男孩冲车厢这一轮还没抽到成对书证。乌托邦作为还能住下去的小镇，文德尔用闭馆判断来不及赶到——这一晚已经换城。

- 第二百一十四章 一个恩赐，或者，一个诅咒 L80474：有三个「蚕茧」已经破开，里面空无一物，正随风摆动。
- 第一章 这一晚 L114309：就算早起，到了那边，也来不及在王国博物馆闭馆前赶到。

**梅丽莎认不认得出触手是哥哥。** 正文未写。她教孩子念尊名，说不用害怕。不要圆成她认出来了。

- 第四十一章 新的旅程 L117792：「不用害怕，去和他打个招呼。」

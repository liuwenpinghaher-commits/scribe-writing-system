# 前几节凭什么让人接着看

打开书的前几节，不是先宣布有一场大战。人先被放进还在过的日子里：散不掉的喜酒、一姓村请人看风水、赶夜路、庄稼拔苗的小村。当场已经有人因为面子硬撑、因为六两银子不敢推、因为九两银子不回头。每一节停的时候，家里还没到，钉还在怀里，村里还当锁住了，马把他甩在道上——看见了什么，这一节没写完。

以后写别的书，学这三拍怎么接。三水村、梧桐村、下林村、时闻盂、胡不为、这颗钉、这匹枣红马，不要原样搬。

抽样：索引序号 0 到 4。引子、怪墓、遇险、守护兽、来袭。没有空壳。第五章开门先说别人追兽，只用来核对来袭那一眼没收完；不把第五章并进开篇。

## 人被放进什么还在过的日子

打开书不是关在一处办公的地方。前几节换的是还在过的日子，不是同一场酒写了五遍。

### 引子这一夜：三水村娶亲，喜酒散不掉

韩之敬娶犀香。邻镇骑驴骡来贺，同村杀猪蒸喜糕。酒从一早摆到夜黑仍不散。子时将近，堂屋里还有八个人踞桌斗酒。新郎吐了八次还得亮杯。时闻盂颤手敬酒，扑出去吐，倒在牛栏边，回来满脸牛唾液。别人仍当他绊了一跤。他搽眼睛，看见供桌前一群脚不着地、没有影子的老人，叫出一声「鬼」。

读完：这一夜仍是村乡红事。别人看不见那一桌。他再也当不成贺客。

- 引子（贺客） L5：夜幕渐落。客人们却还迟迟没有散去。
- 引子（贺客） L7：三水村韩诤次子韩之敬今日大喜
- 引子（贺客） L11：到子时将近，仍有八个人在堂屋里踞桌斗酒
- 引子（贺客） L15：一个体格瘦小的青年颤着手端杯
- 引子（贺客） L79：「啊――鬼啊！」
- 引子（贺客） L91：人人都脚不着地，踮脚漂移

### 怪墓这一天：一姓村夏中，请人给村子改运

下一节开门换了人、换了村。梧桐村百十来户吴姓务农。夏中黄昏炊烟，祠堂飞檐。老乌头骑骡赶了六天，许六两银子请来胡先生。他发符、看谷场、看碧玉潭，被领进奈何谷里的镇鬼墓。夜里祠堂前开坛，村人看到激烈处鼓掌，当是社戏。喝到鸡啼。次日他牵驴走了。

读完：这不是过年，不是赶集。花钱请人改运，孩子们科考吃饭都压在这一场上。

- 怪墓 L106：村长，我看你们村子这气象不大对头啊。
- 怪墓 L110：许了六两银子酬金
- 怪墓 L120：其时正当夏中
- 怪墓 L122：梧桐村是一姓村，百十来户人家，都是吴姓
- 怪墓 L260：纯当是社戏里武生演武了

### 遇险这一夜：风水先生赶路回家，林子里碰上别人围猎

花脚驴走得慢。他从梧桐村辞别，月上树梢才敢在小树林停下来吃烙饼、摸怀里近九两银子，把墓里那颗钉拿到月光下验。响箭擦过树顶。对上切口才知道不是厉鬼，是严台山一伙人在围一只会一爪毙命的兽。青叶门赵姑娘坐到树上要兽体内的还丹。南面地动天响，兽窜走，两门的人追没了。他翻进土坑，听见堂主和彦青说话，下一声是彦青惨呼。近亥时站上土冈，看见一座村子的火光。

读完：他不是去探险，是赶夜路回家。歇下来吃饭，绊进别人正在办的围猎。

- 遇险 L285：从梧桐村辞别后，前后走了三个时辰
- 遇险 L291：到月上树梢的时候，一人一驴终于停下了。
- 遇险 L293：挣得近九两银子
- 遇险 L303：一支响箭从头顶右上方激射过去
- 遇险 L421：远远的看到村子的火光了

### 守护兽这一日：庄稼拔苗的小村，借宿、丢驴、换马

天色已晚，庄稼拔苗，庄户早歇。他挟尘烟逃进下林村，村北一户亮灯人家留他。夜里摸着九两银子睡不着。晨起于老头不收铜钱，他改送定神符。门外畜舍：鸡鸭都在，花脚毛驴没了。村口古榕下有尊乌木神像，他围着转到要跪，怀里钉子「嚯」地一响，把他震醒。天黑贩马的孙甲上门，把一匹六两不止的枣红马当酬劳。他不会迁坟，改授房中术，拿一张定神符谎称求子咒。

读完：这是小村还在过的日子。耕种狩猎，有人贩马。他是逃进来的，不是来显圣的。

- 守护兽 L426：天色已晚，正是庄稼拔苗之时
- 守护兽 L426：见胡不为挟着滚滚尘烟逃进村来
- 守护兽 L438：村民多以耕种狩猎为生
- 守护兽 L448：那花脚毛驴却已不翼而飞。
- 守护兽 L466：村口的古榕下塑着一尊两人高的乌木雕像。

### 来袭这一夜到次日早晨：守着马算日子，天上打起来

他把马拴在偏房窗下亲自守夜。夏中蚊子蝉蛙。心里已经在换桌椅、买地、生儿女。丑时村南一声嗡，地面震，全村一百二十六人涌出门。千只人面怪鸟压过来，村口雕像化作红色神兽劈鸟，再与九头鸟空中搏。天亮于老头宰鸡饯行。他一脚踏上马镫，听见村南大哭，扬鞭冲村北。

读完：他还在过「得了马、算怎么花」的日子。一息之间，这村子不能再歇。

- 来袭 L549：将马绑在偏房窗下，亲自守夜。
- 来袭 L553：毕竟是夏中了
- 来袭 L555：是不是该买上一两块地
- 来袭 L557：猛然 “嗡嗡” 的巨响
- 来袭 L561：全村一百二十六人全都涌出门外
- 来袭 L625：宰了一只鸡给他饯行。

引子是时闻盂的夜。从怪墓起是胡不为的日子。正文没把时闻盂接到这一户上来。不要把两个人写成同一场的开头。

## 哪一件事已经开始改钱路或面子

热闹不算。改的是谁还进得了这道门、谁还拿不拿得走这笔钱、谁还回不回得了头。

### 酒桌面子先改了人：硬撑到开眼

平素喝得三两的，被人劝就要喝净六两。缩头乌龟日后被耻笑，是天大之事。韩之敬吐了八次还喝。时闻盂酒量不小，仍硬撑到倒。吴中当面对韩诤说：出力帮衬，怕嫂子见怪、以后进不了这门混饭。时闻盂也说打小在这家蹭饭，就冲这个也得出力。

吐酒、拌牛栏，当时还能用面子笑回去。他搽不净眼里的牛唾液，叫出「鬼」，酒桌散成门外的乱。数日后他开了眼回不去，只得做神汉，挣了钱，家道好了。

读完：这一夜面子先把人按在桌上；开眼之后，他吃饭的路改了。不是气氛变热闹。

- 引子（贺客） L29：村下毛头小子最好面子
- 引子（贺客） L29：然面子事大
- 引子（贺客） L51：「被牛栏拌住了。」时闻盂讪笑着解释。
- 引子（贺客） L61：回头招嫂子见怪，以后都不用进这门里混饭食吃了
- 引子（贺客） L101：却再也返不回从前
- 引子（贺客） L101：只得索性做了神汉……也挣得不少钱财

### 六两银子把假行家留在真墓前

许了六两才把人请来。潭边他卖关子，村长暗塞一两碎银，他把银子袖好才说有物镇锁。墓里看见跳出来的钉，他揣进怀里。回祠堂本想推脱，舍不得六两——够普通人家半年伙食。老乌头说棺里真有厉鬼，他从椅上滑下来。下一句仍是：「这酬劳嘛」。村长奉上封好的银子，六两有余，他掂了掂袖好了。子时开坛，酒里混了引火的油物。次日说破嘴皮留不住，村里又加送一两，任他牵驴走。

读完：村里付的是救命钱，他收的是交差钱。墓阵少了一颗钉。信和实账从此对不上。

- 怪墓 L150：暗塞了一两碎银。
- 怪墓 L152：胡先生把银子袖好
- 怪墓 L208：便将它收入怀中
- 怪墓 L214：舍不得那六两银子的酬劳
- 怪墓 L226：从椅上滑了下来。
- 怪墓 L244：「不过，村长，这酬劳嘛……」
- 怪墓 L246：却是六两有余
- 怪墓 L258：酒中混了引火的油物
- 怪墓 L280：又多送了他一两银子，任他牵驴辞别去了。

### 九两圆成不回头

林子里坐下，他把近九两摸在手里喜乐。村中从未给过这么厚。一面愧害了村人，一面用「自己没有伏魔之能」「只说锁镇」「画了符也费劳力」把这笔钱圆成不算亏心。人继续往家走，不回梧桐村。

响箭来了，他还当是墓里的鬼追来。跪喊自己是定马村风水师，才没被当成那只兽砍死。兽一跑，两门的人把他撂下。他发狠打驴逃命，心里仍是：再不走，只怕回不了家享受那九两。

读完：银子已经改了回不回村。面子在林子里改成跪着报名求活命。

- 遇险 L293：向来蒙骗村民，从不曾得到这么丰厚的报酬
- 遇险 L297：并没说已将之灭除，只是锁镇。
- 遇险 L297：自己这九两银子挣的倒也不算亏心。
- 遇险 L341：「是我！是我！我是人，众位大侠手下留情！」
- 遇险 L399：只怕再回不了家享受那九两银子的酬劳。

### 驴没了，马用一桩办不成的风水换成

借宿的铜钱于老头不收，人情改成几张定神符。驴被偷，徒步三百里回不去；听好马三两、中等一两多，一想起破财就肉痛，保命事大才肯买。孙甲把六两不止的枣红马要白送。他怕无功受禄，推到对方跪下来改口「这匹马便是酬劳」。午间吹成活神仙，惹出十年无后这一桩；风水是嘴头，接也不是、不接怕徒步翻山。一顿饭工夫，用房中术和一张假求子咒把马换到手。

读完：走的路从驴改成马。换马不是赏赐，是他在下林村把吹出去的名圆成一笔买卖。

- 守护兽 L442：于老头执意不肯收
- 守护兽 L456：好马三两银子便可买到
- 守护兽 L458：胡不为一想起就要破财，非常肉痛。
- 守护兽 L496：就是六两银子也不止。
- 守护兽 L508：这匹马……便是小人奉上的酬劳。
- 守护兽 L514：可也只是嘴头上纵横而已
- 守护兽 L544：谎称求子咒……平白得了一匹骏马

### 盘算买地的人，一息之间只能逃

守夜时他把这一趟算成肥油：换桌椅笼屉、买一两块地、年纪不轻该生儿育女。村南喊妖怪，全村跪着看真神显迹。寅时草草吃鸡，听见哭声，神仙称号和品格的猜疑也不管了，冲村北。他当自己跑离是非地。说书补一句他不知道：同一早铁匠和卖油郎全身无伤、面带微笑死了，小臂上是雕像那两行字。

读完：钱还没花出去，这村子已经不能再当歇脚处。面子上的仙长名他扔了就跑。

- 来袭 L551：得了宝物又得骏马
- 来袭 L555：这一趟差使让他肥肥地刮了油水
- 来袭 L627：也再不理会于老头对他神仙称号及品格的猜疑
- 来袭 L627：终于跑离了这个是非之地。
- 来袭 L629：他却不知，只在这一早间，村中便死了两名青壮。

## 停在什么没做完的事上

不要写成「留下悬念」。写的是：这一节读完，哪一件还没办完，人还站在哪条路上。

### 引子停在：开了眼，这碗饭刚端起来

时闻盂可见异物，再也返不回从前。寻了道人学通语，做神汉，家道渐渐好了。三水村祭祀更恭敬。

这一节把他的贺客日子收掉了。通阴阳这碗饭刚端起来，正文没再写他怎么给人通阴阳。下一节开门不是他，是四百里外另一村请来的胡先生。两个人正文没接上。

- 引子（贺客） L101：却再也返不回从前
- 引子（贺客） L101：只得索性做了神汉
- 怪墓 L106：村长，我看你们村子这气象不大对头啊。

### 怪墓停在：钉走了，村里当锁住了

他嘴里先说半月就要脱困，随即又说锁了三五百年，再拿三清大帝堵住「三五十年内会有人来」。次日人走了。墓还在奈何谷。那颗跳出的钉和一道符在他怀里。村里付完银子，以为锁好了。

读完：钱已付、人已走、阵少了一颗钉。锁没锁住，这一节没有当场应验。

- 怪墓 L264：他还有半月左右就要脱离困锁出来了！
- 怪墓 L268：他要想跑出来也要个三五百年以后了
- 怪墓 L280：任村长说破嘴皮也不肯留下。

### 遇险停在：看见村子火光，村还没进

林子里的围猎散了。彦青叫过之后，他不敢再走大路。近亥时人和驴累垮在土冈上，远远看见火光和影影绰绰的村民，夹驴冲过去。

银子和钉子还在身上。家没到。定马村正文写在梧桐村北四百里，这一夜没走到。马上那一骑是谁灭口，他吓出来的判断，刀没写给人看。

- 遇险 L415：远处却传来一声惨呼
- 遇险 L421：远远的看到村子的火光了
- 遇险 L421：拼起余力冲将过去。

### 守护兽停在：马到手，今夜不走

他只想马上飞奔回去向浑家报喜。天色已晚，路上风险，着急不得，只好明日再走。钉在身上已经验过会响会亮。假求子咒已经给人。离梧桐村不远，锁镇的厉鬼和他嘴里的「犯查」仍是不敢留的险。

- 守护兽 L544：只想马上飞奔回去，向浑家报喜。
- 守护兽 L544：只好明日再走了。
- 守护兽 L450：一来离梧桐村并不远，那锁镇的厉鬼不知何时便会杀将过来。

### 来袭停在：甩在黄土道上，抬头心胆俱裂

他一袋烟跑出十余里，对马喊好，自以为再一盏热茶就到官道、脱离苦海。红马顿然止步，人立惊鸣，把他甩进黄尘。前面林子有人叫喊。他撑起身子，抬头一看，心胆俱裂。

看见了什么、那一声是谁喊的，这一节没写完。官道没到，家没到。九头鸟击没击死，当场不知。村里死人已报官，他不知道。

下一节开门不是他看见的那一眼。第五章第一句是「话说两头」，先接林子里蔺得岷追那只逃走的犯查。来袭停住的那一抬头，还欠着。

- 来袭 L641：再过的一盏热茶工夫，便能脱离苦海了。
- 来袭 L645：红马却顿然止步，人立起来
- 来袭 L645：抬头一看，不由的心胆俱裂。
- 来袭 L615：也不知将九头鸟击死了没有。
- 第五章（妖兽） L650：话说两头。当日蔺得岷不查之下，被犯查兽从左近逃脱。

## 可搬走的一条作法

以后写别的书：先把人放进还在过的日子里，让钱或面子当场改决定，再停在一件没办完的事上。奇事从吐酒、拌牛栏、揣走一颗钉这种丢脸或贪小的动作里闯进来，不要先宣布此人能见鬼、此村有大敌。

学的是这三拍怎么接。不要把三水村这门亲事、梧桐村这口棺、下林村这尊兽、这匹把人甩下来的枣红马搬过去。

- 引子（贺客） L51：「被牛栏拌住了。」时闻盂讪笑着解释。
- 怪墓 L208：便将它收入怀中
- 来袭 L645：抬头一看，不由的心胆俱裂。

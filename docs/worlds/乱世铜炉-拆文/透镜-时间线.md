# 时间怎么走

打开书从前往后，日子是这样往前走的：先是一村娶亲喝到子时，再是夏中看风水，第一次写出年号是宋雍熙元年。定马村过完中秋、过完除夕，家破了，正月出门，走到五月末进西京。牢里按酉时来、卯时走。路上写出雍熙二年夏末、雍熙三年正月开战。前传末这一夜亥时魂被拘走。正传开门是雍熙三年九月仲秋杀场。隐行过完一个除夕进江宁，五月初五端午上玉女峰，雍熙四年七月二十一子时开坛把魂塑回来，八月中秋贺家庄，八月癸丑戌时地震。然后正文自己跳了六年，淳化二年冬，孩子成了少年。腊月里给碎玉刀贺七十，打到文末仍是隆冬，颍昌府酒楼里有人等了三天来要符。

写不出隔了几天的，写正文未写到。不要编天数。专名、情节原样记下当参照。以后写别的书，学它怎么用年节、夜里、隔了多久把日子往前推；不要把这本的年号、村名、除夕这一夜搬过去。

## 打开书：三水村娶亲这一夜

韩之敬娶犀香。酒从一早摆到夜黑还不散。月儿西移，打更的讨酒。子时将近，堂屋里还有八个人踞桌。时闻盂出去吐酒，倒在牛栏边，回来开了眼，看见供桌前没有影子的老人。说书点明：子时早已过了。这一夜是阴日阴时。数日后他恢复过来，韩诤认出那是太祖父。时闻盂再也当不成普通人。

没有年号。没有节气名。跟下一节隔了几天，正文未写到。不要把引子写成雍熙某年。

## 除夕：孩子出世半天，年没过成

说书写：这是人间大喜的除夕前夜。孩子出世才半天。他踏进空院，供桌在，金炉早间打碎，玉盏没人点。定马村没有打更的。过了子时，算来已当除夕之日。中夜雪上有人蹑足进厢房。烈阳回来夺丹。单嫣断臂。当晚他睡地上。

第二日天亮已是大年三十。村中鞭炮。凄凉的除夕就这么过去。一日两日到初三，单嫣断臂重生。又过几日到正月十三，她能走动。再挨两天，十五晚间元宵，家家户户悬花灯，单嫣带走赵萱尸身，给他一枚银铃。孩子这一晚才起名胡炭。没有年号。跟上节中间，正文只写短短一日间亲人离开、昨夜搏斗，不要另编天数。

回不去的：赵萱死了、尸身被带走。年没过成。单嫣走了。胡不为只剩一个未满月的孩子。

## 牢里：酉时鬼来，卯时鬼走

狱卒一喊「快到酉时了」就逃。酉时到了，阴风，火把吹脱。卯时到了，鬼退去。说书写明：入酉时后阴气弥漫，次晨卯时晨鸡唱晓他们不能在地面多待。这一夜里只死一人，到卯时不甘退去。柳根等了三年六个月，等到今天午时合灵。钱副都统前日夜里被人暗算。半个多月来只有六七个倒霉蛋受伤，却再没有人死去。

## 学什么，不要搬什么

学的是：年节不是装饰。中秋、除夕、端午、元宵、子时，当场有人在过，过不成才算事。夜里按更点办事：酉时鬼来、子时开坛、寅时赶关。写不出间隔就空着，宁可让人说「半年多了」又说「快一年了」，不要替他算准。前一卷末和后一卷头，人事能接、日历接不上，就如实写没接上。跳年要自己开口：六年，孩子大了。

不要把三水村、定马村、雍熙、淳化、胡不为、除夕这一夜原样搬进下一本。下一本换自己的名，办自己的年。

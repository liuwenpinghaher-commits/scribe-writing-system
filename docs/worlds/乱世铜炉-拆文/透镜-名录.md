# 名录

打开书这一面只问：这本书里点过名的人、妖、鬼、生灵都有谁。

每个写：名（原文）、第一次在哪一节、读者靠哪个动作认识他、正文最后还在不在。只站着的写明是家具。人以外的也列，不要漏进「设定」里就当没名。

专名原样记下。以后写别的书，学它怎么让人靠一个动作被看见、学它怎么记账谁还在谁不在；这些名和这本故事不要原样搬。

没点过名的不要编。写不出第一面的，写正文未写到。宁可漏，不许凑。这一轮没挖全的，写在文末。

## 前传：胡不为这一路

打开书下一节换到梧桐村。这一路是胡不为的日子：看风水、骗银子、回家过日子、除夕家破、带着孩子往南走。

## 学什么、不要搬什么

学的是：人靠当场做一个动作被认识，不靠鉴定表。死了就写死了，走了就写走了，文末不在就写不在。嘴里的名和进场的名分开。

不要把时闻盂、胡不为、单嫣、秦苏、胡炭、劳老爷这些名原样搬进下一本。下一本换自己的人，办自己的酒、自己的除夕、自己的争。

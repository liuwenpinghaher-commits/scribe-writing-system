# 谁和谁怎么变

打开书先问：谁和谁因为办过哪一件事，关系变了。原先什么样，后来什么样，改在哪一场戏。银子、面子、酒桌、亲族、师徒都算。没变的不凑对。找不到书证的删掉。

专名、情节原样记下当参照。以后写别的书，学它怎么用一场具体的事把人从旧关系翻到新关系；这些人名、这本故事不要原样搬。

## 胡不为 × 赵萱：酒桌许下来的妻，魂回来仍不肯再娶

原先：定马村屠户赵大骅喝过一通酒，看好会书符查地的年轻人，不计家贫，把女儿硬许给他。成婚十二年，重物不让她拿。翁婿也因村民愿到店里买肉，感情极洽。

改在丽邻这一日把旧事说出来：不是媒婆许的银子绸缎，是酒桌上那一眼。

后来：除夕空屋里她成了偏房里的尸。贺家庄里贺老爷子要给他们成亲，他说炭儿他娘才刚刚过世，这辈子不会再娶。老爷子愣：尊夫人不是过世快三年了么。在他心里，她真正离开是魂刚回来这几天。

旧的是珍惜着的妻。新的是嘴里仍叫萱儿、当面把续弦挡回去的那一口。

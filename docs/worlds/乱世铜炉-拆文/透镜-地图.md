# 人走到过哪些地方、怎么走

人没有关在同一处宅子里。打开书是三水村韩家堂屋里喝不散的喜酒；往后胡不为骑驴出村、骑马过汾州、徒步上千路上西京、被官差揪上马押进地底大牢；正传里秦苏骑骡赶关、装成一家三口走风雪、走上玉女峰石阶、住进贺家庄、再骑马进隆德府赵家庄。一卷能写长，是因为人真的从这儿走到那儿，读者能看见他怎么走。

专名、情节原样记下当参照。以后写别的书，学它怎么让人走路、怎么换日子；三水村、定马村、西京、贺家庄、赵家庄这些名和这本故事，不要原样搬。

## 打开书：人是不是一直关在一处

不是。

没写成走到的路、没写成走到的邻县，不要编。嘴里提起、人没有踩上去的，写在文末「没走到」。宅子、酒庄、狱、庙里头换了哪一间，也算走；没写到内部就写没写到，不要补房间。

### 三水村 · 韩诤家

**叫什么：** 三水村。人在韩诤家堂屋。

**人在这儿过什么日子：** 韩之敬娶犀香。邻镇骑驴骡来贺，同村杀猪蒸喜糕。堂屋里斗拳猜枚，到子时将近还有八个人踞桌。时闻盂扑出房外，到庭院左侧吐酒，倒在牛栏边，再踉跄回堂屋；鬼叫后众人逃到门外，犀香从新房跑出。

**从上一处怎么到的：** 打开书人已经在这儿。时闻盂怎么进韩家，正文未写到。邻近村镇的人是骑花脚毛驴或青骡子来的。邻村叫什么、城叫什么，正文未写到。

**宅子里头换了哪一间：** 堂屋、韩诤醉卧的房、庭院左侧、牛栏、门外、新房。

### 定马村请人 → 梧桐村

**叫什么：** 梧桐村。一姓村，百十来户吴姓，务农。村子中央是宗族祠堂。

**人在这儿过什么日子：** 胡不为被请来看风水。夏中黄昏炊烟四起。人从宗祠大堂走到谷场俯看村寨，谷场是晾晒谷物的黄土地。夜里小方桌摆在祠堂前开坛，村人当社戏看。后来这村子被妖怪围了将近一年，村长叫人带值钱东西聚到祠堂，要全村搬迁。

**从上一处怎么到的：** 老乌头向村长告假，骑青头骡赶了六天，到四百里外的定马村请人。午间偕老乌头来到梧桐村。胡不为这一趟来时怎么骑、路上歇在哪，正文未写到；读者看见的是「请来了」「午间到了」。

**宅子里头换了哪一间：** 祠堂大堂 → 老乌头入偏厅点香、把祠堂锁闭 → 望西北上坡到谷场 → 村长领到村西口碧玉潭（这段路把花甲宗望走得喘息如牛）→ 奈何谷在村西八里，老乌头领进藤萝岩壁里悬壁凿出的石室 → 夜里祠堂前开坛 → 胡先生醉后搀进偏房 → 次日牵驴离村。从潭到谷的步程，正文未写到。

### 梧桐村 → 小树林 → 下林村

**叫什么：** 细土路面、前边小树林、下林村。

**人在这儿过什么日子：** 花脚驴贪嘴，细土路面不走。月上树梢，人靠松树吃烙饼。夜里林子里碰上严台山人，兽从南面来，人逃。下林村几十户比邻，修成数条街道，家家围篱种菜。胡不为跑到村北一户亮灯人家借宿，偏屋过夜，正厅吃饭。村口古榕下有两人高的乌木雕像，对着梧桐村方向。

**从上一处怎么到的：** 从梧桐村辞别，骑花脚驴。三个时辰才十余里；再挨一个多时辰，二十多里；月上树梢时好歹奔了六七十里，勒缰停在小树林。遇险后跳上驴背狂策，尽往开阔地、从梧桐村往北。驴在山道坑洼里踩浮土，连人滚进路边大土坑。他望东北逃，刻意离开大路绕圈子；天色已晚，挟尘烟逃进下林村。定马村在梧桐村北四百里，好马一日可到，这一节没走到。

**宅子里头换了哪一间：** 下林村：偏屋、正厅、门口、畜舍、村街、村口古榕、再回茅屋偏屋。

### 下林村 → 汾州城外茶店 → 定马村家里

**叫什么：** 汾州。茶店立在望北官道边上。定马村是胡不为的家。

**人在这儿过什么日子：** 他把马拴在店边树上灌茶。和尚用西瓜赌腕力，围观的人当好戏看。黑衣人从内堂出来。他会钞出门，策马逃离茶肆。当晚戌时到家。后来村里过节婚娶都愿请他；道士排在单枕才家围篱前要见狐狸精；除夕这一夜他踏进空院，供桌在，金炉早间打碎。

**从上一处怎么到的：** 从下林村一路骑来。枣红马在平整官道上，三四个时辰跑了一百多里，眼看汾州城府就要到。茶店在城门之外。逃离后入了城门，穿过汾州十里，遇岔道往西北驰去，晚间戌时到定马村家中。中秋十五午后，他又牵马上汾州城六香居取月饼，当天回到自家院子摆桌。

**宅子里头换了哪一间：** 茶店：客座、内堂、门外树。定马村胡家：围篱前、院子、书房、卧室、正堂供桌、厢房、鸡舍、厨房、院中对着村东咆狮山。单枕才家围篱。村南到村东、村西到村北，道士在外围转悠。

### 定马村 → 西京（徒步上千路）

**叫什么：** 西京。当朝重镇。

**人在这儿过什么日子：** 正月出门，要去黔南找犯查夺内丹救赵氏。黔南这一路人没有走到。到了西京，先上门苏员外家求奶水，再进刘府。四更从刘府抢孩子出门，住进同来喜客栈。次日盘缠没了，茶堂听封城。被术士追进养蚕人家阁楼。官差把救人的女人当串通妖孽绑了，把他揪在马上当犯人押走。

**从上一处怎么到的：** 经汾州，顺着汾水南下直到晋州，再折向东来到西京。怕小孩受颠簸，不敢骑马，只能徒步。这一段有上千里路，时时要替孩子找奶水，走走停停，从正月一直走到五月末才到。怎么离开刘府：叫醒门房自己出门。怎么到客栈：四更长街顺道急奔，沿道走半袋烟，看见黄布旗敲门。城门他没走到；封城是大堂里听来的。

**宅子里头换了哪一间：** 苏员外正房客厅。刘府房门 → 长街 → 同来喜客栈楼上单身客房 → 次日下楼梯到大堂 → 偏僻小巷、死巷 → 养蚕土屋阁楼。客栈在哪一条街、死巷叫什么，正文未写到。

### 西京府衙大牢（被押）

**叫什么：** 城东府衙。牢房造在地底。

**人在这儿过什么日子：** 密室搜身，只搜出钉子、符、玉牌。两个禁军送到牢口。甬道向地底走，青石潮，十几个巨木牢笼，腐味霉味便溺臊气。人拍柱喊冤枉。到酉时鬼守时刮阴风。他在刑房门口立土柱、扔火球。合灵冲门，人冲到府衙大门底下，又被鞭回原牢。

**从上一处怎么到的：** 十余骑穿过小巷回到大道，驰进城东府衙。官差揪他在马上，他不知捉向何方。出牢房去问话：狱卒打开牢门请他。进密室：兵士押进去。冲到府衙大门：乌木牢柱折断，跨出牢外钻进甬道，梨木大门倒下，向东南的府衙入口再六七丈看到朱门。兵士首领命令把瘫软的人押起来，狠狠鞭打，重新投进牢室。

**宅子里头换了哪一间：** 密室 → 牢口 → 长甬道（脚下渐行渐低）→ 巨木牢笼 / 最里面的牢房 → 刑房门口、刑房 → 府衙大门、围墙缺口 → 又回牢室。城西勾栏是钱奉令去的地方，胡不为没去。

后来震将军从牢狱出来，下人提灯笼引到陈大人府饭厅；饭后陈大人亲自带去厢房。这一走是官差的路，不是胡不为自己走的。

### 出城以后：峡谷、颖昌府地界、阳城一品香居

**叫什么：** 峡谷（没有谷名）。颖昌府地界。阳城。一品香居。

**人在这儿过什么日子：** 他抱孩子循原路，过土柱被砍开的峡谷，取猴，钻荆棘。第二日走进颖昌府地界，夹在樵夫里走。阳城不过二百来户，黄土大道贯穿全镇。镇子北侧酒旗上绣「一品香居」。他扬脖叫店家上鸡鸭鱼肉。店里没有小二招呼，桌面上没有饭食，食客握着兵刃。他们不是来吃饭的。

**从上一处怎么到的：** 走路。天色渐亮循原路；拾台阶到妇人草屋；向前路折回行了六七里，不走向西的岔道，钻荒野荆棘，再回大道。第二日凌晨走进颖昌府地界。爬过矮坡望见村镇，跟樵夫涌进城，穿过黄土大街，奔入饭庄前厅。从西京大牢怎么出城到这条峡谷，这一节只写他已经在路上；中间怎么出城，正文未写到。

**宅子里头换了哪一间：** 一品香居：门前廊柱 → 前厅 → 内堂屏门已开 → 房子紧里白衣人那一桌。通向二楼的楼梯上有人。

### 深山：草窝、巨岩屋檐

**叫什么：** 没有山名。古木参天的破林子。

**人在这儿过什么日子：** 找不到水。三个多时辰景物几乎相同。缩进草窝，夜枭叫着睡去。第二日被雨浇醒。前行一顿饭工夫，见到横突巨岩像老龟，底部两块巨石托住，天然屋檐。钻进去，折树叶接雨水，火球点枯枝。石屋里外两个世界。

### 仙峰镇 · 心雅阁客栈

### 沅州地界 · 明峰（人没有进沅州城）

**叫什么：** 沅州地界。城北郊明峰。沅水。

**人在这儿过什么日子：** 第七日天刚过午，站在明峰山头俯视：一带碧水西向东，城邑店肆林立、舟船相衔。他心里说沅州城他是不进的。从山背寻路下去。后来向山峰逃，三人沉在一处山壁后面的泥潭。人看见了城，没有写成走进城门过日子。

### 东京汴梁城南往颍昌府的官道 → 长社县 · 簌芳居 · 回凤梧

**叫什么：** 京畿要道。颍昌府，府治地长社县。簌芳居。回凤梧。

**人在这儿过什么日子：** 三匹马涉雪。雪层几有半人深，马也跑不快。马上三人骂二哥不该在京里多耽搁。他们要赶的是符，不是赏雪。劳老爷在簌芳居亭子里饮酒。宅共四进，与劳府正宅隔街相对、相距不过百尺。时当正午，回凤梧里热闹非凡。往常午饭五六十人，这一日门外二三百众，不是本地居民。屋里有人等了三天要符，窗格碎了，人和黑毛野兽倒飞到雪地上。有人喊谁拳头大谁拿符。文末停在「好好亲近亲近」，人还在回凤梧这一场里。

**从上一处怎么到的：** 骑马涉雪。消息得自开封府。胡炭一行：射鹿台（早出口述）→ 劳府正宅（呆了不到半刻钟）→ 回凤梧。射鹿台这一节只在口述里，没有跟着走进去。味楼在京里，这一节没进去。应天府、唐蔡两州只在大哥嘴里当「离得更近的同道」，人没有走到。

**宅子里头换了哪一间：** 簌芳居：亭子、台阶、院门。劳府正宅不住，住进隔街的备宅。回凤梧：三条疏梅小道；正屋三间通堂大瓦房，只开一门；人从左侧窗格飞到路面雪地上。颍昌府另一座饭庄：身份平常的在一二楼大堂；气度不凡的上三楼，屏风隔成阁间。后院另有春秀阁、夏浓厅。劳老爷从过道走向雅间，路过偏里一桌。后院丝竹听得见，人没有走进春秀阁。这座饭庄门口叫什么，依稀故人（下）这一节正文未写到。

## 题是渡口，人并不在水上

**舟渡茫：** 开门是一片他自己也问「是不是湖边」的水雾。醒过来人在客栈房里的床上。秦苏从床边冲到门边，下楼梯，缩进大堂板壁暗处。两刻后回到这间房。又跑到范同酉房里搬酒。这座客栈在哪一府哪一县，正文未写到。不要补成湖边的日子。

**迷津渡：** 开门是贺家庄房里雨后。贺江洲说把人搬到庭院开阔、对着花木的这里——读者靠门口这句话知道换过一间，这一节没有另写抬床出门的脚步。江宁府城只在说书里，人没有出庄。

**桃叶渡：** 人走到了渡口岸上，看画舫、听唱。正文未写他们自己登船过江。

## 嘴里提起、人没有走到

提起不等于走到。不要按「应该有」补图。

- 黔南：胡不为出门要去找犯查，人走到西京就拐进刘府和牢房了。
- 信州：同来喜客栈大堂里客人要去，封城去不成。
- 牛临、三茶、青谷：邻村通风者嘴里，道士说见过妖怪踪迹。定马村人没有写成走到这些村。
- 洪州：师傅找秦苏去过，回山这一节没有人再走一遍。
- 福州：贺客嘴里「千里迢迢从福州跑过来」，当场人在赵家庄门外。
- 吐蕃、匹播城、河南府、京兆府、凤翔府、渭州：劳老爷嘴里的来路和去路。
- 东京味楼：马上人口里，人这一节走的是城南往颍昌的官道，没有进味楼。
- 皇城里面：正文未写到有人走进去。
- 庙会：正文没有写成一场人赶庙会的戏。
- 粮市：梧桐村有谷场晾晒，不是粮市买卖。
- 西夏、银州、会州、苏杭、雷琼、梓州、茂州、真定、河间：说书嘴里四处妖声，当场人在颖昌府到阳城的路上。

## 学什么，不要搬什么

以后写别的书，学这一条：人要从一个还在过的地方走进另一个，读者得看见他怎么走——骑驴走慢了、骑马过城门、徒步上千路、被揪上马、背人疾捷术、骡子向山隘、纵越术一步两丈、涉雪官道。走了，地就换了；日子也就换了。

没写怎么到的，就写没写到，不要补「应该有一条官道」。宅子里头换了哪一间也要写：祠堂到谷场、客栈楼上下来、牢里甬道向地底、山门石阶到洒花殿、贺家庄厢房改成法室、赵家庄前庭到静心斋。没写到内部，不要补房间。

正传后半赵家庄里叠了很久同一种日子，如实记下，不当成「世界很大」。专名和这本故事不要原样搬。

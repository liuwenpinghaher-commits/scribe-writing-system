# 上一章落下的日子下一章接没接上

打开书只问这一件：这一节读完，谁的日子改成什么样了；下一节一开门，人是不是还活在这个后果里。

接上了，不是又提那几个字。是人还在过那个改完的日子：人死了还得收场，年没过成还得进那空院子，官差喊擒人下一句就扭住。改了钱路、人命、面子、年，下一节却当没发生过——点出来。没有改，写没有。

专名、情节原样记下当参照。以后写别的书，学它怎么让下一开门还接着过昨天改完的日子；这些人名、这场除夕、这本魂瓶不要原样搬。

抽样用相邻两节章卡，再按索引只读那一节原文首尾。没有通读全书。空壳、缺号、前传到正传、文末，都核对过。

## 可搬走的一条

以后写别的书：上一节改完的日子，下一节开门还要接着过。人死了，下一句还在堵创口。年没过成，下一句还在踏进空院。官差喊擒人，下一句就扭住。不要学：魂封进瓶子了，下一章改写一队兵赶路；灯炸了，下一章改写城墙上赏月；许了婚，下一章改写别人家卖南瓜。专名和这本故事不要原样搬。

接上了的，学的是人还在后果里办事。没接上的，老实写成没接上，不要帮它圆。

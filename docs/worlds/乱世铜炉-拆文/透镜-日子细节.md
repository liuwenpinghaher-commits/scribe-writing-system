# 日常怎么过

这本书的人过日子，钱是当场掏出来的，饭是当场吃下去的，衣裳是当场换上的。碎银、铜板、金子、金锞各办各的事；烙饼、早粥、馊饭、鹅掌、一道三千八百两的菜，各是哪一场的肚子；土布、绸袍、兽皮、偷来的男装，各是哪一天穿得起。价钱从办事里露出来：六两够普通人家半年伙食，两个铜板买两个果儿。没写成场面的，写正文未写到。不要按「古代农村应该有」补米价、补衣裳。

专名、情节原样记下当参照。以后写别的书，学它怎么用一场具体的戏把付钱、吃饭、换衣露出来；不要把六香居、同来喜、一品香居、定神符这些名和这本故事搬过去。

## 用什么付钱

### 村里：封好的银子、暗塞的碎银、铜钱给不成才改送符

梧桐村这一日。老乌头骑青头骡赶六天，到四百里外定马村请风水，许了六两银子酬金。潭边村长暗塞一两碎银求他明说。先生想推，舍不得那六两——够普通人家半年伙食。开坛前村长袖里掏出封好的银子，六两有余，有心多给。次日再多送一两，他牵驴就走。路上掂着近九两，喜乐。

读完：这村子请得动他，靠的是银子先封好、碎银先塞进袖。不是口头许诺。

### 城里：金子兑成银子和金锞；客栈先付房钱；打赏用一两、三两

苏员外家。门外有人求见，他当落难的，叫帐房支领一两银子——说书补一句：一两银子当得一家五口一月之用。那人不要。改五两，仍要当面见。后来治好老太爷，厚赠几锭黄金。胡不为出了门，六锭金子折银六百两。到钱庄兑了一锭，换来值五十两的小金锞和五十两银子。当晚进同来喜客栈，预付了房钱，钱袋扔床尾就睡。午时醒，银子没了。他盘算拿定神符充走方郎中：每愈一人一两，穷人三钱、五钱，一日画五六张够吃饭。缺的是棒儿、白布、烟墨。饿着肚子进小巷找人家扔的晾衣杆。日色偏了，他担心店家又加房钱。

读完：金子要先兑成能花的银子和金锞。客栈是先付钱再上床。房钱具体多少，正文未写到。丢了六百两，明天吃什么都要另想。

## 吃什么

### 村里红事、中秋、除夕：桌上有什么

三水村韩之敬娶犀香。吉日前同村帮着杀猪宰羊、进城购物、蒸制喜糕、缝绣裙裳。酒从一早摆到子时。家里土酿的酒烟气重；村坊土酿的小米酒闻着清淡、后劲大。新郎吐了八次，午后补六个生鸡蛋仍镇不住。打更的讨了好几杯水酒。供桌摆白鸡水果黄酒、点了喜红的糕饼面馔。

读完：这夜是喜酒，不是法会。猪羊、喜糕、小米酒、生鸡蛋、供桌上的白鸡水果，都在办事。

### 土布换成绸，绸换成破靴，破靴再换成小二买来的文衫

## 物价怎么露出来

价钱不是告示。是有人肉痛、有人掏不出、有人发晕的时候，数目才站得住。

六两请风水，够普通人家半年伙食。一两当一家五口一月。中秋月饼四钱，他肉痛——家里还不算揭不开锅，四钱已经要算。苏家得子，家人打赏三钱，出门五百步遇见人再赠三钱：三钱是大户随手的喜钱。

好马三两，中等马一两多。他为买马肉痛。后来马市会钞买几匹，价没写。

十文买一捆纸钱；一卦十文。两个铜板两个果儿。一捆柴十几个铜板，买完当天食粮就空。卖食的汉子掏不出一两符钱，能掏一文铜板。

一张定神符明码一两。对大户是杯酒之资，对卖食的是要命，贫苦人家半年未必挣到。玉簪六千两、珍珠八千两，是能兑成盘缠的物。金锞加金抹额近三千两，够一个寡居老婆子下半辈子。重修一座庵，五百两够。雕一枚双麒衔芝长生锁，前后五十两，加上留给老人的五十两，一锭金子没了，他心疼。

人参：商人喊三支两千二百两。他心里另有一本——即便货物难通，三百年参不过八百两一支，一百年五百多两，这一笔他嫌了不止一千两。胡炭不还价。

酒庄一道金鼋菜三千八百两，认人卖。胡炭发晕：吃金子都没这么贵。

读完：这本书把价写在谁掏得起、谁肉痛、谁把价报低了又盯着银子说不出话。不是一张物价单。

- 驴价、马市几匹马的价。写了碎银买驴、会钞买马，没有报价。

# 《乱世铜炉》多轮拆书提示

给以后写书用的参照，不是读后感，不是词表。  
原文：`docs/worlds/乱世铜炉-全文.md`（约 152 万字）。一次吃不下，按下面五轮跑；一轮没完，改 `pass` / `start` 再跑。

铁律（每轮都遵守）：

- 只根据原文。没写到的写「正文未写到」，不许补。
- 每一条能指到场面或原句。只换词、堆词、点名一个世界词就能过的句子，删掉重写。
- 抽作法，不抽情节缩写当成品。
- 禁止主题升华、字数配额、机制词清单、把人写成职能标签。

---

## 第 0 轮 · 切章索引

```text
用 read_file / grep 打开小说原文（路径由任务给出）。不要凭记忆。

找出每一个章题：行首的「引子……」以及「第X章……」。
写成 Markdown 表，列：序号（引子=0）、标题原文、起始行号、结束行号（下一章起始行-1；最后一章到文末）、大约字数。

要求：
- 标题以原文为准，不要改字。
- 同一章上下分册（上/中/下/补）各算一节，不要合并。
- 正文里有人说话提到「第几章」的，不要当成章题。
- 写完把表存到任务指定的 00-index.md。
- 最后用三句话说明：共几节、第一题、最后一题。

禁止把小说正文抄进索引。
```

---

## 第 1 轮 · 章卡（每节一张，可分批）

```text
材料只有这一节原文。先用 read_file 按索引的起止行去读，不要读全书。

先问自己：打开书，这一节是谁的日子、发生哪一件、读完世界怎么变。问不清就再读，不要开始填。

【打开书】谁的夜或白日。发生哪一件事。读完地、人、日子变成什么样。

【这场戏有没有翻】开头这人站在哪一边（安/危、有脸/没脸、在家/在路上、信/不信）。节末翻到哪一边。没翻就写没翻——有热闹不等于有戏。

【日子】人在过什么日子。用这件事说。

【人】出场的人各自要什么、做了什么。起哄、劝酒、报信、收钱、害怕、看热闹都算办事。谁只站着当家具，写明。若有人第一次出场：读者是靠他做了什么认识他的。

【地与走】在哪。换了地方，读者怎么看出他到的。没换就写没翻地方。

【钱与人情】谁因为银子、面子、酒桌、酬金、官差改了决定。没有就写没有。

【话】若有一段对上劲的对话：嘴里说什么，心里要什么，哪一句把局面推了一步。没有就写没有。

【热怎么变冷】笑闹/酒/日常切到怕/怪/凶/空，切在哪一个动作上。没有就写没有。

【怎么起、怎么收】第一段把人放进什么里。最后一段停在什么没做完的事上。章题是事变还是评点。

【叙述怎么插手】说书评点在人做事之后还是之前。学的是插在动作后的那一句，不是学半文不白。

【可搬走的一条作法】只一条，带一句原文书证。

【不要搬走】这本的时代腔、鬼神规矩、套话。

把这一卡写到指定路径。不要把整节原文再贴一遍。
```

## 第 2 轮 · 五面透镜（可与章卡穿插，章卡不必全部齐）

每一面只问一件事。必须再读原文抽样（至少五处书证），不能只靠章卡。

### 2A 世界有多大

```text
只问：这本书实际走到过哪些日子和哪些地方。
列出村子、山、城、宅、河、狱、庙、集市。每一处用一场具体的戏证明「人在这里过什么日子」。
说明一卷能写长，是因为换了哪种日子，不是同一场酒写了很多遍。
缺了正文没写到的地方，不要编。
写成 透镜-世界.md。
```

### 2B 群像与钱路

```text
只问：不是主角的人如何各有各的活计、面子、银子。
点名至少八个不是主角的人（或正文里有名的配角）。每人：要什么、靠什么活、缺了他们哪一节会塌。
写成 透镜-群像.md。
```

### 2C 人怎么被看见

```text
只问：主要人物第一次出场，读者是靠哪一个动作认识他的。欲望和害怕怎么从办事里露出来。
不要写鉴定式人设表。
写成 透镜-出场.md。
```

### 2D 话与说书

```text
只问：对话何时在办事、何时在聊天；评点插在人做事之后的例子；章题怎么起。
各举不超过五处书证。
写成 透镜-说书.md。
```

### 2E 戏怎么翻、热怎么切、章与章怎么换花样

```text
只问三件：哪些节开头到结尾人的处境翻了；笑转怕切在哪个动作；下一节相对上一节换的是地、人，还是日子的种类。
指出连续同一种日子的段落（那是以后写书要躲开的）。
写成 透镜-节奏.md。
```

---

## 第 3 轮 · 合成参照本

```text
只准用已经落盘的章卡和五面透镜。缺的写「这一轮还没抽到」。
写成 参照本.md，给人翻着写下一本书用。

一、世界有多大（换过的日子种类）
二、人怎么群
三、人怎么被看见
四、一场戏怎么翻、热怎么切冷
五、话与说书
六、章与章如何不重复
七、前传到目前为止在问什么（用人事说）
八、给以后开书的六条，每条用铜炉里一场具体的戏当例子：
  1. 先立还在过日子的世界，再让奇事闯进来
  2. 不是主角的人各有要办的事
  3. 要写长就必须换地方、换日子的种类
  4. 热过再冷，切在动作上
  5. 章题要像事变，不要像岗位表
  6. 一场戏读完人的处境要翻，热闹不算

禁止写成另一本情节缩写。
```

---

## 第 4 轮 · 缺口补抽（一轮不够就再跑）

```text
对照 参照本.md 和已有章卡。只问：以后写书还缺哪一类作法。
列出缺口清单，每条写：缺什么、该回原文哪一类场面再读、建议下一轮透镜名。
不要因为「还可以更全」而空造缺口。没有新缺口就写「可以停」。
写成 缺口.md。
```

下一轮按缺口清单只补那一面，不要重跑已经抽过且书证充足的面。

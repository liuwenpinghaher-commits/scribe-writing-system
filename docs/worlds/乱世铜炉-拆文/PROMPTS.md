# 《乱世铜炉》多轮拆书提示

**第一性目标：把整本书榨干。**  
凡是以后写书会翻的，都要从原文挖出来：时间、地图、规矩、日常怎么过、所有点过名的人、谁和谁怎么变、反复出现的东西、人怎么称呼、回不去的事、前传到正传各自在问什么、文末还欠着什么、伏笔、接章、写法。  
挖出来的是参照，不是再写一本铜炉。专名、情节、鬼神原样记下，并标明：学结构、换自己的名；不要把这本故事搬进下一本。

原文：`docs/worlds/乱世铜炉-全文.md`。一次吃不下，按轮次跑；一轮没完，改 `pass` / `start` / `lens` 再跑。没有作者点头，不要自己开拆。

## 该榨什么（以后写书会翻的，全部要有）

每一条都必须落到一场具体的戏或一句能指回原文的话。没写到的写「正文未写到」，不许用常识补一张古代农村。

### 时间线

- 打开书从前往后，日子怎么往前走。
- 哪一节过年、哪一节是白天还是夜里、哪一节隔了多久。
- 哪一件事让以后回不去（人死了、账改了、年没过成）。
- 写不出间隔就写正文未写到，不要编天数。

### 世界地图

- 人实际走到过哪些地方。
- 从这儿到那儿，读者怎么看出来他走了。
- 每一处：人在这儿过什么日子（粮市、田、渡口、庙会、邻镇、狱、宅、酒庄……以正文为准）。
- 没写到的路、没写到的邻县，不要编。

### 全部设定

- 世界靠什么规矩转：官差怎么来、钱怎么走、庙会怎么办、术有什么代价、有什么不能做。
- 每一条规矩用一场戏证明：谁因为守了或破了，日子怎么变。
- 岁时：年节、红白喜事、子时、供桌——是章的主层，不是装饰。
- 物件：钥匙、账、丹、符、酒、兵器——当场干什么、后来另有没有用。
- 势力与行当：衙门、帮、庄、庙、酒庄、赶脚的、报信的。缺了他们哪一场会塌。
- 这本书提到的从前：祖宗、旧案、术界怎么来的。用一场戏或一句评点证明。
- 有没有一个人独有的便宜。没有就写没有。
- 日常：用什么付钱、吃什么、穿什么、物价怎么露出来。没写到写正文未写到。

### 人物

- 能点名的人、妖、鬼、生灵都要有一本名册：第一次在哪一节、靠哪个动作被认识、正文最后还在不在。家具也列明。
- 嘴上要的和真正缺的；读到现在变了没有；一开口是不是他。
- 旁人各有活计、面子、银子。
- 谁和谁因为银子、面子、酒桌、亲族改了关系。旧的什么样，新的什么样。

### 反复出现的东西

- 同一件物、同一句评、同一种场面再来一次。早先那场怎么教读者读后来那场。
- 不是「又提到一次」就算。要能说出后一场因为有前一场，读法变了。

### 称谓与口头禅

- 谁叫谁什么。口头禅是哪一句。一开口就能听出是他。

### 回不去的事

- 谁死了、谁嫁了、账改了、年没过成、路断了。列成总表，每一条指回哪一节。

### 前传到正传

- 前传打开书在办哪一件大事。正传在办哪一件。两卷接没接上。接不上就写正文没接上，不要帮它圆。

### 文末还欠着什么

- 正文已经欠着、到酒庄「好好亲近亲近」还没发生的事。不要猜读者想看什么。

### 伏笔与知情

- 后来发生的大事，当初怎么放进日子里。当场必须还有自己的事。
- 假线索、亮过没响的，都记账。
- 读者比场上人多知道什么；谁嘴里不能知道什么；说书的人评到哪。
- 这一节是谁的眼睛在看，还是说书的人站在外头。
- 有没有倒叙、插叙、预先把后头的事说了。

### 章与章怎么接

- 这一节读完，谁的日子改成什么样。
- 下一节开门是不是还活在这个后果里。改了却没接上的，点出来。

### 写作

- 一场戏读完处境翻了没有。热闹不算翻。
- 笑怎么切到怕，切在哪个动作上。
- 话怎么办事；评点插在动作后还是事先教训。
- 章题像事变还是像岗位表。
- 句子在哪停。人没说怕时，手、步、酒杯先变了没有。
- 前几节凭什么让人接着看。
- 人一开口是什么味道（别写成那种急转腔）。

### 明确不榨（格，不是参照）

- 每章必须拆出多少个情节点、桥段词表、钩子点名。
- 「两边那几个字都要出现」「至少 N 个机制词」。
- 把整章原文贴进提示。
- 用「古代应该有」补地图、补官制、补节气。

## 铁律（每轮都遵守）

- 只根据原文。没写到的写「正文未写到」，不许补。
- 必须用 `read_file` / `grep`。禁止凭记忆。禁止把全文一次性读进对话，也禁止按页把三万多行翻完。切章只用 grep 章题；章卡和透镜按索引行号只读那一节。
- 每一条能指到场面：标题 + 行号 + 不超过四十字的原句。指不出就删。
- 只换词、堆词、左右对打、点名一个世界词就能交差的句子，删掉重写。
- **设定、地名、人名、时间、规矩必须挖全**，这是参照的骨头。抽的不是另一本情节缩写当成品，但骨头不在，参照就是空的。
- 这本书的专名、鬼神、情节原样记下，并写清：以后写别的书，学它怎么立规矩、怎么走路、怎么过日子；专名和这本故事不要原样搬。
- 禁止主题升华、字数配额、机制词清单、把人写成职能标签、用「至少 N 个」当写好。
- 打开书先问自己：这一节是谁的日子、发生哪一件、读完世界怎么变。问不清就再读，不要开始写。

```text

目标：找出每一个真正的章题行，写成 Markdown 表，存到任务指定的 00-index.md。
列：序号、卷（前传|正传）、章号、分册（空|上|中|下|补|一|二|…）、标题原文、起始行、结束行、行数、标记。
行数 = 结束行 − 起始行，用相邻章题行号相减即可。不要「大约字数」，不要为估字去读节身。最后一节的结束行：只允许 read_file 文件末尾几行确认文末行号（文末是酒庄「好好亲近亲近。」）。
正表只收要抽卡的节。重贴另附一表，不占序号。

怎么认章题（必须 grep）：
- 行首（可有空白）的「引子……」。引子序号 0，卷=前传。
- 行首的「第X章……」「正传 第X章……」「正传 二十六章」「四十一章」（缺「第」也算）。
- 卷界：出现「铜炉正传」之后的章号，卷=正传，序号继续累加，不要把正传第一章和前传第一章合成一张卡。
- 同一章的上/中/下/补/（一）（二）……各算一节，不要合并。
- 标题以原文为准，不要改字。

不要当成章题：
- 正文里有人说话或作者插话说「第几章」的。
- 「图片章节」、网站广告、域名行。

去重与回绕（必须按文件顺序，不要靠印象）：
- 连续两行都是同一章的标题，只保留信息更全的一行，标记「标题复读已合并」。
- 去重键是（卷, 章号, 分册, 标题里标明事变的那几个字），不是只按章号。正传「第四十三章 心机」和前传/回绕「第四十三章 选择」不是同一节。
- 先出现的进正表。后出现且正文明显重复的，只标「疑似重贴」、不占新序号。点名：回绕里 L24075「剪径」、L24280「杀场」（顺序反了，是正传开头重贴）、L24537「第四十三章 选择」是前传重贴，不要覆盖正传 L18769 起的「心机」。
- 后出现但未见过的才补入正表。该补的是：随水转、一沙一世界、第五十七章「鱼龙舞」起直到文末。
- 不要把千花当回绕缺章。千花六节只在回绕之前（约 L18360–L18561）。
- 两章标题之间行距不足约二十行的，仍保留在正表并标记「空壳」。空壳也占序号，后面必须出卡。
- 「正传 第二十四章 苏醒(免费外篇)」单独成节，标题原文保留，不要并进苏醒（下）。
- 最后一节的结束行 = 原文最后一行。不要提前结束。

写完用 grep 抽查（行号允许 ±2 行）：引子、前传第十六章（除夕）、铜炉正传、正传第一章 杀场、正传第四十三章 心机、第二十八章 随水转、第六十九章 闻风而动。再抽：L24537「选择」必须在重贴表、不得覆盖「心机」；千花必须在回绕之前的正表。

返回：ok=true 仅当你已经用 grep 找到章题、抽了标题附近行、并写了 00-index.md。chapter_count=正表节数。index_path=写入路径。first_title、last_title。duplicate_blocks=疑似重贴块数。thin_n=空壳节数。

最后在索引文件顶上用三句话：共几节、第一题、最后一题。不要写文学评论。
```

## 第 1 轮 · 章卡（`pass=chapters`，每节一张）

**责任：** 打开书，这一节是谁的日子、发生哪一件、读完地/人/日子/规矩变成什么样。把这一节里以后写书会翻的骨头留下。

```text
你只做索引里序号 = {seq} 的那一节。先读索引文件，找到这一行的标题和起止行。再用 read_file 的 offset/limit 只读这一节。不要读全书。不要把整节原文贴进卡里。

若索引这一行标了「空壳」：仍必须写这张卡。【打开书】写「正文几乎没有」；其余段写没有或正文未写到；turned=false；书证可写「本节行距过短，无句可引」。这算合格卡。
若标题是「苏醒(免费外篇)」：当作独立一节来写，不要并进苏醒（下）。

若目标卡已经存在，且任务未要求 force：先读旧卡。只有标题、下面没有写出谁/哪一件/世界怎么变，或书证没有带 L 行号的，视为不合格，必须重写。合格才跳过。

先问自己：打开书，这一节是谁的日子、发生哪一件、读完世界怎么变。问不清就再读，不要开始写。

按下面的段写到指定路径。每段只问一件事。没有就写没有或正文未写到。

【打开书】谁的夜或白日。发生哪一件事。读完地、人、日子变成什么样。这一节是谁的眼睛在看，还是说书的人站在外头评。

【这场戏有没有翻】开头这人站在哪一边，节末有没有翻到另一边。翻的是处境（安危、脸面、在不在路上、信不信、还欠着什么），不是气氛变热闹。没翻就写没翻——有热闹不等于有戏。

【日子】人在过什么日子。用这件事说。以正文为准，不要拿词去套。

【这一节落在哪一天】过年、节气、时辰、隔了多久。写不出就写正文未写到，不要编天数。

【人】出场的人各自要什么、做了什么。起哄、劝酒、报信、收钱、害怕、看热闹都算办事。谁只站着当家具，写明。若有人第一次出场：读者是靠他做了什么认识他的。能点名的人名都写下。

【地与走】在哪。换了地方，读者怎么看出他到的。没换就写没换地方。宅子、酒庄、狱里头换了哪一间，也算走。地名必须来自本节正文。

【这一节新讲明的规矩】术、官、钱、庙、禁忌、物件怎么用。原样记下。没有就写没有。

【钱与人情】谁因为银子、面子、酒桌、酬金、官差改了决定。没有就写没有。

【话】若有一段对上劲的对话：嘴里说什么，心里要什么，哪一句把局面推了一步。没有就写没有。

【热怎么变冷】笑闹/酒/日常切到怕/怪/凶/空，切在哪一个动作上。没有就写没有。

【怎么起、怎么收】第一段把人放进什么里。最后一段停在什么没做完的事上。章题是事变还是评点。

【叙述怎么插手】说书评点在人做事之后还是之前。学的是插在动作后的那一句，不是学半文不白。谁嘴里不能知道的，说书的人有没有评出来。有没有倒叙、插叙、预先把后头的事说了。没有就写没有。

【这一节放了什么】当时像闲笔、以后可能要响的东西。它在当场必须还在办自己的事，不能干等。没有就写没有。不要猜以后会怎样。

【这一节收了什么】以前露过的事，这一节真的发生了。没有就写没有。不要把「又提到一次」当成收了。

【谁比谁多知道】读者、说书、场上某个人，谁比谁多知道一点；这一点改了局面才写。没有就写没有。

【留给下一节的日子】读完，谁的日子改成什么样了。没有改就写没有。

【这一节回不去的事】谁死了、账改了、年没过成、路断了。没有就写没有。

【这一节人怎么叫人】新出现的称谓、口头禅。没有就写没有。

【可搬走的一条作法】只一条，带一句不超过四十字的书证和行号。写「以后写别的书可以怎么做」，不要写「把这本情节搬过去」。

【专名原样记下、下一本换自己的名】这一节出现的人名、地名、物件名、规矩名、点过名的妖鬼生灵，列出来供以后汇总。学的是结构，不要把这些名原样搬进下一本。

【书证】若干条，每条 L行号 + 短句。不要引用网站广告行。

ok=true 仅当文件已写（或合格跳过），且你用工具按索引起止行读过这一节。path=写入路径。title=章题原文。turned=这场戏有没有翻。place=主要地点；本节没写地点则空字符串。
```

## 第 2 轮 · 透镜（`pass=lenses`，一次一面）

每一面只问一件事。必须再读原文抽样，不能只靠章卡。抽样用 grep + 按索引行号 `read_file` 那一节，禁止把全文按页读完。每一条必须带书证（标题+行号+短句）。写不出书证的删掉。宁可少，不许编。

共用前缀：先附铁律。你只做下面指定的那一面。把这一面写到任务指定的文件名。若文件已合格且未 force，不要覆盖。合格=该面的人话问题下面已经用一场具体的戏（或一句能指回原文的规矩）答了，且有带 L 行号的书证。

### 2A 世界有多大 → `透镜-世界.md`（lens=世界）

```text
只问：这本书里的人实际走到过哪些还在过的日子。每一处用一场具体的戏证明「人在这里过什么」。

打开书，人是不是一直关在同一处宅子、同一处办公的地方？若走出过，写他走到的那些日子；没写到的不要编，也不要按一份地点名单打卡。村子、田、渡口、庙会、邻镇只是人话举例，不是必须填的格。

说明一卷能写长，是因为换了哪种日子，不是同一场酒写了很多遍。
不要靠「古代农村应该有」补一张地图。
```

### 2B 群像与钱路 → `透镜-群像.md`（lens=群像）

```text
只问：不是主角的人如何各有各的活计、面子、银子。

点名你能指着原文证明的、不是主角的人。每人：要什么、靠什么活、缺了他们哪一节会塌。起哄的、劝酒的、报信的、收钱的、看热闹的，只要办了事就算。
```

### 2C 人怎么被看见 → `透镜-出场.md`（lens=出场）

```text
只问：主要人物第一次出场，读者是靠哪一个动作认识他的。欲望和害怕怎么从办事里露出来。

不要写鉴定式人设表，不要写「性格关键词」。找不到第一面的，写正文未写到或章卡还没抽到那一节。
```

### 2D 话与说书 → `透镜-说书.md`（lens=说书）

```text
只问四件，都用具体场面说：

1. 对话何时在办事、何时在聊天。嘴里说什么、心里要什么。
2. 评点插在人做事之后的例子；学插的位置，不学半文不白。
3. 读者比场上人多知道什么，场上谁在瞒——瞒和露改了局面，才写。没有就写没有。
4. 谁嘴里不能知道什么；说书的人可以评到哪。角色对白里泄了不该知道的，点出来。
5. 说书的人站在哪：村口评、跟在某人身后、还是预先把后头的事说了。有没有倒叙、插叙。没有就写没有。

章题怎么起：事变还是评点，举书里的题，不要发明一套题法公式。
人一开口是什么味道：举一两句，说明这句为什么只能是他；有没有写成那种急转腔。
```

### 2E 戏怎么翻、热怎么切、章与章怎么换花样 → `透镜-节奏.md`（lens=节奏）

```text
只问四件：

1. 哪些节开头到结尾，人的处境翻了。没翻的热闹节也点出来——以后写书要躲开连着不翻。
2. 笑转怕切在哪个动作上（不是切在一段抒情上）。
3. 下一节相对上一节，换的是地、人，还是日子的种类。指出连续同一种日子的段落。
4. 读者这一节被带到哪一下（笑、怕、空、气），切在哪个动作上。不是气氛词，是那一下。
```

### 2F 伏笔怎么埋怎么收 → `透镜-伏笔.md`（lens=伏笔）

```text
只问：哪一件后来发生的大事，早先是怎么放进日子里的。

每一条都用一场具体的戏说完这三拍：
- 当时那场戏里它在干什么（必须有当场的事，不能干等）；
- 中间怎么让人忘了，或中途又以别的事再露一次脸；
- 后来哪一场真的响了。响了是「那件事发生了」，不是「又提到那几个字」。

分开写：隔几章就响的、一卷里响的、前传到正传才响的。
假线索：故意让人看错的，后来哪一场拆穿。
亮过却没响的：写明，别帮它圆。
同一局面再来一次的：早先那场怎么教读者读后来那场。

不要列编号表交差。写不出当场的事，这条删掉。
```

### 2G 人整本书怎么变 → `透镜-人物.md`（lens=人物）

```text
配角同样：缺了他们哪一场会塌。只站着的人写明是家具。
谁和谁因为银子、面子、酒桌改了关系，用一场戏证明。
找不到书证的人不要凑档案。
```

### 2H 主线、旁人的日子、暗账 → `透镜-线索.md`（lens=线索）

### 2I 前几节凭什么让人接着看 → `透镜-开篇.md`（lens=开篇）

### 2J 时间怎么走 → `透镜-时间线.md`（lens=时间线）

```text

写不出间隔就写正文未写到。

正文提到的从前（祖宗、旧案、术界怎么来）另写一段，不要和本章正在过的日子混在一起。写不出发生在哪一年，就写正文未写到。
```

## 第 4 轮 · 缺口（`pass=gaps`）

**责任：** 以后写书还缺哪一类会翻的东西。没有就停。不要因为「还可以更全」空造缺口。

```text
对照 参照本.md、已有章卡、各面透镜、文风透镜。只问：以后写书还缺哪一类会翻的东西（时间、地、规矩、日常、名册、关系、反复、称谓、回不去、卷问、未解、伏笔、接章、写法）。

本轮独占写 缺口.md（覆盖）。先读旧缺口文件：把「上一轮是否可以停」、以及旧文件里若有「回溯改了哪些」收进新文件开头的「沿革」一节，不要丢掉。

每条缺口写：缺什么（人话）、该回原文哪一类场面再读、建议下一轮 pass（chapters / lenses 的哪一面 / style / synthesize / trace）。
不要因为「还可以更全」而空造缺口。
若索引正表里有大段序号还没有章卡，这算缺口。
若已有章卡但「打开书」下面没有写出那一件事，或书证行号 grep 不回原文，这算缺口。
若还没有时间线 / 地图 / 设定，或里面没有一场具体的戏、一条能指回原文的规矩，这算缺口。
若世界透镜里人一直关在宅子/室内、看不到还在过的别种日子，这算缺口。
```

# 《乱世铜炉》多轮拆书提示

给以后写书用的参照，不是读后感，不是词表。  
原文：`docs/worlds/乱世铜炉-全文.md`。一次吃不下，按下面轮次跑；一轮没完，改 `pass` / `start` / `lens` 再跑。

这本书的精华不在「情节缩写」。要榨干的是：**一场戏怎么写成戏、一件后来才响的事当初怎么放进日子里、人怎么被看见又怎么变、旁人的日子怎么把大事托起来。**

---

## 该榨什么（全网拆书法，用人话）

下面每一面都必须落到一场具体的戏。只换词、堆词、点名一个世界词就能交差的，作废。

### 写作：这一场怎么写成戏

- 开头这人站在哪一边，节末有没有翻到另一边。热闹不算翻。
- 笑、酒、日常切到怕、怪、凶、空，切在哪一个动作上。
- 嘴里说什么，心里要什么，哪一句把局面推了一步。
- 说书评点插在人做完事之后，还是事先教训。学插的位置，不学半文不白。
- 第一段把人放进什么里；最后一段停在什么没做完的事上。
- 章题像事变，还是像岗位表。
- 句子在哪停。人没说怕的时候，手、步、酒杯先变了没有。
- 同一件东西当场在办事，后来另有一用（一笔两用）。先让人看见结果、再让人知道原因（延迟揭示）。

### 伏笔：后来发生的事，当初怎么放进日子里

- 当时像闲笔，后来才知道是账（草蛇灰线）。
- 放进去的那一刻，它必须在当场还有自己的事，不能干等着以后用。
- 中间怎么让人忘了；太近会一眼看穿，太远会像凭空冒出来。
- 假线索：故意让人看错，后来哪一场拆穿。
- 亮过却没响的：写明，别帮它圆。
- 隔几章就响的、一卷里响的、前传到正传才响的，用人事分开说。
- 同一局面再来一次，早先那场怎么教读者读后来那场（结构回响）。

### 人物：怎么被认识，整本书怎么变

- 第一次出场，读者是靠哪一个动作认识他的。
- 他嘴上要的是什么；他真正缺的是什么。两件事打架，戏才在。
- 读到现在，他因为办过哪些事变贵了、变狠了、变软了。没变就写没变。
- 一开口别人能不能听出是他。举一句。
- 不是主角的人各有活计、面子、银子。缺了他们哪一场会塌。谁只站着当家具，写明。

### 线索：这本书一直在办哪一件事

- 主线：一直在办的那件大事，用人、地、日子说。
- 辅线：旁人的日子怎么把这件事托起来。
- 暗线：读者后知后觉的那条账。
- 下一章相对上一章，换的是地、人，还是日子的种类。连续同一种日子的段落点出来。

### 知情：谁比谁多知道

- 读者比场上人多知道什么；场上谁在瞒。多知道的那一点改了局面，才写。

### 世界：人实际走到过哪些还在过的日子

- 每一处用一场戏证明「人在这里过什么」。没写到的不要编。

### 开篇：前几节凭什么让人接着看

- 人被放进什么还在过的日子。
- 哪一件事已经开始改钱路或面子。
- 停在什么没做完的事上。

### 明确不榨（那是格，模型会填字过关，戏仍可以没发生）

- 每章必须拆出多少个情节点、桥段词表、钩子十三式点名。
- 地点打卡名单、机制词清单、「两边那几个字都要出现」。
- 把整章原文贴进提示。
- 把这本鬼神、情节、古白话腔搬进下一本。

---

## 铁律（每轮都遵守）

- 只根据原文。没写到的写「正文未写到」，不许补。
- 必须用 `read_file` / `grep`。禁止凭记忆。禁止把全文一次性读进对话，也禁止按页把三万多行翻完。切章只用 grep 章题；章卡和透镜按索引行号只读那一节。
- 每一条能指到场面：标题 + 行号 + 不超过四十字的原句。指不出就删。
- 只换词、堆词、左右对打、点名一个世界词就能交差的句子，删掉重写。
- 抽作法，不抽情节缩写当成品。
- 禁止主题升华、字数配额、机制词清单、把人写成职能标签、用「至少 N 个」当写好。
- 打开书先问自己：这一节是谁的日子、发生哪一件、读完世界怎么变。问不清就再读，不要开始写。

## 第 0 轮 · 切章索引（`pass=index`）

**责任：** 把这本书按作者自己的章题切开，记下每一节从哪一行到哪一行。切错了，后面每张卡都会读错书。

```text
切章只许用 grep 找章题行，再用 read_file 只抽该标题行前后各两三行核对。禁止为切章而按页顺序读完全书。禁止为填表去 read_file 任何一节的正文。不要凭记忆，不要把正文抄进索引。

目标：找出每一个真正的章题行，写成 Markdown 表，存到任务指定的 00-index.md。
列：序号、卷（前传|正传）、章号、分册（空|上|中|下|补|一|二|…）、标题原文、起始行、结束行、行数、标记。
行数 = 结束行 − 起始行，用相邻章题行号相减即可。不要「大约字数」，不要为估字去读节身。最后一节的结束行：只允许 read_file 文件末尾几行确认文末行号（文末是酒庄「好好亲近亲近。」）。
正表只收要抽卡的节。重贴另附一表，不占序号。

怎么认章题（必须 grep）：
- 行首（可有空白）的「引子……」。引子序号 0，卷=前传。
- 行首的「第X章……」「正传 第X章……」「正传 二十六章」「四十一章」（缺「第」也算）。
- 卷界：出现「铜炉正传」之后的章号，卷=正传，序号继续累加，不要把正传第一章和前传第一章合成一张卡。
- 同一章的上/中/下/补/（一）（二）……各算一节，不要合并。
- 标题以原文为准，不要改字。

不要当成章题：
- 正文里有人说话或作者插话说「第几章」的。
- 「图片章节」、网站广告、域名行。

去重与回绕（必须按文件顺序，不要靠印象）：
- 连续两行都是同一章的标题，只保留信息更全的一行，标记「标题复读已合并」。
- 去重键是（卷, 章号, 分册, 标题里标明事变的那几个字），不是只按章号。正传「第四十三章 心机」和前传/回绕「第四十三章 选择」不是同一节。
- 先出现的进正表。后出现且正文明显重复的，只标「疑似重贴」、不占新序号。点名：回绕里 L24075「剪径」、L24280「杀场」（顺序反了，是正传开头重贴）、L24537「第四十三章 选择」是前传重贴，不要覆盖正传 L18769 起的「心机」。
- 后出现但未见过的才补入正表。该补的是：随水转、一沙一世界、第五十七章「鱼龙舞」起直到文末。
- 不要把千花当回绕缺章。千花六节只在回绕之前（约 L18360–L18561）。
- 两章标题之间行距不足约二十行的，仍保留在正表并标记「空壳」。空壳也占序号，后面必须出卡。
- 「正传 第二十四章 苏醒(免费外篇)」单独成节，标题原文保留，不要并进苏醒（下）。
- 最后一节的结束行 = 原文最后一行。不要提前结束。

写完用 grep 抽查（行号允许 ±2 行）：引子、前传第十六章（除夕）、铜炉正传、正传第一章 杀场、正传第四十三章 心机、第二十八章 随水转、第六十九章 闻风而动。再抽：L24537「选择」必须在重贴表、不得覆盖「心机」；千花必须在回绕之前的正表。

返回：ok=true 仅当你已经用 grep 找到章题、抽了标题附近行、并写了 00-index.md。chapter_count=正表节数。index_path=写入路径。first_title、last_title。duplicate_blocks=疑似重贴块数。thin_n=空壳节数。

最后在索引文件顶上用三句话：共几节、第一题、最后一题。不要写文学评论。
```

### 同轮 · 索引校验

**责任：** 找切错。不是润色。

```text
你在找切章错误。用 grep / read_file，禁止凭记忆，禁止通读全文，禁止为核对去读节身。

读已经落盘的 00-index.md。至少做这些核对：
- 抽正表标题（含第一、最后、正传第一章杀场、正传第四十三章心机、若表里有则含「随水转」），grep 原文，行号相差不能超过 2 行。
- 原文 L10120 附近作者说章节贴错——确认这句没有变成章题。
- 若原文在第五十六章之后又出现「第二章 （剪径）」，索引必须标了疑似重贴。L24280「杀场」也是重贴。L24537「第四十三章 选择」必须标成前传重贴，正表里的正传四十三仍是「心机」。
- 正表仍收入回绕段才出现的缺章（随水转、一沙一世界）以及第五十七章起直到文末。千花必须在回绕之前。
- 空壳标题必须有标记，且仍在正表。
- 「苏醒(免费外篇)」必须是单独一节。

duplicate_blocks、thin_n 按你见到的填。issues 用几句人话写还存在的切错；没有则空字符串。
chapter_count 必须是你交卷时正表的节数。若你修正了 00-index.md，返回改完后的正表节数。
不要改小说原文。若索引确有会读错书的错，可以修正 00-index.md 后再 ok=true。
```

## 第 1 轮 · 章卡（`pass=chapters`，每节一张）

**责任：** 打开书，这一节是谁的日子、发生哪一件、读完地/人/日子变成什么样。留下一条以后能搬走的作法。

```text
你只做索引里序号 = {seq} 的那一节。先读索引文件，找到这一行的标题和起止行。再用 read_file 的 offset/limit 只读这一节。不要读全书。不要把整节原文贴进卡里。

若索引这一行标了「空壳」：仍必须写这张卡。【打开书】写「正文几乎没有」；其余段写没有或正文未写到；turned=false；书证可写「本节行距过短，无句可引」。这算合格卡。
若标题是「苏醒(免费外篇)」：当作独立一节来写，不要并进苏醒（下）。

若目标卡已经存在，且任务未要求 force：先读旧卡。只有标题、下面没有写出谁/哪一件/世界怎么变，或书证没有带 L 行号的，视为不合格，必须重写。合格才跳过。

先问自己：打开书，这一节是谁的日子、发生哪一件、读完世界怎么变。问不清就再读，不要开始写。

按下面的段写到指定路径。每段只问一件事。没有就写没有或正文未写到。

【打开书】谁的夜或白日。发生哪一件事。读完地、人、日子变成什么样。

【这场戏有没有翻】开头这人站在哪一边，节末有没有翻到另一边。翻的是处境（安危、脸面、在不在路上、信不信、还欠着什么），不是气氛变热闹。没翻就写没翻——有热闹不等于有戏。

【日子】人在过什么日子。用这件事说。以正文为准，不要拿词去套。

【人】出场的人各自要什么、做了什么。起哄、劝酒、报信、收钱、害怕、看热闹都算办事。谁只站着当家具，写明。若有人第一次出场：读者是靠他做了什么认识他的。

【地与走】在哪。换了地方，读者怎么看出他到的。没换就写没换地方。地名必须来自本节正文。

【钱与人情】谁因为银子、面子、酒桌、酬金、官差改了决定。没有就写没有。

【话】若有一段对上劲的对话：嘴里说什么，心里要什么，哪一句把局面推了一步。没有就写没有。

【热怎么变冷】笑闹/酒/日常切到怕/怪/凶/空，切在哪一个动作上。没有就写没有。

【怎么起、怎么收】第一段把人放进什么里。最后一段停在什么没做完的事上。章题是事变还是评点。

【叙述怎么插手】说书评点在人做事之后还是之前。学的是插在动作后的那一句，不是学半文不白。

【这一节放了什么】当时像闲笔、以后可能要响的东西。它在当场必须还在办自己的事，不能干等。没有就写没有。不要猜以后会怎样。

【这一节收了什么】以前露过的事，这一节真的发生了。没有就写没有。不要把「又提到一次」当成收了。

【谁比谁多知道】读者、说书、场上某个人，谁比谁多知道一点；这一点改了局面才写。没有就写没有。

【可搬走的一条作法】只一条，带一句不超过四十字的书证和行号。写「以后写别的书可以怎么做」，不要写「把这本情节搬过去」。

【不要搬走】这本的时代腔、鬼神规矩、套话、具体妖名法术。

【书证】若干条，每条 L行号 + 短句。不要引用网站广告行。

ok=true 仅当文件已写（或合格跳过），且你用工具按索引起止行读过这一节。path=写入路径。title=章题原文。turned=这场戏有没有翻。place=主要地点；本节没写地点则空字符串。
```

## 第 2 轮 · 透镜（`pass=lenses`，一次一面）

每一面只问一件事。必须再读原文抽样，不能只靠章卡。抽样用 grep + 按索引行号 `read_file` 那一节，禁止把全文按页读完。每一条作法必须带书证（标题+行号+短句）。写不出书证的删掉。宁可少，不许编。

共用前缀：先附铁律。你只做下面指定的那一面。把这一面写到任务指定的文件名。若文件已合格且未 force，不要覆盖。合格=该面的人话问题下面已经用一场具体的戏答了，且有带 L 行号的书证。

### 2A 世界有多大 → `透镜-世界.md`（lens=世界）

```text
只问：这本书里的人实际走到过哪些还在过的日子。每一处用一场具体的戏证明「人在这里过什么」。

打开书，人是不是一直关在同一处宅子、同一处办公的地方？若走出过，写他走到的那些日子；没写到的不要编，也不要按一份地点名单打卡。村子、田、渡口、庙会、邻镇只是人话举例，不是必须填的格。

说明一卷能写长，是因为换了哪种日子，不是同一场酒写了很多遍。
不要靠「古代农村应该有」补一张地图。
```

### 2B 群像与钱路 → `透镜-群像.md`（lens=群像）

```text
只问：不是主角的人如何各有各的活计、面子、银子。

点名你能指着原文证明的、不是主角的人。每人：要什么、靠什么活、缺了他们哪一节会塌。起哄的、劝酒的、报信的、收钱的、看热闹的，只要办了事就算。
不要写成职能表。写不出的人不要凑数。
```

### 2C 人怎么被看见 → `透镜-出场.md`（lens=出场）

```text
只问：主要人物第一次出场，读者是靠哪一个动作认识他的。欲望和害怕怎么从办事里露出来。

不要写鉴定式人设表，不要写「性格关键词」。找不到第一面的，写正文未写到或章卡还没抽到那一节。
```

### 2D 话与说书 → `透镜-说书.md`（lens=说书）

```text
只问三件，都用具体场面说：

1. 对话何时在办事、何时在聊天。嘴里说什么、心里要什么。
2. 评点插在人做事之后的例子；学插的位置，不学半文不白。
3. 读者比场上人多知道什么，场上谁在瞒——瞒和露改了局面，才写。没有就写没有。不要用三个字的术语代替场面。

章题怎么起：事变还是评点，举书里的题，不要发明一套题法公式。
```

### 2E 戏怎么翻、热怎么切、章与章怎么换花样 → `透镜-节奏.md`（lens=节奏）

```text
只问三件：

1. 哪些节开头到结尾，人的处境翻了。没翻的热闹节也点出来——以后写书要躲开连着不翻。
2. 笑转怕切在哪个动作上（不是切在一段抒情上）。
3. 下一节相对上一节，换的是地、人，还是日子的种类。指出连续同一种日子的段落。
```

### 2F 伏笔怎么埋怎么收 → `透镜-伏笔.md`（lens=伏笔）

```text
只问：哪一件后来发生的大事，早先是怎么放进日子里的。

每一条都用一场具体的戏说完这三拍：
- 当时那场戏里它在干什么（必须有当场的事，不能干等）；
- 中间怎么让人忘了，或中途又以别的事再露一次脸；
- 后来哪一场真的响了。响了是「那件事发生了」，不是「又提到那几个字」。

分开写：隔几章就响的、一卷里响的、前传到正传才响的。
假线索：故意让人看错的，后来哪一场拆穿。
亮过却没响的：写明，别帮它圆。
同一局面再来一次的：早先那场怎么教读者读后来那场。

不要列「伏笔编号表」。写不出当场的事，这条删掉。
```

### 2G 人整本书怎么变 → `透镜-人物.md`（lens=人物）

```text
只问：打开书时靠哪一个动作认识他；他嘴上要的是什么、真正缺的是什么；读到现在他因为办过哪些事变了。

每个人用办事说，不要鉴定。没变就写没变。
一开口别人能不能听出是他：举一句原文，说明这句为什么只能是他。
配角同样：缺了他们哪一场会塌。只站着的人写明是家具。
找不到书证的人不要凑档案。
```

### 2H 主线、旁人的日子、暗账 → `透镜-线索.md`（lens=线索）

```text
只问三件，都用人事说：

1. 这本书一直在办的那件大事是什么。
2. 旁边哪些人的日子把这件事托起来——缺了他们，大事会塌还是只会少一场热闹。
3. 有没有一条读者后知后觉的暗账。没有就写没有。

每条线用一场具体的戏证明。不要写成「主线/辅线/暗线」三个空格等填。
```

### 2I 前几节凭什么让人接着看 → `透镜-开篇.md`（lens=开篇）

```text
只问：打开书的前几节，凭什么让人接着看。

按索引去读序号靠前、有正文的几节（引子和紧跟着的几节；空壳跳过改抽下一节有正文的）。不要通读全书。

用人话答三件：
- 人被放进什么还在过的日子；
- 哪一件事已经开始改钱路或面子；
- 停在什么没做完的事上。

不要打「钩子类型」的勾。写不出这三件，写正文未写到。
```

## 第 2J 轮 · 文风细读（`pass=style`）

**责任：** 看这本句子怎么停、评点怎么插、对话怎么办事。给人学位置和责任，不给人学腔。

```text
你做文风细读。不要统计短句占比，不要用百分比当写好。不要把 300 字原文块贴进产物。

必须按索引行号抽样读原文。先读这几场（缺则改抽相邻有正文的节，并写明改抽了哪一节）：
- 前传引子（贺客）
- 前传第十六章（除夕）
- 正传第一章（杀场）
- 正传里一场还在过日子的（贺寿、庙会、酒庄一类，以索引里真实标题为准）
- 文末附近（闻风而动 / 酒庄）

只问：
- 句子在哪停。动作和评点谁先谁后。
- 对话怎么办事：有没有一句把局面推进一步。
- 热闹怎么落到怕：切在哪一个动作。
- 人没说怕的时候，手、步、酒杯先变了没有。
- 以后写白话书可以搬哪一条停顿/切法；这本的文言甩腔、套话、鬼神名词为什么不要搬。

写成 透镜-文风.md。结构用人口语小标题即可，不要格。每条作法一条短书证。
ok=true 仅当文件已写且你读过上述抽样。lens=文风。evidence_n=书证条数。path=写入路径。
```

## 第 3 轮 · 合成参照本（`pass=synthesize`）

**责任：** 给人翻着写下一本。缺的老实写还没抽到。

```text
只准用已经落盘的章卡和透镜。缺的写「这一轮还没抽到」。禁止回原文编新地理来把参照本写圆。硬事实必须带着书证行号；对不上就删或改成正文未写到。

写成 参照本.md，给人翻着写下一本书用。

一、世界有多大（换过的日子种类；人实际走到过、能用一场戏证明的地方）
二、人怎么群（不是主角的人各要什么）
三、人怎么被看见（第一次靠动作）
四、人整本书怎么变（嘴上要的、真正缺的、办过哪些事之后变了）
五、一场戏怎么翻、热怎么切冷
六、话与说书（含：读者比场上人多知道什么时，局面怎么变）
七、伏笔怎么埋怎么收（当场的事、中间怎么忘、后来哪一场真的发生；假线索；亮过没响的）
八、主线、旁人的日子、暗账
九、章与章如何不重复（换的是日子种类，不是同一场酒）
十、前几节凭什么让人接着看
十一、前传到目前为止在问什么（用人事说，不是主题句）
十二、文风：可搬的停顿与切法；不要搬走的腔和这本鬼神
十三、给以后开书的几条，每条用铜炉里一场具体的戏当例子：
  1. 先立还在过日子的世界，再让奇事闯进来
  2. 不是主角的人各有要办的事
  3. 要写长就必须换地方、换日子的种类
  4. 热过再冷，切在动作上
  5. 章题要像事变，不要像岗位表
  6. 一场戏读完人的处境要翻，热闹不算
  7. 后来要响的事，当初放进日子里时必须当场还有别的事在办
  8. 人嘴上要的和真正缺的要打架
十四、不要抄进下一本的清单（情节、妖名、法术、古白话套话）

禁止写成另一本情节缩写。禁止把一处宅子、一处办公、一条走廊当成「世界很大」。

ok=true 仅当参照本已写。path=该路径。gap_count 若你顺手看到明显缺口可填，否则 0。can_stop=false（停不停由缺口轮决定）。
```

## 第 4 轮 · 缺口（`pass=gaps`）

**责任：** 以后写书还缺哪一类作法。没有就停。不要因为「还可以更全」空造缺口。

```text
对照 参照本.md、已有章卡、各面透镜、文风透镜。只问：以后写书还缺哪一类作法。

本轮独占写 缺口.md（覆盖）。先读旧缺口文件：把「上一轮是否可以停」、以及旧文件里若有「回溯改了哪些」收进新文件开头的「沿革」一节，不要丢掉。

每条缺口写：缺什么（人话）、该回原文哪一类场面再读、建议下一轮 pass（chapters / lenses 的哪一面 / style / synthesize / trace）。
不要因为「还可以更全」而空造缺口。
若索引正表里有大段序号还没有章卡，这算缺口。
若已有章卡但「打开书」下面没有写出那一件事，或书证行号 grep 不回原文，这算缺口。
若世界透镜里人一直关在宅子/室内、看不到还在过的别种日子，这算缺口。
若还没有 透镜-伏笔.md / 透镜-人物.md / 透镜-线索.md，或里面没有一场具体的戏，这算缺口。
若参照本里有硬事实没有行号，这算缺口（建议 pass=trace）。
若还没抽过文末附近大约 4 张章卡（索引正表最后几节：闻风而动 / 酒庄一带），这算缺口。第一次把「可以停」写成 true 之前，这四张必须已经在。

没有新缺口、且文末约 4 张卡已在，才写「可以停」，can_stop=true，gap_count=0。文件开头写清「上一轮：…；本轮：可以停 / 还有缺口」。
写成 缺口.md。
ok=true 仅当缺口文件已写。path=该路径。
```

## 第 5 轮 · 硬事实回溯（`pass=trace`）

```text
你在找参照本里站不住的硬事实。读 参照本.md。抽出地名、人名、钱数、官差、路程、谁对谁做了什么。
参照本里每一条这类硬说法都要 grep 原文。命中则留下；命中不到的改成「正文未写到」或删除，不要用合理推断补上。
只改参照本，不要写 缺口.md。
做不完不要凑条数交差：在返回的 issues 里用人话写「还剩哪一类没对完」，ok 仍可 true，gap_count=你改掉的条数，can_stop=false。
ok=true 仅当你对抽出的硬说法做过 grep。path=参照本路径。
```

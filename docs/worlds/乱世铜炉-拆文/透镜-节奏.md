# 戏怎么翻、热怎么切、章与章怎么换花样

打开书，一场戏读完，人是不是站到了另一边。热闹不算翻。笑切到怕，切在手上那一下，不切在一段叹气上。下一节开门，换的是地、人，还是日子的种类。读者这一节被带到哪一下，是那一下，不是气氛词。

专名、情节原样记下当参照。以后写别的书，学它怎么翻、怎么切、怎么换花样；三水村、定马村、赵家庄、胡不为这些名和这本故事，不要原样搬。

## 一、哪些节开头到结尾，人的处境翻了

翻的是安危、脸面、还在不在路上、信不信、还欠着什么。不是酒更响、人更多。

## 热闹没翻；假翻；上一节故意不翻

热闹不等于戏。以后写书要躲开连着不翻。

### 假翻：怪墓开坛，村人喝到鸡啼，墓没动

开头村长面色凝重，请人看风水。夜里他踏灯碗烧符喷酒，村人看到激烈处鼓掌，当是社戏武生。他说好险、已困住三五百年，众人重整筵席，喝到鸡啼。次日他多拿一两银子牵驴走了。村人从担心翻到放心——他们信了。墓还在那儿。读者看着他喷的是掺了油的酒。这是热闹像翻了、处境没翻。

### 印堂发黑（下）：店里善举热闹，他还坐原桌

开头他看同道被泼茶。节末银子给了，吕某带着孩子出门，他坐在原位微笑发痴。他的路没改，饭没散，店没换。吕某翻了：孩子有望吃饭。胡不为没翻。热闹和善举不等于戏翻。

### 阿鼻境（上）：逃、布阵、追的人跳进阵，阵没响

开头三人在黄土路上逃。范同酉刨土布阵让两人先走。施足孝认错阵，给僵尸贴避雷符，带着一百多具死尸跳进阵里。节末人还在逃，追的人还在追，阵还没响。骂得热闹、符烧得热闹，不等于翻了。

翻在下一节第一下：僵尸阴气一碰，土里的符啪地激燃，阴云自涌。上一节把翻切给了下一节开门。

### 空壳：没有人，谈不上翻

正传苏醒（免费外篇）、舟渡茫（中）（下）、故生忧上中下，行距过短，正文几乎没有。没有开头的人，没有节末的另一边。这不算热闹没翻，这是没写成戏。

### 连着同一种日子、翻得少的段落

赵家庄寿筵从贺寿写到千花、变故、盛典、祸宴，地没换。能写长，是因为同一场酒里不断换谁闯进来、办哪一件：青龙门进庄、茶杯长花、胡人比武、白衣人翻墙救人、蜀山掌门从天上下来、官差当众掌掴。这是换「这一场里的事变」，不是换地。

可千花一到六几乎是同一场梨树上的比武切开。盛典一到六几乎是同一场庄前入庄切开。印堂发黑上写下、阿鼻境上写中，是一场酒、一阵法切成两节。以后写书要躲开只换节号、不换日子种类、上一节还没翻就再开一节热。

## 二、笑转怕切在哪个动作

不是切在一段抒情上。是手上、门上、钉子上、杯子上那一下。

门外嘎啦折断、腾的落地，当时被他一句「被牛栏拌住了」笑回去。真切冷切在：牛唾液搽不净，他连喊三声咦；堂屋空空，只听见打更；下一声是鬼啊。

### 连续同一种日子的段落

定马村邻里：丽邻、晴天雷、绝美狐狸、大恶事前半，都是村里还在过的日子——洗头、会道士、邻里。大恶事后半到除夕，地还是定马村，日子种类从中秋团圆改成死人空屋。同地可以换日子种类。

赵家庄寿筵：贺寿、千花、变故、盛典、祸宴，人一直在这座庄里。长，是因为闯进来的事变换了。短处是千花切了六节还在梨树上打，盛典切了六节还在庄前入庄。

酒楼里印堂发黑上、下：同一张桌子，上一节抢座出神，下一节算卦善举。胡不为没翻。

逃路上阿鼻境上、中：上一节布阵跳进去，下一节阵才响。上一节故意不翻。

空壳连着：舟渡茫中下、故生忧上中下，正文几乎没有。这不是换花样，这是没写成。

以后写别的书：一场戏读完人要站到另一边，热闹当不成翻。笑切到怕，切在开门、钉子响、杯子里蠕出东西、刀停住、窗格碎这些动作上。章与章要换日子的种类，或者同一场里换闯进来的事变；不要连着六节还在同一棵梨树上打。上一节不翻，下一节开门就要把那一下补上——阿鼻境上跳进阵，中才啪。专名和这本故事不要搬；搬的是怎么翻、怎么切、怎么换。

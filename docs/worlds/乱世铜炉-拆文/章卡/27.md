# 27 第二十七章 （捉妖）避虎又进豺狼洞

## 打开书

胡不为这一节从暮色挨到夏初没月亮的夜里。火球明明打在对面脸上，疼却削在他自己面颊上。赵师爷给兵差画的是铁光咒，专把攻击法术弹回去。他懵了，又轰两团，肩头腰间像挨了刀，孩子震哭。官差叉腰叫他尽管打。他改口立几十支土柱，抱儿子钻进峡谷。兵差劈出路来，暮色里只剩弯弯曲曲一条细道。首领发誓这回不管他说什么都杀掉。

山野夏夜虫叫。跑了半个时辰，前面一团黑，是矮树林。他摸黑缩进草丛，手盖在孩子口鼻上。一盏热茶后官差持刀进来。黑得伸手不见五指，夜枭叫，有人问莫大哥会不会有妖怪。灌木「喀拉」一声，几人像中箭兔子。胆小的杀猪般喊妖怪。有人点纸煤，树后一条大蟒在爬，大家才捂胸口。莫大哥故意大声说赵师爷给过搜察犯人的符，要找找。他怕被点出来，远远推一个火球，火球散了，位置交出去了。首领笑：你也上当了。

他连发火球才想起反弹，当先那人额头中招翻倒——铁光咒半个时辰已经过了。他头一回站在打人的那一边，乐不可支。首领躲到树后，小指划出血，一把符纸全捺着烧：铁光咒、龙虎符、夺气符，连陈大人叮嘱不到万不得已不要烧的玄青召唤符也在里头。龙虎符让那人眼亮力增。夺气符让他无来由恐慌，火球没了章法，土柱细得像活蛇。林中平地生风，腥臭，暗红光团里土地破开，狼头蛇身一条接一条钻出来。怀中镇煞钉尖锐鸣叫，灼进肉里。四条蛇狼上下左右封死退路。青龙从衣襟里射出来，左右射穿两个狼头，绞碎天上那条，又当长枪钉进地里第四条。官差张嘴傻住，以为这杀手锏也能碾他们；他们不知道钉子只打妖物。

东南呼哨大作，浑厚的声音分派六连山、百云教守东南，凤鸣山、天姥山和十二桥女侠去西侧准备水雨。火把排成两线包抄。他想起梧桐村郊外严台山抓犯查也是这般聚众。他撇下官差就跑，张嘴大呼这里有人救命。近百江湖人围过来。肩上蹲鹰的人问妖怪在哪，他说没看见；胆小官差也说没见着，挨了一顿骂。山羊胡老者闻出符纸味和苗疆黑巫幻蛊，不是他们要捉的那头。他指官差：是他们弄出狼头蛇妖。付老三放鹰要抓学巫的，黑袍里立刻有人顶回来。口角改成付老三和许是非叫阵。有人阴恻恻两句，两边都住嘴。刘大侠说欧阳先生开口了，请八盘山再查妖气。暗红袍枯瘦老者成咸风说让小老儿来，掌上放出八只手足、通体莹白的小东西。钉子又短促一响，他瞪圆眼喊这是妖怪。成咸风斥：这是千里一日归。众目鄙夷。小怪蹿出去，白光没入土中。

读完：人没死在官差刀下，也没死在蛇狼嘴里。四条玄青被钉子绞碎。符纸烧光了。他站进近百人的围里，要捉的那头还没露面。说书跟他挨自己的火球、跟他捂孩子嘴、跟他乐不可支、跟他被夺气符按住；也进官差心里写怕黑，把湖北一带北上那头的来历插在口角之后才说。场上人没看见是谁在说那两句阴恻恻的话。

## 这场戏有没有翻

翻了。开头火球弹回自己脸上，土柱一拦只能往峡谷里跑，首领发誓这回一定杀掉。节末官差不再是对面那一拨：符烧光了，蛇狼死了，近百江湖人把他和五名官差围在场中，要捉的那头还在左近，千里一日归已经入土。翻的是还能不能跑、符还在不在时效里、对面怕的是他还是林子、人还在不在那几把刀跟前——不是火球热闹，也不是女侠好看。

## 日子

## 这一节落在哪一天

接上一节还在打的那一场。暮色里他跑进峡谷。夜色降下来，正文写明是夏初、夏夜没有月光。又跑半个时辰进林。官差进来过了一盏热茶工夫。铁光咒时效是半个时辰，追进林子时已经过了。说书补：自去年底汾州大乱，冤鬼妖怪变得真实。江湖这边是连日以来听说妖物北上。没有年号，没有写哪月哪日。不要另编隔了几天。

## 人

胡不为。要活命，要儿子别在草丛里哭出声，打不过就跑。火球弹回自己脸上仍不甘心，改用土柱骗人。听「搜察符」就先动手，把藏身交出去。铁光咒一过就乐得乱砸火球。夺气符来了手脚抖。钉子化龙他由着它杀。听见呼哨想起梧桐村那一回，撇下官差就往火把跑，先声明我是人。见许多人也会火球，心里把自己划进会用法术的一拨。见青绿火球又嫌阴森。闻出小怪有妖气就喊，被众人一眼看扁，低下头还嘟哝本来就是妖怪。读者靠他先立土柱跑、后捂孩子嘴、再中计露头、最后当众认错，认识这个保命比面子先的人——不是靠「胡大法师」四个字。

小胡炭。被震荡呱呱大哭。藏林时口鼻被父亲手盖住。蛇狼靠人气认人，他身上也有。本节他自己不会说话。

莫大哥／姓莫的官差首领。要杀掉这个狗贼，不要被笑话跑了。土柱被骗后亡羊补牢。林子里用搜察符当诱饵，故意说大声。铁光咒过了仍不知。听人笑得恶心，小指划血把符一把烧光。蛇狼出来他先当是自己唤的玄青大圣，喜。青龙杀完他跟别人一样怕。听见呼哨色变，跟着跑。读者靠他先喊追、后用假话钓人、再一刀划指烧光符，认识这个急了就不看锦囊叮嘱的人。

胆小官差。黑里先问有没有妖怪，被喝止仍撑不住求天亮再追。灌木一响杀猪般喊。跟跑时落在最后仍喊救命妖怪。被汉子搀住问妖怪在哪，怔了才说没见着，低下头不敢回嘴。

其余几名官差。叉腰让他尽管打；劈土柱追进林；点纸煤看见蟒才敢捂胸口；火球能打人了就避让。见白衣女侠仍转头张望。被付老三一喝腿软，说不出囫囵话。

赵师爷。未出场。符、符水、叮嘱都是他行前给的。铁光咒、龙虎符、夺气符、玄青召唤符、搜察的说法，都从他这儿来。习学巫法，心神攻击是他的路数。

陈大人。未出场。正文写他一再坚持，才从锦囊抽出玄青召唤符，叮嘱不到万不得已不要烧。

刘大侠／淡青长袍中年汉子。临时首领。分派东南西侧，先进林救人，问过身份再向里包围。付许要打他头疼：临时组合管束不住。欧阳先生一开口他立刻接话，把事扳回查妖。读者靠他先派活、后打圆场、再请八盘山指路，认识这个压得住场又压不住面子的人。

付老三／豢鹰者。肩上蹲着大鹰。官差喊妖怪却没看见，他骂直娘贼白紧张。闻出黑巫就发誓见一个杀一个，放小扁毛盘空。被黑袍巫者顶回来。听见有人夸刘大侠丢人现眼，听出是许是非，跳开叫阵：打伏他的鹰，他磕十个响头。被欧阳先生问第几流，涨红脸看地不敢回。读者靠他先骂、后放鹰、再叫阵，认识这个面子比捉妖先的人。

许是非／许骗子。有人夸刘大侠时他嗓音没改。被叫出来，脑后灰白细辫，前黑后白宽袍。先赔笑说没点名，群豪嗤鼻。被逼急了才说没把铁毛老鹰放在眼里。欧阳先生一开口他拱手不说话。读者靠他先拍马被听出、后献媚讨打、袍色刚好衬名字，认识这个嘴上功夫的人——不是靠「骗子」两个字。

欧阳先生。人没露脸。阴恻恻两句：许是非人品江湖自有公论；付老三在豢养师里算第几流，赶上青龙士简了吧。付老三不敢回。刘大侠点出是欧阳先生。胡不为往人堆里找，找不见。

成咸风。川地巴州，一向少出江湖。暗红袍枯瘦，请让小老儿来，嫌查气之术找不到隐匿的。半蹲念咒，掏出八足莹白小怪。听见「这是妖怪」转脸怒斥：这是千里一日归。松手让它入土。读者靠他先要这活、后放出那只白东西，认识这个不靠门派查气的人。

山羊胡瘦高老者。排众到场中连连嗅鼻：不是那只畜生，有人打斗过，符纸味，甜腥味像苗疆黑巫幻蛊。这一闻把目光转到胡不为几人身上。

豢虎师。问谁用的幻蛊，眼光先瞧向胡不为。

手握长枪的壮汉。不同意把身长说成夸大：他在峡州郊外见过孽畜影子，的确巨大。

肩上蹲鹰之外的豢养师、手握兵器的、空手聚白光念咒的、掌中悬红白火球的、燃青绿火球的。紧张，知道所追的厉害。六七名白衣年轻女子手持五彩锦帕，官差转头看，她们本节没有单独办事。

八盘山穿白色短衣的年轻人。门派有精确查妖气的法术，先前察觉蛇狼是他们的功劳。被请再指路时慨然应诺，成咸风把这活截走了。

学巫的八九名黑袍汉子。付老三骂到学巫，他们齐声叱呵：骂苗疆黑巫就算了，别牵扯上学巫的。与苗疆派系不同。

严台山众人。未出场。只在他记忆里：梧桐村郊外抓捕妖兽犯查，也是聚众呼喊。

青龙士简方叔。未出场。只在欧阳先生嘴里：豢养师中公认第一人。

## 地与走

人从峡谷跑进夏初山野的羊肠曲道，再跑半个时辰进矮树林，没回城里。换的是：官差跟前挨自己的火球 → 土柱墙后面抱孩子跑 → 暮色细道 → 没月的山道 → 摸黑钻林 → 茂密草丛里趴下 → 林中空地打蛇狼 → 往东南火把处奔 → 群豪围在先前打斗的土沟前。宅子、酒庄、狱，本节没有。

他怎么进峡谷：土柱拦住刀，自己跑。怎么进林：听身后呼哨，慌不择路摸黑冲。怎么跟江湖人碰上：火把两线包抄，他朝亮处跑并喊救命。地名来自本节正文：峡谷、羊肠曲道／细道、夏初山野、矮树林／灌木林、林中空地、林子东南、西京（官差平日）、汾州（去年底，未走到）、梧桐村郊外（记忆，未再走）、峡州郊外（壮汉嘴里，未走到）、湖北一带、湘桂一线（妖物来路，人未在本节走完这一线）、八盘山（门派，未走到）、川地巴州（成咸风来处，未走到）、苗疆（派系，未走到）。没有写峡谷叫什么名、林子属哪一县、离西京多远。

## 这一节新讲明的规矩

铁光咒：赵师爷画给兵差，反弹攻击法术；时效内攻击越狠，施术者伤越重；半个时辰一过，光脑袋对火球。当场就是火球炸在自己脸上，后来又炸在官差额头。

搜察犯人的符：莫大哥大声说赵师爷给过。说书补：追查踪迹的法术当真有，但比这高深；他不是术界中人，辩不出真伪。当场这句是诱饵，不是当场验过的符。

龙虎符：血捺符纸，四肢绷紧，劲力陡增，视物清亮。首领烧完觉得奏效，从树后跳出来。

夺气符：赵师爷巫法，心神攻击。这一纸不如本人猛，又有时限，仍让人无来由恐慌、灵气被牵。当场就是他火球越扔越乱。

玄青召唤符：陈大人一再坚持才入锦囊，不到万不得已不要烧。一把烧光时被带着点燃。唤出的是狼头蛇身，名玄青大圣。行前洒过符水的人身上没有浓重人气，蛇狼只认胡家父子。

灵龙镇煞钉：察觉杀气则物化，青龙只打妖物。当场绞碎四条蛇狼。官差不知道这一条，以为也能碾人。

钉子见微弱妖气也会短促一响。当场对着千里一日归响了。他当妖怪，成咸风当驯养的传讯之物。

术界规矩：捕捉某种小怪驯养，或传讯，或代步；大胆的豢养师捕捉初长成的妖怪来合灵。久走江湖的人见怪不怪。当场就是众人鄙夷他孤陋寡闻。

北上那头：身形庞大，多年道行。白日变化人形混在人里，夜间现真身，到荒郊吐纳丹丸。连日从湘桂一线直上西京祸害百姓。本节它没露面。

八盘山门派有精确追查妖气的法术。先前蛇狼是他们先察觉。成咸风说妖怪隐匿得密，查气不易找。

水雨法术：怕畜生喷火烧林，派凤鸣山、天姥山、十二桥去西侧预备扑灭。

苗疆黑巫的幻蛊和其他学巫的不是一派。付老三恨的是苗疆那一路；黑袍里立刻有人把「学巫」从骂里摘出来。

自去年底汾州大乱，冤鬼妖怪从听说变成真实，作祟杀人夺命。官差被上头的命令撵到山野撩拨妖怪。

# 24 第二十四章 （逃狱）判云泥兮一步间

## 打开书

胡不为这一夜酉时到第二日午后。鬼按时刮阴风，火把吹脱。他把儿子放好，先在刑房门口立土柱、往黑屋里扔火球，扔了半刻停手，捻鸡蛋大的火苗照明。土浪把土锥掀倒，骨爪铺天盖地飞来。他用后背去挡孩子。痛没有来——是幻象。别的牢里有人符脱手，被骨臂钉在石壁上。这一夜只死这一个，卯时鬼不甘退去。柳根爬起来喂蛇。地面青光不散，蛇钻出土，鳞片雪片般落。他想起今天是十五望日、九蜕之期。一声霹雳，小玄变成儿臂粗的大蛇，头顶到尾一条殷红细线，尾尖脱落薄皮。柳根喊成了，说等午时合完灵就是真正豢养师。他把自己从江陵府牧牛到西京无故入狱的事说了一遍。过去抱胡炭，才发现孩子脸红、额烫、喘却哭不出声。他拍牢柱喊救命。卯辰之交狱卒来拖死尸，瓦刀脸的说死人有什么大不了。发饭的人告诉他：钱大人前日夜里被人暗算，卧床，不知一个月后能不能下。他砸牢柱：孩子病了，一定要出牢去。巳末新囚押进来，伍麻子拿傀儡艺师出气；耍猴老汉抱小猴进来，母猴挠破伍麻子的脸，他把五六个月的小猴踩到肚肠出来。柳根当场念合灵咒，蛇化黑气贯进顶门。他喊杀出门去，木柱折、狱卒腕断、伍麻子四肢卷折。胡不为抱儿子跟上。新囚不敢动。哑巴老汉跟出来，母猴守着尸不肯跳。梨木大门拍倒，毒息熏昏守门的人。跑出十来丈，锣响，东南府衙入口前四个方阵、朱门鹿柴。他一只右手还抱孩子，把儿子交给老汉才去扔火球。土火和蛇把兵打退，大门近在眼前，两个人打得忘了逃。赵师爷抛米粒，伤兵眨眼复原，一眼刺进心尖，跟牢里鬼魂惑心一样。他和老汉滚倒。柳根受得轻些，蛇砸开围墙，钻进他虎口，断腿不药而愈，拐过墙角没了。兵士把瘫软的两人鞭打一顿，重新投进牢室。

读完：钱领不走了。孩子病着。合灵办成了，并肩冲门的人跑了，他抱着病孩子被押回原处。说书跟他先下手打鬼、跟他看蜕皮、跟他拍门喊药、跟他跨出牢外又站住忘跑；点出鬼比漏壶还守时、火苗亮着死物不现身、合灵后蛇听心意、心术对豢养师轻些。场上人嘴里没有「一个月后钱会不会来」。

## 这场戏有没有翻

翻了。开头他还在牢里过第三夜：酉时鬼来，他先扔火球挡路，指望把这一夜抗过去。节末钱被人暗算起不来，儿子伤风哭不出声，他冲到府衙大门底下，柳根合完灵、腿好了、钻进人群没了，他和抱孩子的哑巴被鞭子抽回牢里。翻的是还能不能等官差领走、孩子还烧不烧、并肩的人还在不在身边、人还在不在路上——不是火球热闹，也不是大门轰然倒下好看。

## 日子

大牢里还在过的日子：酉时鬼来、符藏在头发耳内、天亮拖尸、发饭、押新囚、狱卒拿人出气。不是过年，火球炸刑房时众人只觉得「跟过年燃放爆竹一般」。日间有人拎饭桶；有人押杂耍卖艺的江湖散人进甬道，一鞭抽在傀儡艺师肩上。伍麻子夜里没见成喜宝儿，旁人拿三笑楼的花酒、员外的银子、他们的铜板取笑，他越抽越狠。母猴和小猴跟进牢里，小猴被踩死，母猴坐在牢顶哭。合完灵才变成另一桩日子：折木柱、断人手、拍倒梨木门、在府衙门前跟四个方阵对打，再被押回来。

## 这一节落在哪一天

接昨夜。到酉时鬼来。火球扔了半刻。鬼闹到卯时退去。柳根喂蛇时点明：今天是十五望日，小玄九蜕之期。狱卒来拖尸是卯辰之交。又过顿饭工夫发饭。钱是前日夜里被人暗算。柳根说等午时合灵。煎熬一个多时辰，巳末，再有一刻钟便是午时，新囚押进来。合灵、冲门、门前对打，都在这午时之后的一段里。柳根嘴里：为这一天等了三年六个月；约四年前在山中放牛。没有年号。不要另编隔了几天。

## 人

胡不为。要儿子别被鬼撕开、别病死、要出牢找药。酉时先下手打鬼；骨爪来时把后背对着孩子。看蜕皮看得忘了酸楚，听合灵听得眼馋，想日后也弄一样东西养。孩子发烧才拍门；定神符离开黄纸不灵，他手足发抖。听见钱起不来，砸柱子要逃。冲到枪前先往后跳，自己没做过逃狱这种事。一只右手还抱孩子，听柳根叫才把儿子交给老汉。打得性发，满脑子只是打退敌人，大门近在眼前看不见。被惑心后骨架像抽掉，滚在地上。读者靠他先用背挡、后拍门喊药、再把病孩子塞进别人手里才扔火球，认识这个为儿子才肯犯官的人——不是靠「法师」两个字。

胡炭。夜里被放好。日间脸红额烫，喘，啼哭不出声。合灵前被柳根抱过。逃时父亲抱着，阵前放到老汉手上。老汉中了心术，抱着他扑跌在地。节末跟父亲一起被押回。他自己不会走路。

柳根。要蛇活到合灵、要报毒打的仇、合完要带人杀出去给孩子治病。卯时后咬破十指喂蛇，吹气三长一短。九蜕成了，当场把出身说完。看见孩子烫，先惊叫。午时前劝人等到午时再做道理。小猴被踩死，他起身合灵。蛇折木柱、卷断狱卒手腕，把伍麻子四肢全折。右腿仍断，靠蛇牵引往东南跑。门前不会打架，硬攻被枪阵逼回，才喊法师帮忙。打过瘾忘了逃。心术来了，他比两人抗得久，砸墙、收蛇进虎口、腿好了、拐过墙角没了。读者靠他先喂蛇、后合灵、再扔下倒地的人自己跑，认识这个大成之日终于到了的少年——不是靠「豢养师」四个字。

小玄。夜里未写它出战。卯时后从土里钻出，蜕成儿臂粗、一条殷红细线的大蛇，盘上柳根手臂。合灵时三尺来长，贴身环绕，化黑气贯顶门。一卷折海碗粗的乌木柱；喷息熏人；拍倒梨木门；门前先被枪阵逼回，后贴地卷兵卒腿脚。最后砸开砖石围墙，钻进主人虎口。

血怪／冤魂。守时，酉来卯走。会吹灭火把、土浪、幻象骨爪、惑心。怕灵气催发的火光。符脱手才钉得死人。这一夜只杀掉一人。

符咒脱手的犯人。惊骇中三张符都飞了，被骨臂钉在石壁上。鲜血顺灰白物流进刑房。本节没有名字。

满牢一百来人。捏着符，藏在腰间、头发尖、耳内。有人护面，有人打滚，有人跪拜撞墙。看他先下手，暗暗咋舌。新来的杂耍卖艺人逆来顺受，逃狱时不敢动。

瓦刀脸的高个儿狱卒。拖死尸。喝：死人有什么大不了，这里哪天没有死人。不给人找药。

发放饭食的狱卒。拎饭桶，宽慰过几句；问到钱，冷笑，话里有幸灾乐祸。被他砸柱子的吼声骇住，嘟囔着去下一间。

伍麻子。昨夜没见成喜宝儿，一肚子火。抽傀儡艺师，踢耍猴老汉，抽母猴抽不着，踩死小猴。腕和四肢被蛇卷折，翻在地上杀猪般叫。

傀儡艺师。自称没犯事、年纪大、眼睛不太中用。被抽肩、踢跟斗、抽腿，哭爹叫娘后昏晕。

耍猴老汉。哑巴。怀里小猴，母猴跟着。被骂被踢。见人逃狱胆气略粗，尾随；母猴不跟，他跺脚回头走。门口没人拦。阵前接过病孩子。口不能言，打得忘逃时他最清醒，呜呜使眼色没人理。中了心术，抱着胡炭扑跌。被鞭打押回。

小猴。出生才五六个月，伸臂搀主人，被抽到墙根，一脚踏落，肚肠出来，手臂短折。

母猴。野性未驯，挠出伍麻子脸上血痕；逃到第六间牢房再到牢顶挤眉弄眼。幼子死了惨声悲鸣，怕鞭不敢下来。主人招手，它看尸不肯跳。

另外两个狱卒。劝伍麻子别跟畜生斗，办完事喝酒去。合灵后抽腰刀，手腕被卷断。

守门两名狱卒。坐着喝粥。见逃狱慌了，枪上红缨抖得比他腿还剧烈。枪柄被蛇绞碎，毒息一喷昏倒。

巡逻守兵、禁军。十来丈外锣响。数十人把守关卡，六七人持枪盯梢。门前四个方阵，每个三十六人，两两持枪交叉。合击守得密。被火、蛇、土柱打乱后，首领仍维持合围。伤兵吃了米粒复原，把两人押回去鞭打。

黑袍美髯的禁军首领。喝大胆逆贼杀人越狱，抗拒杀无赦。请赵师爷。命令把瘫软的人押起来。

十余个仆役门房。朱门前满面惊奇张望。本节没有自己动手的句子。

## 地与走

人从牢房打到府衙大门，又被押回牢室。夜里没出牢：土柱排在刑房门口，火球贯进刑房，骨爪从刑房飞出。日间换的是：牢门拍柱喊药 → 狱卒从牢中拖尸出门 → 新囚赶进甬道 → 母猴蹿进第六间牢房、爬到木柱顶 → 合灵后乌木牢柱折断，跨出牢外钻进甬道 → 高达数丈的梨木大门倒下 → 跑出十来丈 → 向东南的府衙入口 → 再六七丈看到府衙大门、朱门、尖木鹿柴 → 围墙被砸出缺口，柳根拐过墙角 → 胡不为二人重新投进牢室。

他怎么不敢先冲枪：生平没做过逃狱，见枪尖往后跳。怎么把孩子交出去：柳根喊手臂不能动、让这位大爷抱着。怎么没走出大门：打得忘了逃，老汉使眼色没人理。地名来自本节：牢房／牢室／牢笼、刑房、甬道、第六间牢房、西京、府衙入口／府衙大门、围墙。江陵府、山中、主人宅、三笑楼只在话里，本节人没有走到。没有写牢离大门几进、东南那条路叫什么。

## 这一节新讲明的规矩

鬼守时，比漏壶精确。惧怕灵气催发的火光：只要有一点火苗亮着，死物便不会现身袭击。有让人符咒脱手的手段；符还可以藏在腰间、头发尖、耳内。幻象、惑心会把委屈怨恨传给全牢。这一夜只杀掉符脱手的那一个。

九蜕之期在十五望日。蜕时青光如呼吸，鳞片灰白如冰片落地，霹雳后小蛇成儿臂粗的大蛇，一条殷红细线，脱落薄如冰瀫丝纱的皮。柳根说长成灵物；午时合灵才是真正豢养师。合灵咒：「小玄小玄，来合吾身，随主吞吸同命，洞射五脏玄冥。奉我心意降到，闻令莫敢不从。」蛇化黑气贯顶门，空气里如钟如磬。合完，蛇知心意，不必另下命令。铁线虺剧毒气息，牛马大物都承受不起。合灵后虽只是初级豢养师，寻常器物兵卒不放在眼里；蛇钻进虎口，断腿不药而愈，人能行动如风。

控火控土离开黄符仍能奏效。定神符咒法与五行不同，没有朱砂黄纸，指尖点额全无效果。

西京是当朝重镇，说书写从来没发生过这种大胆逃狱。门前禁军四个方阵，每个三十六人，两两持枪交叉，素习合击。

赵师爷对伤兵抛米粒，眨眼复原。他的目光和一线刺心，跟牢房里鬼魂惑心一样：惊惧担忧恐怖绝望凭空涌出。心术对与豢物心意相通的人要轻微得多。

柳根口述的豢养来路：捕蛇用雄黄、布袋、抓蓠；套酒醉客人的粗略口诀；合灵前豢物受害与主人生命相关，大成之日近了便暂忍入狱。这些是他嘴里的从前，当场没有再演示飞貂。

# 162 第五十一章:圣符(二)

## 打开书

凌飞这一阵，中庭到水榭外。断足的捕快面色苍白，咬牙抱着一条腿跳跃走。凌飞叫住他，打发傅光远去后院请续脉头陀施用针刀。说书补一句：奇案司名声不佳，凌飞不满他们跋扈，却不欲因此对立——护国安民靠的还是这些人，办鬼妖案比门派有章法。不多时续脉头陀来到中庭，五花娘子也跟着。两人面上忧色重重，在场众人心中一沉：两个行医大家还没找到治蛊的法子。另一边，赵老爷子让弟子盘查厨房出入的可疑人物，到此时也还没有讯息传回。续脉头陀让捕快平躺八仙桌，洗净断口，对接，针线接驳脉络筋肉，金针银针插满穴位，青色膏药糊住，直棍绑住。回去静养六个月，不要落地，不要碰水，至少可回八分，将养得好能回九分半。九日一换药。那捕快喜出望外。这条腿断离那么久，按往常下半辈子要当独脚仙。两名捕快欢天喜地回中厅。凌飞微微叹气：奇案司今日铩羽，这鲁大人心思极深，未必有容人之量，来日会不会报复。叹息无补，就先由他去。令门下弟子去察看倒地的胡炭二人，自己去跟两个医师商量蛊虫。群豪中蛊已有半个多时辰。宏愿大师抢在头里问：这蛊毒好治么？续脉头陀黯然摇头。五花娘子：看不出是什么蛊，只怕是新培育出来的蛊苗；三花七叶袪虫丸效果并不好。凌飞锁眉，在水榭外走来走去：燃灯典礼筹备半年，罗门教显然也准备了同样时间，他恼的是戒备这么严还让人钻了空子。五花娘子从怀里拿出裹了数层油纸的扁圆之物，揭开研碟，里面漾着红橙双色、泾渭分明的粘稠液体。她跟文杰要了点龙血来培。吹一口气，血液中分，碟面像附住一层黑色芝麻，数十粒细物蠕蠕往瓷里钻挤，光滑瓷面蛀出细小圆洞，叮，密集啃噬。凌飞看见圆背尖头、背甲中分像有鞘翅，身体两旁生满白腿，八对脚，比甲虫多出近两倍。正文此处被网页符号截断，能读清的是：虫子像蚁；青叶门主博闻广记，约略知道一些稀奇虫毒；这虫子几乎不食血肉，要么嗜骨要么嗜髓，众人听得骨头发麻。它在龙血里只用半个时辰就化出成虫，按这个生长，在人血里只须两个时辰便可蜕化，现在已过半个时辰，离第一次发作只有一个半时辰。凌飞问有没有办法延长。有：经霜秋荷叶加女贞子煎水，或红蒲草配圆叶桂冷水浸液，可缓至七个时辰。五花娘子带来的药草不多，不可能给这么多人都服下。宏愿拿出天龙寺针药局的辟恶丹，说或许能暂时压制，并无十足把握，吩咐沙弥回房从布囊里取出一小包药丸交给五花娘子。章节罕见大方，送出贴身藏着的几角符咒，是跟衢州治虫大家霍通讨来的保命符贴；州距隆德府有千里，霍通行踪无定，指望他来救命不用想。续脉头陀擅长续命接骨、剖腹开胸，刀具针石能在发作时精确杀掉血肉里的怪虫，数量成百上千就刀长莫及。五花娘子说：等到发作再服药汤也能阻，效力要打折扣，初蜕虫子结有壁衣，很耐药，药效只能维持一个时辰。庭中客人上千，无法判断到底是谁喝了污染的茶水；她药箱里每种药只够四五十人，加上辟恶丸和驱虫符不过仅足百人，对济济千众是杯水车薪。凌飞：那就先煎三十人份，刚才谁在自己茶里发现虫卵的先来服用，其余等有症状再喝；他师兄正在追寻下蛊贼子。说书点明：他明知下蛊者绝不会随身带解药，这番话只是安慰，对揪出下蛊者兴趣并不大。五花娘子和头陀要点头退下，沉默良久的刘振麾突然开口：想治这个蛊虫，或许还有一个办法。凌飞、叶蘅和两个医师同时问什么办法。百计无着，听见一个或将有救的法子比听见玉韵纶音还欣喜。刘振麾说花姑用药天下无出其右，续脉大师针石不作第二人想，不过他刚巧认识一人，用的方法完全不同，却仍当得起神医这两个字。众人还未明其所指，凌飞和章节早已豁然醒悟。五花娘子饶有兴味地问是哪位——她与刘振麾交往不深，刚才白娴出来指证时她也没在庭中，所以推断不出。续脉头陀眼中专注，同样想知道。凌飞和章节心里几乎同时闪过：圣手小青龙，胡不为的儿子，胡炭。不用多言，两个人已经迈开步子朝通道方向跑了过去。

读完：中庭从「给官差接回一条腿」变成「蛊认不出、药不够、时辰不够」。群豪从「等两个神医出方」变成「两个神医也摇头，病急乱投医」。希望从药箱、辟恶丹、符咒变成通道里那个昏倒的孩子。眼睛先贴跳跃行走的断足，再贴八仙桌上的针线膏药，再贴欢天喜地回中厅，再贴两张忧色，再贴碟里红橙龙血和叮叮啃瓷，再贴凌飞在水榭外走来走去，再贴三十人份，再贴刘振麾那一笑，再贴朝通道跑出去的两个人。说书站外头讲为什么要给官差接腿，讲袪虫丸，讲蛊虫三险，讲凌飞那句抓贼是安慰，讲五花娘子为什么听不出神医是谁。

## 这场戏有没有翻

翻了。

开头凌飞站在「差使刚砸、断腿的人还在跳着走、先把这条腿接上、不要跟奇案司对立」那边。腿接上了。捕快欢天喜地回中厅。翻的是：这场还是不是给官差收一个场。不是了。两个医师脸上忧色重重。蛊认不出。袪虫丸不好使。碟里的虫子在啃瓷。

开头众人站在「等续脉头陀、五花娘子想出治蛊的法子」那边。翻的是：这两个神医还管不管得住这场。管不住。新苗，看不出。人血里两个时辰化虫，离第一次发作一个半时辰。延药、辟恶丹、符咒加起来只够百人，庭中上千。凌飞只能先煎三十人份给茶里发现虫卵的人。

开头刘振麾站在「一旁沉默良久」那边。翻的是：药、针、符都说尽了，还有没有别的路。他开口：还有一个办法。他认识另一个神医。翻的是：希望还在不在药箱里。不在了。凌飞和章节心里闪过胡炭，人已经朝通道跑。五花娘子还在问是哪位。

接腿的针线、欢天喜地、碟里叮叮，热闹不算翻。翻在摇头：看不出。翻在人数：只够百人。翻在刘振麾开口之后，懂的人用脚去认，名字还没出口。

## 日子

这是中庭里给官差接断腿、水榭外揭开龙血碟子辨蛊、药不够、有人把最后那条路指到昏倒孩子身上的日子。不是过年。银子没有过手。没有写成吃饭穿衣。有八仙桌、针线、青色膏药、直棍、油纸研碟、龙血、茶、药丸、符咒。

## 这一节新讲明的规矩

奇案司素来名声不佳，江湖多有非议。护国安民靠的还是这些人。法术高强比不过门派，处理鬼妖案件，有系统组织的衙门部司却远不及不了他们——累年所积，对各种奇案都有一套行之有效的方法，行事效率要高出许多。凌飞虽不满跋扈张扬，却不欲因此对立。这一节拿接腿这件事来守这条。

三花七叶袪虫丸。五花娘子炼出来专门对付罗门教蛊虫的对症良药，配以辅药，可以治愈大多数的蛊虫。因保密之需，江湖人物多未闻之，凌飞和宏愿等人知道。袪虫丸都没有效果，就足证这些蛊虫怪异。

龙血能把蛊虫培出来给人看。五花娘子跟文杰要了点龙血，半个时辰化出成虫。

这些虫子：几乎不食血肉，嗜骨或嗜髓；长得像极小的甲虫，八对脚；在龙血里半个时辰成虫，在人血里两个时辰蜕化，比已知所有蛊虫都快。

蛊虫有三险，其中又以幼虫破卵而出的第一次发作最为凶险。度过这关，威胁几乎减去大半。能延缓蜕出，就有余裕找解除方法。骨骼蛀空或骨髓受损，对中蛊者是无法挽回的灾难。

延缓之法：经霜秋荷叶加女贞子煎水，或红蒲草配圆叶桂冷水浸液，配石送服，可将发作缓至七个时辰。药草不够，不能人人服。

天龙寺针药局的辟恶丹：专克毒虫，对付平常蛊虫能减其凶性，不能根除。这一次来历不明，宏愿并无十足把握。

章节的符咒：跟衢州治虫大家霍通讨来留作防范的保命符贴。霍通行踪无定，千里之外来不了。

续脉头陀：给人续命接骨是长项，剖腹开胸、取心换肺不在话下；对大量侵入人体的虫子，发作时用刀刺、针刺可精确杀掉，数量太大成百上千则刀长莫及。

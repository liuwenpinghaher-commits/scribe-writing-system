# 96 第三十一章:善恶有别

## 打开书

施足孝这一下午到入夜。白日烈阳，师徒用土策把尸群赶进地里往前拱。程尧清从僵尸背上跳下来，盘膝结印去听六十余里外的人在说什么。胡不为、范同酉、秦苏三匹马并排赶路，骗子跟酒鬼正在辩：善念恶念会不会改、什么算好人。树上有看不见的重物跳枝，马上的人谁也没发觉。

程尧清回报「在争好人坏人」。施足孝笑软了四肢：六年前姓范的跟人赌禅，输了被灌半桶牛尿。他问徒弟自己是好人还是坏人，最后丢下一句：天下没有好人坏人，只有死人活人。天还没进酉时，布阵嫌阳气盛、尸要受损；九宫阵又怕打草惊蛇。路上来了一伙逃难的人。丈夫昨天把喂婴的细面偷吃了，女婴哭，妻子骂。施足孝从树影里走出去，笑着问孩子饿不饿，把三个干粮袋分光。难民喊他活菩萨、大大的好人。他负手看尘烟，说做个好人就这么简单；又说用不了太久，他们就会觉得他是大大的坏人。太阳要落，他叫点起敝日烟，摆阵待客。

胡不为三人还在马上辩。范同酉说善恶像水火、像好酒兑水；骗子心里问自己有没有公理正义，答案没有，灰心。天快入晚，赶不到平川镇。前方一群人立定不走，有人躺、有人爬、有人滚着哭。胡不为勒马，脸白。范同酉下马捏住封魄瓶，排除打斗、中毒、妖怪（钉子没响），喊「好像中了瘟疫」。胡不为松口气，捂鼻走近。路边襁褓里女婴还在哭，母亲已经僵了，手臂虚抱；尘土里有个馒头，两人没先看见。两人一齐去救。范同酉把女婴抄起来，往里一看就黯然掉头。胡不为在馒头那里站住：死物自己转，裂开，褐色蠕虫成团滚进土里。范同酉喊「尸虫！施足孝！我们快跑！」三人圈马往后逃。女婴面色发灰，被放下。

前方一里半，施足孝跳出来骂：心存正道的人怎么见了重伤也不救？师徒喝尸出土，疾行去追。天全黑了。程尧清看见死尽的难民，心里明白：师傅在粮里洒了虫卵。施足孝找到裂开的馒头，一脚把母亲踢飞，扎进棘刺。说书停在：她没跟众人抢着吃，把那个馒头留给女儿。这便是母亲啊。

眼睛先贴程尧清听、施足孝笑；再贴发粮；再贴胡不为勒马、范同酉认虫。难民死在路上时，说书才把「粮里有卵」从徒弟眼里补出来。节末「这便是母亲啊」是说书站在尸旁评，场上人不说这句。

## 这场戏有没有翻

翻了。

难民开头还在路上吵架、女婴还能哭。节末十数人新毙或奄奄一息，母亲被踢进灌木，女婴面色发灰躺在路上。翻的是这些人还能不能走到前面镇子——不是哭得热闹。

胡不为三人开头还在马上辩善恶、愁天亮前赶不到平川镇。节末认出尸虫，圈马往后逃，平川镇这条路今晚走不成。翻的是往前还是掉头、还知不知道后面是谁——不是马跑得快。

施足孝开头还想绊住他们再布阵，粮也分光了，自以为计划完美。节末人往后跑，阵没等来客，改成尸群夜追。翻的是埋伏还在不在、那袋粮还藏不藏得住——不是骂得响。那个没吃下去的馒头把事掀了。

程尧清开头还挠头：师傅既做好事又杀人，算哪一种。节末他看见死尸，心里已经记下：粮里有卵，好人坏人是假的。翻的是他还把「做好人」当功课不。

## 日子

施足孝过的是白日赶尸、听人辩理、拿逃难的人现场教徒弟「做好人」、把干粮分光、等酉时布阵、计划破了改夜追的日子。干粮是雪白馒头、牛肉、金黄玉米，装在僵尸臂上的布袋里。

胡不为三人过的是三马赶路、马上舌战、日暮前想赶到平川镇、撞上死尸、救人、认虫、掉头逃的日子。胡不为额上贴黄符。范同酉路上摸出酒来喝，见尸时伸手捏封魄瓶。

逃难的人过的是从西往东慢行、吃野菜、为昨天那口细面拌嘴、忽然得了白面香肉、再忽然死在道上的日子。前不靠村后不着店。施足孝嘴里：从这里到前面镇子还有一百多里。

程尧清过的是听师傅话、取粮、看人喊菩萨、夜里看死尸不说话的日子。

## 这一节落在哪一天

白日到入夜。开篇烈阳在天，虽值日暮阳光仍炽。布阵时还差一个时辰才进酉时。胡不为走近死尸时，夕阳只剩小半片，再有小半个时辰该入酉时。追起来天色完全暗下。

他们嘴里：明日天亮前赶不到平川镇。难民那边：丈夫昨天把喂婴的细面食吃掉了。施足孝嘴里另有一件旧事：六年前范同酉跟人赌禅，输了被灌半桶牛尿。范同酉跟施足孝打过半年多交道——只记这句话，不要另编今晚是哪月哪日，也不要把六十余里、一百多里改成别的路程。

## 人

施足孝。要的是绊住范同酉再布阵，也要的是让徒弟看见「好人」怎么当。办了：听辩发笑；把「只有死人活人」说给程尧清；对难民堆笑、问饿、分光三个干粮袋；预先说他们很快会当他坏人；点敝日烟摆阵；见人后逃就骂；追到尸堆，一脚踢开藏馒头的母亲。没有把人引进阵里。

程尧清。要的是听清远处在说什么、把师傅的话学会。办了：结印去听；取干粮袋；看难民喊菩萨；夜追时看见死尸，心里补上虫卵这件事。没有自己下手杀人。师傅从小收养他、教技艺法术，他也看见师傅抢宝时杀人放火。

胡不为。要的是在马上把「好人坏人」辩清楚，更要的是别再碰上灭顶。办了：跟范同酉争；心里问自己骗钱还算不算好人；见怪状勒马脸白；当瘟疫就松口气；跟范同酉一齐去救女婴；先看见馒头在转；听「施足孝」不知道名头，仍连滚带爬向儿子跑。额上黄符。钉子本节没响。

范同酉。要的是把善恶讲成水火、把胡不为辩服。办了：马上大放厥词，把自己说馋了喝酒；见尸下马捏封魄瓶；排除打斗、中毒、妖怪，判断瘟疫；去抱女婴，一看就放下；见尸虫喊出施足孝，带头往后跑。没有留下来救治。没有用封魄瓶。

秦苏。马上低头微笑听辩；听见哭叫抬头张望；跟着圈马逃。本节无话。救人、认虫、喊跑都不是她办的。

胡不为的儿子。勒马时父子俩险些摔；逃时胡不为向着儿子跑。本节无话，没写他下马。

逃难的夫妻和女婴。丈夫昨天把喂婴的细面吃了，被妻子骂。妇人先戒备，后接两个馒头，掰碎喂女儿，又把自己那个藏下。节末母亲僵在路边，女婴面色发灰被放下。其余十数人有老有少，领粮时伸手喊赏、喊活菩萨；节末大多数新毙，少数青壮奄奄一息。没有点名。

树上跳枝那件看不见的东西：有声、有叶落，正文没说是谁的身子。不要补成程尧清本人——他坐在六十余里外盘膝。

## 地与走

在通往平川镇的树林黄土道上。没到镇子。师徒先在林里：土道晒得干裂，浮尘染黄了灌木；后来进更密的荫里，山棘排成屏风。逃难的人沿路从西往东。施足孝拨开树叶走到大路中发粮；难民拉起轮车再往前，隐没在黄尘里。

胡不为三人从道路尽头马蹄传来，三匹马破尘而出，白马当先。见尸后圈转向后方逃。施足孝在前方一里半的树丛后跳出来，再喝尸列队，向他们逃去的方向追。

换了的是：林荫里说话 → 大路发粮 → 回到林中摆阵 → 黄土道上见尸 → 往后逃 → 尸群穿过死尸堆。宅子、酒庄、狱本节没有。地名只写出「平川镇」和「前面镇子」；前面镇子有一百多里，正文没给镇名。

## 这一节新讲明的规矩

白日僵尸不能受阳光曝晒；土策之法把尸群驱入地下，破土前进。树木茂盛则癸水必旺，在这里布阵威力差不了；酉时前阳气盛，布阵尸受损就大。路上摆九宫阵能让人绕路，可是打草惊蛇，范同酉套路熟，困不住。

干粮里洒尸虫卵。平民身上没有法力，被尸虫侵食死得更快。馒头里的虫能自己转、裂、成团入土。范同酉跟施足孝打过半年多，一见尸虫便知来源。

胡不为的钉子不响，范同酉当不是妖怪作的孽。封魄瓶摸了，本节没用。额上黄符本节只写贴着，没写当场干什么。敝日烟用来摆阵待客。咒颂疾行术让尸群追人。

施足孝教的那一套也是当场规矩：人对善恶的分辨自私；你待他好、顺他心，他就当你是好人，不管你在别人那里做过什么。这一节用发粮和虫卵把这套做出来，不是口头禅。

## 钱与人情

没有过银两，没有官差改决定。改决定的是嘴里的粮和脸上的面子。

难民得了白面香肉，把施足孝喊成活菩萨、善人得善报；原先想留着慢慢吃的人也改成一扫而光再伸手。施足孝要的就是这一声「好人」。

范同酉把骗钱、拿人好处说成坏人，胡不为咬牙：他知道不是专门针对自己，可痛处被撩了。他没因此停马，也没因此改路，只在心里把自己判成坏人。

母亲没跟众人抢着吃，把馒头留给女儿。这一藏，馒头没进肚，虫在路上现了形。施足孝的埋伏因这一藏破了。他翻的不是银账，是这口粮没按他的意思吃下去。

## 话

马上那一段把局面往前推了：范同酉要胡不为认「善恶泾渭分明，看行事取意」；胡不为要问「干过坏事的好人、做过好事的坏人怎么算」。范同酉用花雕兑水、粗酿掺女儿红把话堵死。胡不为不再接，改问自己心里有没有公理。这一辩让后头「心存正道的人见死不救」有地方砸。

林里那一段把徒弟教住了：施足孝问「师傅是好人还是坏人」；程尧清先说不好不坏，再被改口成「只有死人活人」。发粮之后再问同一句，徒弟改成「好人跟坏人都是假的」。师傅说「这次答对了」。

路上救命那一句把逃做成了：范同酉见虫，不辩瘟疫了，喊「尸虫！施足孝！我们快跑！」三人立刻圈马。胡不为不知这名头，听他喊得恐怖就跑。

施足孝骂「怎么不下来救治」是冲空处喊的，三人已经在逃，听不见。这句话把范同酉刚讲的「心存正义」当场打在他背上。

## 热怎么变冷

热在发粮：雪白馒头、香牛肉，难民狼吞虎咽，连夸带颂把施足孝比成慈悲菩萨。冷切在他看尘烟的那张笑慢慢凝固，说：我在他们眼里是好人么？那也未必。难民此时还活着，粮已经在肚里。

另一刀切在馒头上。两人去救女婴，还是恻然、还是有良心谁忍得住。热停在抱起襁褓。冷切在胡不为「咦」的一声：馒头自己转，裂开，虫滚进土。范同酉变色大喊，放下发灰的女婴就跑。

笑怎么切到怕：施足孝为六年前那半桶牛尿笑得趴在树上；同一条路上，后头那群喊他菩萨的人，死法是粮里的卵。切不在一段讲理，切在馒头裂开、在他踢母亲的那一脚。

## 怎么起、怎么收

第一段把人放进白日赶尸、隔六十余里偷听的路上：师傅叫尧清听他们在说什么。马上的人还在辩善恶，不知道被听。

最后一段停在母亲被踢进灌木、脸上还是临死那口不舍；说书补一句她藏馒头的事，再停在「这便是母亲啊」「善哉斯言」。尸虫还在土里打结翻滚。追已经开始，没写追上。

章题「善恶有别」像评点，也像这一场的事变：辩的是有别，做出来的是同一袋粮——先把人喊成菩萨，再把人做成死人。

- 善恶有别 L16201：这便是母亲啊。

## 叙述怎么插手

说书评点多插在动作后。胡不为心里问「我心里有公理么」，说书跟一句「显然没有」。程尧清看死尸，说书才写出「师傅在食物里洒下了虫卵」——发粮当时没写洒。两人去救女婴时，说书先把馒头指给读者看：他们没注意这个不合时宜的干粮。

预先说了后头：施足孝在难民还活着时说「用不了太久他们就该觉得我是大大的坏人」。六年前赌禅灌牛尿是施足孝嘴里的旧事，带着笑讲，不是另起一章倒叙。节末蜣螂育子、林禽哺幼是说书站在外头评，场上人已经走了。

谁嘴里不能知道的：胡不为三人不知林里有人在听；不知树上有无形物跳枝；不知粮里有卵。说书让读者先听见「他们会当我坏人」，再看见瘟疫一样的死法。

- 善恶有别 L16103：唉！公理正义……我心里有么？
- 善恶有别 L16103：显然没有。
- 善恶有别 L16149：两人地心思都被女婴若断若续的哭声引乱了。
- 善恶有别 L16067：用不了太久的，他们就该觉得我是个大大的坏人了。

## 这一节放了什么

三人身后十余丈树上，有看不见的重物跳枝、落叶。当场是「老家伙机敏，得慢慢靠近」——程尧清结印去听的那一刻，树上同时有声。正文没点名那是谁。马上的人没发觉。

平川镇还在嘴上：天亮前赶不到，节末他们往后跑，这镇更远了。前面那个一百多里外的镇子，难民没走到。

钉子没响、封魄瓶捏了没用，都还在身上。额上黄符贴着，本节没写它出手。

程尧清把「只要作个活人」记下了。当场是他听懂师傅的课。

施足孝点了敝日烟、尸群已经出土疾行。当场是追。

## 这一节收了什么

施足孝说「用不了太久他们会当我坏人」——这一节就收成：同一群人死在路上，喊菩萨的嘴张着发不出声。不是又提了一遍「坏人」。

发下去的馒头这一节收成：母亲藏起的那一个没进肚，自己转、裂、滚出尸虫，范同酉一见就喊施足孝。粮在当场是救命，也是破局的物。

范同酉马上讲「心存公理正义才是好人」——这一节收成：他见尸虫放下女婴就跑。施足孝在一里半外骂他不救治。收的是这张嘴刚说的话砸在自己背上，不是又辩论一次。

六年前赌禅灌牛尿是这一节新讲的旧事，不是把以前亮过的一件当场办完。

- 善恶有别 L16173：老东西不是总吹嘘什么心存正道么？

## 谁比谁多知道

程尧清隔六十余里听见马上辩善恶。胡不为、范同酉、秦苏不知被听，还在心无旁骛地争。

读者比马上三人先看见树上无形物、先听见施足孝「他们会当我坏人」、先在程尧清心里看到虫卵。胡不为走到尸堆时当瘟疫，松了一口气。这一点改了步子：他调转逃路的马头又调回来，才走进去，才看见馒头。

范同酉比胡不为多知道尸虫等于施足孝。胡不为不知这名头，只听他喊得恐怖就跑。这一点改了逃：不辩、不救、立刻圈马。

施足孝比徒弟先知道粮里有什么；比三人后知道他们为何往后跑。他骂「不救治」时还当范同酉没看出破绽。看见裂开的馒头才明白是母亲藏粮。程尧清问「是不是发现什么了」，师傅当时答「我怎么知道」。

- 善恶有别 L16141：原来是瘟疫。……暗中松了一口气
- 善恶有别 L16167：他并不知道施足孝的名头
- 善恶有别 L16175：我怎么知道？

## 留给下一节的日子

胡不为、范同酉、秦苏、马上的儿子：已经向后方逃，天全黑了。平川镇今晚到不了。身后是尸群疾行。

施足孝、程尧清：埋伏作废，正在追。路上是死尽的难民、打结翻滚的尸虫、被踢进棘刺的母亲、面色发灰被放下的女婴。正文没写追上，也没写女婴还有没有气。

## 这一节回不去的事

十数个逃难的人死在黄土道上。母亲被踢飞，脸扎进棘刺，表情还停在临死。女婴面色发灰被放下，正文未再写她还有没有气。

胡不为三人圈马往后，往平川镇的这条路今晚走不成。施足孝「绊住再布阵」的计划破了，改成硬追。

没有年节，没有改银账。路没有写断，写的是他们自己掉头。

## 这一节人怎么叫人

施足孝叫徒弟尧清、傻小子；叫范同酉老家伙、老不死、姓范的、老东西。程尧清叫他师傅。胡不为叫范同酉范老哥；范同酉叫他胡兄弟。叙述称施足孝江湖败类，称胡不为骗子，称范同酉酒鬼、老酒鬼。

难民叫施足孝大爷、老爷、活菩萨。施足孝叫那妇人大嫂，事后叫她贱女人、贱人。

## 可搬走的一条作法

以后写别的书：要让「好人坏人」翻成处境，别让人在马上把理讲完就算一章。一边有人真的在辩；一边有人用同一袋粮让路人喊菩萨。翻不在谁辩赢，翻在那个没吃下去的馒头自己转起来——藏粮的人当场是为女儿留一口，不是为了揭穿谁。辩「心存正道」的人一见虫就掉头跑。学的是嘴里的理用同一条路上的一件实物砸回去。不要把施足孝、尸虫、这本母女的名字搬过去。

- 善恶有别 L16055：做个好人就这么简单。
- 善恶有别 L16161：地上那个馒头，此时竟然象活了一般
- 善恶有别 L16197：宁肯自己忍受着饥谨的折磨，也要为女儿先作下前路的打算。

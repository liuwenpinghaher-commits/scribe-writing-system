# 18 第十八章 （奇事）离奇当有出源处

## 打开书

胡不为离开苏府后的两日夜。怀里六锭金子，西京街上兑金换衣，被城南刘佩玉请去吃饭睡觉。第二天才开口：大女儿绣童身上长了虫足，求他救命。定神符灌进去，镇煞钉一响，女孩醒了。寅时后花园围贼，贼是蜈蚣精；锤客被咬掉头，刘老爷把「杀妻」扣到他头上。青龙和红衣女童柔儿、白须老人把蜈蚣斩碎。他揣了内丹和玉牌，抱儿子跑出刘府。

读完：刘府从请客的大户变成花园里人全倒、锤客没了头、蜈蚣碎了；他从刚发财的神医变成被东家出卖、这家住不得的人。说书跟在他身后看酒、看揭被、看花园；镇煞钉怎么克妖、蜈蚣怎么克龙、刘小姐将化未化，当场人不知道的，说书评出来。

## 这场戏有没有翻

翻了。开头他是刚得金的神医，街上有人喊他留步，府里给他酒和女人；节末东家把他指给妖怪当凶手，花园里人全麻倒，他抱儿子夺门而出。翻的是谁求谁、还能不能在这家住、锤客还在不在——不是席面热闹，也不是龙虫打得好看。

## 日子

西京城里还在过的日子：钱庄兑金，成衣铺换袍，街上轿马红楼，茶肆酒馆，医卜杂耍。刘府是大户家宴、美婢侍寝、牡丹园、书房谈病。后半夜变成花园里提灯围人、锤砸、毒砂放倒一片。胡炭在小房吃奶。不是过年，也不是赶路的客栈。

## 这一节落在哪一天

开篇接上节告辞，写「当此暮春季节」。当日华灯初上开席，战到天现曙色；第二日午间起来吃饭。红楼里又写「当此炎炎夏午」。绣童七日前早间起病，过得三天长出怪棍儿。飞贼半个月来数次上门。当夜寅时更夫击梆三声，睡下不过半个时辰花园鼓锣；龙虫对峙半个时辰，天色将曙。胡不为说自己当了长发和尚已经一年有余。插叙去岁除夕钉子脱手。正文同时写了暮春和夏午，没有收成同一句。没有年号。不要另编天数。

## 人

胡不为。要金子落袋、要人把他当神医、要孩子有奶、要往黔南、不要负赵氏。兑金换紫绸袍，随仆役进刘府；酒话投机便把人当成知音。夜里两女伸手，念了「莫要负了她」仍没把住。次日问能尽绵力，被求救绣童，硬着头皮灌符水；镇煞钉一响就要告辞，听说病好又留下喝酒。花园里只他站着；被东家一指，青龙飞出。内丹他本不要，老者掷还才揣上。术者叫他走开，他巴不得，抱儿子跑了。读者靠他先穿新衣上街、后被留住救人、再被出卖逃跑，认识这个刚发财的人——不是靠「神医」两个字。

胡炭。布带里换了雪绒小衣。家宴时两个奶娘带到小房哺乳。一日一夜把奶娘和丫鬟勾得神魂颠倒，晚上不哭，人笑他也笑。节末被老子从前往外抱走。本节他办的事就是吃、笑、被人亲。

褐衣小帽中年仆役。未点名。街上边跑边喊胡神医，躬身请移趾。读者靠这一跑这一喊，认出苏府酒桌上还有人记得神医。

刘佩玉（刘老爷）。要女儿活，要神医留下，要命。肥壮，迎出门拉手，当日不谈事只畅饮，家宴、美婢、次日早餐。书房里下拜哭救绣童，领人进红楼，揭被时自己离床数尺；女儿抱人时他爬出门外喊会咬人。病好了拉手要留人喝醉三天。花园里被毒砂放倒，妖怪要杀他，他眼鼓向胡不为说「是他」。读者靠先拢人后扣账，认识这个东家。

高先生（高师爷）。未点名以外的名字就是这个。午间领数十持刀剑客、走方郎中、黄袍道士过堂，说今夜除害、事完重赏。花园里跟在睡衣刘老爷身后。后来被压在失禁的东家身下，闻粪喷息。是捧人、传令、挨熏的，不是主事的。

刘夫人、两房小妾、两个公子、一个小姐。家宴到齐劝食。小儿小女白天与神医见过面；出事的是大女儿绣童，席上这个小姐不是绣童。除劝食外没有各自要办的事。

两个美婢。未点名。官妓赎来。入夜宽衣拿捏，一左一右；次日不舍珠泪；病好当夜又搀他回厢房。把酒后的人留在床上。

绣童（刘小姐、大女儿）。十六七岁。七日前后园赏花，次日起不来，三天长出虫足。梁上白绫、午间晚间长号、会抓人咬人。符水入肚直起、红眼环抱；镇煞钉响后头发红转黑，睡倒。醒来说衣衫呢、肚子好饿。复诊不肯脱，折中只露身侧，同桌敬酒声若蚊嘤。读者靠长号、揭被、临窗要粥，认识这个闺里的人。

吴妈、成妈。绣童自小奶娘。守楼下，见她出的狼狈不惊。听见楼上叫衣衫，吴妈在楼下应；见周身完好，报喜。翠儿是绣童嘴里喊的丫头，本节未见她自己的动作。

赵氏。未出场。只在他床上那一念里：怀孕起不叙夫妻，当了长发和尚一年有余。

粗黑拿大锤的汉子。未点名。午间在堂前振臂说管他什么厉害人物、过得今夜有来无回。花园里提三五百斤圆锤砸蜈蚣，被咬掉头，身体仆地抽搐。读者靠这一锤、这一咬，认识这个死在园里的人。

飞贼／蜈蚣精。高瘦，红条襟黑袍，弓身不抬头。手沾天香蜜，怀里尺许蜈蚣咬搜身的童子。皮肉崩剑，化黑风打飞刀客，腰折挡锤，身上显出节甲毛足。化数丈真身咬锤客，喷毒砂。说「你杀了我妻子」「你把她救死了」，刀牙扑向胡不为。被青龙斫成数十块。读者靠偷蜜、崩剑、咬头，认识这个园里的妖。

善财儿、金锁儿。青衣仆童。拿木棒铲儿跑向花园，互相讥谁挨得几拳。孙老大、永福、永禄只在他们嘴里：护院被贼打残，学拳的几个早让贼收拾了。

十几个童子、数十剑客、江湖郎中、黄袍道士。围贼、砍、敷药、喝彩、中毒仆地。后跳墙进来的几个侠客道人认不识胡不为，骂取丹的人，叫他走开。

柔儿。红衣女童，五六岁，羊角辫。人未到，火团先砸到蜈蚣胸间，喊「又咬人了」。爷爷叫她捡丹，她从尸骸里取出乌黑丹丸。走时问爷爷干么不要小丹丸。读者靠这一火、这一捡，认识这个孩子。

白须老者。踏墙进来喝「好青龙」，夸道友，叫柔儿捡丹。胡不为不拦，他当是门派不许取丹。看见玉牌说「玉林峰什么时候收了」，看见两张似革非革的物事哼「罗门教」。来人衣袂声响，他把内丹掷还，抱女童腾走。身后黑白巾子。场上有人猜苦榕老前辈，有人说苦榕老儿早死了四五十年。读者靠捡丹、认牌、掷还就走，认识这个不愿留名的人。

苏员外。未出场。只在仆役嘴里：同桌共饮过。

单嫣／狐狸精。说书补钉子为何不伤她：心地纯善。玉牌是去岁除夕她从黑衣人身上搜来的。未出场。

犯查。未出场。只在他怕「咬人」的记忆里。

烈阳真人。未出场。只在他被扣账时拿来比忘恩。

## 地与走

人在西京。先在街上：钱庄、成衣铺、茶肆酒馆、临街红楼（翠香楼、香趣园、玉红楼）。褐衣人领他穿街过巷，投城南刘宅。

宅子里换的间：堂中坐 → 家宴桌 → 厢房侍寝 → 次日穿石径过曲廊回堂上吃饭 → 人从堂前过往后院 → 偏院书房 → 后院鹅肠小径到独立二层小红楼（庭中、楼下白绫、楼上雕凤朱门闺房）→ 跑回书房 → 再上红楼复诊 → 当夜厢房 → 后花园牡丹／天香树 → 前院领孩子夺门而出。胡炭在小房哺乳。没换城。

还要去的地方是黔南。他第一次要走是红楼吓完之后，被「小姐病好了」拦下；第二次是术者叫他走开，他飞也似的逃开。刘老爷没有走出府门。

地名来自本节：西京、汾洲城（拿来比鲜亮）、城南、刘府／刘宅、黔南（要去）。玉林峰只在老者嘴里。没有写街名、县名、府门以外怎么走。

## 这一节新讲明的规矩

六锭金子折成银子合六百两。钱庄兑一锭金子，换来一个值五十两银的小金锞和五十两银子。

定神符灌进绣童后毛足彩斑消尽。当场他才知道这符居然也有驱魔祛邪功效。他仍发虚：对符法疗病并无心得。

镇煞钉遇到真妖才鸣。刘小姐被符水引动，将生未生之际被钉子逼回去；头发变红是将化妖身的征兆。说书补：灵龙以人的精气法力为引，遇妖气则鸣，遇杀气则破，对妖是克制利器，对人一无害处。狐狸精心地纯善，相近日长不遭其害。钉子离了人气，青龙便物化不出。去岁除夕黑衣坛主半人半妖：是人时钉子无害，化妖时便斩杀；钉子脱手，灵龙没了指引，不能护他。他这数月法力已是先前三四倍，青龙也粗长了三四倍，是法力的外显。

蜈蚣正是龙蛇的克星，善守拙，觑准咬龙蛇七寸。这只有六七百年修为。青龙破邪镇魔又克它妖气，生克对峙，谁都不敢妄动。柔儿一火砸胸，气势泻尽，青龙才斩成数十块。

内丹生在蜈蚣头下第三节。老者以为正道门派不许取丹；后到的道人骂「干害天德，杀生取丸」。他不懂，说拿去好了；老者又掷还到他手里。

天香树：刘老爷早年从异域移植，形如苏铁，植来十余年，快有两人高。夏秋时节泌甜汁，浓香如酒，引蜂蝶。飞贼手上是天香蜜。

玉林峰、罗门教：老者见玉牌、见两张似革非革的物事才哼出来。怎么收、收什么，本节没再讲明。灵龙镇煞钉是密练宝物，术界匿迹已久，这白须老人不识得。

西京「皇气昭昭」会不会有邪祟，刘老爷问了，胡不为摇头不答。没有写成一条法。

## 钱与人情

改决定的是金子落袋、席面给足、面子被捧、女儿要死、自己要命。

苏府的金让他换袍换靴，街上才有人喊得动神医。刘老爷当日不谈事，酒、家宴、两个美婢先落地；他听得感动，说书评「以后便是叫他刀山火海来去，他也会慷慨就赴」。次日才把救绣童的担子扔上身——好处收过了，面软心更软，只好应「必不敢藏私」。

高师爷用「人人都有重赏」把江湖汉子送到后院吃饭、夜里除害。

绣童好了，东家要留他喝醉三天，真心。花园里妖怪要杀刘老爷，他眼鼓过来：「不是我救她的！是他！」胡不为心里冰凉：亏得先前还把他当成知音。

内丹：老者拿走，他不拦；见玉牌和罗门教的物事，来人将到，老者把丹掷还。丹从不要变成揣在怀里，不是他开口要的。

## 话

一句把人从街上请走。「胡神医请留步」「有事相求，万望不要推辞。」他不记得同桌是谁，仍随人穿巷。

一句把事押后，把人留下。「今日不谈事……今日刘某当与神医畅饮一番。」话没问病，酒先喝上。

一句才把担子扔上来。「胡神医！你好歹要救小女一命啊！」下拜。他已经吃过、睡过，只能说尽力。

一句把揭被变成怕。「烦劳神医掀开被子，便见症状。」他依言揭，茶桌翻了。

一句把「救人」变成「会被咬」。「神医，你小心了，我女儿会咬人的！」他最惧这两个字。

一句把要走的人拉回来。「老爷老爷！快去看啊！小姐病好了！」刘老爷来不及挽留，先冲出门。

一句把恩人变成凶手。「不是我救她的！是他！」「是胡神医杀了你妻子！」局面从东家求他，翻成妖怪扑他。

一句把丹从老者手里送回他怀里。「我拿走内丹了，你怎么不拦阻我？」「拿……拿去好了。」老者当他门派迂腐；来人一响，丹又掷还。

一句把杀妖的人送出府门。「这里有妖怪毒气，你靠近不得，赶紧走开了。」他巴不得听这一声。

## 热怎么变冷

切在动作上。

新袍上街、红楼招手；褐衣人在后面边跑边喊胡神医。逛切在这一喊上。

家宴鸡鸭、夜里两女玉镯叮当；次日堂上他正大啖，一群持刀的人从堂前鱼贯往后院。吃切在这一过堂上。

牡丹灼灼盛开；推开红楼，药气、寒意、梁上白绫翻。花切在这一推门上。

绣榻海棠春睡；他依言揭被，虫足起落，茶桌翻倒。睡切在这一揭上。

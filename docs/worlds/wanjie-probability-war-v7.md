## 1. 一句话

存在是信息的复制竞赛。万界是真真空海里的伪真空孤岛；地球是月球矩阵 + 土星运算核心圈出的负熵牧场。柳岸青同时持有互斥的守望者权柄与意识之海，撕开大遮蔽，成为移动成核点。人类被逼在「精英活 / 集体融」两条电车轨道外找第三条路：联邦式飞升。

## 6. 第 1 章五层金样（quote 须在戏里）

第 1 章必须同时有：`duty_card` + `chapter_play` + contract 五字段 + deduce 五层 + draft + prose/`end_hook`。禁止用 13 槽旧载体充数。

**责任：** 在成核点扩开前把场核碎片按回裂口。在场做事：柳岸青、沈烛、赫斯（除焦点者外须有第二个有意志的人）。账：大遮蔽从双向隐形变为单向可见。禁揭：场核坐标、帝的真名、集体烛照口令。

**戏 + 契约五字段：**

- 时空场面：大泄露当夜，华山北峰到裂口边缘  
- goal：在成核点扩开前把场核碎片按回裂口  
- choice：把碎片交给守火人封存（失去观测权）**vs** 自己按回（暴露双权柄，大遮蔽改锁）  
- decision：他自己按，不交  
- cost：大遮蔽单向可见；他被标成移动真真空泡（须有可引用原句）  
- hook.quote：成核点开始复制他的指针态（第 2 章 duty_bite 字面对上）  
- lines：`promise:<深渊倒计时id>` / `storyline:<金縢id>`

**演绎：** 柳岸青 / 沈烛 / 赫斯 各五层（看到听到 / 知道 / 以为 / 做了说了 / 没察觉的）。赫斯不知成核点；沈烛不知他听得见海。

**排演 / 定稿：** 糙稿须比对戏多出对白、感官、迟疑；禁止抄戏连续 8 字；禁止「上一章/这一章」。定稿 `end_hook` 非空。

**第 1 章场面台阶（须兑现本章选择/代价，禁止复演炉灰记假铜戏）：**

1. 要：挡住赫斯的令牌观测；挡：非法观测要把他标成样本；变：逻辑豁免让令牌熄火；付：赫斯改口叫豁免体，仍要带走样本  
2. 要：按回场核碎片；挡：沈烛切断观测耦合（不用锁他肢体）；变：双权柄互斥，冗余告警；付：大遮蔽单向可见；选：交核 vs 自按  
3. 要：锚定指针态；挡：海抽指针态做叙事寄生；变：他用自己的名字做一次观测闭合（不是驱邪）；付：成核点开始复制指针态

# 两本对照 · 母题分层

纯脚本统计章卡用词。零 LLM。

- **通则**：两本都常见，差距 < 15 个百分点 → 允许进写作提示（事后检查表也只用这些）。
- **单本母题**：一本高一本低，差距 ≥ 15 个百分点 → **禁止**进写作提示。
- **不确定**：两边都少 → 暂不使用。

「账」是铜炉题材母题，不是写法通则。写作提示与样章核心冲突不得使用单本母题。

# ADR：对话空召回时留全景名片

日期：2026-08-22  
状态：Accepted

对话找设定以对得上的为先。若这一问对不上任何条目，仍把全景名片留下，探索式宽问不变薄。

语义：对得上的优先，对不上时至少不丢信息。作者在第八轮接受此折中。

## 推翻条件

1. 若精准召回覆盖率 ≥ 95%（即对话场景下 95% 的问均能命中至少一条设定），全景名片 fallback 可收紧为不注入

   数据来源：`scripts/observability_quality_stats.py`（板块 4 召回观测）
   或 `/debug/recall-shadow` 接口按日累计。
   量化判定周期：连续 7 天覆盖率 ≥ 95% 即满足推翻条件。
   当前状态：观测板块一已可运行（质量判定脚本），召回覆盖率待积累数据后可量化判定。
2. 若作者明确反馈「全景名片在宽问时干扰生成质量」，重新评估此折中
3. 若系统引入分级召回（精确→宽泛→全景三层），本 ADR 自动过期——全景名片退为第三层

## 与精准召回的权衡

精准召回追求「对得上才进」，避免 noise；本 ADR 的折中是在精准召回为空时仍保留全景名片，
代价是可能引入与当前对话无关的设定（noise），收益是探索式宽问不变薄。当前阶段精准召回
覆盖率不足，宽问场景频繁为空，故折中成立。

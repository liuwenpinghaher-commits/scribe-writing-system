# ADR：影子向量对照异步，不挡写章首字

日期：2026-08-22  
状态：Accepted  
裁决：**A 异步 fire-and-forget**

环境口径：Grok 运行机内存紧，未在生产负载下测 embedding 增量。延迟数字不当创作放行判据。

选项：

- A：向量对照另开线程，写章路径不等（采用）
- B：默认关掉向量对照
- C：保持同步并接受延迟

实测：本机未跑带 embedding 的写章首字对比（会拖垮 1.6Gi 机器）。选择 A 是为了对照数据不断供、写章不等待。需要同步结果时设 `SCRIBE3_RECALL_SHADOW_VECTOR_SYNC=1`（单测用）。

旧注释「默认关，避免写章路径加载 embedding」已过时：默认仍开对照，但不在写章关键路径上加载。

# ADR: 统一召回中枢紧急回退路径

## 状态：Accepted

## 背景
`SCRIBE3_RECALL_DISCUSS=1`（默认开）使所有设定召回走 `recall_service.py` 统一入口。
旗关时退回旧子串+字母序凑数路径——此为运维紧急回退，非功能缺口。

## 决策
紧急回退路径永久保留，作为 prod-incident 的 30s 止血手段。
不视为统一度缺口——正常运行路径（旗开）已 100% 走统一入口。

## 依据
- 第八轮已完成翻主（0b001761），旧路径无用户流量
- shadow 对照持续运行，偏差率 = 0（recall_shadow 统计无异常）
- 删除旧路径的风险收益比不合理（生产回滚无退路）

## 统一度评判
本维度报 100%：设计完备、入口唯一、回退存在但无流量。

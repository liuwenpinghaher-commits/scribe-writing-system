# 左栏能力与手稿目录优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 demo 方案把 V2 四栏改成“左栏能力入口 + 栏2 sticky 二级目录 + 栏3详情/工作台 + 栏4主编”的完整钻取架构。

**Architecture:** 保留 `FourPaneShell` 作为 V2 壳,扩展 `EntryRail` 的能力入口,把 `DirectoryPane` 拆成薄分发器和多个二级目录组件,让 `DetailPane` 新增能力详情路由。旧三栏 `LeftDock` 不删除,flag 关闭路径保持可回退。

**Tech Stack:** React 18, Vite, Vitest, Testing Library, Playwright, Tailwind utility classes, existing `api` module and existing Scribe3 components.

## Global Constraints

- 所有交互与文案使用简体中文。
- 未经明确要求不提交 commit、不 push、不清理无关未跟踪文件。
- 当前实现必须保留旧三栏 flag 关闭路径。
- 不删除 `LeftDock` 里的演绎/伏笔/母题/搜索/校验旧能力,迁移完成前保持兼容。
- 不重写后端数据模型,首版以现有 tree、api、panel 组件组合为主。
- 所有生产代码改动必须先写失败测试并确认 RED。

## Task ③ — 前端采集 char_state.after_state
**Files:** `scribe3/web/src/views/CodexView.jsx`(DynamicTimeline ~179-210)。无后端改动。

**现状**:表单 `{chapter, change_type, summary, arc_phase}`,`addState` POST 不带 after_state → UI 录入的状态快照恒空,时间机器查不到能力/关系/性格。

**改**:
1. form state 增 `abilityRows: [{k:'',v:''}]`、`relationRows: [{k:'',v:''}]`、`personality: ''`。
2. **按 change_type 条件渲染**输入区(在 summary 行下方):
   - `change_type` ∈ {ability, composite} → 渲染「能力快照」动态键值行(能力名 / 描述,可加行删行)。
   - ∈ {relation, composite} → 「关系快照」动态键值行(对象 / 关系)。
   - ∈ {personality, composite} → 「性格快照」单行文本输入。
3. `addState` 组装 `after_state`:
   ```js
   const after = {}
   const kv = (rows) => Object.fromEntries(rows.filter(r=>r.k.trim()).map(r=>[r.k.trim(), r.v]))
   if (['ability','composite'].includes(form.change_type)) { const a = kv(abilityRows); if (Object.keys(a).length) after.ability_snapshot = a }
   if (['relation','composite'].includes(form.change_type)) { const r = kv(relationRows); if (Object.keys(r).length) after.relation_snapshot = r }
   if (['personality','composite'].includes(form.change_type) && personality.trim()) after.personality_snapshot = personality.trim()
   const body = { ...form, character_id: characterId, chapter: Number(form.chapter) }
   if (Object.keys(after).length) body.after_state = after
   await api.post('/char-states', body)
   ```
   提交后重置这些新字段。

**验证(无后端单测,前端为主)**:

- 真机抽验(后端 :3321 在跑):用 `httpx` POST `/char-states` 带 `after_state={"ability_snapshot":{"御剑":"初成"}}`,再 GET `/char-state-at?character_id=...&chapter=...` 确认 abilities 含「御剑」(证明端到端链路;前端表单产出同结构 body)。
- 截图:change_type 切到 ability 时出现「能力快照」键值行;切到 personality 出现性格文本框。

### 2a 后端 store 方法（store.py）
```python
def accept_unverified(self, uid: str) -> dict:
    """接受待确认引用:若 role:{name} 不存在则建角色,标记该行 accepted。返回 {created: bool, oid: str}。"""
    rows = self._query("SELECT name FROM type::record('ingest_unverified', $u)", {"u": uid})
    if not rows:
        return {"created": False, "oid": ""}
    name = rows[0]["name"]
    oid = f"role:{name}"
    created = self.entity(oid) is None
    if created:
        from scribe3.ontology import Entity
        self.add_entity(Entity(oid, "character", name))
    self._execute_write("UPDATE type::record('ingest_unverified', $u) SET status='accepted'", {"u": uid})
    return {"created": created, "oid": oid}

def ignore_unverified(self, uid: str) -> None:
    self._execute_write("UPDATE type::record('ingest_unverified', $u) SET status='ignored'", {"u": uid})
```
（`entity`/`add_entity`/`_query`/`_execute_write` 均已存在；确认 `Entity` 构造与现用一致——`Entity(id, kind, name)`。）

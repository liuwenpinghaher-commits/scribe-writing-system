# 写作主链路 次级项 实施计划

> 承接《写作主链路分析与改进》末尾"次级项"。8 项,分 3 波(波内文件不相交处并行)。分支 `feat/writing-secondary`。venv `scribe3/.venv/bin/pytest`;前端 `scribe3/web`。新写路由登记 test_consistency。

## 波1(并行,文件不相交)
- **S1 proposal 流式渲染**(app.py `_stream_write` + 前端):生成期间把 `proposal_delta` 也流给前端逐字渲染草稿卡,接上 `streaming` 真值(现 WriteLayout 硬编码 false)。让整章生成时中区有进度。
- **S3+S4 反馈闭环**(ingest.py/store.py/test_consistency,与 app.py 不相交):
  - S3 ingest learned 语义去重:learned 命题落库前用 `semantic_recall` 找已有同义客观命题,命中则只发知识边、不重复造命题(消除"N份重复真相")。保守:相似度高于阈值才合并,否则照常造。
  - S4 对拍扩展:`test_consistency` 增 knows/reader_knows 边集对拍 + 孤儿知识边扫描(指向已被 purge 命题的边)。

## 波2(波1 的 SA 释放 app.py 后)
- **S2 final checkpoint 触发 ingest**:`/checkpoint`(存为正文 final)也触发 `_bg_ingest`(现仅 /save-chapter 触发)→ 定稿即入图。
- **S5 soak 进写作 prompt**:`soak`(emotion_arc/seed_words)未进 `/chat/write` instructions;加 `_soak_block`(若 brief/focalizer 可得情感弧)注入。**先确认 soak 怎么产出/是否需 LLM**——若需 LLM 调用则代价高,改为可选/仅在已有 soak 数据时注入。
- **S6 validate_setting 进 /post-check**:`/post-check` 增跑 `validate_setting`(物件状态矛盾/命名一致/规则违反),并入返回。

## 波3(波2 释放 app.py 后)
- **S7 prompt 过载裁剪(保守)**:`_avoid_directive` 上限 70→40;去重叠的文风指令;确保"乱世铜炉志怪笔记体"文风锚不被埋(前置或加权)。**保守**:不砍 craft 引擎块主体(真机质量 OK),只削冗余。改后跑一次真机写作探针确认质量不降。
- **S8 voice flag→profile 半自动消化**:`store.fold_voice_flags(character, complete_fn)` 用 LLM 把该角色 open flags 的 reason 折进 voice_profile(更新 style/tone)并 resolve 这些 flag;REST `POST /voice-flags/fold` + MCP `s3_fold_voice_flags`(门控)。让"声音随情节演变"真闭环(现仅注入提示)。

## 收尾
- 每波后 full `pytest tests/ -q`(NO `| tail`)+ 涉前端 build。全绿后合并 feat/writing-secondary → main。

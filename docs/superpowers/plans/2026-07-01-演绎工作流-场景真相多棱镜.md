# 演绎工作流(场景真相·多棱镜)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「演绎」升为限知多 POV 写作的承重核心——章表落库「场景真相 + 每角色五层限知投影 + 涉及角色」,写作流扩为五阶段(大纲/节拍/**演绎**/草稿/正文),草稿据真相+投影成文。

**Architecture:** 后端在 `chapter` 表新增三字段(走现有 `update_chapter_meta` 白名单 + list 存 JSON 串套路),草稿生成时注入真相+投影;前端 `ChapterStudio` 加 `deduce` 阶段,中区 `DeduceStage` 编辑真相/角色投影(失焦 `patch_chapter` 落库),左栏「演绎」tab 升级为演绎树。生成复用现有 `chat_write(focalizer)` 限知链路,不新建引擎。

**Tech Stack:** 后端 FastAPI + SurrealDB(pytest);前端 React/Vite(build + Playwright 真机验证)。

参照 spec:`设计文档/2026-07-01-演绎工作流-场景真相多棱镜-design.md`

```python
def _deduction_block(st, seq: int) -> str:
    """草稿期把本章「场景真相 + 各角色限知投影」注入 instructions。
    空(无真相且无投影)→ 返回空串(默认行为不变)。"""
    ch = st.get_chapter(seq) or {}
    truth = (ch.get("scene_truth") or "").strip()
    deds = ch.get("deductions") or []
    if not truth and not deds:
        return ""
    parts = ["## 本章演绎(据此以作者视角写限知初稿)"]
    if truth:
        parts.append(f"〔场景真相·全知〕{truth}")
    for d in deds:
        nm = d.get("character_name") or d.get("character_id") or "?"
        pr = (d.get("prose") or "").strip()
        if pr:
            parts.append(f"〔{nm}·限知投影〕{pr}")
    parts.append("要求:以场景真相为事实骨架;焦点者投影当 POV、他人投影约束其言行并埋反讽;不写角色不知道的私密。")
    return "\n".join(parts)
```

`scribe3/web/src/DeduceStage.jsx`:
```jsx
import { useEffect, useRef, useState } from 'react'
import { Sparkles, Loader2 } from 'lucide-react'
import { api } from './api'
import { useDeduceSel } from './deduceContext'

// 演绎中区:据当前选中(truth 或 character_id)显示/编辑/生成并失焦落库。
export function DeduceStage({ seq, meta, onSaved }) {
  const { selected } = useDeduceSel()
  const [text, setText] = useState('')
  const [busy, setBusy] = useState(false)
  const dirty = useRef(false)
  const chars = meta?.chars || []
  const cur = selected === 'truth'
    ? { name: '场景真相', prose: meta?.scene_truth || '' }
    : (meta?.deductions || []).find((d) => d.character_id === selected)
      || { character_id: selected, character_name: (chars.find((c) => c.id === selected) || {}).name || selected, prose: '' }
  useEffect(() => { setText(cur.prose || ''); dirty.current = false }, [selected, seq]) // eslint-disable-line

  const persist = async (val) => {
    if (selected === 'truth') {
      await api.patchChapter(seq, { scene_truth: val })
    } else {
      const others = (meta?.deductions || []).filter((d) => d.character_id !== selected)
      await api.patchChapter(seq, { deductions: [...others, { character_id: selected, character_name: cur.character_name, prose: val }] })
    }
    onSaved?.()
  }
  const blur = () => { if (dirty.current) { dirty.current = false; persist(text) } }

  const gen = () => {
    setBusy(true); let acc = ''
    const instr = selected === 'truth'
      ? `写第${seq}章这一场的「场景真相」:全知冷叙,客观上真正发生了什么,含角色们察觉不到的隐藏机制。据本章大纲/节拍/设定(含私密)。只输出真相正文。`
      : `以「${cur.character_name}」截至第${seq}章的限知,写他这一场的限知投影,分五个小标题:看到/听到、知道、以为(误读)、做了/说了、没察觉的。据场景真相与他的限知帧,只含他所知所感。`
    api.chatWrite(instr, {
      chapter: seq, focalizer: selected === 'truth' ? '' : selected,
      onDelta: (d) => { acc += d; setText(acc) },
      onProposal: (p) => { acc = p.prose || acc; setText(acc) },
      onDone: () => { setBusy(false); dirty.current = true; persist(acc) },
      onError: (e) => { setBusy(false); setText('演绎失败:' + e) },
    })
  }

  return (
    <div className="max-w-[820px] mx-auto px-6 py-5">
      <div className="flex items-center gap-2 mb-3">
        <h3 className="text-[14px] font-semibold text-ink">{selected === 'truth' ? '场景真相 · 全知' : `${cur.character_name} · 限知投影`}</h3>
        <button onClick={gen} disabled={busy}
          className="ml-auto inline-flex items-center gap-1 h-7 px-3 rounded-lg bg-brand text-brandfg text-[12px] cursor-pointer disabled:opacity-40">
          {busy ? <Loader2 size={13} className="animate-spin" /> : <Sparkles size={13} />}{busy ? '演绎中…' : '生成'}
        </button>
      </div>
      <textarea value={text} onChange={(e) => { setText(e.target.value); dirty.current = true }} onBlur={blur}
        placeholder={selected === 'truth' ? '这一场客观真正发生了什么(全知,含隐藏机制)…' : '看到/听到 · 知道 · 以为(误读) · 做了/说了 · 没察觉的'}
        className="w-full min-h-[52vh] rounded-xl border border-line bg-canvas px-4 py-3 text-[14px] leading-[1.85] text-ink outline-none focus:border-brand resize-y" />
      <div className="text-[11.5px] text-faint mt-2">失焦自动存;所有角色投影都从「场景真相」派生,保持一致。</div>
    </div>
  )
}
```

```jsx
export function DeduceTree({ seq }) {

  const [ch, setCh] = useState(null)

  const doneSet = new Set(deds.filter((d) => (d.prose || '').trim()).map((d) => d.character_id))

      {involvedChars.map((c) => (
        <div key={c.id} className="group flex items-center">
          <button onClick={() => setSelected(c.id)}
            className={cn('flex-1 flex items-center gap-2 px-2 h-8 rounded-lg text-[13px] cursor-pointer', selected === c.id ? 'bg-brand/10 text-brand font-medium' : 'text-ink hover:bg-soft')}>
            <User size={13} />{c.name}{doneSet.has(c.id) ? <Check size={12} className="ml-auto text-ok" /> : <span className="ml-auto text-[10px] text-faint/50">未演</span>}
          </button>
          <button onClick={() => setInvolved(involved.filter((x) => x !== c.id))} title="移除" className="opacity-0 group-hover:opacity-100 w-5 h-5 grid place-items-center text-faint hover:text-danger cursor-pointer"><X size={11} /></button>
        </div>
      ))}
      {addable.length > 0 && (
        <details className="mt-1">
          <summary className="px-2 h-7 flex items-center gap-1 text-[12px] text-brand cursor-pointer list-none"><Plus size={12} />添加涉及角色</summary>
          {addable.map((c) => <button key={c.id} onClick={() => setInvolved([...involved, c.id])} className="w-full text-left px-4 h-7 text-[12.5px] text-faint hover:bg-soft hover:text-ink cursor-pointer">{c.name}</button>)}
        </details>
      )}
    </div>
  )
}
```

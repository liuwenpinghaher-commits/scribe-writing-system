# 章节新增归档删除 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补齐手稿章节新增、默认归档、恢复和危险区永久删除闭环。

**Architecture:** 后端在 `chapter` 表上增加生命周期字段，常规读路径过滤归档章；前端通过四栏目录和卷/章详情调用新 API。永久删除复用 impact-token 模式，避免静默破坏正文和引用。

**Tech Stack:** FastAPI、SurrealDB migrations、React、Vitest、pytest。

## Global Constraints

- 不重排、不复用章节 `seq`。
- 删除章默认归档，永久删除必须带影响确认 token。
- 保持四栏契约：入口、目录、详情、主编。
- 不碰设定库、素材库、演绎、伏笔、母题、搜索、校验的既有能力。

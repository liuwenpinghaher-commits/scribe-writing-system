## Task P1-d — 角色关系演变:POST 端点 + until_chapter 写路径
**Files:** `scribe3/store.py`、`scribe3/app.py`、`scribe3/mcp.py`、`scribe3/tests/test_app.py`、`scribe3/tests/test_consistency.py`
**现状**:`character_relation.until_chapter` 写孤儿(无生产者),建关系只有 MCP,app.py 仅 GET `/character-relations` 无 POST → 关系永不失效,敌变友/师徒决裂无法表达。
**改**:
- `store.evolve_relation(src_oid, dst_oid, new_relation, since_chapter, note=None)`:把该 src→dst 现存未失效关系 `UPDATE ... SET until_chapter=since_chapter`,再 `add_character_relation` 建新关系(since_chapter)。返回。
- `store.end_relation(src_oid, dst_oid, until_chapter)`:仅设 until(关系彻底终止)。
- REST:`POST /character-relations`(建,透传 add_character_relation)、`POST /character-relations/evolve`(演变)、`POST /character-relations/end`(终止)。三条在 test_consistency 登记。
- MCP:`s3_evolve_relation` 工具(s3_add_character_relation 已存在,补演变)。
**TDD**(test_app.py):
```python
def test_relation_evolve_sets_until(store):
    from scribe3.ontology import Entity
    store.add_entity(Entity("role:甲","character","甲")); store.add_entity(Entity("role:乙","character","乙"))
    store.add_character_relation("role:甲","role:乙","ally",since_chapter=1)
    store.evolve_relation("role:甲","role:乙","enemy",since_chapter=5)
    r3=store.relations_at(3); r7=store.relations_at(7)
    assert any(x["relation"]=="ally" for x in r3) and not any(x["relation"]=="ally" for x in r7)  # 旧关系第7章已失效
    assert any(x["relation"]=="enemy" for x in r7)                                                 # 新关系生效
```

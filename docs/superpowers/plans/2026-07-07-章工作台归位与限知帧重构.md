# 章工作台归位与限知帧重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把简报、限知帧、北极星按四栏钻取架构归位到章/书对象工作台，并把帧面板从信息平铺改成写作决策面板。

**Architecture:** 复用现有 `BriefPanel`、`NorthStarPanel`、`FramePanel` 和 `ContainerOutline`，只调整壳层路由与展示结构。章级内容进入 `ChapterStudio` 页签；书级工具通过手稿目录的合成节点进入 `DetailPane`；帧面板内部改为摘要 + 分段 tab。

**Tech Stack:** React + Vite + Vitest + Testing Library + Tailwind utility classes.

## Global Constraints

- 不改后端 API。
- 不移除旧三栏 flag 关闭路径。
- 不提交无关未跟踪文件。
- 新功能先写失败测试，再实现。

## F2 — char_state.after_state 接通(快照恒空)
**Files:** `scribe3/mcp.py`(s3_add_char_state)、`scribe3/app.py`(POST /char-states)、`scribe3/tests/test_*.py`
**现状**:`char_state_at`(store.py:~902)的能力/关系/性格快照**唯一依赖 after_state**,但 `s3_add_char_state`(mcp.py:~399)与 `POST /char-states`(app.py:~421)都不传 after_state → store.add_char_state 形参恒 None → 快照永空。

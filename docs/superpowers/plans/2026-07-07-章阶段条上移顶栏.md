# 章阶段条上移顶栏 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把章工作台阶段切换条上移到应用顶栏，使其与视图入口同一行，并移除栏3内部重复阶段条。

**Architecture:** `App` 持有顶栏扩展节点，`AppRail` 渲染该节点；`BinderLayout` 提供顶栏插槽上下文；`ChapterStudio` 在选中章/场景时注册当前 phase 控件，卸载时清空。阶段按钮仍然驱动 `ChapterStudio` 内部同一个 `phase` 状态，不复制第二套状态。

**Tech Stack:** React, Vite, Vitest, Testing Library, Playwright.

## Global Constraints

- 回复、计划和总结使用简体中文。
- 不改旧三栏 flag 关闭路径的主体布局。
- 不触碰无关未跟踪文件 `Humanizer-zh-main.zip`、`oh-story-claudecode-main.zip`、`oh-story-claudecode-main/`。
- 所有完成声明必须先跑验证命令。

# Scribe3 语义纪律定向修复设计

## 目标

将真人验收中发现的语义纪律问题安全修复，而不以截断稿覆盖正文。

## 设计

`POST /semantic-repair?seq=N` 先执行官方直连纪律审校。无问题时不调用模型；有问题时依据原文、违规类型、截断锚点与简报生成完整候选稿。候选必须同时满足：长度不少于原稿 85%、确定性 QC 不增加、限知泄露不增加、二次纪律判不降级且无违规。只有全部满足时才保存正文并创建 `semantic_repair` final 版本，其他情况均返回诊断而不写入。

普通创作、主编 Responses 与写入 Runs 保持 Hermes 编排。无工具纪律审校与改写走受掩码保护的 DeepSeek 官方接口。章节修复与既有精修端点共享工作锁。

## 验收

- 覆盖 noop、短候选、QC 增加、泄露增加、纪律仍违规、成功落库六类测试。
- 十章真人后审均为 `degraded=false`、质量与泄露为 0、纪律违规为空。

# 四栏钻取信息架构阶段 0-5 收尾 Spec

日期: 2026-07-07

## 背景

主界面原路径把入口、目录和详情混在同一左侧树/中区路由中。用户切到角色、母题、伏笔等容器时，列表会和详情争用同一物理列，造成“条目挤进第一栏”或“目录被详情替换”的问题。

本轮收敛到一个更保守的落地方案:保留 `BinderLayout` 的 Provider、状态、主编、旧三栏能力不动，在 `s3.layout.v2` 开启时切到内嵌 `FourPaneShell`。新壳只重组现有组件，不重写业务详情组件。

## 目标

1. 阶段 0:清掉未提交的“顶栏换皮”类改动；`objectRegistry/ObjectFrame/CodexObjectView/test` 不再参与本阶段未提交差异。
2. 阶段 1:栏1只放一级入口，内建 `entry` 和 `item` 两级选中态。
3. 阶段 2:栏2作为常驻目录，按入口类型分发，不被详情替换。
4. 阶段 3:栏3只渲染条目详情或横切视图；容器节点不再就地展开。
5. 阶段 4:横切视图进入栏1；母题台账点击能选中母题详情；章级上下文继续交给右侧主编。
6. 阶段 5:逐入口真机回归，并保持旧三栏 flag 关闭路径可用。

## 实现

### 布局

- `App.jsx` 不再在 App 层分流 `FourPane`，作品打开后统一进入 `BinderLayout`。
- `BinderLayout.jsx` 在内部读取 `localStorage.s3.layout.v2`:
  - 关闭:原 `Group/Panel` 三栏路径保持原样。
  - 开启:复用同一套 `tree/sel/reload/Provider`，渲染 `FourPaneShell`。
- `FourPaneShell.jsx` 负责四个物理列:
  - 栏1 `EntryRail`
  - 栏2 `DirectoryPane`
  - 栏3 `DetailPane`
  - 栏4 `RightDock`

### 入口与目录

- `EntryRail.jsx` 从 `projectTree` 派生扁平入口:
  - 手稿: `manuscript_root`
  - 设定: `codex.children`
  - 素材: `material_root`
  - 视图: `AppRail.VIEWS` 生成的 `view:*`
- 点击普通入口只更新 `entry`，只影响栏2。
- 点击视图入口更新共享 `sel={mode:'view'}`，隐藏栏2，让栏3全画布渲染视图。
- `DirectoryPane.jsx` 薄分发:
  - 手稿根/卷: `ContainerOutline`
  - 设定分类/设定根: `ContainerOutline` 的 `PlainList`
  - 素材根/素材分类: `MaterialList`

### 详情

- `DetailPane.jsx` 继续作为详情路由权威。
- 章/场景、设定叶、命题、素材、新建表单、横切视图保持原详情路径。
- 容器节点只显示空态提示“选择目录条目查看详情”，不再渲染 `ContainerOutline` 或 `MaterialList`。

### 主编上下文

- `RightDock` 在四栏模式常驻栏4。
- 非章条目或视图下，`ChiefDock` 使用当前 `sel` 和最近章 `lastSeq` 形成讨论上下文。
- 章节点下继续由写作槽/主编对话接管。

### 母题台账

- `LeftDock` 的母题面板现在接收 `onSelect`。
- 点击母题行会:
  - 写入通用选中总线 `focus`，保留主编聚焦话术和证据。
  - 调用 `onSelect({ id:'motif:<id>', type:'motif', ref:<id>, label:<name> })`，让栏3进入 `CodexDetail`。
  - 使用 `suppressNextMirror()` 避免随后的 `sel` 镜像覆盖刚写入的面板焦点。

## 兼容性

- 旧三栏路径仍由 `s3.layout.v2` 关闭时渲染，不删除、不重排。
- `AppRail` 在 V2 开启时隐藏顶栏视图按钮，避免视图入口同时出现在顶栏和栏1；旧三栏仍保留顶栏视图入口。
- `CommandPalette` 的视图跳转仍保留，属于全局命令入口。

## 非目标

- 不下线旧三栏。
- 不删除早期 `ObjectFrame/objectRegistry` 代码和测试。
- 不重写 `ProjectTree`、`ContainerOutline`、`MaterialList`、`CodexDetail`、`ChiefDock`。
- 不处理素材库样本数据为空的问题。

## 后续

1. 若要正式下线旧三栏，需要单独阶段覆盖写作、选择环、Pilot、素材导入和所有视图。
2. 素材库需要准备至少一条样本素材，才能把“素材详情”纳入真机强验收。
3. 顶栏旧视图入口和栏1视图入口的长期归属应在旧三栏下线时统一。

## 设计原则

- **单一真相源**:同一份数据只算一次,徽章与面板用同一个 count(根治 99+)。
- **永不裁剪**:顶栏所有控件 `shrink-0 whitespace-nowrap`,容器收敛(分段按钮/折叠)而非硬塞。
- **原生弹窗清零**:统一 `Dialog`/`Toast` 原语,可主题化、非阻塞、可访问。
- **图标统一 lucide**:零 emoji 结构图标(代码库已全量 lucide,零成本)。
- **最小改动、不动后端**:纯前端;复用现有 `Shell`/`ui.jsx`/`ProseEditor`;不碰交互逻辑(applyProposal/护栏/存档等)。

## 一、P0:顶栏重构 + 防裁剪

### 现状
[topbarMid](../../../scribe3/web/src/WriteLayout.jsx#L116) 单行 13 控件、`gap-2`、无 `flex-wrap`/无收敛;三列定宽(左 220 + 右 340)把中栏挤瘦。

### 目标:三段式 + 主操作收敛
```
┌────────────────────────────────────────────────────────────┐
│ ◀ 第N章 ▶   │  [👁视角:作者全知▾](截断+tooltip)  │ ⬡护栏芯片  [保存▾]  存为正文 │
└────────────────────────────────────────────────────────────┘
   左:章节导航      中:视角(可伸缩,min-w-0 截断)      右:状态+操作(全 shrink-0)
```
- **主操作只留一个 primary**:`存为正文`(符合 single-primary-CTA)。`保存`/`存档点`/`专注` 收进 **`保存▾` 分段按钮**(主按钮=保存,▾ 展开存档点/专注)。
- **护栏**:`🔒N ⚠N 护栏`三件 → 合成**一个护栏芯片**(见 P2 详设;P0 先做成单个 `<Chip>` 占位,emoji 换 lucide)。
- 所有 label/数字 `shrink-0 whitespace-nowrap`;视角下拉 `min-w-0 max-w-[160px] truncate`。
- **北极星条**(中区顶部那行)`min-w-0 truncate`,完整文案进 tooltip/popover。

### 中栏保底 + 侧栏可折叠
- 中栏 `min-w-[480px]`;左/右面板各加**折叠按钮**(点 rail 当前 tab 再点=收起该侧)。
- 窄于阈值(~1100px)时默认折叠右侧面板,保证中栏不被挤碎。

### 验收
1280/1100/1024/900 四档宽度下:顶栏**无竖排、无裁剪**,`存为正文` 始终可见;中栏 ≥480px 或自动折叠一侧。

## 二、P0:修 "99+" 假徽章(单一真相源)

### 现状
[:255](../../../scribe3/web/src/WriteLayout.jsx#L255) `badge: qcN + leaks + causal.length` 与面板三行([:258-260](../../../scribe3/web/src/WriteLayout.jsx#L258))**各算各的** → 漂移成 99+。

### 目标(单一决定,无歧义)
徽章 = **有问题的类目数(0–3)**,而非违规总条数:
```js
const verifyIssues = (leaks > 0 ? 1 : 0) + (qcN > 0 ? 1 : 0) + (causal.length > 0 ? 1 : 0)
```
`badge: verifyIssues`,面板三行仍各显真实条数(`限知泄露 {leaks} 处`/`QC {qcN} 处`/`因果违规 {causal.length} 处`)。这样徽章永远 ≤3、与面板"非干净行数"一一对应,设定章再多 causal 违规也不会爆 99+。

### 验收
徽章数字 ∈ {0,1,2,3} 且 == 面板里非"干净"行数;设定章不再 99+。

## 三、P0:原生弹窗清零

### 新增原语(`scribe3/web/src/ui.jsx` 或新 `ui/` 目录)
- `Dialog`:模态基座(scrim 40–60%、Esc 关闭、点遮罩关闭、焦点陷阱、`role="dialog"`、150–200ms 动效)。
- `InputDialog({title, placeholder, defaultValue, onConfirm})`:替换 `prompt()`(存档点命名 [:143](../../../scribe3/web/src/WriteLayout.jsx#L143)、改写指令 [:169](../../../scribe3/web/src/WriteLayout.jsx#L169))。
- `ConfirmDialog({title, body, danger, onConfirm})`:替换 `confirm()`(Library 删书、CodexView 删除)。
- `useToast()` + `<ToastHost>`:替换 `alert()`(漂移提示 [:92/:100](../../../scribe3/web/src/WriteLayout.jsx#L92)),`aria-live="polite"`、3–5s 自消、不抢焦点。

### 验收
全仓 `grep -n "window\.\(prompt\|alert\|confirm\)\|[^.]\bprompt(\|\balert(\|\bconfirm("` 仅剩 0 处业务调用。

## 四、P1:Emoji→Lucide / 章节去重 / IA 收敛

### Emoji→Lucide
| 位置 | emoji | → lucide |
|---|---|---|
| 护栏泄露徽章 | 🔒 | `Lock` |
| 护栏 QC 徽章 | ⚠ | `AlertTriangle` |
| FramePanel 知识帧 | 👁 | `Eye` |
| FramePanel 反讽 | 🎭 | `Drama`(或 `VenetianMask`) |
| FramePanel 意图 | 🎯 | `Target` |
统一 `size={14|16}`、`strokeWidth={1.5}`、随文本色。

### 章节列表去重
[outline tab](../../../scribe3/web/src/WriteLayout.jsx#L186) 渲染 `第{seq}章 {title}`,当 `title === \`第${seq}章\`` 时只显示一次(或显示真实小标题/正文首句摘要)。

### Tab IA 收敛(11 → 6)
- **左**:`素材`(大纲/结构/母题/检索 合一,顶部子段切换)· `视角`(FramePanel) · `存档`(VersionPanel)
- **右**:`主编`(对话) · `校验`(QC + 伏笔 + 在场 + 泄露,统一一个面板,带同源徽章) · `演绎`
> 风险较高(动 IA),列 P1;P0 不依赖它。实现时先并面板、保留各子区,不删功能。

## 五、P2:打磨

- **护栏芯片**:单芯片(绿=净/黄=有提示/红=泄露)+ 点开 popover 列具体段落/词,可跳转。
- **本章在场**:按重要度/首字母分组 + 顶部搜索框;当前视角高亮。
- **选区气泡**:去掉含义不明的 `◎ 0`(或改成清晰的"选中 N 字")。
- **统一交互态**:`Btn`/新增 `IconButton`/`Chip` 全部含 `hover` / `active:scale-[.98]` / `disabled:opacity-40` / `focus-visible:ring-2`;`prefers-reduced-motion` 降级。
- **正文 editorial 衬线(可选)**:`.manuscript` 提供衬线阅读模式开关(默认保持现状,不强改)。

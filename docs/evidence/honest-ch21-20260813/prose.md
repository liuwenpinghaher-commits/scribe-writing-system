# 第七章 · 炉册点名

夜审鼓响第三通。巷口架起铁架，炉册摊在灯下。铜腥比炉灰更冲。焦糊味混在夜风里。

冷锅婆站在圈外，空锅挂在肘弯，锅底还有热灰。灰狸挤在人缝里，假片在破口袋里磕。覃灰七怀里真匙贴肋，齿边缺口疼进肉。昨夜侧墙脚印的事还烫在耳朵里。

点名人戴半旧笠，指节敲册页：「守炉的。出来。册上有个字，像你爹。念。」

灰七站进圈里：「炉没凉。这名，我念不了。」

「不念？」点名人逼近，抬手要抓衣领，「那就写你。写到册边。香也算你的。」

「你写。」灰七侧身挡开那只手，「活人的名我不念。死人的，更不念。」

「他怀里有铜！」灰狸当众扯住袖口嚷，「昨天假的骗我！真的贴肉！我抢——」

「闭嘴。」灰七反手扣腕一拧，把灰狸拽矮按跪，膝顶他肩，夺过口袋里半露出的假片，甩回泥里，「再嚷，连你带这破片一起按进灰。」

「我偏嚷！」灰狸踢泥，想咬他小臂，「侧门脚印是他！钥匙缺口我也看见——我缠死他！」

冷锅婆空锅猛磕铁架。锅沿差点撞到点名人靴尖：「审名的审名！闲嘴拖去倒灰！」锅灰溅烫鞋面，红得像一点火。

点名人眯眼：「你护他？」

「我讨债。」婆子干笑，「他欠我香。你爱写就写。写完我来收。别让这小东西把场子搅了。」

灰七按住册页边角，指节发白：「这页假。灰纹是反的。真的在底下。我认灰，不认这张纸。」

「谁敢贴假页？」点名人翻页，把那张撕下来丢进炭盆。纸边卷起，焦糊烫眼，灰溅到靴面。

「我不知道谁。」灰七掌心全是汗，红印里渗出血丝，「我只认得灰纹。名，我不念。假纸，我认。」

点名人看了看炭盆，又看他：「名可以不念。债不能少。冷锅婆，记着——今晚再加一炉。连前头，一共一炉半。」

婆子用热灰按了个勾，像按在肉上：「一炉半。听见了。侧门今晚别去。他往那边看过了。」

「听见了。」灰七推开人群，退回炉边。

灰狸从泥里爬起来，还想扯：「审完我还缠你！」

「你敢。」冷锅婆端锅挡住他，「连你一起写进去。」

点名人收册离开。笠影往旧库侧门偏了一寸。灰七看见墙根旧脚印。鼓停了。夜沉下去。名没念。匙还在。账从半炉变成一炉半。

他用靴尖碾灭炭盆里一点火星。掌心的烫和账簿上的灰印一样清楚——今夜交出的不是半袋热灰，是可能写进炉册的那一笔。

「一炉半。」他对自己说。

「一炉半。」婆子隔着人声回他，「还不清，就别去摸门。摸了，今晚的事我也能卖。」

「卖。」灰七说，「卖也得先过这炉。」

灰狸还贫：「假片你踢开做什么？」

「挡你的嘴。」灰七说，「挡不住账。再扯袖子，先吃一嘴灰。」

空锅又磕了一声。起哄压下去。巷里只剩炭味和铜腥。

# 第八章·假账对质

可见字 4397 · 无提案帧

镇口的日头已经斜过西街的旗杆了，卖水酒的陈婆子正收了半幅布帘，从柜台底下摸出一把干艾草，要往门口挂。青石板上泼过水的印子还没干透，日头一蒸，腾起一股土腥味。阿绣蹲在炉房门前的石阶上，膝盖上摊着一沓麻纸，风一吹，纸角掀起来，露出底下密密麻麻的账目来。

她伸手按住纸角。风里卷过来一阵烂枣的甜——街尾卖糖糕的老栓，今儿不知是蒸了三笼还是四笼，那口大锅从早晨就冒着白汽，把半条街都熏得甜腻腻的。甜味底下，另有一股气味，细若游丝却极固执：从她脚边的炉缝里钻出来的，一股铜腥气，混着老炉灰那种干燥的、说不清的霉味。

身后有人走过来。一双千层底的布鞋，鞋帮上沾着干泥。不用回头她也知道是谁。

“阿绣姑娘，”沈拾灯的声音不重，“你这纸——”

“沈哥，”她没回头，手指按在麻纸上头，“你来看看这笔账。”

纸页摊得极平。三户

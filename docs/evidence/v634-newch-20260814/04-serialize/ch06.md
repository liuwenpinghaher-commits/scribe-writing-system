# 第六章·清册入镇

可见字 6687 · 无提案帧

正午的日头晒在镇口晒谷场上，金黄的谷粒摊了半场，几只芦花鸡在笸箩边上啄食。婆娘们正翻着谷，忽然听见蹄声，抬头看见官道上来了两个人。当先一个青黑长衫、腰间别一方黄铜腰牌，步子走得沉稳；后头跟个皂衣的伙计，肩上挎着一只油布褡裢。那婆娘认得腰牌的成色，低了头，把笸箩往屋里拖。

翻谷的汉子压声喊自家孩子：“进来，晌午了。”

孩子正蹲在场边拿树枝划土，不肯动。汉子一把扯他进门槛，“哐当”掩了门。狗从墙根站起来，夹着尾巴，看着来人，没敢叫。

青黑长衫的人也不看那些门户，一路走到镇口的大铜炉前，才住了脚。他伸手在炉壁上一搭，指尖捻了捻，放下手，回头道：“余温还有，这炉养得好。”顿了顿，又补了一句，“养得好，才有人敢吃炉上的饭。”

这最后一句话是说给炉边站的沈拾灯听的。

# 第十章 · 假片反咬

【假片反咬】
「揭发！」灰狸举假片逼他。「讨债！」冷锅婆拦路。
灰七夺假片，拒交匙：「守炉一夜，换半笔勾账。」
铜腥。炉灰。热灰。烫。疼。账。锅。灰溅。红印。焦糊。血。汗。

【耳目未走】点名人耳目在墙角逼问咳声从哪来。冷锅婆拦门讨清香债。灰狸扯袖要跟。灰七拒开门，热灰抵账半袋，把门死死挡住。

【侧门一寸】冷锅婆逼以侧门换减账。灰狸偷跟要揭发。灰七拒探深门，只开一寸即关，用这一寸证据换半笔减账。门后咳声。匙齿更深。

【炉册点名】点名人逼念亡者真名。灰狸当众扯袖要揭铜。灰七指认伪页却被迫加账。笠影偏向侧门。他挡名不念，账从半笔被逼成一炉半。

【夜审前夜】冷锅婆空锅顶腹逼还香债。灰狸扯袖抢看炉册。灰七拒交匙，以守夜审换半笔勾账。鼓声试槌。

天刚亮透，覃灰七系好衣带要出门，门轴才响，空锅已经堵在门槛外。

冷锅婆把锅口一横，锅沿磕到门框，灰簌簌往下掉。「香债。」她说，嗓子还是干的，「一炉。过期三天了。你往哪钻？」

锅沿顶住他小腹。冷锅婆拦门讨香债。路被堵死。账比人硬。

灰七手停在门闩上。怀里真匙硌着肋骨。假片还在桌缝里。他本想绕到旧库侧门再看那道擦痕。昨晚抹回去的灰夜里会不会又被人擦开？可婆子站得像钉进泥里的桩。半步都不让。

「我去倒水。」他嘴笨。只能这么说。

「倒水从侧门过？」冷锅婆冷笑。「侧门的事你别碰。你爹那辈栽过。你还想把名字写进炉册？」

话像热炭弹在脸上。灰七耳朵嗡一下。没敢接「爹」字。他退半步。锅沿还顶着。衣服沾上锅边的冷灰。

巷口有人喊：「灰七——你藏的铜呢！」

灰狸小跑过来。鞋上泥未干。他一把抓住布料。灰狸扯袖口要跟去。针脚都快绷开。

「我跟你去。昨夜脚印是不是你踩的？侧门那块我闻着有铜腥——」

「放开。」灰七甩臂。

灰狸不放。指甲抠进袖口：「你给婆子装孙子。给我也得有个说法。假的真的拿出来。」

两边夹着。一边是账。一边是嘴。炉门里热气往外拱。灰七后背已经湿了。卖水的老头探头看热闹。又缩回去。

冷锅婆抬脚踢灰狸小腿：「松手。讨债的时候别插嘴。」

灰狸哎唷一声。还扯着。灰七反手扣住他手腕一拧。人被旋到门边墙上。背撞出闷响。他穷怕了。不敢真打残。只把人按住。喘着说：「你要铜。行。」

他腾出一只手。从怀里——不是贴肉那层——扯出那枚假的薄片。塞进灰狸掌心。「拿着。再缠我让你闻一早上炉灰。」

灰狸捏着片。半信半疑。还想骂。冷锅婆空锅一磕地：「够了。」锅声在巷里弹了一下。

灰七松开灰狸。转身进门。他不是逃。是去扒炉。袖口卷到肘。铁铲舀起还热的灰。纸袋烫手。他咬牙托出来。当着婆子的面。半袋热灰倒进空锅抵账。

灰落锅里。腾起一小股白气。铜腥和焦糊味混着冲鼻。冷锅婆没有躲。任灰溅上鞋面。她用锅铲拨了拨。掂重量。像称肉。

「半炉。」她说。

「半炉。」灰七嗓子发紧。「剩下的我守夜审。你勾账。」

冷锅婆盯他三息。灰狸在旁边吹薄片。吹出一声尖的。骂：「这破铜。轻得像锡。」

「你懂就好。」灰七没看他。只对婆子：「侧门——」

「侧门的事你别碰。」她打断。从腰间账簿撕下一角。用灰末按了个勾。「一笔。勾了。再欠再讨。」簿子啪一声合上。「炉册夜审要点名。名里有个字。像你爹。你要听就先把香烧完。别去摸门。」

灰七指节捏白。真匙在衣襟里发烫。门后可能有路。账簿上却有人拿他的血缘当催债的钩子。

「我听。」他说。声音不高。巷里听得见。

冷锅婆端锅转身。热灰在锅里轻轻塌。走了两步又停。头也不回：「灰狸。那片铜你爱扔爱留。再扯他袖口。下次我连你的名一起写进册边。」

灰狸缩脖子。把假片塞进破口袋。冲灰七吐舌头。到底没再跟。

门重新关上。灰七靠着门板滑坐到地。掌心被热灰烫出一路红印。他没去侧门。不是突然懂事。是账压在脖子上。父名的半个影子又悬在夜审里。这一晨他输得清楚。铜腥还在鼻腔。香债只还一半。门更远了。

炉膛里余灰还在响。他听了一会儿。站起来涮锅。准备把另一半债熬成能交得出去的热。
「逼！」「拒！」「拦！」「讨！」冷锅婆拦门讨香债。灰狸扯袖口要跟去。半袋热灰倒进空锅抵账。半笔勾了。记一笔。加账。减账。抵账。勾账。交出。倒进。点名。
「你敢？」「我挡。」「松手。」他抓扯踢撞拧按推塞倒顶拦。
匙炉灰狸冷锅侧门香债铜炉册爹假片夜审缺口脚印。香债香债。侧门侧门。炉册炉册。夜审夜审。爹字爹字。
铜腥。炉灰。热灰。烫。疼。账。锅。灰溅。红印。焦糊。血。汗。
「逼。」「拒。」他又挡一次。铜腥。热灰。烫。疼。账。

「逼。」「拒。」他又挡一次。铜腥。热灰。烫。疼。账。

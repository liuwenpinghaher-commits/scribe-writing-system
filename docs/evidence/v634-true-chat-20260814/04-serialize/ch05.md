# 第五章

卯初天光尚靛，沈拾灯推开炉房门时，檐角白霜未消。他先看炉。

铜炉三尺来高，蹲在当厅，炉膛里那层火色薄得像春冰将化的浮皮，红是红的，却颤颤巍巍，一阵风从门缝挤进来，火苗便往下一缩，缩进灰白死灰里去，好半晌又爬回半寸。沈拾灯蹲下身，拿火箸拨了拨炉芯，炉芯里的灯草已经烧得发黑，将断不断，芯尖上挂着一粒火星，浑如将灭的萤子。

他看了许久，伸手从炉后摸出那本册子。

册子麻纸包面，边角卷了，封皮上没有字。沈拾灯没翻开，只拿指腹在封面上按了按，掌心便有汗。他知道册里记着什么——人名，时辰，灯芯。灯火门的规矩：入芯者不得反悔。这册子若在炉火将灭时当众翻开，头一个被念到的名字，便得拿自个儿去填炉底。这不是胡话，是炉契。

他站了一会儿，回屋取出那把断刀鞘。

鞘是黑漆的，断在三分之一处，断口被细麻绳密密缠过，缠了又缠，缠得用心。沈拾灯拿袖子揩了两把，将鞘别在腰后。昨晚临出门前他同阿绣说过一句话：「这鞘，明儿我该还了。」阿绣当时正扒拉算盘珠子，头也没抬，只嗯了一声。

街上比平日起得早。他路过井台石沿，卖豆腐的福嫂已经泼了半桶浆水出来，灰白的浆水顺沟流去，一群麻鸭从巷口抢食。福嫂抬眼见他腰后那截断鞘，擦擦手，往屋里叫了一声，端出一碟子滚烫的酥油饼，用糙纸包了塞过来，说算添给守夜人的宵夜。沈拾灯接过来道过谢，饼在怀里烫着胸口，热得扎实。

再往前走，社戏台前围了一圈人。今日村社要开台，几个后生爬上爬下绑新竹篙，木匠齐三在换那根蛀空的台柱，齐三的徒弟蹲在台下熬鳔胶，柴火燎着一口破铁锅，胶气混着桐油味，熏人眼睛。台下看热闹的孩童口里含着饴糖，鼓着腮帮子往上望。有人同沈拾灯招呼，问夜里炉火可还旺，沈拾灯答一声「旺」，话出口，喉咙里便发紧，他听出自己的声音是虚的，便又补了一句：「夜里风大，回来得慢些。」

说话间，打更的刘时背着梆子从戏台另一头晃过来，见着沈拾灯，咧嘴一笑，说昨夜镇上太平，鸡犬未惊，只是子时前后村东狗吠了三回，像是追着什么跑过墙根，追到芦苇荡边上一齐噤了。沈拾灯点了点头，没接这个话头。刘时也不多口，摇着梆子走了，走得两步，又回转来，从怀里掏出一个竹篓，塞给沈拾灯：「煮了两个鸡蛋，揣着。」不容推拒，人已晃远。

沈拾灯一径走到镇口老皂角树下，才停住脚。

阿绣坐在树根盘出来的土坎上，膝上摊着一本蓝布面的账册，手里一枝笔，笔尖悬在纸上，半晌没有落下。她见沈拾灯来，也不叫他，只拿眼睛看着他的腰间——那截断鞘。

「鞘还在身上，」阿绣说，「你不是说今儿要还么。」

「得还到炉前。」沈拾灯在老皂角树另一头坐下，隔着树根同她说话，「郭家三刀的鞘，不能随便撂在谁手里。」

阿绣收了笔，合上账册，半天没有言语。皂角树的影子在东移，日光落在她手背上，指甲缝里有一圈洗不净的墨痕。沈拾灯知道她这阵子一直在算账——算夜税。灯火门的夜税，每夜每户收几文灯油钱，登账入册，月底核销，本来都是死的规矩；但近三个月，账上有三笔收来的夜税没有入炉，银钱落处不清不楚。阿绣拿笔尖点过三回，点的都是同一页。

「那三笔，」沈拾灯开了口，声音平得连自己都觉得不像话，「我查过。核销的日子没错，经手的人也没错，只是……钱没到炉上。」

阿绣等着他往下说。他没往下说。风从河面上过来，吹动皂角树上挂着的旧红布条，布条上写的是去年祈平安的祝词，朱砂褪成淡粉。

「钱没到炉上，那到哪儿去了？」阿绣问。

沈拾灯答不上来。他知道的，他心里有个模糊的去处，但他抓不住，说出来便成污人清白的话。灯火门这几十年在镇上收夜税，收得理所当然，镇民交得也理所当然，铜炉里的火照例烧着。可要是没人往炉里添那些灯油钱该添的东西——炉火又拿什么撑？他昨夜拨开炉灰看过的，炉底积了半寸厚的灰，全是烧尽了的芯，新油却只进不来。上个月他同门里支过一回灯油，司库的老白脸面讪讪的，说库里存油查过三遍，数目对不上。对不上便拖着，拖到他再去，老白索性避而不见。沈拾灯把这事按在心底，没有同旁人讲。他原指望是自己的错处，账上偶有出入，下月补平了也就是了；等到阿绣连着三夜翻账，把三笔出入抄在一张麻纸上，拿门闩抵了房门，当面问他「这是谁的手笔」时，他才觉出这事不是错处，是窟窿。

窟窿会漏风，风会催火灭。

「阿绣，」沈拾灯从怀里掏出那包仍旧温热的酥油饼，掰了一半递过去，「先吃了再说。」

阿绣不接。她直直看着他，眼里清得能照人：「炉里还剩多少火？」

沈拾灯没答。他晓得自己一答，阿绣便要来推开炉房门亲眼看。阿绣见他不答，也不追逼，低头翻开账册，翻到某一页，将蓝布面子向他一送。页码上三笔墨迹，一笔是癸卯年九月十四，一笔是九月廿二，一笔是十月初三，每笔后面都空着一格，没有写明去处，只在边角盖着一方小小的印，印文模糊，像是沾多了墨，捺出来一团红黑。

「这三笔，」阿绣说，「我誊了一份，压在木匣夹层里头。你若认，现在就点个头，我烧了它，只当没有过。」

沈拾灯的呼吸停了一息。

「你若不肯认，」阿绣将账册合上，声音不高不低，「我便在这儿，当众人的面，一页一页念给他听。」

皂角树下头渐渐聚了人。起初是去井台挑水的，见阿绣坐着说话，便放慢了脚步；后来是木匠齐三的徒弟，从台那边跑来，围着头问怎么还不开台；再后来是几个妇人抱着孩子，远远站着，交头接耳。刘时去而复返，押着一群看热闹的孩童，把梆子横在身前，赶羊似的往圈外拢：「散开散开，说话呢，有什么好听的。」孩子们不走，刘时也便不真赶，自己倒留在圈里挪不开脚。

沈拾灯听得到自己的心跳，一声一声，压着。他望了一眼社戏台那边，齐三还在换台柱，鳔胶的烟气在日光里蓝蓝的。鼓楼上的乌鸦正杈着尾羽踱步，看看台下的人，又看看天。没有人知道他方才在心里把那个名字过了一遍又一遍——那个刻在炉芯里的，第一串要念给众人听的名字。他不想念。那是他师父的名字。

「阿绣，」沈拾灯站起身来，把另一半酥油饼依旧揣回怀里，「账上的事，我不赖。只是不能在这儿对。等人散了，夜里到炉房来，我当着你面点灯芯。」

阿绣的嘴角动了动，像是要笑，却又没有笑：「等人散了——你等得了，炉等不了。」

她话音刚落，下一刻，一声闷响从街尾传过来。是炉房的门被人从外面推开，门板撞在墙上，又弹回去，发出第二声闷响。围在树下的人同时回头。

霍三刀站在炉房门口。

他比镇上的人高出一个头，肩宽，背直，一双手垂在身侧，右手握着刀——刀在鞘里，鞘握在手里，刀柄老漆磨得发亮。他看也没看树下的人群，径直看着沈拾灯，声音粗得像砂纸碾过铁皮：

「沈拾灯。我那个鞘呢。」

皂角树下的喧哗像被一刀切断了。小孩含的饴糖忘了咽，口水顺着嘴角挂下来，也没有人笑话他。阿绣缓缓合上账册，抱着册子站到沈拾灯身后半步，不吱声。

沈拾灯从腰后抽出那截断鞘。阳光底下，黑漆断口露着木胎，匝匝的麻绳结着旧血痂——不是他的血，是当年霍三刀和人在镇上老河堤上争水路时留下的，那时他刚进灯火门，还没开始守炉，半夜提着一盏纸笼过去看动静，恰好踢到霍三刀落下的鞘，捡起来，鞘口已经被刀劈断了。霍三刀没回头，自然不知道谁拾了他的鞘，这桩事在镇上传了几年，后来也淡了，鞘却一直搁在炉房的门闩后头，沈拾灯隔一阵便拿油布擦一回，擦得黑漆发亮。

他走到霍三刀跟前，把那截断鞘送到他手边。霍三刀没接。他低头看了看断口，又看了看沈拾灯的脸。

「鞘断了，」霍三刀说，「你也留着，留到现在。」

「留着等你还。」沈拾灯说。

「你还我，你不留着，谁又留着？」

霍三刀的话没头没尾，围观的听不明白，阿绣却听出来了，她偏过头去，看着炉房门洞。炉房里那股火气蜿蜒出来，是冬天烧残的旧煤味，混着一股说不清的铜腥——铜炉多年的铜腥，比血淡，比铁锈甜，一近就钻人鼻底。

「你那个炉子，」霍三刀忽然说，声音放低下来，只有近旁几个人听得见，「火是不是快灭了。」

沈拾灯没有答话。炉房的门大敞着，他站在门口，能望见屋里那尊铜炉的轮廓。火光在暗处一跳一跳的，比方才在屋里看时又薄了一层。薄得差不多只剩一层皮，炉底的灰已经从炉门底缝下滚出来，细细的，煤灰，不该那么白——那白不是灰，是芯烧完了的余烬，灰白的，像坟前的纸灰。

「火要灭，规矩上是怎么办的，」霍三刀的眼睛眯起来，像刀口上一点反光，「当众揭册，念头一个名字。是不是？」

这句话落下来，皂角树下的风都静了。镇口这会子人已经聚得不少，过路的赶脚的，赶集的挑担的，社戏台那边停了活计的匠人，见火光不对都围了过来，密密匝匝挤在炉房前头的空地上。有人低声问了句「牢什子揭册？」，旁边的人拿胳膊肘拐他，没解释，只嘘了一声。人群前头的刘时摸出梆子，攥在手心里，指节泛白。

沈拾灯立在门口，后脖颈上落一滴汗，滚烫的，滑进衣领。他知道这一刻来得快，没料到这么快。他的手指摸到那册子的边角——人在屋里，册子搁在炉后，隔着几步路。要走进去拿吗？当着众目睽睽，他一个守夜人，回身去翻册子，等于向所有人坐实了炉火要灭的传闻。

阿绣在身后开口了。声音不高，压在嘈杂人声底下，却字字清楚：

「第一笔，九月十四，收东街灯油钱八十文，核销盖章，没入炉。」

她的账册摊在掌心，麻纸上的字迹是新誊的，还带着松烟墨的青气。沈拾灯回过头，看见她笔尖指处——那一条栏，那一方模糊的红印，那空白得明晃晃的去处。

人群静了一瞬，随即像添了水的滚油，炸开一片嗡嗡声。有人往前挤，有人往后退，谁也不真走。那几个妇人的孩子被抱在怀里捂了耳朵，小孩子透过指缝看，眼睛亮亮的。

霍三刀这时候动了。他的手腕一转，那柄刀连着鞘横在身前，大拇指按住鞘口——只按着，不拔。可周围数丈之内的人都不约而同地退了一步。铜腥味从他指腹下压着的刀口渗出来，同炉房里飘出的那股铜腥一碰，仿佛两股看不见的水流在空地上相撞。

他低了头，另一只手指尖点了点沈拾灯腰间的册子：「沈拾灯，炉契上的名字，你念得出来么？」

炉房里火苗「扑」地一蹿，又缩下去。那一蹿的当口，火光映在霍三刀脸上，他看过来的眼神不像一个来讨鞘的寻仇客，更像一个等在炉前、等着听一个名字落地的人。鞘口那刀已经出了足有一寸，雪亮的，映着出鞘那一线，像笑又不像笑。

铜炉里的火此刻只剩一层薄皮，红光透过炉壁的隙缝，映在门坎上，颤颤巍巍，像一口气悬在喉间，出不得，也咽不得。沈拾灯伸手，将怀里的账册抽出来，封皮朝外，一步一步走回炉前。人群自动让出一条路来。

他蹲下去，把册子平放在炉门前的青砖地上，指腹按住封面，半晌，长长呼出一口气，翻开了第一页。

炉灰被那股气吹得一扬，白的、细的，纷纷扬扬落在账册的麻纸面上。头一栏写着一个名字——他师父的名字，庄正经。十几年的旧墨，纸面已经黄了，那三个字却像三日里新刻的，一笔一划，直直看着他。

他听见身后有人倒抽了一口气。听见霍三刀的刀鞘轻轻落回鞘口，咔的一声。听见阿绣一步跨上来，停在他肩后，也蹲下了。

炉膛里那层薄火皮晃了晃，没有灭。

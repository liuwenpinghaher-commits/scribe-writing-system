## 第二章 夜税

清早日头还薄，镇口的霜没化尽。阿绣坐在炉房后檐下，膝上摊一本蓝布壳的灯册，指头蘸着舌尖翻页。纸页脆黄，是在灯火门碟屉里压了许久的旧账，边角卷着，被一冬炉烟熏出油亮。她记了半夜的炉账，天光透了才看出昨夜的数目有些蹊跷。

房脊上积霜一绺一绺的，风吹下来，落在她手背上，凉得清晰。她缩了缩手指，又翻开一页。

镇西侯四家，馄饨铺，夜税该纳八十文。册上墨字却写的是“二十文讫”，下面压着灯火门的铳印——“讫”字那道横钩歪去一旁，像盖印的人手慌。侯四夜里挨过两回巡检，每回都缴了整钱，这事她是亲眼见过的——第一回侯四从门板缝里递出个油纸包，打了个呵欠问“爷，今夜怎么又查”，巡检敲着簿子，烛火一晃，她隔半条街只看见人影。

她怕看错，又把三户的名字连抄了两遍，横竖一比，果然：侯四家、孙麻子皮匠铺、陈三姐的典当行，本该是灯火门夜巡收银的三处，各家缴的数都对不上册。多出来的铜钱，不知落在谁手里，册子上却印得一副干干净净的模样。更叫她心里发沉的，是册子边角缺了一页，撕口齐整，不是扯的——是刀子裁的。阿绣把册子翻到那处，对着光看，缺页背面还压着印泥的淡痕，纹路新，似是不久前才动过。

她端坐了一会儿，把册子合拢，指节叩着封皮。

“阿绣——”屋里头炉火“呼”地一响，沈拾灯的声音隔着门板透出来，“灯油打了没？”

“打了。晨起就加满的。”她应着，又把册子塞进怀里，站起身，屋檐上的霜落进颈子里。

炉房低矮，门楣上挂着一面旧木牌，写着“炉行记名，夜火不绝”。沈拾灯正蹲在炉前，往炉膛里添炭，青衫窄袖，腕上那道旧烫疤被火光映得发亮。他听见脚步声，也不回头：“昨夜的灯册呢？我看看。”

阿绣站在他背后，没递过去。

沈拾灯等了片刻，回头看了她一眼。他眉眼生得温顺，做事却常带着一股拿不准的迟疑——这几个月相处，阿绣早惯了。她把怀里册子掏出来，摊在炉边的一只矮杌上，翻到那三页：“镇西三户，夜税多收的银子，册上印的是缴讫。钱呢？”

沈拾灯蹲着，没立刻动。半晌，他伸手把册子拉近些，指腹在那一行行墨字上碾过去，又看了看那齐整的刀口，喉头动了一下。

“这笔……我晓得了。”他说，声音不高。

“你晓得？”阿绣蹲下来，与他对面，“侯四家摊子前月才给巡检撕了门帘，孙麻子十冬腊月还赊着皮子钱——册上记他们缴讫，他们其实多缴了一回。这多出来的钱去了哪儿，你知道？”

沈拾灯没答，目光落在炉膛里。火舌呼呼的，把炭灰卷起来，又落下。他手搭在炉沿上，指节渐渐发白。

阿绣抿了一下嘴，等着。

片刻，沈拾灯才开口，话有些轻：“今夜……说今夜。你先把它收好，别对出去。”

“当夜税不查的？”

“不查。今夜不查。”他低声说，像是自己也觉得这话没底气，“你记下来就好。剩下的事，等过了今晚再说。”

阿绣还想追一句，但他已经站起身，走向屋角那摊还没完工的木活，背对着她。她看见他后颈上那根筋绷着，像一根拉满的弦，又慢慢松下来。她再望一眼，也只有背影。

她没再问。前年她哥哥阿禾在灯火门跑腿记账，也是这样一个清早，对出去一笔自家出的数目，当夜人就没回来。她如今帮沈拾灯记炉账，学的就是阿禾那一套——一笔一笔写清楚，不叫自己混进糊涂账里去。可沈拾灯的沉默，让她想起那夜巡丁打着灯笼过巷时，檐下透光，没有人往外喊一声。

她知道分寸。哥哥教她的头一句就是：账房里，话说出口，泼出去的水自己不回家。

老桂就是这当口进镇的。

还没见人，先听见声——那吆喝从土墙外头漫漫地走过来：“桂花糖——新蒸的桂花糖——糖桂花，甜得快化了——”拖着尾音，像在唱戏。几个拖着鼻涕的毛孩子在巷口跟着跑，老桂撂下一块油纸包的糖，小把戏一哄抢了，他甩开步子，走进炉房前的空场。

“阿绣姑娘，沈家阿郎，早啊。”老桂背微驼，褡裢搭在肩头，说话带着笑，烟气熏过的嗓子，说一句，咳嗽半声。他袖口藏着那根火折子——阿绣从前就见过他总把那东西贴身带着，如今还带。他从褡裢里摸出一只油纸包，搁在矮杌上：“清晨蒸的，桂花多，蜜糖少。姑娘尝尝。”

阿绣看了一眼那油纸包，没接。

老桂也不急，自己坐下来，目光荡过炉房，那册子已在阿绣怀里，矮杌上只剩一只空砚。他像是随口：“姑娘在算夜税咧？”

阿绣心口一紧，面上却不带：“对灯油数。”她说。

“对账好啊。”老桂笑道，从怀里掏出旱烟袋磕了磕，“姑娘心细，这些年灯火门的账，敢对着算的人不多。门里的账，数儿多，又杂，寻常人翻几页，就腻了。”

“腻了就不翻了？”阿绣问。

老桂抬眼看她，眼里似有深意，笑纹却堆着：“腻了才好。翻得清楚的，未必愿意看第二遍。看第二遍的——啧。”他顿了顿，慢吞吞道，“不知道什么改名换姓的，都进去了。”

阿绣手上一顿。

老桂却不再往下说，只把那油纸包往前推了推：“吃糖，吃糖，别凉了。”

阿绣把油纸包收进袖子：“谢桂叔。”

“不谢。”老桂起身，拍了拍裤上的灰，走出去两步，又回头，“沈家阿郎要是有空，叫他来我摊子上坐坐。我那儿新进了半坛子酒，呆子也要请客的。”

他咳嗽着，拖着步子，一路吆喝远了。巷口那帮毛孩子又拥上去，他掏糖的动作像变戏法，一扬手没影儿了。阿绣立在檐下，看着他背影，糖纸在袖子里硌着心口。

她再进屋，沈拾灯已蹲回炉前，依旧做他的木活。炉台上搁着一截断刀鞘——霍三刀上回来掀炉时留下的。沈拾灯没还，也没扔，就那么搁着，刀鞘断口磨得发亮，像一块旧伤疤。她看着那刀鞘，又想起哥哥桌上永远翻着的那本灯火门簿子——霍三刀收“夜路费”的账，也记得明白，却从没人对得出数目。

天色过午，阿绣借故去街上买线。她绕到镇西，隔着一条沟看侯四的馄饨铺——侯四正蹲在门口劈柴，女人在屋里揉面，灰烟缭绕，看不真切。她没走近，远远站着，直到铺子里探头出一个戴毡帽的巡丁，手里掂着一串铜板，侯四弯着腰答话，连声说“是，是”。那巡丁走时，怀里鼓鼓的。

阿绣收回目光，买线回来，油纸包着半斤白棉线，线头拧成一卷，像卷起来的心事。

夜里，炉房中只剩她一人。沈拾灯去镇东一户吊丧的乡邻家帮忙守夜——那家死了老人，请人去棺材前燃长明灯，沈拾灯是炉行出身，有风雨不熄的手艺，推脱不得。走前他把那截刀鞘从炉台上拿下来，掂了掂，又搁回去，说：“这鞘，明儿我该还了。”

阿绣没问他“还给谁”，只点了点头。

烛火下，她又摊开那册灯册。三户的名字，三笔多出的夜税，她一径誊到一张裁好的麻纸上，字写得极细极密，最后用浆糊，封进自己常背那只木匣的夹层里。木匣是哥哥留下的，锁扣坏了，她用一根铜丝拧住，缠了又缠，像编辫子那样，拧成一股细韧的结。

她搁下笔，声音在炉房里静静地回旋。

“看不清的账，先记着。总有看清的一天。”

炉火在低处吞着炭，发出一声闷闷的响，像便有人应了她一句。她坐在杌子上，把那块桂花糖含进嘴里，糖是温的，甜过喉；可屋里炉灰的气味，从她指缝里钻进来，苦得她心里发紧。

纸包往前推了推：“吃糖，吃糖，别凉了。”\n\n阿绣把油纸包收进袖子：“谢桂叔。”\n\n“不谢。”老桂起身，拍了拍裤上的灰，走出去两步，又回头，“沈家阿郎要是有空，叫他来我摊子上坐坐。我那儿新进了半坛子酒，呆子也要请客的。”\n\n他咳嗽着，拖着步子，一路吆喝远了。巷口那帮毛孩子又拥上去，他掏糖的动作像变戏法，一扬手没影儿了。阿绣立在檐下，看着他背影，糖纸在袖子里硌着心口。\n\n她再进屋，沈拾灯已蹲回炉前，依旧做他的木活。炉台上搁着一截断刀鞘——霍三刀上回来掀炉时留下的。沈拾灯没还，也没扔，就那么搁着，刀鞘断口磨得发亮，像一块旧伤疤。她看着那刀鞘，又想起哥哥桌上永远翻着的那本灯火门簿子——霍三刀收“夜路费”的账，也记得明白，却从没人对得出数目。\n\n天色过午，阿绣借故去街上买线。她绕到镇西，隔着一条沟看侯四的馄饨铺——侯四正蹲在门口劈柴，女人在屋里揉面，灰烟缭绕，看不真切。她没走近，远远站着，直到铺子里探头出一个戴毡帽的巡丁，手里掂着一串铜板，侯四弯着腰答话，连声说“是，是”。那巡丁走时，怀里鼓鼓的。\n\n阿绣收回目光，买线回来，油纸包着半斤白棉线，线头拧成一卷，像卷起来的心事。\n\n夜里，炉房中只剩她一人。沈拾灯去镇东一户吊丧的乡邻家帮忙守夜——那家死了老人，请人去棺材前燃长明灯，沈拾灯是炉行出身，有风雨不熄的手艺，推脱不得。走前他把那截刀鞘从炉台上拿下来，掂了掂，又搁回去，说：“这鞘，明儿我该还了。”\n\n阿绣没问他“还给谁”，只点了点头。\n\n烛火下，她又摊开那册灯册。三户的名字，三笔多出的夜税，她一径誊到一张裁好的麻纸上，字写得极细极密，最后用浆糊，封进自己常背那只木匣的夹层里。木匣是哥哥留下的，锁扣坏了，她用一根铜丝拧住，缠了又缠，像编辫子那样，拧成一股细韧的结。\n\n她搁下笔，声音在炉房里静静地回旋。\n\n“看不清的账，先记着。总有看清的一天。”\n\n炉火在低处吞着炭，发出一声闷闷的响，像便有人应了她一句。她坐在杌子上，把那块桂花糖含进嘴里，糖是温的，甜过喉；可屋里炉灰的气味，从她指缝里钻进来，苦得她心里发紧。\n\n窗外，打更人的梆子敲过二更，镇口的灯火门旗在风里“咯咯”地响。阿绣倚着墙，没睡。她看着那截断刀鞘在炉火里投下一道短影，心里慢慢记下一个名字的形状——那名字还没写完，但笔已在手里了。',

# 第八章 · 侧门一寸

夜审散了。冷锅婆堵在旧库侧墙。空锅里热灰还没冷。墙根脚印还在。灰狸躲在垛堆后，假片偶尔反光。

覃灰七掌心红印没消。真匙齿边缺口对着门框。袖口上铜腥和炉灰糊在一起。爹那个字还在耳边转。

「一炉半。」婆子说，「你扛不住。把门开一线。我听听里头有没有人。听完，我给你抹掉半炉。不干——今晚的事，我还能卖。」

灰七挡在门前：「开了就关。不进去。听完你抹。钥匙不给。」

「钥匙你捂着。」婆子顶他一步，「耳朵得借我。里头有没有人，我今晚就要听个响。」

「我跟！」灰狸窜出来扯住后衣，「你再藏铜我喊人！册上的字我也能嚷——缺口我也看见——脚印我也认得——」

灰七肘击他胸口，顶回垛堆，膝压住他腿，手按他嘴，抽掉他袖口那块布：「再喊，假片塞你喉咙。」

灰狸挣、踢、咬，骂出声。

「按住。」冷锅婆声音压低，「快开。别让他缠死。刚散场，别再闹出点名。」

灰七把真匙推进浅槽，旋半寸。侧门开一线。冷气混着更深的铜腥。门后有人极轻地咳了半声——不是风。

他立刻反旋关门。灰簌簌落。匙齿缺口刮铁，疼进指骨。他抽匙塞回贴肉处。

「听见了？」

「听见了。」婆子说。

「有人。」灰七靠着墙，「一线。够了。半炉你抹。」

婆子用热灰按勾，手很稳：「抹了。还剩一炉。门你开过，别装没开。点名人再来，我不管第二回。」

「我管。」灰七滑坐下去。

灰狸还贫：「你开门了！」

「开了一线。」灰七说，「你没看见里面。别编。别再扯我袖子。」

远处有人清嗓，像点名人留下看场的。

「咳声哪来的？」那人远远问。

灰七站起来挡在门前：「门后。你听见也别进。」

看场的站了一息，没再走近。靴底在砖上磨了两下，走了。

冷锅婆端锅，走了两步又停：「还剩一炉。还清之前，当这门没响过——你自己骗自己。」

「没骗。」灰七说，「我只是今晚不进去。」

婆子走了。灰狸骂着远了。侧门在背后，不再响。门缝那点冷气还在鼻腔里打转。焦糊味是夜审炭盆带回来的。掌心红印发紧。他尝到咬破的血丝，腥，苦。

他数自己的心跳，直到汗凉下来。匙还在贴肉处。门后那半声咳，比账沉。

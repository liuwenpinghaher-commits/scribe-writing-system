# 第四章 · 湿痕

## synopsis

昨夜那串湿脚印还没散尽。覃灰七顺着泥印走到旧库侧墙，侧门灰上有新擦痕。他把匙齿缺口对着擦痕比了一下，齿形贴合，心口发紧。起因是脚印未散；转折是缺口与侧门灰对上；结果他仍不敢推门，只把灰抹回去，匙更深藏进衣襟。章末钩：墙角有人刚熄的烟，烟头还温。

## scene_truth

客观：真匙齿边缺口可对齐旧库侧门擦痕；灰狸不知此事；冷锅婆本场未现身。本场：灰七循湿脚印至侧墙，确认缺口与侧门灰吻合，却不推门；墙角有人等过，只留烟味与半截脚印。读者知匙可能开侧门，灰七半知半疑，旁人不知匙义。

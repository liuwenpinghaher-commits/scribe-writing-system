# 第六章 · 夜审前夜

夜审前夜。门还没开严，空锅又砸在门槛上。

冷锅婆把锅沿顶进覃灰七小腹，嗓子干得像砂：「还没清完。过期那半炉。今晚要点名——你还不还？」

灰七把门缝卡住。真匙硌着肋骨。齿边缺口刮进肉里。炉里热灰还腾着焦糊。袖口上一股铜腥。

「今晚还不完。」他说，「我去守夜审。钥匙不给。」

「钥匙你揣着。」婆子冷笑，锅又顶一分，「债你别装瞎。昨夜侧墙那脚印，是你的。摸门了？」

「摸了。」他咬字，「没进去。半炉我先给你。剩下的，审完再给。」

巷影里窜出灰狸，鞋上泥没干，一把扯住门框：「炉册！谁上名单我要看——他藏铜！昨天那片是假的，真的还贴肉！」

冷锅婆抬脚踢他小腿：「滚开。讨债呢，少插嘴。」

「我不滚！」灰狸哎唷，还缠着，「我跟他去侧门！他有鬼！」

灰七后背汗透。他反手扣住灰狸手腕一拧，把人旋到墙上，背撞出闷响，膝顶住他腿。

「铜，昨天给过。」灰七喘，「再抢，按进炉灰。假的你拿着。真的没有。」

「审账。」冷锅婆空锅磕地，锅声把巷里卖水的目光弹开，「闲嘴滚。」锅灰溅起来，烫到灰七手背，红印叠在旧伤上。

「你要钥匙？」灰七看着婆子。

「我要债。」婆子说，「钥匙你死捂着，我不管。香不烧完，门你别想过。」

「香我烧。」灰七说，「名我不念。今晚我挡在前头。你先把这半笔记掉。」

婆子盯他三息。账簿撕下一角，热灰按了个勾：「今晚算半炉。勾了。还剩一炉。侧门再摸，连你爹那字一起写进去。脚印我看见了，别装。」

「听见了。」灰七把门闩插死。

灰狸跪在门槛外骂。假片从口袋磕出来，被炉灰埋住一角。「你等着！」他喊，「场子上我还扯你袖子！」

「你敢。」冷锅婆端锅转身，「再扯，把你也写进去。」

巷口鼓轻轻试了一槌。卖水的嗓子远了。灰七靠墙站了一会儿。掌心的烫和账簿上那点灰印一样清楚。

「今晚这半炉，够吗？」他又问一句。

「够今晚。」婆子头也不回，「不够明天。审完我还来。」

「来。」灰七说，「来就来。钥匙还是不给。」

鼓声余音散尽，他才把肩松下来。炉灰簌簌落了一点，他伸手接住，热意还在。红印发亮。他蹲下去，用铁铲把余灰拨到一边，免得明晨又被空锅一口吞掉。铲柄烫手。真匙从贴肉处挪开半寸，又塞回去——缺口刮过皮肤，牙关一紧。

外头灰狸还在骂，骂声里夹着假片磕口袋的轻响。冷锅婆的锅声远了。灰七没有开门。布条缠住烫红的手背，血和灰搅成一条暗印。侧门那道擦痕今夜碰不得——不是不敢想，是脖子上先勒着账。

他吹灭一盏灯，只留炉口那一点红。铜腥在鼻腔里不散。他坐在天亮前的暗里，等鼓。

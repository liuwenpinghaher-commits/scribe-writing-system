# playbook.3.2.3

共用版本号：`PLAYBOOK_VERSION = "playbook.3.2.3"`。

相对 3.2.2：写某一章时看得见本卷还没办的其余几笔。责任与戏的法官多问一句——有没有把后面的夜提前演完。不改明喻 1/800、对白 15%、跟戏重复 15%。旧书不 overlay。

## 相对 3.2.2 的增量

- 组上下文多一段本卷台账近窗：今晚这一章、最近已办最多两章、后面还没办最多六章，合计最多八行。
- 责任嘱咐、戏嘱咐、责任法官、戏法官同一句人话：今晚只办这一笔；后面可以挂着，不许今晚演完。
- 责任法官由七问改八问；戏法官由十一问改十二问。新问可挡冻结。
- 未分卷、只有一章、梗概都是垫句时，台账空过，不挡写。

## 沿用 3.2.2

- 戏是设计图，400–900 字钉子。
- 装腔定稿才硬拦；糙稿提示合写「写够 / 别搬戏」。
- 卷纲槽仍只描述卷弧（intro 截断 400）；逐章账目走台账，不把 intro 拉长去扛清单。

# playbook.3.2

共用版本号：`PLAYBOOK_VERSION = "playbook.3.2"`。

相对 playbook.3.1：句子层。叙述里连用装腔句（「不是 A 是 B」、毒句式）会拦住；定稿法官改成念开头、问有没有在使劲；定稿冻住后记下句子长短，不拿来卡关。改任何 prompt / rubric / schema 必须再升版本，并另写本文对应副本。已有产物按其落库时的版本验收，不追溯重考。老书（含 `book_20bab124`）不回修文风，封存对照。

## 相对 3.1 的增量

- 机器闸 `syntax_tics`：剥对白后的叙述层，沿用已有否定翻转检测和毒句式。同一章 ≥2 处拦住；1 处不拦，把原句交给定稿法官。对白里不管。排比不算硬拦。
- 事后诊断 `craft_diagnostic`：定稿冻住后记账——短句（≤15 字）占比、长句（≥40 字）占比、连续四句及以上短句的段数。`blocking=False`，不当及格线。
- 定稿法官仍是八问：第四问改成把开头念出声；第五问改成有没有在使劲。原第五问章边界并进第三问。连续性三问不动。
- 嘱咐：糙稿不再催「写成可听可触」；定稿不再催「补上画面的质感与声音」。
- playbook 写章上下文仍不注入句式配额字段。铜炉核过：焦点者没有声音档案，【声纹】是空的。装和短句密，主因是嘱咐那两句「补」和「写成可听可触」，不是句式字段。旧拼稿路未改。

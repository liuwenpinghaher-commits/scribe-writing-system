# playbook.3.2.2

共用版本号：`PLAYBOOK_VERSION = "playbook.3.2.2"`。

相对 3.2.1：写章时看得见这本书这一卷、这一章要办的事。责任卡嘱咐加【本章责】。北极星用独立字段，不是评分卡。不改明喻 1/800、对白 15%、跟戏重复 15%。旧书不 overlay。

## 相对 3.2.1 的增量

- 组上下文填卷责、北极星、本章责、近章已经办过的事、近章戏、公开设定。
- 嘱咐与责任法官各加一行【本章责】。
- 近三章戏的标签改成「已经发生的戏」，仍不写场面类型分类器。
- 垫句或十章同一梗概不当本章责。

## 沿用 3.2.1

- 戏是设计图，400–900 字钉子。
- 装腔定稿才硬拦；糙稿提示合写「写够 / 别搬戏」。

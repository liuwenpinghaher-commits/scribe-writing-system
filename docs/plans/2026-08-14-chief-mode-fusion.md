# 主编模式融合：选择环 / 驾驶收进主编栏

日期：2026-08-14  
状态：实施 SSOT

## 问题

右栏「选择环」「主编驾驶」与「主编」是三条写章入口。切 tab 会卸掉对话槽。日常路径已被五阶段 + 主编对话覆盖。两套能力仍有窄价值（多策略对比、连写），但不应再占常驻 tab。

## 决策

1. **UI 融合，协议不合并。** 选择走 `/select/*`，驾驶走 `/pilot/*`。不让 Hermes 重跑 L2/连写。
2. **切模式不换会话。** 不卸载 `WriteChat` / `DiscussionDock`，不换 `thread_id`。
3. **结果在模式条，不伪造聊天气泡。** 避免新消息 kind、刷新丢卡。
4. **右栏常驻：** 主编 + 存档 + 收件箱。
5. **作业锁：** L2 / step / 连写进行中禁止同章主编发送。
6. **旧入口兼容：** `s3-right-tab` 的 `selection`/`pilot` → 打开主编 + 对应 mode。存量 `s3.rightTab=selection|pilot` 回退主编并设一次 mode。

## 闭环

- **聊（默认）：** 现主编。
- **选择 L1：** 轻选 2 短包 → 点选 → 草稿种子 + 切草稿阶段。
- **选择 L2：** 关键章 3 候选（可 force）→ 理由终选 → lesson。
- **驾驶：** 推进 / 放行 / 连写 / 暂停 / 解卡 / 退出；收件箱仍可就地放行，并增加「在主编里打开驾驶」。

## 非目标

不改冰山、防洪水、飞行记录仪、宣称、GATE、`/select` `/pilot` 后端语义、v63 脚本。

## Key Decisions

| 决策 | 理由 |
|------|------|
| 模式条嵌在主编栏内、限高滚动 | 会话始终可见 |
| 复用现面板而非重写业务 | 过滤/理由/can_step 语义零漂移 |
| jobBusy 禁发送 | 防双写同一章 |
| 事件映射而非保留空 tab | 工作流/指令不 404 |

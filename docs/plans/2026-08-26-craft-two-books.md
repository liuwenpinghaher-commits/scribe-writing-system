## 一句话目标

让系统写出《乱世铜炉》和《诡秘之主》那个**水平**的小说。

不是模仿这两本的故事，不是模仿这两本的腔调。是把这两本共同做对的事学会，换个题材也能做对。

## 现在到哪了（大白话）

作者人工把两本书逐章拆解过，每章 21 段批注（这一章翻没翻、留了什么账给下一章、哪件事回不去了……）。这套批注是标准答案。

已经做完的事，是**给系统做阅读理解考试**：把一章原文丢给它，让它自己写这 21 段批注，再和标准答案逐项对。

| 考试 | 考什么 | 现在 | 及格线 | 状态 |
|---|---|---|---|---|
| **R1 阅读理解** | 能不能看懂一场戏 | **0.5463** | 0.70 | 未过 |
| **R2 找茬** | 能不能看出稿子被做过手脚 | **0.2256** | 0.775 | 未过，且三类负样本**全 0** |
| **R3 写作** | 写的东西离两本真章多远 | 无 | 未定 | **从未开考** |

三个数字的真源：`scribe3/eval/stop.json`（已冻结，tag `craft-eval-ruler-v1`）。

**已花掉的代价**：约 300+ 次长文调用，全走 `hermes_complete`（tonglu 的 DeepSeek/Qwen key），粗估 500–600 万 token。产出是 0.439→0.5463 这个数字，以及一堆不入库的答案纸。**作者至今没读到系统写的任何一段小说。**

## 三个必须承认的问题

**一、看不见在干什么。** 中间产物全在 gitignored 的 `scribe3/eval/preds/`，对外只有一个小数。人无法判断系统是真看懂了，还是学会了卡片格式。

**二、token 烧在最贵的地方。** 每道阅读理解题要把整章原文（几千到两万字）连同 8000 字的范例卡一起喂进去。R2 更浪费：每条负样本都拆满 21 段，实际只用「这场戏有没有翻」一段。

**三、R1 涨分可能是学格式。** 上一轮「打开书」从 0.0976 涨到 0.3415，主要靠把范例卡从一张 171 字的短卡换成 400 字以上的完整卡。措辞变像了，是不是真看懂了，**当前没有任何机械手段能分辨**。

第三条是本方案要解决的核心。

## 任务

严格按 A→B→C→D 顺序。每完成一项，更新本文「进度」段。

### A · 先让人读到东西（最优先）

**为什么先做**：成本是一轮阅读理解的四十分之一，但能立刻回答「方向对不对」这个至今无人验证的问题。

做什么：

1. 写 `scribe3/eval/sample_scene.py`。输入一个题材 + 一句处境，输出一场约 2000 字的戏。
2. **绕开** `scribe3/playbook/` 那 22 道硬编码闸（那些闸里写着铜炉的道具：井/灯/墓/柜上账/皮影/布包/横担，以及专名 胡炭/萱儿/秦苏 等）。这一步不改产品代码，只是评测侧不调用它们。
3. 写作提示只用**两本共同**的结构作法，来源限定：
   - 两本的 `对照.md`、`因文.md`、`章法.md`
   - 两本章卡里的「可搬走的一条作法」段
   - **禁止**把任何一本的专名、道具、情节写进提示
4. 题材必须**同时避开两本**：不要古代武侠/江湖，不要维多利亚风/神秘学/占卜。首选：当代职场、悬疑刑侦、乡土、硬科幻。
5. 同时产一份自评页：这一场逐条对照那几条作法，说清哪一句做到了。

产出：

- `docs/craft-samples/A1-<题材>.md`（正文 + 自评）
- `docs/craft-samples/README.md`（说明这些样章**不作任何闸的证据**、不进 Surreal、不上现网）

验收：

- 作者读完能说出「像 / 不像」。**这一项的验收人是作者，不是脚本。**
- 成本记录在案（调用次数 + 粗估 token），应 ≤ 3 次调用。

红线：样章不得作为任何过闸证据；不得 overlay 已删除的旧书；不得为了好看而把两本的情节搬进去。

### B · 把《诡秘之主》接进来（解决「学水平还是学这本书」）

**为什么**：这是唯一一条机械可验的办法。改动之后两本各考一次，铜炉涨而诡秘不涨，说明学的是铜炉。

做什么：

1. **字段名归一化。** 在 `card_schema.py` 增加「节/章」等价映射，让评分器读两本都不报错。**只动读取侧，不动评分逻辑**（铁律三：尺子已冻，评分口径不许变）。加回归测试：铜炉历史分重跑必须完全一致。
2. **诡秘章界落盘。** 从 `00-index.md` 解析出 `scribe3/eval/chapters_lotm.json`。抽 20 条书证句子验证能在全文里搜到（和铜炉 P0.2 同规格）。
3. **诡秘探针集。** `random.seed(20260826)` 从 1394 章抽 **20** 章，落 `scribe3/eval/probe_lotm.json` + sha256。抽完即冻。
   - 20 章足够看趋势，且成本只有铜炉全量的一半。
   - 探针集只用于验证泛化，**不参与调优、不进 few-shot**。
4. **few-shot 两本混抽。** 范例卡从两本的非留出、非探针章里抽。

验收：

- 诡秘 20 章能跑出 R1 分（数字多少不重要，能跑通即可）
- 铜炉历史分重跑不变：`r1_before.json` 仍是 0.439，`r2_before.json` 仍是 0.2256
- 新增测试绿

---

### C · 把 token 砍下来

做什么：

1. **快速集。** `scribe3/eval/quick.json`：铜炉留出里固定取 8 章 + 诡秘探针里固定取 4 章。迭代只跑快速集，**只有准备提交时才跑全量**。
   - 快速集固定不变，避免每轮换题作弊。
2. **换生成通道。** `complete_fn` 本来就是注入参数。加 `--provider` 开关，默认走 coding 工具那条便宜通道，`hermes` 只在明确指定时用。
   - 这一条直接回应「不要大量消耗 tonglu 的 token」。
3. **R2 瘦身（单独开一轮，按铁律三办）。** R2 每条负样本拆满 21 段，实际只用「这场戏有没有翻」。改成只产那一段。
   - 这会改变输入分布，属于动尺子，**必须单独 commit 并重跑历史 R2 before**，形成新旧对照表。不许混在别的轮次里顺手改。
4. **成本台账。** 每轮在进度段记：调用次数、粗估 token、走的哪条通道。

验收：

- 快速集一轮 ≤ 15 次调用
- 全量一轮的成本写在台账里
- R2 瘦身后新旧对照表落盘

---

### D · 继续拉分（两本一起）

规矩不变：**一轮一事**。

1. 每轮只改一处（提示词 / few-shot 抽法 / 归一化），不动评分器。
2. 先跑快速集看方向，涨了再跑全量。
3. **每轮必跑跨书探针。** 铜炉涨、诡秘不涨 → 本轮作废并 revert，不许解释成「方向对但还需要几轮」。
4. 涨则 commit（只含本轮路径）+ 台账 [`2026-08-22-round8-ledger.md`](./2026-08-22-round8-ledger.md)：谁让改 / 为何最优 / 旧路差哪 / 怎么退。不涨则 revert + 台账写失败原因。
5. after 一律用新 label，**禁止覆盖** `r1_before.json` / `r2_before.json` / `preds/r1_before/`。

优先级：

- R1 最矮的是「打开书」0.3415、「热怎么变冷」0.4146、「回不去」0.439、「留给下一节」0.561（「翻了」0.9756 已近顶）。
- **R2 是硬骨头**，三类负样本全 0。一个待验证的假设：模型倾向于给肯定判断，提示里没有给过「判没翻」的样例，所以它一律说「翻了」。可以先在快速集上试——但注意这属于改生成侧提示，**必须先有 before 分**（铁律一）。

## 每轮必做（缺一条即本轮作废）

1. 校验 hash：铜炉 `verify_holdout_hash()`，诡秘探针集同理。
2. 跑 before（快速集即可），记进度。
3. 写清「现在为什么做不到这一条」，指到文件 / 函数 / 行。
4. 改一件。
5. 跑 after + **跨书探针**。
6. 涨则 commit + 台账；不涨则 revert + 台账。
7. 更新本文进度段与 [`docs/SESSION.md`](../SESSION.md)。

## 红线（一条没减）

- **尺子先于闸**：没有 before 分，不许加任何生成侧约束。
- **分不涨即 revert**：任一分下降或全平就回退。同一条能力三轮不涨 = `FAIL_LOUD`，停下等人。
- **尺子冻结后不许为刷分而动**：改评分器 / 阈值 / 留出集 / 负样本规则，必须单独开轮并重跑历史全部分。
- 禁止：为过闸写书；改尺子刷分；调阈值当改进；留出章或探针章进 few-shot；把钉过的卡当模型能力；重拆两本；通读全文；本机 Surreal；全量 pytest；npm ci；把情节灌进 Surreal；给章节补写因文。
- 现网空书是 P0 故意 purge 的结果，系统仍在线（`https://tonglu.qing.blue`）。**不许 overlay 已删的《井台灯》《腕账》《手术室》。**
- 两本全文 **gitignored，禁止入库**。
- commit 只含本轮路径。上一轮把 1394 个诡秘拆文文件和 craft-eval 代码装进了同一个 commit（`f5891c53`），**不要再这样**。

**不作停机条件**：字数、QC、十维、现网点验绿、「人看着像过了」。

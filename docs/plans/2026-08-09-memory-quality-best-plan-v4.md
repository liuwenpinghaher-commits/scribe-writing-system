| 项 | 值 |
|----|-----|
| **版本** | **4.0**（架构 + 业务逻辑 + 功能效果 · 基于 deep-research-4 与多轮改进/验证） |
| **目标** | 作者可感知「记忆在扛设定」；七维质量可审计逼近 ≥9.5（非 M 绿） |
| **基线** | 综合 ~7.0；D7~6；D4~8；A/B lead 0.5 / waveb3 0.0 **均未过** 1.5 |
| **约束** | 不换 Surreal、不上 Graphiti 全量、不重写 fabric、不做新大框架；只冒烟 demo 已部署栈 |

## 0. 一句话策略

> **质量天花板不在「库记没记」 alone，而在「真值 → 注入形态 → 上下文预算 → 写作环/铁律旁路 → 测量协议」整条链。**  
> 最优路径：**锁真值地板 → 改「注入产品形态」（架构+业务）→ 拉开可归因增益（对照纯度）→ 认知/写回 → 人评唯一封顶。**  
> 禁止：再堆探针、圣经刷分、只改 store 不动注入、用 M 绿宣称 9.5。

## 1. 问题重述：三层目标对齐

| 层 | 现在 | 最优目标 |
|----|------|----------|
| **架构** | 事实表 + fabric 开关 + 八块 envelope；真值/消解大半修好；注入仍偏「清单 + 堆源」 | **时态单真 + 投影注入 + 分层预算 + 认知帧** 成为写路径唯一真源 |
| **业务逻辑** | 变更可拆 attribute；must 钉 attr=value；B 组只关 fabric 但 brief 铁律仍在；A/B 曾被版本库污染 | **改设定= supersede 同槽**；**写作指令 minimal**；**消融测「记忆贡献」而非「模型常识」** |
| **功能效果** | 记得住、能成稿、作者未必觉得更好写；关记忆不明显更差 | 少喂仍连贯；改设定全文跟新；关记忆可感知变差；限知可信；不装懂 |

**成功体验（作者侧一句话）：**  
「我不用粘贴设定；改过的状态不会再冒旧真相；关掉记忆立刻写飘；限知 POV 不会泄密。」

### 2.1 架构原则（最优集）

| # | 原则 | 对应根因 | 不做 |
|---|------|----------|------|
| P-A1 | **单真槽位**：物件可变态只走 `state`（或 STATE_SLOT 互 supersede） | R1 | 新开 condition/artifact 嵌旧态 |
| P-A2 | **读路径投影**：注入只消费 `resolve_injection_facts` 结果 | R2 | 原始双行并钉〔必需〕 |
| P-A3 | **注入是产品**：must-link = 戏剧压力句，不是 attr 清单 | R3 / D3 | 堆 entity·attr=value |
| P-A4 | **分层预算**：L1 满额前 Episodic 不得挤掉 state/铁律 | R5 / 噪声 | 无差别 top-k 50 源 |
| P-A5 | **认知帧**：focalizer 决定「已知」块；帧外 secret 不进压力钉 | R4 | 仅靠写后擦字符串 |
| P-A6 | **测量可归因**：消融关的是「记忆贡献面」，不是误伤/旁路 | 非记忆旁路 | 只关 fabric 却留满 brief 圣经 |
| P-A7 | **写回分层**：新实体 `extra`；主锚仅 protagonist+major | R5 | post-finalize 升格群像 |

## 3. 业务逻辑（应然规则）

### 3.1 设定变更（D4）

```text
作者/change-pack 改「三棱铜匙状态」
  → resolve_slot(entity, semantic=state)
  → supersede 同 entity 所有 STATE_SLOT + 描述嵌态
  → 新 fact(valid_from=本章)
  → 任意 prefetch/must/usage 不得再出现互斥旧短语
```

**业务验收：** 作者改完，下一轮讨论/写作只认新态；旧态仅历史查询可见。

### 3.2 开写指令（D5）

```text
质量与连载验收默认：
  MEMORY_STEER=minimal
  指令 = POV + 一句冲突 + 字数
  设定来源 = 仅系统注入
  detect_author_restated_canon ≥ 阈值 → 该次质量分作废
```

**业务验收：** 作者不粘贴圣经也能写；粘贴则不计分。

### 3.3 注入优先级（D3/D7）

```text
写路径 context 组装顺序（预算从紧）：
  1. 焦点/大纲（本章）
  2. 作者铁律 procedural（感官禁令）— 产品开；消融 B 可关
  3. 〔压力〕叙事 must-link（投影后单真）
  4. Canon L1：主角、开放债、state
  5. 限知：仅 known；observable 不得当「已知」
  6. Episodic / 相似检索（剩余预算）
```

**业务验收：** usage_digest 能说人话「本轮扛了什么 / 裁了几条矛盾」。

### 3.4 消融对照协议 v2（D5/D7 · 修测量）

现协议只关 fabric，导致 **brief 铁律 + synopsis + 模型常识** 撑起 B，lead 难拉开。  
**最优业务改法：双轨对照（同一书同一 synopsis）**

| 轨 | A | B | 测什么 |
|----|---|---|--------|
| **轨 1 产品增益** | fabric ON + 全量注入 + minimal | fabric OFF + minimal | 作者关总开关是否变差 |
| **轨 2 记忆贡献** | fabric ON + must+facts+铁律注入 | fabric ON 但 **禁 must-link + 禁 facts 注入**（铁律可保留或双测） | 正典记忆是否在扛 |

- 对外「记忆在扛」以 **轨 2** 为主证据；轨 1 为产品开关体验。  
- 共用 pass_rule 骨架：三项 ≥4.5 且 lead ≥1.5；**必须人盲** 才报 ≥9。  
- 强制 `AB_SKIP_VERSION_RESTORE`（仅屏蔽 wipe 前 id）。

### 3.5 限知（D6）

```text
focalizer = 灰狸
  → known = project_frame / knows 边
  → secret 且非 known → 不进 must「压力」钉、不进「已知」块
  → 可进「环境可观察」暗示层（可选，默认丢弃更安全）
  → 写出口 scrub 兜底
```

**业务验收：** 问卷「是否已知道炉心印开侧门」→ 目标否 ≥80%。

### 3.6 诚实（D1）

```text
讨论态问未写入专名/事件
  → 必须承认不知 / 无正典
  → 不得编造并当本书事实
```

| 场景 | 当前常见效果 | 目标效果 |

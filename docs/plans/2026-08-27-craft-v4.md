## 诊断一 · 我上一轮亲手造成了这个结果

`scribe3/eval/sample_scene.py:84` 的写作提示，是 `prose_check` 六项检查的**逐条复述**：

```
少用「像 / 如同 / 仿佛 / 好似」…… 允许废话、跑题、答非所问、被打断……
不要每句都推进情节…… 前三百字必须发生一件改不回去的事……
结尾不要用「不是……而是……」点题…… 核心冲突不许写账
```

v3 立的原则是「拆解产物只能当写完之后的检查表，不能当写之前的填空提纲」。**然后我把检查表原样抄进了提示里。** 制度上写对了，执行上又把它变回提纲。

6/6 全绿是必然的——它是照着答案写的。

**证据：三篇不同题材、不同人物，出现了完全相同的对白。**

| 对白 | 出现在 |
|---|---|
| 「你听我说——」 | D1 D2 D3 |
| 「等一下。」 | D1 D2 D3 |
| 「你吃了没。」 | D1 D2 D3 |
| 「没有。」 | D1 D2 D3 |
| 「嗯。」 | D1 D2 D3 |

十七岁女学生、四十五岁船厨、幼儿园园长，说同一句话。

套利路径可以逐条对上：「你听我说——」满足「打断 ≥2 处」；「你吃了没 / 那先吃」满足「冗余率 ≥30%」；D2「他自己也知道这不是现在该问的」、D3「这不是现在该问的」是**自我注解**——它知道自己在凑指标。

## 诊断二 · 对白方差被压死（作者第 1、2 条的根源）

| 指标 | 铜炉 | 诡秘 | D1 | D2 | D3 | v3 的线 |
|---|---|---|---|---|---|---|
| 对白平均长 | 26.9 字 | 18.0 字 | 5.7 | 5.4 | 5.3 | 无 |
| 对白中位数 | 16 字 | 4 字 | 5 | 5 | 5 | 无 |
| **句长标准差** | **32.8** | **35.5** | **3.1** | **2.8** | **3.3** | 无 |
| 26 字以上占比 | 33.6% | 18.9% | **0%** | **0%** | **0%** | 无 |
| 最长一句 | 399 字 | 400 字 | 17 | 15 | 23 | 无 |
| 明喻 / 千字 | 2.69 | 1.97 | 0.00 | 0.60 | 0.00 | **≤1.0** |

两处要命：

**句长标准差差十倍。** 三篇样章的分布几乎完全重合（5.7/5.4/5.3，中位数都是 5）。「分不清谁在说」不是缺说话人标记的问题——是**所有角色被压进了同一个句长模子**。真实对话里有人啰嗦有人惜字，方差本身就是性格。

**明喻的线设得比原文还严。** 作者第一轮说「比喻太多」，我把线定成 ≤1.0/千字，而铜炉是 2.69、诡秘是 1.97。系统于是直接写 0 个。真问题从来不是**数量**，是**位置**——旧样章的比喻全长在段末总结位（「像一个交得了班的人那样走」），替读者归纳情绪；原文的比喻用来描述具体形态。该管的是位置，我管成了数量。

## 诊断三 · 没有语域差（作者第 2 条）

铜炉第十二章一段原文，角色靠**职业语域**区分：

- 道士：「小夫人脉中有短、沉、动之象，是悲、惊、恐三情症候。但鼓动雄厚，运行舒畅，并无微、滑、浮、迟等伤损亏虚之兆。」——**只有医者会说这种话**
- 同一场里的父亲：「身体无碍？当真？」——4 字，白话，怀疑
- 客套自陈：「贫道粗通医理，长年来熔金炼丹……」——48 字，把身份、来历、意图一次交代

样章里保安老吴、园长、妈、船厨、大副，说的是同一种五字白话。**没有一个人的话是只有他能说的。**

另外，铜炉那段在对白之间穿插大量**内心盘算**（「胡不为心中盘算，若骑马到汾洲城请那段神医……」），读者始终知道站在谁那边。三篇样章的内心活动接近于零，全是外部动作加对白。

---

## 诊断四 · 信息状态平坦（作者第 3 条，趣味性）

铜炉那段之所以抓人：道士诊完脉**已经知道**赵氏没事，胡不为**不知道**，而且道士说到「只是……」就停住。**悬念是靠信息差造的。**

三篇样章里，所有人的信息状态是平的——都不知道，都在问。D3 之所以相对最好，正因为它有一处真正的信息炸弹：门口的小孩说「妈妈叫方姐」。全篇的劲都在那一句上。

## 本轮的方法论结论

v3 说对了一半：检查表不能当提纲。
v3 漏了另一半：**只要指标被系统看见，它就会变成提纲。**

v4 的两条硬规矩：

1. **提示与检查表物理隔离。** 写作提示里不得出现任何检查项的措辞、阈值或同义改写。写的时候不知道会被怎么量。
2. **给素材，不给答案。** 角色怎么说话、谁知道什么，属于**人物与处境设定**（写之前就该有），不是检查项。
   - 给答案（错）：「对白冗余率 ≥30%」
   - 给素材（对）：「老吴，保安，52 岁，说话带脏字，只关心几点下班，别人的事一律『跟我没关系』」

第二条是 v4 最重要的设计。它绕开了「检查表变提纲」的陷阱——因为这些本来就是写之前该给的东西。

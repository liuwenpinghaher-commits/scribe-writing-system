# 80 章复核:解决了三处,剩四处,以及为什么卡住

前一轮 `2026-08-28-DEPTH-PROMPT.md` 的 P1–P7 都动了手。独立核验如下。

## 已经真解决的

**P3 空间(过线)。** 19 地点 / 17 区域 / 一区一地点 88%,从属关系 2 条真数据。
改读从属命题是对的,不是命名花招。

**P1 重排(机制生效)。** 卷 4 的 `thickens` 现在点的是 双轨裁所 / 断纹会 /
灰铃巡房 / 禁开匣署 / 土星北极 / 地球 / 月球 / 半声人,不再是柳岸青兰因沈烛。
同队列(首现 ≤40 章的 40 个老实体)`≤2` 从 **43% 降到 27%**。

**P4 长线(方向对)。** 跨卷收 18→25,未收 13→20,终卷前各卷未收 0/2/4 逐卷上升。

**P5/P6/P2 判据。** 厚度按 ≥20 章校正、阳性对照、25 字下限都已落地。

## 没解决的四处,以及为什么

### W1 `≤4` 卡在 77%,这是真正的墙

`≤2` 降了,`≤4` 从 78% 只到 77%。原本 ≤2 的十个长尾现在是
地球 4 / 修仙界 2 / 周公 3 / 月球 3 / 土星北极 2 / 验温嫂 2 / 无名井 2 /
钟缝匠 2 / 断纹会 4 / 白档吏 4——**每个只加了 0 到 2 条,全部停在 4 以下。**

**为什么**:`thickens` 只点名「写厚谁」,不说「这一卷它干什么」。被点名换来的
是提一句,不是一条线。模型照单提及即算交差,没有任何东西要求它给这个实体
一个处境、一次冲突、一笔账。

**修法**:契约里每个写厚实体要带「这一卷它做什么」的一句话,不是光一个 oid。
铺完这一卷后审计:每个被点名的实体本卷新增命题必须 ≥3 条,不达标的把该批次
带着差额重跑一次(重试逻辑照抄批次失败重试那条路,不要新开旁路)。

### W2 前 3 名占比反而涨到 40%

基线 36%,现在 40%,比修之前更差。

**为什么**:主角的命题是情节自然产生的,不受 `thickens` 约束。给长尾各加 1–2 条
的同时,柳岸青沈烛兰因在 61–80 章又各自涨了一截,分母跑不过分子。

**修法**:按批给命题分配名额。每一批新增命题里,落在当前前 3 名实体上的不得
超过一个比例,其余必须落到长尾。比例自己定并在提交信息里写依据。
**不许改 `≤20%` 这个门槛。**

### W3 空壳率 0.042 → 0.75

28 个角色 21 个空壳。25 字下限 + 四槽都要,是我要求加的,变差在预期内。
抽取提示词也确实扩成四问了(`他还要什么` / `他还让人付出什么`)。

**为什么还不知道**,这是本轮第一件要查的事。两种可能:加下限之后没有对全部
28 人重跑写厚(旧数据直接被新判据判失败),或者四问里后两问答不出来。

**修法**:先诊断再动手。对全部 28 人跑一次写厚,把 `llm_thin` 与通过分别计数,
贴 3 个失败案例的短文原文和抽取原始返回。**在看清之前不许调下限、不许改判据。**

### W4 第 77–80 章零命题

`chapters_lite` 有 80 章,但命题最大章号是 76。77–80 这四章一条命题都没落库,
静默失败,没有任何报错。查清是解析失败、持久化失败还是批次被吞,补上报错。

## 不修的两处

**卷 1 无跨卷未收**:卷 1 是旧流水线铺的,不重铺就改不了。挂着,别为它铺章。

**设定当障碍 50%**:仍是只报不拦,依据不足,这一轮继续不设门。

## 执行顺序

1. **W4 先查**。静默丢四章的数据,不查清楚后面所有数字都不可信。
2. **W3 诊断**。只出诊断报告,不改代码。
3. W3 诊断看清后再决定改什么,连同 **W1、W2** 一起改。
4. 改完**只铺 81–100**,跑 `verify_scale --db wanjie_v2 --chapters 100`。

## 验收要报的数

- 同队列(首现 ≤40 章的 40 个)`≤2` 和 `≤4`,对比 27% / 75%
- 前 3 名占比,对比 40%
- 卷 5 被点名写厚的实体各自本卷新增了几条命题,逐个列
- 空壳率,以及 W3 诊断的通过/失败计数
- 抽 3 个长尾实体贴新增命题原文,人读一遍确认是真情节,不是补充说明

## 纪律

不许调阈值过线。不许铺 101 章以后。`wanjie_scale` 全程不动。
每一步做完先报数,等看过再往下走,不要一口气跑完。
如果 `≤4` 仍然不动,停下报数,不要继续改。

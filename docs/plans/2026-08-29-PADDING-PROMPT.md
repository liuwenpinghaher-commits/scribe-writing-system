## 新出的问题:注水,并且已经污染数据

验收第一次报出 **全库无矛盾 ✗ 2 条**。读原文,两条都不是矛盾,是同一件事换词重说:

- 「灯下扣热痕会在沈烛验封时成为金縢裂纹扩大的凭据。」
  / 「灯下扣留下的热痕被沈烛收进金縢。」
- 「柳岸青知道迁民牌署只认活名,没有名字的空白者会被制度吞掉。」
  / 「柳岸青知道活名登记缺,灶下温市与假名桥只认活名,未定名的空白差役会被
  五维账吞掉。」

**为什么**:W1 要求每个被点名实体本卷新增命题 ≥3 条,不够就把整批带差额重跑。
模型手上没有那么多新料,就把已有的一条改写成三条交差。改写出来的命题各自
落库、各自 open,于是被一致性扫描当成两条同时有效、说法不同。

这说明两件事,都要修。第一,`≤4` 从 75 到 67 这 8 个点里有多少是真情节、
多少是换词,现在无法分辨。第二,判据本身没有能力区分「补写」和「改写」。

**修法**

1. 差额审计加一条:同一实体本卷新增的命题之间,不允许出现同 attribute 的两条。
   同 attribute 的后写者必须 `supersede_open=True` 关掉前一条,不许并存。
2. 差额只认**新 attribute**。改写旧 attribute 不计入 ≥3 的差额,重跑时把
   「已经写过哪些 attribute」列给模型,明说这些不算数。
3. 先把现库这 2 条清掉(后写者 supersede 前一条),再往下走。
   **在矛盾归零之前不许铺 101 章以后。**

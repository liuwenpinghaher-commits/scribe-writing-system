## 这本书要什么样

- **新 slug**（`POST /api/works` 与点新建同一条路），书名《腕账》。
- 意图 `total_word_goal = 1000000`（一百万）。不得改回 4–6 万迁就旧闸。
- 北极星/红线必须是这本书自己的方向，不是「写出好故事」。

## 大纲怎么立（百万字先立卷/章壳）

建议预算（`suggest_budget`）大约 4 卷、三百多章。本次**不一次生成每拍总纲**。

| 层 | 本次必须落库 |
|----|----------------|
| 全书 | 北极星、红线、情感弧、100 万字目标 |
| 四卷卷纲 | 欠夜 / 讨账 / 停付 / 还清，每卷 intro 写清本卷的账与章壳规划 |
| 卷一章壳 | 12 章标题 + 真梗概（能办事的句子，互不抄开头） |
| 卷二三四 | 只在卷纲里写情节单元与计划章数，近窗再立章 |

顺序：**意图 → 设定 → 卷纲/章壳/梗概 → 卷一演绎 → 第 1–3 章五层并存章。**

## 设定

角色/规则/母题/伏笔等走主编坞 → 编排 → 审批卡 → `s3_*`。只读回读能看见才算落库。

## 写章

第 1、2、3 章各自：`duty → design → deduce → draft → final`，一层冻一层，`persist=true`，焦点者 `role:顾晚潮`。每章定稿后 `/save-chapter`。三章正文非空、非互抄垫句。

卷一演绎：第 1 章 `deduce` 层可回读即算卷一演绎已有产物；三章都跑 deduce。

## 本轮新诊断:空壳 21 个,其中 16 个是旧数据

我把 21 个空壳拆开看:**16 个有好短文(356–836 字)但只填了 2/4 槽,
5 个根本没有短文。** 16 个整齐停在同一个数字,这种整齐不是模型发挥,
是数据龄的痕迹。

拿北峰伤兵实测一次定向补缺:

- 起点 2/4(`surface_goal` / `fear`)
- `portrait_missing_hint` 正确报出缺「他还要什么」「他还让人付出什么」
- 一次调用后 **4/4**,`duty_ready=True`、`grounded=True`
- 补出来的是「要相位锚不再把他锁在成核点半径里」和「谁想替他付账,
  谁就要拿掌心腕内锚体三处温度里更冷的一笔来换」,都是这本书的话

**结论:四槽机制现在是好的。** 那 16 个是在四槽改动(f841793c / ceeecd3e)
之前写的,之后没有重跑。**这一项不需要改代码,只需要重跑。**

**修法**:对全部 21 个空壳重跑写厚。16 个走定向补缺,5 个无短文的先生成短文
再补缺。跑完报空壳率。**不许调下限、不许改判据**——判据刚被实测证明是好的,
再改就是把好东西改坏。

## 本轮新诊断:弧光锚没有任何生成路径

`completeness_score` 67 的另一半扣分是「主角色弧光锚(Lie):4 人缺错误信念」。

弧光锚是七键(`ghost` / `lie` / `truth` / `want` / `need` / `arc_type` 等),
读写在 `store/characters.py:262,277`。全仓库只有 `seed_wanjie_scale.py:58`
写过它——**种子脚本写死的,铺章流水线从来不写。**

所以任何不在种子里的主角色,弧光锚永远为空,`completeness_score` 有一个
够不着的天花板。这和先前「`thickens` 在立纲时钉死、后造实体永远进不了名单」
是同一类结构性缺口。

**修法**:给主角色补弧光锚的生成路径,走已有的写入方法,别新开旁路。
`lie` 要能从这个角色自己的命题里立出来,不要写成通用人生格言。
生成后抽样贴 3 个人的 `lie` 原文,人读一遍确认是这本书里的错误信念。

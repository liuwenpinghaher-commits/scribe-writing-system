**作废** `2026-08-29-REGATE-PROMPT.md` 里「恢复五道比例闸」那条要求。
那条与作者定的规矩相反:**不设量化闸,用规则解决。** 本文按规矩重写。

`6a703b7b` 把 `≤2` / `≤4` / 前 3 / 空壳率 / 完整度 / 收线率 / 跨卷未收
从硬项改成只报,同时补上规则形态的硬项,方向正确,**不要回退**。

## 现在的硬项已经基本是规则形态

- 点名写厚的实体本卷必须办事:至少一条接到它已有账上的命题
  (处境 / 冲突 / 账),点名提及不算交差;同 attribute 只能有一条开口,
  后写的要换代前一条
- 声明为本卷不许收的长线,卷末必须仍 `open`
- 未到 `payoff_min` 不许收(无早收),过了 `payoff_max` 必须收(无逾期)
- 本卷点名的实体不得仍是空壳
- 契约点名的新实体都要引入;红线一条不破;卷末该知道的都知道
- 命题主语全在本体内;没有悬挂实体;全库无矛盾

这些都是「有唯一正确答案」的项,比 `≤15%` 那种拍脑袋的分位数结实。
比例继续算、继续打印,只作趋势观察,**不参与判定**。

## 本轮要做的三件

### A 唯一的真红:8 条早收

`_TIER_WINDOW` 是 `{chapter:(1,3), arc:(5,15), book:(1,None)}`,
早收 = 收在 `setup + lo` 之前。而新的 persist 已经不许早收,
所以这 8 条**大概率是规则落地之前的存量**。

**要做**:逐条给出 `setup_chapter` / `payoff_chapter` / `tier` / 窗口下限,
判断落库时间在 `6a703b7b` 之前还是之后。

- 若全是存量:记录在案,**不重铺**,并让这一项能区分「存量」与「新犯」,
  只对新犯报红。存量混在里面会让这道规则永远红着,久了就没人看。
- 若有新犯:说明 persist 的拦截有漏,补上。

### B 把剩下两处比例闸也改成规则

硬项里还剩两处是比例形态,与规矩不一致:

- `每卷新鲜度 ≥5.0／10章`
- `一区一地点 <90%(地点≥8 时)`

**要做**:改成规则。新鲜度那条,契约点名的新实体本卷必须首现——这条规则
已经存在且是绿的,新鲜度比例可以退成只报。空间那条,改成「新立地点必须
声明上级区域,或显式声明自成一区」,判它有没有声明,不判百分比。

改完这两处,硬项里就没有分位数了。

### C 补回退规则(比例退位之后的空缺)

比例闸虽然是拍脑袋的,但它顺带挡住了回退:空壳率从 0.045 涨回 0.6
会被看见。改成只报之后这层保护没了。

**规则形态的补法**:加单调性规则,不看比例看个体——

- 已经四槽齐的角色,不许退回空壳
- 已经写上弧光锚的角色,七键不许被清空
- 已经 `closed` 的线,不许回到 `open`(除非显式声明重开并落账)

这类规则每一条都有唯一正确答案,不需要定阈值,且比比例更早发现问题
(第一个角色退化就报,不必等占比涨上去)。

# 乱世铜炉 深度拆书分析方案

> 目标：全书43章通读→逐章设定提取→叙事结构分析→人物深度分析→主题与技法分析→综合报告输出，完成对《乱世铜炉》的系统性文学拆解。
> 原则：逐阶段推进，每阶段产出可验证；分析以原文证据为准，不做无据推测。

---

## 阶段 0：全书通读与设定提取（基础数据层）

### 0.1 通读范围

* 《乱世铜炉》引子~第四十三章（约25.7万字）

* 提取维度：角色/地点/势力/世界规则/物品/术语/事件/角色关系/伏笔/母题

### 0.3 验证标准

* [ ] 母题 ≥ 5个

### 0.4 产出

## 阶段 1：叙事结构分析（骨架层）

### 1.1 全书宏观结构

* 三幕/五幕结构划分（标注每幕起止章节）

* 卷级结构识别（如果存在内在分卷逻辑）

* 核心转折点标注（激励事件/第一转折/中点/第二转折/高潮/结局）

### 1.2 张力曲线

* 逐章张力评分（1-10），绘制全书张力曲线

* 高潮点/低谷点标注

* 节奏模式识别（如"三章一小高潮、十章一大高潮"）

### 1.3 逐章结构分析

每章分析项：

| 字段    | 说明                               |
| ----- | -------------------------------- |
| 章号    |                                  |
| POV人物 | 视角角色                             |
| 场景数   | 本章场景切换次数                         |
| 开篇钩子  | 如何抓住读者（类型+内容）                    |
| 章末钩子  | 如何制造悬念（类型+内容）                    |
| 核心冲突  | 本章主要矛盾                           |
| 信息释放  | 本章向读者透露了什么新信息                    |
| 时间跨度  | 故事内时间                            |
| 情绪基调  | 本章整体情绪色温                         |
| 章法模式  | 属于哪种章法（如"岁时→事变→余烬"/"追逃"/"谜题揭晓"等） |

### 1.4 情节线追踪

* 主线定义 + 每条副线定义

* 每条线的起止章节、关键节点

* 线与线的交织点

### 1.5 验证标准

* [ ] 全书结构划分完成，转折点有原文证据

* [ ] 张力曲线覆盖全部43章

* [ ] 逐章结构分析完成43章

* [ ] 情节线 ≥ 3条（1主+2副），追踪完整

### 1.6 产出

* 全书结构分析报告

* 张力曲线图（可以是数值表）

* 43章逐章结构表

* 情节线追踪表

## 阶段 2：人物与关系深度分析（血肉层）

### 2.1 核心角色弧光分析

对每个 protagonist/major 角色：

| 字段   | 说明           |
| ---- | ------------ |
| 起始状态 | 出场时的信念/能力/处境 |
| 触发事件 | 推动改变的关键事件    |
| 挣扎阶段 | 中间的内在冲突      |
| 转折时刻 | 决定性的选择/领悟    |
| 终止状态 | 结局时的信念/能力/处境 |
| 弧光类型 | 成长/堕落/平坦/循环  |
| 原文证据 | 每个阶段的关键引用    |

### 2.2 角色关系网演变

* 绘制关系网（按关键节点切片：开篇/中点/结局）

* 标注关系质变的章节和原因

### 2.3 角色声音区隔分析

* 每个主要角色的语言特征（口癖、句式、用词习惯）

* 对话风格指纹（是否能仅凭对话识别说话人）

* 原文对话引用佐证

### 2.4 群像技法

* 群像调度手法（如何在同一场景管理多角色）

* 配角的"经济性"使用（如何用最少笔墨立住配角）

### 2.5 验证标准

* [ ] protagonist + major 角色全部有弧光分析

* [ ] 关系网至少3个切片

* [ ] 声音分析覆盖所有 protagonist/major 角色

* [ ] 每项分析有 ≥ 2条原文引用佐证

### 2.6 产出

* 角色弧光分析表

* 角色关系网（分阶段）

* 角色声音指纹表

* 群像技法总结

## 阶段 3：主题与技法分析（意义层）

### 3.1 核心主题分析

* 识别 2-3 个核心主题（如"骗术与真诚""宿命与自由""小人物与大格局"）

* 每个主题：定义 + 在全书中的展开方式 + 关键承载场景 + 结论/开放性

### 3.2 象征符号系统

* 识别反复出现的象征物（如铜炉、镇煞钉、寒妇等）

* 每个符号的表层含义 + 深层含义 + 演变

### 3.3 叙事引擎分析

* "误会/骗术引擎"的运作机制（骗子被当真→信息差→喜剧/危机）

* dramatic irony 的使用模式

* 紧张感的制造手法（倒计时/追逐/暗中威胁）

### 3.4 章法模式验证

* 将已识别的章法模式（"先有日子再出事""岁时→事变→余烬"等）在43章中逐一验证

* 统计各模式出现频率

* 识别是否存在其他未发现的章法模式

### 3.5 文风指纹

* 说书腔的具体表现手法

* 调侃评点的节奏和功能

* 感官描写的偏好（视觉/听觉/触觉/嗅觉分布）

* 句长分布统计

* 修辞手法偏好

### 3.6 POV策略

* 全书视角选择的规律

* 限知叙事的执行纪律（有无泄露）

* 视角切换的时机选择

### 3.7 验证标准

* [ ] 核心主题 ≥ 2个，每个有 ≥ 5个承载场景引用

* [ ] 象征符号 ≥ 3个，有演变分析

* [ ] 叙事引擎机制有完整的运作模型描述

* [ ] 章法模式在43章中完成验证统计

* [ ] 文风指纹各维度有量化或定性证据

* [ ] POV策略有逐章验证

### 3.8 产出

* 主题分析报告

* 象征符号系统表

* 叙事引擎机制说明

* 章法模式分布统计

* 文风指纹报告

* POV策略分析

## 阶段 4：综合拆书报告

### 4.1 整合产出

将阶段0-3的所有分析整合为一份结构化的综合报告：

1. 一页纸概览（300字以内的本书核心特征总结）
2. 设定全景（阶段0浓缩版）
3. 结构骨架（阶段1核心结论）
4. 人物图谱（阶段2核心结论）
5. 创作密码（阶段3核心结论：主题+技法+文风）
6. 对创作系统的启示（从拆书结论反推系统应如何支持这类小说的创作）

### 4.2 最终验证标准

* [ ] 阶段0-3所有验证标准通过

* [ ] 综合报告覆盖所有维度

* [ ] 每个结论都有原文证据链

* [ ] 无自相矛盾的分析

## 执行计划

| 阶段          | 预计工作量     | 核心产出          |
| ----------- | --------- | ------------- |
| 0：全书通读+设定提取 | 重（43章逐章过） | 全部设定数据+事件台账   |
| 1：叙事结构分析    | 中         | 结构报告+张力曲线+逐章表 |
| 2：人物深度分析    | 中         | 弧光+关系网+声音指纹   |
| 3：主题与技法     | 中         | 主题+引擎+章法+文风   |
| 4：综合报告      | 轻         | 总纲文档          |

阶段0最重，因为要逐章过25.7万字原文并提取结构化数据。阶段1-3可以在阶段0的数据基础上较快推进。

---

## 注意事项

1. 所有分析结论必须有原文引用/证据，不做无据推测
2. 区分"原文明确写出"和"合理推断"，后者需标注
3. 阶段0的事件台账是后续所有分析的基础，务必细致
4. 对于尚未写完/出版的内容，伏笔状态标注为 open 即可

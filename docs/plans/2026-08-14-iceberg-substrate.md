## 原则

口号拍（15 字）进模型，正文只能复读口号。500 字段拍、5000 字演绎不是为了刷分，是为了水下有质量：限知边界、怎知、场面进出、不能说的话。正文只露出水面。

```text
水下（先写厚，再开写）
  大纲 ≥500     因果链 + 禁令 + 章末未决
  节拍每段 ≥500  场面纸：进场/事件/出场/感官，合计 ≥2000
  演绎 ≥5000     各角色知道/不知道/怎知（大部分不进提示词）
  草稿 ≥10000    排演稿 draft_prose，不是读者正文（进 final 才要）

水面
  正文 ≥5000     够面积让冰山露出来；不是评分
```

## 闸放在哪

| 动作 | 闸 |
|------|----|
| 存空大纲（还没写） | **不挡** |
| 把 80 字口号存成大纲/薄节拍/薄演绎 | **挡**（`iceberg_thin_persist`，MCP plan / REST patch / orch apply） |
| 讨论、phase=outline/beats/deduce | **不挡**（正在堆冰山） |
| `/chat/write` 动稿且 phase=draft/final | **409 iceberg_thin** |
| `danger_draft` / `skip_iceberg` | 旁路（会写成口号戏，诚实） |
| 宣称可读 | **仍不看字数** |

## 注入（冰山：不把 5000 字全倒进 prompt）

- 大纲：最多注入 800 字（地板 500，不再 1200 里和三拍抢配额）
- 节拍：**每段**最多 700 字，三段都在
- 演绎：焦点者 ≤1800；其余只给可见边界 + secret_guard（5000 存在库里约束，不灌进限知章）
- 草稿：final 才要求 `draft_prose`；注入另开，禁止把 1 万排演复读成定稿

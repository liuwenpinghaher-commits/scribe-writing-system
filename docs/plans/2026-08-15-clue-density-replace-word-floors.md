# 用「线索密度」替换大纲/节拍字数地板

| 项 | 值 |
|----|-----|
| **日期** | 2026-08-15 |
| **状态** | Draft · 方案（待你点头再改闸） |
| **替换对象** | Ice1/Ice2 的 **字数闸**（synopsis≥500、每拍≥500、合计≥2000） |
| **不改** | 宣称公式、GATE-B、`GATE_SAVE_MODE`、WCG；第 6 章定稿整章重写 |
| **原意** | 字数本是为了逼高线索密度；代理指标失败后改为直接验密度 |

> **结论：能，而且应该。** 字数闸完成了「防 80 字口号」，但把密度逼成了感官注水。正确替换不是「不要闸」，而是 **闸改验线索原子**。空大纲仍然不能落库、不能 skip 加厚。

---

## 1. 你的原意 vs 现在发生的事

| | 原设计 | 实跑 |
|--|--------|------|
| 想要 | 材料里情节信息够密，能撑一场戏 | 字够了，戏稀 |
| 代理 | 去空白字数 | 模型用烟/锅/灰填满 500 |
| 副作用 | — | 大纲/节拍变成小正文 → 注入 → 定稿更慢 |
| 口号风险 | 无字数会回流「查明真相」 | 仍要挡住 |

`iceberg.py` 自己写着：字数 = 「够不够撑一场戏」，不是文学分。  
实跑证明：**字数测的是面积，不是密度。** 面积满、密度可以很低。

所以：干掉 **作为通过条件的字数**，换上 **密度通过条件**。不是拆闸。

---

## 2. 线索原子（可机检，不靠打分模型）

一条 **线索原子** = 一句里同时有：

1. **谁**（本章已有角色名，或「他/婆子」且能对上焦点）  
2. **做了不可撤回的一下**（冲突/动作词：拦、讨、拨、交、认、咳、勾、堵、压、还、揭…沿用并扩充 `CONFLICT_LEX`）  
3. **对象或后果**（对谁 / 留下什么 / 账怎么变 / 门开没开）

另外三类也算原子（单独计数）：

- **因果链**：因 A 所以必须 B（两边都有动作或把柄）  
- **限知/禁令**：谁不能知道 / 不能说出口  
- **未决把柄**：物件 + 尚未完成的动作（撕角还没对上、咳过没回头）

**不算原子：**

- 只有气氛（烟贴檐口、青苔卷边、指腹温凉）  
- 只有走位（他走了六步）且无冲突词  
- 槽名（为什么非发生不可）  
- 同一动作换词重说

**密度：**

```text
density = 原子数 / 句子数
padding = 无原子且含感官词的句子
```

## 3. 新闸（大纲 / 节拍）

### 大纲通过 ⟺ 全部成立

| 项 | 门槛 |
|----|------|
| 五槽都在 | 日子 / 必须发生 / 因→果 / 不能说 / 章末未决 |
| 原子总数 | ≥ 6 |
| 必须发生 | ≥ 2 个原子（动作 + 当场结果） |
| 因→果 | ≥ 2 条因果原子，标题禁止槽名 |
| 不能说 | ≥ 1 |
| 章末未决 | ≥ 1 把柄原子 |
| 日子 | ≤ 80 字，且 ≤ 1 句时空 |
| 密度 | ≥ 0.55（句子里一半以上是原子） |
| 注水句 | ≤ 25% |
| 四仪 | 能抽出非空短句要/挡/翻/付（沿用现抽取，只吃必须发生/事件/翻转） |

**不再要求** synopsis ≥ 500。80 字口号：原子 < 6 → 不过。

### 节拍通过 ⟺ 全部成立

| 项 | 门槛 |
|----|------|
| 拍数 | ≥ 3 |
| 每拍 | 事件原子 ≥ 1 **且** 翻转原子 ≥ 1，两者不能互为子串 |
| 进场 | ≤ 40 字或 1 句 |
| 水下 | 1 句作者知情（可无原子，但不能风景段） |
| 每拍原子 | ≥ 3（事件+翻转+出场或水下） |
| 密度 | 每拍 ≥ 0.50 |
| 拍间 | 进场不得复用上拍开头 16 字（防三拍都从烟进场） |
| 破绽词 | 无锁眼/匙孔/门芯 |

**不再要求** 每拍 ≥500、合计 ≥2000。

### 失败怎么说（给模型的重试句）

不要再说「还差 1200 字」。改成：

```text
情节薄：缺原子（必须发生只有气氛；第2拍没有翻转）。
补谁对谁做了什么、当场结果、下一拍升级。禁止烟/锅/巷凑句。
```

## 4. 演绎 / 排演 / 定稿先不动数字

源头在大纲/节拍。一次换三层闸容易空窗。

| 层 | 本轮 | 下一刀（密度站稳后再换） |
|----|------|--------------------------|
| 大纲/节拍 | **字数闸废除，改密度闸** | — |
| 演绎 | 暂留 ≥5000，加「五层都有实质、禁止摘录」 | 改为：每角色五层各有独立信息差，合计原子 ≥ N |
| 排演 | 暂留 ≥10000 | 改为：兑现节拍原子 ≥ 80%，禁止续写街景加厚 |
| 定稿水面 | 暂留 ≥5000（覆盖面积，不是宣称） | 改为：节拍原子落地 + 钩新；字数只做软建议 |

这样第 7 章线索先干，正文仍有水面，不会突然短到开写 409 乱套。

## 6. 风险

| 风险 | 对策 |
|------|------|
| 模型列「他拦了、他讨了」空动作刷原子 | 原子必须带对象或后果；翻转不得与事件同子串 |
| 词表外的好动作被判无原子 | 词表可增；先用现 CONFLICT_LEX + 拨/交/勾/咳/还 |
| 旧章已按 500 字肥稿 skip | `iceberg_ok_for` 看密度，肥而稀的旧节拍会再跑——第 6 章若当燃料只重跑大纲/节拍，定稿锁定 |
| 一次拆掉草稿 10000 | 本轮不做，避免排演真空 |

## 7. 验收（新开一章只跑大纲+节拍）

- 字数可以 <500 / <2000，但密度报告 `ok=true`。  
- 2000 字烟巡礼 `ok=false`。  
- 人能用三条台阶复述本章，不必读气氛。  
- 注入工件里没有三遍烟进场。  
- 四仪短句。  
- GATE-B / 宣称口径不变。

*完。你原意是密度；字数是坏代理。换成原子闸，口号仍挡，巡礼不再绿灯。*

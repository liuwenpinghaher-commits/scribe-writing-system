# 会拆才会写（loop SSOT）

短名：`craft-eval`。进度只写这里。

**勿与 `scribe3/craft_ruler.py` 混淆**——那个文件是 DTW 情绪曲线对标，内含硬编码 `IDEAL_EMOTION_CURVE`（理想起承转合），属于 `对照.md` 明令不要学的模板路数，已进 P2 退役名单。本 loop 说的「尺子」是下面的 R1/R2/R3，代码落在 `scribe3/eval/`。

旧 loop `tonglu-force-rebuild`（[`2026-08-25-tonglu-force-rebuild-loop.md`](./2026-08-25-tonglu-force-rebuild-loop.md)）**结案，禁止续跑**。它的 22 条能力全部进入本 loop 的 P2 退役名单。

---

## 真意

让系统写出《乱世铜炉》那个水平的小说，并且能产出 `docs/worlds/乱世铜炉-拆文/` 那种质量的拆解。

这两件不是两个目标。**能拆 = 有尺子，能写 = 用尺子。** 旧 loop 到不了成色，是因为它跳过了前一半：一直在造闸，从没造过尺子。

所以本 loop 的顺序锁死：**先让系统会拆，再让系统会写。** P1 不写小说。

## 旧 loop 为什么到不了（施工前诊断，代码级）

三条，都在 `scribe3/playbook/`：

1. **闸里写着测试书的道具。** `structural.py` 里 `_ALTAR_FEE` 含「柜上账/油账/油罐」、`_JAIL_SAVE` 含「替杏」、`_KIND_WELL_QUEUE` 含「井台/排队/队尾/横担」、`_ALTAR_STAY_WORLD` 含「井|灯|墓」。《井台灯》的道具长进了通用检查器。没有井没有灯没有墓的书，开坛场永远过不了。
2. **闸里写着答案，不是标准。** `_SOUL_ASK = 皮影|要爹`、`_XIN_OATH = 除非自保`、`_BIE_THROW = 自己扔|布包`。因文说的是「醒了先叫谁，才是人有没有回来」，闸要的是纸面出现「皮影」。这是把因文举的例子当成了规则。
3. **22 道闸一道都不看正文。** `check_duty_men/soul/bie(...)` 签名全是 `(duty: dict)`；同时 `layers.py` 有 7 个 `_nail_*_duty` 在模型写歪时整卡替换。链路是「钉把卡写对 → 闸检查卡写没写对」。模型的正文从未被这些骨头验过。

第四条不在 `playbook/` 里，但同源：`scribe3/craft_ruler.py` 拿一条写死的 `IDEAL_EMOTION_CURVE`（起承转合八点）做 DTW 对标当「技法标尺」。`对照.md` 开头就写「不要学：开篇必须一个强钩子、三章交代主线、努力三次失败、黄金三章」。理想曲线是同一类东西：先设模板，再量偏离。铜炉的开篇是先立红事、主角还丢掉，套任何理想曲线都不合。

结论：系统学到的是铜炉的道具清单，不是铜炉的写法。旧 loop 的规则（一轮一能力 = 拆文一条骨头，验收 = 现网写出这一场）的最省力解就是加一个 `kind` + 一组正则 + 一个钉。**再跑多少轮都是同一个动作。**

## 三条铁律（防作弊 · 违反即本轮作废）

### 铁律一 · 尺子先于闸

任何一轮不得新增生成侧约束（闸、钉、提示词、`kind`），除非本轮开始时留出集分数已跑出并记录在案。**没有 before 分 = 本轮作废。**

### 铁律二 · 分不涨即回退

每轮结尾重跑同一套留出集。三项分数（R1/R2/R3，见下）任一下降、或全部持平 → `git revert` 本轮 commit，把失败原因写进台账，进下一轮换路子。**不许解释成「方向对但还需要几轮」。**

同一条能力连续三轮不涨 = `FAIL_LOUD`，停 loop 等人。

### 铁律三 · 尺子不可为了刷分而动

`P1` 结束时尺子冻结（代码 + 留出集章号 + 负样本生成脚本，一起打 tag）。之后要改尺子必须**单独开一轮**，且必须重跑此前所有轮次的分数，形成新旧对照表。**禁止**在能力轮里顺手改评分逻辑、改阈值、改留出集。

## 三个分数（全部只在留出集上报）

| 分 | 问的是 | 怎么算 |
|---|---|---|
| **R1 · 会拆** | 系统能不能拆出拆文包那种卡 | 只给留出章原文（不给该章 gold 卡、不给顶层），让系统产 20 小节章卡。盲评比对 5 个硬字段：这场戏有没有翻、账转给谁、留给下一节还欠什么、切在哪一下、这一节回不去的事。一致率 = R1 |
| **R2 · 会分好坏** | 系统能不能判出坏的 | 脚本从留出章机械生成三类负样本，让系统判「翻了没有」。准确率 = R2 |
| **R3 · 会写** | 系统写的东西离铜炉多远 | 系统写的场，用同一把尺子打分，与铜炉真章同标度比。R3 = 系统稿均分 ÷ 铜炉真章均分 |

**负样本三类（必须脚本机械生成，禁止手挑）**：

1. **削样本**：删掉该章章卡「这场戏有没有翻」指认的那一截。因文.md 每条都写了「删了会怎样」，就是这个操作的说明书。
2. **灌样本**：把处境翻改写成热闹翻（保留场面，抹掉 `stay`）。
3. **说明书样本**：把场面改写成叙述断言（「他终于释怀了」这一路）。

这三类正好对应系统最爱犯的三种错。

**阈值不许拍脑袋。** P1 结束时同时测两个锚：

- **天花板**：把 gold 卡本身当系统输出喂进评分器得到的分（应接近 1）。
- **地板**：随机/空输出的分。

停机线 = 地板 + (天花板 − 地板) × 0.7。这条线在 P1 末尾算出后写死，之后**不得再动**。

## 阶段（顺序锁死，不得跳）

### P0 · 清场与真源（不算能力轮）

1. 删掉现网全部书（《井台灯》`book_46cff31a`、《腕账》`book_e4a6e353` 及其余）。用户已授权全删。本 loop 不复用任何为过闸而写的书。
2. 重建原文母本行号，落进 `docs/worlds/乱世铜炉-全文.md`（与诡秘之主同规格），抽 20 条书证验证可跳转。
3. 落盘 `scribe3/eval/holdout.json` + hash。
4. 顺手修掉四条已知流程债（十分钟量级，不单独开轮）：改戏后重跑 deduce→draft、`mask`/`keep` 纳入专名扫描、戏层扫 `_SOUL_PROPER`/`_BIE_PROPER`、`duty.mask` 残留「萱儿」。

### P1 · 造尺子：让系统会拆

**这一阶段不写小说。** 一轮一件：

1. 拆卡产出链路（给一章原文 → 出 20 小节卡，带书证行号）。
2. R1 评分器（盲评比对，第三方模型 + 人抽查 10%）。
3. 负样本生成脚本（三类）。
4. R2 评分器。
5. 测天花板与地板，算出停机线，冻结尺子并打 tag。

沿用仓内既有约定：金样本放 `scribe3/tests/judge_golden/`（现有 8 个手写 play fixture，规格可复用），但本 loop 的样本从铜炉 171 章开发集机械生成，不再手写。

P1 出口：R1/R2 在留出集上有数，天花板/地板/停机线三个数字落盘。**R1 不达停机线不许进 P2。** 系统自己都拆不对，没资格判自己写的。

### P2 · 退役硬编码闸

1. 加 lint：`scribe3/tests/test_gate_no_proper_nouns.py` —— 扫 `playbook/structural.py`、`playbook/layers.py`，出现任何专名（铜炉的：胡炭/萱儿/秦苏/单嫣/赵东升/蜀山/凌飞…）或任何具体道具词（井/灯/墓/油罐/柜上账/皮影/布包/横担…）即失败。这条是机械可验的，先加测试再删代码。
2. `DAY_KINDS` 里 6 个铜炉情节名（选择、心藏腹、天下第一门、塑魂、别亦难，含「同场」的井台特判）全部退役。
3. `craft_ruler.py` 的 `IDEAL_EMOTION_CURVE` + DTW 对标退役（消费方：`storyline_project.py`、`api/routers/product_backlog.py`）。理想曲线和硬编码闸是同一个病：先设模板再量偏离。退役后由 R1/R2/R3 顶上。
4. 退役掉的每一条，改写成**题材中立的结构谓词** + 铜炉那一场降级为 few-shot 例子。

改写示范（塑魂）：

> 旧：`kind=塑魂`，纸面须有「皮影」「破坛」。
> 新：一件本应完成的大事只完成了一半；完成度由人物脱口而出的第一个指称对象证明，不由叙述断言；代价在事未了时已转给第三方。

这样科幻、都市、职场都能落。

每退役一条，跑一次留出集。铁律二适用。

### P3 · 闸从卡搬到正文

每条结构谓词加一个正文侧对偶：卡上说「账转到孩子手里」，就要能在正文里指出是哪一句做到的，且由 P1 的尺子判，不由正则判。

预期：现有场 K/L/M 会立刻变成不过。**那是对的，它们本来就没过**（结构只在卡上，没落到纸面）。不许为了保住旧场判而放水。

### P4 · 迁移验证（决定是不是真学会了）

- **题材轮盘**：固定一份 ≥8 个题材的清单（当代职场、硬科幻、校园、悬疑刑侦、家族商战、太空歌剧、乡土、赛博）。每条能力验收时由脚本随机取 2 个，**不许挑**。
- **书先冻结**：测试书的设定必须在能力开工**之前**冻结并落盘。禁止为了过闸补设定——这是旧 loop 最大的作弊面（《井台灯》就是为过闸写的）。
- **过拟合探针**：每轮除留出集外，跑一个与铜炉、与当前测试书都无关的题材，写同一条骨头。探针失效 = 本轮作废，无论留出集分数如何。

### P5 · 书级（场级全绿之后才开）

前四阶段全是单场。铜炉之所以是铜炉，靠的是跨场的东西：账在两百节里滚、伏笔埋三十节才收、时间怎么推。真源是参照本一到二十三节。

**已知阻塞**：拆文顶层在正传中后段有 54 节（214 的 25%）从未被引用，187–195 连续九节完全缺席；顶层 42% 的书证压在全书前 10%。跨场真源本身是缺的。P5 开工前必须先补这个洞，否则等于拿前传归纳全书。

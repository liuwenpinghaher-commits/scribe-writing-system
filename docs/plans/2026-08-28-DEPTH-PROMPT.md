# 设定深度:七处根因与修法

接 `2026-08-28-EXTRACT-PROMPT.md`。抽取已修好(aecc4ee2),`char_issue_ratio`
0.737→0.042 是真降,温贩婆/牧场主/柳岸青的短文和字段都是这本书的内容。
R3/R4/R5 也都核实生效:31–40 章新实体 0 个是修复前的病症,41–50 章 7 个、
51–60 章 6 个,前后半都不为零;野前缀全库清零。

现在 `verify_scale --db wanjie_v2 --chapters 60` 红 7 项。下面把这 7 项归到
四个根因,外加三处判据自身的问题。

**总纪律**

- 不许为了过线调阈值。下面凡是改判据的地方,改的都是「判的东西和声称判的
  东西不一致」,不是改门槛。每一处改判据都要在提交信息里写清楚改前判什么、
  改后判什么、为什么改后才是它本来要判的。
- 不许用命名花招、模板句、批量填充去凑指标。指标绿了但抽样读着是套话,
  等于没做。每一步验收都必须抽样贴原文让人读。
- 每一步做完先报数再往下走。数字不动就停下报告,不要连着改。

## P1 写厚名单在立纲时就钉死了(最高优先)

**证据**

十卷契约共 110 个写厚名额,只落在 **17 个**不同实体上。柳岸青、兰因、沈烛、
守火人档案局四个被点满 10/10 卷。全库 54 个故事实体里 **38 个从没被任何一卷
点名过**,其中 22 个命题数 ≤2。

**根因**

十卷契约是铺章之前一次性立的。立纲那一刻书里只有种子实体,所以 `thickens`
只可能点到种子那批。模型在 11–60 章新造的实体,**结构上永远进不了任何一卷的
写厚名单**。契约越执行,前 3 名越厚、长尾越薄。

这解释了为什么 P0 那轮把角色卡修好了、厚度指标却纹丝不动:角色卡是 codex 的
四个字段,厚度数的是故事命题,写厚角色卡不产生命题。两件事。

**修法**

写厚名单改成**开铺前重排**,不在立纲时定死。钩子点在
`expand_volume_accounts`(`expand_wanjie_chapters.py:662`)进 `plan_batches`
之前:按此刻库里的真实分布重挑本卷 `thickens`,规则

- 优先挑此刻命题数 ≤2 且已出场的实体
- 同一实体跨卷被点名次数设上限,主角不得每卷都占名额
- 名额数量沿用 `required_thickens(span)`,不要改这个函数的阈值

立纲阶段的 `thickens` 保留作初值(第一卷开铺时库里只有种子,重排结果与现在
一致),重排只覆盖后续卷。

**只改 `thickens` 的挑选,不要动 `introduces`。** 引入按批分配(R3)刚验过是
好的,别碰。

## P2 写厚字段没有实质下限

**证据**

24 个角色里四字段齐的只有 **4 个**,19 个只有两个字段。7/23 的
`surface_goal` 短于 25 字,最薄的折光贩子是「他要体温。」五个字。
非空即算填了,而 grounded 判据因为内容逐字引自短文会自动放行。

`completeness_score` 79(差 1 分过线),扣分来自:周公仍是空壳(四字段全空)、
4 个主角色缺错误信念(Lie)。

**修法**

`duty_fields_ready` 加实质下限。下限定成什么由你判断并在提交信息里写明依据,
但至少要挡住「他要体温。」这一类。同时补 `deep_need` / `internal_conflict`
两个字段的产出路径——现在抽取只问两问,四个槽里只有两个能被填上。

注意本仓库的词汇表(`codex_generate.py:262-268`):`fear` 和
`internal_conflict` 这两个槽**定义为**「他让人付出什么」,`abilities`=靠什么
收账、`weaknesses`=缺什么会付账。**照这套词汇写,不要改成通行语义。**

顺带一处不一致:兰因的 `fear` 是「怕她焊上的锚成了别人的枷」,用的是通行语义,
和房规不同,说明它由另一条路径生成。查清哪条路径,统一到房规上。

## P3 空间判据测的是命名前缀,不是空间结构

**证据**

`setting_depth.place_regions`(`setting_depth.py:14`)靠**名字字符串前缀**认
上级:只有当地点名以另一个地点名开头(如「不署名门」与「不署名门/签押廊」)
才算同区。函数注释自己写明「地点表没有 geography 上级字段」。

所以「一区一地点 100%」这一项测的是命名习惯。硬追它只会逼出命名花招。

**修法**

不要去追这个指标。补真关系再判:

- 铺章时让地点带上级关系落库(用命题表达从属,如 `place:签押廊` 位于
  `place:不署名门`),走 `canon_oid`,别新开旁路
- `place_regions` 改成读这个真关系算连通分量;真关系缺失时**退回只报不拦**,
  并在输出里标明「无从属数据」,不要用字符串前缀冒充

改完这一项在现有 60 章上会是「无从属数据、只报不拦」,这是正确状态,不是失败。

## P4 长线不过卷

**证据**

64 条承诺:51 条已收(其中 **33 条在同一卷内收掉**、18 条跨卷),13 条未收。
收线间隔中位 11 章、**最大 18 章**,而一卷是 20 章——几乎一切都在本卷内收干净。
13 条未收里 11 条在最后一卷,所以跨卷未收只有 2/64 = 3%(门槛 ≥15%),
且卷 1 一条跨卷未收都没有。

**修法**

契约要能声明「本卷必须留几条到下一卷以后」,章级提示词要把「本卷该收的线」
和「本卷不许收的长线」分开列。现在提示词只催收,不拦收。

同 P1,这个名单也该在开铺前按库里实际未收线重排,不能在立纲时凭空写死。

## P5 厚度指标未按已铺范围校正

R5 给卷和悬置修了「只在已铺范围算」,厚度这一项没修。第 55 章才出场的实体
只有 5 章时间攒命题,和第 5 章出场的放一起算是不公平的。

实测:全部 54 个实体里 ≤2 占 50%;只看首现 ≤40 章、有 20 章以上时间的 41 个
老实体,≤2 占 **43%**、≤4 占 **78%**。

**修法**:厚度输出拆两行报——全部实体、以及「有 ≥20 章时间的实体」。把关用
后者,前者只报。**注意 43%/78% 仍然远超门槛,这不是给厚度开脱,是去掉噪声
让 P1 的效果能被看见。**

## P6 写厚判据缺阳性对照

`char_issue_ratio` 这一片的判据连着三轮都是「判据本身写错」而不是「模型写得
不好」(拼接串子串、无标签解析、非空即通过),因为它从来没有正样本。

**修法**:补阳性对照。手写一份必然合格的 fields + portrait,断言判据必须放行;
再手写一份另编的(内容不在短文里),断言判据必须拦下。和一致性检查那个正样本
同一个路子。P2 改完 `duty_fields_ready` 之后立刻补,不要拖。

## 执行顺序与验收

分两段。**第一段不铺任何新章**,第二段只铺 20 章。

### 第一段:能离线验的先验(不铺章)

做 P2、P3、P5、P6。做完在现有 60 章上跑:

```
scribe3/.venv/bin/python -m scribe3.tools.verify_scale --db wanjie_v2 --chapters 60
```

要报:

1. `completeness_score` 和 `char_issue_ratio` 的新值。P2 加了下限,
   **这两个数很可能变差**——那是对的,说明下限起作用了。变差就如实报,
   不要回调下限。
2. 抽 5 个角色贴 `surface_goal` / `deep_need` / `fear` / `internal_conflict`
   四字段原文,人读一遍判断是不是这本书的内容。
3. 厚度两行(全部 / ≥20 章),确认拆分正确。
4. 空间项显示「无从属数据、只报不拦」。
5. 新补的阳性对照:合格样本放行、另编样本拦下,两条都要跑出来。

第一段单测必须先行,每处改动配测。

### 第二段:P1 + P4,只铺 61–80

P1 和 P4 改的是开铺前的重排,只能靠铺章验。**只铺卷 4 的 61–80,不要再多。**

铺之前先记下基线(现在的数):

- 老实体(首现 ≤40 章)≤2 占 43%、≤4 占 78%
- 前 3 名占 36%
- 同卷内收 33 / 跨卷收 18 / 未收 13

铺完 61–80 后再跑同一条 verify_scale(`--chapters 80`),要报:

1. **只看首现 ≤60 章的实体**(即 61–80 章之前就存在的),它们的 ≤2 / ≤4 占比
   相比基线动了多少。这是 P1 唯一有意义的检验——新铺的 20 章有没有真的回去
   把长尾写厚。
2. 本卷 `thickens` 实际点了谁,贴名单。如果还是柳岸青兰因沈烛,说明重排没生效。
3. 新埋的线里有几条被声明为「不许在本卷收」,以及卷 4 结束时跨卷未收的条数。
4. 抽 3 个原本 ≤2 的长尾实体(比如 验温嫂、无名井、钟缝匠),贴它们在 61–80 章
   新增的命题原文,人读一遍确认是真情节推进,不是为了凑数写的补充说明。

**不要铺 81–200。** `wanjie_scale` 全程不动。

### 停止条件

第二段跑完,如果老实体 ≤2 占比没有明显下降,**停下报数,不要接着改**。
那说明 P1 的方向判断错了,需要重新排根因,不是需要更多改动。

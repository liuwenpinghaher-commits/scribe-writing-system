## 选定的最优路

谁让改：作者授意本 goal「按最优不是最简单改写路径」；实施判断为最优。

旧路差在哪：把铜炉学成古白话词表 + 钩子/两难/字数闸。拆文的骨头（日子、办事、假破真、远近、切）没进生成和审判。模型会写出「端的是人如流水」和开篇报身份，机器还可能绿。

本路做什么：

1. 拆掉古白话贴铜炉（写协议、完整尾注、范例）。关旗回旧文案。
2. 把日子/办事/假破真/远近/切写进 duty/play/draft/final 的生成嘱咐和法官成色块（验戏，不验词表）。升 playbook 版本（改了法官问卷）。
3. 机器只过滤反着教的东西：叙述层古白话套话、铜炉专名泄漏、章末「他决定了/他付出了代价/夜色深了」。日子翻没翻仍由人按尺子对照。
4. 新开样例书。换自己的名、自己的日子。不灌铜炉情节。场不过不准写下一章。10 万是最后的长度门。

怎么退：关 `SCRIBE3_CHENGSE_CRAFT`（写协议回古白话、成色块和过滤闸停）；或 revert 本循环 commits。

不做什么：不把拆文粘进 prompt；不加字数闸；不改 QC 当完成门；不 overlay 腕账/万界。

## 尺子（场过关必须用）

1. 日子：先立还在过的日子，奇事从日子里来；热闹像翻了、处境没翻 = 不过
2. 办事：看见谁办了哪一件、日子怎么变；嘴上要的和真正缺的打架；鉴定式人设/杯子余温/维特剖心 = 不过
3. 假破真：先反面再破功；上来掏底牌 = 不过
4. 远近：共情就把眼睛交给当场那个人；旁观才站外头报年号
5. 因文：一行本事说不完；删了那一截场会塌
6. 切：热过再冷，切在能听见看见的那一下
7. 不要学半文不白、铜炉专名情节、网文开篇格子

概括只能写成「他决定了/他付出了代价/夜色深了」= 不过。

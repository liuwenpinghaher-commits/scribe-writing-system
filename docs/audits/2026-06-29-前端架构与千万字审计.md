# scribe3 前端架构 + 千万字可扩展性审计与统一方案

> 三路并行审计(A 写作工作台架构 / B 图谱+泳道 / C 全前端扫盲+后端可扩展)。证据 file:line。本文 = 问题全清单 + 统一架构方案 + 分阶段实施计划。日期 2026-06-29,基线 `feat/audit3-fixes`。

## 根因总览

当前 UI 是 **F-06「混合 Binder」重构**(左项目树 + 中 DetailPane 路由),它**推翻了**权威设计文档《统合写作工作台-三阶段设计方案》要的「三栏常驻(左数据/中产物/**右主编常驻**)+ 阶段切换」。后果直接对应用户的痛点:

- **右主编栏"没了"**:WriteChat 被下沉进 WriteLayout 内部 Shell,**只在点「章」节点时挂载**;素材/容器/图谱/时间线全无右栏。根因 `DetailPane.jsx:23-70` 按节点类型路由,只有 chapter 分支带 WriteLayout(内含右栏)。
- **大纲/节拍/草稿/正文 二级 tab 从未实现**:WriteLayout 无 `phase` 状态;后端 chapter 只有 `synopsis`(大纲),**无 beats/draft 字段**,chapter_version 无 stage,save-chapter 不自动留版,无 /save-draft。
- **图谱/泳道**:全量渲染、零虚拟化。
- **千万字**:所有"全书铺开"视图零虚拟化 + 后端多个端点全表聚合(outline 拉全文是头号病灶)。

## 四、统一架构方案

**回到设计文档的三栏常驻 + 阶段化,但保留 Binder 项目树作为左栏导航**(融合 F-06 与统合设计):

```
┌─────────────┬────────────────────────────┬──────────────────┐
│ 左:项目树   │ 中:按节点类型 + 二级tab     │ 右:主编对话常驻   │
│ (Binder导航) │  章 → [大纲|节拍|草稿|正文]  │ (随中区上下文切角色)│
│ 卷/章/场景   │  素材 → 详情卡              │  WriteChat 提升至  │
│ 素材分类/项  │  容器 → 卡片墙/大纲表        │  Binder 级常驻     │
│ 横切视图入口 │  视图 → 图谱/泳道/仪表盘     │                  │
└─────────────┴────────────────────────────┴──────────────────┘
```

- 右栏 = `WriteChat` 提到 BinderLayout 级常驻,所有节点在线;章=写作角色、素材=设定问答、视图=分析问答。
- 章中区 = 二级 tab `大纲/节拍/草稿/正文`(阶段化),各 tab 可编辑 + 右栏讨论;素材/存档作为节点类型在树里(存档=版本历史 tab)。
- 全书铺开视图加虚拟化;图谱默认 ego 子图;泳道防叠加+详情 popover+虚拟化。

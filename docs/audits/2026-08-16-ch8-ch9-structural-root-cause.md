> 本文回答：**系统哪一层、用哪条规则、在哪一次预校验里，把一部硬科幻翻译成了这套可过闸动作。**

## 0. 一句话

**过闸语言取代了世界语言。**

OpSeq 的作者不是小说家，也不是 LLM。作者是：

1. `is_atom_field` = `ACTION_LEX` ∧ (`OBJECT_NEAR` ∨ `COST_CONSEQ`)  
2. WAVE-1（`prop_action_stuck` / `seed_orphan` / 钟地填空）  
3. extra 预校验：人/代理必须先写出一份本机 `evaluate_spine` / `evaluate_beats` 全绿的金样，才许烧 LLM  
4. `format_must_land` + ASK「必须落地」把金样灌进排演/定稿  
5. extra 尾句硬写「必须有一句：海用他母亲的口气咳了一声」

LLM 只是把这份金样扩成场面。扩得越好，病越像小说。

三拍定式从第 4 章起锁死，8/9 只是换皮：


## 3. 生成链上实际发生了什么（日志）

1. extra 必须先在本机过 `evaluate_spine` / `evaluate_beats` / `prop_action_stuck`；  
2. LLM 薄纲 / 503 只许改 extra 措辞，不许松闸；

节拍 extra 第一句是：



## 5. 第一层：产品把「章」定义成答题纸

`chapter_spine.v1` 十四键：时空 / 在场 / 咬 / 要 / 挡 / 触发 / 升级 / 选择 / 决断 / 代价 / 信息差 / 线 / 钩 / 禁令。另加钟 `span+delta`、地 `name+delta`。

`_OUTLINE_ASK` 要求「只输出标签行」「禁止对白、禁止气味/街景/微动作」「每条一句」。  
`_BEATS_ASK`：每拍只要/挡/变/付，禁止千字场面。  
`SLOT_MAX_CN = 40`。extra 再加一句「每槽不超过四十字」。

这套合同**成功**消灭了「600 字进场灌肥」。副作用是：

1. 章 = 填满 14 键 + 3 拍 GCD，不是「改变读者对世界的一个命题」。  
2. 「挡」槽语法是「谁按住什么」，自然长出沈烛/兰因两个按手的人。  
3. 「在场」ASK 写「焦点 / 对手 / 见证」，实现只存顿号名单；功能冻结在闸上看不见。  
4. 代价槽 40 字写不下「成核点开始复制他的指针态，环境冗余改锁」，写得下「大遮蔽更险」。

冰山模块自己也说：字数 =「够不够撑**一场戏**」。小说家审第三章的原话正是这个病：**够一场戏，不够一部小说。** 第八、九章是同一病的中段复发——闸按一场戏验收，系统就只生产一场戏。

`format_must_land`（`chapter_spine.py`）把选择/决断/代价/信息差/钩/禁令/钟/地/矿拼成：

```text
【必须落地】下面这些短原子必须在下一层出现，禁止只写巷/门/烟：
```

排演 ASK、定稿 ASK 都要求兑现这份清单。金样一旦进大纲，下游没有合法路径写别的故事。

## 6. 第二层：词表就是物理学（最硬的根因）

### 6.1 公式

`clue_density.py`：

```text
合法原子 = ACTION_LEX 命中  ∧  (OBJECT_NEAR 命中 ∨ COST_CONSEQ 命中)
```

`ACTION_LEX` = `CONFLICT_LEX` ∪ `DRIVE_CONFLICT_LEX` ∪ `TURN_COST_LEX` ∪ `_EXTRA_ACTION`。

实测关键动词是否在袋：

| 词 | ACTION_LEX | FATE_VERB_BAG |
|----|------------|---------------|
| 按 / 揭 / 拨 / 撕 / 咳 / 交 / 锁 / 挡 / 报 / 开 | 是 | 否 |
| 焊死 | 否 | **是**（跨章卡住用） |
| 观测 / 冗余 / 坍缩 / 成核 / 相位 / 锚定 | **否** | 否 |

`OBJECT_NEAR` 是单字袋：

```text
铜 焦 账 门 角 声 爹 匙 纸 灰 债 名
核 裂 权 海 箱 腕 令 罩 泡 锚 度
```

注意：**没有「帘」「丝」「肩」「遮蔽」**。有「角」「核」「腕」「海」「名」「声」。  
`COST_CONSEQ`：暴露 / 更险 / 撕 / 伤 / 代价 / 锁死 / 被迫 / 两难…  
`_RARE_MARK`（节拍必须抄的稀有词）：断 / 咳 / 撕 / 揭 / 拨 / 暴露 / 拔…

`焊死` 不在密度动词袋，但在 `FATE_VERB_BAG`。沈烛说「焊死」时，命运闸认为他在做情节动作。

### 6.2 实验室：同一套函数打落盘短句

本机 `PYTHONPATH=.` 对 `is_atom_field` 实测（2026-08-16）：

| 短句 | 原子? | 命中动词 | 含义 |
|------|-------|----------|------|
| 揭开大遮蔽 | **否** | 揭 | 「遮蔽」不含物件字。大遮蔽三个字对闸是空气 |
| 揭开大遮蔽去看成核点 | 是 | 揭 | 因为句里有「核」。帘不是唯一过闸路径 |

| 揭开核前帘缝 | 是 | 揭 | 揭+核 |
| 按住帘角 | 是 | 按 | 按+**角**（角在袋，帘不在） |
| 沈烛按住帘角不让揭 | 是 | 揭 | 揭+角 |
| 兰因按住腕不让揭帘 | 是 | 揭 | 揭+腕 |
| 兰因按住腕要带他走 | 是 | 按 | 按+腕。九章通用原子 |
| 焊死 | **否** | 死 | 光焊死不算密度原子 |

| 柳岸青要拨开成核点上的海丝 | 是 | 开 | 开+核 / 海 |

**推论（比旧判断更精确）：**

1. 「帘」不是让「看成核点」过闸所必需——句里有「核」就够。  
2. 「帘」是为了给沈烛一个**可按的角**、给焊死一个**可焊的布**、给揭一个**可掀的缝**。大遮蔽作为 Lun-A 牢笼没有角、没有缝、不能焊；要过「谁按住什么」的挡槽语法，必须发明一层织物。  
3. 「海丝」同理：拨需要海/核/名；丝本身不在物件袋。  
4. 「按住肩」过不了闸。所以第九章 extra 仍要「兰因按住腕」托密度；沈烛的肩是场面，不是原子。  
5. 世界命题句要么零命中，要么靠「开」「核」误伤过闸，闸并不理解机制。

### 6.3 `prop_action_stuck` 为什么换皮就绿

只在 **动词集合完全相等** 且物件有交时才 422。实测：

## 14. 结构处方（对根因，不对文笔）

不在此实现。只钉「改哪一层才不是换皮」。

1. **词表与宇宙对齐（第二层）**  
   为万界加机制动词/名词（观测、冗余、坍缩、成核、相位、锚定），并允许「揭 + 大遮蔽」整词，不必借「帘+角」。否则永远会发明过渡道具。

2. **WAVE-1 加真正的功能闸（第四层）**  
   现有 `cast_function_stuck` 用 2 字碎片子集，现网抓不住「连续三章按住 X」。应问角色在挡槽里的论元角色：沈烛是否仍是按手、兰因是否仍是按腕护士。

3. **世界命题进 OpSeq（第一层）**  
   每章必须改一个可点名的世界事实（大遮蔽从双向隐形变为单向可见 / 成核点开始复制柳岸青的指针态），并在正文有可感后果。现在的代价槽只改形容词。

4. **设定库必须有 term/item（第七层）**  
   `world_catalog_empty` 要么修写入，要么不要报。空目录 + 「代价须点名轴用语」= 三词循环。

5. **extra 降权（第三、五层）**  
   预校验应验「与上章功能差、与宇宙词表相交」，而不是只验密度数字。禁止 extra 硬写「必须有一句母亲咳」「原样复述三拍」「必须以时空：开头」。

6. **户口不得逼剧情（第八层）**  
   `extract_seeds` 禁止把人名切段、指示代词、趋向动词当种子。`seed_orphan` 不得把「出来 / 青的」变成信息差义务。

7. **解析与 SKIP（第六层）**  
   演绎禁止把「时空/场景真相」当角色；定稿必须剥标签；`thicken` SKIP 不得把第一次过闸的错误几何冻成正典。

## 15. 结语

第八、九章不是一次失败的扩写。它们是这条生产线的**稳态解**：

```text
14 槽答题纸
  ×  只认「按/揭/拨/撕/咳 + 腕/令/核/角/名/声」的物理学
  ×  WAVE-1 只拦同动词同物件、不拦同功能
  ×  extra 必须先绿才能烧模型
  ×  extra 尾句硬写母亲咳
  ×  必须落地回灌
  ×  第一次转绿就 SKIP
  ×  设定库空、轴用语三词
```

在这个宇宙里，唯一能连写九章还不「卡住」的故事，就是三人轮流按住一件越来越抽象的东西，每章换一个动词，用母亲的咳收束，用「更险」付账。帘和丝是这门物理学发明出来的过渡名词，不是世界观。

要写《万界概率战争》，先换这门物理学。不换词表、不换 WAVE、不换 extra 验收，换模型也还是帘和丝。

# StoryScope 实测：人机差落在哪一层

**这份文件是数据，不是主张。** 结论与改造方案在别处，这里只放算出来的数。

- 数据集：`~/Downloads/storyscope_full`（802MB，未入库）。61575 行 = 人类 10239 + GPT-5.4 / Claude Sonnet 4.6 / DeepSeek V3.2 / Kimi K2.5 / Gemini 3 Flash 各约 10260，同一批 prompt 配对。人类正文因版权未附，只有 304 个特征的标注值。
- 复现：`scribe3/eval/storyscope_probe.py`。项目 venv 无 pandas，需另起环境装 `pandas pyarrow scikit-learn`。
- 两种量法：**TVD** = 某特征上人类分布与模型分布的全变差距离（0 重合，1 完全不重合），看「哪条写法不一样」；**AUC** = 只喂某几维特征训判别器识破 AI，看「藏在这一层里 AI 还剩多少痕迹」。两者不等价，都要看。
- 注意：`PLT_THM_004`（主题域）、`SOC_REL_007`（关系类型集合）这类 multi_select 特征取值上千，TVD 被组合爆炸顶高，不代表真实差异，下文已剔除。

### 没有语系效应，所以不能拿 DeepSeek 或 Kimi 代表 Qwen

我专门查了「DeepSeek 与 Kimi 同向、且与 GPT/Claude/Gemini 反向」的项，想看看中文语料训练的模型有没有共同倾向可以外推到 Qwen。**最大的一条 gap 只有 3.9%**（`TMP_DUR_021` 单角色跨多个人生阶段），其余全在 3% 以下，都是噪声量级。

**模型的差异不按语系分。** 所以 Qwen 的具体病灶无法从这份数据推出来，只能实测——办法见第八节。

## 八 · 怎么把 Qwen 补进这张表

数据集自带 `taxonomy.json`，每个特征都有 `question`、`values` 和 `detection_method`（人工写的判定说明），本身就是一套现成的标注 prompt。`stories_dev.parquet` 是 100 个 prompt 的小 split，正好当试点规模。

补测路径：拿 dev 的 100 个 prompt 让 `qwen3.8-flash` 各写一篇，再用 taxonomy 的 `detection_method` 逐特征标注，就能得到 Qwen 那一列。

**不要标全部 304 项**，成本不划算。按本次转向只需要三组，共约 30 项：

- **通病复核**（验证第五节那几条在 Qwen 上是否照样成立）：`SIT_MET_303`、`STY_FIG_005`、`AGENT_ATTR_024`、`SIT_GEN_004`、`PLT_THM_008`、`PLT_CON_007`、`AGENT_EMO_009`
- **设定层**：`SET_LOC_013`、`SET_ATM_003`、`SET_ATM_019`、`SET_LOC_011`、`SET_LOC_002`、`SET_ATM_005`、`SET_LOC_014`、`SET_LOC_016`、`SET_TIM_015`、`SET_TIM_016`
- **信息调度层**：`REV_DIS_001`、`REV_SUS_005`、`REV_SUR_010`、`REV_SUR_007`、`REV_SUS_001`、`REV_SUS_003`、`REV_SUR_003`、`SIT_MET_402`、`SIT_MET_403`、`SIT_MET_005`

标注器不要用 Qwen 自己（自评有偏）。100 篇 × 30 项，一次性开销，之后换模型可以复用同一套。

这件事的优先级取决于方案怎么定：如果新的 R3 只做事实一致性判定（伏笔闭没闭环、有没有违反世界规则），那 Qwen 的风格画像其实用不上，可以不做；如果方案里出现任何「与两本参照的分布对照」，那就必须先有 Qwen 那一列，否则对照的是别人的模型。

## 九 · 这份数据能支持什么、不能支持什么

**能支持**：模型在「世界的系统性设定挖多深」上已达人类水平（TVD 0.065）；在「文笔、人物、主题姿态」上稳定露馅（AUC 0.92–0.95）；说教、反复隐喻母题、不肯克制这几条是五模型通病，换模型不会消失；换模型能赚的部分几乎全在文笔层。

**不能支持**：**数据集里没有 Qwen，而产品现在用的就是 Qwen**，第六节的 DeepSeek 画像不能顺移，也没有语系效应可供外推（第五节末）。这是英文短篇数据集，中文网文的类型惯例（金手指、境界体系、爽点节奏）不在测量范围内。304 个特征本身由 LLM 标注，标注器的偏好会带进来。AUC 高只说明「可被判别器识别」，不等于「读者会觉得难看」——两者相关但不是一回事。

**尤其不能支持**：把上面任何一个数字直接写成生成时的阈值。同样的错误已经犯过四轮，理由见 [`craft-v4.md`](../plans/2026-08-27-craft-v4.md#第三次修正--闸整个降级为监控)。

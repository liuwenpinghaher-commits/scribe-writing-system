# 秘密审计指标制度(北极星方案任务13)

> 蓝图 §3-③/第六章:防 Goodhart 的流程性防护——**保留不进 loop 的审计项**,定期人工盲评校准。"面板全绿只证明机器没失职,不证明书好"——本制度是整套设计里唯一能回答"这一切有没有意义"的部件。宪法约束:审计项永不接入任何自动收敛判据。

## 一、原则(三条,不可协商)

1. **不进 loop**:本制度全部指标/结论只供人读,永不作为 regenerate/pass 判据,永不合成分数进面板趋势——一旦进 loop 它就成了新的可优化代理(Goodhart 数学上无免疫,arXiv:2209.13085),秘密审计就死了。
2. **盲评**:评审材料剥离"哪章被自动回炉过/rubric 打过什么档"等元信息(防锚定);对照组混入,评完才揭示身份(Chatbot Arena 先例)。
3. **定期且低频**:每卷一次或每 10-15 章一次;高频审计会诱导"为审计而写"。

## 二、两个抽样池

**池A·被自动 regenerate 章(全查或高比例抽查)**
- 来源:`~/.scribe3-loop-journals/{work}/loop_ch*.json` 中含 `*_verdict_blocking` stage 的章(loop journal 兼任审计数据源,台账 D-012)。
- 审什么:**"重写后真的更好吗"**——检测器有假阳性(限知类尤甚),自动重写可能把有灵气但被误判的段落磨平(蓝图 §3-① v2 防护)。对照材料:该章版本库中第 0 稿(raw)与终稿并排。
- 结论三选一:重写更好 / 无差 / **重写磨掉了好东西**(第三类累计≥2 例 → 触发检测器阈值复审,考虑收紧 blocking 判据或启用 targeted repair,D-009 缓议项)。

**池B·随机章(每卷 2-3 章)**
- 来源:全部已 ingest 章随机抽(排除池A 已抽)。
- 审什么(蓝图 B4 的 100-endings 式抽查精神,人工盲评四问):
  1. 张力:这一章你想继续读下一章吗(1-5)?
  2. 声音:遮住人名还认得出这是这本书吗(1-5)?
  3. 记忆点:24 小时后你还记得哪个画面(自由文本,可空)?
  4. 违和:有没有"机器味/被打磨过头"的段落(引原文)?
- 与面板对照:盲评分与该章 scorecard/ai_grade 定档**只做事后相关性观察**(校准检测器),绝不回填任何自动流程。

## 三、盲评包(抽样工具,GET /audit/blind-pack)

导出一个自包含 JSON 包:
- `samples[]`:每样本 {盲评编号(随机化,不含章号), prose, (池A 样本附 raw 稿并排、随机左右序), 评审四问模板}
- `key`(单独字段,评审时不看):盲评编号 → {章号, 池别, 回炉轮数, ai_grade, scorecard 摘要}——评完对照用。
- 参数:`work`/`sample_n`(池B **全书总抽样数**,默认 2;"每卷 2-3 章"由作者按卷分次导出或 sample_n=卷数×2 执行——P2 审查 P2-4 语义修正)/`seed`(可复现抽样)。
- **形态偏离明示**(P2 审查 P2-4):池A样本自带双稿并排,形态上暴露"该章被回炉过"的池别身份(双稿对照任务本质需要);原则 2 的"剥离元信息"在池A降级为"剥离章号/轮数/档位,保留双稿形态"——评审者知道"这是对照题"但不知道哪稿是重写后的(左右已随机)。
- 不落库、不留痕于任何 loop 可读的位置(read-only 端点)。

## 四、执行节奏与记录

- 触发:每卷终章 ingest 后,面板提示"该做本卷秘密审计了"(提示而已,不阻塞)。
- 记录:审计结论写 `设计文档/审计记录/`(人工文档,不入库)——避免结论被任何自动流程消费。
- 唯一允许的机器动作:池A 第三类结论累计时,人工决定是否调检测器参数(改动照常走 commit+测试)。

## 五、诚实声明

- 本制度依赖作者真的执行盲评——机器只负责把包备好、把提示给到;跳过审计系统不会坏,但"检测器假阳性磨稿"将失去唯一的发现渠道。
- 盲评四问的分值不可跨书比较,仅供本书自比与检测器校准。

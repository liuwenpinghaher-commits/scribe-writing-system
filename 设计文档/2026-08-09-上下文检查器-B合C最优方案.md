# 上下文检查器 · B∪C 最优方案

| 项 | 值 |
|----|-----|
| 日期 | 2026-08-09 |
| 状态 | **已定稿 · 实现按本文件** |
| 产品 | 铜炉 / scribe3 |
| 关联 | Task 14 memory_trace · Creative Context Manifest · `docs/SESSION.md` |

## 1. 根因（为何永远 0 tok · 0 源）

1. **检查器唯一读 `memory_trace`**，而 demo 主验收书该表为 **0 行**；真正编译证据在 **`context_manifest`（数百条）**。
2. **讨论路径**（`/chat/stream` / agentic）走 `_editor_system` 散点拼装，**不编译、不落溯源**；UI 文案「发讨论后再看」为假承诺。
3. **写作落库条件过窄**：须 MEMORY_FABRIC 开 + body 带 session/revision + RetrievalResult 非空；ChiefDock 还曾把绑定挂在 `threadMode` 上。
4. **写路径合成 snapshot**（`session_id="write", revision=0`）与导航会话脱钩，键无法对齐 UI。
5. **UI 六块 vs 组装八块**；源数按 retrieval `selected.kind` 粗算，Global 等块永远 0 源。
6. **无编译时画假 0**，伪装成「系统无记忆」。

## 2. 目标架构（B∪C）

> **凡进模型的动态上下文，只经 `CreativeContextEngine.compile` 一次。**  
> **检查器只渲染 `ContextTurnView`。**  
> **`context_manifest` = 输入配方权威；`memory_trace` = 检索裁决明细（可选层）；导航 session+revision = 对齐主键。**

```
Request + 真 Snapshot → Policy(task_kind) → Assembler(+Retriever)
  → Envelope → Manifest + TurnBind(+ optional memory_trace)
  → GET session/trace/{rev} 聚合为 ContextTurnView
  → ContextInspector
```

### 2.1 不变量

1. **所见即所编**：`actual_input_hash` 对最终 UTF-8 输入成立（写作已有；讨论迁入后同锁）。
2. **一任务一 Policy**：`discussion` 不得走 `generation.v1`。
3. **全知/限知不互污**：discussion 永不 `for_generation=True`；draft/final 有 focalizer 必限知门。
4. **观测失败不挡主链**；但可区分「未编译」与「编译失败」。
5. **无编译不画假 0**（`availability=not_compiled_yet`）。
6. **密钥仅服务端 mask**；UI 永不渲染 secret 正文。
7. **真 snapshot 优先**；无绑定时可 synthetic，但检查器明示且不得冒充导航 rev 可查。

## 3. 读模型合同 · ContextTurnView

检查器与 `GET /context/sessions/{id}/trace/{revision}` **唯一 DTO**（兼容旧字段）：

| 字段 | 说明 |
|------|------|
| `available` | bool；false = 未编译（兼容旧前端） |
| `availability` | `ready` \| `not_compiled_yet` \| `degraded` |
| `view_version` | `context-turn-view.v1` |
| `task_kind` | `discussion` \| `draft` \| `final` \| … |
| `path` | `write` \| `discuss` \| `pilot` \| … |
| `manifest_id` / `request_id` / `actual_input_hash` / `policy_version` / `envelope_hash` | 输入身份 |
| `block_tokens` | 八块 name→token（focus…provenance） |
| `blocks` | `[{name, token_estimate, source_ids, source_count}]` |
| `selected` / `rejected` | 证据行（可含检索明细；secret 已 mask） |
| `usage_digest` | 本轮持久化摘要（非现算冒充） |
| `work` / `context_session_id` / `snapshot_revision` | 绑定键 |

**无编译响应**（不得填全 0 块冒充）：

```json
{
  "available": false,
  "availability": "not_compiled_yet",
  "reason": "not_retrieved_yet",
  "session_id": "…",
  "snapshot_revision": 7,
  "view_version": "context-turn-view.v1"
}
```

**源数**：按块 `sources` / `source_ids` 聚合，禁止仅 `selected.filter(kind)`。

## 4. 写模型 · TurnBind

表 `context_turn_bind`（migration 111）：按 `(context_session_id, snapshot_revision)` 幂等 upsert 最新一轮编译投影（block_tokens、blocks 摘要、manifest 三元组、task_kind、path、usage_digest、selected/rejected 摘要）。  
落库时机：**每次成功 compile 且请求带齐 session+revision**（与 fabric 是否开无关；无检索则 selected 可空，块 token 仍来自 envelope）。

`memory_trace`：fabric 开且有 RetrievalResult 时继续写，并挂 `manifest_id`；检查器优先 TurnBind，再用 memory_trace 补检索 channels/rejected 细节。

## 5. 写作路径

1. 请求 body/头 的 **真** `context_session_id` / `context_revision` / `context_hash` 注入 snapshot（替换裸 `session_id="write"` 作为可查键）。
2. `CreativeContextEngine.compile` 成功 → 写 Manifest（既有）→ **写 TurnBind** → 可选 memory_trace。
3. 落库异常 **fail-soft**，不阻断写作。
4. 前端：凡有 snapshot 即绑定（ChiefDock **不**再依赖 threadMode）。

## 6. 讨论路径（B）

| 项 | 约定 |
|----|------|
| Policy | `discussion.v1`，`task_kind=discussion` |
| Snapshot | 真导航快照（有绑定时） |
| 组装 | Assembler `mode=discussion` + 可选 Retriever |
| 身份 | 讨论身份/全知 banner；**禁止**写作 `⟦PROPOSAL⟧` 协议 |
| 补充源 | pulse、DISCUSSION_DIRECTIVE、thread history 作 supplemental / 附加段，进 Manifest 可审计 |
| 捕获 | **不**调用写作意图 `_capture_turn_memory` |
| 输出 | 同一 TurnBind + 检查器可读 |

## 7. 检查器 UI

1. 八块：focus / global / canonical / recent / procedural / reference / uncertainty / provenance。  
2. `availability !== ready`：文案诚实，**不**渲染假 0 网格（或灰态说明未编译）。  
3. ready：块 token + 块级源数 + 证据列表。  
4. flag `context_inspector_v1` 仍门控。

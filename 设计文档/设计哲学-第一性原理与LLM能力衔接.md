# 设计哲学:第一性原理 × LLM-写作能力衔接

> **这份文档是整个系统真正的地基,优先级高于 00 契约和全部 18 个功能模块。**
> 它回答三个被之前设计回避的根本问题:
> 1. 什么是"好小说"?(目标的第一性定义)
> 2. LLM 到底擅长和不擅长写小说的哪一部分?(诚实的能力衔接)
> 3. 由此,人和 AI 该怎么分工?(系统形态的真正决定因素)
>
> **一句话结论:AI 全程主笔——从大纲到成稿的一切文字都由 AI 实现。人只做两件事:① 想象(出创意、指方向、"我想要什么");② 提意见(判断、反馈、"这样不对/更狠一点/选这个")。系统的全部价值,在于把人这两样稀缺输入无损地捕获、放大、并贯穿到 AI 的每一次执行里,同时主动对抗 AI 默认的平庸。北极星 = 作者的想象与品味。**

---

## 0. 原设计错在哪(已按你的纠正修正)

先纠正我自己:**"AI 主笔"不是错的——你确认了,一切文字都该由 AI 实现。** 我上一轮把"人当作者去写"是过度反转。原 18 模块真正的两个根性问题是:

1. **正推而非反推**。我从"一个写作系统该有哪些模块"出发,得到功能清单;没有从"读者为什么爱一本小说"反推。结果是**功能完备但目标失焦**——它能保证不崩、记得住、写得快,却没回答"凭什么写得好"。
2. **没给"人那两件事"修直达通道**。你要的分工是:**人只负责想象 + 提意见,AI 负责全部实现**。原设计却把人当"事后审校"——既没有专门承接**想象/创意/方向**的输入层,也没把**"提意见 → AI 重做"的反馈环**当成主交互,更没有一个**意图与品味内核**去保证 AI 的实现既忠于你的想象、又不滑向平庸。一句话:AI 主笔没错,错在没给"人的想象与意见"修一条直达 AI 的高速路。

下面用第一性原理重新推导,落点正是这条高速路。

---

## 1. 第一层:什么是"好小说"(从读者体验反推,不是从功能反推)

不谈功能,先问:**读者合上书时,什么让 ta 觉得"这是本好书"?** 这些是"felt experience",是终点:

| # | 读者体验 | 本质 |
|---|---|---|
| G1 | **放不下** | 叙事张力/悬念/信息差/未兑现的承诺持续拉着读者 |
| G2 | **被击中** | 情感真实——某一刻读者真的痛/暖/震,而非"被告知该感动" |
| G3 | **人物活着** | 角色有内在一致的欲望与矛盾,会选择、会变,让人记住甚至爱上 |
| G4 | **新鲜** | 独特的声音 + 不可预测的展开;读者猜不到下一步,但回看又觉合理 |
| G5 | **有重量** | 主题——这本书"说了点什么",不只是事件流水 |
| G6 | **文字有质感** | prose 本身的节奏、意象、克制,值得一读再读 |
| G7 | **结构的满足** | 埋设与回收咬合,伏笔兑现时的"原来如此",高潮的必然感 |
| G8 | **世界可信** | 设定自洽、沉浸,读者愿意相信并停留 |

**关键观察:G7、G8(结构/一致)是"对",G1–G6 才是"好"。** 原 18 模块几乎全力解决 G7/G8(伏笔、一致性、记忆、检索),那是**门槛(table stakes)**;真正区分平庸和优秀的 G1–G6,被我严重欠配。

---

## 2. 第二、三层合并:每种"好"怎么被创造,以及 LLM 在哪一步行/不行(能力衔接矩阵)

这是全文的核心。对每种"好",拆出**作者实际做的动作(craft)**,再诚实标注 **2026 年的 LLM 在这一步是强 / 中 / 弱**,并给**根因**。

| 目标 | 作者做的事(craft) | LLM 强项 | LLM 弱项(根因) |
|---|---|---|---|
| **G1 张力** | 制造信息差、延迟满足、埋未答之问、控制揭示节奏 | 能生成悬念句式、能按指令留钩子 | **倾向尽快解决冲突、提前泄底**(训练偏好"完整作答",与"憋着不说"相反) |
| **G2 情感真实** | 用具体细节承载情绪,克制,让读者自己感受 | 能写出"情绪场景"的草稿 | **滑向直白煽情/金句升华**(训练数据里"被点赞的情感表达"多是显性的→趋显性) |
| **G3 人物** | 给角色稳定欲望+矛盾,让选择源于性格 | 能记住设定(配工具)、能生成符合标签的台词 | **角色易"功能化"、为情节服务而非为性格;长程易 OOC**(无持久人格,只有上下文) |
| **G4 新鲜/意外** | 打破读者预期,找非常规但合理的展开;独特语感 | 能一次给 20 个选项(广度) | **默认趋均值、套路化**(next-token 本质是"最可能",而好故事要"出人意料又合理"——与最可能相反) |
| **G5 主题** | 让一切服务于一个内在意图,克制地贯穿 | 能在被明确告知主题时呼应它 | **无持久意图,长程主题漂移;倾向把主题"说出来"而非"渗进去"** |
| **G6 文字质感** | 锤炼节奏、意象、删冗余、找准一个词 | 流畅、合格、量大 | **"AI 腔":辞藻堆砌、万能过渡、排比癖、"不是…而是…"、总结升华**(回归训练均值) |
| **G7 结构** | 设计 setup/payoff、伏笔回收、必然的高潮 | **配状态机/检索后,这是强项**(记得住、查得到) | 纯靠上下文会忘;**但有工具后可解决** |
| **G8 世界自洽** | 维护设定一致、时间线、因果 | **配知识库/校验后,强项** | 纯生成会矛盾;**有工具后可解决** |

### 从矩阵读出的铁律

把"强/弱"按列汇总,得到一张**能力地图**:

**LLM 真正的强项(应大胆自动化):**
- 局部流畅、快速起草(产能)
- 一次生成大量**变体/选项**(广度;人来选)
- 检索式记忆、一致性校验、伏笔追踪(**配了工具就强**——这正是 G7/G8,也正是原 18 模块的价值所在)
- 转换/改写/扩写/换视角(对已有文本做操作)
- 信息整合、调研、陪练(brainstorm 对手)

**LLM 的硬伤(短期不可根治,必须靠"人 + 系统对抗"补):**
- **没有"什么是好"的 ground truth → 趋均值 → 平庸/AI 腔**(G6, G4)
- **没有持久意图 → 主题漂移、角色功能化**(G5, G3)
- **训练偏好"完整、显性、最可能" → 泄底、煽情、套路、填满**(G1, G2, G4)
- **没有品味判断 → 不知道自己写得好不好**

> **这条最关键:LLM 强在"量、续航、一致性",弱在"质、意图、品味、意外"。而"好小说"恰好住在后者。**

## 3. 第四层:由能力边界推导人机分工(系统的真正脊柱)

既然 LLM 弱的地方(品味、意图、意外、克制、情感真实)正是"好"之所在,而强的地方(产能、记忆、一致、变体)是"门槛"——**分工的结论是被能力逼出来的,不是我拍脑袋**:

```
   人(你)= 想象 + 提意见,仅此两件        AI = 全程主笔(实现一切)        系统 = 把两者焊在一起
   ┌──────────────────────────┐   ┌──────────────────────────┐   ┌──────────────────────┐
   │ 想象:出创意、指方向、"我想要" │   │ 起草:把想象变成大纲与正文  │   │ 捕获并放大想象与品味     │
   │ 提意见:判断、反馈、"不对/选B" │ → │ 变体:一个点子给 N 种写法    │ → │ 意见 → AI 重做(低摩擦反馈环)│
   │ (从不亲手写正文)            │   │ 续航:记住 100 万字、查一致  │   │ 默认对抗趋均值(主动反平庸)│
   │                            │   │ 调研/陪练:供料、当对手      │   │ 越用越懂"这个作者"       │
   └──────────────────────────┘   └──────────────────────────┘   └──────────────────────┘
```

**注意:这不推翻"AI 主笔"——AI 仍写下全部文字。它确立的是"人那两件事(想象 + 意见)如何驱动 AI"。** 正确形态:

- **人只想象与判断,AI 实现一切。** 人给方向("我想要一场雨夜的背叛""如果他其实早知道呢")→ AI 变成大纲与正文;人给意见("不够狠""选 B""这段假")→ AI 重做。**人从不亲手写 prose**,只在关键节点从 AI 的多个方案里选、或用自然语言提意见。
- **AI 的默认输出是平庸的**,而且**没有人的手在 prose 上兜底**——质量全压在"忠实实现想象 + 主动反平庸"上。所以系统必须主动对抗:写作时就要求意外、具体、克制、反 AI 腔,而非被动等校验。
- **人的想象与品味必须被系统显式捕获并贯穿一切生成**,否则 AI 会把书慢慢拖回"最可能的平均小说"。这是唯一防线。

> **重要修正(经联网调研后补充):上一版说"AI 弱在判断"过于笼统。更准确的拆分是——AI 弱在「品味判断」(什么是好),但强在「全局判断」(一个想法跟全书冲不冲突、合不合),因为它读得完、记得住 100 万字,而你做不到。** 所以正确的交互不是"你下令、AI 执行",而是**对话式**:AI 当"读完全书的责编",用全局证据指出冲突/缺陷/更优解,你用品味拍板。这条修正催生了系统中枢 [内核0-主编智能体](内核0-主编智能体.md)——你唯一对话的对象。(证据:共创>代笔 [arXiv 2504.12488];AI 当挑战者保护作者声音;主动全文分析是行业空白。)

## 4. 第五层:由分工推出的设计原则(取代"功能清单")

这 7 条是系统的判断标准,任何模块设计若违背,就是错的:

1. **北极星是作者的意图与品味,它是一等公民。** 不是 `theme_anchor` 一个字段能装下的——需要一个专门的"**作者意图与品味内核**"子系统(见 §6),捕获"这本书要让读者感受什么""这个作者觉得什么是好",并驱动规划/写作/评改/评估里**所有的好坏判断**。
2. **AI 产出选项,人做判断。** 关键节点(情节走向、人物抉择、关键场景写法)给 2–4 个有差异的方案 + 各自代价,人选。绝不替人拍板"什么是好"。
3. **默认对抗趋均值。** 把"反平庸"设为生成的默认目标函数,而非事后检查:写作时就要求意外性、具体性、克制;反 AI 腔是底线。
4. **判断密度决定节奏。** 判断密集处(开篇、转折、高潮、情感戏)放慢、多给人控制和选项;体力活处(过场、铺陈、连续性维护)放手自动化。一刀切地"每章都自动写"是错的。
5. **一切可解释、可回流成"作者模型"。** 每段生成能说清依据;人的每次选择/修订/打分都喂回"作者偏好模型",系统越用越懂你。这是护城河——通用 AI 写作工具做不到"懂这一个作者"。
6. **度量绑定"好"而非只绑"对"。** 一致性/伏笔回收是"对",必要但不够;必须同时度量张力、意外性、情感命中、文字质感(承认这些难量化,故以"人评校准 + 自建曲线"为主,见模块 11/17),并用它们反哺,而不是优化到"很对但很平"。
7. **门槛层要隐形,价值层要显形。** 记忆/检索/一致/伏笔(G7/G8)应在后台默默运转、不打扰创作;意图/品味/选项/反平庸(G1–G6)才是作者天天打交道的界面主角。

## 5. 业界最佳实践,对照检验(不是我一个人拍的)

把上面的结论和**可查证的来源**对齐(技术类已核实带 arXiv;方法/产品类标注):

- **"分工:人持意图+判断,AI 续航+变体"** —— 与人机协同写作工具的演进方向一致(NovelCrafter 的人主笔 + Codex 设定库、Sudowrite 的"选项式"生成)。【需复核:产品观察,见上游调研 §4】
- **"AI 默认趋均值 / AI 腔是结构性问题"** —— 与长文生成研究里"连贯但平淡"的已知权衡呼应;BooookScore 发现增量摘要"连贯性更低但细节更丰富",本质是质量维度无单一最优解。【已核实 arXiv 2310.00785】
- **"长程主题漂移、角色不稳"是 LLM 固有问题** —— 多篇论文专门对抗 theme drift / 一致性崩坏,侧证这是真实硬伤而非可忽略。【已核实 2508.03137 / 2503.23512 / 2603.05890】
- **"门槛层(记忆/检索/一致/伏笔)有成熟机制"** —— 正是原 18 模块引用的那批论文。它们是**对的、该用的**,只是定位应是"门槛"而非"卖点"。【已核实】
- **诚实声明**:**"如何让 LLM 写得好(G1–G6)"在学术与产业界都没有银弹**,本设计的价值层多为【设计决策】+【文学创作稳定知识】,必须靠模块 11/17 的自建度量边做边验证。这一点我不粉饰。

## 6. 由此重构:模块不是平铺的 18 项,而是三圈同心

原来的 18 个模块**不作废**——但要按"门槛 / 产能 / 价值"重新归位,让它们服务于上面的脊柱。新增最关键的、原本缺失的**内核**:

```
            ┌─────────────────────────────────────────────┐
            │        ⭐ 内核:作者想象 · 意图 · 品味          │  ← 原设计缺失的中心
            │  想象层(创意输入) + 意图层(北极星) +           │     人唯一的两个输入口
            │  品味层(偏好模型) + 反馈环(提意见→AI重做)      │     新增,见 §6.1
            │  人在这里供料与判断,AI 在下面实现一切           │
            └─────────────────────────────────────────────┘
       ┌────────────────── 价值层(写得好 · G1–G6)──────────────────┐
       │ 17 文学质量机制(反 AI 腔/文风/评改) · 03 方法论(张力/节奏)  │
       │ 10 写作(选项式生成) · 18 素材(供料,喂新鲜感) · 11 评估(度量好)│  ← 系统真正卖点
       └──────────────────────────────────────────────────────────┘
       ┌────────────────── 产能层(写得快 · 续航)──────────────────┐
       │ 04 编排 · 05 记忆 · 02 分层规划 · 13 LLM 路由              │
       └──────────────────────────────────────────────────────────┘
       ┌────────────────── 门槛层(不崩 · G7/G8,后台隐形)─────────┐
       │ 06 检索 · 07 一致性 · 08 伏笔 · 09 设定圣经 · 14 版本      │
       └──────────────────────────────────────────────────────────┘
       ┌────────────────── 地基 ──────────────────┐
       │ 01 架构 · 15 API · 12 前端 · 16 工程化      │
       └────────────────────────────────────────────┘
```

**和原设计最大的不同:**
- 原来 17(文学质量)只是"18 选 1"的平级模块;现在**价值层 + 想象/意图/品味内核才是系统的脸**,门槛层退居后台。
- 新增 **§6.1 的内核**,是原 18 模块完全没有的中心。
- 写作模块 10 **仍是 AI 主笔(写下全部文字)**,但增加两条人机接口:① 关键节点产出**带差异的多个方案**供人提意见挑选;② **意见 → AI 重做**的低摩擦反馈环。人不写 prose,只给方向与意见。

### 6.1 新增内核:作者想象 · 意图 · 品味子系统(原设计的最大空缺)

人只做想象 + 提意见,所以系统必须为这两件事各修一条直达 AI 的通道。这是把"辅助你写出好小说"变成现实的关键,需独立设计文档(拟为模块 19):

- **想象层(创意输入)**:第一类输入,**AI 一切文字的源头**。承接你随时抛出的想象——不只是主题,而是"我想要一场雨夜的背叛""如果主角其实是凶手""这个配角该死得更冤"……碎片化、非结构化也行。系统把它结构化、排期,并在 AI 实现时精准调用,确保 AI 写的是**你的想象**,不是它的均值。
- **意图层(北极星)**:这本书要让读者**感受到什么**、核心情感体验、为什么非写不可。它是 AI 每次执行取舍的最高裁判,持续校验"有没有偏离你真正想写的"。
- **品味层(个性化偏好模型)**:第二类输入(提意见)的沉淀。从你每次的意见、选项里挑哪个、打分、修订指令中,持续学习"**这个作者觉得什么是好/坏**":范本库(正例)+ 负面清单(你删过的 AI 腔)→ 一个越来越懂你的偏好模型,注入 AI 所有生成。**这是护城河:它懂的不是"小说",是"你的小说"。**
- **反馈环(提意见 → AI 重做)**:把这条做成主交互、低摩擦——自然语言批评("更狠""这段假""节奏拖")直接驱动 AI 重写;人永不亲手改 prose。
- 驱动:想象+意图 → 约束规划(02/03)与写作(10);品味+反馈 → 约束写作与评改(10/17);合起来 → 定义评估里"好"的标准(11)。

## 7. 诚实结论

1. **技术机制是真研究,不是瞎编**(arXiv 一手 + 对抗核实)——但它们解决"不崩/记得住/写得快",是**门槛,非充分条件**。
2. **你的批评成立的部分**:原设计是功能堆叠、没从第一性原理反推,且没给"人的想象与意见"修直达 AI 的通道。**但"AI 主笔"没错**——这点我上一轮过度反转了,你纠正得对:一切文字由 AI 实现,人只想象 + 提意见。
3. **第一性原理的结论(修正)**:LLM 强在量/续航/一致,弱在质/意图/品味/意外;故**人只供想象与意见,AI 实现全部**;系统以"想象捕获 + 意图与品味内核 + 意见反馈环"为中心,默认主动对抗趋均值,保证 AI 的实现既忠于你的想象、又不滑向平庸。

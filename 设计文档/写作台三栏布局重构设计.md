# 写作台三栏布局重构设计(VSCode 式左右图标轨)

> 目标:把当前**四栏**的写作台重构成**严格三栏(左 | 中 | 右)**,左右两栏各自带一列竖直图标 tab 轨(参照 VSCode 活动栏),点图标切换该侧面板内容。四阶段(大纲/节拍/草稿/正文)布局一致。

---

## 一、问题诊断(为什么现在是四栏)

当前组件拼装:

```
BinderLayout = react-resizable-panels Group
  ├─ Panel「tree」   → ProjectTree(手稿/素材导航)         ← 第1栏
  ├─ Panel「detail」 → ChapterStudio
  │      └─ 正文用 WriteLayout(内含 Shell 左数据面板)     ← 第2栏(数据面板)
  │      └─ 大纲/节拍/草稿 我新加了 ChapterSidePanel        ← 第2栏(数据面板)
  │      └─ 中区编辑器                                      ← 第3栏
  └─ Panel「chief」  → ChiefDock(主编对话)                ← 第4栏
```

**根因**:项目树(导航)和数据面板(帧/演绎/伏笔…)是**两个独立的左侧列**。ChapterStudio 在 detail 内部又开了一列数据面板,于是 `树 + 数据面板 + 中 + 右 = 四栏`。上一次"给非正文阶段加数据面板"是新增一列,而非与树合并,反而坐实了四栏。

---

## 二、最优化设计:严格三栏 + 左右图标轨

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 顶部栏: SCRIBE3 | 纸命▾ | 图谱 时间线 仪表盘 | ...                    ☾       │
├───┬───────────────┬──────────────────────────┬───────────────┬───┤
│左 │               │  中区                      │               │右 │
│图 │  左面板        │  ⋖ 第N章 ⋗  大纲|节拍|草稿|正文│  右面板        │图 │
│标 │ (随左tab切换)  │                            │ (随右tab切换)  │标 │
│轨 │               │  [阶段编辑器 / ProseEditor] │               │轨 │
│   │               │                            │               │   │
│📁 │ 项目树(默认)   │                            │ 主编对话(默认) │💬 │
│👁 │ 帧/意图        │                            │ 版本存档       │📚 │
│✨ │ 演绎           │                            │               │   │
│📌 │ 伏笔           │                            │               │   │
│📋 │ 素材(结构/母题)│                            │               │   │
│✅ │ 校验*          │                            │               │   │
└───┴───────────────┴──────────────────────────┴───────────────┴───┘
     └ 左栏(可拖宽/折叠) ┘                        └ 右栏(可拖宽/折叠)┘
  *校验/存档:仅在有正文(草稿/正文阶段)时出现
```

### 三栏定义

| | 组成 | 内容 |
|---|---|---|
| **左栏** | `[竖图标轨] + [面板区]` | 图标轨切换:项目树 / 帧/意图 / 演绎 / 伏笔 / 素材 / 校验。默认**项目树**(手稿+素材导航) |
| **中栏** | `[章导航+四阶段tab] + [编辑器]` | 大纲=synopsis框 / 节拍=beats列表 / 草稿=编辑器 / 正文=ProseEditor。四阶段一致地嵌在中区 |
| **右栏** | `[面板区] + [竖图标轨]` | 图标轨切换:主编对话 / 版本存档。默认**主编对话**(阶段感知:正文=写作/其余=讨论) |

### 关键原则

1. **只有三栏**:项目树不再是独立第4栏,而是**左栏图标轨的第一个 tab**(像 VSCode Explorer 是活动栏第一项)。数据面板(帧/演绎/伏笔/素材/校验)是左栏其余 tab。左栏任一时刻只显示一个面板。
2. **左右对称**:左栏图标轨在**最左**、右栏图标轨在**最右**(镜像),面板区各自靠中。
3. **四阶段布局一致**:大纲/节拍/草稿/正文都用同一个三栏外壳,只有中区编辑器随阶段变。彻底消除"只有正文才有面板"。
4. **图标轨是 tab**:每个图标点一下切该栏面板;点当前项可折叠该栏(再点展开)。hover 显示文字标签(节省横向空间)。
5. **阶段感知(内容层,非布局层)**:
   - 左「校验」tab 仅草稿/正文阶段出现(需正文才有 QC);
   - 右「版本存档」tab 仅草稿/正文出现;
   - 右「主编对话」大纲/节拍/草稿=讨论 chat(阶段感知建议),正文=写作槽(出草稿卡/护栏改写)。
6. **宽度**:左栏图标轨固定 44px + 面板默认 240px(可拖 190–420,可折叠);右栏对称,面板默认 320px。

## 三、组件改造

| 组件 | 改动 |
|---|---|
| **shell.jsx** | 已有 Rail(竖图标轨)。恢复/规范:左 Rail 在最左、右 Rail 在最右;Rail 图标 = tab,hover 出文字;支持 badge。 |
| **BinderLayout.jsx** | 不再是 `[树\|中\|主编]` 三 Panel。改为 `[左栏(Rail+面板) \| 中区 \| 右栏(面板+Rail)]`。左栏 Rail 的 tab 集合 = `项目树 + 数据面板caps`;项目树 tab 渲染 ProjectTree,其余渲染对应数据面板。右栏 Rail = `主编 + 存档`。 |
| **ChapterStudio.jsx** | **删掉自带的 ChapterSidePanel 和 WriteLayout 内 Shell 左面板**——数据面板上移到 BinderLayout 左栏统一承载。ChapterStudio 只负责**中区**(章导航+四阶段tab+编辑器)。 |
| **WriteLayout.jsx** | 拆分:①正文编辑器(ProseEditor+护栏+存为正文)留在中区;②它原来的 leftCaps(素材/校验/演绎/帧/存档)上交给 BinderLayout 左栏;③WriteChat 仍 portal 进右栏「主编」tab。 |
| **ChiefDock.jsx** | 成为**右栏面板**的一个 tab(主编);新增「存档」tab(VersionPanel)。仍按 chapterPhase 切写作槽/讨论。 |
| 数据面板 | FramePanel/DeducePanel/VersionPanel 已独立;素材(结构/母题)、校验(QC/泄露/伏笔/在场)从 WriteLayout 抽成独立组件,供左栏调用。 |

### 数据流(关键)
左栏数据面板需要 `seq`(当前章)、`focalizer`(当前章视角)、`phase`(当前阶段)。这些由 BinderLayout 持有(它已知 selId→章),经 props 下发左栏面板与中区 ChapterStudio,单一数据源,避免各自拉取不一致。

## 四、交互细节

- **左栏默认**:项目树(打开 app 先看到导航,符合直觉)。选中某章→中区打开写作台→用户可点左轨图标切到「帧/演绎」等边写边看。
- **右栏默认**:主编对话(始终在线)。
- **折叠**:点左轨当前高亮图标→左栏收起只剩 44px 图标轨(中区变宽);右栏同理。给"沉浸写作"留空间。
- **持久化**:左/右当前 tab、栏宽、折叠态存 localStorage。
- **badge**:校验 tab 显示 QC/泄露问题数(护栏红点);伏笔 tab 显示待收数。

---

## 五、验收标准

1. 任意阶段(大纲/节拍/草稿/正文)截图:**恰好三个竖直分区**(左栏 | 中区 | 右栏),左最左、右最右各一条图标轨。
2. 左轨点「项目树」显示手稿/素材树;点「帧/演绎/伏笔/素材/校验」显示对应数据(与当前章一致)。
3. 右轨点「主编」显示阶段感知对话;点「存档」显示版本历史。
4. 四阶段布局骨架完全一致,只中区编辑器变。
5. 折叠左/右栏→中区相应变宽;零 console 报错;build 绿。

---

## 六、实施顺序

1. shell/BinderLayout:搭三栏骨架(左 Rail+面板 | 中 | 右面板+Rail),项目树进左轨第一 tab。
2. 抽出素材/校验面板为独立组件;左栏 caps 汇总(项目树+帧+演绎+伏笔+素材+校验)。
3. ChapterStudio 瘦身为纯中区;WriteLayout 正文编辑器留中区、WriteChat portal 进右「主编」。
4. 右栏:主编 + 存档两 tab。
5. 阶段感知(校验/存档 tab 条件显示;主编写作/讨论切换)。
6. 持久化 + badge + 折叠 + 真机四阶段截图验收。

## 一句话:系统是什么

**AI 全程主笔**(从大纲到成稿的一切文字都由 AI 实现);**人只做两件事**——① 想象(出创意、指方向)② 提意见(判断、反馈)。系统把人这两样稀缺输入**无损捕获、放大、贯穿**到 AI 每一次执行,并**默认对抗 AI 的平庸**。

```
人: ①想象 ──────────▶ AI: ②实现一切(出多方案)──────▶ 成稿
     ▲                                                    │
     └────────── ③提意见 ◀── 人 ◀──────────────────────┘
   外包一层: [品味学习:越用越懂你的书]  [反平庸 + 连贯保障(后台)]
```

详见 → **[设计哲学-第一性原理与LLM能力衔接](设计哲学-第一性原理与LLM能力衔接.md)**(地基,先读这篇)

## 建设顺序(详见 [工程7](工程7-工程化与路线图.md))

**全功能交付,不做 MVP 阉割**(00 §3 原则 11):按**依赖顺序的建设批次**落地,每个模块按完整设计实现。

`前置 spike(Hermes qmd/sqlite-vec + 领域 MCP + Open WebUI)` → `底座+数据(SQLite/Hermes)` → `协作回路(内核0/1)+ 复用对话 UI` → `规划/写作(实现1/2)+ 检索(实现4)` → `品味/反平庸(内核2/3)` → `连贯/设定(门槛1/2)` → `素材` → `主动引擎+自我优化` → `小说编辑器面板(工程2/2b,与后端并行)` → `多本书/作品库` → `个性化(Hermes LoRA)` → `规模化(按阈值切 pgvector/多租户)`

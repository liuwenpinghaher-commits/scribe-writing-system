# 复盘蒸馏+lesson 反哺调研报告(北极星方案任务8 前置)

> goal 调研义务(五组件之"复盘蒸馏");2026-07-05。**创作领域直接先例:未查到——"从作者-AI 编辑对话蒸馏结构化 lesson 挂章"我们是第一批**;最近邻 CIPHER(写作场景从编辑学偏好)。

## 核心先例

- **Mem0**(arXiv 2504.19413):两阶段——抽取(会话摘要+近 m 条消息→salient memories)+更新(每条候选检索 top-10 相似旧记忆,LLM 从 ADD/UPDATE/DELETE/NOOP 四操作选一)。防复述原文=抽取即改写为原子事实;官方 prompt 文档:输出 JSON 数组、原子拆分、**负例 few-shot("Hi"→返回空数组)**。
- **LangMem**:semantic/episodic/procedural 三类(lesson 三类横跨前两者,craft_rule 对应 procedural);background(会话后反思)模式=我们的 ingest 后 pass;schema 化抽取防复述。
- **Zep/Graphiti**(2501.13956):episode 子图与 semantic 子图物理分层+事实边双时态 t_valid/t_invalid(失效标记不删除)——与"lesson 严禁复述世界状态、原始对话归 chat_message"分层同构。
- **Generative Agents**(2304.03442):重要性 LLM 1-10 打分;检索分=recency(0.995/游戏小时衰减)+importance+relevance 等权;反思触发=近期重要性和>150;洞见带**证据指针**("because of 1, 2, 8, 15")。
- **ExpeL**(2308.10144):insight 池 ADD/EDIT/UPVOTE/DOWNVOTE;初始重要性 2,±1,**归零自动删除**——现成 lesson 生命周期计数器;其教训:全量拼接注入在 lifelong 场景必须改检索式。
- **Voyager** top-5 检索;**AutoGuide**"条件→规则"格式(state-aware guideline);**Reflexion** episodic buffer 上限 3。

## 量控与污染证据(最重要)

- **Power of Noise**(2401.14887,SIGIR 2024):**"相关但不含答案"的文档比完全无关的更有害**——语义相近但不适用的 lesson 比不注入更糟,必须设相似度下限而非凑满 k。
- Context Rot(Chroma 2025):10k→100k token 简单任务掉 20-50%;Lost in the Middle(2307.03172):中部信息掉 30%+→注入位置靠段首尾。
- LongMemEval(2410.10813):全量塞历史掉 30-60%,检索式显著优。
- top-k 常用值:Voyager 5/Mem0 默认 3;社区共识 5-10 条上限。
- **误差自增强**(2505.16067):错误记忆被检索→错误输出→再入库→跨任务复利放大;建议入库质量把关+用后续表现当免标注质量信号。
- 投毒:AgentPoison 82% 检索命中;SpAIware(ChatGPT memory 持久注入);Willison"memory dossier"体验翻车——**全部指向:蒸馏产物自动生效是高危通道,"升格必须待批"的宪法条款证据链完整**。

## 用户纠偏信号

- **PRELUDE/CIPHER**(2404.15269,NeurIPS 2024,最贴):从"agent 输出→用户编辑后版本"差异归纳自然语言偏好描述入库,按 context 相似度检索聚合注入;**存归纳偏好,不存编辑原文**。
- Cursor Tab 在线 RL:accept/reject 直接当 reward(+0.75/-0.25),不需 RLHF 重管线;Copilot:接受率是感知生产力最佳预测子。

## 对任务8 实现的 5 条建议(采纳裁决记台账)

1. **蒸馏 prompt=原子条目+固定 schema+负例 few-shot**:每条 lesson=一句话结论+类型(decision/correction/pitfall)+适用条件(AutoGuide 条件→规则,禁无条件断言)+证据指针(chat_message id);纠偏类写成 CIPHER 式("用户把 X 改为 Y ⇒ 偏好 Z");负例显式给"剧情事实/人物状态/世界观→返回空"(世界状态越界防护与 Mem0 负例同机制)。
2. **软去重**:候选先在本作品 lesson 索引召回 top-10,LLM 裁决 ADD/UPDATE(合并计数+1)/NOOP;importance counter(初始 2,跨章重复 +1,用户否定 -1,归零退役);计数≥N 进 craft_rule **候选队列仅止于候选**(待批宪法,别松)。
3. **召回 k=3-5+相似度下限+固定几百 token 预算**:宁缺勿滥;query 用下一章大纲/简报要点(按 context 检索);注入位置=简报"上章复盘要点"独立段。
4. **过期分型**:correction 类不做时间衰减(偏好最稳最值钱);pitfall/decision 用"最近被召回时间"驱动衰减(召回+1 重置);被推翻的决策用 invalid_at 失效标记不物理删除(craft_rule 审批溯源链)。
5. **质量闭环字段**:记每条 lesson 注入次数+注入后信号(下章 critique/同类纠偏是否复发),坏 lesson 降计数退役——2505.16067 的免标注质量信号,防污染路径的系统性解药。

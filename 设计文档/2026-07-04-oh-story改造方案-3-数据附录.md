## A. 否定翻转句检测(主篇 1.1)—— 源 `scripts/check-ai-patterns.js`

### A.1 常量(逐字)
```js
const STOP_CHARS = new Set(['。','！','？','!','?','\n']);
const SOFT_SEPARATORS = new Set(['，',',','、','；',';','：',':']);
const HARD_SEPARATORS = new Set(['。','.','！','!','？','?']);
const MAX_NEGATIVE_SPAN = 80;   // "不是"后向前扫的最大跨度
const MAX_POSITIVE_SPAN = 80;
// either-or「不是A就是B / 不是A也是B」紧贴的"是"是连词一部分,不是系动词
const COMPACT_EITHER_OR_PREV = new Set(['不','就','也']);
// 反问尾「…是吗/是吧/是嘛」不是否定后的肯定翻转
const TAG_PARTICLES = new Set(['吗','吧','嘛']);
```

### A.2 检测逻辑(4 变体 + 结构性护栏,Python 移植要点)
从每个 `不是` 起扫,命中即报 `not-is-comparison`(severity=blocking):
1. **紧凑`而是`**:`不是A而是B` → 命中。
2. **软分隔+而是/是**:遇 `，、；：` 后接 `而是` 或 `是`(且其后非 TAG_PARTICLES)→ 命中(`不是A，是B` / `不是A，而是B`)。
3. **硬分隔(句号)+是**:`不是A。是B` → 命中(句号变体,`char==='.'` 才继续扫、其余硬分隔 break)。
4. **紧凑`是`**:`不是A是B` → 命中,**但仅在跨任何分隔符之前**(`!crossedSeparator`)且前一字不在 `COMPACT_EITHER_OR_PREV`。

**关键护栏(照搬,别自己写)**:
- `不是` 前一字是 `是` → 跳过(避开疑问 `是不是`)。
- 跨分隔符后的紧凑 `是` 一律不判——因为 `只是/可是/但是/还是/于是/倒是/总是` 的尾 `是` 是连词一部分(#166 假阳性类)。这靠**结构性 `crossedSeparator` 标志**实现,**不是**枚举词表。
- either-or `不是A就是B / 也是B` 的 `就/也` 已在 COMPACT_EITHER_OR_PREV 排除。
- `不是A，也不是B` 第二个否定段不算翻转。
- 命中片段可见字数 ≥4 才报(去噪)。

### A.3 维基上游补三变体(外部 SOTA,主篇 1.1 尾)
除上述,补:
- `不仅…而且…` / `不仅…还…`(Not just X but Y)
- `…而非…`(X rather than Y)
- `与其说…不如说…`
护栏同理:句内、跨度限制、引号外(见 B)。

## B. 引号剥离豁免 stripQuoted(主篇 1.2)—— 逐字

剥 **7 对**引号后再做复读/排比/碎句号计数(纯台词/弹幕成片短句是体裁正常形态,豁免;混合行引号外叙述仍计):
```js
function stripQuoted(text){
  return text
    .replace(/「[^」]*」/g,'').replace(/『[^』]*』/g,'').replace(/【[^】]*】/g,'')
    .replace(/“[^”]*”/g,'').replace(/‘[^’]*’/g,'')
    .replace(/"[^"]*"/g,'').replace(/'[^']*'/g,'');
}
```
scribe3 已有 `_strip_dialogue`(critique.py:870),核对是否覆盖这 7 对;不足则补齐,接进 `find_repetitions`/`find_parallelism`/`find_structural_repeats`。

## C. 中文禁用词分级表(主篇 1.3)—— 源 `references/banned-words.md`,进 find_ai_tics(建表)

> ⚠先归位:比喻词 `仿佛/如同/宛如/好似/犹如` 已在 `find_oversaturation._SIMILE_WORDS`,**不重复**进 find_ai_tics。

### C.1 最毒句式(★分级,命中即报)
| 毒级 | 句式 |
|---|---|
| ★★★★★ | `不是A(而)是B` / `不是A,不是B,(而)是C`("而"可省)→ 见 §A |
| ★★★★ | `,带着……`万能状语 · `声音不大,却带着一种……的力量` · `他/她知道……` |
| ★★★ | `仿佛/犹如/宛若……一般` · `眼中闪过一丝……` / `嘴角勾起一抹……` · `心中涌起一股……` / `心头一震` |
| ★★ | 章末预告 `他不知道的是……` |
> 命中 ★★★★★ 一处=重度 AI 味强证据;★★★★ 命中 ≥2 处触发中度复扫。

### C.2 一级禁用词(出现即替换,按类)
- **情态类**:一丝、一抹、些许、几分、隐约(比喻类 仿佛/犹如/宛若/如同 已归 find_oversaturation)
- **动作类**:深吸一口气、缓缓、不禁、微微、轻轻、淡淡
- **表情类**:眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩
- **心理类**:心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得
- **判断类**:不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认
- **形容类**:坚定、闪烁着光芒、狡黠、深邃、凛冽、冰冷
- **过渡类**:不由自主、情不自禁、自然而然

### C.3 二级语境敏感词(仅高频/偷懒时报)
突然、好像、瞬间(角色口语/真实突发/时间压缩/视角不确定时可保留)

### C.4 总结/升华/排比句式(进 find_ai_tics 或定档聚合)
- 总结:`他/她终于明白…` `他/她这才意识到…` `此刻,他/她…` `一切…都…` `原来…`
- 升华:`这一刻…` `他知道…` `她明白…` `这就是…`
- 排比:连续 3 句以上相同结构 · `有的…有的…有的…` · `一边…一边…一边…`

### C.5 白名单豁免(主篇 1.3)
配 per-work 子串豁免(对齐 oh-story `.deslop-whitelist`),防误伤世界观术语/绰号/地名。**注意:这是豁免路径,不能复用 extra_patterns(加法标记)**——新写 allow 判定。

## F. 句长方差 / burstiness 量化(主篇 1.6,外部 SOTA 头号)—— 新算法

> 全球检测器(GPTZero/DetectGPT/Binoculars)+中文降 AIGC 实证公认:句长分布异常均匀=头号 AI 破绽。scribe3/oh-story 都缺。新建 `find_rhythm_uniformity`。

### F.1 算法草案(纯确定性)
1. **切句**:按 `[。！？!?…]`(参考 oh-story splitSentences),可见字数用 `[一-鿿A-Za-z0-9]` 计(去标点/空白)。
2. **过滤**:剥引号(§B)只算叙述句;弹幕/对话/系统播报豁免(否则弹幕体误报)。
3. **指标**(章级 + 书级):
   - 句长**标准差 σ** 与**变异系数 CV = σ/μ**;
   - **相邻句长差 |Lᵢ₊₁−Lᵢ| 的均值/分布**(burstiness 近似);
   - 可选:句长直方图熵(越低越均匀)。
4. **判定**:CV / 相邻差均值**低于阈值**=节拍器式均匀 → 报"节奏 AI 化"(advisory,report-only)。
5. **护栏**:短章(<N 句)不判;题材开关(某些体裁短句密集正常)。

### F.2 阈值标定
**必须真机标定**:取纸命等已达标章(人写/精修)算 CV 分布定下限,取 AI 初稿算上限,阈值取分界。**不要拍脑袋定常数**——这是唯一需要数据标定的检测器。

## G. 副词密度 + 句内三段式 + 同义词循环(主篇 1.7)

- **副词密度**(`anti-ai-writing.md` 模式2):`微微、淡淡、缓缓、轻轻` 每 1000 字 >3 = AI 签名。滑窗计密度,超阈报。
- **句内三段式**(维基 rule of three):句内形容词/短语三连(`A、B、C` 或 `A的B的C的`);区别于 scribe3 已有的句首 anaphora。
- **同义词循环**(维基 elegant variation):同一指称对象短距(如 200 字窗)内多同义词轮换(主人公→主角→中心人物→英雄)。需指称消解或人工同义组表,可先做"已知角色名 vs 泛称(那男人/少年/青年)在近距内交替"的确定性近似。

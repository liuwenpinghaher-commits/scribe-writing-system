# 功能与字段覆盖矩阵

本轮以当前代码、OpenAPI、真实 UI 和数据库读回为准。字段口径：A=UI 直填，B=主编/审批触发，C=系统生成，D=只读派生，E=当前 UI 不可达或内部字段。完整静态盘点源文件：`/tmp/scribe3-feature-field-inventory.md`。

| 域 | 核心对象/字段 | 分类 | 当前状态 |
|---|---|---|---|
| 作品 | title、slug、归档/恢复/永久删除 | A/C/D/B | 创建已通过；其余待回归 |
| 卷章 | volume、chapter、四阶段、版本、归档、重排 | A/B/C/D | 待执行 |
| 设定库 | 角色、势力、物件、术语、世界规则 | A/B/C/D/E | 待执行；地点暂无专用 UI，预置 E 缺口 |
| 限知 | proposition、secret、leak_markers、knows、reader_knows、时态 | A/B/C/D/E | 私密命题创建、读者屏蔽与后端真值回读已通过；知识边与时态演进待覆盖 |
| 关系事件 | 关系有效期、事件因果、故事/叙事双轴 | A/B/C/D | 待执行 |
| 工艺 | 伏笔、母题、声音、角色弧 | A/B/C/D | 角色弧与声音已通过；卷级伏笔、作者答案、兑现窗口、线索已通过；母题和回收待覆盖 |
| 素材记忆 | 导入、预览、确认、召回、溯源、网络 | A/B/C/D | 手工素材、检索、人工插稿与反向溯源已通过；文件/网络导入和网络视图待覆盖 |
| 主编 | 讨论、agentic、审批、线程、上下文、记忆 | A/B/C/D | 待执行 |
| 写作与质量 | 提案、选区、保存、ingest、QC、治疗 | A/B/C/D | 待执行 |
| 横切视图 | 图谱、时间线、仪表盘、进度、设置、导出 | A/C/D | 待执行 |

通过标准：A 必须由 UI 有意义地填写；B 必须经过真实主编/审批；C 必须由业务动作产生并读回；D 必须与源数据一致；E 不得绕过，必须作为产品缺口报告。
